## 2. プロフィール

### 2.1 背景

対象範囲とWCAGレベルを先に整理すると、実装方針が安定するため。

### 2.2 目的

アクセシビリティ要件と範囲を明確化する。

### 2.3 責務

| 責務       | 成果物       |
| ---------- | ------------ |
| 範囲整理   | 要件整理メモ |
| レベル整理 | WCAGレベル   |
| 制約整理   | 制約リスト   |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 対象UIとユーザー層を整理する   |
| 2        | WCAGレベルと達成目標を整理する |
| 3        | 制約と優先度を記録する         |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 範囲     | 範囲が明記されている     |
| レベル   | レベルが明記されている   |
| 制約     | 制約が整理されている     |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                   |
| ---- | ---------------------- |
| 範囲 | 対象ページを明確にする |
| 目標 | WCAG達成基準を明記する |

---
