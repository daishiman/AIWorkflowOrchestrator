## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション             |
| -------- | ---------------------- |
| 1        | 評価結果を整理する     |
| 2        | 重要指標を抽出する     |
| 3        | レポートに落とし込む   |
| 4        | 共有ポイントを記録する |

### 4.2 チェックリスト

| 項目     | 基準                   |
| -------- | ---------------------- |
| レポート | 必須項目が揃っている   |
| サマリ   | 重要点が明記されている |
| 体裁     | 読みやすい構成         |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                             |
| -------- | -------------------------------- |
| 共有優先 | ステークホルダー向け要約を含める |
| 記録必須 | レポートを必ず保存               |
