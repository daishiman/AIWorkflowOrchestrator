## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 優先度と期限を整理する   |
| 2        | 修正手順を整理する       |
| 3        | リスクと代替案を記録する |
| 4        | 運用方針をまとめる       |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 計画     | 実行順序が明記されている |
| 期限     | 期限が明記されている     |
| リスク   | リスクが記録されている   |
| 出力検証 | 必須項目が欠けていない   |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                   |
| -------- | ---------------------- |
| 実行可能 | 実行可能な計画のみ記載 |
| 記録必須 | 計画は必ず記録         |
