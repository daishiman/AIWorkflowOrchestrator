# Level 1: Basics

## 概要

ベストプラクティスの収集と評価の基本を整理する。

## 基本概念

- 情報源の分類（一次/二次/三次）
- 品質評価（正確性/完全性/明確性）
- 統合パターン

## 使用タイミング

- 新しいベストプラクティスを収集する時
- 評価基準を整備する時

## 最小手順

1. 収集対象を明確にする
2. 情報源を分類する
3. 評価チェックリストで採点する
4. 統合方針を決める
