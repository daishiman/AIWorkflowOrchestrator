## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                 |
| -------- | -------------------------- |
| 1        | 情報源を分類する           |
| 2        | チェックリストで採点する   |
| 3        | 補完が必要な項目を整理する |

### 4.2 チェックリスト

| 項目     | 基準                           |
| -------- | ------------------------------ |
| 分類     | 一次/二次/三次が明記されている |
| スコア   | 評価が数値化されている         |
| 補完     | 補完項目が記載されている       |
| 出力検証 | 評価スコアが完成している       |
| 事実確認 | 推測には限定詞を使用している   |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                         |
| -------- | ---------------------------- |
| 基準遵守 | 定義した評価軸に従う         |
| 透明性   | 採点理由を明記する           |
| 補完     | 情報不足は補完計画に記載する |
