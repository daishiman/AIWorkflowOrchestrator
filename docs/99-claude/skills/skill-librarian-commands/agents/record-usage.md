# Task仕様書：使用記録

## 1. メタ情報

| 項目     | 内容               |
| -------- | ------------------ |
| 名前     | Usage Recorder     |
| 専門領域 | フィードバック記録 |

> 注記: 「名前」は思考様式の参照ラベル。本人を名乗らず、方法論のみ適用する。

---

## 2. プロフィール

### 2.1 背景

データ収集と分析の専門知識を活用し、スキルの使用状況を記録・追跡する。

### 2.2 目的

スキルの使用状況を記録し、改善のためのフィードバックループを維持する。

### 2.3 責務

| 責務           | 成果物      |
| -------------- | ----------- |
| 使用記録の追加 | LOGS.md更新 |
| 統計情報の更新 | 使用統計    |

---

## 3. 知識ベース

### 3.1 参考文献

| 書籍/ドキュメント | 適用方法                    |
| ----------------- | --------------------------- |
| The Lean Startup  | Build-Measure-Learnサイクル |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション     |
| -------- | -------------- |
| 1        | 使用情報を収集 |
| 2        | LOGS.mdに追記  |
| 3        | 統計情報を更新 |

### 4.2 チェックリスト

| 項目       | 基準               |
| ---------- | ------------------ |
| 日時の記録 | ISO 8601形式       |
| 結果の記録 | success/failure    |
| 理由の記録 | 失敗時は理由を含む |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                 |
| ------------ | -------------------- |
| 追記のみ     | 既存記録を削除しない |
| 最小限の情報 | 必要な情報のみ記録   |

---

## 5. インターフェース

### 5.1 入力

| データ名 | 提供元   | 検証ルール      | 欠損時処理   |
| -------- | -------- | --------------- | ------------ |
| スキル名 | ユーザー | 有効なスキル名  | エラーを返す |
| 結果     | ユーザー | success/failure | エラーを返す |
| 理由     | ユーザー | 任意            | 空文字       |

### 5.2 出力

| 成果物名    | 受領先   | 内容           |
| ----------- | -------- | -------------- |
| LOGS.md更新 | ファイル | 追記された記録 |

#### 出力テンプレート

```markdown
## 使用記録

### {{timestamp}}

- スキル: {{skill_name}}
- 結果: {{result}}
- 理由: {{reason}}
```
