## 目的

- スキルの使用パターンを追跡

## 使用方法

スキル実行後、以下のコマンドでログを記録：

```bash
node .claude/skills/query-optimization/scripts/log_usage.mjs \
  --result success \
  --phase "Phase 2: Optimization" \
  --agent "QueryAnalyzer" \
  --notes "N+1問題をJOIN戦略で解決、クエリ数を100→1に削減"
```

## フィードバック収集の指針

### 記録すべき成功パターン

- クエリ実行時間の具体的な改善値
- N+1問題の解消による影響
- インデックス追加の効果測定
- 実行計画分析による最適化の成果

### 記録すべき失敗パターン

- 最適化が期待通りに機能しなかった理由
- 選択した戦略が不適切だった要因
- 新たに発生したボトルネック
- ツールやスクリプトの不具合

### 改善提案の記録

- スキル内容の追加・修正提案
- 新しいパターンやアンチパターンの発見
- ツール・スクリプトの改善アイデア
- ドキュメントの明確化が必要な箇所
