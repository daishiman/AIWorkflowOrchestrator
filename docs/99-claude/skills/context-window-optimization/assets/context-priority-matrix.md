# 優先順位付けマトリクス

## 使い方

- 各情報項目を重要度・再利用性・依存度で評価する
- 合計スコアで「保持/圧縮/削除」を判断する

## 評価表

| 情報項目 | 重要度 (1-5) | 再利用性 (1-5) | 依存度 (1-5) | 合計 | 判定 |
| -------- | ------------ | -------------- | ------------ | ---- | ---- |
|          |              |                |              |      |      |

## 判定ルール（例）

- 合計 12以上: 保持
- 合計 8-11: 圧縮
- 合計 7以下: 削除候補
