# レベル4: 専門

## 概要

長期運用や複数フェーズにまたがるコンテキスト管理を扱う。

## 前提条件

- レベル3の圧縮サマリが完成している
- 検証とログ運用が可能

## 詳細ガイド

### 使用タイミング

- 長期的な会話や反復改善が必要な場面
- 追加情報を段階的に読み込む場面

### 必要な知識

- 段階的な情報開示の設計
- 計測データの蓄積と再利用

### 主要リソース

- `references/Level3_advanced.md`: 圧縮成果の前提
- `references/requirements-index.md`: 仕様整合性の確認

### 成果物要件

- 改善サイクルに必要なログと指標が残る
- 次回の最適化に再利用できる

## 実践手順

1. 検証結果をログに記録する
2. 改善仮説を更新する
3. 次回に向けてテンプレートを調整する
