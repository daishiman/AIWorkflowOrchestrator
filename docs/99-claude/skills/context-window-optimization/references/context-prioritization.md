# 情報優先順位付けガイド

## 目的

必須情報の保持と削減対象の明確化を行う。

## 優先順位カテゴリ

| カテゴリ | 説明 | 例 |
| --- | --- | --- |
| 必須 | 欠落すると目的が達成できない | 主要要件、出力仕様 |
| 重要 | 品質を支えるが必須ではない | 背景、前提 |
| 補助 | 参考情報、後で読める | 参考リンク |
| 削除候補 | 目的に寄与しない | 重複、雑談 |

## 判断基準

- 目的との直接関係があるか
- 依存関係があるか
- 再利用性があるか

## 実務フロー

1. 情報を分類する
2. 必須を確定する
3. 重要/補助を圧縮対象にする
4. 削除候補を明確化する

## 出力形式（推奨）

- 必須: 箇条書きで全件列挙
- 重要: 圧縮理由と一緒に整理
- 補助: 参照先だけ残す
- 削除候補: 削除理由を記録
