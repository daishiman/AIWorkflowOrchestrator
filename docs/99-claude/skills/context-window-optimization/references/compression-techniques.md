# 圧縮技法ガイド

## 目的

情報量を維持しながらトークン使用量を削減する。

## 基本ルール

- 必須情報は削除しない
- 意味が変わる削減は行わない
- 圧縮理由を記録する

## 圧縮パターン

| パターン | 内容                   | 注意点           |
| -------- | ---------------------- | ---------------- |
| 重複排除 | 同じ情報の重複を削除   | 参照先を残す     |
| 要約     | 段落単位で要点化       | 主語・結論を残す |
| 構造化   | 箇条書き・表に整理     | 形式を統一する   |
| 圧縮語彙 | 長い表現を短い語に置換 | 意味の維持       |
| 参照化   | 詳細を参照リンクに集約 | 参照先を明記     |

## 実践手順

1. 圧縮対象を選定する
2. ルールに沿って圧縮する
3. 必須情報の欠落を確認する
4. 削減率を記録する
