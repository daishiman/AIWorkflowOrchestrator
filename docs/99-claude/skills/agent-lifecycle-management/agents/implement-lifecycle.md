## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                |
| -------- | ----------------------------------------- |
| 1        | コンテキスト分析結果を確認                |
| 2        | 対応するレベルガイドを参照                |
| 3        | `references/execution-protocol.md` を確認 |
| 4        | `assets/lifecycle-template.md` を参照     |
| 5        | 状態遷移ロジックを実装                    |
| 6        | リソース管理（初期化/終了）を実装         |
| 7        | 監視・ログポイントを実装                  |
| 8        | 実装ドキュメントを出力                    |

### 4.2 チェックリスト

| 項目         | 基準                                    |
| ------------ | --------------------------------------- |
| 状態遷移     | 全遷移パスが実装されている              |
| リソース対称 | 初期化と終了が対称的に実装されている    |
| バージョン   | バージョニング戦略が定義されている      |
| 監視ポイント | ログ/メトリクスが各段階に配置されている |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                             |
| -------------- | -------------------------------- |
| プロトコル準拠 | execution-protocol.md に従うこと |
| 非同期化       | 長時間処理は非同期化を検討       |
| リークなし     | リソースリークを防止すること     |
