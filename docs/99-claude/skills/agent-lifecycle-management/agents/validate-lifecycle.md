## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                  |
| -------- | ------------------------------------------- |
| 1        | 実装ドキュメントを確認                      |
| 2        | `scripts/check-lifecycle.mjs` を実行        |
| 3        | `scripts/validate-skill.mjs` を実行         |
| 4        | プロトコル準拠を確認                        |
| 5        | 問題があれば implement-lifecycle に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存        |
| 7        | 検証結果レポートを出力                      |

### 4.2 チェックリスト

| 項目               | 基準                              |
| ------------------ | --------------------------------- |
| ライフサイクル検証 | check-lifecycle.mjs が終了コード0 |
| スキル構造         | validate-skill.mjs が終了コード0  |
| 状態遷移網羅       | 全遷移パスがテストされている      |
| リソースリーク     | リソースリークが検出されない      |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                             |
| ------------ | -------------------------------- |
| 改善必須     | 問題検出時は具体的改善策を提示   |
| 記録必須     | 成功・失敗に関わらず記録を保存   |
| 両スクリプト | ライフサイクルと構造の両方を検証 |
