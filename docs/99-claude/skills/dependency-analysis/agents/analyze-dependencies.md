## 2. プロフィール

### 2.1 背景

依存方向と境界を整理し、分析対象を明確化する。

### 2.2 目的

対象範囲と抽出条件を整理し、依存グラフの基礎情報を作成する。

### 2.3 責務

| 責務     | 成果物       |
| -------- | ------------ |
| 対象整理 | 対象範囲メモ |
| 抽出条件 | 抽出条件メモ |
| 目的整理 | 要件メモ     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                   |
| -------- | ---------------------------- |
| 1        | 対象範囲と除外条件を整理する |
| 2        | 依存抽出ルールを決定する     |
| 3        | 目的と優先度を記録する       |
| 4        | 不明点を整理する             |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 対象範囲 | 対象が明記されている     |
| 抽出条件 | パターンが明記されている |
| 目的     | 目的が明記されている     |
| 出力検証 | 必須項目が欠けていない   |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                   |
| -------- | ---------------------- |
| 影響範囲 | 影響範囲を必ず記録する |
| 除外条件 | 除外パターンを明示する |
