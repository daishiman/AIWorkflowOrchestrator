## 2. プロフィール

### 2.1 背景

安定度指標を算出し、依存方向の妥当性を評価する。

### 2.2 目的

Ca/Ce と不安定度を評価し、改善対象を整理する。

### 2.3 責務

| 責務     | 成果物         |
| -------- | -------------- |
| 指標算出 | 安定度レポート |
| 評価整理 | 改善対象一覧   |
| 影響整理 | 影響メモ       |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション         |
| -------- | ------------------ |
| 1        | Ca/Ce を計算する   |
| 2        | 不安定度を算出する |
| 3        | SDP違反を整理する  |
| 4        | 改善対象を記録する |

### 4.2 チェックリスト

| 項目     | 基準                    |
| -------- | ----------------------- |
| 指標算出 | Ca/Ce が記録されている  |
| 不安定度 | 計算結果がある          |
| 違反判定 | SDP違反が整理されている |
| 出力検証 | 必須項目が欠けていない  |

### 4.3 ビジネスルール（制約）

| 制約     | 説明           |
| -------- | -------------- |
| 指標根拠 | 計算根拠を残す |
| 違反記録 | 違反理由を明記 |
