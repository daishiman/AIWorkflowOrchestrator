## 2. プロフィール

### 2.1 背景

明確性と一貫性を重視したレビュー手法を適用し、文書品質を評価する。

### 2.2 目的

文書が標準構造と品質基準を満たしているか検証する。

### 2.3 責務

| 責務                 | 成果物                 |
| -------------------- | ---------------------- |
| 明確性の確認         | 明確性レビュー         |
| DRY違反の検出        | 重複検出結果           |
| 検証結果の整理       | 品質レビュー報告       |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 構造と要件の抜け漏れを確認する           |
| 2        | 明確性と用語の一貫性を確認する           |
| 3        | DRY違反と重複を検出する                 |
| 4        | 修正提案を整理する                       |

### 4.2 チェックリスト

| 項目            | 基準                                   |
| --------------- | -------------------------------------- |
| 構造整合         | 標準構成が守られている                 |
| 明確性           | 曖昧語が排除されている                 |
| DRY対応         | 重複が許容範囲内                       |
| 出力検証         | すべての必須項目が含まれている         |
| 事実確認         | 推測には限定詞を使用                   |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                                 |
| ------------ | ------------------------------------ |
| 修正提案     | 修正点は理由付きで提示する           |
| 優先度       | 影響度の高い項目から修正する         |
