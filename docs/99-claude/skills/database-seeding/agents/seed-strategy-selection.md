## 2. プロフィール

### 2.1 背景

データ整合性と冪等性を重視し、投入戦略の選定基準を明確にする。

### 2.2 目的

要件に合致したシード戦略を整理し、環境ごとの優先度を決定する。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 目的と対象環境を整理する |
| 2        | 要件テンプレートを埋める |
| 3        | 戦略候補を比較する       |
| 4        | 優先度とリスクを記録する |

### 4.2 チェックリスト

| 項目     | 基準                         |
| -------- | ---------------------------- |
| 目的整理 | 対象と優先度が明記されている |
| 冪等性   | 反復実行時の方針がある       |
| 制約整理 | 本番実行条件が明記されている |
| 出力検証 | 必須項目が欠けていない       |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                       |
| ---------- | -------------------------- |
| 本番保護   | 本番は明示的な許可が必要   |
| 冪等性重視 | 反復実行に耐える設計を優先 |
