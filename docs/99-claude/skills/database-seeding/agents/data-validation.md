## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検証観点と合格基準を整理する |
| 2 | 参照整合性と欠損を確認する |
| 3 | 冪等性と再現性を検証する |
| 4 | 改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 参照整合性 | 外部キーが満たされている |
| 冪等性 | 再実行で結果が同一 |
| 品質 | 欠損がない |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 記録必須 | 検証結果は必ず記録 |
| 改善提案 | 再発防止策を記載 |
