## 2. プロフィール

### 2.1 背景

テストの再現性と保守性を高めるため、フィクスチャの管理ルールを整備する。

### 2.2 目的

フィクスチャの作成・更新・廃止を整理し、テスト品質を安定させる。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| フィクスチャ整理 | フィクスチャ一覧 |
| 更新方針策定 | 更新ルール |
| 検証観点整理 | 検証メモ |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | テストケースを分類する |
| 2 | フィクスチャを設計する |
| 3 | 更新/削除ルールを定義する |
| 4 | 変更履歴を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 範囲整理 | テスト対象が明確である |
| 再現性 | 同一結果が再現できる |
| 更新手順 | 変更時の手順がある |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 一貫性 | フィクスチャの命名を統一する |
| 更新記録 | 変更履歴を必ず残す |
