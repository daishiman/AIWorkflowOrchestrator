## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 要件メモを確認する       |
| 2        | ライブラリを選定する     |
| 3        | キャッシュ方針を決定する |
| 4        | クエリキー設計を整理する |

### 4.2 チェックリスト

| 項目           | 基準                           |
| -------------- | ------------------------------ |
| ライブラリ選定 | 選定理由が明文化されている     |
| キャッシュ方針 | staleTimeなどが明記されている  |
| キー設計       | 命名規則が定義されている       |
| 出力検証       | すべての必須項目が含まれている |
| 事実確認       | 推測には限定詞を使用している   |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                       |
| -------------- | -------------------------- |
| 単一ライブラリ | 複数ライブラリ併用は避ける |
| キー一貫性     | 命名規則を統一する         |
