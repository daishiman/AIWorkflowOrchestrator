# 品質チェックリスト

## 明確性チェック

- [ ] **単一責務**: 各例は1つの概念のみを示している
- [ ] **直感的な命名**: 変数名・関数名が目的を明確に示している
- [ ] **段階的開示**: 複雑さが段階的に導入されている
- [ ] **不要なコメントなし**: 自己説明的なコードにはコメントがない

## 完全性チェック

- [ ] **インポート明記**: すべての依存関係がリストされている
- [ ] **バージョン明記**: 依存関係のバージョンが固定されている
- [ ] **環境設定明記**: 必要なNode.js/Python等のバージョンが明記
- [ ] **インストール手順**: パッケージのインストール方法が提供
- [ ] **期待される出力**: 実行結果が示されている
- [ ] **コピー&ペースト可能**: そのまま実行できる

## 実用性チェック

- [ ] **現実的なシナリオ**: 実際のユースケースに基づいている
- [ ] **ベストプラクティス**: 推奨されるパターンを使用している
- [ ] **セキュリティ**: ハードコードされた認証情報がない
- [ ] **非推奨API不使用**: 最新のAPIを使用している

## 保守性チェック

- [ ] **バージョン固定**: 依存関係のバージョンが明記されている
- [ ] **テスト可能**: 例が実行可能な状態である
- [ ] **更新容易**: 構造が明確で更新しやすい

## スコアリング

| スコア | 合格数   | 判定     |
| ------ | -------- | -------- |

| 良好   | 12-13/15 | 合格     |
| 許容   | 10-11/15 | 条件付き |
| 要改善 | 0-9/15   | 不合格   |
