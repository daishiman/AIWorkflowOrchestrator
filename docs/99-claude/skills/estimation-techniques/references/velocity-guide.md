# ベロシティ追跡ガイド

> 相対パス: `references/velocity-guide.md`
> 原典: Agile Estimating and Planning (Mike Cohn)

---

## ベロシティの定義

| 項目           | 説明                                         |
| -------------- | -------------------------------------------- |
| 定義           | スプリントで完了したストーリーポイントの合計 |
| 単位           | ストーリーポイント/スプリント                |
| 計測タイミング | スプリント終了時                             |

**完了の定義**: DoD（Definition of Done）を満たしたストーリーのみカウント

---

## ベロシティの計算

| 種類           | 計算方法                | 用途       |
| -------------- | ----------------------- | ---------- |
| 単一スプリント | 完了SP合計              | 実績記録   |
| 平均ベロシティ | 直近3-5スプリントの平均 | 計画基準   |
| 範囲ベロシティ | 最小〜最大の範囲        | リスク考慮 |

```
平均ベロシティ = (Sprint1 + Sprint2 + Sprint3) / 3
範囲 = [最小値, 平均値, 最大値]
```

---

## ベロシティの安定化

| フェーズ | スプリント数 | 特徴                     |
| -------- | ------------ | ------------------------ |
| 立ち上げ | 1-3          | 変動大、参考値として使用 |
| 安定化   | 4-6          | 傾向が見え始める         |
| 成熟     | 7+           | 予測可能な範囲に収束     |

---

## ベロシティに影響する要因

| 要因           | 影響           | 対応                 |
| -------------- | -------------- | -------------------- |
| チーム構成変更 | ベロシティ変動 | 再計測期間を設ける   |
| 技術的負債     | 徐々に低下     | 定期的な返済         |
| スキル向上     | 徐々に上昇     | 自然な成長として受容 |
| 外部要因       | 一時的変動     | 異常値として除外     |

---

## ベロシティの誤用

| 誤用          | 問題                 | 正しい使い方         |
| ------------- | -------------------- | -------------------- |
| チーム間比較  | ポイント基準が異なる | チーム内でのみ使用   |
| KPIとして使用 | 水増しインセンティブ | 計画ツールとして使用 |
| 増加を強制    | 品質低下、燃え尽き   | 自然なペースを尊重   |
