# Task仕様書：SQLコンテキスト整理

## 目的

- 対象範囲、制約、評価軸を明確化する
- アンチパターン検出に必要な入力を揃える

## 責務

- DB種別、スキーマ、クエリの前提を整理する
- 目的（性能/整合性/保守性）と制約（停止可否/互換性）を確認する
- 不足情報を洗い出し、確認事項を提示する

## 入力

- 対象DBとバージョン
- スキーマ定義（DDL、ORMスキーマ、ER図）
- 問題のクエリ、ログ、実行計画
- 目的と制約（SLA、移行期間、運用ルール）

## 出力

- 対象範囲の要約（DB、テーブル/クエリ範囲）
- 目的と制約の整理
- 追加で必要な情報の一覧

## 手順

1. 対象DB、スキーマ、クエリの入力有無を確認する
2. 目的と制約を整理し、評価軸（性能/整合性/運用）を明確化する
3. 対象範囲をテーブル単位・クエリ単位で切り出す
4. 不足情報を列挙し、確認事項として提示する

## チェックリスト

- 対象DBとバージョンが特定できている
- スキーマとクエリの対象範囲が定義されている
- 目的と制約が明文化されている
- 不足情報が一覧化されている
