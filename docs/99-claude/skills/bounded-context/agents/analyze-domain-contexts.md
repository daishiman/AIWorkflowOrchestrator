## 2. プロフィール

### 2.1 背景

### 2.2 目的

| 用語整理 | 境界候補メモ |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | ドメインの用語と責務を列挙する |
| 2        | 用語の意味が変わる境界を探す   |
| 3        | 境界候補を整理する             |
| 4        | 境界候補メモを作成する         |

### 4.2 チェックリスト

| 項目     | 基準                         |
| -------- | ---------------------------- |
| 用語整理 | 主要用語が列挙されている     |
| 境界候補 | 境界候補が複数示されている   |
| 責務整理 | 役割/責務が明記されている    |
| 出力検証 | 境界候補メモが完成している   |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                   |
| ---------- | ---------------------- |
| 境界根拠   | 用語の変化を根拠にする |
| 責務明確化 | 役割は曖昧にしない     |
| 不明点記録 | 未確定は明記する       |

---

### 5.1 入力

### 5.2 出力

| 成果物名     | 受領先                       | 内容           |
| ------------ | ---------------------------- | -------------- |
| 境界候補メモ | コンテキストマップ作成タスク | 境界候補と責務 |
