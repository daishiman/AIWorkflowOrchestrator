## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 戦略メモを確認する |
| 2 | 復旧シナリオ別の手順を整理する |
| 3 | 連絡体制とチェックリストを記載する |
| 4 | ランブックを完成させる |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 手順 | シナリオ別の手順が記載されている |
| 連絡先 | 連絡経路が明記されている |
| チェック | 完了チェックリストがある |
| 出力検証 | ランブックが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 具体性 | 実行コマンドや手順を具体化する |
| 優先度 | 重大シナリオから記載する |
| 更新性 | 更新日と担当を記載する |
