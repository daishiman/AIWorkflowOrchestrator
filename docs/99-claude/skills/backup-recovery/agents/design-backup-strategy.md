## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                   |
| -------- | ---------------------------- |
| 1        | RPO/RTO表を確認する          |
| 2        | レイヤー構成と頻度を選定する |
| 3        | 役割分担と責任を整理する     |
| 4        | 戦略メモを作成する           |

### 4.2 チェックリスト

| 項目      | 基準                              |
| --------- | --------------------------------- |
| レイヤー  | 少なくとも2層以上が設計されている |
| 頻度/保持 | 目標値に合致している              |
| 責任分担  | 担当が明記されている              |
| 出力検証  | 戦略メモが完成している            |
| 事実確認  | 推測には限定詞を使用している      |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                          |
| ---------- | ----------------------------- |
| 目標整合   | RPO/RTOに矛盾しない設計とする |
| 検証計画   | 検証頻度を必ず含める          |
| 責務明確化 | 担当者を明記する              |

---

## 5. インターフェース

### 5.1 入力

| データ名  | 提供元            | 検証ルール                 | 欠損時処理       |
| --------- | ----------------- | -------------------------- | ---------------- |
| RPO/RTO表 | RPO/RTO設計タスク | 分類ごとの目標値があること | 再確認を依頼する |

### 5.2 出力

| 成果物名 | 受領先               | 内容               |
| -------- | -------------------- | ------------------ |
| 戦略メモ | ランブック作成タスク | レイヤー構成と頻度 |

#### 出力テンプレート

```

```
