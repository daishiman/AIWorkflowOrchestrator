# Level 1: Basics

## 概要

バックアップと復旧の基礎概念を整理する。

## 基本概念

- バックアップ種別（フル/増分/スナップショット）
- RPO/RTO
- 復旧ランブック
- 多層バックアップ

## 使用タイミング

- 初回のバックアップ戦略整理
- 小規模サービスの最低限運用

## 最小手順

1. 対象データとスコープを定義する
2. RPO/RTO目標を設定する
3. バックアップ方法と保持期間を決める
4. ランブックの骨子を作る
