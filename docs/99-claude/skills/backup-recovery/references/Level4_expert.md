# Level 4: Expert

## 概要

監査対応や大規模システム向けに、復旧体制を継続的に改善する。

## 上級テーマ

- コンプライアンス対応（監査証跡）
- マルチリージョン/多クラウド戦略
- 事業継続計画(BCP)との統合
- 障害訓練の高度化

## 推奨アクション

1. 監査証跡と証拠資料を整理する
2. DR計画をBCPと連携させる
3. 多リージョンの復旧シナリオを追加する
4. 復旧演習の結果を継続改善に反映する

## チェックリスト

- [ ] 監査証跡が保管されている
- [ ] BCP/DR計画の整合が取れている
- [ ] 多リージョンの手順が定義されている
- [ ] 改善サイクルが定期運用されている
