# Level 2: Intermediate

## 概要

運用に耐えるバックアップ戦略と復旧手順を整備する。

## 強化ポイント

- 多層バックアップ設計
- RPO/RTOと保持期間の整合
- 復旧ランブックの具体化
- DR計画の基本構成

## 参照すべき資料

- `references/backup-strategy-layers.md`: 多層バックアップ設計
- `references/disaster-recovery-planning.md`: DR計画
- `references/recovery-procedures.md`: 復旧シナリオ手順
- `references/rpo-rto-design.md`: RPO/RTO設計
- `references/turso-backup-guide.md`: Turso環境の運用
- `references/requirements-index.md`: 既存要件がある場合

## 推奨テンプレート

- `assets/backup-policy-template.md`: バックアップポリシー
- `assets/recovery-runbook-template.md`: 復旧ランブック

## 推奨アクション

1. RPO/RTO表を作成する
2. 多層バックアップ構成と頻度を決定する
3. DR計画と復旧手順を文書化する
4. ランブックにチェックリストを追加する

## チェックリスト

- [ ] 多層構成が明記されている
- [ ] 保持期間と責任者が定義されている
- [ ] 復旧シナリオが記載されている
- [ ] DR計画の概要が整理されている
