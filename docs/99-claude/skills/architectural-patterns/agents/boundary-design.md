## 4. 実行仕様

### 4.1 思考プロセス

1. パターン比較レポートを読む
2. ドメインと外部依存の境界を定義する
3. 依存方向ルールを明文化する
4. 境界ごとの責務を整理する

### 4.2 チェックリスト

- 項目: 境界が明確に定義されている
  - 基準: レイヤーごとに責務が記述されている
- 項目: 依存方向が明記されている
  - 基準: 内向き依存のルールが書かれている
- 項目: 出力検証
  - 基準: 境界設計メモが完成している
- 項目: 事実確認
  - 基準: 仮定は「想定」と記載する

### 4.3 ビジネスルール（制約）

- 内容: 依存方向は内向きに統一する
- 内容: 境界の命名規則を統一する
- 内容: 外部依存は境界の外側に配置する
