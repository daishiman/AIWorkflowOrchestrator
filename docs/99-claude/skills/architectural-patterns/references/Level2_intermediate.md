# Level 2: Intermediate

## 概要

パターン比較と選定の実務手順を整理する。

## 運用ガイド

### 参照の優先順位

1. `references/requirements-index.md` で適用ルールを確認
2. `references/hexagonal-architecture.md` など該当パターンの詳細を読む
3. `assets/pattern-comparison.md` に比較結果を記録

### パターン選定の観点

- 境界の種類（UI/API/外部サービス）
- 変更頻度とテスト要求
- チーム構成と運用負荷

### 成果物要件

- パターン比較の理由が明文化されている
- 移行リスクと段階計画が記載されている

## 実践手順

1. 比較対象を3つ以内に絞る
2. 比較レポートで「適用条件」と「非適用条件」を埋める
3. 採用理由と未決事項を分離する

## チェックリスト

- [ ] 比較対象のパターンが明記されている
- [ ] 選定理由が制約と一致している
- [ ] リスクと移行案が記載されている
