# Level 4: Expert

## 概要

複合パターンの設計、運用最適化、継続改善の観点をまとめる。

## 複合パターン

- 基盤はClean Architecture、機能単位はVertical Sliceなどの組み合わせを検討
- 境界のルールが衝突する場合は「依存方向」を優先する

## 運用最適化

- 境界ごとの責務とレビュー担当を固定する
- 変更レビュー時に依存ルールをチェックする

## 継続改善

- 違反が繰り返される箇所はルールの誤解を疑う
- 比較レポートを定期的に更新し、判断根拠を維持する

## チェックリスト

- [ ] 複合パターンの責務分担が明文化されている
- [ ] 依存ルールのレビューが運用に組み込まれている
- [ ] 判断根拠が更新されている
