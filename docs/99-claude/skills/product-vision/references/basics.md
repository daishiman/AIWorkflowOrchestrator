# プロダクトビジョン 基礎知識

## 概要

プロダクトビジョン、OKR、ロードマップの基本概念と適用タイミングを理解するための基礎知識。

## プロダクトビジョンとは

### 定義

プロダクトビジョンは、製品が目指す長期的な方向性と価値を簡潔に表現したもの。チームとステークホルダーに共通の目標を提供します。

### 優れたビジョンの特徴

1. **簡潔性**: 1-2文で表現できる
2. **記憶性**: チームメンバーが覚えられる
3. **鮮明性**: 未来の製品像が明確
4. **鼓舞性**: チームのモチベーションを高める
5. **実現可能性**: 現実的な範囲で野心的

### ビジョンの例

- **Airbnb**: "誰もがどこにでも居場所を感じられる世界を創る"
- **Tesla**: "持続可能なエネルギーへの世界の移行を加速する"
- **Spotify**: "すべてのクリエイターに可能性を、すべてのファンに音楽を"

## OKR（Objectives and Key Results）とは

### 定義

目標設定フレームワーク。定性的な目標（Objective）と定量的な成果指標（Key Results）で構成されます。

### 構造

```
Objective（目標）: 達成したい定性的な目標
├─ Key Result 1: 測定可能な成果指標
├─ Key Result 2: 測定可能な成果指標
└─ Key Result 3: 測定可能な成果指標
```

### OKRの原則

1. **野心的**: 70%達成で成功（100%達成は目標が低すぎる）
2. **測定可能**: Key Resultsは定量的
3. **時間制限**: 通常は四半期単位
4. **透明性**: 全社に公開
5. **整合性**: 会社→チーム→個人でカスケード

### OKRの例

```
Objective: ユーザーエンゲージメントを劇的に向上させる

Key Result 1: 月間アクティブユーザーを10,000から25,000に増加
Key Result 2: セッション時間を平均5分から15分に延長
Key Result 3: 週次リテンション率を30%から60%に改善
```

## ロードマップとは

### 定義

製品の進化を時系列で示す戦略的計画。優先順位付けされたイニシアチブと大まかなタイムラインを可視化します。

### ロードマップの種類

1. **ビジョンロードマップ**: 長期的な方向性（1-3年）
2. **戦略ロードマップ**: 主要イニシアチブ（6-12ヶ月）
3. **リリースロードマップ**: 具体的な機能（3-6ヶ月）

### 優れたロードマップの特徴

- **柔軟性**: 変更を前提とした設計
- **テーマ指向**: 機能リストではなく、成果やテーマを中心に
- **ステークホルダー特化**: 対象に応じた粒度と内容
- **証拠ベース**: データと洞察に基づく優先順位付け

## 適用タイミング

### ビジョン定義が必要な時

- 新規プロダクト立ち上げ時
- 大規模なピボット時
- チームの方向性が不明確な時
- ステークホルダー間で認識のズレがある時

### OKR設定が必要な時

- 四半期の開始時
- 重要なマイルストーンの設定時
- チーム拡大時（目標の整合性確保）
- 測定可能な成果が必要な時

### ロードマップ作成が必要な時

- 年間計画策定時
- ステークホルダーへの説明時
- チーム間の依存関係調整時
- リソース配分の検討時

## 3つの関係性

```
ビジョン（長期）
    ↓
  OKR（中期：四半期）
    ↓
ロードマップ（短中期：3-12ヶ月）
```

- **ビジョン**: 目指す姿（Where）
- **OKR**: 測定可能な成果（What）
- **ロードマップ**: 実現手段と順序（How）
