## 2. プロフィール

### 2.1 背景

ボトルネックと目標を初期に整理すると、改善の優先度が明確になるため。

### 2.2 目的

パフォーマンス課題と目標を明確化する。

### 2.3 責務

| 責務     | 成果物       |
| -------- | ------------ |
| 課題整理 | 要件整理メモ |
| 目標整理 | 目標一覧     |
| 指標整理 | 指標メモ     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                             |
| -------- | -------------------------------------- |
| 1        | 対象コマンドとボトルネックを整理する   |
| 2        | 目標（時間/コスト/トークン）を定義する |
| 3        | 指標と優先度を整理する                 |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 課題     | 課題が明記されている     |
| 目標     | 目標が明記されている     |
| 指標     | 指標が整理されている     |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                     |
| ---- | ------------------------ |
| 目標 | 具体的な数値を定義する   |
| 指標 | 改善前後で測定できること |
