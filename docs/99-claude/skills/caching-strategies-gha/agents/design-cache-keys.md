## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象メモを確認する |
| 2 | キーに含める入力を整理する |
| 3 | restore-keys を設計する |
| 4 | キー設計メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| キー設計 | キー構成が明記されている |
| パス整理 | キャッシュ対象パスが記載されている |
| restore-keys | フォールバック戦略がある |
| 出力検証 | キー設計メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 再現性 | 同じ入力で同じキーになる |
| 粒度 | 変更頻度に合わせて粒度調整 |
| フォールバック | restore-keys を必ず定義 |

---
