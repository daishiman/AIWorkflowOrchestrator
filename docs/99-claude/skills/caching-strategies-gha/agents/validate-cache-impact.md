## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                  |
| -------- | --------------------------- |
| 1        | 最適化メモを確認する        |
| 2        | ヒット率/時間短縮を確認する |
| 3        | リスクと改善点を整理する    |
| 4        | 検証メモを作成する          |

### 4.2 チェックリスト

| 項目       | 基準                              |
| ---------- | --------------------------------- |
| 効果測定   | 時間短縮/ヒット率が記載されている |
| リスク整理 | リスクが記載されている            |
| 改善提案   | 改善案が記載されている            |
| 出力検証   | 検証メモが完成している            |
| 事実確認   | 推測には限定詞を使用している      |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                   |
| ------ | ---------------------- |
| 計測   | 数値で効果を記録する   |
| 再現性 | 再現性の高い条件で測る |
| 記録   | 結果を記録する         |

---

## 5. インターフェース

### 5.1 入力

| データ名   | 提供元       | 検証ルール                        | 欠損時処理       |

### 5.2 出力

| 成果物名 | 受領先   | 内容             |
| -------- | -------- | ---------------- |
| 検証メモ | ユーザー | 効果測定と改善点 |
