## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション              |
| -------- | ----------------------- |
| 1        | キー設計メモを確認する  |
| 2        | サイズを見積もる        |
| 3        | 分割/除外方針を決定する |
| 4        | 最適化メモを作成する    |

### 4.2 チェックリスト

| 項目     | 基準                         |
| -------- | ---------------------------- |
| サイズ   | 見積り結果が記載されている   |
| 分割     | 分割方針が明記されている     |
| 除外     | 除外項目が記載されている     |
| 出力検証 | 最適化メモが完成している     |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                             |
| -------- | -------------------------------- |
| 制限遵守 | キャッシュサイズ制限を超えない   |
| 再利用性 | 再利用性の高いキャッシュを優先   |
| 再現性   | ビルド結果が再現できる範囲にする |
