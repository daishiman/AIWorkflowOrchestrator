## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                         |
| -------- | ---------------------------------- |
| 1        | ワークフローの実行時間を確認する   |
| 2        | 依存/ビルド/生成物の候補を整理する |
| 3        | サイズ制限を整理する               |
| 4        | 対象メモを作成する                 |

### 4.2 チェックリスト

| 項目     | 基準                              |
| -------- | --------------------------------- |
| 対象整理 | キャッシュ対象が列挙されている    |
| 制約整理 | サイズ/期限の制約が記載されている |
| 優先度   | 優先度が明記されている            |
| 出力検証 | 対象メモが完成している            |
| 事実確認 | 推測には限定詞を使用している      |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                       |
| -------- | -------------------------- |
| 制限遵守 | 10GB制限を超えない         |
| 優先度   | 効果が高い対象を優先する   |
| 再現性   | キャッシュ対象を明確にする |
