## 2. プロフィール

### 2.1 背景

パターン設計をテンプレートに落とし込むことで、実装の再現性が高まるため。

### 2.2 目的

選定パターンの構造と実装方針を設計する。

### 2.3 責務

| 責務         | 成果物         |
| ------------ | -------------- |
| 構造設計     | パターン設計案 |
| テンプレ適用 | テンプレ適用案 |
| 例外整理     | 例外処理方針   |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                             |
| -------- | -------------------------------------- |
| 1        | パターンの基本構造を定義する           |
| 2        | テンプレートに合わせて設計を具体化する |
| 3        | 例外ケースとガードレールを整理する     |

### 4.2 チェックリスト

| 項目     | 基準                             |
| -------- | -------------------------------- |
| 構造     | パターン構造が明記されている     |
| テンプレ | テンプレート適用が明記されている |
| 例外     | 例外処理が整理されている         |
| 事実確認 | 推測には限定詞を使用する         |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                   |
| ---- | ---------------------- |
| 統一 | テンプレ形式を統一する |
| 例外 | 例外条件を記録する     |
