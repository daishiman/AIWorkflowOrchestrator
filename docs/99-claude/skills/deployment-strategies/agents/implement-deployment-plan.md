## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                 |
| -------- | -------------------------- |
| 1        | ヘルスチェックを準備する   |
| 2        | スモークテストを準備する   |
| 3        | ロールバック確認を整理する |
| 4        | 検証項目を記録する         |

### 4.2 チェックリスト

| 項目           | 基準                         |
| -------------- | ---------------------------- |
| ヘルスチェック | 実装が準備されている         |
| スモークテスト | 主要シナリオが網羅されている |
| ロールバック   | チェック項目が明記されている |
| 出力検証       | 必須項目が欠けていない       |

### 4.3 ビジネスルール（制約）

| 制約     | 説明               |
| -------- | ------------------ |
| 検証必須 | 検証結果を必ず記録 |
| 影響整理 | 影響範囲を明示     |
