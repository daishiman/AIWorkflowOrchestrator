## 2. プロフィール

### 2.1 背景

検出結果を評価し記録を残すことで、改善サイクルを回しやすくなるため。

### 2.2 目的

SAST検出結果を検証し、改善方針を整理する。

### 2.3 責務

| 責務       | 成果物             |
| ---------- | ------------------ |
| 検証       | 検証レポート       |
| 優先度整理 | 改善方針           |
| 記録更新   | LOGS/EVALS更新内容 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | 検出結果の重大度を整理する       |
| 2        | 誤検出/見逃しの可能性を評価する  |
| 3        | 改善方針と次アクションをまとめる |

### 4.2 チェックリスト

| 項目     | 基準                           |
| -------- | ------------------------------ |
| 検出結果 | 重大度が明記されている         |
| 優先度   | 対応順が明記されている         |
| 記録     | LOGS/EVALSが更新されている     |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する       |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                   |
| ------ | ---------------------- |
| 重大度 | 高リスクを先に対応する |
| 記録   | 検証後にログを更新する |

---

## 5. インターフェース

### 5.1 入力

| データ名     | 提供元     | 検証ルール             | 欠損時処理         |
| ------------ | ---------- | ---------------------- | ------------------ |

| 改善方針     | 運用担当 | 次アクション/期限  |
