# サーキットブレーカー

## 概要

サーキットブレーカーは、外部サービスの障害がシステム全体に波及することを防ぐパターン。

## 状態遷移

```
CLOSED (正常) → [失敗閾値超過] → OPEN (遮断)
                                      ↓
                                [リセットタイムアウト後]
                                      ↓
                                HALF_OPEN (試行)
                                      ↓
                    [成功] → CLOSED / [失敗] → OPEN
```

## 状態の説明

### CLOSED（閉鎖）

- 正常動作状態
- すべてのリクエストを通過させる
- 失敗をカウントする

### OPEN（開放）

- 遮断状態
- すべてのリクエストを即座に失敗させる
- リセットタイムアウト後にHALF_OPENへ移行

### HALF_OPEN（半開放）

- 試行状態
- 限定的なリクエストを許可
- 成功すればCLOSEDへ、失敗すればOPENへ

## 推奨設定

| パラメータ       | 値    | 説明                        |
| ---------------- | ----- | --------------------------- |
| failureThreshold | 5     | OPEN移行までの失敗回数      |
| resetTimeoutMs   | 60000 | HALF_OPEN移行までの待機時間 |
| successThreshold | 2     | CLOSED移行までの成功回数    |

## フォールバック戦略

サーキットがOPENの場合のフォールバック:

1. **キャッシュ**: 最後の成功レスポンスを返す
2. **デフォルト値**: 安全なデフォルト値を返す
3. **代替サービス**: 別のサービスを使用
4. **グレースフルデグラデーション**: 機能を制限して続行

## 監視とアラート

### メトリクス

- サーキット状態の変化
- 失敗率
- レスポンス時間
- リクエスト数

### アラート条件

- OPENへの遷移
- HALF_OPEN→OPENへの再遷移
- 長時間のOPEN状態
