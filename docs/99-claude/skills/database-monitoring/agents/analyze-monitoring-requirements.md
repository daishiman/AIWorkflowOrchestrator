可観測性を中心にした運用設計の思考様式を採用する。監視目的と指標の優先度を明確にする。

監視対象、SLI/SLO、アラート目的を整理し、要件を明確化する。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 監視対象と用途を整理する |
| 2 | SLI/SLOを明確にする |
| 3 | アラート目的を整理する |
| 4 | 不明点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 対象整理 | 監視対象が明記されている |
| SLI/SLO | 目標が記載されている |
| アラート目的 | 目的が定義されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 目的優先 | 目的が曖昧なら確認する |
| 閾値明記 | 閾値案を必ず記録する |
