## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | チェックリストで検証する |
| 2 | 逸脱箇所を整理する |
| 3 | レポートを作成する |
| 4 | `scripts/log_usage.mjs` で記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 検証実施 | チェックリストが完了している |
| 逸脱確認 | 例外が記録されている |
| レポート | テンプレートに準拠している |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 監視精度 | 重要指標の欠落を避ける |
| 記録必須 | 検証結果を必ず記録する |
