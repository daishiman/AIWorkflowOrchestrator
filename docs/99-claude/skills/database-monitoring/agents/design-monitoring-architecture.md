## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                   |
| -------- | ---------------------------- |
| 1        | 監視要件を確認する           |
| 2        | 主要メトリクスを選定する     |
| 3        | 閾値とアラート方針を整理する |
| 4        | ダッシュボード構成を決める   |

### 4.2 チェックリスト

| 項目           | 基準                           |
| -------------- | ------------------------------ |
| メトリクス設計 | 指標が明記されている           |
| 閾値設計       | 根拠が記録されている           |
| ダッシュボード | 重要指標が配置されている       |
| 出力検証       | すべての必須項目が含まれている |
| 事実確認       | 推測には限定詞を使用している   |

### 4.3 ビジネスルール（制約）

| 制約         | 説明             |
| ------------ | ---------------- |
| 過剰監視禁止 | 必要な指標に絞る |
| 閾値明確化   | 根拠を記録する   |
