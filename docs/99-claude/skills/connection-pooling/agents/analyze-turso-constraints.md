## 2. プロフィール

### 2.1 背景

Turso やサーバーレス特有の制約を先に整理すると、接続設計の失敗を防げるため。

### 2.2 目的

Turso/サーバーレス環境の制約と運用前提を明確化する。

| リスク整理 | リスクメモ |
