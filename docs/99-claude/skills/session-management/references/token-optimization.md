# トークン最適化手法

> **相対パス**: `references/token-optimization.md`
> **読込条件**: トークン最適化の詳細が必要な場合

---

## 最適化の目的

長時間セッションを可能にし、コンテキスト枯渇を防ぐ。

---

## 最適化テクニック

### 1. 選択的ファイル読み込み

| 方法              | 説明                         |
| ----------------- | ---------------------------- |
| Glob + 部分Read   | 対象ファイルを絞ってから読む |
| Grep + 行番号指定 | 必要な行のみ抽出             |
| offset/limit      | 大きなファイルを分割読み込み |

### 2. 会話の要約

```markdown
## セッションサマリー

- 完了: タスクA, タスクB
- 進行中: タスクC
- 次のアクション: タスクDの実装
```

### 3. 外部化

| 情報           | 外部化先         |
| -------------- | ---------------- |
| 長い出力結果   | ファイルに保存   |
| 中間成果物     | チェックポイント |
| 詳細な参照情報 | references/      |

### 4. 不要情報の除外

- 成功したコマンドの詳細出力を省略
- 過去のエラーメッセージを削除
- 重複する情報を統合

---

## 消費パターンと対策

| パターン             | 症状             | 対策                 |
| -------------------- | ---------------- | -------------------- |
| 大量ファイル読み込み | 急激な消費増加   | 選択的読み込み       |
| 長時間会話           | 緩やかな消費増加 | 定期的な要約         |
| 試行錯誤の繰り返し   | 不要情報の蓄積   | チェックポイント活用 |
