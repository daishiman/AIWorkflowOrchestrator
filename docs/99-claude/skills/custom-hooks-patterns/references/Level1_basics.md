# レベル1: 基礎

## 概要

カスタムフックの抽出基準と基本パターンを扱う。

SKILL.md と本レベルのみで完結する基本運用を対象とする。

## 前提条件

- SKILL.md の概要とワークフローを読了している
- 抽出対象のロジックが把握できている

## 詳細ガイド

### 使用タイミング

- 抽出候補を整理する段階
- フック化の是非を判断する段階

### 必要な知識

- 対象領域: 抽出基準と基本フック設計
- 主要概念: 単一責務、状態/副作用の分離
- 実務指針: 抽出基準のチェックを行う

### 判断基準

- 避けるべき判断: 目的のない抽出を行う

### 成果物の最小要件

- 抽出理由と対象が明記されている
- 主要テンプレート: `assets/hook-api-contract-template.md`

### 主要リソース

- `SKILL.md`: 基本方針とワークフロー
- `references/extraction-criteria.md`: 抽出基準

### 主要テンプレート

- `assets/hook-api-contract-template.md`: 参照のみ

## 実践手順

1. 抽出候補を列挙する
2. 抽出基準に照らして評価する
3. フック化の目的を記録する
