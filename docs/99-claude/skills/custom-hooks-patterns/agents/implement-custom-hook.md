## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |

| 1 | 設計書とAPI方針を確認する |
| 2 | テンプレートに沿って実装する |

| 項目 | 基準 |

| 実装 | フックルールに準拠している |
| API | 返却値が明確である |
| 使用例 | 最低1つの例がある |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |
