## 2. プロフィール

### 2.1 背景

レガシーコードへの変更を安全に進めるため、変更点の隔離と段階的導入を重視する。
テスト保護を前提に、最小限の変更でパターン導入を成立させる方法論を適用する。

### 2.2 目的

パターン導入計画を作成し、段階的に適用するための手順を定義する。

### 2.3 責務

| 責務                               | 成果物                             |
| ---------------------------------- | ---------------------------------- |
| 導入計画の作成                     | パターン導入計画                   |
| 変更ステップの分割                 | ステップ一覧                       |
| テスト/検証ポイントの設定          | 検証手順                           |
| ロールバック条件の定義             | ロールバック方針                   |
| 適用結果の整理                     | 適用結果メモ                       |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                                     |
| -------- | -------------------------------------------------------------- |
| 1        | パターン機会レポートを確認し、導入対象を確定する               |
| 2        | `assets/pattern-refactor-plan-template.md` に沿って計画を作る  |
| 3        | `references/incremental-application-steps.md` で分割を決める   |
| 4        | `scripts/validate-pattern-plan.mjs` で計画の欠落を検証する     |
| 5        | 変更を段階的に適用し、各段階でテストを通す                     |

### 4.2 チェックリスト

| 項目                       | 基準                                                   |
| -------------------------- | ------------------------------------------------------ |
| 導入計画が作成されている   | テンプレの全セクションが埋まっている                   |
| 変更ステップが分割されている | 1ステップあたりの変更量が小さい                       |
| 検証ポイントが明記されている | 各ステップでテスト/チェックが定義されている           |
| ロールバック条件がある     | 失敗時の戻し方が明記されている                         |
| 出力検証                   | すべての必須項目が含まれている                         |
| 事実確認                   | 推測には限定詞を使用                                   |

### 4.3 ビジネスルール（制約）

| 制約                             | 説明                                           |
| -------------------------------- | ---------------------------------------------- |
| 一度の変更量                     | 差分がレビュー可能な範囲に限定                 |
| テスト未整備時の対応             | 先に保護テストを追加する                       |
| 構造変更は段階的に               | 置き換え前に並行稼働ステップを入れる           |
