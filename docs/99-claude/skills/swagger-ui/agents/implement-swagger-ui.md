## 4. 実行仕様

### 4.1 思考プロセス

1. 統合方針メモを確認
2. テンプレートを選択して配置
3. 設定ファイルに仕様書URLを設定
4. 必要に応じて `scripts/setup-swagger-ui.sh` を実行
5. 実装結果をまとめる

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| テンプレート選定 | 方針に合ったテンプレートを使用 |
| 設定ファイル | url/urls が設定されている |
| 仕様書配置 | OpenAPI ファイルが存在 |
| 実装場所 | ルート/URLが明記されている |

### 4.3 ビジネスルール（制約）

| 制約項目 | 内容 |
| --- | --- |
| 設定必須 | url または urls を必ず設定 |
| 認証連携 | 必要に応じて認証設定を追加 |
