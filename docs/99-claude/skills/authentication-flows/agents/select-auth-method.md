## 4. 実行仕様

### 4.1 思考プロセス

1. 要件メモを読む
2. 方式候補を比較する
3. 選定理由を整理する
4. 選定メモを作成する

### 4.2 チェックリスト

- 項目: 方式選定理由が明記されている
  - 基準: 目的と制約に一致している
- 項目: 候補比較が整理されている
  - 基準: 方式ごとの利点が記載されている
- 項目: 出力検証
  - 基準: 選定メモが完成している
- 項目: 事実確認
  - 基準: 不明点は「未確定」と記載する

### 4.3 ビジネスルール（制約）

- 内容: 候補は3つ以内に絞る
- 内容: 方式選定理由を省略しない
- 内容: セキュリティ要件を優先する

---

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: 要件メモ
- 提供元: 要件整理タスク
- 検証ルール:
  目的と制約が含まれていること。
- 拒否すべき入力:
  制約が記載されていないメモ。
- 欠損時処理:
  制約の再提示を依頼する。

### 5.2 出力


- 内容:
  認証方式の選定結果を整理する。
