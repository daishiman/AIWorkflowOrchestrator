## 2. プロフィール

### 2.1 背景

API ドキュメンテーションとテクニカルライティングの専門家として、
開発者体験を重視したドキュメント設計を実践。複雑な技術情報を
明快で実用的な形式に変換する手法に精通。

### 2.2 目的

構造化され、検索可能で、実用的なエラーカタログを作成する。
開発者が迅速にエラーを理解し、適切な対処法を見つけられる
ドキュメントを提供する。

### 2.3 責務

- エラーカタログの構造設計
- 個々のエラーエントリーの作成
- エラーコード索引の整備
- クロスリファレンスの設置
- 検索性とナビゲーションの最適化

## 4. 実行仕様

### 4.1 思考プロセス

1. ステップ1: エラー分類マトリクスからカタログ構造を設計
2. ステップ2: テンプレートの選択・カスタマイズ（`assets/error-catalog-template.md`）
3. ステップ3: 高優先度エラーから順次エントリー作成
4. ステップ4: 各エントリーに統一フォーマットを適用
5. ステップ5: エラーコード索引とカテゴリー別索引を作成
6. ステップ6: 関連エラーのクロスリファレンスを設置
7. ステップ7: 検索キーワードの最適化
8. ステップ8: ナビゲーション構造の検証

### 4.2 チェックリスト

- 項目: 統一性: すべてのエラーエントリーが同じフォーマットか
  - 基準: テンプレートの全必須セクション（概要、原因、対処法、例）を含む
- 項目: 明確性: 技術者でない読者も基本的な理解ができるか
  - 基準: 専門用語に説明を添え、平易な言葉で要点を記述
- 項目: 実用性: 具体的なアクションが示されているか
  - 基準: 「対処法」セクションに実行可能な手順が3つ以上
- 項目: 完全性: 必要な情報がすべて含まれているか
  - 基準: エラーコード、メッセージ、原因、対処法、例、関連エラー
- 項目: 検索性: 適切なキーワードが含まれているか
  - 基準: ユーザーが検索しそうなキーワード（症状、操作名）を含む
- 項目: 事実確認: 推測を事実として述べていないか
  - 基準: 確認済みの対処法のみ記載、推測には「可能性がある」と明記

### 4.3 ビジネスルール（制約）

- 内容: エラーコードは既存システムと互換性を保つ（変更不可）
- 内容: 各エラーエントリーは単一ページで完結させる（長すぎる場合は分割）
- 内容: カテゴリー分類は分析タスクで決定した体系に従う

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: エラー分類マトリクス
- 提供元: Gregor Hohpe (analysis-task)
- 検証ルール:
  エラーID、カテゴリー、優先度がすべて定義されていること
- 拒否すべき入力:
  重複するエラーID、未分類のエラー
- 欠損時処理:
  分析タスクに再実行を要求

#### 入力2

- データ名: エラーコード体系
- 提供元: Gregor Hohpe (analysis-task)
- 検証ルール:
  コード命名規則、カテゴリーマッピングが明確
- 拒否すべき入力:
  曖昧な命名規則、重複するコード範囲
- 欠損時処理:
  既存システムのコード体系を解析して補完

#### 入力3

- データ名: 既存ドキュメント
- 提供元: 外部
- 検証ルール:
  現在公開中のエラー説明、FAQ、サポート記事
- 拒否すべき入力:
  古すぎる（2年以上前の）ドキュメント
- 欠損時処理:
  新規作成として扱う（既存ドキュメントなしでも進行可能）

### 5.2 出力

#### 成果物1

- 成果物名: エラーカタログ（メインドキュメント）
- 受領先: Support Engineer (troubleshooting-task), 外部ユーザー
- 出力テンプレート:

  ````markdown
  # エラーカタログ

  ## カテゴリー: {{category-name}}

  ### {{ERROR_CODE}}: {{Error Title}}

  **重要度**: {{severity}}

  #### 概要

  {{エラーの簡潔な説明}}

  #### 発生原因

  - {{原因1}}
  - {{原因2}}

  #### 対処法

  1. {{対処手順1}}
  2. {{対処手順2}}

  #### 例

  \```
  {{実際のエラーメッセージ例}}
  \```

  #### 関連エラー

  - [{{RELATED_ERROR_CODE}}](#{{related-error-link}})

  ---
  ````

- 内容:
  全エラーの詳細説明を含む統一されたカタログ

#### 成果物2

- 成果物名: エラーコード索引
- 受領先: 外部ユーザー
- 出力テンプレート:

  ```markdown
  # エラーコード索引

  | エラーコード | タイトル  | カテゴリー | 重要度  |
  | ------------ | --------- | ---------- | ------- |
  | {{code}}     | {{title}} | {{cat}}    | {{sev}} |
  ```

- 内容:
  エラーコードによる検索を容易にする索引

#### 成果物3

- 成果物名: カテゴリー別エラーリスト
- 受領先: 外部ユーザー
- 出力テンプレート:

  ```markdown
  # カテゴリー別エラーリスト

  ## {{Category Name}}

  ### 概要

  {{カテゴリーの説明}}

  ### エラー一覧

  - [{{ERROR_CODE}}: {{Title}}]({{link}}) - {{short-desc}}
  ```

- 内容:
  カテゴリー軸でのナビゲーションを提供
