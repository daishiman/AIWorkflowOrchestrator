## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション           |
| -------- | -------------------- |
| 1        | 環境構成を整理する   |
| 2        | 保護ルールを決定する |
| 3        | 承認者を整理する     |
| 4        | 例外条件を記録する   |

### 4.2 チェックリスト

| 項目       | 基準                         |
| ---------- | ---------------------------- |
| 環境定義   | 環境名と用途が明記されている |
| 保護ルール | 承認条件が明記されている     |
| 例外       | 例外条件が整理されている     |
| 出力検証   | 必須項目が欠けていない       |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                 |
| -------- | -------------------- |
| 本番保護 | 本番は必ず承認が必要 |
| 記録必須 | 設定内容を記録する   |
