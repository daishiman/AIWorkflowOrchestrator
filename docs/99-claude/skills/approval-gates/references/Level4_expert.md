# Level 4: Expert

## 概要

監査・例外運用・継続改善を中心に、承認ゲートを長期運用するための指針をまとめる。

## 監査と証跡

- 承認記録に「誰が」「いつ」「なぜ」を残す
- 例外承認は理由と期限を必ず紐付ける
- 証跡は変更単位で参照できる形にする

## 例外運用

- 緊急リリース用の短縮ゲートを定義
- 緊急時は事後レビューを必須化
- 例外の適用回数を上限化し、恒常化を防ぐ

## 継続改善

- 失敗理由を分類し、ゲート条件の改善に反映
- ゲートの目的と実運用の差分を四半期ごとに棚卸し
- ゲート数が増えすぎた場合は統合・簡素化を検討

- [ ] 監査証跡が検索可能な形で保存されている
- [ ] 例外運用の判断基準が明文化されている
- [ ] 定期的な見直しサイクルが設計されている
