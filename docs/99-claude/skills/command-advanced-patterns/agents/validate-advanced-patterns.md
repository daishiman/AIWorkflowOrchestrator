## 2. プロフィール

### 2.1 背景

検証と記録を揃えることで、パターン適用の品質が安定するため。

### 2.2 目的

高度パターンの適用結果を検証し、記録を更新する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 検証 | 検証レポート |
| 結果整理 | 改善方針 |
| 記録更新 | LOGS/EVALS更新内容 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検証対象と成功条件を整理する |
| 2 | 検証スクリプトを実行する |
| 3 | 結果と改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 検証結果 | 適用結果が確認されている |
| テンプレ | テンプレートが適用されている |
| 記録 | LOGS/EVALSが更新されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 検証順 | 検証→記録の順で進める |
| 共有 | 重大な問題は共有する |
