# エラーレスポンス標準

## 基本形式（RFC 7807）

| 項目     | 説明                   |
| -------- | ---------------------- |
| type     | エラー種別を表すURI    |
| title    | 人間向けの短い説明     |
| status   | HTTPステータスコード   |
| detail   | 具体的な原因           |
| instance | 追跡用の識別子（任意） |

## 推奨追加項目

| 項目     | 説明                               |
| -------- | ---------------------------------- |
| trace_id | 追跡可能なID                       |
| errors   | バリデーションエラーの詳細（配列） |

## 例示の注意点

- typeはドキュメントで説明可能なURIにする
- titleは短く、detailで具体的に説明する
- statusはHTTPレスポンスと一致させる
