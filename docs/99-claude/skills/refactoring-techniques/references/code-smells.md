# コードスメルカタログ

## 概要

コードスメルは「コードに問題がある可能性を示すサイン」。
バグではないが、設計上の問題を示唆し、リファクタリングの必要性を示す。

---

## メソッドレベルのスメル

### Long Method（長大なメソッド）

| 項目         | 内容                                     |
| ------------ | ---------------------------------------- |
| 検出基準     | 30行超 / スクロール必要 / 複数の「段落」 |
| 対処パターン | Extract Method, Replace Temp with Query  |
| 優先度       | 高                                       |

### Long Parameter List（パラメータ過多）

| 項目         | 内容                                              |
| ------------ | ------------------------------------------------- |
| 検出基準     | パラメータ4個以上 / 同じ組み合わせの繰り返し      |
| 対処パターン | Introduce Parameter Object, Preserve Whole Object |
| 優先度       | 中                                                |

### Complex Conditional（複雑な条件式）

| 項目         | 内容                                 |
| ------------ | ------------------------------------ |
| 検出基準     | ネスト3段階以上 / &&/\|\|が3つ以上   |
| 対処パターン | Decompose Conditional, Guard Clauses |
| 優先度       | 高                                   |

### Duplicated Code（重複コード）

| 項目         | 内容                           |
| ------------ | ------------------------------ |
| 検出基準     | 3行以上の同一コードが2箇所以上 |
| 対処パターン | Extract Method, Pull Up Method |
| 優先度       | 高                             |

### Magic Number（マジックナンバー）

| 項目         | 内容                                  |
| ------------ | ------------------------------------- |
| 検出基準     | 0,1,-1以外の数値リテラル / 意味が不明 |
| 対処パターン | Replace Magic Number with Constant    |
| 優先度       | 低                                    |

## クラスレベルのスメル

### Large Class（巨大クラス）

| 項目         | 内容                                    |
| ------------ | --------------------------------------- |
| 検出基準     | 500行超 / メソッド20個超 / 複数の関心事 |
| 対処パターン | Extract Class, Extract Subclass         |
| 優先度       | 中                                      |

### Feature Envy（特性への依存）

| 項目         | 内容                              |
| ------------ | --------------------------------- |
| 検出基準     | 他クラスのgetterを3つ以上呼び出す |
| 対処パターン | Move Method                       |
| 優先度       | 中                                |

### Data Clumps（データの群れ）

| 項目         | 内容                                      |
| ------------ | ----------------------------------------- |
| 検出基準     | 同じ3つ以上のフィールドが複数クラスに存在 |
| 対処パターン | Extract Class, Introduce Parameter Object |
| 優先度       | 中                                        |

### Primitive Obsession（基本データ型への固執）

| 項目         | 内容                                    |
| ------------ | --------------------------------------- |
| 検出基準     | 文字列で型表現 / 数値で状態表現         |
| 対処パターン | Replace Type Code with Class/Subclasses |
| 優先度       | 低                                      |

---

## 変更妨害のスメル

### Divergent Change（変更の発散）

| 項目         | 内容                               |
| ------------ | ---------------------------------- |
| 検出基準     | 異なる理由で同じクラスを頻繁に変更 |
| 対処パターン | Extract Class, Split Phase         |
| 優先度       | 中                                 |

### Shotgun Surgery（散弾銃手術）

| 項目         | 内容                                  |
| ------------ | ------------------------------------- |
| 検出基準     | 小さな変更で多数のファイルを修正      |
| 対処パターン | Move Method, Move Field, Inline Class |
| 優先度       | 中                                    |

---

## 優先度マトリクス

### 即座に対処（高優先度）

```
重複コード     → バグ修正時の漏れリスク
長大なメソッド → 可読性の大幅な低下
複雑な条件式   → バグの温床
```

### 計画的に対処（中優先度）

```
パラメータ過多 → 引数の理解が困難
データの群れ   → 凝集度の低下
Feature Envy   → 責務の不明確
```

### 余裕時に対処（低優先度）

```
マジックナンバー     → 意図の不明確
基本データ型への固執 → 型安全性の低下
```

## 検出チェックリスト

### メソッドレビュー時

- [ ] 行数が30行を超えていないか
- [ ] パラメータが4つ以上ないか
- [ ] ネストが3段階以上ないか
- [ ] マジックナンバーがないか
- [ ] 重複コードがないか

### クラスレビュー時

- [ ] 行数が500行を超えていないか
- [ ] 単一責任原則に従っているか
- [ ] 他クラスへの依存が過度でないか
- [ ] 同じデータ群が繰り返し現れていないか
