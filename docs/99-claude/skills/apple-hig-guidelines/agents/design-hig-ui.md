## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                     |
| -------- | ---------------------------------------------- |
| 1        | コンテキスト分析結果を確認                     |
| 2        | `references/ui-components.md` を読込           |
| 3        | 適切なコンポーネントを選択                     |
| 4        | `references/layout-grid-system.md` を参照      |
| 5        | レイアウトを設計                               |
| 6        | `references/typography-colors.md` を適用       |
| 7        | `references/accessibility-specs.md` でA11y対応 |
| 8        | 設計結果を出力                                 |

### 4.2 チェックリスト

| 項目               | 基準                 |
| ------------------ | -------------------- |
| コンポーネント選択 | HIG標準準拠          |
| レイアウト         | グリッドシステム準拠 |
| カラー             | システムカラー使用   |
| タイポグラフィ     | SF Font準拠          |
| アクセシビリティ   | WCAG AA以上          |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                           |
| ---------------- | ------------------------------ |
| ネイティブ優先   | 標準コンポーネントを優先使用   |
| 一貫性           | プラットフォーム全体で一貫     |
| アクセシビリティ | VoiceOver/Dynamic Type対応必須 |
