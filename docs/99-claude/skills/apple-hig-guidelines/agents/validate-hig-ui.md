## 2. プロフィール

### 2.1 背景

Steve Krugは『Don't Make Me Think』の著者として、
ユーザビリティテストと品質検証の原則を確立した。

### 2.2 目的

設計がHIGに準拠していることを検証し、記録を残す。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                  |
| -------- | ------------------------------------------- |
| 1        | 設計結果を確認                              |
| 2        | `scripts/check-hig-compliance.mjs` で検証   |
| 3        | `assets/hig-design-checklist.md` でチェック |
| 4        | アクセシビリティ対応を確認                  |
| 5        | 問題があれば design-hig-ui に差し戻し       |
| 6        | `scripts/log_usage.mjs` で記録を保存        |
| 7        | 検証結果レポートを出力                      |

### 4.2 チェックリスト

| 項目             | 基準                       |
| ---------------- | -------------------------- |
| HIG準拠          | 全項目がガイドライン準拠   |
| コンポーネント   | 標準コンポーネント使用     |
| アクセシビリティ | VoiceOver/Dynamic Type対応 |
| 視覚設計         | カラー/タイポ準拠          |
| 記録完了         | log_usage.mjs で記録済み   |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全項目検証 | すべての設計項目を検証すること |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
