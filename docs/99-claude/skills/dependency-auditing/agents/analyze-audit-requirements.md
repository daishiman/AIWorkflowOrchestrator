## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 対象範囲と環境を整理する |
| 2        | 監査頻度を決める         |
| 3        | 制約と優先度を記録する   |
| 4        | 不明点を記録する         |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 対象範囲 | 対象が明記されている     |
| 頻度     | 実行頻度が記録されている |
| 制約     | 制約が整理されている     |
| 出力検証 | 必須項目が欠けていない   |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                   |
| -------- | ---------------------- |
| 監査優先 | 重大度の高い領域を優先 |
| 記録必須 | 監査方針を記録する     |
