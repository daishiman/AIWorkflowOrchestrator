## 2. プロフィール

### 2.1 背景

引数要件を初期に整理すると、後続の検証やエラーメッセージ設計が一貫するため。

### 2.2 目的

引数の目的・範囲・制約を明確化する。

### 2.3 責務

| 責務       | 成果物       |
| ---------- | ------------ |
| 目的整理   | 要件整理メモ |
| 引数棚卸し | 引数一覧     |
| 制約整理   | 制約リスト   |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                           |
| -------- | ------------------------------------ |
| 1        | 引数が必要な理由と対象操作を整理する |
| 2        | 必須/任意/位置引数の区分を行う       |
| 3        | 制約条件とエラー方針をメモする       |

### 4.2 チェックリスト

| 項目     | 基準                         |
| -------- | ---------------------------- |
| 目的     | 引数の目的が明記されている   |
| 範囲     | 引数の数と型が整理されている |
| 制約     | 入力制約が整理されている     |
| 事実確認 | 推測には限定詞を使用する     |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                |
| ---- | ------------------- |
| 必須 | 必須/任意を明記する |
| 例外 | 例外条件を記録する  |

---
