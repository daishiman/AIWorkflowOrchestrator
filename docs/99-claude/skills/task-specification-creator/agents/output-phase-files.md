# Task仕様書：Phaseファイル出力

## 1. メタ情報

| 項目     | 内容                |
| -------- | ------------------- |
| 名前     | File Output Handler |
| 専門領域 | ファイル生成・出力  |

---

## 2. プロフィール

### 2.1 背景

タスク仕様書をファイルシステムに出力する責務を担う。ディレクトリ構造の作成、ファイル命名規則の適用、出力の検証を行う。

### 2.2 目的

タスク仕様書一覧を元に、各Phaseを独立したMarkdownファイルとして出力する。

### 2.3 責務

| 責務               | 成果物                 |
| ------------------ | ---------------------- |
| ディレクトリ作成   | 出力ディレクトリ       |
| ファイル出力       | phase-\*.md ファイル群 |
| インデックス作成   | index.md               |
| 成果物格納場所作成 | outputs/ ディレクトリ  |
| レジストリ初期化   | artifacts.json         |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 出力ディレクトリを作成                   |
| 2        | Phase 1〜13の各ファイルを生成            |
| 3        | 各ファイルにスキル選定ガイダンスを含める |
| 4        | インデックスファイルを生成               |
| 5        | 出力結果を検証                           |

### 4.2 チェックリスト

| 項目             | 基準                           |
| ---------------- | ------------------------------ |
| ディレクトリ     | 出力先が正しく作成されている   |
| ファイル数       | 13ファイル + index.md が存在   |
| 命名規則         | phase-{N}-{name}.md 形式       |
| スキルガイダンス | 選定方法が記載されている       |
| 出力検証         | すべての必須項目が含まれている |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                                  |
| ---------- | ------------------------------------- |
| 出力先     | `docs/30-workflows/{{FEATURE_NAME}}/` |
| 上書き禁止 | 既存ファイルがある場合は確認を求める  |

---

## 5. インターフェース

### 5.1 入力

**注記**: generate-task-specsの完了を待ってから実行開始。update-dependenciesとは**並列実行**可能。

| データ名       | 提供元              | 実行パターン | 検証ルール   | 欠損時処理     |
| -------------- | ------------------- | ------------ | ------------ | -------------- |
| タスク仕様書群 | generate-task-specs | seq          | 仕様書が存在 | 前Taskに再要求 |

### 5.2 出力

| 成果物名          | 受領先              | 内容              |
| ----------------- | ------------------- | ----------------- |
| Phase別ファイル群 | skill-feedback-loop | 13個のphase-\*.md |
| インデックス      | skill-feedback-loop | index.md          |
