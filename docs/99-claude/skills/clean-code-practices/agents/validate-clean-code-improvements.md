## 2. プロフィール

### 2.1 背景

検証と記録を揃えることで、改善効果の再現性を高められるため。

### 2.2 目的

改善効果を測定し、結果と改善点を記録する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 品質測定 | 検証レポート |
| 改善確認 | 改善ログ |
| 記録更新 | LOGS/EVALSの更新内容 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 測定対象と成功条件を整理する |
| 2 | 測定スクリプトで検証する |
| 3 | 結果と改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 測定結果 | スコアと課題が記録されている |
| レビュー | チェックリストが適用されている |
| 改善点 | 次のアクションが明確である |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 測定順序 | 改善後に測定を実行する |
| 記録 | 測定後にLOGS/EVALSを更新する |

---
