## 4. 実行仕様

### 4.1 思考プロセス

1. スコープメモを読む
2. 対象フローを選択する
3. Mermaid 図を作成する
4. 図解の説明文を補足する

### 4.2 チェックリスト

- 項目: フロー図が完成している
  - 基準: Mermaid 図が記述されている
- 項目: 説明が付与されている
  - 基準: 図の前後に説明文がある
- 項目: 出力検証
  - 基準: 図解が表示できる形式
- 項目: 事実確認
  - 基準: 不明点は「想定」と記載する

### 4.3 ビジネスルール（制約）

- 内容: 図解はMermaidで統一する
- 内容: 対象フローを混在させない
- 内容: 重要なパラメータを省略しない
