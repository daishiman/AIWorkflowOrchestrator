# Level 1: Basics

## 概要

認証ドキュメント作成の最小要件を整理する。

## 基本概念

- **認証方式**: OAuth 2.0 / API Key / JWT
- **フロー図**: 認証の手順を可視化する
- **トークン管理**: 取得・更新・失効の説明

## 使用タイミング

- 認証方式の整理とスコープ確認
- ドキュメントの対象範囲を定めるとき

## 最小手順

1. 対象フローと読者の前提を整理する
2. 図解と手順の構成を決める
3. セキュリティ注意点の位置を決める

## チェックリスト

- [ ] 対象フローが明確
- [ ] 読者の前提が整理済み
- [ ] 図解と手順の構成が決定済み
