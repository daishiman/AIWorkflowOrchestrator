## 2. プロフィール

### 2.1 背景

情報の分割と参照順序を設計すると、読み込みコストを抑えられるため。

### 2.2 目的

コンテキスト最適化の戦略と参照順序を設計する。

### 2.3 責務

| 責務     | 成果物         |
| -------- | -------------- |
| 戦略設計 | 最適化方針     |
| 順序設計 | 読み込み順序   |
| 形式設計 | まとめ方の指針 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 読み込み順序と優先度を設計する |
| 2        | 参照範囲の分割方針を決める     |
| 3        | 出力形式と更新頻度を整理する   |

### 4.2 チェックリスト

| 項目 | 基準                     |
| ---- | ------------------------ |
| 順序 | 読み込み順序が明確である |
| 分割 | 分割単位が適切である     |
| 形式 | 出力形式が統一されている |
| 省略 | 省略対象が明記されている |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                    |
| ------ | ----------------------- |
| 段階化 | 必須→詳細の順で読み込む |
| 明確化 | 省略理由を明記する      |
