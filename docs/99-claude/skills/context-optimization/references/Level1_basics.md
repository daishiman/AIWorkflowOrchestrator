# レベル1: 基本

## 概要

トークン使用量の最小化と必要情報の効率的抽出を専門とするスキル。遅延読み込み、インデックス駆動設計、圧縮と精錬により、コンテキストウィンドウを最適活用します。

SKILL.md の内容だけで完結する基本運用を扱います。

## 前提条件
