## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 要件候補をFR/NFRに分類する |
| 2 | 要件IDを付与し、1要件=1項目で記述する |
| 3 | 受け入れ基準をGiven-When-Thenで記述する |
| 4 | 依存関係と優先度を整理する |
| 5 | テンプレートへ反映し完成度を確認する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| ID | 重複がなく連番で付与されている |
| 受け入れ基準 | GWT形式で記述されている |
| 依存関係 | 依存が明記されている |
| 優先度 | Must/Should/Could等が明示されている |
| 出力検証 | テンプレート必須項目を満たす |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 仕様化順序 | 要件候補の合意後に仕様化する |
| 表現統一 | 用語集にない用語は定義してから記述する |
