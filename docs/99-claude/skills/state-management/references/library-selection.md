# ライブラリ選定ガイド

## 比較軸

| 観点           | 例                            |
| -------------- | ----------------------------- |
| 学習コスト     | APIの単純さ、ドキュメント整備 |
| 拡張性         | ミドルウェア、エコシステム    |
| 予測可能性     | 状態更新の一貫性              |
| パフォーマンス | 再レンダリング制御            |
| チーム運用     | ルール化とレビューポイント    |

## 代表的な選択肢

- Context + Hooks: 小規模、状態共有が限定的
- Redux Toolkit: 大規模、可視化と規約重視
- Zustand/Jotai: 中規模、柔軟性と軽量性重視
- Vue/Pinia: Vueアプリ向けの標準構成

## 選定の決め方

1. 変更頻度と状態の共有範囲を整理する
2. 監査・可視化の必要性を確認する
3. 既存チームの経験値と運用コストを評価する
