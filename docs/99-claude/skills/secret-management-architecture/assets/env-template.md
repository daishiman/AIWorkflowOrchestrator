# 環境変数テンプレート

> **用途**: 環境変数設定のサンプルとガイドライン
> **対象**: 開発環境構築

---

## 使用方法

1. このテンプレートを `.env.example` としてプロジェクトルートにコピー
2. 実際の値を設定して `.env` として保存
3. `.env` は `.gitignore` に追加

---

## テンプレート

```bash
# =============================================================================
# シークレット管理設定
# =============================================================================

# -----------------------------------------------------------------------------
# 環境設定
# -----------------------------------------------------------------------------
NODE_ENV=development
APP_ENV=local

# -----------------------------------------------------------------------------
# データベース接続（Critical/High）
# -----------------------------------------------------------------------------
# 本番環境ではVault/Secrets Managerから取得
DB_HOST=localhost
DB_PORT=5432
DB_NAME=myapp
DB_USER=app_user
# ⚠️ 本番環境では環境変数に直接設定しない
DB_PASSWORD=

# -----------------------------------------------------------------------------
# Redis接続（Medium）
# -----------------------------------------------------------------------------
REDIS_HOST=localhost
REDIS_PORT=6379
# ⚠️ 本番環境では認証必須
REDIS_PASSWORD=

# -----------------------------------------------------------------------------
# 外部API認証（High）
# -----------------------------------------------------------------------------
# ⚠️ 本番環境ではVault/Secrets Managerから取得
API_KEY=
API_SECRET=

# -----------------------------------------------------------------------------
# JWT/認証（Critical）
# -----------------------------------------------------------------------------
# ⚠️ 本番環境ではHSM/KMSで管理
JWT_SECRET=
JWT_EXPIRES_IN=1h
REFRESH_TOKEN_SECRET=
REFRESH_TOKEN_EXPIRES_IN=7d

# -----------------------------------------------------------------------------
# 暗号化キー（Critical）
# -----------------------------------------------------------------------------
# ⚠️ 本番環境ではHSM/KMSで管理
ENCRYPTION_KEY=

# -----------------------------------------------------------------------------
# シークレット管理バックエンド
# -----------------------------------------------------------------------------
# Vault設定
VAULT_ADDR=http://localhost:8200
VAULT_TOKEN=
VAULT_NAMESPACE=

# AWS Secrets Manager設定
AWS_REGION=ap-northeast-1
AWS_SECRET_NAME_PREFIX=/myapp/

# -----------------------------------------------------------------------------
# 監視・ロギング
# -----------------------------------------------------------------------------
LOG_LEVEL=debug
SENTRY_DSN=

# -----------------------------------------------------------------------------
# サードパーティサービス
# -----------------------------------------------------------------------------
STRIPE_API_KEY=
SENDGRID_API_KEY=
SLACK_WEBHOOK_URL=
```

---

## 分類別ガイドライン

| 分類     | 環境変数での管理    | 推奨管理方法          |
| -------- | ------------------- | --------------------- |
| Critical | ❌ 禁止             | HSM/KMS               |
| High     | ⚠️ 開発環境のみ     | Vault/Secrets Manager |
| Medium   | ✅ 可（暗号化推奨） | Vault/Secrets Manager |
| Low      | ✅ 可               | 環境変数/設定ファイル |

- [ ] `.env` ファイルが `.gitignore` に含まれている
- [ ] Critical/Highシークレットが環境変数に直接設定されていない
- [ ] 本番環境ではシークレット管理バックエンドを使用している
- [ ] 開発環境と本番環境で異なるシークレットを使用している
- [ ] シークレットがログに出力されないよう設定している
