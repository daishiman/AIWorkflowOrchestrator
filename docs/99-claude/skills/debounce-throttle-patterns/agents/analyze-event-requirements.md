## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | イベントタイプと頻度を整理する |
| 2        | UX/性能要件を記録する          |
| 3        | 制約と優先度を整理する         |
| 4        | 不明点を記録する               |

### 4.2 チェックリスト

| 項目     | 基準                         |
| -------- | ---------------------------- |
| 目的整理 | イベント目的が明記されている |
| 頻度     | 発火頻度が記録されている     |
| 制約     | リソース制約が記録されている |
| 出力検証 | 必須項目が欠けていない       |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                             |
| -------- | -------------------------------- |
| 体感優先 | UXに影響する場合は優先度を上げる |
| 制約記録 | 不明点は必ず記録する             |
