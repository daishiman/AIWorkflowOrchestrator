## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 測定項目を確認する |
| 2 | 実測データを取得する |
| 3 | 改善効果を評価する |
| 4 | 改善提案を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 測定項目 | 目標値が明記されている |
| 測定結果 | 取得データが記録されている |
| 改善評価 | 期待値との差分がある |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 実測優先 | 推定ではなく実測を優先 |
| 記録必須 | 結果を必ず記録 |

---
