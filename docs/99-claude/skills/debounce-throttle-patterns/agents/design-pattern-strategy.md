## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション             |
| -------- | ---------------------- |
| 1        | パターン候補を比較する |
| 2        | パラメータを設計する   |
| 3        | トレードオフを記録する |
| 4        | 実装方針を整理する     |

### 4.2 チェックリスト

| 項目         | 基準                   |
| ------------ | ---------------------- |
| パターン選定 | 根拠が明記されている   |
| パラメータ   | 値が明記されている     |
| トレードオフ | 影響が記録されている   |
| 出力検証     | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約     | 説明               |
| -------- | ------------------ |
| 根拠記録 | 選定理由を残す     |
| 影響整理 | 影響範囲を明記する |
