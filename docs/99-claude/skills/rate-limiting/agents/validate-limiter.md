## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                            |
| -------- | ------------------------------------- |
| 1        | 負荷テストでRate Limitingの動作を確認 |
| 2        | 429レスポンスの発生タイミングを検証   |
| 3        | レート制限のメトリクスを収集          |
| 4        | アラート閾値を設定                    |
| 5        | 検証レポートを作成                    |

### 4.2 チェックリスト

| 項目           | 基準                       |
| -------------- | -------------------------- |
| Rate Limit発動 | 設定した上限で429が返る    |
| ヘッダー確認   | X-RateLimit-\*が正しく返る |
| Retry-After    | 適切な待機時間が返る       |
| メトリクス     | 429発生率が記録されている  |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                         |
| -------------- | ---------------------------- |
| テスト環境実行 | 本番に負荷をかけない         |
| 段階的負荷     | 急激な負荷ではなく徐々に増加 |
| アラート閾値   | 429率が1%を超えたらアラート  |
