## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                       |
| -------- | ------------------------------------------------ |
| 1        | 要件定義書からバースト許容度を評価               |
| 2        | Token Bucket、Leaky Bucket、Sliding Windowを比較 |
| 3        | 分散環境対応の必要性を判断                       |
| 4        | ストレージ要件（Redis、メモリ）を検討            |
| 5        | アルゴリズム選定書を作成                         |

### 4.2 チェックリスト

| 項目             | 基準                             |
| ---------------- | -------------------------------- |
| アルゴリズム選定 | 要件に最適なものが選ばれている   |
| バースト対応     | 許容すべきか明確に決定されている |
| 分散環境対応     | 必要な場合Redisが選定されている  |
| 実装複雑度評価   | チームスキルに適合している       |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                          |
| ------------ | ----------------------------- |
| 分散環境     | 複数インスタンス時はRedis必須 |
| シンプル優先 | 要件が単純なら固定窓から開始  |
| バースト許容 | UX重視ならToken Bucketを選択  |
