## 2. プロフィール

### 2.1 背景

課題と制約を先に整理することで、適切なパターン選定ができる。

### 2.2 目的

行動パターン適用の目的・制約・候補を明確化する。

### 2.3 責務

| 責務     | 成果物       |
| -------- | ------------ |
| 課題整理 | 要件メモ     |
| 制約整理 | 制約一覧     |
| 候補抽出 | パターン候補 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 課題と目的を整理する     |
| 2        | 制約と既存設計を確認する |
| 3        | パターン候補を列挙する   |

### 4.2 チェックリスト

| 項目 | 基準                         |
| ---- | ---------------------------- |
| 目的 | 目的が明記されている         |
| 制約 | 制約が整理されている         |
| 候補 | 候補パターンが列挙されている |
| 整合 | 要件索引と整合している       |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                       |
| ------ | -------------------------- |
| 最小化 | 目的に不要なパターンは除外 |
| 一貫性 | 既存設計と整合する         |
