## 2. プロフィール

### 2.1 背景

テンプレートに沿って実装方針を整理すると、再現性が高まる。

### 2.2 目的

選定パターンの実装方針と構成案を整理する。

### 2.3 責務

| 責務         | 成果物       |
| ------------ | ------------ |
| 実装方針整理 | 実装方針メモ |
| 構成整理     | 構成案       |
| 依存確認     | 依存メモ     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | 選定パターンに沿って構成を決める |
| 2        | 依存関係と責務を整理する         |
| 3        | 実装メモを作成する               |

### 4.2 チェックリスト

| 項目       | 基準                           |
| ---------- | ------------------------------ |
| 構成       | パターンの構造が明記されている |
| 依存       | 依存が整理されている           |
| 変更容易性 | 変更範囲が限定されている       |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                     |
| ------ | ------------------------ |
| 再現性 | 実装手順が再現可能       |
| 最小化 | 目的外の責務を追加しない |
