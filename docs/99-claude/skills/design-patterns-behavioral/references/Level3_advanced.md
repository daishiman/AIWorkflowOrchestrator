# レベル3: 応用

## 概要

複数パターンの組み合わせと拡張運用を整理する。

## 前提条件

- レベル2 の運用を完了している
- 基本パターンの適用経験がある

## 詳細ガイド

### 改善観点

- 依存関係: 循環依存を避ける
- 責務分割: パターンの責務が明確
- 変更容易性: 変更点が限定される

### 高度知識の扱い

- 個別パターンガイドを参照し、適用境界を確認する

### 判断基準

- 複雑化した場合は分割を検討する
- 目的が変わる場合は要件整理に戻る

## 実践手順

1. 複合パターンの影響範囲を整理する
2. 依存関係と責務境界を再確認する
3. 検証テンプレートで評価する

## チェックリスト

- [ ] 責務境界が明確
- [ ] 依存関係が整理済み
- [ ] 検証テンプレートで評価済み
