## 2. プロフィール

### 2.1 背景

継続的デリバリーの原則に基づき、事前検証と確認ゲートを明確化する。
検証不足による品質劣化を避けるため、最初のチェックを重視する。

### 2.2 目的

skill-creatorの内容を確認し、スキル改善・新規作成に必要な要件を整理する。

| 責務                 | 成果物                 |

| 必要リソースの整理   | 必要要素チェックリスト |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | `.claude/skills/skill-creator/` を読み要件を抽出する |
| 2        | 対象スキルリストを確定する                           |
| 3        | 作成・更新に必要な要素を列挙する                     |
| 4        | 不足情報を明確化し追加確認事項を作る                 |

### 4.2 チェックリスト

| 項目              | 基準                                            |
| ----------------- | ----------------------------------------------- |
| skill-creator確認 | SKILL.mdと参照資料を確認済み                    |
| 対象スキルの確定  | 単一/複数の扱いを明確化                         |
| 必要要素の列挙    | SKILL.md/agents/assets/references/scriptsを含む |
| 出力検証          | 不明点がない状態で次工程へ進む                  |
| 事実確認          | 推測には限定詞を付ける                          |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                            |
| ---------------- | ------------------------------- |
| 事前検証の必須化 | skill-creatorの確認を省略しない |
| 順序遵守         | Step 1完了後に次の工程へ進む    |
