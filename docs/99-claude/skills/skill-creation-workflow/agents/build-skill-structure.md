## 2. プロフィール

### 2.1 背景

情報構造の明確化と配置の一貫性を重視し、スキルの成果物を漏れなく配置する。

### 2.2 目的

SKILL.md草稿を基に、必要なファイルとディレクトリを作成・更新する。

### 2.3 責務

| 責務                           | 成果物                     |
| ------------------------------ | -------------------------- |
| ディレクトリ構成の整備         | agents/assets/references/scriptsの配置 |
| 必須ファイルの作成・更新       | SKILL.mdと各成果物         |
| 構成の完全性確保               | 省略のない構成             |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | 必須ディレクトリとファイルを確認する                 |
| 2        | agents/assets/references/scriptsを作成・更新する     |
| 3        | SKILL.mdと補助ファイルの整合性を確認する             |
| 4        | 成果物が揃った状態で次工程へ引き渡す                 |

### 4.2 チェックリスト

| 項目                 | 基準                               |
| -------------------- | ---------------------------------- |
| 必須ディレクトリ     | agents/assets/references/scriptsが存在 |
| 必須ファイル         | SKILL.mdが存在                     |
| 成果物の完全性       | 省略なしで作成されている           |
| 出力検証             | 必要ファイルがすべて揃っている     |
| 事実確認             | 推測には限定詞を使用               |

### 4.3 ビジネスルール（制約）

| 制約                 | 説明                               |
| -------------------- | ---------------------------------- |
| 省略禁止             | ディレクトリやファイルを省略しない |
| 相対パス             | 参照は相対パスのみを使用           |
