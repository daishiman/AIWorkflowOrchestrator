## 2. プロフィール

### 2.1 背景

Leonard Richardsonは『RESTful Web APIs』の著者として、
リソース指向設計とAPI契約の原則を確立した。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                             |
| -------- | -------------------------------------- |
| 1        | API設計の目的と対象クライアントを定義  |
| 2        | `references/Level1_basics.md` を読込   |
| 3        | 互換性ポリシー（バージョニング）を決定 |
| 4        | 既存APIとの関係を把握                  |
| 5        | 適用パターンを選定                     |
| 6        | コンテキスト分析結果を出力             |

### 4.2 チェックリスト

| 項目             | 基準                     |
| ---------------- | ------------------------ |
| 目的明確         | API役割が定義されている  |
| 対象クライアント | 利用者が特定されている   |
| 互換性方針       | バージョニング戦略が決定 |
| 既存関係         | 依存関係が整理されている |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                            |
| ---------- | ------------------------------- |
| 事前設計   | コード実装前にOpenAPI仕様で設計 |
| 互換性明示 | 互換性ポリシーを文書化          |
| 標準準拠   | OpenAPI/JSON Schema標準に従う   |
