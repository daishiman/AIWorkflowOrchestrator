## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                              |
| -------- | --------------------------------------- |
| 1        | 設計結果を確認                          |
| 2        | API実装がOpenAPI仕様に準拠か確認        |
| 3        | バリデーションルールを検証              |
| 4        | クライアント互換性をテスト              |
| 5        | 問題があれば design-contract に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存    |
| 7        | 検証結果レポートを出力                  |

### 4.2 チェックリスト

| 項目         | 基準                     |
| ------------ | ------------------------ |
| OpenAPI準拠  | 仕様と実装が一致         |
| スキーマ検証 | JSON Schema準拠          |
| 互換性テスト | 既存クライアントが動作   |
| 記録完了     | log_usage.mjs で記録済み |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全項目検証 | すべての設計を検証すること     |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
