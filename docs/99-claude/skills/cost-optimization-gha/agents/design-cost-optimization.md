## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | コスト要因を優先順位付けする |
| 2 | 目標削減率と期限を設定する |
| 3 | 実装の順序と依存関係を整理する |
| 4 | リスクと影響範囲を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 優先順位 | 影響度と工数が評価されている |
| 目標設定 | 削減率/期限が明記されている |
| 実装順序 | 依存関係が整理されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 影響評価必須 | 品質低下を許容しない |
| 小さく反復 | 一度に大きく変えない |
