# ランナー選定マトリクス

## 評価基準

| 項目     | 説明                  |
| -------- | --------------------- |
| 単価     | 実行1分あたりのコスト |
| 実行時間 | 速度差による影響      |
| 互換性   | OS依存の有無          |
| 信頼性   | 失敗率や安定性        |
| 代替可否 | 他OSへ移行可能か      |

## 収集表

| ジョブ | 現行ランナー | 単価 | 実行時間 | 代替候補 | 判定 |
| ------ | ------------ | ---- | -------- | -------- | ---- |
|        |              |      |          |          |      |

## 判定ルール（例）

- 代替候補で品質が維持できる場合はコスト優先
- OS依存がある場合は例外理由を記録
