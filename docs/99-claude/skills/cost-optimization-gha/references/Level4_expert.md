# レベル4: 専門

## 概要

継続的なコスト監視と改善サイクルを設計する。

## 前提条件

- レベル3の実装が完了している
- 実行結果の計測が可能

## 詳細ガイド

### 使用タイミング

- 継続的な改善運用を行うとき
- 請求額の監視と再設計を行うとき

### 必要な知識

- 監視指標の設計
- コストアラートの運用
- 長期的な最適化ロードマップ

### 主要リソース

- `references/billing-monitoring.md`: 請求監視の運用
- `references/requirements-index.md`: 仕様整合性の確認

### 成果物要件

- 監視項目とレビュー周期が明記されている
- 改善履歴が記録されている

## 実践手順

1. 監視指標と閾値を設定する
2. 定期レビューのスケジュールを決める
3. 次回改善候補を整理する

## チェックリスト

- [ ] 監視項目が明確である
- [ ] レビューサイクルが決まっている
- [ ] 改善履歴が更新されている
