# レベル1: 基礎

## 概要

GitHub Actions のコスト最適化を始めるための基礎知識を扱う。

SKILL.md と本レベルのみで完結する基本運用を対象とする。

## 前提条件

- SKILL.md の概要とワークフローを読了している
- 対象ワークフローの構成が把握できている

## 詳細ガイド

### 使用タイミング

- コスト削減の初期調査
- 実行頻度や予算の整理段階

### 必要な知識

- 対象領域: GitHub Actions の実行コスト
- 主要概念: 実行時間 / ランナー単価 / ストレージ
- 実務指針: ベースラインの計測を優先する

### 判断基準

- 避けるべき判断: 計測なしで施策を決める

### 成果物の最小要件

- 実行頻度・ランナー構成・概算コストが記録されている
- 主要テンプレート: `assets/cost-optimization-plan.md`

### 参照書籍

- 『High Performance Browser Networking』: 計測から改善する姿勢

### 主要リソース

- `SKILL.md`: スキルの目的とワークフロー
- `references/runner-costs.md`: ランナー単価の考え方

### 主要テンプレート

- `assets/cost-optimization-plan.md`: 参照のみ

## 実践手順

1. ワークフロー構成と実行頻度を整理する
2. `scripts/estimate-costs.mjs` で概算を算出する
3. コスト要因を分類する

## チェックリスト

- [ ] 実行頻度が記録されている
- [ ] ランナー構成が明記されている
- [ ] 概算コストが算出されている
