# レベル2: 実務

## 概要

削減施策の設計と実装順序の整理を行う。

references/ と assets/ を活用する運用を前提とする。

## 前提条件

- レベル1の成果物が揃っている
- ベースラインが数値化されている

## 詳細ガイド

### 必要な知識・情報

- 主要トピック: 優先順位付け、ランナー選定、キャッシュ、ストレージ管理
- 参照必須: `references/execution-time.md`

### 判断基準と検証観点

- 回避事項: 品質影響を評価せずに削減を進める

### リソース運用

- `references/runner-costs.md`: 単価比較の基準
- `references/artifact-storage.md`: 保持期間と圧縮指針

### スクリプト運用

- `scripts/estimate-costs.mjs`: 施策前後の概算確認
- `scripts/validate-skill.mjs`: 構造検証

### テンプレート運用

- `assets/runner-selection-matrix.md`: ランナー選定
- `assets/cost-optimization-plan.md`: 計画整理

### 成果物要件

- 削減施策と優先順位が明記されている
- 影響範囲とリスクが整理されている

## 実践手順

1. ランナー選定マトリクスで候補を整理する
2. 最適化計画に施策と優先順位を記入する
3. 実装順序とリスクを確認する
