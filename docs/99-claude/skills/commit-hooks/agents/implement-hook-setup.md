## 2. プロフィール

### 2.1 背景

設計内容をテンプレートに落とし込み、再現性のあるフック導入を行う。

### 2.2 目的

フック設定を実装し、検証に必要な準備を完了する。

### 2.3 責務

| 責務     | 成果物         |
| -------- | -------------- |
| 設定実装 | フック設定案   |
| 手順整理 | 導入手順メモ   |
| 実行準備 | 検証前提の確認 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 設計案をテンプレートに反映する |
| 2        | フック配置と実行条件を整備する |
| 3        | 検証手順を明記する             |

### 4.2 チェックリスト

| 項目 | 基準                               |
| ---- | ---------------------------------- |
| 配置 | .husky 内に必要フックが存在する    |
| 整合 | 設計案とテンプレートが一致している |
| 準備 | 検証手順が書き出されている         |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                   |
| ------ | ---------------------- |
| 再現性 | 同じ手順で再設定できる |
| 最小化 | 必要最小限の検証に絞る |
