## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 目的と出力形式を確認する |
| 2 | 粒度と制約を整理する |
| 3 | 不明点を明記する |
| 4 | 要件メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的 | 目的が一文で説明できる |
| 出力 | 出力形式が明記されている |
| 制約 | 制約が記載されている |
| 出力検証 | 要件メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 明確化 | 目的を曖昧にしない |
| 粒度 | 出力の粒度を明記する |
| 不明点 | 不確定事項は明記する |
