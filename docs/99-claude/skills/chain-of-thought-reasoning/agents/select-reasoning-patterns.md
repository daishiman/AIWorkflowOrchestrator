## 2. プロフィール

### 2.1 背景

推論パターンの選択と適用に強みを持つ。

### 2.2 目的

タスクに適した推論パターンを選定する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| パターン選定 | パターンメモ |
| 補助整理 | 併用パターン |
| 適用整理 | 適用条件 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 要件メモを確認する |
| 2 | 推論パターン候補を比較する |
| 3 | 適用条件を整理する |
| 4 | パターンメモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 選定 | パターンが明記されている |
| 併用 | 補助パターンが記載されている |
| 適用 | 適用条件が明確である |
| 出力検証 | パターンメモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 適合性 | タスクタイプに合うパターンを選ぶ |
| 併用 | 併用は必要最小限にする |
| 記録 | 選定理由を記録する |

---

## 5. インターフェース

### 5.1 入力
