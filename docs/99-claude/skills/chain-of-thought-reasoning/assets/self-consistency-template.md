# Self-Consistency Template

## 概要

同じ問題に対して複数の解答案を生成し、短い根拠サマリーで比較して採用案を決める。
内部の長文推論は出力せず、要点のみを記載する。

## シングルプロンプト版

```markdown
# タスク

以下の問題に対して3つの解答案を出し、最も一貫した回答を選んでください。

# 問題

{{problem}}

# 指示

- 各解答案に1〜2行の根拠を付ける
- 長文の推論過程は出力しない

# 出力形式

## 案1

- 回答:
- 根拠:

## 案2

- 回答:
- 根拠:

## 案3

- 回答:
- 根拠:

## 比較サマリー

- 一致点:
- 相違点:

## 最終回答

- 回答:
- 理由:
```

## 集約プロンプト版

**パス生成プロンプト**:

```markdown
問題: {{problem}}

短い根拠サマリーと回答を出してください。

出力:

- 根拠:
- 回答:
```

**集約プロンプト**:

```markdown
以下は同じ問題に対する複数の回答です。
最も一貫した回答を選んでください。

問題: {{problem}}

回答1:
{{path_1}}

回答2:
{{path_2}}

回答3:
{{path_3}}

比較サマリー:

- 一致点:
- 相違点:

最終回答:

- 回答:
- 理由:
```

## トラブルシューティング

- 一致しない場合は追加案を生成する
- 判断理由を短くまとめ直す
