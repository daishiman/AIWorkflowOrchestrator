# 推論パターン集

## 概要

タスクタイプに応じた推論パターンの選択ガイド。
根拠は短いサマリーとして整理する。

## 演繹パターン

- **用途**: ルール/前提が明確なとき
- **サマリー構成**: 前提 → ルール適用 → 結論

## 帰納パターン

- **用途**: データから傾向を推測するとき
- **サマリー構成**: 観察 → パターン → 仮説

## 仮説（アブダクション）パターン

- **用途**: 最も妥当な説明を選ぶとき
- **サマリー構成**: 事実 → 仮説候補 → 最有力

## 比較パターン

- **用途**: 複数案の比較
- **サマリー構成**: 選択肢 → 評価基準 → 判断

## ケース分解パターン

- **用途**: 場合分けが必要なとき
- **サマリー構成**: ケース一覧 → 条件 → 結論

## 分割統治パターン

- **用途**: 問題が大きいとき
- **サマリー構成**: サブ問題 → 合成 → 結論

## 逆算パターン

- **用途**: 目標から条件を逆算
- **サマリー構成**: 目標 → 必要条件 → 解
