# Level 1: Basics

## 概要

推論パターンと短い根拠サマリーの基本を整理する。

## 基本概念

- 目的/制約/前提
- 推論パターン選択
- 簡潔な根拠サマリー

## 使用タイミング

- 推論パターンを選びたい時
- 根拠を短く要約したい時

## 最小手順

1. 目的と制約を整理する
2. 推論パターンを選ぶ
3. 根拠を短くまとめる
