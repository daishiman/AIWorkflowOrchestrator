| ---------- | -------- |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | UI要件と再利用対象を列挙する     |
| 2        | 合成パターンの適用条件を整理する |
| 3        | 期待するAPIと制約を明文化する    |

### 4.2 チェックリスト

| 項目     | 基準                             |
| -------- | -------------------------------- |
| 目的     | 目的と成果物が一致している       |
| 制約     | 制約が漏れなく整理されている     |
| 期待値   | APIの期待値が明記されている      |
| 可観測性 | 成果物の確認方法が記載されている |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                   |
| ------ | ---------------------- |
| 単純化 | 不要な抽象化は避ける   |
| 一貫性 | 既存UIとの一貫性を保つ |
