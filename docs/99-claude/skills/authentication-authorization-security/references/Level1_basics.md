# Level 1: Basics

## 概要

認証・認可の基本概念と脅威モデルの最小要件を整理する。

## 基本概念

- **Authentication**: 本人確認
- **Authorization**: 権限確認
- **Token/Session**: 認証状態の保持方法

## 使用タイミング

- 要件整理と脅威整理の初期段階
- フロー選定前の前提確認

## 最小手順

1. 認証と認可の目的を整理する
2. 想定する脅威を列挙する
3. 主要な資産（ユーザー情報/権限情報）を洗い出す
