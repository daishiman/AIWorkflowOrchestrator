## 4. 実行仕様

### 4.1 思考プロセス

1. コンテキスト要約を読む
2. OAuth フローの候補を比較する
3. トークン方針を決定する
4. フロー選定メモを作成する

### 4.2 チェックリスト

- 項目: フロー選定理由が明記されている
  - 基準: 目的と制約に一致している
- 項目: トークン方針が明記されている
  - 基準: 有効期限と保存先が書かれている
- 項目: 出力検証
  - 基準: フロー選定メモが完成している
- 項目: 事実確認
  - 基準: 不明点は「未確定」と記載する

### 4.3 ビジネスルール（制約）

- 内容: フロー候補は2つ以内に絞る
- 内容: トークン方針を省略しない
- 内容: 目的と制約に反しない
