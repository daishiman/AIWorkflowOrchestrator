## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | チェックリストを確認する |
| 2 | 正規形の妥当性を評価する |
| 3 | 非正規化判断の根拠を確認する |
| 4 | 改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 正規形 | 適用レベルが妥当 |
| 非正規化 | 判断根拠が記録済み |
| 影響範囲 | 影響が整理されている |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 変更記録 | 結果は必ず記録する |
| 改善提案 | 再発防止策を記載する |
