## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                   |
| -------- | ---------------------------- |
| 1        | 対象スキーマと用途を整理する |
| 2        | 制約と性能要件を記録する     |
| 3        | 評価対象の範囲を確定する     |
| 4        | 不明点を記録する             |

### 4.2 チェックリスト

| 項目     | 基準                           |
| -------- | ------------------------------ |
| 対象範囲 | テーブルと用途が明記されている |
| 制約     | 非機能要件が記録されている     |
| 目的     | 目的と優先度が明記されている   |
| 出力検証 | 必須項目が欠けていない         |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                   |
| -------- | ---------------------- |
| 目的優先 | 目的が曖昧なら確認する |
| 影響範囲 | 影響範囲を必ず明記する |
