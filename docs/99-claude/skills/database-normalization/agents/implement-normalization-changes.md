## 2. プロフィール

### 2.1 背景

設計変更の影響を意識しながら、正規化の修正を安全に反映する。

### 2.2 目的

正規化設計に基づく変更を実装し、影響と差分を記録する。

### 2.3 責務

| 責務     | 成果物     |
| -------- | ---------- |
| 変更実装 | 実装差分   |
| 影響整理 | 影響一覧   |
| 再評価   | 再評価メモ |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 設計メモの内容を確認する |
| 2        | 変更点を実装する         |
| 3        | 影響範囲を記録する       |
| 4        | 再評価結果を整理する     |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 変更反映 | 設計と一致している       |
| 影響整理 | 影響範囲が明記されている |
| 再評価   | 分析結果が記録されている |
| 出力検証 | 必須項目が欠けていない   |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                 |
| -------- | -------------------- |
| 変更記録 | 差分と理由を記録する |
| 影響確認 | 影響範囲を明示する   |
