正規化レベルの判断と非正規化の可否を設計メモにまとめる。

| 影響整理     | 影響範囲一覧     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                   |
| -------- | ---------------------------- |
| 1        | 正規形の適用レベルを評価する |
| 2        | 非正規化の要否を検討する     |
| 3        | トレードオフを記録する       |
| 4        | 影響範囲を整理する           |

### 4.2 チェックリスト

| 項目     | 基準                       |
| -------- | -------------------------- |
| 正規形   | 適用レベルが明記されている |
| 非正規化 | 判断根拠が記録されている   |
| 影響範囲 | 影響範囲が整理されている   |
| 出力検証 | 必須項目が欠けていない     |

### 4.3 ビジネスルール（制約）

| 制約     | 説明               |
| -------- | ------------------ |
| 変更管理 | 変更は必ず記録する |
| 監査対応 | 判断根拠を残す     |
