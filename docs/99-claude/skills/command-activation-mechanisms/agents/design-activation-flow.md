## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 起動トリガーを定義する |
| 2 | フロー図と手順を整理する |
| 3 | 例外と安全策を定義する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| トリガー | トリガー条件が明記されている |
| フロー | 実行手順が明記されている |
| 安全策 | ガードレールが明記されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 自動起動 | 重要操作は確認ステップを挟む |
| 例外処理 | 例外時の動作を明記する |
