## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション           |
| -------- | -------------------- |
| 1        | 目的と対象を整理する |
| 2        | 認証要件を明記する   |
| 3        | 対象範囲を合意する   |

### 4.2 チェックリスト

| 項目 | 基準                   |
| ---- | ---------------------- |
| 目的 | 目的が明記されている   |
| 対象 | 対象が明確             |
| 整合 | 要件索引と整合している |

### 4.3 ビジネスルール（制約）

| 制約   | 説明               |
| ------ | ------------------ |
| 最小化 | 必須範囲に絞る     |
| 合意   | 認証方式を明記する |
