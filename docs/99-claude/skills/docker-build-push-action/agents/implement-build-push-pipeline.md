## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | ワークフローを実装する   |
| 2        | キャッシュ設定を整理する |
| 3        | タグ戦略を確定する       |

### 4.2 チェックリスト

| 項目       | 基準                 |
| ---------- | -------------------- |
| 実装       | YAMLが整合している   |
| キャッシュ | 設定が有効           |
| タグ       | 戦略が明記されている |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                       |
| ------ | -------------------------- |
| 再現性 | 同じ構成を再利用できる     |
| 最小化 | 不要なステップを追加しない |
