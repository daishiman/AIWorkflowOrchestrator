## 2. プロフィール

### 2.1 背景

ワークフロー構成と認証を整理することで、運用の失敗を減らせる。

### 2.2 目的

build/push ワークフローと認証方針を設計する。

### 2.3 責務

| 責務     | 成果物             |
| -------- | ------------------ |
| 構成設計 | ワークフロー設計   |
| 認証設計 | 認証方針           |
| チェック | チェックリスト更新 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | ワークフロー構成を決める |
| 2        | 認証フローを整理する     |
| 3        | チェックリストで検証する |

### 4.2 チェックリスト

| 項目       | 基準                   |
| ---------- | ---------------------- |
| 構成       | ワークフロー構成が明確 |
| 認証       | Secretsが定義済み      |
| キャッシュ | キャッシュが有効       |

### 4.3 ビジネスルール（制約）

| 制約   | 説明                   |
| ------ | ---------------------- |
| 最小化 | 最小権限にする         |
| 再現性 | 同じ構成を再利用できる |
