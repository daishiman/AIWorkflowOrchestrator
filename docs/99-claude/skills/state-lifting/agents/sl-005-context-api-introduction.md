## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                 |
| -------- | ------------------------------------------ |
| 1        | Props伝播階層と頻度を確認する              |
| 2        | Prop Drillingの負荷を評価する              |
| 3        | Context導入のメリット/デメリットを整理する |
| 4        | Providerの責務範囲を定義する               |
| 5        | 導入判断を文書化する                       |

### 4.2 チェックリスト

| 項目     | 基準                                         |
| -------- | -------------------------------------------- |
| 負荷評価 | 伝播階層と再レンダリング影響が整理されている |
| 導入理由 | Context導入の理由が明文化されている          |
| 影響範囲 | Providerの影響範囲が限定されている           |
| 出力検証 | すべての必須項目が含まれている               |
| 事実確認 | 推測には限定詞を使用している                 |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                               |
| ------------ | ---------------------------------- |
| 最小範囲     | Providerの影響範囲を最小化する     |
| 過度導入禁止 | propsで解決可能ならContextを避ける |
