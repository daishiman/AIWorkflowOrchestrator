## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                            |
| -------- | ----------------------------------------------------- |
| 1        | コンテキスト分析結果を確認                            |
| 2        | `references/Level2_intermediate.md` を読込            |
| 3        | `assets/openapi-template.yaml` を参照                 |
| 4        | `assets/endpoint-template.md` でエンドポイント記述    |
| 5        | 認証フローを`references/authentication-docs.md`で確認 |
| 6        | エラーレスポンスを定義                                |
| 7        | 作成結果を出力                                        |

### 4.2 チェックリスト

| 項目        | 基準                        |
| ----------- | --------------------------- |
| OpenAPI完全 | 全エンドポイントが定義      |
| 認証記述    | 認証フローが文書化          |
| エラー定義  | 統一されたエラー形式        |
| サンプル    | リクエスト/レスポンス例あり |

### 4.3 ビジネスルール（制約）

| 制約        | 説明                       |
| ----------- | -------------------------- |
| OpenAPI準拠 | 仕様はOpenAPI形式で定義    |
| 一貫性      | エラー形式を統一           |
| 実用性      | 実際の運用ケースに基づく例 |
