## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                    |
| -------- | --------------------------------------------- |
| 1        | 作成結果を確認                                |
| 2        | `scripts/validate-openapi.mjs` で検証         |
| 3        | `scripts/validate-skill.mjs` でスキル構造確認 |
| 4        | ドキュメントの完全性を確認                    |
| 5        | 問題があれば create-documentation に差し戻し  |
| 6        | `scripts/log_usage.mjs` で記録を保存          |
| 7        | 検証結果レポートを出力                        |

### 4.2 チェックリスト

| 項目        | 基準                     |
| ----------- | ------------------------ |
| OpenAPI検証 | バリデーションエラーなし |
| 完全性      | 全エンドポイントが記述   |
| 一貫性      | スタイルが統一           |
| 記録完了    | log_usage.mjs で記録済み |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全項目検証 | すべてのドキュメントを検証     |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
