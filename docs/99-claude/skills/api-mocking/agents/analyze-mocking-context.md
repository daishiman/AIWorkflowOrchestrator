## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                   |
| -------- | -------------------------------------------- |
| 1        | テスト対象のAPI仕様を確認                    |
| 2        | `references/Level1_basics.md` を読込         |
| 3        | `references/mock-patterns.md` でパターン確認 |
| 4        | モック化の範囲を定義                         |
| 5        | エラーケースの要件を整理                     |
| 6        | コンテキスト分析結果を出力                   |

### 4.2 チェックリスト

| 項目         | 基準                   |
| ------------ | ---------------------- |
| API仕様      | エンドポイントが特定   |
| モック範囲   | 範囲が明確に定義       |
| エラーケース | テスト対象エラーが列挙 |
| パターン     | 実装パターンが選定     |

### 4.3 ビジネスルール（制約）

| 制約        | 説明                            |
| ----------- | ------------------------------- |
| 外部API排除 | テスト環境では外部API依存を排除 |
| エラー包括  | 4xx、5xx、タイムアウトを含める  |
| 正確性      | 実API仕様に基づいたモック       |
