## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                 |
| -------- | ------------------------------------------ |
| 1        | コンテキスト分析結果を確認                 |
| 2        | `references/Level2_intermediate.md` を読込 |
| 3        | ユーザーストーリーを作成                   |
| 4        | プランニングポーカーで見積もり             |
| 5        | スプリントバックログを作成                 |
| 6        | 日次スタンドアップを実施                   |
| 7        | 進捗を追跡しバーンダウンを更新             |

### 4.2 チェックリスト

| 項目               | 基準                               |
| ------------------ | ---------------------------------- |
| ユーザーストーリー | 受け入れ基準が明確                 |
| 見積もり           | ストーリーポイントが付与されている |
| スプリント目標     | 達成可能な目標が設定されている     |
| 進捗追跡           | バーンダウンが更新されている       |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                   |
| -------------- | ---------------------- |
| タイムボックス | スプリント長は固定     |
| WIP制限        | 作業中アイテム数を制限 |
| 透明性         | 進捗は常に可視化       |
