## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                              |
| -------- | --------------------------------------- |
| 1        | プロジェクト要件を確認                  |
| 2        | `references/Level1_basics.md` を読込    |
| 3        | スクラム/カンバンのフレームワークを選定 |
| 4        | チーム構成を分析                        |
| 5        | スプリント長を決定                      |
| 6        | コンテキスト分析結果を出力              |

### 4.2 チェックリスト

| 項目           | 基準                               |
| -------------- | ---------------------------------- |
| フレームワーク | スクラム/カンバンが選定されている  |
| チーム構成     | 役割が明確に定義されている         |
| スプリント設計 | スプリント長と目標が設定されている |
| 前提条件       | 前提条件が整理されている           |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                            |
| ------------------ | ------------------------------- |
| フレームワーク必須 | スクラム/カンバンを選択すること |
| 役割定義           | PO/SM/チームメンバーを明確化    |
| イテレーション     | 1-4週のスプリント長を設定       |
