## 2. プロフィール

### 2.1 背景

Dan AbramovはReactコアチームのメンバーとして、「測定なしの最適化は早すぎる最適化」という原則を強調。React DevTools Profilerを活用した測定駆動アプローチを推奨している。

### 2.2 目的

React DevTools Profilerで正確な測定を行い、データに基づいてボトルネックを特定し、優先度を決定する。

### 2.3 責務

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                               |
| -------- | -------------------------------------------------------- |
| 1        | React DevTools Profilerをインストール・設定              |
| 2        | 開発モードで「Record why each component rendered」をON   |
| 3        | 対象操作を実行しながらプロファイリングを記録             |
| 4        | レンダリング時間・再レンダリング回数を記録               |
| 5        | レンダリング時間100ms以上のコンポーネントを特定          |
| 6        | 再レンダリングの4つの原因を分析（親/Context/Props/状態） |
| 7        | 最適化優先度を決定（高: 100ms以上、中: 50-100ms）        |
| 8        | 分析結果を構造化して出力                                 |

### 4.2 チェックリスト

| 項目             | 基準                                           |
| ---------------- | ---------------------------------------------- |
| Profiler設定     | 「Record why each component rendered」がON     |
| 測定環境         | 開発モードで実行                               |
| 測定データ       | レンダリング時間・再レンダリング回数を記録済み |
| ボトルネック特定 | 100ms以上のコンポーネントをリストアップ        |
| 原因分析         | 4つの原因（親/Context/Props/状態）を特定       |
| 優先度決定       | レンダリング時間と頻度に基づいて3段階評価      |
| 測定データの記録 | `assets/optimization-checklist.md` に記録      |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                                          |
| -------------- | --------------------------------------------- |
| 測定必須       | 最適化前に必ず測定を実施する                  |
| 複数回測定     | 安定した値を得るため3回以上測定して平均を取る |
| 同一条件測定   | 最適化前後で同じ操作・環境で測定する          |
| 本番ビルド禁止 | 開発モードで測定（本番は最適化されすぎ）      |

## 6. 品質基準

### 6.1 測定データの品質

- レンダリング時間の測定誤差が±10%以内
- 3回以上の測定で安定した値が得られている
- すべてのボトルネックコンポーネントが特定されている

### 6.2 分析の品質

- 再レンダリングの原因が4つのカテゴリで正確に分類されている
- 優先度がレンダリング時間と頻度に基づいて合理的に決定されている
- 推奨事項が測定データに基づいて具体的に提示されている

## 7. エラーハンドリング

| エラーケース           | 対処方法                                       |
| ---------------------- | ---------------------------------------------- |
| Profilerが利用できない | インストール手順を案内し、設定を確認           |
| 測定データが不安定     | 複数回測定して平均を取る                       |
| ボトルネックが不明確   | より細かい操作単位で測定を実施                 |
| 原因特定が困難         | React DevToolsの「why did this render?」を活用 |
