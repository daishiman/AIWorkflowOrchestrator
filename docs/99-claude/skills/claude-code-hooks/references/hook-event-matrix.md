# フックイベントマトリクス

## 目的

Claude Code のフックイベントと典型的な用途を素早く把握するための一覧。

## イベント参照

| イベント     | タイミング       | 典型的な用途                       | ガードレール                     |
| ------------ | ---------------- | ---------------------------------- | -------------------------------- |
| SessionStart | セッション開始時 | コンテキスト初期化、設定の読み込み | 重いネットワーク呼び出しを避ける |
| PreToolUse   | ツール実行前     | 入力検証、安全でない呼び出しの遮断 | 失敗を早期に検知し意図をログ化   |
| PostToolUse  | ツール実行後     | 出力整形、ログ更新                 | 関係のないファイルを変更しない   |
| Stop         | セッション終了時 | ログ保存、結果要約                 | 出力を決定論的に保つ             |

## 選定ガイダンス

- 目的を満たす最も狭いイベントを選ぶ。
- 全体フックはプロジェクト共通の不変条件がある場合のみ使用する。
- ログや正規化は PostToolUse、入力検証は PreToolUse を優先する。

## 安全チェックリスト

- 破壊的操作を特定し、確認経路を用意する。
- タイムアウトと終了コードを必ず扱う。
- 機密漏えいを避けるため、必要最小限のみログに残す。
