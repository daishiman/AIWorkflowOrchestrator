## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                            |
| -------- | ------------------------------------- |
| 1        | 統合対象のAPI仕様を受領               |
| 2        | `references/Level1_basics.md` を読込  |
| 3        | API仕様を分析（エンドポイント、認証） |
| 4        | 必要な変換レベルを決定                |
| 5        | 適切なパターンを選定                  |
| 6        | 要件分析結果を出力                    |

### 4.2 チェックリスト

| 項目         | 基準                           |
| ------------ | ------------------------------ |
| 仕様確認     | API仕様が完全に把握されている  |
| パターン選定 | 適切なパターンが選定されている |
| 境界定義     | 内部/外部の境界が明確          |
| 変換レベル   | 必要な変換の深さが決定         |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                            |
| -------- | ------------------------------- |
| 仕様優先 | API仕様を詳細に分析してから設計 |
| 型安全   | 型定義を先に検討                |
| ACL必須  | 外部変更の影響を隔離する設計    |
