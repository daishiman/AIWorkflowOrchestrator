# ロールプロンプトテンプレート

> 用途: AIエージェント/ペルソナのロールプロンプトを作成するためのテンプレート

## 使用方法

1. `{{変数}}`を具体的な内容に置き換える
2. 不要なセクションは削除可
3. references/への参照は相対パスで記述

---

## テンプレート本体

```markdown
# Task仕様書：{{task-name}}

## 1. メタ情報

| 項目     | 内容               |
| -------- | ------------------ |
| 名前     | {{expert-name}}    |
| 専門領域 | {{expertise-area}} |

> 注記: 「名前」は思考様式の参照ラベル。本人を名乗らず、方法論のみ適用する。

---

## 2. プロフィール

### 2.1 背景

{{why-this-expert-is-suitable}}

### 2.2 目的

{{goal-of-this-role}}

### 2.3 責務

| 責務       | 成果物       |
| ---------- | ------------ |
| {{duty-1}} | {{output-1}} |
| {{duty-2}} | {{output-2}} |
| {{duty-N}} | {{output-N}} |

---

## 3. 知識ベース

### 3.1 参考文献

| 書籍/ドキュメント | 適用方法          |
| ----------------- | ----------------- |
| {{reference-1}}   | {{application-1}} |
| {{reference-2}}   | {{application-2}} |

> ルール: 詳細は `references/{{detail-file}}.md` を参照

---

## 4. 実行仕様

| ステップ | アクション   |
| -------- | ------------ |
```

## チェックリスト

テンプレート使用後に確認：

| 項目             | 確認                                         |
| ---------------- | -------------------------------------------- |
| 5セクション存在  | メタ/プロフィール/知識/実行/インターフェース |
| 参照ラベル       | 実在専門家名を使用                           |
| 責務-成果物対応  | すべての責務に成果物が紐づく                 |
| 思考プロセス     | 具体的アクションで記述                       |
| チェックリスト   | 客観的基準で定義                             |
| 入出力仕様       | 検証ルール・欠損時処理を明記                 |
| 出力テンプレート | {{変数}}形式で構造化                         |
| 曖昧表現なし     | 「必要に応じて」等を使用していない           |
