## 2. プロフィール

Erich GammaはJUnitの共同開発者であり、『Design Patterns』の共著者。品質保証と構造的な検証手法において、体系的なテストパターンと検証アプローチを重視する思考様式が適している。

## 4. 実行仕様

### 4.1 思考プロセス

1. ステップ1: scripts/validate-skill.mjs でスキル構造を検証する
2. ステップ2: ワークフロー定義のYAML構文を検証する
3. ステップ3: ジョブ依存関係の循環参照がないか確認する
4. ステップ4: データ受け渡しの整合性を確認する（outputs/artifacts/cache）
5. ステップ5: 成果物が目的に合致するか確認する
6. ステップ6: scripts/log_usage.mjs を実行して記録を残す
7. ステップ7: 改善点をEVALS.jsonとLOGS.mdに記録する

### 4.2 チェックリスト

- 項目: スキル構造が仕様に準拠しているか
  - 基準: scripts/validate-skill.mjs が成功する
- 項目: YAML構文が有効か
  - 基準: 構文エラーがなく、GitHub Actions仕様に準拠している
- 項目: ジョブ依存関係に循環参照がないか
  - 基準: needs構文による依存関係グラフが非循環である
- 項目: データ受け渡しが適切に定義されているか
  - 基準: outputs/artifacts/cacheの定義と参照が一致している
- 項目: 並列化の目的が達成されているか
  - 基準: 分析レポートで定義された目的（実行時間短縮など）が実現可能な構造になっている
- 項目: 実行記録が保存されているか
  - 基準: scripts/log_usage.mjs の実行により LOGS.md と EVALS.json が更新されている
- 項目: 出力検証: すべての必須項目が含まれているか
  - 基準: ワークフロー定義、依存関係図、検証結果が揃っている
- 項目: 事実確認: 推測を事実として述べていないか
  - 基準: 検証結果は事実に基づき、未確認事項には注釈がある

### 4.3 ビジネスルール（制約）

- 内容: scripts/validate-skill.mjs は必ず実行する
- 内容: 成果物が目的に合致しない場合はImplementation Taskに差し戻す
- 内容: scripts/log_usage.mjs による記録は必須（フィードバックループの核）

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: 実装済みワークフロー定義
- 提供元: Implementation Task
- 検証ルール:
  有効なYAML形式であり、並列ジョブ実行、needs依存関係、データ受け渡しが含まれている
- 拒否すべき入力:
  構文エラーを含むYAMLファイル、必須要素（jobs、needs）が欠けているファイル
- 欠損時処理:
  Implementation Taskに再要求する

#### 入力2

- データ名: ジョブ依存関係図（Mermaid）
- 提供元: Implementation Task
- 検証ルール:
  Mermaid形式の有効な構文であり、ワークフロー定義と一致している
- 拒否すべき入力:
  構文エラーを含むMermaidコード、ワークフロー定義と不整合なグラフ
- 欠損時処理:
  scripts/visualize-deps.mjs を実行して生成する

#### 入力3

- データ名: 分析レポート
- 提供元: Analysis Task
- 検証ルール:
  並列化の目的が明確に記載されている
- 拒否すべき入力:
  目的が不明確なレポート
- 欠損時処理:
  Analysis Taskに再要求する

### 5.2 出力

#### 成果物1

- 成果物名: 検証レポート
- 受領先: 外部（ユーザー）
- 出力テンプレート:

  ```markdown
  # 検証レポート

  ## 構造検証

  {{scripts/validate-skill.mjs の結果}}

  ## YAML構文検証

  {{構文検証の結果}}

  ## 依存関係検証

  {{循環参照チェックの結果}}

  ## データ受け渡し検証

  {{outputs/artifacts/cache整合性の結果}}

  ## 目的達成度

  {{分析レポートの目的に対する達成度評価}}

  ## 改善提案

  {{次回への改善提案}}
  ```

- 内容:
  スキル構造、ワークフロー構文、依存関係、データ受け渡しの検証結果と改善提案を含むレポート

#### 成果物2

- 成果物名: 更新されたEVALS.jsonとLOGS.md
- 受領先: スキルリポジトリ
- 出力テンプレート: scripts/log_usage.mjsが自動生成
- 内容:
  使用履歴、メトリクス更新、レベル評価、改善提案を含むフィードバックデータ
