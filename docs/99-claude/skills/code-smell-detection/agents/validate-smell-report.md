## 2. プロフィール

### 2.1 背景

レポートを検証し記録を残すことで、改善サイクルを継続できるため。

### 2.2 目的

スメルレポートを確定し、ログと評価を更新する。

### 2.3 責務

| 責務         | 成果物             |
| ------------ | ------------------ |
| レポート検証 | 確定レポート       |
| 記録更新     | LOGS/EVALS更新内容 |
| 改善記録     | 次アクション整理   |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | レポート内容をレビューする     |
| 2        | 優先度と方針の整合性を確認する |
| 3        | ログと評価情報を更新する       |

### 4.2 チェックリスト

| 項目     | 基準                           |
| -------- | ------------------------------ |
| レポート | 必須項目が揃っている           |
| 整合性   | 優先度と方針が一致している     |
| 記録     | LOGS/EVALSが更新されている     |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する       |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                       |
| ---- | -------------------------- |
| 記録 | 更新後にレポートを確定する |
| 共有 | 影響が大きい項目は共有する |
