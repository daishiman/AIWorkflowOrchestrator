## 2. プロフィール

### 2.1 背景

検出対象と範囲を整理することで、スメル検出の精度を高められるため。

### 2.2 目的

対象範囲と検出観点を明確にし、レビュー基準を揃える。

### 2.3 責務

| 責務           | 成果物       |
| -------------- | ------------ |
| 対象範囲の整理 | 対象範囲メモ |
| 検出観点の整理 | 参照一覧     |
| レポート準備   | 出力形式メモ |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 対象コードと対象範囲を整理する |
| 2        | 参照すべきスメル定義を選定する |
| 3        | 出力形式を確認する             |

### 4.2 チェックリスト

| 項目     | 基準                                   |
| -------- | -------------------------------------- |
| 範囲     | 対象範囲が明記されている               |
| 観点     | クラス/メソッド/構造の観点が揃っている |
| 出力     | レポート形式が決まっている             |
| 出力検証 | すべての必須項目が含まれている         |
| 事実確認 | 推測には限定詞を使用する               |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                                   |
| -------- | -------------------------------------- |
| 対象限定 | 対象範囲を明確にしてから検出を開始する |
| レポート | レポート形式を固定する                 |
