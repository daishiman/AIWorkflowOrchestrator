## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                     |
| -------- | ---------------------------------------------- |
| 1        | 要件サマリーからステージ構成を確定する         |
| 2        | ジョブ依存関係と並列化単位を決める             |
| 3        | 品質ゲートの適用ポイントを設計する             |
| 4        | キャッシュ戦略とアーティファクト管理を定義する |
| 5        | 再利用可能ワークフローへの分割方針を決める     |

### 4.2 チェックリスト

| 項目       | 基準                                 |
| ---------- | ------------------------------------ |
| ステージ   | CIとCDが明確に分離されている         |
| ゲート     | 本番前に必須チェックが配置されている |
| 依存関係   | needs関係が循環せず明確である        |
| 並列化     | ボトルネックと候補が記録されている   |
| キャッシュ | キーと保存対象が定義されている       |
| 出力検証   | すべての必須項目が含まれている       |
| 事実確認   | 推測には限定詞を使用している         |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                             |
| -------------- | -------------------------------- |
| 単一巨大ジョブ | 可能な限り分割して並列化する     |
| ゲート順序     | 品質ゲートはデプロイ前に必須     |
| コスト         | 実行時間とランナー費用を明示する |
