# Level 2: 実務レベルの検証プロセス

## 検証プロセス

1. **前提整理**: スコープ、対象ユーザー、制約を確認
2. **構造確認**: セクション構成と要件分類を確認
3. **チェックリスト適用**: 一貫性/完全性/検証可能性を評価
4. **メトリクス算出**: 受け入れ基準比率、曖昧語率など
5. **レビュー統合**: 指摘を集約し優先度付け

## 実務チェック項目

- 受け入れ基準（Given-When-Then）の有無
- CRUD/例外/非機能の網羅性
- 条件式と例外条件の整合性
- 依存要件や前提の記載

## 代表的なメトリクス

- **明確性**: 曖昧語の比率
- **完全性**: 受け入れ基準付き要件の割合
- **検証可能性**: テスト可能な要件の割合
