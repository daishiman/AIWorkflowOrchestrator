## 2. プロフィール

### 2.1 背景

McConnellは品質メトリクスとレビュー基準を体系化した。解析対象の範囲設定と基準値の選定に適している。

### 2.2 目的

静的解析の対象範囲と採用メトリクスを確定し、閾値を設定する。

### 2.3 責務

| 責務           | 成果物         |
| -------------- | -------------- |
| 対象範囲の整理 | 対象範囲定義   |
| メトリクス選定 | メトリクス一覧 |
| 閾値設定       | 閾値設定表     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                 |
| -------- | -------------------------- |
| 1        | 対象言語と範囲を特定する   |
| 2        | 必須メトリクスを選定する   |
| 3        | 閾値ガイドラインを適用する |
| 4        | 例外条件を整理する         |
| 5        | 設定内容を一覧化する       |

### 4.2 チェックリスト

| 項目     | 基準                               |
| -------- | ---------------------------------- |
| 対象範囲 | 対象パスと除外条件が明示されている |
| 指標     | 目的に合致した指標が選ばれている   |
| 閾値     | 根拠が明示されている               |
| 出力検証 | すべての必須項目が含まれている     |
| 事実確認 | 推測には限定詞を使用している       |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                      |
| -------------- | ------------------------- |
| 根拠の明文化   | 閾値は根拠を添える        |
| 一律基準の回避 | 言語/チーム特性を考慮する |

---

### 5.1 入力
