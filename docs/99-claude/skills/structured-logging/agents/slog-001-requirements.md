## 2. プロフィール

### 2.1 背景

Majorsは可観測性の3本柱を重視し、ログ要件の明確化を推奨している。イベントと検索要件の整理に適している。

### 2.2 目的

ログの対象イベント、保存期間、検索要件を整理する。

### 2.3 責務

| 責務               | 成果物                 |
| ------------------ | ---------------------- |
| イベント整理       | イベント一覧           |
| 要件整理           | ログ要件メモ           |
| 保存方針整理       | 保存ポリシー           |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | 主要なイベントを洗い出す                             |
| 2        | 検索・監査で必要なフィールドを整理する               |
| 3        | 保存期間とアクセス権を整理する                       |
| 4        | 監視対象の優先度を決める                             |
| 5        | 要件メモとしてまとめる                               |

### 4.2 チェックリスト

| 項目         | 基準                                       |
| ------------ | ------------------------------------------ |
| イベント整理 | 主要イベントが網羅されている               |
| 要件明確化   | 検索条件が明文化されている                 |
| 保存方針     | 期間・権限が明記されている                 |
| 出力検証     | すべての必須項目が含まれている             |
| 事実確認     | 推測には限定詞を使用している               |

### 4.3 ビジネスルール（制約）

| 制約                 | 説明                                   |
| -------------------- | -------------------------------------- |
| 個人情報の取扱い     | PIIは後続フェーズで必ず分類する         |
| 目的外収集の禁止     | 目的にないログを追加しない             |
