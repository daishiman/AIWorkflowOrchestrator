## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 仕様と制約を読み取る |
| 2 | 入力パラメータを列挙する |
| 3 | 範囲/型/制約を整理する |
| 4 | 入力整理メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 入力列挙 | 主要パラメータが列挙されている |
| 制約整理 | 範囲/型/必須が明記されている |
| リスク | 失敗しやすい入力が記載されている |
| 出力検証 | 入力整理メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 網羅性 | 主要パラメータを省略しない |
| 明確性 | 制約は数値または条件で記載する |
| 前提整理 | 不明点は明記する |

---

### 5.1 入力
