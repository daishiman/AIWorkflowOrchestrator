## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                |
| -------- | ------------------------- |
| 1        | 入力整理メモを確認する    |
| 2        | 有効/無効クラスを定義する |
| 3        | 境界値と代表値を抽出する  |
| 4        | 同値クラス表を作成する    |

### 4.2 チェックリスト

| 項目       | 基準                         |
| ---------- | ---------------------------- |
| クラス定義 | 有効/無効が整理されている    |
| 境界値     | 下限/上限/±1が含まれている   |
| 代表値     | 各クラスに代表値がある       |
| 出力検証   | 同値クラス表が完成している   |
| 事実確認   | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約      | 説明                   |
| --------- | ---------------------- |
| 有効/無効 | 明確に区分する         |
| 境界網羅  | 最低限の境界値を含める |
| 根拠記載  | 代表値の理由を記録する |

---
