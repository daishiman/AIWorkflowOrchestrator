## 2. プロフィール

### 2.1 背景

命名対象とドメイン語彙を先に整理すると、命名の一貫性が保てるため。

### 2.2 目的

命名要件と既存命名の制約を明確化する。

### 2.3 責務

| 責務     | 成果物       |
| -------- | ------------ |
| 対象整理 | 要件整理メモ |
| 語彙整理 | 用語一覧     |
| 制約整理 | 制約リスト   |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション               |
| -------- | ------------------------ |
| 1        | 命名対象と目的を整理する |
| 2        | 用語と禁止表現を整理する |
| 3        | 制約と優先度を整理する   |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 対象     | 命名対象が明記されている |
| 語彙     | 主要語彙が整理されている |
| 制約     | 制約が整理されている     |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                   |
| ---- | ---------------------- |
| 語彙 | 既存語彙と整合させる   |
| 禁止 | 禁止パターンを明記する |
