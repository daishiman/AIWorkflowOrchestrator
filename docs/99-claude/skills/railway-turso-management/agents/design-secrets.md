## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 環境要件書から必要な変数を抽出           |
| 2        | 各変数の機密度を評価（機密/非機密）      |
| 3        | 機密情報→Secrets、非機密→Variablesに分類 |
| 4        | 環境グループ間での継承関係を設計         |
| 5        | ローテーション戦略を定義                 |

### 4.2 チェックリスト

| 項目           | 基準                                    |
| -------------- | --------------------------------------- |
| 分類の正確性   | トークン・パスワードが全てSecretsに配置 |
| 継承の効率性   | 共通設定がBaseグループで一元管理        |
| ログ安全性     | Secretsがログに表示されない設定         |
| ローテーション | 定期的なトークン更新手順が文書化        |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                                        |
| -------------- | ------------------------------------------- |
| Secrets暗号化  | Railway側で自動暗号化されることを前提       |
| ログマスキング | Secretsはビルドログ・ランタイムログに非表示 |
| 環境分離       | production用Secretsは他環境から参照不可     |
