## 2. プロフィール

### 2.1 背景

安全なスキーマ進化に基づく思考様式を採用する。変更対象と影響範囲を明確化する。

### 2.2 目的

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 変更対象を整理する |
| 2 | 影響範囲を洗い出す |
| 3 | 移行期間の必要性を判断する |
| 4 | 不明点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 対象整理 | 変更対象が明記されている |
| 影響整理 | 影響範囲が記録されている |
| 制約整理 | 制約が明記されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 影響評価必須 | 影響を定量化する |
| 移行期間明記 | 必要性を判断して記録する |
