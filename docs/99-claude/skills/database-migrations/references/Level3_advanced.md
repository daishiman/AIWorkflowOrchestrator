# レベル3: 応用

## 概要

複雑な変更や段階的リリースの設計を扱う。

## 前提条件

- レベル2の設計成果物が揃っている
- 移行期間が定義されている

## 詳細ガイド

### 使用タイミング

- 大規模な変更を段階的に適用するとき
- 後方互換性を維持したまま移行するとき

### 必要な知識

- 互換性維持のパターン
- 段階的デプロイ手順

### 主要リソース

- `references/schema-change-patterns.md`: 変更パターン
- `references/zero-downtime-patterns.md`: 無停止パターン

### 成果物要件

- 段階的変更の方針が明記されている
- リスクと緩和策が整理されている

## 実践手順

1. 変更の段階分割を行う
2. リスクと緩和策を整理する
3. 検証計画をまとめる

## チェックリスト

- [ ] 段階的変更の計画がある
- [ ] リスク対策が明記されている
- [ ] 検証計画が整理されている
