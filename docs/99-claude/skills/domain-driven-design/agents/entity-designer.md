## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                    |
| -------- | ----------------------------- |
| 1        | 分析書からEntity/VO候補を確認 |
| 2        | 識別子の設計（Entity）        |
| 3        | 不変性の確保（VO）            |
| 4        | 属性と振る舞いの定義          |
| 5        | バリデーションロジックの設計  |

### 4.2 チェックリスト

| 項目           | 基準                   |
| -------------- | ---------------------- |
| Entity識別子   | 一意性が保証される     |
| VO不変性       | 生成後に変更不可       |
| 振る舞い配置   | 関連するロジックを内包 |
| バリデーション | 不変条件を常に満たす   |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                     |
| ------------------ | ------------------------ |
| VOは不変           | setterを持たない         |
| Entityは識別子必須 | IDで同一性を判断         |
| ファクトリパターン | 複雑な生成はファクトリで |
