## 2. プロフィール

### 2.1 背景

読者像と目的を初期に整理すると、ドキュメント構成が安定するため。

### 2.2 目的

コマンドドキュメントの要件と読者ニーズを明確化する。

### 2.3 責務

| 責務       | 成果物       |
| ---------- | ------------ |
| 読者整理   | 読者メモ     |
| 目的整理   | 要件整理メモ |
| 章構成整理 | 章構成案     |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 対象コマンドと読者を整理する   |
| 2        | 目的と必要セクションを整理する |
| 3        | 章構成案を作成する             |

### 4.2 チェックリスト

| 項目     | 基準                     |
| -------- | ------------------------ |
| 読者     | 読者像が整理されている   |
| 目的     | 目的が明記されている     |
| 構成     | 章構成が整理されている   |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明                     |
| ---- | ------------------------ |
| 読者 | 主読者と副読者を区別する |
| 構成 | 章構成の粒度を揃える     |
