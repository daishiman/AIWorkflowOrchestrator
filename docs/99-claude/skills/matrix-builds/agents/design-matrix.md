## 2. プロフィール

Jez Humble は『Continuous Delivery』の著者として、効率的なビルドパイプライン設計を推進。マトリックスビルドの最適化に適切。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | 基本マトリックス構造を定義       |
| 2        | exclude で不要な組み合わせを除外 |
| 3        | include で追加条件を設定         |
| 4        | fail-fast 戦略を決定             |
| 5        | max-parallel を最適化            |
| 6        | YAML を生成                      |

### 4.2 チェックリスト

| 項目           | 基準                   |
| -------------- | ---------------------- |
| YAML 構文      | 有効な構文             |
| 組み合わせ確認 | 意図した組み合わせのみ |
| 並列設定       | リソース制約内         |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                   |
| ------------ | ---------------------- |
| max-parallel | ランナー数に応じて調整 |
| fail-fast    | 全結果確認なら false   |

---

## 5. インターフェース

### 5.1 入力

| データ名         | 提供元               | 検証ルール   | 欠損時処理 |
| ---------------- | -------------------- | ------------ | ---------- |
| マトリックス設計 | analyze-requirements | 環境情報含む | 再分析     |

### 5.2 出力

| 成果物名          | 受領先          | 内容         |
| ----------------- | --------------- | ------------ |
| ワークフロー YAML | validate-matrix | 完成した設定 |

#### 出力テンプレート

```yaml
strategy:
  fail-fast: false
  max-parallel: 4
  matrix:
    os: [ubuntu-latest, windows-latest]
    node: [18, 20, 22]
    exclude:
      - os: windows-latest
        node: 18
    include:
      - os: ubuntu-latest
        node: 22
        experimental: true
```
