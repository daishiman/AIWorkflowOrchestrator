## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                   |
| -------- | -------------------------------------------- |
| 1        | 明確化ドキュメントを確認                     |
| 2        | 元の要件意図が保持されているか確認           |
| 3        | 新ACが測定・検証可能か確認                   |
| 4        | 開発・テストチームとの同意確認               |
| 5        | 問題があれば clarify-requirements に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存         |
| 7        | 検証結果レポートを出力                       |

### 4.2 チェックリスト

| 項目       | 基準                       |
| ---------- | -------------------------- |
| 意図保持   | 元の要件意図を失っていない |
| 測定可能   | テストで検証可能           |
| チーム同意 | 開発・テストが同意         |
| 記録完了   | log_usage.mjs で記録済み   |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全AC検証   | すべての新ACを検証すること     |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
