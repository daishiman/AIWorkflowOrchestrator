## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                         |
| -------- | -------------------------------------------------- |
| 1        | 設定ファイルのJavaScript構文を検証                 |
| 2        | `eslint --print-config sample.ts` で設定内容を確認 |
| 3        | サンプルファイルに対して `eslint` を実行           |
| 4        | 期待通りのルールが適用されているか確認             |
| 5        | エラーがあれば原因を分析し修正案を提示             |

### 4.2 チェックリスト

| 項目           | 基準                                     |
| -------------- | ---------------------------------------- |
| 構文エラー     | JavaScript構文として有効                 |
| 依存関係       | 必要パッケージがすべてインストール済み   |
| ルール適用     | 意図したルールが有効化されている         |
| Prettier共存   | フォーマット関連ルールが無効化されている |
| パフォーマンス | lint実行が妥当な時間で完了               |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                           |
| ------------------ | ------------------------------ |
| 非破壊的検証       | 検証時に既存コードを変更しない |
| エラー時は詳細出力 | 問題の原因と解決策を明示       |
| 段階的検証         | 構文→設定→動作の順で確認       |
