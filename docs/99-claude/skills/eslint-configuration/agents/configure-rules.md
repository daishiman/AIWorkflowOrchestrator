## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                              |
| -------- | --------------------------------------- |
| 1        | 技術スタック情報を確認                  |
| 2        | Flat Config形式でeslint.config.jsを設計 |
| 3        | 言語に応じたパーサーを選定              |
| 4        | フレームワーク固有プラグインを追加      |
| 5        | recommendedルールセットを適用           |
| 6        | Prettier使用時は競合ルールを無効化      |
| 7        | 設定ファイルを生成                      |

### 4.2 チェックリスト

| 項目       | 基準                                          |
| ---------- | --------------------------------------------- |
| 形式       | Flat Config（eslint.config.js）を使用         |
| パーサー   | TypeScript時は@typescript-eslint/parserを使用 |
| プラグイン | 必要最小限のプラグインのみ追加                |
| 競合解決   | Prettier使用時はeslint-config-prettier適用    |
| コメント   | 設定意図を日本語コメントで記載                |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                                |
| ------------------ | ----------------------------------- |
| Flat Config優先    | ESLint v9以降の標準形式             |
| 段階的厳格化       | まずrecommended、必要に応じてstrict |
| パフォーマンス考慮 | 型チェックルールは必要時のみ        |

## 5. インターフェース

### 5.1 入力

### 5.2 出力

| 成果物名           | 受領先       | 内容                 |
| ------------------ | ------------ | -------------------- |
| ESLint設定ファイル | プロジェクト | eslint.config.js     |
| 必要パッケージ一覧 | ユーザー     | インストールコマンド |

#### 出力テンプレート

```javascript
// eslint.config.js
// Generated by eslint-configuration skill
// Project: {{projectName}}
// Date: {{date}}

import globals from "globals";
{{#if typescript}}
import tseslint from "typescript-eslint";
{{/if}}
{{#if react}}
import reactPlugin from "eslint-plugin-react";
import reactHooksPlugin from "eslint-plugin-react-hooks";
{{/if}}
{{#if prettier}}
import eslintConfigPrettier from "eslint-config-prettier";
{{/if}}

export default [
  // グローバル設定
  {
    languageOptions: {
      globals: {
        ...globals.{{environment}},
      },
    },
  },
  {{#if typescript}}
  // TypeScript設定
  ...tseslint.configs.recommended,
  {{/if}}
  {{#if react}}
  // React設定
  reactPlugin.configs.flat.recommended,
  reactPlugin.configs.flat["jsx-runtime"],
  {{/if}}
  {{#if prettier}}
  // Prettier競合解決
  eslintConfigPrettier,
  {{/if}}
  // カスタムルール
  {
    rules: {
      {{#each customRules}}
      "{{this.name}}": "{{this.value}}",
      {{/each}}
    },
  },
];
```
