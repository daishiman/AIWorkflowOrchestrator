# スライド出力ディレクトリ設定

## 概要

生成したスライドファイルの保存先ディレクトリを設定できます。presentation-slide-generatorスキルで作成されたHTMLスライドは、この設定で指定したディレクトリに保存されます。

## 設定方法

### 1. 設定画面を開く

アプリケーションのメニューから「設定」を選択します。

### 2. スライド設定タブを選択

設定画面で「Slide Output Directory」セクションを見つけます。

### 3. ディレクトリを設定

以下のいずれかの方法でディレクトリを設定できます：

#### 方法A: 直接入力

入力欄にディレクトリパスを直接入力します。

- 例: `/Users/username/Documents/Slides`
- チルダ（`~`）を使用可能: `~/Documents/Slides`

#### 方法B: ダイアログで選択

1. 「Browse」ボタンをクリック
2. OS標準のフォルダ選択ダイアログが開きます
3. 保存先フォルダを選択
4. 「選択」または「開く」をクリック

### 4. 設定を保存

「Save」ボタンをクリックして設定を保存します。

- ボタンは変更がある場合のみ有効になります
- 保存後、設定は即座に反映されます
- アプリを再起動しても設定は維持されます

## デフォルト設定

| 項目                 | デフォルト値         |
| -------------------- | -------------------- |
| 出力ディレクトリ     | `~/Documents/Slides` |
| ディレクトリ自動作成 | 有効                 |
| デフォルトテーマ     | Kanagawa             |

## トラブルシューティング

### パスが無効と表示される場合

- **原因**: 指定したパスが存在しないか、ディレクトリではない
- **対処**:
  1. パスが正しいか確認してください
  2. フォルダが存在することを確認してください
  3. 「Browse」ボタンで直接選択してください

### 保存に失敗する場合

- **原因**: 指定したディレクトリへの書き込み権限がない
- **対処**:
  1. 別のディレクトリを選択してください
  2. ディレクトリの権限設定を確認してください
  3. 必要に応じてシステム管理者に相談してください

### 設定が反映されない場合

- **対処**:
  1. 「Save」ボタンをクリックしたか確認
  2. 「Unsaved changes」メッセージが消えたか確認
  3. アプリを再起動して設定を確認
