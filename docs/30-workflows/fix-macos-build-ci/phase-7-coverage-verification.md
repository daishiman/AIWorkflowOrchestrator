## 目的

Phase 6の拡充結果を検証し、テストカバレッジ基準を満たしていることを確認する。

## 背景

CI/CD修正の品質を保証するため、テストカバレッジの達成状況を確認するゲートフェーズ。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ状況の確認

**目的**: テストカバレッジの達成状況を確認する

**実行手順**:

1. Phase 6で実行したテスト結果を集約
2. 各テストカテゴリの達成状況を確認
3. 未達項目があれば特定
4. カバレッジレポートを作成

**期待される成果物**:

- カバレッジレポート（`outputs/phase-7/coverage-report.md`）

---

### タスク2: 統合テストの再実行

**目的**: 統合テストが全て成功することを再確認する

**実行手順**:

1. CI環境での統合テストを再実行
2. 全テストが成功することを確認
3. 失敗があれば原因を特定
4. 再実行結果を記録

**期待される成果物**:

- 統合テスト再実行結果（`outputs/phase-7/integration-test-rerun.md`）

---

### タスク3: カバレッジゲート判定

**目的**: カバレッジ基準を満たしているか判定する

**実行手順**:

1. テストカバレッジ基準との比較
2. 達成/未達の判定
3. 未達の場合は Phase 6 に戻る
4. 達成の場合は次のPhaseへ

**期待される成果物**:

- ゲート判定結果（カバレッジレポートに含める）
