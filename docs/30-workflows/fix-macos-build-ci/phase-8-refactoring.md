## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ワークフロー設定の整理

**目的**: GitHub Actions ワークフローの可読性を向上させる

**実行手順**:

1. ワークフローファイルのコメントを整理
2. ステップの命名を見直し
3. 不要なコードを削除
4. 設定値の整理

**期待される成果物**:

- 整理された `.github/workflows/build-electron.yml`

---

### タスク2: electron-builder設定の整理

**目的**: electron-builder設定の可読性を向上させる

**実行手順**:

1. 設定ファイルのコメントを追加・整理
2. 設定の構造を見直し
3. 不要なコードを削除
4. 設定値の意図を明記

**期待される成果物**:

- 整理された `apps/desktop/electron-builder.yml`

---

### タスク3: リファクタリング後のテスト実行

**目的**: リファクタリングが既存機能を壊していないことを確認

**実行手順**:

1. ローカルビルドを再実行
2. CI環境でのテストを再実行
3. 全テストが成功することを確認
4. 結果を記録

**期待される成果物**:

- リファクタリング後テスト結果（`outputs/phase-8/refactoring-test-result.md`）

---

### タスク4: リファクタリングログの作成

**目的**: 実施したリファクタリング内容を文書化する

**実行手順**:

1. 変更点を記録
2. 改善理由を記録
3. 注意点を記録
4. 今後の改善案を記録（あれば）

**期待される成果物**:

- リファクタリングログ（`outputs/phase-8/refactoring-log.md`）
