## 実装ガイド

### Part 1: 概念的な説明

#### 問題の背景（中学生にもわかる説明）

**比喩**: macOS のアプリを配布するには「箱詰め」が必要です。

- **DMG（ディスクイメージ）**: きれいな化粧箱。開けると「アプリをApplicationsにドラッグ」という説明付き。
- **ZIP（圧縮ファイル）**: シンプルな段ボール箱。解凍するだけでアプリが使える。

GitHub Actions（クラウド上のロボット）は、化粧箱（DMG）を作る特殊な道具（hdiutil）を使えません。
そこで、シンプルな段ボール箱（ZIP）だけを作ることにしました。

#### なぜこの解決策を選んだか

| 選択肢     | メリット             | デメリット | 採用 |
| ---------- | -------------------- | ---------- | ---- |
| ZIPのみ    | 確実に動く、シンプル | DMGがない  | ✅   |
| 別ツール   | DMGが作れる          | 設定が複雑 | ❌   |
| 専用マシン | 完全な機能           | コスト高   | ❌   |

### Part 2: 技術的な詳細

#### 変更内容

```yaml
# Before: DMG + ZIP
mac:
  target:
    - target: dmg
      arch: [x64, arm64]
    - target: zip
      arch: [x64, arm64]

# After: ZIP only
mac:
  target:
    - target: zip
      arch: [x64, arm64]
```

#### 設計の理由

1. **最小限の変更**: 4行削除のみで問題解決
2. **後方互換性**: dmg セクションは残して将来の再有効化に備える
3. **CI互換性**: macos-14 runner の制限を回避
