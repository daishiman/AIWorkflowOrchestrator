# スコープ定義書

## 概要

macOS CI ビルドエラー修正の対象範囲と対象外を明確に定義する。

---

## 修正対象（In Scope）

### ファイル

| ファイルパス                        | 修正内容                                         |
| ----------------------------------- | ------------------------------------------------ |
| `apps/desktop/electron-builder.yml` | macOS ターゲットから DMG を除外し ZIP のみにする |

### 変更内容

1. **electron-builder.yml の修正**
   - `mac.target` セクションを変更
   - `dmg` ターゲットを削除
   - `zip` ターゲットのみ残す
   - `dmg` セクションは将来のリリース用に残す（コメントアウトまたは維持）

### 変更のイメージ

**Before:**

```yaml
mac:
  target:
    - target: dmg
      arch:
        - x64
        - arm64
    - target: zip
      arch:
        - x64
        - arm64
```

**After:**

```yaml
mac:
  target:
    - target: zip
      arch:
        - x64
        - arm64
```

---

## 修正対象外（Out of Scope）

### ファイル

| ファイルパス                           | 理由                                                |
| -------------------------------------- | --------------------------------------------------- |
| `.github/workflows/build-electron.yml` | アーティファクトパスは `*.zip` を含んでおり変更不要 |
| `apps/desktop/package.json`            | スクリプトに変更なし                                |
| `apps/desktop/scripts/notarize.mjs`    | 署名なしビルドのため影響なし                        |
| Windows/Linux 設定                     | 今回のスコープ外（無効化中）                        |

### 機能

| 機能                         | 理由                                   |
| ---------------------------- | -------------------------------------- |
| DMGの再有効化                | 将来のリリースワークフローで対応予定   |
| コード署名                   | 現在無効化されており、今回のスコープ外 |
| 公証（Notarization）         | 署名なしビルドのため無効               |
| Windows/Linux ビルドの有効化 | 別タスクで対応                         |
| リリースワークフローの作成   | 別タスクで対応                         |

## 制約

| 制約                    | 説明                                                         |
| ----------------------- | ------------------------------------------------------------ |
| GitHub Actions 環境制限 | macos-14 runner では hdiutil による DMG 生成が制限されている |
| 署名なしビルド          | 現在は署名なしでビルドしているため、DMG の配布には制限がある |
| CI 時間制限             | GitHub Actions の実行時間制限に従う                          |

## リスク

| リスク                 | 影響度 | 対策                                              |
| ---------------------- | ------ | ------------------------------------------------- |
| DMG が提供できない     | 低     | ZIP で代替可能。将来リリースワークフローでDMG対応 |
| ローカルビルドへの影響 | 低     | ローカルでも ZIP のみ生成になるが実用上問題なし   |
| 既存ユーザーへの影響   | なし   | まだリリースされていないアプリ                    |
