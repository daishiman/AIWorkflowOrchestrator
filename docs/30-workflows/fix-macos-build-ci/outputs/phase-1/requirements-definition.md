# 要件定義書

## 概要

GitHub Actions CI で macOS ビルドが成功するよう修正し、配布可能な成果物を生成する。

---

## 機能要件

### FR-1: CIビルドの成功

| 項目   | 内容                                               |
| ------ | -------------------------------------------------- |
| 要件ID | FR-1                                               |
| 要件名 | CIビルドの成功                                     |
| 優先度 | 必須                                               |
| 説明   | GitHub Actions の macOS ビルドジョブが成功すること |

**受け入れ基準**:

- [ ] `build-macos-arm64` ジョブが正常終了する
- [ ] ビルドログにエラーが含まれない
- [ ] `hdiutil: create failed` エラーが発生しない

### FR-2: 配布可能な成果物の生成

| 項目   | 内容                                                |
| ------ | --------------------------------------------------- |
| 要件ID | FR-2                                                |
| 要件名 | 配布可能な成果物の生成                              |
| 優先度 | 必須                                                |
| 説明   | macOSで実行可能な配布形式のファイルが生成されること |

**受け入れ基準**:

- [ ] ZIP形式の成果物が生成される
- [ ] 成果物がGitHub Actionsのアーティファクトとしてアップロードされる
- [ ] 成果物のサイズが妥当である（空ファイルでない）

### FR-3: アーティファクトのアップロード

| 項目   | 内容                                                           |
| ------ | -------------------------------------------------------------- |
| 要件ID | FR-3                                                           |
| 要件名 | アーティファクトのアップロード                                 |
| 優先度 | 必須                                                           |
| 説明   | 生成された成果物がGitHub Actionsからダウンロード可能であること |

**受け入れ基準**:

- [ ] `Upload artifact` ステップが成功する
- [ ] アーティファクトがGitHub UIからダウンロード可能
- [ ] アーティファクト名が `electron-macos-arm64` である

---

## 非機能要件

### NFR-1: ビルド時間

| 項目   | 内容                             |
| ------ | -------------------------------- |
| 要件ID | NFR-1                            |
| 要件名 | ビルド時間                       |
| 優先度 | 推奨                             |
| 説明   | ビルド時間が許容範囲内であること |

**受け入れ基準**:

- [ ] 全体のビルド時間が30分以内
- [ ] DMG生成をスキップすることで、従来より高速化される可能性あり

### NFR-2: 成果物のサイズ

| 項目   | 内容                           |
| ------ | ------------------------------ |
| 要件ID | NFR-2                          |
| 要件名 | 成果物のサイズ                 |
| 優先度 | 推奨                           |
| 説明   | 成果物のサイズが適切であること |

**受け入れ基準**:

- [ ] ZIPファイルのサイズが100MB〜500MB程度（アプリの内容に依存）
- [ ] 圧縮が正常に行われている

### NFR-3: 後方互換性

| 項目   | 内容                                 |
| ------ | ------------------------------------ |
| 要件ID | NFR-3                                |
| 要件名 | 後方互換性                           |
| 優先度 | 必須                                 |
| 説明   | 修正が既存の機能に影響を与えないこと |

**受け入れ基準**:

- [ ] ローカルでのビルドが引き続き動作する
- [ ] 他のプラットフォーム（Windows/Linux）のビルド設定に影響がない
- [ ] 既存のリリースワークフローに影響がない

---

## 制約条件

| 制約               | 説明                                                   |
| ------------------ | ------------------------------------------------------ |
| GitHub Actions環境 | macos-14 runner の制限に従う                           |
| DMG生成            | CI環境ではDMG生成ができない（hdiutil制限）             |
| 署名               | 署名なしビルド（`CSC_IDENTITY_AUTO_DISCOVERY: false`） |

---

## 前提条件

| 前提                 | 説明                               |
| -------------------- | ---------------------------------- |
| pnpmの使用           | パッケージマネージャーはpnpmを使用 |
| Node.js 22           | Node.js 22を使用                   |
| electron-builder v26 | electron-builder v26.0.0を使用     |

---

## 受け入れ基準まとめ

| ID   | 基準                                 | 必須 |
| ---- | ------------------------------------ | ---- |
| AC-1 | `build-macos-arm64` ジョブが成功する | ✅   |
| AC-2 | ZIP形式の成果物が生成される          | ✅   |
| AC-3 | アーティファクトがアップロードされる | ✅   |
| AC-4 | エラーログがない                     | ✅   |
| AC-5 | ローカルビルドに影響がない           | ✅   |
| AC-6 | 他プラットフォームに影響がない       | ✅   |
