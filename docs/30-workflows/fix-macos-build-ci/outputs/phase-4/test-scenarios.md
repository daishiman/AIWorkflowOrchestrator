# テストシナリオ一覧

## 概要

macOS CI ビルド修正の検証に必要なテストシナリオを定義する。

---

## 正常系テストシナリオ

### TS-001: CIビルド成功

| 項目       | 内容                                                  |
| ---------- | ----------------------------------------------------- |
| シナリオID | TS-001                                                |
| シナリオ名 | CIビルドが成功する                                    |
| 前提条件   | `electron-builder.yml` で DMG target が除外されている |
| 実行手順   | 1. PRを作成またはブランチをプッシュ                   |
|            | 2. GitHub Actions が起動                              |
|            | 3. `build-macos-arm64` ジョブが実行される             |
| 期待結果   | ジョブが成功（緑チェック）                            |
| 優先度     | 高                                                    |

### TS-002: ZIP成果物生成

| 項目       | 内容                                       |
| ---------- | ------------------------------------------ |
| シナリオID | TS-002                                     |
| シナリオ名 | ZIP形式の成果物が生成される                |
| 前提条件   | CIビルドが実行されている                   |
| 実行手順   | 1. ビルドジョブの完了を待つ                |
|            | 2. `apps/desktop/dist/` ディレクトリを確認 |
| 期待結果   | `*.zip` ファイルが生成されている           |
| 優先度     | 高                                         |

### TS-003: アーティファクトアップロード

| 項目       | 内容                                          |
| ---------- | --------------------------------------------- |
| シナリオID | TS-003                                        |
| シナリオ名 | アーティファクトがアップロードされる          |
| 前提条件   | ビルドが成功している                          |
| 実行手順   | 1. GitHub Actions の Summary ページを確認     |
|            | 2. Artifacts セクションを確認                 |
| 期待結果   | `electron-macos-arm64` アーティファクトが存在 |
| 優先度     | 高                                            |

### TS-004: ローカルビルド成功

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| シナリオID | TS-004                                       |
| シナリオ名 | ローカル環境でビルドが成功する               |
| 前提条件   | Node.js 22, pnpm がインストールされている    |
| 実行手順   | 1. `pnpm install`                            |
|            | 2. `pnpm --filter @repo/shared build`        |
|            | 3. `pnpm --filter @repo/desktop build`       |
|            | 4. `pnpm --filter @repo/desktop package:mac` |
| 期待結果   | 全コマンドがエラーなく完了                   |
| 優先度     | 中                                           |

## 異常系テストシナリオ

### TS-101: ビルド失敗時の挙動

| 項目       | 内容                                           |
| ---------- | ---------------------------------------------- |
| シナリオID | TS-101                                         |
| シナリオ名 | ビルド失敗時にエラーが適切に報告される         |
| 前提条件   | 意図的にビルドを失敗させる（シミュレーション） |
| 実行手順   | 1. 設定を一時的に破壊                          |
|            | 2. CIを実行                                    |
|            | 3. エラーメッセージを確認                      |
| 期待結果   | 明確なエラーメッセージが出力される             |
| 優先度     | 低                                             |

### TS-102: 成果物非生成時の挙動

| 項目       | 内容                                            |
| ---------- | ----------------------------------------------- |
| シナリオID | TS-102                                          |
| シナリオ名 | 成果物が生成されない場合の挙動                  |
| 前提条件   | ワークフローが `if-no-files-found: warn` を設定 |
| 実行手順   | 1. 成果物が生成されない状態でビルド             |
|            | 2. ワークフローの結果を確認                     |
| 期待結果   | 警告は出るがジョブは失敗しない                  |
| 優先度     | 低                                              |

## エッジケース

### TS-201: 既存設定との互換性

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| シナリオID | TS-201                                       |
| シナリオ名 | 他のelectron-builder設定への影響がない       |
| 前提条件   | 修正が `mac.target` のみに限定されている     |
| 実行手順   | 1. electron-builder.yml の他セクションを確認 |
|            | 2. ビルド後のアプリが正常に動作              |
| 期待結果   | アプリ署名、カスタムプロトコル等が正常       |
| 優先度     | 中                                           |

### TS-202: アーキテクチャ別ビルド

| 項目       | 内容                                  |
| ---------- | ------------------------------------- |
| シナリオID | TS-202                                |
| シナリオ名 | x64とarm64の両方がビルドされる        |
| 前提条件   | `arch: [x64, arm64]` が設定されている |
| 実行手順   | 1. ビルドを実行                       |
|            | 2. 生成されたZIPファイルを確認        |
| 期待結果   | 2つのZIPファイル（x64, arm64）が生成  |
| 優先度     | 中                                    |
