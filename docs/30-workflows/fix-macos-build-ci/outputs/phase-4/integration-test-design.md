# 統合テスト設計書

## 概要

CI/CDパイプライン全体の統合テストを定義する。

---

## 統合テストカテゴリ

### 1. CI接続テスト

**目的**: GitHub Actions ワークフローが正しく起動・実行されることを確認

| テストID | テスト名             | 検証内容                            |
| -------- | -------------------- | ----------------------------------- |
| IT-001   | ワークフロートリガー | push/PR時にワークフローが起動する   |
| IT-002   | ジョブ依存関係       | shared → desktop の順序で実行される |
| IT-003   | 環境変数設定         | CI環境変数が正しく設定される        |

### テスト手順

```bash
# 1. ワークフロートリガー確認
git push origin fix/macos-build-ci
gh run list --workflow=build-electron.yml --limit=1

# 2. ジョブ依存関係確認
gh run view <run-id> --json jobs
# → build-shared が build-macos-arm64 より先に完了

# 3. 環境変数確認
# ログで CSC_IDENTITY_AUTO_DISCOVERY: false を確認
```

---

### 2. ビルドフローテスト

**目的**: 依存関係インストールからパッケージングまでの一連のフローが成功することを確認

| テストID | テスト名             | 検証内容                     |
| -------- | -------------------- | ---------------------------- |
| IT-011   | 依存関係インストール | pnpm install が成功          |
| IT-012   | shared ビルド        | @repo/shared のビルドが成功  |
| IT-013   | desktop ビルド       | @repo/desktop のビルドが成功 |
| IT-014   | macOS パッケージング | package:mac が成功           |

### テスト手順

```bash
# CI ログで各ステップの成功を確認
gh run view <run-id> --log

# 確認項目:
# - "Install dependencies" ステップが成功
# - "Build shared package" ステップが成功
# - "Build desktop" ステップが成功
# - "Package desktop" ステップが成功
```

---

### 3. 成果物生成テスト

**目的**: ZIP ファイルが正しく生成されることを確認

| テストID | テスト名             | 検証内容                      |
| -------- | -------------------- | ----------------------------- |
| IT-021   | ZIP ファイル生成     | dist/ に ZIP が存在           |
| IT-022   | ファイル命名規則     | artifactName 形式に従っている |
| IT-023   | アーキテクチャ別生成 | x64 と arm64 両方が生成される |

### テスト手順

```bash
# CI 完了後、成果物を確認
gh run download <run-id> --name electron-macos-arm64

# ファイル確認
ls -la *.zip

# 期待されるファイル:
# - AI Workflow Orchestrator-1.0.0-arm64.zip
# - AI Workflow Orchestrator-1.0.0-x64.zip
```

---

### 4. アーティファクトアップロードテスト

**目的**: GitHub Actions のアーティファクトが正しくアップロードされることを確認

| テストID | テスト名             | 検証内容                              |
| -------- | -------------------- | ------------------------------------- |
| IT-031   | アーティファクト存在 | Summary に Artifacts セクションが存在 |
| IT-032   | ダウンロード可能     | アーティファクトがダウンロードできる  |
| IT-033   | ファイル整合性       | ダウンロードしたZIPが有効             |

### テスト手順

```bash
# アーティファクト確認
gh run view <run-id> --json artifacts

# ダウンロード
gh run download <run-id> --name electron-macos-arm64

# ZIP整合性確認
unzip -t *.zip
```

---

### 5. エラーハンドリングテスト

**目的**: エラー時に適切なハンドリングが行われることを確認

| テストID | テスト名           | 検証内容                            |
| -------- | ------------------ | ----------------------------------- |
| IT-041   | hdiutil エラー回避 | DMG 除外により hdiutil が呼ばれない |
| IT-042   | 成果物なし時の警告 | `if-no-files-found: warn` が機能    |
| IT-043   | ビルド失敗時のログ | 失敗原因が明確に出力される          |

### テスト手順

```bash
# ログで hdiutil を検索
gh run view <run-id> --log | grep -i hdiutil
# → 結果なし（hdiutil が呼ばれていない）

# アーティファクトアップロードステップの確認
# → 警告なしで完了
```
