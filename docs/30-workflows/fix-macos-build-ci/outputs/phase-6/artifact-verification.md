# 成果物検証結果

## 概要

CI で生成された成果物の検証結果を記録する。

---

## 検証対象

| 成果物             | パス          | 形式 |
| ------------------ | ------------- | ---- |
| macOS arm64 アプリ | `*.arm64.zip` | ZIP  |
| macOS x64 アプリ   | `*.x64.zip`   | ZIP  |

---

## 検証手順

### 1. アーティファクトのダウンロード

```bash
# GitHub CLI でダウンロード
gh run download <run-id> --name electron-macos-arm64

# または GitHub UI からダウンロード
# Actions > 該当の Run > Artifacts セクション
```

### 2. ファイル存在確認

```bash
ls -la *.zip
```

**期待される出力**:

```
-rw-r--r--  AI Workflow Orchestrator-1.0.0-arm64.zip
-rw-r--r--  AI Workflow Orchestrator-1.0.0-x64.zip
```

### 3. ファイルサイズ確認

```bash
# サイズ確認（100MB〜500MB程度を期待）
du -h *.zip
```

### 4. ZIP整合性確認

```bash
# ZIP ファイルの整合性を確認
unzip -t *.zip
```

### 5. 内容確認

```bash
# ZIP 内のファイル一覧を確認
unzip -l "AI Workflow Orchestrator-1.0.0-arm64.zip" | head -30
```

**期待される内容**:

- `.app` ディレクトリが存在
- `Contents/MacOS/` に実行ファイルが存在
- `Contents/Resources/` にリソースが存在

## DMG非生成の確認

### 確認事項

- [ ] DMG ファイルが生成されていない
- [ ] ビルドログに DMG 関連のエラーがない
- [ ] hdiutil コマンドが呼び出されていない

### 確認方法

```bash
# DMG ファイルの確認
ls -la *.dmg 2>/dev/null || echo "DMG ファイルなし（期待通り）"

# ログで hdiutil を検索
gh run view <run-id> --log | grep -i hdiutil
# 結果なしが期待される
```
