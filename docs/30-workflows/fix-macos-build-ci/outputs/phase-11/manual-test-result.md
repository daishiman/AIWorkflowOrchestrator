| 項目     | 内容                                   |

| 期待結果 | build-macos-arm64 ジョブが成功         |

| 期待結果 | ZIP ファイルがアーティファクトに存在 |
| 実行結果 | ⏳ PR 作成時に確認                   |

### シナリオ3: エラーログ確認

| 項目     | 内容                                     |

## 確認コマンド

```bash
# CI 実行状況確認
gh run list --workflow=build-electron.yml --limit=1

# 実行詳細確認
gh run view <run-id>

# アーティファクト確認
gh run view <run-id> --json artifacts

# ログダウンロード
gh run download <run-id> --name electron-macos-arm64
```
