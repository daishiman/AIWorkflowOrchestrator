# テスト戦略書

## 概要

macOS CI ビルド修正の検証方法とテスト戦略を定義する。

---

## テスト戦略概要

### テストレベル

| レベル   | 内容                             | 実行環境       |
| -------- | -------------------------------- | -------------- |
| ユニット | 設定ファイルの構文検証           | ローカル       |
| 統合     | ビルドパイプライン全体の動作確認 | ローカル + CI  |
| E2E      | CI環境での実際のビルド           | GitHub Actions |

### テストフェーズ

```
Phase 4: テストシナリオ作成（Red）
    ↓
Phase 5: 実装（Green）
    ↓
Phase 6: テスト拡充
    ↓
Phase 7: カバレッジ確認
    ↓
Phase 11: 手動テスト（CI環境確認）
```

---

## テストシナリオ

### 1. ローカルビルドテスト

**目的**: 修正後もローカルでビルドが成功することを確認

**テスト手順**:

```bash
# 1. 依存関係インストール
pnpm install

# 2. shared パッケージビルド
pnpm --filter @repo/shared build

# 3. desktop アプリビルド
pnpm --filter @repo/desktop build

# 4. macOS パッケージング
pnpm --filter @repo/desktop package:mac
```

**成功基準**:

- [ ] 全コマンドがエラーなく完了
- [ ] `apps/desktop/dist/` に ZIP ファイルが生成
- [ ] ZIP ファイルのサイズが妥当（10MB以上）

### 2. CI環境ビルドテスト

**目的**: GitHub Actions で macOS ビルドが成功することを確認

**テスト手順**:

1. 修正をブランチにプッシュ
2. GitHub Actions ワークフローが起動することを確認
3. `build-macos-arm64` ジョブの実行を監視
4. 成功を確認

**成功基準**:

- [ ] `build-macos-arm64` ジョブが成功（緑チェック）
- [ ] `hdiutil` エラーが発生しない
- [ ] アーティファクトがアップロードされる

### 3. 成果物検証テスト

**目的**: 生成された成果物が正しいことを確認

**テスト手順**:

1. GitHub Actions のアーティファクトをダウンロード
2. ZIP ファイルの内容を確認
3. アプリケーションの実行を確認（可能な場合）

**成功基準**:

- [ ] ZIP ファイルが存在
- [ ] ZIP 内に `.app` が含まれている
- [ ] ファイルサイズが妥当（100MB〜500MB程度）

## 成功/失敗の判定基準

### 成功条件

| 条件                                 | 必須 |
| ------------------------------------ | ---- |
| GitHub Actions ビルドが成功          | ✅   |
| ZIP ファイルが生成される             | ✅   |
| アーティファクトがアップロードされる | ✅   |
| エラーログがない                     | ✅   |
| ビルド時間が30分以内                 | 推奨 |

### 失敗条件

| 条件                             | 重大度   |
| -------------------------------- | -------- |
| `hdiutil` エラーが発生           | CRITICAL |
| ビルドが失敗                     | CRITICAL |
| 成果物が生成されない             | CRITICAL |
| アーティファクトアップロード失敗 | MAJOR    |

## ロールバック手順

### ロールバックが必要な場合

- 修正後もビルドが失敗する
- 予期しない副作用が発生する
- ローカルビルドに重大な影響がある

### ロールバック手順

1. **変更を元に戻す**

   ```yaml
   # electron-builder.yml
   mac:
     target:
       - target: dmg
         arch:
           - x64
           - arm64
       - target: zip
         arch:
           - x64
           - arm64
   ```

2. **CI を再実行**（ローカルビルドのみ確認）

3. **別の解決策を検討**
   - オプション3: ワークフローでターゲット指定
   - オプション5: リリースワークフロー分離
