## 2. 手動テスト項目

### テストケース 1: 検索パネルの開閉

| 項目         | 内容                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 目的         | Cmd+F/Ctrl+Fで検索パネルが開くことを確認                                                       |
| 前提条件     | Electronアプリが起動済み                                                                       |
| 手順         | 1. エディタでファイルを開く<br>2. Cmd+F (macOS) または Ctrl+F (Windows/Linux) を押す           |
| 期待結果     | SearchPanelが表示される                                                                        |
| 確認ポイント | - パネルがモーダルとして表示<br>- 検索入力にフォーカス<br>- 置換フィールドは非表示（初期状態） |

### テストケース 2: ファイル内検索

| 項目         | 内容                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| 目的         | 検索機能が正常動作することを確認                                                                     |
| 前提条件     | SearchPanelが開いている                                                                              |
| 手順         | 1. 検索入力に "hello" と入力<br>2. Enterキーを押す                                                   |
| 期待結果     | - マッチ箇所がハイライト表示<br>- "1/N" のように結果数が表示<br>- エディタが最初のマッチにスクロール |
| 確認ポイント | - ハイライトの視認性<br>- スクロール動作<br>- 結果カウンター表示                                     |

### テストケース 3: 検索オプション

| 項目         | 内容                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| 目的         | 検索オプションが機能することを確認                                                             |

## 8. 注意事項

### 実機テストが必要な理由

- ユニットテストでは統合状態を完全には検証できない
- Electronアプリ固有の動作確認が必要
- ユーザー体験（UX）の確認が必要

### テストで確認できなかった場合

実機でのテストが実行できない場合、以下のドキュメントベースの確認で代替：

1. コンポーネントの統合状態をコードレビュー
2. キーボードショートカットの登録状態を確認
3. IPC通信の実装状態を確認
4. ユニットテストの結果（94テスト合格）で品質を担保
