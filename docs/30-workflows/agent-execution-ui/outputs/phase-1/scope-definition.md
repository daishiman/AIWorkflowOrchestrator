# エージェント実行UI スコープ定義

## 概要

| 項目     | 内容               |
| -------- | ------------------ |
| タスクID | AGENT-004          |
| 機能名   | agent-execution-ui |
| 作成日   | 2026-01-12         |

---

## スコープ内（In Scope）

### 機能

| カテゴリ         | 機能                                             |
| ---------------- | ------------------------------------------------ |
| 画面遷移         | スキル詳細→実行画面への遷移                      |
| チャットUI       | メッセージ入力・送信・表示                       |
| ストリーミング   | リアルタイム出力表示                             |
| 実行制御         | キャンセル、クリア                               |
| 権限確認         | Permission Dialog（許可/拒否/記憶）              |
| エラー処理       | エラーメッセージ表示                             |
| アクセシビリティ | キーボードナビゲーション、スクリーンリーダー対応 |

### UIコンポーネント

| コンポーネント         | Atomic Design階層 | 責務                     |
| ---------------------- | ----------------- | ------------------------ |
| AgentExecutionView     | Template/Page     | 実行画面全体のレイアウト |
| AgentChatInterface     | Organism          | チャットインターフェース |
| AgentOutputStream      | Molecule          | ストリーミング出力表示   |
| AgentMessageInput      | Molecule          | メッセージ入力欄         |
| AgentExecutionControls | Molecule          | 実行制御ボタン群         |
| PermissionDialog       | Organism          | 権限確認ダイアログ       |

### 状態管理

| 状態                  | 説明                         |
| --------------------- | ---------------------------- |
| executionStatus       | 実行状態（idle/executing等） |
| messages              | チャット履歴                 |
| currentExecutionId    | 現在の実行ID                 |
| pendingPermission     | 保留中の権限確認             |
| rememberedPermissions | 記憶した権限選択             |

### IPC通信

| チャンネル           | 方向  | 責務           |
| -------------------- | ----- | -------------- |
| agent:start          | R → M | 実行開始       |
| agent:stop           | R → M | 実行停止       |
| agent:query          | R → M | クエリ送信     |
| agent:abort          | R → M | 中断           |
| agent:stream         | M → R | ストリーミング |
| agent:message        | M → R | メッセージ配信 |
| agent:permission     | M → R | 権限確認要求   |
| agent:permission:res | R → M | 権限確認応答   |

### テスト

| テスト種別       | 対象                               |
| ---------------- | ---------------------------------- |
| ユニット         | 各コンポーネント、フック、状態管理 |
| 統合             | IPC通信、コンポーネント間連携      |
| E2E              | 全フロー（送信→応答→完了）         |
| アクセシビリティ | キーボード操作、スクリーンリーダー |

## 境界条件

### 入力制約

| 項目         | 制約                 |
| ------------ | -------------------- |
| メッセージ長 | 最大100,000文字      |
| 同時実行     | 1セッション1実行のみ |
| タイムアウト | デフォルト30秒       |

### 出力制約

| 項目           | 制約                           |
| -------------- | ------------------------------ |
| メッセージ表示 | 自動スクロール                 |
| 履歴保持       | セッション中のみ（永続化なし） |
