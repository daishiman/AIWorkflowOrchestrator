## 目的

## 実行タスク

### タスク1: カバレッジ計測

**目的**: 現在のカバレッジを計測し、不足箇所を特定する

**手順**:

1. `cd apps/desktop && pnpm vitest run --coverage src/renderer/components/AuthGuard/` を実行
2. Line Coverage / Branch Coverage / Function Coverage を確認
3. 未カバー箇所をリストアップ

**カバレッジ基準**:

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

### タスク2: エッジケーステスト追加

**目的**: 境界値・異常系のテストを追加する

**追加テストケース候補**:

| #   | テスト名                                                   | カテゴリ         |
| --- | ---------------------------------------------------------- | ---------------- |
| 1   | タイムアウト直前（9999ms）ではまだ "checking"              | 境界値           |
| 2   | コンポーネントアンマウント時にタイマーがクリアされる       | リソースリーク   |
| 3   | isLoading が高速に true/false 切り替わる場合のタイマー挙動 | 競合状態         |
| 4   | リトライ後に再度タイムアウトした場合                       | 再帰シナリオ     |
| 5   | AuthTimeoutFallback の各ボタンのアクセシビリティ属性       | アクセシビリティ |
| 6   | AuthTimeoutFallback のダークモード表示                     | ビジュアル       |
| 7   | 開発モード時のタイムアウト挙動                             | 環境依存         |

### タスク3: 統合テスト追加

**目的**: コンポーネント間の連携をテストする

**追加テストケース候補**:

| #   | テスト名                                                           | テスト範囲         |
| --- | ------------------------------------------------------------------ | ------------------ |
| 1   | AuthGuard → タイムアウト → リトライ → 認証成功の全フロー           | E2E的統合テスト    |
| 2   | AuthGuard → タイムアウト → Settings遷移 → API設定 → 戻るの全フロー | ナビゲーション統合 |
| 3   | 既存の認証フロー（タイムアウトなし）が影響を受けないこと           | 回帰テスト         |
