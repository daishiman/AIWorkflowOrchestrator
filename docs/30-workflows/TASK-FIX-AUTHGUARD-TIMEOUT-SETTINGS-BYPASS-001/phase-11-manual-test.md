## 目的

## CLI環境での代替検証（P53対応）

CLI環境でスクリーンショット取得が困難な場合、以下で代替:

1. **Playwright スクリプト**:

   ```bash
   cd apps/desktop && npx playwright test --grep "timeout-fallback" --screenshot=on
   ```

2. **Electron capturePage**:

   ```typescript
   const image = await mainWindow.webContents.capturePage();
   fs.writeFileSync("timeout-fallback.png", image.toPNG());
   ```

3. **自動テスト結果**: Phase 4-7 のテスト結果を「間接的な視覚検証」として記録
