## 実行手順

### 1. カバレッジ測定

```bash
pnpm test:coverage -- --filter=@repo/desktop
```

### 2. ギャップ分析

**分析対象ファイル**:

| ファイル                                             | 分析観点                  |
| ---------------------------------------------------- | ------------------------- |
| `apps/desktop/src/renderer/utils/editorSelection.ts` | 全分岐、エラーパス        |
| `apps/desktop/src/main/ipc/chatEditHandlers.ts`      | 全分岐、validateIpcSender |
| `apps/desktop/src/preload/chatEditApi.ts`            | IPC呼び出し               |

### 3. 追加テスト作成

**追加すべきテストケース**:

| カテゴリ | テストケース                        |
| -------- | ----------------------------------- |
| 境界値   | 空ファイルでの選択                  |
| 境界値   | 非常に長い行での選択                |
| エラー系 | executeJavaScriptが例外を投げる場合 |
| エラー系 | BrowserWindowが存在しない場合       |
| 統合     | 実際のMonaco Editorとの連携         |

### 4. 統合テスト再実行

```bash
pnpm test:integration
```
