# TASK-SKILL-LIFECYCLE-05: 作成済みスキルを使う主導線

## 概要

作ったスキルをその場で使う導線と、後から一覧・履歴・Workspace/Agent から再利用する導線を定義するタスク。`作ったが使われない` 状態を防ぐ。

## メタ情報

| 項目       | 内容                                |
| ---------- | ----------------------------------- |
| タスクID   | TASK-SKILL-LIFECYCLE-05             |
| タスク種別 | 設計                                |
| 優先度     | 高                                  |
| ステータス | not_started                         |
| 依存タスク | TASK-SKILL-LIFECYCLE-01, 02, 03, 04 |

## 受入基準

| ID   | 基準                                         |
| ---- | -------------------------------------------- |
| AC-1 | 作成直後の `今すぐ使う` 導線が定義されている |
| AC-2 | 保存済みスキルの再利用導線が定義されている   |
| AC-3 | 実行結果から改善へ戻る導線が定義されている   |
| AC-4 | 利用中の品質表示と再評価が定義されている     |
