# Phase 2: 設計 - タスク仕様書

## 目的

作成済みスキルを日常利用へ接続する画面、遷移、再利用、再評価、改善戻りの設計を確定する。

## 実行タスク

1. `今すぐ使う` CTA と `あとで使う` 保存導線を設計する
2. 一覧/履歴/お気に入り/最近使ったスキルの再利用導線を設計する
3. 実行画面に品質表示と再評価を埋め込む
4. 実行結果から改善へ戻るショートカットを設計する
5. 利用導線での `Atent Team` / SubAgent の見せ方を最小化する

## 設計方針

- 作成直後の利用導線と、後日再利用導線は同じ実行面へ収束させる
- `Workspace` と `Agent` の二重主導線は許容せず、どちらか一方を主導線に固定する
- 品質表示は Task04 の評価モデルを使い回し、利用導線ごとに別採点ロジックを持たない

## 完了条件

- [ ] 作成直後と後日利用の両方が設計されている
- [ ] 実行結果から改善へ戻れる
- [ ] 品質表示が利用中に参照できる
