# Phase 2: 設計 - タスク仕様書

## 目的

ライフサイクル履歴モデル、フィードバック収集、再利用支援、推薦材料の設計を確定する。

## 実行タスク

1. イベントモデルと集約ビューを設計する
2. 最近使ったスキル、成功率、品質推移の表示モデルを設計する
3. 実行結果から改善へ戻るフィードバックモデルを設計する
4. Task08 が使う公開判断メトリクスを設計する
5. 自動収集と手動フィードバック入力の役割分担を設計する

## 完了条件
