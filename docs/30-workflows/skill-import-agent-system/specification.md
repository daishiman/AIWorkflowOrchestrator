# スキルインポート機能仕様書

## 1. 概要

### 1.1 目的

`.claude/skills/` 配下のスキルをスキャンし、**配下の全情報（agents/, references/, scripts/等）を取得**してシステムにインポートする機能を提供する。

### 1.2 背景

- 現在、`.claude/skills/` 配下に複数のスキルが存在（6種類）
- **既存のAgentView/AgentExecutionView**がスキル管理・実行UIとして存在
- 既存のインポート機能はスキルの基本情報のみ取得しており、配下の詳細情報が不足
- スキルディレクトリの全構造（サブエージェント、参照資料等）を取得する必要がある

### 1.3 既存システムとの関係

```
┌─────────────────────────────────────────────────────────────────┐
│                    既存システム（維持）                          │
├─────────────────────────────────────────────────────────────────┤
│  AgentView          - スキル一覧表示、選択、削除                │
│  AgentExecutionView - スキル実行、チャットUI、権限確認          │
│  agentSlice         - スキル状態管理                            │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 今回の改善対象
┌─────────────────────────────────────────────────────────────────┐
│                    スキルインポート機能（置換）                  │
├─────────────────────────────────────────────────────────────────┤
│  SkillScanner       - 配下の全情報を取得するスキャナー          │
│  SkillImportStore   - インポート設定の永続化                    │
│  ImportDialog       - 詳細情報を表示するインポートダイアログ    │
│  型定義             - 拡張されたSkillMetadata型                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.5 スコープ

**今回のスコープ（スキルインポート機能の置換）**:

- SkillScanner: 配下の全情報を取得（agents/, references/, scripts/, assets/, schemas/, indexes/）
- SkillImportStore: electron-storeによる永続化（schemaVersion対応）
- 型定義: 拡張されたSkillMetadata、SkillSubResource型
- ImportDialog: 詳細情報を表示するインポートダイアログUI
- IPC: スキャン・インポート用チャネル

**スコープ外（既存を維持）**:

- AgentView: スキル一覧・選択UI
- AgentExecutionView: 実行UI、チャットインターフェース
- agentSlice: 状態管理（必要に応じて型のみ拡張）

## 2. 使い方ガイド

### 2.1 基本的な使用フロー（既存AgentViewを使用）

```
┌─────────────────────────────────────────────────────────────────┐
│ 1. スキルのインポート（AgentView）                              │
│    ① サイドバーから「Agent」を選択してAgentViewを開く          │
│    ② ヘッダーの「インポート」ボタンをクリック                  │
│    ③ インポートダイアログで詳細情報を確認                      │
│       - サブエージェント一覧（agents/）                         │
│       - 参照資料一覧（references/）                             │
│       - 許可ツール                                              │
│    ④ 「インポート」ボタンで確定                                │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 2. スキルの選択・実行（既存機能）                               │
│    ① スキル一覧からインポート済みスキルをクリック              │
│    ② 詳細パネルで「実行」ボタンをクリック                      │
│    ③ AgentExecutionViewでプロンプトを入力して実行              │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 インポートダイアログの改善点

**従来のインポート：**

- スキル名と説明のみ表示

**新しいインポート（本仕様）：**

- スキル配下の全情報を表示
  - agents/: サブエージェント一覧
  - references/: 参照資料一覧
  - scripts/: スクリプト一覧
  - assets/: アセット一覧
  - 許可ツール（allowed-tools）
  - その他ファイル（EVALS.json, LOGS.md等）

### 2.3 スキルの管理

```
スキル管理機能（AgentView内）:
├─ 再スキャン - ファイルシステムを再スキャンして新しいスキルを検出
├─ スキル削除 - インポート済みスキルを削除（設定も削除）
└─ スキル設定 - 権限自動許可などの個別設定（将来実装）
```

#### 4.7.4 ストリーミング状態管理（useSkillExecution フック）

```typescript
// Renderer側でのストリーミングメッセージ処理フロー
interface ToolExecutionState {
  /** ツール使用ID */
  toolUseId: string;

  /** ツール名 */
  toolName: string;

  /** 引数 */
  args: Record<string, unknown>;

  /** 状態 */
  status:
    | "pending"
    | "executing"
    | "completed"
    | "failed"
    | "blocked"
    | "permission_pending";

  /** 開始時刻 */
  startedAt: number;

  /** 完了時刻 */
  completedAt?: number;

  /** 結果 */
  result?: unknown;

  /** エラー */
  error?: string;
}

// useSkillExecution フックの状態管理
function useSkillExecution() {
  const [toolExecutions, setToolExecutions] = useState<ToolExecutionState[]>(
    [],
  );

  // ストリーミングメッセージを処理
  const handleStreamMessage = useCallback((msg: SkillStreamMessage) => {
    switch (msg.type) {
      case "tool_use":
        // 新しいツール実行を追加
        setToolExecutions((prev) => [
          ...prev,
          {
            toolUseId: msg.content.toolUseId,
            toolName: msg.content.toolName,
            args: msg.content.args,
            status: "executing",
            startedAt: msg.timestamp,
          },
        ]);
        break;

      case "tool_result":
        // ツール実行結果を更新
        setToolExecutions((prev) =>
          prev.map((t) =>
            t.toolUseId === msg.content.toolUseId
              ? {
                  ...t,
                  status: msg.content.success ? "completed" : "failed",
                  completedAt: msg.timestamp,
                  result: msg.content.result,
                  error: msg.content.error,
                }
              : t,
          ),
        );
        break;

      case "status":
        if (msg.content.status === "tool_completed") {
          // PostToolUse通知を処理
        }
        break;
    }
  }, []);

  return { toolExecutions, handleStreamMessage };
}
```

```typescript
/**
 * Hooks生成関数
 * 参照: apps/desktop/src/main/services/agent/HooksFactory.ts
 */
function createHooks(
  mainWindow: BrowserWindow,
  executionId: string,
  permissionResolver: PermissionResolver,
): SDKHooks {
  return {
    // 危険コマンド・保護パスのブロック
    PreToolUse: async (input, _toolUseId, _context) => {
      // Bashツールの危険コマンドチェック
      if (input.toolName === "Bash") {
        const command = (input.args.command as string) || "";

        for (const pattern of DANGEROUS_PATTERNS.BASH_COMMANDS) {
          if (command.includes(pattern)) {
            return {
              proceed: false,
              message: `危険なコマンドをブロック: ${pattern}`,
            };
          }
        }
      }

      // Write/Editツールの保護パスチェック
      if (input.toolName === "Write" || input.toolName === "Edit") {
        const filePath = (input.args.path as string) || "";

        for (const pattern of DANGEROUS_PATTERNS.PROTECTED_PATHS) {
          if (matchPath(filePath, pattern)) {
            return {
              proceed: false,
              message: `保護されたパスへの書き込みをブロック: ${pattern}`,
            };
          }
        }
      }

      return { proceed: true };
    },

    // ツール完了通知
    PostToolUse: async (input, _toolUseId, _context) => {
      mainWindow.webContents.send("agent:status", {
        executionId,
        type: "tool_completed",
        tool: input.toolName,
        timestamp: Date.now(),
      });
      return {};
    },

    // 権限確認（UIダイアログ連携）
    PermissionRequest: async (input, _toolUseId, context) => {
      const requestId = uuidv4();

      // RendererにPermissionリクエストを送信
      mainWindow.webContents.send("agent:permission", {
        executionId,
        requestId,
        toolName: input.toolName,
        args: input.args,
      });

      // 応答を待機
      const response = await permissionResolver.waitForResponse(
        requestId,
        context.signal,
      );

      return {
        proceed: response.approved,
        message: response.rejectReason,
      };
    },
  };
}
```

```typescript
// apps/desktop/src/main/services/skill/SkillScanner.ts

import * as fs from "fs/promises";
import * as path from "path";
import * as yaml from "yaml";

/**
 * スキルスキャナー
 * ~/.claude/skills/ 配下のスキルを検出し、全情報を取得
 */
export class SkillScanner {
  private skillsDir: string;

  constructor(skillsDir?: string) {
    this.skillsDir =
      skillsDir || path.join(process.env.HOME!, ".claude", "skills");
  }

  /**
   * 全スキルをスキャンして全情報を取得
   */
  async scanAll(): Promise<SkillMetadata[]> {
    const skills: SkillMetadata[] = [];

    try {
      const entries = await fs.readdir(this.skillsDir, { withFileTypes: true });

      for (const entry of entries) {
        if (!entry.isDirectory()) continue;

        const skillPath = path.join(this.skillsDir, entry.name);
        const skillMdPath = path.join(skillPath, "SKILL.md");

        try {
          const skill = await this.parseSkill(skillPath, skillMdPath);
          if (skill) skills.push(skill);
        } catch (e) {
          // 無効なスキルはスキップ
          console.warn(`スキル読み込みスキップ: ${entry.name}`, e);
        }
      }
    } catch (e) {
      console.error("スキルディレクトリ読み込みエラー:", e);
    }

    return skills;
  }

  /**
   * 単一スキルをパース（配下の全情報を取得）
   */
  private async parseSkill(
    skillPath: string,
    skillMdPath: string,
  ): Promise<SkillMetadata | null> {
    const content = await fs.readFile(skillMdPath, "utf-8");
    const { frontmatter, body } = this.parseFrontmatter(content);

    if (!frontmatter.name) return null;

    const stat = await fs.stat(skillMdPath);

    // 配下のサブディレクトリを全てスキャン
    const [agents, references, scripts, assets, schemas, indexes, otherFiles] =
      await Promise.all([
        this.scanSubDirectory(skillPath, "agents"),
        this.scanSubDirectory(skillPath, "references"),
        this.scanSubDirectory(skillPath, "scripts"),
        this.scanSubDirectory(skillPath, "assets"),
        this.scanSubDirectory(skillPath, "schemas"),
        this.scanSubDirectory(skillPath, "indexes"),
        this.scanOtherFiles(skillPath),
      ]);

    return {
      name: frontmatter.name,
      description: frontmatter.description || body.slice(0, 200),
      allowedTools: frontmatter["allowed-tools"] || [],
      path: skillPath,
      updatedAt: stat.mtime,
      agents,
      references,
      scripts,
      assets,
      schemas,
      indexes,
      otherFiles,
    };
  }

  /**
   * サブディレクトリ内のファイルをスキャン
   */
  private async scanSubDirectory(
    skillPath: string,
    subDir: string,
  ): Promise<SkillSubResource[]> {
    const dirPath = path.join(skillPath, subDir);
    const resources: SkillSubResource[] = [];

    try {
      const entries = await fs.readdir(dirPath, { withFileTypes: true });

      for (const entry of entries) {
        if (!entry.isFile()) continue;

        const filePath = path.join(dirPath, entry.name);
        const stat = await fs.stat(filePath);

        // Markdownファイルの場合は先頭から説明を抽出
        let description: string | undefined;
        if (entry.name.endsWith(".md")) {
          description = await this.extractDescription(filePath);
        }

        resources.push({
          filename: entry.name,
          relativePath: path.join(subDir, entry.name),
          description,
          size: stat.size,
        });
      }
    } catch {
      // ディレクトリが存在しない場合は空配列
    }

    return resources;
  }

  /**
   * スキルディレクトリ直下のその他のファイルをスキャン
   */
  private async scanOtherFiles(skillPath: string): Promise<SkillOtherFile[]> {
    const files: SkillOtherFile[] = [];

    try {
      const entries = await fs.readdir(skillPath, { withFileTypes: true });

      for (const entry of entries) {
        if (entry.isFile() && entry.name !== "SKILL.md") {
          const filePath = path.join(skillPath, entry.name);
          const stat = await fs.stat(filePath);

          // ファイルタイプを判定
          let type: SkillOtherFile["type"] = "other";
          if (entry.name === "EVALS.json") type = "evals";
          else if (entry.name === "LOGS.md") type = "logs";
          else if (entry.name === "package.json") type = "package";

          files.push({
            filename: entry.name,
            type,
            size: stat.size,
          });
        }
      }
    } catch {
      // エラー時は空配列
    }

    return files;
  }

  /**
   * Markdownファイルから説明を抽出
   */
  private async extractDescription(filePath: string): Promise<string> {
    try {
      const content = await fs.readFile(filePath, "utf-8");
      // 最初の見出しまたは最初の段落を抽出
      const match = content.match(/^#\s+(.+)$/m);
      if (match) return match[1];

      const lines = content.split("\n").filter((l) => l.trim());
      return lines[0]?.slice(0, 100) || "";
    } catch {
      return "";
    }
  }

  /**
   * YAML Frontmatterをパース
   */
  private parseFrontmatter(content: string): {
    frontmatter: Record<string, unknown>;
    body: string;
  } {
    const match = content.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/);
    if (!match) {
      return { frontmatter: {}, body: content };
    }

    try {
      return {
        frontmatter: yaml.parse(match[1]),
        body: match[2],
      };
    } catch {
      return { frontmatter: {}, body: content };
    }
  }
}
```

### 5.7 SkillExecutor実装仕様

```typescript
// apps/desktop/src/main/services/skill/SkillExecutor.ts

import { query } from "@anthropic-ai/claude-agent-sdk";
import { BrowserWindow } from "electron";
import { v4 as uuidv4 } from "uuid";
import { SKILL_CHANNELS } from "../../../preload/channels";
import {
  SkillExecutionRequest,
  SkillExecutionResponse,
  SkillMetadata,
  SkillStreamMessage,
  DANGEROUS_PATTERNS,
} from "@repo/shared";
import { PermissionResolver } from "../agent/HooksFactory";

/**
 * スキル実行エンジン
 * Claude Agent SDK経由でスキルを実行し、結果をストリーミング
 */
export class SkillExecutor {
  private mainWindow: BrowserWindow;
  private permissionResolver: PermissionResolver;
  private activeExecutions: Map<string, AbortController> = new Map();

  constructor(mainWindow: BrowserWindow) {
    this.mainWindow = mainWindow;
    this.permissionResolver = new PermissionResolver();
  }

  /**
   * スキルを実行
   * @returns 実行ID（executionId）
   */
  async execute(
    request: SkillExecutionRequest,
    skill: SkillMetadata,
  ): Promise<SkillExecutionResponse> {
    const executionId = uuidv4();
    const abortController = new AbortController();

    this.activeExecutions.set(executionId, abortController);

    try {
      // 実行開始を通知
      this.sendStream({
        executionId,
        type: "status",
        content: { status: "started", detail: skill.name },
        timestamp: Date.now(),
      });

      // スキルプロンプトを構築
      const prompt = await this.buildPrompt(request.prompt, skill);

      // Hooksを作成
      const hooks = this.createHooks(executionId);

      // Claude Agent SDKを実行
      const conversation = query({
        prompt,
        options: {
          tools: skill.allowedTools || ["Read", "Edit", "Bash", "Glob", "Grep"],
          hooks,
          permissionMode: "default",
          ...(request.workingDirectory && { cwd: request.workingDirectory }),
        },
      });

      // ストリーミング処理
      for await (const message of conversation.stream()) {
        if (abortController.signal.aborted) {
          break;
        }

        await this.handleStreamMessage(executionId, message);
      }

      // 完了通知
      this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_COMPLETE, {
        executionId,
      });

      return { executionId, success: true };
    } catch (error) {
      const errorMessage =
        error instanceof Error ? error.message : "Unknown error";

      // エラー通知
      this.sendStream({
        executionId,
        type: "error",
        content: {
          code: this.categorizeError(error),
          message: errorMessage,
          retryable: this.isRetryable(error),
        },
        timestamp: Date.now(),
      });

      this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_ERROR, {
        executionId,
        error: errorMessage,
      });

      return { executionId, success: false, error: errorMessage };
    } finally {
      this.activeExecutions.delete(executionId);
    }
  }

  /**
   * 実行を中止
   */
  abort(executionId: string): void {
    const controller = this.activeExecutions.get(executionId);
    if (controller) {
      controller.abort();
      this.activeExecutions.delete(executionId);
    }
  }

  /**
   * 権限応答を処理
   */
  handlePermissionResponse(response: PermissionResponse): void {
    this.permissionResolver.resolveRequest(response);
  }

  /**
   * スキルプロンプトを構築
   */
  private async buildPrompt(
    userPrompt: string,
    skill: SkillMetadata,
  ): Promise<string> {
    // SKILL.mdの内容を読み込み
    const skillContent = skill.content || "";

    // サブエージェント、参照資料の情報を付加
    const contextInfo = this.buildContextInfo(skill);

    return `${skillContent}

## コンテキスト情報
${contextInfo}

## ユーザーリクエスト
${userPrompt}`;
  }

  /**
   * コンテキスト情報を構築
   */
  private buildContextInfo(skill: SkillMetadata): string {
    const parts: string[] = [];

    if (skill.agents.length > 0) {
      parts.push(
        `### 利用可能なサブエージェント (agents/):\n${skill.agents.map((a) => `- ${a.filename}: ${a.description || ""}`).join("\n")}`,
      );
    }

    if (skill.references.length > 0) {
      parts.push(
        `### 参照資料 (references/):\n${skill.references.map((r) => `- ${r.filename}: ${r.description || ""}`).join("\n")}`,
      );
    }

    if (skill.scripts.length > 0) {
      parts.push(
        `### スクリプト (scripts/):\n${skill.scripts.map((s) => `- ${s.filename}`).join("\n")}`,
      );
    }

    return parts.join("\n\n");
  }

  /**
   * Hooksを作成
   */
  private createHooks(executionId: string): SDKHooks {
    return {
      PreToolUse: async (input, _toolUseId, _context) => {
        // 危険コマンドチェック
        if (input.toolName === "Bash") {
          const command = (input.args.command as string) || "";
          for (const pattern of DANGEROUS_PATTERNS.BASH_COMMANDS) {
            if (command.includes(pattern)) {
              return {
                proceed: false,
                message: `危険なコマンドをブロック: ${pattern}`,
              };
            }
          }
        }

        // 保護パスチェック
        if (input.toolName === "Write" || input.toolName === "Edit") {
          const filePath = (input.args.path as string) || "";
          if (this.isProtectedPath(filePath)) {
            return {
              proceed: false,
              message: `保護されたパスへの書き込みをブロック: ${filePath}`,
            };
          }
        }

        return { proceed: true };
      },

      PostToolUse: async (input, _toolUseId, _context) => {
        this.sendStream({
          executionId,
          type: "status",
          content: { status: "tool_completed", detail: input.toolName },
          timestamp: Date.now(),
        });
        return {};
      },

      PermissionRequest: async (input, _toolUseId, context) => {
        const requestId = uuidv4();

        this.mainWindow.webContents.send(
          SKILL_CHANNELS.SKILL_PERMISSION_REQUEST,
          {
            executionId,
            requestId,
            toolName: input.toolName,
            args: input.args,
          },
        );

        const response = await this.permissionResolver.waitForResponse(
          requestId,
          context.signal,
        );

        return {
          proceed: response.approved,
          message: response.rejectReason,
        };
      },
    };
  }

  /**
   * ストリームメッセージを処理
   */
  private async handleStreamMessage(
    executionId: string,
    message: SDKMessage,
  ): Promise<void> {
    switch (message.type) {
      case "assistant":
        this.sendStream({
          executionId,
          type: "assistant",
          content: {
            text: message.message.content || "",
            isPartial: false,
          },
          timestamp: Date.now(),
        });
        break;

      case "result":
        this.sendStream({
          executionId,
          type: "tool_result",
          content: {
            toolUseId: message.message.tool_use_id || "",
            success: !message.message.is_error,
            result: message.message.content,
            error: message.message.is_error
              ? String(message.message.content)
              : undefined,
          },
          timestamp: Date.now(),
        });
        break;

      case "stream_event":
        // 部分メッセージはアシスタントメッセージとして送信
        if (message.event?.partial) {
          this.sendStream({
            executionId,
            type: "assistant",
            content: {
              text: message.event.partial,
              isPartial: true,
            },
            timestamp: Date.now(),
          });
        }
        break;
    }
  }

  /**
   * ストリームメッセージを送信
   */
  private sendStream(message: SkillStreamMessage): void {
    this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_STREAM, message);
  }

  /**
   * 保護パスかどうかを判定
   */
  private isProtectedPath(filePath: string): boolean {
    for (const pattern of DANGEROUS_PATTERNS.PROTECTED_PATHS) {
      if (this.matchGlob(filePath, pattern)) {
        return true;
      }
    }
    return false;
  }

  /**
   * Globパターンマッチ（簡易版）
   */
  private matchGlob(path: string, pattern: string): boolean {
    // **を.*?に、*を[^/]*に変換
    const regex = new RegExp(
      "^" +
        pattern
          .replace(/\*\*/g, ".*")
          .replace(/\*/g, "[^/]*")
          .replace(/~/g, process.env.HOME || "") +
        "$",
    );
    return regex.test(path);
  }

  /**
   * エラーカテゴリを判定
   */
  private categorizeError(
    error: unknown,
  ): "sdk_error" | "permission_denied" | "timeout" | "network" | "unknown" {
    if (error instanceof Error) {
      if (error.message.includes("abort")) return "timeout";
      if (error.message.includes("permission")) return "permission_denied";
      if (
        error.message.includes("network") ||
        error.message.includes("ECONNREFUSED")
      )
        return "network";
      if (error.message.includes("SDK")) return "sdk_error";
    }
    return "unknown";
  }

  /**
   * リトライ可能かどうかを判定
   */
  private isRetryable(error: unknown): boolean {
    const category = this.categorizeError(error);
    return category === "network" || category === "timeout";
  }
}
```

### 5.8 skillHandlers（IPCハンドラ）実装仕様

```typescript
// apps/desktop/src/main/ipc/skillHandlers.ts

import { ipcMain, BrowserWindow } from "electron";
import { SKILL_CHANNELS } from "../../preload/channels";
import { SkillScanner } from "../services/skill/SkillScanner";
import { SkillExecutor } from "../services/skill/SkillExecutor";
import { skillImportStore } from "../settings/skillImportStore";
import type { SkillExecutionRequest, PermissionResponse } from "@repo/shared";

let skillScanner: SkillScanner | null = null;
let skillExecutor: SkillExecutor | null = null;
let cachedSkills: SkillMetadata[] | null = null;

export function registerSkillHandlers(mainWindow: BrowserWindow): void {
  skillScanner = new SkillScanner();
  skillExecutor = new SkillExecutor(mainWindow);

  // スキル一覧取得（キャッシュあり）
  ipcMain.handle(SKILL_CHANNELS.SKILL_LIST, async () => {
    if (!cachedSkills) {
      cachedSkills = await skillScanner!.scanAll();
    }
    return cachedSkills;
  });

  // スキル再スキャン（キャッシュ無効化）
  ipcMain.handle(SKILL_CHANNELS.SKILL_SCAN, async () => {
    cachedSkills = await skillScanner!.scanAll();
    return cachedSkills;
  });

  // スキルインポート
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_IMPORT,
    async (_event, skillName: string) => {
      skillImportStore.addImport(skillName);

      const skill = cachedSkills?.find((s) => s.name === skillName);
      if (!skill) {
        throw new Error(`スキルが見つかりません: ${skillName}`);
      }

      return {
        ...skill,
        importedAt: new Date(),
        status: "active" as const,
      };
    },
  );

  // インポート済みスキル取得
  ipcMain.handle(SKILL_CHANNELS.SKILL_GET_IMPORTED, async () => {
    const imported = skillImportStore.getImported();
    const skills: ImportedSkill[] = [];

    for (const data of imported) {
      const skill = cachedSkills?.find((s) => s.name === data.name);
      if (skill) {
        skills.push({
          ...skill,
          importedAt: new Date(data.importedAt),
          status: data.status,
        });
      }
    }

    return skills;
  });

  // スキル削除
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_REMOVE,
    async (_event, skillName: string) => {
      skillImportStore.removeImport(skillName);
    },
  );

  // スキル実行
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_EXECUTE,
    async (_event, request: SkillExecutionRequest) => {
      const skill = cachedSkills?.find((s) => s.name === request.skillName);
      if (!skill) {
        throw new Error(`スキルが見つかりません: ${request.skillName}`);
      }

      // SKILL.mdの内容を読み込み
      const fs = await import("fs/promises");
      const path = await import("path");
      const skillMdPath = path.join(skill.path, "SKILL.md");
      const content = await fs.readFile(skillMdPath, "utf-8");

      const enrichedSkill = { ...skill, content };

      return skillExecutor!.execute(request, enrichedSkill);
    },
  );

  // 実行中止
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_ABORT,
    async (_event, executionId: string) => {
      skillExecutor!.abort(executionId);
    },
  );

  // 権限応答受信
  ipcMain.on(
    SKILL_CHANNELS.SKILL_PERMISSION_RESPONSE,
    (_event, response: PermissionResponse) => {
      skillExecutor!.handlePermissionResponse(response);
    },
  );
}
```

```typescript
import Store from "electron-store";

interface SkillStoreSchema {
  /** スキーマバージョン（マイグレーション用） */
  schemaVersion: number;

  /** インポート済みスキル（キー: スキル名） */
  importedSkills: Record<string, ImportedSkillData>;

  /** スキル個別設定（キー: スキル名） */
  skillSettings: Record<string, SkillSettings>;

  /** 最終スキャン日時（キャッシュ用） */
  lastScanAt?: string;

  /** スキルメタデータキャッシュ（キー: スキル名） */
  skillCache?: Record<string, { metadata: SkillMetadata; cachedAt: string }>;
}

interface ImportedSkillData {
  /** スキル名 */
  name: string;

  /** インポート日時（ISO文字列） */
  importedAt: string;

  /** ステータス */
  status: "active" | "disabled";

  /** 最終使用日時（ISO文字列） */
  lastUsedAt?: string;
}

interface SkillSettings {
  /** 読み取り専用ツールを自動許可 */
  autoApproveReadOnly: boolean;

  /** 権限設定を記憶 */
  rememberPermissions: boolean;

  /** 記憶された権限設定 */
  rememberedPermissions: Record<string, "allow" | "deny">;
}

const CURRENT_SCHEMA_VERSION = 1;

const store = new Store<SkillStoreSchema>({
  name: "skill-imports",
  defaults: {
    schemaVersion: CURRENT_SCHEMA_VERSION,
    importedSkills: {},
    skillSettings: {},
  },
  // マイグレーションサポート
  migrations: {
    "1": (store) => {
      // 初期バージョン - 変更なし
      store.set("schemaVersion", 1);
    },
    // 将来のマイグレーション例:
    // '2': (store) => {
    //   // v2へのマイグレーション処理
    //   store.set('schemaVersion', 2);
    // },
  },
});

export const skillImportStore = {
  /** インポート済みスキル一覧を取得 */
  getImported(): ImportedSkillData[] {
    return Object.values(store.get("importedSkills"));
  },

  /** スキルをインポート */
  addImport(skillName: string): void {
    store.set(`importedSkills.${skillName}`, {
      name: skillName,
      importedAt: new Date().toISOString(),
      status: "active",
    });
  },

  /** スキルを削除 */
  removeImport(skillName: string): void {
    const imports = store.get("importedSkills");
    delete imports[skillName];
    store.set("importedSkills", imports);

    // 設定も削除
    const settings = store.get("skillSettings");
    delete settings[skillName];
    store.set("skillSettings", settings);
  },

  /** スキル設定を取得 */
  getSettings(skillName: string): SkillSettings {
    return (
      store.get(`skillSettings.${skillName}`) || {
        autoApproveReadOnly: true,
        rememberPermissions: false,
        rememberedPermissions: {},
      }
    );
  },

  /** スキル設定を更新 */
  updateSettings(skillName: string, settings: Partial<SkillSettings>): void {
    const current = this.getSettings(skillName);
    store.set(`skillSettings.${skillName}`, { ...current, ...settings });
  },

  /** 権限を記憶 */
  rememberPermission(
    skillName: string,
    toolName: string,
    decision: "allow" | "deny",
  ): void {
    const settings = this.getSettings(skillName);
    settings.rememberedPermissions[toolName] = decision;
    this.updateSettings(skillName, settings);
  },
};
```

### 7.2 権限確認

- `permissionMode: 'default'` でSDKデフォルトの権限制御を使用
- 読み取り専用ツール（Read, Glob, Grep, LS）は自動許可
- 書き込み系ツール（Write, Edit, Bash）は権限確認ダイアログ表示
- ユーザーが明示的に許可しない限り実行しない

### 7.3 スキルコンテンツ検証

- SKILL.md のYAML frontmatterをパース時に検証
- 不正なスキル定義はインポート拒否
- `allowed-tools`のホワイトリスト検証
