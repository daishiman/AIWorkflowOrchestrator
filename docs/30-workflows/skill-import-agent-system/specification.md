# スキルインポート機能仕様書

## 1. 概要

### 1.1 目的

`.claude/skills/` 配下のスキルをスキャンし、**配下の全情報（agents/, references/, scripts/等）を取得**してシステムにインポートする機能を提供する。

### 1.2 背景

- 現在、`.claude/skills/` 配下に複数のスキルが存在（6種類）
- **既存のAgentView/AgentExecutionView**がスキル管理・実行UIとして存在
- 既存のインポート機能はスキルの基本情報のみ取得しており、配下の詳細情報が不足
- スキルディレクトリの全構造（サブエージェント、参照資料等）を取得する必要がある

### 1.3 既存システムとの関係

```

│                    既存システム（維持）                          │
├─────────────────────────────────────────────────────────────────┤

│  AgentExecutionView - スキル実行、チャットUI、権限確認          │
│  agentSlice         - スキル状態管理                            │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ 今回の改善対象
┌─────────────────────────────────────────────────────────────────┐
│                    スキルインポート機能（置換）                  │
├─────────────────────────────────────────────────────────────────┤
│  SkillScanner       - 配下の全情報を取得するスキャナー          │
│  SkillImportStore   - インポート設定の永続化                    │

└─────────────────────────────────────────────────────────────────┘
```

### 1.5 スコープ

**今回のスコープ（スキルインポート機能の置換）**:

- SkillScanner: 配下の全情報を取得（agents/, references/, scripts/, assets/, schemas/, indexes/）
- SkillImportStore: electron-storeによる永続化（schemaVersion対応）
- 型定義: 拡張されたSkillMetadata、SkillSubResource型
- ImportDialog: 詳細情報を表示するインポートダイアログUI
- IPC: スキャン・インポート用チャネル

**スコープ外（既存を維持）**:

- AgentView: スキル一覧・選択UI
- AgentExecutionView: 実行UI、チャットインターフェース
- agentSlice: 状態管理（必要に応じて型のみ拡張）

## 2. 使い方ガイド

### 2.1 基本的な使用フロー（既存AgentViewを使用）

```
┌─────────────────────────────────────────────────────────────────┐
│ 1. スキルのインポート（AgentView）                              │
│    ① サイドバーから「Agent」を選択してAgentViewを開く          │
│    ② ヘッダーの「インポート」ボタンをクリック                  │
│    ③ インポートダイアログで詳細情報を確認                      │
│       - サブエージェント一覧（agents/）                         │
│       - 参照資料一覧（references/）                             │
│       - 許可ツール                                              │
│    ④ 「インポート」ボタンで確定                                │
└─────────────────────────────────────────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│ 2. スキルの選択・実行（既存機能）                               │
│    ① スキル一覧からインポート済みスキルをクリック              │
│    ② 詳細パネルで「実行」ボタンをクリック                      │
│    ③ AgentExecutionViewでプロンプトを入力して実行              │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 インポートダイアログの改善点

**従来のインポート：**

- スキル名と説明のみ表示

**新しいインポート（本仕様）：**

- スキル配下の全情報を表示
  - agents/: サブエージェント一覧
  - references/: 参照資料一覧
  - scripts/: スクリプト一覧
  - assets/: アセット一覧
  - 許可ツール（allowed-tools）
  - その他ファイル（EVALS.json, LOGS.md等）

### 2.3 スキルの管理

```
スキル管理機能（AgentView内）:
├─ 再スキャン - ファイルシステムを再スキャンして新しいスキルを検出
├─ スキル削除 - インポート済みスキルを削除（設定も削除）
└─ スキル設定 - 権限自動許可などの個別設定（将来実装）
```

**改善ポイント（Apple HIG準拠）:**

1. **専門用語の排除**: 「サブエージェント」「参照資料」は詳細画面でのみ表示
2. **区分けの廃止**: 「インポート済み/利用可能」の区別をなくし、使えるものだけ表示

#### 4.6.4 フォーカス管理

```typescript
// フォーカストラップ（ダイアログ内）
const FocusTrap = ({ children }: { children: React.ReactNode }) => {
  const trapRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const trap = trapRef.current;
    if (!trap) return;

    const focusableElements = trap.querySelectorAll(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );

    const firstElement = focusableElements[0] as HTMLElement;
    const lastElement = focusableElements[focusableElements.length - 1] as HTMLElement;

    // 最初の要素にフォーカス
    firstElement?.focus();

    // Tab循環
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Tab') {
        if (e.shiftKey && document.activeElement === firstElement) {
          e.preventDefault();
          lastElement?.focus();
        } else if (!e.shiftKey && document.activeElement === lastElement) {
          e.preventDefault();
          firstElement?.focus();
        }
      }
    };

    trap.addEventListener('keydown', handleKeyDown);
    return () => trap.removeEventListener('keydown', handleKeyDown);
  }, []);

  return <div ref={trapRef}>{children}</div>;
};
```

```typescript
// Renderer側でのストリーミングメッセージ処理フロー
interface ToolExecutionState {
  /** ツール使用ID */
  toolUseId: string;

  /** ツール名 */
  toolName: string;

  /** 引数 */
  args: Record<string, unknown>;

  /** 状態 */
  status:
    | "pending"
    | "executing"
    | "completed"
    | "failed"
    | "blocked"
    | "permission_pending";

  /** 開始時刻 */
  startedAt: number;

  /** 完了時刻 */
  completedAt?: number;

  /** 結果 */
  result?: unknown;

  /** エラー */
  error?: string;
}

// useSkillExecution フックの状態管理
function useSkillExecution() {
  const [toolExecutions, setToolExecutions] = useState<ToolExecutionState[]>(
    [],
  );

  // ストリーミングメッセージを処理
  const handleStreamMessage = useCallback((msg: SkillStreamMessage) => {
    switch (msg.type) {
      case "tool_use":
        // 新しいツール実行を追加
        setToolExecutions((prev) => [
          ...prev,
          {
            toolUseId: msg.content.toolUseId,
            toolName: msg.content.toolName,
            args: msg.content.args,
            status: "executing",
            startedAt: msg.timestamp,
          },
        ]);
        break;

      case "tool_result":
        // ツール実行結果を更新
        setToolExecutions((prev) =>
          prev.map((t) =>
            t.toolUseId === msg.content.toolUseId
              ? {
                  ...t,
                  status: msg.content.success ? "completed" : "failed",
                  completedAt: msg.timestamp,
                  result: msg.content.result,
                  error: msg.content.error,
                }
              : t,
          ),
        );
        break;

      case "status":
        if (msg.content.status === "tool_completed") {
          // PostToolUse通知を処理
        }
        break;
    }
  }, []);

  return { toolExecutions, handleStreamMessage };
}
```

```typescript
    return this.value === other.value;

    return this.value
```

```typescript
// packages/shared/src/domain/SkillAssets.ts

/**
 * スキルのアセット（サブリソース）を統合管理するクラス
 * Martin Fowler "Extract Class" リファクタリングにより Data Clumps を解消
 */
export type AssetCategory =
  | "agents"
  | "references"
  | "scripts"
  | "assets"
  | "schemas"
  | "indexes";

export class SkillAssets {
  private readonly resources: Map<AssetCategory, SkillSubResource[]>;

  constructor(data: {
    agents?: SkillSubResource[];
    references?: SkillSubResource[];
    scripts?: SkillSubResource[];
    assets?: SkillSubResource[];
    schemas?: SkillSubResource[];
    indexes?: SkillSubResource[];
  }) {
    this.resources = new Map([
      ["agents", data.agents ?? []],
      ["references", data.references ?? []],
      ["scripts", data.scripts ?? []],
      ["assets", data.assets ?? []],
      ["schemas", data.schemas ?? []],
      ["indexes", data.indexes ?? []],
    ]);
  }

  static readonly CATEGORIES: AssetCategory[] = [
    "agents",
    "references",
    "scripts",
    "assets",
    "schemas",
    "indexes",
  ];

  getByCategory(category: AssetCategory): SkillSubResource[] {
    return this.resources.get(category) ?? [];
  }

  getAllResources(): SkillSubResource[] {
    return [...this.resources.values()].flat();
  }

  getTotalSize(): number {
    return this.getAllResources().reduce((sum, r) => sum + r.size, 0);
  }

  getTotalCount(): number {
    return this.getAllResources().length;
  }

  hasCategory(category: AssetCategory): boolean {
    return (this.resources.get(category)?.length ?? 0) > 0;
  }

  getCategoryCounts(): Record<AssetCategory, number> {
    const counts = {} as Record<AssetCategory, number>;
    for (const category of SkillAssets.CATEGORIES) {
      counts[category] = this.resources.get(category)?.length ?? 0;
    }
    return counts;
  }

  toJSON(): Record<AssetCategory, SkillSubResource[]> {
    const result = {} as Record<AssetCategory, SkillSubResource[]>;
    for (const [key, value] of this.resources) {
      result[key] = value;
    }
    return result;
  }
}
```

```typescript
// apps/desktop/src/main/application/use-cases/ImportSkillUseCase.ts

/**
 * スキルインポートのユースケース
 * Robert C. Martin "Clean Architecture" のユースケース層
 */
export interface ISkillScanner {
  scan(path: string): Promise<SkillMetadata>;
  scanAll(basePath: string): Promise<SkillMetadata[]>;
}

export interface ISkillRepository {
  findByName(name: SkillName): Promise<ImportedSkill | null>;
  save(skill: ImportedSkill): Promise<void>;
  delete(name: SkillName): Promise<void>;
  findAll(): Promise<ImportedSkill[]>;
}

export interface ISkillValidator {
  validate(metadata: SkillMetadata): ValidationResult;
}

export interface ValidationResult {
  isValid: boolean;
  errors: ValidationError[];
  warnings: ValidationWarning[];
}

export class ImportSkillUseCase {
  constructor(
    private readonly scanner: ISkillScanner,
    private readonly repository: ISkillRepository,
    private readonly validator: ISkillValidator,
  ) {}

  async execute(path: string): Promise<ImportResult> {
    // 1. スキルをスキャン
    const metadata = await this.scanner.scan(path);

    // 2. バリデーション
    const validation = this.validator.validate(metadata);
    if (!validation.isValid) {
      return {
        success: false,
        errors: validation.errors,
      };
    }

    // 3. 既存チェック
    const skillName = SkillName.create(metadata.name);
    const existing = await this.repository.findByName(skillName);
    if (existing) {
      return {
        success: false,
        errors: [
          {
            code: "ALREADY_EXISTS",
            message: `スキル "${metadata.name}" は既にインポートされています`,
          },
        ],
      };
    }

    // 4. インポート済みスキルを作成
    const importedSkill: ImportedSkill = {
      ...metadata,
      importedAt: new Date(),
      status: "active",
    };

    // 5. 保存
    await this.repository.save(importedSkill);

    return {
      success: true,
      skill: importedSkill,
      warnings: validation.warnings,
    };
  }
}

// apps/desktop/src/main/application/use-cases/ExecuteSkillUseCase.ts

export interface ISkillExecutor {
  execute(
    skill: ImportedSkill,
    prompt: string,
    options: ExecutionOptions,
  ): AsyncGenerator<SkillStreamMessage>;
}

export interface IPermissionResolver {
  resolvePermissions(
    skill: ImportedSkill,
    toolName: string,
    args: unknown,
  ): Promise<PermissionDecision>;
}

export class ExecuteSkillUseCase {
  constructor(
    private readonly repository: ISkillRepository,
    private readonly executor: ISkillExecutor,
    private readonly permissionResolver: IPermissionResolver,
  ) {}

  async *execute(
    request: SkillExecutionRequest,
  ): AsyncGenerator<SkillStreamMessage> {
    // 1. スキルを取得
    const skillName = SkillName.create(request.skillName);
    const skill = await this.repository.findByName(skillName);

    if (!skill) {
      throw new SkillNotFoundError(request.skillName);
    }

    if (skill.status !== "active") {
      throw new SkillNotActiveError(request.skillName);
    }

    // 2. 実行オプションを構築
    const options: ExecutionOptions = {
      workingDirectory: request.workingDirectory,
      permissionResolver: this.permissionResolver,
    };

    // 3. 実行（ストリーミング）
    yield* this.executor.execute(skill, request.prompt, options);
  }
}
```

```typescript
// packages/shared/src/domain/specifications/index.ts

/**
 * 仕様パターンの基底インターフェース
 * 複雑なビジネスルールを再利用可能なオブジェクトとして表現
 */
export interface Specification<T> {
  /**
   * 候補が仕様を満たすか判定
   */
  isSatisfiedBy(candidate: T): boolean;

  /**
   * AND結合
   */
  and(other: Specification<T>): Specification<T>;

  /**
   * OR結合
   */
  or(other: Specification<T>): Specification<T>;

  /**
   * NOT（否定）
   */
  not(): Specification<T>;
}

/**
 * 合成仕様の基底クラス
 */
export abstract class CompositeSpecification<T> implements Specification<T> {
  abstract isSatisfiedBy(candidate: T): boolean;

  and(other: Specification<T>): Specification<T> {
    return new AndSpecification(this, other);
  }

  or(other: Specification<T>): Specification<T> {
    return new OrSpecification(this, other);
  }

  not(): Specification<T> {
    return new NotSpecification(this);
  }
}

class AndSpecification<T> extends CompositeSpecification<T> {
  constructor(
    private readonly left: Specification<T>,
    private readonly right: Specification<T>,
  ) {
    super();
  }

  isSatisfiedBy(candidate: T): boolean {
    return (
      this.left.isSatisfiedBy(candidate) && this.right.isSatisfiedBy(candidate)
    );
  }
}

class OrSpecification<T> extends CompositeSpecification<T> {
  constructor(
    private readonly left: Specification<T>,
    private readonly right: Specification<T>,
  ) {
    super();
  }

  isSatisfiedBy(candidate: T): boolean {
    return (
      this.left.isSatisfiedBy(candidate) || this.right.isSatisfiedBy(candidate)
    );
  }
}

class NotSpecification<T> extends CompositeSpecification<T> {
  constructor(private readonly spec: Specification<T>) {
    super();
  }

  isSatisfiedBy(candidate: T): boolean {
    return !this.spec.isSatisfiedBy(candidate);
  }
}
```

```typescript
    this.eventPublisher.publish(
      new SkillImportedEvent(skill.id, skill.name, command.timestamp),
    );

    return ImportResult.success(skill);
  }
```

```typescript
  addFile(path: string, content: string, stat?: Partial<FileStat>): void {
    this.files.set(path, content);
    this.stats.set(path, {
      size: content.length,
      isDirectory: false,
      isFile: true,
      modifiedAt: new Date(),
      createdAt: new Date(),
      ...stat,
    });
  }

  addDirectory(path: string): void {
    this.directories.add(path);
    this.stats.set(path, {
      size: 0,
      isDirectory: true,
      isFile: false,
      modifiedAt: new Date(),
      createdAt: new Date(),
    });
  }

  // IFileSystemPort実装
  async readdir(path: string): Promise<string[]> {
    const entries: string[] = [];
    const prefix = path.endsWith("/") ? path : path + "/";

    for (const filePath of this.files.keys()) {
      if (filePath.startsWith(prefix)) {
        const relativePath = filePath.substring(prefix.length);
        const firstSegment = relativePath.split("/")[0];
        if (!entries.includes(firstSegment)) {
          entries.push(firstSegment);
        }
      }
    }

    for (const dirPath of this.directories) {
      if (dirPath.startsWith(prefix)) {
        const relativePath = dirPath.substring(prefix.length);
        const firstSegment = relativePath.split("/")[0];
        if (!entries.includes(firstSegment)) {
          entries.push(firstSegment);
        }
      }
    }

    return entries;
  }

  async readFile(path: string): Promise<string> {
    const content = this.files.get(path);
    if (content === undefined) {
      throw new Error(`ENOENT: no such file or directory, open '${path}'`);
    }
    return content;
  }

  async stat(path: string): Promise<FileStat> {
    const stat = this.stats.get(path);
    if (!stat) {
      throw new Error(`ENOENT: no such file or directory, stat '${path}'`);
    }
    return stat;
  }

  async exists(path: string): Promise<boolean> {
    return this.files.has(path) || this.directories.has(path);
  }

  async isDirectory(path: string): Promise<boolean> {
    return this.directories.has(path);
  }

  // テストヘルパー
  clear(): void {
    this.files.clear();
    this.directories.clear();
    this.stats.clear();
```

#### 5.2.3 Hooks実装パターン（v0.1.73+仕様：直接関数形式）

```typescript
/**
 * Hooks生成関数
 * 参照: apps/desktop/src/main/services/agent/HooksFactory.ts
 */
function createHooks(
  mainWindow: BrowserWindow,
  executionId: string,
  permissionResolver: PermissionResolver,
): SDKHooks {
  return {
    // 危険コマンド・保護パスのブロック
    PreToolUse: async (input, _toolUseId, _context) => {
      // Bashツールの危険コマンドチェック
      if (input.toolName === "Bash") {
        const command = (input.args.command as string) || "";

        for (const pattern of DANGEROUS_PATTERNS.BASH_COMMANDS) {
          if (command.includes(pattern)) {
            return {
              proceed: false,
              message: `危険なコマンドをブロック: ${pattern}`,
            };
          }
        }
      }

      // Write/Editツールの保護パスチェック
      if (input.toolName === "Write" || input.toolName === "Edit") {
        const filePath = (input.args.path as string) || "";

        for (const pattern of DANGEROUS_PATTERNS.PROTECTED_PATHS) {
          if (matchPath(filePath, pattern)) {
            return {
              proceed: false,
              message: `保護されたパスへの書き込みをブロック: ${pattern}`,
            };
          }
        }
      }

      return { proceed: true };
    },

    // ツール完了通知
    PostToolUse: async (input, _toolUseId, _context) => {
      mainWindow.webContents.send("agent:status", {
        executionId,
        type: "tool_completed",
        tool: input.toolName,
        timestamp: Date.now(),
      });
      return {};
    },

    // 権限確認（UIダイアログ連携）
    PermissionRequest: async (input, _toolUseId, context) => {
      const requestId = uuidv4();

      // RendererにPermissionリクエストを送信
      mainWindow.webContents.send("agent:permission", {
        executionId,
        requestId,
        toolName: input.toolName,
        args: input.args,
      });

      // 応答を待機
      const response = await permissionResolver.waitForResponse(
        requestId,
        context.signal,
      );

      return {
        proceed: response.approved,
        message: response.rejectReason,
      };
    },
  };
}
```

#### 5.2.4 Permission Control（権限制御の4層）

**処理順序**:

```
PreToolUse Hook
    ↓
Deny Rules（拒否ルール）
    ↓
Allow Rules（許可ルール）
    ↓
Ask Rules（確認ルール）
    ↓
Permission Mode Check
    ↓
canUseTool Callback
    ↓
PostToolUse Hook
```

**Permission Modes**:

```typescript
type PermissionMode =
  | "auto" // すべて自動承認（⚠️ 本番非推奨）
  | "ask" // すべて確認
  | "deny" // すべて拒否
  | "default"; // デフォルト（ツールごとの設定に従う）
```

**Permission Rules 構文**:

```typescript
interface PermissionRules {

  ask?: ToolPermissionRule[]; // 確認ルール

  tool: string | string[]; // ツール名またはパターン
  paths?: string[]; // 対象パス（オプション）

}
```

#### 5.2.8 セキュリティベストプラクティス

**すべきこと**:

- Permission Rulesで適切な権限制御を設計する
- PreToolUseフックで危険なコマンドをブロックする
- AbortSignalを使用してタイムアウト処理を実装する
- IPCチャネル名を一貫した命名規則で設計する
- ストリーミングメッセージを適切にUI更新に反映する
- signal.abortedを定期的にチェックする

**避けるべきこと**:

- `permissionMode: 'auto'` を本番環境で使用する
- Hookなしで危険なツール（Bash等）を許可する
- Main ProcessでUIロジックを処理する
- ストリーミング中のエラーを無視する
- APIキーをRenderer Processで扱う
- signal.abortedのチェックを省略する

### 5.6 SkillScanner実装仕様

```typescript
// apps/desktop/src/main/services/skill/SkillScanner.ts

import * as fs from "fs/promises";
import * as path from "path";
import * as yaml from "yaml";

/**
 * スキルスキャナー
 * ~/.claude/skills/ 配下のスキルを検出し、全情報を取得
 */
export class SkillScanner {
  private skillsDir: string;

  constructor(skillsDir?: string) {
    this.skillsDir =
      skillsDir || path.join(process.env.HOME!, ".claude", "skills");
  }

  /**
   * 全スキルをスキャンして全情報を取得
   */
  async scanAll(): Promise<SkillMetadata[]> {
    const skills: SkillMetadata[] = [];

    try {
      const entries = await fs.readdir(this.skillsDir, { withFileTypes: true });

      for (const entry of entries) {
        if (!entry.isDirectory()) continue;

        const skillPath = path.join(this.skillsDir, entry.name);
        const skillMdPath = path.join(skillPath, "SKILL.md");

        try {
          const skill = await this.parseSkill(skillPath, skillMdPath);
          if (skill) skills.push(skill);
        } catch (e) {
          // 無効なスキルはスキップ
          console.warn(`スキル読み込みスキップ: ${entry.name}`, e);
        }
      }
    } catch (e) {
      console.error("スキルディレクトリ読み込みエラー:", e);
    }

    return skills;
  }

  /**
   * 単一スキルをパース（配下の全情報を取得）
   */
  private async parseSkill(
    skillPath: string,
    skillMdPath: string,
  ): Promise<SkillMetadata | null> {
    const content = await fs.readFile(skillMdPath, "utf-8");
    const { frontmatter, body } = this.parseFrontmatter(content);

    if (!frontmatter.name) return null;

    const stat = await fs.stat(skillMdPath);

    // 配下のサブディレクトリを全てスキャン
    const [agents, references, scripts, assets, schemas, indexes, otherFiles] =
      await Promise.all([
        this.scanSubDirectory(skillPath, "agents"),
        this.scanSubDirectory(skillPath, "references"),
        this.scanSubDirectory(skillPath, "scripts"),
        this.scanSubDirectory(skillPath, "assets"),
        this.scanSubDirectory(skillPath, "schemas"),
        this.scanSubDirectory(skillPath, "indexes"),
        this.scanOtherFiles(skillPath),
      ]);

    return {
      name: frontmatter.name,
      description: frontmatter.description || body.slice(0, 200),
      allowedTools: frontmatter["allowed-tools"] || [],
      path: skillPath,
      updatedAt: stat.mtime,
      agents,
      references,
      scripts,
      assets,
      schemas,
      indexes,
      otherFiles,
    };
  }

  /**
   * サブディレクトリ内のファイルをスキャン
   */
  private async scanSubDirectory(
    skillPath: string,
    subDir: string,
  ): Promise<SkillSubResource[]> {
    const dirPath = path.join(skillPath, subDir);
    const resources: SkillSubResource[] = [];

    try {
      const entries = await fs.readdir(dirPath, { withFileTypes: true });

      for (const entry of entries) {
        if (!entry.isFile()) continue;

        const filePath = path.join(dirPath, entry.name);
        const stat = await fs.stat(filePath);

        // Markdownファイルの場合は先頭から説明を抽出
        let description: string | undefined;
        if (entry.name.endsWith(".md")) {
          description = await this.extractDescription(filePath);
        }

        resources.push({
          filename: entry.name,
          relativePath: path.join(subDir, entry.name),
          description,
          size: stat.size,
        });
      }
    } catch {
      // ディレクトリが存在しない場合は空配列
    }

    return resources;
  }

  /**
   * スキルディレクトリ直下のその他のファイルをスキャン
   */
  private async scanOtherFiles(skillPath: string): Promise<SkillOtherFile[]> {
    const files: SkillOtherFile[] = [];

    try {
      const entries = await fs.readdir(skillPath, { withFileTypes: true });

      for (const entry of entries) {
        if (entry.isFile() && entry.name !== "SKILL.md") {
          const filePath = path.join(skillPath, entry.name);
          const stat = await fs.stat(filePath);

          // ファイルタイプを判定
          let type: SkillOtherFile["type"] = "other";
          if (entry.name === "EVALS.json") type = "evals";
          else if (entry.name === "LOGS.md") type = "logs";
          else if (entry.name === "package.json") type = "package";

          files.push({
            filename: entry.name,
            type,
            size: stat.size,
          });
        }
      }
    } catch {
      // エラー時は空配列
    }

    return files;
  }

  /**
   * Markdownファイルから説明を抽出
   */
  private async extractDescription(filePath: string): Promise<string> {
    try {
      const content = await fs.readFile(filePath, "utf-8");
      // 最初の見出しまたは最初の段落を抽出
      const match = content.match(/^#\s+(.+)$/m);
      if (match) return match[1];

      const lines = content.split("\n").filter((l) => l.trim());
      return lines[0]?.slice(0, 100) || "";
    } catch {
      return "";
    }
  }

  /**
   * YAML Frontmatterをパース
   */
  private parseFrontmatter(content: string): {
    frontmatter: Record<string, unknown>;
    body: string;
  } {
    const match = content.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/);
    if (!match) {
      return { frontmatter: {}, body: content };
    }

    try {
      return {
        frontmatter: yaml.parse(match[1]),
        body: match[2],
      };
    } catch {
      return { frontmatter: {}, body: content };
    }
  }
}
```

```typescript
import { BrowserWindow } from "electron";
import { v4 as uuidv4 } from "uuid";
import { SKILL_CHANNELS } from "../../../preload/channels";

  SkillExecutionResponse,
  SkillMetadata,
  SkillStreamMessage,
  DANGEROUS_PATTERNS,

/**
 * スキル実行エンジン
 * Claude Agent SDK経由でスキルを実行し、結果をストリーミング
 */
export class SkillExecutor {
  private mainWindow: BrowserWindow;
  private permissionResolver: PermissionResolver;
  private activeExecutions: Map<string, AbortController> = new Map();

  constructor(mainWindow: BrowserWindow) {
    this.mainWindow = mainWindow;
    this.permissionResolver = new PermissionResolver();
  }

  /**
   * スキルを実行
   * @returns 実行ID（executionId）
   */
  async execute(
    request: SkillExecutionRequest,
    skill: SkillMetadata,
  ): Promise<SkillExecutionResponse> {
    const executionId = uuidv4();
    const abortController = new AbortController();

    this.activeExecutions.set(executionId, abortController);

    try {
      // 実行開始を通知
      this.sendStream({
        executionId,
        type: "status",
        content: { status: "started", detail: skill.name },
        timestamp: Date.now(),
      });

      // スキルプロンプトを構築
      const prompt = await this.buildPrompt(request.prompt, skill);

      // Hooksを作成
      const hooks = this.createHooks(executionId);

      // Claude Agent SDKを実行
      const conversation = query({
        prompt,
        options: {
          tools: skill.allowedTools || ["Read", "Edit", "Bash", "Glob", "Grep"],
          hooks,
          permissionMode: "default",
          ...(request.workingDirectory && { cwd: request.workingDirectory }),
        },
      });

      // ストリーミング処理
      for await (const message of conversation.stream()) {
        if (abortController.signal.aborted) {
          break;
        }

        await this.handleStreamMessage(executionId, message);
      }

      // 完了通知
      this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_COMPLETE, {
        executionId,
      });

      return { executionId, success: true };
    } catch (error) {
      const errorMessage =
        error instanceof Error ? error.message : "Unknown error";

      // エラー通知
      this.sendStream({
        executionId,
        type: "error",
        content: {
          code: this.categorizeError(error),
          message: errorMessage,
          retryable: this.isRetryable(error),
        },
        timestamp: Date.now(),
      });

      this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_ERROR, {
        executionId,
        error: errorMessage,
      });

      return { executionId, success: false, error: errorMessage };
    } finally {
      this.activeExecutions.delete(executionId);
    }
  }

  /**
   * 実行を中止
   */
  abort(executionId: string): void {
    const controller = this.activeExecutions.get(executionId);
    if (controller) {
      controller.abort();
      this.activeExecutions.delete(executionId);
    }
  }

  /**
   * 権限応答を処理
   */
  handlePermissionResponse(response: PermissionResponse): void {
    this.permissionResolver.resolveRequest(response);
  }

  /**
   * スキルプロンプトを構築
   */
  private async buildPrompt(
    userPrompt: string,
    skill: SkillMetadata,
  ): Promise<string> {
    // SKILL.mdの内容を読み込み
    const skillContent = skill.content || "";

    // サブエージェント、参照資料の情報を付加
    const contextInfo = this.buildContextInfo(skill);

    return `${skillContent}

## コンテキスト情報
${contextInfo}

## ユーザーリクエスト
${userPrompt}`;
  }

  /**
   * コンテキスト情報を構築
   */
  private buildContextInfo(skill: SkillMetadata): string {
    const parts: string[] = [];

    if (skill.agents.length > 0) {
      parts.push(
        `### 利用可能なサブエージェント (agents/):\n${skill.agents.map((a) => `- ${a.filename}: ${a.description || ""}`).join("\n")}`,
      );
    }

    if (skill.references.length > 0) {
      parts.push(
        `### 参照資料 (references/):\n${skill.references.map((r) => `- ${r.filename}: ${r.description || ""}`).join("\n")}`,
      );
    }

    if (skill.scripts.length > 0) {
      parts.push(
        `### スクリプト (scripts/):\n${skill.scripts.map((s) => `- ${s.filename}`).join("\n")}`,
      );
    }

    return parts.join("\n\n");
  }

  /**
   * Hooksを作成
   */
  private createHooks(executionId: string): SDKHooks {
    return {
      PreToolUse: async (input, _toolUseId, _context) => {
        // 危険コマンドチェック
        if (input.toolName === "Bash") {
          const command = (input.args.command as string) || "";
          for (const pattern of DANGEROUS_PATTERNS.BASH_COMMANDS) {
            if (command.includes(pattern)) {
              return {
                proceed: false,
                message: `危険なコマンドをブロック: ${pattern}`,
              };
            }
          }
        }

        // 保護パスチェック
        if (input.toolName === "Write" || input.toolName === "Edit") {
          const filePath = (input.args.path as string) || "";
          if (this.isProtectedPath(filePath)) {
            return {
              proceed: false,
              message: `保護されたパスへの書き込みをブロック: ${filePath}`,
            };
          }
        }

        return { proceed: true };
      },

      PostToolUse: async (input, _toolUseId, _context) => {
        this.sendStream({
          executionId,
          type: "status",
          content: { status: "tool_completed", detail: input.toolName },
          timestamp: Date.now(),
        });
        return {};
      },

      PermissionRequest: async (input, _toolUseId, context) => {
        const requestId = uuidv4();

        this.mainWindow.webContents.send(
          SKILL_CHANNELS.SKILL_PERMISSION_REQUEST,
          {
            executionId,
            requestId,
            toolName: input.toolName,
            args: input.args,
          },
        );

        const response = await this.permissionResolver.waitForResponse(
          requestId,
          context.signal,
        );

        return {
          proceed: response.approved,
          message: response.rejectReason,
        };
      },
    };
  }

  /**
   * ストリームメッセージを処理
   */
  private async handleStreamMessage(
    executionId: string,
    message: SDKMessage,
  ): Promise<void> {
    switch (message.type) {
      case "assistant":
        this.sendStream({
          executionId,
          type: "assistant",
          content: {
            text: message.message.content || "",
            isPartial: false,
          },
          timestamp: Date.now(),
        });
        break;

      case "result":
        this.sendStream({
          executionId,
          type: "tool_result",
          content: {
            toolUseId: message.message.tool_use_id || "",
            success: !message.message.is_error,
            result: message.message.content,
            error: message.message.is_error
              ? String(message.message.content)
              : undefined,
          },
          timestamp: Date.now(),
        });
        break;

      case "stream_event":
        // 部分メッセージはアシスタントメッセージとして送信
        if (message.event?.partial) {
          this.sendStream({
            executionId,
            type: "assistant",
            content: {
              text: message.event.partial,
              isPartial: true,
            },
            timestamp: Date.now(),
          });
        }
        break;
    }
  }

  /**
   * ストリームメッセージを送信
   */
  private sendStream(message: SkillStreamMessage): void {
    this.mainWindow.webContents.send(SKILL_CHANNELS.SKILL_STREAM, message);
  }

  /**
   * 保護パスかどうかを判定
   */
  private isProtectedPath(filePath: string): boolean {
    for (const pattern of DANGEROUS_PATTERNS.PROTECTED_PATHS) {
      if (this.matchGlob(filePath, pattern)) {
        return true;
      }
    }
    return false;
  }

  /**
   * Globパターンマッチ（簡易版）
   */
  private matchGlob(path: string, pattern: string): boolean {
    // **を.*?に、*を[^/]*に変換
    const regex = new RegExp(
      "^" +
        pattern
          .replace(/\*\*/g, ".*")
          .replace(/\*/g, "[^/]*")
          .replace(/~/g, process.env.HOME || "") +
        "$",
    );
    return regex.test(path);
  }

  /**
   * エラーカテゴリを判定
   */
  private categorizeError(
    error: unknown,
  ): "sdk_error" | "permission_denied" | "timeout" | "network" | "unknown" {
    if (error instanceof Error) {
      if (error.message.includes("abort")) return "timeout";
      if (error.message.includes("permission")) return "permission_denied";
      if (
        error.message.includes("network") ||
        error.message.includes("ECONNREFUSED")
      )
        return "network";
      if (error.message.includes("SDK")) return "sdk_error";
    }
    return "unknown";
  }

  /**
   * リトライ可能かどうかを判定
   */
  private isRetryable(error: unknown): boolean {
    const category = this.categorizeError(error);
    return category === "network" || category === "timeout";
  }
}
```

```typescript
// apps/desktop/src/main/ipc/skillHandlers.ts

import { ipcMain, BrowserWindow } from "electron";
import { SKILL_CHANNELS } from "../../preload/channels";
import { SkillScanner } from "../services/skill/SkillScanner";
import { SkillExecutor } from "../services/skill/SkillExecutor";
import { skillImportStore } from "../settings/skillImportStore";
import type { SkillExecutionRequest, PermissionResponse } from "@repo/shared";

let skillScanner: SkillScanner | null = null;
let skillExecutor: SkillExecutor | null = null;
let cachedSkills: SkillMetadata[] | null = null;

export function registerSkillHandlers(mainWindow: BrowserWindow): void {
  skillScanner = new SkillScanner();
  skillExecutor = new SkillExecutor(mainWindow);

  // スキル一覧取得（キャッシュあり）
  ipcMain.handle(SKILL_CHANNELS.SKILL_LIST, async () => {
    if (!cachedSkills) {
      cachedSkills = await skillScanner!.scanAll();
    }
    return cachedSkills;
  });

  // スキル再スキャン（キャッシュ無効化）
  ipcMain.handle(SKILL_CHANNELS.SKILL_SCAN, async () => {
    cachedSkills = await skillScanner!.scanAll();
    return cachedSkills;
  });

  // スキルインポート
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_IMPORT,
    async (_event, skillName: string) => {
      skillImportStore.addImport(skillName);

      const skill = cachedSkills?.find((s) => s.name === skillName);
      if (!skill) {
        throw new Error(`スキルが見つかりません: ${skillName}`);
      }

      return {
        ...skill,
        importedAt: new Date(),
        status: "active" as const,
      };
    },
  );

  // インポート済みスキル取得
  ipcMain.handle(SKILL_CHANNELS.SKILL_GET_IMPORTED, async () => {
    const imported = skillImportStore.getImported();
    const skills: ImportedSkill[] = [];

    for (const data of imported) {
      const skill = cachedSkills?.find((s) => s.name === data.name);
      if (skill) {
        skills.push({
          ...skill,
          importedAt: new Date(data.importedAt),
          status: data.status,
        });
      }
    }

    return skills;
  });

  // スキル削除
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_REMOVE,
    async (_event, skillName: string) => {
      skillImportStore.removeImport(skillName);
    },
  );

  // スキル実行
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_EXECUTE,
    async (_event, request: SkillExecutionRequest) => {
      const skill = cachedSkills?.find((s) => s.name === request.skillName);
      if (!skill) {
        throw new Error(`スキルが見つかりません: ${request.skillName}`);
      }

      // SKILL.mdの内容を読み込み
      const fs = await import("fs/promises");
      const path = await import("path");
      const skillMdPath = path.join(skill.path, "SKILL.md");
      const content = await fs.readFile(skillMdPath, "utf-8");

      const enrichedSkill = { ...skill, content };

      return skillExecutor!.execute(request, enrichedSkill);
    },
  );

  // 実行中止
  ipcMain.handle(
    SKILL_CHANNELS.SKILL_ABORT,
    async (_event, executionId: string) => {
      skillExecutor!.abort(executionId);
    },
  );

  // 権限応答受信
  ipcMain.on(
    SKILL_CHANNELS.SKILL_PERMISSION_RESPONSE,
    (_event, response: PermissionResponse) => {
      skillExecutor!.handlePermissionResponse(response);
    },
  );
}
```

- `permissionMode: 'default'` でSDKデフォルトの権限制御を使用

- 書き込み系ツール（Write, Edit, Bash）は権限確認ダイアログ表示
- ユーザーが明示的に許可しない限り実行しない

```typescript
// apps/desktop/src/main/services/skill/SkillFileManager.ts

export class SkillFileManager {
  private skillsDir: string;
  private backupDir: string;

  constructor(skillsDir?: string) {
    this.skillsDir =
      skillsDir || path.join(process.env.HOME!, ".claude", "skills");
    this.backupDir = path.join(this.skillsDir, ".skill-backups");
  }

  /** スキルファイルを読み込み */
  async readFile(skillName: string, relativePath: string): Promise<string> {
    const filePath = path.join(this.skillsDir, skillName, relativePath);
    return fs.readFile(filePath, "utf-8");
  }

  /** スキルファイルを保存（バックアップ付き） */
  async saveFile(
    skillName: string,
    relativePath: string,
    content: string,
  ): Promise<void> {
    const filePath = path.join(this.skillsDir, skillName, relativePath);

    // バックアップを作成
    if (await this.fileExists(filePath)) {
      await this.createBackup(skillName, relativePath);
    }

    await fs.writeFile(filePath, content, "utf-8");
  }

  /** バックアップを作成 */
  private async createBackup(
    skillName: string,
    relativePath: string,
  ): Promise<void> {
    const backupPath = path.join(
      this.backupDir,
      skillName,
      `${Date.now()}_${relativePath.replace(/\//g, "_")}`,
    );
    await fs.mkdir(path.dirname(backupPath), { recursive: true });

    const original = await this.readFile(skillName, relativePath);
    await fs.writeFile(backupPath, original, "utf-8");

    // 古いバックアップを削除（最大10個）
    await this.cleanupBackups(skillName);
  }

  /** 新規ファイルを作成 */
  async createFile(
    skillName: string,
    relativePath: string,
    content: string,
  ): Promise<void> {
    const filePath = path.join(this.skillsDir, skillName, relativePath);
    await fs.mkdir(path.dirname(filePath), { recursive: true });
    await fs.writeFile(filePath, content, "utf-8");
  }

  /** ファイルを削除 */
  async deleteFile(skillName: string, relativePath: string): Promise<void> {
    await this.createBackup(skillName, relativePath);
    const filePath = path.join(this.skillsDir, skillName, relativePath);
    await fs.unlink(filePath);
  }
}
```

```typescript
export class SkillCreatorService {
  private skillsDir: string;

    const skillCreatorContent = await this.loadSkillCreatorContent();

    // 生成プロンプトを構築
    const prompt = this.buildCreationPrompt(requirements, skillCreatorContent);

    // Claude Agent SDKで実行

    }

    // 生成されたスキルをスキャン
    const skillName = this.extractSkillName(requirements);
    const scanner = new SkillScanner();

    return skills.find((s) => s.name === skillName)!;

    const executionId = uuidv4();

    // 対象スキルを読み込み
    const skillContent = await this.loadSkillContent(skillName);

    // 改善プロンプトを構築
    const prompt = this.buildImprovementPrompt(
      skillName,
      skillContent,
      improvements,
    );

    const conversation = query({
      prompt,
      options: {
        tools: ["Read", "Write", "Edit", "Glob"],
        hooks: this.createHooks(executionId),
        permissionMode: "default",
      },
    });

    for await (const message of conversation.stream()) {
      this.handleStreamMessage(executionId, message);
    }
  }

  /** タスク仕様書を実行 */
  async executeTasks(taskDir: string): Promise<void> {
    const executionId = uuidv4();

    // タスク仕様書を読み込み・パース
    const tasks = await this.loadTaskSpecs(taskDir);

    // 依存関係を解決してトポロジカルソート
    const executionOrder = this.resolveExecutionOrder(tasks);

    // 順次実行
    for (const taskGroup of executionOrder) {
      // 並列実行可能なグループは同時実行
      await Promise.all(
        taskGroup.map((task) => this.executeTask(executionId, task)),
      );
    }
  }

    requirements: string,
    skillCreatorContent: string,

上記の要求に基づいて、新しいスキルを作成してください。

1. スキル名を決定（英語、ケバブケース）
2. ~/.claude/skills/{skill-name}/ ディレクトリを作成
3. SKILL.md を作成（frontmatter + 本文）
4. 必要に応じて agents/, references/, scripts/ を作成
5. 作成完了を報告`;
  }
```

```typescript
// apps/desktop/src/main/services/skill/SkillAnalyzer.ts

export interface SkillAnalysisResult {
  score: SkillScore;
  issues: SkillIssue[];
  suggestions: SkillSuggestion[];
}

export interface SkillScore {
  overall: number; // 0-100
  categories: {
    clarity: number; // プロンプトの明確さ
    efficiency: number; // 実行効率
    security: number; // セキュリティ
    maintainability: number; // 保守性
  };
}

export interface SkillIssue {
  type: "error" | "warning" | "info";
  category: string;
  message: string;
  location?: {
    file: string;
    line?: number;
  };
  fix?: string;
}

export interface SkillSuggestion {
  id: string;
  category: "prompt" | "structure" | "security" | "performance";
  title: string;
  description: string;
  priority: "high" | "medium" | "low";
  autoFixable: boolean;
  diff?: string;
}

export class SkillAnalyzer {
  /** スキルを分析 */
  async analyze(skillName: string): Promise<SkillAnalysisResult> {
    const scanner = new SkillScanner();
    const skills = await scanner.scanAll();
    const skill = skills.find((s) => s.name === skillName);

    if (!skill) {
      throw new Error(`スキルが見つかりません: ${skillName}`);
    }

    // 静的解析
    const staticIssues = await this.runStaticAnalysis(skill);

    // AI分析
    const aiResult = await this.runAIAnalysis(skill);

    // 結果をマージ
    return {
      score: aiResult.score,
      issues: [...staticIssues, ...aiResult.issues],
      suggestions: aiResult.suggestions,
    };
  }

  /** 静的解析 */
  private async runStaticAnalysis(skill: SkillMetadata): Promise<SkillIssue[]> {
    const issues: SkillIssue[] = [];

    // frontmatter検証
    if (!skill.description || skill.description.length < 10) {
      issues.push({
        type: "warning",
        category: "metadata",
        message: "説明文が短すぎます。より詳細な説明を追加してください。",
        location: { file: "SKILL.md" },
      });
    }

    // allowed-tools検証
    if (!skill.allowedTools || skill.allowedTools.length === 0) {
      issues.push({
        type: "warning",
        category: "security",
        message: "allowed-toolsが未定義です。必要なツールを明示してください。",
        location: { file: "SKILL.md" },
      });
    }

    // 危険なツールの警告
    const dangerousTools = ["Bash"];
    const hasDangerous = skill.allowedTools?.some((t) =>
      dangerousTools.includes(t),
    );
    if (hasDangerous) {
      issues.push({
        type: "info",
        category: "security",
        message:
          "Bashツールが許可されています。危険なコマンドへの対策を確認してください。",
        location: { file: "SKILL.md" },
      });
    }

    return issues;
  }

  /** AI分析（Claude Agent SDK使用） */
  private async runAIAnalysis(skill: SkillMetadata): Promise<{
    score: SkillScore;
    issues: SkillIssue[];
    suggestions: SkillSuggestion[];
  }> {
    const skillContent = await this.loadSkillContent(skill);

    const conversation = query({
      prompt: this.buildAnalysisPrompt(skillContent),
      options: {
        tools: ["Read"],
        permissionMode: "default",
      },
    });

    let result = "";
    for await (const msg of conversation.stream()) {
      if (msg.type === "assistant") {
        result += msg.message.content;
      }
    }

    return this.parseAnalysisResult(result);
  }
}
```

```typescript
// apps/desktop/src/main/services/skill/SkillImprover.ts

export class SkillImprover {
  private analyzer: SkillAnalyzer;
  private fileManager: SkillFileManager;

  constructor() {
    this.analyzer = new SkillAnalyzer();
    this.fileManager = new SkillFileManager();
  }

  /** 改善を適用 */
  async applyImprovement(
    skillName: string,
    suggestionId: string,
  ): Promise<void> {
    const analysis = await this.analyzer.analyze(skillName);
    const suggestion = analysis.suggestions.find((s) => s.id === suggestionId);

    if (!suggestion) {
      throw new Error(`提案が見つかりません: ${suggestionId}`);
    }

    if (!suggestion.autoFixable || !suggestion.diff) {
      throw new Error("この提案は自動適用できません");
    }

    // diffを適用
    await this.applyDiff(skillName, suggestion.diff);
  }

  /** すべての自動修正可能な改善を適用 */
  async applyAllAutoFixes(skillName: string): Promise<number> {
    const analysis = await this.analyzer.analyze(skillName);
    const autoFixable = analysis.suggestions.filter((s) => s.autoFixable);

    for (const suggestion of autoFixable) {
      if (suggestion.diff) {
        await this.applyDiff(skillName, suggestion.diff);
      }
    }

    return autoFixable.length;
  }
}
```

```typescript
export class TaskExecutor {
  /** 依存関係を解決してトポロジカルソート */
  resolveExecutionOrder(tasks: TaskSpec[]): TaskSpec[][] {
    const graph = this.buildDependencyGraph(tasks);

    const graph = new Map<string, Set<string>>();

    for (const task of tasks) {
      graph.set(task.id, new Set(task.dependsOn || []));
    }

    return graph;
  }

  /** トポロジカルソート（Kahnのアルゴリズム） */
  private topologicalSort(graph: Map<string, Set<string>>): string[] {
    const inDegree = new Map<string, number>();
    const result: string[] = [];
    const queue: string[] = [];

    // 入次数を計算
    for (const [node, deps] of graph) {
      inDegree.set(node, deps.size);
      if (deps.size === 0) {
        queue.push(node);
      }
    }

    while (queue.length > 0) {
      const node = queue.shift()!;
      result.push(node);

      for (const [n, deps] of graph) {
        if (deps.has(node)) {
          deps.delete(node);
          if (deps.size === 0) {
            queue.push(n);
          }
        }
      }
    }

    // 循環依存チェック
    if (result.length !== graph.size) {
      throw new Error("循環依存が検出されました");
```

```typescript
/**
 * スキルチェーン実行エンジン
 */
export class SkillChainExecutor {
  constructor(
    private skillExecutor: SkillExecutor,
    private mainWindow: BrowserWindow,
  ) {}

  async executeChain(
    chain: SkillChainDefinition,
    initialInput?: string,
  ): Promise<SkillChainResult> {
    const context: ChainExecutionContext = {
      variables: { ...chain.variables },
      results: [],
      currentStepIndex: 0,
    };

    for (const step of chain.steps) {
      // 条件チェック
      if (step.condition && !this.evaluateCondition(step.condition, context)) {
        context.results.push({ stepId: step.stepId, skipped: true });
        continue;
      }

      // 入力を構築
      const input = this.buildStepInput(step, context, initialInput);

      try {
        // スキル実行
        const result = await this.skillExecutor.execute(
          { skillName: step.skillName, prompt: input },
          await this.getSkillMetadata(step.skillName),
        );

        // 出力をマッピング
        if (step.outputMapping && result.output) {
          const extracted = this.extractOutput(
            result.output,
            step.outputMapping,
          );
          context.variables[step.outputMapping.variableName] = extracted;
        }

        context.results.push({
          stepId: step.stepId,
          success: result.success,
          output: result.output,
        });

        context.lastOutput = result.output;
      } catch (error) {
        context.results.push({
          stepId: step.stepId,
          success: false,
          error: String(error),
        });

        // エラーハンドリング
        if (chain.errorHandling === "stop") {
          break;
        } else if (chain.errorHandling === "retry" && step.retryCount) {
          // リトライロジック
        }
      }

      context.currentStepIndex++;
    }

    return {
      chainId: chain.id,
      success: context.results.every((r) => r.success || r.skipped),
      results: context.results,
      finalVariables: context.variables,
    };
  }

  private buildStepInput(
    step: SkillChainStep,
    context: ChainExecutionContext,
    initialInput?: string,
  ): string {
    const { inputMapping } = step;

    switch (inputMapping.type) {
      case "literal":
        return inputMapping.value || "";
      case "variable":
        return String(context.variables[inputMapping.value || ""] || "");
      case "previousOutput":
        return context.lastOutput || initialInput || "";
      case "template":
        return this.renderTemplate(inputMapping.template || "", context);
      default:
        return "";
    }
  }
}
```

```typescript
export class SkillForker {
  constructor(private skillsDir: string) {}

  async fork(options: ForkOptions): Promise<ForkResult> {
    const sourcePath = path.join(this.skillsDir, options.sourceSkill);
    const destPath = path.join(this.skillsDir, options.newName);

    // 既存チェック
    if (await this.exists(destPath)) {
      throw new Error(`スキル "${options.newName}" は既に存在します`);
    }

    // ディレクトリ作成
    await fs.mkdir(destPath, { recursive: true });

    const copiedFiles: string[] = [];
    const warnings: string[] = [];

    // SKILL.md をコピー・修正
    const sourceSkillMd = await fs.readFile(
      path.join(sourcePath, "SKILL.md"),
      "utf-8",
    );
    const newSkillMd = this.modifySkillMd(sourceSkillMd, options);
    await fs.writeFile(path.join(destPath, "SKILL.md"), newSkillMd);
    copiedFiles.push("SKILL.md");

    // サブディレクトリをコピー
    if (options.copyAgents) {
      const copied = await this.copyDirectory(sourcePath, destPath, "agents");
      copiedFiles.push(...copied);
    }

    if (options.copyReferences) {
      const copied = await this.copyDirectory(
        sourcePath,
        destPath,
        "references",
      );
      copiedFiles.push(...copied);
    }

    if (options.copyScripts) {
      const copied = await this.copyDirectory(sourcePath, destPath, "scripts");
      copiedFiles.push(...copied);
    }

    if (options.copyAssets) {
      const copied = await this.copyDirectory(sourcePath, destPath, "assets");
      copiedFiles.push(...copied);
    }

    // フォーク元の情報を記録
    await this.writeForkMetadata(destPath, {
      forkedFrom: options.sourceSkill,
      forkedAt: new Date().toISOString(),
      originalPath: sourcePath,
    });

    return {
      success: true,
      newSkillPath: destPath,
      copiedFiles,
      warnings: warnings.length > 0 ? warnings : undefined,
    };
  }

  private modifySkillMd(content: string, options: ForkOptions): string {
    // Frontmatterを更新
    const { frontmatter, body } = this.parseFrontmatter(content);

    frontmatter.name = options.newName;
    if (options.description) {
      frontmatter.description = options.description;
    }
    if (options.modifyAllowedTools) {
      frontmatter["allowed-tools"] = options.modifyAllowedTools;
    }

    // フォーク情報を追加
    frontmatter["forked-from"] = options.sourceSkill;

    return this.serializeFrontmatter(frontmatter, body);
  }
```

### 20.3 SkillShareManager 実装

```typescript
export class SkillShareManager {
  constructor(
    private skillsDir: string,
    private octokit?: Octokit, // GitHub API クライアント
  ) {}

  /**
   * スキルをインポート
   */
  async import(source: ShareTarget): Promise<ImportResult> {
    switch (source.type) {
      case "github":
        return this.importFromGitHub(source);
      case "gist":
        return this.importFromGist(source);
      case "local":
        return this.importFromLocal(source);
      case "url":
        return this.importFromUrl(source);
      default:
        throw new Error(`Unknown source type: ${source.type}`);
    }
  }

  private async importFromGitHub(source: ShareTarget): Promise<ImportResult> {
    if (!this.octokit || !source.repo) {
      throw new Error("GitHub認証が必要です");
    }

    const [owner, repo] = source.repo.split("/");
    const skillPath = source.path || "";

    // SKILL.mdの存在を確認
    const skillMdPath = path.join(skillPath, "SKILL.md");
    const { data: skillMdContent } = await this.octokit.repos.getContent({
      owner,
      repo,
      path: skillMdPath,
      ref: source.branch || "main",
    });

    // スキル名を抽出
    const content = Buffer.from(skillMdContent.content, "base64").toString();
    const { frontmatter } = this.parseFrontmatter(content);
    const skillName = frontmatter.name || path.basename(skillPath);

    // ディレクトリ全体をダウンロード
    const destPath = path.join(this.skillsDir, skillName);
    await this.downloadDirectory(
      owner,
      repo,
      skillPath,
      destPath,
      source.branch,
    );

    return {
      success: true,
      skillName,
      skillPath: destPath,
      source,
      importedAt: new Date(),
    };
  }

  private async importFromGist(source: ShareTarget): Promise<ImportResult> {
    if (!source.gistId) {
      throw new Error("Gist IDが必要です");
    }

    // Gist APIでファイル一覧を取得
    const response = await fetch(
      `https://api.github.com/gists/${source.gistId}`,
    );
    const gist = await response.json();

    // SKILL.mdを探す
    const skillMdFile = gist.files["SKILL.md"];
    if (!skillMdFile) {
      throw new Error("Gist内にSKILL.mdが見つかりません");
    }

    const { frontmatter } = this.parseFrontmatter(skillMdFile.content);
    const skillName = frontmatter.name || `gist-${source.gistId.slice(0, 8)}`;
    const destPath = path.join(this.skillsDir, skillName);

    await fs.mkdir(destPath, { recursive: true });

    // 全ファイルを保存
    for (const [filename, file] of Object.entries(gist.files)) {
      const filePath = path.join(destPath, filename);
      await fs.mkdir(path.dirname(filePath), { recursive: true });
      await fs.writeFile(filePath, file.content);
    }

    return {
      success: true,
      skillName,
      skillPath: destPath,
      source,
      importedAt: new Date(),
    };
  }

  /**
   * スキルをエクスポート
   */
  async export(
    skillName: string,
    destination: ShareTarget,
  ): Promise<ExportResult> {
    const skillPath = path.join(this.skillsDir, skillName);

    switch (destination.type) {
      case "gist":
        return this.exportToGist(skillPath, skillName);
      case "local":
        return this.exportToLocal(skillPath, destination.localPath!);
      default:
        throw new Error(`Export to ${destination.type} is not supported`);
    }
  }

  private async exportToGist(
    skillPath: string,
    skillName: string,
  ): Promise<ExportResult> {
    if (!this.octokit) {
      throw new Error("GitHub認証が必要です");
    }

    // ファイル一覧を取得
    const files: Record<string, { content: string }> = {};
    const exportedFiles: string[] = [];

    await this.collectFilesForExport(skillPath, "", files, exportedFiles);

    // Gist作成
    const { data: gist } = await this.octokit.gists.create({
      description: `Claude Code Skill: ${skillName}`,
      public: false,
      files,
    });

    return {
      success: true,
      destination: { type: "gist", gistId: gist.id },
      exportedFiles,
      shareUrl: gist.html_url,
    };
  }
}
```

### 21.3 SkillScheduler 実装

```typescript
import * as cron from "node-cron";

export class SkillScheduler {
  private scheduledTasks: Map<string, cron.ScheduledTask> = new Map();
  private store: ScheduleStore;
  private skillExecutor: SkillExecutor;
  private notifier: NotificationService;

  constructor(
    store: ScheduleStore,
    skillExecutor: SkillExecutor,
    notifier: NotificationService,
  ) {
    this.store = store;
    this.skillExecutor = skillExecutor;
    this.notifier = notifier;
  }

  /**
   * 全スケジュールを初期化（アプリ起動時）
   */
  async initialize(): Promise<void> {
    const schedules = await this.store.getAll();

    for (const schedule of schedules) {
      if (schedule.enabled) {
        this.activateSchedule(schedule);
      }
    }
  }

  /**
   * スケジュールを追加
   */
  async addSchedule(
    schedule: Omit<ScheduledSkill, "id" | "runHistory">,
  ): Promise<ScheduledSkill> {
    const newSchedule: ScheduledSkill = {
      ...schedule,
      id: uuidv4(),
      runHistory: [],
      nextRun: this.calculateNextRun(schedule.schedule),
    };

    await this.store.save(newSchedule);

    if (newSchedule.enabled) {
      this.activateSchedule(newSchedule);
    }

    return newSchedule;
  }

  /**
   * スケジュールを有効化
   */
  private activateSchedule(schedule: ScheduledSkill): void {
    if (this.scheduledTasks.has(schedule.id)) {
      this.scheduledTasks.get(schedule.id)?.stop();
    }

    switch (schedule.schedule.type) {
      case "cron":
        if (schedule.schedule.cronExpression) {
          const task = cron.schedule(schedule.schedule.cronExpression, () => {
            this.executeScheduledSkill(schedule);
          });
          this.scheduledTasks.set(schedule.id, task);
        }
        break;

      case "interval":
        if (schedule.schedule.interval) {
          const intervalId = setInterval(() => {
            this.executeScheduledSkill(schedule);
          }, schedule.schedule.interval);
          // Note: node-cronではないのでラッパーが必要
        }
        break;

      case "once":
        if (schedule.schedule.runAt) {
          const delay = schedule.schedule.runAt.getTime() - Date.now();
          if (delay > 0) {
            setTimeout(() => {
              this.executeScheduledSkill(schedule);
              // 実行後は無効化
              this.disableSchedule(schedule.id);
            }, delay);
          }
        }
        break;

      case "event":
        // イベントリスナーを登録
        this.registerEventListener(schedule);
        break;
    }
  }

  /**
   * スケジュールされたスキルを実行
   */
  private async executeScheduledSkill(schedule: ScheduledSkill): Promise<void> {
    const runId = uuidv4();
    const startedAt = new Date();

    try {
      const skill = await this.getSkillMetadata(schedule.skillName);
      const result = await this.skillExecutor.execute(
        { skillName: schedule.skillName, prompt: schedule.prompt },
        skill,
      );

      const runResult: ScheduledRunResult = {
        runId,
        startedAt,
        completedAt: new Date(),
        success: result.success,
        output: result.output,
      };

      await this.store.addRunResult(schedule.id, runResult);

      if (schedule.notification.onSuccess) {
        this.notifier.notify({
          title: `スケジュール実行完了: ${schedule.skillName}`,
          body: "正常に完了しました",
          type: schedule.notification.notificationType,
        });
      }
    } catch (error) {
      const runResult: ScheduledRunResult = {
        runId,
        startedAt,
        completedAt: new Date(),
        success: false,
        error: String(error),
      };

      await this.store.addRunResult(schedule.id, runResult);

      if (schedule.notification.onFailure) {
        this.notifier.notify({
          title: `スケジュール実行失敗: ${schedule.skillName}`,
          body: String(error),
          type: schedule.notification.notificationType,
        });
      }
    }

    // 次回実行時刻を更新
    await this.store.updateNextRun(
      schedule.id,
      this.calculateNextRun(schedule.schedule),
    );
  }
}
```

### 22.3 SkillDebugger 実装

```typescript
export class SkillDebugger {
  private sessions: Map<string, DebugSession> = new Map();
  private pausedResolvers: Map<string, () => void> = new Map();

  /**
   * デバッグセッションを開始
   */
  async startDebugSession(
    skillName: string,
    prompt: string,
    breakpoints: Breakpoint[] = [],
  ): Promise<string> {
    const sessionId = uuidv4();

    const session: DebugSession = {
      sessionId,
      skillName,
      status: "running",
      breakpoints,
      steps: [],
      variables: {},
      currentStepIndex: 0,
    };

    this.sessions.set(sessionId, session);

    // デバッグモードでスキル実行
    this.executeWithDebug(session, prompt);

    return sessionId;
  }

  /**
   * デバッグ実行
   */
  private async executeWithDebug(
    session: DebugSession,
    prompt: string,
  ): Promise<void> {
    const skill = await this.getSkillMetadata(session.skillName);

    const hooks: SDKHooks = {
      PreToolUse: async (input, toolUseId) => {
        // ステップを記録
        const step: DebugStep = {
          stepIndex: session.steps.length,
          timestamp: new Date(),
          type: "tool_call",
          content: {
            toolName: input.toolName,
            toolInput: input.args,
          },
        };
        session.steps.push(step);
        session.currentStepIndex = step.stepIndex;

        // ブレークポイントチェック
        const shouldBreak = this.checkBreakpoints(
          session,
          "tool",
          input.toolName,
        );
        if (shouldBreak) {
          session.status = "paused";
          this.emitDebugEvent(session.sessionId, "paused", step);

          // 再開を待機
          await this.waitForResume(session.sessionId);
          session.status = "running";
        }

        // UIに通知
        this.emitDebugEvent(session.sessionId, "step", step);

        return { proceed: true };
      },

      PostToolUse: async (input, output) => {
        // ツール結果を記録
        const resultStep: DebugStep = {
          stepIndex: session.steps.length,
          timestamp: new Date(),
          type: "tool_result",
          content: {
            toolName: input.toolName,
            toolOutput: output,
          },
        };
        session.steps.push(resultStep);

        this.emitDebugEvent(session.sessionId, "step", resultStep);

        return {};
      },
    };

    try {
      const conversation = query({
        prompt: this.buildPrompt(prompt, skill),
        options: {
          tools: skill.allowedTools || ["Read", "Edit", "Bash"],
          hooks,
        },
      });

      for await (const message of conversation.stream()) {
        // メッセージを記録
        const messageStep: DebugStep = {
          stepIndex: session.steps.length,
          timestamp: new Date(),
          type: "assistant_message",
          content: { message: String(message) },
        };
        session.steps.push(messageStep);
      }

      session.status = "completed";
      this.emitDebugEvent(session.sessionId, "completed", null);
    } catch (error) {
      session.status = "error";
      this.emitDebugEvent(session.sessionId, "error", { error: String(error) });
    }
  }

  /**
   * 一時停止から再開
   */
  resume(sessionId: string): void {
    const resolver = this.pausedResolvers.get(sessionId);
    if (resolver) {
      resolver();
      this.pausedResolvers.delete(sessionId);
    }
  }

  /**
   * ステップ実行（次のツール呼び出しまで実行）
   */
  stepOver(sessionId: string): void {
    const session = this.sessions.get(sessionId);
    if (session) {
      // 一時的なブレークポイントを設定して再開
      session.breakpoints.push({
        id: "temp-step-over",
        type: "tool",
        enabled: true,
      });
      this.resume(sessionId);
    }
  }

  /**
   * 変数を評価
   */
  evaluate(sessionId: string, expression: string): unknown {
    const session = this.sessions.get(sessionId);
    if (!session) return undefined;

    try {
      // 安全な評価（sandboxed）
      const func = new Function("vars", `with(vars) { return ${expression}; }`);
      return func(session.variables);
    } catch {
      return undefined;
    }
  }
}
```

```typescript
export class SkillDocGenerator {
  constructor(
    private skillScanner: SkillScanner,
    private llmClient: LLMClient,
  ) {}

  /**
   * ドキュメントを生成
   */
  async generate(options: DocGenerationOptions): Promise<GeneratedDoc> {
    const skill = await this.skillScanner.getSkill(options.skillName);
    if (!skill) {
      throw new Error(`スキル "${options.skillName}" が見つかりません`);
    }

    const sections: Record<DocSection, string> = {} as Record<
      DocSection,
      string
    >;

    // 各セクションを生成
    for (const section of options.sections) {
      sections[section] = await this.generateSection(skill, section, options);
    }

    // 統合ドキュメントを作成
    const content = this.assembleDocument(sections, options);

    // フォーマット変換
    const formatted = await this.formatDocument(content, options.outputFormat);

    return {
      content: formatted,
      format: options.outputFormat,
      sections,
      generatedAt: new Date(),
    };
  }

  private async generateSection(
    skill: SkillMetadata,
    section: DocSection,
    options: DocGenerationOptions,
  ): Promise<string> {
    const prompts: Record<DocSection, string> = {
      overview: `以下のスキルの概要説明を生成してください：
スキル名: ${skill.name}
説明: ${skill.description}
許可ツール: ${skill.allowedTools.join(", ")}

エージェント: ${skill.agents.map((a) => a.filename).join(", ")}
参照資料: ${skill.references.map((r) => r.filename).join(", ")}

日本語で、技術的だが読みやすい文章で書いてください。`,

      usage: `以下のスキルの使い方を説明してください：
${skill.content}

具体的なコマンド例を含めてください。`,

      api: `以下のスキルのAPI仕様を文書化してください：
許可ツール: ${skill.allowedTools.join(", ")}
エージェント: ${JSON.stringify(skill.agents, null, 2)}

入力パラメータ、出力形式、エラーケースを含めてください。`,

      examples: `以下のスキルの使用例を3つ生成してください：
${skill.content}

実際に使えるコマンド例を含めてください。`,

      troubleshooting: `以下のスキルで発生しうる問題とその解決方法を列挙してください：
${skill.name}
許可ツール: ${skill.allowedTools.join(", ")}`,

      // ... 他のセクション
    };

    const prompt = prompts[section];
    if (!prompt) {
      return "";
    }

    const response = await this.llmClient.generate(prompt);
    return response;
  }

  private assembleDocument(
    sections: Record<DocSection, string>,
    options: DocGenerationOptions,
  ): string {
    const parts: string[] = [];

    parts.push(`# ${options.skillName}`);
    parts.push("");
    parts.push(
      `> 自動生成ドキュメント - ${new Date().toLocaleDateString("ja-JP")}`,
    );
    parts.push("");

    // 目次
    parts.push("## 目次");
    for (const section of options.sections) {
      parts.push(`- [${this.getSectionTitle(section)}](#${section})`);
    }
    parts.push("");

    // 各セクション
    for (const section of options.sections) {
      parts.push(`## ${this.getSectionTitle(section)}`);
      parts.push("");
      parts.push(sections[section]);
      parts.push("");
    }

    return parts.join("\n");
  }

  private getSectionTitle(section: DocSection): string {
    const titles: Record<DocSection, string> = {
      overview: "概要",
      installation: "インストール",
      usage: "使い方",
      configuration: "設定",
      api: "API仕様",
      examples: "使用例",
      troubleshooting: "トラブルシューティング",
      changelog: "変更履歴",
    };
    return titles[section] || section;
  }
}
```

### 24.3 SkillAnalytics 実装

```typescript
export class SkillAnalytics {
  private store: AnalyticsStore;

  constructor(store: AnalyticsStore) {
    this.store = store;
  }

  /**
   * 実行を記録
   */
  async recordExecution(execution: SkillExecution): Promise<void> {
    await this.store.addExecution({
      id: execution.id,
      skillName: execution.skillName,
      startedAt: execution.startedAt,
      completedAt: execution.completedAt,
      success: execution.success,
      duration: execution.completedAt.getTime() - execution.startedAt.getTime(),
      toolsUsed: execution.toolsUsed,
      error: execution.error,
    });
  }

  /**
   * 使用統計を取得
   */
  async getStats(
    skillName: string,
    period: StatsPeriod = { type: "month" },
  ): Promise<SkillUsageStats> {
    const executions = await this.store.getExecutions(skillName, period);

    // 基本統計
    const totalExecutions = executions.length;
    const successfulExecutions = executions.filter((e) => e.success).length;
    const failedExecutions = totalExecutions - successfulExecutions;

    // 時間統計
    const durations = executions.map((e) => e.duration);
    const averageExecutionTime =
      durations.length > 0
        ? durations.reduce((a, b) => a + b, 0) / durations.length
        : 0;

    // ツール使用統計
    const toolUsage: Record<string, number> = {};
    for (const execution of executions) {
      for (const tool of execution.toolsUsed) {
        toolUsage[tool] = (toolUsage[tool] || 0) + 1;
      }
    }

    // 時間帯別分布
    const hourlyDistribution = new Array(24).fill(0);
    for (const execution of executions) {
      const hour = new Date(execution.startedAt).getHours();
      hourlyDistribution[hour]++;
    }

    // エラー分析
    const errorMap = new Map<string, ErrorStat>();
    for (const execution of executions.filter((e) => !e.success)) {
      const errorType = this.categorizeError(execution.error);
      if (!errorMap.has(errorType)) {
        errorMap.set(errorType, {
          errorType,
          count: 0,
          lastOccurred: execution.completedAt,
          examples: [],
        });
      }
      const stat = errorMap.get(errorType)!;
      stat.count++;
      if (stat.examples.length < 3) {
        stat.examples.push(execution.error || "");
      }
      if (execution.completedAt > stat.lastOccurred) {
        stat.lastOccurred = execution.completedAt;
      }
    }

    // トレンドデータ
    const usageTrend = this.calculateTrend(executions, period);

    return {
      skillName,
      period,
      totalExecutions,
      successfulExecutions,
      failedExecutions,
      averageExecutionTime,
      maxExecutionTime: Math.max(...durations, 0),
      minExecutionTime:
        Math.min(...durations, Infinity) === Infinity
          ? 0
          : Math.min(...durations),
      toolUsage,
      mostUsedTools: Object.entries(toolUsage)
        .sort((a, b) => b[1] - a[1])
        .slice(0, 5)
        .map(([tool]) => tool),
      hourlyDistribution,
      dailyDistribution: this.calculateDailyDistribution(executions),
      commonErrors: Array.from(errorMap.values()).sort(
        (a, b) => b.count - a.count,
      ),
      usageTrend,
    };
  }

  /**
   * 全スキルのサマリー
   */
  async getOverallStats(): Promise<OverallStats> {
    const allExecutions = await this.store.getAllExecutions();

    const skillStats = new Map<string, { total: number; success: number }>();

    for (const execution of allExecutions) {
      if (!skillStats.has(execution.skillName)) {
        skillStats.set(execution.skillName, { total: 0, success: 0 });
      }
      const stats = skillStats.get(execution.skillName)!;
      stats.total++;
      if (execution.success) stats.success++;
    }

    return {
      totalExecutions: allExecutions.length,
      uniqueSkillsUsed: skillStats.size,
      mostUsedSkills: Array.from(skillStats.entries())
        .sort((a, b) => b[1].total - a[1].total)
        .slice(0, 10)
        .map(([name, stats]) => ({
          name,
          executions: stats.total,
          successRate: stats.success / stats.total,
        })),
      averageSuccessRate:
        allExecutions.filter((e) => e.success).length / allExecutions.length,
    };
  }
}
```
