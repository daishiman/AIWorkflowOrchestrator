# スキルインポートエージェントシステム

## 概要

`~/.claude/skills/` 配下のスキルをスキャンし、配下の全情報（agents/, references/, scripts/等）を取得してシステムにインポートする機能。

## クイックスタート

### 並列実行可能なフェーズ

```
Phase 2 (サービス層):
  2A: SkillScanner      ─┐
  2B: SkillImportStore   ├── 同時実行可能
  2C: Security Patterns ─┘

Phase 3 (実行エンジン):
  3-1-B: Hooks         ─┐
  3-1-C: PermissionReq  ├── 3-1-A完了後、同時実行可能
  3-2: PermResolver    ─┘

Phase 7 (UIコンポーネント):
  7A: SkillSelector      ─┐
  7B: SkillImportDialog   ├── 同時実行可能
  7C: PermissionDialog   ─┘

Phase 8 (テスト):
  8C-B~D: E2Eテスト群 ─── 8C-A完了後、同時実行可能

Phase 9 (スキル管理拡張):
  9A-A~C: SkillEditor    ─┐
  9B-A~G: skill-creator   ├── 同時実行可能（各サブは順次）
  9C: SkillImprover      ─┘

Phase 10A (ライフサイクル):
  10A-A~C: UI群 ─── 同時実行可能 → 10A-Dで統合
```

### 依存関係チェーン

```
Phase 1 (型定義)
    ↓
Phase 2 (サービス層) ※2A,2B,2C並列可
    ↓
Phase 3 (実行エンジン) ※3-1-A→3-1-B,3-1-C並列可
    ↓
Phase 4 (IPC層)
    ↓
Phase 5 (Preload API)
    ↓
Phase 6 (Zustand)
    ↓
Phase 7 (UIコンポーネント) ※7A,7B,7C並列可
    ↓
Phase 8 (テスト) ※8C-A→8C-B~D並列可
    ↓
Phase 9A/9B/9C (スキル管理拡張) ※並列可
    ↓
Phase 10A (ライフサイクル管理) ※10A-A~C並列可→10A-D
```

Step  5: [4-1]
Step  6: [4-2]
Step  7: [5-1]
Step  8: [6-1]
Step  9: [7A] [7B] [7C]                          ← 3タスク並列
