## クリティカルパス

最も時間がかかる経路（ボトルネック）:

```
00 → 01 → 02 → 04A → 04B or 04C → 09
```

**理由**: 02（large複雑度）と04A（large複雑度）がパス上にあるため、この経路が全体の所要時間を決定する。

## 実行コマンド例

```bash
# Wave 1: 直列実行
skill-creator execute TASK-UI-00
skill-creator execute TASK-UI-01   # 00完了後
skill-creator execute TASK-UI-02   # 01完了後

# Wave 2: 並列実行（02完了後）
skill-creator execute --parallel \
  TASK-UI-03 \
  TASK-UI-04A \
  TASK-UI-05 \
  TASK-UI-06 \
  TASK-UI-07 \
  TASK-UI-08

# Wave 2b: 04A完了後に並列実行
skill-creator execute --parallel \
  TASK-UI-04B \
  TASK-UI-04C

# Wave 3: 全完了後
skill-creator execute TASK-UI-09
```
