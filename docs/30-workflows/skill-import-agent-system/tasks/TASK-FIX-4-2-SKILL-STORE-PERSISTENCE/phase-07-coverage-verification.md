## 1. 目的

Phase 6 で拡充したテスト結果を検証し、ユニットテストおよび統合テストのカバレッジ基準を満たすことを確認する。カバレッジ未達の場合は Phase 6 に戻り、追加テストを作成する。

---

## 2. カバレッジ目標基準

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

---

## 3. 実行タスク

### Task 1: ユニットテストカバレッジ計測

#### 目的

永続化修正に関連するファイルのカバレッジを測定する

#### 手順

1. カバレッジ付きでテストを実行する:

   ```bash
   pnpm --filter @repo/desktop test --coverage SkillImportManager
   ```

2. カバレッジレポートを確認する

3. 以下のファイルのカバレッジを記録する:

   | ファイル                               | Line | Branch | Function |
   | -------------------------------------- | ---- | ------ | -------- |
   | `services/skill/SkillImportManager.ts` | -    | -      | -        |
   | `ipc/skillHandlers.ts`                 | -    | -      | -        |

#### 成果物

- カバレッジ計測結果

#### 完了条件

- [ ] カバレッジが計測されている
- [ ] 各カバレッジ指標が記録されている

---

### Task 2: カバレッジ目標達成確認

#### 目的

計測結果が基準を満たしているか判定する

#### 手順

1. カバレッジ目標と実績を比較する

2. 目標未達の場合は、カバーされていない箇所を特定する

3. 不足箇所に対する追加テスト要否を判断する

#### カバレッジ達成確認チェックリスト

| 指標              | 目標 | 実績 | 達成 |
| ----------------- | ---- | ---- | ---- |
| Line Coverage     | 80%+ | -    | [ ]  |
| Branch Coverage   | 60%+ | -    | [ ]  |
| Function Coverage | 80%+ | -    | [ ]  |

#### 成果物

- カバレッジ達成確認結果

#### 完了条件

- [ ] カバレッジ目標が達成されている
- [ ] または追加テストが必要な箇所が特定されている

---

### Task 3: 統合テスト結果確認

#### 目的

永続化の保存・ロードサイクルが正しく動作することを検証する

#### 手順

1. 統合テストを実行する:

   ```bash
   pnpm --filter @repo/desktop test SkillImportManager.integration
   ```

2. 以下のシナリオが全て PASS することを確認する:

   | シナリオ                          | 結果 |
   | --------------------------------- | ---- |
   | スキルインポート → 保存           | [ ]  |
   | アプリ再起動シミュレーション      | [ ]  |
   | 再起動後 getImported でデータ維持 | [ ]  |
   | 複数スキルの整合性維持            | [ ]  |
   | 空 store からの起動（エラーなし） | [ ]  |

#### 成果物

- 統合テスト実行結果

#### 完了条件

- [ ] 全統合テストが PASS
- [ ] 永続化サイクルが正しく動作している

---

### Task 4: 未達の場合の対応判定

#### 目的

カバレッジ未達または統合テスト失敗時に Phase 6 へ戻る判定を行う

#### 手順

1. カバレッジ基準を満たしているか確認する

2. 統合テストが全て PASS しているか確認する

3. 未達の場合は以下を記録して Phase 6 へ戻る:
   - カバーされていない行・分岐
   - 失敗しているテストケース
   - 追加が必要なテストシナリオ

#### 判定基準

| 状態                          | 判定           |
| ----------------------------- | -------------- |
| カバレッジ達成 & テスト全PASS | Phase 8 へ進む |
| カバレッジ未達                | Phase 6 へ戻る |
| 統合テスト失敗                | Phase 6 へ戻る |

#### 成果物

- Phase 判定結果

#### 完了条件

- [ ] 判定が記録されている

---

### Task 5: カバレッジレポート作成

#### 目的

#### 手順

   - 各指標の実績値
   - カバーされていない箇所（ある場合）
   - 統合テスト結果
   - Phase 判定結果

#### 成果物

- `outputs/phase-07/coverage-report.md`

#### 完了条件

- [ ] カバレッジレポートが作成されている
