## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

SDK正式統合前の暫定措置として、SDK関連のテスト17箇所が `// TODO: SDK統合後に実装` コメント付きで無効化されている。SDK正式統合後もこれらのテストが有効化されておらず、重要な検証が欠落している。

### 1.2 問題点・課題

| テストファイル            | 無効化箇所数 | 未テスト項目                            |
| ------------------------- | ------------ | --------------------------------------- |
| `skill-executor.test.ts`  | 5            | 実行フロー、ストリーミング、abort       |
| `sdk-integration.test.ts` | 3            | SDK呼び出し、レスポンス処理             |
| `agent-client.test.ts`    | 9            | 認証、HTTPエラー(401/500)、タイムアウト |

### 1.3 放置した場合の影響

- 認証エラー（401）のハンドリングが未検証
- サーバーエラー（500）時のフォールバック動作が未検証
- タイムアウト処理（30秒）が未検証
- SDK バージョンアップ時のリグレッション検出不可

---

## 2. 何を達成するか（What）

### 2.1 目的

無効化された17箇所のSDK統合テストを有効化し、テストカバレッジの空白を埋める。

### 2.2 最終ゴール

1. 17箇所のテストが全て有効化されている
2. `// TODO: SDK統合後に実装` コメントが全て除去されている
3. 全テストが PASS

### 2.3 スコープ

#### 含むもの

- 無効化テストの有効化
- テストコードの実装（必要に応じてモック作成）
- TODOコメントの除去

#### 含まないもの

- 新規テストケースの追加
- テストフレームワークの変更

### 2.4 成果物

| 成果物                        | 説明                     |
| ----------------------------- | ------------------------ |
| 有効化されたテストファイル3件 | 17箇所のテストが実行可能 |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-9B-I-SDK-FORMAL-INTEGRATION 完了（`as any` が除去され型安全なSDK統合）

### 3.2 依存タスク

- TASK-9B-I-SDK-FORMAL-INTEGRATION

### 3.3 必要な知識

- Vitest テスト作成
- SDK のモックパターン
- 非同期テスト・ストリーミングテスト

### 3.4 推奨アプローチ

1. 各テストファイルのTODO箇所を特定
2. SDK をモック化してテストを実装
3. ファイルごとに有効化・PASS を確認

## 4. 実行手順

### Step 1: TODO箇所の棚卸し

#### 手順

1. `grep -rn "TODO.*SDK" apps/desktop/src/**/*.test.ts` で全箇所を特定
2. 各箇所の期待動作を分析

### Step 2: テスト実装

#### ファイルごとの方針

**skill-executor.test.ts（5箇所）**:

- SDK `query()` のモック作成
- ストリーミングレスポンスのモック
- abort シグナルのテスト

**sdk-integration.test.ts（3箇所）**:

- SDK 呼び出し→レスポンス処理のE2Eモック
- エラーレスポンスのハンドリング

**agent-client.test.ts（9箇所）**:

- 認証エラー（401）のテスト
- サーバーエラー（500）のテスト
- タイムアウト（30秒）のテスト
- ネットワークエラーのテスト

### Step 3: 全テスト PASS 確認

#### 手順

1. 各ファイル個別にテスト実行
2. テストスイート全体を実行
3. カバレッジ向上を確認

## 9. 備考

### テスト無効化の経緯

SDK 正式リリース前に暫定統合（`as any`）が行われた際、型安全なテストが書けないためTODOコメント付きで無効化された。SDK正式統合（TASK-9B-I）完了後に有効化すべきもの。
