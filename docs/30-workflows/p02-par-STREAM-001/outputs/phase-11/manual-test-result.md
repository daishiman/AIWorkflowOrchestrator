## BLOCKED 理由と代替確認の記録

### BLOCKED 理由

手動テストシナリオ MT-01〜MT-04 はすべて Electron アプリを起動した状態での実行を前提とする。
本 worktree 環境（エージェント実行環境）では Electron アプリの起動・GUI操作が不可能なため、
全シナリオが **BLOCKED** となった。

これはテスト実装の問題ではなく、**実行環境の制約**によるものである。

### ユニットテストによる代替確認

以下のユニットテストケースが各シナリオに相当する動作を保証している。

| MT-ID | 代替ユニットテスト概要                                                                                   | 実装状態                        |
| ----- | -------------------------------------------------------------------------------------------------------- | ------------------------------- |
| MT-01 | `createSkill` に `onProgress` を渡したとき最初の呼び出しが `planning/10%` であること                     | コミット `36ed8ad03` で確認済み |
| MT-02 | `onProgress` が `planning → generating-skill → generating-agents → validating → done` の順で呼ばれること | 同上                            |
| MT-03 | `createSkill` の戻り値がスキルディレクトリパス（文字列）であること                                       | 既存テスト                      |
