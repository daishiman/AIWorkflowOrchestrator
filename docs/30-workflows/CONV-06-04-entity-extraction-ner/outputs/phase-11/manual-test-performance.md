## 7. 環境依存の警告

### 7.1 タイミング変動によるテスト失敗

以下のテストは環境変動により不安定になる場合がある:

| テスト                           | 原因                     |
| -------------------------------- | ------------------------ |
| バッチ vs シーケンシャル比較     | JIT最適化、GCタイミング  |
| 連続処理のパフォーマンス劣化検出 | キャッシュウォームアップ |

**注記**: これらは実装の問題ではなく、テスト設計上の許容範囲。
