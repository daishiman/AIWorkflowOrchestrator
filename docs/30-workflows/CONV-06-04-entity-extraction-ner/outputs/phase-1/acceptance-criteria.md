## 1. 必須機能の受け入れ基準

### 1.1 IEntityExtractor インターフェース

| 基準ID | 基準                                                           | 必須 |
| ------ | -------------------------------------------------------------- | ---- |
| AC-001 | `extract()` メソッドが単一チャンクからエンティティを抽出できる | ✅   |
| AC-002 | `extractBatch()` メソッドが複数チャンクから並列抽出できる      | ✅   |
| AC-003 | `mergeEntities()` メソッドが重複エンティティをマージできる     | ✅   |
| AC-004 | Result型でエラーハンドリングが行われる                         | ✅   |

### 1.2 LLMEntityExtractor

| 基準ID | 基準                                                          | 必須 |
| ------ | ------------------------------------------------------------- | ---- |
| AC-101 | 52種類のエンティティタイプを分類できる                        | ✅   |
| AC-102 | 抽出結果に信頼度スコア（0.0〜1.0）が含まれる                  | ✅   |
| AC-103 | `generateDescriptions: true` 時にエンティティ説明が生成される | ✅   |
| AC-104 | エイリアス（別名）が抽出される                                | ✅   |
| AC-105 | テキスト内の出現位置（Mention）が記録される                   | ✅   |
| AC-106 | ILLMProviderインターフェース経由でLLMを呼び出す               | ✅   |
| AC-107 | JSONパースエラー時に空結果を返却する                          | ✅   |

### 1.3 RuleBasedEntityExtractor

| 基準ID | 基準                                                      | 必須 |
| ------ | --------------------------------------------------------- | ---- |
| AC-201 | 技術名（TypeScript, React等）をパターンマッチで抽出できる | ✅   |
| AC-202 | 組織名（Google, Microsoft等）を抽出できる                 | ✅   |
| AC-203 | 日付パターン（2024-01-15, 2024年1月15日等）を抽出できる   | ✅   |
| AC-204 | 外部依存なしで動作する（純粋関数）                        | ✅   |
| AC-205 | LLM抽出失敗時のフォールバックとして機能する               | ✅   |

### 1.4 バッチ処理

| 基準ID | 基準                                             | 必須 |
| ------ | ------------------------------------------------ | ---- |
| AC-301 | 最大100チャンクのバッチ処理が可能                | ✅   |
| AC-302 | 部分失敗時に成功分を返却し、失敗分をログ記録する | ✅   |
| AC-303 | BatchSummaryに処理統計が含まれる                 | ✅   |
| AC-304 | バッチ全体のタイムアウト（5分）が設定されている  | ✅   |

### 1.5 永続化連携

| 基準ID | 基準                                            | 必須 |
| ------ | ----------------------------------------------- | ---- |
| AC-401 | ExtractedEntityがEntityEntityに正しく変換される | ✅   |
| AC-402 | entitiesテーブルへのINSERT/UPDATEが行われる     | ✅   |
| AC-403 | chunk_entitiesテーブルに関連付けが保存される    | ✅   |
| AC-404 | 既存エンティティの重複検出と更新が行われる      | ✅   |
