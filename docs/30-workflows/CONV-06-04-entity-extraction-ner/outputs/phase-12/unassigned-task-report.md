| テスト                                | 原因                     | 対応 |

| バッチ vs シーケンシャル比較          | JIT最適化、GCタイミング  | 許容 |
| 連続100回処理のパフォーマンス劣化検出 | キャッシュウォームアップ | 許容 |

### 4.2 RuleBasedExtractor の制限事項

| 制限事項               | 対応方針               |

| 日本語組織名（辞書外） | LLM使用推奨            |
| カタカナ技術用語一部   | パターン追加で対応可能 |

**注記**: これらは設計上の想定内であり、LLMEntityExtractor使用時は問題なく抽出可能。
