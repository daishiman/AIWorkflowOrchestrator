**目的**: エンティティ抽出の基本機能を手動で確認する

**実行手順**:

1. サンプルテキストでエンティティ抽出を実行
2. 抽出結果の正確性を確認
3. 各エンティティタイプの抽出を確認
4. 信頼度スコアの妥当性を確認

**期待される成果物**:

- `outputs/phase-11/manual-test-basic.md`

## テストシナリオ

### シナリオ1: 技術文書からのエンティティ抽出

```
入力: 技術ブログ記事（日本語、約2000文字）
期待結果:
- 技術用語（React, TypeScript等）が正しく抽出される
- 人名が正しく抽出される
- 組織名が正しく抽出される
```

### シナリオ2: 会議メモからのエンティティ抽出

```
入力: 会議議事録（日本語、約500文字）
期待結果:
- 参加者名が正しく抽出される
- 議題に関連する概念が抽出される
- 組織・部署名が抽出される
```
