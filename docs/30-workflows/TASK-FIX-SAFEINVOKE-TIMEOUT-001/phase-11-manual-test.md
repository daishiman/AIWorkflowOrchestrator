## 目的

実際の Electron 環境で `safeInvoke` のタイムアウト機構が正しく動作することを手動テストで確認する。

## 実行タスク

### タスク1: 正常動作テスト

**目的**: タイムアウトが正常な操作に影響しないことを確認する

**テストシナリオ**:

| #   | シナリオ          | 手順                               | 期待結果                     |
| --- | ----------------- | ---------------------------------- | ---------------------------- |
| M1  | 設定画面表示      | Settings 画面を開く                | 5秒以内に設定が表示される    |
| M2  | LLMプロバイダ取得 | 設定 > LLM タブを開く              | プロバイダ一覧が表示される   |
| M3  | スキル一覧取得    | エージェント画面でスキル一覧を確認 | スキルが正常に表示される     |
| M4  | 認証初期化        | アプリ起動                         | 認証状態が正常に初期化される |

### タスク2: タイムアウト発動テスト

**目的**: IPC が応答しない場合にタイムアウトが発動することを確認する

**テストシナリオ**:

| #   | シナリオ            | 手順                                  | 期待結果                                             |
| --- | ------------------- | ------------------------------------- | ---------------------------------------------------- |
| M5  | Supabase 未設定環境 | Supabase URL を未設定でアプリ起動     | 認証初期化がタイムアウトし、エラーハンドリングされる |
| M6  | ネットワーク切断    | ネットワーク切断状態で外部API呼び出し | タイムアウトエラーが発生し、UI がブロックされない    |

**検証方法**:

1. DevTools Console を開く
2. `IPC timeout:` を含むエラーメッセージが出力されることを確認
3. UI がフリーズせず、エラー状態が適切に表示されることを確認

### タスク3: DevTools での検証

**目的**: Developer Tools でタイムアウトの動作を直接確認する

**手順**:

1. Electron アプリを起動
2. DevTools Console を開く（`Cmd+Option+I`）
3. 以下のコマンドを実行して応答時間を確認:

```javascript
// 正常なIPC呼び出しの応答時間
console.time("ipc-test");
window.electronAPI.settings.getAll().then((r) => console.timeEnd("ipc-test"));

// タイムアウト時のエラーメッセージ確認（ネットワーク切断時）
window.electronAPI.auth.initialize().catch((e) => console.error(e.message));
```

4. 正常呼び出しが 5000ms 未満で完了することを確認
5. タイムアウト時にエラーメッセージが出力されることを確認
