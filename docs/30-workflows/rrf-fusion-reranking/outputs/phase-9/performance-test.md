## スケーラビリティ分析

### 計算量分析

| 処理                       | 計算量     | 備考               |
| -------------------------- | ---------- | ------------------ |
| RRFFusion.fuse()           | O(n \* m)  | n=結果数, m=戦略数 |
| WeightedScoreFusion.fuse() | O(n \* m)  | n=結果数, m=戦略数 |
| NoOpReranker.rerank()      | O(n)       | n=候補数           |
| ソート処理                 | O(n log n) | n=統合後の結果数   |

### ボトルネック分析

| 処理          | ボトルネック | 最適化可能性   |
| ------------- | ------------ | -------------- |
| Fusion処理    | Mapの操作    | 低（既に最適） |
| Reranking処理 | API呼び出し  | 低（外部依存） |
| ソート処理    | 比較演算     | 低（既に最適） |
