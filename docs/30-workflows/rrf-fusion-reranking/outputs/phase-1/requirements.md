## 1. 概要

本ドキュメントはRRF Fusion + Reranking機能の機能要件を定義する。3つの検索戦略（Keyword/Semantic/Graph）からの結果を統合し、リランキングにより最終順位を決定する機能を実装する。

---

## 2. 機能要件一覧

### 2.1 RRFFusion

Reciprocal Rank Fusion (RRF) アルゴリズムによる検索結果統合。

| ID     | 要件名           | 説明                                                                                    |
| ------ | ---------------- | --------------------------------------------------------------------------------------- |
| FR-001 | 結果セット統合   | 3つの検索戦略（keyword/semantic/graph）からの結果セットを受け取り、統合された結果を返す |
| FR-002 | RRFスコア計算    | `score(d) = Σ (weight_i / (k + rank_i(d)))` の計算式でRRFスコアを算出                   |
| FR-003 | 重み適用         | Query Classifierから提供される各戦略の重み（SearchWeights）を正しく適用                 |
| FR-004 | 重複チャンク統合 | 複数の戦略で出現する同一チャンクを1つにマージし、全ソース情報を保持                     |
| FR-005 | スコア正規化     | fusedScoreを0-1の範囲に正規化（理論最大値で除算）                                       |
| FR-006 | kパラメータ設定  | コンストラクタでRRFのkパラメータを設定可能（デフォルト: 60）                            |
| FR-007 | メタデータマージ | 重複チャンクのメタデータをマージして保持                                                |
| FR-008 | ソース情報記録   | 各結果に対し、元の戦略・ランク・スコアをsources配列に記録                               |

### 2.2 WeightedScoreFusion

重み付きスコア平均による代替統合方式。

| ID     | 要件名             | 説明                                                          |
| ------ | ------------------ | ------------------------------------------------------------- |
| FR-009 | 加重平均スコア計算 | 各戦略のスコアに重みを適用し、加重平均でfusedScoreを計算      |
| FR-010 | 重複チャンク処理   | 重複するチャンクのスコアを正しく統合（重み付き合計 / 総重み） |
| FR-011 | RRF代替機能        | RRFの代わりに使用できる代替統合方式として機能                 |

### 2.3 IReranker インターフェース

リランキング機能の抽象インターフェース。

| ID     | 要件名               | 説明                                                                    |
| ------ | -------------------- | ----------------------------------------------------------------------- |
| FR-012 | インターフェース定義 | `rerank(query, candidates, limit)` メソッドを持つインターフェースを定義 |
| FR-013 | Result型返却         | `Result<FusedSearchResult[], Error>` を返却し、エラーを明示的に伝播     |
| FR-014 | 複数実装対応         | LLM/Cohere/Voyage/NoOpの4種類の実装をサポート                           |

### 2.4 LLMReranker

LLMベースのリランカー実装。

| ID     | 要件名                 | 説明                                                                    |
| ------ | ---------------------- | ----------------------------------------------------------------------- |
| FR-015 | バッチスコアリング     | 候補をバッチサイズ単位でLLMに送信し、関連度スコアを取得                 |
| FR-016 | スコアリングプロンプト | クエリと候補のペアに対し、0-10のスコアをLLMに評価させるプロンプトを構築 |
| FR-017 | スコアパース           | LLMからのカンマ区切りスコアをパースし、0-1に正規化                      |
| FR-018 | フォールバック処理     | LLMエラー時はfusedScoreをそのまま使用してフォールバック                 |
| FR-019 | バッチサイズ設定       | オプションでバッチサイズを設定可能（デフォルト: 10）                    |
| FR-020 | 候補数判定             | 候補数がlimit以下かつalwaysRerankがfalseの場合、リランキングをスキップ  |

### 2.5 CohereReranker

Cohere Rerank APIを使用したリランカー。

| ID     | 要件名             | 説明                                                                     |
| ------ | ------------------ | ------------------------------------------------------------------------ |
| FR-021 | Cohere API呼び出し | `https://api.cohere.ai/v1/rerank` エンドポイントを呼び出し               |
| FR-022 | モデル選択         | コンストラクタでモデルを指定可能（デフォルト: rerank-multilingual-v3.0） |
| FR-023 | 認証ヘッダー       | Bearer認証でAPIキーを送信                                                |
| FR-024 | エラーハンドリング | API応答がエラーの場合、適切なエラーメッセージを返却                      |
| FR-025 | 結果マッピング     | APIレスポンスのindex/relevance_scoreを元の候補にマッピング               |

### 2.6 VoyageReranker

Voyage AI Rerank APIを使用したリランカー。

| ID     | 要件名             | 説明                                                          |
| ------ | ------------------ | ------------------------------------------------------------- |
| FR-026 | Voyage API呼び出し | `https://api.voyageai.com/v1/rerank` エンドポイントを呼び出し |
| FR-027 | モデル選択         | コンストラクタでモデルを指定可能（デフォルト: rerank-2）      |
| FR-028 | 認証ヘッダー       | Bearer認証でAPIキーを送信                                     |
| FR-029 | エラーハンドリング | API応答がエラーの場合、適切なエラーメッセージを返却           |
| FR-030 | 結果マッピング     | APIレスポンスのindex/relevance_scoreを元の候補にマッピング    |

### 2.7 NoOpReranker

フォールバック用のNo-Opリランカー。

| ID     | 要件名             | 説明                                                              |
| ------ | ------------------ | ----------------------------------------------------------------- |
| FR-031 | 順序保持           | 入力候補の順序を変更せずにそのまま返却                            |
| FR-032 | limit適用          | 指定されたlimit件数に切り詰めて返却                               |
| FR-033 | フォールバック用途 | 開発・テスト環境、または外部API不使用時のフォールバックとして使用 |
