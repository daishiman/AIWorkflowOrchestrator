## 1. パフォーマンス要件

### 1.1 レイテンシ

| コンポーネント      | 目標値      | 最大許容値 | 備考                       |
| ------------------- | ----------- | ---------- | -------------------------- |
| RRFFusion.fuse()    | 20ms        | 50ms       | 1000件以下の候補統合       |
| WeightedScoreFusion | 20ms        | 50ms       | 1000件以下の候補統合       |
| LLMReranker         | 外部API依存 | 30秒       | バッチサイズ・モデルに依存 |
| CohereReranker      | 外部API依存 | 10秒       | Cohere APIレスポンス時間   |
| VoyageReranker      | 外部API依存 | 10秒       | Voyage APIレスポンス時間   |
| NoOpReranker        | 1ms         | 5ms        | 順序変更なし               |

### 1.2 スループット

| 項目               | 目標値      | 備考                         |
| ------------------ | ----------- | ---------------------------- |
| 同時リクエスト処理 | 100 req/s   | Fusion処理のみ               |
| バッチ処理効率     | 10件/バッチ | LLMRerankerのバッチサイズ    |
| メモリ使用量       | 100MB以下   | 1回のFusion/Rerank処理あたり |

### 1.3 スケーラビリティ

| 項目           | 対応方針                              |
| -------------- | ------------------------------------- |
| 候補数増加     | ストリーミング処理可能な設計          |
| 検索戦略追加   | Map型のresultSetsで任意数の戦略に対応 |
| リランカー追加 | IRerankerインターフェースで拡張可能   |

---

## 2. 可用性要件

### 2.1 フォールバック戦略

| 障害ポイント      | フォールバック動作                              |
| ----------------- | ----------------------------------------------- |
| Cohere API障害    | LLMRerankerまたはNoOpRerankerに切り替え         |
| Voyage AI API障害 | LLMRerankerまたはNoOpRerankerに切り替え         |
| LLM API障害       | fusedScoreをそのまま使用（rerankedScore未設定） |
| 全リランカー障害  | NoOpRerankerでfusedScore順序を維持              |

### 2.2 タイムアウト設定

| コンポーネント | タイムアウト | リトライ回数 |
| -------------- | ------------ | ------------ |
| CohereReranker | 10秒         | 1回          |
| VoyageReranker | 10秒         | 1回          |
| LLMReranker    | 30秒         | 0回          |

### 2.3 エラーハンドリング

| エラー種別         | 処理方針                                   |
| ------------------ | ------------------------------------------ |
| ネットワークエラー | Result.errでラップして呼び出し元に伝播     |
| APIレート制限      | エラーを返却（リトライは呼び出し元の責務） |
| 不正レスポンス     | パースエラーとして処理、デフォルト値で継続 |
