## 3. 統合ポイント

### 3.1 入力統合ポイント

| 入力元                | 提供データ             | 型               |
| --------------------- | ---------------------- | ---------------- |
| KeywordSearchStrategy | キーワード検索結果     | `SearchResult[]` |
| VectorSearchStrategy  | セマンティック検索結果 | `SearchResult[]` |
| GraphSearchStrategy   | グラフ検索結果         | `SearchResult[]` |
| QueryClassifier       | 検索重み               | `SearchWeights`  |

### 3.2 出力統合ポイント

| 出力先            | 提供データ           | 型                    |
| ----------------- | -------------------- | --------------------- |
| CRAGEvaluator     | リランキング済み結果 | `FusedSearchResult[]` |
| HybridRAGSearcher | 最終検索結果         | `FusedSearchResult[]` |

### 3.3 外部API統合

| API                  | 用途                      | 認証方式         |
| -------------------- | ------------------------- | ---------------- |
| Cohere Rerank API    | Cross-Encoderリランキング | Bearer Token     |
| Voyage AI Rerank API | Cross-Encoderリランキング | Bearer Token     |
| LLM API (各種)       | LLMベースリランキング     | プロバイダー依存 |

## 5. 拡張性設計

### 5.1 Fusion戦略の拡張

新しいFusion戦略を追加する場合:

1. `IFusionStrategy` インターフェースを実装
2. 新しいクラスを `fusion/` ディレクトリに配置
3. `index.ts` からエクスポート

```typescript
// 将来の拡張例
class CombMNZFusion implements IFusionStrategy {
  fuse(resultSets, weights): FusedSearchResult[];
}
```

### 5.2 Rerankerの拡張

新しいRerankerを追加する場合:

1. `IReranker` インターフェースを実装
2. 新しいクラスを `reranking/` ディレクトリに配置
3. `index.ts` からエクスポート

```typescript
// 将来の拡張例
class JinaReranker implements IReranker {
  rerank(query, candidates, limit): Promise<Result<FusedSearchResult[], Error>>;
}
```
