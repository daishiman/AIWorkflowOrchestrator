## 目的

静的解析、セキュリティ、パフォーマンスの観点からコード品質を検証する。

## 背景

リファクタリング後のコードが品質基準を満たしているか、多角的な観点から検証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析（Lint）

**目的**: ESLintによるコード品質チェック

**実行手順**:

1. ESLintを実行:

   ```bash
   pnpm --filter @repo/shared lint
   ```

2. エラー・警告がないことを確認

3. 問題があれば修正

**期待される成果物**:

- `outputs/phase-9/lint-results.md` - Lint実行結果

---

### タスク2: 型チェック

**目的**: TypeScript型チェックによる型安全性検証

**実行手順**:

1. 型チェックを実行:

   ```bash
   pnpm --filter @repo/shared typecheck
   ```

2. 型エラーがないことを確認

3. 問題があれば修正

**期待される成果物**:

- `outputs/phase-9/typecheck-results.md` - 型チェック結果

---

### タスク3: コードフォーマット

**目的**: Prettierによるコードフォーマット確認

**実行手順**:

1. フォーマットチェックを実行:

   ```bash
   pnpm --filter @repo/shared format:check
   ```

2. フォーマット違反がないことを確認

3. 問題があれば修正:
   ```bash
   pnpm --filter @repo/shared format
   ```

**期待される成果物**:

- `outputs/phase-9/format-results.md` - フォーマットチェック結果

---

### タスク4: セキュリティチェック

**目的**: セキュリティ脆弱性の検出

**実行手順**:

1. 以下のセキュリティ観点を確認:

| #   | チェック項目                               | 確認結果 | 備考 |
| --- | ------------------------------------------ | -------- | ---- |
| 1   | APIキーがハードコードされていない          |          |      |
| 2   | 入力値の検証が適切に行われている           |          |      |
| 3   | エラーメッセージに機密情報が含まれていない |          |      |
| 4   | 外部APIへの接続がHTTPSを使用している       |          |      |
| 5   | ログに機密情報が出力されていない           |          |      |

2. 問題があれば修正

**期待される成果物**:

- `outputs/phase-9/security-check.md` - セキュリティチェック結果

---

### タスク5: パフォーマンステスト

**目的**: パフォーマンス要件の検証

**実行手順**:

1. 以下のパフォーマンス基準を確認:

| #   | テスト項目                | 目標値  | 実測値 | 判定 |
| --- | ------------------------- | ------- | ------ | ---- |
| 1   | RRF Fusion（100件入力）   | < 50ms  |        |      |
| 2   | RRF Fusion（1000件入力）  | < 200ms |        |      |
| 3   | NoOpReranker（100件入力） | < 10ms  |        |      |

2. 目標値を超過する場合は最適化を検討

**期待される成果物**:

- `outputs/phase-9/performance-test.md` - パフォーマンステスト結果

---

### タスク6: 全テスト再実行

**目的**: 品質修正後もテストが全て通ることを確認する

**実行手順**:

1. 全テストを実行:

   ```bash
   pnpm --filter @repo/shared test -- --testPathPattern="fusion|reranking"
   ```

2. 全テストが成功することを確認

3. 結果を記録

**期待される成果物**:

- `outputs/phase-9/all-tests-results.md` - 全テスト実行結果
