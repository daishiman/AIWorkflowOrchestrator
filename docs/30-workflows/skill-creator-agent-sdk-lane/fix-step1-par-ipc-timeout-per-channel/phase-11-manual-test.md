## 目的

自動テストでは確認しにくい実際の IPC 呼び出し動作を手動で検証する。

---

## 前提条件

- アプリケーションがローカルで起動している
- DevTools が使用可能（console.log の確認用）
- タイムアウト値を確認できる環境（ログまたは trace）がある

---

## 手動テスト手順

### シナリオ MT-001: デフォルトタイムアウトの動作確認

1. アプリを起動する
2. DevTools の Console で `getChannelTimeout("unknown:test")` を評価する
3. `5000` が返ることを確認する

### シナリオ MT-002: auth:login タイムアウトの確認

1. ログインボタンを押す
2. DevTools の Network または console で `auth:login` の IPC 呼び出しを確認する
3. タイムアウト設定が 500ms であることをログで確認する

### シナリオ MT-003: skill:execute タイムアウトの確認

1. スキル実行フローを開始する
2. DevTools の Console で `getChannelTimeout("skill:execute")` を評価する
3. `60000` が返ることを確認する
4. スキル実行が 60 秒以内に正常に完了することを確認する

### シナリオ MT-004: 後方互換性の確認

1. 既存の IPC 呼び出しフロー（auth 以外）が正常に動作することを確認する
2. タイムアウト変更によって既存機能に影響がないことを確認する
