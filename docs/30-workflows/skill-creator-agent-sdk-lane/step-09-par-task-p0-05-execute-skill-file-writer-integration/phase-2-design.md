## 目的

LLM 応答パーサー、SkillGeneratedContent 型変換、persist() 呼び出しフロー、エラーハンドリングを設計する。

- LLM 応答パーサーのアルゴリズムを設計する（コードブロック抽出、メタデータ解析）
- SkillGeneratedContent 型のフィールド構造を設計する
- execute() 内のフロー（LLM呼び出し → パース → 型変換 → persist → 結果反映）を設計する
- エラーケース（パース失敗、persist 失敗）のハンドリングフローを設計する
- ExecuteResult 拡張フィールドを設計する
