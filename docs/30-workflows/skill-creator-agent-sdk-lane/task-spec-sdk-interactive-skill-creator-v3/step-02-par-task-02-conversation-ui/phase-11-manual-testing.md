## 目的

Electron アプリを実際に起動し、UI コンポーネントが期待通りに動作することを手動で確認する。  
自動テストでは検証しにくい視覚的な動作・UX・レイアウトを重点的に確認する。

## 事前準備

```bash
# Electron アプリを開発モードで起動
pnpm --filter @repo/desktop dev
```

TASK-SDK-SC-01（SDK Session Bridge）が稼働していることを確認する。  
スキル生成インタビューを開始できる状態にする。

## 手動テストケース

### MT-01: 選択式質問が表示・回答できること

**テストシナリオ**: `single_select` タイプの質問が正しく表示・操作できること

| ステップ | 操作                                                     | 期待する動作                                     |
| -------- | -------------------------------------------------------- | ------------------------------------------------ |
| 1        | スキル生成インタビューを開始する                         | `SkillCreatorConversationPanel` が表示される     |
| 2        | 質問カードが表示されるまで待機する                       | 質問テキストと選択肢ボタンが表示される           |
| 3        | 選択肢ボタンが縦に並んでいることを確認する               | 各選択肢が視覚的に区別できる状態で表示される     |
| 4        | 末尾の選択肢が「その他（自由入力）」であることを確認する | 破線ボーダーで区別されている                     |
| 5        | 通常の選択肢（「その他」以外）をクリックする             | ボタンが選択済みスタイルに変化し、次の質問に進む |
| 6        | `ConversationProgress` が更新されることを確認する        | 「質問 2 / 10」のように番号が進む                |

**確認ポイント**: 選択後に即座に次の質問が表示されること（multi_select とは異なり送信ボタン不要）

---

### MT-02: 「その他」選択時に自由入力フォームに切り替わること

**テストシナリオ**: 「その他（自由入力）」選択時の UX が正常であること

| ステップ | 操作                                               | 期待する動作                                                       |
| -------- | -------------------------------------------------- | ------------------------------------------------------------------ |
| 1        | `single_select` タイプの質問が表示されるまで待機   | 選択肢ボタン一覧が表示される                                       |
| 2        | 末尾の「その他（自由入力）」ボタンをクリックする   | テキストエリアが展開表示される                                     |
| 3        | テキストエリアに任意のテキストを入力する           | 入力中はリアルタイムに文字が反映される                             |
| 4        | Enter キーを押す（Shift なし）                     | 入力したテキストが回答として送信され、次の質問に進む               |
| 5        | 次の質問で「その他」以外の通常選択肢をクリックする | テキストエリアが閉じて選択肢表示に戻る（選択後に即座に次の質問へ） |
| 6        | Shift+Enter で改行が挿入されることを確認する       | 改行のみが挿入され、送信されない                                   |

**確認ポイント**: 「その他」選択後に他の選択肢に切り替えるとテキストエリアが閉じること

---

### MT-03: 10ターン完了でスキル生成に進むこと

**テストシナリオ**: インタビューの全質問を回答してスキル生成フェーズに移行すること

| ステップ | 操作                                                         | 期待する動作                                                        |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------------- |
| 1        | インタビューを開始し、各質問に回答し続ける                   | 「質問 N / 10」の N が 1 ずつ増加していく                           |
| 2        | `confirm` タイプの質問が表示されたとき「はい」をクリックする | 「はい」ボタンがハイライトされ、次の質問に進む                      |
| 3        | `secret` タイプの質問が表示されたとき値を入力する            | パスワードマスク（●●●）で表示される                                 |
| 4        | 全ての質問に回答する（推定10問）                             | スキル生成フェーズへ移行する（`onComplete` コールバックが呼ばれる） |
| 5        | 進捗バーが 100% 近くまで伸びることを確認する                 | プログレスバーが視覚的に完了に近い状態を示す                        |

**確認ポイント**: 最後の質問回答後にパネルがスキル生成画面に遷移すること

---

### MT-04: `multi_select` タイプの複数選択動作確認

**テストシナリオ**: 複数選択 UI が正常に動作すること

| ステップ | 操作                                            | 期待する動作                                                 |
| -------- | ----------------------------------------------- | ------------------------------------------------------------ |
| 1        | `multi_select` タイプの質問が表示されるまで待機 | 選択肢ボタンと送信ボタンが表示される                         |
| 2        | 複数の選択肢をクリックする                      | クリックした選択肢が選択済みスタイルに変化する（トグル動作） |
| 3        | 同じ選択肢を再度クリックする                    | 選択が解除されて未選択スタイルに戻る                         |
| 4        | 「送信」ボタンをクリックする                    | 選択中の全選択肢が配列として送信され、次の質問に進む         |
| 5        | 何も選択せずに「送信」ボタンをクリックする      | 「送信」ボタンが無効化されていてクリックできない             |

---

### MT-05: `isSubmitting` 時の UI 無効化確認

**テストシナリオ**: 回答送信中に重複送信が防止されること

| ステップ | 操作                                         | 期待する動作                                                   |
| -------- | -------------------------------------------- | -------------------------------------------------------------- |
| 1        | 通常の選択肢をクリックして回答を送信する     | 送信処理中に全ての ChoiceButton が無効化される（opacity 低下） |
| 2        | 送信処理中に別の選択肢をクリックしようとする | クリックが無視される（`disabled` 状態のため）                  |
| 3        | 次の質問が受信されたとき                     | 無効化が解除され、新しい選択肢がクリックできる状態になる       |
