## 目的

Phase 5 の実装（仕様書更新）に対して、drift 再発観点の検証を追加する。Phase 4 で定義したテストマトリックスを実行し、更新漏れ・新規 drift の発生がないことを確認する。

## 実行タスク

- Phase 4 のテストマトリックスを実行し、結果を記録する
- SDK-04 の path drift 解消後に残存 stale path がないことを確認する
- SDK-02 の wording 更新後に未完了表現がないことを確認する
- docs-only 制約（コード変更なし）を再確認する
- 更新漏れや予期しない変更がないことを確認する

## テスト拡張観点

| 観点                 | 確認内容                                                                     |
| -------------------- | ---------------------------------------------------------------------------- |
| 残存 stale path      | Phase 5 で更新した 4 ファイル以外に stale path が残っていないか              |
| 参照整合性           | SDK-04 修正後のリンク先ファイルが実際に存在するか                            |
| wording 一貫性       | SDK-02 修正後に system spec 内で「future」「予定」等の表現が混在していないか |
| 連鎖 drift の確認    | 今回の修正が他のドキュメントの導線を壊していないか                           |
| no-op ファイルの確認 | 変更していないファイルに意図しない変更が入っていないか                       |
