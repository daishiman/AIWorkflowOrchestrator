## 概念解説（中学生レベル）

### IPC と fire-and-forget とは？

**IPC (Inter-Process Communication)** とは、アプリケーションの異なる部分（レンダラーとメインプロセス）が通信するための仕組みです。

**fire-and-forget（撃ったら忘れる）** とは、処理を開始したらすぐに次に進む方式です。

例えば：

- 誰かに手紙を送る時、返信を待たずに次の仕事を続ける = fire-and-forget
- 返信が届いたら別の通知（手紙）で教えてもらう = `AUTH_STATE_CHANGED` イベント

今回の修正では:

- 「ログイン開始しました（`{ success: true }`）」とすぐ返す
- ログインが完了したら「ログイン完了しました（`AUTH_STATE_CHANGED`）」と別途通知する
