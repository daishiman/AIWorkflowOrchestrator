# Phase 11: 手動テスト

## メタ情報

| 項目   | 値                                         |
| ------ | ------------------------------------------ |
| Phase  | 11                                         |
| 機能名 | auth:login IPCハンドラーの非ブロッキング化 |
| 作成日 | 2026-04-01                                 |

## 目的

スキル生成ボタン押下時に `auth:login` タイムアウトエラーが発生しないことを手動で確認する。

## 事前条件

- アプリケーションが起動している
- スキル生成機能にアクセスできる状態である
- ブラウザの開発者ツール（または Electron の DevTools）でコンソールを確認できる

## テスト手順

### シナリオ 1: スキル生成ボタン押下 → エラーなし確認

```
1. アプリケーションを起動する
2. DevTools のコンソールを開く
3. スキル生成ボタンを押下する
4. コンソールに以下のエラーが表示されないことを確認する:
   "IPC timeout: auth:login did not respond within 5000ms"
5. OAuth 認証フローが開始される（ブラウザウィンドウが開く等）ことを確認する
```

| 確認項目         | 期待結果               | 実際の結果 |
| ---------------- | ---------------------- | ---------- |
| コンソールエラー | タイムアウトエラーなし | TBD        |
| OAuth フロー開始 | 認証画面が表示される   | TBD        |

### シナリオ 2: OAuth 認証完了後の状態確認

```
1. シナリオ 1 に続いて OAuth 認証を完了させる
2. アプリケーションが認証状態に遷移することを確認する
3. スキル生成処理が続行されることを確認する
```

| 確認項目       | 期待結果                       | 実際の結果 |
| -------------- | ------------------------------ | ---------- |
| 認証状態遷移   | ログイン後状態に切り替わる     | TBD        |
| スキル生成継続 | 認証後にスキル生成が続行される | TBD        |

### シナリオ 3: OAuth 認証キャンセル時の動作確認

```
1. スキル生成ボタンを押下する
2. OAuth 認証画面をキャンセルまたは閉じる
3. アプリケーションが適切なエラー状態に遷移することを確認する
4. "auth:login タイムアウト" エラーが発生しないことを確認する
```

| 確認項目               | 期待結果               | 実際の結果 |
| ---------------------- | ---------------------- | ---------- |
| キャンセル時エラー表示 | タイムアウトエラーなし | TBD        |
| 状態の整合性           | 未認証状態が維持される | TBD        |
