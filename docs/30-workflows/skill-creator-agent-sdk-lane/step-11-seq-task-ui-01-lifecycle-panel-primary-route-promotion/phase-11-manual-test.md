## 目的

自動テストでは検証が困難なナビゲーション動作、視覚的なレイアウト、ユーザー体験を手動で確認する。スクリーンショットで証跡を残す。

## 実行タスク

### Task 1: デスクトップナビゲーション動作確認

- メインナビゲーション「スキル作成」をクリックし、SkillLifecyclePanel が表示されることを確認
- SkillLifecyclePanel の初期状態（会話型インタビュー開始画面）が正しく表示されることを確認
- SkillCreateWizard への導線（存在する場合）が機能することを確認
- SkillManagementPanel → LifecyclePanel の既存導線が機能することを確認
- スクリーンショットを撮影

### Task 2: ナビゲーション遷移確認

- LifecyclePanel → 他画面 → LifecyclePanel の遷移が正常であることを確認
- 戻る/進む操作時のルーティングが正常であることを確認
- LifecyclePanel 上で作成フロー（plan → review → execute）の開始が可能であることを確認
- スクリーンショットを撮影

### Task 3: モバイルビュー確認（レスポンシブ）

- ブラウザのレスポンシブモードまたは DevTools でモバイルサイズに変更
- モバイルナビゲーションから LifecyclePanel にアクセスできることを確認
- レイアウトが崩れていないことを確認
- スクリーンショットを撮影

### Task 4: エッジケース手動確認

- アプリケーション起動直後のナビゲーション動作
- 複数タブ/ウィンドウでの同時アクセス
- ネットワーク遅延時の表示挙動（可能な範囲で）

### Task 5: テスト結果記録

- 全テスト結果を `outputs/phase-11/manual-test-result.md` にまとめる
- スクリーンショットを `outputs/phase-11/screenshots/` に保存
