# Manual Test Checklist

| ID    | 観点             | 実施内容                                  |
| ----- | ---------------- | ----------------------------------------- |
| MT-01 | verify detail    | status / nextAction / provenance が読める |
| MT-02 | improve list     | suggestion selection が動く               |
| MT-03 | apply result     | applied / skipped / error が読める        |
| MT-04 | re-verify        | apply 後に再検証起点が見える              |
| MT-05 | terminal_handoff | guidance と manual boundary が読める      |
