## 目的

Electron アプリ上でスタブ → エラー変換が正しく動作し、ユーザーに適切なエラーメッセージが表示されることを手動で確認する。

## 実行タスク

- llmAdapter 未注入状態でスキル作成を実行し、エラー表示を確認する
- resourceLoader 未設定状態でスキル作成を実行し、エラー表示を確認する
- 正常系（llmAdapter & resourceLoader 正常）でスキル作成が成功することを確認する
- エラーメッセージの文言・表示位置が UX として適切であることを確認する
- テスト結果を記録する

## 実行手順

### ステップ1: Electron アプリを起動する

```bash
pnpm --filter @repo/desktop dev
```

### ステップ2: llmAdapter 未注入テスト

1. llmAdapter を未設定の状態にする（設定画面で API キーを削除、または環境変数を未設定にする）。
2. スキル作成ウィザードを開く。
3. スキル仕様を入力して「作成」を押す。
4. **期待結果**: エラーメッセージ「LLM アダプタが利用できません。設定を確認してください。」が表示される。
5. 空のスキル名・空のエージェントリストが表示されないことを確認する。

### ステップ3: resourceLoader 未設定テスト

1. llmAdapter は設定済み、resourceLoader を無効化する。
2. スキル作成を実行する。
3. **期待結果**: エラーメッセージ「リソースローダーが利用できません。」が表示される。

### ステップ4: 正常系テスト

1. llmAdapter & resourceLoader を正常に設定する。
2. スキル作成を実行する。
3. **期待結果**: 正常にスキルが作成され、スキル名・エージェントリストが表示される。
4. エラーメッセージが表示されないことを確認する。

### ステップ5: UX 確認

- エラーメッセージの文言がユーザーフレンドリーであること。
- エラー表示位置が適切であること（モーダル / インライン / トースト）。
- エラー状態からの回復パス（設定変更 → 再試行）が明確であること。

### ステップ6: テスト結果を記録する

- `{outputs/phase-11/manual-test-result.md` にテスト結果を記録する。
- 発見された問題は `{outputs/phase-11/discovered-issues.md` に記録する。
