## FR-1: 履歴一覧表示

### AC-1.1: 履歴一覧の初期表示

| 項目     | 内容                                                 |
| -------- | ---------------------------------------------------- |
| 前提条件 | ファイルID（履歴が存在するファイル）が指定されている |
| 操作     | 履歴ページにアクセスする                             |
| 期待結果 | 履歴一覧が表示される（最新順、最大20件）             |
| 成功条件 | バージョン番号、作成日時、ファイルサイズが表示される |
| 失敗条件 | データ取得エラーでエラーメッセージが表示される       |

### AC-1.2: 最新バージョンの識別

| 項目     | 内容                                         |
| -------- | -------------------------------------------- |
| 前提条件 | 履歴一覧が表示されている                     |
| 操作     | 一覧を確認する                               |
| 期待結果 | 最新バージョンに「現在」バッジが表示される   |
| 成功条件 | isLatest=trueのアイテムにバッジが表示される  |
| 失敗条件 | バッジが表示されない、または複数に表示される |

### AC-1.3: ページネーション

| 項目     | 内容                                       |
| -------- | ------------------------------------------ |
| 前提条件 | 履歴が21件以上存在する                     |
| 操作     | 「さらに読み込む」ボタンをクリック         |
| 期待結果 | 追加の20件が一覧に追加される               |
| 成功条件 | hasMore=trueの場合のみボタンが表示される   |
| 失敗条件 | 読み込み失敗でインラインエラーが表示される |

### AC-1.4: 履歴なしの表示

| 項目     | 内容                                         |
| -------- | -------------------------------------------- |
| 前提条件 | 履歴が存在しないファイルIDが指定されている   |
| 操作     | 履歴ページにアクセスする                     |
| 期待結果 | 「履歴がありません」のEmptyStateが表示される |
| 成功条件 | EmptyStateコンポーネントが表示される         |
| 失敗条件 | 空の一覧やエラーが表示される                 |

## FR-2: バージョン詳細表示

### AC-2.1: 詳細パネル表示

| 項目     | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| 前提条件 | 履歴一覧が表示されている                                           |
| 操作     | 履歴アイテムをクリック                                             |
| 期待結果 | 右側に詳細パネルが表示される                                       |
| 成功条件 | conversionId, version, createdAt, size, mimeType, hashが表示される |
| 失敗条件 | 詳細取得エラーでエラーメッセージが表示される                       |

### AC-2.2: 変換ログ表示

| 項目     | 内容                                            |
| -------- | ----------------------------------------------- |
| 前提条件 | バージョン詳細パネルが表示されている            |
| 操作     | 詳細パネルを確認する                            |
| 期待結果 | 変換ログ一覧が表示される                        |
| 成功条件 | timestamp, level（バッジ）, messageが表示される |
| 失敗条件 | ログが表示されない                              |

## FR-3: ログフィルタリング

### AC-3.1: フィルタ適用

| 項目     | 内容                                    |
| -------- | --------------------------------------- |
| 前提条件 | 変換ログが表示されている                |
| 操作     | フィルタドロップダウンで「error」を選択 |
| 期待結果 | errorレベルのログのみが表示される       |
| 成功条件 | level=errorのログのみがフィルタされる   |
| 失敗条件 | 他レベルのログが混在する                |

### AC-3.2: フィルタ解除

| 項目     | 内容                                       |
| -------- | ------------------------------------------ |
| 前提条件 | フィルタが適用されている                   |
| 操作     | フィルタドロップダウンで「すべて」を選択   |
| 期待結果 | 全レベルのログが表示される                 |
| 成功条件 | info, warn, error, debugすべてが表示される |
| 失敗条件 | 一部のログが欠落する                       |

## FR-4: バージョン復元

### AC-4.1: 確認ダイアログ表示

| 項目     | 内容                                              |
| -------- | ------------------------------------------------- |
| 前提条件 | 履歴一覧または詳細パネルが表示されている          |
| 操作     | 「復元」ボタンをクリック                          |
| 期待結果 | 確認ダイアログが表示される                        |
| 成功条件 | バージョン情報と確認/キャンセルボタンが表示される |
| 失敗条件 | ダイアログが表示されない                          |

### AC-4.2: 復元実行

| 項目     | 内容                                           |
| -------- | ---------------------------------------------- |
| 前提条件 | 確認ダイアログが表示されている                 |
| 操作     | 「確認」ボタンをクリック                       |
| 期待結果 | 復元処理が実行され、成功後にダイアログが閉じる |
| 成功条件 | isSuccess=trueで履歴一覧が更新される           |
| 失敗条件 | エラーメッセージがダイアログ内に表示される     |

### AC-4.3: 復元キャンセル

| 項目     | 内容                                   |
| -------- | -------------------------------------- |
| 前提条件 | 確認ダイアログが表示されている         |
| 操作     | 「キャンセル」ボタンをクリック         |
| 期待結果 | ダイアログが閉じ、復元は実行されない   |
| 成功条件 | ダイアログが閉じ、履歴一覧に変更がない |
| 失敗条件 | 復元が実行される                       |

### AC-4.4: 最新バージョン復元制限

| 項目     | 内容                                            |
| -------- | ----------------------------------------------- |
| 前提条件 | 最新バージョン（isLatest=true）が選択されている |
| 操作     | 「復元」ボタンを確認                            |
| 期待結果 | 復元ボタンが無効化されているか、非表示          |
| 成功条件 | 最新バージョンは復元不可                        |
| 失敗条件 | 最新バージョンに対して復元が可能                |

## 統合テスト受け入れ基準

### AC-INT-1: IPC通信

| 項目     | 内容                                       |
| -------- | ------------------------------------------ |
| 前提条件 | アプリケーションが起動している             |
| 操作     | 履歴ページにアクセスする                   |
| 期待結果 | history:getFileHistoryが正常に呼び出される |
| 成功条件 | DevToolsのConsoleにエラーがない            |
| 失敗条件 | IPC通信エラーが発生する                    |

### AC-INT-2: データフロー

| 項目     | 内容                                                  |
| -------- | ----------------------------------------------------- |
| 前提条件 | 履歴データがデータベースに存在する                    |
| 操作     | 履歴一覧を取得                                        |
| 期待結果 | Renderer → preload → Main → Service → DB → 逆順で返却 |
| 成功条件 | データベースのデータが画面に表示される                |
| 失敗条件 | データが取得できない、または不正なデータが表示される  |

### AC-INT-3: エラーハンドリング

| 項目     | 内容                                               |
| -------- | -------------------------------------------------- |
| 前提条件 | HistoryServiceがエラーを返す                       |
| 操作     | 履歴一覧を取得                                     |
| 期待結果 | エラーメッセージが画面に表示される                 |
| 成功条件 | { success: false, error: {...} }が正しく処理される |
| 失敗条件 | 未処理例外が発生する                               |
