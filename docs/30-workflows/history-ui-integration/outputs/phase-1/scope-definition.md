## 2. スコープ外（含まないもの）

### 2.1 実装しないもの

| 項目                 | 理由                         |
| -------------------- | ---------------------------- |
| 新機能の追加         | 既存コンポーネントの統合のみ |
| パフォーマンス最適化 | 仮想スクロール等は将来対応   |
| UIデザインの変更     | 既存デザインを維持           |
| 認証・認可機能       | 履歴機能に認証は不要         |
| 多言語対応           | 現時点では日本語のみ         |
| オフライン対応       | オンライン前提で設計         |

### 2.2 変更しないもの

| 項目                     | 理由                 |
| ------------------------ | -------------------- |
| 既存コンポーネントの実装 | CONV-05-03で完了済み |
| 既存フックの実装         | CONV-05-03で完了済み |
| HistoryServiceの実装     | CONV-05-02で完了済み |
| データベーススキーマ     | CONV-05-01で完了済み |
| 他画面への影響           | 履歴画面のみを対象   |
