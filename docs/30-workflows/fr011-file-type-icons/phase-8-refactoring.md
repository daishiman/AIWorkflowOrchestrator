**目的**: 拡張子マッピングの重複を整理する

**実行手順**:

1. 拡張子マッピング定義を確認
2. 重複定義と不要な条件分岐を削除
3. `outputs/phase-8/refactor-log.md` に整理内容を記載

**期待される成果物**:

- `outputs/phase-8/refactor-log.md`

### タスク2: コンポーネント構造整理

**目的**: FileTypeIconと既存コンポーネントの責務分離を確認する

**実行手順**:

1. FileTypeIconの責務とpropsの見直し
2. Iconコンポーネントの型定義の整理
3. 変更内容を `outputs/phase-8/refactor-log.md` に記載

**期待される成果物**:

- `outputs/phase-8/refactor-log.md`

---

### タスク3: リファクタ後のテスト確認
