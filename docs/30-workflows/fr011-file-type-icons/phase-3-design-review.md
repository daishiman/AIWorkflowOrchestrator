## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 要件適合レビュー

**目的**: 要件と設計の差分を確認する

**実行手順**:

1. Phase 1の要件と受け入れ基準を確認
2. Phase 2の設計内容と比較
3. 差分と課題を `outputs/phase-3/design-review-result.md` に記載

**期待される成果物**:

- `outputs/phase-3/design-review-result.md`

---

### タスク2: UI/UX設計レビュー

**目的**: UI/UX仕様に沿った設計か確認する

**実行手順**:

1. アイコンサイズと色設計がUI/UX仕様に一致しているか確認
2. FileTreeItemとSelectableFileTreeItemの統合が妥当か確認
3. 指摘事項をレビュー結果に記載

**期待される成果物**:

- `outputs/phase-3/design-review-result.md`

---

### タスク3: 実装準備レビュー

**目的**: 実装の影響範囲と変更箇所が明確か確認する

**実行手順**:

1. Iconコンポーネントの型拡張が設計に反映されているか確認
2. 変更対象ファイルが一覧化されているか確認
3. 判定をレビュー結果に記載

**期待される成果物**:

- `outputs/phase-3/design-review-result.md`
