## 手動テストケース

### 1. 基本操作テスト

#### 1.1 埋め込み挿入

```typescript
// テストシナリオ
// 1. テスト用のchunkを作成
// 2. Float32Arrayベクトルを生成
// 3. insertEmbeddingsBatchで挿入
// 4. 正常に挿入されることを確認
```

- [x] 単一の埋め込みが挿入できる
- [x] バッチで複数の埋め込みが挿入できる
- [x] 重複するchunkIdでエラーになる

#### 1.2 ベクトル検索

```typescript
// テストシナリオ
// 1. テストデータをセットアップ
// 2. クエリベクトルを生成
// 3. searchByVectorで検索
// 4. 結果が期待通りか確認
```

- [x] コサイン類似度検索が動作する
- [x] ユークリッド距離検索が動作する
- [x] 内積検索が動作する
- [x] limitオプションが機能する
- [x] minSimilarityオプションが機能する
- [x] fileIdsフィルターが機能する

### 2. エッジケーステスト

#### 2.1 境界値テスト

- [x] 空のベクトル（0次元）でエラーになる
- [x] 次元数が異なるベクトルでエラーになる
- [x] limit=0で空の結果が返る
- [x] minSimilarity=1.0で完全一致のみ返る

#### 2.2 大量データテスト

- [x] 1,000件の埋め込みで検索が動作する
- [x] 10,000件の埋め込みで検索時間が50ms以内
- [x] バッチ挿入が100件単位で分割される

### 3. エラーハンドリングテスト

- [x] 存在しないchunkIdでエラーになる
- [x] 不正なベクトル形式でエラーになる
- [x] データベース接続エラー時の挙動

### 4. カスケード削除テスト

- [x] chunkを削除すると関連するembeddingも削除される
- [x] トランザクション内での削除が正しく動作する
