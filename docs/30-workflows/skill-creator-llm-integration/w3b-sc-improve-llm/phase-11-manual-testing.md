## 目的

実際の Anthropic API を使って improve() を呼び出し、LLM による改善提案が正しく生成・返却されることを確認する。

## 実行タスク

1. 手動テスト環境の準備
   - Anthropic API キーが設定されていることを確認
   - 既存のスキル（例: `test-skill`）が存在することを確認
2. 手動テストシナリオ MT-1: 基本的な改善提案生成
   - 操作: IPC 経由または直接 improve("test-skill", "このスキルの説明をより明確にしてください") を呼び出す
   - 期待結果: section, before, after, reason を含む改善提案が1件以上返される
   - 確認: JSON が正しいフォーマットであることを確認
3. 手動テストシナリオ MT-2: 改善提案の SKILL.md への適用
   - 操作: MT-1 で得た改善提案を承認し applyImprovement() を呼び出す
   - 期待結果: SKILL.md の該当箇所が更新される
   - 確認: 更新後の SKILL.md ファイルを直接確認
4. 手動テストシナリオ MT-3: 存在しないスキルへの呼び出し
   - 操作: improve("non-existent-skill", "改善してください") を呼び出す
   - 期待結果: SKILL_NOT_FOUND エラーが返される
5. 手動テストシナリオ MT-4: 実際の LLM レスポンス品質確認
   - 具体的なフィードバック（例: 「使用例をもっと追加してください」）を入力
   - 返された提案が実際に意味のある内容かを確認
6. テスト結果を本ファイルに記録する
