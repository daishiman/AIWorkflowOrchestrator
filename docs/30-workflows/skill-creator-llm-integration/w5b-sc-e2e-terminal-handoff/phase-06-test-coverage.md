## 目的

Phase 4 の5シナリオでは網羅しきれなかった境界値・負荷・タイムアウト系のテストを追加し、E2Eレベルでの品質を強化する。

## 実行タスク

1. **同時実行テスト**
   - 複数の `skill-creator:plan` を同時に呼び出した場合に正しく処理されること
   - 競合状態（Race Condition）が発生しないことを確認する
   - 2回の同時呼び出しで、それぞれ独立したレスポンスが返ること

2. **大量入力テスト**
   - スキル名が最大長（例: 255文字）の場合に正しく処理されること
   - スキルの説明文が非常に長い場合（10,000文字）のパフォーマンス確認
   - 特殊文字（日本語・記号・絵文字）を含む入力の正常処理確認

3. **長時間タイムアウトテスト**
   - plan が 30秒を超えた場合にタイムアウトエラーが返ること
   - execute が 120秒を超えた場合にタイムアウトエラーが返ること
   - タイムアウト後にアプリがクラッシュしないこと（NFR-4）
   - P13対策: タイマーテストは `advanceTimersByTime` を使用する

4. **セキュリティテスト**（NFR-1）
   - エラーレスポンスにシステム内部情報（スタックトレース・ファイルパス）が含まれないこと
   - `suggestedCommand` にシェルインジェクション可能な文字列が含まれないこと
   - APIキーがレスポンスに含まれないこと

5. **ネットワーク切断テスト**
   - LLM API への接続が途中で切断された場合に `NETWORK_ERROR` が返ること
   - 切断後に再接続試行が行われること
