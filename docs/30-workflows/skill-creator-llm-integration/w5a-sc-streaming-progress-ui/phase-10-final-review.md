## 目的

AC-3（進捗ストリーミング）・AC-6（エラーメッセージ）の充足を多角的に検証し、PASS / MINOR / MAJOR / CRITICAL の判定を行う。MINOR 指摘は必ず未タスク仕様書に変換する。

## 実行タスク

1. **AC-3（進捗ストリーミング）の検証**
   - SKILL_CREATOR_PROGRESS イベントを受け取り、UIがリアルタイムで更新されること
   - 4段階（構造計画中→SKILL.md生成中→agents生成中→バリデーション中）が正しい順序で表示されること
   - `percent` 値に応じてプログレスバーが正しく動作すること

2. **AC-6（エラーメッセージ）の検証**
   - API Key 未設定エラー時に設定画面への誘導が表示されること
   - LLMエラー時にリトライボタンが表示されること
   - ネットワークエラー時にオフライン表示が出ること
   - エラーメッセージにシステム内部情報（スタックトレース等）が漏洩していないこと（セキュリティ）

3. **P5（リスナー二重登録）対策の最終確認**
   - コンポーネントのアンマウント・再マウント時にリスナーが正しく管理されていること

4. **P31・P48 対策の最終確認**
   - Zustand 個別セレクタが正しく使用されていること
   - `useShallow` が必要な箇所に適用されていること

5. **アクセシビリティ確認**
   - プログレスバーに `aria-valuenow` / `aria-valuemin` / `aria-valuemax` が設定されていること
   - エラーメッセージに `role="alert"` が設定されていること
   - キャンセルボタンに適切なラベルが設定されていること

6. **総合判定**
   - PASS: Phase 11 へ
   - MINOR: 指摘事項を未タスク仕様書に変換後 Phase 11 へ（省略不可）
   - MAJOR / CRITICAL: 影響範囲に応じて Phase 1-5 へ戻る
