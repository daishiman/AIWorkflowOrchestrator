## 目的

Phase 4 では網羅しきれなかった境界値・異常系・タイミング系テストを追加し、カバレッジ基準（Line 80%以上 / Branch 60%以上 / Function 80%以上）を達成する。

## 実行タスク

1. **進捗100%未到達でのストリーム切断テスト**
   - `percent` が 80% の状態でストリームが切断された場合のUI確認
   - `NETWORK_ERROR` エラーが表示されること
   - プログレスバーが 80% で停止したまま表示されること

2. **高速連続更新時のUI安定性テスト**
   - 100ms 未満の間隔で進捗イベントが連続して届いた場合のUI安定性確認
   - レンダリングデバウンス（P13対策: `advanceTimersByTime` を使用）
   - 最終的な表示が最後のイベントと一致することを確認

3. **境界値テスト**
   - `percent` = 0 / 50 / 100 の各境界でのプログレスバー表示
   - `previewContent` = `null` / 空文字列 / 長文（100行超）の各ケース
   - `message` が空文字列の場合のフォールバック表示

4. **リスナー登録・解除テスト**
   - コンポーネントのアンマウント時にリスナーが解除されること（P5対策）
   - 再マウント時に二重登録されないこと

5. **エラー → リトライ → 成功フローテスト**
   - `LLM_ERROR` 後にリトライボタンを押すと生成が再開されること
   - リトライ後に進捗が 0% からリスタートすること
