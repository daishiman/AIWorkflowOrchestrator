## 目的

実際のElectronアプリを操作し、ストリーミング進捗UIが正しく動作することを手動で確認する。P53（CLI環境でのスクリーンショット取得制約）を考慮した代替検証方法を使用する。

## 実行タスク

1. **スキル生成中のプログレスバー動作確認**
   - スキル生成ウィザードを開き、最終ステップ（GenerateStep）に進む
   - 生成開始後、プログレスバーが 0% から動き始めること
   - 各段階（構造計画中→SKILL.md生成中→agents生成中→バリデーション中）でステップ表示が更新されること
   - 生成完了時にプログレスバーが 100% になること

2. **エラー時のリトライボタン表示確認**
   - LLMエラーをシミュレートする（テスト用の不正APIキーを使用）
   - エラーメッセージとリトライボタンが表示されること
   - リトライボタン押下で生成が再試行されること

3. **キャンセルで中断されることの確認**
   - スキル生成中にキャンセルボタンを押す
   - 生成が中断され、「キャンセルしました」メッセージが表示されること
   - ウィザードが先頭ステップに戻ること（または閉じること）

4. **API Key 未設定時の設定画面誘導確認**
   - API Key を削除した状態でスキル生成を試みる
   - 設定画面への誘導リンク付きエラーメッセージが表示されること
   - リンク押下で設定画面が開くこと

5. **P53対策: CLI環境での代替検証**
   - スクリーンショットが取得できない場合は、Playwright の `page.screenshot()` を使用する
   - または、自動テストの実行ログを視覚確認の代替証跡とする
