## 目的

エッジケースや異常系のテストを追加し、テストカバレッジを向上させる。

## 背景

Phase 5で基本実装が完了したが、エッジケースや異常系のテストが不足している。
テストカバレッジを向上させることで、本番環境での予期せぬエラーを防止する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: エッジケーステスト追加

**目的**: 境界値や特殊な入力に対するテストを追加する

**実行手順**:

1. 以下のテストケースを実装

| TC-ID    | テストケース                 | 対象                      | 期待結果       |
| -------- | ---------------------------- | ------------------------- | -------------- |
| TC-6-001 | 空文字のskillIdで実行        | skillAPI.execute          | エラーを返す   |
| TC-6-002 | nullパラメータで実行         | skillAPI.execute          | 正常に実行     |
| TC-6-003 | 非常に長いskillIdで実行      | skillAPI.execute          | エラーを返す   |
| TC-6-004 | 不正な形式のパラメータで実行 | SkillService.executeSkill | エラーを返す   |
| TC-6-005 | キャッシュにないスキルの実行 | SkillService.executeSkill | スキャン後実行 |

2. テストコードを実装
3. `outputs/phase-6/edge-case-tests.md` に結果を出力

**期待される成果物**:

- エッジケーステスト

---

### タスク2: 異常系テスト追加

**目的**: エラー発生時の動作を確認するテストを追加する

**実行手順**:

1. 以下のテストケースを実装

| TC-ID    | テストケース                    | 期待動作               |
| -------- | ------------------------------- | ---------------------- |
| TC-6-006 | IPC通信タイムアウト             | エラーメッセージを返す |
| TC-6-007 | スキル実行中の例外発生          | エラーステータスで返す |
| TC-6-008 | 無効なBrowserWindowでの呼び出し | UNAUTHORIZED エラー    |
| TC-6-009 | DevToolsからの呼び出し          | FORBIDDEN エラー       |

2. テストコードを実装
3. `outputs/phase-6/error-handling-tests.md` に結果を出力

**期待される成果物**:

- 異常系テスト

---

### タスク3: 統合テストシナリオ追加

**目的**: エンドツーエンドのテストシナリオを追加する

**実行手順**:

1. 以下のシナリオテストを実装

| TC-ID    | シナリオ                         | 期待動作           |
| -------- | -------------------------------- | ------------------ |
| TC-6-010 | スキル一覧→選択→実行の完全フロー | 成功トースト表示   |
| TC-6-011 | 存在しないスキルの実行           | エラートースト表示 |
| TC-6-012 | 連続実行のテスト                 | 順次実行される     |

2. テストコードを実装
3. `outputs/phase-6/integration-test-scenarios.md` に結果を出力

**期待される成果物**:

- 統合テストシナリオ

---

### タスク4: テスト実行とカバレッジ確認

**目的**: テストを実行してカバレッジを確認する

**実行手順**:

1. テストを実行

```bash
pnpm --filter @repo/desktop test -- --coverage
```

2. カバレッジレポートを確認
3. `outputs/phase-6/coverage-report.md` に結果を出力

**期待される成果物**:

- カバレッジレポート
