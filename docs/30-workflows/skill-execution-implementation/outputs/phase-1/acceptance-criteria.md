## AC-01: スキル選択と実行

### 基準

Agent画面でスキルを選択し「実行」ボタンをクリックできる

### 検証手順

1. アプリケーションを起動する
2. サイドバーから「Agent」を選択する
3. スキル一覧から任意のスキルをクリックする
4. 詳細パネルが表示されることを確認
5. 「実行」ボタンが表示されていることを確認
6. 「実行」ボタンをクリックする
7. スキルが実行されることを確認（コンソールログまたはトースト）

### 合格条件

- スキル選択後、詳細パネルに「実行」ボタンが表示される
- ボタンクリックでスキル実行リクエストがIPCを通じて送信される

---

## AC-02: ローディングインジケータ

### 基準

実行中はローディングインジケータが表示される

### 検証手順

1. スキルを選択する
2. 「実行」ボタンをクリックする
3. ボタンまたは周辺にローディングインジケータが表示されることを確認
4. 実行完了後、ローディングインジケータが消えることを確認

### 合格条件

- 実行開始から完了までローディング状態が視覚的にわかる
- ローディング中は適切なUI変化（スピナー、ボタンの状態変化等）がある

---

## AC-03: 成功トースト

### 基準

実行成功時に「スキルを実行しました」トーストが表示される

### 検証手順

1. 正常に実行可能なスキルを選択する
2. 「実行」ボタンをクリックする
3. 実行が完了するのを待つ
4. 緑色の成功トーストが表示されることを確認
5. トースト内容が「スキルを実行しました」または同等のメッセージであることを確認
6. 5秒後にトーストが自動消去されることを確認

### 合格条件

- 成功時に緑色のトーストが表示される
- メッセージ内容が適切である
- 5秒後に自動消去される

---

## AC-04: エラートースト

### 基準

実行失敗時にエラーメッセージがトーストで表示される

### 検証手順

1. 実行時にエラーが発生するスキルを用意（またはモック）
2. 「実行」ボタンをクリックする
3. エラーが発生するのを待つ
4. 赤色のエラートーストが表示されることを確認
5. エラーメッセージにエラー詳細が含まれることを確認

### 合格条件

- 失敗時に赤色のトーストが表示される
- エラーメッセージが具体的で理解可能である
- 5秒後に自動消去される

---

## AC-05: 実行中の再実行無効化

### 基準

実行中は再実行ボタンが無効化される

### 検証手順

1. スキルを選択する
2. 「実行」ボタンをクリックする
3. 実行中にボタンが無効化されていることを確認
4. 実行中にボタンをクリックしても反応しないことを確認
5. 実行完了後にボタンが有効化されることを確認

### 合格条件

- 実行中はボタンがdisabled状態になる
- 実行完了後にボタンが再度有効になる

## AC-09: IPC sender検証

### 基準

IPC sender検証が実装されている

### 検証方法

1. skill:execute ハンドラーのコードレビュー
2. validateIpcSender が呼び出されていることを確認
3. 不正な送信元からのリクエストが拒否されることをユニットテストで確認

### 合格条件

- validateIpcSender による検証が実装されている
- 許可されていないウィンドウからのリクエストが拒否される
- ユニットテストでセキュリティ検証がカバーされている

## 統合テスト連携要件

### IPC通信要件

| 接続ポイント              | 検証内容                           |
| ------------------------- | ---------------------------------- |
| skillAPI.execute          | Renderer から Preload への呼び出し |
| skill:execute チャンネル  | Preload から Main への IPC 通信    |
| SkillService.executeSkill | Main プロセス内のサービス呼び出し  |

### 統合テストシナリオ

1. **正常系**: スキル実行成功フロー
   - skillAPI.execute 呼び出し
   - IPC 通信成功
   - SkillService 実行成功
   - 成功レスポンス返却

2. **異常系**: スキル実行失敗フロー
   - skillAPI.execute 呼び出し
   - IPC 通信成功
   - SkillService 実行失敗
   - エラーレスポンス返却

3. **セキュリティ**: 不正アクセス拒否
   - 許可されていないウィンドウからの呼び出し
   - sender 検証失敗
   - エラースロー
