## 1. 機能要件の受け入れ基準

### 1.1 Preload API

| 要件ID | 要件                       | 受け入れ基準                                                   | 検証方法       |
| ------ | -------------------------- | -------------------------------------------------------------- | -------------- |
| FR-001 | onStream コールバック登録  | `skillAPI.onStream(callback)` を呼ぶとコールバックが登録される | ユニットテスト |
| FR-002 | onStream クリーンアップ    | 戻り値の関数を呼ぶとリスナーが解除される                       | ユニットテスト |
| FR-003 | メッセージ受信             | `skill:stream` からのメッセージがコールバックに渡される        | 統合テスト     |
| FR-004 | executionId フィルタリング | React Hook で現在の executionId のメッセージのみ処理される     | ユニットテスト |
| FR-005 | abort 呼び出し             | `skillAPI.abort(executionId)` が成功すると true が返される     | ユニットテスト |
| FR-006 | abort 失敗                 | 存在しない executionId で abort すると false が返される        | ユニットテスト |

### 1.2 React Hook (useSkillExecution)

| 要件ID | 要件           | 受け入れ基準                                                        | 検証方法       |
| ------ | -------------- | ------------------------------------------------------------------- | -------------- |
| FR-007 | 初期状態       | status が "idle"、messages が空配列                                 | ユニットテスト |
| FR-008 | 実行開始時     | execute() 呼び出しで status が "running" に変化                     | ユニットテスト |
| FR-009 | メッセージ蓄積 | ストリームメッセージ受信時に messages 配列に追加される              | ユニットテスト |
| FR-010 | メッセージ順序 | 受信順序通りにメッセージが配列に格納される                          | ユニットテスト |
| FR-011 | 完了状態       | type: "complete" 受信時に status が "completed" に変化              | ユニットテスト |
| FR-012 | エラー状態     | type: "error" 受信時に status が "error" に変化                     | ユニットテスト |
| FR-013 | 中断状態       | abort() 呼び出し後、中断メッセージ受信で status が "aborted" に変化 | ユニットテスト |
| FR-014 | リセット       | reset() 呼び出しで初期状態に戻る                                    | ユニットテスト |

### 1.3 UI コンポーネント

| 要件ID | 要件                    | 受け入れ基準                                                   | 検証方法         |

| FR-019 | error メッセージ表示    | type: "error" のメッセージがエラーとして強調表示される         | スナップショット |
| FR-020 | 中断ボタン表示          | status が "running" の時のみ中断ボタンが表示される             | ユニットテスト   |
