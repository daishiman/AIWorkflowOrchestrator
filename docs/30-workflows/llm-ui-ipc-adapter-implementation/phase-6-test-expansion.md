## 目的

Phase 5の実装に対してテストを拡充し、カバレッジ目標を達成する。

## 背景

TDDのGreenフェーズ後、リファクタリングに進む前にテストカバレッジを十分に確保し、接続不良による画面未表示などの不具合を事前に防止する。

## 実行手順

### 1. カバレッジ測定

```bash
pnpm --filter @repo/desktop test:coverage
```

### 2. ギャップ分析

- 未到達の行/分岐/関数を特定
- 統合テスト不足領域を特定

### 3. 追加テスト作成

- ユニット/統合/E2Eの不足分を追加
- フロント・バックエンド接続経路を優先

### 4. 統合テスト再実行

```bash
pnpm --filter @repo/desktop test:run
```
