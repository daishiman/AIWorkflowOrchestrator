## 実装ガイド概要

### Part 1: 概念的説明

**LLMアダプターシステムとは?**

複数のAIプロバイダー（OpenAI、Anthropic、Google、xAI）を統一されたインターフェースで扱うための「翻訳者」のような仕組み。

**比喩で説明:**
電源アダプターが世界中の異なるコンセント形状を統一するように、LLMアダプターは各AIプロバイダーの異なるAPIを統一された形式に変換する。

```
ユーザー → 統一リクエスト → アダプター → 各プロバイダーAPI
                              ↓
ユーザー ← 統一レスポンス ← アダプター ← 各プロバイダーAPI
```
