# Phase 3: 設計レビュー

## 目的

Phase 2 の設計を 30思考法と 4条件でレビューし、spec 再構成方針を確定する。

## レビュー観点

| 系統         | 主な思考法                                                           | 本 task での使用目的                            |
| ------------ | -------------------------------------------------------------------- | ----------------------------------------------- |
| 論理分析系   | 批判的思考、演繹思考、帰納的思考、アブダクション、垂直思考           | 実コードと仕様書の矛盾抽出                      |
| 構造分解系   | 要素分解、MECE、2軸思考、プロセス思考                                | phase / artifact / gate の再配置                |
| メタ・抽象系 | メタ思考、抽象化思考、ダブル・ループ思考                             | 個別修正でなく骨格再整列へ導く                  |
| 発想・拡張系 | ブレインストーミング、水平思考、逆説思考、類推思考、if思考、素人思考 | `NON_VISUAL code task` 再分類と理解容易性の向上 |
| システム系   | システム思考、因果関係分析、因果ループ                               | 命名揺れと close-out 漏れの因果を断つ           |
| 戦略・価値系 | トレードオン思考、プラスサム思考、価値提案思考、戦略的思考           | 全面破棄ではなく高影響箇所優先の再構成          |
| 問題解決系   | why思考、改善思考、仮説思考、論点思考、KJ法                          | 真因をテンプレート逸脱へ集約する                |

## Gate 判定

| 判定項目 | 条件                                                             |
| -------- | ---------------------------------------------------------------- |
| PASS     | 仕様書群を既存実装ベースで再構成する方針が一貫している           |
| MINOR    | 文言修正のみ残る                                                 |
| MAJOR    | task 分類、artifact registry、Phase 11/12 の再設計が不足している |
