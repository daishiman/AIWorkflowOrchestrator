## 3. テスト要件

### 3.1 機能要件（FR）

| FR-ID | 要件                 | 受け入れ基準                                 | 優先度 |
| ----- | -------------------- | -------------------------------------------- | ------ |
| FR-01 | 履歴一覧表示         | ファイルの変換履歴が一覧で表示されること     | 高     |
| FR-02 | ローディング状態表示 | データ取得中にスケルトンが表示されること     | 高     |
| FR-03 | 空状態表示           | 履歴がない場合に適切なメッセージが表示される | 中     |
| FR-04 | バージョン選択       | 履歴アイテムクリックで詳細パネルが表示される | 高     |
| FR-05 | バージョン詳細表示   | 選択バージョンの詳細情報が表示されること     | 高     |
| FR-06 | 変換ログ表示         | 変換ログが時系列で表示されること             | 中     |
| FR-07 | ログレベルフィルタ   | ログレベルでフィルタできること               | 中     |
| FR-08 | 追加読み込み         | 「もっと見る」で追加データが読み込まれること | 中     |
| FR-09 | 復元ダイアログ表示   | 復元ボタンで確認ダイアログが表示されること   | 高     |
| FR-10 | バージョン復元       | 確認後にバージョンが復元されること           | 高     |
| FR-11 | 復元キャンセル       | キャンセルでダイアログが閉じること           | 中     |

### 3.2 非機能要件（NFR）

| NFR-ID | 要件カテゴリ     | 要件                   | 受け入れ基準                                 |
| ------ | ---------------- | ---------------------- | -------------------------------------------- |
| NFR-01 | アクセシビリティ | WCAG 2.1 AA準拠        | キーボードのみで全操作可能                   |
| NFR-02 | アクセシビリティ | スクリーンリーダー対応 | VoiceOverで適切に読み上げられる              |
| NFR-03 | アクセシビリティ | フォーカス管理         | ダイアログ開閉時にフォーカスが適切に移動する |
| NFR-04 | アクセシビリティ | ARIA属性               | 適切なrole/aria属性が設定されている          |
| NFR-05 | エラー処理       | エラーメッセージ表示   | API障害時にエラーメッセージが表示される      |
| NFR-06 | エラー処理       | 再試行機能             | エラー時に再試行ボタンが表示される           |
