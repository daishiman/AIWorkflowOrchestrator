## 目的

手動テスト実施の結果をドキュメント化し、技術的な理解を促進するドキュメントを作成し、未完了タスクを検出・記録する。

## 背景

Phase 11で手動テストが完了し、テスト結果と発見課題が記録されている状態。これらの成果物を整理し、将来のメンテナンスのための実装ガイドを作成するとともに、残課題を検出して未タスクとして記録する。

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 実装ガイド作成【必須】

**目的**: 手動テスト実施方法を2パート構成でドキュメント化する。

**実行手順**:

**Part 1: 概念的説明（初学者・非技術者向け）**

1. 手動テストの目的と重要性を説明
   - なぜ自動テストだけでは不十分なのか
   - 手動テストで確認できること
2. テスト対象機能の概要を説明
   - 履歴表示機能とは何か
   - ユーザーにとっての価値
3. テストカテゴリの説明
   - 機能テスト: 正しく動作するか
   - エラーハンドリング: 問題時の対応
   - アクセシビリティ: 誰でも使えるか

**Part 2: 技術的詳細（開発者・技術者向け）**

1. テスト対象コンポーネントの詳細
   - コンポーネント構成と責務
   - カスタムフックの役割
   - IPCチャンネルの設計
2. テスト実行手順の詳細
   - 環境準備コマンド
   - テストケースの実行方法
   - 結果の記録方法
3. トラブルシューティング
   - よくある問題と解決方法
   - デバッグ手法

**期待される成果物**:

- `outputs/phase-12/implementation-guide.md`

   ```markdown
   | ---------- | ----------- | ------------------------ |
   | 2026-01-XX | Claude Code | 手動テスト実装ガイド作成 |
   | 2026-01-XX | Claude Code | テスト結果レポート作成   |

   ## 更新ファイル一覧

   | ファイル                                 | 更新種別 | 説明                   |
   | ---------------------------------------- | -------- | ---------------------- |
   | outputs/phase-11/manual-test-result.md   | 新規作成 | 手動テスト結果レポート |
   | outputs/phase-11/discovered-issues.md    | 新規作成 | 発見課題リスト         |
   | outputs/phase-12/implementation-guide.md | 新規作成 | 手動テスト実装ガイド   |

   ## 関連システム仕様

   本タスクで参照・更新したシステム仕様:

   - `.claude/skills/aiworkflow-requirements/references/ui-ux-history-panel.md`
   ```

**期待される成果物**:

### タスク3: 未タスク検出【必須】

**目的**: 手動テストで発見された課題を未タスクとして記録する。

**実行手順**:

1. 以下のソースから未完了タスクを検出
   | # | ソース | 確認項目 |
   | --- | --- | --- |
   | 1 | Phase 11テスト結果 | FAILになったテストケース |
   | 2 | Phase 11発見課題 | 重要度「高」の課題 |
   | 3 | アクセシビリティ結果 | WCAG違反項目 |

2. 検出結果を`outputs/phase-12/unassigned-task-report.md`に記録

   ```markdown
   # 未タスク検出レポート

   ## 検出日: 2026-01-XX

   ## 検出結果サマリー

   | ソース           | 検出数  |
   | ---------------- | ------- |
   | テスト結果       | X件     |
   | 発見課題         | X件     |
   | アクセシビリティ | X件     |
   | **合計**         | **X件** |

   ## 検出タスク一覧

   ### 1. [タスク名]

   - **発見元**: Phase 11 テスト結果
   - **内容**: [課題の詳細]
   - **優先度**: 高/中/低
   - **未タスク指示書**: `docs/30-workflows/unassigned-task/task-xxx.md`

   ## 未タスク指示書作成状況

   | タスク名 | 指示書パス                                    | 作成状態        |
   | -------- | --------------------------------------------- | --------------- |
   | xxx      | docs/30-workflows/unassigned-task/task-xxx.md | 作成済み/未作成 |
   ```

3. 検出された課題が重大な場合、未タスク指示書を作成
   - 配置先: `docs/30-workflows/unassigned-task/`
   - テンプレート: `.claude/skills/task-specification-creator/assets/unassigned-task-template.md`

**期待される成果物**:

- `outputs/phase-12/unassigned-task-report.md`【必須】
- 未タスク指示書（課題検出時のみ）
