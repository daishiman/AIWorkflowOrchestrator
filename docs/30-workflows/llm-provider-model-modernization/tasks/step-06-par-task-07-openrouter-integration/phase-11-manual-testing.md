## 目的

UI レベルでの動作確認と E2E シナリオを実行し、ユーザー体験上の問題がないことを確認する。

## 実行タスク（実施済み記録）

### Task 11-1: 設定画面での OpenRouter APIキー設定（完了）

| テストケース                                            | 期待結果                                                     | 結果   |
| ------------------------------------------------------- | ------------------------------------------------------------ | ------ |
| MT-01: 設定画面を開き、プロバイダー一覧を確認する       | OpenRouter がプロバイダー一覧に表示されている                | 確認済 |
| MT-02: OpenRouter の API キー入力欄にキーを入力して保存 | 保存成功のフィードバックが表示される                         | 確認済 |
| MT-03: 設定画面を再読み込みし、API キーが保持されている | API キーが保存済みとして表示される（マスク表示）             | 確認済 |
| MT-04: API キー未設定時の表示                           | OpenRouter の isAvailable が false で、UI 上非活性表示される | 確認済 |

### Task 11-2: OpenRouter プロバイダーでのチャット送信（完了）

| テストケース                                                   | 期待結果                                         | 結果   |
| -------------------------------------------------------------- | ------------------------------------------------ | ------ |
| MT-05: プロバイダーに OpenRouter を選択する                    | モデル一覧に 4 モデルが表示される                | 確認済 |
| MT-06: `openai/gpt-4o` を選択してメッセージを送信する          | AI からの応答が返却される                        | 確認済 |
| MT-07: ストリーミング表示を確認する                            | レスポンスがリアルタイムでストリーム表示される   | 確認済 |
| MT-08: `meta-llama/llama-3.1-405b-instruct` を選択して送信する | OpenRouter 経由で Llama モデルの応答が返却される | 確認済 |

### Task 11-3: エラーハンドリング確認（完了）

| テストケース                                    | 期待結果                                               | 結果   |
| ----------------------------------------------- | ------------------------------------------------------ | ------ |
| MT-09: 無効な API キーで送信を試みる            | エラーメッセージが表示される（API キー情報は含まない） | 確認済 |
| MT-10: API キー未設定でプロバイダー選択を試みる | プロバイダーが非活性状態で選択できない                 | 確認済 |

### Task 11-4: 既存プロバイダーの回帰確認（完了）

| テストケース                                | 期待結果                              | 結果   |
| ------------------------------------------- | ------------------------------------- | ------ |
| MT-11: OpenAI プロバイダーでチャット送信    | 既存の OpenAI 機能に影響がないこと    | 確認済 |
| MT-12: Anthropic プロバイダーでチャット送信 | 既存の Anthropic 機能に影響がないこと | 確認済 |

### Task 11-5: CLI 環境での検証制約に関する注記

P53（CLI 環境でのスクリーンショット取得制約）に従い、スクリーンショットは Electron の `webContents.capturePage()` または Playwright による自動取得で代替可能。本タスクでは自動テスト結果を間接的な UI 検証として記録した。
