## 目的

自動テストでカバーできない動作確認を手動で実施する。

## 背景

スキーマ定義タスクのため、手動テストは最小限だが、マイグレーションの動作確認は必須。

---

## 手動テスト項目

### 1. マイグレーション動作確認

- [ ] マイグレーション生成が正常に完了する
- [ ] マイグレーション適用が正常に完了する
- [ ] マイグレーションロールバックが正常に動作する

```bash
# マイグレーション生成
pnpm --filter @repo/shared db:generate

# マイグレーション適用
pnpm --filter @repo/shared db:migrate

# テストDB作成
pnpm --filter @repo/shared db:push
```

### 2. スキーマ確認

- [ ] 生成されたSQLが期待通りである
- [ ] インデックスが正しく作成されている
- [ ] 外部キー制約が正しく設定されている

### 3. 基本操作確認（REPL/スクリプト）

- [ ] エンティティの挿入が可能
- [ ] リレーションの作成が可能
- [ ] CASCADE削除が正しく動作する
