## 実行コマンド

```bash
# Lint
pnpm --filter @repo/shared lint

# 型チェック
pnpm --filter @repo/shared typecheck

# テスト（カバレッジ付き）
pnpm --filter @repo/shared test:coverage

# セキュリティスキャン
pnpm audit
```
