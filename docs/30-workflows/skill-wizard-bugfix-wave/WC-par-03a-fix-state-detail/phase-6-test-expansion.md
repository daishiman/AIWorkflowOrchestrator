## 目的

最小テストで見落としやすい境界条件を補強し、
4件のバグ再発と回帰の両方を防止するテストカバレッジを確保する。

## 実行タスク

### Task 1: internalAnswers境界ケース追加

- `answers` propが空オブジェクトから非空オブジェクトへ変化した場合のリセット動作を確認する
- 同一値での再レンダリング時に不要なリセットが発生しないことを確認する
- リトライを複数回繰り返した場合でも毎回リセットされることを確認する

### Task 2: キャンセルボタン境界ケース追加

- templateモード・非エラー状態ではキャンセルボタンが表示されないことを確認する
- キャンセルボタン押下後にウィザードが意図したステップへ戻ることを確認する
- キャンセル後に再度templateモードで生成を開始できることを確認する

### Task 3: resolveExternalIntegration境界ケース追加

- q5を複数回変更した場合に毎回最新値で再計算されることを確認する
- q5以外の質問（q1〜q4・q6）を変更した場合に再計算が発生しないことを確認する
- resolveExternalIntegrationが返す値がhasExternalIntegrationとexternalToolNameに正しく反映されることを確認する

### Task 4: generationLockRef境界ケース追加

- 生成中にキャンセルし、即座に再生成を開始した場合にロックが正しく機能することを確認する
- エラー発生後のロック状態を確認し、次の生成操作が可能であることを確認する
- 非同期処理が中断された後のfinally節が確実に実行されることを確認する
