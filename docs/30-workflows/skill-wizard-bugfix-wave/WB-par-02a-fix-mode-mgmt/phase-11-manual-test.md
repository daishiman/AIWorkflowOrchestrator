## 目的

Electron 実機でウィザードの動作を手動確認し、ラジオボタン削除・Step 1スキップ修正が正しく反映されていることを視覚的に検証する。自動テストでは検出できない UX 上の問題を発見する。

## 手動テストシナリオ

### シナリオ 1: ラジオボタン削除の視覚確認（VISUAL必須）

| ステップ | 操作                                                 | 期待結果                                                                  |
| -------- | ---------------------------------------------------- | ------------------------------------------------------------------------- |
| 1        | ウィザードを開く（「ウィザードで作成」ボタンを押す） | Step 0（スキル情報入力）が表示される                                      |
| 2        | Step 0 の画面全体を目視確認する                      | 「テンプレートから作成」「LLMで生成」のラジオボタンが**一切表示されない** |
| 3        | Step 0 に表示されるUI要素を確認する                  | スキル名・目的・カテゴリの入力フォームのみが表示される                    |
| 4        | スクリーンショットを撮影する                         | `step0-no-radio-button.png` として保存                                    |

### シナリオ 2: 正規フロー（Step 0→1→2→3）の視覚確認

| ステップ | 操作                                                      | 期待結果                                                 |
| -------- | --------------------------------------------------------- | -------------------------------------------------------- |
| 1        | Step 0 でスキル名・目的・カテゴリを入力して「次へ」を押す | Step 1（ConversationRoundStep / Q1〜Q6）が表示される     |
| 2        | Step 1 が表示されることを目視確認する                     | Q1〜Q6のインタビュー画面が表示される（Step 2に飛ばない） |
| 3        | Step 1 のスクリーンショットを撮影する                     | `step1-conversation.png` として保存                      |
| 4        | Q1〜Q6 に回答して「生成」ボタンを押す                     | Step 2（GenerateStep）が表示される                       |
| 5        | Step 2・Step 3 を順番に確認する                           | Step 2→Step 3 の順で遷移することを確認                   |

### シナリオ 3: Step 1スキップが発生しないことの確認

| ステップ | 操作                          | 期待結果                                     |
| -------- | ----------------------------- | -------------------------------------------- |
| 1        | ウィザードを開く              | Step 0 が表示される                          |
| 2        | Step 0 の「次へ」ボタンを押す | **Step 2（生成画面）に直接遷移しない**こと   |
| 3        | 遷移先の画面を目視確認する    | Step 1（Q1〜Q6インタビュー）が表示されること |

### シナリオ 4: ウィザード全画面での generationMode 残骸確認

| ステップ | 操作                                           | 期待結果                                                                      |
| -------- | ---------------------------------------------- | ----------------------------------------------------------------------------- |
| 1        | Step 0〜Step 3 の全画面を順番に確認する        | どの画面にも「テンプレート」「template」「LLMで生成」のラジオボタンがないこと |
| 2        | ブラウザの開発者ツール（コンソール）を確認する | `generationMode` / `hasActivatedLlmMode` 関連のエラーや警告が0件であること    |

### シナリオ 5: ステップインジケーターの確認

| ステップ | 操作                                   | 期待結果                                         |
| -------- | -------------------------------------- | ------------------------------------------------ |
| 1        | ウィザード起動時にインジケーターを確認 | Step 0〜3 のインジケーターが正しく表示されること |
| 2        | 各ステップ遷移後にインジケーターを確認 | 現在のステップがハイライトされることを確認       |
