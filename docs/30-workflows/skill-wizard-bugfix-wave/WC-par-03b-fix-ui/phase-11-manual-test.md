## 目的

本タスクはUI変更を伴うため、自動テストでは検証しきれない視覚的な整合性を手動で確認する。
カテゴリ複数選択・解除のUIフィードバック・ProgressBarの動的変化・ボタンの外観統一を目視で確認する。

## 実行タスク

- [ ] カテゴリ解除動作を目視確認する
- [ ] InterviewProgressBarの動的変化を目視確認する
- [ ] 全ウィザードボタンの外観統一を目視確認する
- [ ] ライトモード・ダークモードの両方で外観を確認する

## 実行手順

### Step 1: アプリ起動

```bash
pnpm --filter @repo/desktop dev
```

Electronウィンドウが起動したら、スキル作成ウィザードを開く。

### Step 2: カテゴリ複数選択の目視確認（AC-1）

| 確認項目                                    | 期待動作                                             | 結果   |
| ------------------------------------------- | ---------------------------------------------------- | ------ |
| カテゴリボタンが5つ表示されている           | 自動化・外部連携・データ分析・コードサポート・その他 | 要確認 |
| 1つ選択すると選択状態（ハイライト）になる   | 選択ボタンが強調表示される                           | 要確認 |
| 2つ目を選択すると両方がハイライトされる     | 1つ目が解除されず、両方が選択状態になる              | 要確認 |
| 3つ以上選択できる                           | 選択上限なし                                         | 要確認 |
| 選択済みボタンに`aria-pressed="true"`が付く | アクセシビリティ属性が正しく設定される               | 要確認 |

### Step 3: カテゴリ解除の目視確認（AC-2）

| 確認項目                                          | 期待動作                                         | 結果   |
| ------------------------------------------------- | ------------------------------------------------ | ------ |
| 選択済みカテゴリを再クリックすると解除される      | ハイライトが消える                               | 要確認 |
| 最後の1つを解除すると「次へ」ボタンが非活性化する | 全カテゴリ未選択状態になり「次へ」が押せなくなる | 要確認 |
| 解除後に別のカテゴリを選択できる                  | 解除後の操作が正常に機能する                     | 要確認 |

### Step 4: ボタン外観統一の目視確認（AC-3）

| 確認箇所                                      | 期待する外観                                 | 旧外観との比較         | 結果   |
| --------------------------------------------- | -------------------------------------------- | ---------------------- | ------ |
| Step 0「次へ」ボタン（SkillInfoStep）         | CSS変数色（ライト: 青系 / ダーク: テーマ色） | `bg-blue-600`廃止      | 要確認 |
| LLMモード「次へ」ボタン（SkillCreateWizard）  | 同上                                         | `bg-blue-600`廃止      | 要確認 |
| 「次のページ」ボタン（ConversationRoundStep） | 同上（元から適用済み）                       | 変化なし               | 要確認 |
| 全ボタンの角丸が`rounded-lg`に統一されている  | 角丸サイズが統一されている                   | `rounded`→`rounded-lg` | 要確認 |
| ダークモードでボタン色が正しく表示される      | `--status-primary`がダークテーマ色を返す     | -                      | 要確認 |

### Step 5: InterviewProgressBarの動的変化の目視確認（AC-4）

Step 1（ConversationRoundStep）に進み、以下の手順で確認する。

| 操作                         | 期待する表示                   | 結果   |
| ---------------------------- | ------------------------------ | ------ |
| Step 1開始直後（全問未回答） | 質問 1/6                       | 要確認 |
| Q1の選択肢を1つクリック      | 質問 1/6                       | 要確認 |
| Q2の選択肢を1つクリック      | 質問 2/6                       | 要確認 |
| Q3の選択肢を1つクリック      | 質問 3/6                       | 要確認 |
| 「次のページ」をクリック     | 質問 3/6（変化なし・Q4未回答） | 要確認 |
| Q4の選択肢を1つクリック      | 質問 4/6                       | 要確認 |
| Q5・Q6も選択                 | 質問 5/6 → 6/6                 | 要確認 |

**旧動作との比較:**

- 旧: Page 1は常に「質問 1/6」、Page 2は常に「質問 4/6」
- 新: 実際の回答状況に応じて動的変化
