## レビュー観点

### 1. 要件との整合性

| チェック項目       | 確認内容                                     |
| ------------------ | -------------------------------------------- |
| 機能要件カバレッジ | 全機能要件が設計でカバーされているか         |
| 非機能要件対応     | パフォーマンス・信頼性要件が考慮されているか |
| スコープ逸脱       | 要件外の機能が含まれていないか               |

### 2. アーキテクチャ品質

| チェック項目 | 確認内容                                     |
| ------------ | -------------------------------------------- |
| レイヤー分離 | Clean Architectureの原則に従っているか       |
| 依存関係     | 依存の方向が正しいか（内側に向かっているか） |
| 単一責務     | 各クラス・インターフェースが単一責務か       |

### 3. インターフェース設計

| チェック項目   | 確認内容                         |
| -------------- | -------------------------------- |
| 抽象化         | 適切なレベルで抽象化されているか |
| 拡張性         | 新しい実装を追加しやすいか       |
| テスタビリティ | モック・スタブを作成しやすいか   |

### 4. 型安全性

| チェック項目 | 確認内容                                 |
| ------------ | ---------------------------------------- |
| 型定義       | 全ての入出力に適切な型が定義されているか |
| Null安全     | nullableな値が明示されているか           |
| 型推論       | 型推論が適切に機能するか                 |

---

## レビュー結果判定

| 判定     | 条件                     | 次のアクション            |
| -------- | ------------------------ | ------------------------- |
| PASS     | 全レビュー観点で問題なし | Phase 4へ進行             |
| MINOR    | 軽微な指摘あり           | 指摘対応後、Phase 4へ     |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻る      |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認 |

### 戻り先決定基準

| 問題の種類 | 戻り先              |
| ---------- | ------------------- |
| 要件の問題 | Phase 1（要件定義） |
| 設計の問題 | Phase 2（設計）     |
