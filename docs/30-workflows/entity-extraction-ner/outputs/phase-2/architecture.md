## 4. 依存関係の方向

```
Application (外部)
       │
       ▼
 IEntityExtractor ←────────────────────────────────┐
       │                                           │
       ▼                                           │
 LLMEntityExtractor                    RuleBasedExtractor
       │                                           │
       ▼                                           │
   types.ts ◄──────────────────────────────────────┘
       │
       ▼
  rag/graph/types (EntityType)
  rag/branded (ChunkId)
  rag/result (ok, err)
```

**依存の原則:**

1. 依存は常に「内側」（より抽象的な層）に向かう
2. サービス層は Domain 層に依存
3. Domain 層は外部依存を持たない
4. Infrastructure 層（ILLMProvider）は Interface で抽象化
