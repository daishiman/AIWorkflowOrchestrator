## 2. RuleBasedEntityExtractor 手動テスト

### 2.1 技術系テキストからの抽出

**入力テキスト**:

```
このプロジェクトではTypeScriptとReactを使用しています。
バックエンドはNode.jsで構築し、データベースにはPostgreSQLを採用しました。
```

**期待結果**:

- TypeScript, React, Node.js, PostgreSQL が抽出される

**実際の結果**: ✅ PASS

- 全ての技術名が正常に抽出された
- 各エンティティに適切な信頼度スコア（0.85〜0.90）が付与された

### 2.2 組織名の抽出

**入力テキスト**:

```
MicrosoftはTypeScriptを開発しました。
GoogleはAngularを、MetaはReactを開発しています。
OpenAIとAnthropicはAI研究で知られています。
```

**期待結果**:

- Microsoft, Google, Meta, OpenAI, Anthropic が抽出される

**実際の結果**: ✅ PASS

- 全ての組織名が正常に抽出された
- type: "organization" に分類された

### 2.3 日付の抽出

**入力テキスト**:

```
プロジェクトは2024-01-15に開始しました。
次のマイルストーンは2024年3月31日です。
最終リリースは2024/12/25を予定しています。
```

**期待結果**:

- ISO形式、日本語形式、スラッシュ形式の日付が抽出される

**実際の結果**: ✅ PASS

- 3つの日付形式すべてが正常に抽出された
- type: "date"、confidence: 0.90〜0.95

### 2.4 メンション追跡

**入力テキスト**:

```
ReactはUIライブラリです。Reactは2013年にリリースされました。
多くの企業がReactを採用しています。
```

**期待結果**:

- "React" の3回の出現が追跡される
- 各出現の位置情報が記録される

**実際の結果**: ✅ PASS

- mentions.length = 3
- 各mentionにstartPosition, endPosition, contextが含まれている

### 2.5 フィルタリング機能

**テスト**: タイプフィルタで技術のみ抽出

**入力**:

```
MicrosoftがTypeScriptを2024-01-15にリリース。
```

**オプション**: `{ types: ["technology"] }`

**実際の結果**: ✅ PASS

- TypeScriptのみが抽出された
- Microsoft（organization）と日付は除外された
