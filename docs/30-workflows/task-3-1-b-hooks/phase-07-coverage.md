## 目的

テストカバレッジが目標値を達成していることを確認し、統合テストを実行する。

## 背景

品質を保証するため、コードカバレッジの測定と統合テストの実行が必要である。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ測定

**目的**: 現在のテストカバレッジを測定する

**実行手順**:

1. カバレッジ測定コマンドを実行
2. カバレッジレポートを確認
3. 目標値との比較を行う

**期待される成果物**:

- カバレッジレポート

```bash
# カバレッジ測定コマンド
pnpm --filter @repo/desktop test -- --coverage --grep "SkillExecutor"
```

### タスク2: 未カバー箇所の特定

**目的**: カバレッジが不足している箇所を特定する

**実行手順**:

1. カバレッジレポートの詳細を確認
2. 未カバーの行・ブランチをリストアップ
3. 追加テストの必要性を評価

**期待される成果物**:

- 未カバー箇所リスト

### タスク3: 統合テスト実行

**目的**: 統合テストを実行してシステム全体の動作を確認する

**実行手順**:

1. IPCチャネル経由でのHooks動作確認
2. エンドツーエンドのフロー確認
3. 異常系の統合テスト実行

**期待される成果物**:

- 統合テスト結果

#### 統合テストシナリオ

| シナリオ                             | 期待結果                           | 結果 |
| ------------------------------------ | ---------------------------------- | ---- |
| 安全なスキル実行                     | 正常完了、tool_use/tool_result送信 |      |
| 危険コマンドを含むスキル実行         | ブロック、エラー通知送信           |      |
| 保護パスへの書き込みを含むスキル実行 | ブロック、エラー通知送信           |      |
| 実行中のAbort                        | 正常中断、タイムアウトエラー       |      |
| ネットワークエラー発生               | リトライ可能エラー通知             |      |

---

### タスク4: カバレッジ不足時の追加テスト

**目的**: カバレッジ目標未達の場合、追加テストを作成する

**実行手順**:

1. 未カバー箇所に対するテストを追加
2. 再度カバレッジを測定
3. 目標達成を確認

**期待される成果物**:

- 追加テスト（必要な場合）
- 最終カバレッジレポート
