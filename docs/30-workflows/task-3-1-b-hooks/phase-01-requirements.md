## 目的

Claude Agent SDK の Hooks システム（PreToolUse / PostToolUse）を実装するための要件を明確にし、受け入れ基準を定義する。

## 背景

TASK-3-1-Aで実装した`SkillExecutor`の基本構造に対し、セキュリティ機能とツール実行通知機能を追加する必要がある。TASK-2Cで定義したセキュリティパターン（`isDangerousCommand`、`isProtectedPath`）を活用し、危険なツール操作をブロックする。

---

**目的**: 本タスクの入力となる成果物が利用可能であることを確認する

### タスク2: 機能要件の定義

**目的**: Hooks実装に必要な機能要件を明確化する

**実行手順**:

1. PreToolUse Hook の機能要件を列挙
2. PostToolUse Hook の機能要件を列挙
3. エラーハンドリングの機能要件を列挙
4. ストリーム通知の機能要件を列挙

**期待される成果物**:

- 機能要件一覧

#### 機能要件一覧

**FR-001: PreToolUse Hook - 危険コマンドブロック**

| 項目     | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 要件ID   | FR-001                                                                   |
| 要件名   | 危険コマンドのブロック                                                   |
| 説明     | Bashツール実行前に、コマンドが危険パターンにマッチする場合はブロックする |
| 入力     | `toolName: "Bash"`, `args.command: string`                               |
| 出力     | `{ proceed: false, message: string }` または `{ proceed: true }`         |
| 検証方法 | `isDangerousCommand(command)` を呼び出し                                 |
| 優先度   | 必須                                                                     |

**FR-002: PreToolUse Hook - 保護パスブロック**

| 項目     | 内容                                                             |
| -------- | ---------------------------------------------------------------- | ------------------- | --------------- |
| 要件ID   | FR-002                                                           |
| 要件名   | 保護パスへの書き込みブロック                                     |
| 説明     | Write/Editツール実行前に、パスが保護対象の場合はブロックする     |
| 入力     | `toolName: "Write"                                               | "Edit"`, `args.path | args.file_path` |
| 出力     | `{ proceed: false, message: string }` または `{ proceed: true }` |
| 検証方法 | `isProtectedPath(filePath)` を呼び出し                           |
| 優先度   | 必須                                                             |

**FR-003: PreToolUse Hook - ツール実行開始通知**

| 項目   | 内容                                                       |
| ------ | ---------------------------------------------------------- |
| 要件ID | FR-003                                                     |
| 要件名 | ツール実行開始通知                                         |
| 説明   | セキュリティチェック通過後、ツール実行開始をストリーム送信 |
| 入力   | `toolName`, `args`, `toolUseId`                            |
| 出力   | `SkillStreamMessage { type: "tool_use" }`                  |
| 優先度 | 必須                                                       |

**FR-004: PostToolUse Hook - ツール結果通知**

| 項目   | 内容                                         |
| ------ | -------------------------------------------- |
| 要件ID | FR-004                                       |
| 要件名 | ツール実行結果通知                           |
| 説明   | ツール実行完了後、結果をストリームに送信     |
| 入力   | `toolName`, `result`, `toolUseId`            |
| 出力   | `SkillStreamMessage { type: "tool_result" }` |
| 優先度 | 必須                                         |

**FR-005: PostToolUse Hook - 完了ステータス通知**

| 項目   | 内容                                                                      |
| ------ | ------------------------------------------------------------------------- |
| 要件ID | FR-005                                                                    |
| 要件名 | ツール完了ステータス通知                                                  |
| 説明   | ツール実行完了後、ステータスをストリームに送信                            |
| 入力   | `toolName`                                                                |
| 出力   | `SkillStreamMessage { type: "status", content.status: "tool_completed" }` |
| 優先度 | 必須                                                                      |

**FR-006: エラーカテゴリ判定**

| 項目     | 内容                                                              |
| -------- | ----------------------------------------------------------------- |
| 要件ID   | FR-006                                                            |
| 要件名   | エラーカテゴリの判定                                              |
| 説明     | エラーを5つのカテゴリに分類する                                   |
| カテゴリ | `sdk_error`, `permission_denied`, `timeout`, `network`, `unknown` |
| 優先度   | 必須                                                              |

**FR-007: リトライ可能性判定**

| 項目   | 内容                                                 |
| ------ | ---------------------------------------------------- |
| 要件ID | FR-007                                               |
| 要件名 | リトライ可能性の判定                                 |
| 説明   | ネットワークエラー・タイムアウトはリトライ可能と判定 |
| 入力   | `error: Error`                                       |
| 出力   | `boolean`                                            |
| 優先度 | 必須                                                 |
