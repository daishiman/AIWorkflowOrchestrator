## 目的

UXと実環境での動作を手動で確認し、自動テストでは検出できない問題を発見する。

## 背景

自動テストは機能の正確性を検証するが、実際のユーザー体験や環境依存の問題は手動テストで確認する必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連する自動テストの実行確認

**目的**: 手動テスト前に自動テストが全てパスしていることを確認する

**実行手順**:

1. ユニットテストを実行
2. 統合テストを実行
3. 全テストがパスすることを確認

**期待される成果物**:

- テスト実行結果

```bash
# 全テスト実行コマンド
pnpm --filter @repo/desktop test
```

---

### タスク2: 機能テスト（正常系）

**目的**: 主要機能が正常に動作することを手動で確認する

**実行手順**:

1. デスクトップアプリを起動
2. スキルを選択して実行
3. Hooksが正常に動作することを確認

**期待される成果物**:

- 機能テスト結果

#### 機能テスト結果

| TC-ID  | 機能               | 操作                   | 期待結果                  | 結果 | 備考 |

| TC-001 | スキル実行開始通知 | スキルを実行           | tool_useメッセージが表示  |      |      |
| TC-002 | ツール完了通知     | ツール実行を待つ       | tool_completedが表示      |      |      |
| TC-003 | 実行完了通知       | スキル実行を完了させる | completedステータスが表示 |      |      |

### タスク3: エラーハンドリングテスト（異常系）

**目的**: エラー発生時の動作を手動で確認する

**実行手順**:

1. 危険コマンドを含むスキルを実行（テスト用）
2. ブロックメッセージが表示されることを確認
3. エラー通知が適切に表示されることを確認

**期待される成果物**:

- エラーハンドリングテスト結果

#### エラーハンドリングテスト結果

| TC-ID  | 状況               | 操作                          | 期待結果                 | 結果 | 備考 |
| ------ | ------------------ | ----------------------------- | ------------------------ | ---- | ---- |
| TC-101 | 危険コマンド       | rm -rfを含むスキルを実行      | ブロックメッセージが表示 |      |      |
| TC-102 | 保護パス書き込み   | /etcへの書き込みを試みる      | ブロックメッセージが表示 |      |      |
| TC-103 | ネットワークエラー | オフラインで実行              | リトライ可能エラーが表示 |      |      |
| TC-104 | 実行中キャンセル   | 実行中にAbortボタンをクリック | タイムアウトエラーが表示 |      |      |
