## 品質チェックリスト

### docs品質チェック

| チェック項目                                               | 判定基準                     | 合否 |
| ---------------------------------------------------------- | ---------------------------- | ---- |
| AC-4追記に曖昧表現がないか（「適切に」「必要に応じて」等） | 曖昧表現ゼロ                 | -    |
| フォールバックテンプレートの追記が既存構造と整合しているか | 既存セクション命名規則と一致 | -    |
| フィールド独立性の定義が複数箇所で矛盾していないか         | 定義が一意・一貫             | -    |
| テンプレート変更が既存参照パスを壊していないか             | リンク切れゼロ               | -    |

### test品質チェック

| チェック項目                           | 判定基準                        | 合否 |
| -------------------------------------- | ------------------------------- | ---- |
| テスト全件PASS                         | 0件FAIL                         | -    |
| TC-FB03-01〜09が全件実行されていること | 全ケース実行確認                | -    |
| 境界値テスト文字列の実文字数確認済み   | `// length: N` コメント付与済み | -    |
