## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-Aで実装した`formatRelativeTime`関数は、相対時間を日本語で表示する（「たった今」「X秒前」「X分前」など）。グローバル展開を見据え、多言語対応が必要となる。

### 1.2 問題点・課題

| 問題点                   | 詳細                                               |
| ------------------------ | -------------------------------------------------- |
| ハードコードされた日本語 | 「たった今」「秒前」「分前」等がコード内に直接記述 |
| 国際化対応なし           | i18nフレームワーク未統合                           |
| 言語切替不可             | ユーザーの言語設定に応じた表示変更ができない       |

### 1.3 放置した場合の影響

- 非日本語話者へのアプリ提供が困難
- グローバル展開時の大規模リファクタリングが必要
- 他の国際化対応との一貫性がなくなる

---

## 2. 何を達成するか（What）

### 2.1 目的

formatRelativeTime関数とSkillStreamDisplayのUIテキストを多言語対応する。

### 2.2 最終ゴール

- 相対時間表示が複数言語に対応
- ユーザーの言語設定に応じた表示
- 将来の言語追加が容易な構造

### 2.3 スコープ

#### 含むもの

| 項目                    | 説明                     |
| ----------------------- | ------------------------ |
| formatRelativeTime i18n | 相対時間文字列の国際化   |
| 対応言語                | 日本語（ja）、英語（en） |
| 翻訳ファイル構造        | JSON形式の言語リソース   |
| テスト                  | 各言語での表示テスト     |

#### 含まないもの

| 項目                   | 理由                                 |
| ---------------------- | ------------------------------------ |
| 日時フォーマット       | Intl.DateTimeFormatで対応済み        |
| 他コンポーネントのi18n | 別タスクでシステム全体の国際化を検討 |
| RTL対応                | 現状対象言語になし                   |

### 2.4 成果物

| 成果物                 | パス                                                        |
| ---------------------- | ----------------------------------------------------------- |
| 翻訳リソース（日本語） | `apps/desktop/src/renderer/locales/ja/time.json`            |
| 翻訳リソース（英語）   | `apps/desktop/src/renderer/locales/en/time.json`            |
| formatRelativeTime更新 | `apps/desktop/src/renderer/utils/formatTime.ts`             |
| i18nユーティリティ     | `apps/desktop/src/renderer/utils/i18n.ts`（新規or既存更新） |
| テスト更新             | 多言語テストケース追加                                      |
