## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-AでMessageTimestampコンポーネントを実装し、各メッセージに相対時刻（「X秒前」「X分前」等）を表示する機能を追加した。現在、タイムスタンプはメッセージ受信時に一度だけ計算され、その後は更新されない。

### 1.2 問題点・課題

| ID  | 課題                     | 現状                                        |
| --- | ------------------------ | ------------------------------------------- |
| T1  | タイムスタンプが静的     | 「5秒前」のまま時間が経過しても更新されない |
| T2  | 長時間実行時の正確性低下 | 実行開始から時間が経つと表示が古くなる      |
| T3  | ユーザー混乱の可能性     | 「1分前」が10分後も「1分前」のまま          |

### 1.3 放置した場合の影響

- **T1**: ユーザーが正確な時間経過を把握できない
- **T2**: 長時間実行タスクのデバッグ時に混乱
- **T3**: UXの一貫性低下

**注意**: 現状でも初回表示は正確であり、重大な問題ではない。パフォーマンス影響を考慮した上での任意改善。

---

## 2. 何を達成するか（What）

### 2.1 目的

MessageTimestampコンポーネントの相対時刻表示を定期的に自動更新し、常に正確な経過時間を表示する。

### 2.2 最終ゴール

| 達成項目           | 達成状態                                       |
| ------------------ | ---------------------------------------------- |
| 自動更新機能       | タイムスタンプが定期的に自動更新される         |
| 更新間隔の最適化   | 経過時間に応じた適切な更新間隔が設定されている |
| パフォーマンス維持 | 大量メッセージでもパフォーマンス劣化なし       |

### 2.3 スコープ

#### 含むもの

- MessageTimestampコンポーネントの自動更新機能実装
- 更新間隔の最適化ロジック
- パフォーマンス最適化
- 関連ユニットテストの追加

#### 含まないもの

- formatRelativeTime関数の変更
- 他のコンポーネントへの影響
- 絶対時刻表示モードの追加

### 2.4 成果物

| 成果物                 | パス                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| 改善済みコンポーネント | `apps/desktop/src/renderer/components/AgentView/SkillStreamDisplay.tsx`                |
| 追加テスト             | `apps/desktop/src/renderer/components/AgentView/__tests__/SkillStreamDisplay.test.tsx` |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-3-2-Aが完了していること
- MessageTimestampコンポーネントが正常に動作していること
- 既存テストが全てPASSしていること

### 3.2 依存タスク

| タスクID   | タスク名                  | ステータス |
| ---------- | ------------------------- | ---------- |
| TASK-3-2-A | SkillStreamDisplay UX改善 | 完了       |

### 3.3 必要な知識

| 技術領域    | 必要な知識                   |
| ----------- | ---------------------------- |
| React       | useEffect、useState、useRef  |
| JavaScript  | setInterval、clearInterval   |
| Performance | メモ化、レンダリング最適化   |
| Testing     | タイマーモック、非同期テスト |

### 3.4 推奨アプローチ

1. **更新間隔の最適化**
   - 1分未満: 1秒ごとに更新
   - 1分〜1時間: 1分ごとに更新
   - 1時間以上: 1時間ごとに更新

2. **実装パターン**
   - `useInterval` カスタムフックの作成
   - 可視状態に応じた更新停止（`document.hidden`）

3. **パフォーマンス最適化**
   - React.memoによるMessageItemの再レンダリング防止
   - 単一タイマーで全タイムスタンプを更新（バッチ処理）

### Phase 5: 実装

#### 目的

MessageTimestampコンポーネントに自動更新機能を実装する。

#### 手順

1. **useIntervalカスタムフック作成**
   - 動的な更新間隔をサポート
   - クリーンアップ処理を実装

2. **可視状態検知の実装**
   - `document.visibilitychange` イベントの監視
   - 非表示時は更新を停止

3. **MessageTimestampの改善**
   - `useInterval` を使用した定期更新
   - 経過時間に応じた更新間隔の動的変更

4. **バッチ更新の実装**
   - Context APIで現在時刻を共有
   - 単一タイマーで全コンポーネントを更新

#### 成果物

- useIntervalカスタムフック
- 改善済みMessageTimestampコンポーネント
