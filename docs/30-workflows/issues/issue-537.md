## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-Aで実装した`formatRelativeTime`関数は、メッセージのタイムスタンプを「たった今」「X分前」などの相対時間で表示する機能を提供している。現在の実装では、コンポーネントのマウント時点での相対時間が静的に表示され、時間経過に伴う自動更新は行われない。

### 1.2 問題点・課題

| 問題点               | 詳細                                                         |
| -------------------- | ------------------------------------------------------------ |
| 静的表示             | 「たった今」と表示されたまま数分経過しても更新されない       |
| ユーザー体験の違和感 | 長時間画面を開いていると、表示と実際の経過時間にズレが生じる |
| 再レンダリング依存   | 他の操作で再レンダリングが発生するまで時間表示が更新されない |

### 1.3 放置した場合の影響

- ユーザーがメッセージの新しさを誤認する可能性
- 長時間のセッションでUX品質が低下
- 他のアプリケーション（Slack、Discord等）と比較した際の見劣り

---

## 2. 何を達成するか（What）

### 2.1 目的

タイムスタンプ表示を一定間隔で自動更新し、常に正確な相対時間を表示する。

### 2.2 最終ゴール

- メッセージのタイムスタンプが時間経過に応じて自動的に更新される
- パフォーマンスへの影響を最小限に抑える
- 既存の`formatRelativeTime`関数を活用した実装

### 2.3 スコープ

#### 含むもの

| 項目                 | 説明                                 |
| -------------------- | ------------------------------------ |
| useRelativeTime Hook | 自動更新ロジックをカプセル化したHook |
| 更新間隔の最適化     | 経過時間に応じた更新間隔の動的調整   |
| パフォーマンス最適化 | 不要な再レンダリングの防止           |
| 単体テスト           | Hook動作の検証                       |

#### 含まないもの

| 項目                   | 理由                     |
| ---------------------- | ------------------------ |
| formatRelativeTime変更 | 既存実装をそのまま利用   |
| UI変更                 | 表示形式は現状維持       |
| バックエンド変更       | フロントエンドのみの機能 |

### 2.4 成果物

| 成果物               | パス                                                                |
| -------------------- | ------------------------------------------------------------------- |
| useRelativeTime Hook | `apps/desktop/src/renderer/hooks/useRelativeTime.ts`                |
| Hook単体テスト       | `apps/desktop/src/renderer/hooks/__tests__/useRelativeTime.test.ts` |
| 統合テスト更新       | `SkillStreamDisplay.test.tsx`の時間更新テスト追加                   |

## 3. どのように実行するか（How）

### 3.1 前提条件

| 条件           | 確認方法                         |
| -------------- | -------------------------------- |
| TASK-3-2-A完了 | formatRelativeTime関数が実装済み |
| React 18以上   | useEffect、useStateが利用可能    |
| Vitest環境     | タイマーモックが利用可能         |

### 3.2 依存タスク

| タスクID   | 名称                      | ステータス |
| ---------- | ------------------------- | ---------- |
| TASK-3-2-A | SkillStreamDisplay UX改善 | 完了       |

### 3.3 必要な知識

| 知識領域             | 詳細                             |
| -------------------- | -------------------------------- |
| React Hooks          | useEffect、useState、useCallback |
| タイマー管理         | setInterval、clearInterval       |
| パフォーマンス最適化 | メモ化、不要レンダリング防止     |

### 3.4 推奨アプローチ

```
useRelativeTime(timestamp: number): string
├── 初期値: formatRelativeTime(timestamp)で計算
├── 更新間隔: 経過時間に応じて動的調整
│   ├── 1分未満: 10秒間隔
│   ├── 1時間未満: 1分間隔
│   └── 1時間以上: 5分間隔
└── クリーンアップ: アンマウント時にinterval解除
```
