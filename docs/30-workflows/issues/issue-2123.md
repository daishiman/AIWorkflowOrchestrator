## 概要

アナリティクス HTTP 送信において、ネットワーク一時障害時に自動リトライする機能を実装する。

## 背景

現在の実装では、ネットワーク障害が発生した場合に即座に失敗となり、アナリティクスデータが失われる。
指数バックオフを使ったリトライ機能を追加することで、一時的なネットワーク障害に対する耐障害性を向上させる。

## 受入基準

- [ ] ネットワーク一時障害時に指数バックオフによるリトライが実行される
- [ ] リトライ回数の上限が設定可能である（デフォルト値を設ける）
- [ ] リトライ間隔が指数的に増加する（例: 1秒, 2秒, 4秒）
- [ ] 最大リトライ回数を超えた場合は最終的なエラーが返される
- [ ] リトライ動作に対応したテストが追加される
- [ ] 既存のテストが引き続き通過する
