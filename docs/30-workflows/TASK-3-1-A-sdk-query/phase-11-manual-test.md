## 目的

自動テストでは検証できない実環境動作を手動で確認する。
実際の SDK 連携・ストリーミング動作・中断処理を検証する。

## 背景

SkillExecutor は Claude Agent SDK と連携するため、
実際の API 呼び出しを含む手動テストが必要。
