## 実行タスク

### タスク1: カバレッジ再測定

**目的**: 最終的なテストカバレッジを測定

**実行手順**:

1. カバレッジ測定コマンドを実行
2. レポートを確認
3. 基準達成状況を判定

**コマンド**:

```bash
pnpm --filter @repo/desktop test:coverage
```

### タスク2: 統合テスト実行

**目的**: 統合テストの全実行と結果確認

**実行手順**:

1. 統合テストを実行
2. 失敗テストがないことを確認
3. 結果を記録

**コマンド**:

```bash
pnpm --filter @repo/desktop test
```

### タスク3: ゲート判定

**目的**: カバレッジ基準達成を判定

**判定基準**:

| 指標              | 最低基準 | 推奨基準 | 結果 |
| ----------------- | -------- | -------- | ---- |
| Line Coverage     | 80%      | 90%      | -    |
| Branch Coverage   | 60%      | 70%      | -    |
| Function Coverage | 80%      | 90%      | -    |

**未達の場合**: Phase 6 へ戻ってテストを追加
