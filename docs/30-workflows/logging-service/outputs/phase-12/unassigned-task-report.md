### TD-1: dispose()の非同期処理

**現状**:

```typescript
dispose(): void {
  if (this.flushTimer) {
    clearInterval(this.flushTimer);
    this.flushTimer = null;
  }
  // 同期的にflushを呼び出すが、結果は待たない
  void this.flush();
}
```

**課題**:

- dispose時のflush失敗がハンドリングされない
- テストでカバーされていない（4行）

**推奨対応**:

- CONV-05-02でasync dispose()への変更を検討
- または、エラーログ出力の追加
