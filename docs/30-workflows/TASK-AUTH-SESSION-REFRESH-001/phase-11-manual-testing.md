## テスト実行手順

1. `pnpm --filter @repo/desktop preview` でアプリを起動
2. OAuth認証（Google/GitHub/Discord）でログイン
3. コンソールログでスケジューラー開始を確認
4. 各テストケースを順次実行
5. 結果を記録

**時間短縮テスト方法:**

- TokenRefreshSchedulerのconfigで`refreshBeforeExpiryMs`を大きな値（例: 3500000 = 58分20秒）に一時変更
- これにより有効期限1時間のうち、約1分40秒後にリフレッシュが実行される
- テスト完了後、元の値（300000 = 5分）に戻す
