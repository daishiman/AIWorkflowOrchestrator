## リファクタリングチェックリスト

### 命名

- [ ] 変数名が意図を表している
- [ ] 関数名が動作を表している
- [ ] クラス名が責務を表している

### 関数

- [ ] 関数が1つのことだけを行っている
- [ ] 関数の引数が3つ以下である
- [ ] 副作用がない（または明確に示されている）

### 重複

- [ ] DRY原則に従っている
- [ ] 抽象化が適切である

### コメント

- [ ] 不要なコメントがない
- [ ] コードが自己文書化されている
