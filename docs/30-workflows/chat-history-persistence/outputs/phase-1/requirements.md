# チャット履歴永続化機能 - 要件定義書

## 1. 機能要件

### FR-001: セッション作成

- ユーザーは新しいチャットセッションを作成できる
- タイトル未指定時は「新しいチャット YYYY-MM-DD HH:mm」形式で自動生成

### FR-002: セッション一覧取得

- ユーザーは自身のセッション一覧を取得できる
- 作成日時の降順でソートされる

### FR-003: セッション削除

- ユーザーはセッションを削除できる
- 削除時、関連メッセージも削除される（カスケード削除）
- 論理削除（ソフトデリート）を採用

### FR-004: ユーザーメッセージ保存

- ユーザーからのメッセージを保存できる
- メッセージインデックスは自動採番

### FR-005: アシスタントメッセージ保存

- AIアシスタントからのメッセージを保存できる
- LLMプロバイダー・モデル情報を付与

### FR-006: LLMメタデータ保存

- トークン使用量、応答時間を記録
- プロバイダー、モデル名を記録

### FR-007: キーワード検索

- タイトル・プレビューテキストを対象に全文検索
- FTS5を使用した高速検索

### FR-010: Markdownエクスポート

- セッションをMarkdown形式でエクスポート
- メタデータ含有オプション

### FR-011: JSONエクスポート

- セッションをJSON形式でエクスポート
- バージョン情報付き

### FR-013: タイトル編集

- セッションタイトルを変更できる

### FR-014: お気に入り/ピン留め

- セッションをお気に入りに追加できる
- セッションをピン留めできる（最大10件）

## 2. 非機能要件

### NFR-001: パフォーマンス

- セッション検索: 100ms以内
- メッセージ一覧取得: 50ms以内

### NFR-002: データ整合性

- ACID特性を保証
- 外部キー制約によるカスケード削除

### NFR-003: テストカバレッジ

- 目標: 80%以上

## 3. スコープ

### 含む

- チャットセッションの自動保存
- メタデータ（日時、使用LLM、タイトル）の保存
- システムプロンプトの保存
- 添付ファイル情報の保存
- 履歴一覧表示（サイドバー）
- 日付/キーワード検索
- タイトル編集
- 履歴の削除
- お気に入り/ピン留め
- Markdown/JSONエクスポート

### 含まない

- クラウド同期
- 複数デバイス間の履歴共有
- 履歴の暗号化
