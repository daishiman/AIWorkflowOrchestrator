## 3. コンポーネント設計

### 3.1 サイドバー（履歴一覧）

#### SessionList

- ピン留めセッションを上部に表示
- 通常セッションを作成日時降順で表示
- 各セッションはSessionItemコンポーネント

#### SessionItem

```
┌─────────────────────────────────────┐
│ 📌 React開発の質問                   │ ← タイトル（ピン留めアイコン）
│ 最後のメッセージのプレビュー...      │ ← lastMessagePreview
│ 2026-01-04 14:30  💬 12             │ ← 日時、メッセージ数
└─────────────────────────────────────┘
```

**操作:**

- クリック: セッション選択
- 右クリック: コンテキストメニュー
  - タイトル編集
  - ピン留め/解除
  - お気に入り登録/解除
  - エクスポート（Markdown/JSON）
  - 削除

#### SearchBar

- キーワード入力でセッション検索（FTS5）
- フィルター: お気に入り、ピン留め

### 3.2 メインコンテンツ（チャット画面）

#### MessageList

- メッセージを時系列で表示
- ユーザー/アシスタントで視覚的に区別

#### MessageItem

**ユーザーメッセージ:**

```
                    ┌─────────────────────────────────────┐
                    │ ユーザーメッセージ内容               │
                    │ 14:30                               │
                    └─────────────────────────────────────┘
```

**アシスタントメッセージ:**

```
┌─────────────────────────────────────┐
│ アシスタントメッセージ内容           │
│ 14:31 | claude-3-5-sonnet          │ ← LLMモデル表示
└─────────────────────────────────────┘
```

#### InputArea

- テキスト入力エリア
- 送信ボタン
- 添付ファイル追加ボタン（将来対応）

## 5. インタラクション

### 5.1 セッション作成

1. ユーザーが「新規チャット」をクリック
2. 新規セッションが作成される（デフォルトタイトル自動生成）
3. チャット画面が空の状態で表示される

### 5.2 メッセージ送信

1. ユーザーがメッセージを入力
2. 送信ボタンクリックまたはEnter
3. ユーザーメッセージが保存・表示される
4. AIが応答を生成
5. アシスタントメッセージが保存・表示される
6. セッションのmessageCount、lastMessagePreviewが更新される

### 5.3 セッション検索

1. ユーザーが検索バーにキーワードを入力
2. FTS5による全文検索が実行される
3. マッチするセッションが一覧表示される

### 5.4 エクスポート

1. ユーザーがセッションのコンテキストメニューからエクスポートを選択
2. 形式選択ダイアログが表示される（Markdown/JSON）
3. 選択した形式でファイルがダウンロードされる
