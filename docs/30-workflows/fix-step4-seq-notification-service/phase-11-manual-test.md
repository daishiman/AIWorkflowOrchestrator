## 目的

自動テストでは検証しにくい「macOS ネイティブ通知が実際に表示されること」と「`before-quit` ガードダイアログが正しく機能すること」を Electron アプリ上で直接確認する。

---

## NON_VISUAL タスクの記録

本タスクは UI コンポーネントを変更しない NON_VISUAL タスクである。
通知は macOS ネイティブ通知（OS 管理の UI）であり、アプリ内の Renderer Process UI には変更がない。

スクリーンショットの添付は任意だが、通知ポップアップとダイアログの画面記録が推奨される。

---

## 手動テスト前提条件

- macOS 環境で Electron アプリが起動できること
- TASK-FIX-EXECUTE-PLAN-FF-001 が完了しており、スキル生成が実行可能な状態であること
- 有効な API キーが設定されていること

pnpm --filter @repo/desktop dev

## テストケース

### MTC-01: スキル生成完了時に macOS 通知が表示されること

| 手順 | 操作内容                                         | 期待結果                                                                             |
| ---- | ------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 1    | Electron アプリを起動する                        | アプリが正常に表示される                                                             |
| 2    | スキル生成画面を開く                             | スキル生成フォームが表示される                                                       |
| 3    | スキル名を入力し、生成ボタンを押下する           | スキル生成が開始される                                                               |
| 4    | スキル生成が完了するまで待つ（10〜30 分）        | 生成が完了する                                                                       |
| 5    | macOS の通知センターまたはポップアップを確認する | 「スキル作成完了」というタイトルと、スキル名が body に表示される通知が表示されること |

### MTC-02: スキル生成失敗時に macOS 通知が表示されること

| 手順 | 操作内容                                                      | 期待結果                                                                                   |
| ---- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 1    | スキル生成が失敗する条件（例: 無効な API キー）で生成を試みる | 生成がエラーで終了する                                                                     |
| 2    | macOS の通知センターまたはポップアップを確認する              | 「スキル作成失敗」というタイトルとエラーメッセージが body に表示される通知が表示されること |

### MTC-03: スキル生成中にアプリを終了しようとすると確認ダイアログが表示されること

| 手順 | 操作内容                                                          | 期待結果                                                                 |
| ---- | ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1    | スキル生成を開始する                                              | スキル生成が進行中になる                                                 |
| 2    | 生成完了前にアプリを Cmd+Q または「終了」で閉じようとする         | 「スキル作成が進行中です」という確認ダイアログが表示されること           |
| 3    | ダイアログで「キャンセル」を選択する                              | ダイアログが閉じ、アプリが継続して動作すること。スキル生成が続行すること |
| 4    | 再度 Cmd+Q で閉じようとし、ダイアログで「中断して終了」を選択する | アプリが終了すること                                                     |

### MTC-04: スキル生成中でないときはアプリが正常に終了すること

| 手順 | 操作内容                                   | 期待結果                                         |
| ---- | ------------------------------------------ | ------------------------------------------------ |
| 1    | スキル生成が完了した状態でアプリを終了する | 確認ダイアログが表示されずにアプリが終了すること |
