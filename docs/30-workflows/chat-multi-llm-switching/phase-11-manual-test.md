## 手動テストシナリオ

### シナリオ1: LLM選択と切り替え

| ステップ | 操作                    | 期待結果                      |
| -------- | ----------------------- | ----------------------------- |
| 1        | チャット画面を開く      | デフォルトLLMが選択されている |
| 2        | LLMドロップダウンを開く | 利用可能なLLM一覧が表示される |
| 3        | Claude 3.5を選択        | Claude 3.5が選択状態になる    |
| 4        | メッセージを送信        | Claude 3.5でレスポンスが返る  |
| 5        | GPT-4に切り替え         | GPT-4が選択状態になる         |
| 6        | メッセージを送信        | GPT-4でレスポンスが返る       |

### シナリオ2: 会話履歴の維持

| ステップ | 操作                         | 期待結果                       |
| -------- | ---------------------------- | ------------------------------ |
| 1        | Claude 3.5でメッセージを送信 | 会話履歴に追加される           |
| 2        | GPT-4に切り替え              | 会話履歴が維持されている       |
| 3        | 「前の回答について」と送信   | 前のClaudeの回答を参照した応答 |

### シナリオ3: システムプロンプトの維持

| ステップ | 操作                         | 期待結果                           |
| -------- | ---------------------------- | ---------------------------------- |
| 1        | システムプロンプトを設定     | 設定が保存される                   |
| 2        | Claude 3.5でメッセージを送信 | システムプロンプトに従った応答     |
| 3        | GPT-4に切り替え              | システムプロンプト設定が維持       |
| 4        | GPT-4でメッセージを送信      | 同じシステムプロンプトに従った応答 |

### シナリオ4: エラーハンドリング

| ステップ | 操作                     | 期待結果                             |
| -------- | ------------------------ | ------------------------------------ |
| 1        | 無効なAPIキーを設定      | エラーメッセージが表示される         |
| 2        | ネットワークを切断       | 適切なエラー表示とリトライオプション |
| 3        | タイムアウトを発生させる | タイムアウトメッセージが表示される   |
