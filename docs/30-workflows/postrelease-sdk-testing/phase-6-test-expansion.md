## 目的

Phase 5の実装に対してテストを拡充し、パフォーマンス・安定性・ネットワーク障害テストを完全に実行する。

## 背景

Phase 5ではE2Eテストの基本動作を確認した。本Phaseでは、長時間実行テスト、詳細なパフォーマンス計測、ネットワーク障害テストを実行し、本番品質を検証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: パフォーマンステストの詳細実行

**目的**: ストリーミング性能を詳細に計測する。

**実行手順**:

1. パフォーマンステストを複数回実行（10回以上）
2. 統計情報を収集（平均、中央値、P95、P99）
3. 目標値との比較
4. ボトルネックの特定（必要に応じて）
5. レポート作成

**計測項目**:

| 指標               | 目標値    | 測定回数 |
| ------------------ | --------- | -------- |
| 初回応答時間       | 500ms以下 | 10回     |
| メッセージ間遅延   | 100ms以下 | 10回     |
| セッション作成時間 | 200ms以下 | 10回     |

**期待される成果物**:

- パフォーマンス計測レポート

---

### タスク2: 安定性テストの実行

**目的**: 長時間実行時の安定性を検証する。

**実行手順**:

1. 安定性テストスクリプトを実行（1時間）
2. メモリ使用量を継続的にモニタリング
3. クラッシュの有無を確認
4. メモリリークの検出
5. レポート作成

**監視項目**:

| 指標           | 目標値    | 監視間隔 |
| -------------- | --------- | -------- |
| メモリ増加量   | 100MB以下 | 1分      |
| クラッシュ回数 | 0回       | 常時     |
| CPU使用率      | 記録のみ  | 1分      |

**実行コマンド**:

```bash
node apps/desktop/scripts/long-running-test.mjs --duration 3600
```

**期待される成果物**:

- 安定性テストレポート

---

### タスク3: ネットワーク障害テストの実行

**目的**: ネットワーク障害時の動作を検証する。

**実行手順**:

1. ネットワーク切断シミュレーションテストを実行
2. ネットワーク復旧後の再接続テストを実行
3. タイムアウトシミュレーションテストを実行
4. エラーメッセージ表示の確認
5. レポート作成

**テストシナリオ**:

| シナリオ         | 期待動作                         |
| ---------------- | -------------------------------- |
| ネットワーク切断 | エラーメッセージ表示、再試行可能 |
| ネットワーク復旧 | 自動または手動で再接続可能       |
| タイムアウト     | 適切なエラーメッセージ表示       |

**期待される成果物**:

- ネットワーク障害テストレポート

---

### タスク4: エッジケーステストの追加

**目的**: 追加のエッジケースをカバーする。

**実行手順**:

1. 最大長プロンプトテストを追加・実行
2. 最大セッション数テストを追加・実行
3. 同時実行テストを追加・実行
4. 異常入力テストを追加・実行

**期待される成果物**:

- エッジケーステスト結果
