## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。基準未達の場合はPhase 6に戻ってテストを追加する。

## 背景

Phase 6でテストを拡充したが、カバレッジ目標を達成しているか最終確認が必要。本Phaseでは、全テストの再実行とカバレッジゲート判定を行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ再測定

**目的**: テストカバレッジを再計測し、基準達成を確認する

**実行手順**:

1. 全テストを実行してカバレッジを測定:

   ```bash
   pnpm --filter @repo/desktop test:coverage
   ```

2. カバレッジ結果を確認:

   | 指標              | 最低基準 | 推奨基準 | 実測値 | 判定 |
   | ----------------- | -------- | -------- | ------ | ---- |
   | Line Coverage     | 80%      | 90%      |        | [ ]  |
   | Branch Coverage   | 60%      | 70%      |        | [ ]  |
   | Function Coverage | 80%      | 90%      |        | [ ]  |

3. 未達の場合:
   - 未カバー領域を特定
   - Phase 6に戻ってテストを追加
   - 再度本Phaseを実行

**期待される成果物**:

- カバレッジ測定結果

---

### タスク2: 統合テスト実行

**目的**: 統合テストを実行し、全シナリオが成功することを確認する

**実行手順**:

1. 統合テストを実行:

   ```bash
   pnpm --filter @repo/desktop test sdk-integration
   ```

2. E2Eテストを実行（該当する場合）:

   ```bash
   pnpm --filter @repo/desktop test:e2e
   ```

3. テスト結果を確認:

   | テストカテゴリ     | テスト数 | 成功 | 失敗 | 判定 |
   | ------------------ | -------- | ---- | ---- | ---- |
   | API接続テスト      |          |      |      | [ ]  |
   | データフローテスト |          |      |      | [ ]  |
   | エラーハンドリング |          |      |      | [ ]  |
   | 認証連携テスト     |          |      |      | [ ]  |
   | 状態同期テスト     |          |      |      | [ ]  |

4. 失敗するテストがある場合:
   - 原因を調査
   - Phase 5（実装）またはPhase 6（テスト）に戻って修正

**期待される成果物**:

- 統合テスト実行結果

---

### タスク3: ゲート判定

**目的**: カバレッジ基準とテスト成功を総合判定する

**実行手順**:

1. 以下の判定表に基づいて総合判定:

   | 判定項目                        | 基準        | 結果 | 判定 |
   | ------------------------------- | ----------- | ---- | ---- |
   | ユニットテストLine Coverage     | 80%以上     |      | [ ]  |
   | ユニットテストBranch Coverage   | 60%以上     |      | [ ]  |
   | ユニットテストFunction Coverage | 80%以上     |      | [ ]  |
   | 統合テストAPI接続               | 100%成功    |      | [ ]  |
   | 統合テスト正常系シナリオ        | 100%成功    |      | [ ]  |
   | 統合テスト異常系シナリオ        | 80%以上成功 |      | [ ]  |

2. 総合判定:
   - **PASS**: 全項目が基準を満たす → Phase 8へ進行
   - **FAIL**: 1項目以上が基準未達 → Phase 6に戻ってテスト追加

**期待される成果物**:

- `outputs/phase-7/coverage-report.md` - カバレッジ確認レポート
- `outputs/phase-7/integration-test.md` - 統合テスト実行結果
