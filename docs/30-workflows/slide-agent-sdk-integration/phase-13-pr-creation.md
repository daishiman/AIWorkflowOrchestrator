## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 最終チェック

**目的**: PRを作成する前に全ての品質基準を満たしていることを確認する

**実行手順**:

1. 品質チェックを実行:

   ```bash
   pnpm lint
   pnpm typecheck
   pnpm --filter @repo/desktop test
   ```

2. チェックリストを確認:

   | チェック項目           | コマンド/確認方法    | 結果 |
   | ---------------------- | -------------------- | ---- |
   | Lintエラーなし         | `pnpm lint`          | [ ]  |
   | 型エラーなし           | `pnpm typecheck`     | [ ]  |
   | テスト全成功           | `pnpm test`          | [ ]  |
   | カバレッジ基準達成     | `pnpm test:coverage` | [ ]  |
   | ドキュメント更新済み   | 手動確認             | [ ]  |
   | コミットメッセージ適切 | `git log --oneline`  | [ ]  |

3. 問題があれば修正

**期待される成果物**:

- 最終チェック完了

### タスク2: ユーザーにローカル動作確認を依頼【必須】

**目的**: ユーザーにローカル環境での動作確認を依頼する

**実行手順**:

1. ユーザーに以下の確認を依頼する:
   - アプリケーションが正常にビルドできる
   - 主要機能が動作する
   - SDKスキル実行が正常に完了する

2. ユーザーからの確認を待つ

**重要**: ユーザーから確認が得られるまで次のタスクに進まないこと。

**期待される成果物**:

- ユーザーからのローカル動作確認完了

---

### タスク3: 変更サマリー提示と許可確認【必須】

**目的**: 変更内容のサマリーを提示し、PRを作成してよいかユーザーに確認する

**実行手順**:

1. 変更サマリーを作成する:

   ```markdown
   ## 変更サマリー

   ### 変更ファイル

   - `apps/desktop/src/main/slide/skill-executor.ts` - SDK統合実装
   - `apps/desktop/src/main/slide/agent-client.ts` - SDK統合実装
   - `apps/desktop/src/main/slide/__tests__/` - テスト追加

   ### 主な変更内容

   - シミュレーション実装をClaude Agent SDK呼び出しに置換
   - 進捗コールバック・キャンセル機能を実装
   - APIキー暗号化保存を実装
   - 30秒タイムアウトを設定

   ### テスト結果

   - ユニットテスト: X件成功
   - 統合テスト: X件成功
   - カバレッジ: Line X%, Branch X%, Function X%
   ```

2. ユーザーにPR作成の許可を求める

**重要**: ユーザーから明示的な許可を得るまでPR作成を実行しないこと。

**期待される成果物**:

- ユーザーからのPR作成許可

---

### タスク4: コミット整理

**目的**: コミット履歴を整理してレビューしやすくする

**実行手順**:

1. コミット履歴を確認:

   ```bash
   git log --oneline origin/main..HEAD
   ```

2. 必要に応じてコミットを整理:
   - 関連するコミットはsquash
   - 意味のある単位でコミットを分割
   - コミットメッセージをConventional Commitsに準拠

3. コミットメッセージ例:

   ```
   feat(slide): Claude Agent SDK統合を実装

   - skill-executor.tsにSDK呼び出しを実装
   - agent-client.tsにSDK呼び出しを実装
   - safeStorage APIでAPIキーを暗号化保存
   - 進捗コールバックとキャンセル機能を実装
   - 30秒タイムアウトを設定

   Refs: #XXX
   ```

**期待される成果物**:

- 整理されたコミット履歴

---

### タスク5: PR作成

**目的**: Pull Requestを作成する

**実行手順**:

1. ブランチをプッシュ:

   ```bash
   git push -u origin task/slide-agent-sdk-integration
   ```

2. `/ai:diff-to-pr`を実行してPRを作成:

   ```
   /ai:diff-to-pr
   ```

3. PRが作成されたことを確認

4. フォールバック（必要時）:

   `/ai:diff-to-pr` が使えない場合は、git/gh CLIで手動対応する。

   ```bash
   gh pr create --title "feat(slide): Claude Agent SDK統合を実装" --body-file outputs/phase-13/pr-description.md
   ```

5. ラベルを付与:
   - `feature`
   - `slide-agent`
   - `sdk-integration`

**期待される成果物**:

- 作成されたPR

**目的**: CIが通過したことを確認する

**実行手順**:

1. CIの実行状況を確認:

   ```bash
   gh pr checks
   ```

2. CIが失敗した場合:
   - 失敗原因を調査
   - 修正してプッシュ
   - 再度CIを確認

**期待される成果物**:

- CI通過確認

   | テスト             | テストカバレッジ、エッジケース             |
   | パフォーマンス     | 非同期処理、メモリリーク対策               |
