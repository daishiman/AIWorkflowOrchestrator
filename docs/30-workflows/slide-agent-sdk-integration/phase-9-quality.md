## 目的

定義された品質基準をすべて満たすことを検証する。SDK統合コードの機能検証、コード品質、テスト網羅性、セキュリティを総合的に確認する。

## 背景

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 機能検証

**目的**: 全自動テストの成功を確認する

**実行手順**:

1. ユニットテストを実行:

   ```bash
   pnpm --filter @repo/desktop test
   ```

2. 統合テストを実行:

   ```bash
   pnpm --filter @repo/desktop test sdk-integration
   ```

3. E2Eテストを実行（該当する場合）:

   ```bash
   pnpm --filter @repo/desktop test:e2e
   ```

4. 結果を記録:

   | テスト種別 | テスト数 | 成功 | 失敗 | 判定 |
   | ---------- | -------- | ---- | ---- | ---- |
   | ユニット   |          |      |      | [ ]  |
   | 統合       |          |      |      | [ ]  |
   | E2E        |          |      |      | [ ]  |

**期待される成果物**:

- テスト実行結果

---

### タスク2: コード品質チェック

**目的**: Lint/型チェックがクリアであることを確認する

**実行手順**:

1. ESLintを実行:

   ```bash
   pnpm lint
   ```

2. TypeScript型チェックを実行:

   ```bash
   pnpm typecheck
   ```

3. Prettierフォーマットチェック:

   ```bash
   pnpm format:check
   ```

4. 結果を記録:

   | チェック項目 | エラー数 | 警告数 | 判定 |
   | ------------ | -------- | ------ | ---- |
   | ESLint       |          |        | [ ]  |
   | TypeScript   |          |        | [ ]  |
   | Prettier     |          |        | [ ]  |

**期待される成果物**:

- コード品質チェック結果

---

### タスク3: テスト網羅性確認

**目的**: カバレッジ基準が達成されていることを確認する

**実行手順**:

1. カバレッジ測定:

   ```bash
   pnpm --filter @repo/desktop test:coverage
   ```

2. 結果を記録:

   | 指標              | 基準 | 実測値 | 判定 |
   | ----------------- | ---- | ------ | ---- |
   | Line Coverage     | 80%+ |        | [ ]  |
   | Branch Coverage   | 60%+ |        | [ ]  |
   | Function Coverage | 80%+ |        | [ ]  |

3. 総合カバレッジ指数を計算:
   - 総合カバレッジ指数 = Line + Branch + Function
   - 目標: 180%以上

**期待される成果物**:

- カバレッジ確認結果

---

### タスク4: セキュリティチェック

**目的**: 重大なセキュリティ脆弱性がないことを確認する

**実行手順**:

1. 依存関係の脆弱性スキャン:

   ```bash
   pnpm audit
   ```

2. APIキー管理のセキュリティ確認:

   | 確認項目                                  | 対応状況 | 判定 |
   | ----------------------------------------- | -------- | ---- |
   | APIキーがコードにハードコードされていない |          | [ ]  |
   | APIキーがsafeStorageで暗号化されている    |          | [ ]  |
   | APIキーがログに出力されていない           |          | [ ]  |
   | エラーメッセージにAPIキーが含まれない     |          | [ ]  |

3. 結果を記録

**期待される成果物**:

- セキュリティチェック結果

---
