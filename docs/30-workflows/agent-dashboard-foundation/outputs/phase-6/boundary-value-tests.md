## 境界値分析

### 1. スキル配列 (skills)

| パラメータ | 下限値 | 上限値 | 境界値テストケース  |
| ---------- | ------ | ------ | ------------------- |
| 配列長     | 0      | ∞      | 0, 1, 100, 1000     |
| スキルID   | ""     | N/A    | "", "a", 長い文字列 |
| スキル名   | ""     | N/A    | "", "a", 1000文字   |

#### テストケース

| ID            | 入力値            | 期待結果             | 分類       |
| ------------- | ----------------- | -------------------- | ---------- |
| BV-SKILLS-001 | skills = []       | 空配列を保持         | 下限値     |
| BV-SKILLS-002 | skills = [1件]    | 1件のスキルを保持    | 下限+1     |
| BV-SKILLS-003 | skills = [100件]  | 100件のスキルを保持  | 大量データ |
| BV-SKILLS-004 | skills = [1000件] | 1000件のスキルを保持 | 極大値     |

### 2. スキルフィルター (skillFilter)

| パラメータ | 下限値 | 上限値 | 境界値テストケース                 |
| ---------- | ------ | ------ | ---------------------------------- |
| 文字列長   | 0      | ∞      | "", "a", 1000文字                  |
| 特殊文字   | N/A    | N/A    | 空白, 日本語, 絵文字, 正規表現文字 |

#### テストケース

| ID            | 入力値    | 期待結果           | 分類       |
| ------------- | --------- | ------------------ | ---------- |
| BV-FILTER-001 | ""        | 空文字列を保持     | 下限値     |
| BV-FILTER-002 | "a"       | 1文字を保持        | 最小有効値 |
| BV-FILTER-003 | 1000文字  | 長い文字列を保持   | 大量データ |
| BV-FILTER-004 | "テスト"  | 日本語を保持       | 多言語     |
| BV-FILTER-005 | ".\*+?^$" | 正規表現文字を保持 | 特殊文字   |
| BV-FILTER-006 | "🎉"      | 絵文字を保持       | Unicode    |

### 3. 実行出力 (executionOutput)

| パラメータ | 下限値 | 上限値 | 境界値テストケース   |
| ---------- | ------ | ------ | -------------------- |
| 配列長     | 0      | ∞      | 0, 1, 100, 1000      |
| 行の長さ   | 0      | ∞      | "", 1文字, 10000文字 |

#### テストケース

| ID            | 入力値          | 期待結果         | 分類       |
| ------------- | --------------- | ---------------- | ---------- |
| BV-OUTPUT-001 | []              | 空配列           | 下限値     |
| BV-OUTPUT-002 | [1行]           | 1行を保持        | 最小有効値 |
| BV-OUTPUT-003 | [100行]         | 100行を保持      | 大量データ |
| BV-OUTPUT-004 | [1000行]        | 1000行を保持     | 極大値     |
| BV-OUTPUT-005 | [""]            | 空文字列行を保持 | 空行       |
| BV-OUTPUT-006 | [10000文字の行] | 長い行を保持     | 極大行     |

### 4. エラーメッセージ (error)

| パラメータ | 下限値 | 上限値 | 境界値テストケース   |
| ---------- | ------ | ------ | -------------------- |
| 文字列長   | 0      | ∞      | null, "", 長い文字列 |

#### テストケース

| ID           | 入力値   | 期待結果         | 分類       |
| ------------ | -------- | ---------------- | ---------- |
| BV-ERROR-001 | null     | エラーなし       | 下限値     |
| BV-ERROR-002 | ""       | 空エラー（無効） | 境界       |
| BV-ERROR-003 | "Error"  | 短いエラー       | 通常       |
| BV-ERROR-004 | 1000文字 | 長いエラーを保持 | 大量データ |

### 5. 実行ステータス (executionStatus)

| 値        | 遷移先                               | 遷移テスト       |
| --------- | ------------------------------------ | ---------------- |
| idle      | executing, completed, error, aborted | 全遷移をテスト   |
| executing | completed, error, aborted, idle      | 全遷移をテスト   |
| completed | idle                                 | リセットをテスト |
| error     | idle                                 | リセットをテスト |
| aborted   | idle                                 | リセットをテスト |

## 同値分割

### スキル (Skill) オブジェクト

| フィールド  | 有効クラス          | 無効クラス                |
| ----------- | ------------------- | ------------------------- |
| id          | 非空文字列          | 空文字列, null, undefined |
| name        | 非空文字列          | 空文字列, null, undefined |
| description | 任意文字列          | null, undefined           |
| path        | 有効パス            | 空文字列                  |
| triggers    | 配列                | null, undefined           |
| category    | 文字列 or undefined | null (許容する場合も)     |

### 実行ステータス

| 有効クラス  | 無効クラス     |
| ----------- | -------------- |
| "idle"      | その他の文字列 |
| "executing" | 数値           |
| "completed" | null           |
| "error"     | undefined      |
| "aborted"   | オブジェクト   |
