### ステップ2: テストケース詳細

#### TC-001: Backend lint コマンド正常実行

| 項目     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 前提条件 | `apps/backend/package.json` と `eslint.config.mjs` が更新済み |
| 実行手順 | `pnpm --filter @repo/backend lint` を実行                     |
| 期待結果 | 正常終了（exit code 0）、lint エラーなし                      |
| 検証方法 | コマンドの終了コード確認                                      |

#### TC-002: Backend lint コマンドのエラー検出

| 項目     | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 前提条件 | 意図的に lint エラーを含むファイルを配置                                    |
| 実行手順 | lint エラーを含むファイルに対して `pnpm --filter @repo/backend lint` を実行 |
| 期待結果 | エラーが検出され exit code が 0 以外                                        |
| 検証方法 | コマンドの終了コードとエラーメッセージ確認                                  |

#### TC-003: ルート lint コマンド正常実行

| 項目     | 内容                                                |
| -------- | --------------------------------------------------- |
| 前提条件 | backend の設定変更が完了済み                        |
| 実行手順 | ルートで `pnpm lint` を実行                         |
| 期待結果 | 正常終了（exit code 0）、既存の lint 結果に変化なし |
| 検証方法 | コマンドの終了コード確認                            |

#### TC-004: ESLint 設定の構文チェック

| 項目     | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| 前提条件 | `eslint.config.mjs` が更新済み                                  |
| 実行手順 | `cd apps/backend && npx eslint --print-config src/app/page.tsx` |
| 期待結果 | 設定が正しく解決され、ルール一覧が出力される                    |
| 検証方法 | 出力に Next.js 推奨ルールが含まれていることを確認               |

#### TC-005: Next.js 推奨ルール適用確認

| 項目     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 前提条件 | `eslint.config.mjs` に `next/core-web-vitals` が設定済み |
| 実行手順 | `--print-config` で適用ルールを確認                      |
| 期待結果 | `@next/next/*` ルールが適用されている                    |
| 検証方法 | 設定ダンプに Next.js 固有ルールが含まれる                |

#### TC-006: キャッシュ動作確認

| 項目     | 内容                                                |
| -------- | --------------------------------------------------- |
| 前提条件 | lint コマンドが正常動作する                         |
| 実行手順 | 1. `pnpm --filter @repo/backend lint` を2回連続実行 |
| 期待結果 | 2回目の実行が1回目より高速（キャッシュ利用）        |
| 検証方法 | 実行時間の比較                                      |

#### TC-007: ignores 設定の動作確認

| 項目     | 内容                                                |
| -------- | --------------------------------------------------- |
| 前提条件 | ignores にテストファイル・ビルド出力が設定済み      |
| 実行手順 | lint 実行時にテストファイルが対象外であることを確認 |
| 期待結果 | `__tests__/**`、`.next/**` 等が lint 対象外         |
| 検証方法 | `--debug` オプションで対象ファイル一覧を確認        |
