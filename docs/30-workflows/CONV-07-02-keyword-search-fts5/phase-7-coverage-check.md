## 目的

テストカバレッジが目標値を達成しているかを確認し、不足があれば追加テストを作成する。

## 背景

品質保証の基盤として、テストカバレッジ目標（Line 80%、Branch 60%、Function 80%）の達成を検証する。既存実装では93.39%を達成しており、同等以上を目指す。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジレポートの生成

**目的**: 現在のテストカバレッジを計測する

**実行手順**:

1. カバレッジ計測コマンドを実行

```bash
pnpm --filter @repo/shared test -- --coverage --testPathPattern="keyword-search"
```

2. カバレッジレポートを確認
3. 未カバー行・分岐を特定

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: カバレッジ目標達成状況の確認

**目的**: 目標値との差分を確認する

**実行手順**:

1. Line Coverage: 80%以上か確認（目標93%+）
2. Branch Coverage: 60%以上か確認（目標80%+）
3. Function Coverage: 80%以上か確認（目標100%）
4. 未達の場合は不足箇所を特定

**カバレッジ目標**:

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 93%+     |
| Branch Coverage   | 60%      | 80%+     |
| Function Coverage | 80%      | 100%     |

**期待される成果物**:

- `outputs/phase-7/coverage-analysis.md`

---

### タスク3: 不足テストの追加（未達の場合）

**目的**: カバレッジ目標を達成するテストを追加する

**実行手順**:

1. 未カバー行に対するテストを作成
2. 未カバー分岐に対するテストを作成
3. 再度カバレッジを計測
4. 目標達成を確認

**期待される成果物**:

- 追加テストケース（必要な場合）

---

### タスク4: 統合テストの再実行

**目的**: 統合テストが全て成功することを確認する

**実行手順**:

1. 統合テストを実行

```bash
pnpm --filter @repo/shared test -- --testPathPattern="keyword-search.integration"
```

2. 失敗テストがあれば修正
3. 全テスト成功を確認

**期待される成果物**:

- `outputs/phase-7/integration-test-result.md`
