### タスク1: 基本動作確認

**目的**: キーワード検索の基本機能を手動で確認する

**実行手順**:

1. キーワード検索の実行
   - 単一キーワードで検索
   - 複数キーワードで検索
   - 結果の確認

2. フレーズ検索の実行
   - ダブルクォートで囲んだ検索
   - 完全一致のみ返ることを確認

3. 近接検索の実行
   - searchNear()での検索
   - 距離指定の動作確認

4. 検索結果の確認
   - スコアの降順ソート
   - ハイライト情報の確認

**期待される成果物**:

- `outputs/phase-11/manual-test-basic.md`

## テストシナリオ

### シナリオ1: 技術文書検索

```
入力: "TypeScript React"
期待結果:
- TypeScriptとReactを含むチャンクが返る
- BM25スコアに基づいてソートされる
- 0-1に正規化されたスコア
```

### シナリオ2: フレーズ検索

```
入力: "\"async await pattern\""
期待結果:
- "async await pattern"という完全一致フレーズを含むチャンクのみ返る
- 部分一致は除外される
```

### シナリオ3: 近接検索

```
入力: searchNear("database index", 5)
期待結果:
- "database"と"index"が5単語以内に出現するチャンクが返る
```
