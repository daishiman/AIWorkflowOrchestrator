# Phase 10: 最終レビュー

## メタ情報

| 項目      | 内容                                     |
| --------- | ---------------------------------------- |
| Phase     | 10                                       |
| 名称      | 最終レビュー                             |
| 前提Phase | Phase 9                                  |

## 目的

実装全体の差分をレビューし、見落としや設計からの逸脱がないことを確認する。PR 作成前の最終品質ゲートとして機能する。

## 実行タスク

### Task 10-1: 変更ファイル差分レビュー

```bash
git diff --stat main...HEAD
```

以下の全変更ファイルに対して差分をレビューする：

| ファイル                                               | 変更種別 | レビュー観点                                                  |
| ------------------------------------------------------ | -------- | ------------------------------------------------------------- |
| `packages/shared/tsup.config.ts`                       | 修正     | `format: ["esm", "cjs"]` が正しく設定されているか             |
| `packages/shared/package.json`                         | 修正     | 全 37 exports に `require` が追加されているか。パスが正しいか |
| `apps/desktop/electron.vite.config.ts`                 | 修正     | main と preload 両方に `exclude: ['@repo/shared']` があるか   |
| `apps/desktop/package.json`                            | 修正     | `@electron/rebuild` が devDep にあるか。スクリプトが正しいか  |
| `apps/desktop/electron-builder.yml`                    | 修正     | `afterPack` のパスが正しいか                                  |
| `scripts/setup-native-modules.sh`                      | 修正     | Electron チェック・リビルドロジックが正しいか                 |
| `apps/desktop/scripts/rebuild-native-for-electron.mjs` | 新規     | `rebuild()` の引数が正しいか                                  |
| `package.json`（root）                                 | 修正     | postinstall から冗長なフォールバックが削除されているか        |
| テストファイル群                                       | 新規     | テストロジックが正しいか                                      |
