## ドキュメント更新内容

### ユーザーガイド（search-replace.md）

```markdown
# 検索・置換機能

## ファイル内検索

### 検索パネルを開く

- キーボードショートカット: `Ctrl+F` (macOS: `Cmd+F`)

### 検索オプション

- 大文字/小文字を区別: アイコンをクリックして切り替え
- 単語単位で検索: 完全一致のみを検索
- 正規表現: パターンマッチング検索

### 検索結果のナビゲーション

- 次の結果: `F3` または `Enter`
- 前の結果: `Shift+F3`

## ファイル内置換

### 置換パネルを表示

- キーボードショートカット: `Ctrl+H` (macOS: `Cmd+H`)
- または検索パネルの展開ボタン

### 置換操作

- 単一置換: 現在の一致のみを置換
- 全置換: 全ての一致を置換

## ワークスペース検索

### ワークスペース検索パネルを開く

- キーボードショートカット: `Ctrl+Shift+F` (macOS: `Cmd+Shift+F`)

### 検索結果

- ファイル別にグルーピング表示
- クリックで該当ファイル・行に移動

### フィルタリング

- ファイルパターン: 特定のファイルタイプのみ検索
- 除外パターン: node_modules等を除外

## ワークスペース置換

### 置換操作

- プレビュー: 置換前に変更内容を確認
- 確認ダイアログ: 複数ファイルの変更前に確認
```

### 開発者ドキュメント（search-engine.md）

```markdown
# 検索エンジン 技術仕様

## アーキテクチャ

SearchService → FileSearchEngine, WorkspaceSearchEngine, ReplaceEngine

## API

### searchInFile

ファイル内容から検索パターンにマッチする箇所を検索

### searchInWorkspace

ワークスペース全体から検索（AsyncGenerator）

### replaceInFile

ファイル内容の検索パターンを置換

### replaceInWorkspace

ワークスペース全体で置換

## パフォーマンス考慮事項

- 大きなファイル: 非同期処理
- ワークスペース検索: ストリーミング
- 正規表現: ReDoS対策（タイムアウト）
```

### キーボードショートカット更新

| ショートカット | 機能                     |
| -------------- | ------------------------ |
| Ctrl+F         | ファイル内検索を開く     |
| Ctrl+H         | ファイル内置換を開く     |
| Ctrl+Shift+F   | ワークスペース検索を開く |
| F3             | 次の検索結果             |
| Shift+F3       | 前の検索結果             |
| Escape         | 検索パネルを閉じる       |
