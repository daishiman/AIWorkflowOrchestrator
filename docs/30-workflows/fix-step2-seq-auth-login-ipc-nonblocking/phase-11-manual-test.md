## 目的

実際の Electron アプリで OAuth フローが正常に動作することを目視確認する。
fire-and-forget 化後も `AUTH_STATE_CHANGED` イベントが正しく受信されることを確認する。

## 実行タスク

### タスク1: Electron アプリ起動

```bash
pnpm --filter @repo/desktop dev
```

### タスク2: OAuth ログインフロー確認

**手動テストシナリオ**:

| シナリオ                       | 確認手順                                                                  | 期待結果                                                |
| ------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------- |
| Google ログイン正常系          | ログイン画面で「Google でログイン」をクリック → ブラウザが開く → 認証完了 | アプリがメイン画面に遷移する                            |
| GitHub ログイン正常系          | 同様                                                                      | アプリがメイン画面に遷移する                            |
| ログインタイムアウトエラー不発 | ログインボタンクリック後 500ms 以内にエラーが表示されないこと             | エラーなし（fire-and-forget）                           |
| ログイン失敗時の通知           | OAuth でキャンセルまたはエラー時                                          | エラーメッセージが表示される（AUTH_STATE_CHANGED 経由） |

### 確認ポイント

- [ ] 「`IPC timeout: auth:login did not respond within 500ms`」エラーが発生しないこと
- [ ] 認証成功後にアプリがメイン画面に遷移すること
- [ ] 認証失敗時にエラーメッセージが表示されること
- [ ] ログアウト後に再ログインできること
