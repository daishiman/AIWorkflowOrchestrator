## 目的

| 判定  | 条件             | 対応                         |

## レビュー観点

### 1. コンポーネント設計レビュー

| チェック項目                | 確認内容                                             |
| --------------------------- | ---------------------------------------------------- |
| Props設計の妥当性           | `skill: SkillMetadata`型が十分な情報を提供しているか |
| コンポーネント分割の適切さ  | Section/ResourceListの分割粒度は適切か               |
| useAppStoreとの連携パターン | importSkill/isImporting/importingSkillNameで十分か   |
| 条件表示ロジック            | 空配列時のセクション非表示が正しく設計されているか   |

### 2. UI/UX設計レビュー

| チェック項目   | 確認内容                                                |
| -------------- | ------------------------------------------------------- |
| レイアウト構造 | max-w-2xl/max-h-[80vh]は適切か                          |
| スクロール設計 | コンテンツ量が多い場合のoverflow-y-autoは適切か         |
| ボタン配置     | キャンセル/インポートの配置（右寄せ）は適切か           |
| ローディングUI | 「インポート中...」テキスト変更のフィードバックは十分か |

### 3. アクセシビリティレビュー

| チェック項目       | 確認内容                                            |
| ------------------ | --------------------------------------------------- |
| ARIA属性           | role/aria-modal/aria-labelledbyが正しく設定されるか |
| フォーカストラップ | PermissionDialogのパターンで実現可能か              |
| キーボード操作     | ESC/Tab/Shift+Tabで期待通り動作するか               |
| 色コントラスト     | WCAG 2.1 AAの4.5:1比率を満たすか                    |

### 4. SkillSlice連携レビュー

| チェック項目              | 確認内容                                    |
| ------------------------- | ------------------------------------------- |
| importSkillの呼び出し     | awaitでインポート完了を待てるか             |
| isImportingの判定ロジック | 複数スキル同時インポート時の考慮は必要か    |
| エラーハンドリング        | importSkill失敗時のUI表示は考慮されているか |
| onClose呼び出しタイミング | インポート完了後の自動クローズは適切か      |

## 統合テスト連携【必須】

統合テスト観点のレビューゲートを実施:

| レビュー観点       | 確認項目                                         |
| ------------------ | ------------------------------------------------ |
| 状態管理連携       | useAppStoreからのデータ取得設計の妥当性          |
| 型安全性           | SkillMetadata/SkillSubResource型の利用方法       |
| エラーハンドリング | importSkill失敗時のダイアログ表示設計            |
| データフロー       | SkillSelector → Dialog → SkillSlice のフロー設計 |
