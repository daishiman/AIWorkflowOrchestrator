## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

設計タスク（spec_created）でも Phase 1-13 を運用しているが、既存テンプレートは実装タスク前提のため、成果物定義と判定基準が揺れやすい。

### 1.2 問題点・課題

- Phase 4-9 の成果物が「コード」前提で書かれている。
- Phase 11 の扱い（スクリーンショット前提）が設計タスクと噛み合いにくい。
- 並列実行時に SubAgent の完了判定が曖昧。

### 1.3 放置した場合の影響

- Phase 10/12 で毎回「形式不足」の手戻りが発生。
- spec_created タスクの品質が担当者依存になる。

## 2. 何を達成するか（What）

### 2.1 目的

設計タスク用の Phase テンプレート変換ルールを定義し、再監査のばらつきを減らす。

### 2.2 最終ゴール

- `分類: 設計` のときの Phase 4-9/11 成果物定義が固定される。
- SubAgent 分割基準とフォールバック手順がテンプレート化される。

### 2.3 スコープ

#### 含むもの

- 設計タスク向け成果物マッピング。
- `task-specification-creator` の分岐ルール定義。
- Pitfall 追加（設計タスク特有の再発パターン）。

#### 含まないもの

- 既存実装タスクテンプレートの廃止。
- 既存全workflowの一括移行。

### 2.4 成果物

- 設計タスク向け Phase マッピング表。
- SubAgent 運用ガイド追記。
- Pitfall 追補案（P57/P58 相当）。

## 3. どのように実行するか（How）

### 3.1 前提条件

- `task-specification-creator` のテンプレート資産を編集可能。
- `05-task-execution.md` / `06-known-pitfalls.md` が最新。

### 3.2 依存タスク

- TASK-IMP-AI-RUNTIME-AUTHMODE-UNIFICATION-001（再監査経験の反映）。

### 3.3 必要な知識

- Phase 1-13 運用、spec_created 判定、SubAgent 並列実行パターン。

### 3.4 推奨アプローチ

- 実装タスクと設計タスクを明示分岐し、共通部だけ再利用する。
- 自動判定可能なチェックを優先してテンプレートへ組み込む。

## 4. 実行手順

### Phase構成

- Phase A: 差分整理
- Phase B: テンプレート定義
- Phase C: 運用ガード追加

### Phase A: 差分整理

#### 目的

実装タスク前提と設計タスク前提の差異を特定する。

#### 手順

1. Phase 4-9/11 の既存テンプレートを棚卸し。
2. 設計タスク実績（Task01）との不一致を抽出。
3. 必須変換項目を一覧化。

#### 成果物

差分一覧表。

#### 完了条件

テンプレート差分が網羅されている。

### Phase B: テンプレート定義

#### 目的

設計タスク向け定義を明文化する。

#### 手順

1. `分類: 設計` 分岐の成果物マッピングを作成。
2. Phase 8/9 を文書品質活動として再定義。
3. Phase 11 の設計レビュー運用を定義。

#### 成果物

更新テンプレート案。

#### 完了条件

設計タスクで 1-13 が矛盾なく実行できる。

### Phase C: 運用ガード追加

#### 目的

並列実行時の失敗と早期完了誤記を減らす。

#### 手順

1. SubAgent 分割上限（3ファイル/agent）を明記。
2. 完了判定に `git diff --stat` を必須化。
3. タイムアウト時フォールバック手順を追記。
4. Pitfall へ再発パターンを登録。

#### 成果物

運用ガード更新版テンプレート。

#### 完了条件

同種タスクで再利用可能な手順になっている。

## 6. 検証方法

### テストケース

- 設計タスク1件で新テンプレート適用を試行し、Phase 4-9/11 が自然に埋まること。
- `audit-unassigned-tasks --target-file` で未タスク指示書フォーマットが通ること。

### 検証手順

1. サンプル設計タスクを生成。
2. `verify-all-specs` / `validate-phase-output` で整合確認。
3. SubAgent 分割と完了判定ログをレビュー。
