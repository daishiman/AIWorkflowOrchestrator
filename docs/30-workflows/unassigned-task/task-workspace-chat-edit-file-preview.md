## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-WCE-UI-001（Issue #494）でFileContextListコンポーネントを実装した。現在、添付されたファイルはファイル名とサイズのみ表示される。ユーザーは添付前にファイル内容を確認することができない。

### 1.2 問題点・課題

| 項目               | 現状 | 課題                                 |
| ------------------ | ---- | ------------------------------------ |
| ファイル内容確認   | 不可 | 誤ったファイルを添付するリスク       |
| プレビュー         | なし | ファイルを開かないと内容が分からない |
| ファイル選択の効率 | 低   | 確認のために複数回の操作が必要       |

### 1.3 放置した場合の影響

- ユーザーが誤ったファイルを添付してしまうリスク
- チャットに不要なファイルが送信される可能性
- ワークフローの効率低下

---

## 2. 何を達成するか（What）

### 2.1 目的

添付ファイルをホバーまたはクリックした際に、ファイル内容のプレビューを表示する。

### 2.2 最終ゴール

- テキストファイル（.txt, .md, .ts, .tsx）のコード/テキストプレビュー
- 画像ファイル（.png, .jpg, .gif）のサムネイルプレビュー
- プレビュー不可ファイルの適切なフォールバック表示

### 2.3 スコープ

#### 含むもの

- FilePreviewPopoverコンポーネント新規作成
- テキストファイルのシンタックスハイライト付きプレビュー
- 画像ファイルのサムネイルプレビュー
- キーボードナビゲーション対応
- アクセシビリティ対応

#### 含まないもの

- PDFプレビュー
- 動画ファイルプレビュー
- ファイル編集機能
- サーバーサイドのファイル処理

### 2.4 成果物

| 成果物                         | 配置先                                                               |

| FilePreviewPopover.tsx         | `apps/desktop/src/renderer/features/workspace-chat-edit/components/` |

| FilePreviewPopover.stories.tsx | `stories/`                                                           |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-WCE-UI-001（Issue #494）が完了していること
- FileContextListコンポーネントが存在すること
- Electron IPC経由でファイル内容を読み取れること

### 3.2 依存タスク

| タスク          | 状態 |
| --------------- | ---- |
| TASK-WCE-UI-001 | 完了 |

### 3.3 必要な知識

- React / TypeScript
- Tailwind CSS
- Electron IPC（ファイル読み取り）
- シンタックスハイライト（Prism.js or highlight.js）
- WCAG 2.1 AAアクセシビリティ要件

### 3.4 推奨アプローチ

1. FilePreviewPopoverコンポーネントを新規作成
2. ファイル種別判定ロジックを実装
3. テキストプレビュー（シンタックスハイライト付き）を実装
4. 画像プレビュー（サムネイル）を実装
5. FileContextBadgeにプレビュートリガーを追加
6. キーボードナビゲーション・アクセシビリティ対応

### Phase 5: 実装

#### 目的

FilePreviewPopoverコンポーネントを実装し、FileContextBadgeと連携させる

#### 手順

1. ファイル種別判定ユーティリティを作成
   - テキストファイル: .txt, .md, .ts, .tsx, .js, .json, .yaml, .yml
   - 画像ファイル: .png, .jpg, .jpeg, .gif, .webp
   - その他: プレビュー不可表示

2. FilePreviewPopoverコンポーネントを作成
   - ポップオーバーレイアウト（最大幅400px、最大高さ300px）
   - ファイル種別に応じたレンダリング
   - ローディング状態の表示
   - エラー状態の表示

3. テキストプレビューサブコンポーネント
   - 行番号表示
   - シンタックスハイライト（言語自動検出）
   - スクロール可能エリア
   - 最大100行までの表示制限

4. 画像プレビューサブコンポーネント
   - アスペクト比維持のサムネイル
   - 代替テキスト表示
   - ローディングインジケーター

5. FileContextBadgeにトリガー追加
   - ホバー時にプレビュー表示（遅延300ms）
   - クリックで固定表示
   - Escapeキーで閉じる

#### 成果物

FilePreviewPopover.tsx、FileContextBadge.tsx（更新）

## 7. リスクと対策

| リスク                               | 影響度 | 発生確率 | 対策                                      |
| ------------------------------------ | ------ | -------- | ----------------------------------------- |
| 大きいファイルでのパフォーマンス低下 | 中     | 中       | プレビュー行数制限（100行）、遅延読み込み |
| メモリ使用量増加                     | 中     | 低       | プレビュー閉じたらキャッシュクリア        |
| セキュリティリスク                   | 高     | 低       | ファイル内容のサニタイズ、XSS対策         |
