## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-9B-GでResourceLoaderにキャッシュ機能を実装した。
スキルファイルやスキーマは一度読み込むとメモリにキャッシュされ、再読み込みを回避する。

### 1.2 問題点・課題

- 現在のキャッシュは無効化する仕組みがない
- 外部でスキルファイルが更新されても、古いキャッシュが使用される
- 開発中のスキルを更新しても反映されない

### 1.3 放置した場合の影響

- スキル更新後もアプリケーション再起動が必要
- 開発体験の低下
- デバッグ時の混乱

---

## 2. 何を達成するか（What）

### 2.1 目的

ResourceLoaderにキャッシュ無効化（invalidation）機能を追加する。

### 2.2 最終ゴール

- 特定キャッシュエントリの無効化
- 全キャッシュのクリア
- ファイル変更検知による自動無効化（オプション）

### 2.3 スコープ

#### 含むもの

- `invalidate(key)`: 特定エントリ無効化
- `invalidateAll()`: 全エントリクリア
- `invalidateByPattern(pattern)`: パターンマッチ無効化
- ユニットテスト

#### 含まないもの

- ファイルウォッチャー実装（別タスク推奨）
- TTL（有効期限）ベースの自動無効化

### 2.4 成果物

| 成果物         | パス                                                                            |
| -------------- | ------------------------------------------------------------------------------- |
| ResourceLoader | `apps/desktop/src/main/services/skill/ResourceLoader.ts`（更新）                |
| テスト         | `apps/desktop/src/main/services/skill/__tests__/ResourceLoader.test.ts`（追記） |

| 項目     | 内容                                                   |
