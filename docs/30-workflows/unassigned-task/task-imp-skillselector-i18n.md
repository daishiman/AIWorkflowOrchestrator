## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-7AでSkillSelectorコンポーネントを実装した際、UIテキストが日本語でハードコードされている。現在のプロジェクトはi18n（国際化）対応を進めており、他のコンポーネントはreact-i18nextを使用した多言語対応が実装されている。SkillSelectorも同様の対応が必要。

### 1.2 問題点・課題

- 「スキルを選択」「なし」「インポート済みスキル」等のUIテキストが日本語ハードコード
- アプリケーション全体の言語設定変更に追従しない
- 日本語以外のユーザーにとって使用困難

### 1.3 放置した場合の影響

- 多言語対応アプリケーションとしての一貫性が失われる
- 海外ユーザーの利用障壁
- 将来的なローカライズ作業の負担増大

---

## 2. 何を達成するか（What）

### 2.1 目的

SkillSelectorコンポーネントの全UIテキストをi18n対応し、アプリケーションの言語設定に応じて日本語・英語を切り替え可能にする。

### 2.2 最終ゴール

- 全ハードコードされた日本語テキストがreact-i18nextのt()関数経由に置換されている
- 言語切り替え時に即座にUIテキストが更新される
- 既存のi18nネームスペース構造に準拠している

### 2.3 スコープ

#### 含むもの

- SkillSelector.tsx内の全日本語テキストのi18n化
- 翻訳リソースファイル（ja.json, en.json）への追加
- 単体テストの更新（モック対応）

#### 含まないもの

- 他言語（中国語、韓国語等）の追加
- 翻訳品質のレビュー
- i18nライブラリの変更

### 2.4 成果物

| 成果物                 | 説明                       |
| ---------------------- | -------------------------- |
| SkillSelector.tsx      | i18n対応済みコンポーネント |
| ja.json                | 日本語翻訳リソース追加     |
| en.json                | 英語翻訳リソース追加       |
| SkillSelector.test.tsx | i18nモック対応テスト       |
