## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

task-imp-permission-readable-ui-001で固定テンプレート方式の人間可読説明文が実装された。現在の説明文テンプレートはハードコードされており、ユーザーが自分の好みに合わせてカスタマイズすることができない。パワーユーザーは技術的な詳細を好み、初心者は平易な説明を好む等、ユーザーによってニーズが異なる。

### 1.2 問題点・課題

| 課題             | 詳細                                   |
| ---------------- | -------------------------------------- |
| カスタマイズ不可 | 説明文のスタイルを変更できない         |
| ユーザー多様性   | 技術レベルに応じた説明が選べない       |
| 固定的な表示方式 | 詳細展開のデフォルト状態を変更できない |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                     | 重要度 |
| ------------ | ---------------------------- | ------ |
| UX品質       | ユーザーの好みに合わない表示 | 低     |
| 柔軟性       | パワーユーザーの効率低下     | 低     |

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogの説明文表示をユーザーがカスタマイズできる設定画面を提供する。

### 2.2 最終ゴール

- [ ] 説明文の詳細レベルを選択できる（簡潔/標準/詳細）
- [ ] 詳細展開のデフォルト状態を設定できる
- [ ] 設定がアプリ再起動後も保持される
- [ ] 既存テストが全てPASSする

### 2.3 スコープ

**含まれるもの**:

- 設定画面UI
- 設定の永続化（PermissionStore統合）
- 説明文レベル切り替えロジック
- テストケースの追加

**含まれないもの**:

- ユーザー独自テンプレートの作成機能
- テンプレートのインポート/エクスポート
- ツール別の個別設定

### 2.4 成果物

| 成果物               | パス                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| 設定UIコンポーネント | `apps/desktop/src/renderer/components/skill/PermissionSettings.tsx`（既存に追加）  |
| 修正後モジュール     | `apps/desktop/src/renderer/components/skill/permissionDescriptions.ts`             |
| 追加テスト           | `apps/desktop/src/renderer/components/skill/__tests__/PermissionSettings.test.tsx` |
