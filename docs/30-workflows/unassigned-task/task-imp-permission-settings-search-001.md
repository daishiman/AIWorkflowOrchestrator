## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

ui-ux-settings.mdの「ツール許可設定（Permission Settings）」セクションでは、許可済みツール一覧の表示と個別取り消し・全クリア機能が定義されている。現在のUIでは許可済みツールがフラットなリストで表示されるが、使用頻度の増加に伴い許可ツール数が増えた場合に特定のツールを素早く見つける手段がない。

### 1.2 問題点・課題

- 許可済みツール数が10件を超えると、目的のツールを探すのに時間がかかる
- 特定のツール（例: 特定パスへのRead許可）を個別に取り消したい場合に一覧からの検索が困難
- フィルタリング機能がないため、ツール名やパターンでの絞り込みができない

### 1.3 放置した場合の影響

- ユーザーが不要な永続許可を放置する（取り消し操作が面倒）
- セキュリティメンテナンスの実施率が低下する
- 許可済みツールの管理が煩雑になり、「全クリア」操作に頼る非効率な運用になる

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionSettingsの許可済みツール一覧にリアルタイム検索・フィルタ機能を追加し、特定ツールへの迅速なアクセスを実現する。

### 2.2 最終ゴール

- 許可済みツール一覧の上部に検索入力フィールドが表示される
- ツール名、引数パターンでリアルタイムフィルタリングが可能
- フィルタ結果の件数が表示される
- クリアボタンでフィルタをリセットできる

### 2.3 スコープ

#### 含むもの

- 検索入力フィールドの追加
- ツール名による部分一致フィルタリング
- 引数パターンによるフィルタリング
- 結果件数表示
- クリアボタン
- キーボードショートカット（Ctrl/Cmd+F でフォーカス）
- ユニットテスト・コンポーネントテスト

#### 含まないもの

- 高度な検索構文（正規表現等）
- 検索履歴の保存
- カテゴリフィルタ（別タスク: task-imp-permission-tool-categories-001依存）

## 3. どのように実行するか（How）

### 3.1 前提条件

- PermissionSettings UIが実装されていること（ui-ux-settings.md準拠）
- PermissionStoreに許可済みツール一覧取得APIが存在すること

### 3.2 依存タスク

| タスクID                            | 状態 | 依存内容          |
| ----------------------------------- | ---- | ----------------- |
| task-imp-permission-readable-ui-001 | 完了 | Permission UI基盤 |

### 3.3 必要な知識

- React useStateによるフィルタ状態管理
- 文字列部分一致検索の実装
- Tailwind CSS フォーム要素スタイリング
- キーボードイベントハンドリング

### 3.4 推奨アプローチ

1. `filterPermissions(permissions: AllowedTool[], query: string): AllowedTool[]`関数を作成
2. PermissionSettingsコンポーネントに検索入力フィールドを追加
3. `useState`でフィルタクエリを管理し、リアルタイムフィルタリング
4. `useMemo`でフィルタ結果をメモ化（パフォーマンス考慮）
5. 結果件数を「n件中m件表示」形式で表示

## 7. リスクと対策

| リスク                           | 影響度 | 発生確率 | 対策                                   |
| -------------------------------- | ------ | -------- | -------------------------------------- |
| 検索パフォーマンスの劣化         | 低     | 低       | useMemoによるメモ化、debounce処理      |
| 特殊文字（正規表現メタ文字）入力 | 低     | 中       | 入力をエスケープしてプレーン文字列検索 |
| 既存テストとの互換性             | 中     | 低       | 追加UIのため既存テストへの影響なし     |
