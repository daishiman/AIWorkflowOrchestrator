## 目的

GitHub ActionsのCI/CDパイプラインにカバレッジ閾値チェックを統合し、品質低下を自動的に検出・防止する。

## 背景

vitest.config.tsにカバレッジ閾値（80%）は設定済みだが、CI/CDパイプラインには未統合。PRマージ前に自動的にカバレッジをチェックする仕組みが必要。

---

## 実装対象

### 1. GitHub Actions ワークフロー更新

| 項目       | 内容                       |
| ---------- | -------------------------- |
| ファイル   | `.github/workflows/ci.yml` |
| 追加ジョブ | カバレッジチェック         |
| 閾値       | lines: 80%, functions: 80% |
| 失敗時     | PRマージをブロック         |

### 2. Codecov統合

| 項目             | 内容                         |
| ---------------- | ---------------------------- |
| カバレッジ可視化 | Codecovダッシュボード        |
| PRコメント       | カバレッジ差分を自動コメント |

---

## 受け入れ基準

- [ ] CI/CDでカバレッジチェックが実行される
- [ ] 閾値未達でPRがブロックされる
- [ ] Codecovでカバレッジが可視化される
- [ ] PRにカバレッジ差分がコメントされる
