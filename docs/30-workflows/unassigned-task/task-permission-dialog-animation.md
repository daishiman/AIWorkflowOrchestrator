## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-4-2（PermissionResolver IPC Handlers）で実装したPermissionDialogコンポーネントは、表示/非表示がアニメーションなしで瞬時に切り替わる。モダンなUIでは、ダイアログの表示にフェードインやスライドインなどのトランジションを付けることで、ユーザーの注意を適切に引き、より洗練された体験を提供できる。

### 1.2 問題点・課題

| 問題                 | 説明                                             |
| -------------------- | ------------------------------------------------ |
| 唐突な表示           | ダイアログが瞬時に表示され、ユーザーが驚く可能性 |
| 視覚的連続性の欠如   | 表示/非表示の遷移に自然な流れがない              |
| モダンUI基準との乖離 | 他のアプリと比較してUIが古く見える可能性         |

### 1.3 放置した場合の影響

- ユーザー体験の質が若干低下
- アプリ全体の洗練度に影響
- 競合アプリとの比較でUI品質が劣る印象

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogの表示/非表示時にスムーズなアニメーショントランジションを追加し、より洗練されたユーザー体験を提供する。

### 2.2 最終ゴール

- ダイアログ表示時: フェードイン + スケールアップ（0.95→1.0）アニメーション
- ダイアログ非表示時: フェードアウト + スケールダウン（1.0→0.95）アニメーション
- アニメーション時間: 150-200ms（ユーザー設定で無効化可能）
- reduced-motion設定を尊重

### 2.3 スコープ

#### 含むもの

- PermissionDialog.tsxへのアニメーション追加
- オーバーレイ背景のフェードアニメーション
- `prefers-reduced-motion`メディアクエリ対応
- アニメーションON/OFF設定（オプション）
- ユニットテストの更新

#### 含まないもの

- 他のダイアログコンポーネントへの適用
- 複雑なアニメーションライブラリの導入
- 3Dトランスフォームや物理ベースアニメーション

### 2.4 成果物

| 成果物                        | パス                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| 更新されたコンポーネント      | `apps/desktop/src/renderer/components/Permission/PermissionDialog.tsx`                |

| アニメーション用CSS（必要時） | `apps/desktop/src/renderer/styles/animations.css`                                     |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-4-2（PermissionResolver IPC Handlers）が完了していること
- Tailwind CSSのアニメーション機能が利用可能であること

### 3.2 依存タスク

| タスク   | 内容                                        |
| -------- | ------------------------------------------- |
| TASK-4-2 | PermissionResolver IPC Handlers（完了済み） |

### 3.3 必要な知識

- CSS Transitions / Animations
- Tailwind CSSのアニメーションユーティリティ
- `prefers-reduced-motion`メディアクエリ
- React状態遷移とアニメーションの連携

### 3.4 推奨アプローチ

1. CSS Transitionsを使用したシンプルなアニメーション実装
2. Tailwind CSSの`transition-*`クラスを活用
3. `motion-safe:` / `motion-reduce:` バリアントでアクセシビリティ対応
4. 必要に応じて`react-transition-group`などの軽量ライブラリを検討

## 4. 実行手順

### Phase構成

| Phase | 内容                         | 見積もり |
| ----- | ---------------------------- | -------- |
| 1     | 要件定義・アニメーション設計 | 0.5日    |

| 11-13 | 検証・ドキュメント・PR       | 0.5日    |

### Phase 5: 実装

#### 目的

PermissionDialogに表示/非表示アニメーションを追加する。

#### 手順

1. アニメーション用の状態管理を追加（`isAnimating`, `isVisible`）
2. CSSトランジションクラスを定義
3. 表示時: `opacity-0 scale-95` → `opacity-100 scale-100`
4. 非表示時: `opacity-100 scale-100` → `opacity-0 scale-95`
5. オーバーレイ背景のフェードアニメーションを追加
6. `prefers-reduced-motion`対応を追加
7. テストを更新

#### 成果物

- 更新されたPermissionDialog.tsx
- 更新されたテストファイル

#### 完了条件

- [ ] 表示アニメーションが動作する
- [ ] 非表示アニメーションが動作する
- [ ] reduced-motion設定でアニメーションが無効化される
- [ ] テストがパスする

6. システム設定でreduced-motionを有効化
7. アニメーションが無効化されていることを確認
