## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-8C-D（E2Eテスト - 権限ダイアログフロー）のPhase 9ドキュメント品質確認において、プロジェクトREADMEにE2Eテストの実行方法が記載されていないことがMINOR指摘（DOC-M1）として記録された。

### 1.2 問題点・課題

- 新規開発者がE2Eテストの実行方法を知るための情報がREADMEにない
- Playwrightを使用したE2Eテストの存在自体がドキュメント化されていない
- オンボーディング時に追加の口頭説明や個別のファイル探索が必要

### 1.3 放置した場合の影響

- 新規メンバーのオンボーディング効率がわずかに低下
- E2Eテストの存在や実行方法の発見可能性が低下
- **機能的影響はなし**（テスト自体は問題なく動作）

---

## 2. 何を達成するか（What）

### 2.1 目的

プロジェクトREADMEにE2Eテストセクションを追加し、テスト実行方法を文書化する。

### 2.2 最終ゴール

- READMEにE2Eテストセクションが追加されている
- E2Eテストの実行コマンドが記載されている
- トラブルシューティング情報が含まれている

### 2.3 スコープ

#### 含むもの

- `apps/desktop/README.md`（またはプロジェクトルートREADME）へのE2Eテストセクション追加

#### 含まないもの

- E2Eテストコードの修正
- 他のテスト種別（ユニットテスト、統合テスト）のドキュメント更新
- 詳細なテストケース説明

### 2.4 成果物

- 更新されたREADME.md（E2Eテストセクション追加）

## 4. 実行手順

### Phase構成
