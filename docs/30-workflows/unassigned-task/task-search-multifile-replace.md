## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

task-imp-search-ui-001で検索/置換UIを実装した際、単一ファイル内での置換は対応したが、
複数ファイルにまたがる一括置換は「将来的な拡張候補」としてスコープ外とした。

### 1.2 問題点・課題

- 現状は1ファイルずつ手動で置換を実行する必要がある
- リファクタリング時に同じパターンを複数ファイルで置換したい場面で手間がかかる
- VS Code等の主要エディタが持つ機能として期待されるユーザー体験

### 1.3 放置した場合の影響

- ユーザビリティの低下（他エディタとの比較で劣位）
- 大規模リファクタリング作業の効率悪化
- ユーザー離脱リスク（代替手段を求めて外部ツール使用）

---

## 2. 何を達成するか（What）

### 2.1 目的

WorkspaceSearchModalで検索した複数ファイルの結果に対し、
一括で置換を実行できる機能を提供する。

### 2.2 最終ゴール

- WorkspaceSearchModalに「すべて置換」ボタンを追加
- 置換プレビュー表示（変更前/変更後の差分表示）
- 確認ダイアログによる安全な実行フロー

### 2.3 スコープ

#### 含むもの

- 複数ファイル一括置換UI
- 置換プレビュー表示
- 確認ダイアログ
- 置換結果サマリー表示
- Undo機能（1回の操作で全ファイルを元に戻す）

#### 含まないもの

- 正規表現キャプチャグループを使った高度な置換
- 差分の逐次適用（全件一括のみ）
- バックアップファイル自動生成

### 2.4 成果物

| 成果物                   | 説明                                  |
| ------------------------ | ------------------------------------- |
| ReplacePreview.tsx       | 置換プレビューコンポーネント          |
| replaceService.ts        | 複数ファイル置換ロジック              |
| ReplaceConfirmDialog.tsx | 確認ダイアログコンポーネント          |
| E2Eテスト                | マルチファイル置換のE2Eテストスイート |

### 3.3 必要な知識

- React/TypeScript
- Electron IPC通信（Main Process でのファイル操作）
