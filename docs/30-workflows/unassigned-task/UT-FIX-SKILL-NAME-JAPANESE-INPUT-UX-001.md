# UT-FIX-SKILL-NAME-JAPANESE-INPUT-UX-001

## 概要

スキル作成ウィザードで日本語や特殊文字を入力した場合に、`toWizardSkillName()` が生成するスキル名をリアルタイムにプレビュー表示する UX 改善を行う。

## 背景

- TASK-FIX-IPC-SKILL-NAME-001（2026-04-06）で `toWizardSkillName()` の正規化フローを修正し、日本語・特殊文字は自動的に `-` 変換・`new-skill` フォールバックが適用されるようになった。
- しかし、ユーザーが日本語でスキル説明を入力した場合、変換後のスキル名が予測しにくいという UX 上の課題が残る。
- 入力フォーム下にリアルタイムプレビューを表示することで、ユーザーの混乱を防ぐ。

## 実行タスク

1. スキル作成ウィザードの説明入力フォームに、リアルタイム変換プレビュー（「スキル名: xxx-yyy」）を追加する。
2. `toWizardSkillName()` のフロントエンド版（または shared 関数化）を使って Renderer 側でリアルタイム計算する。
3. プレビューは入力変化の debounce（300ms 程度）で更新する。
4. アクセシビリティ（aria-live による読み上げ対応）を考慮する。

## 完了条件

- 説明入力時にリアルタイムでスキル名プレビューが表示される。
- 日本語・特殊文字入力時も正確なプレビューが表示される。
- アクセシビリティ要件を満たす。
- 全テスト PASS。
