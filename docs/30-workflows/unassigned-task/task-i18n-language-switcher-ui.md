## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

現在のi18n実装では、言語設定はシステムロケールまたはデフォルト値（"ja"）に依存している。ユーザーが手動で言語を選択する機能がないため、システムロケールと異なる言語を使用したいユーザーのニーズに応えられない。

### 1.2 問題点・課題

| 問題点               | 影響                             |
| -------------------- | -------------------------------- |
| 言語選択UIの不在     | ユーザーが言語を選べない         |
| システムロケール依存 | 多言語環境でのユーザビリティ低下 |
| 設定の永続化未対応   | 毎回デフォルト言語になる         |

### 1.3 放置した場合の影響

| 影響                       | 深刻度 |
| -------------------------- | ------ |
| 多言語ユーザーの使いづらさ | 中     |
| 競合製品との機能差         | 低     |
| 国際展開時の障壁           | 中     |

---

## 2. 何を達成するか（What）

### 2.1 目的

ユーザーが設定画面から言語を手動で選択し、その設定が永続化される機能を提供する。

### 2.2 最終ゴール

| ゴール                     | 検証方法             |
| -------------------------- | -------------------- |
| 設定画面に言語選択UIがある | UI目視確認           |
| 言語切替が即座に反映       | 切替操作テスト       |
| 設定が永続化される         | アプリ再起動後の確認 |

### 2.3 スコープ

#### 含むもの

- 言語選択ドロップダウンUI
- 選択言語の永続化（Electron Store）
- アプリ起動時の言語復元

#### 含まないもの

- 3言語以上のUI対応（別タスク）
- 自動言語検出の高度化
- 地域設定（ロケール詳細）

### 2.4 成果物

| 成果物               | ファイルパス                                        |
| -------------------- | --------------------------------------------------- |
| LanguageSelector     | `apps/desktop/src/renderer/components/settings/`    |
| 言語設定Store        | `apps/desktop/src/renderer/stores/settingsSlice.ts` |
| Electron Store永続化 | `apps/desktop/src/main/stores/`                     |

## 6. 検証方法

### テストケース

| テストケース               | 期待結果               |
| -------------------------- | ---------------------- |
| ドロップダウンで英語選択   | UIが英語に切り替わる   |
| ドロップダウンで日本語選択 | UIが日本語に切り替わる |
| アプリ再起動               | 選択言語が保持される   |
| キーボード操作             | Tab/Enter で操作可能   |

### 検証手順

1. `pnpm --filter @repo/desktop test` でテスト実行
2. 開発サーバーで設定画面を開き、言語切替を確認
3. アプリ再起動後に言語設定が保持されていることを確認
