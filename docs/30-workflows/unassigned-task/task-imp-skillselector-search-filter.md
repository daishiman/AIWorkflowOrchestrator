## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-7AでSkillSelectorコンポーネントを実装した際、仕様書（specification.md 4.6E）で定義されている検索/フィルター機能が未実装となった。現状ではスキル数が少ないため問題ないが、スキル数が増加した際のユーザビリティ向上に必要。

### 1.2 問題点・課題

- スキル一覧から目的のスキルを探すのに時間がかかる（スキル数増加時）
- 仕様書の定義（4.6E: 検索/フィルター）が満たされていない
- 大量スキル表示時のスクロール負担

### 1.3 放置した場合の影響

- スキル数が増えた場合にユーザー体験が低下
- 仕様書との乖離が残る
- 目的スキルへのアクセス時間増加

---

## 2. 何を達成するか（What）

### 2.1 目的

SkillSelectorにテキスト検索とフィルター機能を追加し、大量のスキルから目的のスキルを素早く見つけられるようにする。

### 2.2 最終ゴール

- ドロップダウン内に検索入力フィールドがある
- 入力テキストでスキル名・説明をリアルタイムフィルタリング
- フィルタリング結果が即座に反映される
- 該当なしの場合は適切なメッセージ表示

### 2.3 スコープ

#### 含むもの

- 検索入力フィールドの追加
- スキル名・説明でのフィルタリング
- フィルタリング結果の即時反映
- 検索結果なし時のUI
- キーボードナビゲーションとの統合

#### 含まないもの

- 高度な検索構文（AND/OR等）
- 検索履歴の保存
- サーバーサイド検索
- あいまい検索（fuzzy search）

### 2.4 成果物

| 成果物                 | 説明                          |
| ---------------------- | ----------------------------- |
| SkillSelector.tsx      | 検索/フィルター機能追加       |
| SkillSelector.test.tsx | 検索/フィルター関連テスト追加 |
| 翻訳リソース           | 検索UI用テキスト追加          |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-7A（SkillSelector実装）が完了していること
- キーボードナビゲーションの動作を理解していること

### 3.2 依存タスク

| タスクID                        | 状態 | 説明                         |
| ------------------------------- | ---- | ---------------------------- |
| TASK-7A                         | 完了 | SkillSelector基本実装        |
| task-imp-skillselector-i18n-001 | 推奨 | i18n対応（検索UIテキスト用） |

### 3.3 必要な知識

- React hooks（useState, useMemo）
- 文字列フィルタリングロジック
- アクセシビリティ（検索フィールドのARIA属性）

1. ドロップダウン上部に検索入力フィールドを追加
2. useMemoでフィルタリング結果を計算
3. キーボードナビゲーションと検索フィールドのフォーカス管理を統合
4. 検索結果なし時の表示を追加

### Phase 2: 設計

#### 目的

検索機能のUI/UXと状態管理を設計する

#### 手順

1. 検索UIの配置決定（ドロップダウン上部固定）
2. 状態管理設計（searchQuery state追加）
3. フィルタリングロジック設計
4. キーボードナビゲーション統合設計
5. アクセシビリティ設計

#### 設計概要

```tsx
// 状態追加
const [searchQuery, setSearchQuery] = useState("");

// フィルタリング
const filteredOptions = useMemo(() => {
  if (!searchQuery.trim()) return allOptions;
  const query = searchQuery.toLowerCase();
  return allOptions.filter(
    (opt) =>
      opt.name?.toLowerCase().includes(query) ||
      opt.description?.toLowerCase().includes(query),
  );
}, [allOptions, searchQuery]);

// キーボードナビゲーション
// - Escapeで検索クリア→ドロップダウン閉じる
// - ArrowDown/Upで検索フィールド↔リスト間移動
```
