# UT-SC-03-002: plan() 実行時の動的 apiKey 設定メカニズム

## メタ情報

| 項目       | 値                                              |
| ---------- | ----------------------------------------------- |
| 未タスクID | UT-SC-03-002                                    |
| 検出元     | TASK-SC-03-PLAN-LLM-PROMPT Phase 3 設計レビュー |
| 優先度     | 低                                              |
| 影響範囲   | LLMAdapterFactory, AnthropicAdapter             |

## 概要

LLMAdapterFactory.getAdapter() は DI 時点の apiKey で初期化されるが、plan() 実行時の decision.apiKey と異なる可能性がある。動的 apiKey 設定の仕組みが必要。

## 対応方針

1. ILLMAdapter に `setApiKey(key: string)` メソッドを追加、または sendChat の引数に apiKey を渡す方式を検討
2. plan() 内で decision.apiKey を LLM アダプタに動的に設定
3. セキュリティ要件（apiKey のメモリ上の寿命管理）を考慮
