## 1. なぜこのタスクが必要か（Why）

### 背景

Claude CLI統合のAPI層では、ストリーミング出力イベント（onSessionOutput）が実装済みだが、UIでこれらのイベントをリアルタイム表示するコンポーネントが未実装である。

### 問題点・課題

- スキル実行中に何が起きているかユーザーに見えない
- 処理の進捗が不明
- 長時間実行時にフリーズしているように見える

### 放置した場合の影響

- ユーザーの不安感増大
- 実行中かどうか判断できない
- UX品質の著しい低下

---

## 2. 何を達成するか（What）

### 目的

スキル実行中のストリーミング出力をリアルタイムで表示し、ユーザーに処理状況を伝えるUIを実装する。

### 最終ゴール

- ストリーミング出力のリアルタイム表示
- 処理フェーズの視覚的表示
- スピナー/プログレス表示
- 経過時間の表示

### スコープ

**含むもの**:

- ストリーミング出力表示コンポーネント
- 進捗インジケーター
- 経過時間タイマー
- 自動スクロール機能

**含まないもの**:

- API層の修正（実装済み）
- 出力のシンタックスハイライト（将来課題）

### 成果物

| 成果物                | 形式            |
| --------------------- | --------------- |
| ExecutionProgress.tsx | React Component |
| StreamingOutput.tsx   | React Component |
| useSessionOutput.ts   | React Hook      |
| ユニットテスト        | TypeScript      |

---

## 3. どのように実行するか（How）

### 前提条件

- UNASSIGNED-CLI-001（Renderer API実装）完了
- onSessionOutput/onSessionStatusイベント実装済み

### 依存タスク

| タスクID           | 内容             | ステータス |
| ------------------ | ---------------- | ---------- |
| UNASSIGNED-CLI-001 | Renderer API実装 | 未着手     |

### 必要な知識・スキル

- React Hooks（useEffect, useState）
- EventEmitterパターン
- 仮想スクロール（大量出力対応）

### 推奨アプローチ

1. useSessionOutputフックでイベント購読を抽象化
2. 出力バッファリングで再レンダリング最適化
3. 仮想スクロールライブラリの検討（react-window等）

---

## 4. 実行手順

### Phase 1: React Hook実装

1. `useSessionOutput.ts`を作成
2. onSessionOutput/onSessionStatusの購読
3. クリーンアップ処理の実装

### Phase 2: 進捗表示コンポーネント

1. `ExecutionProgress.tsx`を作成
2. スピナー/ステータス表示
3. 経過時間タイマー

### Phase 3: ストリーミング出力表示

1. `StreamingOutput.tsx`を作成
2. 出力テキストの追加表示
3. 自動スクロール機能
4. 大量出力時のパフォーマンス考慮

## 6. 検証方法

| カテゴリ       | テストケース                     |
| -------------- | -------------------------------- |
| イベント購読   | 購読/解除が正しく動作            |
| 表示更新       | 出力追加時にUIが更新される       |
| パフォーマンス | 大量出力でもスムーズに動作       |
| クリーンアップ | コンポーネント破棄時にリーク無し |

## 7. リスクと対策

| リスク                       | 影響 | 対策                        |

| 大量出力でのメモリ増大       | 中   | 出力行数上限/仮想スクロール |
| 高頻度更新でのパフォーマンス | 中   | バッファリング/throttle     |
| イベントリスナーのリーク     | 中   | useEffect cleanup実装       |
