## 1. なぜこのタスクが必要か（Why）

### 背景

Claude CLI統合のAPI層では、セッション終了（terminateSession）APIが実装済みだが、UIからこの機能を呼び出すための中断ボタン・確認ダイアログが未実装である。

### 問題点・課題

- スキル実行中にユーザーが中断したい場合のUI操作が存在しない
- 長時間実行されるスキルを停止する手段がない
- 誤操作防止の確認ダイアログがない

### 放置した場合の影響

- ユーザーが実行中のスキルを中断できない
- 意図しない長時間実行を止められない
- UX品質の低下

---

## 2. 何を達成するか（What）

### 目的

スキル実行中に「中断」ボタンを表示し、確認ダイアログを経てセッションを安全に終了するUIを実装する。

### 最終ゴール

- 実行中のスキルに「中断」ボタンを表示
- クリック時に確認ダイアログを表示
- 確認後にterminateSession APIを呼び出し
- 中断成功/失敗のフィードバック表示

### スコープ

**含むもの**:

- 中断ボタンコンポーネント
- 確認ダイアログコンポーネント
- terminateSession API呼び出し処理
- 状態管理（中断中フラグ）

**含まないもの**:

- API層の修正（実装済み）
- E2Eテスト（UI統合テストと同時に実装）

### 成果物

| 成果物                 | 形式            |
| ---------------------- | --------------- |
| AbortButton.tsx        | React Component |
| AbortConfirmDialog.tsx | React Component |
| ユニットテスト         | TypeScript      |

## 4. 実行手順

### Phase 1: 中断ボタン実装

1. `AbortButton.tsx`を作成
2. 実行中のセッションがある場合のみ表示
3. disabled状態（中断処理中）の管理

### Phase 2: 確認ダイアログ実装

1. `AbortConfirmDialog.tsx`を作成
2. 「中断しますか？」メッセージ表示
3. 「キャンセル」「中断する」ボタン

### Phase 3: API連携

1. terminateSession API呼び出し
2. 成功/失敗のトースト通知
3. セッション状態の更新
