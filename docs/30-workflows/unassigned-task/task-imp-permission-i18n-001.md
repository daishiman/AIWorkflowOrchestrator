## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

task-imp-permission-readable-ui-001でPermissionDialogの人間可読説明文が日本語で実装された。しかし、プロダクトの国際展開を考えると、英語等の多言語対応が必要となる。現在のpermissionDescriptions.tsは日本語のテンプレートのみをハードコードしている。

### 1.2 問題点・課題

| 課題                     | 詳細                                             |
| ------------------------ | ------------------------------------------------ |
| 日本語のみ対応           | 英語ユーザーが説明文を理解できない               |
| ハードコード方式         | テンプレート文字列が直接コードに埋め込まれている |
| i18nフレームワーク未統合 | アプリ全体のi18n方針との統合が未実施             |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                             | 重要度 |
| ------------ | ------------------------------------ | ------ |
| ユーザー体験 | 非日本語ユーザーの理解度低下         | 中     |
| 国際展開     | 多言語対応がブロッカーになりうる     | 中     |
| 保守性       | テンプレート変更時に複数箇所修正必要 | 低     |

---

## 2. 何を達成するか（What）

### 2.1 目的

permissionDescriptions.tsの説明テンプレートを多言語対応させ、ユーザーの言語設定に応じた説明文を表示する。

### 2.2 最終ゴール

- [ ] 日本語・英語の2言語に対応
- [ ] アプリの言語設定に連動して説明文が切り替わる
- [ ] i18nフレームワークとの統合
- [ ] 既存テストが全てPASSする
- [ ] 新規テストが追加される

### 2.3 スコープ

**含まれるもの**:

- permissionDescriptions.tsの多言語テンプレート対応
- 言語切り替えロジック
- テストケースの追加

**含まれないもの**:

- 3言語以上の対応（日英以外）
- 翻訳管理ツールの導入
- PermissionDialog以外のコンポーネントの多言語対応

### 2.4 成果物

| 成果物           | パス                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------- |
| 修正後モジュール | `apps/desktop/src/renderer/components/skill/permissionDescriptions.ts`                |
| 追加テスト       | `apps/desktop/src/renderer/components/skill/__tests__/permissionDescriptions.test.ts` |
