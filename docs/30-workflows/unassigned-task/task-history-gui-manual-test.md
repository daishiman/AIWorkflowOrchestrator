## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

history-service-db-integration タスクでHistoryServiceのDB統合を実装したが、Phase 11の手動テスト検証時にRendererビルド問題（renderer-build-fix参照）が発生し、GUI手動テストが実施できなかった。

バックエンド（Mainプロセス）のテストは完了し、統合テストで92.16%のカバレッジを達成したが、Renderer側（GUI）の動作確認が未実施のまま残っている。

### 1.2 問題点・課題

| 問題           | 詳細                                         |
| -------------- | -------------------------------------------- |
| GUI動作未確認  | HistoryPanel UIの実際の動作が未検証          |
| UX品質未確認   | ユーザビリティの問題が潜在的に存在する可能性 |
| 統合動作未確認 | IPC経由の実データ表示が未確認                |

### 1.3 放置した場合の影響

| 影響                         | 深刻度 |
| ---------------------------- | ------ |
| GUI表示バグの見逃し          | 中     |
| UX問題の見逃し               | 中     |
| 本番リリース後のユーザー影響 | 高     |

## 4. 実行手順

### Phase構成

このタスクは手動テスト中心のため、簡易Phase構成（2 Phase）を採用。

### Phase 1: 環境準備・テストデータ作成

#### 目的

手動テスト実行に必要な環境とテストデータを準備する。

#### 手順

1. アプリビルド・起動確認

   ```bash
   pnpm --filter @repo/desktop build
   pnpm --filter @repo/desktop start
   ```

2. HistoryPanelへの遷移確認
   - サイドバーから履歴ページへ遷移可能であることを確認

3. テストデータ作成（20件以上の履歴）
   - ファイル変換機能を使用して複数のファイルを変換
   - または、テスト用SQLスクリプトでダミーデータを投入
   ```sql
   -- ダミーデータ投入例
   INSERT INTO conversions (file_id, status, created_at, ...)
   VALUES
     ('file-1', 'completed', datetime('now', '-1 day'), ...),
     ('file-2', 'completed', datetime('now', '-2 day'), ...),
     -- ... 20件以上
   ```

#### 成果物

- 起動確認スクリーンショット
- テストデータ投入ログ

#### 完了条件

- [ ] アプリが正常に起動
- [ ] HistoryPanelへ遷移可能
- [ ] 20件以上の履歴データが存在

### Phase 2: 手動テスト実行・結果記録

#### 目的

全14件の手動テストを実行し、結果を記録する。

#### 手順

##### MT-01: 履歴ページへ遷移

1. サイドバーの「履歴」メニューをクリック
2. 履歴ページが表示されることを確認
3. スクリーンショットを取得

##### MT-02: 履歴アイテムの表示

1. 履歴一覧に履歴アイテムが表示されることを確認
2. 各アイテムにファイル名、日時、ステータスが表示されることを確認
3. スクリーンショットを取得

##### MT-03: 最新バージョン表示

1. 履歴アイテムの中で最新バージョンに「最新」ラベルが表示されることを確認
2. スクリーンショットを取得

##### MT-04: 空の履歴表示

1. 履歴がないファイルを選択（または全履歴を削除）
2. 「履歴がありません」メッセージが表示されることを確認
3. スクリーンショットを取得

##### MT-05: ローディング表示

1. 履歴読み込み中にローディングインジケータが表示されることを確認
2. スクリーンショットを取得（タイミングが難しい場合はスキップ可）

##### MT-06: 追加読み込み（DEFERRED項目）

1. 20件以上の履歴がある状態で履歴ページを開く
2. 一覧をスクロールダウン
3. 追加の履歴が読み込まれることを確認
4. スクリーンショットを取得

##### MT-07: バージョン選択

1. 履歴アイテムをクリック
2. 詳細パネルが開くことを確認
3. スクリーンショットを取得

##### MT-08: 詳細情報表示

1. バージョン詳細パネルで以下が表示されることを確認:
   - ファイルサイズ
   - ハッシュ値
   - 作成日時
   - ステータス
2. スクリーンショットを取得

##### MT-09: 変換ログ表示

1. 詳細パネル内の「ログ」タブをクリック
2. 変換ログが表示されることを確認
3. スクリーンショットを取得

##### MT-10: ログフィルタ

1. ログレベルフィルタ（ERROR/WARN/INFO）を操作
2. フィルタに応じてログ表示が変わることを確認
3. スクリーンショットを取得

##### MT-11: 復元ダイアログ表示

1. 過去バージョンを選択
2. 「復元」ボタンをクリック
3. 確認ダイアログが表示されることを確認
4. スクリーンショットを取得

##### MT-12: 復元キャンセル

1. 確認ダイアログで「キャンセル」をクリック
2. ダイアログが閉じ、復元が行われないことを確認

##### MT-13: 復元実行

1. 過去バージョンを選択し「復元」をクリック
2. 確認ダイアログで「復元」をクリック
3. 復元処理が実行されることを確認
4. スクリーンショットを取得

##### MT-14: 復元後の一覧更新

1. 復元完了後、履歴一覧が更新されることを確認
2. 新しいバージョンが「最新」として表示されることを確認
3. スクリーンショットを取得

##### IT-03: データ永続化テスト（DEFERRED項目）

1. アプリを終了
2. アプリを再起動
3. 履歴データが保持されていることを確認
4. スクリーンショットを取得

#### 成果物

- 各テストケースのスクリーンショット
- テスト結果レポート（PASS/FAIL/SKIP）

#### 完了条件

- [ ] MT-01〜MT-14の全テストを実行
- [ ] MT-06（追加読み込み）を実行
- [ ] IT-03（データ永続化）を実行
