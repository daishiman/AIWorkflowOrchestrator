# UT-SC-02-004: bundle 構築の二重責務

| 項目     | 値                                |
| -------- | --------------------------------- |
| タスクID | UT-SC-02-004                      |
| 優先度   | 低                                |
| 元タスク | TASK-SC-02-RUNTIME-POLICY-CLOSURE |

## 概要

TerminalHandoffBundle の構築が RuntimePolicyResolver のプライベートメソッドと TerminalHandoffBuilder.build() に分散。shell injection 対策の有無が不均一。

## 対応方針

Resolver の bundle 構築を TerminalHandoffBuilder に委譲し一箇所に統合する。

## 完了条件

- [ ] TerminalHandoffBundle の構築責務が TerminalHandoffBuilder に統合される
- [ ] RuntimePolicyResolver のプライベートメソッドから bundle 構築が除去される
- [ ] shell injection 対策が統合先で均一に適用される
- [ ] 関連テストが PASS する
