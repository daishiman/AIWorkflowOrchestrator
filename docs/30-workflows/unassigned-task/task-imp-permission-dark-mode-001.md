## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-7C Phase 11の手動テスト検証において、PermissionDialogが白背景のみでダークモード非対応であることがスコープ外の改善提案として検出された。アプリケーション全体がダークモードをサポートしている場合、ダイアログのみが白背景だとUIの一貫性が損なわれる。

### 1.2 問題点・課題

| 課題                     | 詳細                                       |
| ------------------------ | ------------------------------------------ |
| UIの一貫性欠如           | アプリがダークモード時もダイアログは白背景 |
| 視覚的な不快感           | 暗い環境でダイアログが眩しい               |
| デザインシステムとの乖離 | ui-ux-design-system.mdのテーマ仕様と不整合 |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                           | 重要度 |
| ------------ | ---------------------------------- | ------ |
| UX品質       | ダークモードユーザーの視覚体験低下 | 低     |
| 一貫性       | デザインシステムとの整合性欠如     | 低     |

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogをダークモード対応させ、アプリケーション全体のテーマと一貫したUIを提供する。

### 2.2 最終ゴール

- [ ] ダークモード時に適切な背景色・テキスト色が適用される
- [ ] ライトモード時の表示に変更がない
- [ ] テーマ切り替えでリアルタイムに反映される
- [ ] 既存テストが全てPASSする

### 2.3 スコープ

**含まれるもの**:

- Tailwind CSSのdark:クラス追加
- カラートークンの適用
- テストケースの追加

**含まれないもの**:

- テーマ切り替えUI（既存機能を使用）
- カスタムカラーテーマ
- ハイコントラストモード

### 2.4 成果物

| 成果物               | パス                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 修正後コンポーネント | `apps/desktop/src/renderer/components/skill/PermissionDialog.tsx`                |
| 追加テスト           | `apps/desktop/src/renderer/components/skill/__tests__/PermissionDialog.test.tsx` |

## 4. 実行手順

### Phase 1: カラーマッピング確認

**目的**: デザインシステムのダークモードカラーを確認

**手順**:

1. ui-ux-design-system.mdを参照
2. 使用するカラートークンをリストアップ
3. コントラスト比を計算

**カラーマッピング例**:
| 要素 | ライトモード | ダークモード |
| -------------- | ----------------- | ------------------ |
| オーバーレイ | bg-black/50 | bg-black/50 |
| ダイアログ背景 | bg-white | dark:bg-gray-800 |
| ヘッダー背景 | bg-yellow-50 | dark:bg-yellow-900/30 |
| テキスト | text-gray-900 | dark:text-gray-100 |
| コードブロック | bg-gray-100 | dark:bg-gray-700 |

**成果物**: カラーマッピングドキュメント

**完了条件**:

- [ ] 全要素のカラーマッピングが決定
- [ ] コントラスト比が4.5:1以上

### Phase 2: 実装

**目的**: dark:クラスを追加

**手順**:

1. PermissionDialog.tsxの各要素にdark:クラスを追加
2. ボタンのホバー状態もダークモード対応
3. チェックボックスのスタイル確認

**成果物**: 修正後のPermissionDialog.tsx

**完了条件**:

- [ ] 全要素にdark:クラスが追加されている
- [ ] ダークモードで視認性が確保されている

### Phase 3: テスト

**目的**: ダークモード表示のテストを追加

**手順**:

1. 既存テストが全てPASSすることを確認
2. ダークモードクラスの存在確認テストを追加
