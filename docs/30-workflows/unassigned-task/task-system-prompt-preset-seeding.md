## 1. なぜこのタスクが必要か（Why）

### 背景

システムプロンプトのDB永続化機能が完了し、プリセットテンプレートをコード内定数として提供する仕組みは実装済みです。しかし、実際のプリセットテンプレート（内容）はまだ定義されていません。

### 問題点・課題

| 問題                   | 影響                                   |
| ---------------------- | -------------------------------------- |
| プリセットが空         | 初期ユーザーが使えるテンプレートがない |
| 開始体験の欠如         | ユーザーが機能を試す手がかりがない     |
| ベストプラクティス不在 | 効果的なプロンプトの例がない           |

### 放置した場合の影響

- ユーザーが自分でテンプレートを一から作成する必要がある
- 機能の価値が伝わりにくい
- ユーザー離脱の可能性

---

## 2. 何を達成するか（What）

### 目的

初期ユーザーがすぐに使える標準プリセットテンプレートを提供する。

### 最終ゴール

| ゴール              | 詳細                             |
| ------------------- | -------------------------------- |
| プリセット4種類以上 | 翻訳、プログラミング、校正、要約 |
| 高品質なプロンプト  | 効果的で汎用的なプロンプト       |
| 多言語対応          | 日本語・英語両方で使用可能       |

### スコープ

**含むもの**:

- 翻訳アシスタント
- プログラミング支援
- 文章校正
- 要約・整理

**含まないもの**:

- 専門分野特化テンプレート
- ユーザーカスタマイズ機能

### 成果物一覧

| 種別         | 成果物           | 配置先                                                   |
| ------------ | ---------------- | -------------------------------------------------------- |
| 実装         | プリセット定数   | `packages/shared/src/constants/system-prompt-presets.ts` |
| テスト       | プリセットテスト | `packages/shared/src/constants/*.test.ts`                |
| ドキュメント | プリセット一覧   | `docs/features/system-prompt-presets.md`                 |
