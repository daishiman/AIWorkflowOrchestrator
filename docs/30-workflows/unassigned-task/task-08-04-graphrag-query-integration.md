## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

CONV-08-03でコミュニティ要約生成機能を実装した。この機能により、Knowledge Graph内のコミュニティ（意味的に関連するエンティティのクラスタ）に対して、LLMを使用した要約とセマンティック検索用の埋め込みベクトルが生成されるようになった。

現状では、要約は生成・保存されているが、実際のクエリ処理（GraphRAG Query Handler）ではまだ活用されていない。

### 1.2 問題点・課題

1. **クエリ応答の品質制限**: コミュニティ要約を活用していないため、広範なトピックに関する質問への回答が限定的
2. **階層的情報の未活用**: コミュニティの階層構造（詳細→概要）が回答生成に活かされていない
3. **セマンティック検索の未統合**: 要約の埋め込みベクトルが検索に使用されていない

### 1.3 放置した場合の影響

- GraphRAGの回答品質が向上しない
- コミュニティ要約生成の投資（トークンコスト・処理時間）が活用されない
- 競合製品（Microsoft GraphRAG等）と比較して劣る

---

## 2. 何を達成するか（What）

### 2.1 目的

GraphRAGのクエリ処理において、コミュニティ要約を活用して回答品質を向上させる。

### 2.2 最終ゴール

1. ユーザーのクエリに対して、関連するコミュニティ要約がセマンティック検索で取得される
2. 取得したコミュニティ要約がLLM回答生成のコンテキストに含まれる
3. 階層レベルに応じた適切な粒度の情報が回答に反映される

### 2.3 スコープ

#### 含むもの

- GraphRAG Query Handlerへのコミュニティ要約検索統合
- クエリ→コミュニティ要約のセマンティック検索実装
- 回答生成プロンプトへのコミュニティ要約コンテキスト追加
- 検索結果のスコアリング・ランキング調整

#### 含まないもの

- コミュニティ要約生成機能の変更（CONV-08-03で完了）
- UI実装（CONV-08-05で対応）
- リアルタイム更新（スコープ外）

### 2.4 成果物

| 成果物             | 説明                                   |
| ------------------ | -------------------------------------- |
| クエリハンドラ更新 | コミュニティ要約検索統合済み           |
| ユニットテスト     | 新機能のテストケース（カバレッジ80%+） |
| 統合テスト         | E2Eフロー検証                          |
| 実装ガイド         | Phase 12ドキュメント                   |

## 3. どのように実行するか（How）

### 3.1 前提条件

- CONV-08-03（コミュニティ要約生成）が完了していること
- Knowledge Graphにコミュニティとその要約が存在すること
- 埋め込みベクトルが生成されていること

### 3.2 依存タスク

| タスクID   | タスク名               | 状態 |
| ---------- | ---------------------- | ---- |
| CONV-08-02 | Leidenコミュニティ検出 | 完了 |
| CONV-08-03 | コミュニティ要約生成   | 完了 |

### 3.3 必要な知識

- GraphRAGアーキテクチャ
- ICommunitySummarizer.searchSummaries() の使用方法
- LLMプロンプトエンジニアリング
- Result型パターン（success/data/error）

### 3.4 推奨アプローチ

1. **段階的統合**: まず単純な検索統合から開始し、スコアリング・ランキングを後から調整
2. **TDD**: テストを先に書いてから実装
3. **既存パターン踏襲**: ICommunitySummarizer の使用パターンを踏襲

## 4. 実行手順

### Phase構成

標準のPhase 1〜13構成に従う。主要な実装はPhase 4〜8で行う。

### Phase 4: テスト作成

#### 目的

クエリ→コミュニティ要約→回答のフローをテストするテストケースを作成

#### 手順

1. GraphRAG Query Handler のテストファイルを確認
2. コミュニティ要約検索を含むテストケースを追加
3. 回答生成プロンプトにコミュニティ要約が含まれることを検証するテストを追加

#### 成果物

- `graphrag-query-handler.test.ts` への追加テストケース

#### 完了条件

- [ ] セマンティック検索のテストケースが作成されている
- [ ] 回答生成へのコンテキスト統合テストが作成されている
- [ ] すべてのテストがRed状態

### Phase 5: 実装

#### 目的

コミュニティ要約をクエリ処理に統合

#### 手順

1. Query HandlerにICommunitySummarizerを依存注入
2. クエリ処理フローに searchSummaries() 呼び出しを追加
3. 回答生成プロンプトにコミュニティ要約コンテキストを追加
4. 階層レベルに応じたフィルタリング実装

#### 成果物

- 更新された GraphRAG Query Handler
- 新しい回答生成プロンプトテンプレート

#### 完了条件

- [ ] 全テストがGreen状態
- [ ] クエリに関連するコミュニティ要約が回答に反映される

## 6. 検証方法

### テストケース

| ID   | シナリオ                           | 期待結果                         |
| ---- | ---------------------------------- | -------------------------------- |
| TC01 | 関連コミュニティが存在するクエリ   | 要約がコンテキストに含まれる     |
| TC02 | 関連コミュニティがないクエリ       | 通常の回答生成（フォールバック） |
| TC03 | 階層レベル指定検索                 | 指定レベルの要約のみ返される     |
| TC04 | 複数コミュニティがマッチするクエリ | スコア順でランキング             |

### 検証手順

1. テスト実行: `pnpm --filter @repo/shared test`
2. カバレッジ確認: `pnpm --filter @repo/shared test:coverage`
3. 統合テスト: 実際のクエリを投げて回答を確認
