## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-Dで実装されたコピー履歴機能は、最大50件の件数制限でFIFO削除を行っている。しかし、古い履歴が時間経過で自動削除される機能はない。

### 1.2 問題点・課題

- 古い履歴が蓄積し続ける（件数制限まで）
- 不要な古い履歴が残り続ける
- 永続化機能との組み合わせで問題が顕在化する可能性

### 1.3 放置した場合の影響

- 現時点では件数制限があるため影響は限定的
- 永続化機能実装後に古いデータが残り続ける可能性

---

## 2. 何を達成するか（What）

### 2.1 目的

一定期間（例: 7日間）経過した履歴を自動的に削除する。

### 2.2 最終ゴール

- 設定した期間を超えた履歴が自動削除される
- 期限設定が変更可能である
- 既存の件数制限と併用できる

### 2.3 スコープ

#### 含むもの

- 時間ベースの自動削除ロジック
- デフォルト期限設定（7日間）
- 設定UIの追加（オプション）

#### 含まないもの

- ユーザー別の期限設定
- 削除前の確認ダイアログ

### 2.4 成果物

- 自動期限切れロジック
- 設定定数の追加
- 単体テスト
- 実装ガイド更新

---

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-3-2-D（コピー履歴機能）が完了していること
- TASK-3-2-D-01（永続化）が完了していることが望ましい

### 3.2 依存タスク

- TASK-3-2-D（完了済み）
- TASK-3-2-D-01（推奨、オプション）

### 3.3 必要な知識

- JavaScriptの日付操作
- React useEffect

### 3.4 推奨アプローチ

1. DEFAULT_EXPIRE_DAYS 定数を定義（7日）
2. addToHistory 時に古い履歴をフィルタリング
3. useEffect でアプリ起動時に期限切れ履歴を削除
