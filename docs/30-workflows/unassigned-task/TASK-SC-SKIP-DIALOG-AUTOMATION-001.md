## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-SC-DIALOG-MANDATORY-001 で `/skill-creator` の対話を強制化した（`AskUserQuestion` を必ず最初に実行）。
これにより、詳細な要件を事前に書いてあっても必ず確認質問が入る仕様となった。

### 1.2 問題点・課題

| ID  | 問題                                                                          | 根本原因                                                            |
| --- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| P01 | CI/CD パイプラインや自動化スクリプトからの呼び出しで対話が必須になった        | TASK-SC-DIALOG-MANDATORY-001 で「例外なし」の対話強制を実装したため |
| P02 | テストコードで `/skill-creator` を呼ぶ場合に AskUserQuestion がブロックになる | 同上                                                                |

### 1.3 放置した場合の影響

- 将来の自動化ユースケース（スクリプト経由でのスキル雛形生成など）で利用不可能になる
- テストハーネスから呼び出す際の回避策が増え、保守コストが増大する

> **現時点での緊急度**: 低。現在の利用はすべて対話前提のため即座の影響なし。

---

## 2. 何を達成するか（What）

### 2.1 目的

skill-creator スキルが自動化コンテキストから呼び出される場合に、対話をスキップして事前定義パラメータで動作できる仕組みを提供する。

### 2.2 最終ゴール

- `--skip-dialog` フラグまたは環境変数で対話フェーズをバイパスできる
- 自動化コンテキスト（CI、スクリプト、テスト）から安全に呼び出せる
- 既存の対話フロー（Phase 0-0〜0-8）に影響なし

### 2.3 スコープ

#### 含むもの

- `--skip-dialog` フラグの設計と実装
- 自動化コンテキスト検出の仕組み（環境変数 or 引数）
- 自動化時のデフォルトパラメータ定義
- 対話スキップ時の動作仕様書

#### 含まないもの

- 既存の collaborative フロー（Phase 0-0〜0-8）の変更
- 自動化専用の別スキル作成（フラグで制御する方針）

## 3. どのように実現するか（How）

### 3.1 設計方針

| 方針                      | 説明                                                                             |
| ------------------------- | -------------------------------------------------------------------------------- |
| フラグ追加                | SKILL.md の `必須：最初の実行ステップ` ブロックに `--skip-dialog` 条件分岐を追加 |
| 環境変数サポート          | `SKILL_CREATOR_NO_DIALOG=1` 環境変数でも制御可能にする                           |
| problem-definition 必須化 | スキップ時は `problem-definition.json` が存在することを前提条件とする            |

### 3.2 変更対象ファイル（予定）

| ファイル                                                  | 変更種別 | 内容                                         |
| --------------------------------------------------------- | -------- | -------------------------------------------- |
| `.claude/skills/skill-creator/SKILL.md`                   | 変更     | `--skip-dialog` 条件分岐を必須ブロックに追加 |
| `.claude/skills/skill-creator/agents/discover-problem.md` | 変更     | 実行ゲートに skip 条件を追加                 |
| `.claude/skills/skill-creator/agents/interview-user.md`   | 変更     | フラグ確認ロジックを追加                     |
