## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

CONV-04-05でKnowledge Graphテーブル群のDrizzle ORMスキーマ定義が完了した。
スキーマ定義は完了しているが、実際のデータベースにテーブルを作成するためのマイグレーションファイルがまだ生成されていない。

### 1.2 問題点・課題

- Drizzle ORMスキーマ定義はTypeScriptコードとして存在するが、SQLiteデータベースにテーブルが作成されていない
- マイグレーションファイルがないため、開発環境や本番環境でテーブルを利用できない
- 後続のKnowledge Graph Store実装（CONV-08-01）がブロックされている

### 1.3 放置した場合の影響

- Knowledge Graph機能が使用できない
- GraphRAG実装が遅延する
- テスト環境でのスキーマ検証ができない

---

## 2. 何を達成するか（What）

### 2.1 目的

Knowledge Graphテーブル群のマイグレーションファイルを生成し、データベースに適用可能な状態にする。

### 2.2 最終ゴール

- Drizzle Kitによるマイグレーションファイルが生成されている
- マイグレーションがローカル開発環境に適用されている
- 全テーブルがSQLiteデータベースに存在することが確認されている

### 2.3 スコープ

#### 含むもの

- マイグレーションファイル生成（drizzle-kit generate）
- マイグレーション適用（drizzle-kit push または migrate）
- 生成されたマイグレーションファイルの検証
- 外部キー制約の有効化確認

#### 含まないもの

- Knowledge Graph Store実装（CONV-08-01で実施）
- 既存データの移行
- 本番環境へのデプロイ

### 2.4 成果物

| 成果物                     | パス                                      |
| -------------------------- | ----------------------------------------- |
| マイグレーションファイル   | `packages/shared/src/db/migrations/*.sql` |
| マイグレーション適用確認書 | `outputs/migration-verification.md`       |

- CONV-04-05（Knowledge Graphテーブル群実装）が完了していること
- Drizzle Kitがインストールされていること
- SQLiteデータベースファイルが存在すること

### 3.2 依存タスク

| タスクID   | タスク名                      | ステータス |
| ---------- | ----------------------------- | ---------- |

### 3.3 必要な知識・スキル

- Drizzle ORM / Drizzle Kit の使用方法

## 6. 検証方法

### テストケース

| テスト           | 期待結果                       |
| ---------------- | ------------------------------ |
| テーブル一覧取得 | 6テーブルが存在する            |
| 外部キー確認     | PRAGMA foreign_keysがON        |
| インデックス確認 | 各テーブルのインデックスが存在 |

### 検証手順

```bash
# テーブル一覧確認
sqlite3 <db-path> ".tables"

# 外部キー確認
sqlite3 <db-path> "PRAGMA foreign_keys;"

# スキーマ確認
sqlite3 <db-path> ".schema entities"
```
