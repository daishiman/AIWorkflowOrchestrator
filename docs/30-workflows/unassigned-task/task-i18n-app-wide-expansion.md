## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-BでSkillStreamDisplayコンポーネントにi18n対応（formatRelativeTime関数のlocaleパラメータ追加）を実装した。この実装はSkillStreamDisplay限定であり、アプリケーション全体の国際化には至っていない。

### 1.2 問題点・課題

| 問題点               | 影響                                         |
| -------------------- | -------------------------------------------- |
| 部分的なi18n対応のみ | ユーザー体験の一貫性欠如                     |
| 翻訳管理の分散       | SkillStreamDisplayとその他で管理方法が異なる |
| 言語設定の不統一     | コンポーネントごとに言語設定が必要           |

### 1.3 放置した場合の影響

| 影響                         | 深刻度 |
| ---------------------------- | ------ |
| 海外ユーザーへの訴求力低下   | 高     |
| UI文言の一貫性欠如           | 中     |
| 将来のローカライズコスト増大 | 高     |

---

## 2. 何を達成するか（What）

### 2.1 目的

アプリケーション全体を国際化対応し、ユーザーが選択した言語で一貫したUIを提供する。

### 2.2 最終ゴール

| ゴール                       | 検証方法                   |
| ---------------------------- | -------------------------- |
| 全UIコンポーネントがi18n対応 | 全翻訳キーの網羅性確認     |
| 言語設定の一元管理           | 設定画面での言語切替テスト |
| 日英2言語での動作確認        | 手動テスト                 |

### 2.3 スコープ

#### 含むもの

- 全UIコンポーネントの翻訳対応
- i18next/react-i18nextの導入
- 翻訳リソースファイルの作成
- 言語設定の永続化

#### 含まないもの

- 3言語以上の対応（別タスク）
- 翻訳管理システム連携（別タスク）
- 自動翻訳機能

### 2.4 成果物

| 成果物                 | ファイルパス                                 |
| ---------------------- | -------------------------------------------- |
| i18n設定               | `apps/desktop/src/renderer/i18n/`            |
| 翻訳リソース（日本語） | `apps/desktop/src/renderer/i18n/locales/ja/` |
| 翻訳リソース（英語）   | `apps/desktop/src/renderer/i18n/locales/en/` |
| 言語設定Store          | `apps/desktop/src/renderer/stores/`          |

## 4. 実行手順

### Phase構成

| Phase | 名称               | 主要タスク                 |
| ----- | ------------------ | -------------------------- |
| 1     | 設計               | i18n戦略策定、翻訳キー設計 |
| 2     | 基盤実装           | i18next導入、Provider設定  |
| 3     | 翻訳作成           | 翻訳リソースファイル作成   |
| 4     | コンポーネント移行 | 各コンポーネントのi18n対応 |
| 5     | 言語設定           | 言語設定Store、永続化      |
| 6     | テスト・検証       | 統合テスト、手動テスト     |

### Phase 1: 設計

#### 目的

i18n戦略を策定し、翻訳キーの命名規則を定義する。

#### 手順

1. 既存UI文言の洗い出し
2. 翻訳キー命名規則の策定
3. 名前空間（namespace）構造の設計
4. formatRelativeTime関数のi18next統合方針決定

#### 成果物

| 成果物     | 説明                   |
| ---------- | ---------------------- |
| i18n設計書 | 翻訳キー命名規則、構造 |

#### 完了条件

- [ ] 全UI文言のリストが作成されている
- [ ] 翻訳キー命名規則が定義されている
- [ ] 名前空間構造が設計されている

## 6. 検証方法

### テストケース

| テストケース       | 期待結果                 |
| ------------------ | ------------------------ |
| 日本語設定でUI表示 | 全文言が日本語           |
| 英語設定でUI表示   | 全文言が英語             |
| 言語切替           | リアルタイムで切り替わる |
| アプリ再起動       | 言語設定が保持される     |

### 検証手順

1. `pnpm --filter @repo/desktop test` でテスト実行
2. `pnpm --filter @repo/desktop dev` で起動、言語切替確認
3. アプリ再起動後の言語設定保持確認
