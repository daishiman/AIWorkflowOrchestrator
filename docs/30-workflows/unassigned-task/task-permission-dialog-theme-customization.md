## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-4-2（PermissionResolver IPC Handlers）で実装したPermissionDialogコンポーネントは、固定のスタイル（インラインCSS）で実装されている。アプリケーション全体でダーク/ライトテーマの切り替え機能がある場合、ダイアログがテーマに追従しないため視覚的な一貫性が損なわれる。

### 1.2 問題点・課題

| 問題                 | 説明                                                   |
| -------------------- | ------------------------------------------------------ |
| テーマ非対応         | PermissionDialogがアプリのテーマ設定を反映しない       |
| ハードコードスタイル | 色やフォントがインラインで固定されている               |
| 視覚的不整合         | ダークモード時にダイアログだけ白背景で表示される可能性 |

### 1.3 放置した場合の影響

- ダークモードユーザーにとって眩しい/見づらいダイアログ表示
- アプリ全体のビジュアル統一感の欠如
- UXの低下（特に長時間使用時）

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogコンポーネントをアプリケーションのテーマ設定に追従させ、ライト/ダークモード両方で適切なスタイルが適用されるようにする。

### 2.2 最終ゴール

- ダイアログがアプリのテーマ設定（ライト/ダーク）を検知して自動的にスタイルを切り替える
- WCAG 2.1 AAのコントラスト基準を両テーマで満たす
- Tailwind CSSのダークモードクラス（`dark:`）を活用した実装

### 2.3 スコープ

#### 含むもの

- PermissionDialog.tsxのスタイル実装変更
- テーマ対応CSS変数の定義
- ライト/ダークモード両方でのコントラスト検証
- ユニットテストの更新

#### 含まないもの

- テーマ切り替え機能自体の実装（既存機能を利用）
- 他のダイアログコンポーネントへの適用
- カスタムテーマ（ユーザー定義色）対応

### 2.4 成果物

| 成果物                   | パス                                                                                  |
| ------------------------ | ------------------------------------------------------------------------------------- |
| 更新されたコンポーネント | `apps/desktop/src/renderer/components/Permission/PermissionDialog.tsx`                |
| 更新されたテスト         | `apps/desktop/src/renderer/components/Permission/__tests__/PermissionDialog.test.tsx` |
| テーマ変数定義（必要時） | `apps/desktop/src/renderer/styles/theme.css`                                          |

## 3. どのように実行するか（How）

### 3.1 前提条件

- TASK-4-2（PermissionResolver IPC Handlers）が完了していること
- アプリケーションにテーマ切り替え機能が実装されていること
- Tailwind CSSのダークモード設定が有効であること

### 3.2 依存タスク

| タスク   | 内容                                        |
| -------- | ------------------------------------------- |
| TASK-4-2 | PermissionResolver IPC Handlers（完了済み） |

### 3.3 必要な知識

- Tailwind CSSのダークモード機能（`dark:` バリアント）
- CSS変数を使用したテーマ実装パターン
- WCAGコントラスト基準（4.5:1以上）
- React/TypeScript

### 3.4 推奨アプローチ

1. 既存のインラインスタイルをTailwind CSSクラスに変換
2. `dark:` バリアントを使用してダークモードスタイルを追加
3. コントラストチェッカーツールで両テーマを検証
4. VRTまたはスナップショットテストで視覚的検証

5. テストを更新してダークモード表示を検証

## 6. 検証方法

### テストケース

| TC-ID  | テスト内容                     | 期待結果                     |
| ------ | ------------------------------ | ---------------------------- |
| TC-001 | ライトモードでダイアログを表示 | 白背景・黒テキストで表示     |
| TC-002 | ダークモードでダイアログを表示 | 暗背景・白テキストで表示     |
| TC-003 | テーマ切り替え時の動的変更     | リアルタイムでスタイルが変更 |
| TC-004 | コントラスト比検証（ライト）   | 4.5:1以上                    |
| TC-005 | コントラスト比検証（ダーク）   | 4.5:1以上                    |

### 検証手順

1. 開発サーバーを起動（`pnpm dev`）
2. テーマをライトモードに設定
3. 権限確認ダイアログをトリガー
4. スタイルを目視確認
5. テーマをダークモードに切り替え
6. スタイルが変更されることを確認
7. コントラストチェッカーで検証
