## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-WCE-MONACO-001（Monaco Editor選択範囲取得機能）では、標準モードでの選択範囲取得を実装した。Monaco EditorはVimモード（monaco-vim）やEmacsモードのプラグインをサポートしているが、これらのモードでの選択範囲取得は検証されていない。

### 1.2 問題点・課題

1. **Vimユーザーの制限**: Visual mode選択がchat-edit機能で正しく動作しない可能性
2. **Emacsユーザーの制限**: Mark-region選択が認識されない可能性
3. **パワーユーザー離脱**: Vim/Emacsキーバインドを好むユーザーが機能を使えない

### 1.3 放置した場合の影響

- Vim/Emacsモードを使用するパワーユーザーの体験が制限される
- ただし、標準モードで基本機能は動作するため、影響は限定的（優先度: 低）

---

## 2. 何を達成するか（What）

### 2.1 目的

Monaco EditorのVimモード・Emacsモードにおける選択範囲を正しく取得し、chat-edit機能で使用可能にする。

### 2.2 最終ゴール

- Vimモード Visual selection がTextSelectionとして取得可能
- Emacsモード Mark-region がTextSelectionとして取得可能
- モード間での選択範囲取得の一貫性を確保

### 2.3 スコープ

#### 含むもの

- monaco-vim プラグインとの選択範囲連携検証
- Vimモード Visual mode（v, V, Ctrl+V）の選択範囲取得
- 必要に応じたアダプター実装
- ユニットテスト追加

#### 含まないもの

- Vim/Emacsモード自体の実装
- Vim/Emacsプラグインのバグ修正
- Vim/Emacs固有のキーバインド追加

### 2.4 成果物

| 成果物                 | 説明                               |
| ---------------------- | ---------------------------------- |
| 調査ドキュメント       | Vim/Emacsモード選択範囲API調査結果 |
| editorSelection.ts修正 | モード別選択範囲取得アダプター     |
| ユニットテスト         | Vim/Emacsモードテストケース        |

### 3.1 前提条件

- TASK-WCE-MONACO-001（Monaco Editor選択範囲取得）が完了していること
- monaco-vim プラグインがプロジェクトに導入されていること（または導入検討）

### 3.2 依存タスク

| タスク              | ステータス | 関係     |
| ------------------- | ---------- | -------- |
| TASK-WCE-MONACO-001 | ✅ 完了    | 基盤実装 |

### 3.3 推奨アプローチ

1. monaco-vim の選択範囲APIを調査（`cm.getCursor()`, `cm.getSelection()` 等）
2. 標準Monaco APIとmonaco-vimの差異を特定
3. 必要に応じてアダプター関数を実装
4. モード検出ロジックを追加（Vimモード有効/無効）

## 9. 備考

### 発見元の原文（備考セクション）

```
### 補足事項
- 将来的にはVim/Emacsモードでの選択範囲取得も考慮が必要だが、本タスクでは標準モードのみを対象
```

### 補足事項

- 本タスクは優先度「低」のため、Vim/Emacsユーザーからのフィードバックがあった場合に着手を検討
- monaco-vimがプロジェクトに導入されていない場合は、導入タスクが先行して必要
- Visual Block選択（矩形選択）は複雑なため、初期実装では対象外とすることも検討
