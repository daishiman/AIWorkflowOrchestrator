## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-3-2-Dで実装されたコピー履歴機能は、Tab/Enter/Escape/Spaceのキーボード操作に対応している。しかし、パネルを素早く開閉するためのグローバルショートカットキーは実装されていない。

### 1.2 問題点・課題

- パネル開閉にマウスクリックが必要
- キーボード主体のワークフローで効率が落ちる
- 他のアプリケーションで一般的なショートカット（Ctrl+Shift+H等）がない

### 1.3 放置した場合の影響

- キーボードユーザーの作業効率低下
- ただし、現在のマウス操作で十分に機能している

---

## 2. 何を達成するか（What）

### 2.1 目的

グローバルキーボードショートカット（例: Ctrl+Shift+H）でコピー履歴パネルを開閉できるようにする。

### 2.2 最終ゴール

- Ctrl+Shift+H（Windows/Linux）またはCmd+Shift+H（Mac）でパネルをトグル
- ショートカットキーの設定変更が可能（オプション）

### 2.3 スコープ

#### 含むもの

- グローバルショートカットキーの登録
- パネル開閉のトグル機能
- プラットフォーム別のキー設定

#### 含まないもの

- カスタムショートカット設定UI
- 他の操作（コピー、削除等）のショートカット

### 2.4 成果物

- キーボードショートカットハンドラー
- 単体テスト
- 実装ガイド更新

### 3.2 依存タスク

### 3.3 必要な知識

- React useEffect

1. useEffect でキーボードイベントをリッスン
