# UT-SC-02-002: RuntimeSkillCreatorFacade.execute() の terminal_handoff 未分岐

| 項目     | 値                                |
| -------- | --------------------------------- |
| タスクID | UT-SC-02-002                      |
| 優先度   | 高                                |

---

## 概要

`plan()` と `improve()` は `terminal_handoff` 時に早期リターンするが、`execute()` は `void decision;` で lint エラー回避しているだけで terminal_handoff 時も SkillExecutor.execute() を呼び出す。

## 対応方針

plan()/improve() と同様に terminal_handoff 時の早期リターンと HandoffGuidance 返却を追加する。

## 完了条件

- [ ] `execute()` が `terminal_handoff` 時に早期リターンし HandoffGuidance を返す
- [ ] `plan()` / `improve()` / `execute()` の terminal_handoff 分岐パターンが統一される
- [ ] 関連テストが PASS する
