## 1. なぜこのタスクが必要か（Why）

### 背景

全体カバレッジ82.23%で目標80%を達成しているが、ClaudeCliManager単体のカバレッジは64%と低い。CLI実行部分のモック化が困難なため。

### 問題点・課題

- ClaudeCliManagerのカバレッジが64%
- CLI実行部分のテストが不足
- エッジケースのテストが少ない

### 放置した場合の影響

- Facadeレイヤーのリグレッションリスク
- 統合部分のバグ見逃し
- 品質保証の信頼性低下

---

## 2. 何を達成するか（What）

### 目的

ClaudeCliManagerのテストカバレッジを64%から80%以上に向上させる。

### 最終ゴール

- ClaudeCliManagerカバレッジ80%以上
- 主要エッジケースのテスト追加
- モック戦略の改善

### スコープ

**含むもの**:

- ClaudeCliManager.test.tsの拡充
- 内部コンポーネントモックの改善
- エッジケーステストの追加

**含まないもの**:

- 他コンポーネントのカバレッジ改善
- E2Eテスト

### 成果物

| 成果物                 | 形式       |
| ---------------------- | ---------- |
| テストケース追加       | TypeScript |
| カバレッジレポート更新 | Markdown   |
