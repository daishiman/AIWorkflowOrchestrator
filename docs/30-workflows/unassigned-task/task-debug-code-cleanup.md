## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

スキル管理UI（AGENT-002）の開発中に、デバッグ目的でストレージクリア処理や認証モックが追加された。これらのデバッグコードが本番コードに残っている。

### 1.2 問題点・課題

1. **ストレージクリア処理**（App.tsx:18）
   - 初回起動時にストレージを強制クリアする処理が残っている
   - ユーザーの設定やデータが毎回削除される可能性がある

2. **認証モック有効化**（devMockAuth.ts:29）
   - 認証モック機能が有効なまま残っている
   - 本番環境で認証をバイパスする可能性がある

### 1.3 放置した場合の影響

- ユーザーデータの意図しない削除
- セキュリティリスク（認証バイパス）
- 本番環境での予期せぬ動作
- 開発者の混乱（デバッグコードと本番コードの区別がつかない）

---

## 2. 何を達成するか（What）

### 2.1 目的

開発中に追加されたデバッグコードを削除し、本番環境で安全に動作するコードにする。

### 2.2 最終ゴール

- デバッグ用ストレージクリア処理が削除されている
- 認証モック機能が適切に無効化されている
- 本番環境で安全に動作する

### 2.3 スコープ

#### 含むもの

- `apps/desktop/src/renderer/App.tsx` のデバッグコード削除
- `apps/desktop/src/renderer/utils/devMockAuth.ts` の確認・整理
- 関連するTODOコメントの削除

#### 含まないもの

- 認証機能の本番実装（別タスク）
- 新機能の追加
- 他のデバッグコードの検索（本タスクは検出済みのみ対象）

### 2.4 成果物

| 成果物          | パス                                             |
| --------------- | ------------------------------------------------ |
| App.tsx更新     | `apps/desktop/src/renderer/App.tsx`              |
| devMockAuth更新 | `apps/desktop/src/renderer/utils/devMockAuth.ts` |
