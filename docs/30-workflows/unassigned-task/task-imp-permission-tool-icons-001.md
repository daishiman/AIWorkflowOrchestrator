## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-7C PermissionDialogコンポーネントの元タスク仕様書には、ツール別アイコン表示機能（toolIcons）が定義されていた。しかし、優先度とスコープの観点から、最小実装として3ボタン応答パターンとformatArgsヘルパーのみを実装し、ツールアイコンは実装スコープ外とされた。

```typescript
// 元タスク仕様書で定義されていたtoolIcons
const toolIcons: Record<string, string> = {
  Bash: "💻",
  Read: "📖",
  Write: "✏️",
  Edit: "📝",
  Glob: "🔍",
  Grep: "🔎",
  LS: "📁",
  Task: "📋",
  WebSearch: "🌐",
  WebFetch: "🌐",
};
```

### 1.2 問題点・課題

| 課題               | 詳細                                             |
| ------------------ | ------------------------------------------------ |
| ツール識別性の低さ | 現状はテキストバッジのみでツールを表示           |
| 視覚的直感性の欠如 | アイコンがないためツールの性質が一目で分からない |
| 仕様書との乖離     | 設計仕様に含まれていた機能が未実装               |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                                     | 重要度 |
| ------------ | -------------------------------------------- | ------ |
| UX品質       | ツール識別に時間がかかる                     | 低     |
| 仕様整合性   | 設計仕様と実装の乖離が残る                   | 低     |
| 拡張性       | 新規ツール追加時にアイコン対応が後回しになる | 低     |

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogのツール名表示にアイコンを追加し、ユーザーがツールの種類を視覚的に即座に識別できるようにする。

### 2.2 最終ゴール

- [ ] ツール名の左側にアイコンが表示される
- [ ] 10種類以上のツールに対応するアイコンマッピングが実装される
- [ ] 未定義ツールにはデフォルトアイコンが表示される
- [ ] 既存テストが全てPASSする
- [ ] アイコン表示のテストが追加される

### 2.3 スコープ

**含まれるもの**:

- toolIconsマッピングオブジェクトの追加
- PermissionDialog.tsxへのアイコン表示ロジック追加
- テストケースの追加
- 実装ガイドの更新

**含まれないもの**:

- カスタムSVGアイコンの作成
- アイコン設定のUI
- ツールごとのカスタムカラー

### 2.4 成果物

| 成果物               | パス                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 修正後コンポーネント | `apps/desktop/src/renderer/components/skill/PermissionDialog.tsx`                |
| 追加テスト           | `apps/desktop/src/renderer/components/skill/__tests__/PermissionDialog.test.tsx` |
