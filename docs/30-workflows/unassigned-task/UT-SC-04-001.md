## 概要

`SkillFileWriter` 具象クラスを直接 `RuntimeSkillCreatorFacadeDeps.skillFileWriter` に注入している。DIP（依存性逆転原則）に準拠するため、`ISkillFileWriter` インターフェースを抽出し、依存先をインターフェースに変更する。

## 現状

```typescript
// RuntimeSkillCreatorFacade.ts
import type { SkillFileWriter } from "../skill/SkillFileWriter";
export interface RuntimeSkillCreatorFacadeDeps {
  skillFileWriter?: SkillFileWriter; // 具象クラス依存（P61）
}
```
