## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

task-imp-permission-readable-ui-001で固定テンプレート方式の人間可読説明文が実装された。しかし、固定テンプレートでは対応できない複雑な操作（複数引数の組み合わせ、コンテキスト依存の説明等）がある。AIによる動的説明文生成を導入することで、より正確で文脈に応じた説明文を提供できる。

### 1.2 問題点・課題

| 課題                   | 詳細                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 固定テンプレートの限界 | 複雑な引数パターンに対応しきれない                           |
| コンテキスト欠如       | 操作の前後関係や目的が説明に反映されない                     |
| 新規ツール対応の手動化 | 新しいツールが追加されるたびにテンプレートを手動追加する必要 |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                             | 重要度 |
| ------------ | ------------------------------------ | ------ |
| UX品質       | 複雑な操作の説明が不十分             | 低     |
| 保守性       | ツール追加時にテンプレート追加が必要 | 低     |
| 拡張性       | 新しい説明パターンへの対応が困難     | 低     |

---

## 2. 何を達成するか（What）

### 2.1 目的

AIモデルを活用して、ツール操作の動的な説明文を生成し、固定テンプレートでは対応できないケースもカバーする。

### 2.2 最終ゴール

- [ ] AIによる動的説明文生成が機能する
- [ ] 固定テンプレートとのフォールバック機構が存在する
- [ ] レスポンス時間が許容範囲内（2秒以内）
- [ ] 既存テストが全てPASSする

### 2.3 スコープ

**含まれるもの**:

- 固定テンプレートとのフォールバック機構
- キャッシュ機構

**含まれないもの**:
