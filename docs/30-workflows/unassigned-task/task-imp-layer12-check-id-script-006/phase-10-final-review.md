## 実行タスク

### タスク1: 受け入れ基準の全件確認

| AC   | 基準                                                                            | 確認方法                                      | 判定   |
| ---- | ------------------------------------------------------------------------------- | --------------------------------------------- | ------ |
| AC-1 | スクリプト実行で実装の全 check ID と仕様書の全 check ID が突き合わされる        | `node scripts/verify-check-id-parity.js` 実行 | 未確認 |
| AC-2 | 仕様書の「拡張ガイドライン」セクション内の例示値（`L2-008` 等）が誤検知されない | 統合テスト PASS 確認                          | 未確認 |
| AC-3 | 差分が 0 件のとき PASS 出力、差分があるとき FAIL 出力と差分一覧が表示される     | 両ケースの動作確認                            | 未確認 |
| AC-4 | check ID が 30 件超に増加しても手動修正なしで動作する（ハードコードなし）       | コードレビュー                                | 未確認 |
| AC-5 | スクリプトの実行方法が README または実行コメントで明示されている                | コメント・ヘルプ確認                          | 未確認 |

### タスク2: スコープの確認

**スコープ外が混入していないか確認する**:

- [ ] check ID の追加・変更自体が行われていない
- [ ] `SkillCreatorVerificationEngine.ts` 本体のコード変更が行われていない
- [ ] Layer 5 以降の設計・実装が行われていない

### タスク3: 判定と記録

**判定基準**:

| 判定  | 条件                      | 対応                   |
| ----- | ------------------------- | ---------------------- |
| PASS  | AC-1〜AC-5 が全件 OK      | Phase 11 へ進行        |
| MINOR | AC の一部が軽微な問題あり | 修正後 Phase 11 へ進行 |
| MAJOR | AC の根幹部分に問題あり   | 前 Phase へ差し戻し    |

> MINOR 判定の指摘事項は未タスク候補として `unassigned-task-detection.md`（Phase 12 Task 4）に記録する。
