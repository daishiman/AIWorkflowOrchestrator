## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

CONV-07-05でRRF Fusion + Reranking機能を実装したが、現状ではRerankerの選択（LLM/Cohere/Voyage/NoOp）はコード上で設定する必要がある。ユーザーがUI上で直感的にRerankerを選択できる機能があれば、より使いやすくなる。

### 1.2 問題点・課題

- 現在のReranker選択はコード設定のみ
- 非エンジニアユーザーが設定変更しにくい
- A/Bテストや比較検証が手軽にできない

### 1.3 放置した場合の影響

- **影響度**: 低
- ユーザビリティが低下するが、機能自体は正常に動作
- コード設定で対応可能なため、緊急性は低い

---

## 2. 何を達成するか（What）

### 2.1 目的

設定画面上でRerankerを選択できるUIを提供し、ユーザビリティを向上させる。

### 2.2 最終ゴール

- 設定画面にReranker選択ドロップダウンが表示される
- 選択したRerankerが検索時に適用される
- Reranker別のAPI Key設定が可能（Cohere/Voyage用）

### 2.3 スコープ

#### 含むもの

- 設定画面へのReranker選択UIの追加
- Rerankerタイプの永続化（設定保存）
- Reranker別API Key入力フォーム

#### 含まないもの

- Rerankerの実装追加（既に実装済み）
- 新しいRerankerの追加

### 2.4 成果物

| 成果物                   | 説明                           |
| ------------------------ | ------------------------------ |
| 設定画面UIコンポーネント | Reranker選択ドロップダウン     |
| 設定スキーマ更新         | Rerankerタイプ保存用フィールド |
| 設定連携コード           | UI選択→バックエンド連携        |

## 3. どのように実行するか（How）

### 3.1 前提条件

- CONV-07-05（RRF Fusion + Reranking）が完了していること
- 設定画面の基盤が存在すること

### 3.2 依存タスク

| タスクID   | タスク名               | ステータス |
| ---------- | ---------------------- | ---------- |
| CONV-07-05 | RRF Fusion + Reranking | 完了       |

### 3.3 必要な知識

- React/Next.js UIコンポーネント設計
- Zustand/Context API（状態管理）
- Rerankerインターフェース（IReranker）

### 3.4 推奨アプローチ

1. 設定画面にRerankerセクションを追加
2. ドロップダウンでRerankerタイプを選択可能に
3. Cohere/Voyageを選択した場合、API Key入力欄を表示
4. 設定を永続化し、検索時に適用

## 6. 検証方法

### テストケース

1. 各Rerankerが選択できること
2. 設定保存後、ページリロードで設定が維持されること
3. 選択したRerankerが実際に適用されること

### 検証手順

1. 設定画面を開く
2. Reranker選択ドロップダウンで各オプションを選択
3. 設定保存
4. ページリロード後、設定が維持されていることを確認
5. 検索実行し、選択したRerankerが適用されていることを確認
