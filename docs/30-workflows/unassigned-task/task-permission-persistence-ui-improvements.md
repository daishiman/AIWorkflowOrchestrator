## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

TASK-2B（SkillImportStore）で権限記憶機能（rememberPermissions）を実装したが、UI側でのユーザーへのフィードバックが限定的である。現在のPermissionDialogでは「この選択を記憶する」チェックボックスのみで、記憶された権限の管理UIが存在しない。

### 1.2 問題点・課題

- 記憶された権限の一覧表示がない
- 記憶された権限の削除/リセットUIがない
- どのスキルにどの権限が記憶されているか確認できない
- 権限の有効期限（TTL: 1時間）がUIで明示されていない

### 1.3 放置した場合の影響

- ユーザーがどの権限を許可したか把握できない
- 不要な権限を取り消す手段がない
- セキュリティ上の透明性が低い
- ユーザーの不安感につながる可能性

---

## 2. 何を達成するか（What）

### 2.1 目的

権限永続化の状態をユーザーが確認・管理できるUIを提供し、セキュリティの透明性を向上させる。

### 2.2 最終ゴール

- 記憶された権限の一覧表示
- 個別権限の削除機能
- 全権限の一括リセット機能
- 権限の有効期限表示

### 2.3 スコープ

#### 含むもの

- PermissionManagementPanelコンポーネント
- 記憶された権限の一覧表示
- 個別削除・一括リセット機能
- 有効期限の表示
- ユニットテスト

#### 含まないもの

- 権限の有効期限のカスタマイズUI
- 権限のエクスポート/インポート
- 権限の詳細なカスタマイズ（ファイルパス指定など）

### 2.4 成果物

## 9. 備考

### UI設計案

```
┌─────────────────────────────────────────────────┐
│ 記憶された権限                                   │
├─────────────────────────────────────────────────┤
│ スキル名      │ ツール │ 許可/拒否 │ 有効期限  │ 操作 │
│───────────────│────────│───────────│───────────│──────│
│ my-skill      │ Bash   │ ✓ 許可    │ 45分      │ 🗑️    │
│ my-skill      │ Write  │ ✗ 拒否    │ 30分      │ 🗑️    │
│ other-skill   │ Read   │ ✓ 許可    │ 15分      │ 🗑️    │
├─────────────────────────────────────────────────┤
│ [すべての記憶をリセット]                         │
└─────────────────────────────────────────────────┘
```

### 補足事項

- 有効期限は「残り○分」形式で表示（リアルタイム更新は不要、ページ読み込み時の計算でOK）
- 削除確認は個別削除では不要、一括リセットのみ確認ダイアログを表示
- 設定画面の「セキュリティ」セクションに配置を推奨
