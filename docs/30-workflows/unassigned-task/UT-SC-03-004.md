# UT-SC-03-004: plan() 出力型の SkillBlueprint 互換移行

## メタ情報

| 項目       | 値                                                 |
| ---------- | -------------------------------------------------- |
| 未タスクID | UT-SC-03-004                                       |
| 検出元     | TASK-SC-03-PLAN-LLM-PROMPT 正本との整合性検証      |
| 優先度     | 高                                                 |
| 影響範囲   | RuntimeSkillCreatorFacade.ts, skillCreator.ts, w3a |

## 概要

index.md（正本）では plan() の出力型は SkillBlueprint（category + customizations + files + reasoning フィールド含む）と定義されているが、現在の実装は RuntimeSkillCreatorPlanResult（flat な agents/scripts リスト）のみ。後続タスク w3a（SkillFileWriter）が SkillBlueprint を入力に期待するため、型不整合が発生する。

## 対応方針

1. 段階的移行として、現在の flat 構造を SkillBlueprint の subset（`category: "standard"` 固定）として返すアダプタレイヤーを検討
2. RuntimeSkillCreatorPlanResult を SkillBlueprint に変換する関数を実装
3. w3a タスクとの型契約を確定
