# Phase 7: カバレッジ確認

## メタ情報

| 項目   | 値                          |
| ------ | --------------------------- |
| Phase  | 7                           |
| 機能名 | claude-code-cli-integration |
| 作成日 | 2026-01-16                  |

## 目的

テストカバレッジが目標値を達成しているか確認し、未達の場合はPhase 6に戻る。

## 判定基準

| 指標              | 最低基準 | 推奨基準 | 判定          |
| ----------------- | -------- | -------- | ------------- |
| Line Coverage     | 80%      | 90%      | 80%未満で未達 |
| Branch Coverage   | 60%      | 70%      | 60%未満で未達 |
| Function Coverage | 80%      | 90%      | 80%未満で未達 |

### 判定フロー

```
カバレッジ測定
    ↓
全指標が最低基準を満たす？
    ├─ YES → Phase 8へ進行
    └─ NO → Phase 6に戻りテスト追加
```

## 実行タスク

### タスク1: カバレッジ測定

**目的**: 現在のテストカバレッジを測定する

**手順**:

1. カバレッジ付きでテスト実行
2. カバレッジレポート生成
3. 各指標の数値を記録

**コマンド**:

```bash
# カバレッジ測定
pnpm --filter @repo/desktop test -- --run --coverage

# HTMLレポート生成
pnpm --filter @repo/desktop test -- --run --coverage --reporter=html
```

**期待される成果物**:

- カバレッジレポート

### タスク2: カバレッジ分析

**目的**: カバレッジ不足の箇所を特定する

**手順**:

1. ファイル別カバレッジを確認
2. 未カバー行を特定
3. 未カバーブランチを特定
4. 優先度付けして記録

**分析観点**:

| 観点             | 確認内容                   |
| ---------------- | -------------------------- |
| 低カバレッジ     | 80%未満のファイル          |
| 未カバー行       | テストされていないコード行 |
| 未カバーブランチ | テストされていない条件分岐 |
| デッドコード     | 到達不能なコード           |

**期待される成果物**:

- カバレッジ分析レポート

### タスク3: 判定

**目的**: カバレッジ目標達成を判定する

**手順**:

1. 各指標と目標値を比較
2. 判定結果を記録
3. 未達の場合は不足箇所を明記

**判定テンプレート**:

```markdown
# カバレッジ判定結果

## 測定結果

| 指標              | 測定値 | 最低基準 | 判定      |
| ----------------- | ------ | -------- | --------- |
| Line Coverage     | XX%    | 80%      | PASS/FAIL |
| Branch Coverage   | XX%    | 60%      | PASS/FAIL |
| Function Coverage | XX%    | 80%      | PASS/FAIL |

## 総合判定

**判定**: PASS / FAIL

## 未達箇所（FAILの場合）

| ファイル | 現在値 | 目標値 | 不足行/ブランチ |
| -------- | ------ | ------ | --------------- |
| ...      | ...    | ...    | ...             |

## 次のアクション

- [ ] （未達の場合）Phase 6に戻りテスト追加
- [ ] （達成の場合）Phase 8へ進行
```

**期待される成果物**:

- 判定結果ドキュメント
