## メタ情報

| 項目       | 値                          |
| ---------- | --------------------------- |
| 機能名     | claude-code-cli-integration |
| バージョン | 1.0.0                       |

| Phase      | 2                           |

---

## 1. 概要

本ドキュメントでは、Claude Code CLI統合の主要な処理フローをシーケンス図で示す。

### 1.1 対象フロー

| フロー名             | 説明                           |
| -------------------- | ------------------------------ |
| アプリケーション起動 | CLI検出・初期化フロー          |
| スキル一覧取得       | スキルスキャン・フィルタリング |
| スクリプト実行       | 実行開始〜ストリーミング〜完了 |
| セッション終了       | graceful shutdown              |
| エラーハンドリング   | 各種エラー発生時の処理         |

## 7. 統合ポイント/契約定義

### 7.1 契約一覧

| 統合ポイント        | 契約（型）                               | 方向            |
| ------------------- | ---------------------------------------- | --------------- |
| Renderer → preload  | `ClaudeCliAPI` interface                 | invoke/callback |
| preload → Main      | `CLAUDE_CLI_CHANNELS` + request/response | IPC             |
| Main → CLI Manager  | `ClaudeCliManager` class methods         | 内部呼び出し    |
| CLI Manager → Child | `spawn()` + stdin/stdout/stderr/exit     | プロセス        |
