## 目的

Undo 操作後にサーバー状態が実際に巻き戻されることを手動で確認する。

## 手動テストシナリオ

| シナリオ                    | 手順                                                    | 期待結果                                                   |
| --------------------------- | ------------------------------------------------------- | ---------------------------------------------------------- |
| 基本的な Undo 動作確認      | ラリーで2〜3ステップ進み、Undo ボタンをクリックする     | 前の質問に戻り、サーバー状態も同期して巻き戻される         |
| サーバー状態の同期確認      | Undo 後に次の送信を行う                                 | サーバー側の前の質問に対して回答が送信される（整合性確認） |
| Undo 失敗時のエラー表示確認 | ネットワーク切断状態で Undo をクリックする              | エラーメッセージが表示される                               |
| IPC ログ確認                | 開発者ツールのネットワークタブで IPC 呼び出しを確認する | `skill-creator:undo-user-input` が呼ばれていることを確認   |
