## 変更内容の説明（中学生レベル）

このタスクでは「ラリー（インタビュー）が終わったかどうかをユーザーに伝える画面」を作りました。

ラリーとは、AIがユーザーに順番に質問をして、スキル（機能の設計書）を作るための会話のことです。

変更前は、AIが次の質問を準備しているときと、すべての質問が終わってラリーが完了したときの両方で「質問を待っています...」と表示されていました。ユーザーから見ると「まだ続くの？もう終わったの？」と分かりませんでした。

変更後は：

- ラリーが完了したとき → 「ラリーが完了しました」と表示（緑色）
- 次の質問を準備中のとき → 「次の質問を準備しています...」と表示

この2つが別々のメッセージになったので、ユーザーがいつ終わったかを分かるようになりました。
