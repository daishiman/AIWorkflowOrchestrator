## 目的

Phase 5 で実施したTODOコメント整理の結果コードを、可読性・保守性の観点で再調整する。
テストが全て Green であることを維持しながらコードを整理する。
本タスクはコメント整理のため、リファクタリングの対象範囲は最小限となる。

## 実行タスク

### Task 1: コード品質チェック

整理後のコードを以下の観点で確認する。

| 観点                   | チェック内容                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| コメントの適切性       | 整理後のコメントが意図を正確に表しているか（オプション A: 削除済み / オプション B: 明確化済み） |
| 不要コードの除去       | オプション A-1 採用時: `MAIN_TOOL_BADGE_ENABLED` 参照が完全に除去されているか                   |
| トレーサビリティの確保 | オプション B 採用時: 書き換え後のTODOコメントが具体的な条件を含んでいるか                       |
| 一貫性                 | コメントスタイルがファイル内の他のコメントと統一されているか                                    |

### Task 2: 命名と構造の整理

- オプション A 採用時: 削除したコメント・フラグの痕跡（空白行など）が残っていないか確認する
- オプション B 採用時: 書き換えたTODOコメントが正しいフォーマットになっているか確認する
