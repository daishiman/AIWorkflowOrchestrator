## 手動テストシナリオ

### TC-11-UI-01: 送信中のボタン disabled 確認（目視必須）

| 項目         | 内容                                                            |
| ------------ | --------------------------------------------------------------- |
| 前提条件     | ラリー進行中で回答入力済みの状態                                |
| 操作手順     | 回答を送信する                                                  |
| 期待結果     | 送信ボタンが disabled になり「送信中...」表示になること         |
| 確認ポイント | 送信完了前に次の質問が表示されないこと                          |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-01-submitting-state.png` |

### TC-11-UI-02: 送信完了後の質問切り替え確認（目視必須）

| 項目         | 内容                                                        |
| ------------ | ----------------------------------------------------------- |
| 前提条件     | 送信中状態から送信完了した直後                              |
| 操作手順     | 送信完了後の画面を観察する                                  |
| 期待結果     | 次の質問が正しく表示されること                              |
| 確認ポイント | 「送信中...」と「次の質問」が同時表示されないこと           |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-02-after-submit.png` |

### TC-11-UI-03: 送信中の画面状態全体確認（目視必須）

| 項目         | 内容                                                                |
| ------------ | ------------------------------------------------------------------- |
| 前提条件     | isSubmitting = true の状態                                          |
| 操作手順     | 送信中の画面全体をスクリーンショット撮影                            |
| 期待結果     | ローディング表示と既存の質問履歴のみが表示されていること            |
| 確認ポイント | 競合するUI要素（次の質問 + ローディング）が同時表示されていないこと |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-03-no-conflict.png`          |
