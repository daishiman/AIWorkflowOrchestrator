## 変更内容の説明（中学生レベル）

このタスクでは「ラリー中にエラーが起きたとき、ユーザーが次に何をすればいいかを教える画面」を作りました。

ラリーでは、回答を送信するときにインターネット通信が失敗することがあります。これは、Wi-Fiが不安定なときやサーバーが混んでいるときに起こります。

変更前は、エラーが起きたとき「回答の送信に失敗しました」というメッセージがどこかに表示されるだけで、ユーザーは「もう一度試せばいいの？最初からやり直すの？」と分からなくなっていました。

変更後は、エラーが起きると：

- 「再試行する」ボタン: 同じ回答をもう一度送る
- 「最初からやり直す」ボタン: ラリーをはじめから始める（設定されている場合）

の2つのボタンが表示されるようになりました。ユーザーが迷わず次のアクションを選べるようになります。
