## 手動テストシナリオ

### TC-11-UI-01: エラー発生時の回復UIの表示（目視必須）

| 項目         | 内容                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| 前提条件     | ネットワーク切断またはモックによりonSubmitが失敗する状態                      |
| 操作手順     | 回答を入力して送信する                                                        |
| 期待結果     | 「回答の送信に失敗しました」とエラーメッセージが表示される                    |
| 確認ポイント | 「再試行する」ボタンと「最初からやり直す」ボタン（onReset定義時）が表示される |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-01-error-recovery-ui.png`              |

### TC-11-UI-02: 再試行ボタンの動作確認（目視必須）

| 項目         | 内容                                                        |
| ------------ | ----------------------------------------------------------- |
| 前提条件     | エラーUI表示状態（TC-11-UI-01 の状態）                      |
| 操作手順     | 「再試行する」ボタンをクリックする                          |
| 期待結果     | 同じ回答が再送信され、送信中状態に遷移すること              |
| 確認ポイント | エラーUIが消えて通常フローに戻ること                        |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-02-retry-button.png` |

### TC-11-UI-03: エラー中の入力エリア非表示確認（目視必須）

| 項目         | 内容                                                        |
| ------------ | ----------------------------------------------------------- |
| 前提条件     | エラーUI表示状態                                            |
| 操作手順     | 画面全体を確認する                                          |
| 期待結果     | 通常の入力エリアが非表示になっていること                    |
| 確認ポイント | エラーUIと入力エリアが同時表示されていないこと              |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-03-input-hidden.png` |

### TC-11-UI-04: onResetなし時のリセットボタン非表示確認（目視必須）

| 項目         | 内容                                                           |
| ------------ | -------------------------------------------------------------- |
| 前提条件     | `onReset` プロップスが渡されていない状態でエラー発生           |
| 操作手順     | エラーUI を確認する                                            |
| 期待結果     | 「最初からやり直す」ボタンが表示されていないこと               |
| 確認ポイント | 「再試行する」ボタンのみが表示されること                       |
| 証跡         | `outputs/phase-11/screenshots/TC-11-UI-04-no-reset-button.png` |
