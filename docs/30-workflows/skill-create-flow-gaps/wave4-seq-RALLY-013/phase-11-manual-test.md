## 目的

Undoインジケーターの表示をElectronアプリ上で目視確認し、ステップ数が正しく表示され、Undoボタンの disabled 状態が視覚的に正しいことをスクリーンショットで記録する。

**RALLY-010〜013 はUIタスクのため、このPhase 11は特に重要。**
RALLY-013 は ConversationalInterview ドメインのチェーン末尾であり、RALLY-010〜013 の全変更が統合された状態での最終UI確認となる。
