## 実行手順

### ステップ1: 要件抽出

未タスク仕様書から機能要件・非機能要件を抽出する。

**機能要件（FR）**:

| FR-ID | 要件                                        | 優先度 |
| ----- | ------------------------------------------- | ------ |
| FR-01 | コピー履歴パネルを表示できる                | 高     |
| FR-02 | 履歴項目をクリックして再度コピーできる      | 高     |
| FR-03 | 複数メッセージを選択して一括コピーできる    | 中     |
| FR-04 | 履歴を手動でクリアできる                    | 中     |
| FR-05 | 最大50件まで履歴を保持する                  | 中     |
| FR-06 | 履歴項目にプレビュー（最初の100文字）を表示 | 低     |

**非機能要件（NFR）**:

| NFR-ID | 要件                                         | 優先度 |
| ------ | -------------------------------------------- | ------ |
| NFR-01 | 既存CopyButton機能を維持する                 | 高     |
| NFR-02 | キーボード操作に対応する（Tab/Enter/Escape） | 高     |
| NFR-03 | スクリーンリーダー対応（aria-label等）       | 高     |
| NFR-04 | 履歴追加時のUI遅延を100ms以下に抑える        | 中     |
| NFR-05 | メモリ使用量を抑制する（50件上限）           | 中     |

### ステップ2: 受け入れ基準作成

各要件に対して検証可能な受け入れ基準を定義する。

| 要件ID | 受け入れ基準                                                       |
| ------ | ------------------------------------------------------------------ |
| FR-01  | 履歴アイコンをクリックするとポップオーバーパネルが開く             |
| FR-02  | 履歴項目をクリックするとクリップボードに内容がコピーされる         |
| FR-03  | チェックボックスで複数選択し「一括コピー」ボタンで結合コピーできる |
| FR-04  | 「クリア」ボタンをクリックすると全履歴が削除される                 |
| FR-05  | 51件目のコピー時に最古の履歴が自動削除される                       |
| FR-06  | 100文字を超えるコンテンツは「...」で省略表示される                 |
| NFR-01 | 既存のCopyButtonテストが全てPASSする                               |
| NFR-02 | Tabキーでフォーカス移動、Enterで選択、Escapeでパネルを閉じられる   |
| NFR-03 | スクリーンリーダーで各要素の役割と状態が読み上げられる             |

### ステップ3: FR/NFR分類と優先度設定
