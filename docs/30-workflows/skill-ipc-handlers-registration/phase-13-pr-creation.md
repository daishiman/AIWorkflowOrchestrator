## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認

**目的**: PR作成前のローカル確認を完了する

**実行手順**:

1. `pnpm build` でビルドが成功することを確認する
2. `pnpm test` で全テストがパスすることを確認する
3. `pnpm typecheck` で型チェックがパスすることを確認する
4. `pnpm lint` でLintエラーがないことを確認する

**期待される成果物**:

- ローカル確認結果

---

### タスク2: ユーザー確認

**目的**: PR作成の許可を得る

**実行手順**:

1. 変更内容のサマリーをユーザーに提示する
2. PR作成の許可を求める
3. 許可が得られたらPhase 13-3に進む

**重要**: **PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

**期待される成果物**:

- ユーザー確認結果

---

### タスク3: PR作成（ユーザー許可後）

**目的**: PRを作成しCIを確認する

**実行手順**:

1. `/ai:diff-to-pr` コマンドを実行する
2. PRが作成されたことを確認する
3. CIが成功することを確認する
4. マージ可能状態を報告する

**期待される成果物**:

- PR URL
- CI結果

## PR作成に関する重要な注意

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                 | 理由                                           |
| ---------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                       | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行 | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする               | 動作確認されていないコードがPRに含まれる       |
