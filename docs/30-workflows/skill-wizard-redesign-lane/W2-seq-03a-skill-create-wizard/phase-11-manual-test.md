## 手動テストシナリオ

### シナリオ 1: 正常系 complete フロー

| ステップ | 操作                                                                                           | 期待結果                                                                              |
| -------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1        | SkillLifecyclePanel の「ウィザードで作成」ボタンを押す                                         | ウィザードが開き Step 0（スキル情報入力）が表示される                                 |
| 2        | ステップインジケーターを確認する                                                               | 「スキル情報入力 / 詳細設定 / 生成 / 完了」と表示される                               |
| 3        | スキル名「Slack通知」、目的「毎日Slackに通知」、カテゴリ「automation」を入力して「次へ」を押す | Step 1（詳細設定）に遷移する                                                          |
| 4        | Step 1 の質問に全6問回答する                                                                   | 各回答がハイライトされ進捗「質問6/6」になる                                           |
| 5        | 「生成」ボタンを押す                                                                           | LLM 生成が開始し生成中インジケーターが表示される                                      |
| 6        | 生成完了後                                                                                     | Step 3（完了画面）に遷移する                                                          |
| 7        | 完了画面で 👍 を押す                                                                           | フィードバックが記録される（W3-seq-04 計装確認）                                      |
| 8        | 完了画面のネクストアクション 3カードと `skillPath` を確認する                                  | `今すぐ実行する` / `エディタで開く` / `別のスキルを作る` と生成結果のパスが表示される |
