## 目的

Phase 4 の基本テストを拡充し、エッジケース・回帰テストで品質を高める。

## 拡充テストケース

### inferSmartDefaults エッジケース

| ケース                                   | 期待結果                                               |
| ---------------------------------------- | ------------------------------------------------------ |
| purpose が空文字の場合                   | 全フィールドが undefined                               |
| purpose に複数のツール名が含まれる場合   | 最初に一致したツールが採用される                       |
| purpose に大文字/小文字混在の「slack」   | 大文字小文字を区別せず `tool="slack"` になることを確認 |
| purpose に「毎日」と「リアルタイム」両方 | どちらの timing が採用されるかを確認（先勝ち/後勝ち）  |
| category が null の場合                  | format が null になること                              |
| inferenceLog が空配列として返ること      | 推論が0件でも inferenceLog が配列として存在すること    |

### handleStep0Next 回帰テスト

| ケース                                     | 期待結果                                                   |
| ------------------------------------------ | ---------------------------------------------------------- |
| formData が null/undefined の場合          | エラーをスローしないこと（または適切なエラーハンドリング） |
| onNext が呼ばれた直後の currentStep        | 0 → 1 に遷移していること                                   |
| smartDefaults が null の状態で呼ばれた場合 | inferSmartDefaults の結果で上書きされること                |

### handleGenerate エッジケース

| ケース                                            | 期待結果                                                 |
| ------------------------------------------------- | -------------------------------------------------------- |
| LLM 生成が失敗した場合（Promise reject）          | エラー状態が適切にハンドリングされること                 |
| "complete" と "skip" で generationMethod が変わる | generationMethod state が正しく更新されること            |
| 生成中（isGenerating=true）に再度呼ばれた場合     | `generationLockRef` も含めて二重呼び出しが防止されること |
| 生成成功後の `skillPath`                          | CompleteStep に渡せる値が保持されること                  |

### handleRetry 回帰テスト

| ケース                                    | 期待結果                       |
| ----------------------------------------- | ------------------------------ |
| CompleteStep で 👎 を押した場合           | currentStep が 0 に戻ること    |
| Step 0 に戻った後も formData が保持される | 前回入力がプリフィルされること |
| `skillPath` が再利用されないこと          | 旧生成結果の表示が残らないこと |

### CompleteStep 外部連携表示の回帰テスト

| ケース                               | 期待結果                                 |
| ------------------------------------ | ---------------------------------------- |
| hasExternalIntegration=true の場合   | 外部連携チェックリストが表示されること   |
| hasExternalIntegration=false の場合  | 外部連携チェックリストが非表示であること |
| externalToolName が undefined の場合 | デフォルトの外部ツール名が表示されること |

### STEPS 配列回帰テスト

| ケース       | 期待結果                    |
| ------------ | --------------------------- |
| STEPS の長さ | 4 であること                |
| STEPS[0]     | "スキル情報入力" であること |
| STEPS[1]     | "詳細設定" であること       |
| STEPS[2]     | "生成" であること           |
| STEPS[3]     | "完了" であること           |

### 旧 state / legacy prop 削除の回帰テスト

| ケース                                           | 期待結果                                                                  |
| ------------------------------------------------ | ------------------------------------------------------------------------- |
| "template" 文字列がソースコードに残っていないか  | `generationMode` / `description` / `options` 関連の文字列が存在しないこと |
| `setGenerationMode` が呼ばれないこと             | 旧関数が呼ばれないことの確認                                              |
| GenerateStep に `generationMode` prop を渡さない | LLM 専用化後の契約が維持されていること                                    |
