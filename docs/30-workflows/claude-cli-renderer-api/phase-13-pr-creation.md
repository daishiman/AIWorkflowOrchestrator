## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認チェックリスト

**目的**: PR作成前にローカルでの確認を完了する

**実行手順**:

1. 以下のチェックリストを全て確認する:

   | #   | 確認項目             | コマンド         | 結果 |
   | --- | -------------------- | ---------------- | ---- |
   | 1   | ビルドが成功する     | `pnpm build`     | [ ]  |
   | 2   | 全テストがパスする   | `pnpm test`      | [ ]  |
   | 3   | 型チェックがパスする | `pnpm typecheck` | [ ]  |
   | 4   | Lintエラーがない     | `pnpm lint`      | [ ]  |

2. 全てのチェック項目がパスすることを確認する

**期待される成果物**:

- ローカル確認チェックリスト完了

---

### タスク2: 変更内容の確認

**目的**: コミットする変更内容を確認する

**実行手順**:

1. 変更されたファイルを確認する:
   ```bash
   git status
   ```
2. 変更内容を確認する:
   ```bash
   git diff
   ```
3. 以下の変更が含まれていることを確認する:
   - テストファイルの追加/更新
   - ドキュメントの追加
   - 必要な実装修正（あれば）

**期待される成果物**:

- 変更内容の確認結果

---

### タスク3: ユーザー確認の取得

**目的**: PR作成前にユーザーの明示的な許可を得る

**実行手順**:

1. ユーザーに以下を確認する:
   - 変更内容は期待通りか
   - PRを作成してよいか
   - ブランチ名は適切か
2. **ユーザーの明示的な許可を得てから**タスク4に進む

> **重要**: PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。

**期待される成果物**:

- ユーザー許可の取得

---

### タスク4: `/ai:diff-to-pr`の実行

**目的**: コミット・PR作成・CI確認を実行する

**実行手順**:

1. **ユーザーの許可を得た後**、`/ai:diff-to-pr`コマンドを実行する
2. コマンドが以下のワークフローを実行することを確認する:
   - リモートmain同期・コンフリクト解消
   - 品質検証（typecheck, lint, test）
   - 差分分析・ブランチ作成・コミット
   - PR本文生成・PR作成
   - 補足コメント投稿
   - CI/CD完了確認
   - マージ可能報告
3. CI/CDが成功することを確認する

**期待される成果物**:

- PR URL
- CI/CD成功確認

---

### タスク5: PR作成完了の記録

**目的**: PR作成完了を記録する

**実行手順**:

1. `outputs/phase-13/pr-creation-result.md`を作成する
2. 以下の情報を記録する:
   - PR URL
   - ブランチ名
   - CI/CD結果
   - 作成日時

**期待される成果物**:

- `outputs/phase-13/pr-creation-result.md`（PR作成結果）

## 重要な注意事項

### PR作成に関する禁止事項

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

### マージに関する注意

- **マージはユーザーがGitHub UI上で手動実行する**
- 本タスクはPR作成までを範囲とし、マージは含まない
