## 目的

静的解析、セキュリティチェック、パフォーマンス確認を行い、コードの品質を保証する。

## 背景

リファクタリング後のコードが品質基準を満たしていることを確認する。Lint、型チェック、セキュリティスキャンなどを実行する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: Lintチェック

**目的**: ESLintによる静的解析を実行する

**実行手順**:

1. Lintを実行する:
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. エラーがあれば修正する
3. 警告を確認し、必要に応じて対応する
4. 結果を記録する

**期待される成果物**:

- Lintチェック結果（エラー0件）

---

### タスク2: 型チェック

**目的**: TypeScriptの型チェックを実行する

**実行手順**:

1. 型チェックを実行する:
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
2. 型エラーがあれば修正する
3. 結果を記録する

**期待される成果物**:

- 型チェック結果（エラー0件）

---

### タスク3: セキュリティチェック

**目的**: Preload APIのセキュリティを確認する

**実行手順**:

1. 以下のセキュリティ観点を確認する:
   - `safeInvoke`によるチャンネルホワイトリスト検証
   - `safeOn`によるイベント購読のセキュリティ
   - `contextBridge`による安全な公開
   - 機密情報の漏洩がないか
2. セキュリティチェックリストを確認する:
   - [ ] 許可されていないチャンネルへのアクセスが拒否される
   - [ ] 全IPCチャンネルがホワイトリストに登録されている
   - [ ] `contextBridge`経由でのみAPIが公開されている
   - [ ] エラーメッセージに機密情報が含まれていない

**期待される成果物**:

- セキュリティチェック結果

---

### タスク4: パフォーマンス確認

**目的**: Preload APIのパフォーマンスを確認する

**実行手順**:

1. 以下のパフォーマンス観点を確認する:
   - 同期処理がブロッキングしていないか
   - 大量データのストリーミングが適切に処理されるか
   - メモリリークの可能性がないか（イベントリスナーの登録/解除）
2. 確認結果を記録する

**期待される成果物**:

- パフォーマンス確認結果

---

### タスク5: 品質レポートの作成

**目的**: 品質保証の結果をレポートにまとめる

**実行手順**:

1. タスク1-4の結果を`outputs/phase-9/quality-report.md`にまとめる
2. 以下の項目を含める:
   - Lintチェック結果
   - 型チェック結果
   - セキュリティチェック結果
   - パフォーマンス確認結果
   - 総合評価

**期待される成果物**:

- `outputs/phase-9/quality-report.md`（品質レポート）
