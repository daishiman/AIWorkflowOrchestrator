## 詳細仕様

### FR-001: コミュニティ構造のグラフ/ツリー表示

**概要**: コミュニティをノード、親子関係をエッジとしてグラフ形式で表示する

**詳細**:

- コミュニティを円形ノードとして表示
- ノードサイズはコミュニティのサイズ（メンバー数）に比例
- 親子関係を有向エッジで表示（親→子）
- 階層レベルに応じた縦方向のレイアウト（上位レベルが上）
- dagre（階層グラフレイアウトアルゴリズム）を使用

**受け入れ基準**:

- [ ] 全コミュニティがノードとして表示される
- [ ] 親子関係がエッジで正しく接続される
- [ ] 階層構造が視覚的に理解できるレイアウトである
- [ ] 100件以上のコミュニティでも表示できる

---

### FR-002: コミュニティクリックによる詳細パネル表示

**概要**: ノードをクリックすると右側に詳細パネルが表示される

**詳細**:

- クリックしたノードが選択状態（ハイライト）になる
- 詳細パネルに選択したコミュニティの情報を表示
- 他のノードをクリックすると選択が切り替わる
- パネル外クリックまたはEscapeで選択解除

**受け入れ基準**:

- [ ] ノードクリックで詳細パネルが表示される
- [ ] 選択中のノードが視覚的に区別できる
- [ ] Escapeキーで選択を解除できる
- [ ] 連続したクリックで正しく切り替わる

---

### FR-003: コミュニティ要約の表示

**概要**: 選択したコミュニティの要約情報を詳細パネルに表示する

**詳細**:

- 要約文（summary）を本文として表示
- キーワード（keywords）をバッジとして表示
- 主要エンティティ（mainEntities）をリスト表示
- センチメント（sentiment）をアイコン/色で表示
- 信頼度（confidence）をパーセント表示
- 要約未生成の場合は「要約が生成されていません」メッセージ

**受け入れ基準**:

- [ ] 要約文が表示される
- [ ] キーワードがバッジ形式で表示される
- [ ] 主要エンティティがリスト表示される
- [ ] 要約未生成時に適切なメッセージが表示される

---

### FR-004: メンバーエンティティの表示

**概要**: コミュニティに属するメンバーエンティティをリスト表示する

**詳細**:

- エンティティ名、タイプを表示
- スクロール可能なリスト形式
- メンバーが多い場合（10件以上）は件数表示
- エンティティをクリックで詳細表示（将来拡張）

**受け入れ基準**:

- [ ] メンバーエンティティがリスト表示される
- [ ] エンティティ名とタイプが表示される
- [ ] 多数のメンバーがある場合もスクロールで全件確認可能
- [ ] メンバー数が表示される

---

### FR-005: 階層レベルによるフィルタリング

**概要**: 特定の階層レベルのコミュニティのみを表示する

**詳細**:

- ドロップダウンでレベルを選択
- 「全て」オプションで全レベルを表示
- 選択レベルのコミュニティのみグラフに表示
- フィルタ変更時はグラフがスムーズに更新

**受け入れ基準**:

- [ ] 利用可能なレベルがドロップダウンに表示される
- [ ] レベル選択で該当コミュニティのみ表示される
- [ ] 「全て」選択で全コミュニティが表示される
- [ ] フィルタ変更後もグラフが正常に動作する

---

### FR-006: コミュニティ検索

**概要**: キーワードでコミュニティを検索・ハイライトする

**詳細**:

- 検索入力フィールドを提供
- 入力に応じてリアルタイム検索（デバウンス300ms）
- マッチするコミュニティをハイライト表示
- 検索対象: 要約、キーワード、エンティティ名
- クリアボタンで検索リセット

**受け入れ基準**:

- [ ] 検索入力フィールドが表示される
- [ ] 入力後にマッチするコミュニティがハイライトされる
- [ ] デバウンス処理が適用されている
- [ ] クリアボタンで検索がリセットされる

---

### FR-007: ズーム・パン操作

**概要**: グラフのズームイン/アウト、パン（移動）操作を提供する

**詳細**:

- マウスホイールでズームイン/アウト
- ドラッグでパン（ビュー移動）
- ズームコントロールボタン（+/-）
- フィットボタンで全体を収める表示
- ダブルクリックでデフォルトズームにリセット

**受け入れ基準**:

- [ ] マウスホイールでズームできる
- [ ] ドラッグでビューを移動できる
- [ ] フィットボタンで全体が表示される
- [ ] ズーム範囲が適切に制限されている（0.1x〜4x）

---

### FR-008: 空状態・エラー状態の表示

**概要**: データがない場合やエラー発生時に適切なUIを表示する

**詳細**:

- **空状態**: コミュニティが0件の場合
  - 「コミュニティが検出されていません」メッセージ
  - コミュニティ検出を促すガイダンス
- **ローディング状態**: データ取得中
  - スピナーまたはスケルトン表示
- **エラー状態**: IPC通信失敗など
  - エラーメッセージ表示
  - 再試行ボタン

**受け入れ基準**:

- [ ] コミュニティ0件時に空状態メッセージが表示される
- [ ] データ取得中にローディング表示される
- [ ] エラー発生時にエラーメッセージが表示される
- [ ] 再試行ボタンでデータ再取得ができる
