## 検出された未タスク・フォローアップ候補

### 1. `SkillCreatorProgressData` 型の `packages/shared/` への移動

| 項目           | 内容                                                                                                                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 優先度         | 中                                                                                                                                                                                      |
| 状態           | 未タスク（フォローアップ推奨）                                                                                                                                                          |
| 根拠           | Phase 2 設計書で記録済み                                                                                                                                                                |
| 詳細           | `onProgress` コールバックの引数型 `{ phase, percentage, message }` が `packages/shared/types` に定義されていない。現状は `skillCreatorHandlers.ts` 内のインライン型定義として存在する。 |
| 推奨アクション | `packages/shared/types` に `SkillCreatorProgressData` 型を移動し、`skillCreatorHandlers.ts` と `sendSkillCreatorProgress` の両方から参照するように変更する                              |
| 推定規模       | 小（1-2時間）                                                                                                                                                                           |

### 2. エラー時のプログレスバー状態管理

| 項目           | 内容                                                                                                                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 優先度         | 中                                                                                                                                                                                                    |
| 状態           | 未タスク（確認・対応推奨）                                                                                                                                                                            |
| 詳細           | `createSkill()` が例外をスローした場合、最後に送信されたプログレス値がプログレスバーに残留する可能性がある。エラー発生時に `percentage: 0` または専用のエラー状態をレンダラーに通知する仕組みがない。 |
| 推奨アクション | エラー時に `sendSkillCreatorProgress(mainWindow, { phase: 'error', percentage: 0, message: '...' })` を送信するか、専用の `SKILL_CREATOR_PROGRESS_ERROR` チャンネルを設ける                           |
| 推定規模       | 小〜中（2-4時間）                                                                                                                                                                                     |

---

### 3. `GenerateStep.tsx` の props 接続確認結果

| 項目     | 内容                                                                                                                                                                                                                             |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 状態     | **接続済み（対応不要）**                                                                                                                                                                                                         |
| 確認結果 | `SkillCreateWizard.tsx` では `useStreamingProgress()` の戻り値 `streaming` と `useGenerationProgress()` の戻り値 `generationProgress` の両方が `GenerateStep` に渡されている。`GenerateStep.tsx` は `generationProgress?: string | null` を props として受け取り、`message` が空の場合のフォールバックとして使用している。 |
| 備考     | Phase 3 ゲート判定において「接続済み」と確認済み                                                                                                                                                                                 |

---

### 4. プログレス通知の頻度・スロットリング

| 項目           | 内容                                                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 優先度         | 低                                                                                                                                                      |
| 状態           | 未タスク（将来的な最適化候補）                                                                                                                          |
| 詳細           | 現在の実装では `createSkill()` が `onProgress` を呼ぶ頻度に制限がない。高頻度で呼ばれた場合、IPC 送信が過多になりパフォーマンスに影響する可能性がある。 |
| 推奨アクション | 必要に応じて `sendSkillCreatorProgress` にスロットリング（例: 100ms間隔）を追加する                                                                     |
| 推定規模       | 小（1-2時間）                                                                                                                                           |
