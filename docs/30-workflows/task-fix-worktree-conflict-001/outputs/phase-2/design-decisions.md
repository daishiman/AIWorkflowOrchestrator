# 設計決定記録 - TASK-FIX-WORKTREE-CONFLICT-001

## FIX-001-A: EVALS.json merge 戦略修正

| アプローチ     | 決定       | 理由                                                      |
| -------------- | ---------- | --------------------------------------------------------- |
| `merge=ours`   | **採用**   | JSON 破損を確実に防ぎ、現ブランチ値を保持。後方互換性あり |
| `merge=union`  | 不採用     | 行単位マージで JSON キー重複 → 無効 JSON になるリスク     |
| `merge=theirs` | 不採用     | 現ブランチの評価データが消えるリスク                      |
| JSONL 移行     | スコープ外 | 有効な長期解決策だが本タスクの範囲を超える                |

**変更内容**:

```diff
- .claude/skills/*/EVALS.json       merge=union
- .agents/skills/*/EVALS.json       merge=union
+ .claude/skills/*/EVALS.json       merge=ours
+ .agents/skills/*/EVALS.json       merge=ours
```

## FIX-001-B: CI 設定更新

| 項目                | 決定                       | 理由                                          |
| ------------------- | -------------------------- | --------------------------------------------- |
| `paths-ignore` 対象 | `.claude/**`, `.agents/**` | スキルファイルはアプリコードに影響しない      |

**変更内容**: 既存 `paths-ignore` に 2 行追加 + `merge_group:` トリガー追加

## FIX-001-C: post-merge フック設計

| 項目             | 決定                        | 理由                               |
| ---------------- | --------------------------- | ---------------------------------- |
| 実行方式         | post-merge シェルスクリプト | git 標準フック、追加ツール不要     |
| 冪等性           | `cp + chmod` のみ           | 2回実行しても副作用なし            |
| スクリプト不在時 | `[ -f "$SCRIPT" ]` チェック | スクリプトがなくてもフック壊れない |
| 自動インストール | session-init.sh でチェック  | Claude Code 起動時に自動適用       |

## FIX-001-D: SKILL.md 構造分割

## FIX-001-E: gwt() post-merge フック自動インストール

| 項目         | 決定                                  | 理由                                |
| ------------ | ------------------------------------- | ----------------------------------- |
| 呼び出し位置 | `git worktree add` 成功直後           | worktree ディレクトリが確定している |
| フック不在時 | `[ -f "$hook_script" ] \|\| return 0` | FIX-001-C 未完了でも壊れない        |
| 冪等性       | `[ ! -f "$hook_file" ] \|\| return 0` | 既存フックを上書きしない            |

## FIX-001-F: B レイアウト重いフックスキップ

| 項目     | 決定                        | 理由                                 |
