## 目的

静的解析、セキュリティ、パフォーマンスの観点からコード品質を検証する。

## 背景

リファクタリングが完了した。

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析実行

**目的**: ESLint と TypeScript による静的解析を実行する

**実行手順**:

1. ESLint を実行する
2. TypeScript 型チェックを実行する
3. エラー・警告を修正する

**実行コマンド**:

```bash
# ESLint
pnpm --filter @repo/desktop lint

# TypeScript 型チェック
pnpm --filter @repo/desktop typecheck
```

**品質基準**:

| チェック項目      | 基準         | 状態 |
| ----------------- | ------------ | ---- |
| ESLint エラー     | 0 件         | [ ]  |
| ESLint 警告       | 0 件（推奨） | [ ]  |
| TypeScript エラー | 0 件         | [ ]  |

**期待される成果物**:

- 静的解析結果レポート

---

### タスク2: セキュリティチェック

**目的**: セキュリティ観点でコードをレビューする

**実行手順**:

1. セキュリティチェックリストを確認する
2. 実装がセキュリティ要件を満たしているか確認する
3. 問題があれば修正する

**セキュリティチェックリスト**:

| チェック項目       | 確認内容                                   | 状態 |
| ------------------ | ------------------------------------------ | ---- |
| 機密情報サニタイズ | password, token, secret が除去されている   | [ ]  |
| 長文省略           | 500文字を超える引数が省略されている        | [ ]  |
| IPC データ検証     | 送信データが適切に検証されている           | [ ]  |
| エラーメッセージ   | 機密情報がエラーメッセージに含まれていない | [ ]  |
| AbortSignal 処理   | キャンセル時に適切にクリーンアップされる   | [ ]  |

**期待される成果物**:

- セキュリティチェック結果

---

### タスク3: パフォーマンス確認

**目的**: パフォーマンス要件を満たしているか確認する

**実行手順**:

1. パフォーマンス要件を確認する
2. 実装がパフォーマンス要件を満たしているか確認する

**パフォーマンス要件**:

| 要件                   | 基準                       | 確認方法                 | 状態 |
| ---------------------- | -------------------------- | ------------------------ | ---- |
| 権限リクエスト送信時間 | 100ms 以内                 | 同期処理のみ使用を確認   | [ ]  |
| サニタイズ処理時間     | 大きなオブジェクトでも高速 | 再帰深度制限を確認       | [ ]  |
| メモリリーク           | なし                       | AbortController 解放確認 | [ ]  |

**確認ポイント**:

```typescript
// 確認1: 同期的なIPC送信
this.mainWindow.webContents.send(...); // 非同期ではない

// 確認2: サニタイズの再帰深度
// 深すぎるネストへの対策があるか

// 確認3: AbortController の解放
// finally ブロックでクリーンアップされているか
```

**期待される成果物**:

- パフォーマンス確認結果

---

### タスク4: コードフォーマット確認

**目的**: コードフォーマットが統一されているか確認する

**実行手順**:

1. Prettier を実行する
2. フォーマットの差分を確認する
3. 必要に応じてフォーマットを適用する

**実行コマンド**:

```bash
# フォーマットチェック
pnpm --filter @repo/desktop format:check

# フォーマット適用
pnpm --filter @repo/desktop format
```

**期待される成果物**:

- フォーマット確認結果
