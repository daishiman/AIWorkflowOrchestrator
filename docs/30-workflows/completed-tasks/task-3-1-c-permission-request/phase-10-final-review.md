### タスク5: レビュー結果判定

**目的**: レビュー結果に基づき次のアクションを決定する

**実行手順**:

1. 全てのチェック項目の結果を集計する
2. 判定基準に基づき PASS/MINOR/MAJOR/CRITICAL を判定する
3. 次のアクションを決定する

**判定基準**:

| 判定     | 条件                    | 次のアクション              |
| -------- | ----------------------- | --------------------------- |
| PASS     | 全てのチェック項目が OK | Phase 11 へ進行             |
| MINOR    | 軽微な問題が 1-2 件     | 問題修正後、Phase 11 へ進行 |
| MAJOR    | 重大な問題あり          | 該当 Phase へ戻り修正       |
| CRITICAL | 致命的な問題あり        | Phase 1 へ戻りユーザー確認  |

**期待される成果物**:

- レビュー結果判定書
