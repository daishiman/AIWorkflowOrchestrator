## Hook シグネチャ

```typescript
interface Hooks {
  permissionRequest?: (
    input: {
      toolName: string;
      args: Record<string, unknown>;
    },
    toolUseId: string,
    context: {
      signal: AbortSignal;
    },
  ) => Promise<{ behavior: "allow" } | { behavior: "deny"; message: string }>;
}
```

## エラーハンドリングフロー

### タイムアウト

```
waitForResponse() 開始
        │
        ▼
setTimeout(30000) 設定
        │
        ├─────────────────────────────────────┐
        │                                     │
        ▼                                     │
   [待機中...]                                │
        │                                     ▼
        │                           30秒経過 - timeout発火
        │                                     │
        │                                     ▼
        │                           pendingRequests.delete(requestId)
        │                                     │
        │                                     ▼
        │                           reject(new Error("タイムアウト"))
        │                                     │
        └─────────────────────────────────────┤
                                              │
                                              ▼
                                    catch (error) で捕捉
                                              │
                                              ▼
                                    return { behavior: "deny",
                                             message: "権限確認がタイムアウトしました（30秒）" }
```

### AbortSignal キャンセル

```
waitForResponse() 開始
        │
        ▼
signal.addEventListener("abort", ...) 設定
        │
        ├─────────────────────────────────────┐
        │                                     │
        ▼                                     │
   [待機中...]                                │
        │                                     ▼
        │                           signal.abort() 呼び出し
        │                                     │
        │                                     ▼
        │                           clearTimeout(timeoutId)
        │                                     │
        │                                     ▼
        │                           pendingRequests.delete(requestId)
        │                                     │
        │                                     ▼
        │                           reject(new Error("キャンセル"))
        │                                     │
        └─────────────────────────────────────┤
                                              │
                                              ▼
                                    catch (error) で捕捉
                                              │
                                              ▼
                                    return { behavior: "deny",
                                             message: "権限確認がキャンセルされました" }
```
