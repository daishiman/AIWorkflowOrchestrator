## 目的

テストカバレッジ目標の達成を確認し、統合テストの実行結果を検証する。

## 背景

Phase 6 でテストが拡充された。
本 Phase では、カバレッジ目標の達成を確認し、必要に応じて追加テストを行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジレポート生成

**目的**: 詳細なカバレッジレポートを生成する

**実行手順**:

1. カバレッジ測定付きでテストを実行する
2. HTML レポートを生成する
3. 結果を確認する

**実行コマンド**:

```bash
# カバレッジ測定付きテスト実行
pnpm --filter @repo/desktop test -- --coverage --run

# 対象ファイルのみ
pnpm --filter @repo/desktop test -- --coverage --run src/main/services/skill/
```

**期待される成果物**:

- カバレッジレポート（HTML/テキスト）

---

### タスク2: カバレッジ目標との比較

**目的**: カバレッジが目標に達しているか確認する

**実行手順**:

1. 各メトリクスを確認する
2. 目標との差異を計算する
3. 結果をドキュメント化する

**カバレッジ目標**:

| メトリクス        | 最低基準 | 推奨基準 | 現在値 | 判定 |
| ----------------- | -------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | 90%      | \_%    | [ ]  |
| Branch Coverage   | 60%      | 70%      | \_%    | [ ]  |
| Function Coverage | 80%      | 90%      | \_%    | [ ]  |

**期待される成果物**:

- カバレッジ比較表

---

### タスク3: 未カバー箇所の分析

**目的**: カバーされていない箇所を特定し、対策を検討する

**実行手順**:

1. 未カバー箇所を一覧化する
2. 各箇所の重要度を評価する
3. テスト追加の要否を判断する

**分析項目**:

| 未カバー箇所       | 重要度 | テスト追加 | 理由             |
| ------------------ | ------ | ---------- | ---------------- |
| （例）エラーパス   | 高     | 必要       | 本番で発生しうる |
| （例）デバッグログ | 低     | 不要       | 本番では無効     |

**期待される成果物**:

- 未カバー箇所分析表

---

### タスク4: 追加テスト実装（必要な場合）

**目的**: 未カバーで重要な箇所のテストを追加する

**実行手順**:

1. 重要度「高」の未カバー箇所を特定する
2. テストケースを作成する
3. カバレッジを再測定する

**期待される成果物**:

- 追加テストコード
- 更新されたカバレッジレポート

---

### タスク5: 全テスト実行と確認

**目的**: 全テストが通過することを確認する

**実行手順**:

1. 全テストを実行する
2. 失敗がないことを確認する
3. 結果をドキュメント化する

**実行コマンド**:

```bash
pnpm --filter @repo/desktop test -- --run
```

**期待される結果**:

- 全テスト PASS
- 最終カバレッジが目標を達成
