## 目的

Phase 5の実装に対してテストを拡充し、カバレッジ目標を達成する。

## 背景

実装完了後、カバレッジ基準（Line 80%+, Branch 60%+, Function 80%+）を達成するためにテストを追加する。特に統合テストを拡充し、フロントエンド・バックエンド接続の信頼性を確保する。

---

## 実行タスク

### タスク1: カバレッジ分析

**目的**: 現在のテストカバレッジを測定し、不足領域を特定する

**実行手順**:

1. カバレッジレポートを生成
2. 未カバーの行/分岐/関数を特定
3. 優先度の高い不足領域を特定
4. テスト追加計画を策定

**実行コマンド**:

\`\`\`bash

# カバレッジ測定

pnpm --filter @repo/shared test:coverage

# カバレッジレポート確認

open coverage/lcov-report/index.html
\`\`\`

---

### タスク2: ユニットテスト拡充

**目的**: ユニットテストカバレッジ基準を達成する

**実行手順**:

1. 未カバーのコードパスを特定
2. 追加テストケースを作成
3. エッジケースのテストを追加
4. カバレッジを再測定

**ユニットテストカバレッジ基準**:

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

**結合テストカバレッジ基準**:

| 指標                         | 目標 |
| ---------------------------- | ---- |
| APIエンドポイント            | 100% |
| モジュール間インターフェース | 100% |
| 正常系シナリオ               | 100% |
| 異常系シナリオ               | 80%+ |
| 外部連携ポイント             | 100% |

---

### タスク3: 統合テスト拡充

**目的**: 統合テストの全カテゴリでカバレッジを向上させる

**実行手順**:

1. API接続テストを拡充
2. データフローテストを拡充
3. エラーハンドリングテストを拡充
4. 認証連携テストを追加（該当する場合）
5. 状態同期テストを追加（該当する場合）
6. 統合テストを実行

**統合テストカテゴリ**:

| テストカテゴリ     | 検証項目                                   | 目標 |
| ------------------ | ------------------------------------------ | ---- |
| API接続テスト      | ISearchStrategy.search()の動作確認         | 100% |
| データフローテスト | SearchQuery→FTS5→SearchResultItem[]変換    | 100% |
| エラーハンドリング | DB接続エラー、タイムアウト、無効クエリ     | 80%+ |
| 認証連携テスト     | 認証トークン検証（該当する場合）           | 100% |
| 状態同期テスト     | 楽観的UI更新・ロールバック（該当する場合） | 100% |

---

### タスク4: 性能テスト追加

**目的**: 性能目標（<100ms）の達成を検証するテストを追加する

**実行手順**:

1. 性能テストケースを作成
2. 10,000チャンクでの検索速度テストを実装
3. 並行検索（10リクエスト）のテストを実装
4. 性能テストを実行

**性能テストケース**:

| テストケース       | 条件             | 目標値       |
| ------------------ | ---------------- | ------------ |
| キーワード検索速度 | 10,000チャンク   | < 100ms      |
| フレーズ検索速度   | 10,000チャンク   | < 100ms      |
| NEAR検索速度       | 10,000チャンク   | < 150ms      |
| 並行検索           | 10リクエスト同時 | 平均 < 100ms |
