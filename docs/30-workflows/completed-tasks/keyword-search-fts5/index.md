## 目的

HybridRAG検索エンジンのキーワード検索戦略として、SQLite FTS5（Full-Text Search 5）とBM25アルゴリズムを活用した高速・高精度な全文検索機能を実装する。

## 背景

HybridRAGパイプラインでは、Semantic検索（ベクトル検索）、Graph検索と並んでKeyword検索が重要な検索戦略の一つである。既にデータベース層（`chunks-search.ts`）にFTS5クエリ関数は実装済みだが、検索サービス層として統一されたインターフェースと検索戦略パターンの実装が必要。

### 現状の実装状況

| レイヤー       | 実装状況    | 備考                       |
| -------------- | ----------- | -------------------------- |
| データベース層 | ✅ 実装済み | `queries/chunks-search.ts` |
| サービス層     | ❌ 未実装   | ISearchStrategy実装が必要  |
| 検索統合       | ❌ 未実装   | HybridRAGサービスとの統合  |

## スコープ

### 含まれるもの

1. `ISearchStrategy` インターフェースに準拠したKeywordSearchStrategy実装
2. BM25スコアリングの正規化（0.0〜1.0）
3. キーワード検索（OR検索）、フレーズ検索、NEAR検索のサポート
4. ハイライト機能（マッチ箇所の強調表示）
5. ファイルIDによるフィルタリング
6. 検索結果のSearchResultItem形式への変換
7. 検索メトリクス（実行時間、ヒット数）の収集

### 含まれないもの

- Semantic検索（CONV-07-03で実装）
- Graph検索（CONV-07-04で実装）
- RRF統合（CONV-07-05で実装）
- CRAG評価（CONV-07-06で実装）
- クエリ分類器（CONV-07-01で実装済み）
