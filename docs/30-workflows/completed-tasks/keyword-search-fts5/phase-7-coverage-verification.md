## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。

## 背景

カバレッジ基準を満たすまでPhase 6へ戻りテスト拡充を繰り返すゲートとして機能する。すべての基準を満たした場合のみPhase 8へ進行する。

---

## 実行タスク

### タスク1: ユニットテストカバレッジ再測定

**目的**: ユニットテストカバレッジ基準の達成を確認する

**実行手順**:

1. カバレッジレポートを生成
2. Line/Branch/Function各カバレッジを確認
3. 基準達成の判定

**実行コマンド**:

```bash
pnpm --filter @repo/shared test:coverage
```

**判定基準**:

| 指標              | 最低基準 | 現在値 | 判定 |
| ----------------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | -      | -    |
| Branch Coverage   | 60%      | -      | -    |
| Function Coverage | 80%      | -      | -    |

---

### タスク2: 統合テスト実行

**目的**: 統合テストの成功を確認する

**実行手順**:

1. 統合テストを実行
2. 全テストケースの成功を確認
3. 失敗がある場合は原因を特定

**実行コマンド**:

```bash
pnpm --filter @repo/shared test:integration
```

---

### タスク3: 性能テスト実行

**目的**: 性能目標の達成を確認する

**実行手順**:

1. 性能テストを実行
2. 各検索モードの実行時間を確認
3. 目標値との比較

**性能目標**:

| テストケース      | 目標値  | 実測値 | 判定 |
| ----------------- | ------- | ------ | ---- |
| キーワード検索    | < 100ms | -      | -    |
| フレーズ検索      | < 100ms | -      | -    |
| NEAR検索          | < 150ms | -      | -    |
| 並行検索（10req） | < 100ms | -      | -    |

---

### タスク4: ゲート判定

**目的**: Phase 8へ進行可能か判定する

**判定基準**:

| 判定項目         | 基準     | 結果 | 判定 |
| ---------------- | -------- | ---- | ---- |
| ユニットLine     | 80%+     | -    | -    |
| ユニットBranch   | 60%+     | -    | -    |
| ユニットFunction | 80%+     | -    | -    |
| 統合テスト       | 全て成功 | -    | -    |
| 性能テスト       | 目標達成 | -    | -    |

**判定結果**:

- **PASS**: すべての基準を満たす → Phase 8へ進行
- **FAIL**: 基準未達 → Phase 6へ戻りテスト拡充
