## テストシナリオ

### シナリオ 1: SkillLifecyclePanel 一次導線アクセス (AC-1)

| ステップ | 操作                                       | 期待結果                         |
| -------- | ------------------------------------------ | -------------------------------- |
| 1        | アプリ起動                                 | ダッシュボード表示               |
| 2        | Cmd+5 または「スキルセンター」クリック     | SkillCenterView 表示             |
| 3        | 「作成を始める」CTA クリック               | SkillLifecyclePanel が表示される |
| 4        | ConversationalInterview が起動していること | 会話型インタビュー UI が見える   |

### シナリオ 2: SkillCreateWizard 後方互換 (AC-2)

| ステップ | 操作                                  | 期待結果                                                                |
| -------- | ------------------------------------- | ----------------------------------------------------------------------- |
| 1        | SkillCenterView を表示                | -                                                                       |
| 2        | ヘッダーの「+新規作成」ボタンクリック | SkillCreateWizard（4ステップフォーム）が表示される                      |
| 3        | SkillManagementPanel 経由のアクセス   | SkillManagementPanel から「新規作成（AI）」ボタン → SkillLifecyclePanel |

### シナリオ 3: ナビゲーション戻り動作 (AC-5)

| ステップ | 操作                                   | 期待結果                                         |
| -------- | -------------------------------------- | ------------------------------------------------ |
| 1        | SkillLifecyclePanel を開く             | -                                                |

| 3        | AppDock の「スキルセンター」ハイライト | skillLifecycle 表示中も skillCenter がアクティブ |
