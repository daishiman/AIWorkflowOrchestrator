## 目的

## 実行タスク

### Task 1: 不要ルート定義の整理

- ルート定義の重複がないことを確認
- 不要になった中間ルート（SkillManagementPanel 経由の迂回ルート等）を整理
- ただし後方互換性のために必要なルートは維持する

### Task 2: normalizeSkillLifecycleView() の簡素化

- 条件分岐の最適化
- デッドコードの除去
- ロジックの見通しの改善

### Task 3: ナビゲーション定義の整理

- `skillLifecycleJourney.ts` の定義の重複排除
- 命名規則の統一
- コメントの追加（一次導線/二次導線の区別を明確に）

### Task 4: 型定義の整理

- ViewType 定義に不要な値が追加されていないことを確認
- 型の一貫性確認

### Task 5: リファクタリング後のテスト実行

- 全テストが pass することを確認
- リファクタリングによるリグレッションがないことを確認
