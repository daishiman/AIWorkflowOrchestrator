# Discovered Issues - Session Dock Artifact Bridge

## 概要

本タスクは設計タスク（type: design）であるため、実画面での手動テストは未実施。以下は設計レビュー過程で発見された潜在的な issue を記録する。

## 発見事項

### DI-01: Share Rail と Transcript Detail の操作競合

| 項目     | 内容                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------- |
| 重要度   | 低                                                                                              |
| カテゴリ | UI/UX                                                                                           |
| 詳細     | transcript を展開した状態で Share Rail のドロップダウンを開くと、表示領域が競合する可能性がある |
| 対策案   | Share Rail を sticky footer にするか、transcript 展開時は Share Rail を上部に移動する           |
| 対応方針 | 実装タスクで UI レイアウトを調整時に検証                                                        |

### DI-02: 長いファイルパスの Artifact Summary 内表示

| 項目     | 内容                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 重要度   | 低                                                                                                                                     |
| カテゴリ | UI/UX                                                                                                                                  |
| 詳細     | ArtifactItem.path が長い場合（例: `apps/desktop/src/renderer/components/execution/ArtifactSummary.tsx`）にテキスト溢れが発生する可能性 |
| 対策案   | `text-overflow: ellipsis` + tooltip でフルパス表示                                                                                     |
| 対応方針 | 実装タスクで CSS 対応                                                                                                                  |

### DI-03: handoff → ready への戻り遷移（T10）の UI フィードバック

| 項目     | 内容                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------- |
| 重要度   | 低                                                                                                    |
| カテゴリ | UI/UX                                                                                                 |
| 詳細     | T10（USER_CANCEL_HANDOFF）で handoff → ready に戻る際、ユーザーに遷移が起きたことが伝わりにくい可能性 |
| 対策案   | 遷移時にトースト通知「実行をキャンセルしました」を表示する                                            |
| 対応方針 | 実装タスクで検討                                                                                      |

## Phase 12 引き継ぎ

DI-01〜DI-03 は全て低重要度であり、実装タスクで対応可能。Phase 12 の未タスク検出に含めるかは Phase 12 で判断する。
