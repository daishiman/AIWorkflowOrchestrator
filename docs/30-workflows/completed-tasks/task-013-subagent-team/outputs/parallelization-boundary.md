## 4. 並列化判定フローチャート

タスク間の並列可否を判定する基準:

1. **IPCチャネル名前空間が分離しているか？** — 同一名前空間を使用する場合は直列必須
2. **型定義ファイルが独立しているか？** — 同一型定義ファイルを変更する場合は直列必須
3. **UI画面遷移の前提関係があるか？** — 遷移先を定義する側が先行必須
4. **共有リソースへの書き込みがあるか？** — 読み取りのみの共有は並列可能、書き込み共有は直列必須
