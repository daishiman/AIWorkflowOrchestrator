## ガード処理の採用方針

**採用**: `weekdays.length === 0` のとき空文字 `""` を返す early return

**理由**:

- UI 側の既存バリデーションと整合する
- 意図しない曜日への自動補完（例: 日曜0を補完）を避けられる
- 呼び出し元に追加の例外処理を強制しない
- 型シグネチャ `string` を維持できる

**不採用案**:

- 例外スロー: 呼び出し元にtry-catchが必要になりスコープ超過
- 日曜(0)フォールバック: 意図しないスケジュールを生成する
