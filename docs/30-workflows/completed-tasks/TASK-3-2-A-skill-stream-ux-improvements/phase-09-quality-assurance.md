## 1. 目的

## 2. タスク

### Task 9-1: 静的解析

**実行コマンド**:

```bash
# TypeScript型チェック
pnpm --filter @repo/desktop typecheck

# ESLint
pnpm --filter @repo/desktop lint

# Prettier
pnpm --filter @repo/desktop format:check
```

**確認項目**:

| ID  | チェック項目             | 判定      |
| --- | ------------------------ | --------- |
| 1   | TypeScriptエラーなし     | PASS/FAIL |
| 2   | ESLintエラーなし         | PASS/FAIL |
| 3   | Prettierフォーマット済み | PASS/FAIL |
