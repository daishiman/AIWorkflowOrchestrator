## 1. 概要

SkillStreamDisplayコンポーネントのユーザー体験を改善するため、以下の3つの機能を追加する。

| 改善ID | 機能名                     | 目的                             |
| ------ | -------------------------- | -------------------------------- |
| R1     | ローディングアニメーション | 実行中の視覚的フィードバック向上 |
| R2     | タイムスタンプ表示         | メッセージの時系列追跡           |
| R3     | クリップボードコピー       | デバッグ情報の共有効率化         |

| 要件ID | 要件                                          | 実装場所                    |

### 3.3 formatRelativeTime仕様

```typescript
/**
 * タイムスタンプを相対時刻文字列に変換
 * @param timestamp - Unixタイムスタンプ (ミリ秒)
 * @returns 「X秒前」「X分前」「X時間前」「X日前」
 */
function formatRelativeTime(timestamp: number): string {
  const now = Date.now();
  const diff = now - timestamp;
  const seconds = Math.floor(diff / 1000);
  const minutes = Math.floor(seconds / 60);
  const hours = Math.floor(minutes / 60);
  const days = Math.floor(hours / 24);

  if (days > 0) return `${days}日前`;
  if (hours > 0) return `${hours}時間前`;
  if (minutes > 0) return `${minutes}分前`;
  return `${seconds}秒前`;
}
```

## 4. R3: クリップボードコピー

### 4.1 機能要件

| 要件ID | 要件                                         | 優先度 | 確認方法       |
| ------ | -------------------------------------------- | ------ | -------------- |
| R3-1   | 各メッセージにコピーボタンを表示             | 必須   | UI確認         |
| R3-2   | ボタンアイコン: クリップボードアイコン       | 必須   | UI確認         |
| R3-3   | ホバー時にボタンを表示（通常時は非表示）     | 推奨   | UI確認         |
| R3-4   | クリック時にメッセージ内容をコピー           | 必須   | ユニットテスト |
| R3-5   | コピー成功時に「コピーしました」トースト表示 | 必須   | UI確認         |
| R3-6   | トースト表示時間: 2000ms                     | 推奨   | ユニットテスト |
| R3-7   | navigator.clipboard.writeText APIを使用      | 必須   | 実装確認       |

### 4.2 アクセシビリティ要件

| 要件ID | 要件                                          | WCAG基準 |
| ------ | --------------------------------------------- | -------- |
| A3-1   | ボタンにaria-label="メッセージをコピー"を設定 | 1.1.1    |
| A3-2   | コピー成功時にaria-live="polite"で通知        | 4.1.3    |
| A3-3   | キーボードでフォーカス可能                    | 2.1.1    |
| A3-4   | Enterキーでコピー実行                         | 2.1.1    |

### 4.3 フォールバック要件

| 要件ID | 要件                                 | 理由                         |
| ------ | ------------------------------------ | ---------------------------- |
| F3-1   | Clipboard API非対応時はボタン非表示  | グレースフルデグラデーション |
| F3-2   | コピー失敗時はコンソールにエラー出力 | デバッグ支援                 |

### 4.4 実装仕様

```tsx
// コピーボタンコンポーネント例
function CopyButton({ content }: { content: string }) {
  const [copied, setCopied] = useState(false);

  const handleCopy = async () => {
    try {
      await navigator.clipboard.writeText(content);
      setCopied(true);
      setTimeout(() => setCopied(false), 2000);
    } catch (err) {
      console.error("Failed to copy:", err);
    }
  };

  // Clipboard API非対応時は非表示
  if (!navigator.clipboard) return null;

  return (
    <button
      onClick={handleCopy}
      aria-label="メッセージをコピー"
      className="copy-button opacity-0 group-hover:opacity-100"
    >
      {copied ? "コピーしました" : <ClipboardIcon />}
    </button>
  );
}
```

## 5. 非機能要件

### 5.1 パフォーマンス

| 要件                               | 指標               |
| ---------------------------------- | ------------------ |
| スピナーアニメーションは軽量に保つ | CSS animationのみ  |
| コピー操作は非同期で即時応答       | 100ms以下          |
| メモ化を維持                       | React.memo継続使用 |

| 要件                      | 対応範囲             |

| Clipboard API             | モダンブラウザ全対応 |
