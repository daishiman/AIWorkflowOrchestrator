## 1. 既存実装の概要

### 1.1 コンポーネント構成

```
SkillStreamDisplay
├── ヘッダー部（stream-header）
│   ├── ステータスバッジ
│   ├── 中断ボタン（running時のみ）
│   └── リセットボタン（completed/error/aborted時のみ）
├── コンテンツ部（stream-content）
│   ├── 空状態メッセージ（idle時）
│   ├── ローディングテキスト（running/メッセージなし時）
│   └── メッセージリスト（MessageItem）
└── 権限確認ダイアログ（PermissionDialog）
```

### 1.2 現在のステータス管理

| ステータス | 表示テキスト | UIアクション                          |
| ---------- | ------------ | ------------------------------------- |

| running    | 実行中       | 中断ボタン表示、「実行中...」テキスト |
| completed  | 完了         | リセットボタン表示                    |
| error      | エラー       | リセットボタン表示                    |
| aborted    | 中断         | リセットボタン表示                    |

| タイプ   | 表示内容                | スタイリング               |

## 2. 改善が必要な箇所

### 2.1 R1: ローディングアニメーション

**現状**: `status="running"` 時に「実行中...」テキストのみ表示

**問題点**:

- 視覚的フィードバックが弱い
- 動的な処理進行を示すアニメーションがない
- ユーザーがシステムが応答しているか判断しにくい

**改善案**: スピナーアニメーションの追加

### 2.2 R2: タイムスタンプ表示

**現状**: `SkillStreamMessage.timestamp` は存在するが、UI上で表示していない

**問題点**:

- メッセージの時系列が把握しにくい
- デバッグ時に時間経過を確認できない
- 長時間実行時の進捗把握が困難

**改善案**: 各メッセージに相対時刻を表示

### 2.3 R3: クリップボードコピー機能

**現状**: メッセージのコピー機能が存在しない

**問題点**:

- デバッグ情報の共有が手間
- エラーメッセージのコピーに手動選択が必要
- ツール名やログの転記が煩雑

**改善案**: 各メッセージにコピーボタンを追加
