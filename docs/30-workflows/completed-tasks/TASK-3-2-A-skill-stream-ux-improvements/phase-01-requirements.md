### Task 1-2: R1 ローディングアニメーション要件定義

**目的**: 実行中の視覚的フィードバックを改善

**要件詳細**:

| 要件ID | 要件                                             | 優先度 |
| ------ | ------------------------------------------------ | ------ |
| R1-1   | status="running"時にスピナーアニメーションを表示 | 必須   |
| R1-2   | スピナーはTailwind CSS animate-spinを使用        | 必須   |
| R1-3   | スピナーサイズは16x16px (h-4 w-4)                | 必須   |
| R1-4   | スピナー色はblue-500を使用                       | 推奨   |
| R1-5   | aria-label="実行中"を設定                        | 必須   |
| R1-6   | スピナーとテキスト間にgap-2を設定                | 推奨   |

**アクセシビリティ要件**:

| 要件ID | 要件                                           |
| ------ | ---------------------------------------------- |
| A1-1   | スピナーに適切なaria-label属性を設定           |
| A1-2   | role="status"をスピナーコンテナに設定          |
| A1-3   | スクリーンリーダーで「実行中」と読み上げられる |

---

### Task 1-3: R2 タイムスタンプ表示要件定義

**目的**: メッセージの時系列追跡を可能にする

**要件詳細**:

| 要件ID | 要件                                    | 優先度 |
| ------ | --------------------------------------- | ------ |
| R2-1   | 各メッセージに相対時刻を表示            | 必須   |
| R2-2   | 表示形式: 「X秒前」「X分前」「X時間前」 | 必須   |
| R2-3   | 60秒未満: 「X秒前」                     | 必須   |
| R2-4   | 60分未満: 「X分前」                     | 必須   |
| R2-5   | 24時間未満: 「X時間前」                 | 必須   |
| R2-6   | 24時間以上: 「X日前」                   | 必須   |
| R2-7   | タイムスタンプはメッセージ右端に表示    | 推奨   |
| R2-8   | 文字色はtext-gray-400でコンテンツと区別 | 推奨   |
| R2-9   | 文字サイズはtext-xsで控えめに           | 推奨   |

**技術要件**:

| 要件ID | 要件                                          |
| ------ | --------------------------------------------- |
| T2-1   | formatRelativeTime関数をutilsに作成           |
| T2-2   | SkillStreamMessage.timestampを使用            |
| T2-3   | 1秒ごとの自動更新は不要（パフォーマンス考慮） |

---

### Task 1-4: R3 クリップボードコピー要件定義

**目的**: デバッグ情報の共有効率を向上

**要件詳細**:

| 要件ID | 要件                                         | 優先度 |
| ------ | -------------------------------------------- | ------ |
| R3-1   | 各メッセージにコピーボタンを表示             | 必須   |
| R3-2   | ボタンアイコン: クリップボードアイコン       | 必須   |
| R3-3   | ホバー時にボタンを表示（通常時は非表示）     | 推奨   |
| R3-4   | クリック時にメッセージ内容をコピー           | 必須   |
| R3-5   | コピー成功時に「コピーしました」トースト表示 | 必須   |
| R3-6   | トースト表示時間: 2000ms                     | 推奨   |
| R3-7   | navigator.clipboard.writeText APIを使用      | 必須   |

**アクセシビリティ要件**:

| 要件ID | 要件                                          |
| ------ | --------------------------------------------- |
| A3-1   | ボタンにaria-label="メッセージをコピー"を設定 |
| A3-2   | コピー成功時にaria-live="polite"で通知        |
| A3-3   | キーボードでフォーカス可能                    |
| A3-4   | Enterキーでコピー実行                         |

**フォールバック要件**:

| 要件ID | 要件                                 |
| ------ | ------------------------------------ |
| F3-1   | Clipboard API非対応時はボタン非表示  |
| F3-2   | コピー失敗時はコンソールにエラー出力 |
