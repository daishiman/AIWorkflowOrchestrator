## 目的

自動テストでは検証できないユーザー体験・UI/UX・実環境動作を手動で確認する。SkillEditorView のファイルツリー + コードエディター型体験が設計どおりに機能し、全マイクロインタラクション・保存/バックアップ操作・レスポンシブ対応が視覚的かつ機能的に正しく動作することを検証する。

> **注記（2026-03-02）**: `spec_created` 状態を維持しつつ再監査を実施。`views/SkillEditorView` 実装ファイルの実在と現行UI証跡を確認し、未完了項目は未タスクとして分離した。

## 実行タスク

- 手動テストシナリオの実行: 全8カテゴリのテストケースを順次実行
- アクセシビリティ検証: WCAG 2.1 AA 基準に基づくキーボード・スクリーンリーダー確認
- レスポンシブデザイン検証: 3段階ブレークポイントでのレイアウト確認
- DevTools 確認: コンソールエラーなし・パフォーマンスの検証
- スクリーンショット撮影: 各テストシナリオの証跡
