## 目的

スキル生成フロー実行時に `spawn node ENOENT` / `Claude Code executable not found` が出ないことを手動で確認する。

## 事前条件

- アプリケーションが起動している
- スキル生成機能へ到達できる
- `ANTHROPIC_API_KEY` が設定されている

## テスト手順

### シナリオ 1: スキル生成時に ENOENT が出ない

1. スキル生成ボタンを押す
2. DevTools またはログに `spawn node ENOENT` が出ないことを確認する
3. `Claude Code executable not found` が出ないことを確認する

| 確認項目          | 期待結果                     | 実際の結果 |
| ----------------- | ---------------------------- | ---------- |
| ENOENT エラーなし | `spawn node ENOENT` が出ない | PASS       |
| 実行継続          | スキル生成処理が中断しない   | PASS       |

### シナリオ 2: 生成フローが完了する

1. シナリオ 1 のまま生成フローを最後まで進める
2. エラーなく完了することを確認する

| 確認項目       | 期待結果               | 実際の結果 |
| -------------- | ---------------------- | ---------- |
| スキル生成完了 | 正常に生成・保存される | PASS       |

## 確認不要な項目

- 画面レイアウト
- 色 / アニメーション
- スクリーンショット証跡
