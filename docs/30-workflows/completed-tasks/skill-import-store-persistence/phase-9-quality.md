---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析の総合実行

**目的**: プロジェクト全体の静的解析を実行する

**実行手順**:

1. ESLintを実行する
   ```bash
   pnpm lint
   ```
2. TypeScript型チェックを実行する
   ```bash
   pnpm typecheck
   ```
3. Prettierでフォーマットを確認する
   ```bash
   pnpm format:check
   ```
4. エラーがあれば修正する
5. 結果を記録する

**期待される成果物**:

- 静的解析結果

---

### タスク2: セキュリティ確認

**目的**: セキュリティ上の問題がないことを確認する

**実行手順**:

1. 以下の観点でコードをレビューする
   - 機密情報（APIキー等）がハードコードされていないか
   - ファイルパスの入力検証が適切か
   - エラーメッセージに機密情報が含まれていないか
2. electron-storeのファイルパーミッションが適切か確認する
3. セキュリティ確認結果を記録する

**期待される成果物**:

- セキュリティ確認結果

---

### タスク3: 品質ゲート判定

**目的**: 品質基準を満たしているか判定する

**実行手順**:

1. 以下の品質ゲート項目を確認する
   - [ ] 全ユニットテスト成功
   - [ ] 全統合テスト成功
   - [ ] Lintエラーなし
   - [ ] 型エラーなし
   - [ ] コードフォーマット適用済み
   - [ ] セキュリティ問題なし
2. 判定結果を記録する

**期待される成果物**:

- `outputs/phase-09/quality-assurance-result.md`
