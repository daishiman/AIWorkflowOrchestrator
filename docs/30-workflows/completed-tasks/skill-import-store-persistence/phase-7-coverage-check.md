## 目的

テストカバレッジ目標を検証し、統合テストを再実行してゲート判定を行う。

## 背景

Phase 5-6で実装とテスト拡充が完了した。本Phaseでは、カバレッジ目標が達成されているか検証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ計測

**目的**: 現在のテストカバレッジを計測する

**実行手順**:

1. カバレッジ付きでテストを実行する
   ```bash
   pnpm --filter @repo/desktop test -- --coverage SkillImportManager
   ```
2. 以下のカバレッジ指標を確認する
   - Line Coverage
   - Branch Coverage
   - Function Coverage
3. カバレッジレポートを保存する

**期待される成果物**:

- `outputs/phase-07/coverage-report.md`

---

### タスク2: カバレッジ目標判定

**目的**: カバレッジ目標が達成されているか判定する

**実行手順**:

1. 以下の目標と比較する
   | 指標 | 最低基準 | 現在値 | 判定 |
   | ----------------- | -------- | ------ | ---- |
   | Line Coverage | 80% | | |
   | Branch Coverage | 60% | | |
   | Function Coverage | 80% | | |
2. 未達の場合はPhase 6に戻り、追加テストを作成する
3. 判定結果を記録する

**期待される成果物**:

- カバレッジ判定結果

---

### タスク3: 統合テストの再実行

**目的**: 全統合テストを再実行し、回帰がないことを確認する

**実行手順**:

1. 関連する全テストを実行する
   ```bash
   pnpm --filter @repo/desktop test
   ```
2. 全テストが成功することを確認する
3. 失敗するテストがある場合は原因を調査する
4. テスト結果を記録する

**期待される成果物**:

- `outputs/phase-07/test-results.md`
