## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コード品質の確認

**目的**: 修正コードの品質を確認し、改善点を特定する

**実行手順**:

1. SkillImportManager.tsのコードをレビューする
2. 以下の観点で改善点を特定する
   - コードの重複がないか
   - 命名が適切か
   - コメントが必要な箇所があるか
   - 不要なデバッグログがないか
3. 改善点リストを作成する

**期待される成果物**:

- 改善点リスト

---

### タスク2: リファクタリング実施

**目的**: 特定した改善点を修正する

**実行手順**:

1. タスク1で特定した改善点を修正する
2. 修正内容の例：
   - 不要なデバッグログの削除または整理
   - 定数の抽出
   - メソッド名の改善
   - コード構造の整理
3. テストが引き続き成功することを確認する
   ```bash
   pnpm --filter @repo/desktop test -- SkillImportManager
   ```

**期待される成果物**:

- リファクタリングされたコード

---

### タスク3: 静的解析の実行

**目的**: 静的解析でコード品質を検証する

**実行手順**:

1. ESLintを実行する
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. TypeScript型チェックを実行する
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
3. エラーがあれば修正する
4. 実行結果を記録する

**期待される成果物**:

- `outputs/phase-08/refactoring-result.md`
