## 目的

実環境でのUX・動作確認を行い、修正が正しく機能することを検証する。

## 背景

本タスクの発端は実環境での動作不具合であった。自動テストだけでなく、実環境での手動テストで修正を検証することが重要。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連テストの実行

**目的**: 手動テスト前に自動テストを全て実行する

**実行手順**:

1. 関連するテストを全て実行する
   ```bash
   pnpm --filter @repo/desktop test
   ```
2. 全テストがPASSすることを確認する
3. 結果を記録する

**期待される成果物**:

- テスト実行結果

---

### タスク2: 実環境での動作確認

**目的**: Electronアプリを起動して実際の動作を確認する

**実行手順**:

1. アプリを起動する
   ```bash
   pnpm --filter @repo/desktop dev
   ```
2. 以下のテストケースを実行する

**テストケース一覧**:

| TC-ID        | テスト内容                     | 期待結果                                       | 結果 |
| ------------ | ------------------------------ | ---------------------------------------------- | ---- |
| TC-STORE-001 | スキルインポート後のリスト取得 | インポートしたスキルが一覧に含まれる           |      |
| TC-STORE-002 | ストアファイルの存在確認       | `skills.json`が正しい場所に作成される          |      |
| TC-STORE-003 | アプリ再起動後のリスト取得     | 再起動前にインポートしたスキルが保持されている |      |

**期待される成果物**:

- `outputs/phase-11/manual-test-result.md`

---

### タスク3: ストアファイルの確認

**目的**: 実際のストアファイルの内容を確認する

**実行手順**:

1. ストアファイルの場所を確認する
   ```bash
   ls -la ~/Library/Application\ Support/aiworkflow-orchestrator/
   # または
   ls -la ~/Library/Application\ Support/Electron/
   ```
2. `skills.json`の内容を確認する
   ```bash
   cat ~/Library/Application\ Support/<app-name>/skills.json
   ```
3. インポートしたスキルIDが正しく保存されているか確認する
4. 結果を記録する

**期待される成果物**:

- ストアファイル確認結果

---

### タスク4: 発見課題の記録

**目的**: 手動テストで発見した課題を記録する

**実行手順**:

1. テストで発見した課題があれば記録する
2. 課題がない場合も「発見課題なし」と明記する
3. 課題がある場合は重要度を判定する

**期待される成果物**:

- `outputs/phase-11/discovered-issues.md`
