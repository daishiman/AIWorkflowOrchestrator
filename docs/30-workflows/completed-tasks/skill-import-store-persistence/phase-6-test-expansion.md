## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: エッジケーステストの追加

**目的**: 境界条件やエッジケースをカバーするテストを追加する

**実行手順**:

1. 以下のエッジケースに対するテストを作成する
   - 空のskillIdでインポート
   - 重複するskillIdでインポート
   - 大量のスキル（100件以上）をインポート
   - 不正な文字を含むskillId
2. テストファイルに追加する
3. テストが成功することを確認する

**テストケース例**:

```typescript
describe("エッジケーステスト", () => {
  it("空のskillIdでインポートした場合はエラーになる", () => {
    expect(() => manager.importSkill("")).toThrow();
  });

  it("重複するskillIdは一度のみ保存される", () => {
    manager.importSkill("skill-001");
    manager.importSkill("skill-001");
    const ids = manager.getImportedSkillIds();
    expect(ids.filter((id) => id === "skill-001")).toHaveLength(1);
  });

  it("100件のスキルをインポートできる", () => {
    for (let i = 0; i < 100; i++) {
      manager.importSkill(`skill-${i}`);
    }
    expect(manager.getImportedSkillIds()).toHaveLength(100);
  });
});
```

**期待される成果物**:

- 追加されたエッジケーステスト

### タスク2: 異常系テストの追加

**目的**: エラーハンドリングをカバーするテストを追加する

**実行手順**:

1. 以下の異常系に対するテストを作成する
   - ストアファイルが書き込み不可の場合
   - ストアファイルが破損している場合
   - ディスク容量不足の場合（可能であれば）
2. エラーメッセージが適切かを検証する
3. テストが成功することを確認する

**期待される成果物**:

- 追加された異常系テスト

---

### タスク3: 統合テストの拡充

**目的**: 統合テストのカバレッジを向上させる

**実行手順**:

1. 以下の統合テストシナリオを追加する
   - インポート→削除→再インポートのフロー
   - 複数スキルの同時インポート
   - アプリ再起動後のデータ保持
2. IPC経由のテストを拡充する
3. テストが成功することを確認する

**期待される成果物**:

- 拡充された統合テスト
