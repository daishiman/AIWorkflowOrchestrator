## 目的

自動テストでは検証できないユーザー体験・UI/UX・実環境動作を手動で確認する。特に、設定画面やLLM選択、スキル選択において無限ループが発生しないことを実環境で検証する。

## 背景

本タスクは `useAuthModeStore()` 等の合成Store Hookが毎回新しいオブジェクトを返すため、その中の関数を `useEffect` の依存配列に含めると無限ループが発生する問題（P31）を修正するリファクタリングである。無限ループはUIの挙動に直接影響するため、手動での検証が必須。

## 手動統合テスト（詳細）

### 無限ループ検証手順

**確認手順**:

1. Electron DevTools を開く（`Cmd+Option+I`）
2. Console タブを開く
3. 以下のコードを実行してuseEffect実行回数を確認:

```javascript
// ConsoleでuseEffect実行回数を確認するためのログ
// 修正後のコードでは、useEffectは1-2回のみ実行されるはず
console.log("Checking for infinite loop...");

// 5秒後にログ出力が止まっていれば無限ループなし
setTimeout(() => {
  console.log("If no repeated logs above, infinite loop is fixed!");
}, 5000);
```

**期待結果**: useEffectの実行ログが1-2回で止まり、5秒後も新たなログが出力されない

### Zustand Devtools での状態確認

```javascript
// DevTools Console で Zustand state を確認
// 状態が安定していることを確認

// 現在の認証モード状態を確認
console.log(
  "Auth mode state:",
  window.__ZUSTAND_STORE__?.getState?.()?.authMode,
);

// 状態変化のリスナーを設定（5秒間監視）
let changeCount = 0;
const unsubscribe = window.__ZUSTAND_STORE__?.subscribe?.(
  (state, prevState) => {
    changeCount++;
    console.log(`State change #${changeCount}:`, state);
  },
);

setTimeout(() => {
  unsubscribe?.();
  console.log(`Total state changes in 5 seconds: ${changeCount}`);
  // 正常な場合、変更回数は0-3回程度のはず
}, 5000);
```

## 注意事項

### 無限ループ検証に関する特記事項

> **重要**: 本タスクは無限ループの修正であり、新機能の追加は含まない。
>
> テスト時に以下の症状が発生した場合は、バグが修正されていない可能性がある:
>
> - 設定画面を開くと画面がぐるぐる回り続ける
> - DevToolsのConsoleにログが止まらずに出力され続ける
> - CPUファンが回り出す、またはアプリが重くなる
> - UIの反応が極端に遅くなる

### P31対策の確認ポイント

| 確認項目                   | 確認方法                                                    |
| -------------------------- | ----------------------------------------------------------- |
| useRefによるガード         | 初期化関数が1回のみ実行されることを確認                     |
| 依存配列の空配列化         | useEffectの依存配列が空（[]）になっていることをコードで確認 |
| 個別セレクタの使用（長期） | 合成Hookではなく個別セレクタを使用していることを確認        |
