## 8. P31対策の確認ポイント

### 8.1 useRefによるガード確認

個別セレクタはZustandの `useStore((state) => state.xxx)` パターンを使用しており、関数参照が安定しているため、useRefによるガードは不要です。

**確認結果**: PASS（ガード不要な設計で実装済み）

### 8.2 依存配列の空配列化確認

個別アクションセレクタは安定した関数参照を返すため、依存配列に含めても無限ループは発生しません。

```typescript
// 修正後のパターン（推奨）
const setMode = useSetAuthMode(); // 安定した関数参照
useEffect(() => {
  setMode("api-key");
}, [setMode]); // 依存配列に含めても無限ループしない
```

**確認結果**: PASS（個別セレクタにより解決）
