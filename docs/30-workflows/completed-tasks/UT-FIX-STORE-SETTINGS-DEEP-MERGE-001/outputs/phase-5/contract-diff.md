# 契約差分

## IPC 契約の変更

なし（チャネル名・入出力型は変更なし）

## 内部実装の変更

| 項目           | 変更前                       | 変更後                        |
| -------------- | ---------------------------- | ----------------------------- |
| マージ方式     | `{ ...current, ...updates }` | `deepMerge(current, updates)` |
| ネスト保持     | なし                         | あり                          |
| 配列扱い       | 上書き（shallow と同じ）     | 上書き（明示）                |
| null 扱い      | 上書き（shallow と同じ）     | 上書き（明示）                |
| undefined 扱い | 省略（keyがない場合）        | 省略（明示）                  |

## 後方互換性

- トップレベルキーのみ更新するユースケース: 動作変化なし
- ネストオブジェクトの部分更新: 改善（フィールド消失がなくなる）
