## 目的

実際の Electron アプリで `settings:update` ハンドラの動作確認を行い、証跡を記録する。
このタスクは IPC ハンドラの修正であり UI への直接影響はないため、
手動テストは「設定が保存・ロードされる動作確認」に限定する。

## 背景

Phase 10 のゲートを通過した実装が、実際の Electron アプリ環境でも
正しく動作することを確認する。開発者コンソール（DevTools）または
設定関連の呼び出し経路を通じて `settings:update` IPC を呼び出し、
ネストした設定変更の保持とアプリ再起動後のロードを確認する。

UI コンポーネントの変更は伴わないため、スクリーンショットによる
視覚的 UI 証跡は N/A とし、コンソールログ・IPC 通信ログを主な証跡とする。

## 手動テストシナリオ

### シナリオ 1: ネストした設定変更の保持確認

| 項目     | 内容                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 目的     | `settings:update` でネストした設定を部分更新した際に、同一親キー配下の他フィールドが保持されることを確認する |
| 前提     | Electron アプリが開発モードで起動済みであること                                                              |
| 手順     | 1. DevTools コンソールを開く                                                                                 |
|          | 2. `window.api.settings.update({ theme: { mode: 'dark' } })` を実行する                                      |
|          | 3. `window.api.settings.get()` を実行し、`theme` 配下の他フィールドが保持されているか確認する                |
| 期待結果 | `theme.mode` が `'dark'` に更新され、`theme` 配下の他フィールドが消失しないこと                              |
| 証跡     | DevTools コンソールの出力ログ                                                                                |
| 判定基準 | 期待結果と一致すれば PASS、一致しなければ FAIL（原因を記録する）                                             |

### シナリオ 2: アプリ再起動後の設定ロード確認

| 項目     | 内容                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 目的     | アプリ再起動後に、シナリオ 1 で更新した設定が正しくロードされることを確認する |
| 前提     | シナリオ 1 が PASS であること                                                 |
| 手順     | 1. Electron アプリを終了する                                                  |
|          | 2. `pnpm --filter @repo/desktop dev` で再起動する                             |
|          | 3. DevTools コンソールで `window.api.settings.get()` を実行し、設定を確認する |
| 期待結果 | シナリオ 1 で更新した `theme.mode: 'dark'` が再起動後も保持されていること     |
| 証跡     | DevTools コンソールの出力ログ・アプリ起動ログ                                 |
| 判定基準 | 期待結果と一致すれば PASS、一致しなければ FAIL（原因を記録する）              |
