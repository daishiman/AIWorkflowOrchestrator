## 受け入れ基準一覧

### AC-001: 履歴一覧取得

| ID        | 基準                                                        | 検証方法           |
| --------- | ----------------------------------------------------------- | ------------------ |
| AC-001-01 | `getFileHistory`が実際のDBからデータを取得する              | 統合テスト         |
| AC-001-02 | 戻り値の`items`が`VersionHistoryItem[]`型である             | 型テスト           |
| AC-001-03 | `total`がDB内の該当ファイルの総バージョン数と一致する       | テストアサーション |
| AC-001-04 | `hasMore`がページネーション状態を正しく反映する             | テストアサーション |
| AC-001-05 | `limit=20`（デフォルト）、`offset=0`で正しく動作する        | テストアサーション |
| AC-001-06 | 履歴が新しい順（降順）でソートされている                    | テストアサーション |
| AC-001-07 | 空の履歴の場合、`items: [], total: 0, hasMore: false`を返す | テストアサーション |
