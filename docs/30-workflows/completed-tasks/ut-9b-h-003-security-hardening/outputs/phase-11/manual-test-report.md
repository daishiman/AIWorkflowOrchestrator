## DevTools手動テスト手順（開発者向けリファレンス）

アプリ起動後のDevToolsコンソールで以下を実行して検証可能:

```javascript
// パストラバーサル拒否確認
await window.electronAPI.skillCreator.executeTasks({
  tasksDir: "../../etc/passwd",
  outputDir: "./output",
  schemaName: "skill-spec",
});
// → { success: false, error: "無効なパスが指定されました: tasksDir" }

// エラーサニタイズ確認
await window.electronAPI.skillCreator.executeTasks({
  tasksDir: "./nonexistent-dir-12345",
  outputDir: "./output",
  schemaName: "skill-spec",
});
// → success: false のエラーメッセージにファイルパスが含まれないこと

// schemaName拒否確認
await window.electronAPI.skillCreator.validateSchema("evil-schema", {});
// → { success: false, error: "無効なスキーマ名が指定されました: evil-schema" }

// schemaName許可確認
await window.electronAPI.skillCreator.validateSchema("skill-spec", {});
// → スキーマ名バリデーション通過（後続処理で別エラーの可能性あり）
```
