## 受入基準充足状況

### AC-1: 未完了セッション検出時に復元プロンプト表示

| 項目   | 内容                                                                                                                                |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 実装   | SkillLifecyclePanel マウント時に `listSessions()` を呼び出し、1件以上存在する場合に SessionResumePrompt を表示。0件の場合は非表示。 |
| テスト | TC-1-1, TC-1-2, TC-1-3 + SessionResumePrompt UI テスト                                                                              |
| 判定   | **PASS**                                                                                                                            |

### AC-2: セッション復元で前回の会話状態から継続

| 項目   | 内容                                                                                                                                      |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 実装   | `handleResumeSession` が `resumeSession(checkpointId)` API を呼び出し、成功時にワークフロー状態（planId, currentPhase, snapshot）を復元。 |
| テスト | TC-2-1, TC-2-2, TC-2-3 + WorkflowEngine resumeFromCheckpoint テスト                                                                       |
| 判定   | **PASS**                                                                                                                                  |

### AC-3: スキップ選択で新規セッション開始

| 項目   | 内容                                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 実装   | `handleSkipSessions` が `availableSessions` を `null` にセットし、SessionResumePrompt を非表示にして通常の新規セッションフローへ遷移。 |
| テスト | TC-3-1, TC-3-2 + SessionResumePrompt UI テスト                                                                                         |
| 判定   | **PASS**                                                                                                                               |

### AC-4: アクティブセッション ID・経過時間表示

| 項目   | 内容                                                                                                                                      |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 実装   | SessionIndicator コンポーネントが planId（先頭8文字）、現在フェーズ、経過時間を表示。パルスアニメーション付き。60秒間隔で経過時間を更新。 |
| テスト | TC-4-1, TC-4-2, TC-4-3 + SessionIndicator UI テスト                                                                                       |
| 判定   | **PASS**                                                                                                                                  |

### AC-5: セッション削除

| 項目   | 内容                                                                                                                                |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 実装   | `handleDeleteSession` が `deleteSession(checkpointId)` API を呼び出し、成功後にローカルのセッションリストからも該当エントリを除去。 |
| テスト | TC-5-1 + WorkflowEngine deleteCheckpoint テスト + Facade テスト                                                                     |
| 判定   | **PASS**                                                                                                                            |

### AC-6: TTL 自動クリーンアップ

| 項目   | 内容                                                                                                                                   |

| テスト | TC-5-1, TC-5-2, TC-5-3 + TTL 境界値テスト（86,400,001ms）                                                                              |
| 判定   | **PASS**                                                                                                                               |
