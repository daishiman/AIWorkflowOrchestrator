## 品質保証チェックリスト

### 型安全性

- [x] TypeScript strict モード: エラー0件
- [x] `any` 型の使用なし
- [x] 全 IPC リクエスト・レスポンス型が `packages/shared` で定義済み
- [x] UI コンポーネントの Props 型が明示的に定義済み

### セキュリティ

- [x] 全 IPC ハンドラーで `validateSender` パターンによる送信元検証を実施
- [x] 全 IPC ハンドラーで `isBlank` ガードによる空入力・不正入力チェックを実施
- [x] エラーメッセージは `sanitizeErrorMessage` でサニタイズ（内部情報の漏洩防止）
- [x] IPC チャネルは `ALLOWED_INVOKE_CHANNELS` ホワイトリストに登録済み
- [x] XSS リスクなし（ユーザー入力の直接 DOM 挿入なし）
- [x] インジェクションリスクなし（IPC 経由のデータは型バリデーション済み）

### パフォーマンス

- [x] SessionResumePrompt: `React.memo` + `useCallback` で不要な再レンダリングを抑制
- [x] SessionIndicator: `React.memo` + 60秒間隔の更新（毎秒更新を回避）
- [x] セッション TTL（24時間 = 86,400,000ms）によるステールデータの自動クリーンアップ
- [x] `evaluateCompatibility` は遅延評価（不要な事前計算を回避）

### 互換性・信頼性

- [x] セッション TTL（24時間）によるステールセッション蓄積の防止
- [x] 互換性チェック（engineVersion / routeType / lease / root）による不整合復元の防止
- [x] incompatible 判定時の新規セッションフォールバック
- [x] IPC エラー時のグレースフルデグレデーション（エラー表示なし、新規開始）

### コード品質

- [x] 既存パターン（IPC 4層整合、Facade 薄ラッパー、Engine コアロジック）に準拠
- [x] 命名規則の統一（IPC: kebab-case、型: PascalCase、関数: camelCase）
- [x] 重複コードなし
- [x] 全ハンドラーで統一的なエラーハンドリングパターンを適用
