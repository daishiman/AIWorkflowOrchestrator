# Phase 8 Wording Normalization

## fixed vocabulary

| 用語                                  | 使い方                                      |
| ------------------------------------- | ------------------------------------------- |
| `completed`                           | Phase 1-12 の実行完了                       |
| `blocked`                             | Phase 13 のユーザー指示待ち                 |
| `current facts`                       | 実ファイルと validator 実測に基づく記述     |
| `validator compatibility placeholder` | docs-only Phase 11 の補助成果物             |
| `no-op`                               | 本文追記不要だが、理由を summary に残す状態 |
