## 目的

UX・実環境動作確認を手動で実施し、自動テストでカバーできない領域を検証する。

## 背景

マイグレーションはデータベーススキーマの変更を伴うため、実際の操作で問題がないことを手動で確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカルDB動作確認

**目的**: ローカル環境でマイグレーションが正常に動作することを確認する

**実行手順**:

1. 新規SQLiteデータベースファイルを作成
2. `pnpm --filter @repo/shared drizzle-kit push` を実行
3. Drizzle Studioで6テーブルの作成を確認
4. 各テーブルのカラム・制約を目視確認

**期待される成果物**:

- ローカルDB動作確認結果

---

### タスク2: データ投入・検索テスト

**目的**: Knowledge Graphデータの基本操作が可能であることを確認する

**実行手順**:

1. entitiesテーブルにサンプルデータを挿入
2. relationsテーブルに関係性データを挿入
3. 外部キー制約が正しく機能することを確認
4. 検索クエリを実行し結果を確認

**期待される成果物**:

- データ投入・検索テスト結果

---

### タスク3: CASCADE動作確認

**目的**: 外部キーCASCADE動作が正しく機能することを確認する

**実行手順**:

1. 親エンティティを削除
2. 関連する子レコードが自動削除されることを確認
3. 更新時のCASCADE動作を確認
4. 意図しないデータ削除がないことを確認

**期待される成果物**:

- CASCADE動作確認結果
