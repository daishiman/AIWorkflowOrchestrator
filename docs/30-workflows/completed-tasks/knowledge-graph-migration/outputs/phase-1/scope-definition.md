## 1. スコープ概要

### 1.1 目的

Knowledge Graphテーブル群（6テーブル）のマイグレーションファイルを生成し、SQLiteデータベースに適用可能な状態にする。

### 1.2 背景

- CONV-04-05でDrizzle ORMスキーマ定義が完了済み
- 実際のデータベースにテーブルが未作成
- 後続タスク（CONV-08-01: Knowledge Graph Store実装）がブロックされている

---

## 2. 含むもの（In Scope）

### 2.1 マイグレーション生成

| 項目                         | 詳細                                               |
| ---------------------------- | -------------------------------------------------- |
| drizzle.config.ts確認・更新  | graph/ディレクトリがschemaに含まれていることを確認 |
| マイグレーションSQL生成      | `drizzle-kit generate`による6テーブル分のSQL生成   |
| マイグレーションファイル管理 | Git管理下への追加                                  |

### 2.2 マイグレーション適用

| 項目             | 詳細                                 |
| ---------------- | ------------------------------------ |
| ローカルDB適用   | `drizzle-kit push`によるスキーマ適用 |
| 外部キー有効化   | PRAGMA foreign_keys = ON の確認      |
| テーブル存在確認 | 6テーブル全ての存在を検証            |

### 2.3 品質確認

| 項目       | 詳細                               |
| ---------- | ---------------------------------- |
| 型チェック | TypeScript型エラーがないことを確認 |
| Lint       | ESLintエラーがないことを確認       |
| テスト     | 既存テストが全てパスすることを確認 |

### 2.4 対象テーブル（6テーブル）

| テーブル名         | 役割                                    |
| ------------------ | --------------------------------------- |
| entities           | Knowledge Graphのノード（頂点）         |
| relations          | Knowledge Graphのエッジ（辺）           |
| relation_evidence  | 関係の証拠チャンク（中間テーブル）      |
| communities        | Leidenアルゴリズムによるクラスター      |
| entity_communities | エンティティ-コミュニティ（多対多中間） |
| chunk_entities     | チャンク-エンティティ（出現情報中間）   |

## 4. 前提条件

### 4.1 技術的前提

| 項目                    | 内容                                                |
| ----------------------- | --------------------------------------------------- |
| スキーマ定義完了        | `packages/shared/src/db/schema/graph/`に定義済み    |
| Drizzle Kitインストール | pnpmでインストール済み                              |
| SQLiteデータベース      | ローカル開発環境に存在                              |
| chunksテーブル          | relation_evidence, chunk_entitiesが参照するため必須 |

### 4.2 組織的前提

| 項目         | 内容                                   |
| ------------ | -------------------------------------- |
| レビュー不要 | 自動生成されるマイグレーションファイル |
| 承認フロー   | Phase 13でPR作成時にレビュー           |

---

## 5. 制約事項

### 5.1 技術的制約

| 制約               | 詳細                                                         |
| ------------------ | ------------------------------------------------------------ |
| SQLite互換         | libSQL互換のSQL構文のみ使用可能                              |
| 外部キー有効化必須 | SQLiteはデフォルトで外部キー無効                             |
| 変数名制約         | `relations`はDrizzle ORMと競合するため`graphRelations`を使用 |

### 5.2 品質制約

| 制約             | 基準                                  |
| ---------------- | ------------------------------------- |
| テストカバレッジ | Line 80%+, Branch 60%+, Function 80%+ |
| 型安全性         | TypeScript strict modeでエラーなし    |
