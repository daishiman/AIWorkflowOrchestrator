## 目的

`/ai:diff-to-pr` でコミット・PR作成・CI確認を行い、タスクを完了させる。

## 背景

Phase 1〜12で作成した全ての成果物をコミットし、Pull Requestを作成してCI通過を確認する最終Phase。

---

## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認【PR作成前に必須】

**目的**: PR作成前にローカル環境で全チェックを通過することを確認する

**実行手順**:

1. `pnpm build` でビルド成功を確認
2. `pnpm test` で全テストパスを確認
3. `pnpm typecheck` で型チェックパスを確認
4. `pnpm lint` でLintエラーなしを確認

**チェックリスト**:

| #   | 確認項目             | コマンド         | 結果 |
| --- | -------------------- | ---------------- | ---- |
| 1   | ビルドが成功する     | `pnpm build`     | -    |
| 2   | 全テストがパスする   | `pnpm test`      | -    |
| 3   | 型チェックがパスする | `pnpm typecheck` | -    |
| 4   | Lintエラーがない     | `pnpm lint`      | -    |

**期待される成果物**:

- ローカル確認結果

---

### タスク2: ユーザー許可確認【必須】

**目的**: PR作成の許可をユーザーから明示的に得る

**実行手順**:

1. ローカル確認結果をユーザーに報告
2. PR作成の許可を明示的に確認
3. 許可が得られた場合のみ次のタスクへ進む

**確認内容**:

- 変更ファイル一覧
- コミットメッセージ案
- PR作成の可否

**期待される成果物**:

- ユーザー許可記録

---

### タスク3: PR作成

**目的**: `/ai:diff-to-pr` スキルを使用してPRを作成する

**実行手順**:

1. `/ai:diff-to-pr` スキルを実行
2. コミットメッセージを生成
3. PRを作成
4. CI結果を確認

**コミットメッセージ形式**:

```
feat(db): add Knowledge Graph migration for 6 tables

- Add Drizzle ORM schema for entities, relations, relation_evidence
- Add communities, entity_communities, chunk_entities tables
- Configure foreign key constraints with CASCADE behavior
- Add indexes for performance optimization

CONV-04-06
```

**期待される成果物**:

- PR URL
- CI結果

---

### タスク4: タスク完了処理

**目的**: CI通過後、タスクディレクトリを完了フォルダに移動する

**実行手順**:

1. CI通過を確認
2. タスクディレクトリを `docs/30-workflows/completed-tasks/` に移動
3. `artifacts.json` の `status` を `"completed"` に更新
4. 元の未タスク指示書を削除（該当する場合）
5. 変更をコミット・プッシュ

**移動コマンド**:

```bash
mv docs/30-workflows/knowledge-graph-migration/ docs/30-workflows/completed-tasks/
```

**期待される成果物**:

- 完了状態のタスクディレクトリ
