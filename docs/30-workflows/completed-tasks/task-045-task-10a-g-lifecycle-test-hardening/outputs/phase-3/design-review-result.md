## 5. MINOR 指摘事項

### MINOR-1: G2-IMP-02 テスト期待値の実装不一致

**対象**: Phase 4 仕様書 G2-IMP-02
**内容**: テスト名「改善成功後に currentAnalysis がクリアされる」と記載されているが、実装（agentSlice.ts L897-899）では改善後に `analyze()` を再呼び出しして `currentAnalysis` を新しい値で更新する
**修正**: テスト名を「改善成功後に currentAnalysis が再分析結果で更新される」に変更し、期待値を `null` ではなく再分析結果に変更する
**影響範囲**: G2-IMP-02 テストケース1件のみ
**Phase 4 での対応**: テストコード作成時に修正済みの期待値で実装する

### MINOR-2: G1 テストケース数の仕様書間不一致

**対象**: index.md vs Phase 4 仕様書
**内容**: index.md では G1=14件 (VAL:6, DEL:3, ERR:3, SEC:2) だが、Phase 4 仕様書のテストケース表は12件
**修正**: 以下の2件を Phase 4 テストケース表に追加して14件に合わせる

1. G1-VAL-07: `description` が `undefined` の場合に VALIDATION_ERROR を throw する（型チェック境界値）
2. G1-SEC-01: `getAllowedWindows` コールバックが `[mainWindow]` を返すことを検証（v8 カバレッジ P41 対策）
   **影響範囲**: Phase 4 テストケース表の更新のみ
