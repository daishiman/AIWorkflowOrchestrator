## テストカバレッジ確認

### Vitest カバレッジ計測

```bash
# カバレッジレポートを生成
pnpm --filter @repo/desktop test:run --coverage

# カバレッジサマリー確認
# （better-sqlite3 を使用する DB 関連コードのカバレッジを確認）
```

### カバレッジ基準

本タスクはバグ修正（ABI 不一致の解消）であり、追加するコードは `package.json` の1行のみ。
そのため TypeScript コードのカバレッジ増減はない。

カバレッジ確認の焦点:

| 確認項目                                          | 基準           | 理由                                           |
| ------------------------------------------------- | -------------- | ---------------------------------------------- |
| `better-sqlite3-abi.test.ts` のテストケース全通過 | 100%           | ABI 修正の補助的な確認として全ケース通過が必要 |
| DB 操作関連の既存テスト                           | 退行がないこと | 修正が既存テストを壊していないことを確認       |

### テスト通過確認コマンド

```bash
# desktop パッケージの全テストを実行
pnpm --filter @repo/desktop test:run --reporter=verbose 2>&1 | tail -20

# 期待される終了状態
# Test Files  X passed (X)
# Tests       X passed (X)
# Duration    Xs
```
