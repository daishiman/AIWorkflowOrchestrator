# Phase 8 Output: Naming Normalization

## standard companion naming

| 用途                        | suffix                             |
| --------------------------- | ---------------------------------- |
| parent entrypoint           | 元ファイル名維持                   |
| core detail                 | `-core.md`                         |
| secondary detail            | `-details.md`                      |
| deep / optional detail      | `-advanced.md`                     |
| extra detail bundle         | `-reference*.md`                   |
| history / completed / links | `-history*.md`                     |
| workflow active / backlog   | `-active.md`, `-backlog.md`        |
| workflow completed          | `-completed*.md`                   |
| logs archive                | `logs-archive-YYYY-MM[-suffix].md` |

## 適用結果

- F2-F6 は standardized companion naming に統一
- F1 は ledger 固有の suffix へ分離
- `.claude` / `.agents` で同名構造を維持
