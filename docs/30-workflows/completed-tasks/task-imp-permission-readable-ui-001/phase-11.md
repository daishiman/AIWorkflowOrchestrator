## 目的

自動テストでは検証が困難なUI/UX面の品質を手動で確認する。PermissionDialogの人間可読説明文が自然に表示されるか、折りたたみUIが直感的に操作できるか、非技術者ユーザーの観点で検証する。

---

## タスク

- Task 1: 説明文の自然さ確認
  - 各ツール（Bash, Read, Write, Edit, Glob, Grep等）の説明文が日本語として自然か確認する
  - 非技術者が読んで操作内容を理解できるレベルか確認する
  - 説明文の長さが適切か確認する（長すぎず短すぎず）

- Task 2: UI/UXの目視確認
  - 説明文の表示位置がUIレイアウト上で適切か確認する
  - テキストサイズ・色・コントラストが読みやすいか確認する
  - 既存UIとの視覚的な整合性を確認する

- Task 3: 折りたたみUI動作確認
  - 「詳細を表示」ボタンのクリックで技術的詳細が展開されるか確認する
  - 「詳細を隠す」ボタンのクリックで折りたたまれるか確認する
  - 展開/折りたたみのアニメーション（もしあれば）がスムーズか確認する
  - デフォルト状態が折りたたみであるか確認する

- Task 4: アクセシビリティ手動確認
  - キーボードのみで全操作が可能か確認する
  - Tab順序が論理的か確認する
  - フォーカスインジケーターが視認可能か確認する
  - スクリーンリーダーで読み上げ内容が適切か確認する（可能な場合）

- Task 5: エッジケース目視確認
  - 非常に長いコマンド・パスの表示が崩れないか確認する
  - 未定義ツールのデフォルト説明が適切に表示されるか確認する
  - ダイアログ再表示時に折りたたみ状態がリセットされるか確認する

## 手順

### Task 1 実行手順

1. テストランナーまたは実際のElectronアプリで以下のツールの説明文を確認する：

| ツール       | 引数例                      | 期待される説明文                           |
| ------------ | --------------------------- | ------------------------------------------ |
| Bash         | `{ command: "ls -la" }`     | 「ls -la」コマンドを実行します             |
| Read         | `{ path: "/tmp/file.txt" }` | 「/tmp/file.txt」ファイルを読み取ります    |
| Write        | `{ path: "/tmp/out.txt" }`  | 「/tmp/out.txt」ファイルに書き込みます     |
| Edit         | `{ path: "/src/app.tsx" }`  | 「/src/app.tsx」ファイルを編集します       |
| Glob         | `{ pattern: "**/*.ts" }`    | 「\*_/_.ts」パターンでファイルを検索します |
| Grep         | `{ pattern: "TODO" }`       | 「TODO」を含むファイルを検索します         |
| WebSearch    | `{ query: "React hooks" }`  | 「React hooks」で検索します                |
| 未定義ツール | `{ foo: "bar" }`            | デフォルト説明が表示される                 |

2. 各説明文が非技術者にも理解可能か主観的に評価する

### Task 2 実行手順

1. PermissionDialogを表示し、以下を確認する：
   - 説明文がツール名の下に適切に配置されている
   - テキストの色がダークテーマで読みやすい
   - 8pxグリッドに沿ったスペーシング

### Task 3 実行手順

1. PermissionDialogを表示し、折りたたみUIを操作する：
   - デフォルト: 折りたたみ状態（技術的詳細が非表示）
   - 「詳細を表示」クリック → 技術的詳細が表示
   - 「詳細を隠す」クリック → 技術的詳細が非表示
   - 連続操作で状態が正しく切り替わる

### Task 4 実行手順

1. マウスを使わずキーボードのみで操作する：
   - Tab: 次の要素にフォーカス移動
   - Enter/Space: 折りたたみ展開/折りたたみ
   - Escape: ダイアログ閉じる

### Task 5 実行手順

1. 以下のエッジケースを目視確認する：
   - 100文字超のコマンド文字列
   - 日本語を含むファイルパス
   - 空引数のツール
   - ダイアログの連続表示/非表示
