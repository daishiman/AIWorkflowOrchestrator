| ID     | 基準                                                                                                                                      | 確認結果 |

| AC-002 | `getChannelTimeout(channel)` がマップ未定義チャンネルには `IPC_TIMEOUT_MS`（5000ms）を返す                                                | （未）   |
| AC-003 | `invokeWithTimeout` が `getChannelTimeout` を使い、チャンネル別タイムアウトで動作する                                                     | （未）   |
| AC-004 | `auth:login` は 500ms、`auth:get-session` / `auth:refresh` は 10000ms、`skill-creator:plan` は 30000ms、`skill:execute` は 60000ms である | （未）   |
| AC-005 | 既存テストが全て PASS する（後方互換性維持）                                                                                              | （未）   |
| AC-006 | `getChannelTimeout` のユニットテストが全パターンを網羅している                                                                            | （未）   |
