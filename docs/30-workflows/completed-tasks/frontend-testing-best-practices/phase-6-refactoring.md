## 実行手順

### ステップ1: コードスメル検出

code-smell-detectionスキルを使用して、以下を検出：

| コードスメル     | 確認項目                 |
| ---------------- | ------------------------ |
| 重複コード       | 同じパターンの繰り返し   |
| 長いメソッド     | 複雑なテストセットアップ |
| マジックナンバー | ハードコードされた値     |
| 命名不備         | 意図が不明確な変数名     |

### ステップ2: リファクタリング実施

| 改善項目           | 対応                       |
| ------------------ | -------------------------- |
| テストセットアップ | beforeEach/afterEachに集約 |
| モックデータ       | ファクトリーに統一         |
| アサーション       | カスタムマッチャーに抽出   |
| テストヘルパー     | 共通ヘルパーに抽出         |

### ステップ3: テスト実行確認

```bash
# 全テスト実行（リグレッションなし確認）
pnpm test:run

# カバレッジ維持確認
pnpm test:coverage
```
