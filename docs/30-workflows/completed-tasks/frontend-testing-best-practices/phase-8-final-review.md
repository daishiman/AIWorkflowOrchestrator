## 判定基準

| 判定     | 条件             | 対応                                  |
| -------- | ---------------- | ------------------------------------- |
| PASS     | 全観点で問題なし | Phase 9へ進行                         |
| MINOR    | 軽微な指摘あり   | 未完了タスクとして記録後Phase 9へ進行 |
| MAJOR    | 重大な問題あり   | 影響範囲に応じて戻り先を決定          |
| CRITICAL | 致命的な問題あり | Phase 1へ戻りユーザーと要件を再確認   |
