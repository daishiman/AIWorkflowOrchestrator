## 実行手順

### ステップ1: 機能検証

```bash
# 全テスト実行
pnpm test:run

# E2Eテスト実行
pnpm --filter @repo/desktop test:e2e
```

### ステップ2: コード品質チェック

```bash
# Lint実行
pnpm lint

# 型チェック
pnpm typecheck
```

### ステップ3: カバレッジ検証

```bash
# カバレッジ確認
pnpm test:coverage

# 閾値: 80%以上
```

### ステップ4: セキュリティチェック

| チェック項目                    | 結果 |
| ------------------------------- | ---- |

| 機密情報がログ出力されていない  | [ ]  |
