## 目的

評価設計が導線制御に直接効く形で成立しているかをレビューし、実装開始可否を判定する。

## 実行タスク

- タスク1: スコアモデルとゲート判定の妥当性をレビューする。
- タスク2: Task03/05 の連携契約が双方向に成立するかをレビューする。
- タスク3: aiworkflow 参照仕様との整合性をレビューする。
- タスク4: PASS/MINOR/MAJOR の判定と戻り先を決定する。

## 実行手順

1. 要件と設計の対応関係をレビュー表に整理する。
2. SubAgent-A/B/C が個別観点でレビューを実施する。
3. 指摘を `PASS` `MINOR` `MAJOR` で分類する。
4. 判定に応じた戻り先を決定する。

## 統合テスト連携

- Phase 4 のテストケースへ反映する必須指摘を ID 付きで引き渡す。
- `MAJOR` 指摘が 1 件以上ある場合は Phase 4 を開始しない。

## 多角的チェック観点（AIが判断）

- スコアが表示目的で終わらず、導線判定に使われているか。
- 仕様抽出マップに載せた正本仕様と矛盾がないか。
- 戻り先ルールが曖昧になっていないか。
