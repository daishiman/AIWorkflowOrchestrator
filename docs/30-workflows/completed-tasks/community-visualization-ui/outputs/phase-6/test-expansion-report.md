## 3. 追加テストの詳細

### 3.1 CommunityVisualization 統合テスト（18テスト）

コンポーネント間の連携動作を検証：

- **初期レンダリング**: テンプレートのレンダリング、API呼び出し
- **Filter → Graph 連携**: レベルフィルター選択、検索ハイライト
- **Graph → DetailPanel 連携**: ノード選択、詳細表示
- **複合連携**: レベル変更時の選択リセット
- **エラー状態**: API エラー、詳細取得エラー
- **パフォーマンス**: 100+ コミュニティのレンダリング
- **アクセシビリティ**: キーボード操作、ラベル

### 3.2 useCommunities エッジケーステスト（15テスト）

- **境界値テスト**:
  - 1件のコミュニティ
  - 1000件以上のコミュニティ
  - レベル0のフィルタリング
  - 大きなレベル値

- **異常データ処理**:
  - null/undefinedレスポンス
  - 重複レベル
  - 負のレベル値

- **並行処理・タイミング**:
  - 連続refetch
  - アンマウント後のステート更新防止
  - レースコンディション処理

- **エラー回復**:
  - 一時的エラー後の回復
  - 連続エラー後の操作継続

### 3.3 CommunityGraph エッジケーステスト（28テスト）

- **境界データ**:
  - サイズ0のコミュニティ
  - 非常に大きなサイズ
  - 深い階層構造（5+レベル）
  - 同一レベル多数ノード
  - 特殊文字を含むID

- **親子関係の表示**:
  - 孤立した子（親が存在しない）
  - 循環参照データ
  - 複数の子を持つ親

- **ズーム・パン操作**:
  - ズーム上限・下限
  - ホイール操作

- **選択とハイライト**:
  - 存在しないIDでの選択
  - 全ノードハイライト
  - 選択とハイライトの同時適用

- **アクセシビリティ強化**:
  - 選択状態のクラス
  - ズームコントロールのaria-label
  - Tab操作
  - スクリーンリーダー対応
  - ローディング・エラー状態の通知

### 3.4 CommunityDetailPanel エッジケーステスト（14テスト）

- **境界データ**:
  - 長いサマリーテキスト（2000文字）
  - 多数のキーワード（50+）
  - 空のキーワード
  - 多数のメンバー（100人）
  - 信頼度0%/100%
  - 小数点以下の信頼度

- **センチメント表示**:
  - positive/negative/neutral

- **エラーハンドリング**:
  - 長いエラーメッセージ
  - 特殊文字を含むエラー

- **メンバークリック**:
  - onEntityClick未定義
  - 複数回クリック

- **アクセシビリティ強化**:
  - 見出し階層
  - アクセシブルなボタン名
  - aria-label
  - キーボード操作
