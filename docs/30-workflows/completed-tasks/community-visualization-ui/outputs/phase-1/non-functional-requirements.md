## 1. パフォーマンス要件

### 1.1 描画パフォーマンス

| 項目                  | 基準値  | 測定方法        |
| --------------------- | ------- | --------------- |
| 初期表示時間（100件） | < 1秒   | Performance API |
| 初期表示時間（500件） | < 3秒   | Performance API |
| ノードクリック応答    | < 100ms | User Timing API |
| フィルタリング適用    | < 100ms | User Timing API |
| 検索結果ハイライト    | < 200ms | User Timing API |

### 1.2 操作パフォーマンス

| 操作       | 基準値             | 備考                  |
| ---------- | ------------------ | --------------------- |
| ズーム操作 | 60fps維持          | requestAnimationFrame |
| パン操作   | 60fps維持          | requestAnimationFrame |
| スクロール | 慣性スクロール対応 | CSS scroll-behavior   |

### 1.3 メモリ使用量

| 項目              | 基準値  |
| ----------------- | ------- |
| コミュニティ100件 | < 50MB  |
| コミュニティ500件 | < 100MB |
| メモリリーク      | なし    |

## 2. アクセシビリティ要件

### 2.1 WCAG 2.1 AA準拠

| 基準                          | 要件                         | 対応方法             |
| ----------------------------- | ---------------------------- | -------------------- |
| 1.4.3 コントラスト            | 4.5:1以上（通常テキスト）    | デザイントークン使用 |
| 1.4.11 非テキストコントラスト | 3:1以上（UIコンポーネント）  | フォーカスリング     |
| 2.1.1 キーボード              | 全機能がキーボードで操作可能 | tabindex, onKeyDown  |
| 2.4.7 フォーカス可視          | フォーカス位置が視覚的に明確 | :focus-visible       |

### 2.2 キーボードナビゲーション

| キー      | 動作                           |
| --------- | ------------------------------ |
| Tab       | 次のインタラクティブ要素へ移動 |
| Shift+Tab | 前のインタラクティブ要素へ移動 |
| Enter     | ノード選択/ボタン実行          |
| Escape    | 選択解除/ダイアログ閉じる      |
| 矢印キー  | グラフ内ノード間移動           |
| +/-       | ズームイン/アウト              |
| Home      | 全体フィット表示               |

### 2.3 スクリーンリーダー対応

| 要素         | ARIA属性                                                    |
| ------------ | ----------------------------------------------------------- |
| グラフ全体   | `role="application"`, `aria-label="コミュニティ構造グラフ"` |
| ノード       | `role="button"`, `aria-label="コミュニティ {name}"`         |
| 詳細パネル   | `role="complementary"`, `aria-label="コミュニティ詳細"`     |
| フィルター   | `aria-label="階層レベルフィルター"`                         |
| 検索         | `aria-label="コミュニティ検索"`                             |
| ローディング | `aria-live="polite"`, `aria-busy="true"`                    |
| エラー       | `role="alert"`, `aria-live="assertive"`                     |

## 3. 型安全性要件

### 3.1 Branded Types使用

| 型            | 用途               | 定義                                  |
| ------------- | ------------------ | ------------------------------------- |
| `CommunityId` | コミュニティ識別子 | `string & { __brand: "CommunityId" }` |
| `EntityId`    | エンティティ識別子 | `string & { __brand: "EntityId" }`    |

### 3.2 Result型パターン

```typescript
type Result<T, E> = { ok: true; value: T } | { ok: false; error: E };
```

| 使用箇所   | 成功時の型                   | エラー時の型     |
| ---------- | ---------------------------- | ---------------- |
| IPC通信    | `Result<T, Error>`           | エラーメッセージ |
| Hook戻り値 | `{ data, isLoading, error }` | Error            |

### 3.3 TypeScript設定

| 設定               | 値     | 理由             |
| ------------------ | ------ | ---------------- |
| `strict`           | `true` | 厳密な型チェック |
| `noImplicitAny`    | `true` | any型禁止        |
| `strictNullChecks` | `true` | null安全性       |
