## 目的

TDDのRefactorフェーズとして、テストを維持しながらコードの品質を改善する。可読性・保守性・パフォーマンスの向上を図る。

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コード重複の排除

**目的**: DRY原則に従い、重複コードを共通化する

**実行手順**:

1. 重複パターンの特定:
   - 複数コンポーネントで使用されるスタイル
   - 共通のエラーハンドリングロジック
   - 類似のデータ変換処理
2. 共通コンポーネント/ユーティリティの抽出:
   ```typescript
   // 例: 共通のローディング状態表示
   function useCommunityData<T>(fetcher: () => Promise<T>) {
     // 共通ロジック
   }
   ```
3. リファクタリング後、全テストがGreenであることを確認

**期待される成果物**:

- 共通化されたコンポーネント/ユーティリティ

---

### タスク2: コンポーネント責務の明確化

**目的**: 単一責任原則に従い、コンポーネントの責務を整理する

**実行手順**:

1. 各コンポーネントの責務を確認:
   - CommunityGraph: グラフ描画のみ
   - CommunityDetailPanel: 詳細表示のみ
   - CommunityFilter: フィルタリングロジックのみ
2. 責務が混在している場合:
   - 表示ロジックとビジネスロジックを分離
   - カスタムHookへのロジック抽出
3. リファクタリング後、全テストがGreenであることを確認

**期待される成果物**:

- 責務が明確化されたコンポーネント

---

### タスク3: 型安全性の強化

**目的**: TypeScriptの型システムを最大限活用する

**実行手順**:

1. any型の排除:
   ```bash
   grep -rn "any" apps/desktop/src/renderer/components/community/
   ```
2. Branded Types の確認:
   - CommunityId が正しく使用されているか
   - 型キャストが最小限か
3. ジェネリクスの適切な使用:

   ```typescript
   // 悪い例
   function handleData(data: any) {}

   // 良い例
   function handleData<T extends Community | CommunitySummary>(data: T) {}
   ```

4. リファクタリング後、全テストがGreenであることを確認

**期待される成果物**:

- 型安全性が強化されたコード

---

### タスク4: パフォーマンス最適化

**目的**: レンダリングパフォーマンスを最適化する

**実行手順**:

1. 不要な再レンダリングの排除:
   - React.memo の適切な使用
   - useMemo, useCallback の適切な使用
   - 依存配列の最適化
2. コンポーネント分割の最適化:
   ```typescript
   // 大きなコンポーネントの分割
   const CommunityNode = React.memo(({ data }) => {
     // ノード表示ロジック
   });
   ```
3. レンダリング計測:
   ```typescript
   // React DevTools Profiler で確認
   ```
4. リファクタリング後、パフォーマンステストがGreenであることを確認

**期待される成果物**:

- パフォーマンス最適化されたコンポーネント

---

### タスク5: コードスタイルの統一

**目的**: 既存のコードベースとスタイルを統一する

**実行手順**:

1. ESLint/Prettier の適用確認:
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. 命名規則の統一:
   - PascalCase: コンポーネント
   - camelCase: 関数、変数
   - UPPER_CASE: 定数
3. ファイル構造の整理:
   ```
   community/
   ├── CommunityGraph/
   │   ├── index.tsx           # エクスポート
   │   ├── CommunityGraph.tsx  # メインコンポーネント
   │   ├── CommunityNode.tsx   # サブコンポーネント
   │   ├── types.ts            # 型定義
   │   └── __tests__/          # テスト
   ```
4. リファクタリング後、全テストがGreenであることを確認

**期待される成果物**:

- スタイルが統一されたコード

---
