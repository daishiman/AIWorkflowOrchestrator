## 目的

実際のデスクトップアプリケーション環境でUIの動作を手動確認し、ユーザビリティ・実環境での動作を検証する。

## 背景

自動テストでは検出しにくいUIの使用感、視覚的な問題、実環境でのパフォーマンスを手動で確認する。実際にElectronアプリを起動して操作を行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: テスト環境の準備

**目的**: 手動テスト用の環境を準備する

**実行手順**:

1. アプリケーションをビルド:
   ```bash
   pnpm --filter @repo/desktop build
   ```
2. 開発サーバーを起動:
   ```bash
   pnpm --filter @repo/desktop dev
   ```
3. テストデータの準備:
   - コミュニティ検出を実行済みであること
   - 複数レベルのコミュニティが存在すること
   - コミュニティ要約が生成されていること

**期待される成果物**:

- テスト環境準備完了

---

### タスク2: 基本機能テスト

**目的**: 基本的な機能が正しく動作することを確認する

**実行手順**:

1. コミュニティ可視化画面を開く
2. 以下のテストケースを実行:

| ID   | テストケース     | 手順                         | 期待結果                           | 結果 |
| ---- | ---------------- | ---------------------------- | ---------------------------------- | ---- |
| TC01 | グラフ表示       | 画面を開く                   | コミュニティがノードとして表示     | ⬜   |
| TC02 | 階層構造表示     | 画面を確認                   | 親子関係がエッジで接続             | ⬜   |
| TC03 | ノードクリック   | 任意のノードをクリック       | 詳細パネルに情報表示               | ⬜   |
| TC04 | 要約表示         | ノードを選択                 | 要約・キーワード・メンバー表示     | ⬜   |
| TC05 | レベルフィルター | レベルをドロップダウンで選択 | 選択レベルのコミュニティのみ表示   | ⬜   |
| TC06 | 検索             | キーワードを入力             | マッチするコミュニティがハイライト | ⬜   |
| TC07 | ズーム           | マウスホイールでズーム       | グラフが拡大/縮小                  | ⬜   |
| TC08 | パン             | ドラッグで移動               | グラフビューが移動                 | ⬜   |
| TC09 | フィット         | フィットボタンをクリック     | 全体が収まるように表示             | ⬜   |

**期待される成果物**:

- 基本機能テスト結果

---

### タスク3: エッジケーステスト

**目的**: 特殊なケースでの動作を確認する

**実行手順**:

| ID   | テストケース    | 手順                       | 期待結果                     | 結果 |
| ---- | --------------- | -------------------------- | ---------------------------- | ---- |
| TC10 | 空データ        | コミュニティなしでアクセス | 適切なメッセージ表示         | ⬜   |
| TC11 | 大量データ      | 100+コミュニティで表示     | パフォーマンス問題なし       | ⬜   |
| TC12 | 要約未生成      | 要約なしコミュニティを選択 | 「要約未生成」メッセージ表示 | ⬜   |
| TC13 | 長いテキスト    | 長い要約を持つコミュニティ | 適切に折り返し表示           | ⬜   |
| TC14 | 連続選択        | 複数ノードを連続クリック   | 正しく切り替わる             | ⬜   |
| TC15 | フィルター+検索 | フィルター後に検索         | 両条件が適用される           | ⬜   |

**期待される成果物**:

- エッジケーステスト結果

### タスク5: 手動統合テスト

**目的**: UI/IPC接続の実環境動作を確認する

**実行手順**:

| ID   | テストケース | 手順                           | 期待結果                 | 結果 |
| ---- | ------------ | ------------------------------ | ------------------------ | ---- |
| TC21 | データ取得   | 画面を開く                     | IPC経由でデータ取得成功  | ⬜   |
| TC22 | 詳細取得     | コミュニティを選択             | IPC経由で詳細取得成功    | ⬜   |
| TC23 | エラー回復   | ネットワーク障害をシミュレート | リトライで回復可能       | ⬜   |
| TC24 | 状態同期     | フィルター変更                 | グラフと詳細パネルが同期 | ⬜   |

**期待される成果物**:

- 手動統合テスト結果

---

### タスク6: テスト結果のまとめ

**目的**: 全テスト結果を集約し、問題点を整理する

**実行手順**:

1. 全テスト結果を集約
2. 発見した問題を分類:
   - CRITICAL: 致命的（機能が動作しない）
   - MAJOR: 重大（UXに大きな影響）
   - MINOR: 軽微（改善推奨）
   - INFO: 情報（将来対応可）
3. スコープ外の発見事項を記録（未タスク候補）

**期待される成果物**:

- テスト結果サマリー
- 発見問題リスト
- スコープ外発見事項
