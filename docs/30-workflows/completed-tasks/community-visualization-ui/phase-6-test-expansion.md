## 目的

Phase 5（実装）完了後、カバレッジ目標達成に向けて追加テストを作成する。ユニットテスト・統合テストの両面でカバレッジを向上させる。

## 背景

TDDのGreenフェーズ完了後、リファクタリングに進む前にテストカバレッジを十分に確保する必要がある。Phase 4で作成した基本テストに加え、エッジケース・境界値・異常系のテストを追加する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジの確認と拡充

**目的**: 現在のカバレッジを確認し、不足箇所のテストを追加する

**実行手順**:

1. 現在のカバレッジを確認:
   ```bash
   pnpm --filter @repo/desktop test:coverage
   ```
2. カバレッジレポートを分析し、不足箇所を特定
3. 以下の追加テストを作成:
   - CommunityGraph:
     - [ ] 異なるレイアウトオプションのテスト
     - [ ] ノードホバー時の動作テスト
     - [ ] キーボードナビゲーションテスト
   - CommunityDetailPanel:
     - [ ] 長いテキストの表示テスト
     - [ ] 空のキーワード/メンバーリストのテスト
     - [ ] スクロール動作のテスト
   - CommunityFilter:
     - [ ] 連続入力のデバウンステスト
     - [ ] 特殊文字入力のテスト
     - [ ] 複数フィルター組み合わせテスト

**期待される成果物**:

- 拡充されたテストファイル
- カバレッジレポート

---

### タスク2: 統合テストの拡充

**目的**: コンポーネント間連携・IPC通信のテストを拡充する

**実行手順**:

1. API接続テストの追加:
   ```typescript
   describe("API接続テスト（拡充）", () => {
     it("大量データ取得時のパフォーマンス");
     it("タイムアウト時のエラーハンドリング");
     it("不正なデータ形式の処理");
     it("同時リクエストの処理");
   });
   ```
2. データフローテストの追加:
   ```typescript
   describe("データフローテスト（拡充）", () => {
     it("連続した選択変更の処理");
     it("フィルタとの組み合わせ動作");
     it("検索中の選択変更");
     it("データ更新時の表示同期");
   });
   ```
3. エラーハンドリングテストの追加:
   ```typescript
   describe("エラーハンドリング（拡充）", () => {
     it("ネットワーク切断時の動作");
     it("部分的なデータ取得失敗");
     it("連続エラー時のリトライ制限");
   });
   ```

**期待される成果物**:

- 拡充された統合テストファイル

---

### タスク3: アクセシビリティテストの追加

**目的**: WCAG 2.1 AA準拠を確認するテストを追加する

**実行手順**:

1. axe-coreを使用したアクセシビリティテスト:

   ```typescript
   import { axe, toHaveNoViolations } from "jest-axe";
   expect.extend(toHaveNoViolations);

   describe("アクセシビリティテスト", () => {
     it("CommunityGraphにアクセシビリティ違反がない");
     it("CommunityDetailPanelにアクセシビリティ違反がない");
     it("CommunityFilterにアクセシビリティ違反がない");
   });
   ```

2. キーボードナビゲーションテスト:
   ```typescript
   describe("キーボードナビゲーション", () => {
     it("Tabキーで全インタラクティブ要素にフォーカス移動");
     it("Enterキーでノード選択");
     it("矢印キーでノード間移動");
     it("Escapeキーで選択解除");
   });
   ```
3. スクリーンリーダー対応テスト:
   ```typescript
   describe("スクリーンリーダー対応", () => {
     it("aria-label属性が適切に設定されている");
     it("aria-live属性で状態変更が通知される");
     it("role属性が適切に設定されている");
   });
   ```

**期待される成果物**:

- アクセシビリティテストファイル

---

### タスク4: パフォーマンステストの追加

**目的**: 大量データでのパフォーマンスを検証するテストを追加する

**実行手順**:

1. レンダリングパフォーマンステスト:

   ```typescript
   describe('パフォーマンステスト', () => {
     it('100件のコミュニティを1秒以内に表示', async () => {
       const start = performance.now();
       render(<CommunityGraph communities={largeCommunities} />);
       const duration = performance.now() - start;
       expect(duration).toBeLessThan(1000);
     });

     it('500件のコミュニティでフリーズしない');
     it('ズーム操作が60fps以上を維持');
     it('フィルタリングが100ms以内に完了');
   });
   ```

**期待される成果物**:

- パフォーマンステストファイル

### タスク5: カバレッジ目標達成確認

**目的**: ユニットテスト・結合テストのカバレッジ目標を確認する

**実行手順**:

1. カバレッジレポートを生成:
   ```bash
   pnpm --filter @repo/desktop test:coverage
   ```
2. 以下の基準を確認:
   - ユニットテスト:
     - Line Coverage: 80%以上
     - Branch Coverage: 60%以上
     - Function Coverage: 80%以上
   - 結合テスト:
     - API接続テスト: 全ケース完了
     - データフローテスト: 全シナリオ完了
     - エラーハンドリング: 全パターン完了
3. 未達の場合は追加テストを作成

**期待される成果物**:

- カバレッジレポート（`outputs/phase-6/coverage-report.md`）
