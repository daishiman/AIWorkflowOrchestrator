## テスト設計のポイント

### P9 対策: テスト間状態リーク防止

- 追加テストも既存テストと同様に `beforeEach` で入力データを初期化する
- `vi.mock('fs')` のモック値は各テストで個別に設定する
- `console.log` / `console.warn` の spy は `afterEach` でリストアする

### P41 対策: インライン関数のカバレッジ

- パーサー関数内の `Array.filter()`, `Array.map()`, `Array.reduce()` のコールバックが全て実行されるテストケースを含める
- チェッカー関数内の変換ロジック（サブパスキー → alias キー変換）のコールバックが全分岐で実行されることを確認する
