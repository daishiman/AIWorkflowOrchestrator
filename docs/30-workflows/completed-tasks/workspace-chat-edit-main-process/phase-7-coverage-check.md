## 3. 判定基準

### 3.1 PASS条件

以下の全てを満たすこと:

- [ ] Line Coverage ≥ 80%
- [ ] Branch Coverage ≥ 60%
- [ ] Function Coverage ≥ 80%
- [ ] 全統合テストがパス
- [ ] 全IPCハンドラテストがパス

### 3.2 FAIL時のアクション

- カバレッジ不足の場合 → Phase 6に戻りテスト追加
- テスト失敗の場合 → Phase 5に戻り実装修正
