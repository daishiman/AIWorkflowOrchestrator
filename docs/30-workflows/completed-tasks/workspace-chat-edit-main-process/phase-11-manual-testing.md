## 5. 判定基準

### 5.1 PASS条件

以下を満たすこと:

- [ ] 全必須シナリオがPASS
- [ ] 重大なUI/UX問題がない
- [ ] エラーハンドリングが適切
- [ ] アクセシビリティ基準を満たす

### 5.2 FAIL時のアクション

- UI問題の場合 → Renderer側修正（別タスク）
- 機能問題の場合 → Phase 5に戻り実装修正
- 統合問題の場合 → IPCハンドラ/サービス確認
