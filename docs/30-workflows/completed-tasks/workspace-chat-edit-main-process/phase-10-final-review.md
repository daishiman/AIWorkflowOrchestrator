## 4. 判定基準

### 4.1 APPROVED条件

以下の全てを満たすこと:

- [ ] 全機能要件が充足されている
- [ ] 全非機能要件が充足されている
- [ ] テストカバレッジが目標を達成している
- [ ] 品質保証がPASSしている
- [ ] 重大なリスクが残存していない
- [ ] 全成果物が作成されている

### 4.2 CONDITIONAL条件

- [ ] 軽微な問題があるがリスク受容可能
- [ ] 対応計画が明確になっている

### 4.3 REJECTED時のアクション

- 問題の種類に応じて該当Phaseに戻る
