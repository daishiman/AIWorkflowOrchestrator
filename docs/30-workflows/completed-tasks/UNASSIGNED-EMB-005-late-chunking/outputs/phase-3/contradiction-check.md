# 矛盾チェック表

| チェック観点         | 矛盾の有無 | 詳細                                                               |
| -------------------- | ---------- | ------------------------------------------------------------------ |
| 型名の重複           | なし       | `ChunkBoundary`はembedding側で独自定義（chunking側と名前空間分離） |
| データフロー方向     | なし       | 全文→ウィンドウ→エンコード→プーリング→出力の一方向                 |
| エラー継承関係       | なし       | `InvalidBoundaryError extends EmbeddingError` で統一               |
| インターフェース契約 | なし       | `ILateChunkingService`の入出力型が全Phase間で一致                  |
