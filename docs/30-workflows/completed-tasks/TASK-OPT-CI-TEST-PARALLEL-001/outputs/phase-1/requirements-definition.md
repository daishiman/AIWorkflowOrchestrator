# 要件定義書

## 作成日

2026-02-02

## 機能要件（FR）

### FR-1: シャード数最適化

- **概要**: test-desktopのシャード数を8から16に増加
- **目的**: 各シャードのテスト数を半減し、実行時間を短縮
- **受け入れ基準**: 各シャードの実行時間が10分以下

### FR-2: shared packageビルドキャッシュ

- **概要**: `packages/shared/dist`をactions/cacheでキャッシュ
- **目的**: 依存関係未変更時のビルドスキップ
- **受け入れ基準**: キャッシュヒット時にビルドステップがスキップされる

### FR-3: カバレッジ計測の条件分岐

- **概要**: PRトリガー時はカバレッジ計測をスキップ
- **目的**: PR時の高速フィードバック
- **受け入れ基準**:
  - PR時: `--coverage`なしでテスト実行
  - mainブランチpush時: `--coverage`ありでテスト実行

### FR-4: Vitest並列化設定最適化

- **概要**: maxForks、fileParallelismの調整
- **目的**: 各シャード内でのテスト実行効率向上
- **受け入れ基準**: メモリエラーなしでテスト完了

### FR-5: カバレッジ改善

- **概要**: Line Coverageを78.68%から80%以上に改善
- **目的**: 品質しきい値達成
- **受け入れ基準**: `pnpm --filter @repo/desktop test:run --coverage`で80%以上

## 非機能要件（NFR）

### NFR-1: パフォーマンス

| 項目               | 現状 | 目標     |
| ------------------ | ---- | -------- |
| 各シャード実行時間 | 13分 | 10分以下 |
| 全体CI時間         | 18分 | 12分以下 |
| キャッシュヒット率 | -    | 80%以上  |

### NFR-2: 信頼性

- Flaky testの増加なし
- 3回連続実行で同一結果

### NFR-3: 互換性

- 既存テストへの影響なし
- ローカル開発環境への影響なし
- 他ワークフローへの影響なし

### NFR-4: 保守性

- CI設定の可読性維持
- コメントによる設定根拠の明記

## 制約条件

1. **GitHub Actionsランナー制約**: ubuntu-latest（2コア、8GB RAM）
2. **同時ジョブ数制限**: 無料枠での制限を考慮
3. **既存テストコードは変更しない**: CI/CD設定のみ変更

## スコープ

### 実装対象

1. `.github/workflows/ci.yml`の修正
2. `apps/desktop/vitest.config.ts`の修正
3. カバレッジ除外設定の調整

### スコープ外

1. テストケースの削減・削除
2. テストコードのリファクタリング
3. E2Eテストの追加・変更
4. 新規ワークフローファイルの作成
