## 依存関係

### 前提条件

- GitHub Actions環境（ubuntu-latest）
- pnpm v9+
- Node.js v22

### 影響を受けるシステム

| システム          | 影響                                 |
| ----------------- | ------------------------------------ |
| CI/CDパイプライン | 直接影響（設定変更）                 |
| Codecov           | カバレッジアップロードタイミング変更 |
| ローカル開発環境  | 影響なし（CI環境のみ変更）           |

## リスク管理

| リスク                         | 対策                         |
| ------------------------------ | ---------------------------- |
| シャード増加によるランナー不足 | concurrencyで同時実行数制限  |
| maxForks増加によるメモリ不足   | 段階的に増加、CI環境のみ変更 |
| キャッシュ無効化による遅延     | restore-keysでフォールバック |
