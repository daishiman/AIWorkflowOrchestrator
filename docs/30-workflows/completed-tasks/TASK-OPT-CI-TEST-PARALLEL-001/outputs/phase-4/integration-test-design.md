# 統合テストシナリオ

## 作成日

2026-02-02

## 統合テスト概要

CI最適化の各コンポーネント間の連携を検証するテストシナリオ。

## シナリオカテゴリ

### 1. シャード動作テスト

| テスト項目       | 検証内容                     | 検証方法                 |
| ---------------- | ---------------------------- | ------------------------ |
| シャード数       | 16シャードが生成される       | CIジョブ一覧確認         |
| テスト分散       | 各シャードにテストが均等分散 | 各シャードのテスト数確認 |
| シャード独立性   | 各シャードが独立して実行完了 | 並列実行ログ確認         |
| シャード結果集約 | 全シャード結果が集約される   | ワークフロー結果確認     |

**統合ポイント**:

- Vitest `--shard=N/16` オプション
- GitHub Actions matrix strategy

### 2. キャッシュ連携テスト

| テスト項目             | 検証内容               | 検証方法              |
| ---------------------- | ---------------------- | --------------------- |
| shared buildキャッシュ | キャッシュの保存・復元 | "Cache hit/saved"ログ |
| pnpm storeキャッシュ   | pnpmキャッシュの動作   | install時間短縮確認   |
| キャッシュキー整合性   | キー計算の正確性       | ハッシュ値確認        |
| フォールバック動作     | restore-keysの動作     | 部分マッチ確認        |

**統合ポイント**:

- `actions/cache@v4`
- `actions/setup-node@v6` cache機能
- pnpm-lock.yaml, packages/shared/src/\*\* のハッシュ

### 3. カバレッジ連携テスト

| テスト項目             | 検証内容                   | 検証方法                  |
| ---------------------- | -------------------------- | ------------------------- |
| 条件分岐               | PR/mainでの計測有無        | テストコマンドログ確認    |
| アーティファクト生成   | 16シャードのカバレッジ出力 | アーティファクト一覧確認  |
| アーティファクトマージ | カバレッジファイルの統合   | coverageジョブログ確認    |
| Codecov連携            | カバレッジアップロード     | Codecovダッシュボード確認 |

**統合ポイント**:

- `actions/upload-artifact@v4`
- `actions/download-artifact@v4` merge-multiple
- `codecov/codecov-action@v5`

### 4. パフォーマンステスト

| テスト項目     | 検証内容            | 検証方法             |
| -------------- | ------------------- | -------------------- |
| 目標時間達成   | 各シャード10分以下  | 実行時間計測         |
| 全体時間達成   | 12分以下            | ワークフロー時間計測 |
| キャッシュ効果 | 2回目以降の時間短縮 | 初回/2回目比較       |
| 並列効果       | maxForks増加の効果  | 並列化前後比較       |

**統合ポイント**:

- Vitest poolOptions.forks.maxForks
- Vitest fileParallelism
- GitHub Actions matrix並列実行

## エンドツーエンド検証フロー

```
┌─────────────────────────────────────────────────────────────┐
│ 1. PRトリガー                                               │
│    ├─ 16シャード生成確認                                    │
│    ├─ --coverageなし確認                                    │
│    ├─ キャッシュ動作確認                                    │
│    └─ 全テストPASS確認                                      │
├─────────────────────────────────────────────────────────────┤
│ 2. mainトリガー                                             │
│    ├─ 16シャード生成確認                                    │
│    ├─ --coverageあり確認                                    │
│    ├─ アーティファクト生成確認                              │
│    ├─ coverageジョブ実行確認                                │
│    └─ Codecovアップロード確認                               │
├─────────────────────────────────────────────────────────────┤
│ 3. パフォーマンス検証                                       │
│    ├─ 各シャード時間測定                                    │
│    ├─ 全体CI時間測定                                        │
│    └─ キャッシュヒット率計算                                │
├─────────────────────────────────────────────────────────────┤
│ 4. 信頼性検証                                               │
│    ├─ 複数回実行での結果一致                                │
│    └─ Flaky test検出                                        │
└─────────────────────────────────────────────────────────────┘
```

## 合格基準

| カテゴリ       | 合格基準                                 |
| -------------- | ---------------------------------------- |
| シャード動作   | 全16シャードが正常完了                   |
| キャッシュ連携 | 2回目以降でキャッシュヒット              |
| カバレッジ連携 | mainでCodecovにアップロード成功          |
| パフォーマンス | 目標時間達成（10分/シャード、12分/全体） |
| 信頼性         | 3回連続で同一結果                        |
