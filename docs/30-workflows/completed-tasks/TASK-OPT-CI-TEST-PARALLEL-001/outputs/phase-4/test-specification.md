## CI動作検証シナリオ

### シナリオ1: PR作成時のCI実行

| 項目     | 内容                               |
| -------- | ---------------------------------- |
| トリガー | Pull Request作成                   |
| 期待結果 | カバレッジなし、16シャード並列実行 |
| 検証方法 | CI実行ログ確認                     |

**検証項目**:

- [ ] 16シャードが並列実行される

## TDD状態の定義

本タスクはCI/CD設定の最適化のため、TDDの「Red」状態を以下のように定義：

| 項目               | 現状（Red） | 目標（Green） |
| ------------------ | ----------- | ------------- |
| 各シャード実行時間 | 13分        | 10分以下      |
| 全体CI時間         | 18分        | 12分以下      |
| シャード数         | 8           | 16            |
| カバレッジ条件分岐 | なし        | PRスキップ    |
