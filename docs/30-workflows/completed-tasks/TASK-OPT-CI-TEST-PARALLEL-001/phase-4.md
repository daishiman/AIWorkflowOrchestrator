## 注意事項

本タスクはCI/CD設定の最適化であり、アプリケーションコードの変更を伴わない。
そのため、TDDの「テストが失敗する状態（Red）」は以下の形で定義する:

1. 現在のCI実行時間（19-20分/シャード）を記録
2. 目標実行時間（10分以下）を設定
3. 変更前のCI設定で目標未達成であることを確認（= Red状態）
