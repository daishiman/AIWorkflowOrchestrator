## 最終レビュー判定

| 判定     | 条件                                               | 対応                                    |
| -------- | -------------------------------------------------- | --------------------------------------- |
| PASS     | 全チェック項目が達成・重大な問題がないこと         | Phase 11（手動テスト）へ進行            |
| MINOR    | 軽微な問題のみで、是正が Phase 11 前に完了すること | 未完了タスクとして記録後 Phase 11へ進行 |
| MAJOR    | 重大な問題があること                               | 影響範囲に応じて戻り先を決定            |
| CRITICAL | 致命的な問題があること                             | Phase 1 へ戻りユーザーと要件を再確認    |

### 戻り先決定基準

| 問題の種類       | 戻り先                      |
| ---------------- | --------------------------- |
| 要件の問題       | Phase 1（要件定義）         |
| 設計の問題       | Phase 2（設計）             |
| テスト設計の問題 | Phase 4（テスト作成）       |
| 実装の問題       | Phase 5（実装）             |
| テスト拡充の問題 | Phase 6（テスト拡充）       |
| カバレッジ未達   | Phase 7（カバレッジ確認）   |
| コード品質の問題 | Phase 8（リファクタリング） |

### MINOR判定時のフロー

- MINOR 判定なら未完了タスクとして記録し、修正後に Phase 11 へ進行する。
