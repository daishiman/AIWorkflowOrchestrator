## 目的

Phase 2 設計の矛盾・漏れ・整合性をレビューし、実装フェーズへの通過判定を行う。

## 実行タスク

1. API シグネチャと要件の矛盾を確認する。
2. 推論ルールとフォールバックの漏れを確認する。
3. 依存関係と境界の不整合を確認する。

## 統合テスト連携

- Phase 4 に進める条件を PASS / FAIL で固定する。
- FAIL の場合は Phase 4 へ進まず、設計を修正する。
