## 事前検証で発見・修正したバグ

### BUG-001: AgentViewがApp.tsxに統合されていなかった

- **発見**: Phase 11 手動テスト準備中
- **原因**: App.tsx の `renderView()` 関数に `agent` ケースが欠落
- **影響**: AgentアイコンをクリックしてもAgentViewが表示されない
- **修正内容**:
  1. `AgentView` のimport追加
  2. `renderView()` の switch文に `case "agent"` 追加
- **修正ファイル**: `apps/desktop/src/renderer/App.tsx`
- **重要度**: Critical（機能が動作しない）
- **ステータス**: 修正済み
