## 実装範囲外（Out of Scope）

### 対象外プロバイダー

| プロバイダー  | 理由                     |
| ------------- | ------------------------ |
| GitHub OAuth  | ユーザー指示により対象外 |
| Discord OAuth | ユーザー指示により対象外 |

### 対象外機能

| 機能               | 理由                                    |
| ------------------ | --------------------------------------- |
| 新規ユーザー登録   | 既存のOAuth認証フローで対応済み         |
| パスワード認証     | OAuthのみ対象                           |
| 2FA/MFA            | 現時点では未実装                        |
| アカウント連携追加 | 別タスクで対応                          |
| プロフィール編集   | 別タスクで対応                          |
| アバター設定       | 別タスクで対応（AUTH-UI-004で一部完了） |

### 対象外ファイル

| ファイル                                       | 理由                     |
| ---------------------------------------------- | ------------------------ |
| `apps/desktop/src/main/ipc/profileHandlers.ts` | プロフィール機能は対象外 |
| `apps/desktop/src/main/ipc/avatarHandlers.ts`  | アバター機能は対象外     |
| UI コンポーネント                              | 既存のエラー表示UI使用   |

| 制約           | 説明                         |
| -------------- | ---------------------------- |
