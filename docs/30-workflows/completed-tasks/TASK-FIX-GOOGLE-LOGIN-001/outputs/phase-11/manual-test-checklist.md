## テストシナリオ

### シナリオ 1: 正常なGoogleログイン

| 手順 | 操作                                 | 期待結果                             |
| ---- | ------------------------------------ | ------------------------------------ |
| 1    | アプリを起動                         | ログイン画面が表示される             |
| 2    | 「Googleでログイン」ボタンをクリック | 外部ブラウザでGoogle認証画面が開く   |
| 3    | Googleアカウントでログイン           | アプリにリダイレクトされる           |
| 4    | アプリを確認                         | ログイン状態になり、ユーザー情報表示 |

### シナリオ 2: Googleログインキャンセル

| 手順 | 操作                                 | 期待結果                                         |
| ---- | ------------------------------------ | ------------------------------------------------ |
| 1    | アプリを起動                         | ログイン画面が表示される                         |
| 2    | 「Googleでログイン」ボタンをクリック | 外部ブラウザでGoogle認証画面が開く               |
| 3    | ブラウザで「キャンセル」をクリック   | アプリにリダイレクトされる                       |
| 4    | アプリを確認                         | 「認証がキャンセルされました」エラーが表示される |

### シナリオ 3: Supabase未設定時のエラー

| 手順 | 操作                                 | 期待結果                                     |
| ---- | ------------------------------------ | -------------------------------------------- |
| 1    | 環境変数を削除/無効化                | -                                            |
| 2    | アプリを起動                         | ログイン画面が表示される                     |
| 3    | 「Googleでログイン」ボタンをクリック | エラーメッセージが表示される（UIまたはログ） |
| 4    | エラー内容を確認                     | AUTH_NOT_CONFIGURED関連のエラー              |

### シナリオ 4: セッション復元

| 手順 | 操作                                  | 期待結果                           |
| ---- | ------------------------------------- | ---------------------------------- |
| 1    | シナリオ1を完了してログイン状態にする | ログイン状態                       |
| 2    | アプリを完全に終了                    | -                                  |
| 3    | アプリを再起動                        | 自動的にログイン状態が復元される   |
| 4    | ユーザー情報を確認                    | 前回と同じユーザー情報が表示される |

### シナリオ 5: 複数回初期化の安定性

| 手順 | 操作                   | 期待結果                                           |
| ---- | ---------------------- | -------------------------------------------------- |
| 1    | 開発者ツールを開く     | コンソールが表示される                             |

| 3    | コンソールログを確認   | "Registering auth state change listener" が1回のみ |
