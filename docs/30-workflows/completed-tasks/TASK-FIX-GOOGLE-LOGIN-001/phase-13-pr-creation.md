## 実行タスク

### タスク1: ローカル動作確認依頼【必須】

**目的**: ユーザーにローカルでの動作確認を依頼する

**実行手順**:

1. 変更内容のサマリーを提示する
2. ユーザーにローカルでの動作確認を依頼する
3. 確認結果を待つ

**期待される成果物**:

- ユーザー確認結果

---

### タスク2: 変更サマリー提示と許可確認【必須】

**目的**: PR作成の許可を得る

**実行手順**:

1. 変更ファイル一覧を提示する
2. 変更内容のサマリーを説明する
3. PRを作成してよいか明示的に確認する

**期待される成果物**:

- ユーザー許可

**重要**: ユーザーから明示的な許可を得るまでPR作成を実行しないこと。

---

### タスク3: PR作成

**目的**: Pull Requestを作成する

**実行手順**:

1. ユーザーの許可を得た後、`/ai:diff-to-pr` を実行する
2. または手動でコミット・PR作成を行う

**期待される成果物**:

- Pull Request

---

### タスク4: CI確認

**目的**: CIが通過したことを確認する

**実行手順**:

1. PRのCIステータスを確認する
2. 失敗している場合は原因を特定し修正する
3. 成功したらユーザーに報告する

**期待される成果物**:

- CI成功確認
