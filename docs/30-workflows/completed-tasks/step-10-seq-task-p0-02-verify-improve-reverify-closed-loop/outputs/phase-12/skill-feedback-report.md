# Phase 12 Task 12-5: スキルフィードバック

## 作成日: 2026-03-30

## task-specification-creator スキルへの改善案

### 改善案 1: Phase 依存関係の自動検出

- **現状**: 各 Phase の依存は手動で artifacts.json に記述
- **提案**: Phase の inputs/outputs を解析して依存関係を自動検出する機能
- **理由**: Phase 3→4 のような直列依存は仕様書から推定可能

### 改善案 2: fail-first テスト実行の自動化

- **現状**: Phase 4（テスト作成）後に手動でテスト実行して fail を確認
- **提案**: Phase 4 完了時に自動でテスト実行し、全テストが fail であることを assert する step
- **理由**: fail-first の確認は重要だが手動だと忘れがち

### 改善案 3: リファクタリング判断の基準明確化

- **現状**: Phase 8 で「リファクタリングすべきか」の判断基準が曖昧
- **提案**: 「共通ロジック3行以上」「メソッド30行以上」など具体的な閾値を設定
- **理由**: 本タスクではリファクタリング見送りが妥当だったが、判断に時間を要した
