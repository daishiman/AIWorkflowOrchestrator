## 1. スコープ内 (In Scope)

### 1.1 実装対象ファイル

| ファイル                   | 変更内容               |
| -------------------------- | ---------------------- |
| `.github/workflows/ci.yml` | coverageジョブを追加   |
| `codecov.yml`              | 新規作成 - Codecov設定 |

### 1.2 実装機能

| 機能               | 説明                                    |
| ------------------ | --------------------------------------- |
| coverageジョブ追加 | testジョブ後にカバレッジをCodecovに送信 |
| 閾値チェック       | 80%未満でCIを失敗                       |
| Codecov統合        | ダッシュボードでカバレッジ可視化        |
| PRコメント         | カバレッジ差分を自動コメント            |

### 1.3 設定変更

| 設定項目                | 値   |
| ----------------------- | ---- |
| Project coverage target | 80%  |
| Patch coverage target   | 80%  |
| fail_ci_if_error        | true |
| Codecov Action version  | v5   |

---

## 2. スコープ外 (Out of Scope)

### 2.1 変更しないもの

| 項目                            | 理由                         |
| ------------------------------- | ---------------------------- |
| 既存のlint/typecheck/testジョブ | 既存機能は維持               |
| Vitest設定ファイル              | 既存の閾値設定は変更しない   |
| テストコードの追加              | カバレッジ達成は別タスク     |
| GitHub Actions以外のCI          | 現在はGitHub Actionsのみ対象 |

### 2.2 将来のタスク候補

| 項目                     | 優先度 | 備考                         |
| ------------------------ | ------ | ---------------------------- |
| カバレッジバッジの追加   | 低     | READMEにバッジを表示         |
| ブランチ別カバレッジ追跡 | 低     | mainブランチの推移を追跡     |
| カバレッジ低下アラート   | 中     | Slackなどに通知              |
| パッケージ別フラグ設定   | 中     | shared/desktopを分離レポート |

## 3. 前提条件

### 3.1 技術的前提

| 前提条件                  | 現状                          |
| ------------------------- | ----------------------------- |
| pnpm test:coverage が動作 | ✅ 動作確認済み               |
| lcovレポートが出力される  | ✅ vitest.config.tsで設定済み |
| GitHub Secretsが使用可能  | ✅ リポジトリ設定で利用可能   |

### 3.2 外部依存

| 依存サービス   | 用途             | 必要な設定        |
| -------------- | ---------------- | ----------------- |
| Codecov        | カバレッジ可視化 | アカウント登録    |
| GitHub Secrets | トークン管理     | CODECOV_TOKEN設定 |

---

## 4. 制約事項

### 4.1 技術的制約

| 制約                           | 影響                     |
| ------------------------------ | ------------------------ |
| GitHub Actionsのジョブ依存関係 | coverageはtestの後に実行 |
| Codecovの無料プラン制限        | Private repoは制限あり   |

### 4.2 時間的制約

| 制約                  | 対応                   |
| --------------------- | ---------------------- |
| coverageジョブ5分以内 | タイムアウト設定で制御 |

---

## 5. 成功基準

### 5.1 最小成功基準 (MVP)

- [ ] coverageジョブがCIに追加されている
- [ ] カバレッジ80%未達でPRがブロックされる
- [ ] Codecovにレポートがアップロードされる

### 5.2 完全成功基準

- [ ] MVP基準を全て満たす
- [ ] PRにCodecovコメントが表示される
- [ ] 既存CIジョブに影響がない
- [ ] ドキュメントが更新されている

---

## 6. リスクと軽減策

| リスク                    | 影響度 | 軽減策                         |
| ------------------------- | ------ | ------------------------------ |
| Codecovサービス障害       | 中     | fail_ci_if_error設定で制御可能 |
| 現在のカバレッジが80%未満 | 高     | 実装前にテスト追加で対応       |
| トークン漏洩              | 高     | GitHub Secretsで安全に管理     |
