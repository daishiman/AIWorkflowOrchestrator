## 1. 機能要件 (Functional Requirements)

### FR-01: CIでカバレッジチェックを実行する

| 項目   | 内容                                                     |
| ------ | -------------------------------------------------------- |
| 要件ID | FR-01                                                    |
| 優先度 | 必須                                                     |
| 説明   | GitHub Actions CIパイプラインでカバレッジを計測・検証    |
| 詳細   | testジョブ完了後にcoverageジョブを実行し、閾値をチェック |

### FR-02: 閾値未達でPRをブロックする

| 項目   | 内容                                           |
| ------ | ---------------------------------------------- |
| 要件ID | FR-02                                          |
| 優先度 | 必須                                           |
| 説明   | カバレッジが閾値未満の場合、PRマージをブロック |
| 詳細   | `fail_ci_if_error: true` でCIを失敗させる      |

### FR-03: Codecovでカバレッジを可視化する

| 項目   | 内容                                      |
| ------ | ----------------------------------------- |
| 要件ID | FR-03                                     |
| 優先度 | 必須                                      |
| 説明   | Codecovダッシュボードでカバレッジを表示   |
| 詳細   | カバレッジレポートをCodecovにアップロード |

### FR-04: PRにカバレッジ差分をコメントする

| 項目   | 内容                                    |
| ------ | --------------------------------------- |
| 要件ID | FR-04                                   |
| 優先度 | 推奨                                    |
| 説明   | PRにカバレッジの変化を自動コメント      |
| 詳細   | Codecov botが差分レポートをPRにコメント |

## 2. 非機能要件 (Non-Functional Requirements)

### NFR-01: パフォーマンス

| 項目     | 内容                              |
| -------- | --------------------------------- |
| 要件ID   | NFR-01                            |
| 優先度   | 必須                              |
| 説明     | カバレッジチェックは5分以内に完了 |
| 計測方法 | GitHub Actionsのジョブ実行時間    |

### NFR-02: セキュリティ

| 項目   | 内容                                     |
| ------ | ---------------------------------------- |
| 要件ID | NFR-02                                   |
| 優先度 | 必須                                     |
| 説明   | Codecovトークンは安全に管理              |
| 詳細   | GitHub Secretsを使用し、ログに出力しない |

### NFR-03: 互換性

| 項目   | 内容                                         |
| ------ | -------------------------------------------- |
| 要件ID | NFR-03                                       |
| 優先度 | 必須                                         |
| 説明   | 既存のCIジョブに影響を与えない               |
| 詳細   | lint, typecheck, test, buildジョブが正常動作 |

### NFR-04: 保守性

| 項目   | 内容                        |
| ------ | --------------------------- |
| 要件ID | NFR-04                      |
| 優先度 | 推奨                        |
| 説明   | 設定が集約され、変更が容易  |
| 詳細   | codecov.ymlで閾値を一元管理 |

## 3. 現状分析

### 3.1 現行CI構成

```
push/PR
    ↓
┌─────────┬───────────┬──────────┬──────────┐
│  lint   │ typecheck │   test   │ security │
└────┬────┴─────┬─────┴────┬─────┴────┬─────┘
     │          │          │          │
     └──────────┴────┬─────┴──────────┘
                     ↓
               ┌──────────┐
               │  build   │ (needs: lint, typecheck, test)
               └──────────┘
```

### 3.2 現行カバレッジ設定

| パッケージ | lines | functions | branches | statements |
| ---------- | ----- | --------- | -------- | ---------- |
| shared     | 65%   | 80%       | 60%      | 65%        |
| desktop    | 80%   | 80%       | 60%      | 80%        |

### 3.3 現行の問題点

1. `pnpm test:coverage` は `continue-on-error: true` で実行されている
2. カバレッジ失敗がPRをブロックしない
3. カバレッジの可視化がない
4. カバレッジの推移が追跡できない
