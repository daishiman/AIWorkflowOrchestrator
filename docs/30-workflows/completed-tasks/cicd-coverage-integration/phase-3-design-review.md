## 目的

実装開始前に要件・設計の妥当性を検証し、手戻りを防止する。

## 背景

CI/CDワークフローの変更は本番環境のビルドプロセスに直接影響するため、設計段階での十分な検証が重要。

## 判定基準

| 判定     | 条件                     | 次のアクション               |
| -------- | ------------------------ | ---------------------------- |
| PASS     | 全レビュー観点で問題なし | Phase 4へ進行                |
| MINOR    | 軽微な指摘あり           | 指摘対応後、Phase 4へ進行    |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻り先を決定 |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認    |

### 戻り先決定基準

| 問題の種類 | 戻り先              |
| ---------- | ------------------- |
| 要件の問題 | Phase 1（要件定義） |
| 設計の問題 | Phase 2（設計）     |
