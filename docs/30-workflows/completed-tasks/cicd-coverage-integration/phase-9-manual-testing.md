## テスト実行手順

### 事前準備

1. **Codecovアカウント設定**
   - Codecov (https://codecov.io) にサインイン
   - リポジトリを連携
   - CODECOV_TOKENを取得

2. **GitHub Secrets設定**
   - Settings → Secrets and variables → Actions
   - CODECOV_TOKEN を追加

3. **ブランチ作成**
   ```bash
   git checkout -b feature/cicd-coverage-integration
   git push -u origin feature/cicd-coverage-integration
   ```
