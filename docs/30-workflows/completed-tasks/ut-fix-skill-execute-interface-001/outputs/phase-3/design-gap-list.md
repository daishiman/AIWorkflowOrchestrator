## MINOR ギャップの詳細

### DG-01: prompt バリデーション未実施

- **現状**: skillNameパスでは `args.skillName` のP42バリデーションのみ実施。`args.prompt` は型チェック・空文字列チェックなし（`skillHandlers.ts:265-266` で `{ prompt: args.prompt }` として直接渡し）
- **リスク**: `prompt: null`, `prompt: 123`, `prompt: ""`, `prompt: "   "` がService層に到達
- **対応方針**:
  - Phase 4: prompt不正入力のテストケースを設計（EXE-VAL-06〜EXE-VAL-09相当）
  - Phase 5: promptのP42準拠3段バリデーション追加を実装計画に含める
- **未解消時の手戻り先**: Phase 2（バリデーション設計の修正）
- **関連GAP**: GAP-04
- **関連リスク**: R-03, R-07

### DG-02: workingDirectory バリデーション規約未定義

- **現状**: `workingDirectory` はオプショナルフィールドとして型定義されているが、Handlerでの検証規約なし（`packages/shared/src/types/skill.ts:306-315` の型定義のみ）
- **リスク**: パストラバーサル攻撃の入り口になる可能性（ただし、Executorレベルでのサンドボックス保護がある場合は影響限定的）
- **対応方針**:
  - Phase 6: workingDirectoryの境界値テスト（存在しないパス、相対パス、パストラバーサルパターン）を追加
  - セキュリティ観点で優先度を再評価
- **未解消時の手戻り先**: Phase 2（セキュリティ設計の追加）
- **関連GAP**: なし（Phase 3で新規検出）
- **関連リスク**: なし（risk-register.md への追加を検討）
