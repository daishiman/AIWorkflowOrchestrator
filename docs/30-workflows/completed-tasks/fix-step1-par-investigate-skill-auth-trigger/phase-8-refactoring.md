- [ ] `[TEMP DEBUG]` コメントが残っていないこと

### 重複チェック

| 確認観点                                 | 方法                                           |
| ---------------------------------------- | ---------------------------------------------- |
| 複数箇所に同じ条件チェックが散在         | `grep` で修正内容の重複を確認する              |
| 既存の auth チェックと修正の二重チェック | 既存の認証ガードと修正の論点が重複していないか |
