## 目的

Phase 5 の修正後、エッジケースと境界条件をカバーするテストを追加する。
特に、修正による意図しない副作用（正当な `auth:login` 呼び出しへの影響）を防ぐためのテストを補充する。

## 追加テストケース

### TC-05: 未ログイン状態でのスキル生成試行

| 項目     | 内容                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| テスト名 | `skill generation prompts auth when user is not logged in`                                     |
| 対象     | スキル生成フロー（認証チェック部分）                                                           |
| 前提条件 | ユーザーは未ログイン状態                                                                       |
| 操作     | スキル生成ボタンを押下                                                                         |
| 期待結果 | 適切なエラーメッセージまたは認証誘導が表示されること                                           |
| 理由     | 修正で「ログイン済み時のみ不要呼び出しを抑制」した場合、未ログイン時に認証が機能することを確認 |

### TC-06: 連続してスキル生成ボタンを押下した場合

| 項目     | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| テスト名 | `rapid skill generation clicks do not trigger multiple auth:login` |
| 対象     | スキル生成フロー（二重呼び出し防止）                               |
| 前提条件 | ユーザーはログイン済み状態                                         |
| 操作     | スキル生成ボタンを短時間に複数回押下                               |
| 期待結果 | `auth:login` が複数回呼ばれないこと                                |
| 理由     | 修正後の呼び出し回数が適切に制御されていることを確認               |

### TC-07: useEffect 依存配列が修正された場合の再レンダリング検証

| 項目     | 内容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| テスト名 | `auth:login is not triggered on component re-render during skill flow` |
| 対象     | 修正されたコンポーネント（Phase 5 で特定）                             |
| 前提条件 | ユーザーはログイン済み・スキル生成フロー実行中                         |
| 操作     | コンポーネントの状態が更新される（ストリーミング進捗更新等）           |
| 期待結果 | 再レンダリング時に `auth:login` が呼ばれないこと                       |
| 理由     | useEffect 連鎖が修正後も再発しないことを確認                           |

### TC-08: authModeSlice の状態変化が auth:login を不要に呼ばないこと

| 項目     | 内容                                                               |
| -------- | ------------------------------------------------------------------ |
| テスト名 | `authModeSlice state changes do not trigger unexpected auth:login` |
| 対象     | `apps/desktop/src/renderer/store/slices/authModeSlice.ts`          |
| 前提条件 | ユーザーはログイン済み状態                                         |
| 操作     | authMode が切り替わる                                              |
| 期待結果 | スキル生成と無関係な authMode 変化で `auth:login` が呼ばれないこと |
| 理由     | authModeSlice が副作用の一因だった場合の回帰確認                   |
