## 目的

修正後の動作を Electron アプリで実際に操作して確認する。
自動テストでは検証しにくい「タイムアウトエラーが発生しないこと」を手動で確認する。

## 手動テスト手順

### 前提条件

- Electron アプリが起動できること
- ユーザーがログイン済みであること
- 有効な API キーが設定されていること

### 起動手順

```bash
pnpm --filter @repo/desktop dev
```

### テストケース

#### MTC-01: スキル生成フローの正常完了確認

| 手順 | 操作内容                      | 期待結果                                    |
| ---- | ----------------------------- | ------------------------------------------- |
| 1    | Electron アプリを起動する     | アプリが正常に表示される                    |
| 2    | スキル生成画面を開く          | 画面が正常に表示される                      |
| 3    | スキル生成ボタンを押下する    | `auth:login` タイムアウトエラーが発生しない |
| 4    | スキル生成が完了するまで待つ  | エラーなく生成が完了する                    |
| 5    | DevTools コンソールを確認する | `auth:login` 関連のエラーログがないこと     |

#### MTC-02: AccountSection からのログイン動作確認

| 手順 | 操作内容                              | 期待結果                          |
| ---- | ------------------------------------- | --------------------------------- |
| 1    | 一度ログアウトする                    | ログアウト状態になる              |
| 2    | AccountSection のログインボタンを押下 | `auth:login` IPC が正常に呼ばれる |
| 3    | ログイン処理が完了する                | ユーザーがログイン状態になる      |

#### MTC-03: デバッグコード痕跡の非存在確認

| 手順 | 操作内容                   | 期待結果                                  |
| ---- | -------------------------- | ----------------------------------------- |
| 1    | DevTools コンソールを開く  | コンソールにデバッグ出力がないこと        |
| 2    | スキル生成ボタンを押下する | `[TRACE-SKILL-AUTH-001]` の出力がないこと |
