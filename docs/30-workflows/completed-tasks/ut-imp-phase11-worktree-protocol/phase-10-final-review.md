## 目的

実装完了後、8 項目のレビュー観点で全体的な品質・整合性を最終検証し、Phase 11 への進行可否を判定する。

## 背景

Phase 9 で品質ゲートを通過した Worktree 環境テストプロトコル（E2E テストスクリプト、CI/CD ワークフロー、プロトコル文書、テンプレート）に対して、要件充足・設計整合性・テストカバレッジ・コード品質・セキュリティ・CI/CD 統合・ドキュメント整合性・3 層テスト分類の妥当性の 8 観点から最終検証を行う。

## 判定基準

| 判定     | 条件             | 対応                                                   |
| -------- | ---------------- | ------------------------------------------------------ |
| PASS     | 全観点で問題なし | Phase 11 へ進行                                        |
| MINOR    | 軽微な指摘あり   | 未タスク仕様書に変換後 Phase 11 へ進行（**省略不可**） |
| MAJOR    | 重大な問題あり   | 影響範囲に応じて戻り先を決定（下記テーブル参照）       |
| CRITICAL | 致命的な問題あり | Phase 1 へ戻りユーザーと要件を再確認                   |

### MAJOR 判定時の戻り先決定基準

| 問題カテゴリ         | 戻り先  | 例                                           |
| -------------------- | ------- | -------------------------------------------- |
| 要件の不備・認識齟齬 | Phase 1 | Worktree 環境での制約定義が不完全            |
| 設計上の欠陥         | Phase 2 | 3 層テスト構造の設計に構造的問題             |
| テスト設計不足       | Phase 4 | 重要な E2E テストシナリオの欠如              |
| 実装品質の問題       | Phase 5 | Worktree 判定ロジックの根本的な欠陥          |
| セキュリティ問題     | Phase 1 | E2E テストがセキュリティ設定を無効化している |
