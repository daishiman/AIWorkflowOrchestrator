## ステータス定義

<!-- パーサー（deferred-tests-parser.ts）は「完了」「対応不要」「対象外」を allResolved 判定の解消済みステータスとして扱う。
     パーサーとの整合性を維持するため、ステータス値を変更する場合はパーサーも同時に更新すること。 -->

| ステータス | 説明                                   | パーサー判定 |
| ---------- | -------------------------------------- | ------------ |
| 未実施     | まだテストを実行していない             | 未解消       |
| 実施中     | メインリポジトリまたはCIで実行中       | 未解消       |
| 完了       | テスト実行が完了し、結果を確認済み     | 解消済み     |
| 対応不要   | テスト内容の変更により実施不要になった | 解消済み     |
