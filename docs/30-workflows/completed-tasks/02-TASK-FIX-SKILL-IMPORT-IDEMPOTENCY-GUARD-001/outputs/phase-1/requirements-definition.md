# Phase 1 要件定義書

## タスク

- スキル再インポート時の冪等化ガード

## 機能要件

- 既にインポート済みのスキルでエラーを返さず、同一操作を安全に再実行できるようにする。
- 失敗再現条件を固定し、回帰テストで検証可能にする。

## 非機能要件

- 関心ごとの分離: Main/IPC/Rendererの責務境界を維持する。
- 回帰耐性: 既存契約を壊さず互換性を保つ。

## 問題定義

- skill:importハンドラとagentSliceが再実行時エラー扱いになり、UXと状態整合が崩れる。

## 完了判定

- 要件がテスト可能な文に分解されていること。
- 対象ファイル境界が明文化されていること。
