## 1. テスト環境

### 1.1 テスト方式

GraphRAGQueryServiceは依存性注入（DI）パターンを採用しており、以下のプロバイダーをモックとして実行しています：

| 依存関係             | モック方式   | 理由                   |
| -------------------- | ------------ | ---------------------- |
| ICommunitySummarizer | Vitestモック | 外部サービス依存を排除 |
| IQueryClassifier     | Vitestモック | 分類ロジックを固定化   |
| ILLMProvider         | Vitestモック | LLM API呼び出しを模擬  |
| IEmbeddingProvider   | Vitestモック | 埋め込み生成を模擬     |

### 1.2 環境変数確認

| 環境変数          | 設定状況 | 説明                 |
| ----------------- | -------- | -------------------- |
| LLM_API_KEY       | N/A      | モック使用のため不要 |
| EMBEDDING_API_KEY | N/A      | モック使用のため不要 |

**注記**: 本実装はDIパターンにより、実際のプロバイダーを注入することで本番環境でも動作します。
