## 1. 概要

### 1.1 目的

CONV-08-03で実装されたコミュニティ要約機能（`ICommunitySummarizer.searchSummaries()`）をGraphRAGクエリ処理フローに統合し、コミュニティ要約を活用した高品質な回答生成を実現する。

### 1.2 背景

現状では、コミュニティ要約は生成・保存されているが、実際のクエリ応答には活用されていない。本機能により、グラフ全体の構造情報を回答生成に反映させることが可能となる。

### 1.3 スコープ

| スコープ内                               | スコープ外                         |
| ---------------------------------------- | ---------------------------------- |
| コミュニティ要約のセマンティック検索統合 | コミュニティ検出アルゴリズムの改善 |
| 検索結果のプロンプトへの統合             | 要約生成ロジックの変更             |
| 階層レベルフィルタリング                 | リアルタイム要約更新               |
| confidence閾値フィルタリング             | 新規UIコンポーネント作成           |
| 結果数制限（limit）                      | バッチ処理・並列クエリ最適化       |
| フォールバック処理                       | キャッシング戦略                   |

## 2. システム仕様との整合性確認

### 2.1 ICommunitySummarizer インターフェース

**確認済みメソッド**: `searchSummaries(query, options?)`

| 項目       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| 入力       | query: string, options?: CommunitySummarySearchOptions |
| 出力       | Result<CommunitySummary[], Error>                      |
| オプション | limit: number (default: 10), level?: number            |

**CommunitySummary型**（主要プロパティ）:

- `communityId: CommunityId`
- `level: number`
- `summary: string`
- `keywords: string[]`
- `mainEntities: string[]`
- `confidence: number` (0.0〜1.0)
- `embedding: number[]?`

### 2.2 既存検索型定義

**SearchResultType**: `chunk | entity | community`

- `community` タイプは既に定義済み

**IQueryClassifier**: クエリ分類機能は実装済み

- `classify()`: クエリタイプ判定
- `getSearchWeights()`: タイプ別検索重み取得

### 2.3 既存実装パターン

| パターン      | 適用                                                   |
| ------------- | ------------------------------------------------------ |
| Result<T, E>  | 全ての非同期操作でResult型によるエラーハンドリング     |
| Branded Types | CommunityId等の型安全なID                              |
| Zodスキーマ   | ランタイムバリデーション                               |
| DIパターン    | コンストラクタでの依存性注入（ICommunitySummarizer等） |

## 3. 機能要件

### 3.1 コア機能要件

| ID     | 要件                         | 優先度 | 説明                                                          |
| ------ | ---------------------------- | ------ | ------------------------------------------------------------- |
| FR-001 | セマンティック検索統合       | 必須   | クエリからコミュニティ要約をセマンティック検索                |
| FR-002 | コンテキスト統合             | 必須   | 取得した要約を回答生成プロンプトに統合                        |
| FR-003 | 階層レベルフィルタリング     | 推奨   | 特定レベルのコミュニティのみ検索可能（communityLevel option） |
| FR-004 | スコアベースランキング       | 必須   | 類似度スコアによる検索結果のランキング                        |
| FR-005 | confidence閾値フィルタリング | 推奨   | 低confidence要約の除外オプション（confidenceThreshold）       |
| FR-006 | 検索結果数制限               | 必須   | 最大取得件数（limit）のサポート（1-20）                       |
| FR-007 | フォールバック処理           | 必須   | 要約なし/検索エラー時の通常回答生成へのフォールバック         |

### 3.2 データフロー

```
ユーザークエリ
    ↓
┌─────────────────────────────────┐
│ GraphRAGQueryService.query()   │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ IQueryClassifier.classify()    │ → クエリタイプ判定
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ ICommunitySummarizer           │
│   .searchSummaries()           │ → コミュニティ要約検索
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ confidence閾値フィルタリング   │ → 低confidence除外
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ プロンプト構築                 │ → 要約をコンテキストに統合
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│ ILLMProvider.chat()            │ → 回答生成
└─────────────────────────────────┘
    ↓
GraphRAGQueryResponse
```

### 3.3 入出力仕様

#### 入力

```typescript
interface GraphRAGQueryInput {
  query: string; // ユーザークエリ（空文字不可）
  options?: GraphRAGQueryOptions; // オプション（省略可）
}

interface GraphRAGQueryOptions {
  limit?: number; // 最大検索結果数（1-20, default: 10）
  communityLevel?: number; // コミュニティ階層レベル（0-5）
  confidenceThreshold?: number; // confidence閾値（0-1, default: 0.5）
  searchWeights?: SearchWeights; // 検索戦略の重み
  enableCommunitySummary?: boolean; // コミュニティ要約検索を有効化（default: true）
}
```

#### 出力

```typescript
interface GraphRAGQueryResponse {
  answer: string; // 生成された回答テキスト
  communitySummaries: CommunitySummaryReference[]; // 参照したコミュニティ要約
  chunks: ChunkReference[]; // 参照したチャンク
  entities: EntityReference[]; // 参照したエンティティ
  metadata: QueryMetadata; // 処理メタデータ
}

interface CommunitySummaryReference {
  communityId: CommunityId;
  level: number;
  summary: string;
  confidence: number;
  relevanceScore: number;
}
```

## 4. 非機能要件

### 4.1 パフォーマンス要件

| 項目               | 要件                 | 基準                             |
| ------------------ | -------------------- | -------------------------------- |
| 検索レイテンシ     | 要約検索時間         | < 100ms（limit=10の場合）        |
| コンテキスト長制限 | プロンプトトークン数 | 既存制限内に収まること           |
| 並行リクエスト     | 同時クエリ処理       | 既存パフォーマンスを劣化させない |

### 4.2 型安全性要件

| 項目          | 要件               | 基準                            |
| ------------- | ------------------ | ------------------------------- |
| Branded Types | CommunityId使用    | 既存パターンに準拠              |
| Result型      | エラーハンドリング | success/data/errorパターン      |
| 厳密な型定義  | any型禁止          | TypeScript strict mode準拠      |
| Zodスキーマ   | 入力バリデーション | 全入力に対してZodスキーマを定義 |

### 4.3 テスタビリティ要件

| 項目             | 要件                 | 基準                                      |
| ---------------- | -------------------- | ----------------------------------------- |
| DI対応           | インターフェース注入 | ICommunitySummarizer注入可能              |
| モック可能性     | 外部依存のモック化   | ILLMProvider/IEmbeddingProviderモック可能 |
| 単体テスト可能性 | 純粋関数の分離       | 副作用を持つ処理の分離                    |

### 4.4 セキュリティ要件

| 項目           | 要件                 | 基準                            |
| -------------- | -------------------- | ------------------------------- |
| 入力検証       | クエリサニタイズ     | Zodスキーマによるバリデーション |
| プロンプト構築 | インジェクション対策 | ユーザー入力のエスケープ処理    |

## 5. 統合テスト接続要件

### 5.1 API接続要件

| 接続ポイント         | 要件                             |
| -------------------- | -------------------------------- |
| ICommunitySummarizer | searchSummaries()の正常呼び出し  |
| IQueryClassifier     | classify()によるクエリタイプ判定 |
| ILLMProvider         | chat()による回答生成             |
| IEmbeddingProvider   | クエリ埋め込み生成               |

### 5.2 データフロー要件

| フロー                      | 検証内容                           |
| --------------------------- | ---------------------------------- |
| クエリ → 分類               | クエリタイプが正しく判定される     |
| 分類 → 検索                 | タイプに応じた検索重みが適用される |
| 検索 → フィルタリング       | confidence閾値が適用される         |
| フィルタリング → プロンプト | 要約がプロンプトに統合される       |
| プロンプト → 回答生成       | 要約を反映した回答が生成される     |

### 5.3 エラーハンドリング要件

| エラーケース         | 対応                             |
| -------------------- | -------------------------------- |
| コミュニティ検索失敗 | 空配列でフォールバック、処理継続 |
| LLM生成失敗          | エラー返却                       |
| バリデーション失敗   | エラー返却                       |
| 埋め込み生成失敗     | エラー返却                       |

## 6. 受け入れ基準

### 6.1 機能テストシナリオ

| ID   | シナリオ                           | 期待結果                             |
| ---- | ---------------------------------- | ------------------------------------ |
| AC01 | 関連コミュニティが存在するクエリ   | 要約がコンテキストに含まれた回答生成 |
| AC02 | 関連コミュニティがないクエリ       | 通常の回答生成（フォールバック）     |
| AC03 | communityLevel指定検索             | 指定レベルの要約のみ返される         |
| AC04 | 複数コミュニティがマッチするクエリ | スコア順でランキングされた結果       |
| AC05 | confidenceThreshold指定            | 閾値未満の要約が除外される           |
| AC06 | limit指定による結果数制限          | 指定件数以下の結果が返される         |
| AC07 | enableCommunitySummary=false       | コミュニティ要約検索がスキップされる |
| AC08 | 空クエリ                           | バリデーションエラー                 |
| AC09 | 無効なオプション値                 | バリデーションエラー                 |
