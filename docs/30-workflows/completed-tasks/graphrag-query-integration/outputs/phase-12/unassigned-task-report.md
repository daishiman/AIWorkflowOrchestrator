## 3. 検出された未タスク一覧

### 3.1 IMP-01: クエリタイプ別プロンプトテンプレート拡張

- **検出元**: Phase 11 手動テストレポート
- **内容**: クエリタイプ（global/local/hybrid）に応じたプロンプトテンプレートの最適化
- **優先度**: 低
- **見積もり**: 中
- **対応予定**: 将来リリース
- **指示書作成**: 不要（低優先度のため）

**詳細**:
現在の実装では全クエリタイプで同一のプロンプトテンプレートを使用している。グローバルクエリでは要約を重視し、ローカルクエリでは詳細情報を重視するなど、クエリタイプ別の最適化が可能。

### 3.2 IMP-02: 検索結果のスコアリングアルゴリズム改善

- **検出元**: Phase 11 手動テストレポート
- **内容**: コミュニティ要約の関連度スコア算出方法の改善
- **優先度**: 低
- **見積もり**: 中
- **対応予定**: 将来リリース
- **指示書作成**: 不要（低優先度のため）

**詳細**:
現在はconfidenceをそのままrelevanceScoreとして使用している。クエリとの意味的類似度を考慮したスコアリングアルゴリズムの導入で精度向上が期待できる。

### 3.3 IMP-03: キャッシング機能追加

- **検出元**: Phase 11 手動テストレポート
- **内容**: 頻出クエリに対するキャッシング機能の追加
- **優先度**: 低
- **見積もり**: 中
- **対応予定**: スコープ外
- **指示書作成**: 不要（スコープ外のため）

**詳細**:
同一または類似クエリの結果をキャッシュすることでパフォーマンスを最適化できる。ただし、コミュニティ要約が更新された場合のキャッシュ無効化戦略が必要。
