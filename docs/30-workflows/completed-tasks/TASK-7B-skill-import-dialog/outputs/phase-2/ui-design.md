## インタラクション定義

### 操作一覧

| 操作                 | 動作                    | 詳細                                                           |
| -------------------- | ----------------------- | -------------------------------------------------------------- |
| オーバーレイクリック | 閉じない                | 誤操作防止のため、オーバーレイクリックではダイアログを閉じない |
| ESCキー              | `onClose()` を呼ぶ      | キーボードによるダイアログ閉鎖                                 |
| インポートボタン     | `handleImport()` を呼ぶ | インポート処理を開始し、完了後にダイアログを閉じる             |
| キャンセルボタン     | `onClose()` を呼ぶ      | ダイアログを即座に閉じる                                       |
| ×ボタン（閉じる）    | `onClose()` を呼ぶ      | ヘッダー右上のボタンでダイアログを閉じる                       |

### インポートボタンの状態遷移

```
[通常] ── クリック ──> [ローディング中] ── 完了 ──> [ダイアログ閉鎖]
                           │
                           ├── テキスト: "インポート中..." に変化
                           ├── disabled: true
                           └── スピナーアイコン表示
```

| 状態         | テキスト        | 操作可否 | 視覚表示                   |
| ------------ | --------------- | -------- | -------------------------- |
| 通常         | インポート      | 有効     | 青色背景、ホバー効果あり   |
| ローディング | インポート中... | 無効     | 薄い青色背景、スピナー表示 |

### キャンセルボタンの状態

| 状態         | 操作可否 | 備考                             |
| ------------ | -------- | -------------------------------- |
| 通常         | 有効     | ダイアログを閉じる               |
| インポート中 | 無効     | インポート処理中はキャンセル不可 |

## アクセシビリティ設計

### ARIA属性

| 属性              | 対象要素         | 値                            | 目的                                   |
| ----------------- | ---------------- | ----------------------------- | -------------------------------------- |
| `role`            | DialogContainer  | `"dialog"`                    | ダイアログとしてのセマンティクスを付与 |
| `aria-modal`      | DialogContainer  | `"true"`                      | モーダルダイアログであることを示す     |
| `aria-labelledby` | DialogContainer  | `"skill-import-dialog-title"` | ダイアログのラベルをタイトルに関連付け |
| `aria-label`      | CloseButton（×） | `"閉じる"`                    | アイコンボタンのアクセシブル名称       |

### フォーカス管理

#### フォーカストラップ

ダイアログが開いている間、フォーカスはダイアログ内の要素に制限される。

```
実装方法: useRef で最初と最後のフォーカス可能要素を管理
- 最初のフォーカス可能要素: 閉じる（×）ボタン
- 最後のフォーカス可能要素: インポートボタン
- Tab キーで最後の要素から最初の要素へ循環
- Shift+Tab キーで最初の要素から最後の要素へ循環
```

#### 初期フォーカス

ダイアログ表示時、キャンセルボタンに初期フォーカスを設定する。これにより、誤ってインポートボタンを押すことを防止する。

#### フォーカス復元

ダイアログ閉鎖時、ダイアログを開いたトリガー要素にフォーカスを復元する。

### キーボード操作

| キー      | 動作                                       |
| --------- | ------------------------------------------ |
| ESC       | `onClose()` を呼び、ダイアログを閉じる     |
| Tab       | 次のフォーカス可能要素へ移動（トラップ内） |
| Shift+Tab | 前のフォーカス可能要素へ移動（トラップ内） |
| Enter     | フォーカス中のボタンを実行                 |
| Space     | フォーカス中のボタンを実行                 |

### ESCキーハンドラー

```
実装方法: useEffect で keydown イベントリスナーを登録
- isOpen が true の場合のみリスナーをアクティブにする
- KeyboardEvent.key === "Escape" を検知
- onClose() コールバックを実行
- クリーンアップでリスナーを解除
```

### スクリーンリーダー対応

| 要件               | 実装                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| ダイアログタイトル | `<h2 id="skill-import-dialog-title">` で明示的にラベル付け           |
| ボタンラベル       | テキストボタンはラベル不要、アイコンボタンには `aria-label` を付与   |
| ローディング状態   | インポートボタンの `aria-disabled="true"` でスクリーンリーダーに通知 |
| セクション構造     | 見出し要素でセクション構造を明確化                                   |
