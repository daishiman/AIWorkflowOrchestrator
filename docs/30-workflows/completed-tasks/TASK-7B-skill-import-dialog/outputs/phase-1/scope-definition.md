## スコープ外（Out-of-Scope）

以下の項目は本タスク（TASK-7B）の実装範囲外とする。

| 項目                         | 理由                                                                           | 対応タスク/時期              |
| ---------------------------- | ------------------------------------------------------------------------------ | ---------------------------- |
| ダークモード対応             | デザインシステム全体のテーマ対応として別タスクで対応                           | 未定                         |
| スキル編集機能               | ダイアログはインポート確認用であり、編集UIは別コンポーネントで実装             | 別タスク                     |
| スキル削除機能               | 削除はインポート済みスキル管理画面で実装                                       | 別タスク                     |
| エラー詳細ダイアログ         | インポート失敗時のエラー表示は SkillSlice の `skillError` で管理（トースト等） | 別タスク                     |
| 国際化（i18n）対応           | 初期実装は日本語固定。多言語対応は全体のi18n対応時に実施                       | 未定                         |
| ドラッグ&ドロップ並べ替え    | サブリソースの表示順変更は不要                                                 | 対応予定なし                 |
| アニメーション               | ダイアログの開閉アニメーションは初期実装では対応しない                         | 後続タスクで検討             |
| otherFiles の表示            | `SkillMetadata.otherFiles` はインポート確認に不要と判断                        | 必要に応じて後続タスクで追加 |
| レスポンシブデザイン         | デスクトップアプリのため、モバイル対応は不要                                   | 対応予定なし                 |
| Mainプロセス / IPC通信の実装 | 本タスクはRenderer側のみ。IPC通信は SkillSlice（TASK-6-1）で実装済み           | TASK-6-1（実装済み）         |
