## 3. 未タスク詳細

### 3.1 IPC通信チャンネル設定

**概要**: Main ProcessのSkillCreatorServiceをRenderer Processから呼び出すためのIPCチャンネルを設定する。

**必要な作業**:

- `ipcMain.handle('skill:detectMode', ...)` の実装
- `ipcMain.handle('skill:createSkill', ...)` の実装
- `ipcMain.handle('skill:executeTasks', ...)` の実装
- `ipcMain.handle('skill:validateSkill', ...)` の実装
- preload.tsへのAPIエクスポート追加

**参照**:

- 既存IPCパターン: `apps/desktop/src/main/ipc/*.ts`
- preload設定: `apps/desktop/src/preload/index.ts`

### 3.2 UI統合（TASK-10A連携）

**概要**: SkillCreatorServiceをReact UIから使用するためのスライスとコンポーネントを実装する。

**必要な作業**:

- `skillCreatorSlice.ts` の作成
- スキル作成ウィザードUIの実装
- モード選択UIの実装
- タスク実行進捗表示UIの実装

**依存関係**:

- TASK-10A（UI基盤）の完了が前提

### 3.3 Claude Agent SDK本格統合

**概要**: collaborativeモードでClaude Agent SDKのquery() APIを使用し、対話的なスキル作成を実現する。

**必要な作業**:

- `runCollaborativeWorkflow()` の本格実装
- Hooksシステムとの統合
- ストリーミングレスポンス処理
- Permission Control統合

**参照**:

- Claude Agent SDKスキル: `.claude/skills/claude-agent-sdk/`

### 3.4 キャッシュ無効化の仕組み追加

**概要**: ResourceLoaderのキャッシュを選択的に無効化できるようにする。

**必要な作業**:

- `invalidateCache(key: string)` メソッド追加
- キャッシュTTL設定の追加（オプション）

### 3.5 タイムアウト設定の外部化

**概要**: ScriptExecutorのタイムアウト設定を外部から設定可能にする。

**必要な作業**:

- `constants.ts` にタイムアウト定数追加
- `execute()` メソッドにtimeoutオプション追加
- 設定ファイルからの読み込み対応
