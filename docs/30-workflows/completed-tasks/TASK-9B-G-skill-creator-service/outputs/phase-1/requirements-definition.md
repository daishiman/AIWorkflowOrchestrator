## 1. 機能要件（FR: Functional Requirements）

### FR-01: モード判定

| 項目       | 内容                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 要件ID     | FR-01                                                                                              |
| 要件名     | モード判定                                                                                         |
| 説明       | リクエスト内容から適切なモード（collaborative/orchestrate/create/update/improve-prompt）を判定する |
| 優先度     | 必須                                                                                               |
| 実装方法   | `detect_mode.js` スクリプトに委譲（Script First原則）                                              |
| 入力       | ユーザーリクエスト文字列                                                                           |
| 出力       | `SkillCreatorMode` 型の値                                                                          |
| エラー条件 | スクリプト実行失敗時                                                                               |

### FR-02: スキル作成

| 項目       | 内容                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 要件ID     | FR-02                                                                        |
| 要件名     | スキル作成                                                                   |
| 説明       | collaborative/orchestrate/createモードに応じたワークフローでスキルを作成する |
| 優先度     | 必須                                                                         |
| 実装方法   | モード分岐 → ワークフロー実行 → スキル構造生成 → SKILL.md生成 → 検証         |
| 入力       | `CreateSkillOptions` オブジェクト                                            |
| 出力       | スキルディレクトリパス                                                       |
| エラー条件 | 検証失敗時、スクリプト実行失敗時                                             |

### FR-03: タスク実行

| 項目       | 内容                                                        |
| ---------- | ----------------------------------------------------------- |
| 要件ID     | FR-03                                                       |
| 要件名     | タスク実行                                                  |
| 説明       | 依存関係を解決し、並列/逐次でタスクを実行する               |
| 優先度     | 必須                                                        |
| 実装方法   | タスクスキャン → 依存グラフ構築 → トポロジカルソート → 実行 |
| 入力       | `ExecuteTasksOptions` オブジェクト                          |
| 出力       | `ExecutionReport` オブジェクト                              |
| エラー条件 | 循環依存検出時、タスク実行失敗時                            |

### FR-04: スキル検証

| 項目       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| 要件ID     | FR-04                                                  |
| 要件名     | スキル検証                                             |
| 説明       | スキルディレクトリの構造・SKILL.md・スキーマを検証する |
| 優先度     | 必須                                                   |
| 実装方法   | `validate_all.js` スクリプトに委譲（Script First）     |
| 入力       | スキルディレクトリパス                                 |
| 出力       | boolean（成功/失敗）                                   |
| エラー条件 | 検証失敗時                                             |

### FR-05: スクリプト実行

| 項目       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 要件ID     | FR-05                                                        |
| 要件名     | スクリプト実行                                               |
| 説明       | scripts/配下のJavaScriptを決定論的に実行する（Script First） |
| 優先度     | 必須                                                         |
| 実装方法   | `child_process.spawn` でスクリプト実行                       |
| 入力       | スクリプト名、引数配列                                       |
| 出力       | `ScriptResult` オブジェクト                                  |
| エラー条件 | スクリプト不存在、実行エラー、タイムアウト                   |

### FR-06: リソース読み込み

| 項目       | 内容                                                                          |
| ---------- | ----------------------------------------------------------------------------- |
| 要件ID     | FR-06                                                                         |
| 要件名     | リソース読み込み                                                              |
| 説明       | agents/references/assets/schemas/を遅延読み込みする（Progressive Disclosure） |
| 優先度     | 必須                                                                          |
| 実装方法   | キャッシュ付きファイル読み込み                                                |
| 入力       | カテゴリ、リソース名                                                          |
| 出力       | リソース内容（string/object）                                                 |
| エラー条件 | ファイル不存在時                                                              |

### FR-07: 循環依存検出

| 項目       | 内容                                     |
| ---------- | ---------------------------------------- |
| 要件ID     | FR-07                                    |
| 要件名     | 循環依存検出                             |
| 説明       | タスク間の循環依存を検出してエラーとする |
| 優先度     | 必須                                     |
| 実装方法   | DFS（深さ優先探索）による循環検出        |
| 入力       | 依存関係グラフ                           |
| 出力       | 循環パス配列（空の場合は循環なし）       |
| エラー条件 | 循環検出時                               |

### FR-08: ドライラン

| 項目       | 内容                                        |
| ---------- | ------------------------------------------- |
| 要件ID     | FR-08                                       |
| 要件名     | ドライラン                                  |
| 説明       | 実行前に実行順序と見積もり時間を表示する    |
| 優先度     | 必須                                        |
| 実装方法   | `dryRun: true` オプションで実行計画のみ返却 |
| 入力       | `ExecuteTasksOptions` with `dryRun: true`   |
| 出力       | 実行計画（タスク順序、見積もり時間）        |
| エラー条件 | なし                                        |
