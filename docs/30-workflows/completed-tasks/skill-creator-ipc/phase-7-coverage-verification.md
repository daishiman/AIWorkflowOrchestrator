### Task 3: 未達時の対応

#### 3-1. 未達の場合（FAIL判定）

以下の手順でPhase 6への差し戻しを実施する:

1. 未カバーの行・ブランチ・関数を特定する
2. 追加すべきテストケースをテストID付きで列挙する
3. Phase 6のTask一覧に追加テストケースを記録する
4. Phase 6へ戻り、特定したテストケースを追加する

#### 3-2. 達成の場合（PASS判定）

1. カバレッジレポートを`outputs/phase-7/coverage-report.md`に保存する
2. 推奨基準に未達の指標がある場合、未カバー箇所をリストアップする
3. 未カバー箇所を改善余地として記録する（Phase 6差し戻しは不要）
4. Phase 8（リファクタリング）へ進行する

#### 3-3. カバレッジ例外（対象外）

以下のコードはカバレッジ対象外として許容する:

| 対象外コード                                         | 理由                       |
| ---------------------------------------------------- | -------------------------- |
| `if (process.env.NODE_ENV !== 'test')` 内のログ出力  | デバッグ専用コード         |
| 型ガード関数のTypeScript型推論専用ブランチ           | 実行時に到達しないブランチ |
| プラットフォーム固有の分岐（テスト環境で再現不可能） | Electron固有のAPI呼び出し  |
