## 機能要件（FR: Functional Requirements）

| ID    | 要件                                            | 優先度 | 対応AC              | 説明                                                                                      |
| ----- | ----------------------------------------------- | ------ | ------------------- | ----------------------------------------------------------------------------------------- |
| FR-01 | detectModeをIPC経由で呼び出し可能にする         | P0     | AC-04, AC-08        | リクエスト文字列を送信し、SkillCreatorMode型の結果を受信する                              |
| FR-02 | createSkillをIPC経由で呼び出し可能にする        | P0     | AC-04, AC-08        | CreateSkillOptionsを送信し、作成されたスキルディレクトリのパス文字列を受信する            |
| FR-03 | executeTasksをIPC経由で呼び出し可能にする       | P0     | AC-04, AC-08        | ExecuteTasksOptionsを送信し、ExecutionReport型の実行レポートを受信する                    |
| FR-04 | validateSkillをIPC経由で呼び出し可能にする      | P0     | AC-04, AC-08        | スキルディレクトリパスを送信し、boolean型の検証結果を受信する                             |
| FR-05 | validateWithSchemaをIPC経由で呼び出し可能にする | P0     | AC-04, AC-08        | スキーマ名とデータを送信し、boolean型の検証結果を受信する                                 |
| FR-06 | 進捗通知をMain→Renderer方向で送信する           | P1     | AC-03, AC-09        | SkillCreatorProgress型の進捗データをM→R方向で送信し、onProgressで購読可能にする           |
| FR-07 | Preload APIに `skillCreator` 名前空間を追加する | P0     | AC-08               | `window.electronAPI.skillCreator` として6メソッド（5 invoke + 1 on）を公開する            |
| FR-08 | 全チャンネルをIPC_CHANNELS定数で一元管理する    | P0     | AC-01, AC-02, AC-03 | 6チャンネル定数をIPC_CHANNELSに定義し、ALLOWED_INVOKE/ON_CHANNELSにホワイトリスト登録する |

### P0（必須）要件の概要

FR-01からFR-05はSkillCreatorServiceの5メソッドの基本的なIPC化であり、本タスクの中核要件。FR-07はPreload層でのAPI公開、FR-08はセキュリティ基盤としてのチャンネル定数管理であり、全ハンドラーが正しく動作するための前提条件。

### P1（重要）要件の概要

FR-06は進捗通知機能であり、長時間実行されるcreateSkill/executeTasksの実行状況をRendererに通知する。機能的には重要だが、基本的なIPC呼び出し（FR-01〜FR-05）が先に動作する必要がある。

### セキュリティ要件の階層構造

```
NFR-05: ホワイトリスト検証（Preload層 - L1）
  ↓ 通過した場合のみ
NFR-01: sender検証（Main層 - L2）
  ↓ 通過した場合のみ
NFR-02: 引数検証（Main層 - L3）
NFR-08: パストラバーサル対策（Main層 - L3の一部）
  ↓ エラー発生時
NFR-03: エラーサニタイズ
NFR-04: スタックトレース除外
```
