# Phase 11: 手動テスト

## メタ情報

- Phase: 11
- タスクID: UT-SKILL-WIZARD-W1-par-02a
- 機能名: SkillInfoStep コンポーネント実装（Step 0）

## 目的

実際のElectronアプリ上で `SkillInfoStep` を手動操作し、自動テストでは検出できない視覚的・操作的な問題を発見する。

- [ ] バリデーション表示を確認する

- [ ] 「次へ」ボタンの活性化を確認する
- [ ] external-integration 選択時の Step 1 Q5 必須を確認する
- [ ] キーボード操作を確認する

## 実行手順

### Step 1: 開発サーバー起動

```bash
pnpm --filter @repo/desktop dev
```

### Step 2: 基本入力操作の確認

| 確認項目     | 手順                                     | 期待結果                               |
| ------------ | ---------------------------------------- | -------------------------------------- |
| スキル名入力 | スキル名フィールドに任意の文字を入力する | 入力した文字がリアルタイムで表示される |
| 目的入力     | 目的・背景テキストエリアに文字を入力する | 入力した文字がリアルタイムで表示される |
| スキル名空欄 | スキル名を空のまま他の操作をする         | エラーが表示されない（任意項目）       |

### Step 3: バリデーション表示の確認

| 確認項目                   | 手順                                                          | 期待結果                                                       |
| -------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------- |
| 目的フィールドのエラー表示 | 目的テキストエリアをクリック後、何も入力せずにTabキーで離れる | 「目的・背景は10文字以上で入力してください」エラーが表示される |
| エラーの解消               | エラー表示後に10文字以上入力する                              | エラーメッセージが非表示になる                                 |
| 「次へ」押下時のエラー     | 目的が空の状態で「次へ」ボタンをクリックする                  | ボタンが無効（disabled）状態のためクリックできない             |

### Step 4: カテゴリタグの視覚的確認

| 確認項目               | 手順                               | 期待結果                                                                     |
| ---------------------- | ---------------------------------- | ---------------------------------------------------------------------------- |
| 5種のタグ表示          | Step 0 を表示する                  | 「自動化」「外部連携」「データ分析」「コードサポート」「その他」が表示される |
| タグ選択ハイライト     | いずれかのタグをクリックする       | クリックしたタグが青色のハイライト表示になる                                 |
| タグ再クリック時の保持 | 選択中のタグを再クリックする       | ハイライトは解除されず、選択状態が保持される                                 |
| 単選択動作             | タグAを選択後、タグBをクリックする | タグBのみがハイライト、タグAのハイライトが解除される                         |

### Step 5: 「次へ」ボタンの活性化確認

| 確認項目           | 手順                                         | 期待結果                                         |
| ------------------ | -------------------------------------------- | ------------------------------------------------ |
| 初期状態（無効）   | Step 0 を表示する                            | 「次へ」ボタンがグレーアウトしてクリックできない |
| 9文字入力（無効）  | 目的に9文字入力する                          | 「次へ」ボタンが無効のまま                       |
| 10文字入力（無効） | 目的に10文字入力する（カテゴリ未選択のまま） | 「次へ」ボタンが無効のまま                       |
| 10文字入力（有効） | 目的に10文字入力し、カテゴリを1つ選択する    | 「次へ」ボタンが青色になり、クリック可能になる   |
| Step 遷移          | 有効状態で「次へ」をクリックする             | Step 1（ConversationRoundStep）へ遷移する        |

### Step 6: external-integration 選択時の動作確認

| 確認項目              | 手順                                             | 期待結果                                                 |
| --------------------- | ------------------------------------------------ | -------------------------------------------------------- |
| Q5 必須フラグの伝達   | 「外部連携」タグを選択し「次へ」で Step 1 へ進む | Step 1 の Q5「外部ツール連携」に必須マークが表示される   |
| Q5 任意（他カテゴリ） | 「自動化」タグを選択し「次へ」で Step 1 へ進む   | Step 1 の Q5「外部ツール連携」に必須マークが表示されない |

### Step 7: キーボード操作の確認

| 確認項目                   | 手順                                                 | 期待結果                                                              |
| -------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------- |
| Tab 移動                   | Tab キーでフォーカスを順番に移動する                 | スキル名 → 目的 → カテゴリタグ（順番）→ 次へ の順でフォーカスが当たる |
| カテゴリタグの Enter/Space | カテゴリタグにフォーカスし Enter または Space を押す | タグが選択され、同じタグを押し直しても解除されない                    |
| 「次へ」の Enter           | 「次へ」ボタンにフォーカスし Enter を押す（有効時）  | onNext が呼ばれ Step 1 へ遷移する                                     |
