## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コード重複の除去

**目的**: 各コンポーネント間で重複しているコードを共通化する

**実行手順**:

1. 重複コードの特定
2. 共通ユーティリティ/コンポーネントの抽出
3. 既存コードのリファクタリング
4. テストが成功することを確認

**重複候補**:

- ボタンスタイル → 共通Buttonコンポーネント
- ローディング状態表示 → 共通Spinnerコンポーネント
- aria-label生成ロジック

**期待される成果物**:

- リファクタリング済みコード
- 共通コンポーネント/ユーティリティ

---

### タスク2: 命名の改善

**目的**: 変数名、関数名、コンポーネント名の可読性を向上させる

**実行手順**:

1. 曖昧な命名の特定
2. より説明的な名前への変更
3. 一貫した命名規則の適用
4. テストが成功することを確認

**命名規則**:

- Props: `on` + 動詞（`onRemove`, `onApply`）
- 状態: `is` + 形容詞（`isLoading`, `isDragging`）
- ハンドラ: `handle` + 動詞（`handleClick`, `handleDrop`）

**期待される成果物**:

- 命名改善済みコード

---

### タスク3: コンポーネント構造の最適化

**目的**: コンポーネントの責務を明確化し、適切な粒度に分割する

**実行手順**:

1. 複雑なコンポーネントの特定
2. 責務分離の検討
3. サブコンポーネントへの分割
4. テストが成功することを確認

**検討対象**:

- FileContextDropZone: ドロップゾーン表示とバリデーションロジックの分離
- DiffPreview: ヘッダー、コンテンツ、フッターの分離

**期待される成果物**:

- 最適化されたコンポーネント構造

---

### タスク4: パフォーマンス最適化

**目的**: 不要なリレンダリングを防止し、パフォーマンスを向上させる

**実行手順**:

1. React.memo の適用検討
2. useMemo / useCallback の適用
3. 不要な状態更新の削除
4. テストが成功することを確認

**最適化候補**:

- FileContextBadge: 親の再レンダリング時の不要な更新防止
- DiffEditor: Monaco Editorの不要な再初期化防止

**期待される成果物**:

- パフォーマンス最適化済みコード

---

### タスク5: 型定義の厳格化

**目的**: TypeScript型定義を厳格化し、型安全性を向上させる

**実行手順**:

1. any型の排除
2. 厳密な型定義への変更
3. 型ガードの追加
4. テストが成功することを確認

**期待される成果物**:

- 厳格化された型定義
