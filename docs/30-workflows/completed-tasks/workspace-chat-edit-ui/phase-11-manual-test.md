### タスク5: 統合テスト（手動）

**目的**: コンポーネント間連携を手動で確認する

**テストシナリオ**:

1. **シナリオA: ファイル添付→編集→適用**
   - ファイルをドラッグ&ドロップ
   - バッジが表示されることを確認
   - 編集コマンドを選択して送信
   - 差分プレビューが表示されることを確認
   - 適用ボタンをクリック
   - ファイルに変更が適用されることを確認

2. **シナリオB: 複数ファイル操作**
   - 複数ファイルをドロップ
   - 各ファイルのバッジが表示されることを確認
   - バッジを1つ削除
   - 残りのバッジが正しく表示されることを確認

**期待される成果物**:

- `outputs/phase-11/integration-test-result.md`
