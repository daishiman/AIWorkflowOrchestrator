## 目的

テストカバレッジが目標（Line 80%以上）を達成しているか確認し、未達の場合は追加テストを作成する。

## 背景

Phase 6でテスト拡充が完了した。カバレッジを測定し、目標達成を確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ測定

**目的**: 現在のテストカバレッジを測定する

**実行手順**:

1. カバレッジ付きテスト実行
2. カバレッジレポート確認
3. 未カバー行の特定

**コマンド**:

```bash
pnpm --filter @repo/desktop test -- --coverage --testPathPattern="workspace-chat-edit/components"
```

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: カバレッジ分析

**目的**: カバレッジ結果を分析し、不足箇所を特定する

**実行手順**:

1. 各コンポーネントのカバレッジ率を確認
2. 未カバー行のリストを作成
3. 優先度付け（重要なビジネスロジック優先）

**分析テンプレート**:
| コンポーネント | Line | Branch | Function | 判定 |
| -------------- | ---- | ------ | -------- | ---- |
| FileContextBadge | ?% | ?% | ?% | ? |
| ApplyControls | ?% | ?% | ?% | ? |
| FileContextDropZone | ?% | ?% | ?% | ? |
| DiffPreview | ?% | ?% | ?% | ? |
| DiffEditor | ?% | ?% | ?% | ? |
| EditCommandInput | ?% | ?% | ?% | ? |

**期待される成果物**:

- `outputs/phase-7/coverage-analysis.md`

---

### タスク3: 追加テスト作成（必要な場合）

**目的**: カバレッジ目標未達の場合、追加テストを作成する

**実行手順**:

1. 未カバー行に対するテストケースを作成
2. テスト実行
3. カバレッジ再測定

**判定基準**:

- Line Coverage ≥ 80%: 達成
- Line Coverage < 80%: Phase 6へ戻り追加テスト

**期待される成果物**:

- 追加テストケース（必要な場合）

---

### タスク4: カバレッジレポート作成

**目的**: 最終的なカバレッジレポートを作成する

**実行手順**:

1. 最終カバレッジ結果を記録
2. 達成/未達の判定
3. 未カバー行の理由（テスト不可能な行等）を記録

**期待される成果物**:

- `outputs/phase-7/final-coverage-report.md`
