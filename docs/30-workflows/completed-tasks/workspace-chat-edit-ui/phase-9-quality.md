## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: Lintチェック

**目的**: ESLintによるコード品質チェックを実行する

**実行手順**:

1. ESLint実行
2. エラー/警告の確認
3. 必要に応じて修正

**コマンド**:

```bash
pnpm --filter @repo/desktop lint -- --filter="**/workspace-chat-edit/components/**"
```

**期待される成果物**:

- Lintエラー0件

---

### タスク2: 型チェック

**目的**: TypeScriptの型チェックを実行する

**実行手順**:

1. TypeScript型チェック実行
2. エラーの確認
3. 必要に応じて修正

**コマンド**:

```bash
pnpm --filter @repo/desktop typecheck
```

**期待される成果物**:

- 型エラー0件

---

### タスク3: セキュリティチェック

**目的**: セキュリティ脆弱性がないことを確認する

**実行手順**:

1. 依存関係の脆弱性チェック
2. XSS脆弱性の確認（DOMPurify使用箇所等）
3. 危険なAPI使用がないことを確認

**チェック観点**:

- [ ] dangerouslySetInnerHTMLの使用箇所確認
- [ ] eval()の使用がないこと
- [ ] ユーザー入力のサニタイズ確認
- [ ] Monaco Editorのサンドボックス設定確認

**コマンド**:

```bash
pnpm audit
```

**期待される成果物**:

- `outputs/phase-9/security-report.md`

---

### タスク4: パフォーマンスチェック

**目的**: パフォーマンス問題がないことを確認する

**実行手順**:

1. バンドルサイズの確認
2. 不要なリレンダリングの確認
3. 大きなファイルの差分表示パフォーマンス確認

**チェック観点**:

- [ ] React.memo/useMemo/useCallbackの適切な使用
- [ ] Monaco Editorの遅延読み込み設定
- [ ] 大きなファイル（10MB）での動作確認

**期待される成果物**:

- `outputs/phase-9/performance-report.md`

---

### タスク5: 品質レポート作成

**目的**: 品質チェック結果をまとめたレポートを作成する

**実行手順**:

1. 全チェック結果を集約
2. 品質判定
3. レポート作成

**期待される成果物**:

- `outputs/phase-9/quality-report.md`
