| dataTransfer.files | ✅ ファイルアクセス可能            | ✅   |

### 2.2 設計されたイベントフロー

```
1. dragenter → setDragging(true) → オーバーレイ表示
2. dragover → preventDefault() → ドロップ許可
3. dragleave → setDragging(false) → オーバーレイ非表示
4. drop → ファイル処理 → attachFile()
```

| 観点               | 評価                                 | 判定 |
| ------------------ | ------------------------------------ | ---- |
| イベント伝播制御   | ✅ stopPropagation()で適切に制御     | ✅   |
| ネスト対応         | ✅ relatedTarget確認でバブリング制御 | ✅   |
| 視覚フィードバック | ✅ isDragging状態で明確な表示        | ✅   |
