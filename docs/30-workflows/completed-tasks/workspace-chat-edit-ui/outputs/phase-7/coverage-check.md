### Task 4: カバレッジ不足箇所の特定

#### 概要

カバレッジが不足している箇所を特定し、追加テストの必要性を判断する。

#### 手順

1. カバレッジレポートからカバー率の低いファイル/行を特定
2. 未カバー行の重要度を評価
3. 必要に応じてPhase 6に差し戻し

#### 評価基準

| カバレッジ | アクション                          |
| ---------- | ----------------------------------- |
| ≥ 80%      | Phase 8へ進行                       |
| 75% - 79%  | 重要箇所のみ追加テスト後、Phase 8へ |
| < 75%      | Phase 6へ差し戻し                   |

#### 成果物

- `coverage-gap-analysis.md`
