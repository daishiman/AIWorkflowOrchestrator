## 3. タスク一覧

### Task 1: 実装ガイド作成（2パート構成）

#### Part 1: 初学者・中学生レベル

**対象読者**: プログラミング初心者、非技術者

**必須要件**:

- 日常生活での例え話を**必ず**含める
- 専門用語は使わない（使う場合は即座に説明）
- 「なぜ必要か」を先に説明してから「何をするか」を説明

**構成例**:

```markdown
## Part 1: 概念説明（中学生でもわかる版）

### この機能は何？

AIにコードを書いてもらうとき、「どのファイルを見てほしいか」を伝える機能です。

### 日常生活での例え

料理のレシピをAIに改善してもらうとき...
[具体的な例え話を記載]

### 主な登場人物（コンポーネント）

- **ファイル添付ボタン**: 「このファイルを見て」とAIに伝えるボタン
- **ファイル一覧**: 今AIが見ているファイルのリスト
```

#### Part 2: 開発者・技術者レベル

**対象読者**: 開発者、技術者

**必須要件**:

- インターフェース/型定義（TypeScript）を含める
- APIシグネチャと使用例を記載
- エラーハンドリングとエッジケースを説明
- 設定可能なパラメータと定数を一覧化

**構成例**:

```markdown
## Part 2: 技術詳細（開発者向け）

### コンポーネント仕様

#### FileAttachmentButton

| Prop            | 型                        | 説明                         |
| --------------- | ------------------------- | ---------------------------- |
| onFilesSelected | (paths: string[]) => void | ファイル選択後コールバック   |
| maxFiles        | number                    | 最大選択数（デフォルト: 10） |

### IPC連携

[chat-edit:read-file チャンネルの詳細]

### エラーハンドリング

[エラーコードと対処法]
```

#### 配置先

`docs/30-workflows/workspace-chat-edit-ui/outputs/phase-12/implementation-guide.md`

### Task 2: システム仕様書更新（2ステップ）

#### Step 1: タスク完了記録（必須）

**Step 1-A: 「完了タスク」セクション追加**

対象ファイル: `.claude/skills/aiworkflow-requirements/references/arch-ui-components.md`

追加内容:

```markdown
### 関連タスク

- **Issue #494**: workspace-chat-edit-ui（YYYY-MM-DD完了）
  - FileAttachmentButton コンポーネント追加
  - FileContextList コンポーネント追加
  - Storybook Stories作成
```

**Step 1-B: 実装状況テーブル更新**

対象ファイル: `.claude/skills/aiworkflow-requirements/references/arch-ui-components.md`

更新内容: 新規コンポーネントの実装状況を追記

#### Step 2: システム仕様更新（条件付き）

**更新が必要な場合**:

- 新規インターフェース/型の追加
- 既存インターフェースの変更
- 新規定数/設定値の追加
- API仕様の変更

**更新が不要な場合**:

- 内部実装の詳細変更のみ
- リファクタリング（インターフェース不変）
- バグ修正（仕様変更なし）

**本タスクでの判断**:

- FileAttachmentButtonProps → arch-ui-components.md に追加
- FileContextListProps → arch-ui-components.md に追加

#### 成果物

- 更新された `arch-ui-components.md`

### Task 4: 未タスク検出レポート作成（0件でも出力必須）

#### 概要

スコープ外の発見事項・残課題を未タスクとして文書化する。

#### 検出ソース

| ソース                 | 確認項目             |
| ---------------------- | -------------------- |
| Phase 3/10レビュー結果 | MINOR判定の指摘事項  |
| Phase 11手動テスト     | スコープ外の発見事項 |
| コードコメント         | TODO/FIXME/HACK/XXX  |

#### 検出コマンド

```bash
# コードコメントからTODO/FIXME検出
grep -rn "TODO\|FIXME\|HACK\|XXX" apps/desktop/src/renderer/features/workspace-chat-edit/
```

#### レポート形式

```markdown
# 未タスク検出レポート

## 検出日: YYYY-MM-DD

## 検出元タスク: TASK-WCE-UI-001 (Issue #494)

## 検出結果

### 検出された未タスク数: N件

| ID     | 内容   | 優先度   | 検出元   |
| ------ | ------ | -------- | -------- |
| UT-001 | [内容] | [優先度] | [検出元] |

### 0件の場合

未タスクは検出されませんでした。

## 次のアクション

- [ ] 高優先度の未タスクは別途Issue化を検討
```
