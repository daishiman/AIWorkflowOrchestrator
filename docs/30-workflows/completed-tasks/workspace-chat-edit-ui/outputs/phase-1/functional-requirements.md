## 1. FileContextBadge

### 概要

添付されたファイルコンテキストをバッジ形式で表示し、削除操作を提供するコンポーネント。

### Props インターフェース

```typescript
interface FileContextBadgeProps {
  /** ファイルコンテキスト */
  context: FileContext;
  /** 削除時コールバック */
  onRemove?: () => void;
  /** ツールチップ表示有無 */
  showTooltip?: boolean;
  /** 追加のクラス名 */
  className?: string;
}
```

### 機能要件

| ID      | 要件                                     | 優先度 |
| ------- | ---------------------------------------- | ------ |
| FC-B-01 | ファイル名（context.fileName）を表示する | 必須   |
| FC-B-02 | 削除ボタン（Xアイコン）を表示する        | 必須   |
| FC-B-03 | 削除ボタンクリックでonRemoveを呼び出す   | 必須   |
| FC-B-04 | ホバー時にファイルパスをツールチップ表示 | 推奨   |
| FC-B-05 | 長いファイル名を省略表示（最大200px）    | 必須   |

### ユースケース

```
UC-B-01: ファイルバッジ表示
  前提: ファイルがコンテキストに追加されている
  操作: バッジが表示される
  結果: ファイル名と削除ボタンが表示される

UC-B-02: ファイル削除
  前提: バッジが表示されている
  操作: 削除ボタンをクリック
  結果: onRemoveが呼び出され、バッジが消える
```

## 2. ApplyControls

### 概要

LLM生成結果に対する適用/却下操作のUIを提供するコンポーネント。

### Props インターフェース

```typescript
interface ApplyControlsProps {
  /** 結果ID */
  resultId: string;
  /** 適用成功時コールバック */
  onApplied?: (result: ApplyResult) => void;
  /** 却下時コールバック */
  onRejected?: () => void;
  /** 無効化フラグ */
  disabled?: boolean;
}
```

### 機能要件

| ID    | 要件                                       | 優先度 |
| ----- | ------------------------------------------ | ------ |
| AC-01 | 適用ボタンを表示する                       | 必須   |
| AC-02 | 却下ボタンを表示する                       | 必須   |
| AC-03 | 適用ボタンクリックでapplyResultを呼び出す  | 必須   |
| AC-04 | 却下ボタンクリックでrejectResultを呼び出す | 必須   |
| AC-05 | ローディング中はボタンを無効化する         | 必須   |
| AC-06 | ローディング中はスピナーを表示する         | 必須   |
| AC-07 | 適用成功時にonAppliedを呼び出す            | 必須   |
| AC-08 | 適用失敗時にエラーメッセージを表示する     | 必須   |

### ユースケース

```
UC-AC-01: 変更適用
  前提: 差分プレビューが表示されている
  操作: 適用ボタンをクリック
  結果: 変更がファイルに適用される

UC-AC-02: 変更却下
  前提: 差分プレビューが表示されている
  操作: 却下ボタンをクリック
  結果: 変更が破棄される
```

## 3. FileContextDropZone

### 概要

ドラッグ&ドロップによるファイル添付UIを提供するコンポーネント。

### Props インターフェース

```typescript
interface FileContextDropZoneProps {
  /** ファイルドロップ時コールバック */
  onFilesDropped?: (files: File[]) => void;
  /** 最大ファイル数（デフォルト: 10） */
  maxFiles?: number;
  /** 最大ファイルサイズ（デフォルト: 10MB） */
  maxFileSize?: number;
  /** 子要素 */
  children?: React.ReactNode;
  /** 追加のクラス名 */
  className?: string;
}
```

### 機能要件

| ID    | 要件                                         | 優先度 |
| ----- | -------------------------------------------- | ------ |
| DZ-01 | ドラッグオーバー時にビジュアルフィードバック | 必須   |
| DZ-02 | ファイルドロップでonFilesDroppedを呼び出す   | 必須   |
| DZ-03 | ファイルサイズバリデーション（10MB上限）     | 必須   |
| DZ-04 | ファイル数バリデーション（10ファイル上限）   | 必須   |
| DZ-05 | バリデーションエラー時にエラーメッセージ表示 | 必須   |
| DZ-06 | ドラッグ離脱時にビジュアル状態をリセット     | 必須   |
| DZ-07 | children要素をラップして表示                 | 必須   |

### ユースケース

```
UC-DZ-01: ファイルドロップ
  前提: ドロップゾーンが表示されている
  操作: ファイルをドラッグ&ドロップ
  結果: ファイルがコンテキストに追加される

UC-DZ-02: サイズ超過エラー
  前提: ドロップゾーンが表示されている
  操作: 10MB超のファイルをドロップ
  結果: エラーメッセージが表示される
```

## 4. DiffPreview

### 概要

差分プレビューパネルを提供するコンポーネント。DiffEditorとApplyControlsを統合。

### Props インターフェース

```typescript
interface DiffPreviewProps {
  /** 生成結果 */
  result: GeneratedResult;
  /** 閉じる時コールバック */
  onClose?: () => void;
  /** 適用成功時コールバック */
  onApplied?: (result: ApplyResult) => void;
}
```

### 機能要件

| ID    | 要件                                    | 優先度 |
| ----- | --------------------------------------- | ------ |
| DP-01 | ファイル名をヘッダーに表示する          | 必須   |
| DP-02 | DiffEditorを統合して差分を表示する      | 必須   |
| DP-03 | ApplyControlsを統合して操作UIを表示     | 必須   |
| DP-04 | 閉じるボタンを表示する                  | 必須   |
| DP-05 | 閉じるボタンクリックでonCloseを呼び出す | 必須   |
| DP-06 | モーダルまたはパネル形式で表示する      | 必須   |
| DP-07 | 変更行数（追加/削除/変更）を表示する    | 推奨   |

### ユースケース

```
UC-DP-01: 差分プレビュー表示
  前提: LLM生成結果がある
  操作: 差分プレビューを開く
  結果: 差分がMonaco Diff Editorで表示される

UC-DP-02: プレビューを閉じる
  前提: 差分プレビューが表示されている
  操作: 閉じるボタンをクリック
  結果: プレビューが閉じる
```

## 5. DiffEditor

### 概要

Monaco Diff Editorを統合した差分表示コンポーネント。

### Props インターフェース

```typescript
interface DiffEditorProps {
  /** 元のコンテンツ */
  original: string;
  /** 変更後のコンテンツ */
  modified: string;
  /** プログラミング言語 */
  language: string;
  /** 読み取り専用（デフォルト: true） */
  readOnly?: boolean;
  /** 高さ（デフォルト: 400px） */
  height?: string | number;
}
```

### 機能要件

| ID    | 要件                                   | 優先度 |
| ----- | -------------------------------------- | ------ |
| DE-01 | Monaco Diff Editorをレンダリングする   | 必須   |
| DE-02 | original/modifiedプロパティを渡す      | 必須   |
| DE-03 | 言語別シンタックスハイライトを設定する | 必須   |
| DE-04 | 行番号を表示する                       | 必須   |
| DE-05 | サイドバイサイド表示をデフォルトにする | 必須   |
| DE-06 | ミニマップを無効化する                 | 推奨   |
| DE-07 | レスポンシブ対応（幅に応じてリサイズ） | 必須   |

### ユースケース

```
UC-DE-01: 差分表示
  前提: original/modifiedコンテンツがある
  操作: DiffEditorをレンダリング
  結果: 差分がハイライト表示される
```

## 6. EditCommandInput

### 概要

編集コマンド入力UIを提供するコンポーネント。

### Props インターフェース

```typescript
interface EditCommandInputProps {
  /** 送信時コールバック */
  onSubmit: (command: EditCommand) => void;
  /** 無効化フラグ */
  disabled?: boolean;
  /** デフォルトのコマンドタイプ */
  defaultType?: EditCommandType;
}
```

### 機能要件

| ID     | 要件                                   | 優先度 |
| ------ | -------------------------------------- | ------ |
| ECI-01 | コマンドタイプセレクタを表示する       | 必須   |
| ECI-02 | 5種類のコマンドタイプを選択可能        | 必須   |
| ECI-03 | customタイプ選択時にテキスト入力を表示 | 必須   |
| ECI-04 | 送信ボタンを表示する                   | 必須   |
| ECI-05 | 送信ボタンクリックでonSubmitを呼び出す | 必須   |
| ECI-06 | disabled時にボタンを無効化する         | 必須   |
| ECI-07 | Enter キーで送信（カスタム入力時）     | 推奨   |

### コマンドタイプ一覧

| タイプ        | 説明             |
| ------------- | ---------------- |
| continue      | 続きを書く       |
| refactor      | リファクタリング |
| generate-test | テスト生成       |
| add-comment   | コメント追加     |
| custom        | カスタム指示     |

### ユースケース

```
UC-ECI-01: コマンド送信
  前提: ファイルがコンテキストに添付されている
  操作: コマンドタイプを選択して送信
  結果: onSubmitがEditCommandと共に呼び出される

UC-ECI-02: カスタム指示入力
  前提: customタイプが選択されている
  操作: テキストを入力して送信
  結果: instruction付きのEditCommandが送信される
```

## 共通要件

### エラーハンドリング

| エラーコード          | 表示メッセージ                         |
| --------------------- | -------------------------------------- |
| FILE_NOT_FOUND        | ファイルが見つかりません               |
| PERMISSION_DENIED     | ファイルへのアクセス権限がありません   |
| TOO_LARGE             | ファイルサイズが10MBを超えています     |
| MAX_CONTEXTS_EXCEEDED | 添付ファイル数の上限（10）に達しました |
| WRITE_ERROR           | ファイルの書き込みに失敗しました       |
| LLM_ERROR             | 生成中にエラーが発生しました           |
