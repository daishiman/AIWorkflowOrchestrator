## 実行手順

### ステップ1: ESLint 設定ファイルのコメント更新

`apps/backend/eslint.config.mjs` のコメントを更新する。

**確認項目**:

| 確認事項                       | 対応内容                                     |
| ------------------------------ | -------------------------------------------- |
| 旧コメント "Next.js 15" の削除 | Next.js 16 対応の旨をコメントに記載          |
| FlatCompat 使用理由の記載      | レガシー設定変換が必要な理由をコメントに追加 |
| ignores の根拠コメント         | 各 ignore パターンの目的を簡潔に記載         |

**更新後のコメント例**:

```javascript
// ESLint config for Next.js 16 backend
// Note: Uses FlatCompat because eslint-config-next uses legacy config format
```

### ステップ2: 設定の最適化

不要な設定項目がないか確認する。

| 確認項目                  | 判定基準                                    |
| ------------------------- | ------------------------------------------- |
| 重複する ignores パターン | ルート設定と backend 設定で重複していないか |
| 未使用の依存パッケージ    | eslint.config.mjs で使用しない依存がないか  |
| 不要なルール設定          | デフォルト値と同じ明示的設定がないか        |

### ステップ3: リファクタリング後の動作確認

```bash
# lint が引き続き正常動作することを確認
pnpm --filter @repo/backend lint
pnpm lint

# 期待結果: 両方とも正常終了
```
