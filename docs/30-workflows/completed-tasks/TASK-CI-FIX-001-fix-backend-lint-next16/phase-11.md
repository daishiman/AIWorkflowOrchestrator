### ステップ2: エラー検出の手動確認

1. 一時ファイルを作成して lint エラー検出を確認:

```bash
# 1. lint エラーを含むファイル作成
echo 'const unused = "test";' > apps/backend/src/temp-test.ts

# 2. lint 実行
pnpm --filter @repo/backend lint
# → 期待: 未使用変数エラーが報告される

# 3. 一時ファイル削除
rm apps/backend/src/temp-test.ts
```
