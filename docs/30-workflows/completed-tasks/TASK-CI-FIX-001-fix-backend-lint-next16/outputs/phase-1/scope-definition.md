# スコープ定義: TASK-CI-FIX-001

## スコープ内

| 項目                               | 詳細                                                     |
| ---------------------------------- | -------------------------------------------------------- |
| `apps/backend/package.json` の変更 | `"lint": "next lint"` → `"lint": "eslint . --cache ..."` |
| `apps/backend/eslint.config.mjs`   | eslint-config-next ルールの FlatCompat 統合              |
| CI lint ジョブの動作確認           | `pnpm --filter @repo/backend lint` の正常動作            |

## スコープ外

| 項目                                     | 理由                     |
| ---------------------------------------- | ------------------------ |
| Next.js 16 その他の破壊的変更対応        | 別タスクとして管理       |
| `apps/web/` パッケージの ESLint 設定変更 | 対象外（存在しない場合） |
| ルートの `eslint.config.js` の変更       | ルート設定は変更不要     |
| ESLint ルールの追加・変更                | 既存ルールの移行のみ     |
| Next.js 16 マイグレーション全般          | 本タスクは lint 修正のみ |

## 変更対象ファイル

| ファイル                         | 変更種別 | 変更概要                |

## 影響範囲

| 影響を受けるシステム | 影響度 | 影響内容                             |

| 他パッケージ         | なし   | 影響なし                             |
