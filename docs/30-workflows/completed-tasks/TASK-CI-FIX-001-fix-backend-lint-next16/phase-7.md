## 目的

ESLint 設定変更が既存テストのカバレッジに影響を与えていないことを確認する。

## 実行タスク

- カバレッジ実行: 既存テストのカバレッジレポートを生成
- 影響確認: 設定変更前後でカバレッジに差異がないことを確認

## 実行手順

### ステップ1: 既存テストの実行

```bash
# Backend テストの実行
pnpm --filter @repo/backend test:run

# 期待結果: 全テストがPASS
```

### ステップ2: カバレッジレポート生成

```bash
# Backend カバレッジレポート生成
pnpm --filter @repo/backend test:coverage

# 期待結果: カバレッジレポートが生成される
```

### ステップ3: 影響確認

本タスクは ESLint 設定の変更であり、ソースコードの変更は含まない。そのため:

| 確認項目                     | 期待結果                     |
| ---------------------------- | ---------------------------- |
| テスト結果                   | 全テストが PASS              |
| カバレッジ数値               | 変更前と同一                 |
| テストファイルの ESLint 除外 | テストファイルが lint 対象外 |

**注**: 本タスクはコード変更を含まないため、カバレッジへの影響は原理的にない。ここでは既存テストが壊れていないことの確認が主目的。

### ステップ4: カバレッジループ判定

| 条件             | 対応           | 理由               |
| ---------------- | -------------- | ------------------ |
| カバレッジ未達成 | Phase 6 に戻る | テスト追加が必要   |
| カバレッジ達成   | Phase 8 に進む | 基準を満たしている |

**カバレッジ基準**（参考: `coverage-standards.md`）:

| 指標              | 最低基準 |
| ----------------- | -------- |
| Line Coverage     | 80%      |
| Branch Coverage   | 60%      |
| Function Coverage | 80%      |
