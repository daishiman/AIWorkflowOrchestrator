## 目的

実際のスキル生成フローを Electron アプリで実行し、
スキル生成中に `GenerateStep.tsx` のプログレスバーが IPC メッセージ受信によって
実際に更新されることを目視確認する（AC-4 の検証）。

## 実行タスク

- Electron アプリの起動
- スキル生成フローの実行（create モード）
- プログレスバーの更新を目視確認
- 各フェーズでの進捗表示を確認
- 手動テスト結果の記録

## 実行手順

### 1. Electron アプリの起動

```bash
# 開発モードで Electron アプリを起動
pnpm --filter @repo/desktop dev
```

### 2. 手動テストシナリオ

#### シナリオ 1: スキル生成中のプログレスバー更新確認

1. スキル作成ウィザードを開く
2. `create` モードを選択する
3. スキル名・説明等を入力して生成を開始する
4. `GenerateStep` 画面（生成中画面）に遷移することを確認する
5. 以下の進捗が順番に表示されることを確認する:

| 確認観点                       | 期待する表示                                    | 結果   |
| ------------------------------ | ----------------------------------------------- | ------ |
| planning フェーズ表示          | プログレスバーが 10% 付近で表示・メッセージ確認 | 確認要 |
| generating-skill フェーズ表示  | プログレスバーが 40% 付近で表示                 | 確認要 |
| generating-agents フェーズ表示 | プログレスバーが 70% 付近で表示                 | 確認要 |
| validating フェーズ表示        | プログレスバーが 90% 付近で表示                 | 確認要 |
| done フェーズ表示              | プログレスバーが 100% で完了表示                | 確認要 |

#### シナリオ 2: 生成前の初期状態確認

1. `GenerateStep` 画面に遷移直後（生成開始前）
2. プログレスバーが `idle` 状態（0% または非表示）であることを確認する

#### シナリオ 3: 生成完了後の状態確認

1. スキル生成が完了した後
2. プログレスバーが完了状態（100% または完了表示）であることを確認する

### 3. 確認できない場合のデバッグ

```bash
# Electron の開発者ツールでコンソール確認
# IPC メッセージが送受信されているか確認
# useStreamingProgress の Zustand ストア状態を確認
```
