## 目的

実際のアプリケーション上で手動テストを実施し、ユーザー体験を検証する。

## 実行タスク

- E2Eテスト: エンドツーエンドのシナリオテスト
- UI/UXテスト: ユーザーインターフェースの操作性確認
- 探索的テスト: 想定外のシナリオ発見

## テストシナリオ

### 1. 正常系シナリオ

#### TS-001: スキル実行フロー

| ステップ | 操作                                     | 期待結果                                   |
| -------- | ---------------------------------------- | ------------------------------------------ |
| 1        | スキル一覧画面を開く                     | スキル一覧が表示される                     |
| 2        | 任意のスキルを選択                       | スキル詳細が表示される                     |
| 3        | プロンプトを入力して実行ボタンをクリック | ローディング表示後、ストリーミング出力開始 |
| 4        | 実行完了を待つ                           | 完了ステータスが表示される                 |

#### TS-002: Permission要求フロー

| ステップ | 操作                               | 期待結果                                 |
| -------- | ---------------------------------- | ---------------------------------------- |
| 1        | ファイル書き込みを伴うスキルを実行 | Permission確認ダイアログが表示される     |
| 2        | 「許可」をクリック                 | 処理が続行される                         |
| 3        | 再度同様の操作を実行               | 「今後も許可」選択時はダイアログスキップ |

#### TS-003: キャンセルフロー

| ステップ | 操作                         | 期待結果                       |
| -------- | ---------------------------- | ------------------------------ |
| 1        | 長時間実行されるスキルを開始 | ストリーミング出力が開始される |
| 2        | キャンセルボタンをクリック   | 実行が中断される               |
| 3        | ステータスを確認             | 「キャンセル済み」と表示される |

### 2. 異常系シナリオ

#### TS-004: 危険コマンドブロック

| ステップ | 操作                                | 期待結果                                   |
| -------- | ----------------------------------- | ------------------------------------------ |
| 1        | rm -rf を含む処理を実行するよう指示 | 処理がブロックされる                       |
| 2        | エラーメッセージを確認              | 「危険なコマンドがブロックされました」表示 |

#### TS-005: ネットワークエラー

| ステップ | 操作                         | 期待結果                           |
| -------- | ---------------------------- | ---------------------------------- |
| 1        | ネットワークを切断           | -                                  |
| 2        | スキルを実行                 | 適切なエラーメッセージが表示される |
| 3        | ネットワークを復旧後、再実行 | 正常に動作する                     |

### 3. 複数実行シナリオ

#### TS-006: 並行実行

| ステップ | 操作                | 期待結果                       |
| -------- | ------------------- | ------------------------------ |
| 1        | スキルAを実行開始   | 実行中表示                     |
| 2        | スキルBを実行開始   | 両方が実行中として表示         |
| 3        | スキルAをキャンセル | スキルAのみキャンセル、Bは継続 |
| 4        | スキルBの完了を待つ | スキルBが正常完了              |

## 実行手順

### 1. アプリケーション起動

```bash
pnpm --filter @repo/desktop dev
```

### 2. テストシナリオ実行

上記のテストシナリオを順番に実行し、結果を記録する。

### 3. バグ報告

発見したバグは以下の形式で記録:

```markdown
## BUG-XXX: [タイトル]

- **重要度**: Critical / High / Medium / Low
- **再現手順**:
  1. ...
  2. ...
- **期待結果**:
- **実際の結果**:
- **スクリーンショット**:
```
