## レビュー観点

### 1. セキュリティレビュー【重点】

Claude Agent SDK統合では、以下のセキュリティ観点を重点的にレビューする:

#### 1.1 コマンドインジェクション対策

| チェック項目                        | 確認内容                                     | 判定 |
| ----------------------------------- | -------------------------------------------- | ---- |
| PreToolUse Hookでの危険コマンド検出 | `rm -rf`, `sudo`, `chmod 777`, `dd if=` 検出 | [ ]  |
| Bashコマンド引数のサニタイズ        | シェルメタ文字のエスケープ                   | [ ]  |
| パストラバーサル防止                | `../` パターンの検出と拒否                   | [ ]  |

#### 1.2 Permission Control

| チェック項目               | 確認内容                                         | 判定 |
| -------------------------- | ------------------------------------------------ | ---- |
| 最小権限の原則             | デフォルトはdeny、必要最小限の許可               | [ ]  |
| システムディレクトリ保護   | `/etc/**`, `/usr/**`, `/var/**` への書き込み禁止 | [ ]  |
| プロジェクト外アクセス制限 | workingDirectory外へのアクセス制御               | [ ]  |

#### 1.3 IPC通信セキュリティ

| チェック項目       | 確認内容                              | 判定 |
| ------------------ | ------------------------------------- | ---- |
| contextBridge使用  | ipcRenderer直接公開の禁止             | [ ]  |
| sender検証         | validateIpcSenderによる呼び出し元検証 | [ ]  |
| 入力バリデーション | Zodスキーマによるリクエスト検証       | [ ]  |

### 2. 既存パターン整合レビュー

| チェック項目               | 確認内容                            | 判定 |
| -------------------------- | ----------------------------------- | ---- |
| 既存IPC設計との整合        | skill:\* チャネルとの命名規則統一   | [ ]  |
| エラーハンドリングパターン | APIResponse型の使用                 | [ ]  |
| 型定義配置                 | packages/shared/src/types/ への配置 | [ ]  |

### 3. 設計妥当性レビュー

| チェック項目    | 確認内容                                     | 判定 |
| --------------- | -------------------------------------------- | ---- |
| 単一責任原則    | クラスの責務分離が適切か                     | [ ]  |
| 依存関係の方向  | 下位層から上位層への依存がないか             | [ ]  |
| AbortSignal伝播 | 全非同期処理でsignal.abortedチェックがあるか | [ ]  |
