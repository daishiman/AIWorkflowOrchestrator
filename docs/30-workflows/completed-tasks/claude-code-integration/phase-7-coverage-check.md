## 実行手順

### 1. カバレッジ測定

```bash
# ユニットテストカバレッジ
pnpm --filter @repo/desktop test:coverage

# 統合テストカバレッジ
pnpm --filter @repo/desktop test:integration --coverage
```

### 2. レポート確認

```bash
# HTMLレポートを開く
open apps/desktop/coverage/index.html
```

### 3. 目標達成判定

| 判定  | 条件                          | 対応             |
| ----- | ----------------------------- | ---------------- |
| PASS  | 全指標が最低基準を達成        | Phase 8へ進行    |
| MINOR | 一部指標が基準未達（80%以上） | 補足テスト追加後 |
| MAJOR | 複数指標が大幅未達（80%未満） | Phase 6へ戻る    |

### 4. ギャップ分析（必要に応じて）

未達の場合、以下を分析:

- カバレッジが低いファイル/関数の特定
- 未テストの分岐条件の特定
- 追加すべきテストケースの洗い出し
