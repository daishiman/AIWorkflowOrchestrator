## 実行手順

### Step 1: テスト環境準備

```bash
# Electronアプリ起動
pnpm --filter @repo/desktop dev

# テスト用スライドプロジェクトを準備
mkdir -p ~/test-slide-project
echo "# Test Structure" > ~/test-slide-project/structure.md
echo "<html></html>" > ~/test-slide-project/index.html
```

### Step 2: 手動テストシナリオ実行

#### シナリオ1: プロジェクトを開く

| ステップ | 操作                                 | 期待結果                     | 結果 |
| -------- | ------------------------------------ | ---------------------------- | ---- |
| 1        | 「プロジェクトを開く」ボタンクリック | ファイル選択ダイアログが表示 | ☐    |

| 3        | -                                    | 同期状態インジケーターが表示 | ☐    |
| 4        | -                                    | スキルフェーズボタンが有効化 | ☐    |

| ステップ | 操作                             | 期待結果                       | 結果 |

| 3        | -                                | 同期状態が「非同期」に変わる   | ☐    |
| 4        | -                                | html-generatorが自動実行される | ☐    |
| 5        | -                                | 同期状態が「同期済み」に戻る   | ☐    |
