# Phase 11: 手動テスト計画

## 概要

Environment Backend（AGENT-007）の手動テスト計画と実施結果。

## テストシナリオ

### シナリオ1: 基本的なコンテンツ抽出

**手順:**

1. エージェント出力テキストにHTMLコードブロックを含める
2. EnvironmentService.extractAndSanitize()を呼び出す
3. 抽出されたコンテンツを確認

**期待結果:**

- HTMLコンテンツが正しく抽出される
- サニタイズが適用される
- 一時ファイルが作成される

**結果:** ユニットテストで検証済み ✓

### シナリオ2: XSS防止テスト

**手順:**

1. script タグを含むHTMLを抽出
2. onclick ハンドラを含むHTMLを抽出
3. javascript: プロトコルを含むリンクを抽出

**期待結果:**

- すべての危険な要素が除去される
- 安全なHTMLのみが残る

**結果:** ユニットテストで検証済み ✓

### シナリオ3: 一時ファイル管理

**手順:**

1. コンテンツを抽出し一時ファイルを作成
2. クリーンアップを実行
3. ファイルが削除されることを確認

**期待結果:**

- 一時ファイルが正しく作成される
- クリーンアップで削除される
- トラッキングが正確

**結果:** ユニットテストで検証済み ✓

### シナリオ4: IPC統合テスト

**手順:**

1. Electronアプリを起動
2. IPC経由でコンテンツ抽出を呼び出す
3. 結果を確認

**期待結果:**

- IPCハンドラが正しく動作する
- エラーハンドリングが機能する

**結果:** E2Eテストで検証予定（フロントエンド統合時）

## テスト環境

- Node.js: 20.x
- Electron: 31.x
- macOS / Windows / Linux
