## 要件詳細

### FR-01: HTMLコードブロック抽出

- Markdownの`html ... `形式からHTMLコンテンツを抽出
- 言語指定がhtmlまたはhtmの場合にHTML型として判定
- 抽出されたコンテンツにはユニークID、タイプ、順序番号を付与

### FR-04: HTMLサニタイズ

除去対象:

- `<script>` タグ
- `<iframe>` タグ
- `<object>` タグ
- `<embed>` タグ
- `<base>` タグ
- `onclick`, `onerror`, `onload` 等のイベントハンドラ
- `javascript:` プロトコル

### NFR-02: ファイルパーミッション

- 一時ファイルは `0o600` (所有者のみ読み書き可能)
- UUIDベースのファイル名で推測攻撃を防止

## 接続要件（IPC）

| チャネル              | 方向            | 説明                       |
| --------------------- | --------------- | -------------------------- |
| agent:extract-content | Renderer → Main | テキストからコンテンツ抽出 |
| agent:get-preview     | Renderer → Main | プレビューコンテンツ取得   |
| agent:cleanup-temp    | Renderer → Main | 一時ファイルクリーンアップ |

## データフロー

```
エージェント出力
    ↓
ContentExtractor（コードブロック抽出）
    ↓
ContentSanitizer（XSS対策）
    ↓
TempFileManager（一時ファイル保存）
    ↓
IPC経由でRenderer送信
    ↓
プレビュー表示
```
