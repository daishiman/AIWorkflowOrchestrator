## 目的

docs-only タスクのため「テスト」はテンプレート構造の検証基準として定義する。期待するテンプレート構造（expected structure）を明文化し、Phase 5実装後の検証に使用するチェックリストを作成する。

## docs-only タスクにおける「テスト」の位置づけ

このタスクはMarkdownテンプレートファイルの更新のみを行うdocs-onlyタスクである。そのため「テスト」は以下のように定義する。

| 通常のテスト             | 本タスクにおける対応                               |
| ------------------------ | -------------------------------------------------- |
| ユニットテスト           | テンプレートの各セクションが期待構造を満たすか確認 |
| インテグレーションテスト | 複数セクション間の参照整合（EC-NNN ↔ SD-NNN）確認  |
| E2Eテスト                | 既存Phase 11実例への新テンプレート適用可否確認     |
| リグレッションテスト     | 既存テンプレート使用箇所への悪影響がないか確認     |

## 期待するテンプレート構造（Expected Structure）

### ES-001: edge case一覧表の期待構造

```markdown
## edge case 一覧表

| ID     | 観点 | 入力値（代表例） | 期待動作 | 仕様判断根拠ID | 結果 |
| ------ | ---- | ---------------- | -------- | -------------- | ---- |
| EC-001 | ...  | ...              | ...      | SD-NNN         | -    |
```

**必須要件:**

- セクション見出しは `## edge case 一覧表` であること
- テーブルヘッダーに `ID`・`観点`・`入力値（代表例）`・`期待動作`・`仕様判断根拠ID`・`結果` の6列が存在すること
- IDは `EC-NNN`（3桁数字）形式であること
- 仕様判断根拠IDは `SD-NNN` 形式または `-`（未紐付け）であること
- 結果列の値は `PASS`・`FAIL`・`SKIP`・`-` のいずれかであること

### ES-002: テスト件数サマリーの期待構造

```markdown
## テスト件数サマリー

| 区分            | 件数 | PASS | FAIL | SKIP |
| --------------- | ---- | ---- | ---- | ---- |
| 正常系テスト    | -    | -    | -    | -    |
| 異常系テスト    | -    | -    | -    | -    |
| edge caseテスト | -    | -    | -    | -    |
| **合計**        | -    | -    | -    | -    |

### 実施情報

| 項目           | 内容       |
| -------------- | ---------- |
| 実施日         | YYYY-MM-DD |
| 実施者         | -          |
| 対象バージョン | -          |
| 実施環境       | -          |
| 関連Issue      | #NNNN      |
```

**必須要件:**

- セクション見出しは `## テスト件数サマリー` であること
- テーブルヘッダーに `区分`・`件数`・`PASS`・`FAIL`・`SKIP` の5列が存在すること
- 区分に `正常系テスト`・`異常系テスト`・`edge caseテスト`・`**合計**` の4行が存在すること
- `### 実施情報` サブセクションが存在すること
- 実施情報テーブルに `実施日`・`実施者`・`対象バージョン`・`実施環境`・`関連Issue` の5行が存在すること

### ES-003: 仕様判断根拠の期待構造

```markdown
## 仕様判断根拠

| ID     | 判断内容 | 根拠 | 影響範囲 |
| ------ | -------- | ---- | -------- |
| SD-001 | ...      | ...  | ...      |
```

**必須要件:**

- セクション見出しは `## 仕様判断根拠` であること
- テーブルヘッダーに `ID`・`判断内容`・`根拠`・`影響範囲` の4列が存在すること
- IDは `SD-NNN`（3桁数字）形式であること

### ES-004: セクション配置順序の期待構造

```markdown
# Phase 11: 手動テスト結果

## テスト件数サマリー ← ES-002（先頭近くに配置）

（既存セクション...）

## edge case 一覧表 ← ES-001

（既存セクション...）

## 仕様判断根拠 ← ES-003（末尾付近に配置）
```

**必須要件:**

- `## テスト件数サマリー` が既存の正常系・異常系テストテーブルより前に存在すること
- `## edge case 一覧表` が正常系・異常系テストテーブルの後に存在すること
- `## 仕様判断根拠` が末尾付近に存在すること
