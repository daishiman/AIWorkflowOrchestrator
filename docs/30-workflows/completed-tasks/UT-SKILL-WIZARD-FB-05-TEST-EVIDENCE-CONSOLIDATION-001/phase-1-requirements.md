## 目的

Phase 11 `manual-test-result.md` テンプレートにedge case一覧表・テスト件数集約構造・仕様判断根拠セクションを追加し、テスト証跡を1ファイルに一本化する。また `task-specification-creator` スキルのPhase 11テンプレートにこの構造を反映させる。

## 背景（問題分析）

テスト証跡に関する情報が複数ファイルに分散しており、以下の問題が発生している。

- **問題1**: Phase 11 `manual-test-result.md` テンプレートにedge case一覧表が存在せず、edge caseの検証状況を把握しにくい
- **問題2**: テスト件数と内訳が複数ファイルに散在し、全体像を1箇所で確認できない
- **問題3**: 仕様判断（空白→空文字扱い等）の根拠が証跡ファイルに明示されておらず、後から判断理由を追跡できない
- **問題4**: `task-specification-creator` スキルのPhase 11テンプレートに上記の構造が反映されていないため、新規タスクでも同じ問題が繰り返される
