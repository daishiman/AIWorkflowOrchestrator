## 採番ルール

- EC-NNN: 3桁ゼロ埋め整数、001から連番、タスクをまたいでリセット可
- SD-NNN: 3桁ゼロ埋め整数、001から連番、タスクをまたいでリセット可
- 逆引き列（SD→EC）は設けない（正方向参照のみ）
