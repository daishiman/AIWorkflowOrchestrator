## 目的

docs-only task のため「手動テスト」とは**新テンプレートを用いた Phase 11 証跡の試作確認**を指す。
実際のコード動作検証ではなく、以下の2軸で検証する:

1. **Semantic 評価**: テンプレートの意味的整合性（各セクション・カラムが意図通りに機能するか）
2. **試作記入**: 新テンプレートを使ってダミーの edge case 一覧を実際に記入してみる

> 本 Phase の正本は `manual-test-checklist.md` / `manual-test-result.md` / `discovered-issues.md` の 3 ファイル。

## 実行タスク

1. Semantic 評価: 各セクションの役割と重複を確認する
2. Semantic 評価: edge case 一覧表の全カラム意味を確認する
3. 試作記入: ダミーデータを新テンプレートに実際に記入する
4. 試作記入: 記入体験を評価し、HIGH/MEDIUM/LOW 問題を記録する
5. HIGH 問題がある場合は unassigned-task を生成する
6. 総合判定を下す
