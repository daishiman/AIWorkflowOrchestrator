## 1. テスト目的

自動テストでは検証できないユーザー体験・実環境動作を手動で確認する。実際のOAuth認証フローにおける自動リフレッシュ動作、エラー時のフォールバック、既存機能へのリグレッションを検証する。

| ログ確認方法        | Electron DevToolsのConsoleタブ                |
| ネットワーク制御    | macOS Wi-Fi切断 / DevTools Network throttling |

1. `pnpm install` が完了していること

## 5. テスト実行手順

### 5.1 標準手順

1. `pnpm --filter @repo/desktop preview` でアプリを起動する
2. Electron DevToolsを開く（Cmd+Option+I）
3. Consoleタブに切り替える
4. OAuth認証（Google/GitHub/Discord）でログインする
5. Consoleでスケジューラー開始ログを確認する
6. 各テストケースを順次実行する
7. 実行結果を記録する

### 5.2 時間短縮テスト方法

標準のAccess Token有効期限が1時間であるため、リフレッシュ発火まで55分待機する必要がある。以下の方法で待機時間を短縮可能。

1. `apps/desktop/src/main/services/tokenRefreshScheduler.ts`を開く
2. `DEFAULT_CONFIG.refreshBeforeExpiryMs`を`3_500_000`（58分20秒）に一時変更する
3. これにより有効期限1時間のうち、約1分40秒後にリフレッシュが発火する
4. テスト完了後、必ず元の値`300_000`（5分）に戻す
5. `pnpm --filter @repo/desktop build` でリビルドする
