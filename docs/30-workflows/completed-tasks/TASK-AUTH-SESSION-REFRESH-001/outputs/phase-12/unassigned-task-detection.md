### 2.1 オフライン時のリフレッシュ失敗処理

| 項目     | 内容                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 候補ID   | UT-OFFLINE-REFRESH-001                                                                                                                         |
| 元記載   | 元タスク仕様書「スコープ外: オフライン時の動作（別タスク）」                                                                                   |
| 説明     | ネットワーク切断中にリフレッシュタイミングが到来した場合の処理                                                                                 |
| 現状     | リトライ3回失敗→ログアウトフロー（オフライン状態の検出はnet.isOnline()で可能だが、リフレッシュスケジューラーではオフライン判定を行っていない） |
