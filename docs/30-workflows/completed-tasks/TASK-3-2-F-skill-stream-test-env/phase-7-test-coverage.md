## 目的

Phase 6でのテスト有効化後、テストカバレッジが目標値を維持していることを確認する。カバレッジ未達の場合はPhase 6に戻る。

## 背景

元タスク仕様書ではカバレッジ100%維持が目標とされている。`describe.skip`解消により、これまでスキップにより除外されていたテストが含まれるため、カバレッジ数値に変動がある可能性がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ計測

**目的**: SkillStreamDisplay関連のユニットテストカバレッジを計測する。

**実行手順**:

1. カバレッジ付きでテストを実行する
   ```bash
   pnpm --filter @repo/desktop vitest run --coverage src/renderer/components/AgentView/__tests__/SkillStreamDisplay
   ```
2. 以下のカバレッジ指標を記録する

| 指標      | 目標値 | 実測値 | 判定 |
| --------- | ------ | ------ | ---- |
| Line      | 80%    | -      | -    |
| Branch    | 60%    | -      | -    |
| Function  | 80%    | -      | -    |
| Statement | 80%    | -      | -    |

3. 全テスト（desktopパッケージ全体）のカバレッジも確認する
   ```bash
   pnpm --filter @repo/desktop test:coverage
   ```
4. カバレッジが目標値を下回る場合、不足箇所を特定する

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（カバレッジレポート）

---

### タスク2: カバレッジ目標達成判定

**目的**: カバレッジが目標値を満たしているか判定する。

**実行手順**:

1. タスク1の計測結果を評価する
2. 以下の判定基準で判定する

| 判定 | 条件                       | 次アクション                |
| ---- | -------------------------- | --------------------------- |
| PASS | 全指標が目標値以上         | Phase 8へ進行               |
| FAIL | いずれかの指標が目標値未満 | Phase 6に戻り追加テスト作成 |

3. FAIL判定の場合、不足箇所と必要なテスト追加方針を記載する
4. 受け入れ基準AC-5（カバレッジ100%維持）の達成状況を確認する

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（タスク1の成果物に判定結果を追記）

---

### タスク3: パフォーマンスベンチマーク確認

**目的**: テスト環境変更後のテスト実行時間がベースライン比+20%以内であることを確認する。

**実行手順**:

1. 全SkillStreamDisplayテストの実行時間を計測する
   ```bash
   pnpm --filter @repo/desktop vitest run src/renderer/components/AgentView/__tests__/SkillStreamDisplay --reporter=verbose 2>&1 | tail -5
   ```
2. Phase 2の互換性分析で記録したベースラインと比較する
3. 以下の基準で判定する

| 判定    | 条件                               | 対応                            |
| ------- | ---------------------------------- | ------------------------------- |
| OK      | 実行時間がベースライン比+20%以内   | 問題なし                        |
| WARNING | 実行時間がベースライン比+20%〜+50% | 原因調査、Phase 8で最適化検討   |
| NG      | 実行時間がベースライン比+50%超     | Phase 5に戻りパフォーマンス改善 |

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（パフォーマンス計測結果を追記）
