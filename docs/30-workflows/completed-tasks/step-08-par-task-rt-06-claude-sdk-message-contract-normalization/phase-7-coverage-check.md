## 目的

要件とテストの対応を確認し、message 種別ごとの coverage を可視化する。

## 背景

Phase 4 / 5 / 6 で作成・拡充したテストが Phase 1 の要件を網羅的にカバーしているかを検証する。カバレッジゲートを通過することで、後続のリファクタリング・品質保証フェーズに安全に進める。

## 実行タスク

### Task 1: message 種別 coverage の確認

**目的**: message 種別 coverage を確認し、未カバーの種別がないことを検証する。

**実行手順**:

1. Phase 1 の message 種別一覧とテストケースを突合する
2. 各種別のカバレッジ状況を一覧化する

**期待される成果物**:

- message 種別カバレッジ表

### Task 2: 項目別 coverage の確認

**目的**: `session_id` / provenance / result subtype coverage を確認する。

**実行手順**:

1. 各項目の正常系・異常系テストの有無を確認する
2. カバレッジギャップがあれば報告する

**期待される成果物**:

- 項目別カバレッジ表
