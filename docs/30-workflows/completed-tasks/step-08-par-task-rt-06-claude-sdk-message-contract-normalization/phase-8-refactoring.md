## 目的

重複した message 変換や UI 依存ロジックを整理し、正規化責務を一点に集約する。

## 背景

Phase 5 で実装した normalizer と Facade 統合にはストリーム変換の重複や SDK 生イベントへの残存依存が生じうる。リファクタリングでこれらを解消し、正規化責務を一点に集約する。

## 実行タスク

### Task 1: duplicate 変換ロジックを削減する

**目的**: 複数箇所に散在する message 変換ロジックを統合し、重複を排除する

**実行手順**:

1. 現在の変換ロジックの重複箇所を特定する
2. 共通化可能な処理を抽出し、正規化層に一元化する

**期待される成果物**:

- 重複が排除された変換ロジック

### Task 2: SDK 生イベント依存を除去する

**目的**: renderer や UI 層から SDK 生イベントへの直接依存を除去する

**実行手順**:

1. SDK 生イベントを直接参照している箇所を洗い出す
2. 正規化済みイベントへの参照に置き換える

**期待される成果物**:

- SDK 生イベント依存が除去されたコード
