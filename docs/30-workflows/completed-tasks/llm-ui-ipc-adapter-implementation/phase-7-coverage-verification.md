## 実行手順

### 1. カバレッジ再測定

```bash
pnpm --filter @repo/desktop test:coverage
```

### 2. 統合テスト実行

```bash
pnpm --filter @repo/desktop test:run
```

### 3. 未達の場合の対応

カバレッジ未達や統合テスト失敗がある場合、Phase 6へ戻って拡充する。
