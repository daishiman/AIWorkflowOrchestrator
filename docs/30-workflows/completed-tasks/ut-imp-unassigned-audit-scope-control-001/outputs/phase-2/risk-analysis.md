# Phase 2 リスク分析

| リスク                       | 影響            | 対策                                         |
| ---------------------------- | --------------- | -------------------------------------------- |
| `--target-file` のパス誤指定 | 誤判定/監査漏れ | 存在確認 + 監査対象ディレクトリ制約 + exit 2 |
| `--diff-from` 参照解決失敗   | CI不安定化      | gitエラーを明示して exit 2                   |
| 既存利用者への破壊的影響     | 運用停止        | scope未指定時は旧挙動を維持                  |
| baseline隠蔽                 | 健全性低下      | baselineはJSONで保持し可視化継続             |
