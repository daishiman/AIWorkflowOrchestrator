## 目的

エンティティ抽出サービス (NER) の機能要件・非機能要件を定義し、受け入れ基準を明確化する。

## 背景

HybridRAGパイプラインにおけるKnowledge Graph構築の基盤として、ドキュメントチャンクからエンティティを抽出する機能が必要。LLMベースとルールベースの2つのアプローチで、精度と処理速度のトレードオフに対応する。

## 機能要件

### FR-001: LLMベースエンティティ抽出

| ID       | 要件                                                                 | 優先度 |
| -------- | -------------------------------------------------------------------- | ------ |
| FR-001-1 | ドキュメントチャンクからエンティティを抽出できる                     | 必須   |
| FR-001-2 | エンティティタイプ（person, organization, technology等）を分類できる | 必須   |
| FR-001-3 | 信頼度スコアを付与できる                                             | 必須   |
| FR-001-4 | エンティティの説明を生成できる（オプション）                         | 任意   |
| FR-001-5 | エンティティのエイリアス（別名）を抽出できる                         | 任意   |

### FR-002: ルールベースエンティティ抽出

| ID       | 要件                                         | 優先度 |
| -------- | -------------------------------------------- | ------ |
| FR-002-1 | パターンマッチングでエンティティを抽出できる | 必須   |
| FR-002-2 | 技術名・組織名・日付を正規表現で検出できる   | 必須   |
| FR-002-3 | LLM不可時のフォールバックとして機能する      | 必須   |

### FR-003: バッチ処理

| ID       | 要件                                             | 優先度 |
| -------- | ------------------------------------------------ | ------ |
| FR-003-1 | 複数チャンクからバッチでエンティティを抽出できる | 必須   |
| FR-003-2 | 重複エンティティをマージできる                   | 必須   |
| FR-003-3 | マージ時にメンション情報を集約できる             | 必須   |

### FR-004: フィルタリング

| ID       | 要件                                     | 優先度 |
| -------- | ---------------------------------------- | ------ |
| FR-004-1 | エンティティタイプでフィルタリングできる | 必須   |
| FR-004-2 | 信頼度スコアでフィルタリングできる       | 必須   |
| FR-004-3 | 最大抽出数を制限できる                   | 必須   |

---

## 非機能要件

### NFR-001: パフォーマンス

| ID        | 要件                   | 目標値            |
| --------- | ---------------------- | ----------------- |
| NFR-001-1 | 単一チャンク処理時間   | 3秒以内（LLM）    |
| NFR-001-2 | バッチ処理スループット | 100チャンク/分    |
| NFR-001-3 | ルールベース処理時間   | 10ms以内/チャンク |

### NFR-002: 精度

| ID        | 要件                   | 目標値  |
| --------- | ---------------------- | ------- |
| NFR-002-1 | エンティティ抽出再現率 | 80%以上 |
| NFR-002-2 | エンティティ分類精度   | 90%以上 |

### NFR-003: 信頼性

| ID        | 要件                             | 目標値                     |
| --------- | -------------------------------- | -------------------------- |
| NFR-003-1 | LLMエラー時のフォールバック      | ルールベースに自動切り替え |
| NFR-003-2 | レスポンスパース失敗時のリトライ | 3回まで                    |
