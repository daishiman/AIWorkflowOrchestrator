### Task 8-2: リファクタリング判定

| 対象                      | Before                       | After                        | 理由                                                                                                          |
| ------------------------- | ---------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Loading skeleton          | 各パネルに個別実装           | 共通化は**見送り**           | data-testid が異なり、レイアウトも微妙に異なるため共通化のメリットが薄い                                      |
| null ガード + ErrorBanner | 各パネルに個別実装           | 共通化は**見送り**           | 3行程度のガード。HOC/ラッパーにするとかえって複雑                                                             |
| 折りたたみセクション      | useState + button + pre/code | パターンは同一だが**見送り** | PlanResultDetailPanel の skillSpec と ImproveResultDetailPanel の revisedSpec で props 名・表示ラベルが異なる |

**結論**: 現状の実装で十分シンプル。過度な共通化は SRP に反するため見送り。result-panel-parts.tsx の既存部品で十分な再利用が達成されている。
