# Phase 11: 手動テスト検証 — SkillEditor コンポーネント実装

## メタ情報

| 項目   | 値                                       |
| ------ | ---------------------------------------- |
| Phase  | 11                                       |
| 機能名 | TASK-9A-C SkillEditor コンポーネント実装 |
| 作成日 | 2026-02-19                               |

## 目的

自動テストでは検証できないユーザー体験・実環境動作を手動で確認する。SkillEditor のファイルツリー表示、ファイル読込、編集/未保存表示、保存、閉じる操作を実機で検証する。

## 実行タスク

- 機能テスト（正常系）: ファイルツリー表示、ファイル選択/読込、編集/未保存表示、保存、閉じる
- 機能テスト（異常系）: 読込エラー時のUI、保存エラー時のUI、存在しないファイル
- UI/UXテスト: レイアウト確認、レスポンシブ対応、キーボードショートカット
- アクセシビリティテスト: フォーカス管理、ARIAラベル、キーボード操作
- 統合テスト: IPC連携、スキル切り替え時のリセット
- リグレッションテスト: 既存機能への影響がないことを確認

## 統合テスト連携【必須】

本 Phase の統合テストは、Phase 6（テスト拡充）で作成された自動テストを補完する形で実施する。自動テストでカバーできない以下の観点を手動で検証する:

| 自動テスト（Phase 6）              | 手動テスト（本Phase）                 |
| ---------------------------------- | ------------------------------------- |
| IPC モック経由のコンポーネント動作 | 実 IPC チャネル経由のエンドツーエンド |
| happy-dom 上の DOM 操作確認        | 実ブラウザ上の描画・レイアウト確認    |
| プログラム的イベント発火           | ユーザー操作（マウス/キーボード）確認 |
| エラー状態のモック検証             | 実環境でのエラー発生・通知フロー確認  |

### 手動統合テスト観点

| テスト項目         | 確認内容                                                                       | 期待結果                                               | 実行結果 |
| ------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------ | -------- |
| API接続            | IPC チャネル（readFile/writeFile）が正常に応答する                             | DevTools Console でエラーがないことを確認              |          |
| 認証フロー         | 認証状態に応じたスキルアクセス制御が正常に動作する                             | 未認証状態・認証済み状態の両方でアクセスを確認         |          |
| データ永続化       | ファイル保存が実際のファイルシステムに反映される                               | 保存後にアプリ再起動し、変更が保持されていることを確認 |          |
| エラーハンドリング | IPC エラー・ファイルシステムエラーがユーザーにエラーメッセージとして表示される | 意図的にエラーを発生させ、通知を確認                   |          |
| 状態同期           | スキル切替時にエディタ状態（選択ファイル・内容・未保存フラグ）がリセットされる | スキルを切り替えて状態のリセットを確認                 |          |
