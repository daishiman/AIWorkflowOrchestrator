## 実行手順

### ステップ1: 設計レビューチェックリスト

**GovernanceSummaryPanel**:

- [ ] Props なしの self-contained 設計が意図通りか
- [ ] `useEffect` のクリーンアップが適切か（setInterval/clearInterval）
- [ ] IPC エラー時のフォールバックが定義されているか
- [ ] ポーリング間隔（5秒）が UX 上適切か

**全フェーズ配線**:

- [ ] execute phase の既存テストへの影響がないか
- [ ] `createGovernanceHooks()` の引数型が正確か
- [ ] Facade のメソッドシグネチャ変更が最小限か

**セキュリティ**:

- [ ] renderer に公開される governance payload に機密情報が含まれていないか
- [ ] IPC チャネルの認証確認

### ステップ2: ゲート判定基準

| 判定     | 条件                                                       |
| -------- | ---------------------------------------------------------- |
| PASS     | 全チェック通過、MINOR なし                                 |
| MINOR    | 軽微な懸念事項あり、Phase 4 進行可能（追跡テーブルに記録） |
| MAJOR    | 設計上の問題あり、Phase 2 に戻って修正が必要               |
| CRITICAL | アーキテクチャ上の根本的問題、全面見直し必要               |
