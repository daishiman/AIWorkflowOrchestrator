## 目的

静的解析、セキュリティチェック、パフォーマンス確認を行い、コードの品質を保証する。

## 背景

リファクタリングが完了し、コード品質が向上した。最終レビューに進む前に、自動化されたチェックで品質を確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析（ESLint）

**目的**: ESLintで静的解析エラーがないことを確認する

**実行手順**:

1. ESLintを実行する:

```bash
pnpm --filter @repo/desktop lint
```

2. エラーがある場合は修正する

3. 結果を記録する:

```markdown
## ESLint結果

### 実行結果

- エラー数: 0
- 警告数: 0

### 修正した項目

（あれば記載）
```

**期待される成果物**:

- `outputs/phase-9/eslint-result.md`

---

### タスク2: 型チェック（TypeScript）

**目的**: TypeScript型エラーがないことを確認する

**実行手順**:

1. 型チェックを実行する:

```bash
pnpm --filter @repo/desktop typecheck
```

2. エラーがある場合は修正する

3. 結果を記録する

**期待される成果物**:

- `outputs/phase-9/typecheck-result.md`

---

### タスク3: フォーマットチェック（Prettier）

**目的**: コードフォーマットが統一されていることを確認する

**実行手順**:

1. Prettierを実行する:

```bash
pnpm --filter @repo/desktop format:check
```

2. フォーマットが崩れている場合は修正する:

```bash
pnpm --filter @repo/desktop format
```

**期待される成果物**:

- フォーマット済みソースコード

---

### タスク4: セキュリティチェック

**目的**: セキュリティ上の問題がないことを確認する

**実行手順**:

1. 依存関係の脆弱性をチェックする:

```bash
pnpm audit
```

2. コード内のセキュリティ確認:

| チェック項目             | 結果 |
| ------------------------ | ---- |
| パストラバーサル防止     | ✓    |
| IPC sender検証           | ✓    |
| 入力バリデーション       | ✓    |
| 機密情報のログ出力防止   | ✓    |
| エラーメッセージの安全性 | ✓    |

3. 結果を記録する

**期待される成果物**:

- `outputs/phase-9/security-check.md`

---

### タスク5: パフォーマンス確認

**目的**: パフォーマンス要件を満たしていることを確認する

**実行手順**:

1. パフォーマンス要件を確認する:

| 要件             | 目標      |
| ---------------- | --------- |
| 初回スキャン     | 3秒以内   |
| キャッシュ利用時 | 100ms以内 |

2. パフォーマンステストを実行する（該当する場合）

3. 結果を記録する

**期待される成果物**:

- `outputs/phase-9/performance-check.md`

---

### タスク6: テスト最終実行

**目的**: 全テストが成功することを最終確認する

**実行手順**:

1. 全テストを実行する:

```bash
pnpm --filter @repo/desktop test
```

2. 統合テストを実行する:

```bash
pnpm --filter @repo/desktop test src/main/services/skill/__tests__/integration.test.ts
```

3. 結果を記録する

**期待される成果物**:

- `outputs/phase-9/final-test-result.md`

---
