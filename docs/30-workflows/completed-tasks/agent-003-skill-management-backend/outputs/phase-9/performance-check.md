## 設計上のパフォーマンス考慮

### 1. キャッシュ機構

**実装箇所**: `SkillService.ts`

```typescript
private cache: Map<string, Skill> = new Map();
private lastScanTime: Date | null = null;
```

**評価**:

- `Map`によるO(1)キャッシュルックアップ
- `forceRefresh`フラグでキャッシュ無効化制御
- キャッシュヒット時はディスクI/Oなし

### 2. 遅延スキャン

**実装箇所**: `SkillService.scanAvailableSkills()`

```typescript
if (!forceRefresh && this.cache.size > 0 && this.lastScanTime) {
  return {
    skills: Array.from(this.cache.values()),
    errors: [],
    scannedAt: this.lastScanTime,
  };
}
```

**評価**:

- 初回スキャン後はキャッシュから即座に返却
- 不要な再スキャンを回避

### 3. ディレクトリスキャン最適化

**実装箇所**: `SkillScanner.scanDirectory()`

**評価**:

- `readdir`で1階層のみスキャン（再帰なし）
- 隠しディレクトリを早期スキップ
- SKILL.mdの存在チェックは`fs.access`で軽量に確認
