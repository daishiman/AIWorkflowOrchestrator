## 1. 機能要件

### 1.1 利用可能スキル一覧取得

| 項目        | 内容                                                                     |
| ----------- | ------------------------------------------------------------------------ |
| IPCチャネル | `agent:scan-available-skills`                                            |
| 説明        | 指定されたディレクトリからSKILL.mdを持つスキルを検出し、メタデータを返す |
| 入力        | `{ basePath?: string }` - 省略時はデフォルトパス                         |
| 出力        | `SkillScanResult` - スキル配列とエラー情報                               |

### 1.2 インポート済みスキル一覧取得

| 項目        | 内容                                       |
| ----------- | ------------------------------------------ |
| IPCチャネル | `agent:get-imported-skills`                |
| 説明        | ユーザーがインポート済みのスキル一覧を返す |
| 入力        | なし                                       |
| 出力        | `Skill[]` - インポート済みスキルの配列     |

### 1.3 スキルインポート

| 項目        | 内容                                   |
| ----------- | -------------------------------------- |
| IPCチャネル | `agent:import-skills`                  |
| 説明        | 指定されたスキルをインポート状態にする |
| 入力        | `{ skillIds: string[] }`               |
| 出力        | `ImportResult` - インポート結果        |

### 1.4 スキル削除

| 項目        | 内容                                             |
| ----------- | ------------------------------------------------ |
| IPCチャネル | `agent:remove-skill`                             |
| 説明        | インポート済みスキルをインポート一覧から削除する |
| 入力        | `{ skillId: string }`                            |
| 出力        | `RemoveResult` - 削除結果                        |

### 1.5 スキル詳細取得

| 項目        | 内容                             |
| ----------- | -------------------------------- | ----- |
| IPCチャネル | `agent:get-skill-detail`         |
| 説明        | 指定されたスキルの詳細情報を返す |
| 入力        | `{ skillId: string }`            |
| 出力        | `Skill                           | null` |

### 1.6 スキルパス設定

| 項目       | 内容                                               |
| ---------- | -------------------------------------------------- |
| 説明       | スキルを検索するベースディレクトリを設定可能にする |
| デフォルト | `~/.claude/skills/`                                |
| 永続化     | electron-storeで保存                               |

## 2. 非機能要件

### 2.1 パフォーマンス

| 要件             | 目標値                         |
| ---------------- | ------------------------------ |
| 初回スキャン     | 3秒以内                        |
| キャッシュ利用時 | 100ms以内                      |
| 並列スキャン     | ディレクトリ読み込みは並列実行 |

### 2.2 セキュリティ

| 要件                 | 詳細                                                  |
| -------------------- | ----------------------------------------------------- |
| パストラバーサル防止 | `../`を含むパスを拒否、ベースパス外へのアクセスを禁止 |
| IPC sender検証       | DevToolsからの呼び出しを検出・拒否                    |
| 入力バリデーション   | skillIdの形式検証、パスの正規化                       |

### 2.3 永続化

| 要件       | 詳細                                       |
| ---------- | ------------------------------------------ |
| ストレージ | electron-store使用                         |
| 保存対象   | インポート済みスキルID一覧、スキルパス設定 |
| 暗号化     | 不要（機密情報なし）                       |

### 2.4 エラーハンドリング

| 要件         | 詳細                                     |
| ------------ | ---------------------------------------- |
| 部分的失敗   | 1つのスキル解析失敗で全体が失敗しない    |
| エラー収集   | 解析エラーを`SkillScanError[]`として返却 |
| ユーザー通知 | 致命的エラーのみUI表示、警告はログのみ   |

---

## 3. 制約事項

- スキル実行機能は含まない（AGENT-005で実装）
- 実行環境管理は含まない（AGENT-007で実装）
- スキル編集・作成機能はスコープ外
- ファイル変更監視は初期実装では除外
