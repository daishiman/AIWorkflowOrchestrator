## 目的

TDDのRefactor段階として、テストを維持しながらコード品質を改善する。重複排除、命名改善、構造整理を行い、保守性を向上させる。

## 背景

カバレッジ確認が完了し、十分なテストで保護された状態になった。この状態でリファクタリングを行い、コードの品質を向上させる。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コード品質分析

**目的**: リファクタリング対象を特定する

**実行手順**:

1. 以下の観点で分析する:

| 観点             | チェック項目                                       |
| ---------------- | -------------------------------------------------- |
| 重複コード       | 同一・類似のコードが複数箇所にないか               |
| 長いメソッド     | 1メソッドが長すぎないか（50行以上）                |
| 複雑な条件分岐   | ネストが深すぎないか（3段以上）                    |
| 命名の不明確さ   | 変数・関数名が意図を表しているか                   |
| 責務の混在       | 1クラス/関数が複数の責務を持っていないか           |
| マジックナンバー | 意味のない数値・文字列がハードコードされていないか |

2. リファクタリング対象をリストアップする:

```markdown
## リファクタリング対象

### 高優先度

| 対象                | 問題           | 改善案             |
| ------------------- | -------------- | ------------------ |
| SkillParser.parse() | メソッドが長い | 内部メソッドに分割 |

### 中優先度

| 対象 | 問題 | 改善案 |
| ---- | ---- | ------ |

### 低優先度

| 対象 | 問題 | 改善案 |
| ---- | ---- | ------ |
```

**期待される成果物**:

- `outputs/phase-8/code-analysis.md`

---

### タスク2: 重複コード排除

**目的**: 重複コードを共通化する

**実行手順**:

1. 重複コードを特定する
2. 共通関数・クラスを作成する
3. テストが通ることを確認する

```bash
pnpm --filter @repo/desktop test
```

4. 変更を記録する

**期待される成果物**:

- 更新されたソースコード
- `outputs/phase-8/refactoring-log.md`（変更記録）

---

### タスク3: 命名改善

**目的**: 変数・関数・クラス名を改善する

**実行手順**:

1. 不明確な命名を特定する
2. 意図が明確な名前に変更する
3. テストが通ることを確認する

```bash
pnpm --filter @repo/desktop test
```

**期待される成果物**:

- 更新されたソースコード

---

### タスク4: 構造整理

**目的**: コード構造を整理する

**実行手順**:

1. 長いメソッドを分割する
2. 複雑な条件分岐を簡略化する
3. 責務を明確に分離する
4. テストが通ることを確認する

```bash
pnpm --filter @repo/desktop test
```

**期待される成果物**:

- 更新されたソースコード

---

### タスク5: 型安全性強化

**目的**: TypeScriptの型安全性を強化する

**実行手順**:

1. any型の使用を排除する
2. 型ガードを追加する（必要に応じて）
3. 型チェックを実行する:

```bash
pnpm --filter @repo/desktop typecheck
```

4. エラーがないことを確認する

**期待される成果物**:

- 型エラーのないソースコード

---

### タスク6: リファクタリング後テスト確認

**目的**: リファクタリング後もテストが通ることを確認する

**実行手順**:

1. 全テストを実行する:

```bash
pnpm --filter @repo/desktop test
```

2. 全テストが成功することを確認する

3. カバレッジが維持されていることを確認する:

```bash
pnpm --filter @repo/desktop test:coverage
```

4. 結果を記録する

**期待される成果物**:

- `outputs/phase-8/refactoring-test-result.md`
