## 目的

自動テストでは検証できないパイプライン全体の動作・エッジケースを手動で確認する。

## 背景

HybridRAGエンジンはバックエンドコンポーネントであり、UIテストは不要だが、パイプライン全体の動作確認や実際のデータを使用した検証が必要である。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連自動テストの確認

**目的**: 関連する自動テストが全て成功することを確認する

**実行手順**:

1. 全テストを実行:
   ```bash
   pnpm --filter @repo/shared test
   ```
2. 結果を確認:
   - [ ] 全ユニットテストがPASS
   - [ ] 全統合テストがPASS

**期待される成果物**:

- テスト実行結果

### タスク2: パイプライン動作確認

**目的**: パイプライン全体の動作を手動で確認する

**実行手順**:

1. テストデータを準備:
   - 検索クエリのサンプル（ローカル/グローバル/リレーションシップ/ハイブリッド）
   - 期待される結果の定義
2. 各クエリタイプでパイプラインを実行:
   | TC-ID | クエリタイプ | クエリ例 | 期待結果 | 結果 |
   | ------ | -------------- | ------------------------------ | ---------------------- | ---- |
   | TC-001 | local | "TypeScriptの型安全性について" | 関連チャンクが返る | {{RESULT}} |
   | TC-002 | global | "プロジェクト全体の構造は？" | コミュニティ要約が含まれる | {{RESULT}} |
   | TC-003 | relationship | "AとBの関係は？" | 関係パスが含まれる | {{RESULT}} |
   | TC-004 | hybrid | "設計パターンの適用例" | バランスの取れた結果 | {{RESULT}} |
3. メタデータを確認:
   - [ ] queryTypeが正しく判定されている
   - [ ] searchWeightsが適切に設定されている
   - [ ] pipelineStagesが全て記録されている
   - [ ] totalDurationが記録されている

**期待される成果物**:

- パイプライン動作確認結果
