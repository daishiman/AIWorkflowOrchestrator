## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。

## 背景

テストカバレッジが目標基準（Line 80%+, Branch 60%+, Function 80%+）を満たしているかを検証し、未達の場合はPhase 6に戻って追加テストを作成する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ再測定

**目的**: Phase 6後のカバレッジを再測定する

**実行手順**:

1. カバレッジを測定:
   ```bash
   pnpm --filter @repo/shared test:coverage
   ```
2. 結果を確認:
   | 指標 | 目標 | 達成値 | 判定 |
   | -------- | ----- | ------ | ---- |
   | Line | 80%+ | {{%}} | {{PASS/FAIL}} |
   | Branch | 60%+ | {{%}} | {{PASS/FAIL}} |
   | Function | 80%+ | {{%}} | {{PASS/FAIL}} |
3. 未達の場合はPhase 6に戻る

**期待される成果物**:

- カバレッジ測定結果

---

### タスク2: 統合テスト実行

**目的**: 統合テストを実行し、全て成功することを確認する

**実行手順**:

1. 統合テストを実行:
   ```bash
   pnpm --filter @repo/shared test -- --grep "Integration"
   ```
2. 結果を確認:
   | テストカテゴリ | 結果 |
   | -------------- | -------- |
   | パイプライン連携 | {{PASS/FAIL}} |
   | 部分失敗 | {{PASS/FAIL}} |
   | 全失敗 | {{PASS/FAIL}} |
   | CRAG補正 | {{PASS/FAIL}} |
3. 失敗がある場合はPhase 5に戻る

**期待される成果物**:

- 統合テスト実行結果

---

### タスク3: ゲート判定

**目的**: Phase 7のゲート判定を行う

**実行手順**:

1. カバレッジゲートを判定:
   - [ ] Line Coverage ≥ 80%
   - [ ] Branch Coverage ≥ 60%
   - [ ] Function Coverage ≥ 80%
2. テストゲートを判定:
   - [ ] 全ユニットテスト成功
   - [ ] 全統合テスト成功
3. 総合判定:
   | 判定 | 条件 | 次のアクション |
   | ---- | ------------------------ | ----------------------- |
   | PASS | 全ゲートクリア | Phase 8へ進行 |
   | FAIL | カバレッジ未達 | Phase 6へ戻る |
   | FAIL | テスト失敗あり | Phase 5へ戻る |

**期待される成果物**:

- ゲート判定結果
