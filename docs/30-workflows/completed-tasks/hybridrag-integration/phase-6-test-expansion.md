## 目的

Phase 5の実装に対してテストを拡充し、カバレッジ目標を達成する。

## 背景

TDD Green状態の実装に対して、追加のテストケースを作成し、カバレッジ目標（Line 80%+, Branch 60%+, Function 80%+）を達成する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ分析

**目的**: 現在のテストカバレッジを測定し、不足領域を特定する

**実行手順**:

1. カバレッジを測定:
   ```bash
   pnpm --filter @repo/shared test:coverage
   ```
2. カバレッジレポートを分析:
   - Line Coverage: 目標80%
   - Branch Coverage: 目標60%
   - Function Coverage: 目標80%
3. 不足領域を特定:
   - 未カバーの行
   - 未カバーの分岐
   - 未カバーの関数

**期待される成果物**:

- カバレッジ分析レポート

---

### タスク2: 追加テスト作成

**目的**: カバレッジ目標達成に向けた追加テストを作成する

**実行手順**:

1. エラーパスのテストを追加:
   ```typescript
   describe("エラーハンドリング", () => {
     it("QueryClassifier失敗時はエラーを返す");
     it("Reranker失敗時はfusedResultsを使用する");
     it("CRAG失敗時はrerankedResultsを使用する");
     it("タイムアウト時はエラーを返す");
   });
   ```
2. 境界条件のテストを追加:
   ```typescript
   describe("境界条件", () => {
     it("結果が0件の場合は空配列を返す");
     it("重複結果がある場合は適切に処理される");
     it("スコアが同一の場合のソート順が安定している");
   });
   ```
3. パフォーマンス関連のテストを追加:
   ```typescript
   describe("パフォーマンス", () => {
     it("並列検索が順次検索より高速である");
     it("メトリクスが正確に記録される");
   });
   ```

**期待される成果物**:

- 追加テストケース

---

### タスク3: 統合テスト拡充

**目的**: 統合テストのカバレッジを向上する

**実行手順**:

1. 統合テストを拡充:
   | テストカテゴリ | 検証項目 | 目標 |
   | ------------------ | ------------------------------------------ | ------ |
   | パイプライン正常系 | 全4ステージの正常フロー | 100% |
   | 部分失敗 | 各検索戦略の失敗パターン | 100% |
   | 全失敗 | 全戦略失敗時のエラー | 100% |
   | CRAG補正 | correct/incorrect/ambiguous | 100% |
   | エッジケース | 空結果、重複、タイムアウト | 80%+ |
2. 統合テストファイルを更新:
   `packages/shared/src/services/search/__tests__/hybrid-rag-engine.integration.test.ts`

**期待される成果物**:

- 統合テストの拡充
