# Phase 2 導線設計

| カード種別 | 補助導線         | 実装方式                                                   | 失敗時挙動                                        |
| ---------- | ---------------- | ---------------------------------------------------------- | ------------------------------------------------- |
| chat       | `やりとりを見る` | `Link` で `/chat/history/:sessionId` へ遷移                | route 不達時は BrowserRouter の標準エラー面に委譲 |
| file       | `エディタで開く` | store に pending path を積み `currentView="editor"` へ切替 | file read 失敗時は EditorView 側エラー面          |
| skill      | `実行情報を確認` | アコーディオン内に詳細を表示し、画面遷移は行わない         | metadata 欠損時は `不明` 表示                     |

## 禁止事項

- chat/file/skill いずれもカードタップ時に全画面遷移しない
- 検索バー操作で view history を汚さない
