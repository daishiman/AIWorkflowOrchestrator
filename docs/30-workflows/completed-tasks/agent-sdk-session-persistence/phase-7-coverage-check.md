## 目的

Phase 6までに作成したテストのカバレッジを計測し、目標カバレッジ（Line 80%+, Branch 60%+, Function 80%+）を達成していることを確認する。未達の場合は追加テストを作成する。

## 背景

テストカバレッジは品質の重要な指標の一つ。目標カバレッジを達成することで、実装の信頼性を担保する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ計測

**目的**: 現在のテストカバレッジを計測する

**実行手順**:

1. 以下のコマンドでカバレッジを計測:

```bash
pnpm --filter @repo/desktop test -- --coverage --testPathPattern="session"
```

2. カバレッジレポートを確認
3. 結果を記録

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: カバレッジギャップ分析

**目的**: 目標に未達の部分を特定する

**実行手順**:

1. 以下の目標との差分を分析:
   - Line Coverage: 80%+ 目標
   - Branch Coverage: 60%+ 目標
   - Function Coverage: 80%+ 目標
2. 未カバーのコードパスを特定
3. ギャップ分析結果を記録

**期待される成果物**:

- `outputs/phase-7/coverage-gap-analysis.md`

---

### タスク3: 追加テスト作成（必要な場合）

**目的**: 目標カバレッジ達成のための追加テストを作成する

**実行手順**:

1. 未カバーのコードパスに対するテストを作成
2. テストを実行して成功を確認
3. 再度カバレッジを計測

**期待される成果物**:

- 追加テストファイル（必要な場合）

---

### タスク4: 統合テスト結果確認

**目的**: 統合テストの結果を確認する

**実行手順**:

1. 統合テストを実行:

```bash
pnpm --filter @repo/desktop test -- --testPathPattern="integration"
```

2. 全統合テストが成功することを確認
3. 結果を記録

**期待される成果物**:

- `outputs/phase-7/integration-test-result.md`

---

### タスク5: ゲート判定

**目的**: カバレッジゲートの合否を判定する

**実行手順**:

1. 以下の基準で判定:

| 指標              | 目標 | 判定 |
| ----------------- | ---- | ---- |
| Line Coverage     | 80%+ | ?    |
| Branch Coverage   | 60%+ | ?    |
| Function Coverage | 80%+ | ?    |

2. PASS/FAILを判定
3. ゲート判定結果を記録

**期待される成果物**:

- `outputs/phase-7/gate-result.md`
