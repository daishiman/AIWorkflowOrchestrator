## 目的

静的解析・型チェック・セキュリティスキャンを実行し、コード品質が基準を満たしていることを確認する。

## 背景

実装・リファクタリングが完了した段階で、自動化された品質チェックを実行し、本番リリースに耐えうる品質であることを担保する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ESLintチェック

**目的**: 静的解析でコード品質を確認する

**実行手順**:

1. 以下のコマンドでESLintを実行:

```bash
pnpm --filter @repo/desktop lint
```

2. エラー・警告を確認
3. 必要に応じて修正
4. 結果を記録

**期待される成果物**:

- `outputs/phase-9/eslint-result.md`

---

### タスク2: TypeScriptチェック

**目的**: 型エラーがないことを確認する

**実行手順**:

1. 以下のコマンドで型チェックを実行:

```bash
pnpm --filter @repo/desktop typecheck
```

2. 型エラーがないことを確認
3. 結果を記録

**期待される成果物**:

- `outputs/phase-9/typecheck-result.md`

---

### タスク3: セキュリティスキャン

**目的**: セキュリティ脆弱性がないことを確認する

**実行手順**:

1. 以下の観点でセキュリティチェック:
   - 永続化データに機密情報が含まれていないか
   - ファイルパスインジェクションの可能性
   - IPC通信でのバリデーション
2. 脆弱性が発見された場合は修正
3. 結果を記録

**期待される成果物**:

- `outputs/phase-9/security-check.md`

---

### タスク4: パフォーマンスチェック

**目的**: パフォーマンス要件を満たしていることを確認する

**実行手順**:

1. 以下のパフォーマンス要件をチェック:
   - 起動時復元: +100ms以内
   - セッション保存: 50ms以内
   - セッション一覧取得: 20ms以内
2. 計測結果を記録
3. 要件未達の場合は最適化

**期待される成果物**:

- `outputs/phase-9/performance-check.md`

---

### タスク5: 最終テスト実行

**目的**: 全テストが成功することを確認する

**実行手順**:

1. 以下のコマンドで全テストを実行:

```bash
pnpm --filter @repo/desktop test -- --testPathPattern="session"
```

2. 全テストが成功することを確認
3. 結果を記録

**期待される成果物**:

- `outputs/phase-9/final-test-result.md`

---

### タスク6: 品質サマリー作成

**目的**: 品質チェック結果を総合する

**実行手順**:

1. 各チェック結果を集約
2. 品質ゲートの合否を判定
3. 品質サマリーを作成

**期待される成果物**:

- `outputs/phase-9/quality-summary.md`
