## 2. 検出タスク一覧

### 2.1 Renderer統合（UI連携）

- **ソース**: Phase 11 手動テスト計画
- **重要度**: 中
- **概要**: Main Process側の永続化サービスは完了したが、Renderer側（UI）との統合が未実装
- **推奨対応**: 別ワークフローで `AgentSDKPage` のセッション一覧UIと永続化サービスを統合

**詳細**:

- IPCハンドラーはmain.tsへの登録が必要
- Preload APIの公開が必要
- React側のhooksまたはstoreとの連携が必要

**関連ファイル**:

- `apps/desktop/src/renderer/pages/AgentSDKPage/index.tsx`
- `apps/desktop/src/preload/index.ts`

### 2.2 自動バックアップ機能の実装

- **ソース**: Phase 2 設計仕様
- **重要度**: 低
- **概要**: `enableAutoBackup` と `backupRetentionCount` の設定は定義済みだが、実際のバックアップ処理は未実装
- **推奨対応**: 運用要件に応じて後日実装

**詳細**:

- 設定: `enableAutoBackup: true`, `backupRetentionCount: 3`
- 現状: 設定値のみ存在、バックアップロジック未実装
- 影響: データ喪失リスクは低（electron-storeは自動的にatomic writeを行う）

検出された課題は **既存の未タスクフォーマット** に該当しないため、新規タスクファイルの作成は **保留** とする。

**理由**:

1. Renderer統合は本ワークフローの「範囲外」として明記されている
2. 自動バックアップは「優先度：低」であり、現時点では運用上の問題がない

**将来的なタスク化の判断基準**:

- Renderer統合が必要になった場合: `task-agent-sdk-ui-persistence-integration.md` を作成
- バックアップ機能が必要になった場合: `task-agent-sdk-session-backup.md` を作成
