## 2. パフォーマンス要件

### NFR-001: 起動時復元性能

| 項目     | 内容                                               |
| -------- | -------------------------------------------------- |
| 要件ID   | NFR-001                                            |
| 要件名   | 起動時復元性能                                     |
| 説明     | アプリ起動時のセッション復元が許容時間内に完了する |
| 基準値   | +100ms以内（ベースライン比）                       |
| 測定方法 | アプリ起動〜UIレンダリング完了までの時間計測       |

**詳細:**

- セッション一覧の読み込み: 50ms以内
- 最後のアクティブセッションのメッセージ読み込み: 50ms以内
- 総計: ベースライン起動時間 +100ms以内

### NFR-002: セッション保存性能

| 項目     | 内容                                   |
| -------- | -------------------------------------- |
| 要件ID   | NFR-002                                |
| 要件名   | セッション保存性能                     |
| 説明     | セッション保存操作がUIをブロックしない |
| 基準値   | 非同期処理、UIスレッドブロック0ms      |
| 測定方法 | IPC呼び出し〜完了までの時間計測        |

**詳細:**

- 保存処理は非同期で実行
- Main Processで処理、Renderer Processへの影響なし
- バッファリング: 100ms間隔でバッチ書き込み

### NFR-003: メッセージ読み込み性能

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| 要件ID   | NFR-003                                  |
| 要件名   | メッセージ読み込み性能                   |
| 説明     | セッション切り替え時のメッセージ読み込み |
| 基準値   | 100件: 50ms以内、1000件: 200ms以内       |
| 測定方法 | loadMessages呼び出し〜返却までの時間計測 |

| 項目   | 内容                         |

## 4. LRU削除ポリシー

### NFR-007: LRU自動削除

| 項目     | 内容                                       |
| -------- | ------------------------------------------ |
| 要件ID   | NFR-007                                    |
| 要件名   | LRU自動削除                                |
| 説明     | 容量上限到達時に最古のセッションを自動削除 |
| トリガー | 容量が上限の90%に達した時点                |
| 削除対象 | lastAccessedAtが最も古いセッション         |

**削除フロー:**

1. 容量が45MB（90%）に達した時点で警告
2. 容量が50MB（100%）に達した時点でLRU削除開始
3. 10%（5MB）の空き容量を確保するまで削除
4. 削除されたセッション数をログ出力

| 要件ID   | NFR-012                                      |
| 要件名   | データ整合性                                 |
| 説明     | 書き込み中断時もデータ破損を防ぐ             |
| 実装方法 | アトミック書き込み（electron-store標準機能） |

### NFR-013: エラーリカバリ

| 項目   | 内容                                   |
| ------ | -------------------------------------- |
| 要件ID | NFR-013                                |
| 要件名 | エラーリカバリ                         |
| 説明   | エラー発生時も機能を継続できる         |
| 対応   | 破損データのスキップ、デフォルト値適用 |

**リカバリフロー:**

1. データ読み込み時にバリデーションエラー発生
2. エラーが発生したセッションをスキップ
3. 正常なセッションのみを復元
4. エラーログを出力、ユーザーに警告表示
