## 1. 概要

セッション永続化機能の完了を判定するための受け入れ基準を定義する。各基準は機能要件（FR）および非機能要件（NFR）に対応する。

---

## 2. 機能受け入れ基準

### AC-001: セッション永続化（FR-001対応）

| 項目     | 内容                    |
| -------- | ----------------------- |
| 基準ID   | AC-001                  |
| 基準名   | セッション永続化        |
| 対応要件 | FR-001                  |
| 検証方法 | 自動テスト + 手動テスト |

**受け入れ条件:**

- [ ] 新規セッション作成時、electron-storeに保存される
- [ ] 保存データにsessionId, createdAt, lastAccessedAt, isActiveが含まれる
- [ ] セッション状態変更時に自動更新される
- [ ] IPC通信で保存処理が完了する

**検証手順:**

1. アプリを起動し、新規セッションを作成
2. electron-storeのデータファイルを確認
3. セッションデータが正しく保存されていることを検証

### AC-002: セッション復元（FR-002対応）

| 項目     | 内容                    |
| -------- | ----------------------- |
| 基準ID   | AC-002                  |
| 基準名   | セッション復元          |
| 対応要件 | FR-002                  |
| 検証方法 | 自動テスト + 手動テスト |

**受け入れ条件:**

- [ ] アプリ起動時に保存済みセッション一覧が復元される
- [ ] 復元されたセッションがサイドバーに表示される
- [ ] 最後にアクティブだったセッションが自動選択される（設定有効時）
- [ ] 復元に失敗した場合、エラーメッセージが表示される

**検証手順:**

1. セッションを3つ作成
2. アプリを完全終了
3. アプリを再起動
4. 3つのセッションが復元されていることを確認

### AC-003: メッセージ履歴永続化（FR-003対応）

| 項目     | 内容                    |
| -------- | ----------------------- |
| 基準ID   | AC-003                  |
| 基準名   | メッセージ履歴永続化    |
| 対応要件 | FR-003                  |
| 検証方法 | 自動テスト + 手動テスト |

**受け入れ条件:**

- [ ] ユーザーメッセージ送信時に永続化される
- [ ] アシスタント応答完了時に永続化される
- [ ] セッション切り替え時に正しいメッセージ履歴が読み込まれる
- [ ] アプリ再起動後もメッセージ履歴が復元される

**検証手順:**

1. セッションを作成し、メッセージを5往復送信
2. アプリを完全終了
3. アプリを再起動し、セッションを選択
4. 5往復のメッセージ履歴が表示されることを確認

### AC-004: セッション削除（FR-004対応）

| 項目     | 内容                    |
| -------- | ----------------------- |
| 基準ID   | AC-004                  |
| 基準名   | セッション削除          |
| 対応要件 | FR-004                  |
| 検証方法 | 自動テスト + 手動テスト |

**受け入れ条件:**

- [ ] 「Destroy Session」ボタンでセッションが削除される
- [ ] セッションメタデータとメッセージ履歴が同時に削除される
- [ ] 削除後、UIから該当セッションが消える
- [ ] アプリ再起動後も削除されたセッションは復元されない

**検証手順:**

1. セッションを作成し、メッセージを送信
2. 「Destroy Session」ボタンをクリック
3. セッションが一覧から消えることを確認
4. アプリを再起動し、削除したセッションが存在しないことを確認

### AC-005: セッション一覧表示（FR-005対応）

| 項目     | 内容                    |
| -------- | ----------------------- |
| 基準ID   | AC-005                  |
| 基準名   | セッション一覧表示      |

- [ ] 選択中のセッションがハイライトされる

### AC-006: 全セッションクリア（FR-006対応）

| 項目     | 内容               |
| -------- | ------------------ |
| 基準ID   | AC-006             |
| 基準名   | 全セッションクリア |

## 3. 非機能受け入れ基準

### AC-101: 起動時復元性能（NFR-001対応）

| 項目     | 内容                 |
| -------- | -------------------- |
| 基準ID   | AC-101               |
| 基準名   | 起動時復元性能       |
| 対応要件 | NFR-001              |
| 検証方法 | パフォーマンステスト |

**受け入れ条件:**

- [ ] 50セッション保存時、起動時間が+100ms以内
- [ ] 100セッション保存時、起動時間が+200ms以内
- [ ] セッション読み込み処理が50ms以内で完了

**検証手順:**

1. 50セッションを永続化
2. アプリの起動時間を計測（5回平均）
3. ベースライン（0セッション）との差が100ms以内であることを確認

### AC-102: 容量制限（NFR-004対応）

| 項目     | 内容             |
| -------- | ---------------- |
| 基準ID   | AC-102           |
| 基準名   | 容量制限         |
| 対応要件 | NFR-004, NFR-007 |
| 検証方法 | 自動テスト       |

**受け入れ条件:**

- [ ] デフォルト容量上限が50MBである
- [ ] 容量が90%に達した時点で警告が表示される
- [ ] 容量が100%に達した時点でLRU削除が実行される
- [ ] 削除後、10%の空き容量が確保される

### AC-103: データ保護（NFR-009対応）

| 項目     | 内容                        |
| -------- | --------------------------- |
| 基準ID   | AC-103                      |
| 基準名   | データ保護                  |
| 対応要件 | NFR-009, NFR-010            |
| 検証方法 | コードレビュー + 手動テスト |

**受け入れ条件:**

- [ ] 永続化データに認証トークンが含まれていない
- [ ] 永続化データにAPIキーが含まれていない
- [ ] ファイルアクセス権限が適切（所有者のみ読み書き可）

**検証手順:**

1. セッションを作成し、メッセージを送信
2. 永続化ファイルの内容を確認
3. 機密情報が含まれていないことを検証

### AC-104: データ整合性（NFR-012対応）

| 項目     | 内容             |
| -------- | ---------------- |
| 基準ID   | AC-104           |
| 基準名   | データ整合性     |
| 対応要件 | NFR-012, NFR-013 |
| 検証方法 | 自動テスト       |

**受け入れ条件:**

- [ ] 書き込み中断時もデータ破損しない
- [ ] 破損データ読み込み時、正常データのみ復元される
- [ ] バリデーションエラー時、警告が表示される

| -------- | ----------------------- |

| 基準名   | UIとストレージの同期    |

## 5. E2E受け入れ基準

### AC-301: 完全シナリオテスト

| 項目     | 内容               |
| -------- | ------------------ |
| 基準ID   | AC-301             |
| 基準名   | 完全シナリオテスト |
| 検証方法 | E2Eテスト          |

**受け入れ条件:**

- [ ] シナリオ1: セッション作成 → メッセージ送信 → アプリ再起動 → 復元確認
- [ ] シナリオ2: 複数セッション作成 → 切り替え → 各履歴確認
- [ ] シナリオ3: セッション削除 → アプリ再起動 → 削除確認
- [ ] シナリオ4: 容量上限到達 → LRU削除 → 正常動作確認
