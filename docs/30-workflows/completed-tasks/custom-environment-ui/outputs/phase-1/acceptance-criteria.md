## 受け入れ基準（Given-When-Then形式）

```gherkin
Feature: カスタム実行環境UI

  Background:
    Given AIWorkflowOrchestratorデスクトップアプリが起動している
    And ユーザーがエージェント実行画面を開いている

  # シナリオ1: HTMLスキルでHTMLプレビューが表示される
  Scenario: AC-001 HTMLスキルでHTMLプレビューが表示される
    Given ユーザーがHTMLスライド作成スキルを選択している
    And スキルにenvironmentType: "html"が設定されている
    When エージェントがHTMLコンテンツを生成する
    Then 画面が左右に分割される
    And 右側パネルにHTMLプレビューが表示される
    And プレビューはsandbox付きiframe内に表示される
    And プレビュー内のスクリプトは実行されない

  # シナリオ2: プレビューがリアルタイムで更新される
  Scenario: AC-002 プレビューがリアルタイムで更新される
    Given ユーザーがHTMLプレビュー環境を使用している
    And 右側パネルにHTMLプレビューが表示されている
    When エージェントが追加のHTMLコンテンツを生成する
    Then プレビューが自動的に更新される
    And 更新はデバウンス（500ms）される

  # シナリオ3: チャットとプレビューが分割表示される
  Scenario: AC-003 チャットとプレビューが分割表示される
    Given ユーザーがカスタム環境対応スキルを実行している
    And スキルにenvironmentType: "html" または "markdown"が設定されている
    When 実行画面が表示される
    Then 画面が左右に分割される
    And 左側にチャットインターフェースが表示される
    And 右側にプレビューが表示される
    And 分割バーが中央に表示される

  # シナリオ4: 分割比率を調整できる
  Scenario: AC-004 分割比率をドラッグで調整できる
    Given 分割レイアウトが表示されている
    And 分割バーが表示されている
    When 分割バーをマウスでドラッグする
    Then 左右のパネル比率が変更される
    And 比率はリアルタイムで反映される
    And 比率が永続化される（ページリロード後も維持）

  # シナリオ4b: 分割比率をキーボードで調整できる
  Scenario: AC-004b 分割比率をキーボードで調整できる
    Given 分割レイアウトが表示されている
    And 分割バーがフォーカスされている
    When 矢印キー（左右）を押す
    Then 左右のパネル比率が変更される
    And 比率の変更はスクリーンリーダーに通知される

  # シナリオ5: 環境を手動で切り替えられる
  Scenario: AC-005 環境を手動で切り替えられる
    Given 複数の環境タイプがサポートされている
    And 環境セレクターが表示されている
    When 環境セレクターで別の環境（例: Markdown）を選択する
    Then 右側パネルの環境が切り替わる
    And 新しい環境タイプでコンテンツが再レンダリングされる

  # シナリオ6: プレビュー内でスクリプトが隔離されている
  Scenario: AC-006 HTMLプレビューでスクリプトが隔離されている
    Given HTMLプレビューが表示されている
    When HTMLに以下の悪意のあるコンテンツが含まれている
      | 攻撃パターン                            |
      | <script>alert('xss')</script>           |
      | <img onerror="alert('xss')">            |
      | <a href="javascript:alert('xss')">      |
      | <div onclick="alert('xss')">            |
    Then スクリプトは実行されない
    And イベントハンドラは除去される
    And javascript: URLは無効化される
    And アラートやリダイレクトは抑制される
    And 親ウィンドウにアクセスできない

  # シナリオ7: Markdownプレビューが表示される
  Scenario: AC-007 Markdownプレビューが表示される
    Given ユーザーがMarkdown対応スキルを選択している
    And スキルにenvironmentType: "markdown"が設定されている
    When エージェントがMarkdownコンテンツを生成する
    Then 右側パネルにレンダリングされたMarkdownが表示される
    And 見出し、リスト、コードブロック等が適切にスタイリングされる

  # シナリオ8: スキルに環境設定がない場合
  Scenario: AC-008 スキルに環境設定がない場合
    Given ユーザーが環境設定のないスキルを選択している
    And スキルにenvironmentTypeが設定されていない（またはenvironmentType: "none"）
    When スキルを実行する
    Then プレビューパネルは表示されない
    And チャットのみのレイアウトになる（従来の全幅表示）
```

## シナリオ別テスト観点

### AC-001: HTMLプレビュー表示

| テスト観点         | 確認内容                                      |
| ------------------ | --------------------------------------------- |
| UIレンダリング     | HTMLがiframe内に正しく表示される              |
| セキュリティ       | sandbox属性が設定されている                   |
| 状態管理           | previewContentが正しく更新される              |
| コンポーネント連携 | ExecutionEnvironment → HTMLPreviewEnvironment |

### AC-002: リアルタイム更新

| テスト観点         | 確認内容                                    |
| ------------------ | ------------------------------------------- |
| ストリーミング連携 | agentSlice.previewContentの更新が反映される |
| デバウンス         | 500ms以内の連続更新は最後のみ反映           |
| パフォーマンス     | 100KB HTMLでも1秒以内に表示                 |

### AC-003: 分割レイアウト

| テスト観点   | 確認内容                                  |
| ------------ | ----------------------------------------- |
| レイアウト   | 左右分割が正しく表示される                |
| 初期比率     | デフォルト比率（50:50または設定値）で表示 |
| レスポンシブ | ウィンドウサイズ変更時の挙動              |

### AC-004: 分割比率調整

| テスト観点       | 確認内容                         |
| ---------------- | -------------------------------- |
| ドラッグ操作     | マウスドラッグで比率が変更される |
| キーボード操作   | 矢印キーで比率が変更される       |
| 永続化           | リロード後も比率が維持される     |
| アクセシビリティ | aria属性が正しく設定される       |

### AC-005: 環境切り替え

| テスト観点               | 確認内容                                     |
| ------------------------ | -------------------------------------------- |
| セレクター動作           | ドロップダウンが開閉する                     |
| 状態更新                 | selectedEnvironmentが更新される              |
| コンテンツ再レンダリング | 環境タイプに応じたコンポーネントに切り替わる |

### AC-006: セキュリティ（スクリプト隔離）

| テスト観点           | 確認内容                          |
| -------------------- | --------------------------------- |
| スクリプト無効化     | `<script>`タグが実行されない      |
| イベントハンドラ除去 | onclick, onerror等が除去される    |
| URL無効化            | javascript: URLが無効化される     |
| CSP適用              | script-src 'none'が設定されている |
| DOMPurify            | サニタイズが正しく動作する        |

### AC-007: Markdownプレビュー

| テスト観点   | 確認内容                                   |
| ------------ | ------------------------------------------ |
| パース       | Markdownが正しくHTMLに変換される           |
| スタイリング | 見出し、リスト、コード等が適切に表示される |
| XSS対策      | Markdown内のHTMLがサニタイズされる         |

### AC-008: 環境設定なし

| テスト観点 | 確認内容                       |
| ---------- | ------------------------------ |
| レイアウト | チャットのみの全幅レイアウト   |
| 状態       | selectedEnvironment === 'none' |
| 後方互換性 | 従来の動作と互換               |
