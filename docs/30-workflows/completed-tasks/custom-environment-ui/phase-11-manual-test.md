## テストシナリオ

### シナリオ1: HTMLプレビュー基本動作

| ステップ | 操作                         | 期待結果                           |
| -------- | ---------------------------- | ---------------------------------- |
| 1        | HTMLスライドスキルを選択     | スキルが選択される                 |
| 2        | 「スライドを作成して」と入力 | エージェントが実行開始             |
| 3        | -                            | 画面が左右に分割される             |
| 4        | -                            | 右側にHTMLプレビューが表示される   |
| 5        | -                            | プレビューがリアルタイム更新される |

### シナリオ2: 分割レイアウト操作

| ステップ | 操作                       | 期待結果                     |
| -------- | -------------------------- | ---------------------------- |
| 1        | 分割バーにマウスを合わせる | カーソルがリサイズカーソルに |
| 2        | 分割バーを左にドラッグ     | 左パネルが狭くなる           |
| 3        | 分割バーを右にドラッグ     | 左パネルが広くなる           |
| 4        | ページをリロード           | 前回の比率が復元される       |
| 5        | 分割バーにTabでフォーカス  | フォーカスリングが表示される |
| 6        | 矢印キーで操作             | 比率が変更される             |

### シナリオ3: 環境切り替え

| ステップ | 操作                     | 期待結果                         |
| -------- | ------------------------ | -------------------------------- |
| 1        | 環境セレクターをクリック | ドロップダウンが開く             |
| 2        | 「Markdown」を選択       | プレビューがMarkdownに切り替わる |
| 3        | 「None」を選択           | プレビューパネルが非表示になる   |
| 4        | 「HTML」を選択           | プレビューが再表示される         |

### シナリオ4: セキュリティ検証

| ステップ | 操作                                      | 期待結果                     |
| -------- | ----------------------------------------- | ---------------------------- |
| 1        | `<script>alert('xss')</script>`を含むHTML | スクリプトが実行されない     |
| 2        | `<img onerror="alert('xss')">`を含むHTML  | イベントハンドラが除去される |
| 3        | 外部リソースを参照するHTML                | 外部リソースが読み込まれない |
| 4        | 開発者ツールでiframeを確認                | sandbox属性が設定されている  |

### シナリオ5: パフォーマンス確認

| ステップ | 操作                       | 期待結果                     |
| -------- | -------------------------- | ---------------------------- |
| 1        | 100KBのHTMLを生成させる    | 1秒以内に表示される          |
| 2        | 連続してHTMLを更新させる   | スムーズに更新される         |
| 3        | 大量の画像を含むHTMLを表示 | メモリ使用量が過大にならない |

### シナリオ6: アクセシビリティ確認

| ステップ | 操作                       | 期待結果                   |
| -------- | -------------------------- | -------------------------- |
| 1        | キーボードのみで操作       | すべての機能にアクセス可能 |
| 2        | スクリーンリーダーで確認   | 適切に読み上げられる       |
| 3        | 高コントラストモードで表示 | 視認性が維持される         |
