# Phase 1 SubAgent分担

## チーム編成

| SubAgent   | 主責務       | 実施内容                               | 状態 |
| ---------- | ------------ | -------------------------------------- | ---- |
| SubAgent-A | 要件固定     | 重複式5件の対象範囲と非範囲を定義      | 完了 |
| SubAgent-B | 回帰要件定義 | 戻り値・エラー・型契約の不変条件を定義 | 完了 |
| SubAgent-C | 実装観点抽出 | 一元化可能な登録パターンを特定         | 完了 |
| SubAgent-D | 品質観点抽出 | 監査再現性と品質ゲート観点を抽出       | 完了 |
| Lead       | 統合判定     | 実施範囲確定とPhase 2引き渡し          | 完了 |

## 並列実行した項目

- SubAgent-A/B: 要件・受入基準の同時整理
- SubAgent-C/D: 実装制約と品質制約の同時整理

## Phase 2 への引き渡し

- 採用方針は「宣言的登録マップ + 共通登録ヘルパー」で比較検討する
- 契約不変（Main/Preload/Renderer）を設計ゲートの最上位条件にする
