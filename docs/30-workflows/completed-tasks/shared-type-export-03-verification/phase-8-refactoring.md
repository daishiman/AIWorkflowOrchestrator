# Phase 8: コード整理

## メタ情報

| 項目       | 内容                      |
| ---------- | ------------------------- |
| Phase番号  | 8                         |
| Phase名    | コード整理                |
| 目的       | 不要コードの除去・整理    |
| 前提Phase  | Phase 7（カバレッジ確認） |
| 推定作業量 | 小                        |

---

## 1. 目的

検証・修正作業で発生した不要なコードや一時的なコードを整理し、コードベースをクリーンな状態にする。

---

## 2. 実行タスク

### Task 8-1: 不要コードの検出

#### 目的

修正作業で発生した不要なコードを検出する。

#### 確認対象

| 確認項目                   | 確認方法     | 対応      |
| -------------------------- | ------------ | --------- |
| 未使用のインポート文       | ESLintで検出 | 削除      |
| コメントアウトされたコード | 目視確認     | 削除      |
| デバッグ用のconsole.log    | grepで検出   | 削除      |
| 一時的なTODOコメント       | grepで検出   | 対応/削除 |

#### 確認コマンド

```bash
# 未使用インポートの検出
pnpm lint --filter @repo/shared 2>&1 | grep "unused"

# console.logの検出
grep -r "console.log" packages/shared/src/services/graph/

# TODOコメントの検出
grep -r "TODO" packages/shared/src/services/graph/
```

#### 成果物

| 成果物             | 配置先                                     |
| ------------------ | ------------------------------------------ |
| 不要コード検出結果 | `outputs/phase-8/unused-code-detection.md` |

#### 完了条件

- [ ] 不要コードが全て検出されている
- [ ] 各項目の対応方針が決定されている

---

### Task 8-2: コード整理実施

#### 目的

検出された不要コードを削除・整理する。

#### 整理対象

| 整理項目         | 対象ファイル     | 対応 |
| ---------------- | ---------------- | ---- |
| 未使用インポート | 修正したファイル | 削除 |
| コメントアウト   | 修正したファイル | 削除 |
| デバッグコード   | 修正したファイル | 削除 |

#### 整理手順

1. 不要コードを特定
2. 変更前の状態をgitで確認可能な状態にする
3. 整理を実施
4. 型チェック・Lintで確認

#### 成果物

| 成果物       | 配置先                              |
| ------------ | ----------------------------------- |
| 整理実施記録 | `outputs/phase-8/cleanup-record.md` |

#### 完了条件

- [ ] 不要コードが全て削除されている
- [ ] 型チェックがPASS
- [ ] Lintエラーがない

---

### Task 8-3: 整理後検証

#### 目的

コード整理後に既存機能が壊れていないことを確認する。

#### 検証コマンド

```bash
# 型チェック
pnpm typecheck

# Lint
pnpm lint

# ビルド
pnpm build
```

#### 成果物

| 成果物         | 配置先                                         |
| -------------- | ---------------------------------------------- |
| 整理後検証結果 | `outputs/phase-8/post-cleanup-verification.md` |

#### 完了条件

- [ ] 型チェックがPASS
- [ ] Lintエラーがない
- [ ] ビルドが成功
