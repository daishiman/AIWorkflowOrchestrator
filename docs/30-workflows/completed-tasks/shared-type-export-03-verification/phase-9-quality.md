---

## 2. 実行タスク

### Task 9-1: 静的解析

#### 目的

静的解析ツールを使用してコード品質を確認する。

#### 検証項目

| 検証項目     | コマンド            | 期待結果         |
| ------------ | ------------------- | ---------------- |
| TypeScript型 | `pnpm typecheck`    | エラー0件        |
| ESLint       | `pnpm lint`         | エラー0件        |
| Prettier     | `pnpm format:check` | フォーマット済み |

#### 検証コマンド

```bash
# 型チェック
pnpm typecheck

# Lint
pnpm lint

# フォーマットチェック（存在する場合）
pnpm format:check || echo "format:check not available"
```

#### 成果物

| 成果物       | 配置先                               |
| ------------ | ------------------------------------ |
| 静的解析結果 | `outputs/phase-9/static-analysis.md` |

#### 完了条件

- [ ] 型チェックがPASS
- [ ] Lintエラーがない
- [ ] コードが適切にフォーマットされている

---

### Task 9-2: 依存関係検証

#### 目的

パッケージ間の依存関係が正しいことを確認する。

#### 検証項目

| 検証項目       | 確認内容                       | 期待結果         |
| -------------- | ------------------------------ | ---------------- |
| 循環参照なし   | パッケージ間に循環依存がない   | 循環参照なし     |
| 依存方向正しい | shared → desktop の方向のみ    | 依存関係違反なし |
| 不要な依存なし | package.jsonに未使用依存がない | 未使用依存なし   |

#### 確認コマンド

```bash
# 依存関係グラフの確認
pnpm why @repo/shared --recursive 2>/dev/null || echo "dependency check"

# package.jsonの依存確認
cat packages/shared/package.json | grep -A 20 "dependencies"
```

#### 成果物

| 成果物           | 配置先                                       |
| ---------------- | -------------------------------------------- |
| 依存関係検証結果 | `outputs/phase-9/dependency-verification.md` |

#### 完了条件

- [ ] 循環参照がない
- [ ] 依存関係の方向が正しい
- [ ] 不要な依存がない

---

### Task 9-3: ビルド検証

#### 目的

最終的なビルドが成功することを確認する。

#### 検証コマンド

```bash
# クリーンビルド
pnpm --filter @repo/shared build
pnpm --filter @repo/desktop build

# 全体ビルド
pnpm build
```

#### 成果物

| 成果物     | 配置先                                  |
| ---------- | --------------------------------------- |
| ビルド結果 | `outputs/phase-9/build-verification.md` |

#### 完了条件

- [ ] @repo/shared のビルドが成功
- [ ] @repo/desktop のビルドが成功
- [ ] 全体ビルドが成功
