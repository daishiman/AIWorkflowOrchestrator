## 3. スコープ外の作業が発生した場合の対応

### 3.1 判断基準

| 状況                       | 対応               |
| -------------------------- | ------------------ |
| 修正なしで検証PASS         | そのまま進行       |
| スコープ内の修正で対応可能 | Phase 5で修正      |
| スコープ外の修正が必要     | 別タスクとして記録 |

### 3.2 別タスク起票テンプレート

```markdown
## タスク起票

### タスク名

[スコープ外修正] XXXの修正

### 背景

SHARED-TYPE-EXPORT-03タスク実行中に発見された問題

### 修正内容

### 優先度

- [ ] 高（ブロッカー）
- [ ] 中（品質改善）
- [ ] 低（将来対応）

### 関連Issue

#373
```

## 4. 判断フローチャート

```
修正が必要な問題を検出
    ↓
スコープ内の修正で解決可能？
    │
    ├─ Yes → Phase 5で修正を実施
    │
    └─ No → 別タスクとして記録
              │
              ├─ ブロッカー → 本タスクを一時停止
              │               別タスク完了後に再開
              │
              └─ 非ブロッカー → 記録して本タスク続行
                               後日対応
```
