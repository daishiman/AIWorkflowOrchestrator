## 2. 修正フロー

```
エラー発生
    ↓
エラー内容を記録
    ↓
エラーパターン判定
    │
    ├─ エクスポート不足 (TS2305/TS2614)
    │      ↓
    │   packages/shared/index.ts を修正
    │      └─ export type { XXX } from "./src/services/graph"; を追加
    │
    ├─ モジュール解決失敗 (TS2307)
    │      ↓
    │   1. package.json の exports フィールドを確認
    │   2. サブパスが必要な場合は追加
    │   3. tsconfig.json の paths を確認
    │
    ├─ 型不一致 (TS2322/TS2339)
    │      ↓
    │   1. 型定義ファイル (types.ts) を確認
    │   2. 期待される型と実際の型を比較
    │   3. 必要に応じて型定義を修正
    │
    └─ 循環参照
           ↓
       1. インポート構造を分析
       2. 依存関係を整理
       3. 必要に応じてファイル分割

    ↓
再検証
    ↓
PASS → 次ステップへ
FAIL → 修正フローを繰り返し
```
