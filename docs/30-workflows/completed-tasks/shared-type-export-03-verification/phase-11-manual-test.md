## 1. 目的

型エクスポートの最終検証として、実際のビルドとpushが成功することを手動で確認する。

---

## 2. 実行タスク

### Task 11-1: 最終ビルド検証

#### 目的

本番環境と同等の条件でビルドが成功することを確認する。

#### 検証手順

1. ワーキングディレクトリをクリーンにする

   ```bash
   git status  # 未コミットの変更がないことを確認
   ```

2. 依存関係を再インストール

   ```bash
   pnpm install
   ```

3. 全体ビルドを実行

   ```bash
   pnpm build
   ```

4. 結果を記録

#### 検証結果テンプレート

```markdown
## ビルド検証結果

| パッケージ    | ビルド結果 | エラー内容（あれば） |
| ------------- | ---------- | -------------------- |
| @repo/shared  | PASS/FAIL  |                      |
| @repo/desktop | PASS/FAIL  |                      |
| @repo/web     | PASS/FAIL  |                      |
| @repo/ui      | PASS/FAIL  |                      |

### 全体ビルド結果

- 結果: PASS/FAIL
- 実行時間: X分X秒
```

#### 成果物

| 成果物         | 配置先                                   |
| -------------- | ---------------------------------------- |
| ビルド検証結果 | `outputs/phase-11/build-verification.md` |

#### 完了条件

- [ ] 全パッケージのビルドが成功
- [ ] エラーがない

---

### Task 11-2: 型チェック最終検証

#### 目的

全パッケージの型チェックが成功することを最終確認する。

#### 検証手順

1. 全体型チェックを実行

   ```bash
   pnpm typecheck
   ```

2. 各パッケージの型チェックを個別実行

   ```bash
   pnpm --filter @repo/shared typecheck
   pnpm --filter @repo/desktop typecheck
   ```

3. 結果を記録

#### 検証結果テンプレート

```markdown
## 型チェック検証結果

| パッケージ    | 型チェック結果 | エラー件数 |
| ------------- | -------------- | ---------- |
| @repo/shared  | PASS/FAIL      | 0          |
| @repo/desktop | PASS/FAIL      | 0          |

### 全体型チェック結果

- 結果: PASS/FAIL
- エラー件数: 0
```

#### 成果物

| 成果物             | 配置先                                       |
| ------------------ | -------------------------------------------- |
| 型チェック検証結果 | `outputs/phase-11/typecheck-verification.md` |

#### 完了条件

- [ ] 全パッケージの型チェックがPASS
- [ ] エラーが0件

---

### Task 11-3: Push検証（dry-run）

#### 目的

pre-push hookが正常に通過することを確認する。

#### 検証手順

1. 変更をステージング（必要な場合）

   ```bash
   git add .
   ```

2. dry-runでpushを試行

   ```bash
   git push --dry-run
   ```

3. pre-push hookの実行結果を確認

4. 結果を記録

#### 検証結果テンプレート

```markdown
## Push検証結果

### pre-push hook実行結果

- 結果: PASS/FAIL
- 実行されたチェック:
  - [ ] typecheck
  - [ ] lint
  - [ ] build
  - [ ] test

### 詳細ログ

\`\`\`
（hookの出力ログ）
\`\`\`
```

- [ ] pre-push hookが成功
