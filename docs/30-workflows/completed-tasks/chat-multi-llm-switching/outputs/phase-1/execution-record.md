## 統合テスト連携

接続要件として以下を明記:

- **API接続要件**: 4プロバイダー（OpenAI/Anthropic/Google/xAI）への接続
- **認証フロー**: APIキー管理、secure-storage使用
- **データフロー**: フロントエンド → API → LLM → API → フロントエンド
- **コンテキスト共有**: 会話履歴、システムプロンプトの維持
