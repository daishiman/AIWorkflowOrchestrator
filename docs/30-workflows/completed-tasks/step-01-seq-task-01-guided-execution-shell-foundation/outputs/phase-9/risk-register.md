### R-2: runtimeAccess.ts の IPC 経由 terminal.open との整合性

| 項目       | 内容                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスクID   | R-2                                                                                                                                                                                                                                                                                                                                                                                               |
| 重大度     | 中                                                                                                                                                                                                                                                                                                                                                                                                |
| 発生確率   | 低                                                                                                                                                                                                                                                                                                                                                                                                |
| 影響範囲   | `runtimeAccess.ts`, `AppLayout/TerminalLauncher.tsx`, Main Process IPC handler                                                                                                                                                                                                                                                                                                                    |
| 説明       | `launchMainlineTerminal()` は `window.electronAPI.terminal.open` IPC を呼び出して外部 terminal プロセスを起動する。本タスクではこの IPC 呼び出しを変更しないが、`TerminalLauncher` の表示ラベルを `実行コンソール` に変更するため、ユーザーが「実行コンソール」ボタンを押した際の挙動が名称と不一致になるリスクがある。ボタン押下で外部 terminal が起動するのか、画面内遷移するのかが不明瞭になる |
| 軽減策     | Phase 5 で `TerminalLauncher` の `onLaunch` prop を `openExecutionConsole()` に接続し、画面内遷移に切り替える。外部 terminal 起動は `ExecutionConsoleView` 内の `高度な表示` セクション（Task03）に移動する                                                                                                                                                                                       |
| 残存リスク | Task03 が完了するまで、`TerminalLauncher` から外部 terminal を直接起動する経路が消失する。代替として `高度な表示` が未実装の間は ExecutionConsoleView の stub に案内テキストを表示する                                                                                                                                                                                                            |

### R-5: GuidanceActionType 変更による exhaustive check 漏れ

| 項目       | 内容                                                                                                                                                                                                                                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| リスクID   | R-5                                                                                                                                                                                                                                                                                                                      |
| 重大度     | 中                                                                                                                                                                                                                                                                                                                       |
| 発生確率   | 低（TypeScript の exhaustive check で検出可能）                                                                                                                                                                                                                                                                          |
| 影響範囲   | `modelSelectionGuidance.ts`, `createGuidanceActionDispatcher`, 全 dispatcher 呼び出し元                                                                                                                                                                                                                                  |
| 説明       | `GuidanceActionType` から `"open-terminal"` を削除して `"open-execution-console"` に変更する際、`createGuidanceActionDispatcher` の switch 文の `case "open-terminal"` が残存するとデッドコードになる。逆に、`case "open-execution-console"` を追加し忘れると exhaustive check の `never` 型でコンパイルエラーが発生する |
| 軽減策     | (1) `GuidanceActionType` の型変更と switch 文の更新を同時に行う (2) `pnpm typecheck` で exhaustive check エラーを検出 (3) `GuidanceActionHandlers` interface の key 名変更も同時に実施                                                                                                                                   |
| 残存リスク | TypeScript のコンパイルエラーで検出可能なため、実質的な残存リスクは低い                                                                                                                                                                                                                                                  |
