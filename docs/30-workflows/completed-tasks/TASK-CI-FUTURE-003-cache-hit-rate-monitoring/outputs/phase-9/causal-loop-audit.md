## 強化ループ（良い方向）

```
キャッシュヒット率が可視化される
  → 劣化を早期検知できる
    → キャッシュ設定を改善できる
      → ヒット率が改善される
        → CI 実行時間が短縮される  ← 正のフィードバック
```

## バランスループ（リスク抑制）

```
判定ステップが失敗する
  → continue-on-error: true が作動
    → CI はブロックされない
      → 本来のジョブが完了する  ← 安全弁として機能
```

## 責務境界

| 確認項目                                                            | 結果 |
| ------------------------------------------------------------------- | ---- |
| 判定ステップは「観察・記録」のみを行い CI 実行制御を変更しない      | ✅   |
| `if: always()` は判定ステップの実行条件であり他ステップに影響しない | ✅   |
| `::warning::` / `::notice::` は通知のみで CI 結果には影響しない     | ✅   |
