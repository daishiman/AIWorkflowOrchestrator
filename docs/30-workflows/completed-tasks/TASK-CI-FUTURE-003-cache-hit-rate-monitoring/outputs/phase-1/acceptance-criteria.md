## 検証手順

各受け入れ基準の検証は GitHub Actions の実行ページで確認する。

### AC-001 / AC-002 / AC-003 の検証

1. 対象ジョブ（lint, typecheck, build-shared 等）の実行ページを開く
2. 「Summary」タブを選択する
3. 「キャッシュヒット率レポート」セクションを確認する
4. 「キャッシュ状態」列に期待する文字列が表示されていることを確認する

### AC-004 の検証

1. GitHub Actions の実行ページの「Annotations」セクションを確認する
2. `::warning::` レベルのメッセージが出力されていることを確認する

### AC-005 の検証

1. 判定ステップが失敗（またはエラー）した場合でも、後続ステップが実行されることを確認する
2. `continue-on-error: true` の設定により、ジョブ全体の結果が「失敗」にならないことを確認する

### AC-006 の検証

1. Phase 5 実装前後の CI 実行時間を比較する
2. 変更前の平均実行時間に対して 5 秒以内の増加であることを確認する
