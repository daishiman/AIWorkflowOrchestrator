## 目的

実際に GitHub Actions を実行し、3 状態のキャッシュヒット率レポートが GitHub Actions Summary に正しく出力されることを手動で確認する。

## タスク種別

| 分類                | 該当 | 理由                                 |
| ------------------- | ---- | ------------------------------------ |
| Visual UI 検証      | ❌   | デスクトップアプリの UI 変更なし     |
| GitHub Actions 確認 | ✅   | CI 実行結果の Summary を手動確認する |

## 実行タスク

### Task 11-A: キャッシュ完全ヒットの確認（TC-001）

**前提条件**: Phase 5 の変更がリモートブランチにプッシュされていること

**手順**:

1. ブランチをプッシュして CI を実行する
2. GitHub Actions の実行ページを開く（リポジトリ > Actions > 最新の CI 実行）
3. lint/typecheck/test ジョブの「キャッシュヒット率確認」ステップを確認する
4. 各ジョブの「Summary」タブを開き、テーブルが出力されているか確認する

**期待する出力**（Summary テーブル）:

```markdown
## キャッシュヒット率レポート

| 項目           | 内容                      |
| -------------- | ------------------------- |
| ジョブ名       | lint                      |
| キャッシュ状態 | ✅ 完全ヒット (Exact Hit) |
| マッチキー     | setup-node-modules-xxxxx  |
```

**期待するアノテーション**: なし

### Task 11-B: フォールバックヒットの確認（TC-002）

**手順**:

1. `pnpm-lock.yaml` に軽微なコメントを追加してキャッシュキーを変更するコミットを作成する
2. ブランチをプッシュして CI を実行する
3. 各ジョブの Summary タブを確認する
4. Annotations セクションで `::notice::` が出力されているか確認する

**期待する出力**（Summary テーブル）:

- `| キャッシュ状態 | ⚠️ フォールバックヒット (Partial Hit) |`

**期待するアノテーション**: `::notice::` が出力される

### Task 11-C: キャッシュミスの確認（TC-003）

**手順**:

1. GitHub CLI または GitHub UI でキャッシュを削除する
   ```bash
   gh cache delete --all --repo daishiman/AIWorkflowOrchestrator
   ```
2. CI を再実行（または新しいコミットをプッシュ）する
3. 各ジョブの Summary タブを確認する
4. Annotations セクションで `::warning::` が出力されているか確認する

**期待する出力**（Summary テーブル）:

- `| キャッシュ状態 | ❌ キャッシュミス (Miss) |`

**期待するアノテーション**: `::warning::` が出力される

### Task 11-D: 証跡の収集

各テストケースの結果をスクリーンショットまたはログとして記録する。

| テストケース | 収集物                               | 保存先                                            |
| ------------ | ------------------------------------ | ------------------------------------------------- |
| TC-001       | Summary タブのスクリーンショット     | `outputs/phase-11/screenshot-tc001-exact-hit.png` |
| TC-002       | Summary タブ + Annotations           | `outputs/phase-11/screenshot-tc002-fallback.png`  |
| TC-003       | Summary タブ + Annotations + Warning | `outputs/phase-11/screenshot-tc003-miss.png`      |

スクリーンショットが取得できない場合は、GitHub Actions の実行 URL とステップのログを記録する。

### Task 11-E: N/A 理由の記録

本タスクは GitHub Actions YAML 変更のみのため、以下の検証項目は N/A となる。

| 検証項目                             | N/A 理由                                |
