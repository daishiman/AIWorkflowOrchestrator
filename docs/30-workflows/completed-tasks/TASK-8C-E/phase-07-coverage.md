## 目的

フィクスチャ検証テストのカバレッジを確認し、テストの網羅性を評価する。本タスクはコード実装ではなくフィクスチャ（静的ファイル）の作成であるため、カバレッジは「フィクスチャ要件の網羅率」を指標とする。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: テスト実行とカバレッジ計測

**目的**: テストの実行結果とカバレッジを計測する

**実行手順**:

1. テストをカバレッジ付きで実行する：
   ```bash
   pnpm --filter @repo/desktop vitest run src/__tests__/fixtures/skills.fixture.test.ts --coverage
   ```
2. テスト結果を確認する（全件パス）
3. SkillScanner 関連コードのカバレッジを確認する（フィクスチャ経由で SkillScanner のどのパスが通るか）

**期待される成果物**:

- テスト実行結果

---

### タスク2: フィクスチャ要件網羅率の確認

**目的**: Phase 1 で定義した要件がフィクスチャとテストでカバーされているか確認する

**実行手順**:

1. 以下の網羅率チェックリストを評価する：

| 要件                         | フィクスチャ              | テスト                         | 状態 |
| ---------------------------- | ------------------------- | ------------------------------ | ---- |
| 有効なスキル（完全構成）     | test-skill                | TC-001〜TC-004, TC-010〜TC-012 |      |
| 有効なスキル（最小構成）     | another-skill             | TC-005〜TC-006, TC-013         |      |
| 無効なスキル（SKILL.mdなし） | invalid-skill             | TC-007〜TC-008, TC-014         |      |
| YAML Frontmatter パース      | test-skill, another-skill | TC-015〜TC-019                 |      |
| サブリソース検出             | test-skill                | TC-020〜TC-025                 |      |
| ディレクトリ構造             | 全体                      | TC-026〜TC-029                 |      |

2. カバレッジレポートを `outputs/phase-07/coverage-report.md` に出力する

**期待される成果物**:

- `outputs/phase-07/coverage-report.md`

---

### タスク3: 不足テストの特定

**目的**: カバレッジ不足のある領域を特定する

**実行手順**:

1. 以下の観点で不足を確認する：
   - SkillScanner のエラーハンドリングパス（例: パーミッションエラー）がフィクスチャでカバーされているか
   - TASK-8C-B/C/D が必要とするフィクスチャが全て揃っているか
2. 不足があれば Phase 6 に戻って追加するか、既存カバレッジで十分か判断する

**期待される成果物**:

- 不足テスト分析結果（`outputs/phase-07/coverage-report.md` に含む）
