## 目的

Phase 2 で設計したフィクスチャ構造が要件を満たし、SkillScanner 仕様と整合していることをレビューする。PASS/FAIL 判定を行い、Phase 4 への進行可否を決定する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 構造整合性レビュー

**目的**: フィクスチャ構造が SkillScanner の期待する形式と一致しているか検証する

**実行手順**:

1. `outputs/phase-02/fixture-design.md` を読む
2. 以下のチェックリストを検証する：

| チェック項目                                              | 判定 |
| --------------------------------------------------------- | ---- |
| test-skill/SKILL.md に name フィールドが存在する          |      |
| test-skill/SKILL.md に description フィールドが存在する   |      |
| test-skill/SKILL.md に allowed-tools フィールドが存在する |      |
| agents/ ディレクトリが test-skill/ 直下にある             |      |
| references/ ディレクトリが test-skill/ 直下にある         |      |
| another-skill/SKILL.md に必須フィールドが存在する         |      |
| invalid-skill/ に SKILL.md が存在しない                   |      |

3. SkillScanner.ts の `parseSkill()` メソッドと照合し、パース可能であることを確認する

**期待される成果物**:

- レビューチェックリスト（`outputs/phase-02/fixture-design.md` に追記 or 別途レビュー記録）

---

### タスク2: E2Eテスト互換性レビュー

**目的**: 設計されたフィクスチャが TASK-8C-B/C/D の要件を満たすか検証する

**実行手順**:

1. TASK-8C-B（スキル選択E2E）の定義を確認し、test-skill と another-skill が選択リストに表示される設計であることを確認する
2. TASK-8C-C（インポート実行E2E）の定義を確認し、test-skill がインポート可能な設計であることを確認する
3. TASK-8C-D（パーミッションE2E）の定義を確認し、test-skill の allowed-tools がパーミッション検証に使用可能であることを確認する

**期待される成果物**:

- E2E 互換性確認結果

---

### タスク3: PASS/FAIL 判定

**目的**: 設計レビューの最終判定を行う

**実行手順**:

1. タスク1・タスク2 の結果を総合する
2. 以下の判定基準に基づき判定を決定する：

| 判定  | 条件                     | 対応                         |
| ----- | ------------------------ | ---------------------------- |
| PASS  | 全レビュー観点で問題なし | Phase 4（テスト作成）へ進行  |
| MINOR | 軽微な指摘あり           | 指摘対応後 Phase 4 へ進行    |
| MAJOR | 重大な問題あり           | 影響範囲に応じて戻り先を決定 |

3. MAJOR 判定時の戻り先決定基準：

| 問題の種類 | 戻り先              |
| ---------- | ------------------- |
| 要件の問題 | Phase 1（要件定義） |
| 設計の問題 | Phase 2（設計）     |
| 両方の問題 | Phase 1（要件定義） |

**期待される成果物**:

- PASS/FAIL 判定結果
