## 目的

フィクスチャファイルとテストコードの品質を見直し、保守性と可読性を向上させる。テストが全件パスする状態を維持しながらリファクタリングを行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: フィクスチャ内容の見直し

**目的**: フィクスチャファイルの内容が E2E テストの目的に適しているか見直す

**実行手順**:

1. 各フィクスチャファイルを読み直し、以下を確認する：
   - SKILL.md の Frontmatter フィールドが SkillScanner 仕様の全フィールドをカバーしているか
   - フィクスチャ間で重複している内容がないか
   - E2E テスト（TASK-8C-B/C/D）のシナリオに必要な情報が十分か
2. 必要に応じてフィクスチャ内容を改善する

**期待される成果物**:

- フィクスチャ改善記録（`outputs/phase-08/refactoring-log.md`）

---

### タスク2: テストコードの見直し

**目的**: テストコードの可読性と保守性を向上させる

**実行手順**:

1. テストファイル `skills.fixture.test.ts` を読み直す
2. 以下の観点でリファクタリングする：
   - テストヘルパー関数の抽出（フィクスチャパスの定数化など）
   - テストケースのグルーピング（describe ブロックの整理）
   - テストの命名規則の統一
3. リファクタリング後にテストを実行し、全件パスすることを確認する：
   ```bash
   pnpm --filter @repo/desktop vitest run src/__tests__/fixtures/skills.fixture.test.ts
   ```

**期待される成果物**:

- リファクタリング済みテストコード
- `outputs/phase-08/refactoring-log.md`
