## 目的

フィクスチャとテストの品質を総合的に検証し、後続の E2E テスト（TASK-8C-B/C/D）で問題なく使用可能であることを保証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析

**目的**: テストコードの品質を静的解析で検証する

**実行手順**:

1. ESLint を実行する：
   ```bash
   pnpm --filter @repo/desktop eslint src/__tests__/fixtures/skills.fixture.test.ts
   ```
2. TypeScript 型チェックを実行する：
   ```bash
   pnpm --filter @repo/desktop tsc --noEmit
   ```
3. エラーがあれば修正する

**期待される成果物**:

- 静的解析結果（品質レポートに含む）

---

### タスク2: フィクスチャ整合性の最終検証

**目的**: フィクスチャが SkillScanner 仕様と完全に整合していることを最終確認する

**実行手順**:

1. SkillScanner のユニットテストを実行し、既存テストに影響がないことを確認する：
   ```bash
   pnpm --filter @repo/desktop vitest run src/main/services/skill/__tests__/SkillScanner.test.ts
   ```
2. E2E フィクスチャ検証テストを実行する：
   ```bash
   pnpm --filter @repo/desktop vitest run src/__tests__/fixtures/skills.fixture.test.ts
   ```
3. 両方のテストが全件パスすることを確認する

**期待される成果物**:

- テスト実行結果

---

### タスク3: セキュリティ検証

**目的**: フィクスチャに機密情報やセキュリティリスクがないことを確認する

**実行手順**:

1. フィクスチャファイルに以下が含まれていないことを確認する：
   - API キー、トークン、パスワード
   - パストラバーサルパターン（`../`）
   - シェルコマンドインジェクションパターン
   - 外部URL参照
2. allowed-tools に危険なツール（制限されるべきもの）が含まれていないことを確認する

**期待される成果物**:

- セキュリティ検証結果（品質レポートに含む）

---

### タスク4: 品質レポート作成

**目的**: 品質検証結果を文書化する

**実行手順**:

1. タスク1〜3の結果を統合し、品質レポートを作成する
2. `outputs/phase-09/quality-report.md` に出力する

**期待される成果物**:

- `outputs/phase-09/quality-report.md`
