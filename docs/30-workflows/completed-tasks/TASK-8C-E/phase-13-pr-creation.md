## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 差分確認

**目的**: コミット対象の変更を確認する

**実行手順**:

1. 変更ファイル一覧を確認する：

   ```bash
   git status
   git diff --stat
   ```

2. 以下のカテゴリに分類する：

| カテゴリ             | 対象ファイル                                                     |
| -------------------- | ---------------------------------------------------------------- |
| フィクスチャファイル | `apps/desktop/src/__tests__/__fixtures__/skills/**`              |
| テストファイル       | `apps/desktop/src/__tests__/fixtures/skills.fixture.test.ts`     |
| ドキュメント         | `docs/30-workflows/skill-import-agent-system/tasks/TASK-8C-E/**` |

3. コミット対象外のファイルがないか確認する

**期待される成果物**:

- 変更ファイル一覧

---

### タスク2: コミット作成

**目的**: 適切なコミットメッセージでコミットを作成する

**実行手順**:

1. コミットメッセージのフォーマット：

   ```
   test(skill): E2Eテストフィクスチャ作成 (TASK-8C-E)

   - test-skill: 完全なスキルフィクスチャ（SKILL.md + agents/ + references/）
   - another-skill: 最小構成スキルフィクスチャ（SKILL.md のみ）
   - invalid-skill: 無効スキルフィクスチャ（SKILL.md なし）
   - フィクスチャ検証テスト（TC-001〜TC-029）
   ```

2. ユーザーの許可を得てからコミットする

**期待される成果物**:

- Git コミット

---

### タスク3: PR 作成

**目的**: GitHub にプルリクエストを作成する

**実行手順**:

1. **ユーザーの明示的な許可を得る**
2. `/ai:diff-to-pr` コマンドを使用して PR を作成する
3. PR の概要：
   - **タイトル**: `test(skill): E2Eテストフィクスチャ作成 (TASK-8C-E)`
   - **本文**: フィクスチャの説明、テスト一覧、後続タスクへの影響

**期待される成果物**:

- GitHub プルリクエスト
- `outputs/phase-13/pr-info.md`（PR URL、ブランチ名、マージ先）
