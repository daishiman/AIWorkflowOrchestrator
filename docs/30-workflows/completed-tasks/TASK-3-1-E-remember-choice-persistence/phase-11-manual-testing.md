## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連自動テストの確認

**目的**: 関連する自動テストが全てパスしていることを確認する

**実行手順**:

1. 以下のコマンドで関連テストを実行:
   ```bash
   pnpm --filter @repo/desktop test -- --grep "PermissionStore"
   ```
2. 全テストがパスすることを確認
3. 結果を記録

**期待される成果物**:

- 自動テスト実行結果

---

### タスク2: 機能テスト（正常系）

**目的**: 主要機能が正常に動作することを手動で確認する

**実行手順**:

1. アプリを起動
2. 以下のテストケースを実行:

| TC-ID  | 機能                           | 手順                                                  | 期待結果                             |
| ------ | ------------------------------ | ----------------------------------------------------- | ------------------------------------ |
| TC-001 | ツール許可と永続化             | スキル実行→権限ダイアログ→「次回から確認しない」+許可 | ダイアログが閉じ、ツールが実行される |
| TC-002 | 自動許可（ダイアログスキップ） | TC-001後、同じスキルを再実行                          | ダイアログが表示されず自動許可される |
| TC-003 | アプリ再起動後の設定維持       | アプリを終了→再起動→TC-002と同じスキルを実行          | ダイアログが表示されず自動許可される |
| TC-004 | 設定画面からの許可確認         | 設定画面→許可済みツールセクション                     | TC-001で許可したツールが一覧に表示   |
| TC-005 | 設定画面からのツール削除       | 設定画面→許可済みツール→削除ボタン                    | ツールが一覧から削除される           |
| TC-006 | 削除後の再許可要求             | TC-005後、同じスキルを実行                            | 権限ダイアログが再度表示される       |

3. 結果を記録

**期待される成果物**:

- 機能テスト結果

---

### タスク3: エラーハンドリングテスト（異常系）

**目的**: エラー時の動作を手動で確認する

**実行手順**:

1. 以下のテストケースを実行:

| TC-ID  | 状況           | 手順                               | 期待結果                           |
| ------ | -------------- | ---------------------------------- | ---------------------------------- |
| TC-101 | 権限拒否       | 権限ダイアログで「拒否」をクリック | ツール実行がキャンセルされる       |
| TC-102 | 拒否後の再許可 | TC-101後、再度同じスキルを実行     | 権限ダイアログが再度表示される     |
| TC-103 | 全設定クリア   | 設定画面→全て削除ボタン            | 全ての許可済みツールがクリアされる |

2. 結果を記録

**期待される成果物**:

- エラーハンドリングテスト結果
