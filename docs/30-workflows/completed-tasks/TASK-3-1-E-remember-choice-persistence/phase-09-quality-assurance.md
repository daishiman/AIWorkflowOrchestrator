## 目的

静的解析、セキュリティ、パフォーマンスの観点からコード品質を保証する。

## 背景

実装・リファクタリングが完了したコードに対して、最終的な品質チェックを行い、本番環境での問題を未然に防ぐ。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析実行

**目的**: ESLint・TypeScriptの静的解析を実行する

**実行手順**:

1. ESLintを実行:
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. TypeScript型チェックを実行:
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
3. エラー・警告がある場合は修正
4. 結果を記録

**期待される成果物**:

- 静的解析結果（エラー0件確認）

---

### タスク2: コードフォーマット確認

**目的**: Prettierによるコードフォーマットを確認する

**実行手順**:

1. Prettierチェックを実行:
   ```bash
   pnpm --filter @repo/desktop format:check
   ```
2. フォーマット違反がある場合は修正:
   ```bash
   pnpm --filter @repo/desktop format
   ```
3. 結果を記録

**期待される成果物**:

- フォーマット確認結果

---

### タスク3: セキュリティチェック

**目的**: セキュリティ観点でのコードレビューを行う

**実行手順**:

1. 以下のセキュリティ項目を確認:
   - [ ] 機密データのログ出力がないか
   - [ ] 設定ファイルの適切な保護
   - [ ] 入力値のバリデーション
   - [ ] 危険なツールの自動許可防止オプション
2. 問題がある場合は修正
3. 結果を記録

**期待される成果物**:

- セキュリティチェックリスト

---

### タスク4: パフォーマンス確認

**目的**: パフォーマンス観点でのコードレビューを行う

**実行手順**:

1. 以下のパフォーマンス項目を確認:
   - [ ] 大量ツール登録時の応答速度
   - [ ] 不必要なファイルI/Oがないか
   - [ ] メモリリークの可能性がないか
2. 問題がある場合は修正
3. 結果を記録

**期待される成果物**:

- パフォーマンスチェックリスト

---

### タスク5: 品質保証レポート作成

**目的**: 品質保証の結果をレポートにまとめる

**実行手順**:

1. 以下の情報をレポートにまとめる:
   - 静的解析結果
   - フォーマット確認結果
   - セキュリティチェック結果
   - パフォーマンス確認結果
2. 問題がある場合は対応状況を記載
3. レポートを出力

**期待される成果物**:

- `outputs/phase-9/quality-assurance-report.md`
