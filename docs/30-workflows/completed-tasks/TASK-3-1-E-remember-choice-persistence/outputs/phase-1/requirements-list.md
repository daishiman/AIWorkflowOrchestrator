## 既存処理フローの分析

### 現在の権限確認フロー

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  SkillExecutor  │    │ PermissionResolver│    │    Renderer     │
└────────┬────────┘    └─────────┬────────┘    └────────┬────────┘
         │                       │                       │
         │ sendPermissionRequest │                       │
         │──────────────────────>│                       │
         │                       │     IPC:skill:        │
         │                       │  permission-request   │
         │                       │──────────────────────>│
         │                       │                       │
         │                       │                       │ ダイアログ表示
         │                       │                       │ (rememberChoiceチェック)
         │                       │                       │
         │                       │  IPC:permission-      │
         │                       │     response          │
         │                       │<──────────────────────│
         │                       │                       │
         │ handlePermissionResponse                      │
         │<──────────────────────│                       │
         │                       │                       │

         │  (Promise解決)        │                       │
         │<──────────────────────│                       │

```

### 永続化追加後のフロー

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  SkillExecutor  │    │ PermissionStore  │    │PermissionResolver│   │    Renderer     │
└────────┬────────┘    └────────┬─────────┘    └─────────┬────────┘   └────────┬────────┘
         │                      │                        │                      │
         │ isToolAllowed(tool)  │                        │                      │
         │─────────────────────>│                        │                      │
         │                      │                        │                      │
         │ [true: 自動承認]     │                        │                      │
         │<─────────────────────│                        │                      │
         │                      │                        │                      │
         │ [false: 通常フロー]  │                        │                      │
         │      :               │                        │                      │
         │ (省略: 従来のフロー) │                        │                      │
         │      :               │                        │                      │
         │                      │                        │                      │
         │ handlePermissionResponse                      │                      │
         │<─────────────────────────────────────────────────────────────────────│
         │                      │                        │                      │
         │ [rememberChoice &&   │                        │                      │
         │  approved]           │                        │                      │
         │ allowTool(toolName)  │                        │                      │
         │─────────────────────>│                        │                      │
         │                      │ (electron-store保存)   │                      │
         │                      │                        │                      │
```

### 永続化追加箇所

1. **sendPermissionRequest前**: `PermissionStore.isToolAllowed()` で許可済みかチェック
2. **handlePermissionResponse内**: `rememberChoice=true && approved=true` の場合に `PermissionStore.allowTool()` 呼び出し

## 機能要件

### FR-001: 権限設定の永続化

| ID      | 要件                                                                    | 優先度 |
| ------- | ----------------------------------------------------------------------- | ------ |
| FR-001a | `rememberChoice=true` かつ `approved=true` の場合、ツール名を永続化する | 必須   |
| FR-001b | electron-storeを使用してJSONファイルに保存する                          | 必須   |
| FR-001c | アプリ再起動後も設定が維持される                                        | 必須   |

### FR-002: 自動許可（ダイアログスキップ）

| ID      | 要件                                                         | 優先度 |
| ------- | ------------------------------------------------------------ | ------ |
| FR-002a | 権限リクエスト前に `isToolAllowed()` でチェックする          | 必須   |
| FR-002b | 許可済みの場合、ダイアログを表示せず自動承認レスポンスを返す | 必須   |
| FR-002c | 自動承認時もログを出力する（デバッグ用）                     | 推奨   |

### FR-003: 許可済みツール一覧取得

| ID      | 要件                                          | 優先度 |
| ------- | --------------------------------------------- | ------ |
| FR-003a | 許可済みツール名の一覧を取得するAPIを提供する | 必須   |
| FR-003b | 許可日時を含むメタデータを取得できる          | 推奨   |

### FR-004: 許可取り消し

| ID      | 要件                                      | 優先度 |
| ------- | ----------------------------------------- | ------ |
| FR-004a | 特定のツールの許可を取り消すAPIを提供する | 必須   |
| FR-004b | 全ての許可設定を一括削除するAPIを提供する | 必須   |

### FR-005: 設定UI連携

| ID      | 要件                                     | 優先度 |
| ------- | ---------------------------------------- | ------ |
| FR-005a | 設定画面から許可済みツール一覧を表示する | 必須   |
| FR-005b | 設定画面から個別ツールの許可を取り消せる | 必須   |
| FR-005c | 設定画面から全許可設定をクリアできる     | 必須   |

### FR-006: IPCチャネル

| ID      | 要件                                            | 優先度 |
| ------- | ----------------------------------------------- | ------ |
| FR-006a | `permission:getAllowedTools` チャネルで一覧取得 | 必須   |
| FR-006b | `permission:revokeTool` チャネルで個別取り消し  | 必須   |
| FR-006c | `permission:clearAll` チャネルで全クリア        | 必須   |

## 非機能要件

### NFR-001: セキュリティ

| ID       | 要件                                                 | 優先度 |
| -------- | ---------------------------------------------------- | ------ |
| NFR-001a | Bashツールは自動許可対象から除外するオプションを提供 | 推奨   |
| NFR-001b | 設定ファイルはユーザーデータディレクトリに保存       | 必須   |
| NFR-001c | 不正なデータ形式の場合はデフォルト値で初期化         | 必須   |

### NFR-002: パフォーマンス

| ID       | 要件                                     | 優先度 |
| -------- | ---------------------------------------- | ------ |
| NFR-002a | isToolAllowed()は同期的に1ms以内で完了   | 必須   |
| NFR-002b | 永続化はelectron-storeの自動同期に任せる | 必須   |

### NFR-003: 互換性

| ID       | 要件                                                   | 優先度 |
| -------- | ------------------------------------------------------ | ------ |
| NFR-003a | スキーマバージョンを持ち、将来のマイグレーションに対応 | 推奨   |
| NFR-003b | 既存のelectron-store設定と競合しない名前空間を使用     | 必須   |

### NFR-004: 可用性

| ID       | 要件                                         | 優先度 |
| -------- | -------------------------------------------- | ------ |
| NFR-004a | 設定ファイル破損時は空のデフォルト状態で起動 | 必須   |
| NFR-004b | 設定読み書きエラーは握りつぶさずログ出力     | 必須   |

## スコープ外

以下の機能は本タスクのスコープに含まれない：

| 項目                 | 理由                                         |
| -------------------- | -------------------------------------------- |
| 時間ベースの有効期限 | 要件の複雑化を避けるため後続タスクで対応     |
| ツール引数ごとの設定 | 粒度が細かすぎて実用性が低いため対象外       |
| 権限レベルの区別     | Read/Write/Execute等の区別は将来検討         |
| 危険ツールの完全除外 | 設定オプションとして提供（除外強制はしない） |
