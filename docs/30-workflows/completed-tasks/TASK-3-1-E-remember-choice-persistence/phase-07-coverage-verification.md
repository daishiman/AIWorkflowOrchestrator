## 目的

テストカバレッジ目標の達成状況を検証し、統合テストを実行してシステム全体の動作を確認する。

## 背景

Phase 6でテストを拡充したが、最終的なカバレッジ目標達成と統合テストの成功を確認する必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ最終確認

**目的**: ユニットテストのカバレッジ目標達成を最終確認する

**実行手順**:

1. 以下のコマンドでカバレッジを確認:
   ```bash
   pnpm --filter @repo/desktop test:coverage -- --grep "PermissionStore"
   ```
2. 以下の基準を満たしていることを確認:
   | 指標 | 最低基準 | 推奨基準 | 実績 |
   | ----------------- | -------- | -------- | ---- |
   | Line Coverage | 80% | 90% | |
   | Branch Coverage | 60% | 70% | |
   | Function Coverage | 80% | 90% | |
3. 未達の場合はPhase 6に戻りテスト追加

**期待される成果物**:

- カバレッジ確認結果表

---

### タスク2: 統合テスト実行

**目的**: 全統合テストを実行し成功を確認する

**実行手順**:

1. 以下のコマンドで統合テストを実行:
   ```bash
   pnpm --filter @repo/desktop test -- --grep "PermissionStore.integration"
   ```
2. 全テストがパスすることを確認
3. 失敗するテストがあれば原因を調査・修正

**期待される成果物**:

- 統合テスト実行結果

---

### タスク3: SkillExecutor連携テスト実行

**目的**: SkillExecutorとの連携テストを実行する

**実行手順**:

1. 以下のコマンドで連携テストを実行:
   ```bash
   pnpm --filter @repo/desktop test -- --grep "SkillExecutor.permission"
   ```
2. 以下のシナリオがテストされていることを確認:
   - 許可済みツールでダイアログスキップ
   - 未許可ツールでダイアログ表示
   - rememberChoice永続化
3. 全テストがパスすることを確認

**期待される成果物**:

- 連携テスト実行結果

## カバレッジ未達時の対応

カバレッジが目標に達しない場合:

1. **Line Coverage未達**: 未テストの行を特定し、テストケースを追加
2. **Branch Coverage未達**: 条件分岐のテストを追加（if/else両方をカバー）
3. **Function Coverage未達**: 未テストの関数を特定し、テストケースを追加

Phase 6に戻り、追加テストを作成後、再度Phase 7を実行する。
