## 目的

実際の環境で認可機能が正しく動作することを手動テストで確認する。

## 背景

自動テストでは検証できないUI/UX観点や実環境での動作を手動で確認する。

---

## 実行タスク

### タスク1: テスト環境の準備

**目的**: 手動テスト用の環境を準備する

**実行手順**:

1. 開発サーバーを起動する:

   ```bash
   pnpm --filter @repo/desktop dev
   ```

2. テスト用ユーザーを準備する:
   - ユーザーA（セッション所有者）
   - ユーザーB（非所有者）

**期待される成果物**: テスト環境準備完了

---

### タスク2: 正常系シナリオテスト

**目的**: 所有者による操作が正常に動作することを確認する

**テストシナリオ**:

| No  | シナリオ                     | 期待結果               | 結果 |
| --- | ---------------------------- | ---------------------- | ---- |
| 1   | 所有者がセッション一覧を表示 | 自分のセッションが表示 | \_\_ |
| 2   | 所有者がセッション詳細を表示 | 詳細が正常に表示       | \_\_ |
| 3   | 所有者がセッションを削除     | 削除が成功             | \_\_ |
| 4   | 所有者がMarkdownエクスポート | ファイルがダウンロード | \_\_ |
| 5   | 所有者がJSONエクスポート     | ファイルがダウンロード | \_\_ |

**期待される成果物**: 正常系テスト結果

---

### タスク3: 異常系シナリオテスト

**目的**: 非所有者によるアクセスが正しく拒否されることを確認する

**テストシナリオ**:

| No  | シナリオ                           | 期待結果                 | 結果 |
| --- | ---------------------------------- | ------------------------ | ---- |
| 1   | 非所有者がセッション詳細にアクセス | アクセス拒否エラー       | \_\_ |
| 2   | 非所有者がセッション削除を試行     | 削除が拒否される         | \_\_ |
| 3   | 非所有者がエクスポートを試行       | エクスポートが拒否される | \_\_ |
| 4   | 存在しないセッションにアクセス     | 適切なエラー表示         | \_\_ |

**期待される成果物**: 異常系テスト結果

---

### タスク4: エラーメッセージ確認

**目的**: エラーメッセージが情報漏洩しないことを確認する

**確認項目**:

- [ ] エラーメッセージにセッションIDが含まれていない
- [ ] エラーメッセージにuserIdが含まれていない
- [ ] 存在しないセッションと認可失敗で同じエラーメッセージ
- [ ] スタックトレースが表示されていない

**期待される成果物**: エラーメッセージ確認結果

---
