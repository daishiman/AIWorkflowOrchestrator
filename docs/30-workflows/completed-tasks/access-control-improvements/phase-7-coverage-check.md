## 目的

テストカバレッジ目標の達成を検証し、統合テストを実行して認可機能が正しく動作することを確認する。

## 背景

Phase 5-6で実装・テストした認可チェック機能のカバレッジを測定し、品質基準を満たしていることを確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジの測定

**目的**: 認可機能のユニットテストカバレッジを測定する

**実行手順**:

1. カバレッジ付きでテストを実行する:

   ```bash
   pnpm --filter @repo/shared test:run chat-history --coverage
   ```

2. 以下の目標を確認する:

   | 指標              | 最低基準 | 推奨基準 | 実測値 |
   | ----------------- | -------- | -------- | ------ |
   | Line Coverage     | 80%      | 90%      | \_\_%  |
   | Branch Coverage   | 60%      | 70%      | \_\_%  |
   | Function Coverage | 80%      | 90%      | \_\_%  |

3. カバレッジが不足している箇所を特定する

**期待される成果物**:

- カバレッジ測定結果

---

### タスク2: カバレッジ不足箇所の分析

**目的**: カバレッジが不足している箇所を分析し、追加テストの必要性を判断する

**実行手順**:

1. カバレッジレポートを確認する:
   - `coverage/lcov-report/index.html` を開く
   - 未カバー行を特定する

2. 以下の観点で分析する:
   - 認可チェック関連コードのカバレッジ
   - errors.ts のカバレッジ
   - verifySessionOwnership のカバレッジ

3. 不足箇所に対するアクションを決定する:
   - 追加テストが必要か
   - テスト不可能なコード（デッドコード等）か

**期待される成果物**:

- カバレッジ分析結果

---

### タスク3: 追加テストの実装（必要な場合）

**目的**: カバレッジ目標未達の場合、追加テストを実装する

**実行手順**:

1. カバレッジ不足箇所に対するテストを追加する
2. テストを実行してカバレッジが向上したことを確認する
3. 目標達成まで繰り返す

**期待される成果物**:

- 追加テスト（必要な場合）
- 更新されたカバレッジ結果

---

### タスク4: 統合テストの実行

**目的**: 認可機能が統合環境で正しく動作することを確認する

**実行手順**:

1. 統合テストを実行する（存在する場合）:

   ```bash
   pnpm --filter @repo/shared test:run integration
   ```

2. 以下のシナリオが正しく動作することを確認する:
   - 認可成功時のデータフロー
   - 認可失敗時のエラーレスポンス
   - エラーハンドリングの動作

**期待される成果物**:

- 統合テスト結果

---

### タスク5: 全テストスイートの実行

**目的**: 全テストが成功することを確認し、リグレッションがないことを検証する

**実行手順**:

1. chat-history関連の全テストを実行する:

   ```bash
   pnpm --filter @repo/shared test:run chat-history
   ```

2. shared パッケージの全テストを実行する:

   ```bash
   pnpm --filter @repo/shared test:run
   ```

3. 全テストが成功することを確認する

**期待される成果物**:

- 全テスト実行結果

---

### タスク6: カバレッジ確認結果の記録

**目的**: カバレッジ確認結果を文書化する

**実行手順**:

1. `outputs/phase-7/` ディレクトリを作成する
2. 以下の内容を含むレポートを作成する:
   - 最終カバレッジ数値
   - 目標達成状況
   - 未カバー箇所の説明（必要な場合）
   - 統合テスト結果
3. レポートを保存する

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`
