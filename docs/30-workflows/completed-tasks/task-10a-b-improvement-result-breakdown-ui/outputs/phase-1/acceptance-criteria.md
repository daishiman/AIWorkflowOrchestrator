# Phase 1 受け入れ基準

## AC一覧

| AC ID | Given               | When                     | Then                                                       |
| ----- | ------------------- | ------------------------ | ---------------------------------------------------------- |
| AC-01 | 分析結果表示中      | 選択適用が成功する       | 結果内訳パネルが表示される                                 |
| AC-02 | `applied` が1件以上 | 結果内訳を表示する       | 提案名と成功/一部成功/失敗バッジが表示される               |
| AC-03 | `skipped` が1件以上 | 結果内訳を表示する       | スキップ提案一覧が表示される                               |
| AC-04 | `errors` が1件以上  | 結果内訳を表示する       | 失敗提案名と理由が表示される                               |
| AC-05 | 結果内訳表示中      | 再分析処理が完了する     | 結果内訳パネルが閉じる                                     |
| AC-06 | 表示中UI            | スクリーンリーダーで読む | 結果更新が `role=status` / `aria-live=polite` で通知される |

## テスト連携ID

- AC-01/02/03/04/05 -> TC-BREAKDOWN-01
- AC-04(失敗理由) -> TC-BREAKDOWN-02
- AC-06(a11y) -> TC-BREAKDOWN-03
