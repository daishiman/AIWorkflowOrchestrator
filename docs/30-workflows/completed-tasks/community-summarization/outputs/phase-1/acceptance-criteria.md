## 1. 機能受け入れ基準

### AC-01: 単一コミュニティの要約生成

| 項目       | 内容                                                        |
| ---------- | ----------------------------------------------------------- |
| ID         | AC-01                                                       |
| 説明       | 単一コミュニティに対して要約が生成できること                |
| 前提条件   | 有効なCommunity、StoredEntity[]、StoredRelation[]が存在する |
| テスト方法 | summarize()を呼び出し、Result.okが返される                  |

**検証項目**:

- [ ] CommunitySummaryが返される
- [ ] summary文字列が空でない
- [ ] keywords配列が空でない
- [ ] mainEntities配列が空でない
- [ ] confidence値が0.0〜1.0の範囲
- [ ] createdAtがDate型

### AC-02: 子コミュニティの要約を使用した親コミュニティの要約生成

| 項目       | 内容                                                               |
| ---------- | ------------------------------------------------------------------ |
| ID         | AC-02                                                              |
| 説明       | 子コミュニティの要約を使用して親コミュニティの要約が生成できること |
| 前提条件   | 子コミュニティに要約が存在する親コミュニティがある                 |
| テスト方法 | useChildSummaries=trueでsummarize()を呼び出す                      |

**検証項目**:

- [ ] 子コミュニティの要約がプロンプトに含まれる
- [ ] 親コミュニティの要約が子の内容を反映している

### AC-03: 全コミュニティの一括要約生成（階層順）

| 項目       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| ID         | AC-03                                                  |
| 説明       | 全コミュニティの要約を階層順（子→親）で生成できること  |
| 前提条件   | CommunityStructureに複数レベルのコミュニティが存在する |
| テスト方法 | summarizeAll()を呼び出す                               |

**検証項目**:

- [ ] CommunitySummarizationResultが返される
- [ ] summaries配列に全コミュニティの要約が含まれる
- [ ] 子コミュニティが親より先に処理される（level降順）
- [ ] totalTokensUsedが0より大きい
- [ ] processingTimeMsが0より大きい

### AC-04: 要約の埋め込み生成とセマンティック検索

| 項目       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| ID         | AC-04                                                    |
| 説明       | 要約の埋め込みが生成され、セマンティック検索ができること |
| 前提条件   | generateEmbedding=trueで要約が生成されている             |
| テスト方法 | searchSummaries()でクエリ検索を実行                      |

**検証項目**:

- [ ] CommunitySummary.embeddingがnumber[]で存在する
- [ ] searchSummaries()でクエリに関連する要約が返される
- [ ] 結果が類似度順にソートされている
- [ ] limit指定が機能する

### AC-05: レベル指定検索

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| ID         | AC-05                                        |
| 説明       | 特定レベルのコミュニティのみを検索できること |
| 前提条件   | 複数レベルの要約が存在する                   |
| テスト方法 | searchSummaries(query, { level: 0 })を実行   |

**検証項目**:

- [ ] 返される全ての要約がlevel=0である
- [ ] 他レベルの要約が含まれない

### AC-06: 要約の更新

| 項目       | 内容                                     |
| ---------- | ---------------------------------------- |
| ID         | AC-06                                    |
| 説明       | 既存コミュニティの要約を再生成できること |
| 前提条件   | 既に要約が存在するコミュニティがある     |
| テスト方法 | updateSummary(communityId)を呼び出す     |

**検証項目**:

- [ ] 新しいCommunitySummaryが返される
- [ ] createdAtが更新されている
- [ ] DBの要約も更新されている

### AC-07: 部分失敗時の継続処理

| 項目       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| ID         | AC-07                                                    |
| 説明       | 一部コミュニティの要約生成が失敗しても処理が継続すること |
| 前提条件   | 一部のコミュニティでLLM呼び出しが失敗する状況            |
| テスト方法 | モックでLLMエラーを発生させてsummarizeAll()を呼び出す    |

**検証項目**:

- [ ] Result.okが返される（全体としては成功）
- [ ] summaries配列に成功した要約が含まれる
- [ ] failedCommunities配列に失敗したコミュニティIDが含まれる
- [ ] 失敗したコミュニティ以外は正常に処理される
