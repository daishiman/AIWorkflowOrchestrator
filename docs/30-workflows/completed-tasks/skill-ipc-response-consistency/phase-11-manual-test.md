## 実行タスク

- タスク1: スキル実行フローを確認し、UI/契約の整合を検証する
- タスク2: スキル削除フローを確認し、戻り値契約と表示更新を検証する
- タスク3: スキルインポートフローを確認し、Profile B 返却の整合を検証する
- タスク4: エラーケースを確認し、サニタイズ済みメッセージ表示を検証する
- タスク5: DevTools 観点で契約整合性を確認する

### タスク1: スキル実行フロー確認

**目的**: skill:execute の契約統一がUI上で正しく動作することを確認する。

**手順**:

1. アプリケーションを開発モードで起動: `pnpm --filter @repo/desktop dev`
2. スキル一覧画面からスキルを選択して実行
3. 実行結果（executionId取得、状態遷移）が正しく表示されることを確認
4. DevTools の Console で `window.electronAPI.skill.execute` の戻り値形式を確認

| #   | 操作                               | 期待結果                                  |
| --- | ---------------------------------- | ----------------------------------------- |
| 1   | スキルを選択して「実行」をクリック | executionIdが取得され、実行状態に遷移する |
| 2   | 実行完了を待つ                     | 完了状態に遷移し、結果が表示される        |
| 3   | DevToolsで戻り値形式を確認         | 契約プロファイルに準拠した形式であること  |

### タスク2: スキル削除フロー確認

**目的**: skill:remove の契約統一がUI上で正しく動作することを確認する。

**手順**:

1. インポート済みスキルの削除を実行
2. 削除結果が正しくUIに反映されることを確認
3. DevTools で `window.electronAPI.skill.remove` の戻り値形式を確認

| #   | 操作                                     | 期待結果                                 |
| --- | ---------------------------------------- | ---------------------------------------- |
| 1   | インポート済みスキルの「削除」をクリック | 削除確認ダイアログが表示される           |
| 2   | 削除を確定                               | スキル一覧から削除され、UIが更新される   |
| 3   | DevToolsで戻り値形式を確認               | 契約プロファイルに準拠した形式であること |

### タスク3: スキルインポートフロー確認

**目的**: skill:import の契約統一がUI上で正しく動作することを確認する。

**手順**:

1. スキルインポートダイアログを開く
2. スキルをインポート
3. インポート結果（ImportedSkill）が正しく表示されることを確認

| #   | 操作                               | 期待結果                                    |
| --- | ---------------------------------- | ------------------------------------------- |
| 1   | スキルインポートダイアログを開く   | ダイアログが正常に表示される                |
| 2   | スキル名を入力してインポートを実行 | ImportedSkillオブジェクトが正しく返却される |
| 3   | インポート後のスキル一覧を確認     | 新しいスキルが一覧に表示される              |

### タスク4: エラーケース確認

**目的**: エラー時のUI表示が適切であることを確認する。

**手順**:

1. 存在しないスキル名でのインポート試行
2. 不正な入力（空文字列等）でのエラー表示確認
3. ネットワークエラー時のフォールバック確認

| #   | 操作                               | 期待結果                               |
| --- | ---------------------------------- | -------------------------------------- |
| 1   | 存在しないスキル名でインポート試行 | エラーメッセージが期待どおりに表示される |
| 2   | 空文字列を入力して実行             | バリデーションエラーが表示される       |
| 3   | DevToolsでエラーレスポンス形式確認 | サニタイズされたエラーが返却されること |

### タスク5: 契約整合性確認

**目的**: DevTools で IPC 契約の整合性を直接確認する。

**手順**:

1. DevTools Console で以下を確認:
   - `typeof window.electronAPI.skill` → オブジェクトであること
   - `window.skillAPI` → undefined であること（旧API削除確認 - P28対策）
2. 主要なメソッドの戻り値型をconsole.logで確認

| #   | 操作                                      | 期待結果                     |
| --- | ----------------------------------------- | ---------------------------- |
| 1   | `typeof window.electronAPI.skill` を実行  | `"object"` が返却される      |
| 2   | `window.skillAPI` を実行                  | `undefined` であること       |
| 3   | `window.electronAPI.skill.execute` を確認 | 関数として定義されていること |
| 4   | `window.electronAPI.skill.remove` を確認  | 関数として定義されていること |
