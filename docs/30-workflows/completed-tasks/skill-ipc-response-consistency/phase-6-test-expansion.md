### タスク1: 正常系テスト拡充

**目的**: 全チャネルの正常系フローをカバーする。

**手順**:

1. 各チャネルの正常系レスポンスを網羅的にテストする
2. Preload → Main → サービス層の正常フローを検証する

**テスト対象の正常系パターン（代表チャネル）**:

| チャネル            | 正常系パターン         | 検証内容                 |
| ------------------- | ---------------------- | ------------------------ |
| `skill:list`        | スキル一覧取得         | 配列の返却、各要素の形状 |
| `skill:getImported` | インポート済み一覧取得 | 配列の返却、各要素の形状 |
| `skill:execute`     | スキル実行成功         | 実行結果の形状           |
| `skill:import`      | スキルインポート成功   | 成功レスポンスの形状     |
| `skill:remove`      | スキル削除成功         | 成功レスポンスの形状     |
| `skill:get-detail`  | スキル詳細取得         | 詳細オブジェクトの形状   |
| `skill:scan`        | スキャン成功           | 返却形式の形状           |

> 14チャネル全体の対象定義は `index.md` の「IPCチャネル正本（Single Source of Truth）」に従う。

### タスク2: 異常系テスト拡充

**目的**: バリデーション失敗・サービス層エラー・IPC通信エラーをカバーする。

**手順**:

1. P42準拠3段バリデーション失敗テストを実装する
   - 型不一致（数値、オブジェクト、配列を引数に渡す）
   - 空文字列（`""`）
   - 空白文字列（`"   "`、`"\t"`, `"\n"`）
2. サービス層エラーのエラー形式テストを実装する
   - SkillNotFound エラー
   - PermissionDenied エラー
   - 実行時エラー
3. validateIpcSender 失敗テストを実装する

**P42準拠3段バリデーションテスト例**:

```typescript
// 型不一致
it("数値引数でバリデーションエラーを返す", async () => {
  const result = await handler(event, 123 as unknown as string);
  expect(result).toMatchObject({
    code: "VALIDATION_ERROR",
  });
});

// 空文字列
it("空文字列でバリデーションエラーを返す", async () => {
  const result = await handler(event, "");
  expect(result).toMatchObject({
    code: "VALIDATION_ERROR",
  });
});

// トリム空文字列
it("空白文字列でバリデーションエラーを返す", async () => {
  const result = await handler(event, "   ");
  expect(result).toMatchObject({
    code: "VALIDATION_ERROR",
  });
});
```

### タスク3: 境界値テスト拡充

**目的**: エッジケースをカバーする。

**手順**:

1. 非常に長いスキル名のテスト（例: 1000文字以上）
2. 特殊文字を含むスキル名のテスト（例: `../`, `<script>`, `\0`）
3. Unicode文字を含むスキル名のテスト（例: 日本語、絵文字）
4. `null` / `undefined` 引数のテスト
5. 同時実行テスト（複数チャネルの同時呼び出し）

**境界値テストパターン**:

| 入力パターン           | 期待動作                     | 検証対象     |
| ---------------------- | ---------------------------- | ------------ |
| 1000文字以上のスキル名 | バリデーションまたは正常処理 | 文字列長制限 |
| パストラバーサル文字列 | バリデーションエラー         | セキュリティ |
| XSS攻撃文字列          | バリデーションエラー         | セキュリティ |
| ヌル文字を含む文字列   | バリデーションエラー         | セキュリティ |
| `null`                 | バリデーションエラー         | 型チェック   |
| `undefined`            | バリデーションエラー         | 型チェック   |
| 日本語スキル名         | 正常処理                     | Unicode対応  |
| 絵文字スキル名         | 正常処理                     | Unicode対応  |
