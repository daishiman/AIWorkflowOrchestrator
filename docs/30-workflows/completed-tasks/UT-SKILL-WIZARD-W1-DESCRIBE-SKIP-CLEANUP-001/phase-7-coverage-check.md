## 目的

変更後のカバレッジ変化がないことを確認する。
`describe.skip` 内のテストは元々実行されないため、
本タスクによるカバレッジへの影響はほぼゼロであることを確認する。

## カバレッジ対象

本タスクはテストファイルのみの変更であり、実装コードの変更はない。
`describe.skip` 内のテストは元々カバレッジの対象外であるため、
変更後もカバレッジ数値に変化がないことを確認する。

| Concern            | カバレッジ方法                                    | 期待水準 |
| ------------------ | ------------------------------------------------- | -------- |
| C-01（テスト整合） | `pnpm --filter @repo/desktop test:run --coverage` | 変化なし |
| C-02（型安全性）   | `pnpm --filter @repo/desktop typecheck`           | PASS     |


## カバレッジ確認観点

- `describe.skip` 内のコードは元々カバレッジに含まれないため、変化なし
- アクティブなテストのカバレッジが変化していないことを確認する
- 変更後のカバレッジが既存の閾値を下回っていないことを確認する
