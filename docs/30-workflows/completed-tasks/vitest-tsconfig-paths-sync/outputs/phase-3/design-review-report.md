## 2. 技術的妥当性レビュー

### 2-1. vite-tsconfig-paths プラグイン互換性

| レビュー項目                            | 確認結果                                                                                   | リスク等級 |
| --------------------------------------- | ------------------------------------------------------------------------------------------ | ---------- |
| Vitest バージョン互換                   | Vitest は Vite ベースであり、プラグインの互換性は高い。Phase 5 で実証する                  | 低         |
| tsconfig `extends` 対応                 | desktop の tsconfig.json を確認済み。extends 使用時も paths は正しく解決される見込み       | 低         |
| `resolve.alias` との優先順位            | Vite の仕様として `resolve.alias` が plugins より優先。手動 alias が上書きされるリスクなし | 低         |
| `@anthropic-ai/claude-agent-sdk` モック | テスト用モックは `resolve.alias` で定義されるため、プラグインの影響を受けない              | 低         |
| monorepo ルート tsconfig                | `tsconfigPaths()` はデフォルトで `process.cwd()` の tsconfig を読み込む。設定で制御可能    | 低         |

**判定**: 技術的に妥当。Phase 5 での実証を条件として PASS。

## 5. レビュー指摘事項

### 指摘 RV-1: vitest-alias-consistency テスト108件のプラグイン導入後の影響要調査

- **深刻度**: MINOR
- **カテゴリ**: 影響範囲
- **詳細**: vitest-alias-consistency テスト（108件）がプラグイン導入後も PASS するかの具体的な調査手順が不足している。108件のテストが `vitest.config.ts` の alias セクションをどのように検証しているか（alias エントリの存在チェック vs モジュール解決の動作チェック）を事前に調査する必要がある
- **推奨対応**: Phase 4（テスト設計）開始前に、108件のテスト内容を分類し、パターン A 導入時の影響を定量的に評価する

### 指摘 RV-2: NFR-2 の変更ファイル数の正確性

- **深刻度**: MINOR
- **カテゴリ**: 要件充足
- **詳細**: パターン A でのサブパス追加時の変更ファイル数は「3ファイル」（exports + typesVersions + tsconfig paths）であり、Phase 1 仕様書の NFR-2 に記載された「2ファイル」は誤りである。プラグインは tsconfig の paths を読み込むため、paths への追加は引き続き必要。削減されるのは vitest alias の1ファイルのみ（4 → 3）
- **推奨対応**: Phase 1 成果物の NFR-2 記載は「3ファイル」として反映済み（Phase 1 成果物で修正済み）。設計書（Phase 2）のトレードオフ分析でも「3ファイル」と記載されていることを確認

### 指摘 RV-3: formatReport テストの後方互換性確認が必要

- **深刻度**: MINOR
- **カテゴリ**: 技術的妥当性
- **詳細**: `formatReport()` にエラーメッセージ（Action ヒント）を追加する場合、既存の43件のテストで出力文字列の完全一致アサーションが存在すると破壊される。テストが `toContain` か `toBe` かを確認し、必要なテスト修正を Phase 4 のスコープに含める必要がある
- **推奨対応**: Phase 4 で `formatReport()` のテストケースのアサーション形式を確認し、Action ヒント追加の影響を評価する
