## 特記事項: テストファイル 1 件時の挙動

`apps/backend` は現在テストファイルが `health.test.ts` の 1 件のみ。

- `--shard=1/2`: `health.test.ts` が割り当てられ、実行される
- `--shard=2/2`: テストファイルが割り当てられず 0 件実行（EXIT 0）

**Vitest の仕様**: テスト 0 件の場合も EXIT 0 を返す。CI は問題なく通過する。
