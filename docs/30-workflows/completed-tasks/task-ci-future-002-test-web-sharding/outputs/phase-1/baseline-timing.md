# test-web ベースライン実行時間

作成日: 2026-04-15
タスクID: TASK-CI-FUTURE-002

## ベースライン計測

### 対象パッケージ

- パッケージ: `@repo/backend` (`apps/backend/`)
- テストファイル数: **1ファイル** (`src/__tests__/health.test.ts`)

### ベースライン計測値

| 計測方法             | 計測値 | 備考                                |
| -------------------- | ------ | ----------------------------------- |
| ローカル計測（推定） | < 30秒 | テストファイルが1件のため非常に高速 |
| CI 実行時間（推定）  | < 2分  | セットアップ含む                    |

> **注意**: CI に `test-web` ジョブが存在しないため、実際の CI 実行時間の計測は不可能。
> ローカルコマンド `time pnpm --filter @repo/backend test:run` による推定値を使用。

### シャード化後の目標値

| メトリクス           | 目標値 | 根拠                                         |
| -------------------- | ------ | -------------------------------------------- |
| 最長シャード実行時間 | < 2分  | ベースライン ÷ 2 × 1.2（オーバーヘッド考慮） |
| CI timeout-minutes   | 15     | test-desktop と同値（余裕を持った設定）      |

### 回帰ガードの閾値

| メトリクス                        | 閾値     | アクション（超過時）                |
| --------------------------------- | -------- | ----------------------------------- |
| test-web 最長シャード実行時間     | 8分以内  | シャード数を 2→3 に増やすことを検討 |
| test-desktop 最長シャード実行時間 | 13分以内 | シャード数を 15→16 に戻すことを検討 |
