# test-desktop シャード削減影響評価

作成日: 2026-04-15
タスクID: TASK-CI-FUTURE-002

## 変更内容

test-desktop のシャード数を **17 → 15** に削減。

## 影響評価テーブル

| 観点                        | 変更前（17シャード） | 変更後（15シャード）  | 影響度 |
| --------------------------- | -------------------- | --------------------- | ------ |
| テストファイル数 / シャード | 約 23〜24 ファイル   | 約 26〜27 ファイル    | 低     |
| 最長シャード実行時間        | ベースライン         | +10〜15% 増加（推定） | 低〜中 |
| CI timeout-minutes          | 15 分                | 15 分（変更なし）     | なし   |
| テスト総数                  | 変化なし             | 変化なし              | なし   |
| カバレッジ計測              | 変化なし             | 変化なし              | なし   |

## シャード数削減のリスク評価

| リスク                               | 可能性                                         | 対処方針                                   |
| ------------------------------------ | ---------------------------------------------- | ------------------------------------------ |
| 最長シャード実行時間が 13 分を超える | 低（現在 17 シャードで余裕あり）               | シャード数を 15→16 に戻す                  |
| タイムアウト（15分）超過             | 非常に低                                       | timeout-minutes を 20 分に増やすことを検討 |
| テスト失敗の増加                     | なし（シャード数変更はテスト内容に影響しない） | —                                          |

## 現在の test-desktop コメント（参考）

```yaml
# CI Optimization (TASK-CI-OPT-001):
# 17シャードに分割して各シャードの実行時間を短縮（16→17に微調整）
# 399テストファイル ÷ 17 ≒ 23〜24ファイル/シャード
# GitHub Free Tier 並列上限20に対して: test-desktop×17+typecheck×1+test-shared×1+e2e×1=20
```

## 変更後のコメント（設計）

```yaml
# CI Optimization (TASK-CI-OPT-001 + TASK-CI-FUTURE-002):
# test-web シャード化のため 17→15 に削減（-2シャード）
# 399テストファイル ÷ 15 ≒ 26〜27ファイル/シャード
# GitHub Free Tier 並列上限20の内訳:
#   test-desktop: 15シャード
#   test-web:      2シャード（TASK-CI-FUTURE-002 新規追加）
#   typecheck:     1ジョブ
#   test-shared:   1ジョブ
#   e2e-desktop:   1ジョブ
#   合計:         20ジョブ（上限 = 20）
```

## 結論

test-desktop を 17→15 に削減しても実行時間への影響は軽微（推定 +10〜15%）。
timeout-minutes 15 分の範囲内に収まる見込みが高く、リスクは低い。
