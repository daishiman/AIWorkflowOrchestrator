# advanced 導線方針

| ルート                           | 残置条件                    | 昇格条件                                | 現時点の判断       |
| -------------------------------- | --------------------------- | --------------------------------------- | ------------------ |
| /advanced/skill-management-panel | 検証用直描画が必要          | 主要 shell からの安定導線が不足する場合 | 補助導線として維持 |
| /advanced/skill-analysis         | 改善 UI の単独検証          | Agent からの自然遷移が主導線化した場合  | 補助導線として維持 |
| /advanced/skill-create-wizard    | 作成 UI 単独検証            | Skill Center から明示昇格時             | 補助導線として維持 |
| /advanced/skill-center           | 代表画面の isolated capture | 不要                                    | 補助導線として維持 |
