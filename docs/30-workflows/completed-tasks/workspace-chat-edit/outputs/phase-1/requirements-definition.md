## 機能要件（FR）

### コンテキスト連携機能

| FR-ID  | 要件                     | 優先度 | 説明                                               | 受け入れ基準                                                                     |
| ------ | ------------------------ | ------ | -------------------------------------------------- | -------------------------------------------------------------------------------- |
| FR-001 | ファイルコンテキスト添付 | 高     | ワークスペースで開いているファイルをチャットに添付 | ワークスペースで開いているファイルが添付ボタンでチャットコンテキストに追加される |
| FR-002 | 選択範囲添付             | 高     | ファイルの選択範囲のみをコンテキストとして添付     | エディタで選択した範囲のみがコンテキストとして添付される                         |
| FR-003 | 複数ファイル同時添付     | 中     | 複数のファイルを同時にコンテキストとして添付       | 3ファイル以上を同時に添付でき、各ファイルの内容が正しく含まれる                  |

### 編集指示機能

| FR-ID  | 要件                 | 優先度 | 説明                             | 受け入れ基準                                                       |
| ------ | -------------------- | ------ | -------------------------------- | ------------------------------------------------------------------ |
| FR-004 | 続きを書く機能       | 高     | 添付ファイルの続きをLLMに生成    | 「続きを書いて」コマンドでファイル末尾に追記される内容が生成される |
| FR-005 | リファクタリング指示 | 高     | 選択範囲に対してリファクタリング | 選択範囲に対して「リファクタリングして」で改善コードが生成される   |
| FR-006 | テスト生成指示       | 中     | 添付コードに対するテストを生成   | 「テストを生成して」で対応するテストコードが生成される             |
| FR-007 | コメント追加指示     | 中     | コードにコメントを追加           | 「コメントを追加して」でJSDoc/コメントが生成される                 |

### 結果適用機能

| FR-ID  | 要件               | 優先度 | 説明                               | 受け入れ基準                                       |
| ------ | ------------------ | ------ | ---------------------------------- | -------------------------------------------------- |
| FR-008 | 生成結果プレビュー | 高     | LLM生成結果を適用前にプレビュー    | 生成結果が専用プレビューパネルに表示される         |
| FR-009 | 差分表示           | 高     | 変更前/変更後を差分形式で表示      | Monaco Diff Editorで変更前/変更後が並列表示される  |
| FR-010 | 承認/却下フロー    | 高     | 生成結果の適用を承認または却下     | 「適用」ボタンでファイルに書き込み、「却下」で破棄 |
| FR-011 | 部分適用           | 中     | 生成結果の一部のみをファイルに適用 | 差分の一部のみを選択して適用できる                 |

### UI/UX機能

| FR-ID  | 要件                  | 優先度 | 説明                                   | 受け入れ基準                                                             |
| ------ | --------------------- | ------ | -------------------------------------- | ------------------------------------------------------------------------ |
| FR-012 | ドラッグ&ドロップ添付 | 高     | ファイルタブからチャットへD&Dで添付    | ファイルタブをチャットエリアにドラッグで添付アイコン表示、ドロップで添付 |
| FR-013 | 右クリックメニュー    | 高     | 右クリックから「チャットで編集」を選択 | 右クリックメニューに表示され、クリックで添付                             |
| FR-014 | ショートカットキー    | 中     | キーボードショートカットで機能呼び出し | Cmd/Ctrl + Shift + Cで現在のファイルをチャットに添付                     |

## 非機能要件（NFR）

### パフォーマンス要件

| NFR-ID  | 要件               | 優先度 | 説明                            | 受け入れ基準                                  |
| ------- | ------------------ | ------ | ------------------------------- | --------------------------------------------- |
| NFR-001 | レスポンス時間     | 高     | ファイル添付は1秒以内に完了     | 1MB以下のファイル添付が1秒以内に完了          |
| NFR-002 | 大規模ファイル対応 | 中     | 1MB以上のファイルでも正常に動作 | 5MBのファイルでも添付・表示が可能（警告付き） |
| NFR-003 | メモリ効率         | 中     | 大量添付時もメモリ使用量を制御  | 10ファイル添付時でもメモリ使用量が500MB以内   |

### アクセシビリティ要件

| NFR-ID  | 要件             | 優先度 | 説明                         | 受け入れ基準                         |
| ------- | ---------------- | ------ | ---------------------------- | ------------------------------------ |
| NFR-004 | アクセシビリティ | 高     | WCAG 2.1 AA準拠              | 全操作がスクリーンリーダーで利用可能 |
| NFR-005 | キーボード操作   | 高     | 全機能をキーボードのみで操作 | マウスなしで全機能が操作可能         |

### 信頼性要件

| NFR-ID  | 要件               | 優先度 | 説明                                 | 受け入れ基準                             |
| ------- | ------------------ | ------ | ------------------------------------ | ---------------------------------------- |
| NFR-006 | エラーハンドリング | 高     | ファイル読み取りエラー時の適切な通知 | エラー発生時に原因と対処法がトースト表示 |
| NFR-007 | 状態管理の一貫性   | 高     | Zustandによる状態管理の統一          | 全状態変更がZustand経由で管理される      |

## 統合テスト連携要件

### IPC接続要件

| チャンネル名             | 方向          | 説明                                   |
| ------------------------ | ------------- | -------------------------------------- |
| `workspace:readFile`     | Renderer→Main | ファイル内容の読み取り                 |
| `workspace:writeFile`    | Renderer→Main | ファイルへの書き込み                   |
| `workspace:getOpenFiles` | Renderer→Main | 開いているファイル一覧の取得           |
| `workspace:getSelection` | Renderer→Main | エディタ選択範囲の取得                 |
| `chat:sendWithContext`   | Renderer→Main | ファイルコンテキスト付きメッセージ送信 |

### 状態管理連携

| Slice名          | 連携内容                               |
| ---------------- | -------------------------------------- |
| workspaceSlice   | 開いているファイル、選択範囲の管理     |
| chatSlice        | チャットメッセージ、コンテキストの管理 |
| diffPreviewSlice | 差分プレビュー状態の管理               |

### データフロー

```
Renderer(添付操作)
    → Main(workspace:readFile)
    → Renderer(コンテキスト追加)
    → LLM(生成リクエスト)
    → Renderer(差分表示)
    → Main(workspace:writeFile)
    → Renderer(完了通知)
```
