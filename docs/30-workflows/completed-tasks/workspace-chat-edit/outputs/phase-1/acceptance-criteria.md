## 受け入れ基準一覧

### AC-001: ファイルコンテキスト添付

**対象要件**: FR-001

| 項目  | 内容                                           |
| ----- | ---------------------------------------------- |
| Given | ワークスペースにファイルが開いている           |
| When  | 添付ボタンをクリックする                       |
| Then  | ファイル内容がチャットコンテキストに追加される |

**検証方法**:

1. ワークスペースで任意のファイルを開く
2. チャット入力エリアの添付ボタンをクリック
3. 開いているファイルが選択肢に表示される
4. ファイルを選択すると、チャット入力に添付マークが表示される
5. メッセージ送信時にファイル内容がコンテキストに含まれる

---

### AC-002: 選択範囲添付

**対象要件**: FR-002

| 項目  | 内容                                       |
| ----- | ------------------------------------------ |
| Given | エディタでテキストが選択されている         |
| When  | 「選択範囲を添付」を実行する               |
| Then  | 選択範囲のみがコンテキストとして添付される |

**検証方法**:

1. エディタで任意のテキスト範囲を選択
2. 右クリックメニューから「チャットで編集」を選択
3. 選択範囲のみがチャットに添付される
4. ファイル全体ではなく選択部分のみが含まれることを確認

---

### AC-003: 複数ファイル同時添付

**対象要件**: FR-003

| 項目  | 内容                                           |
| ----- | ---------------------------------------------- |
| Given | 複数のファイルが開いている                     |
| When  | 複数のファイルを選択して添付する               |
| Then  | 各ファイルの内容が正しくコンテキストに含まれる |

**検証方法**:

1. 3つ以上のファイルをワークスペースで開く
2. 添付メニューで複数ファイルを選択
3. 全てのファイル内容がコンテキストに含まれることを確認
4. ファイル名とパスが正しく識別されることを確認

### AC-004: 続きを書く機能

**対象要件**: FR-004

| 項目  | 内容                                       |
| ----- | ------------------------------------------ |
| Given | ファイルがコンテキストとして添付されている |
| When  | 「続きを書いて」とメッセージを送信する     |
| Then  | ファイル末尾に追記する内容が生成される     |

**検証方法**:

1. コードファイルをコンテキストとして添付
2. 「続きを書いて」または同等の指示を送信
3. 既存コードの文脈を理解した続きが生成される
4. 生成結果が適切なフォーマットで表示される

---

### AC-005: リファクタリング指示

**対象要件**: FR-005

| 項目  | 内容                                           |
| ----- | ---------------------------------------------- |
| Given | コードが選択範囲として添付されている           |
| When  | 「リファクタリングして」とメッセージを送信する |
| Then  | 改善されたコードが生成される                   |

**検証方法**:

1. リファクタリング対象のコードを選択して添付
2. 「リファクタリングして」と送信
3. 改善されたコードが生成される
4. 差分として変更点が明確に表示される

### AC-006: 生成結果プレビュー

### AC-007: 差分表示

**対象要件**: FR-009

| 項目  | 内容                                              |
| ----- | ------------------------------------------------- |
| Given | 既存コードに対する変更が生成されている            |
| When  | 差分プレビューを開く                              |
| Then  | Monaco Diff Editorで変更前/変更後が並列表示される |

**検証方法**:

1. 既存ファイルのリファクタリングを依頼
2. 差分プレビューを開く
3. 左側に変更前、右側に変更後が表示される
4. 追加行は緑、削除行は赤でハイライトされる
5. 差分間のナビゲーションが可能

---

### AC-008: 承認/却下フロー

**対象要件**: FR-010

| 項目  | 内容                                           |
| ----- | ---------------------------------------------- |
| Given | 差分プレビューが表示されている                 |
| When  | 「適用」または「却下」ボタンをクリックする     |
| Then  | 適用時はファイルに書き込み、却下時は破棄される |

**検証方法**:

1. 差分プレビューで「適用」をクリック
2. ファイルが更新されることを確認
3. 差分プレビューで「却下」をクリック
4. ファイルが変更されないことを確認
5. 両ケースで適切なフィードバック表示

### AC-009: ドラッグ&ドロップ添付

**対象要件**: FR-012

| ----- | ------------------------------------------ |

| When  | ファイルタブをチャットエリアにドラッグする |
| Then  | ドロップで添付される                       |

3. ドロップするとファイルが添付される
4. 添付されたファイルがチャット入力に表示される

### AC-010: 右クリックメニュー

**対象要件**: FR-013

| 項目  | 内容                                               |
| ----- | -------------------------------------------------- |
| Given | エディタでコードを表示している                     |
| When  | 右クリックしてメニューを開く                       |
| Then  | 「チャットで編集」が表示され、クリックで添付される |

**検証方法**:

1. エディタ内で右クリック
2. コンテキストメニューに「チャットで編集」が表示される
3. クリックするとファイル/選択範囲がチャットに添付される
4. チャット入力にフォーカスが移動する

### AC-011: レスポンス時間

**対象要件**: NFR-001

| 項目  | 内容                    |
| ----- | ----------------------- |
| Given | 1MB以下のファイルがある |
| When  | ファイルを添付する      |
| Then  | 1秒以内に添付が完了する |

**検証方法**:

1. 1MBのテストファイルを準備
2. 添付操作開始からUI表示完了までの時間を計測
3. 1秒以内であることを確認
4. パフォーマンスプロファイリングでボトルネックがないことを確認

### AC-012: エラーハンドリング

**対象要件**: NFR-006

| 項目  | 内容                                   |
| ----- | -------------------------------------- |
| Given | ファイル読み取りエラーが発生する状況   |
| When  | ファイルを添付しようとする             |
| Then  | エラー原因と対処法がトースト表示される |

**検証方法**:

1. 存在しないファイルパスで添付を試行
2. 適切なエラーメッセージが表示される
3. パーミッションエラーで添付を試行
4. ユーザーに対処方法が提示される

### AC-013: キーボード操作

**対象要件**: NFR-005

| 項目  | 内容                                      |
| ----- | ----------------------------------------- |
| Given | チャットUI/差分プレビューが表示されている |
| When  | キーボードのみで操作する                  |
| Then  | 全機能がアクセス可能である                |

**検証方法**:

1. Tabキーで全インタラクティブ要素にフォーカス可能
2. Enter/Spaceでボタン・メニューを操作可能
3. ショートカットキー（Cmd/Ctrl+Shift+C）で添付可能
4. Escapeでモーダル/プレビューを閉じることが可能
