## スコープ内（In Scope）

| 機能             | 説明                               | 優先度 |
| ---------------- | ---------------------------------- | ------ |
| ファイル添付     | 開いているファイルをチャットに添付 | 高     |
| 選択範囲添付     | エディタの選択範囲のみを添付       | 高     |
| 複数ファイル添付 | 複数ファイルを同時に添付           | 中     |

| 言語検出         | ファイル拡張子から言語を自動検出   | 高     |

## スコープ外（Out of Scope）

### 今回のスコープ外

| 機能                     | 理由                     | 将来対応 |
| ------------------------ | ------------------------ | -------- |
| リアルタイム協調編集     | 個人利用アプリのため不要 | 検討     |
| 複数LLMの同時比較        | MVP後の拡張機能          | 検討     |
| バージョン管理統合       | Git連携は別タスク        | 予定     |
| 音声入力による指示       | アクセシビリティ拡張     | 検討     |
| 画像ファイルのプレビュー | テキストファイルに限定   | 検討     |
| リモートファイル編集     | ローカルファイルのみ対象 | 検討     |
| 自動保存                 | 明示的な承認フローを優先 | 検討     |
| Undo/Redo統合            | Phase 2以降で対応        | 予定     |

### 技術的制約

| 制約               | 説明                                        |
| ------------------ | ------------------------------------------- |
| 対応ファイルサイズ | 10MB以上は警告表示、動作保証外              |
| 対応ファイル形式   | テキストファイルのみ（バイナリは対象外）    |
| 同時添付ファイル数 | 最大10ファイル（コンテキスト長の制約）      |
| オフライン対応     | LLM通信が必要なため、オフラインでは編集不可 |
