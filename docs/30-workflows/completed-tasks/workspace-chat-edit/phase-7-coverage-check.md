## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。基準未達の場合はPhase 6に戻り追加テストを実施する。

## 実行タスク

- **カバレッジ再測定**: テストカバレッジの再計測
- **統合テスト実行**: 統合テストの実行と結果確認
- **ゲート判定**: カバレッジ基準達成の判定

## 実行手順

### 1. カバレッジ再測定

```bash
pnpm --filter @repo/desktop test:coverage
```

### 2. 統合テスト実行

```bash
pnpm --filter @repo/desktop test:integration
pnpm --filter @repo/desktop test:e2e
```

### 3. ゲート判定

カバレッジ未達や統合テスト失敗がある場合、Phase 6へ戻って拡充する。

## 統合テスト連携【必須】

統合テストの再実行とゲート判定:

| 判定項目                 | 基準 | 結果 | 判定 |
| ------------------------ | ---- | ---- | ---- |
| ユニットテストLine       | 80%+ | -    | -    |
| ユニットテストBranch     | 60%+ | -    | -    |
| ユニットテストFunction   | 80%+ | -    | -    |
| 結合テストAPI            | 100% | -    | -    |
| 結合テストシナリオ正常系 | 100% | -    | -    |
| 結合テストシナリオ異常系 | 80%+ | -    | -    |

## ゲート判定基準

| 判定 | 条件                         | 対応              |
| ---- | ---------------------------- | ----------------- |
| PASS | 全カバレッジ基準達成         | Phase 8へ進行     |
| FAIL | いずれかのカバレッジ基準未達 | Phase 6へ戻り拡充 |
