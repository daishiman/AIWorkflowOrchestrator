## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。未達の場合はPhase 6に戻る。

## 背景

カバレッジ確認は品質保証の重要なゲートであり、以下を検証:

- ユニットテストカバレッジ基準の達成
- 結合テストカバレッジ基準の達成
- 全テストの成功確認

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ測定

**目的**: テストカバレッジを測定する

**実行手順**:

```bash
# カバレッジ測定
pnpm --filter @repo/desktop test:coverage
```

**確認項目**:

- Line Coverage
- Branch Coverage
- Function Coverage

**期待される成果物**:

- カバレッジ測定結果

---

### タスク2: カバレッジ基準判定

**目的**: カバレッジが基準を満たしているか判定する

**判定基準**:

| 指標              | 最低基準 | 現在値 | 判定 |
| ----------------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | -      | -    |
| Branch Coverage   | 60%      | -      | -    |
| Function Coverage | 80%      | -      | -    |

**未達の場合の対応**:

- Phase 6に戻り、不足領域のテストを追加

**期待される成果物**:

- カバレッジ判定結果

---

### タスク3: 統合テスト実行

**目的**: 統合テストを実行し、結果を確認する

**実行手順**:

```bash
# 統合テスト実行
pnpm --filter @repo/desktop test:integration
```

**判定基準**:

| 指標                         | 目標 | 現在値 | 判定 |
| ---------------------------- | ---- | ------ | ---- |
| APIエンドポイント            | 100% | -      | -    |
| モジュール間インターフェース | 100% | -      | -    |
| 正常系シナリオ               | 100% | -      | -    |
| 異常系シナリオ               | 80%+ | -      | -    |
| 外部連携ポイント             | 100% | -      | -    |

**期待される成果物**:

- 統合テスト実行結果

---

### タスク4: 全テスト実行確認

**目的**: 全テストが成功することを確認する

**実行手順**:

```bash
# 全テスト実行
pnpm --filter @repo/desktop test
```

**確認項目**:

- [ ] 全ユニットテストが成功
- [ ] 全統合テストが成功
- [ ] テスト実行時間が妥当

**期待される成果物**:

- 全テスト実行結果
