## 目的

定義された品質基準をすべて満たすことを検証する。品質ゲートとして、全項目をクリアする必要がある。

## 背景

品質保証は以下の観点で検証:

- 機能検証（自動テスト）
- コード品質（Lint/型チェック）
- テスト網羅性（カバレッジ）
- セキュリティ（脆弱性スキャン）

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 機能検証

**目的**: 自動テストの完全成功を確認する

**実行手順**:

```bash
# 全テスト実行
pnpm --filter @repo/desktop test

# 統合テスト実行
pnpm --filter @repo/desktop test:integration
```

**チェックリスト**:

- [ ] 全ユニットテスト成功
- [ ] 全統合テスト成功

**期待される成果物**:

- テスト実行結果

---

### タスク2: コード品質検証

**目的**: Lint/型チェックをクリアすることを確認する

**実行手順**:

```bash
# 型チェック
pnpm --filter @repo/desktop typecheck

# Lint
pnpm --filter @repo/desktop lint

# フォーマット確認
pnpm --filter @repo/desktop format:check
```

**チェックリスト**:

- [ ] 型エラーなし
- [ ] Lintエラーなし
- [ ] フォーマット適用済み

**期待される成果物**:

- 品質チェック結果

---

### タスク3: テスト網羅性検証

**目的**: カバレッジ基準を満たしていることを確認する

**実行手順**:

```bash
# カバレッジ確認
pnpm --filter @repo/desktop test:coverage
```

**カバレッジ基準**:

| 指標              | 最低基準 | 結果 |
| ----------------- | -------- | ---- |
| Line Coverage     | 80%      | -    |
| Branch Coverage   | 60%      | -    |
| Function Coverage | 80%      | -    |

**期待される成果物**:

- カバレッジレポート

---

### タスク4: セキュリティ検証

**目的**: 重大な脆弱性がないことを確認する

**実行手順**:

```bash
# 依存関係の脆弱性チェック
pnpm audit

# セキュリティスキャン（あれば）
pnpm --filter @repo/desktop security:scan
```

**チェックリスト**:

- [ ] 重大な脆弱性なし
- [ ] 中程度以上の脆弱性に対策済み

**確認すべきセキュリティ項目**:

- [ ] APIキーがハードコードされていないか
- [ ] ユーザー入力のサニタイズが適切か
- [ ] エラーメッセージに機密情報が含まれていないか

**期待される成果物**:

- セキュリティチェック結果
