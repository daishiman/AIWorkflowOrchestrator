## 2. 除外範囲（Out of Scope）

### 2.1 ストリーミングレスポンス

| 除外項目           | 理由                                             |
| ------------------ | ------------------------------------------------ |
| ストリーミング対応 | 既存のAIChatResponseが非ストリーミング前提の設計 |
| リアルタイム表示   | 現在のIPC設計では対応していない                  |

**備考**: ストリーミングは将来拡張として別タスクで対応

### 2.2 会話履歴の永続化

| 除外項目         | 理由                                   |
| ---------------- | -------------------------------------- |
| 会話履歴のDB保存 | ChatHistory機能として別途実装済み/予定 |
| マルチターン会話 | 本タスクのスコープ外                   |

**備考**: 会話履歴は`ChatHistoryProvider`で管理

### 2.3 RAG機能の実装

| 除外項目                    | 理由                           |
| --------------------------- | ------------------------------ |
| ragEnabled=true時の検索処理 | RAG機能は別タスクで実装予定    |
| ragSourcesの実際の取得      | 本タスクでは空配列またはモック |

### 2.4 UI変更

| 除外項目                 | 理由                   |
| ------------------------ | ---------------------- |
| Renderer側コンポーネント | UIは既存のまま変更なし |
| 新しい設定画面           | 本タスクのスコープ外   |

### 2.5 新規プロバイダーの追加

| 除外項目                | 理由                      |
| ----------------------- | ------------------------- |
| 5番目以降のプロバイダー | 既存4プロバイダーのみ対応 |
