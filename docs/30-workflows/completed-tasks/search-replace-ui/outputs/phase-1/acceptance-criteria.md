## AC-1: ファイル内検索

### AC-1-1: パネル開閉

| 条件  | 内容                                   |
| ----- | -------------------------------------- |
| Given | エディタが開いている状態               |
| When  | Cmd+F（Mac）/ Ctrl+F（Win）を押す      |
| Then  | 検索パネルが表示される                 |
| And   | 検索入力フィールドにフォーカスが当たる |

| 条件  | 内容                       |
| ----- | -------------------------- |
| Given | 検索パネルが開いている状態 |
| When  | Escapeキーを押す           |
| Then  | 検索パネルが閉じる         |
| And   | エディタにフォーカスが戻る |

### AC-1-2: 検索実行

| 条件  | 内容                                 |
| ----- | ------------------------------------ |
| Given | 検索パネルが開いている状態           |
| When  | 検索クエリを入力してEnterを押す      |
| Then  | 検索が実行される                     |
| And   | マッチした箇所がハイライト表示される |
| And   | 結果件数が「X/Y」形式で表示される    |

### AC-1-3: 結果ナビゲーション

| 条件  | 内容                               |
| ----- | ---------------------------------- |
| Given | 検索結果が表示されている状態       |
| When  | F3キーを押す                       |
| Then  | 次のマッチ箇所にカーソルが移動する |
| And   | 現在のマッチがハイライトされる     |

| 条件  | 内容                               |
| ----- | ---------------------------------- |
| Given | 検索結果が表示されている状態       |
| When  | Shift+F3キーを押す                 |
| Then  | 前のマッチ箇所にカーソルが移動する |

### AC-1-4: 置換

| 条件  | 内容                                           |
| ----- | ---------------------------------------------- |
| Given | 置換モードで検索結果が表示されている状態       |
| When  | 置換テキストを入力して「置換」ボタンをクリック |
| Then  | 現在のマッチが置換される                       |
| And   | 次のマッチにカーソルが移動する                 |

| 条件  | 内容                                     |
| ----- | ---------------------------------------- |
| Given | 置換モードで検索結果が表示されている状態 |
| When  | 「全置換」ボタンをクリック               |
| Then  | すべてのマッチが置換される               |
| And   | 結果件数が更新される                     |

## AC-2: ワークスペース検索

### AC-2-1: パネル開閉

| 条件  | 内容                                          |
| ----- | --------------------------------------------- |
| Given | アプリケーションがアクティブな状態            |
| When  | Cmd+Shift+F（Mac）/ Ctrl+Shift+F（Win）を押す |
| Then  | ワークスペース検索パネルが表示される          |
| And   | 検索入力フィールドにフォーカスが当たる        |

### AC-2-2: ファイル横断検索

| 条件  | 内容                                         |
| ----- | -------------------------------------------- |
| Given | ワークスペース検索パネルが開いている状態     |
| When  | 検索クエリを入力してEnterを押す              |
| Then  | ワークスペース内の全ファイルが検索される     |
| And   | 結果がファイルごとにグループ化して表示される |

### AC-2-3: ファイルジャンプ

| 条件  | 内容                                       |
| ----- | ------------------------------------------ |
| Given | ワークスペース検索結果が表示されている状態 |
| When  | 結果の行をクリック                         |
| Then  | 該当ファイルが開く                         |
| And   | 該当行にカーソルが移動する                 |

### AC-2-4: フィルタリング

| 条件  | 内容                                     |
| ----- | ---------------------------------------- |
| Given | ワークスペース検索パネルが開いている状態 |
| When  | 「含めるファイル」に`*.ts`を入力して検索 |
| Then  | TypeScriptファイルのみが検索対象になる   |

| 条件  | 内容                                             |
| ----- | ------------------------------------------------ |
| Given | ワークスペース検索パネルが開いている状態         |
| When  | 「除外するファイル」に`node_modules`を入力       |
| Then  | node_modulesディレクトリが検索対象から除外される |

## AC-3: キーボードショートカット

### AC-3-1: グローバルショートカット

| ショートカット     | macOS       | Windows/Linux | 期待動作                    |
| ------------------ | ----------- | ------------- | --------------------------- |
| ファイル内検索     | Cmd+F       | Ctrl+F        | SearchPanel開く             |
| ファイル内置換     | Cmd+T       | Ctrl+T        | 置換モードでSearchPanel開く |
| ワークスペース検索 | Cmd+Shift+F | Ctrl+Shift+F  | WorkspaceSearchPanel開く    |

### AC-3-2: パネル内ショートカット

| ショートカット         | キー                   | 期待動作         |
| ---------------------- | ---------------------- | ---------------- |
| 閉じる                 | Escape                 | パネルを閉じる   |
| 次の結果               | Enter / F3             | 次のマッチへ移動 |
| 前の結果               | Shift+Enter / Shift+F3 | 前のマッチへ移動 |
| 全置換（置換モード時） | Alt+Enter              | すべて置換       |

## AC-5: アクセシビリティ

### AC-5-1: WCAG 2.1 AA準拠

| 項目               | 基準                                   |
| ------------------ | -------------------------------------- |
| キーボード操作     | すべての機能がキーボードのみで操作可能 |
| フォーカス表示     | フォーカス状態が視覚的に明確           |
| スクリーンリーダー | aria属性による適切なアナウンス         |
| 色のコントラスト   | 4.5:1以上のコントラスト比              |
| フォーカストラップ | モーダル内でフォーカスが維持される     |

## AC-6: パフォーマンス

### AC-6-1: 応答時間

| 操作           | 基準      |
| -------------- | --------- |
| 検索実行       | 200ms以内 |
| 結果表示       | 200ms以内 |
| ハイライト更新 | 100ms以内 |

### AC-6-2: スケーラビリティ

| 条件               | 基準                           |
| ------------------ | ------------------------------ |
| 検索結果1000件以上 | UIがブロックされない           |
| 大規模ファイル     | メモリ使用量が適切に管理される |

## AC-7: セキュリティ

### AC-7-1: ReDoS対策

| 条件  | 内容                              |
| ----- | --------------------------------- |
| Given | 正規表現検索モードが有効          |
| When  | 危険なパターン（`(a+)+`等）を入力 |
| Then  | エラーメッセージが表示される      |
| And   | 検索が実行されない                |

### AC-7-2: パストラバーサル防止

| 条件  | 内容                                |
| ----- | ----------------------------------- |
| Given | ワークスペース検索を実行            |
| When  | `../`を含むパスが検索対象になる場合 |
| Then  | ワークスペース外のパスは除外される  |
| And   | セキュリティログが記録される        |
