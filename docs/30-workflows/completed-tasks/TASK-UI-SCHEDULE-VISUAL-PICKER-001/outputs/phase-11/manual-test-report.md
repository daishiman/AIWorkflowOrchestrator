# Phase 11 手動テストレポート

作成日: 2026-04-09
タスク: TASK-UI-SCHEDULE-VISUAL-PICKER-001

## 手動テスト対象

VisualCronPicker コンポーネントのビジュアル動作・UX フロー確認。
自動テスト（Vitest）でカバーできない実際のレンダリング・インタラクションを確認する。

## 手動テストシナリオ

### シナリオ 1: 基本フロー（毎日 09:00）

| ステップ | 操作                    | 期待動作                                                          |
| -------- | ----------------------- | ----------------------------------------------------------------- |
| 1        | VisualCronPicker を開く | FrequencySelector（「毎日」選択済み）・時刻セレクターが表示される |
| 2        | 時を「9」に設定         | CronPreview が `"毎日 09:00"` / `0 9 * * *` に更新                |
| 3        | 分を「0」に設定         | CronPreview が `0 9 * * *` を維持                                 |
| 4        | 保存ボタンクリック      | IPC に `cronExpression: "0 9 * * *"` が渡される                   |

### シナリオ 2: 毎週フロー（月・水・金 09:00）

| ステップ | 操作                         | 期待動作                                                   |
| -------- | ---------------------------- | ---------------------------------------------------------- |
| 1        | 「毎週」ボタンをクリック     | WeekdaySelector が表示される                               |
| 2        | 「月」「水」「金」をクリック | 3ボタンが aria-pressed=true になる                         |
| 3        | 時を「9」に設定              | CronPreview が `"毎週 月・水・金 09:00"` / `0 9 * * 1,3,5` |
| 4        | 保存クリック                 | IPC に `cronExpression: "0 9 * * 1,3,5"`                   |

### シナリオ 3: 毎月フロー（1日 12:00）

| ステップ | 操作                     | 期待動作                                        |
| -------- | ------------------------ | ----------------------------------------------- |
| 1        | 「毎月」ボタンをクリック | DayOfMonthSelector（1-31 グリッド）が表示される |
| 2        | 「1」をクリック          | 1日が選択状態                                   |
| 3        | 時を「12」に設定         | CronPreview が `"毎月1日 12:00"` / `0 12 1 * *` |

### シナリオ 4: 既存スケジュール読み込み（weekly 逆変換）

| ステップ | 操作                           | 期待動作                                        |
| -------- | ------------------------------ | ----------------------------------------------- |
| 1        | `value="0 9 * * 1,3,5"` で開く | 「毎週」が選択される                            |
| 2        | 月・水・金の曜日が表示される   | WeekdaySelector が選択済みで表示される          |
| 3        | 時が 9 で表示される            | CronPreview が `"毎週 月・水・金 09:00"` を表示 |

### シナリオ 5: 高度な設定モード

| ステップ | 操作                           | 期待動作                                 |
| -------- | ------------------------------ | ---------------------------------------- |
| 1        | 「高度な設定」ボタンをクリック | テキスト入力欄が表示される               |
| 2        | `*/5 * * * *` を入力           | CronPreview がカスタム式を表示           |
| 3        | 「ビジュアル設定」に戻る       | FrequencySelector が custom に切り替わる |

### シナリオ 6: 無効状態（曜日未選択で weekly 確定試行）のエラー表示

| ステップ | 操作                       | 期待動作                                      |
| -------- | -------------------------- | --------------------------------------------- |
| 1        | 「毎週」ボタンをクリック   | WeekdaySelector が表示される                  |
| 2        | 月・水・金の選択を全て解除 | `role="alert"` のエラーメッセージが表示される |
| 3        | 保存を試行                 | IPC が呼ばれない                              |

## 既知の制限事項

| 制限                   | 詳細                                                       | 影響                           |
| ---------------------- | ---------------------------------------------------------- | ------------------------------ |
| semantic cron 検証なし | 2月31日等の意味的に不正な日付を許容                        | ユーザーが理解して設定する前提 |
| Electron specific      | `Intl.DateTimeFormat` のタイムゾーン対応はランタイムに依存 | Node.js/V8 の ICU データによる |
