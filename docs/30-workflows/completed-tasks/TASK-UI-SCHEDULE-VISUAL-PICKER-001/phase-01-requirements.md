## 目的

クロン式の直接入力負担を下げつつ、`SkillWizardScheduleConfig` の `cronExpression` / `timezone` を検証できるようにする。一般ユーザーが直感的に操作できるビジュアルスケジュール入力と、issue #2000 のバリデーション要件を両立させるための要件を確定する。

## 背景

- **現状の問題**: `ScheduleDialog` の cron 入力はプリセット中心で、`ConversationRoundStep` の scheduleConfig は cron の形式確認しか持っていない
- **ユーザーペイン**: 一般ユーザーはクロン式の5フィールド構造（分・時・日・月・曜日）を理解していないため設定を断念するケースが発生
- **検証不足**: `SkillWizardScheduleConfig` の timezone は IANA 文字列として妥当かを明示的に確認する必要がある
- **既存資産**: TASK-9G でバックエンド（ScheduleStore・SkillScheduler・IPC・Preload API）は完全実装済み
- **関連Issue**: daishiman/AIWorkflowOrchestrator#2000（`skill-wizard-schedule-config-cron-validation`）

## 機能要件

### FR-01: 頻度セレクター

選択肢:

- `every-minute` - 毎分
- `every-hour` - 毎時（分を選択）
- `daily` - 毎日（時刻を選択）
- `weekly` - 毎週（曜日 + 時刻を選択）
- `monthly` - 毎月（日付 + 時刻を選択）
- `custom` - カスタム（各フィールドを個別設定）

### FR-02: 曜日セレクター

- 月・火・水・木・金・土・日のトグルボタン形式
- 複数選択可能
- `weekly` 選択時のみ表示
- 少なくとも1つ選択必須（バリデーション）

### FR-03: 時刻ピッカー

- 時: 0-23（ドロップダウンまたはスピナー）
- 分: 0, 5, 10, ..., 55（5分刻みドロップダウン、カスタム入力も許容）
- `every-minute` 以外で表示

### FR-04: 日付ピッカー（月次）

- 1-31日の選択
- `monthly` 選択時のみ表示
- 月末指定オプション（`L`フラグを使用、node-cron対応の場合）

### FR-05: クロン式プレビュー

- 生成されたクロン式を表示（例: `0 9 * * 1,3,5`）
- 自然言語での説明も表示（例: 毎週月・水・金 09:00）
- 上級者向けに直接編集モードへの切り替えボタン

### FR-06: バリデーション

- 必須フィールド未入力時のエラーメッセージ
- 無効なクロン式（直接編集時）のシンタックスエラー表示
- `SkillWizardScheduleConfig` の `cronExpression` に対する 5 フィールド構文チェック
- `SkillWizardScheduleConfig` の `timezone` に対する IANA timezone チェック
- P42準拠の3段バリデーション（型チェック → 空文字列 → トリム空文字列）

### FR-07: 共通バリデーション

- `ConversationRoundStep` と `ScheduleDialog` が同じ検証関数を参照する
- cron の意味論的な next-run 計算は行わず、入力可否のみを判定する

### FR-08: 入力支援

- cron 入力はプリセットとビジュアル選択の両方で支援する
- 既存の cron 文字列を編集する場合も、変換結果を確認できる

## 非機能要件

| ID     | 要件             | 基準                                                               |
| ------ | ---------------- | ------------------------------------------------------------------ |
| NFR-01 | パフォーマンス   | 選択変更からプレビュー更新まで 16ms 以内（1フレーム）              |
| NFR-02 | アクセシビリティ | WCAG 2.1 AA準拠、キーボードナビゲーション対応                      |
| NFR-03 | 国際化           | 曜日・時刻表示は i18n 対応（日本語優先、将来的に英語対応）         |
| NFR-04 | バンドルサイズ   | 外部ライブラリ追加は不要。既存 API と軽量な自前検証で完結する      |
| NFR-05 | 後方互換性       | 既存のクロン式文字列として保存されたスケジュールが正常に読み込める |
