| 思考法           | 確認内容                                                                         |

| ユーザー中心思考 | クロン式を知らないユーザーが3クリック以内で「毎週月曜9:00」を設定できるか        |
| 逆説思考         | 全チェックがPASSでも実際のユーザー操作で問題が起きる箇所がないか（探索的テスト） |
| システム思考     | 因果ループ監査で既存機能への影響が全て「低」または「なし」になっているか         |
| 制約思考         | Electronのレンダラープロセス制約（Node.js API制限）の範囲内で動作しているか      |
| 水平思考         | セキュリティチェックでOWASP Top 10の観点から見落としがないか                     |
