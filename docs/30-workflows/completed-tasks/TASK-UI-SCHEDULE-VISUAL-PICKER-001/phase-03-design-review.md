## ゲート判定基準

| 判定         | 基準                       | 次のアクション                                     |
| ------------ | -------------------------- | -------------------------------------------------- |
| **PASS**     | 全レビュー観点で問題なし   | Phase 4（テスト作成）へ進む                        |
| **MINOR**    | 軽微な指摘（設計変更不要） | 指摘事項を記録し Phase 4 へ進む                    |
| **MAJOR**    | 設計変更が必要な問題       | 影響範囲に応じて Phase 1 または Phase 2 へ差し戻し |
| **CRITICAL** | 致命的な問題（前提が崩壊） | Phase 1 へ戻りユーザー確認                         |
