## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

モバイル詳細パネルはボトムシート表示に対応しているが、下方向スワイプで閉じる操作が未実装。

### 1.2 問題点

- FR-5-3（閾値50pxのスワイプ閉じ）が未達。
- モバイル操作の期待値（ジェスチャー操作）と乖離。
- 誤操作防止（短スワイプ復帰）挙動が存在しない。

### 1.3 放置影響

- モバイルUXの違和感が継続。
- 閉じる操作がクリック依存になり、片手操作性が低下。

---

## 2. 何を達成するか（What）

### 2.1 目的

モバイル詳細パネルに「下方向スワイプで閉じる」操作を導入し、ジェスチャー体験を改善する。

### 2.2 完了イメージ

- ドラッグ距離が50px以上で `onClose` 実行。
- 50px未満は元位置へスナップバック。
- スクロール操作と衝突しないよう縦方向ジェスチャーを判定。

### 2.3 スコープ

- 含む: touch/pointerイベント処理、閾値判定、アニメーション復帰。
- 含まない: デスクトップ挙動の変更。

---

## 3. どのように実行するか（How）

### 3.1 前提条件

- `SkillDetailPanel.tsx` のモバイルブロック編集。
- 既存クローズ手段（オーバーレイ/Escape）を維持する。

### 3.2 推奨アプローチ

1. モバイルボトムシートに drag state を導入。
2. `touchstart/move/end` でY差分を計測し、閾値判定する。
3. ドラッグ中は transform で追従し、完了時にクローズ/復帰を分岐する。

### 3.3 実装課題と解決策（親タスクからの教訓）

| 課題                         | 解決策                                           |
| ---------------------------- | ------------------------------------------------ |
| スクロールとジェスチャー競合 | パネルヘッダー起点または縦方向優先判定を導入する |
| 閾値未調整で誤閉じ発生       | 50px閾値と速度条件をテストで固定する             |

---

## 4. 実行手順

1. 既存モバイルパネルのイベントハンドリングを確認する。
2. ドラッグ開始・移動・終了の状態管理を追加する。
3. `translateY` 追従と閾値判定（50px）を実装する。
4. 短スワイプ時の復帰アニメーションを追加する。
5. モバイル向けテストを追加し、既存閉じる操作との互換を確認する。

---

## 5. 完了条件チェックリスト

- [ ] 50px以上の下方向スワイプでパネルが閉じる。
- [ ] 50px未満のスワイプで元の位置に戻る。
- [ ] 既存のオーバーレイクリック/Escape操作が維持される。
