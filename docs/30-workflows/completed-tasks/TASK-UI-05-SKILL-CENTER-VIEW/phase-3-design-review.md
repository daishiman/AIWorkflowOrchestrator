## 目的

実装開始前に Phase 1（要件定義）および Phase 2（設計）の成果物の妥当性を検証する。要件カバレッジ、設計整合性、IPC契約整合性、P31対策、テスト環境制約、アクセシビリティ、レスポンシブ設計の全観点でレビューを実施する。
