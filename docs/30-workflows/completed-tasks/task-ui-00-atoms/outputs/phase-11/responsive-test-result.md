## コード分析根拠

### レスポンシブ設計の方針

全7コンポーネントはレスポンシブブレークポイント（`sm:`, `md:`, `lg:`）を直接使用していない。代わりに以下の方針で実装されている。

1. **固定サイズ指定**: StatusIndicator のドットサイズ、SuggestionBubble の高さ等は `size` props で制御
2. **パーセント幅**: SkeletonCard 内部ラインは `w-[60%]` 等のパーセント幅で親に追従
3. **Flexbox レイアウト**: `inline-flex` / `flex` ベースのレイアウトでコンテンツに応じた自動調整
4. **最小サイズ保証**: FilterChip の `min-h-[36px] min-w-[36px]` でタッチターゲットの下限を設定

この方針により、Atoms コンポーネントはビューポート幅に関係なく一定の表示品質を維持する設計になっている。ただしレイアウト（余白、最大幅）は親コンテナの責務であるため、統合テストでの確認が推奨される。
