## テスト方針

本タスクは `ApiKeysSection` の `loadProviders` 関数に5層防御ガードを追加する変更であり、DOM構造・スタイル・インタラクションパターンに変更はない。そのため以下の方針で検証する:

1. **自動テストでカバー済みのシナリオ**: テスト名と結果を証跡として引用し「間接検証 PASS」とする
2. **実画面スクリーンショット**: TC-11-01〜TC-11-03 の3シナリオは撮影済み（2026-03-07）
3. **手動確認推奨のシナリオ**: ネットワーク断・高速連続操作は自動テストでの完全再現が困難なため「手動確認推奨」とする
