# Naming Audit

## 統一した語彙

| 語彙                | 採用                                         |
| ------------------- | -------------------------------------------- |
| phase topology      | `phases`                                     |
| resource descriptor | `resources`                                  |
| entry-exit hook     | `entry`, `exit`, `entryHookId`, `exitHookId` |
| manifest version    | `schemaVersion`                              |

## 不採用

- `steps`
- `assetsMap`
- `hooks`
- `routePolicy`
