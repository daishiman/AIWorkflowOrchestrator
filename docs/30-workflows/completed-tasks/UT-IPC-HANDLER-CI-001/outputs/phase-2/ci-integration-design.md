## 既存 CI ワークフローとの統合

新規テストファイルは既存の `pnpm --filter @repo/desktop test` コマンドで自動実行される。CI ワークフローへの追加設定は不要。

### 確認項目

| 確認項目                                 | 確認方法                                    | 期待結果     |
| ---------------------------------------- | ------------------------------------------- | ------------ |
| desktop テストが CI に含まれているか     | `.github/workflows/` 内の test ジョブを確認 | 含まれている |
| スナップショット不一致で CI が失敗するか | `--updateSnapshot` なし実行で確認           | 失敗する     |
| PR マージ前にテストが実行されるか        | ワークフロートリガーを確認                  | 実行される   |

## テスト実行コマンド

| 用途                        | コマンド                                               |
| --------------------------- | ------------------------------------------------------ |
| 通常テスト実行（CI と同等） | `pnpm --filter @repo/desktop test`                     |
| スナップショット初回生成    | `pnpm --filter @repo/desktop test -- --updateSnapshot` |
| カバレッジ計測              | `pnpm --filter @repo/desktop test -- --coverage`       |
| ウォッチモード              | `pnpm --filter @repo/desktop test -- --watch`          |
