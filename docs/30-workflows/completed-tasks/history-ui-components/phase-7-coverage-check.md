## 実行手順

### ステップ1: カバレッジ測定

```bash
# ユニットテストカバレッジ
pnpm --filter @repo/desktop test:coverage

# 結合テストカバレッジ
pnpm --filter @repo/desktop test:integration:coverage
```

### ステップ2: レポート分析

- カバレッジHTMLレポートを確認
- 未到達コードパスを特定
- 分岐カバレッジの不足箇所を特定

### ステップ3: 目標達成判定

| 判定  | 条件                             | 対応             |
| ----- | -------------------------------- | ---------------- |
| PASS  | 全指標が最低基準以上             | Phase 8へ進行    |
| MINOR | 一部指標が最低基準未満           | 追加テスト後進行 |
| MAJOR | 主要指標が大幅に基準未満（-10%） | Phase 6へ戻る    |
