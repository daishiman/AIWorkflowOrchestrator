## 実行手順

### ステップ1: カバレッジ測定

```bash
pnpm --filter @repo/desktop test:coverage
```

### ステップ2: ギャップ分析

- 未到達の行/分岐/関数を特定
- 統合テスト不足領域を特定

### ステップ3: 追加テスト作成

**追加すべきテストカテゴリ:**

| カテゴリ         | 追加テスト例                           |
| ---------------- | -------------------------------------- |
| 異常系           | ネットワークエラー、タイムアウト       |
| 境界値           | 最大件数、空配列、null値               |
| 状態遷移         | ローディング→成功、ローディング→エラー |
| ユーザー操作     | 連続クリック、高速操作                 |
| アクセシビリティ | キーボード操作、スクリーンリーダー対応 |

### ステップ4: 統合テスト実行

```bash
pnpm --filter @repo/desktop test:integration
```
