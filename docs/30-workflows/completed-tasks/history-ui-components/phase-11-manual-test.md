# Phase 11: 手動テスト

## メタ情報

## 目的

自動テストでは検証しきれないユーザー体験、視覚的要素、操作感を確認する。

## テスト環境

| 項目         | 内容                   |
| ------------ | ---------------------- |
| OS           | macOS（最新版）        |
| アプリ       | Electron開発ビルド     |
| テストデータ | 履歴10件、ログ50件以上 |

## 手動テストシナリオ

### シナリオ1: 履歴一覧表示

| ステップ | 操作                   | 期待結果                           |
| -------- | ---------------------- | ---------------------------------- |
| 1        | ファイルを選択         | 履歴パネルが表示される             |
| 2        | 履歴一覧を確認         | 時系列順（新しい順）で表示される   |
| 3        | 各アイテムの情報を確認 | バージョン番号、日時、サイズが表示 |
| 4        | 最新バージョンを確認   | 「現在」ラベルが表示される         |
| 結果     | -                      | PASS / FAIL                        |

### シナリオ2: バージョン詳細表示

| ステップ | 操作                   | 期待結果                         |
| -------- | ---------------------- | -------------------------------- |
| 1        | 履歴アイテムをクリック | 詳細パネルが表示される           |
| 2        | 詳細情報を確認         | 変換設定、入出力パスが表示される |
| 3        | 閉じるボタンをクリック | 詳細パネルが閉じる               |
| 結果     | -                      | PASS / FAIL                      |

### シナリオ3: バージョン復元

| ステップ | 操作                               | 期待結果                         |
| -------- | ---------------------------------- | -------------------------------- |
| 1        | 過去バージョンの復元ボタンクリック | 確認ダイアログが表示される       |
| 2        | 復元対象の情報を確認               | バージョン番号、日時が表示される |
| 3        | 「復元する」をクリック             | 復元処理が実行される             |
| 4        | 復元完了後の状態を確認             | 履歴一覧が更新される             |
| 結果     | -                                  | PASS / FAIL                      |

### シナリオ4: 変換ログ表示

| ステップ | 操作                       | 期待結果                   |
| -------- | -------------------------- | -------------------------- |
| 1        | ログタブをクリック         | ログ一覧が表示される       |
| 2        | フィルタで「Error」を選択  | エラーログのみ表示される   |
| 3        | フィルタで「すべて」を選択 | 全レベルのログが表示される |
| 4        | ログの詳細を展開           | JSON形式で詳細が表示される |
| 結果     | -                          | PASS / FAIL                |

### シナリオ5: ページネーション

| ステップ | 操作                               | 期待結果               |
| -------- | ---------------------------------- | ---------------------- |
| 1        | 20件以上の履歴があるファイルを選択 | 最初の20件が表示される |
| 2        | 「さらに読み込む」をクリック       | 追加の20件が表示される |
| 3        | 全件読み込み後を確認               | ボタンが非表示になる   |
| 結果     | -                                  | PASS / FAIL            |

### シナリオ6: アクセシビリティ

| ステップ | 操作                         | 期待結果                     |
| -------- | ---------------------------- | ---------------------------- |
| 1        | Tabキーでナビゲーション      | フォーカスが論理的順序で移動 |
| 2        | Enter/Spaceでアイテム選択    | アイテムが選択される         |
| 3        | Escapeでダイアログ閉じる     | ダイアログが閉じる           |
| 4        | フォーカスインジケータを確認 | フォーカス位置が明確に表示   |
| 結果     | -                            | PASS / FAIL                  |

### シナリオ7: エラーハンドリング

| ステップ | 操作                       | 期待結果                     |
| -------- | -------------------------- | ---------------------------- |
| 1        | ネットワーク切断状態で操作 | エラーメッセージが表示される |
| 2        | 存在しないファイルIDを指定 | 適切なエラーメッセージが表示 |
| 3        | 復元中にキャンセル         | 処理が中断される             |
| 結果     | -                          | PASS / FAIL                  |
