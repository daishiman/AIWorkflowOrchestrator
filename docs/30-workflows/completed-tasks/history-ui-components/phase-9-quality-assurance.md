## 実行手順

### ステップ1: 静的解析

```bash
# ESLint実行
pnpm --filter @repo/desktop lint

# TypeScript型チェック
pnpm --filter @repo/desktop typecheck

# Prettierチェック
pnpm --filter @repo/desktop format:check
```

### ステップ2: アクセシビリティ監査

`accessibility-wcag`スキルを使用し、以下を確認：

- キーボードのみで全操作が可能か
- フォーカス順序が論理的か
- ARIA属性が適切に設定されているか
- 色だけに頼らない情報伝達ができているか

### ステップ3: パフォーマンス測定

`performance-testing`スキルを使用し、以下を測定：

- React DevToolsでのレンダリング時間
- 大量データ（100件）でのスクロール性能
- メモリ使用量の推移
