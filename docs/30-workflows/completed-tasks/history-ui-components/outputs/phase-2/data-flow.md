## エラーハンドリングフロー

### エラー種別と対応

| エラー種別      | 発生場所   | UI表示                       | 回復方法           |
| --------------- | ---------- | ---------------------------- | ------------------ |
| NetworkError    | IPC通信    | 「通信エラーが発生しました」 | refresh() で再取得 |
| NotFoundError   | Repository | 「データが見つかりません」   | 戻る               |
| ValidationError | Service    | 「入力データが不正です」     | 修正して再試行     |
| DatabaseError   | SQLite     | 「データベースエラー」       | アプリ再起動       |
| UnknownError    | 不明       | 「予期しないエラー」         | アプリ再起動       |

### エラー伝播フロー

```
SQLite Error
    │
    ▼
Repository → Result.failure(error)
    │
    ▼
Service → Result.failure(error)
    │
    ▼
IPC Handler → { success: false, error }
    │
    ▼
Preload API → Result.failure(error)
    │
    ▼
Custom Hook → setError(error), setIsLoading(false)
    │
    ▼
Component → <ErrorMessage message={error.message} />
```
