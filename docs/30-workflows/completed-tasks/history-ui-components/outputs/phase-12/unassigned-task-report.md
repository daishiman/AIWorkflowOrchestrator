### task-req-history-integration-001

#### メタ情報

| 項目         | 値                               |
| ------------ | -------------------------------- |
| タスクID     | task-req-history-integration-001 |
| 分類         | 要件                             |
| 優先度       | High                             |
| 見積もり規模 | M（中規模）                      |
| 発見元       | Phase 11                         |

#### Why（なぜ必要か）

##### 背景

CONV-05-03で開発した履歴/ログ表示UIコンポーネントは、単体テストで動作が検証されているが、実際のElectronアプリケーションにはまだ統合されていない。

##### 問題点

- コンポーネントが実環境でテストされていない
- ユーザーが機能を利用できない状態

##### 放置した場合の影響

- 開発した機能がユーザーに提供されない
- 実環境での問題が発見できない

#### What（何を達成するか）

##### 目的

履歴/ログ表示UIコンポーネントをElectronアプリケーションに統合し、ユーザーが利用可能な状態にする。

##### 最終ゴール

- 履歴一覧画面が表示される
- バージョン詳細が確認できる
- ログが表示・フィルタできる
- バージョン復元が実行できる

##### スコープ

###### 含む

- HistoryPage.tsxの作成
- ルーティング設定
- preloadスクリプトの設定
- IPCハンドラーの登録

###### 含まない

- 新機能の追加
- パフォーマンス最適化

##### 成果物

| 成果物             | 説明                         |
| ------------------ | ---------------------------- |
| HistoryPage.tsx    | 履歴表示ページコンポーネント |
| preload.ts更新     | historyAPIの公開             |
| historyHandlers.ts | IPCハンドラー                |

#### How（どのように実行するか）

##### 前提条件

- CONV-05-01（履歴データ永続化）が完了していること
- CONV-05-02（履歴取得サービス）が完了していること
- CONV-05-03（履歴UIコンポーネント）が完了していること

##### 推奨スキル

```
integration-guide.md（outputs/phase-12/）を参照
```

##### 実行手順

1. integration-guide.mdの手順に従ってファイルを配置
2. preloadスクリプトにhistoryAPIを追加
3. メインプロセスにIPCハンドラーを登録
4. HistoryPage.tsxを作成
5. ルーティングを設定
6. 動作確認

##### 完了条件

- [ ] コンポーネントファイルが適切な場所に配置されている

### task-req-history-preload-001

#### メタ情報

| 項目         | 値                           |
| ------------ | ---------------------------- |
| タスクID     | task-req-history-preload-001 |
| 分類         | 要件                         |
| 優先度       | High                         |
| 見積もり規模 | S（小規模）                  |
| 発見元       | Phase 11                     |

#### Why（なぜ必要か）

##### 背景

ElectronアプリケーションではセキュリティのためcontextIsolationが有効になっており、レンダラープロセスからメインプロセスのAPIに直接アクセスできない。

##### 問題点

preloadスクリプトでhistoryAPIを公開しないと、UIコンポーネントからIPC通信ができない。

##### 放置した場合の影響

履歴機能が動作しない。

#### What（何を達成するか）

##### 目的

preloadスクリプトでhistoryAPIをwindowオブジェクトに公開する。

##### 最終ゴール

window.historyAPIが利用可能になる。

##### スコープ

###### 含む

- contextBridge.exposeInMainWorldの設定
- 4つのAPIメソッドの公開

###### 含まない

- 新しいAPIの追加

##### 成果物

| 成果物         | 説明           |
| -------------- | -------------- |
| preload.ts更新 | historyAPI公開 |

#### How（どのように実行するか）

##### 前提条件

- task-req-history-integration-001と同時に実施

##### 推奨スキル

```
electron-ui-patterns
```

##### 実行手順

1. preload.tsを開く
2. historyAPIオブジェクトを定義
3. contextBridge.exposeInMainWorldで公開
4. 型定義を追加

##### 完了条件

- [ ] window.historyAPIがundefinedでない
- [ ] getFileHistoryが呼び出せる
- [ ] getVersionDetailが呼び出せる
- [ ] getConversionLogsが呼び出せる
- [ ] restoreVersionが呼び出せる

##### 検証方法

DevToolsコンソールで`window.historyAPI`を確認

##### リスクと対策

| リスク            | 対策                     |
| ----------------- | ------------------------ |
| APIが公開されない | webPreferences設定を確認 |
