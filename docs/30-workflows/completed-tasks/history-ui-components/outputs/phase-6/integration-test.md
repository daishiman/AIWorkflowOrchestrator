## 統合テストシナリオ

### シナリオ1: 履歴表示から復元までの完全フロー

```
Given: ファイルID "file-123" の履歴が存在する
When: VersionHistory コンポーネントを表示
Then: 履歴一覧が表示される

When: 履歴アイテム（v2）をクリック
Then: VersionDetail パネルが表示される
And: バージョン2の詳細情報が表示される

When: 「このバージョンに復元」ボタンをクリック
Then: RestoreDialog が表示される
And: 確認メッセージが表示される

When: 「復元」ボタンをクリック
Then: 復元処理が実行される
And: 成功時にダイアログが閉じる
And: 履歴一覧がリフレッシュされる
```

### シナリオ2: ログフィルタリングフロー

```
Given: 変換ID "conv-001" のログが存在する
And: info, warn, error レベルのログが混在している
When: ConversionLogs コンポーネントを表示
Then: すべてのログが表示される

When: フィルタで "error" を選択
Then: error レベルのログのみ表示される
And: info, warn レベルのログは非表示

When: フィルタで "すべて" を選択
Then: すべてのログが再表示される
```

### シナリオ3: ページネーションフロー

```
Given: 50件の履歴データが存在する
When: VersionHistory コンポーネントを表示
Then: 最初の20件が表示される
And: 「さらに読み込む」ボタンが表示される

When: 「さらに読み込む」ボタンをクリック
Then: 追加の20件が読み込まれる
And: 合計40件が表示される

When: 再度「さらに読み込む」ボタンをクリック
Then: 残りの10件が読み込まれる
And: 「さらに読み込む」ボタンが非表示になる
```

### シナリオ4: エラーハンドリングフロー

```
Given: API がエラーを返す状態
When: VersionHistory コンポーネントを表示
Then: エラーメッセージが表示される
And: 「再試行」ボタンが表示される

When: 「再試行」ボタンをクリック
And: API が正常に応答する
Then: 履歴一覧が表示される
```

### シナリオ5: キーボードナビゲーションフロー

```
Given: 履歴一覧が表示されている
When: Tab キーでフォーカスを移動
Then: 履歴アイテムにフォーカスが移動する

When: Enter キーを押す
Then: アイテムが選択される
And: 詳細パネルが表示される

When: Tab キーで復元ボタンにフォーカス
And: Enter キーを押す
Then: RestoreDialog が表示される

When: Escape キーを押す
Then: ダイアログが閉じる
And: フォーカスが復元ボタンに戻る
```
