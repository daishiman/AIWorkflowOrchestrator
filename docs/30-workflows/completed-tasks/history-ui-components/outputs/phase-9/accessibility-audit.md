## ARIA属性監査

### 使用されているARIA属性

| 属性                | コンポーネント  | 用途                       |
| ------------------- | --------------- | -------------------------- |
| role="list"         | VersionHistory  | リスト構造を明示           |
| role="listitem"     | VersionHistory  | リストアイテムを明示       |
| role="status"       | LoadingSkeleton | ローディング状態を通知     |
| role="alert"        | ErrorDisplay    | エラー状態を通知           |
| role="dialog"       | RestoreDialog   | ダイアログを明示           |
| role="presentation" | RestoreDialog   | 装飾要素を明示             |
| aria-modal          | RestoreDialog   | モーダルダイアログを明示   |
| aria-labelledby     | RestoreDialog   | ダイアログタイトル参照     |
| aria-describedby    | RestoreDialog   | ダイアログ説明参照         |
| aria-label          | buttons         | ボタンの目的を説明         |
| aria-expanded       | LogEntry        | 展開状態を通知             |
| aria-hidden         | skeleton        | スクリーンリーダーから隠す |

### ARIA使用の妥当性

| 項目                 | 評価    | コメント                |
| -------------------- | ------- | ----------------------- |
| 必要な場所にのみ使用 | ✅ 適切 | ネイティブ要素を優先    |
| 冗長なARIAなし       | ✅ 適切 | button等にrole設定なし  |
| 親子関係の整合性     | ✅ 適切 | list/listitem正しく使用 |
