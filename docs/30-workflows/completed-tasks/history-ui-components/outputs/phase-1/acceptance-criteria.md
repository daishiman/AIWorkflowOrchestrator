## 境界値テスト

### 履歴件数の境界値

| ケース          | 入力 | 期待結果                           |
| --------------- | ---- | ---------------------------------- |
| 0件             | 0    | 「履歴がありません」メッセージ表示 |
| 1件             | 1    | 1件表示、「さらに読み込む」非表示  |
| 20件（1ページ） | 20   | 20件表示、「さらに読み込む」表示   |
| 21件            | 21   | 20件表示、「さらに読み込む」表示   |

### ログメッセージの境界値

| ケース       | 入力           | 期待結果                   |
| ------------ | -------------- | -------------------------- |
| 空メッセージ | ""             | 空文字列として表示         |
| 長文         | 1000文字       | 折り返しまたはトランケート |
| detailsなし  | details = null | 「詳細を表示」非表示       |
