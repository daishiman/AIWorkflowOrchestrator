## 概要

ファイルのバージョン履歴一覧、詳細表示、復元操作、ログ表示のUIコンポーネントを実装する。

---

## 機能要件（Functional Requirements）

### FR-01: 履歴一覧表示

| 項目     | 内容                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 要件ID   | FR-01                                                                      |
| 要件名   | ファイル履歴一覧表示                                                       |
| 説明     | ファイルIDを指定して、そのファイルの変換履歴一覧を表示する                 |
| 優先度   | Must                                                                       |
| 入力     | fileId: string                                                             |
| 出力     | VersionHistoryItem[] - 時系列順（新しい順）で表示                          |
| 表示項目 | バージョン番号、作成日時、サイズ、現在バージョンラベル、復元ボタン（条件） |

### FR-02: バージョン詳細表示

| 項目     | 内容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 要件ID   | FR-02                                                                  |
| 要件名   | バージョン詳細表示                                                     |
| 説明     | 履歴アイテムをクリックして、そのバージョンの詳細情報を表示             |
| 優先度   | Must                                                                   |
| 入力     | conversionId: string                                                   |
| 出力     | VersionHistoryItem - 詳細情報                                          |
| 表示項目 | バージョンID、作成日時、MIME形式、サイズ、ハッシュ、メタデータ（JSON） |

### FR-03: バージョン復元

| 項目   | 内容                                               |
| ------ | -------------------------------------------------- |
| 要件ID | FR-03                                              |
| 要件名 | 過去バージョンへの復元                             |
| 説明   | 過去のバージョンから現在のファイルを復元する       |
| 優先度 | Must                                               |
| 入力   | fileId: string, conversionId: string               |
| 出力   | Result<VersionHistoryItem, Error> - 復元結果       |
| 制約   | 最新バージョンからの復元は不要（復元ボタン非表示） |

### FR-04: 復元確認ダイアログ

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| 要件ID     | FR-04                                        |
| 要件名     | 復元前の確認ダイアログ表示                   |
| 説明       | 復元操作前にユーザーに確認を求める           |
| 優先度     | Must                                         |
| 入力       | version: VersionHistoryItem, isOpen: boolean |
| 表示項目   | 復元対象バージョン情報、警告メッセージ       |
| アクション | 復元実行、キャンセル                         |

### FR-05: 変換ログ表示・フィルタリング

| 項目     | 内容                                               |
| -------- | -------------------------------------------------- |
| 要件ID   | FR-05                                              |
| 要件名   | 変換ログ一覧表示とフィルタリング                   |
| 説明     | 変換ログをレベル（info/warn/error）でフィルタ可能  |
| 優先度   | Must                                               |
| 入力     | fileId?: string, levelFilter?: LogLevel[]          |
| 出力     | ConversionLog[] - 時系列順（新しい順）             |
| 表示項目 | レベルバッジ、メッセージ、タイムスタンプ、詳細展開 |
| フィルタ | すべて / Info / Warning / Error                    |

### FR-06: ページネーション

| 項目     | 内容                                           |
| -------- | ---------------------------------------------- |
| 要件ID   | FR-06                                          |
| 要件名   | 履歴・ログのページネーション                   |
| 説明     | 20件ずつ「さらに読み込む」ボタンで追加読み込み |
| 優先度   | Must                                           |
| 入力     | limit: number (default: 20), offset: number    |
| 動作     | 既存アイテムを保持したまま追加データを表示     |
| 終了条件 | hasMore = false のときボタン非表示             |

## 非機能要件（Non-Functional Requirements）

### NFR-01: アクセシビリティ（WCAG 2.1 AA準拠）

| 項目           | 内容                                          |
| -------------- | --------------------------------------------- |
| 要件ID         | NFR-01                                        |
| 要件名         | キーボード操作対応                            |
| 説明           | キーボード操作で全機能にアクセス可能          |
| 実装項目       | tabIndex, onKeyDown（Enter/Space/Escape）     |
| フォーカス管理 | モーダルのフォーカストラップ                  |
| ARIA属性       | role, aria-label, aria-describedby            |
| 視覚表現       | 色だけに頼らない情報伝達（アイコン+テキスト） |

### NFR-02: ローディング状態表示

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| 要件ID   | NFR-02                                   |
| 要件名   | ローディング状態の適切な表示             |
| 説明     | データ取得中はローディングスピナーを表示 |
| 表示条件 | isLoading = true かつ データが空         |
| 解除条件 | データ取得完了またはエラー発生           |

### NFR-03: エラー状態表示

| 項目           | 内容                                                 |
| -------------- | ---------------------------------------------------- |
| 要件ID         | NFR-03                                               |
| 要件名         | エラー状態の適切な表示                               |
| 説明           | エラー発生時にユーザーフレンドリーなメッセージを表示 |
| 表示項目       | エラーメッセージ、再試行ボタン（該当時）             |
| メッセージ原則 | 技術的詳細を避け、平易な言葉を使用                   |

### NFR-04: パフォーマンス

| 項目     | 内容                                |
| -------- | ----------------------------------- |
| 要件ID   | NFR-04                              |
| 要件名   | 履歴一覧取得の応答時間              |
| 説明     | 履歴一覧取得は200ms以内にレスポンス |
| 測定条件 | 通常負荷時、20件取得                |
| 最適化   | IPCオーバーヘッドを最小化           |

## 接続要件（統合テスト連携）

### API接続

| 接続先          | メソッド                               | 説明               |
| --------------- | -------------------------------------- | ------------------ |
| IHistoryService | getFileHistory(fileId, options)        | 履歴一覧取得       |
| IHistoryService | getVersionDetail(conversionId)         | バージョン詳細取得 |
| IHistoryService | restoreToVersion(fileId, conversionId) | バージョン復元     |

### 認証フロー

認証不要（ローカルデータへのアクセス）

### データフロー

```
Renderer Process
    ↓ IPC Call (window.historyAPI)
Main Process
    ↓ IPC Handler
HistoryService
    ↓ Repository Call
SQLite Database
    ↓ Query Result
Result<T, Error>
```
