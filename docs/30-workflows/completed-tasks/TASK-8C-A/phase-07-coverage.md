## 目的

Phase 6 で拡充したテストのカバレッジが目標値を達成しているかを検証する。目標未達の場合は Phase 6 に差し戻し、追加テストを実装する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ測定

**目的**: `skillHandlers.ts` のカバレッジを正式に測定する

**実行手順**:

1. カバレッジ付きでテストを実行する：

   ```bash
   pnpm --filter @repo/desktop vitest run --coverage apps/desktop/src/main/ipc/__tests__/skillIpc.integration.test.ts
   ```

2. 以下のカバレッジ指標を記録する：

| 指標               | 目標 | 実測値    | 判定      |
| ------------------ | ---- | --------- | --------- |
| 行カバレッジ       | 90%+ | \_\_\_\_% | PASS/FAIL |
| ブランチカバレッジ | 60%+ | \_\_\_\_% | PASS/FAIL |
| 関数カバレッジ     | 80%+ | \_\_\_\_% | PASS/FAIL |

3. `outputs/phase-07/coverage-report.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-07/coverage-report.md`

---

### タスク2: ゲート判定

**目的**: カバレッジ目標の達成状況に基づきゲート判定を行う

**実行手順**:

1. 全指標が目標を達成している場合: **PASS** → Phase 8 に進む
2. いずれかの指標が目標未達の場合: **FAIL** → Phase 6 に差し戻し
   - 未カバー箇所を特定し、Phase 6 で追加テストを実装する
3. 判定結果を `outputs/phase-07/coverage-report.md` に追記する

**期待される成果物**:

- ゲート判定結果（`outputs/phase-07/coverage-report.md` に含む）

---

### タスク3: 統合カバレッジ確認

**目的**: IPC テスト全体（既存 + 新規）の統合カバレッジを確認する

**実行手順**:

1. IPC テストディレクトリ全体でカバレッジを測定する：

   ```bash
   pnpm --filter @repo/desktop vitest run --coverage apps/desktop/src/main/ipc/__tests__/
   ```

2. `skillHandlers.ts` の統合カバレッジが個別テストの合計で目標を達成しているか確認する
3. 結果を `outputs/phase-07/coverage-report.md` に追記する

**期待される成果物**:

- 統合カバレッジ結果（`outputs/phase-07/coverage-report.md` に含む）

## 統合テスト連携

- 統合カバレッジ（全テストファイル合計）が個別カバレッジと矛盾しないことを確認する
- 既存テストと新規テストのカバレッジが重複していないことを確認する

---

## 多角的チェック観点

| 観点       | 確認内容                                             |
| ---------- | ---------------------------------------------------- |
| カバレッジ | 全指標が目標値を達成しているか                       |
| 網羅性     | 未カバー箇所が特定・記録されているか                 |
| 品質       | カバレッジ目標達成のためだけの無意味なテストがないか |
