## 目的

TASK-8C-A の全成果物をまとめて Pull Request を作成する。PR作成前にローカル検証を実施し、ユーザーの明示的な許可を得てから PR を作成する。

**⚠️ 重要: PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル検証

**目的**: PR作成前に全品質ゲートをローカルでパスすることを確認する

**実行手順**:

1. 以下の検証を実行する：

| #   | 検証項目   | コマンド                                                                 | 結果   |
| --- | ---------- | ------------------------------------------------------------------------ | ------ |
| 1   | ビルド     | `pnpm --filter @repo/desktop build`                                      | \_\_\_ |
| 2   | テスト     | `pnpm --filter @repo/desktop vitest run`                                 | \_\_\_ |
| 3   | 型チェック | `pnpm --filter @repo/desktop tsc --noEmit`                               | \_\_\_ |
| 4   | Lint       | `pnpm --filter @repo/desktop lint`                                       | \_\_\_ |
| 5   | 対象テスト | `pnpm --filter @repo/desktop vitest run ...skillIpc.integration.test.ts` | \_\_\_ |

2. 全項目がパスしていることを確認する
3. 失敗がある場合は該当Phaseに戻って修正する

**期待される成果物**:

- ローカル検証結果（Phase 13 の実行記録として）

---

### タスク2: 変更内容の確認

**目的**: PRに含まれる変更内容を確認する

**実行手順**:

1. `git diff` で変更ファイル一覧を確認する
2. 以下のカテゴリで変更を整理する：

| カテゴリ               | ファイル                                                           |
| ---------------------- | ------------------------------------------------------------------ |
| テストコード           | `apps/desktop/src/main/ipc/__tests__/skillIpc.integration.test.ts` |
| 実装コード（必要時）   | `apps/desktop/src/main/ipc/skillHandlers.ts`                       |
| チャネル定義（必要時） | `apps/desktop/src/preload/channels.ts`                             |
| ドキュメント           | `docs/30-workflows/skill-import-agent-system/tasks/TASK-8C-A/**`   |
| 仕様書更新             | `.claude/skills/aiworkflow-requirements/references/**`             |

3. 不要なファイルが含まれていないことを確認する

**期待される成果物**:

- 変更ファイル一覧（PR本文に含む）

---

### タスク3: ユーザー許可の取得とPR作成

**目的**: ユーザーの明示的な許可を得てPRを作成する

**実行手順**:

1. ユーザーに以下を提示する：
   - 変更ファイル一覧
   - テスト結果サマリー（22テスト全PASS、カバレッジ数値）
   - PR タイトル案: `feat(test): TASK-8C-A IPC統合テスト実装（22テストケース）`

2. ユーザーの許可を得た後、`/ai:diff-to-pr` を実行する

3. PR作成後、CI チェックの結果を確認する

**期待される成果物**:

- `outputs/phase-13/pr-info.md`（PR URL、CI結果）

---

### タスク4: タスクディレクトリの移動

**目的**: 完了タスクを completed-tasks ディレクトリに移動する

**実行手順**:

1. PR がマージされた後（ユーザー確認後）、タスクディレクトリを移動する：

   ```bash
   mv docs/30-workflows/skill-import-agent-system/tasks/TASK-8C-A docs/30-workflows/completed-tasks/TASK-8C-A
   ```

2. 元タスク仕様書のステータスを更新する：
   - `docs/30-workflows/skill-import-agent-system/tasks/task-8c-a-ipc-integration.md` の `status` を `completed` に更新

**期待される成果物**:

- 移動済みタスクディレクトリ
