### R-001: DB初期化タイミング問題

| 項目         | 内容                                                 |
| ------------ | ---------------------------------------------------- |
| リスクID     | R-001                                                |
| リスク名     | DB初期化タイミング問題                               |
| 説明         | DBインスタンス取得前にProvider初期化が呼ばれる可能性 |
| 影響度       | 高                                                   |
| 発生確率     | 低                                                   |
| リスクレベル | 中                                                   |

**対策（設計に含まれているか）**:

- [x] ファクトリーでnullチェックを実施
- [x] 未初期化時は明確なエラーメッセージをスロー
- [x] App.tsx側でDB初期化後にProvider統合

**追加対策（実装時に考慮）**:

- DBの初期化完了を待つ仕組み（Suspense等）の検討

| ------------ | ------------------------------------------------ |
| リスクID     | R-003                                            |
| リスク名     | パフォーマンス低下                               |
| 説明         | Provider追加による初期化遅延・再レンダリング増加 |
| 影響度       | 中                                               |
| 発生確率     | 低                                               |
| リスクレベル | 低                                               |

**対策（設計に含まれているか）**:

- [x] useMemoによるContext値のメモ化（既存実装）
