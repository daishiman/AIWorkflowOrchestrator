## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認チェックリスト

**目的**: PR作成前にローカル環境で最終確認を行う

**実行手順**:

1. 以下の項目を確認する:

| #   | 確認項目             | コマンド                                    | 結果 |
| --- | -------------------- | ------------------------------------------- | ---- |
| 1   | ビルドが成功する     | `pnpm --filter @repo/desktop build`         |      |
| 2   | 全テストがパスする   | `pnpm --filter @repo/desktop test -- --run` |      |
| 3   | 型チェックがパスする | `pnpm --filter @repo/desktop typecheck`     |      |
| 4   | Lintエラーがない     | `pnpm --filter @repo/desktop lint`          |      |
| 5   | 実際の動作確認       | `pnpm --filter @repo/desktop dev`           |      |

2. 全項目がパスしていることを確認する
3. 結果を記録する

**期待される成果物**:

- ローカル確認結果の記録

---

### タスク2: ユーザー確認・許可取得

**目的**: PR作成前にユーザーの明示的な許可を得る

**実行手順**:

1. 変更内容のサマリーをユーザーに提示する:
   - 変更ファイル一覧
   - 実装内容の概要
   - テスト結果
2. PR作成の許可をユーザーに確認する
3. ユーザーから明示的な許可を得る

**重要**: PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。

**期待される成果物**:

- ユーザーからの許可

---

### タスク3: PR作成（/ai:diff-to-pr実行）

**目的**: `/ai:diff-to-pr` スキルを実行してPRを作成する

**実行手順**:

1. ユーザーの許可を得た後、`/ai:diff-to-pr` スキルを実行する
2. スキルが以下を自動実行する:
   - リモートmain同期・コンフリクト解消
   - 品質検証（typecheck, lint, test）
   - 差分分析・ブランチ作成・コミット
   - タスク仕様書 → Issue同期（未同期チェック）
   - PR本文生成・PR作成
   - 補足コメント投稿
   - CI/CD完了確認
   - マージ可能報告
3. PR URLを記録する

**期待される成果物**:

- PR URL

---

### タスク4: CI確認

**目的**: CI/CDパイプラインが成功することを確認する

**実行手順**:

1. GitHub ActionsのCI結果を確認する
2. 全てのチェックがパスしていることを確認する
3. 失敗がある場合は原因を調査し修正する

**期待される成果物**:

- CI確認結果の記録

## 重要な注意事項

### PR作成に関する重要な注意

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

### マージについて

⚠️ マージはユーザーがGitHub UIで手動実行
