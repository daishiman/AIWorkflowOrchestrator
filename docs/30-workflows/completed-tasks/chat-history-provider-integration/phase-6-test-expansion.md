## 目的

Phase 5の実装に対して、カバレッジ目標達成に向けた追加テストを作成する。異常系、境界条件、エッジケースのテストを拡充する。

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ現状確認

**目的**: 現在のテストカバレッジを確認する

**実行手順**:

1. カバレッジレポートを生成する:
   ```bash
   pnpm --filter @repo/desktop test -- --run --coverage
   ```
2. chat-history関連ファイルのカバレッジを確認する
3. カバレッジ不足箇所を特定する
4. 現状レポートを `outputs/phase-6/coverage-baseline.md` に出力する

**期待される成果物**:

- `outputs/phase-6/coverage-baseline.md`

---

### タスク2: 異常系テスト拡充

**目的**: エラー発生時の挙動をテストする

**実行手順**:

1. 以下の異常系テストを追加する:
   - Repository初期化失敗時の挙動
   - DB接続エラー時の挙動
   - Use Case実行失敗時の挙動
2. テストを実装し、実行する
3. テスト追加結果を記録する

**期待される成果物**:

- 異常系テストの追加

---

### タスク3: 境界条件テスト拡充

**目的**: 境界条件での動作をテストする

**実行手順**:

1. 以下の境界条件テストを追加する:
   - 空のセッションリスト時の動作
   - 大量のセッション（パフォーマンス境界）
   - 同時アクセス時の動作
2. テストを実装し、実行する
3. テスト追加結果を記録する

**期待される成果物**:

- 境界条件テストの追加

---

### タスク4: エッジケーステスト拡充

**目的**: 予期しない状況での動作をテストする

**実行手順**:

1. 以下のエッジケーステストを追加する:
   - Provider再マウント時の動作
   - Context値の変更検知
   - 複数Provider入れ子時の動作（想定外パターン）
2. テストを実装し、実行する
3. テスト追加結果を記録する

**期待される成果物**:

- エッジケーステストの追加

---

### タスク5: テスト拡充サマリー

**目的**: Phase 6の成果物をサマリーとしてまとめる

**実行手順**:

1. 追加したテストの一覧を作成する
2. カバレッジ改善状況を記録する
3. サマリーを `outputs/phase-6/test-expansion-summary.md` に出力する

**期待される成果物**:

- `outputs/phase-6/test-expansion-summary.md`
