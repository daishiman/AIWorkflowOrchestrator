## 目的

テストカバレッジがプロジェクト基準を満たしているか検証し、必要に応じて追加テストを行う。

## 背景

Phase 6でテスト拡充を行った結果、カバレッジ目標（Line 80%、Branch 60%、Function 80%）を達成しているか確認する。未達の場合はPhase 6へ戻りテストを追加する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジレポート生成

**目的**: 最新のカバレッジレポートを生成する

**実行手順**:

1. カバレッジレポートを生成する:
   ```bash
   pnpm --filter @repo/desktop test -- --run --coverage
   ```
2. chat-history関連ファイルのカバレッジを確認する
3. カバレッジレポートを `outputs/phase-7/coverage-report.md` に出力する

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: ユニットテストカバレッジ検証

**目的**: ユニットテストカバレッジが目標を満たしているか検証する

**実行手順**:

1. 以下の基準で検証する:
   - Line Coverage: 80%以上（推奨: 90%）
   - Branch Coverage: 60%以上（推奨: 70%）
   - Function Coverage: 80%以上（推奨: 90%）
2. 各ファイルのカバレッジを個別に確認する
3. 検証結果を記録する

**期待される成果物**:

- カバレッジ検証結果の記録

---

### タスク3: 統合テストカバレッジ検証

**目的**: 統合テストカバレッジが目標を満たしているか検証する

**実行手順**:

1. 以下の基準で検証する:
   - Provider統合: 100%
   - Repository注入: 100%
   - 正常系シナリオ: 100%
   - 異常系シナリオ: 80%以上
   - Context伝播: 100%
2. 統合テストシナリオの網羅性を確認する
3. 検証結果を記録する

**期待される成果物**:

- 統合テスト検証結果の記録

---

### タスク4: ゲート判定

**目的**: カバレッジ目標達成を判定する

**実行手順**:

1. タスク2, 3の結果に基づき判定する:
   - **PASS**: 全カバレッジ目標を達成 → Phase 8へ進行
   - **未達**: いずれかの目標未達 → Phase 6へ戻りテスト追加
2. 判定結果を `outputs/phase-7/gate-decision.md` に出力する

**期待される成果物**:

- `outputs/phase-7/gate-decision.md`

---

### タスク5: カバレッジ確認サマリー

**目的**: Phase 7の成果物をサマリーとしてまとめる

**実行手順**:

1. カバレッジ検証結果をまとめる
2. ゲート判定結果を記録する
3. サマリーを `outputs/phase-7/coverage-summary.md` に出力する

**期待される成果物**:

- `outputs/phase-7/coverage-summary.md`
