## 目的

カバレッジ目標達成に向けて、エッジケース・異常系・境界値のテストを追加し、テストの網羅性を高める。

## 背景

Phase 4で作成した基本テストに加え、より堅牢な品質を確保するための追加テストを実装する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: エッジケーステスト追加

**目的**: 境界値・特殊ケースのテストを追加する

**実行手順**:

1. Repository境界値テストを追加する
   - テンプレート名の最大長（255文字）
   - コンテンツの最大長（4000文字）
   - 空文字列の扱い
   - 特殊文字（絵文字・マルチバイト文字）の扱い
2. Sliceエッジケーステストを追加する
   - 同時複数操作時の挙動
   - 急速な連続操作時の挙動
3. マイグレーションエッジケーステストを追加する
   - 大量データ（1000件）のマイグレーション
   - 部分的に破損したデータの扱い
4. テストを実行する
   ```bash
   pnpm --filter @repo/shared test
   pnpm --filter @repo/desktop test
   ```

**期待される成果物**:

- エッジケーステストの追加

---

### タスク2: 異常系テスト追加

**目的**: エラーハンドリングのテストを強化する

**実行手順**:

1. Repository異常系テストを追加する
   - DB接続エラー時の挙動
   - 制約違反時のエラーメッセージ
   - 存在しないIDでの更新・削除
   - 認可エラー時の挙動
2. IPC異常系テストを追加する
   - 無効なリクエスト形式
   - タイムアウト時の挙動
   - 認証切れ時の挙動
3. マイグレーション異常系テストを追加する
   - electron-storeファイル破損時
   - DBへの書き込み失敗時
   - ロールバック失敗時
4. テストを実行する

**期待される成果物**:

- 異常系テストの追加

---

### タスク3: オフライン動作テスト追加

**目的**: Embedded Replicasによるオフライン動作をテストする

**実行手順**:

1. オフラインCRUDテストを追加する
   - オフライン時のテンプレート作成
   - オフライン時のテンプレート取得
   - オフライン時のテンプレート更新
   - オフライン時のテンプレート削除
2. 同期テストを追加する
   - オフライン→オンライン復帰時の同期
   - コンフリクト発生時の挙動
3. テストを実行する

**期待される成果物**:

- オフライン動作テストの追加

---

### タスク4: マルチユーザーテスト追加

**目的**: ユーザー間のデータ分離をテストする

**実行手順**:

1. ユーザー分離テストを追加する
   - ユーザーAのテンプレートがユーザーBに見えない
   - ユーザー切り替え時のデータリフレッシュ
2. プリセットテンプレートテストを追加する
   - プリセットは全ユーザーで共有される
   - プリセットの削除・編集は不可
3. テストを実行する

**期待される成果物**:

- マルチユーザーテストの追加

---

### タスク5: カバレッジ計測・レポート

**目的**: 現在のテストカバレッジを計測する

**実行手順**:

1. カバレッジを計測する
   ```bash
   pnpm --filter @repo/shared test:coverage
   pnpm --filter @repo/desktop test:coverage
   ```
2. カバレッジレポートを確認する
   - Line Coverage
   - Branch Coverage
   - Function Coverage
3. カバレッジ不足箇所を特定する
4. 追加テストが必要な箇所をリストアップする
5. 成果物を `outputs/phase-6/coverage-report.md` に出力する

**期待される成果物**:

- `outputs/phase-6/coverage-report.md`
