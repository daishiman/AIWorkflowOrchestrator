## 目的

自動テストではカバーできないUI/UX・実機動作・シナリオテストを手動で実施し、ユーザー視点での品質を確認する。

## 背景

自動テストは単体・結合レベルの品質を保証するが、実際のユーザー体験はE2Eの手動テストで確認する必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: CRUD操作の手動検証

**目的**: テンプレートのCRUD操作がUIから正常に動作することを確認する

**実行手順**:

1. アプリケーションを起動する
   ```bash
   pnpm --filter @repo/desktop dev
   ```
2. テンプレート作成の検証
   - 設定画面からシステムプロンプトテンプレート管理を開く
   - 新規テンプレートを作成する
   - テンプレート名とコンテンツを入力する
   - 保存ボタンをクリックする
   - 一覧に表示されることを確認する
3. テンプレート読み取りの検証
   - テンプレート一覧が正しく表示されることを確認する
   - テンプレートを選択して内容が表示されることを確認する
4. テンプレート更新の検証
   - 既存テンプレートを選択する
   - 内容を編集する
   - 保存ボタンをクリックする
   - 変更が反映されることを確認する
5. テンプレート削除の検証
   - 既存テンプレートを選択する
   - 削除ボタンをクリックする
   - 確認ダイアログで承認する
   - 一覧から削除されることを確認する
6. 成果物を `outputs/phase-11/crud-manual-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/crud-manual-test.md`

---

### タスク2: プリセット保護の手動検証

**目的**: プリセットテンプレートが保護されていることを確認する

**実行手順**:

1. プリセットテンプレートを確認する
   - プリセットアイコン/バッジが表示されることを確認する
   - プリセットが一覧に表示されることを確認する
2. プリセット編集不可の確認
   - プリセットを選択する
   - 編集ボタンが無効化されていることを確認する
   - または編集時にエラーメッセージが表示されることを確認する
3. プリセット削除不可の確認
   - プリセットを選択する
   - 削除ボタンが無効化されていることを確認する
   - または削除時にエラーメッセージが表示されることを確認する
4. 成果物を `outputs/phase-11/preset-protection-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/preset-protection-test.md`

---

### タスク3: オフライン動作の手動検証

**目的**: オフライン時もアプリケーションが正常動作することを確認する

**実行手順**:

1. オンライン状態でテンプレートを作成する
2. ネットワークを切断する（機内モードなど）
3. オフライン時の動作を確認する
   - テンプレート一覧が表示されることを確認する
   - テンプレートの選択ができることを確認する
   - 新規テンプレート作成ができることを確認する
   - テンプレート更新ができることを確認する
4. ネットワークを再接続する
5. 同期動作を確認する
   - オフライン中の変更が同期されることを確認する
   - エラーなく動作することを確認する
6. 成果物を `outputs/phase-11/offline-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/offline-test.md`

---

### タスク4: マイグレーションの手動検証

**目的**: electron-storeからの移行が正常に動作することを確認する

**実行手順**:

1. テスト用のelectron-storeデータを準備する
   - 既存のelectron-storeにテストデータを追加する
2. アプリケーションを再起動する
3. マイグレーション動作を確認する
   - 既存データがTursoに移行されていることを確認する
   - UIで移行されたテンプレートが表示されることを確認する
4. バックアップファイルを確認する
   - バックアップファイルが作成されていることを確認する
5. 成果物を `outputs/phase-11/migration-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/migration-test.md`

---

### タスク5: エラーハンドリングの手動検証

**目的**: エラー発生時のUI表示が適切であることを確認する

**実行手順**:

1. バリデーションエラーの確認
   - 空のテンプレート名で保存を試みる
   - エラーメッセージが表示されることを確認する
2. 重複エラーの確認
   - 同じ名前のテンプレートを作成しようとする
   - 重複エラーメッセージが表示されることを確認する
3. ネットワークエラーの確認（可能な場合）
   - ネットワークエラー時の表示を確認する
   - 適切なエラーメッセージが表示されることを確認する
4. 成果物を `outputs/phase-11/error-handling-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/error-handling-test.md`

---

### タスク6: UI/UXの手動検証

**目的**: UI/UXが仕様通りであることを確認する

**実行手順**:

1. レイアウトの確認
   - テンプレート一覧のレイアウトが正しいことを確認する
   - テンプレート編集画面のレイアウトが正しいことを確認する
2. レスポンシブ対応の確認
   - ウィンドウサイズ変更時の挙動を確認する
3. ローディング状態の確認
   - データ読み込み中のローディング表示を確認する
4. アクセシビリティの確認
   - キーボード操作が可能であることを確認する
   - フォーカス移動が適切であることを確認する
5. 成果物を `outputs/phase-11/ui-ux-test.md` に出力する

**期待される成果物**:

- `outputs/phase-11/ui-ux-test.md`
