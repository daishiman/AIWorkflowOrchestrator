| 情報漏洩防止       | 存在チェックと認可チェック統合 | ✅         |

**設計済みコード例**:

```typescript
// Service層での認可チェック（実現可能性確認済み）
private async verifyTemplateOwnership(
  templateId: string,
  requestUserId: string,
): Promise<PromptTemplate> {
  const template = await this.repository.findById(templateId);

  // 存在チェックと認可チェックで同一エラー
  if (!template || (template.userId !== requestUserId && !template.isPreset)) {
    throw new UnauthorizedTemplateAccessError(templateId);
  }

  return template;
}
```

**結果**: 4/4 実現可能 (100%)
