## テストケース一覧

### TC-001: テンプレート作成

**手順**:

1. アプリを起動しログイン
2. テンプレート管理画面を開く
3. 「新規作成」ボタンをクリック
4. 名前「手動テスト用テンプレート」を入力
5. 内容「これは手動テストで作成したテンプレートです。」を入力
6. 「保存」ボタンをクリック

**期待結果**:

- [ ] 作成成功メッセージが表示される
- [ ] テンプレート一覧に新しいテンプレートが表示される
- [ ] 名前と内容が正しく保存されている

---

### TC-002: テンプレート一覧表示

**手順**:

1. テンプレート管理画面を開く
2. 一覧を確認する

**期待結果**:

- [ ] 自分が作成したテンプレートが表示される
- [ ] プリセットテンプレートが表示される
- [ ] 各テンプレートの名前・作成日時が表示される

---

### TC-003: テンプレート編集

**手順**:

1. テンプレート一覧から「手動テスト用テンプレート」を選択
2. 「編集」ボタンをクリック
3. 名前を「手動テスト用テンプレート（更新済み）」に変更
4. 「保存」ボタンをクリック

**期待結果**:

- [ ] 更新成功メッセージが表示される
- [ ] 一覧で名前が変更されている
- [ ] 更新日時が更新されている

---

### TC-004: テンプレート削除

**手順**:

1. テンプレート一覧から「手動テスト用テンプレート（更新済み）」を選択
2. 「削除」ボタンをクリック
3. 確認ダイアログで「削除」を選択

**期待結果**:

- [ ] 削除成功メッセージが表示される
- [ ] テンプレート一覧から削除されている

---

### TC-005: プリセット保護

**手順**:

1. プリセットテンプレート「翻訳アシスタント」を選択
2. 「編集」ボタンをクリック（または編集操作を試みる）

**期待結果**:

- [ ] 編集ボタンが無効化されている、または
- [ ] 「プリセットテンプレートは編集できません」エラーが表示される

**削除テスト**:

1. プリセットテンプレートで「削除」を試みる

**期待結果**:

- [ ] 削除ボタンが無効化されている、または
- [ ] 「プリセットテンプレートは削除できません」エラーが表示される

---

### TC-006: バリデーションエラー

#### TC-006-1: 名前が空

**手順**:

1. 新規作成画面で名前を空のまま保存を試みる

**期待結果**:

- [ ] 「テンプレート名は必須です」エラーが表示される

#### TC-006-2: 名前が長すぎる

**手順**:

1. 51文字以上の名前を入力して保存を試みる

**期待結果**:

- [ ] 「テンプレート名は50文字以内にしてください」エラーが表示される

#### TC-006-3: コンテンツが長すぎる

**手順**:

1. 4001文字以上のコンテンツを入力して保存を試みる

**期待結果**:

- [ ] 「コンテンツは4000文字以内にしてください」エラーが表示される

#### TC-006-4: 名前重複

**手順**:

1. 既存のテンプレートと同じ名前で新規作成を試みる

**期待結果**:

- [ ] 「同じ名前のテンプレートが既に存在します」エラーが表示される

---

### TC-007: オフライン動作（Turso Embedded Replica）

**手順**:

1. アプリを起動し、テンプレートを作成
2. ネットワーク接続を切断（機内モードまたはWi-Fi OFF）
3. テンプレート一覧を表示
4. 新しいテンプレートを作成
5. 既存テンプレートを編集
6. テンプレートを削除
7. ネットワーク接続を復帰

**期待結果**:

- [ ] オフライン時も一覧が表示される
- [ ] オフライン時も作成・編集・削除ができる
- [ ] オンライン復帰時にデータが同期される

---

### TC-008: マイグレーション動作

**前提条件**:

- electron-storeにカスタムテンプレートが存在
- マイグレーション未実施状態

**手順**:

1. マイグレーション対象データを準備
2. アプリを起動
3. マイグレーション処理を確認
4. テンプレート一覧を確認

**期待結果**:

- [ ] マイグレーションが自動実行される
- [ ] 全テンプレートがTursoに移行される
- [ ] データ損失がない
- [ ] 2回目以降はマイグレーションがスキップされる

---

### TC-009: エラー回復

**手順**:

1. 意図的にエラーを発生させる（例：DBファイル削除）
2. 操作を実行
3. エラー状態を解消
4. 再度操作を実行

**期待結果**:

- [ ] エラーメッセージが適切に表示される
- [ ] アプリがクラッシュしない
- [ ] エラー解消後に正常動作する
