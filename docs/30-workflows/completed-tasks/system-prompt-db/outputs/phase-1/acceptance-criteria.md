## 1. 機能面の受け入れ基準

### AC-FUNC-001: テンプレートのCRUD操作

| ID            | 基準                                                     | 検証方法   |
| ------------- | -------------------------------------------------------- | ---------- |
| AC-FUNC-001-1 | ユーザーは新しいテンプレートを作成できる                 | 手動テスト |
| AC-FUNC-001-2 | 作成時に名前（1-50文字）と内容（1-4000文字）を指定できる | 単体テスト |
| AC-FUNC-001-3 | ユーザーは自分のテンプレート一覧を取得できる             | 結合テスト |
| AC-FUNC-001-4 | ユーザーはIDを指定して単一テンプレートを取得できる       | 単体テスト |
| AC-FUNC-001-5 | ユーザーは既存テンプレートの名前・内容を更新できる       | 手動テスト |
| AC-FUNC-001-6 | ユーザーは不要なテンプレートを削除できる                 | 手動テスト |
| AC-FUNC-001-7 | 同一ユーザー内で名前が重複するテンプレートは作成できない | 単体テスト |

**Given-When-Then 形式**:

```gherkin
Scenario: テンプレートの作成
  Given ユーザーがログインしている
  When ユーザーが「翻訳アシスタント改」という名前でテンプレートを作成する
  Then テンプレートがデータベースに保存される
  And テンプレート一覧に新しいテンプレートが表示される

Scenario: 名前重複エラー
  Given ユーザーが「翻訳アシスタント」という名前のテンプレートを持っている
  When ユーザーが同じ名前でテンプレートを作成しようとする
  Then 「テンプレート名が重複しています」というエラーが表示される
```

### AC-FUNC-002: ユーザー認証との連動

| ID            | 基準                                                   | 検証方法           |
| ------------- | ------------------------------------------------------ | ------------------ |
| AC-FUNC-002-1 | テンプレートは作成したユーザーのIDに紐づく             | 単体テスト         |
| AC-FUNC-002-2 | ユーザーは自分のテンプレートのみ閲覧できる             | 結合テスト         |
| AC-FUNC-002-3 | 他のユーザーのテンプレートにはアクセスできない         | セキュリティテスト |
| AC-FUNC-002-4 | 認可エラー時は「アクセス権限がありません」と表示される | 単体テスト         |

**Given-When-Then 形式**:

```gherkin
Scenario: ユーザー別テンプレート表示
  Given ユーザーAが3つのテンプレートを持っている
  And ユーザーBが5つのテンプレートを持っている
  When ユーザーAがテンプレート一覧を表示する
  Then ユーザーAの3つのテンプレートのみが表示される

Scenario: 他ユーザーのテンプレートへのアクセス拒否
  Given ユーザーBが「マイテンプレート」を持っている
  When ユーザーAがそのテンプレートにアクセスしようとする
  Then 「アクセス権限がありません」というエラーが返される
```

### AC-FUNC-003: プリセットテンプレートの保護

| ID            | 基準                                                 | 検証方法   |
| ------------- | ---------------------------------------------------- | ---------- |
| AC-FUNC-003-1 | プリセットテンプレートは全ユーザーで共有される       | 結合テスト |
| AC-FUNC-003-2 | プリセットテンプレートは編集できない                 | 単体テスト |
| AC-FUNC-003-3 | プリセットテンプレートは削除できない                 | 単体テスト |
| AC-FUNC-003-4 | 編集・削除試行時は適切なエラーメッセージが表示される | 手動テスト |

**Given-When-Then 形式**:

```gherkin

  Then 「プリセットテンプレートは編集できません」というエラーが表示される

Scenario: プリセット削除拒否
  Given 「プログラミング支援」プリセットが存在する
  When ユーザーがプリセットを削除しようとする
  Then 「プリセットテンプレートは削除できません」というエラーが表示される
```

### AC-FUNC-004: オフライン動作

| ID            | 基準                                         | 検証方法   |
| ------------- | -------------------------------------------- | ---------- |
| AC-FUNC-004-1 | オフライン時もテンプレート一覧を表示できる   | 手動テスト |
| AC-FUNC-004-2 | オフライン時もテンプレートを作成できる       | 手動テスト |
| AC-FUNC-004-3 | オフライン時もテンプレートを編集・削除できる | 手動テスト |
| AC-FUNC-004-4 | オンライン復帰時に自動でデータが同期される   | 結合テスト |

**Given-When-Then 形式**:

```gherkin
Scenario: オフラインでのテンプレート作成
  Given デスクトップアプリがオフラインである
  When ユーザーが新しいテンプレートを作成する
  Then テンプレートがローカルに保存される
  And 「オフラインで保存されました」と表示される

Scenario: オンライン復帰時の同期
  Given オフラインで作成したテンプレートがある
  When ネットワーク接続が復帰する
  Then テンプレートがクラウドに同期される
  And 「同期完了」と表示される
```

## 3. マイグレーション面の受け入れ基準

### AC-MIG-001: 自動マイグレーション

| ID           | 基準                                                | 検証方法   |
| ------------ | --------------------------------------------------- | ---------- |
| AC-MIG-001-1 | アプリ起動時にマイグレーション対象が自動検出される  | 結合テスト |
| AC-MIG-001-2 | electron-storeのテンプレートがTursoに自動移行される | 結合テスト |
| AC-MIG-001-3 | 既存の全テンプレートが正しく移行される              | 結合テスト |
| AC-MIG-001-4 | 移行済みデータはスキップされる                      | 単体テスト |

**Given-When-Then 形式**:

```gherkin
Scenario: 初回起動時の自動マイグレーション
  Given electron-storeに5つのカスタムテンプレートがある
  When アプリが初めてTurso対応版として起動する
  Then 5つのテンプレートがTursoに移行される
  And 「マイグレーション完了」とログに記録される

Scenario: 2回目起動時のスキップ
  Given 既にマイグレーションが完了している
  When アプリが再起動する
  Then マイグレーション処理はスキップされる
```

---

### AC-MIG-002: データ保全

| ID           | 基準                                             | 検証方法   |
| ------------ | ------------------------------------------------ | ---------- |
| AC-MIG-002-1 | マイグレーション前にバックアップが作成される     | 結合テスト |
| AC-MIG-002-2 | データ損失が0件である                            | 結合テスト |
| AC-MIG-002-3 | テンプレートの名前・内容・日時が正しく移行される | 結合テスト |
| AC-MIG-002-4 | 失敗時はバックアップから復元される               | 結合テスト |

**Given-When-Then 形式**:

```gherkin
Scenario: マイグレーション失敗時のロールバック
  Given electron-storeに3つのテンプレートがある
  And バックアップファイルが作成されている
  When マイグレーション中にエラーが発生する
  Then バックアップからデータが復元される
  And 「マイグレーション失敗、フォールバック中」とユーザーに通知される
  And 次回起動時にリトライされる
```

---

### AC-MIG-003: フォールバック

| ID           | 基準                                                   | 検証方法   |
| ------------ | ------------------------------------------------------ | ---------- |
| AC-MIG-003-1 | マイグレーション失敗時はelectron-storeモードで動作する | 結合テスト |
| AC-MIG-003-2 | フォールバック時もCRUD操作が可能である                 | 手動テスト |
| AC-MIG-003-3 | 次回起動時にマイグレーションがリトライされる           | 結合テスト |
