## 2. セキュリティ要件（NFR-SEC）

### NFR-SEC-001: ユーザー認可

| 要件ID        | 要件名         | 詳細                                           |
| ------------- | -------------- | ---------------------------------------------- |
| NFR-SEC-001-1 | 所有者チェック | テンプレート操作時に所有者のみアクセス許可     |
| NFR-SEC-001-2 | 情報漏洩防止   | 存在チェックと認可エラーで同一メッセージを返す |
| NFR-SEC-001-3 | ユーザーID検証 | ユーザーIDの改ざん・偽装を検証                 |

**実装パターン**:

```typescript
// 認可チェック: セッション所有者検証と同様のパターン
private async verifyTemplateOwnership(
  templateId: string,
  requestUserId: string,
): Promise<PromptTemplate> {
  const template = await this.repository.findById(templateId);

  // 存在チェックと認可チェックで同一エラー（情報漏洩防止）
  if (!template || template.userId !== requestUserId) {
    throw new UnauthorizedError(
      'このテンプレートへのアクセス権限がありません',
      'TEMPLATE',
      templateId,
    );
  }

  return template;
}
```
