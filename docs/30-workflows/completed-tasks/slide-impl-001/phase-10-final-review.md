## 判定基準

| -------- | ---------------- | -------------------------------------------------- |
| PASS     | 全観点で問題なし | Phase 11 へ進行                                    |

| MAJOR    | 重大な問題あり   | 影響範囲に応じて Phase 1-5 へ戻る                  |

### MAJOR 判定時の戻り先決定フロー

| 問題の性質       | 戻り先  | 判断基準                             |
| ---------------- | ------- | ------------------------------------ |
| 要件の誤解・不足 | Phase 1 | AC の追加・変更が必要                |
| 設計の欠陥       | Phase 2 | インターフェース・型定義の変更が必要 |
| テスト不足       | Phase 4 | テストケースの追加が必要             |
| 実装の重大バグ   | Phase 5 | プロダクションコードの修正が必要     |
