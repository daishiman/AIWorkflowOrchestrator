## 手動テストシナリオ

### シナリオ 1: アプリ起動時のIPCハンドラ登録エラーなし

**目的**: Bug 1修正により、`registerRuntimeSkillCreatorHandlers()` が例外なく完走することを確認する。

**手順**:

1. Electronアプリを起動する
2. DevToolsコンソール（Mainプロセスログ）を開く
3. 起動完了後のログを確認する

**期待結果**:

- コンソールに `registerSkillCreatorHandlers failed` エラーが**出ない**こと
- `No handler registered for 'skill-creator:*'` 系のエラーが**出ない**こと

**判定**:

| 確認項目                                                         | 結果                |
| ---------------------------------------------------------------- | ------------------- |
| `registerSkillCreatorHandlers failed` エラーが出ないこと         | [ ] PASS / [ ] FAIL |
| `No handler registered for 'skill-creator:*'` エラーが出ないこと | [ ] PASS / [ ] FAIL |

---

### シナリオ 2: スキル作成ウィザード — 英語入力

**目的**: 基本的なスキル作成フローが正常に動作することを確認する。

**手順**:

1. SkillLifecyclePanelを開く
2. スキル作成ウィザードを起動する
3. スキル名またはスキルの説明として英語で `"test skill"` を入力する
4. スキル作成を実行する

**期待結果**:

- エラーダイアログが表示されないこと
- スキルが正常に作成されること
- 作成されたスキル名が `/^[a-z0-9]+(-[a-z0-9]+)*$/` に適合すること（例: `test-skill`）

**判定**:

| 確認項目                                           | 結果                |
| -------------------------------------------------- | ------------------- |
| エラーダイアログが表示されないこと                 | [ ] PASS / [ ] FAIL |
| スキルが正常に作成されること                       | [ ] PASS / [ ] FAIL |
| 作成スキル名がハイフンケース正規表現に適合すること | [ ] PASS / [ ] FAIL |
| 作成スキル名（実測値）                             |                     |

---

### シナリオ 3: スキル作成ウィザード — 日本語入力

**目的**: Bug 2修正により、日本語入力でもエラーなくスキルが作成されることを確認する。

**手順**:

1. SkillLifecyclePanelを開く
2. スキル作成ウィザードを起動する
3. スキル名またはスキルの説明として日本語で `"テストスキル"` を入力する
4. スキル作成を実行する

**期待結果**:

- `スキル名はハイフンケース（小文字、数字、ハイフン）である必要があります` エラーが表示**されない**こと
- スキル名として `new-skill` が基準になり、同名が既に存在する場合は `new-skill-2` 以降で衝突回避されること
- スキルが正常に作成されること

**判定**:

| 確認項目                                         | 結果                |
| ------------------------------------------------ | ------------------- |
| バリデーションエラーが表示されないこと           | [ ] PASS / [ ] FAIL |
| `new-skill` / `new-skill-2` 以降で作成されること | [ ] PASS / [ ] FAIL |
| スキルが正常に作成されること                     | [ ] PASS / [ ] FAIL |
| 作成スキル名（実測値）                           |                     |

## 判定基準

| 判定        | 条件                                              | 次のアクション                     |
| ----------- | ------------------------------------------------- | ---------------------------------- |
| PASS        | 全4シナリオが全てPASSであること                   | Phase 12（ドキュメント更新）へ進む |
| CONDITIONAL | MINOR ISSUEのみ（機能に影響しない表示上の問題等） | 別Issueを作成し、Phase 12へ進む    |
| FAIL        | 1件以上のシナリオがFAILであること                 | Phase 5（実装）へ戻る              |

> **注意**: FAILが発生した場合は、コンソールログ全体を `outputs/phase-11/manual-test-result.md` に記録してからPhase 5へ戻ること。
