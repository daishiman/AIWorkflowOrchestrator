## Blocker判定基準

| 重大度   | 定義                                           | 対応方針                                       |
| -------- | ---------------------------------------------- | ---------------------------------------------- |
| CRITICAL | ACのいずれかがFAILである、またはテストが未実行 | **Phase 5（実装）へ戻る**                      |
| MAJOR    | テストが通るが、実装のロジックに懸念がある     | Phase 5またはPhase 8（リファクタリング）へ戻る |
| MINOR    | コードスタイルや軽微な改善点                   | Phase 11完了後に別タスクとして対応             |
| PASS     | 全AC PASS、Blockerなし                         | Phase 11（手動テスト）へ進む                   |

> **重要**: CRITICALが1件でも存在する場合は、Phase 11へ進まず必ずPhase 5へ戻ること。
