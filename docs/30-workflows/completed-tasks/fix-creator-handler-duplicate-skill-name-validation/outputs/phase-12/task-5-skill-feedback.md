# タスク 5: スキルフィードバック報告

## フィードバック

1. **Bug Fix タスクでは識別子ベースで参照する**
   行番号ではなく関数名・チャンネル名で参照することで、コード変更後も
   仕様書が drift しない。

2. **Phase 12 の未タスクは ID 化して参照のみにする**
   UT-01〜03 のように識別子を付与し、追跡可能にする方が管理しやすい。

3. **Part 1 は非技術者向けに徹底する**
   技術名は Part 2 に集約し、Part 1 は比喩のみにすることで
   読み分けがしやすい。

4. **カバレッジ目標はファイル全体ではなく修正関数単位で設定する**
   ファイル全体 90% は大きなサービスクラスでは非現実的。
   「修正関数の分岐を全て踏む」を主目標にすべき。
