## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連自動テストの実行

**目的**: 手動テスト前に自動テストが全てパスすることを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm --filter @repo/shared test -- --run
```

2. 全テストがパスすることを確認

**期待される成果物**:

- 自動テスト実行結果

---

### タスク2: 実際のインポートテスト

**目的**: `apps/desktop` からの実際のインポートが動作することを確認

**実行手順**:

1. `apps/desktop` のソースコードで以下のインポートが動作するか確認:

```typescript
import type {
  Community,
  CommunitySummary,
  StoredEntity,
} from "@repo/shared/services/graph";
```

2. TypeScriptコンパイルが成功することを確認:

```bash
pnpm --filter @repo/desktop typecheck
```

**期待される成果物**:

- インポートテスト結果

---

### タスク3: 型チェック全体実行

**目的**: プロジェクト全体の型チェックがパスすることを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm typecheck
```

2. 型エラーがないことを確認

**期待される成果物**:

- 型チェック結果（全体）
