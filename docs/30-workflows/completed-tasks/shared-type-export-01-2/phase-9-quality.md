## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 型チェック

**目的**: TypeScript 型エラーがないことを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm --filter @repo/shared typecheck
```

2. 型エラーがないことを確認

**期待される成果物**:

- 型チェック結果（エラーなし）

---

### タスク2: Lint チェック

**目的**: ESLint エラーがないことを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm --filter @repo/shared lint
```

2. Lint エラーがないことを確認

**期待される成果物**:

- Lint チェック結果（エラーなし）

---

### タスク3: フォーマットチェック

**目的**: コードフォーマットが適用されていることを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm format:check
```

2. フォーマットエラーがないことを確認

**期待される成果物**:

- フォーマットチェック結果（エラーなし）

---

### タスク4: 全テスト実行

**目的**: 全てのテストがパスすることを確認

**実行手順**:

1. 以下のコマンドを実行:

```bash
pnpm --filter @repo/shared test -- --run
```

2. 全テストがパスすることを確認

**期待される成果物**:

- テスト実行結果（全てパス）
