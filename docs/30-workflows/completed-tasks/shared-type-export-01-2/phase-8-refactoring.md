### タスク2: エクスポート構造の最適化

**目的**: エクスポート構造を最適化

**実行手順**:

1. エクスポートを以下のグループに整理:
   - Entity関連の型
   - Relation関連の型
   - Graph構造関連の型
   - Community関連の型
   - Query関連の型
   - 値のエクスポート（enum、class、function）

2. 各グループにコメントを追加:

```typescript
// ==========================================
// Entity Types
// ==========================================
export type { StoredEntity, ExtractedEntity, EntityMention } from "./types";

// ==========================================
// Community Types
// ==========================================
export type {
  Community,
  CommunitySummary,
  // ...
} from "./types";
```

**期待される成果物**:

- 整理された `index.ts`
