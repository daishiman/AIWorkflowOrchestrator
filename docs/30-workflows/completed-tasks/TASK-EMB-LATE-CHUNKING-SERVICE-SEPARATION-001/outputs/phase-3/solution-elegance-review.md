## 美しさ（elegance）判定

- 抽出境界が一直線（Extract Class の教科書通り）
- 命名が意図を表現（`LateChunkingService`・`late-chunking/` サブモジュール）
- 後方互換を型で保証（第 4 引数オプショナル、既定で自動生成）
- テスト観測性と利便性を両立（DI 注入も自動生成も両方サポート）
