# Phase 11: UIサニティ・ビジュアルレビュー

## Apple UI/UXエンジニア視点での設計評価

### レイアウト整合性

| 観点                   | 評価    | 根拠                                                         |
| ---------------------- | ------- | ------------------------------------------------------------ |
| バッジ配置             | ✅ 良好 | `inline-flex items-center`でテキストと垂直中央揃え           |
| ボタン内余白           | ✅ 良好 | `ml-2`（8px）でテキストとバッジに適切な間隔                  |
| ボタン全体のサイズ変化 | ✅ 良好 | バッジ追加で幅は増えるが、`flex-wrap` と等間隔配置で破綻なし |
| flex-wrapレイアウト    | ✅ 良好 | 親コンテナ`flex flex-wrap gap-2`でボタンが折り返す           |

### タイポグラフィ

| 観点                 | 評価    | 根拠                                                          |
| -------------------- | ------- | ------------------------------------------------------------- |
| バッジフォントサイズ | ✅ 良好 | `text-xs`（12px）でボタンテキストより小さく補助情報として適切 |
| フォントウェイト     | ✅ 良好 | `font-medium`（600）で可読性確保                              |
| テキスト内容         | ✅ 良好 | 「主ツール」2文字で意味が明確                                 |

### カラーコントラスト

| 要素                     | 背景色             | テキスト色                 | コントラスト比 | WCAG基準 |
| ------------------------ | ------------------ | -------------------------- | -------------- | -------- |
| バッジ（通常時）         | blue-100 (#dbeafe) | blue-800 (#1e40af)         | ~7.5:1         | ✅ AAA   |
| バッジ（選択中ボタン内） | status-primary     | status-primary上のblue-100 | 確認済み       | ✅       |

### インタラクション

| 観点                     | 評価                                                    |
| ------------------------ | ------------------------------------------------------- |
| バッジのクリックイベント | ✅ ボタン全体のクリックと一体（バッジ単独クリック不要） |
| ホバー時の視覚変化       | ✅ ボタン全体のホバースタイルが適用される               |
| 選択解除後のバッジ消去   | ✅ スムーズ（transition-colorsによるアニメーション）    |

### アクセシビリティ（Apple HIG準拠）

| 観点                 | 評価 | 実装                                    |
| -------------------- | ---- | --------------------------------------- |
| VoiceOver対応        | ✅   | `aria-label="主ツールとして使用される"` |
| Dynamic Type対応     | ✅   | `text-xs`はElectron webviewで相対サイズ |
| 最小タップターゲット | ✅   | ボタン全体（44px以上）がタップ対象      |

### 改善提案

1. **ダークモード対応**: 全体テーマの方針に合わせて青系バッジの反転色を検討する
2. **バッジアニメーション**: 選択時に軽い `fade-in` を付けると状態変化がさらに分かりやすい
3. **ツールチップ**: 必要なら補足説明を hover tooltip で追加する

**現在の実装**: Apple HIG準拠の最小限・適切なUIデザイン ✅
