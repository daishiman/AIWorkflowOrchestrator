## 検討観点

### ヘルパー関数化の要否

| 観点                            | 判断       | 理由                                        |
| ------------------------------- | ---------- | ------------------------------------------- |
| `isMainTool`の抽出              | **見送り** | 3行の計算式。インラインで可読性十分         |

### 変更前後の比較テーブル

| 項目                 | 変更前                        | 変更後                                                 | 理由                           |
| -------------------- | ----------------------------- | ------------------------------------------------------ | ------------------------------ |
| `q.options.map` 形式 | `(opt) => (...)` 式形式       | `(opt) => { ... return (...) }` ブロック形式           | `isMainTool`変数計算のため必須 |
| ボタン className     | `"px-3 py-1.5 rounded-lg..."` | `"inline-flex items-center px-3 py-1.5 rounded-lg..."` | バッジとテキストの横並び対応   |
| ボタン子要素         | `{opt}` のみ                  | `{opt}` + 条件付き `<span>`                            | 主ツールバッジ表示             |
