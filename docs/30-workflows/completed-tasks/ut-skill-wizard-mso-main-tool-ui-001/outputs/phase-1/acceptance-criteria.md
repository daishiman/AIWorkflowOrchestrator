# Phase 1: 受入基準（Acceptance Criteria）

## AC一覧

| ID   | 優先度 | 基準内容                                                                                                          | 検証方法                  |
| ---- | ------ | ----------------------------------------------------------------------------------------------------------------- | ------------------------- |
| AC-1 | HIGH   | Q5で2件以上ツールを選択した場合、`selectedOptions[0]`（先頭選択ツール）のボタン内に「主ツール」バッジが表示される | UT + 手動テスト           |
| AC-2 | HIGH   | Q5で1件のみ選択した場合、「主ツール」バッジは表示されない                                                         | UT                        |

| AC-5 | MEDIUM | Q5で3件以上選択しても先頭選択ツールのみバッジが表示される（バッジは常に1件）                                      | UT                        |

## AC詳細

### AC-1: 先頭選択ツールへのバッジ表示

**条件**: Q5 AND `selectedOptions.length >= 2` AND `selectedOptions[0] === option.value`

**期待動作**:

- Slack → GitHub の順で選択 → Slackボタン内に「主ツール」バッジが表示
- バッジは `<span>主ツール</span>` でボタンテキストの右横に配置

### AC-2: 単一選択時のバッジ非表示

**条件**: `selectedOptions.length < 2`（0件または1件）

**期待動作**: どのツールを選択してもバッジは表示されない

### AC-3: aria-label付与

**属性**: `aria-label="主ツールとして使用される"`

**目的**: スクリーンリーダーユーザーへのアクセシビリティ確保

### AC-4: 他設問への副作用なし

**対象設問**: Q1, Q2, Q3, Q4, Q6

**期待動作**: 上記設問で複数選択しても「主ツール」バッジが表示されない

### AC-5: 3件以上選択時のバッジ数

**条件**: `selectedOptions.length >= 3`

**期待動作**: バッジは先頭選択ツールのみに表示（`getAllByText("主ツール").length === 1`）

### AC-6: 0件選択時のバッジ非表示

**条件**: `selectedOptions.length === 0`（初期状態・全解除後）

**期待動作**: バッジが表示されない（DOMに「主ツール」テキストなし）
