## 実行手順

### 1. カバレッジ測定

```bash
pnpm --filter @repo/desktop test -- --coverage --coverageReporters=text-summary
```

### 2. ギャップ分析

未到達の行/分岐/関数を特定し、以下のカテゴリで不足テストを追加:

| カテゴリ           | 追加テスト例                                                   |
| ------------------ | -------------------------------------------------------------- |
| エッジケース       | 1000件ちょうど・1001件・0件のaddHistoryEntry                   |
| エラーハンドリング | localStorage.setItem失敗（QuotaExceededError）、JSON.parse失敗 |
| UIインタラクション | フィルタ変更後の件数表示更新、クリアボタンのdisabled状態       |
| アクセシビリティ   | スクリーンリーダー用announcements、フォーカス管理              |
| 仮想スクロール     | 大量エントリ（500件・1000件）でのレンダリング性能              |

### 3. 追加テスト作成

Phase 4のテストファイルに追加テストケースを追記する。

### 4. 再測定

```bash
pnpm --filter @repo/desktop test -- --coverage
```
