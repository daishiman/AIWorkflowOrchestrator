## 受け入れ基準

| AC ID | 受け入れ基準                                                                                                  | 検証方法   |
| ----- | ------------------------------------------------------------------------------------------------------------- | ---------- |
| AC-1  | PermissionDialogで「許可」「1回許可」「拒否」のいずれかを選択した後、履歴パネルに最新エントリが追加されている | 自動テスト |
| AC-2  | 履歴エントリにISO8601形式のタイムスタンプ、ツール名、引数要約テキスト、判断結果が表示される                   | 自動テスト |
| AC-3  | ツール名ドロップダウンで「Bash」を選択すると、Bash関連エントリのみが表示される                                | 自動テスト |
| AC-4  | 判断結果フィルタで「拒否」を選択すると、拒否エントリのみが表示される                                          | 自動テスト |
| AC-5  | 「履歴をクリア」ボタンをクリックし確認ダイアログで承認すると、履歴が空になる                                  | 自動テスト |
| AC-6  | 100件以上の履歴がある状態でスクロール操作がスムーズ（フレーム落ちなし）                                       | 手動テスト |
| AC-7  | ブラウザリロード後も履歴が保持されている（localStorage永続化）                                                | 自動テスト |
| AC-8  | 1001件目のエントリ追加時、最も古いエントリが自動削除され1000件が維持される                                    | 自動テスト |
