### 4. カバレッジ未達の場合の対応

未達の場合は Phase 6 へ戻り、不足しているカバレッジを補うテストを追加する。

**主な未達パターンと対応**:

| 未達パターン                        | 追加すべきテスト                                               |
| ----------------------------------- | -------------------------------------------------------------- |
| LLM呼び出しパスの branch 未達       | 正常応答・タイムアウト・パースエラーの各ケース                 |
| フォールバックパスの branch 未達    | LLM呼び出し失敗時に空配列が返されることの確認                  |
| generateSkillMdへの連携 branch 未達 | features配列（空・非空）がSKILL.mdに正しく反映されることの確認 |
| 既存ワークフロー回帰の branch 未達  | create / update それぞれのワークフローが正常終了することの確認 |

- **未達**: いずれかの指標が最低基準未満 → Phase 6 へ戻る
