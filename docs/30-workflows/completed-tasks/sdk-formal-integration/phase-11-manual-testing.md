## 目的

Phase 10 までの自動テスト・静的解析では検証できない、IDE 上での型推論表示や開発者体験（DX）を手動で確認する。本タスクは型レベルのみの変更であるため、主に IDE の IntelliSense（型ホバー情報・補完候補・エラー表示）が正しく機能していることを検証する。実機での E2E テスト（Electron アプリでのスキル実行）は環境依存のため、可能な場合のみ実施する。

## 実行タスク

### Task 1: IDE 型チェック確認 — IntelliSense の動作検証

#### テスト環境

| 項目       | 内容                            |
| ---------- | ------------------------------- |
| IDE        | VSCode または Cursor            |
| TypeScript | プロジェクト設定のバージョン    |
| 拡張機能   | TypeScript 言語サービス（標準） |

#### テスト手順

##### テスト 1-1: query() 関数のホバー型情報

1. `apps/desktop/src/main/services/skill/SkillExecutor.ts` を IDE で開く
2. `callSDKQuery()` メソッド内の `query` 関数呼び出し箇所にカーソルを合わせる
3. ホバーで表示される型情報を確認する

| 確認項目                                   | 期待結果                                             | 結果 |
| ------------------------------------------ | ---------------------------------------------------- | ---- |
| `query` にホバーした時に型情報が表示される | `(config: QueryConfig) => Conversation` 相当の型情報 | [ ]  |
| 型が `any` ではない                        | 具体的な関数シグネチャが表示される                   | [ ]  |

##### テスト 1-2: 不正引数の型エラー表示

1. `SkillExecutor.ts` の `query()` 呼び出し箇所を一時的に以下のように変更する:
   ```typescript
   const conversation = query({
     invalidField: "test", // 存在しないフィールド
   });
   ```
2. IDE が赤い波線（型エラー）を表示することを確認する
3. 確認後、変更を元に戻す（**Ctrl+Z / Cmd+Z**）

| 確認項目                                              | 期待結果                       | 結果 |
| ----------------------------------------------------- | ------------------------------ | ---- |
| 存在しないフィールドに対して IDE が型エラーを表示する | 赤い波線が表示される           | [ ]  |
| エラーメッセージに型情報が含まれている                | 型名（`QueryConfig` 等）が表示 | [ ]  |

##### テスト 1-3: 補完候補の表示

1. `SkillExecutor.ts` の `query()` 呼び出し箇所で、引数オブジェクト内にカーソルを置く
2. Ctrl+Space（または自動補完トリガー）で補完候補を表示する
3. `prompt`, `options` 等のフィールドが候補に表示されることを確認する

| 確認項目                                     | 期待結果                         | 結果 |
| -------------------------------------------- | -------------------------------- | ---- |
| 補完候補に `prompt` が表示される             | 表示される                       | [ ]  |
| 補完候補に `options` が表示される            | 表示される                       | [ ]  |
| 補完候補に存在しないフィールドが表示されない | 定義外のフィールドは候補に出ない | [ ]  |

##### テスト 1-4: conversation.stream() の型情報

1. `SkillExecutor.ts` の `conversation.stream()` 呼び出し箇所にカーソルを合わせる
2. ホバーで表示される型情報を確認する

| 確認項目                                      | 期待結果                         | 結果 |
| --------------------------------------------- | -------------------------------- | ---- |
| `stream()` にホバーした時に型情報が表示される | `AsyncIterable<SDKMessage>` 相当 | [ ]  |
| 戻り値の型が `any` ではない                   | 具体的な型が表示される           | [ ]  |

### Task 3: スキル実行 E2E フロー確認（実機テスト可能な場合のみ）

#### 前提条件

| SDK の query() 呼び出しがエラーなく動作する   | エラーなし         | [ ] / スキップ |
