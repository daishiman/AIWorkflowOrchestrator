## 追加フィクスチャ要否

### SkillExecutor補強テスト（SE-02, SE-07, SE-08）

- **ファイルベースフィクスチャ**: 不要（モックベースのテスト）
- **インラインフィクスチャ**: SkillMetadataオブジェクト、SkillExecutionRequestオブジェクトは既存テストのパターンを踏襲

### PermissionResolver補強テスト（PR-03）

- **ファイルベースフィクスチャ**: 不要
- **インラインフィクスチャ**: SkillPermissionResponseオブジェクトをテスト内に定義

## フィクスチャ配置方針

| 種別             | 配置場所             | 使用条件                                   |
| ---------------- | -------------------- | ------------------------------------------ |
| ファイルベース   | `__fixtures__/`      | ファイルシステム操作テスト（SkillScanner） |
| インラインデータ | テストファイル内定数 | 2回以上使用するオブジェクト                |
| ファクトリ関数   | テストファイル内関数 | 3回以上使用＋微小差異があるデータ          |

## 追加が不要な理由

既存テストは150件以上のテストケースを持ち、十分なフィクスチャが定義済み。ギャップ4件の補強テストは既存のモック/フィクスチャパターンを再利用するため、新規フィクスチャの追加は不要。
