### Task 2: AgentView スキル一覧表示テスト

#### 2-1. スキル一覧表示

| #   | 操作                       | 期待結果                                             |
| --- | -------------------------- | ---------------------------------------------------- |
| 1   | Agent ビューを開く         | Agent ビューが正常に描画される                       |
| 2   | スキル一覧セクションを確認 | スキル一覧がリスト形式で表示される                   |
| 3   | DevTools コンソールを確認  | `forEach is not a function` エラーが出力されていない |

#### 2-2. 戻り値の型検証（DevTools で実行）

DevTools コンソールで以下のコマンドを実行し、戻り値が配列であることを確認する。

```javascript
// getImported の戻り値検証
const imported = await window.electronAPI.skill.getImported();
console.log("isArray:", Array.isArray(imported));
console.log("type:", typeof imported);
console.log("length:", imported.length);

// list の戻り値検証
const skills = await window.electronAPI.skill.list();
console.log("isArray:", Array.isArray(skills));
console.log("type:", typeof skills);
console.log("length:", skills.length);
```

- [ ] `getImported()` の戻り値が配列（`Array.isArray() === true`）
- [ ] `list()` の戻り値が配列（`Array.isArray() === true`）
- [ ] 戻り値が `{ success: true, data: [...] }` 形式でないこと（ラッパーが展開されていること）
