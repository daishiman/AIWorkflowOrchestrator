## 4. 実装方針

### Phase 6で追加するテスト

1. **境界値テスト** - 空白のみ、Unicode、特殊文字
2. **エラーハンドリング** - 非Error型例外、不正データ
3. **キャッシュテスト** - 並行処理、LRUエビクション詳細
4. **統合テスト** - 複数フィルタ、edge case

### 備考

- Phase 6仕様書にある `distanceToSimilarity` や `buildFilterClauses` は、
  本実装では `searchByVector()` 関数に内包されているため、
  これらのプライベートメソッドテストは不要
- 代わりに、結果のスコア値が正しく変換されているかを統合テストで確認
