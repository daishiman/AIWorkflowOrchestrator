## 目的

Phase 6のテスト拡充結果を検証し、カバレッジ基準を満たしているかをゲートとして確認する。未達の場合はPhase 6に戻りテストを拡充する。

## 背景

カバレッジ確認はリファクタリング（Phase 8）に進む前の品質ゲート。十分なテスト網羅性がない状態でリファクタリングを行うと、回帰バグのリスクが高まる。本Phaseで基準達成を確認してから次に進む。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ確認

**目的**: ユニットテストのカバレッジ基準達成を確認する

**実行手順**:

1. カバレッジ計測を実行:

   ```bash
   pnpm --filter @repo/shared test:coverage -- --run vector-search-strategy
   ```

2. 以下の基準を確認:
   | 指標 | 最低基準 | 推奨基準 | 実測値 | 判定 |
   | ----------------- | -------- | -------- | ------ | ---- |
   | Line Coverage | 80% | 90% | ? | ? |
   | Branch Coverage | 60% | 70% | ? | ? |
   | Function Coverage | 80% | 90% | ? | ? |

3. 未達の場合は不足箇所を特定

**期待される成果物**:

- ユニットテストカバレッジ確認結果（`outputs/phase-7/unit-coverage-check.md`）

---

### タスク2: 結合テストカバレッジ確認

**目的**: 結合テストのカバレッジ基準達成を確認する

**実行手順**:

1. 結合テストを実行:

   ```bash
   pnpm --filter @repo/shared test -- --run vector-search-strategy.integration
   ```

2. 以下の基準を確認:
   | 指標 | 目標 | 実測 | 判定 |
   | ------------------------------ | ----- | ---- | ---- |
   | IEmbeddingProvider接続 | 100% | ? | ? |
   | モジュール間インターフェース | 100% | ? | ? |
   | 正常系シナリオ | 100% | ? | ? |
   | 異常系シナリオ | 80%+ | ? | ? |
   | 外部連携ポイント（libSQL） | 100% | ? | ? |

3. 結合テストシナリオの網羅性を確認:
   - [ ] API接続テスト
   - [ ] データフローテスト
   - [ ] エラーハンドリングテスト
   - [ ] 認証連携テスト（該当なし）
   - [ ] 状態同期テスト（該当なし）

**期待される成果物**:

- 結合テストカバレッジ確認結果（`outputs/phase-7/integration-coverage-check.md`）

---

### タスク3: 統合テスト再実行

**目的**: 全統合テストが成功することを確認する

**実行手順**:

1. 統合テストを実行:

   ```bash
   pnpm --filter @repo/shared test -- --run vector-search-strategy
   ```

2. 全テストが成功することを確認

3. 失敗がある場合は原因を特定

**期待される成果物**:

- 統合テスト実行結果（`outputs/phase-7/integration-test-result.md`）

---

### タスク4: ゲート判定

**目的**: カバレッジ基準達成の最終判定を行う

**実行手順**:

1. 判定基準:
   - **PASS**: 全カバレッジ基準を達成 → Phase 8へ進む
   - **FAIL**: 基準未達 → Phase 6へ戻りテスト拡充

2. 判定表を作成:
   | カテゴリ | 指標 | 基準 | 実測 | 判定 |
   | -------- | ----------------- | ---- | ---- | ---- |
   | ユニット | Line Coverage | 80% | ? | ? |
   | ユニット | Branch Coverage | 60% | ? | ? |
   | ユニット | Function Coverage | 80% | ? | ? |
   | 結合 | 正常系シナリオ | 100% | ? | ? |
   | 結合 | 異常系シナリオ | 80% | ? | ? |

3. 総合判定を記録

**期待される成果物**:

- ゲート判定結果（`outputs/phase-7/gate-judgment.md`）

## ゲート判定基準

### 判定フロー

```
カバレッジ計測
    ↓
基準チェック
    ↓
┌─────────────────────────────────────┐
│ Line >= 80% AND                     │
│ Branch >= 60% AND                   │
│ Function >= 80% AND                 │
│ 統合テスト全成功                    │
└─────────────────────────────────────┘
    ↓
  ┌─────┴─────┐
  ↓           ↓
PASS        FAIL
  ↓           ↓
Phase 8    Phase 6へ戻る
```

### FAIL時の対応

1. 不足箇所を特定
2. 追加テストケースを計画
3. Phase 6に戻りテスト拡充
