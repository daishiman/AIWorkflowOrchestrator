# Phase 12 スキルフィードバック

## 維持すべき点

- Phaseテンプレートの粒度（目的/実行タスク/完了条件）が実行に直結している。
- `outputs/phase-N` の成果物分割は追跡性が高い。

## 改善提案

1. 監査対象パスを固定値で持たず、存在確認してフォールバックする記述をテンプレート化する。
2. `validate-phase-output.js` の説明文とファイル名（mjs/js）の不整合を解消する。
3. TC-06のような「件数のみでは判定できない」ケースに、補助コマンドをテンプレート標準として追加する。

## 総評

仕様準拠でフェーズ実行は可能だったが、パス移動や実体差分に強いテンプレート化を進めると再利用性が上がる。
