# Phase 2 SubAgent実行計画

## 実行順序

| ステップ | 担当 | 実行                    | 入力          | 出力             |
| -------- | ---- | ----------------------- | ------------- | ---------------- |
| S1       | A    | 直列開始                | `channels.ts` | 棚卸しCSV/MD     |
| S2       | B    | A完了後に並列開始       | 棚卸し        | 命名判定結果     |
| S3       | C    | Bの違反抽出後に部分並列 | 違反一覧      | 影響調査+優先度  |
| S4       | Lead | 直列                    | A/B/C成果物   | 統合監査レポート |

## 並列化区間

- 並列可:
  - Bの判定処理と、Cの参照数収集（違反キー確定後）
  - TC群のうち独立コマンド（TC-01/02/03/04/05/07/08）
- 直列必須:
  - 最終優先度確定
  - Phase間ゲート判定

## 失敗時の戻り

- A失敗: Phase 1要件の対象定義に戻る。
- B失敗: 判定式を見直しPhase 2で再定義。
- C失敗: 参照検索条件（glob除外）を見直す。
