## 手動テスト手順

### ステップ1: デスクトップアプリのビルド・起動

```bash
pnpm --filter @repo/desktop build
NODE_ENV=development pnpm --filter @repo/desktop dev
```

### ステップ2: 設定画面を開く

| 手順                       | 期待結果                                             |
| -------------------------- | ---------------------------------------------------- |
| アプリを起動する           | クラッシュせず正常に起動する                         |
| 設定画面（Settings）を開く | 設定画面が表示される                                 |
| Analytics セクションを確認 | `AnalyticsDashboardPanel` が統合されて表示されている |

### ステップ3: Analytics ダッシュボードの表示確認

| 確認項目                         | 期待結果                                        |
| -------------------------------- | ----------------------------------------------- |
| パネルタイトルが表示されている   | Analytics ダッシュボードの見出しが確認できる    |
| キュー件数が表示されている       | `getQueueSize()` の返り値が UI に反映されている |
| オプトアウト状態が表示されている | ON または OFF のいずれかが明示されている        |

### ステップ4: 開発モードでの診断ブロック確認

| 確認項目                   | 期待結果                                                 |
| -------------------------- | -------------------------------------------------------- |
| 診断ブロックが表示される   | 設定画面に開発専用の診断ブロックが表示される             |
| 本番モードでは非表示になる | `NODE_ENV=production` 起動では診断ブロックが表示されない |

### ステップ5: スクリーンショット撮影

以下のスクリーンショットを `screenshots/` 配下に保存する:

| ファイル名                                   | 内容                                            |
| -------------------------------------------- | ----------------------------------------------- |
| `analytics-panel-default.png`                | 設定画面の analytics ダッシュボード（通常状態） |
| `analytics-panel-opted-out-on.png`           | オプトアウト ON 状態                            |
| `analytics-panel-opted-out-off.png`          | オプトアウト OFF 状態                           |
| `analytics-diagnostic-block-dev.png`         | 開発モードでの診断ブロック表示                  |
| `analytics-diagnostic-block-prod-hidden.png` | 本番モードでの診断ブロック非表示                |
