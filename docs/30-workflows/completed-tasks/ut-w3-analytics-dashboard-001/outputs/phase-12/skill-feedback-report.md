## analytics dashboard spec 固有のノウハウ

1. `injectOnboardingStoreMock()` のように、E2E ではモーダル抑止用の store 値を先に注入するとテストが安定する
2. `window.__analyticsDashboardDevMode` のような限定フックは、prod-hidden のスクリーンショットを追加ビルドなしで取得するのに有効
3. `rerender()` を使うと、同一マウントでの状態変化確認ができ、状態反映の回帰に強い
