## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

## 実行タスク

### タスク1: ローカル動作確認依頼【必須】

**目的**: ユーザーにローカルでの最終動作確認を依頼する

**確認チェックリスト**:

```bash
# ビルド確認
pnpm --filter @repo/desktop build

# テスト確認
pnpm --filter @repo/desktop test

# 型チェック確認
pnpm --filter @repo/desktop typecheck

# Lint確認
pnpm --filter @repo/desktop lint

# 動作確認
pnpm --filter @repo/desktop dev
```

**期待される成果物**:

- ローカル動作確認完了の報告

---

### タスク2: 変更サマリー提示【必須】

**目的**: 変更内容のサマリーを提示しPR作成の許可を確認する

**サマリー内容**:

- 主な変更内容
- テスト結果サマリー

**重要**: ユーザーから明示的な許可を得るまでPR作成を実行しないこと。

**期待される成果物**:

- 変更サマリードキュメント

### タスク3: PR作成

**目的**: ユーザーの許可後に`/ai:diff-to-pr`を実行する

**実行手順**:

2. `/ai:diff-to-pr` を実行
3. PR が作成されたことを確認

**期待される成果物**:

- PR URL

### タスク5: タスク完了処理

**目的**: タスクディレクトリを完了タスクフォルダに移動する

```

    ↓

```
