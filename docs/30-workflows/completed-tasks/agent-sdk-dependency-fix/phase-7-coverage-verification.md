## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。

## 背景

カバレッジ基準を満たさない場合は Phase 6 へ戻ってテストを追加する。

---

## 実行タスク

### タスク1: ユニットテストカバレッジ再測定

**目的**: ユニットテストカバレッジが基準を満たしているか確認する

**実行手順**:

1. `pnpm --filter @repo/desktop test:coverage` でカバレッジ再測定
2. Line/Branch/Function カバレッジを確認
3. 未達の場合は Phase 6 へ戻る

**判定基準**:

| 指標              | 最低基準 | 現在値 | 判定 |
| ----------------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | -      | -    |
| Branch Coverage   | 60%      | -      | -    |
| Function Coverage | 80%      | -      | -    |

**期待される成果物**:

- ユニットテストカバレッジレポート

---

### タスク2: 結合テストカバレッジ確認

**目的**: 結合テストカバレッジが基準を満たしているか確認する

**判定基準**:

| 指標                         | 目標 | 現在値 | 判定 |
| ---------------------------- | ---- | ------ | ---- |
| APIエンドポイント            | 100% | -      | -    |
| モジュール間インターフェース | 100% | -      | -    |
| 正常系シナリオ               | 100% | -      | -    |
| 異常系シナリオ               | 80%+ | -      | -    |
| 外部連携ポイント             | 100% | -      | -    |

**期待される成果物**:

- 結合テストカバレッジレポート

---

### タスク3: 統合テスト実行・確認

**目的**: 統合テストが全て成功することを確認する

**実行手順**:

1. `pnpm --filter @repo/desktop test:integration` で統合テスト実行
2. 全テストが成功することを確認
3. 失敗がある場合は原因を特定し修正

**期待される成果物**:

- 統合テスト実行結果

---

### タスク4: ゲート判定

**目的**: カバレッジ基準達成可否を判定する

**判定結果**:

| 判定 | 条件       | 次のアクション |
| ---- | ---------- | -------------- |
| PASS | 全基準達成 | Phase 8 へ進行 |
| FAIL | 一部未達   | Phase 6 へ戻る |

**期待される成果物**:

- ゲート判定結果
