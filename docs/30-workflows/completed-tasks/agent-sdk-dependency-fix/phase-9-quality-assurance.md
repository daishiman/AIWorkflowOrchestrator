## 実行タスク

### タスク1: 機能検証

**目的**: 全自動テストの成功を確認する

**実行手順**:

```bash
pnpm --filter @repo/desktop test
pnpm --filter @repo/desktop test:integration
pnpm --filter @repo/desktop test:e2e
```

**期待される成果物**:

- 機能検証結果

---

### タスク2: コード品質検証

**目的**: Lint/型チェックの成功を確認する

**実行手順**:

```bash
pnpm --filter @repo/desktop lint
pnpm --filter @repo/desktop typecheck
```

**期待される成果物**:

- コード品質検証結果

---

### タスク3: セキュリティ検証

**目的**: 脆弱性がないことを確認する

**実行手順**:

```bash
pnpm audit
```

**期待される成果物**:

- セキュリティ検証結果

---

### タスク4: パフォーマンス検証

**目的**: パフォーマンス要件を満たすことを確認する

**確認項目**:

- ビルド時間への影響

- バンドルサイズへの影響

**期待される成果物**:

- パフォーマンス検証結果
