## 実行タスク

### タスク1: コードスメル検出

**目的**: 問題のあるコードパターンを特定する

**検出対象**:

- 重複コード
- 長すぎる関数
- 不明確な命名
- 深すぎるネスト
- マジックナンバー

**期待される成果物**:

- コードスメル検出レポート

---

### タスク2: 重複排除

**目的**: 重複コードを排除する

**実行手順**:

1. 類似パターンの抽出
2. 共通関数への切り出し
3. 定数の定義

**期待される成果物**:

- リファクタリング済みコード

---

### タスク3: 命名改善

**目的**: 変数・関数・クラス名をより明確にする

**実行手順**:

1. 曖昧な命名の特定
2. ドメイン用語に沿った命名への変更
3. 一貫した命名規則の適用

**期待される成果物**:

- 命名改善済みコード

---

### タスク4: SOLID原則適用

**目的**: 設計原則に基づくコード改善を行う

**確認項目**:

- [ ] 単一責任原則（SRP）
- [ ] 開放閉鎖原則（OCP）
- [ ] リスコフの置換原則（LSP）
- [ ] インターフェース分離原則（ISP）
- [ ] 依存性逆転原則（DIP）

**期待される成果物**:

- SOLID 適用済みコード
