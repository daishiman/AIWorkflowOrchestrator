# Phase 6: エッジケース結果

## 確認したエッジケース

| ケース          | 結果  |
| --------------- | ----- |
| 空文字          | false |
| 大文字のみ      | false |
| 先頭ハイフン    | false |
| 末尾ハイフン    | false |
| `..`            | false |
| `../etc/passwd` | false |
| `skill\\..`     | false |

## 結論

- 文字列長、区切り記号、経路汚染の 3 系統で安全側に倒れている。
- 例外ではなく `false` で落とすため、呼び出し側の扱いが単純。
