# Phase 1 要件定義書 - TASK-RT-02: API Key UI Adapter Status

## 概要

Main Process の LLMAdapterStatus（ready / initializing / failed）を Renderer UI へ統合し、
ApiKeysSection にてアダプターの状態をリアルタイムで可視化する。

---

## 機能要件 (FR)

| ID    | 要件                             | 説明                                                                       |
| ----- | -------------------------------- | -------------------------------------------------------------------------- |
| FR-01 | IPC 経由の adapterStatus 取得    | Renderer から IPC を通じて各 LLM アダプターの現在ステータスを取得できる    |
| FR-02 | リアルタイムステータス変更通知   | Main Process でステータスが変化した際、Renderer へリアルタイムに通知される |
| FR-03 | AdapterStatusBadge 表示          | ApiKeysSection 内で各アダプターのステータスをバッジとして表示する          |
| FR-04 | failed 状態でのリトライボタン    | ステータスが `failed` の場合、リトライボタンを表示する                     |
| FR-05 | リトライによる再初期化           | リトライボタン押下で IPC 経由の再初期化を実行する                          |
| FR-06 | failureReason のツールチップ表示 | `failed` 状態時、失敗理由をツールチップで表示する                          |
| FR-07 | initializing 状態のスピナー      | `initializing` 状態時、ローディングスピナーを表示する                      |

## 非機能要件 (NFR)

| ID     | 要件                       | 基準                                                             |
| ------ | -------------------------- | ---------------------------------------------------------------- |
| NFR-01 | アクセシビリティ           | WCAG 2.1 AA 準拠（aria-label、キーボード操作、色以外の状態識別） |
| NFR-02 | IPC レイテンシ             | ステータス取得・通知の IPC 遅延 < 100ms                          |
| NFR-03 | リトライ時のフィードバック | リトライ実行中はローディング状態を表示する                       |
| NFR-04 | テーマ対応                 | Light / Dark テーマの両方で正しく表示される                      |
| NFR-05 | レイアウト安定性           | ステータス変更時にレイアウト崩れが発生しない                     |

## 受入基準 (AC)

| ID   | 基準                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------- |
| AC-1 | ApiKeysSection に AdapterStatusBadge が表示される                                                  |
| AC-2 | `ready` 状態で緑のバッジ、`initializing` でスピナー付き黄色バッジ、`failed` で赤バッジが表示される |
| AC-3 | Main Process でステータス変更時、UI がリアルタイムに更新される                                     |
| AC-4 | `failed` 状態でリトライボタンが表示される                                                          |
| AC-5 | リトライボタン押下で再初期化が実行され、ステータスが更新される                                     |
| AC-6 | `failed` 状態のバッジホバー時に failureReason がツールチップで表示される                           |
| AC-7 | WCAG 2.1 AA に準拠したアクセシビリティが確保される                                                 |
| AC-8 | Light / Dark テーマの両方で正しく表示される                                                        |
| AC-9 | ステータス変更時にレイアウト崩れが発生しない                                                       |
