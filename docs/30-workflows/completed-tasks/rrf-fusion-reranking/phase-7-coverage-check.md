## 目的

Phase 6の拡充結果を検証し、カバレッジ基準を満たすまでゲートとして確認する。

## 背景

リファクタリングフェーズに進む前に、テストが十分であることを検証する必要がある。カバレッジが不足している場合はPhase 6へ戻る。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ確認

**目的**: ユニットテストのカバレッジが基準を満たしているか確認する

**実行手順**:

1. カバレッジ測定を実行:

   ```bash
   pnpm --filter @repo/shared test:coverage -- --testPathPattern="fusion|reranking"
   ```

2. 以下の基準を確認:

| 指標              | 最低基準 | 推奨基準 | 現在値 | 判定 |
| ----------------- | -------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | 90%      |        |      |
| Branch Coverage   | 60%      | 70%      |        |      |
| Function Coverage | 80%      | 90%      |        |      |

3. 未達の場合はPhase 6へ戻る

**期待される成果物**:

- `outputs/phase-7/unit-test-coverage.md` - ユニットテストカバレッジ結果

---

### タスク2: 結合テストカバレッジ確認

**目的**: 結合テストのカバレッジが基準を満たしているか確認する

**実行手順**:

1. 結合テストを実行:

   ```bash
   pnpm --filter @repo/shared test -- --testPathPattern="integration"
   ```

2. 以下の基準を確認:

| 指標                         | 目標 | 現在値 | 判定 |
| ---------------------------- | ---- | ------ | ---- |
| APIエンドポイント            | 100% |        |      |
| モジュール間インターフェース | 100% |        |      |
| 正常系シナリオ               | 100% |        |      |
| 異常系シナリオ               | 80%+ |        |      |
| 外部連携ポイント             | 100% |        |      |

**期待される成果物**:

- `outputs/phase-7/integration-test-coverage.md` - 結合テストカバレッジ結果

---

### タスク3: 統合テスト実行確認

**目的**: 統合テストが全て成功しているか確認する

**実行手順**:

1. 統合テストを実行:

   ```bash
   pnpm --filter @repo/shared test -- --testPathPattern="fusion-reranking.integration"
   ```

2. 全テストが成功していることを確認

3. 失敗がある場合は原因を特定し、Phase 5またはPhase 6へ戻る

**期待される成果物**:

- `outputs/phase-7/integration-test-results.md` - 統合テスト実行結果

---

### タスク4: カバレッジゲート判定

**目的**: カバレッジ基準を満たしているか最終判定を行う

**実行手順**:

1. 全カバレッジ結果を集約する
2. 以下の基準で判定する:

| 判定 | 条件                             | 次のアクション |
| ---- | -------------------------------- | -------------- |
| PASS | 全基準を満たしている             | Phase 8へ進行  |
| FAIL | ユニットテストカバレッジ基準未達 | Phase 6へ戻る  |
| FAIL | 結合テストカバレッジ基準未達     | Phase 6へ戻る  |
| FAIL | 統合テスト失敗あり               | Phase 5へ戻る  |

**期待される成果物**:

- `outputs/phase-7/coverage-gate-result.md` - カバレッジゲート判定結果
