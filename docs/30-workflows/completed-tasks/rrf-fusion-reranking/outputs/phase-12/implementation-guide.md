## ガイド概要抜粋

### RRF Fusionとは？（中学生向け説明）

```
想像してください。あなたは「面白い映画」を探しています。

3人の友達に聞いてみました：
- Aさん（映画評論家）: 「この順番がおすすめ！」
- Bさん（友達の好み知ってる人）: 「君ならこれが好きそう」
- Cさん（映画データベース）: 「評価が高い順はこれ」

3つのランキングをどうやって1つにまとめますか？
→ RRF Fusion は「順位」を使ってうまく合体させる方法です！
```
