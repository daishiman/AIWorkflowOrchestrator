**目的**: PRを作成する前に必要な準備が完了していることを確認

**実行手順**:

2. Lint/型チェックがパスしていることを確認

**チェックリスト**:

- [ ] `pnpm lint` 成功

- [ ] `pnpm --filter @repo/desktop test` 成功

### タスク2: PR本文作成

**目的**: レビュアーが理解しやすいPR説明文を作成

**実行手順**:

1. 変更概要の記載
2. 実装内容の詳細記載
3. テスト結果のサマリー記載
4. 関連Issue/PRのリンク

**PR本文テンプレート**:

```markdown
## 概要

LLMストリーミングレスポンス機能を実装しました。

## 変更内容

- 4プロバイダー（OpenAI, Anthropic, Google, xAI）のストリーミング対応
- IPCハンドラーの実装（llm:stream-chat, llm:stream-cancel）
- UIコンポーネントのストリーミング表示対応
- キャンセル機能の実装

## テスト結果

- ユニットテスト: 全テスト成功
- 統合テスト: 全テスト成功
- E2Eテスト: 全テスト成功
- 手動テスト: 全プロバイダーで動作確認済み

## カバレッジ

- Line: XX%
- Branch: XX%
- Function: XX%

## 関連Issue

- closes #465

## レビュー観点

- [ ] アーキテクチャ（Template Methodパターン）
- [ ] エラーハンドリング
- [ ] 型安全性
- [ ] パフォーマンス
```

---

### タスク3: PR作成

**目的**: GitHub上でPRを作成

**実行手順**:

1. `gh pr create`コマンドでPRを作成
2. 適切なラベルを付与
3. レビュアーをアサイン
4. PRリンクを記録

**実行コマンド**:

```bash
gh pr create \
  --title "feat: LLMストリーミングレスポンス機能の実装" \
  --body-file outputs/phase-13/pr-body.md \
  --label "feature,llm,streaming" \
  --assignee @me
```
