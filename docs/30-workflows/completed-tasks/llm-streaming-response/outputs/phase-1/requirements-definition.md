## 1. 機能要件（FR）

### FR-001: ストリーミングチャット送信

| 項目     | 内容                                                                      |

| 要件ID   | FR-001                                                                    |
| 優先度   | 高                                                                        |
| 説明     | ユーザーがメッセージを送信した際、LLMからの応答をストリーミングで受信する |

| 出力     | StreamChunk（リアルタイムで連続送信）                                     |
| 依存関係 | IPC通信基盤、LLMアダプター                                                |

## 3. IPC通信要件

### 3.1 使用チャンネル

| チャンネル        | 方式    | 方向            | 用途                     |
| ----------------- | ------- | --------------- | ------------------------ |
| llm:stream-chat   | invoke  | Renderer → Main | ストリーミング開始       |
| llm:stream-chunk  | send/on | Main → Renderer | チャンク送信             |
| llm:stream-end    | send/on | Main → Renderer | ストリーミング完了       |
| llm:stream-error  | send/on | Main → Renderer | エラー通知               |
| llm:stream-cancel | invoke  | Renderer → Main | ストリーミングキャンセル |

### 3.2 データフロー

```
Renderer (UI)
    │
    ▼ llm:stream-chat (invoke)
Main Process
    │
    ▼ LLMAdapterFactory.getAdapter()
LLM Adapter (OpenAI/Anthropic/Google/xAI)
    │
    ▼ adapter.streamChat()
Provider API (SSE)
    │
    ▼ StreamChunk (continuous)
Main Process
    │
    ▼ llm:stream-chunk (send)
Renderer (UI)
    │
    ▼ UIに即時反映
```

### 3.3 イベント種別

| イベント種別 | 型定義                                        | 説明             |
| ------------ | --------------------------------------------- | ---------------- |
| chunk        | `{ type: "content"; content: string }`        | テキストチャンク |
| done         | `{ type: "done"; response: LLMChatResponse }` | 完了イベント     |
| error        | `{ type: "error"; error: LLMError }`          | エラーイベント   |

## 4. エラーハンドリング要件

### 4.1 対応エラー

| エラー種別       | エラーコード        | 対処方法                         | リトライ |
| ---------------- | ------------------- | -------------------------------- | -------- |
| ネットワーク切断 | NETWORK_ERROR       | エラー表示、途中応答保持         | 可能     |
| タイムアウト     | TIMEOUT             | エラー表示、リトライボタン表示   | 可能     |
| レート制限       | RATE_LIMIT          | 待機時間表示、自動リトライ       | 可能     |
| APIキー無効      | API_KEY_INVALID     | エラー表示、設定画面への誘導     | 不可     |
| コンテンツ制限   | CONTENT_FILTER      | フィルタリングメッセージ表示     | 不可     |
| サービス停止     | SERVICE_UNAVAILABLE | エラー表示、ステータス確認を促す | 可能     |

### 4.2 エラー発生時の挙動

1. ストリーミング即時停止
2. 途中までの応答をUI上に保持
3. エラーメッセージをユーザーフレンドリーな形式で表示
4. リトライ可能な場合はリトライボタンを表示
5. isStreamingフラグを解除
