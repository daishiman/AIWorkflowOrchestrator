## 3. 技術的制約

### 3.1 パフォーマンス制約

| 制約                       | 値        | 理由                     |
| -------------------------- | --------- | ------------------------ |
| 最初のチャンク表示時間     | ≤ 2秒     | UX要件                   |
| UI更新レート               | 60FPS維持 | スムーズなアニメーション |
| メモリ増加許容範囲         | ±10%      | メモリリーク防止         |
| ストリーミングタイムアウト | 60秒      | 長文応答対応             |

### 3.2 互換性制約

| 制約         | 説明                                |
| ------------ | ----------------------------------- |
| Electron IPC | contextBridge経由のみ許可           |
| セキュリティ | ホワイトリストチャンネルのみ許可    |
| 型安全性     | Zodスキーマによるバリデーション必須 |

### 3.3 API制約

| プロバイダー | ストリーミング形式 | 特記事項                           |
| ------------ | ------------------ | ---------------------------------- |
| OpenAI       | SSE                | 標準的なSSE実装                    |
| Anthropic    | SSE (Event型)      | event_typeフィールドでイベント判別 |
| Google       | SSE (?alt=sse)     | URLパラメータでSSE有効化           |
| xAI          | SSE (OpenAI互換)   | OpenAIと同じ形式                   |
