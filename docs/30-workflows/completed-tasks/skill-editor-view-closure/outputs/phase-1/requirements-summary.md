## 概要

TASK-UI-05A（SkillEditorView）の Phase 11/12 で発見された残課題7件（UT-UI-05A-001 から 007）について、機能要件・非機能要件・受け入れ基準を定義した。各課題は WCAG 2.1 AA 準拠と Apple HIG 準拠を必須要件として含む。

---

## 課題一覧と機能要件

### UT-UI-05A-001: FileTree キーボードナビゲーション

| 項目       | 内容                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| 課題概要   | `FileTreeNode` に `tabIndex` と `onKeyDown` が存在せず WAI-ARIA Tree Pattern 1.2 未準拠 |
| 機能要件数 | 6件（F-001-1 から F-001-6）                                                             |

**主要機能要件**:

- ArrowDown/ArrowUp で次/前のノードにフォーカス移動
- ArrowRight でディレクトリ展開、ArrowLeft でディレクトリ折り畳み
- Enter/Space でファイル選択、Escape でフォーカスをツリールートに戻す
- Home/End で最初/最後の表示ノードへ移動

**WCAG準拠要件**: 2.1.1（キーボード）、4.1.2（名前・役割・値）、2.4.7（フォーカス可視）

**受け入れ基準**: Tab キーでフォーカス進入、Arrow キーでノード移動、フォーカスリング表示、スクリーンリーダー対応

---

### UT-UI-05A-002: モバイルドロワー

| 項目       | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 課題概要   | SkillEditorView が固定2ペインレイアウトで768px未満でレスポンシブ対応なし |
| 機能要件数 | 6件（F-002-1 から F-002-6）                                              |

**主要機能要件**:

- 画面幅768px未満でFileTreePanelをドロワーとして表示
- ハンバーガーボタンでトグル、オーバーレイクリックで閉じる
- ドロワーは画面左からスライドイン（transform: translateX）
- ファイル選択後にドロワーが自動的に閉じる

**WCAG準拠要件**: 2.1.1（キーボード）、4.1.3（ステータスメッセージ）、1.4.13（ホバーコンテンツ）

**受け入れ基準**: ドロワーモード切替、250msアニメーション、Escape閉じ、768px以上で2ペイン復帰

---

### UT-UI-05A-003: Cmd/Ctrl+S 保存ショートカット

| 項目       | 内容                                                      |
| ---------- | --------------------------------------------------------- |
| 課題概要   | `handleSave` は実装済みだがキーボードショートカット未対応 |
| 機能要件数 | 5件（F-003-1 から F-003-5）                               |

**主要機能要件**:

- Cmd+S（macOS）/ Ctrl+S（Windows/Linux）でファイル保存
- isReadOnly=true のとき無効、ブラウザデフォルト保存ダイアログをキャンセル
- 保存中の二重送信防止、ファイル未選択時は無効

**WCAG準拠要件**: 2.1.4（文字キーショートカット — 修飾キーとの組み合わせで準拠済み）

**受け入れ基準**: 両OS対応、ブラウザデフォルト抑制、isReadOnly/isSaving/未選択時の無効化

---

### UT-UI-05A-004: 保存成功 Toast 通知

| 項目       | 内容                                                 |
| ---------- | ---------------------------------------------------- |
| 課題概要   | `handleSave` 成功後にフィードバックなし、Toast未実装 |
| 機能要件数 | 6件（F-004-1 から F-004-6）                          |

**主要機能要件**:

- 保存成功時に「保存しました」Toast を2500ms表示（画面右下）
- 再保存時に既存Toastリセットしてカウント再開
- 手動閉じ（xボタン）対応
- 保存失敗時はエラーToast（自動消去なし）
- `useToast` カスタムフックで状態管理

**WCAG準拠要件**: 4.1.3（ステータスメッセージ — 成功: role="status"、エラー: role="alert"）

**受け入れ基準**: 成功/エラーToast表示、2500ms自動消去、手動閉じ、スクリーンリーダー読み上げ

---

### UT-UI-05A-005: 読み取り専用表示強化

| 項目       | 内容                                                                |
| ---------- | ------------------------------------------------------------------- |
| 課題概要   | isReadOnly の視覚的フィードバックが不十分（ボタングレーアウトのみ） |
| 機能要件数 | 6件（F-005-1 から F-005-6）                                         |

**主要機能要件**:

- ファイル名隣にロックアイコン表示
- エディター上部に「読み取り専用 -- 編集できません」バナー表示
- ツールバーの保存・バックアップボタンを非表示（グレーアウトでなく）
- テキスト選択（コピー）は許可
- エディターに readOnly 属性設定

**WCAG準拠要件**: 1.3.1（情報と関係 — aria-readonly="true"）、1.4.1（色の使用 — アイコン+テキスト併用）

**受け入れ基準**: ロックアイコン・バナー表示、ボタン非表示、aria-readonly設定、コピー許可

---

### UT-UI-05A-006: ナビゲーション導線配線

| 項目       | 内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 課題概要   | AppDock/SkillCenterからSkillEditorViewへの遷移フローが未実装 |
| 機能要件数 | 6件（F-006-1 から F-006-6）                                  |

**主要機能要件**:

- AppDock -> SkillCenter -> SkillEditorView の遷移フロー
- SkillEditorView の閉じるボタンで SkillCenter に戻る
- ViewType型に 'skill-editor' を追加、Zustand storeで状態管理
- 未保存変更がある場合に UnsavedChangesDialog を表示
- 編集対象の skillName を store または props で渡す

**WCAG準拠要件**: 2.4.2（ページタイトル — 遷移後のフォーカス管理）

**受け入れ基準**: AppDockナビゲーション項目、SkillCenter編集遷移、閉じるボタン、ViewType追加、currentSkillName保持

---

### UT-UI-05A-007: マイクロアニメーション

| 項目       | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| 課題概要   | FileTreeNodeの色変化のみでパネル切替・ファイル選択時のトランジションなし |
| 機能要件数 | 5件（F-007-1 から F-007-5）                                              |

**主要機能要件**:

- ファイル選択時に150msフェードイン
- ディレクトリ展開/折り畳み時に200ms高さアニメーション
- エディターコンテンツ切り替え時に150ms opacityフェード
- ツールバーボタンホバー時に150msカラートランジション
- `prefers-reduced-motion` を尊重し無効化

**WCAG準拠要件**: 2.3.3（インタラクションによるアニメーション — prefers-reduced-motion: reduce で全無効化）

**受け入れ基準**: 各アニメーション動作、prefers-reduced-motion対応
