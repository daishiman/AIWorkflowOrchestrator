## MINOR 指摘一覧（M-001 から M-007）

### M-001: MobileDrawer フォーカストラップ未定義

| 項目     | 内容                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 対象課題 | UT-UI-05A-002                                                                          |
| 優先度   | 高（必須）                                                                             |
| 指摘内容 | ドロワー内でのフォーカストラップ要件が未定義。WCAG 2.4.11 準拠のため必須               |
| 対応方針 | MobileDrawer に useFocusTrap hook を追加、または focus-trap-react ライブラリを検討する |

---

### M-002: Toast 同時表示上限未定義

| 項目     | 内容                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 対象課題 | UT-UI-05A-004                                                            |
| 優先度   | 中                                                                       |
| 指摘内容 | 短時間に複数回保存した場合の Toast UI 動作が未明確                       |
| 対応方針 | useToast で MAX_TOASTS = 3 の上限を設け、超過時は古い Toast から削除する |

---

### M-003: AppDock 既存実装の事前確認が必要

| 項目     | 内容                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------- |
| 対象課題 | UT-UI-05A-006                                                                                         |
| 優先度   | 中                                                                                                    |
| 指摘内容 | AppDock の既存実装（ViewType 一覧・UI構造）が未確認。存在しない場合や異なる構造の場合に設計修正が必要 |
| 対応方針 | Phase 5 実装前に `grep -rn "ViewType" apps/desktop/src/` で既存実装を確認する                         |

---

### M-004: Toast P47 variantStyles エクスポートパターン

| 項目     | 内容                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 対象課題 | 共通（UT-UI-05A-004）                                                                         |
| 優先度   | 低                                                                                            |
| 指摘内容 | P47 のパターンに従い、Toast の variant CSS クラスをテスト可能な形でエクスポートする必要がある |
| 対応方針 | `variantStyles: Record<ToastVariant, string>` をコンポーネントから export する                |

---

### M-005: flatNodes の useMemo キャッシュ明示

| 項目     | 内容                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 対象課題 | UT-UI-05A-001                                                                                  |
| 優先度   | 中                                                                                             |
| 指摘内容 | useKeyboardNavigation の flatNodes 計算に useMemo が必要だが、設計書に明示的な実装指示がない   |
| 対応方針 | `useMemo(fn, [fileTree, expandedDirs])` でキャッシュし、100+ノード時のパフォーマンス劣化を防止 |

---

### M-006: モバイル->デスクトップ切り替え時のドロワー状態リセット

| 項目     | 内容                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------- |
| 対象課題 | UT-UI-05A-002                                                                                           |
| 優先度   | 中                                                                                                      |
| 指摘内容 | isMobile が false に変わったとき isDrawerOpen をリセットする設計が未記載                                |
| 対応方針 | SkillEditorView に `useEffect(() => { if (!isMobile) setIsDrawerOpen(false); }, [isMobile])` を追加する |

---

### M-007: Toast ID 生成に crypto.randomUUID() を使用

| 項目     | 内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| 対象課題 | UT-UI-05A-004                                                         |
| 優先度   | 低                                                                    |
| 指摘内容 | useToast の Toast ID 生成方法が未定義。Math.random() は衝突リスクあり |
| 対応方針 | `crypto.randomUUID()` を使用する                                      |
