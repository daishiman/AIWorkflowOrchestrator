## アーキテクチャ観点

### Lane 分離

| チェック項目                                                                   | 判定 | 根拠                                        |
| ------------------------------------------------------------------------------ | ---- | ------------------------------------------- |
| Mainline Lane（ChatView）と Review Harness Lane（ChatPanel）が分離されているか | PASS | Lane 設計（3 Lane）に明記                   |

### 責務境界

| チェック項目                                        | 判定           | 根拠                                           |
| --------------------------------------------------- | -------------- | ---------------------------------------------- |
| ChatPanel が chatSlice に直接 dispatch しない設計か | DESIGN-PENDING | GAP-01 解消時に配線するが、dispatch は許容する |
| handler の副作用が ChatPanel スコープ外に漏れないか | PASS（設計）   | useCallback のスコープで管理                   |
| computed state が ChatPanel 内で完結しているか      | PASS（設計）   | refactor-boundaries.md Candidate 1 参照        |

### 依存性逆転（DIP）

| チェック項目                                                      | 判定         | 根拠                                     |
| ----------------------------------------------------------------- | ------------ | ---------------------------------------- |
| handler の実装が interface に依存しているか                       | PASS（設計） | IPC channel 名は定数（IPC_CHANNELS）経由 |
| 子コンポーネントとのインターフェースが Props 型で定義されているか | PASS         | 子コンポーネント Props は既存定義を使用  |
| IPC handler が具象クラスに依存していないか                        | PASS（設計） | P61 対策として設計書に明記               |
