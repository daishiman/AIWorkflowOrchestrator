# Phase 1 成果物: 受け入れ基準

| ID    | 条件                                                                                               |
| ----- | -------------------------------------------------------------------------------------------------- |
| AC-01 | h1 が「ホーム」で表示される                                                                        |
| AC-02 | 表示名ありのとき、時刻に応じた挨拶文が表示される                                                   |
| AC-03 | 表示名なしでも自然な挨拶文が表示される                                                             |
| AC-04 | サジェスチョンは常時 2〜3 件に収まる                                                               |
| AC-05 | サジェスチョン CTA は `workspace` / `skillCenter` / `agent` / `historySearch` の既存遷移だけを使う |
| AC-06 | タイムラインは最大 5 件までで、6 件目以降は「もっと見る」先へ委譲される                            |
| AC-07 | `activityFeed=[]` では歓迎型 EmptyState が表示され、統計カードは表示されない                       |
| AC-08 | `isLoading=true` でもレイアウト崩れなく loading 表示が維持される                                   |
| AC-09 | CTA は Tab, Enter, Space で操作可能である                                                          |
| AC-10 | テスト設計上、既存 `DashboardView.test.tsx` の旧統計カード期待値は削除または更新される             |
