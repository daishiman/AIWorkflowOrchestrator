## 実行タスク

### Task 10-1: 受入条件（AC）の最終確認

| AC   | 条件                                                                              | 確認方法                       | 判定 |
| ---- | --------------------------------------------------------------------------------- | ------------------------------ | ---- |
| AC-1 | `phase-spec-template.md` に Task/Step 分離ガイドラインが追加されている            | TC-01, TC-04 の結果確認        | -    |
| AC-2 | Phase 11 に docs-only / spec_created の evidence ルールが明記されている           | TC-02, TC-09 の結果確認        | -    |
| AC-3 | Phase 12 に root evidence と「実行タスク」/「検証ログ」の分離構造が定義されている | TC-01, TC-03, TC-10 の結果確認 | -    |
| AC-4 | Handlebars 条件分岐が正しく動作する                                               | TC-05, TC-08 の結果確認        | -    |
| AC-5 | 改修済みテンプレートが既存フォーマットと互換性を保っている                        | TC-06, TC-11 の結果            | -    |

### Task 10-2: ブロッカー判定

| 判定分類 | 基準                                  | 対応                           |
| -------- | ------------------------------------- | ------------------------------ |
| CRITICAL | AC が未達成 / Handlebars 構文エラー   | Phase 5/8 へ差し戻し           |
| MAJOR    | 可読性に重大な問題 / 互換性リスクあり | Phase 8 へ差し戻し             |
| MINOR    | 軽微な記述改善 / 将来の拡張提案       | 未タスク化して Phase 11 へ進む |
| PASS     | 全 AC 達成・ブロッカーなし            | Phase 11 へ進む                |

### Task 10-3: MINOR 指摘の未タスク化

Phase 10 で発見した MINOR 指摘事項を `unassigned-task/` へ未タスクとして記録する（0件でも記録）。

### Task 10-4: Phase 11 進行可否の判定

- **PASS**: CRITICAL / MAJOR が 0 件 → Phase 11 へ進む
- **FAIL**: CRITICAL / MAJOR が 1 件以上 → 対応 Phase へ差し戻し
