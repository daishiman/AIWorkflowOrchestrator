## 目的

Phase 5 で実装したテンプレート改修を整理し、Handlebars 条件分岐の複雑さを最小限に保ち、可読性を向上させる。TDD Refactor フェーズ。

## 実行タスク

### Task 8-1: Handlebars 条件分岐の簡略化確認

実装した Handlebars 条件分岐を見直し、以下の観点でリファクタリングを検討する。

**Before/After 記録フォーマット**:

| 対象                   | Before（改修前）         | After（改修後）              | 理由                  |
| ---------------------- | ------------------------ | ---------------------------- | --------------------- |
| NON_VISUAL 分岐        | （実装時の差分から記録） | （リファクタリング後の内容） | 可読性向上 / 冗長削減 |
| Task/Step ガイドライン | （実装時の差分から記録） | （リファクタリング後の内容） | コメントの明確化      |

**リファクタリング方針**:

- 条件分岐は最小限に留める（ネストは 1 段まで）
- `{{#if}}` ブロックの前後にコメントで判断基準を明記する
- 重複する記述は共通セクションへ抽出する

### Task 8-2: コメントの充実化

テンプレートの可読性向上のため、以下の箇所にコメントを追加する:

```handlebars
{{! Task/Step 分離ガイドライン
  このセクションは「計画（plan）」の記述場所。
  実行結果・判定根拠は outputs/ 配下の成果物ファイルに記録する。
  未来形・命令形 → 実行タスク（仕様書本文）
  過去形・完了形 → 検証ログ（成果物ファイル）
}}

{{! VISUAL / NON_VISUAL 判定基準
  NON_VISUAL: 表示層変更なし（テンプレート、型定義、バックエンドのみ）
  VISUAL: UI コンポーネント・スタイル・レイアウト変更あり
  判断に迷う場合: VISUAL 扱い（より厳格な証跡収集を適用）
}}
```

### Task 8-3: 重複記述の排除
