## 目的

テスト（TC-001〜TC-062）が受け入れ基準（AC-001〜AC-011）を十分にカバーしていることを確認し、カバレッジレポートを作成する。

## カバレッジ目標

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

カバレッジ未達成の場合は Phase 6（テスト拡充）へ戻る。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 受け入れ基準カバレッジマッピング

**目的**: 各受け入れ基準がテストケースで十分にカバーされているか確認する

**実行手順**:

1. AC-001〜AC-011 と TC-001〜TC-062 のマッピングテーブルを作成する：

| 基準ID | 基準概要                                           | 対応テストケース                       | カバレッジ |
| ------ | -------------------------------------------------- | -------------------------------------- | ---------- |
| AC-001 | complete-skill が構造検証をパス                    | TC-001〜TC-012, TC-025                 |            |
| AC-002 | complete-skill/SKILL.md が YAML パース可能         | TC-002, TC-038〜TC-040, TC-027         |            |
| AC-003 | agents/\*.md がフォーマット準拠                    | TC-005〜TC-006, TC-029, TC-043〜TC-047 |            |
| AC-004 | schemas/\*.json が JSON Schema 準拠                | TC-011〜TC-012, TC-030                 |            |
| AC-005 | minimal-skill が SKILL.md のみで検証パス           | TC-013〜TC-015, TC-041                 |            |
| AC-006 | invalid-skill が適切にエラーを返す                 | TC-020〜TC-021, TC-026, TC-028, TC-042 |            |
| AC-007 | orchestration-skill の YAML がパース可能           | TC-022〜TC-024, TC-054〜TC-058         |            |
| AC-008 | run-all-validations.js が統合実行可能              | TC-031〜TC-032, TC-052                 |            |
| AC-009 | 検証結果が JSON 形式                               | TC-048〜TC-052                         |            |
| AC-010 | skill-fixture-runner/SKILL.md が正しいフォーマット | TC-033〜TC-034                         |            |
| AC-011 | Vitest テストが全件パス                            | 全テスト実行結果                       |            |

2. 未カバーの受け入れ基準があれば、追加テストを提案する
3. `outputs/phase-07/coverage-report.md` に結果を出力する

**期待される成果物**:

- `outputs/phase-07/coverage-report.md`

2. 検証スクリプトのカバレッジを確認する：

| スクリプト                  | テストケース数 | カバレッジ率 |
| --------------------------- | -------------- | ------------ |
| validate-skill-structure.js |                |              |
| validate-skill-md.js        |                |              |
| validate-agents.js          |                |              |
| validate-schemas.js         |                |              |
| run-all-validations.js      |                |              |

3. `outputs/phase-07/coverage-report.md` に追記する

**期待される成果物**:
