### タスク3: PASS/FAIL 判定

**目的**: 最終レビューの判定を行う

**実行手順**:

1. タスク1〜2 の結果を総合する
2. 以下の判定基準に基づき判定を決定する：

| 判定     | 条件                     | 対応                                     |
| -------- | ------------------------ | ---------------------------------------- |
| PASS     | 全レビュー観点で問題なし | Phase 11（手動テスト）へ進行             |
| MINOR    | 軽微な指摘あり           | 未完了タスクとして記録後 Phase 11 へ進行 |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻り先を決定             |
| CRITICAL | 致命的な問題あり         | Phase 1 へ戻りユーザーと要件を再確認     |

3. MAJOR/CRITICAL 判定時の戻り先決定基準：

| 問題の種類       | 戻り先                      |
| ---------------- | --------------------------- |
| 要件の問題       | Phase 1（要件定義）         |
| 設計の問題       | Phase 2（設計）             |
| テスト設計の問題 | Phase 4（テスト作成）       |
| 実装の問題       | Phase 5（実装）             |
| テスト拡充の問題 | Phase 6（テスト拡充）       |
| カバレッジ未達   | Phase 7（カバレッジ確認）   |
| コード品質の問題 | Phase 8（リファクタリング） |

4. MINOR 判定時のフロー：

```
レビューでMINOR判定
    ↓
指摘事項を分析
    ↓
未完了タスク指示書を作成
    ↓
docs/30-workflows/unassigned-task/ に配置
    ↓
Phase 11へ進行
```

5. `outputs/phase-10/final-review-result.md` に結果を出力する

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`
