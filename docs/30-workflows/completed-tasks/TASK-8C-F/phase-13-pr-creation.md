## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 差分確認

**目的**: コミット対象の変更を確認する

**実行手順**:

1. 変更ファイル一覧を確認する：

   ```bash
   git status
   git diff --stat
   ```

2. 以下のカテゴリに分類する：

| カテゴリ             | 対象ファイル                                                        |
| -------------------- | ------------------------------------------------------------------- |
| フィクスチャファイル | `apps/desktop/src/__tests__/__fixtures__/skill-creator/**`          |
| テストファイル       | `apps/desktop/src/__tests__/fixtures/skill-creator.fixture.test.ts` |
| 検証スクリプト       | `.claude/skills/skill-fixture-runner/scripts/**`                    |
| テスト実行スキル     | `.claude/skills/skill-fixture-runner/SKILL.md` etc.                 |
| タスク仕様書         | `docs/30-workflows/completed-tasks/TASK-8C-F/**`                    |

3. コミット対象外のファイルがないか確認する

**期待される成果物**:

- 変更ファイル一覧

---

### タスク2: コミット作成

**目的**: 適切なコミットメッセージでコミットを作成する

**実行手順**:

1. コミットメッセージのフォーマット：

   ```
   test(skill-creator): テスト用フィクスチャ & 実行スキル作成 (TASK-8C-F)

   - complete-skill: 全ディレクトリ構成フィクスチャ（SKILL.md + agents/ + references/ + scripts/ + assets/ + schemas/）
   - minimal-skill: SKILL.md のみの最小構成フィクスチャ
   - partial-skill: SKILL.md + agents/ の部分構成フィクスチャ
   - invalid-skill: 不正 YAML の検証エラー用フィクスチャ
   - orchestration-skill: chain/parallel 設定付きフィクスチャ
   - skill-fixture-runner: 検証スクリプト統合実行スキル
   - フィクスチャ検証テスト（TC-001〜TC-062）
   ```

2. ユーザーの許可を得てからコミットする

**期待される成果物**:

- Git コミット

---

### タスク3: PR 作成

**目的**: GitHub にプルリクエストを作成する

**実行手順**:

1. **ユーザーの明示的な許可を得る**
2. `/ai:diff-to-pr` コマンドを使用して PR を作成する
3. PR の概要：
   - **タイトル**: `test(skill-creator): テスト用フィクスチャ & 実行スキル作成 (TASK-8C-F)`
   - **本文**: フィクスチャの説明、テスト一覧、skill-fixture-runner スキルの説明

**期待される成果物**:

- GitHub プルリクエスト
- `outputs/phase-13/pr-info.md`（PR URL、ブランチ名、マージ先）
