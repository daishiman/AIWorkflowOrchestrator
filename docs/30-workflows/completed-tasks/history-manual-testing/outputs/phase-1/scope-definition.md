### 1.2 含まないもの（Out of Scope）

| 項目                     | 理由                                   |
| ------------------------ | -------------------------------------- |
| 自動テストの追加         | 既存テスト（94.43%カバレッジ）で十分   |
| パフォーマンステスト     | 将来タスクとして切り出し               |
| ユニットテストの新規作成 | 既存テストが十分なカバレッジを達成済み |
| E2Eテストの追加          | 手動テストで同等の検証が可能           |
| ブラウザ互換性テスト     | Electronアプリのため不要               |
| 多言語テスト             | 現時点では日本語のみ対応               |
| セキュリティテスト       | 別タスク（脆弱性スキャン）で実施       |

## 2. テスト優先度

### 2.1 優先度定義

| 優先度 | 定義                      | 対象テスト                     |
| ------ | ------------------------- | ------------------------------ |
| P1     | クリティカル - 必ずテスト | TC-001, TC-004, TC-010         |
| P2     | 重要 - 基本的にテスト     | TC-002, TC-005, TC-009, TC-201 |
| P3     | 通常 - 時間があればテスト | その他全てのケース             |

### 2.2 テスト実行順序

1. **機能テスト（正常系）**: TC-001 → TC-011
2. **エラーハンドリングテスト**: TC-101 → TC-104
3. **アクセシビリティテスト**: TC-201 → TC-204
4. **レスポンシブテスト**: 最後に実施
