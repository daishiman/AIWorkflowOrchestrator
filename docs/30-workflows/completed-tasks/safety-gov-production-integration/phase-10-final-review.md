## 目的

全受入条件（AC-1〜AC-6）を最終確認し、Phase 11 手動テストに進めるか判定する。
Phase 3 と同様に PASS / MINOR / MAJOR の判定を行う。

## 実行タスク

- AC-1〜AC-6 をコード・自動テスト・手動確認予定の3軸で再点検する
- security 契約と payload 最小化を再確認し、例外があれば差し戻す
- ゲート判定と未タスク化要否を確定する
- Phase 11 に引き継ぐ manual check 項目を固定する

| AC   | 条件                                                             | 検証方法                    | 判定 |
| ---- | ---------------------------------------------------------------- | --------------------------- | ---- |
| AC-1 | 3ハンドラが `registerAllIpcHandlers()` から登録されている        | コードレビュー + テスト結果 | -    |
| AC-2 | `DefaultApprovalGate` が DI で `registerApprovalHandlers` に注入 | コードレビュー + テスト結果 | -    |

| AC-4 | approval:request push が Renderer で受信される                   | 統合テスト結果              | -    |
| AC-5 | セッション終了時に `revokeAll(sessionId)` が呼ばれる             | テスト結果                  | -    |
| AC-6 | 既存 85 テスト + 新規統合テストが全 PASS                         | テスト実行結果              | -    |

### 2. ゲート判定

| 判定              | 説明                   | 対応                           |
| ----------------- | ---------------------- | ------------------------------ |
| **PASS**          | 全 AC が満たされている | Phase 11 へ進む                |
| **MINOR**         | 軽微な問題あり         | 未タスク化して Phase 11 へ進む |
| **MAJOR**         | AC 未達がある          | Phase 5/6/8 へ戻る             |
| **MAJOR（設計）** | 設計に問題             | Phase 2 へ戻る                 |
| **CRITICAL**      | 根本的な問題           | Phase 1 へ戻る                 |
