## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 型チェック

**目的**: TypeScript型チェックをパスすることを確認する

**実行手順**:

1. 型チェックコマンドを実行
2. エラーがないことを確認
3. エラーがあれば修正

**期待される成果物**:

- 型チェック結果

```bash
# 型チェックコマンド
pnpm --filter @repo/desktop typecheck
```

---

### タスク2: Lintチェック

**目的**: ESLintルールに違反していないことを確認する

**実行手順**:

1. Lintコマンドを実行
2. エラー・警告がないことを確認
3. 問題があれば修正

**期待される成果物**:

- Lint結果

```bash
# Lintコマンド
pnpm --filter @repo/desktop lint
```

---

### タスク3: セキュリティチェック

**目的**: セキュリティ上の問題がないことを確認する

**実行手順**:

1. 依存パッケージの脆弱性チェック
2. コードのセキュリティパターン確認
3. 問題があれば対応

**期待される成果物**:

- セキュリティチェック結果

```bash
# 脆弱性チェックコマンド
pnpm audit
```

#### セキュリティチェックリスト

| チェック項目                           | 結果 | 備考 |
| -------------------------------------- | ---- | ---- |
| 依存パッケージに重大な脆弱性がない     |      |      |
| ユーザー入力のサニタイズ               |      |      |
| 危険コマンドパターンの網羅性           |      |      |
| 保護パスパターンの網羅性               |      |      |
| エラーメッセージに機密情報が含まれない |      |      |

---

### タスク4: パフォーマンスチェック

**目的**: パフォーマンス要件（Hook処理10ms以内）を満たすことを確認する

**実行手順**:

1. パフォーマンステストを実行
2. 処理時間を計測
3. 要件を満たすことを確認

**期待される成果物**:

- パフォーマンス測定結果

#### パフォーマンス基準

| 処理                 | 目標   | 測定結果 |
| -------------------- | ------ | -------- |
| PreToolUse Hook処理  | < 10ms |          |
| PostToolUse Hook処理 | < 10ms |          |
| categorizeError      | < 1ms  |          |
| isRetryable          | < 1ms  |          |

---

### タスク5: コードフォーマット

**目的**: コードフォーマットが統一されていることを確認する

**実行手順**:

1. Prettierでフォーマット
2. 差分がないことを確認

**期待される成果物**:

- フォーマット済みコード

```bash
# フォーマットコマンド
pnpm --filter @repo/desktop format
```
