### タスク5: 最終判定

**目的**: 手動テストに進むかどうかを判定する

- 最終判定結果

#### 判定基準

| 判定     | 条件                 | 次のアクション          |
| -------- | -------------------- | ----------------------- |
| PASS     | 全チェック項目でパス | Phase 11へ進行          |
| MINOR    | 軽微な指摘あり       | 指摘対応後、Phase 11へ  |
| MAJOR    | 重大な問題あり       | 該当Phaseへ戻り修正     |
| CRITICAL | 致命的な問題あり     | Phase 1へ戻り要件再確認 |

| -------------- | ----------------------------------- |
| 判定           | （PASS / MINOR / MAJOR / CRITICAL） |
| 判定理由       | （判定の根拠を記載）                |
| 指摘事項       | （ある場合のみ記載）                |
| 次のアクション | （判定に基づくアクションを記載）    |
