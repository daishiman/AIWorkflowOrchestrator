## リファクタリング実施方針

### 変更を行う場合

- テストが GREEN のまま維持されることを確認してから変更する
- 1 変更ごとに `pnpm --filter @repo/desktop vitest run` で確認する
- 型の変更は `pnpm --filter @repo/desktop typecheck` で確認する

### 変更しない場合

- Phase 2 設計書の意図と一致しており、現状で十分明確な場合は変更しない
- 動作しているコードへの不要な変更はリグレッションリスクを増やす

## テスト GREEN 維持確認

```bash
# リファクタリング後の全テスト実行
pnpm --filter @repo/desktop vitest run \
  src/main/ipc/__tests__/creatorHandlers.adapterStatus.test.ts \
  src/renderer/components/skill/__tests__/LLMAdapterErrorBanner.test.tsx \
  src/renderer/components/skill/hooks/__tests__/useLLMAdapterStatus.test.ts

# 型チェック
pnpm --filter @repo/desktop typecheck
```
