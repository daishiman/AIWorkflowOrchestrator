## 2. 失敗時アクション

1. 失敗TCを `finding-log` へ課題IDで登録。
2. 重大度を `critical/high/medium/low` で付与。
3. 修正案と推奨修正先（仕様書）を併記。
4. 再監査条件を明記してPhase 6へ引き継ぐ。

## 3. PASS条件

- 優先AのRed条件がすべて不成立。
- 優先B/Cの失敗は `要追記` として課題化され、証跡欠落なし。
- 判定語彙ゆれがゼロ。
