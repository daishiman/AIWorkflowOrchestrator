リトライ機構の追加により既存のSkillExecutorテスト（`SkillExecutor.test.ts`、`SkillExecutor.integration.test.ts`）への影響はない。リトライ関連コードは既存のexecute()メソッド内に統合されているが、デフォルト設定（maxRetries=3）は既存テストでは非リトライ対象エラーのみを使用するため、既存テストの動作に影響しない。
