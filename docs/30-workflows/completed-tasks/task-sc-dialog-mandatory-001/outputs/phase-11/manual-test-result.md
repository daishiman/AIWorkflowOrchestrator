## TC-001: 最小入力での呼び出し（AC-001 / AC-002 の検証）

**検証観点**: `/skill-creator` 呼び出し時、最初のアクションが AskUserQuestion であること

**ウォークスルー確認**:

SKILL.md の `# Skill Creator` 直後に以下のブロックが存在する：

```
## 必須：最初の実行ステップ
このスキルを呼ばれたら、最初のアクションは必ず AskUserQuestion である。
1. インタビュー深度を確認する（quick / standard / detailed）
...
ユーザーの回答なしに生成を開始してはならない。
```

命令形（「してはならない」「必ず〜である」）で記述されており、ファイル冒頭に配置されている。Claude がスキルを読み込んだ時点でこの命令が最初に処理される。

| 項目   | 内容                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------ |
| 検証AC | AC-001 / AC-002                                                                                  |
| 判定   | **PASS**                                                                                         |
| 根拠   | 命令形ブロックが SKILL.md 冒頭（`# Skill Creator` 直後）に配置され、質問なしの開始を禁止している |

## TC-002: 詳細な要件を書いての呼び出し（AC-003 の検証）

**検証観点**: 詳細な要件が提供された場合でも確認質問が発生すること

**ウォークスルー確認**:

SKILL.md の必須ブロックに「スキル名・目的・想定ユーザーが**完全に**明示されていない限り」という条件がある。
詳細な要件（スキル名・目的・ユーザーの全てが揃っている場合）のみ免除されるが、その場合でも「深度確認の質問を行ってから着手する」という記述がある。
いずれのケースでも少なくとも1回の AskUserQuestion が発生する。

| 項目   | 内容                                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| 検証AC | AC-003                                                                                                                      |
| 判定   | **PASS**                                                                                                                    |
| 根拠   | 必須ブロックの最後に「create / update / improve-prompt モードも、最初に深度確認の質問を行ってから着手する」と明記されている |

## TC-003: discover-problem.md 読み込み後の最初のアクション確認（AC-004 の検証）

**ウォークスルー確認**:

discover-problem.md の冒頭（`> **読み込み条件**` ブロック直後）に以下のゲートが存在する：

```
> **⚠ 実行ゲート: このファイルを読み込んだら、最初のアクションは必ず以下を実行すること。**

> ユーザーの回答なしに Phase 0-0-2 以降へ進んではならない。
```

「このファイルを読み込んだら」というトリガー形式で即時実行を強制している。
