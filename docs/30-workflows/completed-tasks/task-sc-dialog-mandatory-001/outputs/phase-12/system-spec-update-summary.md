# システム仕様更新サマリー

## 変更内容

| 項目                             | 変更前の仕様                                           | 変更後の仕様                                       |
| -------------------------------- | ------------------------------------------------------ | -------------------------------------------------- |
| 最初のアクション                 | AskUserQuestion を推奨するが、詳細な要件があれば省略可 | 最初のアクションは必ず AskUserQuestion（例外なし） |
| problem-definition.json の必須度 | 必須（欠損時エラー停止）                               | 任意（欠損時は AskUserQuestion で収集）            |
| discover-problem.md の実行ゲート | なし                                                   | 読み込み直後に Phase 0-0-1 の質問を強制実行        |

## 影響範囲

- **影響あり**: skill-creator スキルの呼び出しフロー（最初のアクションが変更）
- **影響なし**: 既存の collaborative フロー（Phase 0-0〜0-8）の内容
- **影響なし**: orchestrate / create / update / improve-prompt モードの実行内容（深度確認後は同じ）
- **影響なし**: アプリケーションコード・テストコード・IPC

## システム仕様への反映箇所

- skill-creator スキルの説明文: 「最初のアクションは必ず AskUserQuestion」を明記
- 対話フロー仕様書の冒頭ステップ: インタビュー深度確認を必須ステップとして追記
