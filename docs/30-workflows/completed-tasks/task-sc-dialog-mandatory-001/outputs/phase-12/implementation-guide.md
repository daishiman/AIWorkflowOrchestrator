# 実装ガイド

## 問題の背景

`/skill-creator` 呼び出し時に対話なしでスキル生成が始まる問題があった。
SKILL.md が「ドキュメント（説明書）」として書かれており、Claude への「実行コントロール命令」として機能していなかった。

## 変更概要

| ファイル            | 変更種別 | 変更内容                                                                                                                                 |
| ------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| SKILL.md            | 追加     | `# Skill Creator` 直後に `## 必須：最初の実行ステップ` ブロックを追加（命令形・7行・AskUserQuestion強制）                                |
| discover-problem.md | 追加     | `> **読み込み条件**` ブロック直後に実行ゲートブロックを追加（Phase 0-0-1 質問の即時強制）                                                |
| interview-user.md   | 変更     | セクション5.1 の `problem-definition.json` 欠損時処理を「Phase 0-0未完了エラー」から「AskUserQuestion で収集（エラー停止しない）」に変更 |

## 動作確認方法

Phase 11 手動テスト（TC-001〜TC-010）参照。全テスト PASS を確認済み。

1. `/skill-creator` を最小入力で呼び出す → 最初のレスポンスが AskUserQuestion であることを確認
2. 詳細な要件を書いて呼び出す → 少なくとも1回の確認質問があることを確認
3. `problem-definition.json` が存在しない状態で呼び出す → エラーなく AskUserQuestion で収集が始まることを確認
