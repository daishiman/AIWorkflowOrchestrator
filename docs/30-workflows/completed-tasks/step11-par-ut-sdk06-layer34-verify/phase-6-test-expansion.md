## 結合テスト edge case 一覧

| テストケース   | シナリオ                                                                 | 期待結果                                    |
| -------------- | ------------------------------------------------------------------------ | ------------------------------------------- |
| `T-LOOP-EC-01` | verify→improve でファイルを削除して re-verify                            | L3/L4 が skip または warning に変わる       |
| `T-LOOP-EC-02` | verify→改善なし→re-verify                                                | 2回目も同じ severity が返る（冪等性の確認） |
| `T-LOOP-EC-03` | 複数の Layer3/4 チェックが fail する fixture を 1 回の verify で確認する | 全 fail チェックが配列に含まれる            |

### 実装メモ

- `T-L3-EC-01` は空オブジェクトだけでなく、`true` などの object 以外の JSON 値でも warning にフォールバックして crash しないことを含む
- `T-L3-EC-02` は有効な配列型 `["object", "null"]` に加えて、空配列 `[]` を invalid として扱うことを含む
- `T-L4-EC-03` は `references/../escape.md` のような脱出パスを無視し、`references/` 外を参照先として採用しないことを含む
