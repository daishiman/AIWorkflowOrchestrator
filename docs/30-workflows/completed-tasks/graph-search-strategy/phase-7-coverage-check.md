## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。基準未達の場合はPhase 6へ戻る。

## 背景

テストカバレッジの確認は、品質ゲートとして機能する。すべてのテストが成功し、カバレッジ基準を満たすことを確認してからリファクタリングに進む。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ再測定

**目的**: テストカバレッジの再計測

**実行手順**:

1. ユニットテストカバレッジを測定
2. 結合テストカバレッジを確認
3. カバレッジレポートを生成

**期待される成果物**:

- カバレッジレポート（`outputs/phase-7/coverage-report.md`）

---

### タスク2: 統合テスト実行

**目的**: 統合テストの実行と結果確認

**実行手順**:

1. 統合テストを実行
2. 全テストが成功することを確認
3. 実行結果を記録

**期待される成果物**:

- 統合テスト結果（`outputs/phase-7/integration-test.md`）

---

### タスク3: ゲート判定

**目的**: カバレッジ基準を満たしているか判定

**実行手順**:

1. ユニットテストカバレッジ基準との比較
2. 結合テストカバレッジ基準との比較
3. 未達の場合はPhase 6へ戻る

**期待される成果物**:

- ゲート判定結果

## ゲート判定基準

### 通過条件

以下のすべてを満たす場合、Phase 8へ進む:

| 指標              | 基準 |
| ----------------- | ---- |
| Line Coverage     | 80%+ |
| Branch Coverage   | 60%+ |
| Function Coverage | 80%+ |
| 統合テスト成功率  | 100% |

### 未達時の対応

カバレッジ未達や統合テスト失敗がある場合:

1. 不足しているテストケースを特定
2. Phase 6へ戻ってテストを追加
3. 再度Phase 7で確認
