## 概要

GraphSearchStrategyの実装範囲と除外範囲を明確に定義する。

---

## スコープ内（実装対象）

### コア機能

| 機能                 | 説明                              | 優先度 |
| -------------------- | --------------------------------- | ------ |
| ISearchStrategy実装  | インターフェース準拠              | 必須   |
| localSearch          | エンティティベース検索            | 必須   |
| globalSearch         | コミュニティサマリベース検索      | 必須   |
| relationshipSearch   | 関係パスベース検索                | 必須   |
| クエリタイプ切り替え | local/global/relationship自動選択 | 必須   |
| スコアリング         | 0-1範囲のスコア計算               | 必須   |
| フィルタリング       | fileIds/entityTypes/minRelevance  | 必須   |
| エラーハンドリング   | Result<T, Error>パターン          | 必須   |

### 統合

| 統合対象             | 説明                                 |
| -------------------- | ------------------------------------ |
| IKnowledgeGraphStore | グラフ操作API呼び出し                |
| IEmbeddingProvider   | 埋め込み生成                         |
| ICommunitySummarizer | コミュニティサマリ検索（オプション） |

### テスト

| テスト種別     | 対象                     |
| -------------- | ------------------------ |
| ユニットテスト | 全パブリックメソッド     |
| 統合テスト     | 依存サービス連携         |
| エッジケース   | 境界値、エラー系、空結果 |

## スコープ外（実装対象外）

### 将来対応予定

| 機能               | 理由                                      | 予定 |
| ------------------ | ----------------------------------------- | ---- |
| dateRangeフィルタ  | エンティティ/チャンクに日付属性追加が必要 | 次期 |
| キャッシュ機能     | パフォーマンス最適化フェーズで対応        | 次期 |
| バッチ検索         | 複数クエリ同時実行                        | 次期 |
| ストリーミング結果 | 大量結果の漸進的返却                      | 次期 |

### 対象外（別モジュール責務）

| 機能                   | 責務モジュール      |
| ---------------------- | ------------------- |
| エンティティ抽出       | EntityExtractor     |
| 関係抽出               | RelationExtractor   |
| コミュニティ検出       | CommunityDetector   |
| コミュニティサマリ生成 | CommunitySummarizer |
| クエリ分類             | QueryClassifier     |
| RRF統合                | HybridSearchService |
| リランキング           | Reranker            |
| CRAG評価               | CRAGEvaluator       |

### 明示的に含まない機能

| 機能                      | 理由                         |
| ------------------------- | ---------------------------- |
| グラフ可視化              | UIレイヤーの責務             |
| リアルタイム更新検出      | 非同期イベントシステムが必要 |
| 分散グラフ処理            | 現状のスケールでは不要       |
| 自然言語→エンティティ抽出 | LLMベースNERの別タスク       |

## 前提条件

### 技術前提

| 前提                         | 説明                                                    |
| ---------------------------- | ------------------------------------------------------- |
| IKnowledgeGraphStore実装済み | findSimilarEntities, traverse, findShortestPath使用可能 |
| IEmbeddingProvider実装済み   | embed()メソッド使用可能                                 |
| ICommunitySummarizer実装済み | searchSummaries()メソッド使用可能（オプション）         |
| Result型定義済み             | Ok<T>, Err<E>クラス使用可能                             |
| Branded Types定義済み        | EntityId, ChunkId等使用可能                             |

### データ前提

| 前提                         | 説明                                  |
| ---------------------------- | ------------------------------------- |
| エンティティに埋め込み存在   | findSimilarEntitiesでベクトル検索可能 |
| 関係に証拠チャンク紐付け     | パスからチャンク取得可能              |
| コミュニティサマリに埋め込み | searchSummariesでベクトル検索可能     |

### 環境前提

| 前提             | 説明                                |
| ---------------- | ----------------------------------- |
| Node.js 18+      | ESM, TypeScript 5.x対応             |
| libSQL対応DB     | DiskANNベクトルインデックス使用可能 |
| pnpmモノレポ環境 | @repo/shared配下に実装              |

## 制約

### 技術的制約

| 制約             | 説明                            |
| ---------------- | ------------------------------- |
| シングルスレッド | Node.jsイベントループ内で実行   |
| 同期的グラフ操作 | 非同期APIだがシーケンシャル実行 |
| メモリ内結果集約 | 大量結果はlimitで制限           |

### パフォーマンス制約

| 制約                 | 上限               |
| -------------------- | ------------------ |
| 最大クエリ長         | 1000文字           |
| 最大取得件数         | 100件              |
| 最大トラバーサル深度 | 5（デフォルト: 2） |
| 検索タイムアウト     | 10秒               |

### 依存制約

| 制約                           | 説明                                                |
| ------------------------------ | --------------------------------------------------- |
| IKnowledgeGraphStore必須       | nullの場合はインスタンス化不可                      |
| IEmbeddingProvider必須         | nullの場合はインスタンス化不可                      |
| ICommunitySummarizerオプション | nullの場合globalSearchはlocalSearchにフォールバック |

## リスク

| リスク                   | 影響                       | 軽減策                        |
| ------------------------ | -------------------------- | ----------------------------- |
| グラフデータ量増大       | パフォーマンス低下         | limit制限、インデックス最適化 |
