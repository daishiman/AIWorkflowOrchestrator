## パフォーマンス特性分析

### 計算量分析

| 処理                | 計算量     | 説明                                   |
| ------------------- | ---------- | -------------------------------------- |
| 入力バリデーション  | O(1)       | 定数時間                               |
| クエリ埋め込み生成  | O(n)       | クエリ長に比例（外部API依存）          |
| findSimilarEntities | O(m)       | エンティティ数に比例（GraphStore依存） |
| 結果ソート          | O(k log k) | 結果件数kに依存                        |
| 結果変換            | O(k)       | 結果件数kに比例                        |

### メモリ使用量

| 項目                      | 推定サイズ | 説明                 |
| ------------------------- | ---------- | -------------------- |
| GraphSearchResultInternal | ~500B/件   | 内部結果オブジェクト |
| SearchResultItem          | ~400B/件   | 出力結果オブジェクト |
| Float32Array (埋め込み)   | 1536\*4B   | OpenAI ada-002相当   |
| limit上限100件での合計    | ~100KB     | メモリ効率良好       |

### ボトルネック分析

| 処理           | 影響度 | 対策状況                      |
| -------------- | ------ | ----------------------------- |
| 埋め込み生成   | 高     | 外部API依存、キャッシュ未実装 |
| GraphStore検索 | 中     | インデックス依存              |
| 結果変換       | 低     | 効率的な変換処理              |

## 最適化実装状況

### 実装済み最適化

1. **limit \* 2での先行取得**
   - `findSimilarEntities`で多めに取得してフィルタリング
   - 関連度の高い結果を確保

2. **遅延評価パターン**
   - 必要な場合のみチャンク情報を取得
   - 不要な計算を回避

3. **早期リターン**
   - 空結果時に即座に`ok([])`を返却
   - 不要な処理をスキップ
