## 目的

Phase 6のテスト拡充結果を検証し、カバレッジ基準を満たしていることをゲートとして確認する。

## 背景

TDDサイクルにおいて、十分なテストカバレッジを確保することでリファクタリングの安全性を担保する。このPhaseはゲートとして機能し、基準未達の場合はPhase 6に戻る。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ検証

**目的**: ユニットテストのカバレッジ基準達成を検証する

**実行手順**:

1. カバレッジレポートを生成
2. 各指標を基準と比較
3. 達成/未達を判定

**実行コマンド**:

```bash
pnpm --filter @repo/shared test:coverage -- --run services/graph/
```

**カバレッジ基準**:

| 指標              | 最低基準 | 現在値 | 判定 |
| ----------------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | -      | -    |
| Branch Coverage   | 60%      | -      | -    |
| Function Coverage | 80%      | -      | -    |

**期待される成果物**:

- 検証レポート（出力: `outputs/phase-7/unit-coverage-verification.md`）

---

### タスク2: 統合テスト確認

**目的**: 関連する統合テストの成功を確認する

**実行手順**:

1. `services/graph/` 配下の全テストを実行
2. 既存の統合テストが成功することを確認
3. 結果を記録

**実行コマンド**:

```bash
pnpm --filter @repo/shared test -- --run services/graph/
```

**期待される成果物**:

- 統合テスト結果（出力: `outputs/phase-7/integration-test-results.md`）

---

### タスク3: ゲート判定

**目的**: Phase 8に進む可否を判定する

**実行手順**:

1. カバレッジ基準達成状況を確認
2. 統合テスト成功状況を確認
3. 次のアクションを決定

**判定基準**:

| 条件                              | 判定 | 次のアクション |
| --------------------------------- | ---- | -------------- |
| カバレッジ基準達成 + 全テスト成功 | PASS | Phase 8へ進む  |
| カバレッジ基準未達                | FAIL | Phase 6へ戻る  |
| テスト失敗あり                    | FAIL | Phase 5へ戻る  |

**期待される成果物**:

- ゲート判定結果（出力: `outputs/phase-7/gate-verdict.md`）
