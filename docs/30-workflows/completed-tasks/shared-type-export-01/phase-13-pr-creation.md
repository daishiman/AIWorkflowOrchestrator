## 目的

## 背景

全てのPhase（1〜12）が完了し、品質基準を満たしていることを確認した後、変更をPRとして提出し、マージ準備を整える。

---

## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                       | 理由                                           |
| ---------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                             | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで `/ai:diff-to-pr` を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                     | 動作確認されていないコードがPRに含まれる       |

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認【PR作成前に必須】

**目的**: PR作成前にローカルでの動作確認を完了する

**実行手順**:

1. ビルドが成功することを確認
2. 全テストがパスすることを確認
3. 型チェックがパスすることを確認
4. Lintエラーがないことを確認

**実行コマンド**:

```bash
# ビルド確認
pnpm --filter @repo/shared build

# テスト実行
pnpm --filter @repo/shared test

# 型チェック
pnpm --filter @repo/shared typecheck

# Lint確認
pnpm --filter @repo/shared lint
```

**チェックリスト**:

| #   | 確認項目             | 状況 |
| --- | -------------------- | ---- |
| 1   | ビルドが成功する     | -    |
| 2   | 全テストがパスする   | -    |
| 3   | 型チェックがパスする | -    |
| 4   | Lintエラーがない     | -    |

**期待される成果物**:

- ローカル確認結果（出力: `outputs/phase-13/local-verification.md`）

---

### タスク2: ユーザーへのPR作成許可確認

**目的**: ユーザーからPR作成の明示的な許可を得る

**実行手順**:

1. タスク1の結果をユーザーに報告
2. PR作成の許可を求める
3. 許可が得られるまで待機

**確認事項**:

```
## PR作成準備完了

以下の確認が完了しました:
- [ ] ビルド成功
- [ ] テスト成功
- [ ] 型チェック成功
- [ ] Lint成功

PR作成を実行してもよろしいですか？
```

**期待される成果物**:

- ユーザー許可記録（出力: `outputs/phase-13/user-approval.md`）

---

### タスク3: PR作成（ユーザー許可後のみ）

**目的**: `/ai:diff-to-pr` スキルを使用してPRを作成する

**実行手順**:

1. ユーザーの明示的な許可を確認
2. `/ai:diff-to-pr` を実行
3. PR URLを記録

**実行コマンド**:

```
/ai:diff-to-pr
```

**期待される成果物**:

- PR作成結果（出力: `outputs/phase-13/pr-creation-result.md`）

---

### タスク4: CI確認

**目的**: CIが全て通過することを確認する

**実行手順**:

1. PR上のCI結果を確認
2. 全てのチェックがパスすることを確認
3. 結果を記録

**確認コマンド**:

```bash
gh pr checks <PR_NUMBER>
```

**期待される成果物**:

- CI確認結果（出力: `outputs/phase-13/ci-results.md`）

---

### タスク5: タスクディレクトリ移動

**目的**: タスクディレクトリを `completed-tasks/` に移動する

**実行手順**:

1. PRがマージ可能な状態であることを確認
2. タスクディレクトリを移動
3. 移動をコミット・プッシュ

**実行コマンド**:

```bash
# タスクディレクトリを移動
mv docs/30-workflows/shared-type-export-01/ docs/30-workflows/completed-tasks/

# 移動を確認
ls docs/30-workflows/completed-tasks/ | grep shared-type-export-01

# 変更をコミット
git add docs/30-workflows/
git commit -m "docs(workflows): shared-type-export-01をcompleted-tasksに移動"
git push
```

**期待される成果物**:

- 移動完了記録（出力: `outputs/phase-13/task-completion.md`）

---

### タスク6: 未タスク指示書の削除（該当する場合）

**目的**: 元の未タスク指示書を削除する

**実行手順**:

1. 未タスク指示書の存在を確認
2. 削除を実行
3. 削除をコミット

**実行コマンド**:

```bash
# 未タスク指示書を削除
rm docs/30-workflows/unassigned-task/task-shared-community-types-export-01.md

# 変更をコミット
git add docs/30-workflows/unassigned-task/
git commit -m "docs(workflows): 完了したタスクの未タスク指示書を削除"
git push
```
