## 目的

静的解析、型チェック、セキュリティチェックを実施し、コード品質を保証する。

## 背景

本番環境へのデプロイ前に、コード品質の最終確認を行う。型エクスポートタスクではセキュリティリスクは低いが、一般的な品質チェックを実施する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: TypeScript型チェック

**目的**: 型エラーがないことを確認する

**実行手順**:

1. TypeScript型チェックを実行
2. エラーがないことを確認
3. 結果を記録

**実行コマンド**:

```bash
pnpm --filter @repo/shared typecheck
```

**期待される成果物**:

- 型チェック結果（出力: `outputs/phase-9/typecheck-results.md`）

---

### タスク2: ESLint静的解析

**目的**: Lintエラーがないことを確認する

**実行手順**:

1. ESLintを実行
2. エラー・警告を確認
3. 必要に応じて修正

**実行コマンド**:

```bash
pnpm --filter @repo/shared lint
```

**期待される成果物**:

- Lint結果（出力: `outputs/phase-9/lint-results.md`）

---

### タスク3: 全テスト実行

**目的**: 全てのテストが成功することを最終確認する

**実行手順**:

1. `@repo/shared` パッケージの全テストを実行
2. 成功を確認
3. 結果を記録

**実行コマンド**:

```bash
pnpm --filter @repo/shared test
```

**期待される成果物**:

- テスト結果（出力: `outputs/phase-9/test-results.md`）

---

### タスク4: ビルド確認

**目的**: パッケージが正常にビルドできることを確認する

**実行手順**:

1. ビルドを実行
2. エラーがないことを確認
3. 結果を記録

**実行コマンド**:

```bash
pnpm --filter @repo/shared build
```

**期待される成果物**:

- ビルド結果（出力: `outputs/phase-9/build-results.md`）
