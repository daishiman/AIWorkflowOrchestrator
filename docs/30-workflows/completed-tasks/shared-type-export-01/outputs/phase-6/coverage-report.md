## カバレッジ分析

### index.ts のコード構成

| コード種別                       | 行数   | ランタイム生成 | カバレッジ対象 |
| -------------------------------- | ------ | -------------- | -------------- |
| `export type { ... }`            | 約30行 | なし           | 対象外         |
| `export { enum/class/function }` | 約8行  | あり           | 対象           |
| コメント・空行                   | 約22行 | なし           | 対象外         |

### カバレッジ特性

- **`export type` 文**: TypeScript の型情報のみ、コンパイル後には存在しないためカバレッジ測定対象外
- **`export` 文（値）**: 再エクスポートのみであり、ロジックが存在しないためブランチカバレッジは N/A
- **実質的なカバレッジ**: テストで全ての export が使用されていることで検証
