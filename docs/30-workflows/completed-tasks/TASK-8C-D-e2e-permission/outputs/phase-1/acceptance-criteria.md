## 6. 受け入れテスト手順

### 6.1 自動テスト確認

```bash
# 1. TypeScript コンパイル確認
pnpm --filter @repo/desktop typecheck

# 2. ESLint 確認
pnpm --filter @repo/desktop lint

# 3. E2Eテスト実行
pnpm --filter @repo/desktop test:e2e -- skillPermission

# 4. 連続実行テスト（フレーキー確認）
for i in {1..5}; do
  pnpm --filter @repo/desktop test:e2e -- skillPermission
done
```

### 6.2 手動テスト確認

```bash
# デバッグモードで実行
PWDEBUG=1 pnpm --filter @repo/desktop test:e2e -- skillPermission
```

確認項目:

- [ ] ダイアログが正しく表示される
- [ ] ボタンが正しく動作する
- [ ] キーボード操作が可能
- [ ] 選択記憶が機能する

## 8. 例外・除外事項

### 8.1 スコープ外

| 項目                 | 理由                     |
| -------------------- | ------------------------ |
| パフォーマンステスト | 別タスクで実施           |
| セキュリティテスト   | 別タスクで実施           |
| 国際化テスト         | 基本的な日本語UIのみ対象 |
| 複数ブラウザテスト   | Electron単一環境のみ     |

### 8.2 許容事項

| 項目           | 許容範囲                       |
| -------------- | ------------------------------ |
| テスト実行時間 | 最大30秒/テスト（目標は10秒）  |
| フレーキー     | 一時的な発生は許容（修正必須） |
| セレクター     | DOM構造変更時の更新は許容      |
