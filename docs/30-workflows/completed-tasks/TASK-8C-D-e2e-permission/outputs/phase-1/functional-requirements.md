## 2. テストケース詳細

### TC-1: 権限ダイアログ表示

| 項目         | 内容                                                         |
| ------------ | ------------------------------------------------------------ |
| **テストID** | TC-1                                                         |
| **テスト名** | 権限ダイアログ表示                                           |
| **目的**     | ツール実行時に権限確認ダイアログが正しく表示されることを検証 |

#### 前提条件

- Electronアプリが起動している
- test-skill がインポート済み
- test-skill が選択されている

#### テスト手順

1. チャット入力欄に「Run dangerous command」を入力
2. Enterキーを押して送信

#### 期待結果

- 権限ダイアログが表示される
- ダイアログタイトル「権限の確認が必要です」が表示される
- ダイアログは10秒以内に表示される

#### テストデータ

```typescript
{
  command: "Run dangerous command",
  expectedTitle: "権限の確認が必要です",
  timeout: 10000
}
```

### TC-2: ツール情報表示

| 項目         | 内容                                                         |
| ------------ | ------------------------------------------------------------ |
| **テストID** | TC-2                                                         |
| **テスト名** | ツール情報表示                                               |
| **目的**     | 権限ダイアログ内にツール名・引数が正しく表示されることを検証 |

#### 前提条件

- TC-1 の前提条件が満たされている
- 権限ダイアログが表示されている

#### テスト手順

1. TC-1 の手順でダイアログを表示
2. ダイアログ内の情報を確認

#### 期待結果

- 「ツール:」ラベルが表示される
- 「引数:」ラベルが表示される
- ツール名が表示される（例: Bash, Read, Write等）
- 引数が表示される（JSONまたは整形された形式）

#### テストデータ

```typescript
{
  expectedLabels: ["ツール:", "引数:"],
  toolNameVisible: true,
  argsVisible: true
}
```

### TC-5: 選択記憶

| 項目         | 内容                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| **テストID** | TC-5                                                                       |
| **テスト名** | 選択記憶                                                                   |
| **目的**     | チェックボックスで選択を記憶し、次回以降ダイアログが表示されないことを検証 |

#### 前提条件

- TC-1 の前提条件が満たされている
- 権限ダイアログが表示されている

#### テスト手順

1. TC-1 の手順でダイアログを表示
2. 「この選択を記憶する」チェックボックスをオン
3. 「許可」ボタンをクリック
4. 同じコマンドを再実行

#### 期待結果

- 1回目: 権限ダイアログが表示される
- チェックボックスをオンにして「許可」
- 2回目: 権限ダイアログが表示されない（自動で許可される）

#### テストデータ

```typescript
{
  checkboxSelector: '[type="checkbox"]',
  command: "Run dangerous command",
  waitBeforeSecondCheck: 1000,
  expectDialogOnSecondRun: false
}
```
