## 3. トラブルシューティングガイド

### 3.1 よくある問題と解決方法

| 問題                             | 原因                     | 解決方法                          |
| -------------------------------- | ------------------------ | --------------------------------- |
| Playwrightブラウザ未インストール | 初回実行                 | `npx playwright install chromium` |
| Viteサーバー起動失敗             | ポート使用中             | 他プロセスを終了またはポート変更  |
| タイムアウトエラー               | 遅い環境                 | タイムアウト値を増加              |
| セレクターが見つからない         | UI変更                   | SELECTORS定数を更新               |
| 認証状態エラー                   | storageStateファイル不足 | `e2e/global-setup.ts`を実行       |

### 3.2 デバッグ方法

| 方法                   | コマンド/手順                                 |
| ---------------------- | --------------------------------------------- |
| ヘッダーモード実行     | `pnpm test:e2e:headed -- skill-permission`    |
| Playwright UI          | `pnpm test:e2e:ui -- skill-permission`        |
| デバッグモード         | `PWDEBUG=1 pnpm test:e2e -- skill-permission` |
| トレース確認           | `playwright show-trace trace.zip`             |
| スクリーンショット確認 | `playwright-report/` ディレクトリ確認         |
