## 1. キーボードナビゲーション確認

### 1.1 確認項目

| 確認項目                      | 期待動作                         | 結果 |
| ----------------------------- | -------------------------------- | ---- |
| Tab キーでダイアログ内移動    | フォーカスが要素間を移動         | ⏸️   |
| フォーカストラップ            | フォーカスがダイアログ外に出ない | ⏸️   |
| Enter キーでボタン押下        | フォーカス中のボタンが押される   | ⏸️   |
| Escape キーでダイアログ閉じる | ダイアログが閉じる（拒否扱い）   | ⏸️   |

### 1.2 フォーカス順序

| 順序 | 要素             | 期待されるフォーカス順 |
| ---- | ---------------- | ---------------------- |
| 1    | ダイアログ本体   | 最初にフォーカス       |
| 2    | チェックボックス | Tab で移動             |
| 3    | 許可ボタン       | Tab で移動             |
| 4    | 拒否ボタン       | Tab で移動             |
