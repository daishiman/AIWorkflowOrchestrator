## 3. テスト信頼性確認

### 3.1 モックと実動作の比較

| 動作               | 実装                  | モック         | 乖離リスク |
| ------------------ | --------------------- | -------------- | ---------- |
| スキル一覧取得     | IPC経由でMain Process | 固定リスト返却 | 低         |
| スキルインポート   | ファイル検証・登録    | 即時成功       | 低         |
| 権限リクエスト発火 | Main ProcessからIPC   | setTimeout発火 | 中         |
| 権限応答送信       | IPCでMain Process     | ローカル処理   | 低         |

### 3.2 乖離リスク対策

| リスク                   | 対策                                        |
| ------------------------ | ------------------------------------------- |
| 権限リクエストタイミング | setTimeout(100ms)で非同期性を再現           |
| Main Process状態         | E2EテストではRenderer中心、統合テストで補完 |
| 実際のツール実行         | モック範囲外（統合テストでカバー）          |

### 3.3 フォールスポジティブ/ネガティブリスク

| テスト | フォールスポジティブ | フォールスネガティブ |

| TC-2   | 低（UI表示確認）     | 低                   |

| TC-4   | 低（UI状態確認）     | 中（キャンセル判定） |
| TC-5   | 中（タイミング依存） | 中                   |

### 3.4 判定: **PASS**

モックが実動作と大きく乖離するリスクは限定的。IPC統合テスト（TASK-8C-A）と補完関係にある。
