## 目的

E2Eテストを実際のElectronアプリケーションで実行し、自動テストでは検出できない問題がないか確認する。

## 背景

E2Eテストは自動化されているが、視覚的な確認や実際のユーザー体験の検証は手動で行う必要がある。また、E2Eテスト自体の動作確認も行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: E2Eテスト実行の視覚的確認

**目的**: E2Eテストが正しく動作しているか視覚的に確認する

**実行手順**:

1. ヘッドフルモード（画面表示あり）でE2Eテスト実行

   ```bash
   # ヘッドフルモードで実行（Electron画面が表示される）
   PWDEBUG=1 pnpm --filter @repo/desktop test:e2e -- skillPermission
   ```

2. 各テストケースの動作を目視確認

   | テストケース       | 動作確認 | 視覚的問題 |
   | ------------------ | -------- | ---------- |
   | 権限ダイアログ表示 | [ ]      |            |
   | ツール情報表示     | [ ]      |            |
   | 許可して続行       | [ ]      |            |
   | 拒否して停止       | [ ]      |            |
   | 選択記憶           | [ ]      |            |

3. 問題があれば記録

**期待される成果物**:

- `outputs/phase-11/visual-verification.md`: 視覚的確認結果

---

### タスク2: 手動操作での権限ダイアログ確認

**目的**: 手動操作で権限ダイアログの動作を確認する

**実行手順**:

1. Electronアプリを起動

   ```bash
   pnpm --filter @repo/desktop dev
   ```

2. 手動テストシナリオ実行

   **シナリオ1: 権限ダイアログ許可**
   - [ ] スキルを選択
   - [ ] コマンドを入力して実行
   - [ ] 権限ダイアログが表示されることを確認
   - [ ] ツール名・引数が正しく表示されているか確認
   - [ ] 「許可」ボタンをクリック
   - [ ] ダイアログが閉じ、実行が継続することを確認

   **シナリオ2: 権限ダイアログ拒否**
   - [ ] コマンドを入力して実行
   - [ ] 権限ダイアログが表示される
   - [ ] 「拒否」ボタンをクリック
   - [ ] 実行がキャンセル/エラーになることを確認

   **シナリオ3: 選択記憶**
   - [ ] コマンドを入力して実行
   - [ ] 「この選択を記憶する」チェックボックスをON
   - [ ] 「許可」ボタンをクリック
   - [ ] 同じコマンドを再実行
   - [ ] 権限ダイアログが表示されないことを確認

3. 問題があれば記録

**期待される成果物**:

- `outputs/phase-11/manual-test-result.md`: 手動テスト結果

---

### タスク3: アクセシビリティ手動確認

**目的**: アクセシビリティ機能を手動で確認する

**実行手順**:

1. キーボードナビゲーション確認
   - [ ] Tab キーでダイアログ内の要素を移動できる
   - [ ] フォーカスがダイアログ外に出ない（フォーカストラップ）
   - [ ] Enter キーでフォーカス中のボタンを押せる
   - [ ] Escape キーでダイアログを閉じられる

2. スクリーンリーダー対応確認（可能であれば）
   - [ ] ダイアログのタイトルが読み上げられる
   - [ ] ボタンのラベルが読み上げられる

3. 視覚的アクセシビリティ確認
   - [ ] コントラスト比が十分（テキストが読みやすい）
   - [ ] フォーカス表示が明確

**期待される成果物**:

- `outputs/phase-11/accessibility-check.md`: アクセシビリティ確認結果
