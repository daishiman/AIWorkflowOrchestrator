# Phase 9: 品質保証

## メタ情報

| 項目   | 値                          |

## 目的

全ての品質ゲートをクリアし、リリース品質を確保する。

## 品質ゲート

| ゲート       | 基準            | 必須 |
| ------------ | --------------- | ---- |
| 型チェック   | エラー0件       | ✓    |
| Lint         | エラー0件       | ✓    |
| テスト       | 全テスト通過    | ✓    |
| カバレッジ   | 80%/60%/80%以上 | ✓    |
| セキュリティ | 脆弱性0件       | ✓    |
| ビルド       | 正常完了        | ✓    |

## 実行タスク

### タスク1: 静的解析

**目的**: 静的解析ツールで品質を確認する

**手順**:

1. TypeScript型チェック実行
2. ESLint実行
3. Prettier確認
4. 警告の対応（可能な範囲で）

**コマンド**:

```bash
# 型チェック
pnpm typecheck

# Lint
pnpm lint

# フォーマット確認
pnpm format:check
```

**期待される成果物**:

- 静的解析結果レポート

### タスク2: テスト実行

**目的**: 全テストの通過を確認する

**手順**:

1. ユニットテスト実行
2. 統合テスト実行
3. カバレッジ確認
4. 失敗テストの対応

**コマンド**:

```bash
# 全テスト実行（カバレッジ付き）
pnpm --filter @repo/desktop test -- --run --coverage
```

**期待される成果物**:

- テスト実行結果レポート

### タスク3: セキュリティチェック

**目的**: セキュリティ脆弱性がないことを確認する

**手順**:

1. 依存関係の脆弱性チェック
2. コードのセキュリティレビュー
3. IPC通信のセキュリティ確認
4. パストラバーサル対策の確認

**コマンド**:

```bash
# 依存関係の脆弱性チェック
pnpm audit
```

**セキュリティチェックリスト**:

| 項目                     | 確認内容                               |
| ------------------------ | -------------------------------------- |
| 依存関係                 | 既知の脆弱性がないこと                 |
| IPC通信                  | チャンネルホワイトリストが機能すること |
| 入力検証                 | 全入力がZodスキーマで検証されること    |
| パストラバーサル         | スキルパスが制限されること             |
| コマンドインジェクション | 引数がサニタイズされること             |

**期待される成果物**:

- セキュリティチェック結果

### タスク4: ビルド確認

**目的**: 本番ビルドが正常に完了することを確認する

**手順**:

1. shared パッケージビルド
2. desktop アプリビルド
3. ビルド成果物の確認
4. 起動確認（可能であれば）

**コマンド**:

```bash
# 共有パッケージビルド
pnpm --filter @repo/shared build

# デスクトップアプリビルド
pnpm --filter @repo/desktop build
```

**期待される成果物**:

- ビルド成功確認
