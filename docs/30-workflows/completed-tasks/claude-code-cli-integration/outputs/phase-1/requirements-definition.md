## 1. 機能要件（Functional Requirements）

### FR-001: CLIインストール確認

| 項目     | 内容                                                                |
| -------- | ------------------------------------------------------------------- |
| ID       | FR-001                                                              |
| 名称     | Claude Code CLIインストール確認                                     |
| 説明     | ローカル環境にClaude Code CLIがインストールされているか確認する機能 |
| 優先度   | 高                                                                  |
| 依存関係 | なし                                                                |

**詳細要件**:

- `claude --version` コマンドを実行してCLIの存在を確認する
- CLIが見つからない場合は適切なエラーメッセージを返す
- CLIのバージョン情報を取得・保持する
- 環境変数`PATH`内のclaude実行ファイルを検出する

---

### FR-002: CLIプロセス起動

| 項目     | 内容                                                       |
| -------- | ---------------------------------------------------------- |
| ID       | FR-002                                                     |
| 名称     | CLIプロセス起動                                            |
| 説明     | Claude Code CLIプロセスを`child_process`でスポーンする機能 |
| 優先度   | 高                                                         |
| 依存関係 | FR-001                                                     |

**詳細要件**:

- `child_process.spawn()`を使用してCLIプロセスを起動
- プロセスオプション（cwd, env, stdio）を適切に設定
- プロセスIDを追跡・管理
- スポーン失敗時のエラーハンドリング

## 3. 接続要件

### CLI接続

| 項目             | 要件                                     |
| ---------------- | ---------------------------------------- |
| インストール確認 | `claude --version`コマンドによる存在確認 |
| バージョン要件   | Claude Code CLI >= 1.x                   |
| 実行パス         | PATH環境変数で解決可能であること         |
| 作業ディレクトリ | プロジェクトルートまたは指定ディレクトリ |

### IPC通信

| 項目           | 要件                                            |
| -------------- | ----------------------------------------------- |
| チャンネル設計 | ホワイトリスト方式で管理                        |
| プロトコル     | invoke/handleパターン（リクエスト・レスポンス） |
| ストリーミング | on/sendパターン（リアルタイム配信）             |
| セキュリティ   | sender検証、contextIsolation有効                |

### プロセス管理

| 項目           | 要件                                         |
| -------------- | -------------------------------------------- |
| スポーン方式   | child_process.spawn()                        |
| 監視           | プロセス状態（running, exited, error）の追跡 |
| 終了処理       | SIGTERM → タイムアウト → SIGKILL             |
| クリーンアップ | アプリ終了時の全プロセス終了                 |

### ストリーミング

| 項目               | 要件                               |
| ------------------ | ---------------------------------- |
| 標準出力キャプチャ | stdout/stderrを非同期キャプチャ    |
| バッファリング     | 行単位またはチャンク単位で選択可能 |
| 配信方式           | async generator/EventEmitter       |
| エンコーディング   | UTF-8                              |

### セッション管理

| 項目           | 要件                                            |
| -------------- | ----------------------------------------------- |
| 並列実行       | 最大10セッション                                |
| セッション状態 | pending, running, completed, failed, terminated |
| タイムアウト   | デフォルト30分、設定可能                        |
| クリーンアップ | LRU方式で古いセッションを自動終了               |

## 5. 制約事項

### 技術的制約

1. **CLIの手動インストール前提**: Claude Code CLIの自動インストール機能は含まない
2. **スキル実行のみ**: `.claude/commands/`の実行は対象外
3. **Hooks非統合**: Claude Code Hooksとの統合は将来課題
4. **UI非実装**: API層のみの実装、UIは別タスク

### 運用制約

1. **ネットワーク要件**: Claude Code CLIがAnthropic APIに接続できること
2. **認証要件**: Claude Code CLIの認証が完了していること
3. **ディスク容量**: `.claude/skills/`が存在し、アクセス可能であること
