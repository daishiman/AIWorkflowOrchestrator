## 1. スコープ概要

本ドキュメントは、Claude Code CLI統合機能の実装スコープを明確に定義する。

### 目的

Electronデスクトップアプリから、ローカルのClaude Code CLIを呼び出し、`.claude/skills/`配下の特定のスキルを実行し、その結果を取得できる統合基盤を構築する。

## 2. 含むもの（In Scope）

### 2.1 CLIプロセス管理

| 機能                | 説明                                      | 優先度 |
| ------------------- | ----------------------------------------- | ------ |
| CLIインストール確認 | `claude --version`によるCLI存在確認       | 高     |
| CLIプロセス起動     | `child_process.spawn()`によるプロセス起動 | 高     |
| プロセス状態監視    | running/exited/errorの状態追跡            | 高     |
| プロセス終了処理    | SIGTERM/SIGKILLによるgraceful shutdown    | 高     |
| タイムアウト管理    | 実行タイムアウトの設定と強制終了          | 中     |

## 3. 含まないもの（Out of Scope）

### 3.1 明示的に除外する機能

| 機能                            | 除外理由                                     | 将来対応  |
| ------------------------------- | -------------------------------------------- | --------- |
| Claude Code CLI自動インストール | 手動インストールを前提、配布ライセンス問題   | 検討中    |
| `.claude/commands/`実行         | スキル実行に焦点、コマンドは別アーキテクチャ | 将来課題  |
| Claude Code Hooks統合           | 複雑性増大、別タスクで対応                   | 将来課題  |
| UI実装                          | API層のみ、UIは別タスク                      | Phase 13+ |
| Agent SDK統合切り替え           | 現時点では独立運用、将来的に統合検討         | 将来課題  |

### 3.2 技術的制約による除外

| 機能                     | 制約理由                              |
| ------------------------ | ------------------------------------- |
| Windows WSL2環境サポート | パス変換の複雑性、検証環境不足        |
| Remote CLI実行           | ネットワーク経由のCLI呼び出しは対象外 |
| CLIバージョン自動更新    | ユーザー責任での更新を想定            |
| 認証フロー統合           | CLIの認証は事前完了を前提             |

### 3.3 運用面での除外

| 機能                 | 除外理由                                   |
| -------------------- | ------------------------------------------ |
| CLI実行ログの永続化  | 一時的な実行結果のみ、永続化は別要件       |
| スキル実行統計の収集 | プライバシー配慮、オプトイン方式は将来検討 |
| マルチユーザー対応   | デスクトップアプリは単一ユーザー想定       |

## 4. 境界条件

### 4.1 前提条件（Prerequisites）

| 条件                            | 説明                             | 検証方法         |
| ------------------------------- | -------------------------------- | ---------------- |
| Claude Code CLIインストール済み | `claude --version`で確認可能     | 起動時チェック   |
| CLI認証完了                     | Anthropic APIへの接続が可能      | 接続テスト       |
| `.claude/skills/`存在           | スキルディレクトリがアクセス可能 | ディレクトリ確認 |
| Node.js >= 20.x                 | ランタイム要件                   | package.json     |
| Electron >= 28.x                | フレームワーク要件               | package.json     |

### 4.2 動作環境

| 環境                        | サポート状況           |
| --------------------------- | ---------------------- |
| macOS (Intel/Apple Silicon) | フルサポート           |
| Windows 10/11               | フルサポート           |
| Linux (Ubuntu 20.04+)       | フルサポート           |
| Windows WSL2                | 未サポート（将来検討） |

### 4.3 リソース制約

| リソース               | 制限値                     |
| ---------------------- | -------------------------- |
| 同時セッション数       | 最大10                     |
| セッションあたりメモリ | 50MB以下                   |
| スキル実行タイムアウト | デフォルト30分（設定可能） |
| スキル一覧キャッシュ   | 200スキル、1000ms以内      |
