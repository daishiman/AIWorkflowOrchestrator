# Phase 11: 手動テスト

## メタ情報

| 項目   | 値                          |
| ------ | --------------------------- |
| Phase  | 11                          |
| 機能名 | claude-code-cli-integration |

## 目的

実環境でのUX確認、自動テストでカバーできない動作確認を行う。

## 前提条件

- [ ] Claude Code CLIがローカルにインストールされていること
- [ ] Electronデスクトップアプリがビルドできること
- [ ] `.claude/skills/` 配下にテスト用スキルが存在すること

## 実行タスク

### タスク1: CLI統合動作確認

**目的**: CLI統合が正常に動作することを確認する

**テストシナリオ**:

| ID    | シナリオ           | 手順                            | 期待結果                   |
| ----- | ------------------ | ------------------------------- | -------------------------- |
| MT-01 | CLI存在確認        | アプリ起動 → CLI確認API呼び出し | バージョン情報が表示される |
| MT-02 | スキル一覧取得     | スキル一覧API呼び出し           | スキルリストが表示される   |
| MT-03 | スキル実行（正常） | 簡単なスキルを選択・実行        | 実行結果が表示される       |
| MT-04 | スキル実行（中断） | 実行中に中断ボタン押下          | 実行が中断される           |
| MT-05 | 複数セッション     | 2つのスキルを並列実行           | 両方が正常に完了する       |

**期待される成果物**:

- テスト実行結果

### タスク2: ストリーミング出力確認

**目的**: リアルタイム出力が正常に動作することを確認する

**テストシナリオ**:

| ID    | シナリオ   | 手順                     | 期待結果                         |
| ----- | ---------- | ------------------------ | -------------------------------- |
| MT-06 | stdout表示 | 出力のあるスキル実行     | リアルタイムで出力が表示される   |
| MT-07 | stderr表示 | 警告のあるスキル実行     | エラー出力が区別して表示される   |
| MT-08 | 長時間実行 | 30秒以上かかるスキル実行 | タイムアウトせず完了する         |
| MT-09 | 大量出力   | 大量出力のスキル実行     | パフォーマンス低下なく表示される |

**期待される成果物**:

- ストリーミング動作確認結果

### タスク3: エラーハンドリング確認

**目的**: エラー時の挙動が適切であることを確認する

**テストシナリオ**:

| ID    | シナリオ     | 手順                          | 期待結果                   |
| ----- | ------------ | ----------------------------- | -------------------------- |
| MT-10 | CLI不在      | CLIパスを無効化 → 実行        | 適切なエラーメッセージ表示 |
| MT-11 | スキル不在   | 存在しないスキルを指定        | 適切なエラーメッセージ表示 |
| MT-12 | タイムアウト | タイムアウト設定→長時間スキル | タイムアウトエラー表示     |
| MT-13 | 権限エラー   | 実行権限のないスキル          | 権限エラーメッセージ表示   |

**期待される成果物**:

- エラーハンドリング確認結果

### タスク4: UX確認

**目的**: ユーザー体験が良好であることを確認する

**確認項目**:

| ID    | 確認項目       | 基準                     |
| ----- | -------------- | ------------------------ |
| UX-01 | 応答速度       | CLI確認が1秒以内         |
| UX-02 | フィードバック | 実行中の進捗がわかる     |
| UX-03 | エラー表示     | エラー内容が理解しやすい |
| UX-04 | キャンセル     | いつでもキャンセル可能   |
| UX-05 | 再試行         | エラー後に再試行可能     |

**期待される成果物**:

- UX確認結果

### タスク5: 境界条件確認

**目的**: 境界条件での動作を確認する

**テストシナリオ**:

| ID    | シナリオ       | 手順                     | 期待結果                 |
| ----- | -------------- | ------------------------ | ------------------------ |
| MT-14 | 空プロンプト   | 空文字でスキル実行       | バリデーションエラー     |
| MT-15 | 長いプロンプト | 10000文字のプロンプト    | 正常に実行される         |
| MT-16 | 特殊文字       | 特殊文字を含むプロンプト | エスケープされて実行     |
| MT-17 | 同時接続上限   | 10セッション同時実行     | 上限エラーまたは正常処理 |

**期待される成果物**:

- 境界条件テスト結果
