## 1. スコープ内（In Scope）

### 1.1 機能スコープ

| No  | 機能                   | 説明                                        |
| --- | ---------------------- | ------------------------------------------- |
| 1   | 単一チャンク関係抽出   | 1つのチャンクからエンティティ間の関係を抽出 |
| 2   | バッチ関係抽出         | 複数チャンクの一括処理                      |
| 3   | 関係マージ             | 重複した関係の統合とエビデンス集約          |
| 4   | 関係タイプ分類         | 15種類の定義済み関係タイプへの分類          |
| 5   | 信頼度スコア付与       | 0.0〜1.0の信頼度スコア                      |
| 6   | エビデンス抽出         | 関係を示すテキストの特定と記録              |
| 7   | フィルタリング         | タイプ別・信頼度別のフィルタリング          |
| 8   | 双方向関係識別         | 双方向関係のフラグ設定                      |
| 9   | ExtractionPipeline統合 | エンティティ抽出との連携処理                |

## 2. スコープ外（Out of Scope）

### 2.1 機能スコープ外

| No  | 機能                   | 理由                       | 代替案/将来対応                  |
| --- | ---------------------- | -------------------------- | -------------------------------- |
| 1   | ルールベース関係抽出   | LLM優先のため今回は対象外  | 将来的にフォールバックとして検討 |
| 2   | 関係の時系列追跡       | 複雑度が高い               | CONV-08で検討                    |
| 3   | 関係の重み付け         | 信頼度スコアで代替         | -                                |
| 4   | カスタム関係タイプ追加 | 初期リリースでは15種類固定 | 将来的に拡張機能として検討       |
| 5   | 関係の可視化           | フロントエンド機能         | 別タスクで対応                   |
| 6   | 関係のリアルタイム更新 | バッチ処理を優先           | 将来的に検討                     |

### 2.2 技術スコープ外

| No  | 技術要素            | 理由                                  |
| --- | ------------------- | ------------------------------------- |
| 1   | GraphDBへの直接保存 | Repository層で抽象化（CONV-08で対応） |
| 2   | キャッシュ機構      | 初期実装では不要                      |
| 3   | 並列処理最適化      | 順次処理で十分な性能が期待できる      |
| 4   | ストリーミング処理  | バッチ処理で対応                      |

## 3. 前提条件（Assumptions）

| No  | 前提条件                                                                    |
| --- | --------------------------------------------------------------------------- |
| 1   | CONV-06-04（エンティティ抽出サービス）が完了し、ExtractedEntity型が利用可能 |

## 4. 制約条件（Constraints）

| No  | 制約条件                 | 影響                            |
| --- | ------------------------ | ------------------------------- |
| 1   | LLM API呼び出しコスト    | バッチサイズに上限を設定        |
| 2   | LLM API応答時間          | タイムアウト設定が必要          |
| 3   | 15種類の固定関係タイプ   | 分類できない関係は"other"に分類 |
| 4   | 日本語・英語テキスト対応 | 他言語は動作保証外              |

## 7. 統合テスト連携ポイント

### 7.1 API/認証/データフロー

| 連携ポイント       | 内容                                                   |
| ------------------ | ------------------------------------------------------ |
| ILLMProvider       | LLM APIへのアクセス（認証はプロバイダー側で管理）      |
| IEntityExtractor   | エンティティ抽出結果の受け取り                         |
| EntityRepository   | マージ済みエンティティの保存（ExtractionPipeline経由） |
| RelationRepository | 抽出関係の保存（ExtractionPipeline経由）               |

### 7.2 エンティティ抽出サービス（CONV-06-04）との連携

```typescript
// 連携インターフェース
interface ExtractionPipelineIntegration {
  // 入力: チャンクリスト
  input: ContentChunk[];

  // 中間: エンティティ抽出結果
  entityResult: BatchExtractionResult;

  // 変換: チャンクIDとエンティティのマッピング
  entitiesByChunk: Map<ChunkId, ExtractedEntity[]>;

  // 出力: 関係抽出結果
  relationResult: BatchRelationExtractionResult;
}
```

### 7.3 ExtractionPipelineとの統合ポイント

| ステップ | 処理                   | 担当               |
| -------- | ---------------------- | ------------------ |
| 1        | チャンク受け取り       | ExtractionPipeline |
| 2        | エンティティ抽出       | IEntityExtractor   |
| 3        | エンティティマップ作成 | ExtractionPipeline |
| 4        | 関係抽出               | IRelationExtractor |
| 5        | マージ・正規化         | ExtractionPipeline |
| 6        | DB保存                 | Repository層       |
