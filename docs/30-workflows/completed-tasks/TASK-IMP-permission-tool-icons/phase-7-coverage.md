## 実行手順

### ステップ1: カバレッジレポート生成

```bash
cd apps/desktop && npx vitest run --coverage src/renderer/components/skill/__tests__/PermissionDialog.test.tsx
```

### ステップ2: カバレッジ基準照合

| 指標     | 最低基準 | 推奨基準 | 実測値    | 判定  |
| -------- | -------- | -------- | --------- | ----- |
| Line     | 80%+     | 90%+     | \_\_\_\_% | ✅/❌ |
| Branch   | 60%+     | 70%+     | \_\_\_\_% | ✅/❌ |
| Function | 80%+     | 90%+     | \_\_\_\_% | ✅/❌ |

### ステップ3: カバレッジ分析

追加した実装の各ブランチがテストでカバーされていることを確認する。

| コード箇所                       | カバー対象                     | テスト有無 |
| -------------------------------- | ------------------------------ | ---------- |
| TOOL_ICONS定数                   | 10ツール分の定義               | ✅         |
| DEFAULT_TOOL_ICON定数            | デフォルト値                   | ✅         |
| getToolIcon - 定義済みツール分岐 | TOOL_ICONS[toolName]がある場合 | ✅         |
| getToolIcon - デフォルト分岐     | TOOL_ICONS[toolName]がない場合 | ✅         |
| JSXテンプレート - aria-hidden    | aria-hidden="true"属性         | ✅         |

### ステップ4: 不足箇所への対応

カバレッジが基準を満たさない場合、以下の追加テストを検討する:

- 未カバーのブランチに対するテストケース追加
- 未到達コードパスの確認と対応
