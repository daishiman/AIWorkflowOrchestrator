# Phase 11: 手動テスト検証

## メタ情報

| 項目   | 値                             |
| ------ | ------------------------------ |
| Phase  | 11                             |
| 機能名 | TASK-IMP-permission-tool-icons |
| 作成日 | 2026-01-30                     |

## 目的

自動テストでは検証しきれない視覚的な表示品質、操作感、アクセシビリティをElectronアプリ上で手動検証する。

## 実行タスク

- Task 1: 視覚的表示検証 — アイコンの表示品質・配置を目視確認
- Task 2: 操作フロー検証 — PermissionDialogの一連の操作フローを確認
- Task 3: アクセシビリティ検証 — キーボード操作・スクリーンリーダー確認
- Task 4: テスト結果記録

### ステップ1: 開発サーバー起動

```bash
cd apps/desktop && pnpm dev
```

### ステップ2: 視覚的表示検証

PermissionDialogを表示し、以下を目視確認する。

| TC-ID  | 確認項目                                      | 期待結果                             | 結果  |

| TC-001 | Bashツールのアイコン表示                      | 💻がツール名左側に表示される         | ✅/❌ |
| TC-002 | アイコンとツール名の間隔                      | 適切なギャップ（gap-1 = 4px）        | ✅/❌ |
| TC-003 | アイコンとツール名の縦方向アラインメント      | 中央揃え（items-center）             | ✅/❌ |

## 多角的チェック観点（AIが判断）

| 観点                 | 該当 | 確認内容                                           |
| -------------------- | ---- | -------------------------------------------------- |
| UI/UX（Apple HIG）   | ✅   | アイコン表示がHIG準拠か、視覚的品質が十分か        |
| アクセシビリティ     | ✅   | aria-hidden、フォーカス制御、VoiceOver対応が適切か |
| レスポンシブデザイン | ✅   | 異なるウィンドウサイズでレイアウト崩れがないか     |
| ダークモード対応     | ✅   | ダーク/ライトモード両方でアイコン視認性が確保か    |
| セキュリティ         | -    | 表示のみの変更、手動テストでのセキュリティ確認不要 |
| パフォーマンス       | -    | 体感速度に問題がないか（目視確認レベル）           |
