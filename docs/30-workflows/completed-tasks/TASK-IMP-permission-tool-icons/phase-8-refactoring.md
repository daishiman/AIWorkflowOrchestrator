### ステップ1: コード品質確認

以下の観点で実装コードをレビューする。

| チェック項目                             | 確認  | 備考                                     |
| ---------------------------------------- | ----- | ---------------------------------------- |
| TOOL_ICONS定数の並び順は論理的か         | ✅/❌ | アルファベット順、カテゴリ順などの一貫性 |
| getToolIcon関数のシグネチャは適切か      | ✅/❌ | 引数名、戻り値型が明確か                 |
| JSXの変更は最小限か                      | ✅/❌ | 不要なspanやクラスが追加されていないか   |
| Tailwindクラスの順序は規約に沿っているか | ✅/❌ | レイアウト→スペーシング→装飾の順序       |
| コメントは必要最小限か                   | ✅/❌ | 自明なコードにコメントがないか           |

### ステップ3: リファクタリング実施（該当する場合のみ）

本タスクは小規模変更のため、リファクタリングが不要な可能性が高い。以下の場合のみ実施する:

- 命名が規約に沿っていない場合 → 命名修正
- Tailwindクラスの順序が不適切な場合 → 順序修正
- 不要なコードが混入している場合 → 削除

**重要**: リファクタリング実施後は必ず全テストを再実行する。

