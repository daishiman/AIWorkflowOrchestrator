## 目的

Phase 6 で拡充したテストのカバレッジを計測し、プロジェクト標準のカバレッジ基準を満たしていることを確認する。基準未達の場合は Phase 6 に差し戻す。

## 実行タスク

### Task 7-1: カバレッジ計測実行

**目的**: 対象ファイルのカバレッジを正確に計測する

**実行手順**:

1. 対象ファイルに絞ったカバレッジ計測を実行する:

   ```bash
   cd apps/desktop && pnpm vitest run --coverage src/main/ipc/__tests__/skillFileHandlers.test.ts
   ```

2. SkillFileManager のカバレッジも個別に計測する:

   ```bash
   cd apps/desktop && pnpm vitest run --coverage src/main/services/skill/__tests__/SkillFileManager.test.ts
   ```

3. カバレッジレポート出力を確認する（`coverage/` ディレクトリ）

**カバレッジ対象ファイル**:

| ファイル                                                   | 説明                 |
| ---------------------------------------------------------- | -------------------- |
| `apps/desktop/src/main/ipc/skillFileHandlers.ts`           | IPC ハンドラ         |
| `apps/desktop/src/main/services/skill/SkillFileManager.ts` | ファイル操作サービス |

---

### Task 7-2: 基準充足判定

**目的**: カバレッジ計測結果をプロジェクト基準と照合する

**判定基準**:

#### 最低基準（必達）

| 指標              | 最低基準 | 計測結果 | 判定 |
| ----------------- | -------- | -------- | ---- |
| Line Coverage     | 80%      | -        | -    |
| Branch Coverage   | 60%      | -        | -    |
| Function Coverage | 80%      | -        | -    |

#### 推奨基準（目標）

| 指標              | 推奨基準 | 計測結果 | 判定 |
| ----------------- | -------- | -------- | ---- |
| Line Coverage     | 90%      | -        | -    |
| Branch Coverage   | 70%      | -        | -    |
| Function Coverage | 90%      | -        | -    |

**判定ルール**:

- 最低基準の3指標全てを満たす場合: **PASS** → Phase 8 へ進行
- いずれか1指標でも最低基準を下回る場合: **FAIL** → Phase 6 へ差し戻し

---

### Task 7-3: 未達時のループバック判定

**目的**: カバレッジ基準未達の場合、Phase 6 に戻るための差し戻しレポートを作成する

**ループバック判定テーブル**:

| 条件           | 対応                                       |
| -------------- | ------------------------------------------ |
| Line < 80%     | Phase 6 に戻り、未カバー行のテストを追加   |
| Branch < 60%   | Phase 6 に戻り、未カバー分岐のテストを追加 |
| Function < 80% | Phase 6 に戻り、未カバー関数のテストを追加 |
| 全最低基準達成 | Phase 8（リファクタリング）へ進行          |

**ループバック手順**:

1. カバレッジレポートから未カバー行/分岐/関数を具体的に特定する
2. 各未カバー箇所に対応するテストケースを設計する
3. Phase 6 のテストケーステーブルに追加テストを追記する
4. テスト実装・実行後、再度 Phase 7 でカバレッジを計測する
5. 基準達成まで Phase 6 ↔ Phase 7 を繰り返す
