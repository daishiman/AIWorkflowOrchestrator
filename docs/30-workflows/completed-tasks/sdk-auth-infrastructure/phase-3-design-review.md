## レビュー観点

### 1. 要件との整合性

- [ ] FR-1（暗号化保存）が設計でカバーされている
- [ ] FR-2（query()への認証キー渡し）が設計でカバーされている
- [ ] FR-3（キー未設定時のエラーハンドリング）が設計でカバーされている
- [ ] FR-4（IPC API）が設計でカバーされている
- [ ] NFR-1（セキュリティ要件）が設計に反映されている
- [ ] NFR-2（可用性）が設計に反映されている

### 2. セキュリティ設計

> `04-electron-security.md` に基づく検証

- [ ] 認証キーが Main Process のみでアクセスされる設計
- [ ] Renderer に認証キーが送信されない設計
- [ ] ログに認証キーが含まれない設計
- [ ] `safeStorage` による暗号化が実装される設計
- [ ] 暗号化不可時のフォールバックと警告が設計されている

### 3. 設計品質

- [ ] 単一責務原則（SRP）が守られている
- [ ] インターフェース（IAuthKeyService）が適切に分離されている
- [ ] 依存関係が適切（循環依存なし）
- [ ] 既存 `secureStorage.ts` パターンとの一貫性

### 4. 型安全性

> `02-code-quality.md` に基づく検証

- [ ] TypeScript型が適切に定義されている
- [ ] エラー型（AuthKeyNotSetError, AuthKeyInvalidError）が適切
- [ ] エラーコードが規定範囲（3000-3999）に収まっている
- [ ] Result型パターンとの整合性（必要に応じて）

### 5. IPC設計

> `04-electron-security.md#IPC セキュリティ原則` に基づく検証

- [ ] チャンネル名がホワイトリスト管理される設計
- [ ] 全ハンドラで入力バリデーションが設計されている
- [ ] エラーはサニタイズしてRendererに送る設計
- [ ] Preload Bridge経由のみでアクセスされる設計

### 6. 既知の落とし穴チェック

> `06-known-pitfalls.md` に基づく検証

- [ ] P5（リスナー二重登録）: IPCリスナー登録の設計確認
- [ ] P8（幽霊依存）: 必要なパッケージが明確
- [ ] P12（外部SDK自動処理との競合）: SDK動作への影響確認

### 7. 統合観点

- [ ] SkillExecutor との統合が明確に設計されている
- [ ] 既存のIPCハンドラーアーキテクチャとの整合性
- [ ] エラーハンドリングの統合パターンが一貫している

## レビュー結果判定

| 判定     | 条件                     | 次のアクション            |
| -------- | ------------------------ | ------------------------- |
| PASS     | 全レビュー観点で問題なし | 次のPhaseへ進行           |
| MINOR    | 軽微な指摘あり           | 指摘対応後、次のPhaseへ   |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻る      |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認 |

### 戻り先決定基準

| 問題の種類                   | 戻り先                |
| ---------------------------- | --------------------- |
| 要件の問題（スコープ不明確） | Phase 1（要件定義）   |
| 設計の問題（構造・IF）       | Phase 2（設計）       |
| セキュリティ違反             | Phase 1（要件再確認） |

### 重点検証項目（本タスク固有）

| 検証項目                   | 判定基準                              |
| -------------------------- | ------------------------------------- |
| 認証キーの Renderer 非送信 | CRITICAL: 違反は即座に Phase 1 戻り   |
| safeStorage 暗号化設計     | MAJOR: 未実装は Phase 2 戻り          |
| SkillExecutor 統合設計     | MAJOR: 不明確は Phase 2 戻り          |
| IPC チャンネル設計         | MINOR: 命名規則違反は指摘対応後に進行 |
| エラーコード範囲           | MINOR: 範囲外は指摘対応後に進行       |
