## 目的

UX・実環境動作確認を行い、自動テストでカバーできない観点を検証する。特に、認証キー管理のセキュリティ面とユーザビリティを手動で確認する。

## 背景

自動テストでは検証が難しいユーザー体験・実環境での動作を手動で確認する。認証キー管理は機密情報を扱うため、実際の操作フローでの安全性を確認することが重要。

## 手動テストシナリオ

### 1. 認証キー設定テスト

| #   | 操作                          | 期待結果                                   |
| --- | ----------------------------- | ------------------------------------------ |
| 1   | 有効なAnthropic APIキーを設定 | 設定成功、キーが暗号化保存される           |

| 3   | 空文字列をキーとして設定      | 適切なエラーメッセージが表示される         |
| 4   | 特殊文字を含むキーを設定      | 正しく処理される（保存または適切なエラー） |

### 2. 認証キー検証テスト

| #   | 操作                          | 期待結果                           |
| --- | ----------------------------- | ---------------------------------- |
| 1   | 有効なキーで検証APIを呼び出し | `true` が返され、キーが有効と判定  |
| 2   | 無効なキーで検証APIを呼び出し | `false` が返され、適切なメッセージ |
| 3   | ネットワーク切断状態で検証    | タイムアウトエラーが適切に処理     |

### 3. 認証キー削除テスト

| #   | 操作                       | 期待結果                             |
| --- | -------------------------- | ------------------------------------ |
| 1   | 設定済みキーを削除         | キーが削除され、再取得で null が返る |
| 2   | キー未設定状態で削除を実行 | エラーなく処理される（冪等性）       |

### 4. SDK呼び出しテスト

| #   | 操作                              | 期待結果                             |
| --- | --------------------------------- | ------------------------------------ |
| 1   | キー設定後にSDK query()を実行     | 認証が成功し、SDK呼び出しが完了      |
| 2   | キー未設定でSDK query()を実行     | 明確な認証キー未設定エラーが返される |
| 3   | 無効なキー設定後にSDK query()実行 | 認証エラーが適切にハンドリングされる |

### 5. セキュリティ手動検証

| #   | 検証項目                            | 期待結果                                |
| --- | ----------------------------------- | --------------------------------------- |
| 1   | デベロッパーツールのNetworkタブ確認 | 認証キーが平文で送信されていない        |
| 2   | デベロッパーツールのConsoleログ確認 | 認証キーがログに出力されていない        |
| 3   | electron-storeの保存ファイル確認    | キーが暗号化された状態で保存されている  |
| 4   | IPC通信のモニタリング               | RendererへキーがIPC経由で渡されていない |

### 6. 環境フォールバックテスト（該当環境の場合）

| #   | 操作                                      | 期待結果                       |

| 2   | 環境変数 ANTHROPIC_API_KEY を設定して起動 | 環境変数からキーが読み込まれる |
| 3   | 環境変数フォールバック時のログ確認        | キーがログに露出していない     |
