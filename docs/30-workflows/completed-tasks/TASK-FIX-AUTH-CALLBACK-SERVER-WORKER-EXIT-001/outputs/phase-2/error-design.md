# Phase 2 例外設計表

| ケース                      | 返却/挙動                                          | 方針                       |
| --------------------------- | -------------------------------------------------- | -------------------------- |
| timeout                     | `Callback timeout: no response received` を reject | 待機責務のみ。停止はしない |
| `stop()` 呼び出し時に未起動 | 正常終了                                           | 冪等化                     |
| `server.close()` 失敗       | 例外を外へ投げない                                 | 停止処理は best-effort     |
| code 欠如 callback          | 400 + エラーHTML                                   | 既存仕様維持               |
