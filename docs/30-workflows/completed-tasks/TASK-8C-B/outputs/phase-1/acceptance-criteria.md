## テストケース別受け入れ基準

### TC-SEL-001: スキルセレクター表示

| 項目     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 前提条件 | Electronアプリが起動している                                     |
| 操作     | ChatPanelの表示確認                                              |
| 期待結果 | `role="combobox"` + `aria-haspopup="listbox"` の要素が表示される |
| 検証方法 | `toBeVisible()`                                                  |
| セレクタ | `button[role="combobox"][aria-haspopup="listbox"]`               |

### TC-SEL-002: ドロップダウン開く・スキル一覧表示

| 項目     | 内容                                                    |
| -------- | ------------------------------------------------------- |
| 前提条件 | スキルセレクターが表示されている                        |
| 操作     | セレクターをクリック                                    |
| 期待結果 | `role="listbox"` の要素が表示、「なし」オプションが表示 |
| 検証方法 | `toBeVisible()`, テキスト確認                           |
| セレクタ | `[role="listbox"]`, `text="なし（スキルを使用しない）"` |

### TC-SEL-003: スキル選択

| 項目     | 内容                                                   |
| -------- | ------------------------------------------------------ |
| 前提条件 | ドロップダウンが開いている、test-skillが表示されている |
| 操作     | `test-skill` オプションをクリック                      |
| 期待結果 | セレクターのボタンテキストが `test-skill` を表示       |
| 検証方法 | `toContainText("test-skill")`                          |
| セレクタ | `[role="option"]:has-text("test-skill")`               |

### TC-SEL-004: スキル選択解除

| 項目     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 前提条件 | スキルが選択されている状態                               |
| 操作     | 「なし」オプションをクリック                             |
| 期待結果 | セレクターのボタンテキストが「なし」を表示               |
| 検証方法 | `toContainText("なし")`                                  |
| セレクタ | `[role="option"]:has-text("なし（スキルを使用しない）")` |

### TC-SEL-005: キーボードナビゲーション

| 項目     | 内容                                         |
| -------- | -------------------------------------------- |
| 前提条件 | セレクターにフォーカスがある                 |
| 操作     | ArrowDown → ArrowDown → Enter                |
| 期待結果 | ドロップダウンが閉じ、オプションが選択される |
| 検証方法 | `not.toBeVisible()`, 選択状態確認            |
| 追加検証 | Escape でも閉じることを確認                  |

### TC-SEL-006: 外側クリックで閉じる

| 項目     | 内容                              |
| -------- | --------------------------------- |
| 前提条件 | ドロップダウンが開いている        |
| 操作     | ドロップダウン外の領域をクリック  |
| 期待結果 | ドロップダウンが閉じる            |
| 検証方法 | `not.toBeVisible()`               |
| セレクタ | `body` (position: {x: 10, y: 10}) |

## ARIA属性検証基準

| 属性          | 対象要素       | 期待値           | 検証タイミング |
| ------------- | -------------- | ---------------- | -------------- |
| role          | トリガーボタン | "combobox"       | 初期表示時     |
| aria-haspopup | トリガーボタン | "listbox"        | 初期表示時     |
| aria-expanded | トリガーボタン | "false" → "true" | 開閉時         |
| aria-controls | トリガーボタン | "skill-listbox"  | 初期表示時     |
| role          | ドロップダウン | "listbox"        | 開いた時       |
| role          | オプション     | "option"         | 開いた時       |
| aria-selected | オプション     | "true" / "false" | 選択変更時     |
