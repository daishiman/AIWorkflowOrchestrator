## 実行手順

### 1. 要件抽出

スキル選択UIに対するE2Eテスト要件を抽出する。

**機能要件（FR）**:

| ID    | 要件                                     | 優先度 |
| ----- | ---------------------------------------- | ------ |
| FR-01 | スキルセレクターがChatPanelに表示される  | 高     |
| FR-02 | ドロップダウンが開閉できる               | 高     |
| FR-03 | 利用可能なスキル一覧が表示される         | 高     |
| FR-04 | スキルを選択できる                       | 高     |
| FR-05 | 「なし」を選択してスキル選択を解除できる | 高     |
| FR-06 | キーボードナビゲーションが動作する       | 中     |
| FR-07 | 外側クリックでドロップダウンが閉じる     | 中     |

**非機能要件（NFR）**:

| ID     | 要件                                           | 優先度 |
| ------ | ---------------------------------------------- | ------ |
| NFR-01 | テストは安定して再現可能であること             | 高     |
| NFR-02 | テスト実行時間は10秒以内であること（各ケース） | 中     |
| NFR-03 | アクセシビリティ属性（aria-label等）を検証     | 中     |

### 2. 受け入れ基準作成

| テストケース             | 受け入れ基準                                       |
| ------------------------ | -------------------------------------------------- |
| スキルセレクター表示     | `aria-label="スキルを選択"` の要素が表示されること |
| ドロップダウン開く       | `role="listbox"` の要素が表示されること            |
| スキル選択               | 選択後にセレクターがスキル名を表示すること         |
| スキル選択解除           | 「なし」選択後にセレクターが「なし」を表示すること |
| キーボードナビゲーション | ArrowDown/Enter でスキルを選択できること           |
| 外側クリックで閉じる     | body クリックでドロップダウンが非表示になること    |

### 3. FR/NFR分類

**テスト優先度マトリクス**:

| 優先度 | テストケース                                         |
| ------ | ---------------------------------------------------- |
| P0     | スキルセレクター表示, ドロップダウン開く, スキル選択 |
| P1     | スキル選択解除                                       |
| P2     | キーボードナビゲーション, 外側クリックで閉じる       |
