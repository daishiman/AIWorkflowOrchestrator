## 目的

dead code 削除後のテストカバレッジが維持されていることを確認する。

## 実行タスク

- タスク1: coverage レポートを取得する
- タスク2: AC 群とテスト結果のトレーサビリティを確認する
- タスク3: カバレッジ低下の有無を判定する

## カバレッジ確認方針

dead code 削除のためロジック追加はなく、削除によってカバレッジが向上する（dead code 分のカバレッジ未達が解消される）ことが期待される。

```bash
# カバレッジ付きテスト実行
pnpm --filter @repo/desktop test -- --coverage --reporter=verbose
```

## 確認ポイント

| 確認項目                         | 期待値         | 確認方法                      |
| -------------------------------- | -------------- | ----------------------------- |
| SkillLifecyclePanel のカバレッジ | 削除前以上     | coverage レポート確認         |
| 削除した関数・stateへの参照      | 0件            | grep確認（Phase 5で実施済み） |
| 全体カバレッジ                   | 維持または向上 | coverage レポート確認         |

## 統合テスト連携

- Phase 9 は本Phaseの coverage 結果を品質ゲートへ取り込む
- 低下が見つかった場合は Phase 6 へ戻して targeted 追加を再設計する
