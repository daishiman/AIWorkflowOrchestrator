## 目的

dead code 削除後のコードに追加のリファクタリングが必要かを判断し、必要であれば実施する。

## 実行タスク

- タスク1: 削除後の空行・import・責務境界を点検する
- タスク2: 後続タスクへの handoff に必要な整理だけを実施する
- タスク3: 不要な追加リファクタリングを抑制する

## リファクタリング方針

本タスクは dead code 削除が主目的のため、大規模なリファクタリングは対象外。ただし以下の軽微な整理を検討する。

### 確認項目

| 確認項目                                   | 対処方針                             |
| ------------------------------------------ | ------------------------------------ |
| `useState` インポートが不要になった場合    | インポートを削除する                 |
| 削除によって生じた空行・コメントの整理     | 差分の意味が明確になる範囲で整理する |
| 削除後のコードが読みやすくなっているか確認 | コードレビューで確認                 |
| 後続タスク（RALLY-005）への引き継ぎ事項    | 引き継ぎドキュメントに記載する       |

## 統合テスト連携

- Phase 9 は本Phaseで追加変更があった場合のみ再度 lint/typecheck を要求する
- 追加リファクタリングなしの場合も判断記録を品質根拠として残す
