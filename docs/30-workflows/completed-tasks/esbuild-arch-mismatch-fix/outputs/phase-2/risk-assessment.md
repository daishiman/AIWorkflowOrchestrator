## 詳細分析

### R-3: Volta x64 Node（確定リスク）

**現状**: Volta が x86_64 版 Node.js をインストールしており、`arch -arm64` を使っても
Volta のシムが x64 バイナリを返す。

**影響**: arm64 ネイティブ実行が不可能。

**対策**:

- 即時: x64 で一貫して使用（問題を回避）
- 将来: Volta キャッシュクリア + arm64 シェルで再インストール

### R-5: Rosetta 2 ターミナル（確定リスク）

**現状**: シェルが `i386` (Rosetta 2) で起動されている。

**影響**: 全ての Node.js 実行が x64 になる。

**対策**:

- Terminal.app の場合: 情報ウィンドウ → 「Rosetta を使用して開く」をオフ
- iTerm2 の場合: 同様の設定を確認
- これはユーザーのターミナル設定に依存するため、ドキュメントに記載
