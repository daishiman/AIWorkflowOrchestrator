## 目的

Phase 1〜9 で作成・改善した設計文書群を対象として、設計タスクの集大成として多角的に最終検証を行い、Phase 11（手動テスト）への移行可否を判定する。本 Phase では以下の4軸で評価する。

1. **受入基準（AC-1〜AC-5）の充足確認**: Phase 1 で定義した受入基準が設計に完全に反映されているか
2. **設計完成度の多角的評価**: 要件網羅性・技術実現性・UX 一貫性・保守性の4観点から評価
3. **未実装タスク候補の検出と記録**: 設計スコープ外となった改善点を未タスクとして記録
4. **ゲート判定（PASS/MINOR/MAJOR/CRITICAL）**: Phase 11 移行の可否を明示的に判定

## 実行タスク

- タスク1: 受入基準（AC-1〜AC-5）の充足確認
- タスク2: 設計完成度の多角的評価（要件網羅性・技術実現性・UX 一貫性・保守性）
- タスク3: 未実装タスク候補の検出と記録
- タスク4: ゲート判定と指摘事項の記録

#### 未タスク記録テンプレート

検出した未タスクは以下の形式で記録する。

```markdown
### UT-SKILL-LIFECYCLE-05-NNNN: [タスク名]

| 項目       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| 優先度     | HIGH / MEDIUM / LOW                                    |
| カテゴリ   | 設計補完 / UX 改善 / 技術実装 / ドキュメント           |
| 発見源     | Phase N ステップN の [具体的な箇所]                    |
| 内容       | （検出した問題・改善点の詳細）                         |
| 影響範囲   | （影響するコンポーネント・画面・状態管理等）           |
| 推奨対応   | （対応方針の概要）                                     |
| ブロッカー | 本タスクに対してブロッカーか / Phase 11 移行前提か否か |
```

### ステップ4: ゲート判定（タスク4）

ステップ1〜3 の結果に基づいてゲート判定を実施し、Phase 11 移行可否を決定する。

#### 判定基準

| 判定     | 条件                                                                             | 対応                                               |
| -------- | -------------------------------------------------------------------------------- | -------------------------------------------------- |
| PASS     | AC-1〜AC-5 が全て充足、CRITICAL/MAJOR 指摘 0 件、MINOR 指摘 3 件以下             | Phase 11 へ                                        |
| MINOR    | AC-1〜AC-5 が全て充足、CRITICAL/MAJOR 指摘 0 件、MINOR 指摘 4 件以上             | 未タスク仕様書に変換後 Phase 11 へ（**省略不可**） |
| MAJOR    | AC-1〜AC-5 のいずれかに MAJOR-GAP、または依存契約違反・P31/P48 違反が残存        | 影響範囲に応じて Phase 1-5 へ戻る                  |
| CRITICAL | AC-1〜AC-5 の複数に MAJOR-GAP、または Task01/04 依存契約との根本的整合性問題あり | Phase 1 へ戻り要件再確認                           |

#### CRITICAL 判定チェックリスト

以下のいずれかに該当する場合は CRITICAL 判定とする。

- [ ] Task01 依存契約の禁止事項（settings 例外一般化 / Workspace 探索一覧 / Agent 作成本体）に違反している
- [ ] Task04 の EP-3/EP-4 I/O 型との根本的な不整合が存在する
- [ ] ScoringGate の4段階定義（NEEDS_IMPROVEMENT / SAVE_ALLOWED / USE_ALLOWED / RECOMMENDED）が Task04 と乖離している
- [ ] 3シナリオのうち1つ以上の開始地点〜完了地点が未定義である
- [ ] Workspace → Agent 二段構成が ui-ux-realization.md と根本的に矛盾する

#### MAJOR 判定チェックリスト

以下のいずれかに該当する場合は MAJOR 判定とする。

- [ ] AC-1〜AC-5 のいずれかに MAJOR-GAP が存在する
- [ ] P31 対策（合成 Hook 禁止）が設計に含まれていない
- [ ] P48 対策（配列セレクタへの `useShallow` 適用）が設計に含まれていない
- [ ] `skill:optimize:evaluate` 既存チャネルで EP-3/EP-4 が区別できない根本的な設計欠陥がある
- [ ] コンポーネント責務が Atomic Design から大きく逸脱している

#### MINOR 判定チェックリスト

以下の項目が残存する場合は MINOR 指摘として記録する（各指摘を未タスク仕様書に変換すること）。

- [ ] 設計完成度評価（ステップ2）で「未確認」が残存している
- [ ] 未タスク候補（ステップ3）にブロッカー以外の改善点がある
- [ ] Phase 9 の品質チェックで修正が未完了の曖昧表現が残存している
- [ ] Phase 8 のリンク正規化で「未作成注記」なしの無効リンクが残存している
- [ ] AC チェックリストに MINOR-GAP が存在する
