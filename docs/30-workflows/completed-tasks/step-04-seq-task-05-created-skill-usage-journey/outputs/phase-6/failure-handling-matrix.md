## 設計原則

1. **EP-3/EP-4 は利用をブロックしない**: Task04 ゲート遷移設計に準拠
2. **復旧CTA は常に1つ以上提示**: ユーザーが行き詰まらない設計
3. **二重送信防止**: 復旧操作で同一 IPC が二重に呼ばれない設計
4. **直前状態への復帰可能**: 失敗後に前の画面に戻れる設計
