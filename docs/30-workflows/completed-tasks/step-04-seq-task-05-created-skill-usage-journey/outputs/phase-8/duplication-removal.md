## 一元化詳細

### 1. `ScoreGateBadge`

**正本**: Phase 2 ステップ3「品質表示の埋め込み設計」

正本に含まれる仕様:

- `ScoreGateBadgeProps` インターフェース定義（`gate`, `score`, `size`, `showLabel`）
- `GATE_BADGE_CONFIG` マッピング（4段階 × label/variant/icon）
- 表示モード定義（compact/inline）

**重複削除対象**: Phase 2 ステップ5 コンポーネントツリー

修正前:

```
SkillCenterView
  ├── RecommendedSkillSection
  │   └── SkillCard[] (with ScoreGateBadge: gate, score, size="sm")
```

修正後:

```
SkillCenterView
  ├── RecommendedSkillSection
  │   └── SkillCard[] (with ScoreGateBadge)
```

> `ScoreGateBadge` の仕様は [Phase 2 ステップ3](./../../phase-2-design.md#ステップ3-品質表示の埋め込み設計) を参照

---

### 2. `SkillCard`

**正本**: Phase 2 ステップ2「再利用導線」SkillCard コンポーネント仕様テーブル

正本に含まれる仕様:

- 6要素定義（スキル名 / 説明 / `ScoringGate` バッジ / 最終使用日 / お気に入りスター / クリック動作）
- 各要素の表示ルール（省略文字数、形式、トグル操作）

**重複削除対象**: Phase 2 ステップ5 コンポーネントツリー

修正後: ステップ5のコンポーネントツリーでは `SkillCard[]` と名称のみ記載し、仕様詳細はステップ2を参照する形式に変更

> `SkillCard` の仕様は [Phase 2 ステップ2](./../../phase-2-design.md#skillcard-コンポーネント仕様) を参照

---

### 3. `SkillDetailPanel`

**正本**: Phase 2 ステップ2「再利用導線」スキル詳細パネル セクションテーブル

正本に含まれる仕様:

- 5セクション定義（ヘッダー / スコア詳細 / 説明 / 利用履歴 / CTAバー）
- 各セクションの表示内容

**重複削除対象**: Phase 2 ステップ5 コンポーネントツリー

修正後: ステップ5では `SkillDetailPanel` と名称のみ記載し、セクション詳細はステップ2を参照する形式に変更

> `SkillDetailPanel` の仕様は [Phase 2 ステップ2](./../../phase-2-design.md#スキル詳細パネル) を参照

---

### 4. `PostExecutionActionBar`

**正本**: Phase 2 ステップ4「改善戻りショートカット設計」アクションテーブル

正本に含まれる仕様:

- 4アクション定義（もう一度使う / 改善する / 完了 / terminal で続ける）
- 各アクションの遷移先と渡すコンテキスト

**重複削除対象**: Phase 2 ステップ5 コンポーネントツリー

修正前:

```
PostExecutionActionBar
  ├── RerunButton
  ├── ImproveButton
  ├── CompleteButton
  └── TerminalHandoffButton
```

修正後:

```
PostExecutionActionBar（仕様はステップ4を参照）
```

> `PostExecutionActionBar` の仕様は [Phase 2 ステップ4](./../../phase-2-design.md#agent-実行結果画面からの改善導線) を参照

---

### 5. CTA仕様テーブル

**正本**: Phase 2 ステップ1「今すぐ使う CTA と保存導線」CTA仕様テーブル

正本に含まれる仕様:

- 4種CTA定義（今すぐ使う / 保存して後で使う / 改善してから使う / 改善を推奨）
- 各CTAの表示条件 / 遷移先 / スタイル

**重複削除対象**: Phase 3 ステップ1 要件-設計突合マトリクス

修正後: Phase 3 の突合マトリクスではCTA条件の再掲を削除し、「Phase 2 ステップ1 CTA仕様テーブルと突合し PASS」の判定結果のみ記載する形式に変更

> CTA仕様の正本は [Phase 2 ステップ1](./../../phase-2-design.md#cta-仕様) を参照

## 重複排除サマリー

| 項目                   | 値              |
| ---------------------- | --------------- |
| 重複排除対象           | 5コンポーネント |
| 正本箇所数             | 5箇所           |
| 削除した重複記載箇所数 | 6箇所           |
| 参照リンクへの置換数   | 6箇所           |
| 正本の仕様完全性       | 全5件で確認済み |

重複排除により、各コンポーネントの仕様変更時に更新すべき箇所が1箇所に集約され、仕様ドリフトのリスクが排除された。
