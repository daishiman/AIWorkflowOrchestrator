## 概要

ScoreGateBadge / SkillCard / CTA ボタンの WCAG 2.1 AA 準拠・Apple HIG 準拠のアクセシビリティテストケースを定義する。色だけでなくテキスト・アイコンの3重表現、ARIA ラベル、キーボードナビゲーション、フォーカス状態を検証する。

---

## TC-A11Y-01: ScoreGateBadge の3重表現確認

| 項目               | 内容                                         |
| ------------------ | -------------------------------------------- |
| テストケース ID    | TC-A11Y-01                                   |
| テスト種別         | 設計検証テスト（アクセシビリティ）           |
| 対象コンポーネント | ScoreGateBadge                               |
| WCAG 基準          | 1.4.1 Use of Color（色だけで情報を伝えない） |
| 期待設計           | 以下の3重表現が Props 定義に含まれている:    |

### 3重表現マトリクス

| ScoringGate       | 色 (variant) | ラベル (テキスト) | アイコン     |
| ----------------- | ------------ | ----------------- | ------------ |
| NEEDS_IMPROVEMENT | error (赤)   | 「改善が必要」    | alert-circle |
| SAVE_ALLOWED      | warning (橙) | 「保存可能」      | save         |
| USE_ALLOWED       | success (緑) | 「利用可能」      | check-circle |
| RECOMMENDED       | success (緑) | 「推奨」          | star         |

| 検証項目       | 検証内容                                                                |
| -------------- | ----------------------------------------------------------------------- |
| showLabel prop | デフォルト true で、テキストラベルが常に表示される設計                  |
| アイコン対応   | 4段階全てにアイコン名が設計に含まれていること                           |
| 合否基準       | showLabel がデフォルト true、4段階全てにアイコンが定義されていれば PASS |

## TC-A11Y-02: ScoreGateBadge の ARIA ラベル設計

| 項目               | 内容                                                             |
| ------------------ | ---------------------------------------------------------------- |
| テストケース ID    | TC-A11Y-02                                                       |
| テスト種別         | 設計検証テスト（アクセシビリティ）                               |
| 対象コンポーネント | ScoreGateBadge                                                   |
| WCAG 基準          | 4.1.2 Name, Role, Value                                          |
| 期待設計           | スコア数値が aria-label 属性でスクリーンリーダー向けラベルを持つ |

### ARIA ラベル設計パターン

| ScoringGate       | aria-label 例             |
| ----------------- | ------------------------- |
| NEEDS_IMPROVEMENT | "スコア: 45 (改善が必要)" |
| SAVE_ALLOWED      | "スコア: 72 (保存可能)"   |
| USE_ALLOWED       | "スコア: 85 (利用可能)"   |
| RECOMMENDED       | "スコア: 100 (推奨)"      |

| 検証項目        | 検証内容                                           |
| --------------- | -------------------------------------------------- |
| aria-label 形式 | "スコア: {score} ({gateLabel})" 形式が設計書に定義 |
| role 属性       | span 要素に role="status" が設計に含まれること     |
| 合否基準        | ARIA ラベルの形式が設計書に定義されていれば PASS   |

## TC-A11Y-03: SkillCard のキーボード操作設計

| 項目               | 内容                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| テストケース ID    | TC-A11Y-03                                                                 |
| テスト種別         | 設計検証テスト（アクセシビリティ）                                         |
| 対象コンポーネント | SkillCard                                                                  |
| WCAG 基準          | 2.1.1 Keyboard（全機能がキーボードで操作可能）                             |
| 期待設計           | SkillCard が tabIndex={0} を持ち、Enter/Space キーでクリック動作が発火する |

### キーボード操作仕様

| キー   | 動作                       | 設計要件           |
| ------ | -------------------------- | ------------------ |
| Tab    | SkillCard にフォーカス移動 | tabIndex={0}       |
| Enter  | SkillDetailPanel を開く    | onKeyDown ハンドラ |
| Space  | SkillDetailPanel を開く    | onKeyDown ハンドラ |
| Escape | SkillDetailPanel を閉じる  | パネル内 onKeyDown |

| 合否基準 | キーボードフォーカスとキー操作の設計が Component 仕様に含まれていれば PASS |

## TC-A11Y-04: CTA ボタンのフォーカス状態設計

| 項目               | 内容                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| テストケース ID    | TC-A11Y-04                                                               |
| テスト種別         | 設計検証テスト（アクセシビリティ）                                       |
| 対象コンポーネント | 全 CTA ボタン（今すぐ使う / 保存して後で使う / 改善する / もう一度使う） |
| WCAG 基準          | 2.4.7 Focus Visible                                                      |

### CTA フォーカス状態仕様

| CTA                          | フォーカスリング                          | コントラスト比 |
| ---------------------------- | ----------------------------------------- | -------------- |
| 今すぐ使う (Primary)         | focus:ring-2 ring-[var(--accent-primary)] | 3:1 以上       |
| 保存して後で使う (Secondary) | focus:ring-2 ring-[var(--accent-primary)] | 3:1 以上       |
| 改善する (Warning)           | focus:ring-2 ring-[var(--status-warning)] | 3:1 以上       |
| もう一度使う                 | focus:ring-2 ring-[var(--accent-primary)] | 3:1 以上       |

| disabled 状態 | disabled ボタンはフォーカス不可（tabIndex={-1}）             |
| ------------- | ------------------------------------------------------------ |
| tooltip 連携  | disabled CTA にホバーで理由ツールチップ表示                  |
| 合否基準      | 全 CTA ボタンにフォーカス状態スタイルが定義されていれば PASS |

## TC-A11Y-05: Apple HIG 準拠確認

| 項目            | 内容                              |
| --------------- | --------------------------------- |
| テストケース ID | TC-A11Y-05                        |
| テスト種別      | 設計検証テスト（UI/UX 品質）      |
| 対象            | 全コンポーネントの Apple HIG 準拠 |

### Apple HIG チェックリスト

| #   | チェック項目                    | 検証方法                                 | 合否基準                                                 |
| --- | ------------------------------- | ---------------------------------------- | -------------------------------------------------------- |
| 1   | SkillCard 角丸 8-12px           | component-design.md の borderRadius 定義 | 8px〜12px の範囲内であれば PASS                          |
| 2   | 8px グリッドスペーシング        | component-design.md の spacing 定義      | padding/margin が 8px の倍数であれば PASS                |
| 3   | Apple システムカラー使用        | component-design.md の color 定義        | CSS 変数が Apple HIG System Colors に対応していれば PASS |
| 4   | 全 CTA にホバー・アクティブ状態 | component-design.md の interaction 定義  | hover/active 状態がスタイル定義に含まれていれば PASS     |

| 合否基準 | 4項目全てが Component 仕様に含まれていれば PASS |
