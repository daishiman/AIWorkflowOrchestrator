### 修正方針

B6（「正しく」「正常に」）の修正パターン: テスト合否基準では「何がどの状態になれば PASS か」を具体的に記述する。曖昧な「正しく表示される」を「期待する DOM 要素が期待する属性値で存在する」形式に置き換える。
