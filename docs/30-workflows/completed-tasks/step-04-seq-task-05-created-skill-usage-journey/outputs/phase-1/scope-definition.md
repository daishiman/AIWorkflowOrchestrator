## 1. 対象範囲（In Scope）

### 1.1 設計対象画面

| 画面              | 対象機能                                             |
| ----------------- | ---------------------------------------------------- |
| Skill Creator     | 作成完了後の CTA（今すぐ使う / 保存して後で使う）    |
| Skill Center      | ScoringGate バッジ表示、お気に入り、最近使ったスキル |
| Workspace         | スキル選択連携、EP-3 利用前評価バナー                |
| Agent             | 実行、PostExecutionActionBar、EP-4 利用後再評価      |
| SkillAnalysisView | 改善フローへの遷移先（Task03 管轄、遷移設計のみ）    |

### 1.2 設計対象機能

| 機能カテゴリ   | 具体的な設計範囲                                       |
| -------------- | ------------------------------------------------------ |
| 利用シナリオ   | A: 作成直後利用、B: あとから利用、C: 履歴再利用        |
| 画面遷移フロー | Skill Creator → Workspace → Agent の遷移パス定義       |
| CTA設計        | ScoringGate 4段階 x CTA 4種類 = 16パターンマトリクス   |
| コンポーネント | ScoreGateBadge、SkillCard拡張、PostExecutionActionBar  |
| 状態管理       | favoriteSkillNames、recentlyUsedSkills セレクタ設計    |
| IPC設計        | `skill:optimize:evaluate` 再利用、`skill:list` 再利用  |
| 品質表示       | 7地点での ScoringGate / ScoreDisplay / ScoreDelta 表示 |
| 改善ループ     | 実行結果 → EP-4 → 改善 → EP-2 → 再利用のフロー         |

| Phase | 成果物数 | 主要成果物                                                              |
