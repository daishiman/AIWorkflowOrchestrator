## 目的

Phase 6のテスト拡充後、カバレッジ目標を確実に達成していることを検証する。

- カバレッジ測定: 最終的なテストカバレッジの測定

- レポート作成: カバレッジレポートの最終版作成

## 実行手順

### 1. カバレッジ測定

```bash
# カバレッジ測定コマンド
pnpm --filter @repo/shared test:coverage
```

### 2. カバレッジ確認

| 確認項目                         | 基準 | 結果 |
| -------------------------------- | ---- | ---- |
| Line Coverage ≥ 80%              | 必須 | -    |
| Branch Coverage ≥ 60%            | 必須 | -    |
| Function Coverage ≥ 80%          | 必須 | -    |
| RelevanceEvaluator全関数テスト済 | 必須 | -    |
| CorrectiveRAG全関数テスト済      | 必須 | -    |

### 3. 未達領域の対応

カバレッジ未達の場合:

1. 未到達コードの特定
2. 到達不能コードか検証
3. 到達可能な場合は追加テスト作成
4. 到達不能な場合はコード削除を検討

## 統合テスト連携【必須】

| テストカテゴリ     | 目標 | 達成状況 |

| データフローテスト | 100% | -        |
| エラーハンドリング | 80%+ | -        |
