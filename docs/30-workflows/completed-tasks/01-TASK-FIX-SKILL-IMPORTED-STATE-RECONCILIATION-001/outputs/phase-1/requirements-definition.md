# Phase 1 要件定義書

## タスク

- インポート済みスキル復元の name/id 互換解決

## 機能要件

- ImportManagerが保持するキー形式（id/name）の揺れを吸収し、インポート済み状態を正しく復元する。
- 失敗再現条件を固定し、回帰テストで検証可能にする。

## 非機能要件

- 関心ごとの分離: Main/IPC/Rendererの責務境界を維持する。
- 回帰耐性: 既存契約を壊さず互換性を保つ。

## 問題定義

- getImportedSkills が id 前提で復元しており、旧データ（name保存）でスキルが未追加表示になる。

## 完了判定

- 要件がテスト可能な文に分解されていること。
- 対象ファイル境界が明文化されていること。
