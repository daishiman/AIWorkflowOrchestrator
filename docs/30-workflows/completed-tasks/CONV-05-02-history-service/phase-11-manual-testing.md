## 手動テストシナリオ

### 1. 履歴一覧取得テスト

| #   | 操作                           | 期待結果                         |
| --- | ------------------------------ | -------------------------------- |
| 1   | ファイルIDを指定して履歴を取得 | 履歴一覧が取得できる             |
| 2   | ページネーションを指定して取得 | 指定した件数で分割取得できる     |
| 3   | フィルタ条件を指定して取得     | 条件に合致する履歴のみ取得できる |

### 2. バージョン詳細取得テスト

| #   | 操作                       | 期待結果                   |
| --- | -------------------------- | -------------------------- |
| 1   | 変換IDを指定して詳細を取得 | バージョン詳細が取得できる |
| 2   | 存在しない変換IDを指定     | エラーが返却される         |

### 3. バージョン差分取得テスト

| #   | 操作                          | 期待結果                               |
| --- | ----------------------------- | -------------------------------------- |
| 1   | 2つの変換IDを指定して差分取得 | サイズ変更、メタデータ変更が取得できる |

### 4. バージョン復元テスト

| #   | 操作                         | 期待結果                         |
| --- | ---------------------------- | -------------------------------- |
| 1   | 特定バージョンに復元         | 新しいバージョンとして復元される |
| 2   | 存在しないバージョンに復元   | エラーが返却される               |
| 3   | 別ファイルのバージョンに復元 | エラーが返却される               |
