## 差分一覧

| 項目            | 設計想定                           | 実装結果                                                                   | 理由                                                                                     |
| --------------- | ---------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Import 導線     | SkillCenter へ完全委譲             | ヘッダ右上に既存の `インポート` ボタンを維持                               | 既存 AgentView 利用者の導線断絶を避けつつ、主レイアウトは 3 セクション構成を維持するため |
| Permission mode | 仕様例では拡張モードを含む記述あり | `default` / `acceptEdits` / `bypassPermissions` / `plan` の 4 モードで表示 | 現行 `window.electronAPI.permissions` が返す実契約に合わせた                             |
| 型定義の配置    | 各コンポーネント近傍で定義         | 共通型を `components/organisms/AgentView/types.ts` に集約                  | Phase 8 の保守性改善を前倒しで取り込んだ                                                 |

## 影響評価

- 3セクション構成、検索条件、実行フロー、詳細設定パネルの主要 UX は設計意図と一致
- 差分はいずれも既存契約または保守性の都合に基づくもので、機能後退はない

## 判定

- 重大な設計乖離なし
- 上記 3 件を実装実体として採用
