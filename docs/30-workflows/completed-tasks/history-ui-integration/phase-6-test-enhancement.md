Phase 5の実装に対してテストを拡充し、カバレッジ目標を達成する。

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ測定

**目的**: 現在のテストカバレッジを測定し、不足領域を特定

**実行手順**:

1. カバレッジ測定を実行
2. 未カバーの行/分岐/関数を特定
3. 優先度の高い不足領域をリストアップ

**実行コマンド**:

```bash
pnpm --filter @repo/desktop test:coverage
```

**期待される成果物**:

- カバレッジ分析レポート

---

### タスク2: HistoryPage追加テスト

**目的**: HistoryPageの境界値・異常系テストを追加

**実行手順**:

1. 境界値テスト追加（空の履歴、大量データ等）
2. 異常系テスト追加（API未定義、通信エラー等）
3. インタラクションテスト拡充

**追加テストケース**:

| ケースID | カテゴリ | シナリオ                | 期待結果                     |
| -------- | -------- | ----------------------- | ---------------------------- |
| TS-07    | 境界値   | 履歴が0件の場合         | 空状態メッセージが表示される |
| TS-08    | 境界値   | 大量データ（100件以上） | ページネーションが正しく動作 |
| TS-09    | 異常系   | 復元中に接続エラー      | エラーメッセージが表示される |
| TS-10    | 正常系   | 復元成功後              | 成功通知と履歴再取得         |

**期待される成果物**:

- HistoryPage.test.tsx の拡充
