## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析

**目的**: Lint、型チェック、フォーマットの品質を確認

**実行手順**:

1. ESLint実行
2. TypeScript型チェック
3. Prettier確認

**実行コマンド**:

```bash
# Lint
pnpm --filter @repo/desktop lint

# 型チェック
pnpm --filter @repo/desktop typecheck

# フォーマット確認
pnpm --filter @repo/desktop format:check
```

**期待される成果物**:

- 静的解析結果

---

### タスク2: セキュリティチェック

**目的**: Electron IPCのセキュリティベストプラクティス準拠を確認

**チェック項目**:

| セキュリティ項目 | 確認内容                               | 結果 |
| ---------------- | -------------------------------------- | ---- |
| contextIsolation | preloadでcontextBridge使用             |      |
| nodeIntegration  | レンダラーでNode.js API非使用          |      |
| 入力検証         | IPCハンドラーで入力検証                |      |
| エラー情報       | 詳細エラーをレンダラーに漏洩していない |      |

**期待される成果物**:

- セキュリティチェック結果

---

### タスク3: パフォーマンス確認

**目的**: パフォーマンス目標を満たすことを確認

**パフォーマンス目標**（ui-ux-history-panel.md参照）:

| 指標             | 目標   | 実測 | 判定 |
| ---------------- | ------ | ---- | ---- |
| 初期レンダリング | <100ms |      |      |
| リスト表示       | <200ms |      |      |
| 追加読み込み     | <100ms |      |      |
| フィルタ変更     | <150ms |      |      |

**期待される成果物**:

- パフォーマンス測定結果

---

### タスク4: テスト最終確認

**目的**: 全テストがパスすることを最終確認

**実行コマンド**:

```bash
# 全テスト実行
pnpm --filter @repo/desktop test
```

**期待される成果物**:

- テスト実行結果
