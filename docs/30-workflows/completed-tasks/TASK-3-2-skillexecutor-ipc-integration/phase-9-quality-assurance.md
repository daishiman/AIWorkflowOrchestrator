## 目的

## 背景

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析

**目的**: Lint・型チェック・フォーマットの問題を解消する

**実行手順**:

1. ESLintを実行する

   ```bash
   pnpm --filter @repo/desktop lint
   ```

2. TypeScript型チェックを実行する

   ```bash
   pnpm --filter @repo/desktop typecheck
   ```

3. Prettierでフォーマットを確認する

   ```bash
   pnpm --filter @repo/desktop format:check
   ```

4. 問題があれば修正する

5. 結果を記録する

   | チェック項目 | 結果 | 問題数 |
   | ------------ | ---- | ------ |
   | ESLint       |      |        |
   | TypeScript   |      |        |
   | Prettier     |      |        |

**期待される成果物**:

- `outputs/phase-9/static-analysis-report.md`

---

### タスク2: セキュリティチェック

**目的**: セキュリティの観点からコードを検証する

**実行手順**:

1. IPC通信のセキュリティ確認

   | チェック項目    | 確認内容                         | 結果 |
   | --------------- | -------------------------------- | ---- |
   | 入力検証        | SkillStreamMessageの検証があるか |      |
   | executionId検証 | UUIDフォーマット検証があるか     |      |
   | エラー情報      | 内部情報が漏洩していないか       |      |

2. XSS対策の確認

   | チェック項目   | 確認内容                                  | 結果 |
   | -------------- | ----------------------------------------- | ---- |
   | メッセージ表示 | dangerouslySetInnerHTMLを使用していないか |      |
   | ユーザー入力   | 適切にサニタイズされているか              |      |

3. 問題があれば修正する

**期待される成果物**:

- `outputs/phase-9/security-check-report.md`

---

### タスク3: パフォーマンスチェック

**目的**: パフォーマンスの観点からコードを検証する

**実行手順**:

1. React再レンダリングの確認

   | チェック項目 | 確認内容                     | 結果 |
   | ------------ | ---------------------------- | ---- |
   | useCallback  | 適切に使用されているか       |      |
   | useMemo      | 適切に使用されているか       |      |
   | React.memo   | 必要な箇所で使用されているか |      |

2. メモリリークの確認

   | チェック項目     | 確認内容                               | 結果 |
   | ---------------- | -------------------------------------- | ---- |
   | イベントリスナー | useEffect cleanupで解除されているか    |      |
   | タイマー         | clearTimeout/clearIntervalされているか |      |
   | 参照             | 不要な参照が保持されていないか         |      |

3. 大量メッセージ対応

   | チェック項目 | 確認内容                           | 結果 |
   | ------------ | ---------------------------------- | ---- |
   | 仮想化       | 大量メッセージで仮想化が必要か検討 |      |
   | バッチ更新   | 高頻度更新でバッチ処理が必要か検討 |      |

**期待される成果物**:

- `outputs/phase-9/performance-check-report.md`
