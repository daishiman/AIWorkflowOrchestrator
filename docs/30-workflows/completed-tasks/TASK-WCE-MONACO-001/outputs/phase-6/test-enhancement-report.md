## テストケース一覧

### 正常系テスト

1. エディタを設定できる
2. 設定したエディタを取得できる
3. 選択範囲がある時にTextSelectionを返す
4. 複数行選択時にstartLine < endLineになる
5. 単一行内選択時に正しいカラム番号を返す
6. selectedTextが選択範囲の文字列と一致する
7. 日本語テキストを正しく取得できる
8. 1文字のみの選択を正しく取得できる

### 異常系テスト

1. nullでエディタをクリアできる
2. エディタ未設定時はnullを返す
3. 選択がない時（カーソルのみ）にnullを返す
4. エディタがnullの時にnullを返す
5. getSelection()がnullを返す時にnullを返す
6. getModel()がnullを返す時にnullを返す
7. BrowserWindowがない場合にnullを返す
8. executeJavaScriptがエラーをスローした場合にnullを返す
9. 検証失敗時にエラーをスローする

### 境界値テスト

1. 1文字のみの選択
2. 日本語テキストの選択
3. 1行目からの選択
