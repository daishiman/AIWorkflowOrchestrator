## 検証手順

1. 開発サーバーを起動: `pnpm --filter @repo/desktop dev`
2. スキル実行を開始し、複数のメッセージをコピー
3. 履歴パネルを開き、履歴が表示されることを確認
4. 履歴項目をクリックして再コピーを確認
5. 複数選択して一括コピーを確認
6. クリアボタンで履歴が削除されることを確認
7. キーボード操作を確認
8. 既存機能（CopyButton、タイムスタンプ、スピナー）が正常動作することを確認
