## 1. CopyHistoryContext テスト（6件）

### TC-401: コピー時に履歴に追加される

| 項目     | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| 前提条件 | 履歴が空の状態                                              |
| 操作     | addToHistory('test content') を呼び出す                     |
| 期待結果 | history.length === 1、history[0].content === 'test content' |
| 確認項目 | id, timestamp が自動生成されること                          |

### TC-402: 51件目のコピーで最古の履歴が削除される

| 項目     | 内容                                    |
| -------- | --------------------------------------- |
| 前提条件 | 履歴が50件の状態                        |
| 操作     | addToHistory('51st content') を呼び出す |
| 期待結果 | history.length === 50、最古の項目が削除 |
| 確認項目 | 最新項目が先頭に追加されること          |

### TC-403: removeFromHistory で指定項目が削除される

| 項目     | 内容                                    |
| -------- | --------------------------------------- |
| 前提条件 | 履歴に3件の項目がある状態               |
| 操作     | removeFromHistory('entry-2') を呼び出す |
| 期待結果 | history.length === 2、entry-2 が削除    |
| 確認項目 | 他の項目は影響を受けないこと            |

### TC-404: clearHistory で全履歴が削除される

| 項目     | 内容                       |
| -------- | -------------------------- |
| 前提条件 | 履歴に3件の項目がある状態  |
| 操作     | clearHistory() を呼び出す  |
| 期待結果 | history.length === 0       |
| 確認項目 | selectedIds も空になること |

### TC-405: toggleSelection で選択状態がトグル

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| 前提条件 | 履歴に3件、選択なしの状態                |
| 操作     | toggleSelection('entry-1') を2回呼び出す |
| 期待結果 | 1回目: 選択追加、2回目: 選択解除         |
| 確認項目 | selectedIds.has('entry-1') の値          |

### TC-406: clearSelection で全選択解除

| 項目     | 内容                         |
| -------- | ---------------------------- |
| 前提条件 | 履歴に3件、2件選択の状態     |
| 操作     | clearSelection() を呼び出す  |
| 期待結果 | selectedIds.size === 0       |
| 確認項目 | 履歴自体は影響を受けないこと |
