## 3. インタラクション設計

### 3.1 パネル開閉

| トリガー         | 動作               |
| ---------------- | ------------------ |
| トグルクリック   | パネル開閉をトグル |
| Escape キー      | パネルを閉じる     |
| パネル外クリック | パネルを閉じる     |

### 3.2 項目操作

| 操作                 | 動作             |
| -------------------- | ---------------- |
| チェックボックス     | 選択状態をトグル |
| 項目クリック         | 再コピー実行     |
| コピーボタンクリック | 再コピー実行     |

### 3.3 アクション操作

| 操作         | 動作                 | 条件          |
| ------------ | -------------------- | ------------- |
| 選択をコピー | 選択項目を結合コピー | 1件以上選択時 |
| クリア       | 全履歴削除           | 1件以上履歴時 |

### 3.4 フィードバック

| イベント       | フィードバック                | 持続時間 |
| -------------- | ----------------------------- | -------- |
| コピー成功     | 「コピーしました」トースト    | 2秒      |
| 一括コピー成功 | 「N件コピーしました」トースト | 2秒      |
| クリア成功     | 視覚的な空状態表示            | 即時     |

## 4. アクセシビリティ設計

### 4.1 ARIA属性

| 要素             | ARIA属性                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| パネル           | `role="dialog"`, `aria-label="コピー履歴"`, `aria-modal="true"`            |
| 履歴リスト       | `role="listbox"`, `aria-multiselectable="true"`                            |
| 履歴項目         | `role="option"`, `aria-selected`                                           |
| チェックボックス | `role="checkbox"`, `aria-checked`                                          |
| トグルボタン     | `aria-label="コピー履歴を開く"`, `aria-expanded`, `aria-haspopup="dialog"` |
| 閉じるボタン     | `aria-label="パネルを閉じる"`                                              |
| コピーボタン     | `aria-label="この項目をコピー"`                                            |
| 選択コピーボタン | `aria-label="選択項目をコピー"`                                            |
| クリアボタン     | `aria-label="履歴をクリア"`                                                |

### 4.2 キーボードナビゲーション

| キー      | パネル開時の動作         |
| --------- | ------------------------ |
| Tab       | フォーカス移動（順方向） |
| Shift+Tab | フォーカス移動（逆方向） |
| Escape    | パネルを閉じる           |
| ArrowUp   | 前の項目にフォーカス     |
| ArrowDown | 次の項目にフォーカス     |
| Space     | チェックボックスをトグル |
| Enter     | 項目をコピー             |
| Ctrl+A    | 全選択                   |

### 4.3 フォーカストラップ

パネル表示中は、Tabキーでのフォーカスがパネル内に留まるようにする。

| フォーカス順序 | 要素                         |
| -------------- | ---------------------------- |
| 1              | 閉じるボタン                 |
| 2-N            | 履歴項目（チェックボックス） |
| N+1            | 選択コピーボタン             |
| N+2            | クリアボタン                 |
| → 1に戻る      | 閉じるボタン                 |

## 6. アニメーション

### 6.1 パネル開閉

| 動作   | アニメーション                  | 持続時間 |
| ------ | ------------------------------- | -------- |
| 開く   | フェードイン + スライドダウン   | 150ms    |
| 閉じる | フェードアウト + スライドアップ | 100ms    |

**Tailwind CSS クラス**

```css
/* 開く時 */
.panel-enter {
  animation: panelEnter 150ms ease-out;
}

@keyframes panelEnter {
  from {
    opacity: 0;
    transform: translateY(-8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 6.2 項目ホバー

| 動作       | アニメーション | 持続時間 |
| ---------- | -------------- | -------- |
| ホバー開始 | 背景色変更     | 100ms    |
| ホバー終了 | 背景色変更     | 100ms    |

**Tailwind CSS クラス**: `transition-colors duration-100`
