## 1. 機能要件（Functional Requirements）

### 1.1 要件一覧

| FR-ID | 要件                                        | 優先度 | 関連課題 |
| ----- | ------------------------------------------- | ------ | -------- |
| FR-01 | コピー履歴パネルを表示できる                | 高     | C1       |
| FR-02 | 履歴項目をクリックして再度コピーできる      | 高     | C3       |
| FR-03 | 複数メッセージを選択して一括コピーできる    | 中     | C2       |
| FR-04 | 履歴を手動でクリアできる                    | 中     | -        |
| FR-05 | 最大50件まで履歴を保持する                  | 中     | C1       |
| FR-06 | 履歴項目にプレビュー（最初の100文字）を表示 | 低     | -        |

### 1.2 要件詳細

#### FR-01: コピー履歴パネル表示

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| トリガー   | 履歴アイコンボタンのクリック                 |
| 表示形式   | ポップオーバーパネル                         |
| 表示内容   | 履歴項目一覧、クリアボタン、一括コピーボタン |
| 閉じる条件 | Escapeキー押下、パネル外クリック             |
| 空状態     | 「履歴がありません」メッセージ表示           |

#### FR-02: 履歴項目からの再コピー

| 項目           | 内容                             |
| -------------- | -------------------------------- |
| トリガー       | 履歴項目のクリック               |
| 動作           | 対象内容をクリップボードにコピー |
| フィードバック | 「コピーしました」を2秒間表示    |
| API            | navigator.clipboard.writeText()  |

#### FR-03: 複数選択一括コピー

| 項目       | 内容                               |
| ---------- | ---------------------------------- |
| 選択方法   | チェックボックスによる複数選択     |
| コピー形式 | 選択項目を改行区切りで結合         |
| 結合順序   | 選択順（最初に選択したものが先頭） |
| 最大選択数 | 制限なし（全50件選択可能）         |

#### FR-04: 履歴クリア

| 項目     | 内容                           |
| -------- | ------------------------------ |
| トリガー | 「クリア」ボタンのクリック     |
| 動作     | 全履歴を削除                   |
| 確認     | 即時実行（確認ダイアログなし） |

#### FR-05: 履歴件数管理

| 項目       | 内容                         |
| ---------- | ---------------------------- |
| 最大件数   | 50件                         |
| 超過時動作 | 最古の履歴を自動削除（FIFO） |
| 順序       | 新しい順（最新が先頭）       |

#### FR-06: プレビュー表示

| 項目       | 内容                               |
| ---------- | ---------------------------------- |
| 表示文字数 | 最初の100文字                      |
| 省略表示   | 100文字を超える場合は「...」を付加 |
| 改行の扱い | 改行を空白に置換して表示           |

## 2. 非機能要件（Non-Functional Requirements）

### 2.1 要件一覧

| NFR-ID | 要件                                         | 優先度 | カテゴリ         |
| ------ | -------------------------------------------- | ------ | ---------------- |
| NFR-01 | 既存CopyButton機能を維持する                 | 高     | 後方互換性       |
| NFR-02 | キーボード操作に対応する（Tab/Enter/Escape） | 高     | アクセシビリティ |
| NFR-03 | スクリーンリーダー対応（aria-label等）       | 高     | アクセシビリティ |
| NFR-04 | 履歴追加時のUI遅延を100ms以下に抑える        | 中     | パフォーマンス   |
| NFR-05 | メモリ使用量を抑制する（50件上限）           | 中     | リソース管理     |

### 2.2 要件詳細

#### NFR-01: 後方互換性

| 項目     | 内容                                    |
| -------- | --------------------------------------- |
| 対象機能 | CopyButtonの既存コピー機能              |
| 検証方法 | 既存テストの全PASS確認                  |
| 影響範囲 | MessageItem内のCopyButtonコンポーネント |

#### NFR-02: キーボード操作

| キー        | 動作                                   |
| ----------- | -------------------------------------- |
| Tab         | フォーカス移動（履歴項目間、ボタン間） |
| Enter/Space | 選択/実行                              |
| Escape      | パネルを閉じる                         |
| Ctrl+A      | 全選択（パネル内フォーカス時）         |

#### NFR-03: スクリーンリーダー対応

| 要素             | aria属性                       |
| ---------------- | ------------------------------ |
| 履歴パネル       | aria-label="コピー履歴"        |
| 履歴項目         | role="listitem", aria-selected |
| チェックボックス | aria-checked                   |
| クリアボタン     | aria-label="履歴をクリア"      |
| 一括コピーボタン | aria-label="選択項目をコピー"  |

#### NFR-04: パフォーマンス

| メトリクス | 目標値                  |
| ---------- | ----------------------- |
| 履歴追加   | 100ms以下               |
| パネル表示 | 100ms以下               |
| 一括コピー | 200ms以下（50件選択時） |

#### NFR-05: リソース管理

| 項目       | 内容                     |
| ---------- | ------------------------ |
| メモリ管理 | 50件超過時は自動削除     |
| 永続化     | なし（セッション内のみ） |
| GC対応     | 履歴削除時は参照を解放   |

## 3. 接続要件

### 3.1 状態管理

| 項目         | 内容                                           |
| ------------ | ---------------------------------------------- |
| Context      | CopyHistoryContext                             |
| Provider配置 | App.tsx または AgentView レベル                |
| 状態構造     | { items: CopyHistoryItem[], selectedIds: Set } |

### 3.2 API連携

| API           | 用途                            |
| ------------- | ------------------------------- |
| Clipboard API | navigator.clipboard.writeText() |
| React Context | 履歴状態のグローバル管理        |

### 3.3 データフロー

```
CopyButton.onClick()
    ↓
CopyHistoryContext.addItem(content)
    ↓
state.items に追加（最大50件管理）
    ↓
CopyHistoryPanel が状態を購読・表示
```
