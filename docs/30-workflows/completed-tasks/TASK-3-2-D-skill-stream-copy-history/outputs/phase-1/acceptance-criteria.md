## 1. 機能要件の受け入れ基準

### AC-FR-01: コピー履歴パネル表示

| AC-ID      | 受け入れ基準                                             | 検証方法       |
| ---------- | -------------------------------------------------------- | -------------- |
| AC-FR-01-1 | 履歴アイコンをクリックするとポップオーバーパネルが開く   | 手動テスト     |
| AC-FR-01-2 | パネルには履歴項目一覧が表示される                       | 手動テスト     |
| AC-FR-01-3 | パネルにはクリアボタンと一括コピーボタンが表示される     | ユニットテスト |
| AC-FR-01-4 | Escapeキーでパネルが閉じる                               | ユニットテスト |
| AC-FR-01-5 | パネル外をクリックするとパネルが閉じる                   | ユニットテスト |
| AC-FR-01-6 | 履歴が空の場合「履歴がありません」メッセージが表示される | ユニットテスト |

### AC-FR-02: 履歴項目からの再コピー

| AC-ID      | 受け入れ基準                                               | 検証方法       |
| ---------- | ---------------------------------------------------------- | -------------- |
| AC-FR-02-1 | 履歴項目をクリックするとクリップボードに内容がコピーされる | ユニットテスト |
| AC-FR-02-2 | コピー後「コピーしました」フィードバックが表示される       | ユニットテスト |
| AC-FR-02-3 | フィードバックは2秒後に消える                              | ユニットテスト |

### AC-FR-03: 複数選択一括コピー

| AC-ID      | 受け入れ基準                                                   | 検証方法       |
| ---------- | -------------------------------------------------------------- | -------------- |
| AC-FR-03-1 | チェックボックスで複数の履歴項目を選択できる                   | ユニットテスト |
| AC-FR-03-2 | 「一括コピー」ボタンをクリックすると選択項目が結合コピーされる | ユニットテスト |
| AC-FR-03-3 | 結合は改行区切りで行われる                                     | ユニットテスト |
| AC-FR-03-4 | 結合順序は選択順である                                         | ユニットテスト |
| AC-FR-03-5 | 選択項目がない場合、一括コピーボタンは無効化される             | ユニットテスト |

### AC-FR-04: 履歴クリア

| AC-ID      | 受け入れ基準                                       | 検証方法       |
| ---------- | -------------------------------------------------- | -------------- |
| AC-FR-04-1 | 「クリア」ボタンをクリックすると全履歴が削除される | ユニットテスト |
| AC-FR-04-2 | クリア後、履歴パネルは空状態を表示する             | ユニットテスト |

### AC-FR-05: 履歴件数管理

| AC-ID      | 受け入れ基準                                 | 検証方法       |
| ---------- | -------------------------------------------- | -------------- |
| AC-FR-05-1 | 51件目のコピー時に最古の履歴が自動削除される | ユニットテスト |
| AC-FR-05-2 | 履歴は常に最大50件を超えない                 | ユニットテスト |
| AC-FR-05-3 | 履歴は新しい順（最新が先頭）で表示される     | ユニットテスト |

### AC-FR-06: プレビュー表示

| AC-ID      | 受け入れ基準                                       | 検証方法       |
| ---------- | -------------------------------------------------- | -------------- |
| AC-FR-06-1 | 100文字を超えるコンテンツは「...」で省略表示される | ユニットテスト |
| AC-FR-06-2 | 100文字以下のコンテンツはそのまま表示される        | ユニットテスト |
| AC-FR-06-3 | 改行は空白に置換されて表示される                   | ユニットテスト |

## 2. 非機能要件の受け入れ基準

### AC-NFR-01: 後方互換性

| AC-ID       | 受け入れ基準                                 | 検証方法   |
| ----------- | -------------------------------------------- | ---------- |
| AC-NFR-01-1 | 既存のCopyButtonテストが全てPASSする         | CIテスト   |
| AC-NFR-01-2 | CopyButtonの単体コピー機能が従来通り動作する | 手動テスト |

### AC-NFR-02: キーボード操作

| AC-ID       | 受け入れ基準                                           | 検証方法       |
| ----------- | ------------------------------------------------------ | -------------- |
| AC-NFR-02-1 | Tabキーでフォーカスが履歴項目間を移動する              | ユニットテスト |
| AC-NFR-02-2 | Enterキーで履歴項目を選択/コピーできる                 | ユニットテスト |
| AC-NFR-02-3 | Escapeキーでパネルを閉じられる                         | ユニットテスト |
| AC-NFR-02-4 | Spaceキーでチェックボックスのオン/オフを切り替えられる | ユニットテスト |

### AC-NFR-03: スクリーンリーダー対応

| AC-ID       | 受け入れ基準                                           | 検証方法       |
| ----------- | ------------------------------------------------------ | -------------- |
| AC-NFR-03-1 | 履歴パネルにaria-label="コピー履歴"が設定されている    | ユニットテスト |
| AC-NFR-03-2 | 各履歴項目にrole="listitem"が設定されている            | ユニットテスト |
| AC-NFR-03-3 | スクリーンリーダーで各要素の役割と状態が読み上げられる | 手動テスト     |

### AC-NFR-04: パフォーマンス

| AC-ID       | 受け入れ基準                            | 検証方法             |
| ----------- | --------------------------------------- | -------------------- |
| AC-NFR-04-1 | 履歴追加時のUI更新が100ms以内に完了する | パフォーマンステスト |
| AC-NFR-04-2 | パネル表示が100ms以内に完了する         | パフォーマンステスト |

### AC-NFR-05: リソース管理

| AC-ID       | 受け入れ基準                                     | 検証方法       |
| ----------- | ------------------------------------------------ | -------------- |
| AC-NFR-05-1 | 50件を超える履歴は自動的に古いものから削除される | ユニットテスト |
| AC-NFR-05-2 | 履歴はセッション内のみ保持され、リロードで消える | 手動テスト     |
