# Phase 1: 要件定義サマリー

## 実行日: 2026-02-03

## 1. タスク概要

| 項目       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| タスクID   | TASK-9A-A                                              |
| タスク名   | SkillFileManager 実装                                  |
| 目的       | スキルファイルの読み書き・バックアップ・復元を管理する |
| 前提タスク | TASK-7D                                                |
| 後続タスク | TASK-9A-B                                              |

## 2. 機能要件

| ID   | 機能名           | 説明                                       | 優先度 | 状況 |
| ---- | ---------------- | ------------------------------------------ | ------ | ---- |
| F-01 | ファイル読み込み | スキル内の相対パスでファイル内容を取得     | 必須   | 対応 |
| F-02 | ファイル書き込み | 既存ファイルの更新（バックアップ自動作成） | 必須   | 対応 |
| F-03 | ファイル作成     | 新規ファイルの作成（重複チェック付き）     | 必須   | 対応 |
| F-04 | ファイル削除     | ファイルの削除（バックアップ自動作成）     | 必須   | 対応 |
| F-05 | バックアップ一覧 | スキル内のバックアップファイル一覧を取得   | 必須   | 対応 |
| F-06 | バックアップ復元 | バックアップからファイルを復元             | 必須   | 対応 |

## 3. セキュリティ要件

| ID    | 要件                         | 説明                                   | 状況 |
| ----- | ---------------------------- | -------------------------------------- | ---- |
| SEC-1 | パストラバーサル防止         | `../` を含むパスを検出してエラーを返す | 対応 |
| SEC-2 | 読み取り専用ディレクトリ保護 | `~/.claude/skills/` への書き込みを禁止 | 対応 |
| SEC-3 | シンボリックリンク検証       | リンク先がベースパス外なら操作を拒否   | 対応 |

## 4. 非機能要件

| ID    | 要件           | 基準                                   | 状況 |
| ----- | -------------- | -------------------------------------- | ---- |
| NF-01 | パフォーマンス | 単一ファイル操作は100ms以内に完了      | 対応 |
| NF-02 | 信頼性         | バックアップ作成は書き込み前に必ず完了 | 対応 |
| NF-03 | テスタビリティ | ファイルシステム操作をモック可能な設計 | 対応 |

## 5. ファイル操作対象

| パス                    | 操作             | 説明                          |
| ----------------------- | ---------------- | ----------------------------- |
| `~/.aiworkflow/skills/` | 読み書き可能     | アプリ独自スキル（編集可能）  |
| `~/.claude/skills/`     | **読み取り専用** | Claude CLI スキル（編集不可） |

## 6. 出力成果物

| 種類           | パス                                                                      |
| -------------- | ------------------------------------------------------------------------- |
| 実装ファイル   | `apps/desktop/src/main/services/skill/SkillFileManager.ts`                |
| エラー定義     | `apps/desktop/src/main/services/skill/errors.ts`（追加）                  |
| テストファイル | `apps/desktop/src/main/services/skill/__tests__/SkillFileManager.test.ts` |

## 7. 制約事項

| ID   | 制約                                                               |
| ---- | ------------------------------------------------------------------ |
| C-01 | `~/.claude/skills/` は Claude CLI が管理するため編集不可           |
| C-02 | バックアップファイル名は `.backup.{timestamp}` 形式とする          |
| C-03 | 削除時のバックアップファイル名は `.deleted.{timestamp}` 形式とする |
