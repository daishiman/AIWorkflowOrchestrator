# Phase 7: テストカバレッジ確認

## 1. カバレッジ目標

| メトリクス        | 目標値 | 根拠                   |
| ----------------- | ------ | ---------------------- |
| Line Coverage     | ≥80%   | プロジェクト標準       |
| Branch Coverage   | ≥80%   | 条件分岐の網羅性確保   |
| Function Coverage | ≥90%   | 全メソッドのテスト必須 |

## 2. カバレッジ計測コマンド

```bash
# カバレッジ付きテスト実行
pnpm --filter @repo/desktop test:coverage SkillFileManager

# 詳細レポート生成
pnpm --filter @repo/desktop test:coverage --reporter=html SkillFileManager
```

## 3. 重点カバレッジ対象

### 3.1 必須カバレッジ対象メソッド

| メソッド      | 必須カバレッジ | 理由                     |
| ------------- | -------------- | ------------------------ |
| constructor   | 100%           | 初期化ロジックの完全性   |
| findSkillDir  | 100%           | 全分岐のテスト必須       |
| validatePath  | 100%           | セキュリティクリティカル |
| readFile      | 90%            | エラーハンドリング含む   |
| writeFile     | 90%            | バックアップ連携含む     |
| createFile    | 90%            | 重複チェック含む         |
| deleteFile    | 90%            | バックアップ連携含む     |
| listBackups   | 80%            | 再帰処理含む             |
| restoreBackup | 90%            | パス解析ロジック含む     |
| isReadonly    | 100%           | シンプルなロジック       |

### 3.2 分岐カバレッジ重点箇所

| 箇所          | 必要な分岐テスト                     |
| ------------- | ------------------------------------ |
| findSkillDir  | aiworkflow存在/不在、claude存在/不在 |
| validatePath  | 正常パス、トラバーサルパス           |
| writeFile     | 新規作成、上書き（バックアップあり） |
| createFile    | 新規作成、既存エラー                 |
| deleteFile    | 正常削除、ファイル不在               |
| restoreBackup | .backup パターン、.deleted パターン  |

## 4. カバレッジギャップ分析

### 4.1 未カバー領域の特定

```bash
# 未カバー行の特定
pnpm --filter @repo/desktop test:coverage --reporter=text SkillFileManager | grep -E "^\s+\d+\s+\|"
```

### 4.2 ギャップ解消アクション

| ギャップ種類       | 対応方法                         |
| ------------------ | -------------------------------- |
| エラーハンドリング | エラー条件を強制するモックを追加 |
| 条件分岐           | 各分岐を通るテストケースを追加   |
| 例外経路           | 例外をスローする条件をテスト     |
