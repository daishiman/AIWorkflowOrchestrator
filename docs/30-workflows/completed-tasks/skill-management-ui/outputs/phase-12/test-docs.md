```

        │    E2E     │  少

        ├─────────────┤

        │   Vitest   │

```

### 使用ツール

| 種類       | ツール                         |
| ---------- | ------------------------------ |
| ユニット   | Vitest + React Testing Library |
| 統合       | Vitest + MSW                   |
| E2E        | Playwright                     |
| カバレッジ | @vitest/coverage-v8            |

---

## 2. テスト実行方法

### ユニットテスト

```bash
# 全テスト実行
pnpm --filter @repo/desktop test

# ウォッチモード
pnpm --filter @repo/desktop test:watch

# 特定ファイル
pnpm --filter @repo/desktop test SkillCard
```

### カバレッジレポート

```bash
# カバレッジ付き実行
pnpm --filter @repo/desktop test:coverage

# レポート確認
open apps/desktop/coverage/index.html
```

### E2Eテスト

```bash
# E2E実行（ヘッドレス）
pnpm --filter @repo/desktop test:e2e

# E2E実行（UI表示）
pnpm --filter @repo/desktop test:e2e --headed
```
