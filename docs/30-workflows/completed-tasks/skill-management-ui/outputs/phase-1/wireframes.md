## WF-003: スキルカード

個別のスキルを表示するカードコンポーネント。

```
┌────────────────────────────────┐
│                                │
│  📦 tdd-principles             │
│                                │
│  TDD原則に従った開発を支援する │
│  スキル。Red-Green-Refactor... │
│                                │
│  ┌──────┐ ┌─────┐ ┌──────────┐ │
│  │ Test │ │ TDD │ │ +2 more  │ │
│  └──────┘ └─────┘ └──────────┘ │
│                                │
└────────────────────────────────┘

通常状態

┌────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  ← フォーカスリング（2px）
│                                │
│  📦 tdd-principles             │
│                                │
│  TDD原則に従った開発を支援する │
│  スキル。Red-Green-Refactor... │
│                                │
│  ┌──────┐ ┌─────┐ ┌──────────┐ │
│  │ Test │ │ TDD │ │ +2 more  │ │
│  └──────┘ └─────┘ └──────────┘ │
│                                │
└────────────────────────────────┘

フォーカス/選択状態
```

### カード仕様

| 要素           | スタイル                  | 備考                    |
| -------------- | ------------------------- | ----------------------- |
| 幅             | 280px (min)               | フレキシブル            |
| 高さ           | auto                      | コンテンツに応じる      |
| パディング     | 16px                      | 全方向                  |
| 角丸           | 8px                       | border-radius           |
| シャドウ       | 0 2px 8px rgba(0,0,0,0.1) | 通常時                  |
| ホバー         | scale(1.02), shadow強調   | トランジション200ms     |
| 説明省略       | 2行                       | text-overflow: ellipsis |
| カテゴリバッジ | 最大3つ表示               | +N more で残り表示      |

│ Card 1 │ │ Card 2 │ │ Card 3 │ │ Card 4 │ │ Panel  │
└────────┘ └────────┘ └────────┘ └────────┘ │        │
```

```
┌──────────┐ ┌──────────┐ ┌──────────┐ │ Detail │
│ Card 1   │ │ Card 2   │ │ Card 3   │ │ Panel  │
└──────────┘ └──────────┘ └──────────┘ │        │

│ Card 1       │ │ Card 2       │
