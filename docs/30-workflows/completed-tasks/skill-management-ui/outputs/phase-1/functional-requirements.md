## 機能要件一覧

### FR-001: スキルインポートダイアログ

| 項目   | 内容                                                            |
| ------ | --------------------------------------------------------------- |
| ID     | FR-001                                                          |
| 機能名 | スキルインポートダイアログ                                      |
| 説明   | `.claude/skills/`配下のスキルを選択してインポートするダイアログ |
| 優先度 | 高                                                              |
| 入力   | ユーザー操作（「スキルをインポート」ボタンクリック）            |
| 出力   | 選択したスキルがインポート済みリストに追加される                |

**詳細要件**:

- ダイアログは中央にモーダル表示される
- `.claude/skills/`配下の全スキルを一覧表示する
- スキルごとにチェックボックスで選択/解除できる
- 検索バーでスキル名をフィルタリングできる
- 「インポート」ボタンで選択スキルを一括インポート
- 「キャンセル」ボタンでダイアログを閉じる
- ESCキーでダイアログを閉じられる

---

### FR-002: スキル一覧表示

| 項目   | 内容                                           |
| ------ | ---------------------------------------------- |
| ID     | FR-002                                         |
| 機能名 | スキル一覧表示（カード形式）                   |
| 説明   | インポート済みスキルをカード形式で一覧表示する |
| 優先度 | 高                                             |
| 入力   | AgentView画面アクセス                          |
| 出力   | インポート済みスキルのカード一覧               |

**詳細要件**:

- スキルはカード形式でグリッドレイアウト表示
- 各カードに表示する情報:
  - スキル名
  - 説明（省略表示）
  - カテゴリバッジ
  - Triggerキーワード（最大3つ）
- カードはレスポンシブにリフロー（4列→3列→2列→1列）
- スキルが0件の場合は空状態メッセージを表示
- ローディング中はスケルトンスクリーンを表示

---

### FR-003: スキル検索

| 項目   | 内容                                    |
| ------ | --------------------------------------- |
| ID     | FR-003                                  |
| 機能名 | スキル検索機能                          |
| 説明   | スキル名・Triggerキーワードで検索できる |
| 優先度 | 高                                      |
| 入力   | 検索バーへのテキスト入力                |
| 出力   | 検索条件に一致するスキルのみ表示        |

**詳細要件**:

- リアルタイム検索（デバウンス200ms）
- 検索対象: スキル名、Triggerキーワード、説明文
- 大文字/小文字を区別しない
- 検索結果0件の場合は「該当するスキルがありません」表示
- 検索クリアボタンで検索をリセット

---

### FR-004: カテゴリフィルター

| 項目   | 内容                         |
| ------ | ---------------------------- |
| ID     | FR-004                       |
| 機能名 | カテゴリフィルタリング機能   |
| 説明   | スキルをカテゴリで絞り込める |
| 優先度 | 中                           |
| 入力   | フィルタードロップダウン選択 |
| 出力   | 選択カテゴリのスキルのみ表示 |

**詳細要件**:

- ドロップダウンでカテゴリ選択
- 「すべて」選択でフィルターリセット
- 検索と組み合わせ可能（AND条件）
- カテゴリは動的にスキルから抽出

---

### FR-005: スキル詳細パネル

| 項目   | 内容                                     |
| ------ | ---------------------------------------- |
| ID     | FR-005                                   |
| 機能名 | スキル詳細パネル表示                     |
| 説明   | スキルの詳細情報をサイドパネルに表示する |
| 優先度 | 高                                       |
| 入力   | スキルカードクリック                     |
| 出力   | 右側に詳細パネル表示                     |

**詳細要件**:

- スキルカードクリックで右側にスライドイン表示
- 表示項目:
  - スキル名
  - 完全な説明文
  - Triggerキーワード一覧
  - Anchors（参照情報）一覧
  - ベストプラクティス（あれば）
- 「実行」ボタン（AGENT-004連携）
- 「削除」ボタン
- ESCキーで閉じられる
- パネル外クリックで閉じられる

---

### FR-006: スキル削除

| 項目   | 内容                                             |
| ------ | ------------------------------------------------ |
| ID     | FR-006                                           |
| 機能名 | インポート済みスキル削除機能                     |
| 説明   | インポート済みスキルを削除（インポート解除）する |
| 優先度 | 中                                               |
| 入力   | 詳細パネル内「削除」ボタンクリック               |
| 出力   | スキルがインポート一覧から削除される             |

**詳細要件**:

- 削除確認ダイアログを表示
- 削除後はスキル一覧から即座に削除
- 設定ファイルから永続化情報を削除
- スキルファイル自体は削除しない（インポート解除のみ）

---

### FR-007: インポート設定永続化

| 項目   | 内容                                 |
| ------ | ------------------------------------ |
| ID     | FR-007                               |
| 機能名 | インポート設定の永続化               |
| 説明   | インポート済みスキル情報を永続化する |
| 優先度 | 高                                   |
| 入力   | スキルインポート/削除操作            |
| 出力   | 設定ファイルへの保存                 |

**詳細要件**:

- electron-storeを使用して永続化
- 保存タイミング: インポート時、削除時
- アプリ起動時に永続化情報を読み込み
- 設定ファイルが破損した場合のフォールバック処理

| 用途       | 利用可能スキル一覧取得          |
| リクエスト | なし                            |
