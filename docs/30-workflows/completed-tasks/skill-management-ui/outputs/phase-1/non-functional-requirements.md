## パフォーマンス要件

### NFR-P001: 初期表示速度

| 項目     | 内容                                      |
| -------- | ----------------------------------------- |
| ID       | NFR-P001                                  |
| 要件名   | スキル一覧初期表示速度                    |
| 基準値   | 200ms以下                                 |
| 計測方法 | AgentView開始からスキルカード表示完了まで |
| 優先度   | 高                                        |

**補足**:

- IPC通信時間を含む
- スキル件数100件以下を想定
- スケルトンスクリーン表示は200ms超過時のみ

---

## アクセシビリティ要件（WCAG 2.1 AA準拠）

### NFR-A001: キーボードナビゲーション

| 項目   | 内容                             |
| ------ | -------------------------------- |
| ID     | NFR-A001                         |
| 要件名 | 完全なキーボード操作             |
| 基準   | 全機能がキーボードのみで操作可能 |
| 優先度 | 高                               |

**詳細要件**:

| キー      | 動作                            |
| --------- | ------------------------------- |
| Tab       | 次のインタラクティブ要素へ移動  |
| Shift+Tab | 前のインタラクティブ要素へ移動  |
| Enter     | スキルカード選択/ボタン実行     |
| Space     | チェックボックス切替/ボタン実行 |
| Escape    | モーダル/パネルを閉じる         |
| 矢印キー  | カード間移動（グリッド内）      |

---

### NFR-A002: フォーカス管理

| 項目   | 内容                                     |
| ------ | ---------------------------------------- |
| ID     | NFR-A002                                 |
| 要件名 | 適切なフォーカス管理                     |
| 基準   | フォーカストラップ・復帰が正しく機能する |
| 優先度 | 高                                       |

**詳細要件**:

| シナリオ               | フォーカス移動先                   |
| ---------------------- | ---------------------------------- |
| インポートダイアログ開 | ダイアログ内最初の要素（検索バー） |
| インポートダイアログ閉 | 開いたトリガー要素                 |
| 詳細パネル開           | パネル内最初の要素（スキル名）     |
| 詳細パネル閉           | 選択していたスキルカード           |
| スキル削除後           | 次のスキルカード                   |

---

### NFR-A003: スクリーンリーダー対応

| 項目   | 内容                                 |
| ------ | ------------------------------------ |
| ID     | NFR-A003                             |
| 要件名 | スクリーンリーダー対応               |
| 基準   | VoiceOver/NVDAで全情報にアクセス可能 |
| 優先度 | 高                                   |

**詳細要件**:

| 要素               | ARIA属性                             |
| ------------------ | ------------------------------------ |
| スキルカード       | `role="button"`, `aria-label`        |
| 検索バー           | `aria-label="スキルを検索"`          |
| カテゴリフィルター | `aria-label="カテゴリでフィルター"`  |
| ローディング状態   | `aria-busy="true"`                   |
| エラー表示         | `role="alert"`, `aria-live="polite"` |
| モーダルダイアログ | `role="dialog"`, `aria-modal="true"` |
| 詳細パネル         | `role="complementary"`               |

---

### NFR-A004: コントラスト比

| 項目   | 内容                                   |
| ------ | -------------------------------------- |
| ID     | NFR-A004                               |
| 要件名 | 十分なコントラスト比                   |
| 基準   | テキスト 4.5:1以上、大きいテキスト 3:1 |
| 優先度 | 高                                     |

**詳細要件**:

- 通常テキスト（14px未満）: 4.5:1以上
- 大きいテキスト（18px以上または14px太字）: 3:1以上
- UIコンポーネント・境界線: 3:1以上

---

### NFR-A005: フォーカスインジケータ

| 項目   | 内容                                   |
| ------ | -------------------------------------- |
| ID     | NFR-A005                               |
| 要件名 | 視認可能なフォーカスインジケータ       |
| 基準   | 2px以上の太さ、背景との3:1コントラスト |
| 優先度 | 高                                     |

**詳細要件**:

- `outline-offset: 2px`で要素から離す
- `:focus-visible`でキーボード操作時のみ表示
- フォーカスリングの色はアクセントカラー

---

### NFR-A006: 色だけに頼らない情報伝達

| 項目   | 内容                     |
| ------ | ------------------------ |
| ID     | NFR-A006                 |
| 要件名 | 色以外の情報伝達手段     |
| 基準   | 色のみで状態を表現しない |
| 優先度 | 高                       |

**詳細要件**:

| 状態         | 追加の伝達手段                  |
| ------------ | ------------------------------- |
| 選択状態     | チェックマークアイコン + 背景色 |
| エラー状態   | 警告アイコン + テキスト + 赤色  |
| ローディング | スピナーアイコン + テキスト     |
| カテゴリ     | テキストラベル + 色             |
