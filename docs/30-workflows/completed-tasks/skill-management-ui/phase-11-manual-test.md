## 目的

自動テストでは検証が困難なUX・視覚的確認・実環境での動作確認を手動で実施する。

## 背景

手動テストは、自動テストを補完する重要な検証工程。ユーザー体験、視覚的なレイアウト、実際のElectron環境での動作など、自動テストではカバーしきれない観点を確認する。
