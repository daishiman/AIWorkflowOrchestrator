## 目的

Phase 6（テスト拡充）完了後、テストカバレッジが目標値を満たしているかを検証する品質ゲート。

## 背景

TDDサイクルの品質保証として、定量的なカバレッジ基準を満たすことを確認する。カバレッジが不足している場合は、Phase 6に戻りテストを追加する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ測定

**目的**: ユニットテストのカバレッジを測定し、目標達成を確認する

**実行手順**:

1. カバレッジレポートを生成:

```bash
pnpm --filter @repo/desktop test:coverage -- --coverage
```

2. 以下のカバレッジ目標との比較:

| メトリクス | 目標値 | 測定値 | 判定 |
| ---------- | ------ | ------ | ---- |
| Line       | 80%+   |        |      |
| Branch     | 60%+   |        |      |
| Function   | 80%+   |        |      |

3. 対象ファイルごとのカバレッジを確認:

```
src/renderer/components/skills/
├── SkillCard.tsx             → Line: ___%, Branch: ___%, Function: ___%
├── SkillList.tsx             → Line: ___%, Branch: ___%, Function: ___%
├── SkillDetailPanel.tsx      → Line: ___%, Branch: ___%, Function: ___%
├── SkillSearchBar.tsx        → Line: ___%, Branch: ___%, Function: ___%
├── SkillCategoryFilter.tsx   → Line: ___%, Branch: ___%, Function: ___%
└── SkillImportDialog.tsx     → Line: ___%, Branch: ___%, Function: ___%
```

**期待される成果物**:

- ユニットテストカバレッジレポート（`outputs/phase-7/unit-coverage-report.md`）

| skill:list-imported  |        |        |      |
| skill:import         |        |        |      |
| skill:remove         |        |        |      |
| skill:get-detail     |        |        |      |

**期待される成果物**:

- 結合テストカバレッジレポート（`outputs/phase-7/integration-coverage-report.md`）

### タスク4: カバレッジ判定

**目的**: 総合的なカバレッジ判定を行い、次のアクションを決定する

**実行手順**:

1. 全カバレッジ結果を集約:

| カテゴリ                | 目標達成 | 備考 |
| ----------------------- | -------- | ---- |
| ユニットテスト Line     |          |      |
| ユニットテスト Branch   |          |      |
| ユニットテスト Function |          |      |
| 結合テスト API          |          |      |
| 結合テスト 正常系       |          |      |
| 結合テスト 異常系       |          |      |
| アクセシビリティ        |          |      |

2. 判定基準:

| 判定  | 条件                        | 次のアクション      |
| ----- | --------------------------- | ------------------- |
| PASS  | 全目標値を達成              | Phase 8へ進行       |
| MINOR | 1-2項目が目標未達（5%以内） | 追加テスト後Phase 8 |
| MAJOR | 複数項目が目標未達          | Phase 6へ戻る       |

3. 未達成項目の改善計画を策定

**期待される成果物**:

- カバレッジ判定結果（`outputs/phase-7/coverage-judgment.md`）

---

### タスク5: 未カバー領域の分析

**目的**: カバレッジが不足している領域を特定し、改善策を提示する

**実行手順**:

1. 未カバー行/分岐を特定:

```bash
# カバレッジHTMLレポートを開いて未カバー行を確認
open coverage/lcov-report/index.html
```

2. 未カバー領域の分類:

| 分類       | 対象コード   | 理由         | 対応方針   |
| ---------- | ------------ | ------------ | ---------- |
| テスト困難 | 外部依存処理 | モック困難   | 統合テスト |
| 到達不能   | 防御的コード | 正常時未到達 | 許容       |
| テスト漏れ | 条件分岐     | 単純な漏れ   | テスト追加 |

3. 改善提案を文書化

**期待される成果物**:

- 未カバー領域分析（`outputs/phase-7/uncovered-analysis.md`）
