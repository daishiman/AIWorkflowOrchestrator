## ワークフロー改善点

### Phase 11 代替検証パターンの標準化

worktree 環境でアプリ起動が不可能な場合の代替検証パターンとして、以下のアプローチを標準化することを提案する:

1. **テストコードベース検証**: 手動テスト行列の各項目をテストコードで網羅
2. **DOM 構造検証**: テスト内で `screen.getByRole()` / `screen.getByText()` による UI 構造確認
3. **状態遷移検証**: モック IPC を使用した状態遷移の網羅的テスト
4. **ビジュアル検証の後回し**: Apple HIG 準拠のビジュアル検証はアプリ起動可能な環境で別途実施

このパターンにより、worktree 環境でも Phase 11 の品質ゲートを通過できる。
