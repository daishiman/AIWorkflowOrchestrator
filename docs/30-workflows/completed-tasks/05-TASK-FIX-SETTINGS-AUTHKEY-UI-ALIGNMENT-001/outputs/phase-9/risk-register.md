## リスク一覧

### RISK-001: worktree 環境での esbuild アーキテクチャ問題

| 項目     | 内容                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| リスクID | RISK-001                                                                                                                                 |
| 重要度   | 低                                                                                                                                       |
| 影響範囲 | 開発環境（worktree）のみ。本番ビルドに影響なし                                                                                           |
| 説明     | worktree 環境では esbuild のネイティブバイナリパスが正規リポジトリと異なるため、一部ツール（カバレッジ計測等）が正常動作しない場合がある |
| 発生条件 | `.worktrees/` 配下でのビルド・テスト実行時                                                                                               |
| 緩和策   | テスト全 PASS の確認 + テストケース設計の網羅性分析でカバレッジを間接的に保証                                                            |
| 対応状況 | 許容。正規リポジトリでの CI 実行で最終確認                                                                                               |

### RISK-002: AuthKeySection の Props 契約変更リスク

| 項目     | 内容                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------- |
| リスクID | RISK-002                                                                                              |
| 重要度   | 低                                                                                                    |
| 影響範囲 | 将来の機能拡張時                                                                                      |
| 説明     | AuthKeySection の Props インターフェースが将来変更された場合、SettingsView との統合テストの修正が必要 |
| 発生条件 | AuthKeySection に新しい Props が追加される場合                                                        |
| 緩和策   | Props 型を明示的に定義し、TypeScript の型チェックで変更時に検出可能                                   |
| 対応状況 | 許容。型安全により自動検出される                                                                      |

### RISK-003: Zustand 個別セレクタパターンとの整合性

| 項目     | 内容                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスクID | RISK-003                                                                                                                                                  |
| 重要度   | 低                                                                                                                                                        |
| 影響範囲 | 状態管理層                                                                                                                                                |
| 説明     | P31（Zustand Store Hooks 無限ループ）対策として個別セレクタパターンを使用しているが、AuthKeySection での Store 参照方法が他コンポーネントと一貫しているか |
| 発生条件 | AuthKeySection が直接 Store を参照する場合（現状は Props 経由）                                                                                           |
| 緩和策   | AuthKeySection は Props 経由でデータを受け取る設計のため、Store 直接参照なし。P31 のリスクは回避済み                                                      |
| 対応状況 | 解決済み。Props 経由の設計で P31 リスクを根本回避                                                                                                         |
