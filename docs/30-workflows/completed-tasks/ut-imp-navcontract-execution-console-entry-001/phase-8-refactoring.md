## リファクタリング候補

### 確認項目

| 項目                                | 確認内容                             | 予想判定 |
| ----------------------------------- | ------------------------------------ | -------- |
| iconMap の並び順                    | アルファベット順が維持されているか   | 確認必要 |
| NAV_SECTIONS 内の items 順序        | ショートカット番号順と一致しているか | OK       |
| NAV_SHORTCUT_TO_VIEW のエントリ順序 | 数字順 → 記号順が維持されているか    | OK       |
| DockViewType の union member 順序   | 意味的グルーピングが維持されているか | 確認必要 |

### 対応方針

本タスクは「追加」のみであり、既存コードの構造変更は行わない。以下の場合のみリファクタリングを実施:

- iconMap のアルファベット順が崩れている場合 → 挿入位置を調整
- DockViewType の member 順序が不自然な場合 → 適切な位置に移動

## 実行手順

2. 必要に応じて並び順を調整
3. テスト再実行で回帰がないことを確認
