## スクリーンショット撮影ガイドライン

### 適用判断

本タスクはRendererコンポーネント（Icon, GlobalNavStrip）の変更を含むため、スクリーンショットは**推奨**。ただし、navContract.tsの定数変更が主であり、コンポーネント自体の追加・変更ではないため**必須ではない**。

| タスク種別                      | スクリーンショット | 判断基準                                         |
| ------------------------------- | ------------------ | ------------------------------------------------ |
| 本タスク（navContract定数追加） | 推奨               | データ駆動による自動反映、コンポーネント追加なし |

### CLI環境での代替検証（P53対策）

CLI環境ではElectronアプリの実画面キャプチャができないため、以下で間接検証する:

```bash
# GlobalNavStrip が NAV_SECTIONS を正しく参照していることを確認
grep -n "GLOBAL_NAV_SECTIONS\|NAV_SECTIONS" apps/desktop/src/renderer/components/organisms/GlobalNavStrip/

# play-circle が Icon コンポーネントに正しく登録されていることを確認
grep -n "play-circle" apps/desktop/src/renderer/components/atoms/Icon/index.tsx
```
