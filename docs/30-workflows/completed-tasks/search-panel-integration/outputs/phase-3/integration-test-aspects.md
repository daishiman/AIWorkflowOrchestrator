## 5. Phase 4 でのテスト実装計画

### 5.1 実装順序

1. **API 接続テスト（高優先度）**
   - EditorInstance メソッド呼び出し
   - searchProvider 呼び出し

2. **データフローテスト（高優先度）**
   - 検索 → ハイライト フロー
   - 置換フロー

3. **状態同期テスト（高優先度）**
   - パネル開閉
   - モード切替

4. **エラーハンドリングテスト（中優先度）**
   - 正規表現エラー
   - IPC エラー

5. **エッジケーステスト（低優先度）**
   - 大量データ
   - 特殊文字

### 5.2 テストファイル構成
