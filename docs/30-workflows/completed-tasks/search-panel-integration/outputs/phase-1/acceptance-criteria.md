```bash

pnpm --filter @repo/desktop test:run

# 2. カバレッジレポート
pnpm --filter @repo/desktop test:coverage

# 3. TypeScript 型チェック
pnpm --filter @repo/desktop tsc --noEmit

# 4. ESLint
pnpm --filter @repo/desktop lint

# 5. 実機確認
pnpm --filter @repo/desktop dev
```

## 手動検証手順

### ファイル内検索の検証

1. アプリを起動する
2. ファイルを開く
3. `Cmd+F` (macOS) / `Ctrl+F` (Windows/Linux) を押す
4. 検索パネルが表示されることを確認
5. 検索クエリを入力
6. マッチがハイライトされることを確認
7. Enter で次のマッチに移動することを確認
8. Shift+Enter で前のマッチに移動することを確認
9. 置換テキストを入力し、置換ボタンをクリック
10. 現在のマッチが置換されることを確認
11. Escape でパネルが閉じることを確認

### ワークスペース検索の検証

1. アプリを起動する
2. ワークスペースを開く
3. `Cmd+Shift+F` (macOS) / `Ctrl+Shift+F` (Windows/Linux) を押す
4. ワークスペース検索パネルが表示されることを確認
5. 検索クエリを入力し Enter
6. 結果がファイル別にグループ化されて表示されることを確認
7. マッチ行をクリック
8. 該当ファイルが開き、該当行にジャンプすることを確認
