## 1. ファイル内検索機能

### 1.1 検索パネル開閉

| 要件ID | 要件                                       | 入力                 | 出力                       |
| ------ | ------------------------------------------ | -------------------- | -------------------------- |
| FR-001 | キーボードショートカットで検索パネルを開く | `Cmd+F` / `Ctrl+F`   | SearchPanel が表示される   |
| FR-002 | Escape キーで検索パネルを閉じる            | `Escape`             | SearchPanel が非表示になる |
| FR-003 | パネル閉じるボタンで検索パネルを閉じる     | 閉じるボタンクリック | SearchPanel が非表示になる |

### 1.2 検索実行

| 要件ID | 要件                               | 入力              | 出力                         |
| ------ | ---------------------------------- | ----------------- | ---------------------------- |
| FR-004 | 検索クエリ入力でリアルタイム検索   | テキスト入力      | マッチがハイライト表示される |
| FR-005 | 検索オプション（大文字小文字区別） | Aa ボタントグル   | 大文字小文字を区別して検索   |
| FR-006 | 検索オプション（単語単位）         | [ab] ボタントグル | 単語単位でマッチ             |
| FR-007 | 検索オプション（正規表現）         | .\* ボタントグル  | 正規表現パターンで検索       |
| FR-008 | 検索結果カウント表示               | 検索実行          | "X / Y 件" 形式で表示        |

### 1.3 結果ナビゲーション

| 要件ID | 要件                    | 入力                       | 出力                               |
| ------ | ----------------------- | -------------------------- | ---------------------------------- |
| FR-009 | 次のマッチに移動        | `Enter` / 次へボタン       | 次のマッチにスクロール・ハイライト |
| FR-010 | 前のマッチに移動        | `Shift+Enter` / 前へボタン | 前のマッチにスクロール・ハイライト |
| FR-011 | F3 キーで次へ移動       | `F3`                       | 次のマッチに移動                   |
| FR-012 | Shift+F3 キーで前へ移動 | `Shift+F3`                 | 前のマッチに移動                   |
| FR-013 | 循環ナビゲーション      | 最後/最初で次/前           | 先頭/末尾に循環                    |

### 1.4 置換機能

| 要件ID | 要件                            | 入力                     | 出力                             |
| ------ | ------------------------------- | ------------------------ | -------------------------------- |
| FR-014 | 置換モード表示切替              | 展開ボタンクリック       | 置換入力フィールドが表示         |
| FR-015 | `Cmd+T` / `Ctrl+T` で置換モード | キーボードショートカット | 置換行が表示される               |
| FR-016 | 現在のマッチを置換              | 置換ボタン               | 現在のマッチが置換テキストに変更 |
| FR-017 | 全マッチを一括置換              | 全置換ボタン             | 全てのマッチが置換される         |
| FR-018 | Alt+Enter で全置換              | `Alt+Enter`              | 全マッチが置換される             |

## 2. ワークスペース検索機能

### 2.1 ワークスペース検索パネル開閉

| 要件ID | 要件                           | 入力                           | 出力                          |
| ------ | ------------------------------ | ------------------------------ | ----------------------------- |
| FR-019 | キーボードショートカットで開く | `Cmd+Shift+F` / `Ctrl+Shift+F` | WorkspaceSearchPanel が表示   |
| FR-020 | Escape キーで閉じる            | `Escape`                       | WorkspaceSearchPanel が非表示 |

### 2.2 ワークスペース検索実行

| 要件ID | 要件                                         | 入力               | 出力                                     |
| ------ | -------------------------------------------- | ------------------ | ---------------------------------------- |
| FR-021 | ワークスペース全体を検索                     | 検索クエリ + Enter | ファイル別にグループ化された結果         |
| FR-022 | ファイルフィルター（含む）                   | Include パターン   | 指定パターンにマッチするファイルのみ検索 |
| FR-023 | ファイルフィルター（除外）                   | Exclude パターン   | 指定パターンにマッチするファイルを除外   |
| FR-024 | 検索オプション（大文字小文字/単語/正規表現） | オプションボタン   | 各オプションに基づいて検索               |
| FR-025 | 検索結果統計表示                             | 検索完了           | "X ファイル / Y 件" 形式で表示           |

### 2.3 検索結果表示・操作

| 要件ID | 要件                             | 入力                     | 出力                               |
| ------ | -------------------------------- | ------------------------ | ---------------------------------- |
| FR-026 | ファイル単位で折りたたみ表示     | ファイルヘッダークリック | マッチ行の表示/非表示切替          |
| FR-027 | マッチ行クリックでファイルを開く | マッチ行クリック         | 該当ファイルを開き該当行にジャンプ |
| FR-028 | キーボードナビゲーション         | `ArrowUp` / `ArrowDown`  | 選択アイテムを移動                 |
| FR-029 | Enter で選択アイテムを開く/展開  | `Enter`                  | ファイル展開またはファイルを開く   |

### 2.4 ワークスペース置換機能

| 要件ID | 要件                       | 入力           | 出力                           |
| ------ | -------------------------- | -------------- | ------------------------------ |
| FR-030 | 全ファイルの全マッチを置換 | 全置換ボタン   | 確認ダイアログ表示後、一括置換 |
| FR-031 | 置換確認ダイアログ         | 全置換クリック | 影響範囲を表示して確認を求める |

## 3. 検索モード切替

| 要件ID | 要件                           | 入力                           | 出力                     |
| ------ | ------------------------------ | ------------------------------ | ------------------------ |
| FR-032 | ファイル内検索モードへ切替     | `Cmd+F` / `Ctrl+F`             | searchMode = "file"      |
| FR-033 | ワークスペース検索モードへ切替 | `Cmd+Shift+F` / `Ctrl+Shift+F` | searchMode = "workspace" |
| FR-034 | ファイル名検索モードへ切替     | `Cmd+P` / `Ctrl+P`             | searchMode = "filename"  |
