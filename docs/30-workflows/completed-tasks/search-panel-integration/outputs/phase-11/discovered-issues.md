## 3. 課題詳細

### 課題 #1: worktree環境での@repo/shared参照問題

**重要度**: 中

**発生条件**:

- git worktreeで作成した作業ディレクトリでテスト実行時
- `@repo/shared/types/skill` などの参照が失敗

**影響範囲**:

- search feature には直接影響なし
- 他のコンポーネント（SkillCard等）のテストが失敗

**対応方針**:

- 本番ビルド環境（main worktree）では問題なし
- worktree環境は開発用のため許容

### 課題 #2: 正規表現エラー表示

**重要度**: 低

**発生条件**:

- 正規表現モードで無効なパターン（例: `[`）を入力

**現在の動作**:

- 検索結果が0件として表示
- エラーメッセージは内部でハンドリング済み（Phase 8 リファクタリングで改善）

**対応方針**:

- 現在の実装でエラー情報を返すようにリファクタリング済み
- UIでのエラー表示は今後の改善として許容
