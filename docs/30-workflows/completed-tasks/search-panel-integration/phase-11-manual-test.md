## 実行タスク

### Task 1: 機能テスト（正常系）

**目的**: 主要機能が実機で正常に動作することを確認する

**実行内容**:

開発サーバーを起動:

```bash
pnpm --filter @repo/desktop dev
```

**テストケース一覧**:

| TC-ID  | 機能                   | 手順                                     | 期待結果                    | 結果 |
| ------ | ---------------------- | ---------------------------------------- | --------------------------- | ---- |
| TC-001 | ファイル内検索を開く   | Cmd+F を押す                             | SearchPanel が表示される    | [ ]  |
| TC-002 | 検索クエリ入力         | 検索フィールドに「test」と入力           | マッチがハイライトされる    | [ ]  |
| TC-003 | 次のマッチへ移動       | Enter を押す                             | 次のマッチに移動            | [ ]  |
| TC-004 | 前のマッチへ移動       | Shift+Enter を押す                       | 前のマッチに移動            | [ ]  |
| TC-005 | 検索オプション（Aa）   | 大文字小文字区別ボタンをクリック         | 検索結果が変わる            | [ ]  |
| TC-006 | 検索オプション（Ab）   | 単語単位ボタンをクリック                 | 検索結果が変わる            | [ ]  |
| TC-007 | 検索オプション（.\*）  | 正規表現ボタンをクリック                 | 正規表現検索が有効になる    | [ ]  |
| TC-008 | 置換モードを開く       | Cmd+T を押す                             | 置換フィールドが表示される  | [ ]  |
| TC-009 | 単一置換               | 置換フィールドに入力し「置換」をクリック | 現在のマッチが置換される    | [ ]  |
| TC-010 | 全置換                 | 「すべて置換」をクリック                 | 全マッチが置換される        | [ ]  |
| TC-011 | パネルを閉じる         | Escape を押す                            | パネルが閉じる              | [ ]  |
| TC-012 | ワークスペース検索     | Cmd+Shift+F を押す                       | WorkspaceSearchPanel が表示 | [ ]  |
| TC-013 | 結果クリックでジャンプ | 検索結果をクリック                       | 該当ファイル・行にジャンプ  | [ ]  |

**完了条件**:

- [ ] 全テストケースが PASS

### Task 5: 発見課題の記録

**目的**: 手動テストで発見した課題を記録する

**実行内容**:

```markdown
| #   | 重要度   | 内容       | 対応方針   |
| --- | -------- | ---------- | ---------- |
| 1   | 高/中/低 | (課題内容) | (対応方針) |
```

重要度「高」の課題がある場合は Phase 5（実装）へ戻る。

**完了条件**:

- [ ] 発見課題が記録されている
