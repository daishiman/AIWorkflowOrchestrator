## 目的

Phase 4-6 で作成した全テストがテンプレート項目・三点突合チェックポイント・監査判定パターンを網羅的にカバーしていることを確認する。カバレッジ未達の場合は Phase 6 に戻り追加テストを実施する。

## 背景

テンプレートの必須フィールド、三点突合の全チェックポイント、監査判定の全パターンが100%カバーされていることを保証する。本Phase はカバレッジゲートとして機能し、品質保証の最終防衛線となる。

## SubAgent分担

| SubAgent | 担当                               |
| -------- | ---------------------------------- |
| A        | テンプレートカバレッジ計測         |
| B        | 三点突合カバレッジ計測             |
| C        | 監査ルールカバレッジ計測・総合判定 |

## 実行タスク

### Task 7-1: テンプレートカバレッジ計測

`spec-update-summary.md` / `spec-sync-subagent-report.md` の全必須フィールドがテストされているかを計測する。

**計測方法:**

1. Phase 5 のテンプレートから全必須フィールドを抽出
   - spec-update-summary: `## メタ情報`, `## 更新対象仕様書一覧`, `## 各仕様書の更新内容`, `## 三点突合チェック結果`
   - spec-sync-subagent-report: SubAgent責務テーブル列（ID, 担当仕様書, 責務, 依存, 完了条件）, 実行結果テーブル列
2. Phase 4-6 のテストケースから各フィールドへのテストマッピングを作成
3. テスト未カバーのフィールドをリストアップ

**カバレッジ基準:** テンプレート必須フィールド 100%

**判定:**

| カバレッジ | 判定                                |
| ---------- | ----------------------------------- |
| 100%       | PASS → Phase 8 へ                   |
| 100%未満   | FAIL → Phase 6 へ戻り追加テスト実施 |

### Task 7-2: 三点突合カバレッジ計測

突合対象の全チェックポイントがテストでカバーされているかを計測する。

**計測方法:**

1. Phase 5 Task 5-3 の三点突合チェックリストから全チェックポイントを抽出
   - タスクID一致
   - 更新仕様書リスト一致
   - Step 2判定結果整合
   - Step完了記録整合
   - SubAgent数整合
2. Phase 4-6 のテストケースから各チェックポイントへのテストマッピングを作成
3. テスト未カバーのチェックポイントをリストアップ

**カバレッジ基準:** 三点突合チェックポイント 100%

**判定:**

| カバレッジ | 判定                                |
| ---------- | ----------------------------------- |
| 100%       | PASS → Phase 8 へ                   |
| 100%未満   | FAIL → Phase 6 へ戻り追加テスト実施 |

### Task 7-3: 監査ルールカバレッジ計測

`currentViolations` 判定の全パターンがテストされているかを計測する。

**計測方法:**

1. Phase 5 Task 5-4 の監査基準ルールから全判定パターンを抽出
   - currentViolations=0 → PASS
   - currentViolations>=1 → FAIL
   - baselineViolations のみ → PASS（current に影響しない）
   - メタ情報1セクション原則違反 → FAIL
   - メタ情報正常 → PASS
2. Phase 4-6 のテストケースから各パターンへのテストマッピングを作成
3. テスト未カバーのパターンをリストアップ

**カバレッジ基準:** 監査判定パターン 100%

**判定:**

| カバレッジ | 判定                                |
| ---------- | ----------------------------------- |
| 100%       | PASS → Phase 8 へ                   |
| 100%未満   | FAIL → Phase 6 へ戻り追加テスト実施 |

### Task 7-4: 総合カバレッジ判定

Task 7-1〜7-3 の結果を集約し、Phase 全体のカバレッジ判定を行う。

**判定ルール:**

- 3カテゴリ全て 100% → 総合 PASS（Phase 8 へ進む）
- 1カテゴリでも 100% 未満 → 総合 FAIL（Phase 6 へ戻る）

**レポート構成:**

| カテゴリ                   | 必須項目数 | テスト済み | カバレッジ | 判定 |
| -------------------------- | ---------- | ---------- | ---------- | ---- |
| テンプレート必須フィールド | N          | M          | M/N%       | -    |
| 三点突合チェックポイント   | N          | M          | M/N%       | -    |
| 監査判定パターン           | N          | M          | M/N%       | -    |
| **総合**                   | **N**      | **M**      | **M/N%**   | -    |
