## 5. 依存タスクとの境界

本タスクと依存タスク3件の役割分担を明確にする。

| タスク                                                     | 役割                                            | 本タスクとの境界                                                               |
| ---------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------ |
| **本タスク**（UT-IMP-PHASE12-SUBAGENT-ARTIFACT-GUARD-001） | Phase 12 SubAgent成果物固定の「標準ルール確立」 | テンプレート準拠構造とcurrentViolations=0合否基準を確立する                    |
| UT-IMP-PHASE12-SPEC-SYNC-SUBAGENT-GUARD-001                | SubAgent同期ガードの「詳細ルール実装」          | 本タスクのFR-02（SubAgent責務固定）を受けて、具体的な同期ガード実装を行う      |
| UT-IMP-PHASE12-STEP2-TARGET-TRACE-GUARD-001                | Step 2対象仕様書の「追跡ガード実装」            | 本タスクのFR-03（三点突合説明可能性）を受けて、Step 2追跡の自動化を行う        |
| UT-IMP-PHASE12-EVIDENCE-VALUE-SYNC-GUARD-001               | 証跡値同期の「ガード実装」                      | 本タスクのFR-04（currentViolations=0合否基準）を受けて、証跡値の自動同期を行う |

**実行順序の原則:**

- 本タスク完了 → 依存タスク3件に着手可能
- 依存タスク3件は本タスクの成果物（テンプレート・標準ルール）を参照して実装する

## 6. スコープ外の発見事項の扱い

Phase 1〜13の実行中に、本スコープ外の課題を発見した場合の対応:

1. **未タスク指示書を作成する**: `docs/30-workflows/unassigned-task/` に10見出し形式で作成する
2. **task-workflow.md 残課題テーブルに登録する**: タスクID・タスク名・優先度・指示書パスを記録する
3. **関連仕様書にリンクを追加する**: 発見した仕様書に未タスクへの参照リンクを追加する

これらの3ステップが完了して初めて「スコープ外課題の適切な処理」と判定する。
