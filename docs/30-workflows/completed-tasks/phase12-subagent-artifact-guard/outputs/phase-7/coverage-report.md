## 6. Phase 8（リファクタリング）への引き継ぎ情報

### 6.1 リファクタリング候補

Phase 6結合テスト（TC-6-3）で検出された以下の改善候補をPhase 8で検討する。

1. **S2チーム表現の統一（TC-6-3-01で発見）**: summaryテンプレートのS2チームが「観点テーブル」形式、reportテンプレートが「SubAgent-S2-A/B/Cテーブル行」形式で非対称。CP-5の機械検証を簡素化するため、表現形式の統一を検討する
2. **P-UI6の二重カウント問題（TC-6-3-01で発見）**: P-UI6プロファイルのSubAgent行数が通常テーブルとP-RECHECKテーブルを合算して11行となる。セクション分離してカウントする必要がある
3. **summaryテンプレートのプレースホルダー形式（TC-6-3-02で発見）**: summaryはプレースホルダー形式（`<interface-spec>`）、reportはワイルドカード形式（`interfaces-*`）を使用。命名統一の余地がある

### 6.2 カバレッジ品質補足

- TC-4-3系（監査スクリプト検証9テスト）はテスト設計レベルのカバレッジ。スクリプト実行テストはPhase 11（手動テスト）で実施予定
- TC-6-2系（回帰テスト4テスト）で既存125ワークフローとの互換性を確認済み。非互換は旧形式1件（ut-ipc-channel-naming-audit-001）のみで想定内
- TC-4-4-06（プロファイル選択判定木の決定論性）はPhase 3 MINOR指摘[3-1-M1]への対応確認テスト
