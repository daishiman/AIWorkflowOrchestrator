## 機能要件（Functional Requirements）

### FR-01: スキル実行画面への遷移

| 属性     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 要件     | スキル選択後に実行画面に遷移できる                           |
| 優先度   | 高                                                           |
| 依存機能 | AGENT-002（スキル管理UI）                                    |
| 詳細     | SkillDetailPanelの「実行」ボタンからAgentExecutionViewに遷移 |

**受け入れ基準**:

- スキル詳細パネルに「実行」ボタンが表示される
- ボタンクリックでAgentExecutionViewに遷移する
- 選択したスキル情報が実行画面に引き継がれる

---

### FR-02: メッセージ入力・送信

| 属性   | 内容                                 |
| ------ | ------------------------------------ |
| 要件   | メッセージを入力して送信できる       |
| 優先度 | 高                                   |
| 詳細   | テキスト入力→送信→チャット履歴に表示 |

**受け入れ基準**:

- テキスト入力欄が表示される
- 送信ボタンまたはEnterキーで送信できる
- 送信後、メッセージがチャット履歴に表示される
- 送信中は入力欄とボタンが無効化される

---

### FR-03: ストリーミング出力表示

| 属性   | 内容                                              |
| ------ | ------------------------------------------------- |
| 要件   | エージェントの出力がストリーミングで表示される    |
| 優先度 | 高                                                |
| 詳細   | Main Process→Renderer Processへのリアルタイム配信 |

**受け入れ基準**:

- エージェントの応答がリアルタイムで表示される
- ローディングインジケーターが表示される
- テキストが順次追加される形で表示される
- 出力完了時にインジケーターが消える

---

### FR-04: 実行キャンセル

| 属性   | 内容                           |
| ------ | ------------------------------ |
| 要件   | 実行をキャンセルできる         |
| 優先度 | 高                             |
| 詳細   | 実行中にキャンセルボタンで中断 |

**受け入れ基準**:

- 実行中に「キャンセル」ボタンが表示される
- ボタンクリックで実行が中断される
- 「実行がキャンセルされました」メッセージが表示される
- キャンセル後は新しいメッセージを送信できる

---

### FR-05: チャット履歴クリア

| 属性   | 内容                       |
| ------ | -------------------------- |
| 要件   | チャット履歴をクリアできる |
| 優先度 | 中                         |
| 詳細   | 確認ダイアログ付きでクリア |

**受け入れ基準**:

- 「クリア」ボタンが表示される
- クリック時に確認ダイアログが表示される
- 「はい」選択でチャット履歴がクリアされる
- 「いいえ」選択でダイアログが閉じるのみ

---

### FR-06: エラーメッセージ表示

| 属性   | 内容                                   |
| ------ | -------------------------------------- |
| 要件   | エラー時にエラーメッセージが表示される |
| 優先度 | 高                                     |
| 詳細   | エージェント実行エラーをユーザーに通知 |

**受け入れ基準**:

- エラー発生時にエラーメッセージがチャット履歴に表示される
- エラーメッセージは視覚的に区別される（赤色、アイコン等）
- 実行状態が停止に変わる
- 再試行が可能な状態になる

---

### FR-07: Permission Dialog表示

| 属性   | 内容                                          |
| ------ | --------------------------------------------- |
| 要件   | Permission Dialogが表示される                 |
| 優先度 | 高                                            |
| 詳細   | askルール該当ツール呼び出し時にダイアログ表示 |

**受け入れ基準**:

- askルールに該当するツールが呼び出されるとダイアログが表示される
- ツール名が表示される
- ツールの引数・内容が表示される
- ダイアログはモーダルとして表示される

---

### FR-08: Permission Dialog許可/拒否

| 属性   | 内容                                     |
| ------ | ---------------------------------------- |
| 要件   | Permission Dialogで許可/拒否を選択できる |
| 優先度 | 高                                       |
| 詳細   | 許可→実行続行、拒否→ツール使用拒否通知   |

**受け入れ基準**:

- 「許可」ボタンが表示される
- 「拒否」ボタンが表示される
- 許可クリックでダイアログが閉じ、実行が続行される
- 拒否クリックでダイアログが閉じ、エージェントにツール使用拒否が通知される

---

### FR-09: Permission選択の記憶

| 属性   | 内容                                 |
| ------ | ------------------------------------ |
| 要件   | Permission Dialogで選択を記憶できる  |
| 優先度 | 中                                   |
| 詳細   | 同一ツールの次回以降の確認をスキップ |

**受け入れ基準**:

- 「このツールの選択を記憶する」チェックボックスが表示される
- チェックを入れて許可/拒否すると選択が保存される
- 同一ツールの次回呼び出し時に確認がスキップされる
- 記憶した選択は設定画面から管理可能

---

## 非機能要件（Non-Functional Requirements）

### NFR-01: ストリーミング遅延

| 属性     | 内容                          |
| -------- | ----------------------------- |
| 要件     | ストリーミング遅延は200ms以下 |
| 優先度   | 高                            |
| カテゴリ | パフォーマンス                |

**計測方法**:

- Main Processからのメッセージ送信〜Renderer Processでの表示までの遅延
- 95パーセンタイルで200ms以下を達成

---

### NFR-02: キーボードナビゲーション

| 属性     | 内容                         |
| -------- | ---------------------------- |
| 要件     | キーボードナビゲーション対応 |
| 優先度   | 高                           |
| カテゴリ | アクセシビリティ             |

**対応操作**:

- Tab: 次のインタラクティブ要素へ移動
- Shift+Tab: 前のインタラクティブ要素へ移動
- Enter: 送信、ボタン実行
- Escape: ダイアログを閉じる、キャンセル

---

### NFR-03: スクリーンリーダー対応

| 属性     | 内容                   |
| -------- | ---------------------- |
| 要件     | スクリーンリーダー対応 |
| 優先度   | 中                     |
| カテゴリ | アクセシビリティ       |

**対応項目**:

- 適切なaria-label属性の設定
- role属性の適切な使用
- ライブリージョン（aria-live）の使用
- フォームラベルの関連付け

---

### NFR-04: メモリリーク防止

| 属性     | 内容                           |
| -------- | ------------------------------ |
| 要件     | 長時間実行時のメモリリークなし |
| 優先度   | 高                             |
| カテゴリ | パフォーマンス                 |

**検証方法**:

- 1時間以上の連続実行テスト
- ヒープスナップショットによるメモリ使用量監視
- イベントリスナーの適切なクリーンアップ確認

---

### NFR-05: テストカバレッジ

## 接続要件（統合テスト連携）

### IPC通信チャンネル

| チャンネル             | 方向            | 説明                 |
| ---------------------- | --------------- | -------------------- |
| `agent:start`          | Renderer → Main | エージェント実行開始 |
| `agent:stop`           | Renderer → Main | エージェント実行停止 |
| `agent:stream`         | Main → Renderer | ストリーミング出力   |
| `agent:permission`     | Main → Renderer | 権限確認リクエスト   |
| `agent:permission:res` | Renderer → Main | 権限確認レスポンス   |
| `agent:query`          | Renderer → Main | クエリ実行           |
| `agent:abort`          | Renderer → Main | クエリ中断           |
| `agent:message`        | Main → Renderer | メッセージ配信       |

### ストリーミング仕様

| 項目           | 仕様                            |
| -------------- | ------------------------------- |
| プロトコル     | Electron IPC                    |
| メッセージ形式 | SDKMessage型                    |
| 配信方向       | Main Process → Renderer Process |
| バッファリング | なし（リアルタイム配信）        |

### Permission連携

| 項目               | 仕様                            |
| ------------------ | ------------------------------- |
| リクエストイベント | `agent:permission`              |
| レスポンスイベント | `agent:permission:res`          |
| ペイロード         | ツール名、引数、許可/拒否フラグ |
| タイムアウト       | ユーザー応答まで無期限待機      |
