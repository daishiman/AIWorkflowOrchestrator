本タスクでは `store/index.ts` に15個の個別セレクタHookを追加した。これはUT-STORE-HOOKS-REFACTOR-001で確立されたパターンの延長だが、以下の点で手作業が多い。

**結論:** 現時点では対応不要。合成Store Hookの `@deprecated` 化が完了しており、新規コンポーネントは最初から個別セレクタHookを使用する方針が確立されているため、同様の移行タスクの発生頻度は低下していく見込み。
