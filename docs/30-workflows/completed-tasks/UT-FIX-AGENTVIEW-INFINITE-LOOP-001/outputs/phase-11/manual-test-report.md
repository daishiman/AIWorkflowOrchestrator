## テスト3: パフォーマンス確認（無限ループ不在の検証）

### 目的

P31（Zustand Store Hooks無限ループ）パターンが解消されていることを、DevToolsを用いて定量的に確認する。このセクションが本タスクの最重要検証項目である。

### テストケース

- [ ] **T3-1: Console無限ループ兆候の不在**
  - 手順:
    1. DevTools Consoleをクリアする
    2. AgentViewに遷移する
    3. 5秒間静止する
  - 期待結果: Console上にエラーメッセージの連続出力がないこと
  - 期待結果: `[AgentView][DEBUG]` パターンのログが一切出力されないこと（NFREQ-1: デバッグログ除去）
  - 期待結果: `Warning: Maximum update depth exceeded` が出力されないこと
  - 判定基準: 5秒間のConsole出力が10行以下であること

- [ ] **T3-2: React DevTools Profilerによる再レンダリング回数**
  - 手順:
    1. React DevTools Profilerタブを開く
    2. 「Record」を開始する
    3. 他のViewからAgentViewに遷移する
    4. 3秒間静止する
    5. 「Record」を停止する
  - 期待結果: AgentViewコンポーネントの再レンダリング回数が5回以下であること（StrictMode含む）
  - 期待結果: 再レンダリングが収束し、静止後の追加レンダリングがないこと
  - 判定基準: 最後のレンダリングから1秒以上経過後に追加レンダリングが発生しないこと

- [ ] **T3-3: IPC呼び出し回数の収束確認**
  - 手順:
    1. DevTools Consoleをクリアする
    2. AgentViewに遷移する
    3. 10秒間静止する
  - 期待結果: `skill.getImported` 相当のIPC呼び出しが1回のみ記録されること（REQ-1準拠）
  - 期待結果: 10秒後に追加のIPC呼び出しが発生していないこと
  - 判定基準: IPC呼び出し回数 = 1回（StrictMode環境では最大2回まで許容）

- [ ] **T3-4: CPU使用率のアイドル安定**
  - 手順:
    1. AgentViewに遷移する
    2. DevTools Performanceタブを開く
    3. 10秒間のプロファイリングを記録する
  - 期待結果: 初期ロード後（最初の1-2秒）にCPU使用率がアイドル状態（5%以下）に安定すること
  - 期待結果: 周期的なCPUスパイクが発生しないこと（無限ループ不在の証拠）
  - 判定基準: 安定後のCPUフレームが継続的に低負荷であること

- [ ] **T3-5: メモリリークの不在**
  - 手順:
    1. DevTools Memoryタブを開く
    2. ヒープスナップショットを取得する
    3. AgentViewに遷移し、3秒待機する
    4. 他のViewに遷移し、3秒待機する
    5. AgentViewに再遷移し、3秒待機する
    6. ヒープスナップショットを再取得する
  - 期待結果: 2回のスナップショット間でメモリ使用量が大幅に増加していないこと（10%以下の増加を許容）
  - 期待結果: detached DOM ノードが蓄積していないこと
