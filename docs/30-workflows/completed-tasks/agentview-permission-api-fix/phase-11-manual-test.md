# Phase 11: 手動テスト

## メタ情報

| 項目      | 内容               |
| --------- | ------------------ |
| Phase     | 11                 |
| 名称      | 手動テスト         |
| 前提Phase | Phase 10           |
| 成果物    | 手動テスト実施記録 |

## 目的

Electron デスクトップアプリを実際に起動し、AgentView 画面での Permission API 関連の挙動を手動で確認する。自動テストではカバーできない UI 表示やユーザー操作フローを検証する。

## テストケース

| TC-ID    | 観点             | 手順概要                                      | 期待結果                         |
| -------- | ---------------- | --------------------------------------------- | -------------------------------- |
| TC-11-01 | 初期表示         | AgentView を開く                              | `TypeError` なしで画面表示される |
| TC-11-02 | 許可モード       | 詳細設定を開いて mode を変更する              | local state として即時反映される |
| TC-11-03 | remembered count | 詳細設定を開き `getAllowedTools()` と比較する | UI 件数と API 結果が一致する     |
| TC-11-04 | reset success    | 許可 1 件以上の状態でリセットする             | 件数 0、success toast 表示       |
| TC-11-05 | reset disabled   | 許可 0 件状態で詳細設定を開く                 | `0件` 表示かつ reset disabled    |

## 実行タスク

### タスク 11-1: Electron アプリをビルドして起動する

```bash
pnpm --filter @repo/desktop dev
```

アプリが正常に起動することを確認する。コンソールに `TypeError: Cannot read properties of undefined` が出力されないことを確認する。

### タスク 11-2: AgentView 画面を表示する

1. サイドバーまたはナビゲーションから「AIアシスタント」（AgentView）画面に遷移する
2. 画面が正常に表示されることを確認する
3. DevTools のコンソールにエラーが出力されていないことを確認する

**確認項目**:

- [ ] 「AIアシスタント」ヘッダーが表示されている
- [ ] スキル一覧が表示されている（スキルがインポートされている場合）
- [ ] コンソールに `TypeError` が出力されていない

### タスク 11-3: 詳細設定パネルの許可モードを確認する

1. AgentView 画面右上の設定アイコン（歯車）をクリックする
2. AdvancedSettingsPanel が開くことを確認する
3. 「許可モード」セレクタが表示されていることを確認する
4. セレクタの初期値が「デフォルト」であることを確認する
5. セレクタを「全て許可」に変更する
6. 変更がエラーなく反映されることを確認する（コンソールにエラーが出ない）
7. セレクタの値が「全て許可」に変わっていることを確認する

**確認項目**:

- [ ] 「許可モード」セレクタが表示されている
- [ ] 初期値が「デフォルト」である
- [ ] セレクタ変更時にコンソールエラーが出ない
- [ ] 変更が UI に即座に反映される

### タスク 11-4: 記憶された許可の件数表示を確認する

1. AdvancedSettingsPanel で「記憶された許可: N件」の表示を確認する
2. 件数が `window.permissionAPI.getAllowedTools()` の戻り値と一致していることを確認する

**確認方法**:
DevTools のコンソールで以下を実行して件数を比較する：

```javascript
window.permissionAPI
  .getAllowedTools()
  .then((r) => console.log("tools count:", r.tools.length));
```

**確認項目**:

- [ ] 「記憶された許可: N件」が表示されている
- [ ] 件数が `getAllowedTools()` の結果と一致する

### タスク 11-5: リセットボタンの動作を確認する

1. 許可済みツールが1件以上ある状態にする（ない場合はスキップ）
2. AdvancedSettingsPanel の「リセット」ボタンをクリックする
3. 件数が 0 に変わることを確認する
4. コンソールにエラーが出ないことを確認する
5. 成功 Toast「記憶済みの許可をリセットしました」が表示されることを確認する

**確認項目**:

- [ ] リセットボタンクリック後に件数が 0 になる
- [ ] 成功 Toast が表示される
- [ ] コンソールにエラーが出ない

### タスク 11-6: 許可済みツールがない場合のリセットボタン

1. 許可済みツールが 0 件の状態で AdvancedSettingsPanel を開く
2. 「リセット」ボタンが無効化（disabled）されていることを確認する

**確認項目**:

- [ ] 「記憶された許可: 0件」が表示されている
- [ ] リセットボタンが disabled で操作できない
