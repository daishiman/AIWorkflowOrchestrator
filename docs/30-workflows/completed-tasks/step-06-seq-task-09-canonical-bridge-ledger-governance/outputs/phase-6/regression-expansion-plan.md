# Phase 6 成果物: 回帰拡張計画

> タスクID: TASK-IMP-CANONICAL-BRIDGE-LEDGER-GOVERNANCE-001
> 作成日: 2026-03-23
> Phase: 6 - テスト拡充

## 1. 拡張観点の前提

Phase 4 のテストマトリクスで定義した基本テストケース（U-1-1〜U-3-8、I-1〜I-6、C-1〜C-12、M-1〜M-5）を基に、
Edge / Error / Fallback の観点を追加する。

| 拡張観点 | 対象                                     | 追加理由                                        |
| -------- | ---------------------------------------- | ----------------------------------------------- |
| Edge     | 境界値・最小/最大条件・空値の振る舞い    | Phase 4 で検証しきれない極端な入力を網羅する    |
| Error    | 失敗ケース・中断ケース・不整合状態の回復 | Pitfall P43/P4/P59 の再発を検証で防ぐ           |
| Fallback | 部分成功・ファイル不存在・コマンド失敗   | governance が退化した状態を検出できる観点を追加 |
