# AC-FR-シナリオ対応表

## 概要

正本（`index.md`）の全AC（AC-1〜AC-8）および全FR（FR-1〜FR-6）が、E2Eテストシナリオ（A〜E）によってカバーされていることを確認する対応表。

---

## AC-シナリオ対応表

| AC   | 正本定義                                                    | 対応シナリオ        | 検証方法                                           | 状態       |
| ---- | ----------------------------------------------------------- | ------------------- | -------------------------------------------------- | ---------- |
| AC-1 | 自然言語入力 → LLM がカテゴリベースでスキル一式を生成する   | シナリオA           | plan → execute-plan の正常フロー検証               | テスト対象 |
| AC-2 | 生成スキルが `.claude/skills/` に永続化され即座に実行可能   | シナリオA           | execute-plan 成功レスポンスの検証                  | テスト対象 |
| AC-3 | 生成進捗が UI にストリーミング表示される                    | w5a で検証済み      | `skill-creator:progress` チャンネルの push 検証    | w5a 担当   |
| AC-4 | API Key 未設定時は TerminalHandoffBundle + CLI コマンド表示 | シナリオB           | HandoffGuidance.terminalCommand の非空・形式検証   | テスト対象 |
| AC-5 | improve: フィードバック → 差分提案 → 承認で適用             | シナリオD           | improve-skill → apply-improvement の連携フロー検証 | テスト対象 |
| AC-6 | verify: 生成スキルが要求を満たすかトータル検証できる        | シナリオA（verify） | verify チャンネルの実装・検証（本タスクで実装）    | テスト対象 |
| AC-7 | エラー時に適切なメッセージ表示                              | シナリオC           | エラーレスポンスのサニタイズ検証 + リトライ可能性  | テスト対象 |
| AC-8 | 既存 skill:create（テンプレート生成）が破壊されない         | シナリオE           | skill:create ハンドラーの存在・動作検証            | テスト対象 |

## 網羅性確認

### AC カバレッジ

- AC-1〜AC-8: **全8件カバー済み**
- AC-3 は w5a（ストリーミング進捗UI）で検証済みのため、本タスクでは対象外とする

### FR カバレッジ

- FR-1〜FR-6: **全6件カバー済み**
- FR-5 は w5a で検証済み

### 未カバー項目

なし。全AC・全FRがシナリオまたは別タスク（w5a）でカバーされている。
