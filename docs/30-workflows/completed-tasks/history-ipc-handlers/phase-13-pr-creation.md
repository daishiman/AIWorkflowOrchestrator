## 目的

変更をコミットし、Pull Requestを作成する。
CI/CDが通過することを確認し、マージ準備を完了する。

## 背景

Phase 1〜12で実装・テスト・ドキュメント化が完了した。
本Phaseでは、変更をリポジトリにコミットし、レビュー用のPRを作成する。

---

## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認【PR作成前に必須】

**目的**: PR作成前にローカルで全ての確認を行う。

**実行手順**:

1. `pnpm build` でビルドが成功することを確認する
2. `pnpm test` で全テストがパスすることを確認する
3. `pnpm typecheck` で型チェックがパスすることを確認する
4. `pnpm lint` でLintエラーがないことを確認する
5. `outputs/phase-13/local-verification.md` に結果を記録する

**チェックリスト**:

- [ ] ビルドが成功する
- [ ] 全テストがパスする
- [ ] 型チェックがパスする
- [ ] Lintエラーがない

**期待される成果物**:

- `outputs/phase-13/local-verification.md`（ローカル確認結果）

---

### タスク2: ユーザーへのPR作成許可確認【必須】

**目的**: PR作成前にユーザーの明示的な許可を得る。

**実行手順**:

1. タスク1の結果をユーザーに報告する
2. PR作成の許可を明示的に確認する
3. 許可が得られた場合のみタスク3に進む

**確認内容**:

```
## PR作成準備完了

以下の確認が完了しました:
- [ ] ビルド成功
- [ ] テスト成功
- [ ] 型チェック成功
- [ ] Lint成功

PR作成を実行してもよろしいですか？
```

**期待される成果物**:

- ユーザーからの明示的な許可

---

### タスク3: PR作成（ユーザー許可後のみ実行）

**目的**: `/ai:diff-to-pr` スキルを使用してPRを作成する。

**実行手順**:

1. **ユーザーの許可を確認した後にのみ実行する**
2. `/ai:diff-to-pr` スキルを実行する
3. PRが作成されたことを確認する
4. PR URLを記録する

**期待される成果物**:

- GitHub Pull Request

---

### タスク4: CI/CD確認

**目的**: CIが全て通過することを確認する。

**実行手順**:

1. GitHub ActionsでCIが実行されることを確認する
2. 全てのジョブが成功することを確認する
3. `outputs/phase-13/ci-result.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-13/ci-result.md`（CI結果）

---

### タスク5: タスク完了処理

**目的**: タスクディレクトリを完了フォルダに移動する。

**実行手順**:

1. PRがマージ可能な状態であることを確認する
2. タスクディレクトリを `docs/30-workflows/completed-tasks/` に移動する
3. 元の未タスク指示書を削除する（該当する場合）
4. 移動をコミットする

**移動コマンド**:

```bash
# タスクディレクトリをcompleted-tasksに移動
mv docs/30-workflows/history-ipc-handlers/ docs/30-workflows/completed-tasks/

# 元の未タスク指示書を削除（該当する場合）
rm docs/30-workflows/unassigned-task/task-history-ipc-handlers.md

# 移動をコミット
git add docs/30-workflows/
git commit -m "docs(workflows): history-ipc-handlersをcompleted-tasksに移動"
git push
```

**期待される成果物**:

- タスクディレクトリの移動完了
