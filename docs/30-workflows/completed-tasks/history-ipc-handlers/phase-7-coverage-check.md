## 目的

Phase 6のテスト拡充結果を検証し、カバレッジ基準を満たしているかを確認する。
基準未達の場合はPhase 6に戻りテストを追加する。

## 背景

テストカバレッジは品質の指標の一つ。本Phaseでは、ユニットテストと結合テストのカバレッジが基準を満たしているかをゲートとして確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジの確認

**目的**: ユニットテストカバレッジが基準を満たしているか確認する。

**実行手順**:

1. `pnpm --filter @repo/desktop test:coverage` を実行する
2. カバレッジレポートを確認する
3. 以下の基準を満たしているか確認する:
   - Line Coverage: 80%以上（推奨: 90%）
   - Branch Coverage: 60%以上（推奨: 70%）
   - Function Coverage: 80%以上（推奨: 90%）
4. `outputs/phase-7/unit-coverage-check.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-7/unit-coverage-check.md`（ユニットテストカバレッジ確認結果）

---

### タスク2: 結合テストカバレッジの確認

**目的**: 結合テストカバレッジが基準を満たしているか確認する。

**実行手順**:

1. IPCチャンネルのテストカバレッジを確認する
2. 以下の基準を満たしているか確認する:
   - IPCエンドポイント: 100%
   - モジュール間インターフェース: 100%
   - 正常系シナリオ: 100%
   - 異常系シナリオ: 80%以上
3. `outputs/phase-7/integration-coverage-check.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-7/integration-coverage-check.md`（結合テストカバレッジ確認結果）

---

### タスク3: 統合テスト実行

**目的**: IPC統合テストが全て成功することを確認する。

**実行手順**:

1. IPC統合テストを実行する
2. 全テストが成功することを確認する
3. フロントエンド・バックエンド接続テストが成功することを確認する
4. `outputs/phase-7/integration-test-execution.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-7/integration-test-execution.md`（統合テスト実行結果）

---

### タスク4: カバレッジゲート判定

**目的**: カバレッジ基準を総合判定する。

**実行手順**:

1. タスク1〜3の結果を集約する
2. 基準達成/未達を判定する
3. 未達の場合はPhase 6へ戻る必要性を記録する
4. `outputs/phase-7/coverage-gate-judgment.md` に判定結果を記録する

**期待される成果物**:

- `outputs/phase-7/coverage-gate-judgment.md`（カバレッジゲート判定結果）

## テストカバレッジ基準

### ユニットテスト

| 指標              | 最低基準 | 推奨基準 | 判定 |
| ----------------- | -------- | -------- | ---- |
| Line Coverage     | 80%      | 90%      | -    |
| Branch Coverage   | 60%      | 70%      | -    |
| Function Coverage | 80%      | 90%      | -    |

### 結合テスト

| 指標                         | 目標 | 判定 |
| ---------------------------- | ---- | ---- |
| IPCエンドポイント            | 100% | -    |
| モジュール間インターフェース | 100% | -    |
| 正常系シナリオ               | 100% | -    |
| 異常系シナリオ               | 80%+ | -    |
