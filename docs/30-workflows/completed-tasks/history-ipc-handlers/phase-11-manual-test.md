## 目的

実環境でのUI/UX確認と動作検証を行う。
自動テストでは検証しきれない実際の操作感を確認する。

## 背景

自動テストは全て成功しているが、実際のアプリケーションでの動作確認が必要。
ユーザー視点での操作性や、実環境でのパフォーマンスを検証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: アプリケーション起動確認

**目的**: アプリケーションが正常に起動し、IPCハンドラーが登録されることを確認する。

**実行手順**:

1. `pnpm --filter @repo/desktop dev` でアプリケーションを起動する
2. コンソールで「History handlers registered」ログを確認する
3. エラーが出力されていないことを確認する
4. `outputs/phase-11/startup-test.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-11/startup-test.md`（起動確認結果）

---

### タスク2: 履歴一覧取得テスト

**目的**: 履歴一覧の取得機能が正常に動作することを確認する。

**実行手順**:

1. 履歴画面を開く
2. ファイルを選択して履歴一覧を表示する
3. 履歴データが正しく表示されることを確認する
4. ページネーション（追加読み込み）が動作することを確認する
5. `outputs/phase-11/history-list-test.md` に結果を記録する

**テストケース**:
| ケース | 操作 | 期待結果 |
| ------ | ---- | -------- |
| TC-01 | 履歴画面を開く | 履歴一覧が表示される |
| TC-02 | ファイルを選択 | 選択ファイルの履歴が表示される |
| TC-03 | 「もっと見る」をクリック | 追加の履歴が読み込まれる |

**期待される成果物**:

- `outputs/phase-11/history-list-test.md`（履歴一覧取得テスト結果）

---

### タスク3: バージョン詳細表示テスト

**目的**: バージョン詳細の表示機能が正常に動作することを確認する。

**実行手順**:

1. 履歴一覧からバージョンを選択する
2. バージョン詳細が表示されることを確認する
3. 変換ログが表示されることを確認する
4. ログのフィルタ機能が動作することを確認する
5. `outputs/phase-11/version-detail-test.md` に結果を記録する

**テストケース**:
| ケース | 操作 | 期待結果 |
| ------ | ---- | -------- |
| TC-04 | バージョンを選択 | 詳細画面が表示される |
| TC-05 | ログフィルタを変更 | フィルタが適用される |

**期待される成果物**:

- `outputs/phase-11/version-detail-test.md`（バージョン詳細テスト結果）

---

### タスク4: バージョン復元テスト

**目的**: バージョン復元機能が正常に動作することを確認する。

**実行手順**:

1. 復元したいバージョンを選択する
2. 「復元」ボタンをクリックする
3. 確認ダイアログが表示されることを確認する
4. 復元を実行し、正常に完了することを確認する
5. `outputs/phase-11/restore-test.md` に結果を記録する

**テストケース**:
| ケース | 操作 | 期待結果 |
| ------ | ---- | -------- |
| TC-06 | 復元ボタンをクリック | 確認ダイアログが表示される |
| TC-07 | 復元を確認 | 復元が成功し、完了メッセージが表示される |
| TC-08 | キャンセル | ダイアログが閉じ、復元されない |

**期待される成果物**:

- `outputs/phase-11/restore-test.md`（バージョン復元テスト結果）

---

### タスク5: エラーハンドリングテスト

**目的**: エラー発生時の挙動を確認する。

**実行手順**:

1. 存在しないファイルIDで履歴を取得してみる
2. エラーメッセージが適切に表示されることを確認する
3. 再試行ボタンが表示されることを確認する
4. `outputs/phase-11/error-handling-test.md` に結果を記録する

**テストケース**:
| ケース | 操作 | 期待結果 |
| ------ | ---- | -------- |
| TC-09 | 無効なIDで取得 | エラーメッセージが表示される |
| TC-10 | 再試行をクリック | 再度取得が試行される |

**期待される成果物**:

- `outputs/phase-11/error-handling-test.md`（エラーハンドリングテスト結果）

---

### タスク6: 手動テスト結果サマリー

**目的**: 全手動テストの結果をまとめる。

**実行手順**:

1. タスク1〜5の結果を集約する
2. 発見された問題があれば記録する
3. `outputs/phase-11/manual-test-summary.md` にサマリーを作成する

**期待される成果物**:

- `outputs/phase-11/manual-test-summary.md`（手動テストサマリー）
