## TC-013: readFile パストラバーサル攻撃防御

### テスト内容

`../../../etc/passwd` などのディレクトリトラバーサルパスを指定して `skill:readFile` チャンネルを呼び出し、スキルディレクトリ外へのアクセスが拒否されることを確認する。

### 代替テスト: S-04（セキュリティテスト）

```
skillFileHandlers.security.test.ts
  > S-04: readFile パストラバーサル攻撃を拒否する
```

- **攻撃パターン**: `../../../etc/passwd`, `..\\..\\Windows\\System32\\config`
- **期待結果**: `{ error: { code: 'PATH_TRAVERSAL_DETECTED', ... } }` 形式のエラーレスポンス
- **実テスト結果**: PASS
- **検証内容**: スキルディレクトリ外のパスを含むリクエストが全てブロックされることを確認

## TC-016: エラーサニタイズ確認

### テスト内容

各チャンネルでエラーが発生した際に、内部情報（スタックトレース、サーバーパス、ファイルシステム構造等）がエラーレスポンスに含まれないことを確認する。

### 代替テスト: S-09, S-10（セキュリティテスト）

```
skillFileHandlers.security.test.ts
  > S-09: エラーレスポンスに内部パス情報が含まれない
  > S-10: エラーレスポンスにスタックトレースが含まれない
```

- **期待結果**: エラーレスポンスは `{ code, message }` のみで、パス・スタックトレース・Node.js 内部情報を含まない
- **実テスト結果**: PASS
- **検証内容**: エラー内容のサニタイズが全ハンドラーで一貫して適用されることを確認
