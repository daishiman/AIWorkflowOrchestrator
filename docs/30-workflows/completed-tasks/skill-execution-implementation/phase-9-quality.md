## 目的

静的解析とセキュリティチェックを実施し、コード品質を保証する。

## 背景

リファクタリング完了後、最終的な品質保証として静的解析、セキュリティチェック、
依存関係チェックを実施する。これにより本番環境での問題を未然に防止する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析

**目的**: ESLintとTypeScript型チェックを実行する

**実行手順**:

1. ESLint実行

```bash
pnpm --filter @repo/desktop lint
```

2. TypeScript型チェック

```bash
pnpm --filter @repo/desktop typecheck
```

3. `outputs/phase-9/static-analysis.md` に結果を出力

**期待される成果物**:

- 静的解析結果

---

### タスク2: セキュリティチェック

**目的**: セキュリティ脆弱性がないか確認する

**実行手順**:

1. 以下のチェック項目を確認

| #   | チェック項目                                      | 確認結果 |
| --- | ------------------------------------------------- | -------- |
| 1   | validateIpcSenderが全ハンドラーで使用されているか | [ ]      |
| 2   | 入力値のバリデーションが適切か                    | [ ]      |
| 3   | エラーメッセージに機密情報が含まれていないか      | [ ]      |
| 4   | SQLインジェクションのリスクがないか               | [ ]      |
| 5   | パストラバーサルのリスクがないか                  | [ ]      |

2. `outputs/phase-9/security-check.md` に結果を出力

**期待される成果物**:

- セキュリティチェック結果

---

### タスク3: 依存関係チェック

**目的**: 依存パッケージの脆弱性を確認する

**実行手順**:

1. 脆弱性チェック実行

```bash
pnpm audit
```

2. 結果を確認
3. `outputs/phase-9/dependency-audit.md` に結果を出力

**期待される成果物**:

- 依存関係チェック結果

---

### タスク4: 品質ゲート判定

**目的**: 品質ゲートの判定を行う

**実行手順**:

1. 判定基準に基づき判定

| 項目               | 基準          | 結果 |
| ------------------ | ------------- | ---- |
| ESLintエラー       | 0件           | [ ]  |
| TypeScriptエラー   | 0件           | [ ]  |
| セキュリティ脆弱性 | Critical: 0件 | [ ]  |
| テスト成功率       | 100%          | [ ]  |

2. `outputs/phase-9/quality-gate.md` に判定結果を出力

**期待される成果物**:

- 品質ゲート判定結果
