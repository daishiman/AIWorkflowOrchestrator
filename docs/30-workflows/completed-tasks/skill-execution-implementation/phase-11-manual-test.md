## 目的

実環境でスキル実行機能の動作を確認し、UXの問題を検出する。

## 背景

自動テストでは検出しにくいUI/UXの問題や実環境特有の問題を検出するため、
手動テストを実施する。これにより本番環境でのユーザー体験品質を保証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 環境準備

**目的**: テスト環境を準備する

**実行手順**:

1. アプリケーションをビルド・起動

```bash
pnpm --filter @repo/desktop dev
```

2. Agent画面にアクセス
3. `outputs/phase-11/environment-setup.md` に環境情報を出力

**期待される成果物**:

- 環境準備確認

---

### タスク2: 機能テスト

**目的**: 基本機能の動作を確認する

**実行手順**:

1. 以下のテストケースを実施

| TC-ID     | テストケース           | 手順                             | 期待結果                   | 結果 |
| --------- | ---------------------- | -------------------------------- | -------------------------- | ---- |
| TC-11-001 | スキル一覧表示         | Agent画面を開く                  | スキル一覧が表示される     | [ ]  |
| TC-11-002 | スキル選択             | スキルをクリック                 | 詳細パネルが表示される     | [ ]  |
| TC-11-003 | スキル実行             | 「実行」ボタンをクリック         | ローディング→成功トースト  | [ ]  |
| TC-11-004 | 実行中の再クリック防止 | 実行中に「実行」ボタンをクリック | ボタンが無効化されている   | [ ]  |
| TC-11-005 | エラー時の表示         | 存在しないスキルを実行           | エラートーストが表示される | [ ]  |

2. `outputs/phase-11/functional-test-result.md` に結果を出力

**期待される成果物**:

- 機能テスト結果

---
