## FR-001: スキル詳細パネルから実行ボタンで実行可能

### 概要

ユーザーがAgent画面でスキルを選択し、詳細パネルの「実行」ボタンをクリックすると、選択されたスキルが実行される。

### 受け入れ条件

1. スキル一覧から任意のスキルを選択できる
2. 選択したスキルの詳細パネルに「実行」ボタンが表示される
3. 「実行」ボタンをクリックすると、スキルが実行される
4. 実行リクエストがIPCを通じてメインプロセスに送信される

### 技術仕様

- **Renderer側**: `handleExecute` が `skillAPI.execute(skill.id)` を呼び出す
- **Preload側**: `skillAPI.execute` が `skill:execute` チャンネルでIPCを送信
- **Main側**: `skill:execute` ハンドラーが `SkillService.executeSkill` を呼び出す

## FR-002: 実行中はローディング状態を表示

### 概要

スキル実行中は、UIにローディング状態を表示し、ユーザーに処理中であることを視覚的にフィードバックする。

### 受け入れ条件

1. 実行ボタンクリック直後にローディング状態に遷移
2. ローディング中はボタンにスピナーアイコンまたはローディングインジケータを表示
3. 実行完了（成功/失敗）時にローディング状態を解除

### 技術仕様

- `isExecuting` 状態を `useState` で管理
- 実行開始時に `setIsExecuting(true)`
- 実行完了時に `setIsExecuting(false)`

## FR-003: 実行完了時にトースト通知を表示

### 概要

スキル実行が成功した場合、成功を示すトースト通知を表示する。

### 受け入れ条件

1. 実行成功時に緑色のトースト通知が表示される
2. トースト内容: 「スキルを実行しました」または「{スキル名} を実行しました」
3. トーストは5秒後に自動消去される
4. 閉じるボタンで即座に消去できる

### 技術仕様

- 既存の `showToast` アクションを使用
- `showToast("success", "スキルを実行しました")`

---

## FR-004: 実行エラー時にエラーメッセージを表示

### 概要

スキル実行が失敗した場合、エラーメッセージをトースト通知で表示する。

### 受け入れ条件

1. 実行失敗時に赤色のトースト通知が表示される
2. エラーメッセージにはエラーの詳細が含まれる
3. トーストは5秒後に自動消去される
4. 閉じるボタンで即座に消去できる

### 技術仕様

- 既存の `showToast` アクションを使用
- `showToast("error", "実行に失敗しました: {エラー詳細}")`

---

## FR-005: 実行中は再実行を無効化

### 概要

スキル実行中は、同一スキルの再実行を防止する。

### 受け入れ条件

1. 実行中は「実行」ボタンが無効化される（disabled）
2. 無効化中はボタンがグレーアウトまたは視覚的に無効状態を示す
3. 実行完了後にボタンが再度有効化される

### 技術仕様

- ボタンの `disabled` 属性に `isExecuting` 状態をバインド
- `<button disabled={isExecuting}>`

## IPC通信フロー

```
┌─────────────────┐    skillAPI.execute    ┌─────────────────┐
│   AgentView     │ ──────────────────────▶ │    Preload      │
│  (Renderer)     │                         │   skillAPI      │
└─────────────────┘                         └─────────────────┘
                                                     │
                                                     │ IPC invoke
                                                     │ "skill:execute"
                                                     ▼
                                            ┌─────────────────┐
                                            │  skillHandlers  │
                                            │    (Main)       │
                                            └─────────────────┘
                                                     │
                                                     │ executeSkill
                                                     ▼
                                            ┌─────────────────┐
                                            │  SkillService   │
                                            │    (Main)       │
                                            └─────────────────┘
```
