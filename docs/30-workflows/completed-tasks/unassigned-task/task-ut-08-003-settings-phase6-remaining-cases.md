## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

Phase 6計画で INT-11〜13 が残存し、統合回帰行列が未完了。

### 1.2 問題点・課題

計画と実装の差分が残ると、将来の回帰監査で判定が揺れる。

### 1.3 放置した場合の影響

coverage gap が慢性化し、仕様準拠判定が不透明になる。

## 2. 何を達成するか（What）

### 2.1 目的

INT-11〜13 を実装、または非採用根拠を仕様へ固定して行列を閉じる。

### 2.2 最終ゴール

Phase 6計画と実テストケースの対応が 1:1 で追跡できる。

### 2.3 スコープ

#### 含むもの

- INT-11〜13 の実装可否判定
- 実装 or 非採用理由の文書化

#### 含まないもの

- Settings以外の回帰行列整理

### 2.4 成果物

- regression-expansion-plan 更新
- integration test 追補（必要時）

## 3. どのように実行するか（How）

### 3.1 前提条件

- 現行18テストがGREEN

### 3.2 依存タスク

- 08-TASK 実装済みブランチ

### 3.3 必要な知識

- SettingsView構成
- harness設計

### 3.4 推奨アプローチ

「実装」か「非採用」のどちらでも、根拠を表で固定する。

## 4. 実行手順

1. INT-11〜13 を再評価
2. 実装可能なケースを追加
3. 非採用ケースは根拠と代替検証先を記載
4. Phase 6成果物へ同期

## 5. 完了条件チェックリスト

- [ ] INT-11〜13 の状態が確定
- [ ] 行列に未定義ケースが残らない
- [ ] verify/validate で整合PASS
