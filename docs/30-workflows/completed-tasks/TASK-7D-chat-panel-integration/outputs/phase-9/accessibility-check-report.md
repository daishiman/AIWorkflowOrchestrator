## 2. 色に依存しない識別

### 2.1 StatusBadge

StatusBadge は色に加えてラベルテキストにより状態を識別可能である。

| ステータス         | 色     | ラベルテキスト | 色非依存識別 |
| ------------------ | ------ | -------------- | ------------ |
| running            | 青     | 実行中...      | ✅           |
| waiting_permission | 黄     | 権限確認       | ✅           |
| completed          | 緑     | 完了           | ✅           |
| cancelled          | グレー | キャンセル     | ✅           |
| error              | 赤     | エラー         | ✅           |

### 2.2 tool_result

tool_result の成功/失敗はアイコンにより識別可能である。

| 結果 | アイコン | 色非依存識別 |
| ---- | -------- | ------------ |
| 成功 | ✅       | ✅           |
| 失敗 | ❌       | ✅           |
