## 5. テストパターン

### 5.1 ストアモック

```typescript
vi.mock("@/store/useAppStore", () => ({
  useAppStore: vi.fn(),
}));
```

`useAppStore` を `vi.mock` でモック化し、各テストケースで必要なセレクタ値を返す。個別セレクタパターン（`useAppStore(state => state.xxx)`）に対応するため、モック関数はコールバック引数に基づいて値を返すように設定する。

### 5.2 コンポーネントモック

```typescript
vi.mock('@/components/skill/SkillSelector', () => ({
  SkillSelector: () => <div data-testid="skill-selector" />,
}));
```

依存コンポーネント（SkillSelector, SkillImportDialog, PermissionDialog, SkillStreamingView）はモックコンポーネントに置換し、ChatPanelの統合ロジックに集中してテストする。

### 5.3 テストデータファクトリ

以下のファクトリ関数でテストデータを生成する:

| ファクトリ関数              | 生成データ                  | 用途                   |
| --------------------------- | --------------------------- | ---------------------- |
| `createAssistantMessage()`  | assistantロールメッセージ   | 通常メッセージテスト   |
| `createToolUseMessage()`    | tool_useロールメッセージ    | ツール使用テスト       |
| `createToolResultMessage()` | tool_resultロールメッセージ | ツール結果テスト       |
| `createErrorMessage()`      | errorロールメッセージ       | エラーメッセージテスト |

各ファクトリはデフォルト値を持ち、必要に応じてオーバーライド可能なパラメータを受け取る。
