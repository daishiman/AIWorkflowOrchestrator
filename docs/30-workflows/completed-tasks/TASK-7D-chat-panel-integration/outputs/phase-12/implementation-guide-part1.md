# TASK-7D 実装ガイド Part 1: みんなにわかる ChatPanel のしくみ

- **日付**: 2026-01-30
- **対象読者**: 初学者・中学生レベル
- **タスク**: TASK-7D ChatPanel統合

---

## 1. はじめに - ChatPanel ってなに?

教室にあるホワイトボードを想像してみてください。

ChatPanel は「AIとお話しする教室」のホワイトボードです。このホワイトボードの前に立つと、いろんな道具（スキル）を使って、AIに仕事をお願いできます。たとえば「この文章を要約して」とか「コードを書いて」といったお願いができる場所です。

ChatPanel はただのチャット画面ではありません。いくつかの便利な部品が組み合わさってできています。次のセクションで、その部品たちを紹介します。

---

## 2. 登場する部品たち

### SkillSelector = 「筆箱から道具を選ぶ」

AIに使ってほしい道具（スキル）を選ぶところです。

筆箱を開けて、鉛筆やはさみやのりを選ぶみたいに、AIの道具を選べます。「プレゼン作りスキル」「コード書きスキル」「文章チェックスキル」など、やりたいことに合った道具を選んで使います。

### SkillStreamingView = 「先生が黒板に書いている途中を見ている」

AIが仕事をしているとき、その途中経過をリアルタイムで見られる部品です。

先生が黒板に字を書いているのを見ているのと同じです。AIが「今こんなことを考えています」「このファイルを読んでいます」「この結果が出ました」というのを、一つずつ見ることができます。全部終わるまで待たなくても、途中から見られるのがポイントです。

### PermissionDialog = 「先生に許可をもらう」

AIが何か特別なことをしたいとき、「やってもいいですか?」と聞いてくるダイアログです。

たとえばファイルを書き換えたり、コマンドを実行したりする前に、必ず「これをやってもいいですか?」と確認してきます。勝手に行動しない、安全のための仕組みです。学校で先生に「トイレに行ってもいいですか?」と聞くのと似ています。

### StatusBadge = 「信号機」

今何をしているのかが色で分かる小さなバッジです。

- **青** = 作業中（AIが頑張っています）
- **黄** = 確認中（許可を待っています）
- **緑** = 完了（仕事が終わりました）
- **赤** = エラー（何か問題が起きました）

信号機を見れば車が止まるか進むか分かるように、StatusBadge を見ればAIの状態が一目で分かります。

### ToolExecutionHistory = 「ノートに書いた作業メモ」

AIがどんな道具をどの順番で使ったかの記録です。

テストの解き方をノートにメモするように、AIも「まずファイルを読んで」「次にコードを書いて」「それからテストを実行して」と、やったことを全部記録しています。あとから「どうやってその答えにたどり着いたの?」と確認できます。

## 3. なぜこの仕組みが必要なの?

### なぜスキルを選べるようにするのか

道具が増えると便利になるからです。

プレゼン作りが得意なスキル、コード書きが得意なスキル、文章校正が得意なスキル。それぞれに得意分野があります。全部を一つの道具でやろうとすると中途半端になりますが、専門の道具を選べると、もっといい結果が出せます。

### なぜ途中経過を見せるのか

AIが何をしているか分かると安心できるからです。

レストランで料理を注文したとき、厨房が見えるお店だと「今作ってるんだな」と安心できます。でも厨房が見えないと「本当に作ってるのかな?」と不安になります。AIも同じで、黙って待っているより「今こんなことしてるよ」と教えてくれた方がずっと安心です。

### なぜ許可を求めるのか

安全のためです。

ファイルを変更したり、コマンドを実行したりする前に確認します。もし間違った内容でファイルを書き換えてしまったら大変です。だから「このファイルをこう変えていいですか?」と必ず聞いてから行動します。勝手にやらない、これが大事なルールです。

### なぜ停止ボタンがあるのか

いつでもやめられる安心感があるからです。

AIが間違った方向に進んでいると気づいたとき、すぐに止められます。電車の緊急停止ボタンと同じで、「何かおかしい」と思ったらすぐに止められることが、安心して使える秘訣です。

## 4. むずかしい言葉の説明

### ストリーミング

データが少しずつ流れてくることです。

動画を見るとき、全部ダウンロードしてから再生するのではなく、少しずつ受け取りながら再生しています。AIの回答も同じで、全部考え終わるのを待たず、考えた分から少しずつ画面に表示されます。だから待ち時間が短く感じます。

### コンポーネント

画面の部品のことです。

レゴブロックのように、小さい部品を組み合わせて大きな画面を作ります。SkillSelector という部品、SkillStreamingView という部品、PermissionDialog という部品。これらを組み合わせると ChatPanel という大きな画面ができあがります。部品ごとに分かれているので、一つの部品を直しても他の部品に影響しません。

### 状態管理（Store）

みんなが見られる掲示板のことです。

教室の掲示板に「今日の給食はカレーです」と書くと、クラス全員がその情報を知ることができます。同じように、Store に「今スキル実行中です」と書き込むと、画面のすべての部品がその情報を知ることができます。どの部品からでも掲示板を見られるので、情報の共有がスムーズになります。

### Props

部品に渡すメモのことです。

「この名前で表示してね」「このメッセージを見せてね」というメモを部品に渡すと、部品がその通りに動きます。たとえば StatusBadge に「status = running」というメモを渡すと、青色の「作業中」バッジが表示されます。「status = completed」と渡すと、緑色の「完了」バッジに変わります。メモの内容によって、部品の見た目や動きが変わるのです。
