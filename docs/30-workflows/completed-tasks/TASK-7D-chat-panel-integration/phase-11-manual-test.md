## 実行タスク

### タスク1: 基本動作確認

**目的**: ChatPanel 統合の基本動作が期待通りであることを手動で確認する。

**手順**:

1. Electron デスクトップアプリを起動する:

```bash
pnpm --filter @repo/desktop dev
```

2. 以下のシナリオを実行し結果を記録する:

| #   | シナリオ                                 | 期待結果                                                 | 結果 |
| --- | ---------------------------------------- | -------------------------------------------------------- | ---- |
| 1   | ChatPanel を開く                         | ヘッダーに ModelSelector と SkillSelector が表示される   | ?    |
| 2   | SkillSelector のドロップダウンを開く     | インポート済みスキルと未インポートスキルが表示される     | ?    |
| 3   | スキルを選択する                         | ヘッダーに選択したスキル名が表示される                   | ?    |
| 4   | スキルの選択を解除する（「なし」を選択） | ヘッダーのスキル名が「なし」に戻る                       | ?    |
| 5   | 未インポートスキルのインポートを要求する | SkillImportDialog が表示される                           | ?    |
| 6   | SkillImportDialog を閉じる               | ダイアログが閉じ、ChatPanel が正常に表示される           | ?    |
| 7   | 通常のチャットメッセージを送信する       | メッセージが送信され、応答が表示される（既存機能の確認） | ?    |

**期待される成果物**:

- 基本動作確認結果（`outputs/phase-11/basic-test-results.md`）

| 1   | スキル実行を開始する         | SkillStreamingView が表示される                               | ?    |

## 統合テスト連携

### このフェーズで実施すべき統合テスト観点

| カテゴリ         | テスト観点                                              |
| ---------------- | ------------------------------------------------------- |
| エンドツーエンド | スキル選択 → 実行 → ストリーミング表示 → 完了の全フロー |
| 権限フロー       | 実行中の権限確認割り込み → 応答 → 実行継続              |
| 既存機能回帰     | 通常チャット（スキル未選択時）が正常に動作すること      |

| 観点             | 確認項目                                                           |
