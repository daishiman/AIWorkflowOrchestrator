## 目的

Phase 1（要件定義）と Phase 2（設計）の妥当性を検証し、Phase 4 以降の実装に進むための品質ゲートを通過する。

## 実行タスク

- Task 3-1: 要件の完全性レビュー — 全 FR/NFR に検証可能な受け入れ基準があるか
- Task 3-2: 設計の妥当性レビュー — Phase 5 設計書との整合性、レイヤー依存方向、後方互換性
- Task 3-3: セキュリティレビュー — IPC ハンドラの入力バリデーション、sender 検証
- Task 3-4: アーキテクチャレビュー — DIP 準拠、キャッシュ一貫性、P5/P61 対策

## 実行手順

### ステップ1: レビュー観点ごとに検証

各レビュー観点（要件完全性、設計妥当性、セキュリティ、アーキテクチャ）について PASS/MINOR/MAJOR/CRITICAL で判定する。

### ステップ2: ゲート判定

| 判定              | 対応                  |
| ----------------- | --------------------- |
| PASS              | Phase 4 へ            |
| MINOR             | 指摘対応後 Phase 4 へ |
| MAJOR（要件問題） | Phase 1 へ戻る        |
| MAJOR（設計問題） | Phase 2 へ戻る        |
