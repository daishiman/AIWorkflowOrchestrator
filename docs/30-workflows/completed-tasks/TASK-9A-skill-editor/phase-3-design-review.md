# Phase 3: 設計レビューゲート — スキルエディター機能

## メタ情報

| 項目      | 内容                                                    |
| --------- | ------------------------------------------------------- |
| タスクID  | TASK-9A                                                 |
| Phase     | 3                                                       |
| タスク名  | スキルエディター機能（SKILL.md・サブリソースのGUI編集） |
| 作成日    | 2026-02-26                                              |
| 依存Phase | Phase 1（要件定義）、Phase 2（設計）                    |

## 目的

Phase 1（要件定義）と Phase 2（設計）の成果物を多角的にレビューし、Phase 4（テスト作成）への進行可否を判定する。セキュリティ、型安全性、アーキテクチャ整合性、コンポーネント設計、状態管理、アクセシビリティの6観点から検証を行う。

## 実行タスク

- Task 1: セキュリティレビュー — 読み取り専用制御と多層防御の妥当性を検証する
- Task 2: 型安全性レビュー — 型定義の完全性と整合性を検証する
- Task 3: アーキテクチャ整合性レビュー — 既存パターンとの一貫性を検証する
- Task 4: コンポーネント設計レビュー — Atomic Design 準拠と責務分離を検証する
- Task 5: 状態管理レビュー — Zustand 設計原則への準拠を検証する
- Task 6: アクセシビリティレビュー — WCAG 2.1 AA 準拠を検証する
- Task 7: ゲート判定 — 総合判定を行い、次 Phase への進行可否を決定する

### Task 7: ゲート判定

#### 判定基準テーブル

| 判定  | 条件                                                                               | 対応                                   |
| ----- | ---------------------------------------------------------------------------------- | -------------------------------------- |
| PASS  | SEC / TYP / ARC / CMP / STM / A11Y の全チェック項目が合格                          | Phase 4（テスト作成）へ進行            |
| MINOR | 1-3 個の軽微な指摘があるが、実装に影響しない                                       | 指摘事項を未タスク化し、Phase 4 へ進行 |
| MAJOR | セキュリティ設計に重大な欠陥がある、型定義に根本的な問題がある、またはレイヤー違反 | Phase 1 または Phase 2 へ戻り修正      |

#### 判定プロセス

1. Task 1〜6 の全チェック項目を逐次確認する
2. 各チェック項目に「✅ PASS」「⚠️ MINOR」「❌ MAJOR」を記入する
3. MAJOR が1件でもある場合はゲート判定 MAJOR とする
4. MINOR のみの場合はゲート判定 MINOR とし、指摘事項を記録する
5. 全て PASS の場合はゲート判定 PASS とする

#### MAJOR 判定時の戻り先

| MAJOR の内容                   | 戻り先                    |
| ------------------------------ | ------------------------- |
| 要件の漏れ（FR/NFR に不足）    | Phase 1（要件定義）へ戻る |
| セキュリティ設計の欠陥         | Phase 2（設計）へ戻る     |
| コンポーネント設計の根本的問題 | Phase 2（設計）へ戻る     |
| 状態管理設計の根本的問題       | Phase 2（設計）へ戻る     |
| レイヤー依存方向の違反         | Phase 2（設計）へ戻る     |
