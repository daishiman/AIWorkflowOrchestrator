# Phase 1: 要件定義 — スキルエディター機能

## メタ情報

| 項目     | 内容                                                                       |
| -------- | -------------------------------------------------------------------------- |
| タスクID | TASK-9A                                                                    |
| Phase    | 1                                                                          |
| タスク名 | スキルエディター機能（SKILL.md・サブリソースのGUI編集）                    |
| 作成日   | 2026-02-26                                                                 |
| 優先度   | 高                                                                         |
| 規模     | 中規模                                                                     |
| 依存     | TASK-9A-A（SkillFileManager、完了済）、TASK-9A-B（IPC ハンドラー、完了済） |
| ブロック | なし                                                                       |

## 目的

インポート済みスキルの SKILL.md およびサブリソース（agents/、references/ 等）を GUI で編集できるスキルエディター機能の要件を定義する。`~/.aiworkflow/skills/` 配下のスキルは読み書き可能、`~/.claude/skills/` 配下のスキルは読み取り専用とし、ファイルツリー表示、コンテンツ編集、未保存インジケータ、バックアップ・リストア機能を提供する。

## 実行タスク

- Task 1: 機能要件（FR）を定義する — ファイルツリー表示、コンテンツ編集、保存・バックアップ・復元の入出力仕様を確定する
- Task 2: 非機能要件（NFR）を定義する — セキュリティ・パフォーマンス・アクセシビリティ・状態管理の要件を確定する
- Task 3: 受入基準（AC）を定義する — 各 FR/NFR に対するテスト可能な検証条件を確定する
- Task 4: スコープを確認する — 実施対象と非対象を明文化する
- Task 5: アーキテクチャ層別要件を定義する — Electron 3プロセスモデルの各層における要件を整理する

### Task 1: 機能要件（FR）

#### FR-1: ファイルツリー表示

| 項目           | 内容                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 機能           | 選択したスキルのディレクトリ構造をツリー形式で表示する                                                     |
| データソース   | TASK-9A-B の `skill:readFile` IPC 経由で取得したスキルディレクトリ情報                                     |
| 表示内容       | SKILL.md（ルート）、agents/ 配下のファイル、references/ 配下のファイル、その他のサブディレクトリ・ファイル |
| ツリーノード   | ディレクトリノード（展開/折りたたみ可能）、ファイルノード（クリックで選択）                                |
| 状態表示       | 未保存の変更があるファイルに未保存インジケータ（ドット記号）を表示する                                     |
| 読み取り専用   | `~/.claude/skills/` 配下のスキルはツリー全体にロックアイコンを表示し、編集操作を無効化する                 |
| 更新タイミング | ファイル作成・削除・復元操作の完了後にツリーを自動リフレッシュする                                         |

#### FR-2: ファイル選択とコンテンツ表示

| 項目             | 内容                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| 機能             | ツリーでファイルを選択すると、右ペインにファイル内容を表示する                 |
| IPC チャンネル   | `skill:readFile`（TASK-9A-B 実装済み）                                         |
| 表示形式         | Markdown ファイル（.md）はシンタックスハイライト付きテキストエディタで表示する |
| その他ファイル   | .json, .yaml, .txt 等はプレーンテキストエディタで表示する                      |
| エラー表示       | ファイル読み込み失敗時はエラーメッセージをインラインで表示する                 |
| 読み取り専用表示 | `~/.claude/skills/` 配下のファイルはエディタを読み取り専用モードで表示する     |

#### FR-3: コンテンツ編集

| 項目       | 内容                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 機能       | エディタ上でファイル内容を編集し、変更内容をローカル状態に保持する                 |
| 編集対象   | `~/.aiworkflow/skills/` 配下のスキルファイルのみ                                   |
| 編集制限   | `~/.claude/skills/` 配下のファイルはキーボード入力・ペーストを無効化する           |
| 変更検知   | 元のファイル内容と現在のエディタ内容を比較し、差分がある場合に「未保存」状態とする |
| 未保存表示 | ファイルタブまたはファイルツリーノードに未保存インジケータ（●）を表示する          |

#### FR-4: ファイル保存

| 項目           | 内容                                                                              |
| -------------- | --------------------------------------------------------------------------------- |
| 機能           | 編集中のファイルを保存する                                                        |
| IPC チャンネル | `skill:writeFile`（TASK-9A-B 実装済み）                                           |
| トリガー       | 保存ボタンクリック、または `Cmd+S` / `Ctrl+S` キーボードショートカット            |
| バックアップ   | SkillFileManager が保存前に自動でバックアップを作成する（IPC 層では追加処理不要） |
| 成功時         | 未保存インジケータを消去し、保存完了トーストを表示する                            |
| 失敗時         | エラーメッセージをトーストで表示し、エディタ内容は保持する                        |
| 再スキャン     | SKILL.md 保存時は `skill:writeFile` ハンドラーがスキルメタデータを再スキャンする  |

#### FR-5: ファイル作成

| 項目           | 内容                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| 機能           | スキルディレクトリ内に新規ファイルを作成する                           |
| IPC チャンネル | `skill:createFile`（TASK-9A-B 実装済み）                               |
| トリガー       | ファイルツリーのコンテキストメニューまたは「新規ファイル」ボタン       |
| 入力           | ファイル名（相対パス）をダイアログで入力する                           |
| バリデーション | 空文字列、`..` を含むパス、既存ファイル名との重複を拒否する            |
| 成功時         | ツリーを更新し、作成したファイルを自動選択する                         |
| 読み取り専用時 | `~/.claude/skills/` 配下のスキルでは「新規ファイル」操作を非表示にする |

#### FR-6: ファイル削除

| 項目           | 内容                                                           |
| -------------- | -------------------------------------------------------------- |
| 機能           | スキルディレクトリ内のファイルを削除する                       |
| IPC チャンネル | `skill:deleteFile`（TASK-9A-B 実装済み）                       |
| トリガー       | ファイルツリーのコンテキストメニューまたは削除ボタン           |
| 確認           | 削除前に確認ダイアログを表示する（破壊的操作のため必須）       |
| バックアップ   | SkillFileManager が削除前に自動でバックアップを作成する        |
| 成功時         | ツリーを更新し、削除したファイルが選択中の場合は選択を解除する |
| 読み取り専用時 | `~/.claude/skills/` 配下のスキルでは「削除」操作を非表示にする |
| SKILL.md       | SKILL.md の削除は禁止する（スキルの根幹ファイルのため）        |

#### FR-7: バックアップ一覧表示

| 項目           | 内容                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| 機能           | スキルのバックアップ一覧を表示する                                         |
| IPC チャンネル | `skill:listBackups`（TASK-9A-B 実装済み）                                  |
| トリガー       | バックアップパネルの開閉トグル、または「履歴」ボタン                       |
| 表示項目       | バックアップファイル名、元ファイルパス、種別（backup / deleted）、作成日時 |
| ソート         | 作成日時の降順（最新が先頭）                                               |

#### FR-8: バックアップ復元

| 項目           | 内容                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 機能           | バックアップからファイルを復元する                                   |
| IPC チャンネル | `skill:restoreBackup`（TASK-9A-B 実装済み）                          |
| トリガー       | バックアップ一覧の「復元」ボタン                                     |
| 確認           | 復元前に確認ダイアログを表示する（現在のファイルが上書きされるため） |
| 成功時         | ファイルツリーとエディタ内容をリフレッシュする                       |
| 読み取り専用時 | `~/.claude/skills/` 配下のスキルでは「復元」ボタンを無効化する       |

#### FR-9: 未保存変更の警告

| 項目           | 内容                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 機能           | 未保存の変更がある状態でファイル切替・エディタ離脱時に警告ダイアログを表示する |
| トリガー       | 別ファイルの選択、スキル切替、エディタタブの閉じ操作                           |
| ダイアログ     | 「保存」「保存せずに続行」「キャンセル」の3つの選択肢を表示する                |
| 「保存」       | FR-4 のファイル保存を実行してから遷移する                                      |
| 「保存せず」   | 未保存の変更を破棄して遷移する                                                 |
| 「キャンセル」 | 遷移をキャンセルし、現在のファイルを編集し続ける                               |

### Task 2: 非機能要件（NFR）

#### NFR-1: セキュリティ

| ID      | 要件                                                                                                                  | 根拠                    |
| ------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| NFR-1-1 | ファイル操作は全て TASK-9A-B で実装済みの IPC チャンネル経由で行い、Renderer から直接ファイルシステムにアクセスしない | 04-electron-security.md |
| NFR-1-2 | `~/.claude/skills/` 配下のスキルは Renderer 側で編集 UI を無効化し、IPC 側でも ReadonlySkillError を返す              | 多層防御                |
| NFR-1-3 | ユーザー入力のファイルパスに対して Renderer 側でも `..` を含むパスを拒否する（IPC 側の validatePath に加え多層防御）  | P42 準拠                |
| NFR-1-4 | エディタ内容はメモリ上に保持し、Renderer のローカルストレージには保存しない                                           | セキュリティ原則        |

#### NFR-2: パフォーマンス

| ID      | 要件                                                                                     |
| ------- | ---------------------------------------------------------------------------------------- |
| NFR-2-1 | ファイルツリーの初回描画は 500ms 以内に完了する（100ファイル以下のスキルを対象とする）   |
| NFR-2-2 | ファイル内容の読み込み・表示は 300ms 以内に完了する（100KB 以下のファイルを対象とする）  |
| NFR-2-3 | エディタのキー入力に対するレスポンスは 50ms 以内とする（ユーザー体感でラグが発生しない） |
| NFR-2-4 | ファイルツリーの再描画（作成・削除後）は 200ms 以内に完了する                            |

#### NFR-3: アクセシビリティ（WCAG 2.1 AA）

| ID      | 要件                                                                                                     |
| ------- | -------------------------------------------------------------------------------------------------------- |
| NFR-3-1 | ファイルツリーは WAI-ARIA `tree` / `treeitem` ロールを使用し、キーボードナビゲーション（↑↓←→）に対応する |
| NFR-3-2 | エディタのフォーカス状態が視覚的に明確であること（コントラスト比 3:1 以上の枠線）                        |
| NFR-3-3 | 全ての操作ボタンに `aria-label` を付与する                                                               |
| NFR-3-4 | 未保存インジケータは色だけでなくアイコン（●）で情報を伝える                                              |
| NFR-3-5 | 読み取り専用状態はロックアイコンと `aria-readonly="true"` で伝達する                                     |

#### NFR-4: 状態管理

| ID      | 要件                                                                                              |
| ------- | ------------------------------------------------------------------------------------------------- |
| NFR-4-1 | エディタの状態（選択中ファイル、編集内容、未保存フラグ）は Zustand Store の skillSlice で管理する |
| NFR-4-2 | ファイルツリーの展開・折りたたみ状態はコンポーネントローカル state（useState）で管理する          |
| NFR-4-3 | 個別セレクタパターンを使用し、合成 Store Hook を useEffect 依存配列に含めない（P31 対策）         |

#### NFR-5: UI デザイン

| ID      | 要件                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| NFR-5-1 | Apple Human Interface Guidelines に準拠し、8px グリッドでスペーシングを統一する      |
| NFR-5-2 | ライト/ダークモードの両方で Apple 公式のシステムカラーを使用する                     |
| NFR-5-3 | 角丸は 8px〜12px で統一する                                                          |
| NFR-5-4 | 保存・削除・復元ボタンのホバー・アクティブ・フォーカス状態にフィードバックを提供する |
| NFR-5-5 | 破壊的操作（削除・復元）は確認ダイアログで保護する                                   |

| 観点             | チェック内容                                                                               |

| セキュリティ     | Renderer 側でも読み取り専用チェックを行い、IPC 側の多層防御と合わせて防御する              |
| 型安全性         | skillSlice の型定義と Preload API 戻り値型が矛盾しない                                     |
| パフォーマンス   | 大量ファイルのスキルでもツリー描画が遅延しない                                             |
| アクセシビリティ | キーボード操作のみで全機能にアクセスできる                                                 |
| 既知の Pitfall   | P31（Store Hooks無限ループ）、P39（happy-dom userEvent非互換）、P47（CSS変数テスト）の対策 |
| デザイン一貫性   | Apple HIG 準拠、既存 UI コンポーネントとの視覚的一貫性                                     |
