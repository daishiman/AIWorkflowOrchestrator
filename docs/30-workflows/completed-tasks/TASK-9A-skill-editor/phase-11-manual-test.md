## 目的

自動テストでは検証できないユーザー体験・UI/UX・実環境動作を手動で確認する。スキルエディター機能のファイル操作（読み込み・編集・保存・バックアップ・復元）が `~/.aiworkflow/skills/` と `~/.claude/skills/` の両ディレクトリで正しく動作することを検証する。

## 実行タスク

- 機能テスト（正常系）: SKILL.md読み込み、ファイル編集・保存、agents/references/配下の編集、バックアップ復元、未保存警告の動作確認
- 機能テスト（異常系）: 読み取り専用スキル、存在しないファイル、権限不足エラーの表示確認
- UIテスト: ファイルツリー表示、エディターレイアウト、アクセシビリティの検証
- 統合テスト: IPC通信を経由した実際のファイル操作の動作確認
- 手順書ウォークスルー証跡: 実行手順の再現結果と詰まりポイントを `walkthrough-log.md` に記録

## 実行手順

### ステップ1: テスト環境準備

1. `pnpm --filter @repo/desktop dev` でアプリを起動
2. テスト用スキルを `~/.aiworkflow/skills/` にインポート済みであることを確認
3. `~/.claude/skills/` に読み取り専用スキルが存在することを確認

### ステップ2: 機能テスト（正常系）実行

テストケース No.1〜6 を順番に実行し、結果を記録する。

### ステップ3: 機能テスト（異常系）実行

テストケース No.7〜9 を順番に実行し、結果を記録する。

### ステップ4: UIテスト実行

テストケース No.10〜12 を確認し、結果を記録する。

### ステップ5: 統合テスト連携実行

IPC経由のファイル操作テストを実行し、結果を記録する。

### ステップ6: 結果レポート作成

テスト結果を `outputs/phase-11/manual-test-result.md` に記録する。発見課題は0件の場合でも `outputs/phase-11/discovered-issues.md` に「0件」を明記して出力する。

### ステップ7: 手順書ウォークスルー証跡作成

手動テスト手順の実行ログと判断根拠を `outputs/phase-11/walkthrough-log.md` に記録する。詰まりがなければ「詰まりなし（0件）」を明記する。
