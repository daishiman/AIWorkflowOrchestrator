## 実行タスク

### タスク1: エッジケーステスト追加

**目的**: 境界値・異常系・競合状態のテストを追加する

**実行手順**:

1. 以下のエッジケーステストを追加する:
   - キュー上限到達時の古いイベント破棄
   - 連続高頻度イベント送信（バースト）
   - provider SDK初期化タイムアウト
   - 複数イベントの並列送信
   - キュードレイン中の新規イベント追加
2. 境界値テスト文字列の実文字数を`"...".length`で確認する（[Feedback W0-RV-001]対策）
3. テストが全件通ることを確認する

**期待される成果物**:

- `outputs/phase-6/expanded-test-cases.md`

### タスク2: ネットワーク障害シミュレーションテスト

**目的**: ネットワーク断・復帰・部分障害のシナリオをテストする

**実行手順**:

1. オフライン→イベント発火→キューイング確認テストを追加する
2. オンライン復帰→キュードレイン確認テストを追加する
3. HTTP送信失敗→リトライ or キュー維持のテストを追加する
4. 長期オフライン（TTL超過）時のキュー破棄テストを追加する

**期待される成果物**:

- `outputs/phase-6/expanded-test-cases.md`（ネットワークセクション）

### タスク3: 回帰テスト確認

**目的**: 既存計装ポイントへの影響がないことを確認する

**実行手順**:

1. `trackEvent.test.ts`の全テストがPASSすることを確認する
2. `SkillCreateWizard.tracking.test.tsx`の全テストがPASSすることを確認する
3. 回帰テスト結果を記録する
4. 失敗した場合はPhase 5に戻り修正する

**期待される成果物**:

- `outputs/phase-6/regression-test-result.md`

### タスク4: エッジケース結果記録

**目的**: 追加したエッジケーステストの結果を記録する

**実行手順**:

1. 全エッジケーステストを実行する
2. 結果を記録する
3. 失敗したテストがあれば修正する
4. テストスイート全体のPASS状態を確認する

**期待される成果物**:

- `outputs/phase-6/edge-case-result.md`
