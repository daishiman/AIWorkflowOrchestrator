## ワークフロー改善点

### 1. P53 環境制約への worktree 対策

- **現状**: esbuild アーキテクチャ不一致により worktree 環境で vitest/Electron 実行不可
- **改善提案**: worktree 作成時に `pnpm install --force` を実行するか、ネイティブモジュール互換を確認するスクリプトを SessionStart hook に追加する

### 2. 構造的カバレッジ分析の標準化

- **現状**: vitest 実行不可時に手動でテストケース→ソースコード行のマッピングを行った
- **改善提案**: テストケース ID（R-01 等）とソースコード行番号の対応表を Phase 4 で設計し、Phase 7 で自動照合するスクリプトを作成する
