# Phase 13: PR作成

## メタ情報

| 項目      | 内容                       |
| --------- | -------------------------- |
| Phase     | 13                         |
| Phase名   | PR作成                     |
| 目的      | コミット・PR・CI確認       |
| 前提Phase | Phase 12: ドキュメント更新 |
| 次Phase   | なし（完了）               |

---

## 1. 目的

修正内容をコミットし、Pull Requestを作成してCI/CDパイプラインを通過させる。

---

## 2. 実行タスク

### Task 1: 変更内容の確認

#### 手順

1. 変更されたファイルを確認する：

   ```bash
   git status
   git diff
   ```

2. 変更内容が想定通りであることを確認する

3. 不要な変更（デバッグコードの残り等）がないことを確認する

#### 成果物

- 変更内容確認結果

#### 完了条件

- [ ] 変更内容が想定通りである
- [ ] 不要な変更がない

---

### Task 2: ローカル確認

#### 手順

1. 以下のコマンドを順番に実行し、全てパスすることを確認する：

   ```bash
   # ビルド
   pnpm --filter @repo/desktop build

   # テスト
   pnpm --filter @repo/desktop test

   # 型チェック
   pnpm --filter @repo/desktop typecheck

   # Lint
   pnpm --filter @repo/desktop lint
   ```

#### 成果物

- ローカル確認結果

#### 完了条件

- [ ] ビルドが成功
- [ ] 全テストがパス
- [ ] 型チェックがパス
- [ ] Lintがパス

---

### Task 3: コミット作成

#### 手順

1. 変更をステージングする：

   ```bash
   git add -A
   ```

2. コミットメッセージを作成する：

   ```bash
   git commit -m "$(cat <<'EOF'
   fix(skill): SkillImportManagerの永続化不具合を修正

   ## 概要
   skill:list-imported APIが常に空配列を返す問題を修正

   ## 変更内容
   - SkillImportManagerにエラーハンドリングを追加
   - デバッグログを追加して永続化状態を可視化
   - ストア初期化時のデフォルト値設定を改善

   ## テスト
   - 永続化テストケースを追加
   - エッジケーステストを追加
   - 全既存テストがパス

   Closes #XXX

   Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>
   EOF
   )"
   ```

#### 成果物

- コミット

#### 完了条件

- [ ] コミットが作成されている
- [ ] コミットメッセージが適切である

---

### Task 4: PR作成（ユーザー許可後）

> **重要**: PR作成は必ずユーザーの明示的な許可を得てから実行すること。

#### 手順

1. `/ai:diff-to-pr`スキルを使用してPRを作成する

2. PR本文に以下を含める：
   - 概要
   - 変更内容
   - テスト結果
   - 関連Issue

#### 成果物

- Pull Request

#### 完了条件

- [ ] ユーザーの許可を得ている
- [ ] PRが作成されている
- [ ] PR本文が適切である

---

### Task 5: CI/CD確認

#### 手順

1. PRのCI/CDパイプラインが実行されるのを待つ

2. 全てのチェックがパスすることを確認する：
   - ビルドチェック
   - テストチェック
   - 型チェック
   - Lintチェック

3. 失敗した場合は原因を調査し、修正する

#### 成果物

- CI/CD結果

#### 完了条件

- [ ] 全CI/CDチェックがパス

---

### Task 6: 完了報告

#### 手順

1. `outputs/phase-13/completion-report.md`を作成する

2. 以下の内容を記載する：
   - タスクID
   - 完了日時
   - PR URL
   - CI/CD結果
   - 最終ステータス

#### 成果物

- `outputs/phase-13/completion-report.md`

#### 完了条件

- [ ] 完了報告が作成されている

## 6. PR作成に関する重要な注意

> **警告**: PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |
