# Phase 7: テストカバレッジ確認

## メタ情報

| 項目      | 内容                      |
| --------- | ------------------------- |
| Phase     | 7                         |

| 目的      | カバレッジ目標達成確認    |
| 前提Phase | Phase 6: テスト拡充       |
| 次Phase   | Phase 8: リファクタリング |

---

## 1. 目的

テストカバレッジが目標基準を満たしていることを確認する。

---

## 2. カバレッジ目標

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

---

## 3. 実行タスク

### Task 1: カバレッジ計測

#### 手順

1. カバレッジ付きでテストを実行する：

   ```bash
   pnpm --filter @repo/desktop test --coverage SkillImportManager
   ```

2. カバレッジレポートを確認する

3. 以下の項目を記録する：
   - Line Coverage
   - Branch Coverage
   - Function Coverage
   - カバーされていない行/分岐

#### 成果物

- カバレッジレポート

#### 完了条件

- [ ] カバレッジが計測されている
- [ ] 各カバレッジ指標が記録されている

---

### Task 2: カバレッジ目標達成確認

#### 手順

1. カバレッジ目標と実績を比較する

2. 目標未達の場合は、不足箇所を特定する

3. 不足箇所に対する追加テスト要否を判断する

#### チェックリスト

| 指標              | 目標 | 実績 | 達成 |
| ----------------- | ---- | ---- | ---- |
| Line Coverage     | 80%  | -    | -    |
| Branch Coverage   | 60%  | -    | -    |
| Function Coverage | 80%  | -    | -    |

#### 成果物

- カバレッジ達成確認結果

#### 完了条件

- [ ] カバレッジ目標が達成されている
- [ ] または、追加テストが必要な場合は特定されている

---

### Task 3: 追加テスト作成（必要な場合）

#### 手順

1. カバレッジが不足している箇所を特定する

2. 不足箇所に対するテストケースを追加する

3. 再度カバレッジを計測して目標達成を確認する

#### 成果物

- 追加テストコード（必要な場合）

#### 完了条件

- [ ] カバレッジ目標が達成されている

---

### Task 4: カバレッジレポート作成

#### 手順

1. `outputs/phase-07/coverage-report.md`を作成する

2. 以下の内容を記載する：
   - カバレッジ計測日時
   - 各指標の実績値
   - カバーされていない箇所（ある場合）
   - 追加テストの有無

#### 成果物

- `outputs/phase-07/coverage-report.md`

#### 完了条件

- [ ] カバレッジレポートが作成されている
