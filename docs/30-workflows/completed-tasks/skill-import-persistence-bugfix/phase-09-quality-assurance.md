## 2. 実行タスク

### Task 1: TypeScript型チェック

#### 手順

1. 型チェックを実行する：

   ```bash
   pnpm --filter @repo/desktop typecheck
   ```

2. エラーがある場合は修正する

3. 修正後、再度型チェックを実行してエラーがないことを確認する
