# Phase 11: 手動テスト検証

## メタ情報

| 項目      | 内容                         |
| --------- | ---------------------------- |
| Phase     | 11                           |
| Phase名   | 手動テスト検証               |
| 目的      | 実環境での動作確認           |
| 前提Phase | Phase 10: 最終レビューゲート |
| 次Phase   | Phase 12: ドキュメント更新   |

---

## 1. 目的

実際のElectronアプリ環境で修正が正常に動作することを手動で検証する。

---

## 2. 実行タスク

### Task 1: 機能テスト（正常系）

#### テストケース

| TC-ID  | 機能             | 手順                                                                   | 期待結果                               |
| ------ | ---------------- | ---------------------------------------------------------------------- | -------------------------------------- |
| TC-001 | スキルインポート | 1. アプリ起動 2. スキル一覧表示 3. 任意のスキルをインポート            | インポート成功メッセージが表示される   |
| TC-002 | インポート確認   | TC-001後、`skill:list-imported`を実行                                  | インポートしたスキルが一覧に含まれる   |
| TC-003 | 永続化確認       | TC-002後、1. アプリ終了 2. アプリ再起動 3. `skill:list-imported`を実行 | インポートしたスキルが維持されている   |
| TC-004 | スキル削除       | TC-003後、インポート済みスキルを削除                                   | 削除成功メッセージが表示される         |
| TC-005 | 削除後確認       | TC-004後、`skill:list-imported`を実行                                  | 削除したスキルが一覧から除外されている |
| TC-006 | 削除永続化確認   | TC-005後、1. アプリ終了 2. アプリ再起動 3. `skill:list-imported`を実行 | 削除状態が維持されている               |

#### 成果物

- 機能テスト結果

#### 完了条件

- [ ] 全テストケースがPASS
