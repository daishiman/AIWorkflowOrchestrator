## 3. 実アプリ手動テスト手順

ユーザーによる実アプリ確認用の手順を以下に記載します。

### 3.1 事前準備

```bash
cd apps/desktop
pnpm dev
```

### 3.2 テスト手順

1. **スキルインポート確認**
   - DevToolsのConsoleを開く
   - スキル一覧画面で任意のスキルをインポート
   - `skill:list-imported` IPC呼び出しでインポート確認

2. **永続化確認**
   - アプリを完全終了（Cmd+Q）
   - アプリを再起動
   - `skill:list-imported` IPC呼び出しでインポート維持を確認

3. **ストアファイル確認**
   ```bash
   cat ~/Library/Application\ Support/com.aiworkflow.orchestrator/skills.json
   ```
