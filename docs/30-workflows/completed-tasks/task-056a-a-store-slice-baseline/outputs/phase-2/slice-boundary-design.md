## 1. 判定種別（固定）

| 種別             | 意味                                       |
| ---------------- | ------------------------------------------ |
| `new`            | 新規 Slice/ドメインとして追加する          |
| `extend`         | 既存 Slice/型の拡張で対応する              |
| `no-change`      | 既存実装を変更せず流用する                 |
| `local-useState` | Store ではなく View ローカル状態で管理する |

## 2. 判定ルール

- ルールR1: 複数画面で共有され、永続化または横断イベントが必要な場合は `new`。
- ルールR2: 既存 Slice の責務に収まり、型拡張のみで足りる場合は `extend`。
- ルールR3: 画面固有の一時状態は `local-useState`。
- ルールR4: 既存責務と重複し、追加価値がない場合は `no-change`。
- ルールR5: 判定理由は1項目1文で記載し、後続タスク参照用リンクを持つ。
