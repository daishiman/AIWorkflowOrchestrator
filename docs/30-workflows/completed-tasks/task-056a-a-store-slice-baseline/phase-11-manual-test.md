## 実行手順

### Step 1: 手動シナリオ作成

- Dashboard、SkillCenter、HistorySearchの3画面で検証シナリオを定義する。
- 各シナリオに期待結果を1件設定する。

### Step 2: 証跡定義

- スクリーンショット命名規則を定義する。
- 判定ログ形式を定義する。

### Step 3: 記録テンプレート作成

- PASS/FAIL判定欄を定義する。
- 失敗時の再現手順欄を定義する。

## テストケース

| テストケース | 画面                           | 期待結果                                                      |
| ------------ | ------------------------------ | ------------------------------------------------------------- |
| TC-11-01     | Dashboard                      | 基本統計とアクティビティが崩れず表示される                    |
| TC-11-02     | SkillCenter                    | 検索入力・カテゴリ・カード一覧が視認可能で主要CTAが判別できる |
