# Phase 5: 設計変更記録

## タスク: TASK-FIX-10-1-VITEST-ERROR-HANDLING

## プロダクションコード変更

**なし**。本タスクではプロダクションコードへの変更は発生しなかった。

## 設定変更

### vitest.config.ts

#### 変更1: dangerouslyIgnoreUnhandledErrors の削除

```diff
-    dangerouslyIgnoreUnhandledErrors: true,
```

**理由**: このフラグは Vitest の未処理エラー検出を無効化し、テストの信頼性を低下させていた。テスト内のモジュール解決エラーが隠蔽されており、252テストが実際にはエラーを発生させながらも「パス」と判定されていた。

#### 変更2: @repo/shared サブパスエイリアスの追加

18個の `@repo/shared` サブパスエイリアスを `resolve.alias` セクションに追加。

**理由**: Vitest はモノレポの `packages/shared` パッケージを解決する際に `node_modules` 経由の `dist/` ディレクトリを参照する。テスト実行時にビルド済みファイルが最新でない場合にモジュール解決エラーが発生する。ソースファイルを直接参照するエイリアスを設定することで、ビルド状態に依存しない安定したテスト実行を実現する。

**エイリアス設計方針**:

- 長い（具体的な）パスを先に配置し、短い（汎用的な）パスを後に配置
- `@repo/shared` (パッケージエントリ) は全サブパスエイリアスの後に配置
- 各エイリアスは `packages/shared/package.json` の `exports` フィールドに対応するソースファイルを参照

## アーキテクチャへの影響

なし。本変更は Vitest テスト設定のみの変更であり、ランタイムの動作やアーキテクチャには影響しない。
