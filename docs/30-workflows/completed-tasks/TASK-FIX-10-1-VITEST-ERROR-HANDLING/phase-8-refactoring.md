## 目的

Phase 5-6で修正・追加したコードの品質を改善する。動作を変えずに、重複排除・命名改善・テストユーティリティの整理を行う。

## 実行タスク

- 重複排除: 複数テストファイルで同じ非同期エラーハンドリングパターンが存在する場合、共通ヘルパーに抽出
- テストユーティリティ整理: テスト用の非同期クリーンアップヘルパーの整理・共通化
- 命名改善: 修正箇所の変数名・関数名・テスト記述の明確化
- コードスメル検出: Phase 5-6で追加したコード内の問題パターン特定と修正

## 実行手順

### ステップ1: 重複パターンの特定

Phase 5で修正した箇所を確認し、以下の重複パターンを特定する:

| 重複パターン                      | 検出方法                                                                               |
| --------------------------------- | -------------------------------------------------------------------------------------- |
| 同一の `afterEach` クリーンアップ | `grep -rn "afterEach" apps/desktop/src/**/*.test.ts` で同一パターンを検索              |
| 同一のモック設定                  | `grep -rn "mockResolvedValue\|mockRejectedValue" apps/desktop/src/**/*.test.ts` で検索 |
| 同一のエラーハンドリング          | `grep -rn "rejects.toThrow\|try.*catch" apps/desktop/src/**/*.test.ts` で検索          |

### ステップ2: 共通ヘルパーの抽出

重複が3箇所以上で発見された場合、共通ヘルパーに抽出する。

#### 抽出候補:

- `apps/desktop/src/test/helpers/async-cleanup.ts`: 非同期クリーンアップヘルパー
- `apps/desktop/src/test/helpers/mock-setup.ts`: 共通モックセットアップ（既存のものがあれば拡張）

#### 抽出基準:

| 基準                 | 抽出する   | 抽出しない         |
| -------------------- | ---------- | ------------------ |
| 重複箇所数           | 3箇所以上  | 2箇所以下          |
| パターンの一致度     | 完全一致   | パラメータが異なる |
| 既存ヘルパーとの重複 | 既存に統合 | 新規作成           |

### ステップ3: 命名改善

- テスト記述（`describe` / `it` の文字列）が修正内容を正確に反映しているか確認する
- 変数名が意図を明確に表しているか確認する

### ステップ4: コードスメル検出と修正

以下のコードスメルを確認し、該当する場合は修正する:

| コードスメル             | 確認方法                                   | 修正方針                       |
| ------------------------ | ------------------------------------------ | ------------------------------ |
| 深いネスト（3段以上）    | テストコードのインデント確認               | Early returnまたはヘルパー抽出 |
| 長いテスト関数（30行超） | テスト関数の行数確認                       | Arrange/Act/Assertに分離       |
| マジックナンバー         | テスト内のハードコーディングされた数値     | 定数として定義                 |
| 重複アサーション         | 同じアサーションが複数テストで繰り返される | ヘルパー関数に抽出             |

### ステップ5: リファクタリング後のテスト実行

```bash
cd apps/desktop && pnpm vitest run
```

全テストがPASSすることを確認する（動作変更なし）。
