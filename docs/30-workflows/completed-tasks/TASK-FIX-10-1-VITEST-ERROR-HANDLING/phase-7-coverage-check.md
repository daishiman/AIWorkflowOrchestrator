## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。基準未達の場合はPhase 6に戻ってテストを追加する。

## 実行タスク

- カバレッジ再測定: テストカバレッジの再計測
- ゲート判定: カバレッジ基準の充足判定
- 未達時の差分分析: 基準未達の場合の不足箇所特定

## 実行手順

### ステップ1: カバレッジ再測定

```bash
cd apps/desktop && pnpm vitest run --coverage
```

### ステップ2: カバレッジゲート判定

以下の基準で判定を行う:

#### ユニットテストカバレッジゲート

| 指標              | 最低基準 | 推奨基準 | 測定結果       | 判定          |
| ----------------- | -------- | -------- | -------------- | ------------- |
| Line Coverage     | 80%      | 90%      | （実行時記入） | （PASS/FAIL） |
| Branch Coverage   | 60%      | 70%      | （実行時記入） | （PASS/FAIL） |
| Function Coverage | 80%      | 90%      | （実行時記入） | （PASS/FAIL） |

#### 判定ルール

| 判定結果 | 条件                         | 対応                    |
| -------- | ---------------------------- | ----------------------- |
| PASS     | 全指標が最低基準以上         | Phase 8へ進行           |
| FAIL     | いずれかの指標が最低基準未満 | Phase 6へ戻りテスト追加 |

### ステップ3: 未達時の差分分析（基準未達の場合のみ）

カバレッジが未達の場合、以下の分析を行う:

1. 未到達行・分岐・関数を一覧化する
2. 不足箇所を優先度順に並べる（修正箇所に近い箇所を優先）
3. Phase 6に戻り、不足分のテストを追加する
