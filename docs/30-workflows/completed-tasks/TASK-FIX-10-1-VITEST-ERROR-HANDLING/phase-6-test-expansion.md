## 目的

Phase 5で修正したテストのカバレッジを拡充し、非同期エラーハンドリングのリグレッション防止テストを追加する。修正パターンが将来再発しないことを保証するテストを整備する。

## 実行タスク

- カバレッジ分析: Phase 5の修正箇所に対するカバレッジ測定と不足領域の特定
- リグレッション防止テスト追加: 修正した非同期エラーハンドリングパターンが再発しないことを検証するテスト追加
- 非同期クリーンアップ検証テスト: テスト終了後の非同期処理クリーンアップが正しく行われることを検証するテスト追加
- 統合テスト拡充: IPC通信・サービス層の非同期エラー伝播テスト追加

## 実行手順

### ステップ1: カバレッジ測定

Phase 5で修正した箇所を対象にカバレッジを測定する。

```bash
cd apps/desktop && pnpm vitest run --coverage
```

### ステップ2: ギャップ分析

1. カバレッジレポートから、Phase 5で修正したファイルのカバレッジを確認する
2. 未到達の行/分岐/関数を一覧化する
3. 以下のテスト不足パターンを特定する:

| テスト不足パターン           | 確認方法                                             |
| ---------------------------- | ---------------------------------------------------- |
| 非同期エラーの分岐未テスト   | `catch` ブロック内のコードがカバレッジ未到達         |
| クリーンアップ処理の未テスト | `afterEach` / `finally` 内のコードがカバレッジ未到達 |
| エラー伝播パスの未テスト     | サービス層のエラーがRendererまで到達するパス未テスト |

### ステップ3: リグレッション防止テスト追加

Phase 5で修正した各カテゴリについて、リグレッション防止テストを追加する。

#### 3-1: 未処理Promise拒否の検出テスト

Phase 5で修正した箇所が再び未処理Promise拒否を発生させないことを確認するテストパターン:

```typescript
// テストパターン例: 非同期エラーが正しくキャッチされることを確認
it("非同期エラーが未処理にならないこと", async () => {
  // Arrange: エラーを発生させる条件を設定
  // Act: 非同期操作を実行
  // Assert: エラーが正しくキャッチされ、未処理にならないことを確認
  await expect(asyncOperation()).rejects.toThrow("期待されるエラーメッセージ");
});
```

#### 3-2: テストクリーンアップ検証テスト

テスト終了後に非同期処理が残っていないことを確認するテストパターン:

```typescript
// テストパターン例: タイマーがクリーンアップされることを確認
afterEach(() => {
  vi.clearAllTimers();
  vi.restoreAllMocks();
});
```

### ステップ4: 統合テスト拡充

IPC通信やサービス層の非同期エラー伝播に関するテストを追加する。

| テストカテゴリ               | 検証内容                                                    | テストファイル配置                       |
| ---------------------------- | ----------------------------------------------------------- | ---------------------------------------- |
| IPC非同期エラー伝播テスト    | IPCハンドラのPromise拒否がRenderer側に伝播すること          | `apps/desktop/src/main/ipc/**/*.test.ts` |
| サービス層非同期エラーテスト | サービスメソッドのエラーが呼び出し元に伝播すること          | `apps/desktop/src/main/**/*.test.ts`     |
| Renderer非同期クリーンアップ | コンポーネントアンマウント時にPromiseがキャンセルされること | `apps/desktop/src/renderer/**/*.test.ts` |

### ステップ5: 全テスト再実行

```bash
cd apps/desktop && pnpm vitest run
```

全テストがPASSすることを確認する。

## 統合テスト連携【必須】

統合テストの拡充（非同期エラーハンドリング関連のカバレッジ向上）:

| テストカテゴリ               | 検証項目                                                   | 目標 |
| ---------------------------- | ---------------------------------------------------------- | ---- |
| IPC非同期エラー伝播          | IPCハンドラの非同期エラーがRenderer側に正しく伝播すること  | 100% |
| サービス層エラーハンドリング | サービスメソッドのPromise拒否が呼び出し元に伝播すること    | 100% |
| Renderer非同期処理           | コンポーネントの非同期処理が正しくクリーンアップされること | 80%+ |
