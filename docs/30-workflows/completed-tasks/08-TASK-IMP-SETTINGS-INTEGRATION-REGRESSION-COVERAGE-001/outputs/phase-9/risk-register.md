## リスク一覧

### 1. act() 警告

| 項目      | 内容                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスク ID | R-01                                                                                                                                                  |
| 影響度    | 低                                                                                                                                                    |
| 発生確率  | 確定（現時点で発生済み）                                                                                                                              |
| blocking  | No                                                                                                                                                    |
| 対象      | INT-05a, INT-05b, INT-05c の3テストケース                                                                                                             |
| 説明      | ApiKeysSection の非同期 IPC 呼び出し（apiKey.list()）の state 更新がテスト終了後に発生し、`act()` 警告が出力される。テストの PASS/FAIL には影響しない |
| 対策      | `waitFor` 追加で解消可能。Phase 8 で検討済みだが、テスト機能への影響がないため現時点では未対応                                                        |

### 2. AccountSection の大量セレクタ

| 項目      | 内容                                                                                                                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスク ID | R-02                                                                                                                                                                                                                            |
| 影響度    | 中                                                                                                                                                                                                                              |
| 発生確率  | 低                                                                                                                                                                                                                              |
| blocking  | No                                                                                                                                                                                                                              |
| 対象      | AccountSection が依存する Zustand 個別セレクタ 18個                                                                                                                                                                             |
| 説明      | AccountSection は isAuthenticated, userName, userEmail, avatarUrl 等の18個の個別セレクタに依存しており、harness でこれら全てのデフォルト値を提供する必要がある。セレクタの追加・変更時に harness のメンテナンスコストが増加する |
| 対策      | harness の `createDefaultStoreState()` で全18セレクタをカバー済み（M-01 対応済み）。新規セレクタ追加時は harness のデフォルト値に追加する運用ルールを設定                                                                       |

### 3. ApiKeysSection の非同期 IPC 依存

| 項目      | 内容                                                                                                                                                                                                                                                                 |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスク ID | R-03                                                                                                                                                                                                                                                                 |
| 影響度    | 中                                                                                                                                                                                                                                                                   |
| 発生確率  | 低                                                                                                                                                                                                                                                                   |
| blocking  | No                                                                                                                                                                                                                                                                   |
| 対象      | ApiKeysSection の `window.electronAPI.apiKey.list()` 呼び出し                                                                                                                                                                                                        |
| 説明      | ApiKeysSection は mount 時に `window.electronAPI.apiKey.list()` を非同期呼び出しし、レスポンスに基づいてプロバイダー一覧を表示する。electronAPI mock のレスポンス形式が実際の IPC レスポンスと乖離した場合、統合テストが実環境と異なる振る舞いを検証するリスクがある |
| 対策      | harness の `createDefaultElectronApiKey()` で mock レスポンス形式を一元管理し、IPC 契約変更時に harness のみを更新すれば全テストに反映される設計で安定化済み                                                                                                         |
