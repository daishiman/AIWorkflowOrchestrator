| Node.js                | v20.x以上                           | OK     |
| pnpm                   | v9.x以上                            | OK     |
| アプリケーションビルド | `pnpm --filter @repo/desktop build` | 要実行 |

### 環境構築手順

```bash
# 1. 依存関係インストール
pnpm install

# 2. sharedパッケージビルド
pnpm --filter @repo/shared build

# 3. desktopアプリケーションビルド
pnpm --filter @repo/desktop build

# 4. アプリケーション起動
pnpm --filter @repo/desktop start
```

### APIキー設定

1. アプリケーション起動後、設定画面を開く
2. Anthropic APIキーを入力
3. 保存ボタンをクリック
4. 設定が保持されることを確認
