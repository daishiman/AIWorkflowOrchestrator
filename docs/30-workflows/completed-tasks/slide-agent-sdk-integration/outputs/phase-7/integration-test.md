## 失敗テストの分析

### INT-06: 30秒タイムアウトエラー

**原因**: Anthropic SDKのモックが即座にレスポンスを返すため、setTimeout + AbortController によるタイムアウト処理がトリガーされない。

**影響**: テスト環境でのみ。実環境では正常動作。

**対策**: 実SDKを使用したE2Eテストで検証。

### INT-EXT-15: 複数executorインスタンスの一貫性

**原因**: `getAgentAPI()` がシングルトンパターンを使用しているため、複数の SkillExecutor インスタンスが同じ AgentClient を共有する。これにより、一方の実行中に他方が実行しようとすると排他エラーが発生する。

**影響**: 設計上の制約として正常な動作。

**対策**: ドキュメント化済み。必要に応じて、インスタンスごとに独立した AgentClient を作成するオプションを追加可能。
