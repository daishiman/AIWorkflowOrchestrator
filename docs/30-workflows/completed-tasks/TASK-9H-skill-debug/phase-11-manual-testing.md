## 目的

Electron 実環境およびユニットテスト結果を用いて、7つのデバッグIPCチャンネルの動作を検証する。
自動テストでは検証できないデバッグセッションのライフサイクル、ステップ実行の状態遷移、式評価のサンドボックス境界を実環境で確認する。

## 背景

デバッグ機能はスキル実行中のリアルタイム状態操作を伴うため、ユニットテストだけでは以下の動作を完全に検証できない:

- ブレークポイントでの実行停止と再開のタイミング
- ステップ実行時の状態遷移（Step Over / Step Into / Step Out）
- `skill:debug:event` によるリアルタイムイベント通知
- 同時デバッグセッション制限の実環境動作

---

## テスト実施方針

### 制限事項

- Preload API のスタブ未解消チャンネルが存在する場合、DevToolsからの直接呼び出しが不可能な場合がある
- その場合はユニットテスト結果をもって手動テストの代替とする
- 代替判断は Phase 11 実施時に決定し、理由を `outputs/phase-11/manual-test-result.md` に記録する

### 検証方法

| 方法                           | 対象                              | 優先度 |
| ------------------------------ | --------------------------------- | ------ |
| DevToolsコンソール直接呼び出し | Preload APIが接続済みのチャンネル | 高     |
| ユニットテスト結果の確認       | 全7チャンネル                     | 高     |
| コードリーディング             | セキュリティ実装・サンドボックス  | 中     |
