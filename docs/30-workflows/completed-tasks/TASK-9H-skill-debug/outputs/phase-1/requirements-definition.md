## 機能要件（FR）

### FR-1: デバッグセッション管理

| ID     | 要件                                                           | 優先度 |
| ------ | -------------------------------------------------------------- | ------ |
| FR-1-1 | スキル名・プロンプト・初期ブレークポイント配列でセッション開始 | 必須   |
| FR-1-2 | 一意のセッションID（UUID v4）でセッション追跡                  | 必須   |
| FR-1-3 | 状態遷移: idle → running → paused → running → completed        | 必須   |
| FR-1-4 | error 遷移時にエラー情報保持しセッション終了                   | 必須   |
| FR-1-5 | stop コマンドで任意の状態から即座に終了                        | 必須   |
| FR-1-6 | 同時実行セッション数: 1個のみ（排他制御）                      | 必須   |

### FR-2: ブレークポイント管理

| ID     | 要件                                                 | 優先度 |
| ------ | ---------------------------------------------------- | ------ |
| FR-2-1 | タイプ: tool / hook / step の3種類                   | 必須   |
| FR-2-2 | tool タイプは toolName で特定ツール指定              | 必須   |
| FR-2-3 | hook タイプは hookType (PreToolUse/PostToolUse) 指定 | 必須   |
| FR-2-4 | condition フィールド（文字列式）で条件付き停止       | 任意   |
| FR-2-5 | enabled フラグで一時的無効化                         | 必須   |
| FR-2-6 | 実行中にブレークポイント動的追加・削除               | 必須   |
| FR-2-7 | 各ブレークポイントに一意ID（UUID v4）自動生成        | 必須   |

### FR-3: ステップ実行

| ID     | 要件                                            | 優先度 |
| ------ | ----------------------------------------------- | ------ |
| FR-3-1 | continue: 次のブレークポイントまで実行継続      | 必須   |
| FR-3-2 | stepOver: 現在のステップ実行→次のステップで停止 | 必須   |
| FR-3-3 | stepInto: ネストされたツール呼び出し内部に入る  | 必須   |
| FR-3-4 | stepOut: 現在のスコープを抜けて呼び出し元に戻る | 必須   |
| FR-3-5 | pause: 実行中のセッションを一時停止             | 必須   |
| FR-3-6 | stop: デバッグセッションを即座に終了            | 必須   |
| FR-3-7 | stepNumber, type, timestamp を記録              | 必須   |
| FR-3-8 | input/output を記録しインスペクション可能       | 必須   |

### FR-4: 変数インスペクション

| ID     | 要件                                         | 優先度 |
| ------ | -------------------------------------------- | ------ |
| FR-4-1 | ドット区切りパスで変数指定しインスペクション | 必須   |
| FR-4-2 | Record<string, unknown> 型で変数管理         | 必須   |
| FR-4-3 | 変数変更時に variable-changed イベント発火   | 必須   |

### FR-5: 式評価

| ID     | 要件                                                  | 優先度 |
| ------ | ----------------------------------------------------- | ------ |
| FR-5-1 | 一時停止中にJavaScript式を評価し結果返却              | 必須   |
| FR-5-2 | スコープはセッション variables のみ（グローバル禁止） | 必須   |
| FR-5-3 | タイムアウト: 5秒                                     | 必須   |
| FR-5-4 | ファイルシステム・ネットワーク・プロセス操作禁止      | 必須   |

### FR-6: コールスタック表示

| ID     | 要件                                           | 優先度 |
| ------ | ---------------------------------------------- | ------ |
| FR-6-1 | depth, name, type, startTime を記録            | 必須   |
| FR-6-2 | ツール呼び出し開始でプッシュ、完了でポップ     | 必須   |
| FR-6-3 | 一時停止中にコールスタック全体インスペクション | 必須   |

### FR-7: デバッグイベント通知

| イベント         | 発火条件             | ペイロード                      |
| ---------------- | -------------------- | ------------------------------- |
| step             | 各ステップ実行時     | sessionId, step                 |
| breakpoint-hit   | ブレークポイント到達 | sessionId, breakpoint, step?    |
| variable-changed | 変数変更時           | sessionId, path, value          |
| session-ended    | セッション終了時     | sessionId, error?, completedAt? |

## 非機能要件（NFR）

### NFR-1: セキュリティ

- 式評価はサンドボックス（vm.createContext）で実行
- 全IPCハンドラで validateIpcSender 検証
- 全文字列引数にP42準拠3段バリデーション
- 式評価タイムアウト5秒で無限ループ防止
- デバッグイベントにPII・秘密情報を含めない

### NFR-2: パフォーマンス

- ブレークポイント判定: 10ms以内
- イベント通知遅延: 50ms以内
- 変数インスペクション: 100ms以内
- 最大ステップ数: 10,000
- セッションタイムアウト: 30分

### NFR-3: 信頼性

- セッション異常終了時のリソース解放保証
- ブレークポイント上限: 100個/セッション
- メモリリーク防止（タイマー・リスナーのクリーンアップ）
