#### 5.4 補足事項（PASS判定下の任意改善点）

以下は機能・互換性に影響しない任意の改善点として記録する:

1. **verify-na-log コマンドの堅牢性**: Markdown テーブルのパースが grep + IFS 分割に依存しているため、テーブル形式が変わると壊れる可能性がある。将来的に専用パーサー（Node.js スクリプト）への移行を検討する
2. **baseline取得の自動化**: `git stash` ベースの baseline 取得は、未コミット変更がある場合にリスクがある。`git worktree` ベースの取得方式を将来的に検討する

これらは未タスク化の必要なし（機能影響・互換性影響なし）。Phase 12 の改善検討時に参照する。
