## 概要

本ドキュメントは、FR-1〜FR-4 の各機能要件に対する受け入れ基準（AC）12件を定義する。各ACには検証手段と期待結果を明記し、Phase 9（品質検証）および Phase 10（最終レビュー）での合否判定に使用する。

## FR-1: N/A判定ログテンプレートの定義

### AC-1-1: 推奨5点セット仕様書への判定記録の網羅性

| 項目   | 内容                                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| AC ID  | AC-1-1                                                                                                                                           |
| 対象FR | FR-1                                                                                                                                             |
| 基準   | 全推奨5点セット仕様書（interfaces, api-ipc, security, task-workflow, lessons-learned）に対して、`updated` または `na` のいずれかが必ず記録される |

**検証手段:**

```bash
# N/A判定ログから specName を抽出し、推奨5点セットとの差分を確認
EXPECTED_SPECS=("interfaces" "api-ipc" "security" "task-workflow" "lessons-learned")
# ログ内の specName フィールドに5件全てが存在することを確認
# 未記録の仕様書が0件であること
```

**期待結果:**

| 条件                                                       | 判定 |
| ---------------------------------------------------------- | ---- |
| 推奨5点セット全てに `updated` または `na` が記録されている | PASS |
| 1件以上の未記録仕様書がある                                | FAIL |

## FR-3: current/baseline分離記録フォーマットの定義

### AC-3-1: current違反のみによる合否判定

| 項目   | 内容                                                                            |
| ------ | ------------------------------------------------------------------------------- |
| AC ID  | AC-3-1                                                                          |
| 対象FR | FR-3                                                                            |
| 基準   | `currentViolations.total === 0` の場合に PASS、`> 0` の場合に FAIL と判定される |

**検証手段:**

```bash
# テストシナリオ1: currentViolations.total === 0, baselineViolations.total === 5
#   → 期待判定: PASS
# テストシナリオ2: currentViolations.total === 1, baselineViolations.total === 0
#   → 期待判定: FAIL
# テストシナリオ3: currentViolations.total === 3, baselineViolations.total === 10
#   → 期待判定: FAIL
```

**期待結果:**

| currentViolations.total | baselineViolations.total | 期待判定 |
| ----------------------- | ------------------------ | -------- |
| 0                       | 0                        | PASS     |

| 1                       | 0                        | FAIL     |
| 3                       | 10                       | FAIL     |
