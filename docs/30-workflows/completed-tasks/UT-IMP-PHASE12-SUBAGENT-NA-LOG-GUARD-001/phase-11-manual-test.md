## 目的

本タスクは運用改善タスク（コード実装なし）であるため、手動テストは「テンプレート記入のウォークスルー」と「既存スクリプトの互換動作確認」を対象とする。N/A判定ログテンプレート、三点突合手順、current/baseline分離記録、SubAgent分担表の4つの運用テンプレートが正しく機能することを確認する。

## 実行タスク

- Task 1: N/A判定ログ記入テスト — テンプレートに従って更新不要な仕様書のN/A判定ログを記入し、理由と代替証跡が記録されることを確認
- Task 2: 三点突合テスト（全PASS） — 成果物実体・artifacts.json・チェックリストの三点が全て完了した状態で突合し、完了判定が返ることを確認
- Task 3: 三点突合テスト（部分FAIL） — artifacts.jsonがpendingの状態で突合し、未完了判定が返ることを確認
- Task 4: current/baseline分離記録テスト — 監査結果をcurrent=0, baseline=Nの形式で記録できることを確認
- Task 5: SubAgent分担表テスト — 全仕様書に「更新」または「N/A」が割り当てられることを確認
- Task 6: リグレッションテスト — 既存のPhase 12ワークフローと監査スクリプトが互換動作すること
