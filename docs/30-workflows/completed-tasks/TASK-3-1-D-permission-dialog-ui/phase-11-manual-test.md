## 目的

実際のElectronアプリケーションで手動テストを実施し、ユーザー視点での動作確認を行う。

## 背景

自動テストでは検出が難しいUI/UXの問題や、実環境での挙動を確認するために手動テストを実施する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 開発環境起動

**目的**: 手動テスト用の開発環境を起動する

**実行手順**:

1. 開発サーバー起動:

   ```bash
   pnpm --filter @repo/desktop dev
   ```

2. Electronアプリが正常に起動することを確認

3. 開発者ツールを開き、コンソールエラーがないことを確認

**期待される成果物**:

- 開発環境が正常に起動

---

### タスク2: Permission Dialog表示テスト

**目的**: PermissionDialogが正しく表示されることを確認する

**実行手順**:

1. スキル実行を開始:
   - スキル選択画面でテスト用スキルを選択
   - 実行ボタンをクリック

2. Permission要求発生時:
   - ダイアログがモーダル表示されることを確認
   - 背景がグレーアウトされることを確認
   - ダイアログが画面中央に表示されることを確認

3. ダイアログ内容確認:
   - ツール名が正しく表示されていることを確認
   - 引数情報が正しく表示されていることを確認
   - 理由（reason）が表示されていることを確認
   - 「Allow」「Deny」ボタンが表示されていることを確認
   - 「Remember my choice」チェックボックスが表示されていることを確認

**期待される成果物**:

- `outputs/phase-11/dialog-display-test.md`: ダイアログ表示テスト結果

---

### タスク3: ユーザー操作テスト

**目的**: ユーザー操作が正しく処理されることを確認する

**実行手順**:

1. 許可操作テスト:
   - 「Allow」ボタンをクリック
   - ダイアログが閉じることを確認
   - スキル実行が継続することを確認

2. 拒否操作テスト:
   - 「Deny」ボタンをクリック
   - ダイアログが閉じることを確認
   - スキル実行が適切にハンドリングされることを確認

3. Remember choice テスト:
   - チェックボックスをONにして許可
   - 同じツールの次回要求時に自動許可されることを確認
   - （または選択が記憶されていることを確認）

**期待される成果物**:

- `outputs/phase-11/user-operation-test.md`: ユーザー操作テスト結果

---

### タスク4: アクセシビリティテスト

**目的**: アクセシビリティ要件を満たしていることを確認する

**実行手順**:

1. キーボードナビゲーション:
   - Tabキーでボタン間を移動できることを確認
   - Enterキーでボタンを押せることを確認
   - Escapeキーでダイアログを閉じられることを確認（Denyとして処理）

2. フォーカストラップ:
   - ダイアログ表示中、Tab/Shift+Tabでダイアログ外にフォーカスが移動しないことを確認
   - ダイアログ表示時に自動的にフォーカスが当たることを確認

3. スクリーンリーダー対応:
   - ダイアログのrole属性が正しいことを確認（開発者ツールで確認）
   - aria-label/aria-labelledbyが設定されていることを確認

**期待される成果物**:

- `outputs/phase-11/accessibility-test.md`: アクセシビリティテスト結果

---

### タスク5: エッジケーステスト

**目的**: エッジケースでの挙動を確認する

**実行手順**:

1. 連続リクエストテスト:
   - 複数のPermission要求が連続で発生した場合の挙動を確認
   - 各リクエストが順番に表示されることを確認

2. 長いテキストテスト:
   - 長いツール名、長い引数のケースを確認
   - テキストが適切に折り返しまたは省略されることを確認

3. 実行中断テスト:
   - Permission待ち中にスキル実行を中断した場合の挙動を確認
   - ダイアログが適切に閉じることを確認

**期待される成果物**:

- `outputs/phase-11/edge-case-test.md`: エッジケーステスト結果
