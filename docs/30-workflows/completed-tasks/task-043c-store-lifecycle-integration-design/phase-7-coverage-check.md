| 項目   | 値                                 |

## 目的

Phase 5-6 で実装・テスト追加した selector/action のカバレッジが品質基準を充足しているか確認し、未達の場合は Phase 6 へ差し戻す。

## 実行タスク

- カバレッジレポートを生成し、基準値との比較を行う
- 未カバー箇所を特定し、テスト追加の要否を判断する
- 基準未達の場合は Phase 6 へ差し戻す

## 実行手順

### Step 1: カバレッジレポート生成

以下のコマンドでカバレッジレポートを生成する。

```bash
cd apps/desktop
pnpm exec vitest run \
  src/renderer/store/slices/__tests__/agentSlice*.test.ts \
  --coverage \
  --coverage.provider=v8
```

### Step 2: カバレッジ基準との比較

#### 必須基準

| 指標              | 最低基準 | 推奨基準 | 備考                                     |
| ----------------- | -------- | -------- | ---------------------------------------- |
| Line Coverage     | 80%      | 90%      | 全行のうちテストで通過した行の割合       |
| Branch Coverage   | 60%      | 70%      | 条件分岐のうちテストで通過した分岐の割合 |
| Function Coverage | 80%      | 90%      | 関数のうちテストで呼び出された関数の割合 |

#### 既存メトリクス（参考値）

agentSlice の既存カバレッジ（TASK-FIX-6-1 時点）:

| 指標              | 値     |
| ----------------- | ------ |
| Line Coverage     | 100%   |
| Branch Coverage   | 98.21% |
| Function Coverage | 100%   |

新規追加分がこの水準を大幅に下回らないことを確認する。

### Step 3: 未カバー箇所の特定

カバレッジレポートの `Uncovered Lines` セクションを確認し、以下の分類を行う。

| 分類                          | 対応                       |
| ----------------------------- | -------------------------- |
| テスト追加が必要な箇所        | Phase 6 へ差し戻し         |
| 到達不能コード                | コメントで理由を記載し許容 |
| エラーハンドリングの catch 句 | 異常系テストで網羅         |

### Step 4: 判定

| 判定 | 条件                         | 対応                     |
| ---- | ---------------------------- | ------------------------ |
| PASS | 全指標が最低基準以上         | Phase 8 へ進む           |
| FAIL | いずれかの指標が最低基準未満 | Phase 6 へ戻りテスト追加 |

#### 差し戻し時の対応

- 未カバー箇所のリストを Phase 6 へ引き渡す
- 追加すべきテストケースを具体的に記載する
- 差し戻し回数の上限: 2回（3回目の未達は Phase 10 で MAJOR 判定とする）

### Step 5: P41 対策（v8 プロバイダ固有の注意）

- インライン arrow function（例: selector 内のフィルタコールバック）が独立関数としてカウントされる
- selector のコールバック内関数が Function Coverage を下げる場合、テストで明示的に呼び出す
- `useAvailableSkillsForImport` 内のフィルタ関数が未カバーにならないよう注意する

## 統合テスト連携

- カバレッジ計測は対象ファイルのユニットテストと統合テスト両方を含める
- P31 回帰テストもカバレッジ計測に含め、selector 呼び出しパスを網羅する

## 多角的チェック観点

| 観点              | チェック内容                                              |
| ----------------- | --------------------------------------------------------- |
| Line Coverage     | 80% 以上（推奨 90%）を確認                                |
| Branch Coverage   | 60% 以上（推奨 70%）を確認                                |
| Function Coverage | 80% 以上（推奨 90%）を確認                                |
| P41               | インライン arrow function のカバレッジ漏れがないこと      |
| 差し戻し          | 未達の場合、具体的な未カバー箇所を Phase 6 へ引き渡すこと |
