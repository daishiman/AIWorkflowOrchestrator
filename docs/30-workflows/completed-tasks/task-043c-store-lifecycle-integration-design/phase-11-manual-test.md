## 目的

自動テストでは検証できないユーザー体験・UI/UX・実環境動作を手動で確認する。SkillManagementPanel の import操作フローにおいて、store駆動の状態遷移（import中→成功/失敗）が視覚的・機能的に正しく動作し、P31無限ループが発生しないことを検証する。

## 実行タスク

- 手動テストシナリオの実行: 全8テストケースを順次実行
- 状態遷移確認: import中→成功/失敗の画面遷移が設計どおりであること
- P31確認: 画面がぐるぐる回り続けないこと（無限ループ非発生）
- DevTools確認: コンソールエラーなし・不要な再レンダー非発生の検証
- スクリーンショット証跡の取得

## 実行手順

### ステップ1: テスト環境準備

```bash
# 開発サーバー起動
cd apps/desktop
pnpm dev

# DevTools を開き、Console タブを監視
# React DevTools の Profiler を有効化（再レンダー回数の計測用）
```

### ステップ2: テストシナリオ順次実行

以下のテストケーステーブルを TC-01 から TC-08 まで順に実行する。

### ステップ3: 結果記録

各テストケースの実行結果を `outputs/phase-11/manual-test-result.md` に記録する。

### ステップ4: スクリーンショット保存

各テストケースのスクリーンショットを `outputs/phase-11/screenshots/` に保存する。

### ステップ5: 発見課題記録

手動テストで発見した課題を `outputs/phase-11/discovered-issues.md` に記録する。0件でもファイルを作成し「発見課題: 0件」と明記する。
