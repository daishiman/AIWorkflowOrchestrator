## 目的

追加したテストケース（TC-FB03-01〜09）が、フィールド独立推論性に関する
ロジックを十分にカバーしているかを確認する。

## カバレッジ対象範囲

docs-onlyタスクのため、カバレッジ対象は**変更したファイルおよびブロック**に限定する。

| 対象ファイル                        | 確認項目                                            |
| ----------------------------------- | --------------------------------------------------- |
| SmartDefault関連テストファイル      | TC-FB03-01〜09の全ケースが実行されること            |
| `inferSmartDefaults()` 関連ブロック | フィールド独立推論ロジックの line/branch カバレッジ |

> **[Feedback BEFORE-QUIT-002]** カバレッジ対象範囲は「変更したファイル・ブロック」に限定する。
> 全ファイル一律指定は局所検証の意図をぼやかすため採用しない。

## カバレッジ計測コマンド

```bash
# 対象ファイルに絞ったカバレッジ計測（targeted run）
pnpm vitest run --coverage \
  --coverage.include="<inferSmartDefaults関連パス>" \
  --reporter=verbose

# カバレッジレポート確認
cat coverage/coverage-summary.json | jq '.total'
```

## 未到達分析

カバレッジ計測後、未到達ブロックが発見された場合：

1. 未到達理由を分析する（dead codeか・テスト不足か）
2. テスト不足の場合 → Phase 6へ戻りテスト追加
3. dead codeの場合 → Phase 8（リファクタリング）で対処
