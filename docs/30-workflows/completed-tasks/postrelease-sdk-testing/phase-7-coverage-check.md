## 目的

Phase 6で実行したテスト結果を検証し、全テスト目標を達成していることを確認する。

## 背景

パフォーマンステスト、安定性テスト、ネットワーク障害テストの結果を総合的に評価し、本番品質を満たしているかを判定する。未達の場合はPhase 6へ戻ってテストを追加・修正する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: パフォーマンス目標の達成確認

**目的**: ストリーミング性能が目標値を達成しているかを確認する。

**実行手順**:

1. パフォーマンス計測レポートを確認
2. 各指標が目標値を達成しているか判定
3. 未達の場合は原因を分析
4. 判定結果を記録

**判定基準**:

| 指標               | 目標値    | 判定      |
| ------------------ | --------- | --------- |
| 初回応答時間       | 500ms以下 | PASS/FAIL |
| メッセージ間遅延   | 100ms以下 | PASS/FAIL |
| セッション作成時間 | 200ms以下 | PASS/FAIL |

---

### タスク2: 安定性目標の達成確認

**目的**: 長時間実行時の安定性が目標値を達成しているかを確認する。

**実行手順**:

1. 安定性テストレポートを確認
2. 各指標が目標値を達成しているか判定
3. 未達の場合は原因を分析
4. 判定結果を記録

**判定基準**:

| 指標                      | 目標値    | 判定      |
| ------------------------- | --------- | --------- |
| 1時間連続実行後メモリ増加 | 100MB以下 | PASS/FAIL |
| クラッシュ回数            | 0回       | PASS/FAIL |
| エラーリカバリ成功率      | 100%      | PASS/FAIL |

---

### タスク3: ネットワーク障害耐性の確認

**目的**: ネットワーク障害時の動作が要件を満たしているかを確認する。

**実行手順**:

1. ネットワーク障害テストレポートを確認
2. 各シナリオが期待動作を達成しているか判定
3. 未達の場合は原因を分析
4. 判定結果を記録

**判定基準**:

| シナリオ         | 期待動作                   | 判定      |
| ---------------- | -------------------------- | --------- |
| ネットワーク切断 | エラー表示・再試行可能     | PASS/FAIL |
| ネットワーク復旧 | 再接続可能                 | PASS/FAIL |
| タイムアウト     | 適切なエラーメッセージ表示 | PASS/FAIL |

---

### タスク4: 総合判定

**目的**: 全テスト結果を総合的に判定する。

**実行手順**:

1. 全判定結果を集約
2. 総合判定を決定
3. 次のアクションを決定

**総合判定基準**:

| 判定 | 条件                 | 次のアクション    |
| ---- | -------------------- | ----------------- |
| PASS | 全指標が目標達成     | Phase 8へ進行     |
| FAIL | いずれかの指標が未達 | Phase 6へ戻り改善 |
