## 目的

Lint、型チェック、コードスタイルの最終検証を行い、コード品質基準を満たしていることを確認する。

## 背景

リファクタリングが完了した実装に対して、最終的な品質チェックを実施する。ESLint、TypeScript、Prettierによる静的解析を行い、プロジェクト基準を満たしているかを確認する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ESLint検証

**目的**: ESLintルールに準拠していることを確認する。

**実行手順**:

1. ESLintを実行
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. エラー・警告を確認
3. 自動修正可能な問題を修正
   ```bash
   pnpm --filter @repo/desktop lint --fix
   ```
4. 残る問題を手動で修正
5. 最終確認

**品質基準**:

| 項目    | 基準        |
| ------- | ----------- |
| Error   | 0件         |
| Warning | 0件（推奨） |

**期待される成果物**:

- ESLint検証結果

---

### タスク2: TypeScript型チェック

**目的**: 型安全性が確保されていることを確認する。

**実行手順**:

1. 型チェックを実行
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
2. 型エラーを確認
3. any型の使用箇所を確認
4. 型エラーを修正
5. 最終確認

**品質基準**:

| 項目        | 基準                 |
| ----------- | -------------------- |
| 型エラー    | 0件                  |
| any型使用   | 必要最小限（文書化） |
| strict mode | 有効                 |

**期待される成果物**:

- 型チェック結果

---

### タスク3: コードスタイル検証

**目的**: Prettierによるコードスタイルの一貫性を確認する。

**実行手順**:

1. Prettierでフォーマットチェック
   ```bash
   pnpm prettier --check "apps/desktop/src/**/*.{ts,tsx}"
   ```
2. フォーマット違反を確認
3. 自動フォーマットを適用
   ```bash
   pnpm prettier --write "apps/desktop/src/**/*.{ts,tsx}"
   ```
4. 最終確認

**品質基準**:

| 項目             | 基準      |
| ---------------- | --------- |
| フォーマット違反 | 0件       |
| インデント       | 2スペース |
| セミコロン       | あり      |
| クォート         | シングル  |

**期待される成果物**:

- コードスタイル検証結果

---

### タスク4: セキュリティ検査

**目的**: セキュリティ上の問題がないことを確認する。

**実行手順**:

1. 依存関係の脆弱性チェック

2. 機密情報のハードコーディングチェック
3. 入力値バリデーションの確認
4. エラーメッセージの情報漏洩確認
5. 問題があれば修正

**品質基準**:

| 項目           | 基準                   |
| -------------- | ---------------------- |
| 高リスク脆弱性 | 0件                    |
| 機密情報       | ハードコーディングなし |
| バリデーション | 全入力値で実施         |

**期待される成果物**:

- セキュリティ検査結果
