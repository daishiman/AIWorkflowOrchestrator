## 1. E2Eテスト受け入れ基準

### 1.1 正常系テスト

| ID     | テストケース       | 受け入れ基準                                                 |
| ------ | ------------------ | ------------------------------------------------------------ |
| E2E-01 | SDK初期化          | Claude Code認証済み環境でAgentStatus: initializedになる      |
| E2E-02 | セッション作成     | createSession()がsessionId(UUID)を返す                       |
| E2E-03 | クエリ実行         | query()がエラーなく完了し、応答が受信される                  |
| E2E-04 | ストリーミング受信 | onMessageコールバックが複数回呼ばれ、最終的にisComplete=true |
| E2E-05 | セッション再開     | resumeSession()が既存セッションの会話履歴を保持              |
| E2E-06 | セッション破棄     | destroySession()後にセッションが無効になる                   |
| E2E-07 | 複数セッション管理 | MAX_SESSIONS(10)まで同時セッション管理可能                   |
| E2E-08 | ツール使用権限確認 | PreToolUseフックでPermissionDialogが表示される               |

### 1.2 異常系テスト

| ID     | テストケース         | 受け入れ基準                                    |
| ------ | -------------------- | ----------------------------------------------- |
| E2E-09 | 認証エラー           | 未認証時にAgentInitializationErrorが発生する    |
| E2E-10 | タイムアウト         | 設定時間超過でAgentTimeoutErrorが発生する       |
| E2E-11 | 中断                 | abort()呼び出し後AgentAbortedErrorが発生する    |
| E2E-12 | セッション期限切れ   | 期限切れセッションでAgentSessionErrorが発生する |
| E2E-13 | バリデーションエラー | 不正入力でAgentValidationErrorが発生する        |

### 1.3 境界値テスト

| ID     | テストケース     | 受け入れ基準                               |
| ------ | ---------------- | ------------------------------------------ |
| E2E-14 | 最大プロンプト長 | 100,000文字のプロンプトが正常に処理される  |
| E2E-15 | 最大セッション数 | 11番目のセッション作成が適切にエラーになる |
| E2E-16 | 最大タイムアウト | 300,000ms設定が正常に動作する              |

## 2. パフォーマンス受け入れ基準

### 2.1 レスポンスタイム

| 指標               | P50目標    | P95目標（1.5倍） | P99目標（2倍） |
| ------------------ | ---------- | ---------------- | -------------- |
| 初回応答時間       | 500ms以下  | 750ms以下        | 1000ms以下     |
| メッセージ間遅延   | 100ms以下  | 150ms以下        | 200ms以下      |
| セッション作成時間 | 200ms以下  | 300ms以下        | 400ms以下      |
| SDK初期化時間      | 1000ms以下 | 1500ms以下       | 2000ms以下     |

### 2.2 測定条件

| 項目             | 条件                               |
| ---------------- | ---------------------------------- |
| 測定回数         | 最低10回の測定で統計を取る         |
| ネットワーク環境 | 安定したブロードバンド接続         |
| テスト環境       | 開発用MacBook Pro（Apple Silicon） |
| 同時実行         | 単一クエリでの測定                 |

### 2.3 合格基準

- 全指標でP50目標を達成すること
- P95目標を80%以上達成すること
- P99目標を50%以上達成すること

## 3. 安定性受け入れ基準

### 3.1 長時間実行テスト

| 指標           | 受け入れ基準                |
| -------------- | --------------------------- |
| テスト時間     | 1時間の連続実行             |
| クエリ実行回数 | 最低100回のクエリ実行       |
| メモリ増加量   | 開始時比+100MB以下          |
| クラッシュ     | 0回（プロセス異常終了なし） |
| エラーリカバリ | 一時的エラーからの100%復旧  |

### 3.2 メモリリーク検出基準

| 状態 | 判定                    |
| ---- | ----------------------- |
| 正常 | メモリ増加量が100MB以下 |
| 警告 | メモリ増加量が100-200MB |
| 異常 | メモリ増加量が200MB超   |

### 3.3 合格基準

- 1時間のテストでクラッシュ0回
- メモリ増加量が100MB以下
- 全クエリの95%以上が成功

## 4. ネットワーク障害受け入れ基準

### 4.1 ネットワーク切断テスト

| シナリオ           | 受け入れ基準                       |
| ------------------ | ---------------------------------- |
| クエリ中の切断     | AgentQueryErrorが5秒以内に発生     |
| 切断後のUI         | オフライン状態が表示される         |
| 切断後のセッション | ローカルセッション情報が保持される |

### 4.2 ネットワーク復旧テスト

| シナリオ       | 受け入れ基準                         |
| -------------- | ------------------------------------ |
| 復旧検出       | オンライン復旧が10秒以内に検出される |
| セッション再開 | resumeSession()が正常に動作する      |
| クエリ再実行   | 新規クエリが正常に実行できる         |

### 4.3 タイムアウトテスト

| シナリオ               | 受け入れ基準                    |
| ---------------------- | ------------------------------- |
| デフォルトタイムアウト | 30秒後にAgentTimeoutErrorが発生 |
| カスタムタイムアウト   | 設定値でタイムアウトが発生      |
| タイムアウト後の状態   | セッションが維持され再試行可能  |
