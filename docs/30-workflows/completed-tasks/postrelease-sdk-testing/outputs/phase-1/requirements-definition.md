## 3. パフォーマンス要件

### 3.1 目標値

| 指標               | 目標値     | 測定基準 | 根拠                         |
| ------------------ | ---------- | -------- | ---------------------------- |
| 初回応答時間       | 500ms以下  | P50      | ユーザー体験上の許容待機時間 |
| メッセージ間遅延   | 100ms以下  | P50      | スムーズなストリーミング表示 |
| セッション作成時間 | 200ms以下  | P50      | 即座のセッション開始         |
| SDK初期化時間      | 1000ms以下 | P50      | アプリ起動時の待機許容範囲   |

### 3.2 測定方法

| 指標               | 測定開始点               | 測定終了点                  |
| ------------------ | ------------------------ | --------------------------- |
| 初回応答時間       | query()呼び出し          | 最初のonMessageコールバック |
| メッセージ間遅延   | onMessageコールバック(n) | onMessageコールバック(n+1)  |
| セッション作成時間 | createSession()呼び出し  | Promise resolve             |
| SDK初期化時間      | アプリ起動               | AgentStatus: initialized    |

### 3.3 測定ツール

| ツール          | 用途                  |
| --------------- | --------------------- |
| Performance API | ブラウザ/Electron計測 |
| console.time    | 簡易計測              |
| Playwright      | E2Eテスト内での計測   |

## 4. 安定性要件

### 4.1 目標値

| 指標                 | 目標値    | 測定期間 | 根拠                     |
| -------------------- | --------- | -------- | ------------------------ |
| メモリ増加量         | 100MB以下 | 1時間    | メモリリーク検出基準     |
| クラッシュ回数       | 0回       | 1時間    | プロダクション品質基準   |
| エラーリカバリ成功率 | 100%      | -        | 全エラーからの復旧保証   |
| セッション維持率     | 100%      | 1時間    | 長時間セッションの安定性 |

### 4.2 監視方法

| 指標           | 監視方法                         |
| -------------- | -------------------------------- |
| メモリ使用量   | process.memoryUsage()定期取得    |
| クラッシュ検出 | process.on('uncaughtException')  |
| エラー発生     | 構造化ログ出力                   |
| セッション状態 | SessionManager.getSessionCount() |

### 4.3 長時間テスト仕様

| 項目       | 仕様                               |
| ---------- | ---------------------------------- |
| テスト時間 | 1時間                              |
| クエリ間隔 | 30秒ごとに1クエリ（計120クエリ）   |
| メモリ記録 | 1分ごとにメモリ使用量を記録        |
| 成功判定   | 全クエリ成功 & メモリ増加100MB以下 |

## 5. ネットワーク障害テスト要件

### 5.1 ネットワーク切断時の期待動作

| 状態           | 期待動作                       |
| -------------- | ------------------------------ |
| クエリ実行中   | AgentQueryErrorを発生させる    |
| セッション維持 | セッション情報をローカルに保持 |
| UI表示         | オフライン状態を明示的に表示   |
| リトライ       | 自動リトライは行わない         |

### 5.2 ネットワーク復旧時の期待動作

| 状態           | 期待動作                                |
| -------------- | --------------------------------------- |
| セッション再開 | resumeSession()で既存セッション継続可能 |
| クエリ再実行   | 手動での再実行が可能                    |
| UI表示         | オンライン復旧を通知                    |

### 5.3 タイムアウト時の期待動作

| 状態         | 期待動作                         |
| ------------ | -------------------------------- |
| エラー種別   | AgentTimeoutErrorを発生させる    |
| デフォルト値 | 30,000ms（DEFAULT_TIMEOUT）      |
| カスタム設定 | QueryOptions.timeoutで設定可能   |
| UI表示       | タイムアウトエラーメッセージ表示 |

### 5.4 エラーメッセージ要件

| エラー種別       | メッセージ例                                   |
| ---------------- | ---------------------------------------------- |
| ネットワーク切断 | 「ネットワーク接続が切断されました」           |
| タイムアウト     | 「応答がタイムアウトしました（30秒）」         |
| 認証エラー       | 「認証に失敗しました。再ログインしてください」 |
| SDK初期化失敗    | 「SDKの初期化に失敗しました」                  |

## 6. 実SDK接続要件

### 6.1 SDK認証

| 項目       | 仕様                               |
| ---------- | ---------------------------------- |
| 認証方式   | Claude Code認証フロー              |
| 認証確認   | `claude auth status`コマンドで確認 |
| 認証エラー | AgentInitializationError           |
| 再認証     | `claude login`コマンドで再認証     |

### 6.2 ストリーミング接続

| 項目           | 仕様                        |
| -------------- | --------------------------- |
| プロトコル     | HTTPS（SDK内部で管理）      |
| 接続方式       | SDK query() APIを使用       |
| ストリーミング | onMessageコールバックで受信 |
| 接続維持       | SDK内部で自動管理           |

### 6.3 エラーハンドリング

| エラーコード          | 対処方法                 |
| --------------------- | ------------------------ |
| INITIALIZATION_FAILED | SDK再初期化を試行        |
| QUERY_FAILED          | エラーメッセージを表示   |
| TIMEOUT               | タイムアウトエラーを表示 |
| ABORTED               | 中断完了を通知           |
| SESSION_NOT_FOUND     | 新規セッション作成を促す |
| SESSION_EXPIRED       | 新規セッション作成を促す |
| VALIDATION_FAILED     | 入力エラーを表示         |
