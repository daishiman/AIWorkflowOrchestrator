## 3. テストカテゴリ詳細

### 3.1 E2E統合テスト (agent-sdk-integration.spec.ts)

```
SDK初期化 (2テスト)
├── E2E-01: 認証済み環境で正常初期化
└── E2E-09: 未認証時にエラー表示

セッション管理 (6テスト)
├── E2E-02: 新規セッションIDを取得
├── E2E-05: セッション再開で会話履歴を保持
├── E2E-06: セッション破棄でセッションが無効化される
├── E2E-07: 最大10セッションまで管理可能
├── E2E-12: 期限切れセッションで適切なエラー表示
└── E2E-15: 11番目のセッション作成でエラー

クエリ実行 (6テスト)
├── E2E-03: プロンプト送信と応答受信
├── E2E-04: ストリーミング応答がリアルタイム表示
├── E2E-10: 設定時間超過でタイムアウトエラー
├── E2E-11: abort()でクエリ停止
├── E2E-13: 空のプロンプトでバリデーションエラー
├── E2E-14: 最大プロンプト長（100,000文字）の処理
└── E2E-16: 最大タイムアウト（300秒）設定が有効

権限確認 (3テスト)
├── E2E-08: PermissionDialogが表示される
├── 権限許可操作が正常動作
└── 権限拒否操作が正常動作

エラーハンドリング (3テスト)
├── バリデーションエラーが適切に表示される
├── セッションエラーが適切に表示される
└── ネットワークエラー時に適切なメッセージ表示
```

### 3.2 パフォーマンステスト (agent-performance.spec.ts)

```
パフォーマンス計測 (4テスト)
├── PERF-01: SDK初期化時間 (P50 ≤ 1000ms)
├── PERF-02: セッション作成時間 (P50 ≤ 200ms)
├── PERF-03: 初回応答時間 (P50 ≤ 500ms)
└── PERF-04: メッセージ間遅延 (P50 ≤ 100ms)
```

### 3.3 ネットワーク障害テスト (agent-network-resilience.spec.ts)

```
オフライン時のエラーハンドリング (3テスト)
├── NET-01: オフライン状態でクエリ送信時にエラー表示
├── NET-02: オフライン状態でセッション作成時にエラー表示
└── NET-03: オフライン時にオフラインインジケーターが表示

接続復旧 (3テスト)
├── NET-04: オンライン復旧でインジケーター非表示
├── NET-05: 接続復旧後にクエリが正常に実行できる
└── NET-06: クエリ実行中のネットワーク断でエラー後復旧

タイムアウト処理 (2テスト)
├── NET-07: ネットワーク遅延でタイムアウトエラー
└── NET-08: タイムアウト後のリトライが正常動作

API障害 (4テスト)
├── NET-09: 500エラー時に適切なエラーメッセージ
├── NET-10: 429エラー（レート制限）時に適切なエラー
├── NET-11: 503エラー（サービス利用不可）時にリトライ
└── NET-12: 認証エラー（401）時に再認証を促す

断続的接続 (2テスト)
├── NET-13: 接続が不安定な状態でもセッションが維持
└── NET-14: ストリーミング中の一時的な接続断から復旧

WebSocket接続 (2テスト)
├── NET-15: WebSocket接続が切断された場合に再接続
└── NET-16: WebSocket再接続成功後にクエリが継続

エラー回復 (2テスト)
├── NET-17: ネットワークエラー後にエラー状態がクリア
└── NET-18: 連続エラー後もアプリケーションが応答
```

### 3.4 安定性テスト (long-running-test.mjs)

```
安定性検証項目
├── 1時間の連続クエリ実行
├── メモリ使用量のモニタリング
├── エラー発生率の追跡
└── セッション再開の検証

成功条件
├── 成功率 ≥ 95%
├── エラー率 ≤ 5%
└── メモリ増加量 ≤ 100MB
```
