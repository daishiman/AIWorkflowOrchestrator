## 既知の制限事項

以下は TASK-9I のスコープに起因する設計上の制限事項であり、不具合ではない。

### L-1: LLM query 関数はスタブ実装

| 項目     | 内容                                                                                                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| カテゴリ | 設計上の制限                                                                                                                                                                                                              |
| 内容     | SkillDocGenerator の queryFn は DI（コンストラクタインジェクション）で注入される設計であり、現時点ではスタブ実装（モック関数）が使用されている。実際の LLM プロバイダ（OpenAI, Anthropic 等）との連携は別タスクで対応する |
| 影響     | テスト環境ではモック関数で動作するため機能検証に影響はない。本番環境では LLM プロバイダの設定が必要                                                                                                                       |
| 対応方針 | LLM プロバイダ統合タスクで queryFn の実装を差し替える。DI 設計により既存コードの変更は不要                                                                                                                                |

### L-2: テンプレート CRUD 機能はスコープ外

| 項目     | 内容                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| カテゴリ | スコープ制限                                                                                                                                                          |
| 内容     | `getDocTemplates()` はデフォルトテンプレート（DEFAULT_DOC_TEMPLATE）の読み取り専用機能のみ提供する。テンプレートの作成・更新・削除（CRUD）機能は TASK-9I のスコープ外 |
| 影響     | ユーザーがカスタムテンプレートを永続的に保存する機能は利用できない。generateDocs/previewDocs の引数でカスタムセクションを一時的に指定する機能は利用可能               |
| 対応方針 | テンプレート CRUD 機能が必要な場合は後続タスクとして対応する                                                                                                          |

### L-3: Renderer UI はスコープ外

| 項目     | 内容                                                                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| カテゴリ | スコープ制限                                                                                                                                                                                   |
| 内容     | スキルドキュメント生成の Renderer UI（ドキュメント生成画面、プレビュー画面、エクスポートダイアログ）は TASK-9I のスコープ外であり、TASK-030 で対応予定                                         |
| 影響     | DevTools Console 経由での Preload API 直接呼び出しによる手動テストが実施できない（Renderer 側の呼び出し元 UI が未実装のため）。Phase 11 では自動テスト結果の確認とコードリーディングで代替した |
| 対応方針 | TASK-030（ドキュメント生成 UI）の実装後に、エンドツーエンドの手動テストを実施する                                                                                                              |
