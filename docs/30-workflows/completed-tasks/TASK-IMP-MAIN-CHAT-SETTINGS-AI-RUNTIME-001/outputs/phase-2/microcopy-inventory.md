## 6. マイクロコピー原則（ui-ux-realization.md 準拠）

| 原則                   | 適用例                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| 次アクション同居       | 「未設定です」で終わらず「どこで設定するか」を同じブロックに記載する                            |
| terminal 手動明示      | 「terminal で実行します」ではなく「この画面では自動実行せず terminal で手動実行する」と明示する |
| 共通ラベル統一         | terminal launcher は全画面で「terminal を開く」に統一する                                       |
| 状態語彙統一           | ready / missing-key / blocked / unavailable / terminal-available を全 surface で統一する        |
| 長い待機 vs 出力中区別 | 「確認中...」（待機）と「応答を受信中...」（出力中）を語彙で区別する                            |
