## 1. ToolRiskLevel 4段階定義

| レベル | 識別子     | 説明                                                               | デフォルト権限状態 | autoDeny                             |
| ------ | ---------- | ------------------------------------------------------------------ | ------------------ | ------------------------------------ |
| 最高   | `critical` | システム破壊・データ全損・認証情報漏洩を引き起こす操作             | `denied`           | `true`（ユーザー確認なしで即時拒否） |
| 高     | `high`     | 権限昇格・任意コード実行・設定改竄を引き起こす操作                 | `denied`           | `false`（PermissionDialog を表示）   |
| 中     | `medium`   | ファイル変更・外部通信・タスク委譲を伴うが影響範囲が限定される操作 | `denied`           | `false`（PermissionDialog を表示）   |
| 低     | `low`      | 読み取り専用・検索・メモ書き込みのみで副作用を持たない操作         | `denied`           | `false`（PermissionDialog を表示）   |

> **全レベルのデフォルトは `denied`**: autoDeny=true の `critical` はユーザー確認なしで即座に abort フローへ移行する。他のレベルは PermissionDialog を表示してユーザー確認を経た後に承認/拒否を決定する。
