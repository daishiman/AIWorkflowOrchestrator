## 目的

Phase 4 + Phase 6 のテスト仕様が以下の3つのカバレッジ基準を満たすことを確認し、不足がある場合は Phase 6 に差し戻す（または軽微な不足は Phase 8 以降の未タスクとして記録する）。

1. **concern × command カバレッジ**: Lane-A/B/C の全3つのコンサーンで設計したコマンド（型定義・状態遷移・UI フロー）にテストケースが対応していること
2. **デシジョンテーブルカバレッジ**: リスクレベル4段階 × 権限状態4モード = 16組合せが全て確認されていること
3. **Task 接続ポイントカバレッジ**: Task-03/05/08 との接続インターフェース（INS-01〜03、SafetyGatePort）にテストが存在すること

カバレッジ基準（`02-code-quality.md` 準拠）:

- テスト仕様数（設計レベル）に規定の最低基準なし。ただし上記3基準の達成を必須とする
- Phase 7 で不足が判明した場合、未達カテゴリを `outputs/phase-7/coverage-gaps.md` に記録し Phase 6 に差し戻す

### ステップ 3: 失効ポリシー × リスクレベルのカバレッジ確認

Phase 6 の TC-ST-008（9組合せ）が以下の16組合せのうちどの部分をカバーしているかを確認する。

#### 3-1. 16組合せカバレッジマトリクス

| リスクレベル↓ \ 失効ポリシー→ | session    | time_24h   | time_7d    | permanent  |
| ----------------------------- | ---------- | ---------- | ---------- | ---------- |
| **critical**                  | TC-ST-008a | TC-ST-008b | 未検証     | TC-ST-008c |
| **high**                      | TC-ST-008d | 未検証     | 未検証     | TC-ST-008e |
| **medium**                    | 未検証     | TC-ST-008h | 未検証     | TC-ST-008f |
| **low**                       | 未検証     | 未検証     | TC-ST-008i | TC-ST-008g |

#### 3-2. 未検証セルの処理方針

上記マトリクスで「未検証」となっている8セルについて、以下のいずれかで処理する。

| 未検証セル                  | 処理方針                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------- |
| critical × time_7d          | 「恒久許可/時間制許可ボタンが非表示のため選択不可」の設計上到達不可。未タスク不要        |
| high × time_24h             | TC-ST-008d（session）と同じく「今回のみ」制約内。設計上到達可能 → Phase 8 未タスクに記録 |
| high × time_7d              | 同上 → Phase 8 未タスクに記録                                                            |
| medium × session            | TC-ST-002a と同じ計算。TC-ST-008f（permanent）で代替確認済み。不足なし                   |
| low × session               | 同上。不足なし                                                                           |
| low × time_24h              | TC-ST-008h（medium × time_24h）と同じ計算。代替確認済み。不足なし                        |
| medium × time_7d            | TC-ST-008i（low × time_7d）と同じ計算。代替確認済み。不足なし                            |
| critical × 全時間系ポリシー | 選択 UI が非表示のため到達不可。設計上禁止                                               |

**判定基準**: 設計上到達可能な組合せのうち、2件（high × time_24h、high × time_7d）が Phase 6 未検証。Phase 6 差し戻し基準を満たさない場合は Phase 8 の未タスクとして記録する。
