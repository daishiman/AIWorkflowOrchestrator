## 1. 問題の定義

### 1.1 問題概要

アバター編集メニュー（`z-[9999]`）が連携サービスセクションのGlassPanelに隠れてボタンをクリックできない。

### 1.2 技術的原因

`backdrop-filter: blur()`を使用しているGlassPanelコンポーネントが新しいCSS **Stacking Context**を作成するため、子要素の`z-index`は親Stacking Context内でのみ有効になる。

**Stacking Contextを作成するCSSプロパティ**:

- `backdrop-filter: blur()`
- `filter`
- `transform`
- `opacity < 1`

### 1.3 影響

- アバター編集メニューがProfile CardのGlassPanel内にある
- 連携サービスセクション（別のGlassPanel）の下にメニューが隠れる
- ユーザーがアバターメニューのボタンをクリックできない

## 2. 機能要件（FR）

| ID   | 要件                                                         | 優先度 | 検証方法   |
| ---- | ------------------------------------------------------------ | ------ | ---------- |
| FR-1 | アバター編集メニューが連携サービスセクションの上に表示される | 必須   | 手動テスト |
| FR-2 | メニュー内のすべてのボタンがクリック可能                     | 必須   | 手動テスト |
| FR-3 | メニュー外クリックでメニューが閉じる                         | 必須   | 自動テスト |
| FR-4 | Escキーでメニューが閉じる                                    | 推奨   | 自動テスト |

### 2.1 FR-1: メニュー表示位置

- **条件**: アバター編集ボタンをクリック
- **期待結果**: メニューが連携サービスセクションの上に表示される
- **実装方法**: React createPortalでdocument.body直下にレンダリング

### 2.2 FR-2: ボタンクリック可能性

- **条件**: メニュー表示中
- **期待結果**: 「アップロード」「プロバイダーアバター使用」「アバターを削除」がクリック可能
- **実装方法**: z-[9999]でz-indexを確保

### 2.3 FR-3: アウトサイドクリック

- **条件**: メニュー表示中
- **期待結果**: メニュー外をクリックするとメニューが閉じる
- **実装方法**: useEffectでmousedownイベントリスナー登録

### 2.4 FR-4: Escapeキー

- **条件**: メニュー表示中
- **期待結果**: Escキーを押すとメニューが閉じ、フォーカスがトリガーボタンに戻る
- **実装方法**: useEffectでkeydownイベントリスナー登録

## 3. 非機能要件（NFR）

| ID    | 要件                               | 優先度 | 検証方法              |
| ----- | ---------------------------------- | ------ | --------------------- |
| NFR-1 | WCAG 2.1 AAレベル準拠              | 必須   | axe-core自動テスト    |
| NFR-2 | WAI-ARIA Menu Pattern準拠          | 必須   | 自動テスト            |
| NFR-3 | テストカバレッジ80%以上            | 必須   | カバレッジレポート    |
| NFR-4 | イベントリスナーのメモリリーク防止 | 必須   | useEffect cleanup確認 |

### 3.1 NFR-1: WCAG 2.1 AA準拠

- `aria-label`によるスクリーンリーダー対応
- キーボードナビゲーション対応
- フォーカス管理

### 3.2 NFR-2: WAI-ARIA Menu Pattern

| 要素           | 属性          | 値                     |
| -------------- | ------------- | ---------------------- |
| トリガーボタン | aria-label    | "アバターを編集"       |
| トリガーボタン | aria-expanded | true/false             |
| トリガーボタン | aria-haspopup | "menu"                 |
| メニュー       | role          | "menu"                 |
| メニュー       | aria-label    | "アバター編集メニュー" |
| メニュー項目   | role          | "menuitem"             |

### 3.3 NFR-3: テストカバレッジ

| 指標              | 最低基準 | 推奨基準 |
| ----------------- | -------- | -------- |
| Line Coverage     | 80%      | 90%      |
| Branch Coverage   | 60%      | 70%      |
| Function Coverage | 80%      | 90%      |

### 3.4 NFR-4: メモリリーク防止

- useEffect cleanupでイベントリスナーを必ず解除
- mousedown、keydownリスナーの登録と解除を対で管理
