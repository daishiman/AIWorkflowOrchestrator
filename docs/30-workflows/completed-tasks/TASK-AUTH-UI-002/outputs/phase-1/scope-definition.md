## 1. スコープ概要

### 1.1 目的

アバター編集メニューが常に最前面に表示され、ユーザーがクリック操作できるようにする。

### 1.2 ゴール

アバター編集メニューが連携サービスセクションの上に表示される。

---

## 2. スコープ範囲

### 2.1 含むもの（In Scope）

| カテゴリ         | 内容                                               |
| ---------------- | -------------------------------------------------- |
| コンポーネント   | AccountSection内のアバター編集メニュー             |
| 技術             | React createPortalによるPortal実装                 |
| 位置計算         | getBoundingClientRectによるメニュー位置計算        |
| アクセシビリティ | WAI-ARIA Menu Pattern準拠                          |
| テスト           | AccountSection.portal.test.tsx（Portal関連テスト） |

### 2.2 含まないもの（Out of Scope）

| カテゴリ         | 内容                                       | 理由                           |
| ---------------- | ------------------------------------------ | ------------------------------ |
| GlassPanel修正   | GlassPanelコンポーネント自体の修正         | 影響範囲が大きい               |
| 他ポップアップ   | 他のポップアップ・メニューの修正           | 本タスクのスコープ外           |
| カスタムHook抽出 | usePortalMenu()の共通化                    | リファクタリングフェーズで検討 |
| 位置計算共通化   | 他のPortalメニューとの位置計算ロジック共有 | 将来タスクとして記録           |
