## 目的

- カバレッジ分析: テストカバレッジの測定と不足領域の特定

## 実行手順

### 1. カバレッジ測定

```bash
pnpm --filter @repo/desktop test:coverage AccountSection
```

### 2. ギャップ分析

Portal関連で確認すべきテストケース:

| ケース             | 内容                              | 優先度 |
| ------------------ | --------------------------------- | ------ |
| 位置計算精度       | getBoundingClientRectの戻り値検証 | 高     |
| スクロール時の挙動 | fixed positioningの維持           | 中     |
| 複数回開閉         | メモリリークなし                  | 高     |
| 高速連打           | レースコンディション防止          | 中     |

### 3. 追加テスト作成（必要な場合）

**追加テストケース例**:

| ID   | テスト内容                 | 期待結果                                       |
| ---- | -------------------------- | ---------------------------------------------- |
| PT-7 | メニュー開閉を10回繰り返し | イベントリスナーが適切に解除                   |
| PT-8 | 高速クリック（100ms間隔）  | 状態が一貫している                             |
| PT-9 | ウィンドウリサイズ         | 位置が正しく再計算される（固定位置のため不要） |

### 4. 統合テスト再実行

```bash
pnpm --filter @repo/desktop test AccountSection
```
