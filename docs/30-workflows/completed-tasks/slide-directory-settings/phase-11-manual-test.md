### タスク1: 開発ビルドでの動作確認

**目的**: 開発環境でアプリケーションを起動し、基本動作を確認する

**実行手順**:

1. 開発サーバーを起動:

   ```bash
   pnpm --filter @repo/desktop dev
   ```

2. 基本動作確認:

| 確認項目               | 手順                       | 期待結果                     | 結果       |
| ---------------------- | -------------------------- | ---------------------------- | ---------- |
| アプリ起動             | dev起動後に画面表示        | エラーなく起動               | [ ] 確認済 |
| 設定画面アクセス       | 設定メニューをクリック     | 設定画面が表示される         | [ ] 確認済 |
| スライド設定タブ表示   | 該当タブをクリック         | タブ内容が表示される         | [ ] 確認済 |
| 現在のディレクトリ表示 | 設定画面で確認             | デフォルト値が表示される     | [ ] 確認済 |
| ダイアログ表示         | 「参照」ボタンをクリック   | OS標準ダイアログが開く       | [ ] 確認済 |
| ディレクトリ選択       | ダイアログでフォルダを選択 | パスが入力欄に反映される     | [ ] 確認済 |
| 設定保存               | 「保存」ボタンをクリック   | 成功メッセージが表示される   | [ ] 確認済 |
| 自動作成オプション     | チェックボックスを切り替え | 状態が変更される             | [ ] 確認済 |
| アプリ再起動後の永続化 | アプリを再起動して設定確認 | 保存した設定が維持されている | [ ] 確認済 |

3. 結果を `outputs/phase-11/dev-build-test.md` に出力

**期待される成果物**:

- `outputs/phase-11/dev-build-test.md`

---

### タスク2: エラーケースの手動確認

**目的**: エラー発生時のユーザー体験を確認する

**実行手順**:

1. エラーケーステスト:

| 確認項目             | 手順                           | 期待結果                   | 結果       |
| -------------------- | ------------------------------ | -------------------------- | ---------- |
| 無効なパス入力       | 存在しないパスを直接入力       | バリデーションエラーが表示 | [ ] 確認済 |
| 権限なしディレクトリ | 書き込み権限のないフォルダ選択 | 適切なエラーメッセージ     | [ ] 確認済 |
| ダイアログキャンセル | ダイアログでキャンセルクリック | 何も変更されない           | [ ] 確認済 |
| 空文字列入力         | 入力欄を空にして保存           | バリデーションエラーが表示 | [ ] 確認済 |
| 長すぎるパス         | 非常に長いパスを入力           | エラーまたは適切に処理     | [ ] 確認済 |
| 特殊文字を含むパス   | 日本語/スペースを含むパス      | 正しく処理される           | [ ] 確認済 |

2. エラーメッセージの品質確認:
   - ユーザーが理解できる内容か
   - 解決方法が示されているか
   - 日本語が適切か

3. 結果を `outputs/phase-11/error-case-test.md` に出力

**期待される成果物**:

- `outputs/phase-11/error-case-test.md`

### タスク5: 手動テスト総合判定

**目的**: 手動テストの総合判定を行う

**実行手順**:

1. 全テスト結果を集約

2. 判定基準:

| 判定     | 条件                 | 次のアクション        |
| -------- | -------------------- | --------------------- |
| PASS     | 全項目問題なし       | Phase 12へ進行        |
| MINOR    | 軽微な問題あり       | 問題記録後Phase 12へ  |
| MAJOR    | 重大なUX問題あり     | 問題修正後再テスト    |
| CRITICAL | 基本機能が動作しない | Phase 5へ戻り実装修正 |

3. 判定結果:
   - 基本動作: [ ] PASS / [ ] MINOR / [ ] MAJOR / [ ] CRITICAL
   - エラーハンドリング: [ ] PASS / [ ] MINOR / [ ] MAJOR / [ ] CRITICAL
   - UI/UX: [ ] PASS / [ ] MINOR / [ ] MAJOR / [ ] CRITICAL
   - 総合判定: [ ] PASS / [ ] MINOR / [ ] MAJOR / [ ] CRITICAL

4. 判定結果を `outputs/phase-11/manual-test-verdict.md` に出力

**期待される成果物**:

- `outputs/phase-11/manual-test-verdict.md`
