## 機能要件一覧

### FR-1: ディレクトリ選択機能

**要件**: ユーザーは設定画面からスライド出力ディレクトリを選択できる

**詳細**:

- 設定画面内に「スライド出力設定」セクションを配置
- 現在設定されているディレクトリパスを表示
- 「選択...」ボタンをクリックしてディレクトリを変更可能

**受入条件**:

- 設定画面からディレクトリ選択UIにアクセスできる
- 選択したディレクトリパスがUIに反映される

---

### FR-2: OS標準ダイアログ使用

**要件**: ディレクトリ選択はOS標準のディレクトリ選択ダイアログを使用する

**詳細**:

- Electronの `dialog.showOpenDialog` を使用
- `properties: ["openDirectory"]` でディレクトリ選択モードを指定
- OSネイティブなUIで直感的な操作を提供

**受入条件**:

- macOSではFinderスタイルのディレクトリ選択ダイアログが表示される
- WindowsではExplorerスタイルのディレクトリ選択ダイアログが表示される
- Linuxではデスクトップ環境に応じたダイアログが表示される

---

### FR-3: 設定の永続化

**要件**: 選択されたディレクトリはアプリ再起動後も永続化される

**詳細**:

- `electron-store` を使用した設定の永続化
- JSON形式でローカルファイルに保存
- アプリ起動時に自動的に設定を読み込み

**受入条件**:

- ディレクトリを設定後、アプリを終了・再起動しても設定が維持される
- 設定ファイルが破損した場合はデフォルト値にフォールバック

---

### FR-4: 自動ディレクトリ作成オプション

**要件**: ディレクトリが存在しない場合、自動作成オプションを提供する

**詳細**:

- 「ディレクトリが存在しない場合は自動作成」チェックボックスを提供
- チェックが有効な場合、スライド出力時にディレクトリを自動作成
- デフォルトは有効（true）

**受入条件**:

- チェックボックスで自動作成の有効/無効を切り替え可能
- 自動作成が有効な場合、存在しないディレクトリでも保存時にエラーにならない

---

### FR-5: パス表示・変更機能

**要件**: ディレクトリパスはUI上に表示され、変更可能である

**詳細**:

- 現在のディレクトリパスをテキストフィールドで表示
- テキストフィールドは読み取り専用（直接編集不可）
- 「選択...」ボタンでダイアログ経由で変更

**受入条件**:

- 現在のパスが常に表示されている
- パスが長い場合は省略表示（...）またはツールチップで全体表示

---

### FR-6: デフォルトディレクトリ設定

**要件**: デフォルトディレクトリ（`~/Documents/Slides`）が設定されている

**詳細**:

- 初回起動時のデフォルト値: `~/Documents/Slides`
- `~` はユーザーのホームディレクトリに展開
- 各OSで適切なパスに解決

**受入条件**:

- 初回起動時、設定画面にデフォルトパスが表示される
- macOS: `/Users/{username}/Documents/Slides`
- Windows: `C:\Users\{username}\Documents\Slides`
- Linux: `/home/{username}/Documents/Slides`

---

### FR-7: スキル連携

**要件**: スキル呼び出し時に設定されたディレクトリが自動的に使用される

**詳細**:

- `presentation-slide-generator` スキルがスライドを出力する際、設定されたディレクトリを使用
- スキル側からIPC経由で設定を取得
- 設定が取得できない場合はデフォルト値を使用

**受入条件**:

- スキルでスライド生成時、設定されたディレクトリに出力される
- 設定変更後、次回のスキル呼び出しから新しいディレクトリが使用される

## IPC通信要件（統合テスト連携）

### IPCチャンネル定義

| チャンネル名                      | 機能                   |
| --------------------------------- | ---------------------- |
| `slideSettings:getDirectory`      | 現在のディレクトリ取得 |
| `slideSettings:setDirectory`      | ディレクトリ設定       |
| `slideSettings:selectDirectory`   | ダイアログでの選択     |
| `slideSettings:validateDirectory` | パス有効性検証         |
| `slideSettings:getAllSettings`    | 全設定取得             |

### セキュリティ要件

- ホワイトリスト方式でチャンネルを管理
- `contextBridge` でRendererに公開するAPIを限定
- 全チャンネルで `validateIpcSender` によるsender検証を実施

## 永続化要件（統合テスト連携）

### データ構造

```typescript
interface SlideSettings {
  outputDirectory: string; // 出力先ディレクトリ
  autoCreateDirectory: boolean; // 自動作成フラグ
  defaultTheme: "kanagawa"; // デフォルトテーマ
  schemaVersion: number; // スキーマバージョン
}
```

### デフォルト値

```typescript
const DEFAULT_SLIDE_SETTINGS: SlideSettings = {
  outputDirectory: "~/Documents/Slides",
  autoCreateDirectory: true,
  defaultTheme: "kanagawa",
  schemaVersion: 1,
};
```

### 永続化要件

- `electron-store` を使用
- JSON Schemaによるバリデーション
- 破損時はデフォルト値にフォールバック
- スキーマバージョンによるマイグレーション対応
