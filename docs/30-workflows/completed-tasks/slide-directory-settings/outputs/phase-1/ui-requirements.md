## UI配置

### 設定画面内の位置

- 設定画面は既存の設定ページ内に配置
- 「スライド」または「出力設定」タブ/セクション内に配置
- 他の設定項目との一貫性を保つ

### セクション構成

```
設定画面
├── 一般設定
├── 外観設定
├── スライド出力設定  ← 新規追加
│   ├── 出力先ディレクトリ
│   └── 自動作成オプション
└── その他の設定
```

| 表示位置       | フィールド直下               |

## インタラクション

### ディレクトリ選択フロー

1. ユーザーが「選択...」ボタンをクリック
2. OS標準のディレクトリ選択ダイアログが表示
3. ユーザーがディレクトリを選択（またはキャンセル）
4. 選択した場合：
   - パスがテキストフィールドに反映
   - バリデーションが自動実行
   - 結果がインラインで表示
5. キャンセルした場合：
   - 何も変更されない

### 保存フロー

1. ユーザーが「保存」ボタンをクリック
2. ローディング状態を表示
3. バリデーション実行
4. 自動作成オプション有効＆ディレクトリ不存在の場合：
   - ディレクトリを作成
5. 設定を永続化
6. 成功/失敗のフィードバックを表示
7. 成功時：元の状態に戻る
8. 失敗時：エラーメッセージを表示

### キャンセルフロー

1. ユーザーが「キャンセル」ボタンをクリック
2. 未保存の変更を破棄
3. 元の設定値に戻す
4. （変更がある場合）確認ダイアログを表示

## アクセシビリティ

### キーボード操作

| 操作       | キー        | 動作                        |
| ---------- | ----------- | --------------------------- |
| フォーカス | Tab         | 次の要素へ移動              |
| 逆移動     | Shift+Tab   | 前の要素へ移動              |
| 選択       | Enter/Space | ボタンクリック/チェック切替 |
| キャンセル | Escape      | ダイアログを閉じる          |

### ARIA属性

| 要素                 | 属性                                 |
| -------------------- | ------------------------------------ |
| テキストフィールド   | `aria-readonly="true"`               |
| エラーメッセージ     | `role="alert"`, `aria-live="polite"` |
| 選択ボタン           | `aria-haspopup="dialog"`             |
| チェックボックス     | `aria-checked`                       |
| 保存ボタン（無効時） | `aria-disabled="true"`               |

### フォーカス管理

- ダイアログオープン時：ダイアログ内にフォーカスを閉じ込め
- ダイアログクローズ時：トリガーボタンにフォーカスを戻す
- エラー発生時：エラーメッセージにフォーカスを移動

## レスポンシブ対応

### 狭い画面（幅768px未満）

- テキストフィールドと選択ボタンを縦に配置
- ボタン幅を100%に拡張
- 長いパスは省略表示（...）

### 広い画面（幅768px以上）

- テキストフィールドと選択ボタンを横に配置
- ボタン幅は内容に応じた自動幅
