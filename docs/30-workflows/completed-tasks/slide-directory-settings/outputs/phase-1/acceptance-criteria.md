## 受け入れ基準一覧

### AC-1: ディレクトリ選択

**シナリオ**: ユーザーがディレクトリを選択する

```gherkin
Feature: ディレクトリ選択
  ユーザーとして、
  スライドの出力先ディレクトリを選択したい、
  保存場所をカスタマイズするために。

  Scenario: OS標準ダイアログでディレクトリを選択
    Given 設定画面が開いている
    When ディレクトリ選択ボタンをクリック
    Then OS標準のディレクトリ選択ダイアログが表示される
    And ディレクトリを選択すると、パス表示欄に選択したパスが表示される
```

**テスト手順**:

1. 設定画面を開く
2. 「スライド出力設定」セクションを確認
3. 「選択...」ボタンをクリック
4. OSのディレクトリ選択ダイアログが表示されることを確認
5. 任意のディレクトリを選択
6. 選択したパスがUI上に表示されることを確認

**期待結果**:

- OSネイティブのディレクトリ選択ダイアログが表示される
- 選択後、パスがテキストフィールドに反映される

---

### AC-2: 設定の永続化

**シナリオ**: ユーザーが設定した内容がアプリ再起動後も保持される

```gherkin
Feature: 設定の永続化
  ユーザーとして、
  設定したディレクトリがアプリ再起動後も保持されてほしい、
  毎回設定し直す手間を省くために。

  Scenario: アプリ再起動後に設定が保持される
    Given ディレクトリを設定している
    When アプリを再起動する
    Then 設定したディレクトリが保持されている
```

**テスト手順**:

1. 設定画面でディレクトリを変更
2. 「保存」ボタンをクリック
3. アプリケーションを終了
4. アプリケーションを再起動
5. 設定画面を開く
6. 以前設定したディレクトリが表示されることを確認

**期待結果**:

- アプリ再起動後も設定したディレクトリパスが維持されている

---

### AC-3: 自動ディレクトリ作成

**シナリオ**: 存在しないディレクトリが自動作成される

```gherkin
Feature: 自動ディレクトリ作成
  ユーザーとして、
  存在しないディレクトリを指定しても自動作成されてほしい、
  手動でディレクトリを作成する手間を省くために。

  Scenario: 存在しないディレクトリパスで保存
    Given 存在しないディレクトリパスを選択している
    And 自動作成オプションが有効である
    When 保存ボタンをクリック
    Then ディレクトリが自動作成される
    And 設定が保存される
    And 成功メッセージが表示される
```

**テスト手順**:

1. 設定画面を開く
2. 「ディレクトリが存在しない場合は自動作成」チェックボックスが有効であることを確認
3. 存在しないディレクトリパスを含むフォルダを選択（例: `/tmp/new-slides-folder`）
4. 「保存」ボタンをクリック
5. ディレクトリが作成されることを確認
6. 設定が保存されることを確認

**期待結果**:

- 存在しないディレクトリが自動的に作成される
- 設定が正常に保存される
- 成功のフィードバックが表示される

---

### AC-4: バリデーション

**シナリオ**: 無効なパスが拒否される

```gherkin
Feature: パスバリデーション
  システムとして、
  無効なパスを拒否したい、
  セキュリティと整合性を保つために。

  Scenario: 無効なパスでエラー表示
    Given 設定画面が開いている
    When 無効なパス（例: `///invalid///`）を入力
    Then バリデーションエラーメッセージが表示される
    And 保存ボタンが無効化される

  Scenario: パストラバーサル攻撃の防止
    Given 設定画面が開いている
    When `../` を含むパスを入力
    Then セキュリティエラーメッセージが表示される
    And 保存が拒否される
```

**テスト手順**:

1. 設定画面を開く
2. 無効なパス（`///invalid///`）を持つディレクトリを選択しようとする
3. エラーメッセージが表示されることを確認
4. `../` を含むパスを検証APIに送信
5. セキュリティエラーが返されることを確認

**期待結果**:

- 無効なパスに対してわかりやすいエラーメッセージが表示される
- パストラバーサル攻撃を示すパスは拒否される
- 保存ボタンがバリデーションエラー時に無効化される

### AC-5: デフォルト値

**シナリオ**: 初回起動時にデフォルト値が設定される

```gherkin
Feature: デフォルト値
  ユーザーとして、
  初回起動時に適切なデフォルト値が設定されていてほしい、
  すぐに使い始められるように。

  Scenario: 初回起動時のデフォルト表示
    Given 初回起動時（設定ファイルが存在しない）
    When 設定画面を開く
    Then デフォルトディレクトリ（`~/Documents/Slides`）が表示される
    And 自動作成オプションがデフォルトで有効
```

**テスト手順**:

1. 設定ファイルを削除（またはクリーンインストール状態にする）
2. アプリケーションを起動
3. 設定画面を開く
4. ディレクトリパスがデフォルト値（`~/Documents/Slides`）であることを確認
5. 自動作成チェックボックスが有効であることを確認

**期待結果**:

- デフォルトディレクトリ（`~/Documents/Slides`）が表示される
- ホームディレクトリ（`~`）が適切に展開されて表示される
- 自動作成オプションがデフォルトで有効
