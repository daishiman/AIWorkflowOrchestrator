## 目的

自動テストでは検証できないユーザー体験・実環境動作を手動で確認する。特にファイルシステム操作を伴うスキルフォーク機能のため、実際のディレクトリ構造とファイル内容を目視確認する。

## 背景

SkillForker はファイルシステムへの書き込み操作（ディレクトリコピー、SKILL.md 更新、fork-metadata.json 生成）を行う。自動テストではモック化されている部分があるため、実環境での動作を手動で確認する必要がある。

## 実行タスク

- タスク1: 正常系シナリオ（TC-01〜TC-04）を手動実行して結果を記録する
- タスク2: 異常系シナリオ（TC-05〜TC-07）を手動実行して安全性を確認する
- タスク3: フォーク後スキルの統合シナリオ（TC-08）を手動実行する
