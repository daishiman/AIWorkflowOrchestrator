## 目的

SkillService.executeSkill()からSkillExecutorへの委譲実装について、自動テストでカバーできないユーザー体験・実環境動作を手動で確認する。

## 背景

自動テストでは検証が難しい以下の観点を手動で確認する:

- E2Eでのスキル実行フロー（Renderer→Main→SkillExecutor→SDK）
- ストリーミングメッセージのリアルタイム受信
- 実行中断（abort）の動作確認
- 認証エラー時のUI表示

---

> このPhaseでは特定のスキルは使用せず、手動テスト作業を行います。

## 手動テストシナリオ

### 1. スキル実行E2Eフロー（SDK呼び出しまで到達）

| #   | 操作                                 | 期待結果                                                 |
| --- | ------------------------------------ | -------------------------------------------------------- |
| 1   | アプリを起動し、スキル一覧画面を開く | スキル一覧が表示される                                   |
| 2   | 任意のスキルを選択し実行ボタンを押す | スキル実行が開始される                                   |
| 3   | DevToolsのConsoleでログを確認        | SkillService→SkillExecutor→SDKの呼び出しログが出力される |
| 4   | 実行完了を待つ                       | 正常に完了し、結果が表示される                           |

### 2. ストリーミングメッセージのRenderer受信

| #   | 操作                                 | 期待結果                                           |
| --- | ------------------------------------ | -------------------------------------------------- |
| 1   | ストリーミング出力を持つスキルを実行 | 実行が開始される                                   |
| 2   | 実行中のUI表示を確認                 | ストリーミングメッセージがリアルタイムで表示される |
| 3   | メッセージの順序を確認               | メッセージが送信順に表示される                     |
| 4   | 大量メッセージ時の動作確認           | UIがフリーズせずスムーズに更新される               |

### 3. 実行中断（abort）のE2Eフロー

| #   | 操作                         | 期待結果                                           |
| --- | ---------------------------- | -------------------------------------------------- |
| 1   | 長時間実行されるスキルを開始 | スキル実行が開始される                             |
| 2   | 実行中に中断ボタンを押す     | 中断処理が開始される                               |
| 3   | 中断完了を確認               | 実行がキャンセルされ、適切なメッセージが表示される |
| 4   | DevToolsでリソース解放を確認 | AbortControllerがクリーンアップされている          |
| 5   | 中断後に別のスキルを実行     | 正常に新しいスキルが実行できる                     |

### 4. 認証エラー時の適切なエラー伝播

| #   | 操作                                 | 期待結果                                           |
| --- | ------------------------------------ | -------------------------------------------------- |
| 1   | 認証が必要なスキルを未認証状態で実行 | 認証エラーが発生する                               |
| 2   | エラーメッセージを確認               | ユーザーフレンドリーなエラーメッセージが表示される |
| 3   | エラー詳細を確認（DevTools）         | 技術的詳細がログに出力される                       |
| 4   | 認証後に再実行                       | 正常に実行される                                   |

### 5. 既存機能のリグレッション確認

| #   | 操作                           | 期待結果                     |
| --- | ------------------------------ | ---------------------------- |
| 1   | スキルのインポート機能を実行   | 正常にインポートできる       |
| 2   | スキル一覧の取得を確認         | 全スキルが正しく表示される   |
| 3   | スキルのアンインストールを実行 | 正常にアンインストールできる |
| 4   | スキル設定の変更を実行         | 設定が正しく保存される       |
