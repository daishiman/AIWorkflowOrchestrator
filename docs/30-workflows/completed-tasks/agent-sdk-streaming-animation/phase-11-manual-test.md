## 目的

自動テストでカバーできないアニメーションの視覚的品質・UX・パフォーマンスを手動で確認する。

## 背景

アニメーションの品質は視覚的な確認が必須。FPS計測やreduced-motion動作確認は手動テストで行う。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: アニメーション視覚テスト

**目的**: アニメーション効果が視覚的に正しく動作することを確認する

**実行手順**:

1. デスクトップアプリを起動
2. 以下のシナリオを実行:
   - ストリーミング開始→フェードイン確認
   - カーソルブリンキング確認
   - ストリーミング完了→カーソル非表示確認
3. 視覚的な品質を評価
4. 結果を記録

**期待される成果物**:

- テスト結果レポート（タスク5で統合）

---

### タスク2: パフォーマンステスト

**目的**: 60fps維持を手動で確認する

**実行手順**:

1. Chrome DevTools を開く
2. Performance tab で記録を開始
3. 以下のシナリオを実行:
   - 長文ストリーミング
   - 高速連続チャンク追加
4. FPSを確認
5. 結果を記録

**期待される成果物**:

- テスト結果レポート（タスク5で統合）

---

### タスク3: アクセシビリティテスト

**目的**: reduced-motion対応を手動で確認する

**実行手順**:

1. システム設定で「視覚効果を減らす」を有効化
2. アプリを起動
3. 以下を確認:
   - フェードインアニメーションが無効
   - カーソルブリンキングが無効
   - コンテンツは正常に表示
4. 結果を記録

**期待される成果物**:

- テスト結果レポート（タスク5で統合）

---

### タスク4: ブラウザ互換性テスト

**目的**: 主要ブラウザでの動作を確認する

**実行手順**:

1. 以下のブラウザで動作確認:
   - Chrome（最新）
   - Firefox（最新）
   - Safari（最新）
   - Edge（最新）
2. アニメーションが正常に動作することを確認
3. 結果を記録

**期待される成果物**:

- テスト結果レポート（タスク5で統合）

---

### タスク5: テスト結果レポート作成

**目的**: 手動テスト結果を文書化する

**実行手順**:

1. タスク1〜4の結果を集約
2. 以下の形式でレポートを作成

**期待される成果物**:

- `outputs/phase-11/manual-test-result.md`

---

### タスク6: 発見課題記録

**目的**: 手動テストで発見した課題を記録する

**実行手順**:

1. 発見した課題を重要度別に分類
2. 課題がなくても「発見課題なし」と明記

**期待される成果物**:

- `outputs/phase-11/discovered-issues.md`
