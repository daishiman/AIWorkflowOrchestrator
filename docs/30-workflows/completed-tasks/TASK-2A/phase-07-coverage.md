## 目的

テストカバレッジが目標を達成していることを検証し、カバレッジレポートを生成する。目標未達の場合は Phase 6 に戻りテストを追加する。

## 背景

品質基準として以下のカバレッジ目標を設定している：

- Line Coverage: 80%以上
- Branch Coverage: 60%以上
- Function Coverage: 80%以上

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジレポート生成

**目的**: 詳細なカバレッジレポートを生成する

**実行手順**:

1. カバレッジ付きでテストを実行する：

```bash
pnpm --filter @repo/desktop test -- --coverage --run apps/desktop/src/main/services/skill/__tests__/SkillScanner.test.ts
```

2. 以下のカバレッジ指標を記録する：

| 指標              | 目標 | 実績 | 達成 |
| ----------------- | ---- | ---- | ---- |
| Line Coverage     | 80%  |      | □    |
| Branch Coverage   | 60%  |      | □    |
| Function Coverage | 80%  |      | □    |

3. `outputs/phase-07/coverage-report.md` にレポートを記録する

**期待される成果物**:

- `outputs/phase-07/coverage-report.md`

---

### タスク2: 未カバー箇所の分析

**目的**: カバーされていない箇所を分析する

**実行手順**:

1. カバレッジレポートの詳細を確認する

2. 未カバーの行・分岐を特定し、以下を分析する：
   - 未カバーの理由（到達不能コード、エッジケース等）
   - テスト追加が必要か、または許容範囲か

3. `outputs/phase-07/uncovered-analysis.md` に分析結果を記録する

**期待される成果物**:

- `outputs/phase-07/uncovered-analysis.md`

---

### タスク3: カバレッジ目標達成判定

**目的**: カバレッジ目標の達成を判定する

**実行手順**:

1. タスク1 の結果に基づき判定を行う：

| 判定  | 条件                                  | 次のアクション           |
| ----- | ------------------------------------- | ------------------------ |
| PASS  | 全指標が目標以上                      | Phase 8 へ進む           |
| MINOR | 1指標が目標未達（5%以内）             | 許容し Phase 8 へ        |
| MAJOR | 複数指標が目標未達 or 1指標が大幅未達 | Phase 6 へ戻りテスト追加 |

2. `outputs/phase-07/coverage-decision.md` に判定結果を記録する

**期待される成果物**:

- `outputs/phase-07/coverage-decision.md`

---

### タスク4: テスト品質確認

**目的**: テストの品質を確認する

**実行手順**:

1. 以下のテスト品質基準を確認する：

| 基準                         | 確認項目                                               | 結果 |
| ---------------------------- | ------------------------------------------------------ | ---- |
| テストの独立性               | 各テストが他のテストに依存していないか                 | □    |
| テストの明確性               | テスト名から何をテストしているか分かるか               | □    |
| アサーションの適切性         | 適切なアサーションが使用されているか                   | □    |
| フィクスチャのクリーンアップ | 作成したフィクスチャが適切にクリーンアップされているか | □    |
| テストの実行速度             | 各テストが適切な時間内に完了するか                     | □    |

2. `outputs/phase-07/test-quality.md` に確認結果を記録する

**期待される成果物**:

- `outputs/phase-07/test-quality.md`
