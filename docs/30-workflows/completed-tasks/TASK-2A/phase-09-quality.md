### タスク1: TypeScript 型チェック

**目的**: 型エラーがないことを確認する

**実行手順**:

1. 型チェックを実行する：

```bash
pnpm --filter @repo/desktop typecheck
```

2. エラーがあれば修正する

3. 以下の型安全性基準を確認する：

| 基準                 | 確認項目                                 | 結果 |
| -------------------- | ---------------------------------------- | ---- |
| any 型の不使用       | any 型が使用されていないか               | □    |
| unknown の適切な使用 | 外部入力に unknown を使用しているか      | □    |
| null チェック        | null/undefined チェックが適切か          | □    |
| 戻り値型の明示       | 公開メソッドの戻り値型が明示されているか | □    |

4. `outputs/phase-09/typecheck-result.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-09/typecheck-result.md`

### タスク3: セキュリティチェック

**目的**: セキュリティ上の問題がないことを確認する

**実行手順**:

1. 以下のセキュリティ観点をチェックする：

| 観点                 | 確認項目                                           | 結果 |
| -------------------- | -------------------------------------------------- | ---- |
| パストラバーサル     | ユーザー入力パスが適切にバリデーションされているか | □    |
| ディレクトリ制限     | スキャン対象が指定ディレクトリに限定されているか   | □    |
| 機密情報露出         | ログに機密情報が出力されていないか                 | □    |
| エラー情報露出       | エラーメッセージに内部情報が含まれていないか       | □    |
| ファイルシステム操作 | ファイル操作が安全に行われているか                 | □    |

2. パストラバーサル対策の実装を確認する：

```typescript
// 期待される対策
private isPathSafe(basePath: string, targetPath: string): boolean {
  const resolvedPath = path.resolve(basePath, targetPath);
  return resolvedPath.startsWith(path.resolve(basePath));
}
```

3. `outputs/phase-09/security-review.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-09/security-review.md`

### タスク4: パフォーマンスチェック

**目的**: 性能要件を満たしていることを確認する

**実行手順**:

1. 以下のパフォーマンス観点を確認する：

| 観点           | 確認項目                           | 目標            | 結果 |
| -------------- | ---------------------------------- | --------------- | ---- |
| スキャン速度   | 100スキルのスキャン時間            | 3秒以内         | □    |
| メモリ効率     | 大量ファイルでメモリリークがないか | 安定            | □    |
| 並列処理       | I/O 操作が適切に並列化されているか | Promise.all使用 | □    |
| 不要な読み取り | 必要最小限のファイル読み取りか     | 最小限          | □    |

2. パフォーマンステストを実施する：

```typescript
// テスト例
it("should scan 100 skills within 3 seconds", async () => {
  const start = Date.now();
  await scanner.scanAll();
  const duration = Date.now() - start;
  expect(duration).toBeLessThan(3000);
});
```

3. `outputs/phase-09/performance-review.md` に結果を記録する

**期待される成果物**:

- `outputs/phase-09/performance-review.md`

### タスク5: 品質ゲート判定

**目的**: 全品質基準の達成を判定する

**実行手順**:

1. タスク1〜4 の結果を集計する

2. 以下の品質ゲート基準に基づき判定する：

| 判定     | 条件                       | 次のアクション                 |
| -------- | -------------------------- | ------------------------------ |
| PASS     | 全基準を満たす             | Phase 10 へ進む                |
| MINOR    | 軽微な問題あり（性能以外） | 問題対応後 Phase 10 へ         |
| MAJOR    | 重大な問題あり             | Phase 8 へ戻りリファクタリング |
| CRITICAL | セキュリティ問題あり       | 即座に修正                     |

3. `outputs/phase-09/quality-gate-decision.md` に判定結果を記録する

**期待される成果物**:

- `outputs/phase-09/quality-gate-decision.md`
