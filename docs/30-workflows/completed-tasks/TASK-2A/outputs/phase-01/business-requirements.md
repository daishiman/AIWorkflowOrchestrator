## 1. ビジネス背景

AIWorkflowOrchestrator は、Claude Code のスキル機能を拡張し、ユーザーが独自のスキルを管理・実行できるデスクトップアプリケーションである。現在のシステムでは以下の課題が存在する：

### 1.1 現状の課題

1. **スキル情報の取得が不完全**
   - 既存のインポート機能はスキルの基本情報（name, description）のみを取得
   - `agents/`, `references/`, `scripts/` などの配下情報が欠落している
   - スキルの完全な構造を把握できない

2. **複数スキルディレクトリの非統一管理**
   - `~/.aiworkflow/skills/`（アプリ独自スキル）
   - `~/.claude/skills/`（Claude CLI スキル）
   - 2つのディレクトリを統一的に扱う仕組みがない

3. **読み取り専用スキルの識別不足**
   - Claude CLI のスキルは編集すべきでない
   - 現状ではこの区別ができていない

---

## 2. ビジネス目的

### 2.1 主要目的

| 目的ID | 目的                        | 期待効果                                        |
| ------ | --------------------------- | ----------------------------------------------- |
| BO-001 | スキル完全メタデータの取得  | スキル管理UIで詳細情報を表示可能にする          |
| BO-002 | 2ディレクトリの統一スキャン | ユーザーが全スキルを一元管理できる              |
| BO-003 | 読み取り専用フラグの管理    | Claude CLI スキルの誤編集を防止する             |
| BO-004 | サブリソースの可視化        | agents, references 等の配下情報を活用可能にする |

### 2.2 ビジネス価値

- **ユーザー体験向上**: スキルの詳細情報を確認でき、適切なスキルを選択できる
- **データ整合性**: 全スキル情報を一元的に取得し、一貫性のある管理を実現
- **安全性確保**: 読み取り専用スキルの明示により誤操作を防止

## 5. スコープ

### 5.1 対象範囲

- SkillScanner クラスの実装
- `~/.aiworkflow/skills/` のスキャン
- `~/.claude/skills/` のスキャン（読み取り専用）
- SKILL.md の YAML Frontmatter パース
- 6種類のサブディレクトリスキャン（agents, references, scripts, assets, schemas, indexes）
- その他ファイル検出（EVALS.json, LOGS.md, package.json 等）

### 5.2 対象外

- スキル実行機能（TASK-3-1）
- UI コンポーネント（TASK-7a 以降）
- IPC ハンドラー（TASK-4-2）
- スキルのインポート・エクスポート機能
