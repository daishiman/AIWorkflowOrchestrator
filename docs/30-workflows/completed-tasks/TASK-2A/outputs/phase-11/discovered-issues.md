## 3. 課題詳細

### ISS-01: 未使用型定義

**概要**: `_SubDirectoryType` 型が定義されているが、コード内で使用されていない

**発見経緯**: ESLint チェックで `no-unused-vars` として検出

**対応**:

- アンダースコアプレフィックスを追加して ESLint エラーを回避
- ドキュメント目的の型定義として保持
- 将来的に型ガード等で使用可能

**理由**:

- 型定義を削除すると、サブディレクトリ名の一覧が定数のみになり型情報が失われる
- 将来の拡張時に有用

**ステータス**: 受容（修正不要）

---

## 4. 既知の制限事項

### 4.1 @repo/shared モジュール解決

**内容**: TypeScript 型チェック時に `@repo/shared` モジュールが解決できない

**原因**: プロジェクト全体のモノレポ設定の問題

**影響**: SkillScanner には直接的な影響なし（ビルド・テスト時は正常動作）

**対応**: プロジェクト全体の設定改善として別途対応
