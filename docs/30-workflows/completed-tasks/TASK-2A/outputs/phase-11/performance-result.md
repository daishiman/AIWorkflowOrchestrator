**実装パターン**:

```typescript
// 2ディレクトリを並列スキャン
const [aiworkflowSkills, claudeSkills] = await Promise.all([
  this.scanSkillDirectory(this.aiworkflowSkillsDir, false),
  this.scanSkillDirectory(this.claudeSkillsDir, true),
]);

// 6サブディレクトリを並列スキャン
```
