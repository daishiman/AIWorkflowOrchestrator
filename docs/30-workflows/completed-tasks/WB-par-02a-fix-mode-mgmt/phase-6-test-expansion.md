## 拡充テストケース

### ラジオボタン削除の回帰テスト

| ケース                                                        | 期待結果                                            |
| ------------------------------------------------------------- | --------------------------------------------------- |
| `"テンプレートから作成"` テキストがDOMに存在しないこと        | `queryByText("テンプレートから作成")` が null       |
| `"LLMで生成"` テキストがラジオボタンとしてDOMに存在しないこと | ラジオボタン要素が存在しないこと                    |
| `data-testid="generation-mode-selector"` が存在しないこと     | `queryByTestId("generation-mode-selector")` が null |
| ウィザード再マウント後もラジオボタンが表示されないこと        | コンポーネント再マウント後もモード選択UIがないこと  |

### state廃止の回帰テスト

| ケース                                                 | 期待結果                                                          |
| ------------------------------------------------------ | ----------------------------------------------------------------- |
| `generationMode`関連の文字列がソースに残っていないこと | `"template"` / `"llm"` 条件分岐がウィザードコードに存在しないこと |
| `hasActivatedLlmMode`関連のコードが存在しないこと      | 変数・関数・条件分岐にhasActivatedLlmModeが残っていないこと       |
| `setGenerationMode` が呼ばれないこと                   | 旧関数が呼ばれないことの確認                                      |
| `setHasActivatedLlmMode` が呼ばれないこと              | 旧関数が呼ばれないことの確認                                      |

### Step遷移エッジケーステスト

| ケース                                           | 期待結果                                             |
| ------------------------------------------------ | ---------------------------------------------------- |
| Step 0の次へボタンを素早く2回押した場合          | Step 2に直接飛ばずStep 1が表示されること             |
| Step 0でフォーム未入力のまま次へを押した場合     | バリデーションエラーが表示されStep 1に遷移しないこと |
| Step 1から戻るボタンを押した場合                 | Step 0に戻ること                                     |
| Step 1でQ1〜Q6を全回答後に生成ボタンを押した場合 | Step 2（GenerateStep）に遷移すること                 |

### SkillInfoStep props整合テスト

| ケース                                                           | 期待結果                                               |
| ---------------------------------------------------------------- | ------------------------------------------------------ |
| `SkillInfoStep`に`generationMode` propを渡さなくても動作すること | propなしでレンダリングエラーが発生しないこと           |
| `SkillInfoStep`の`onNext`が呼ばれるとStep 1に遷移すること        | `onNext`コールバックが正しくStep 1遷移を引き起こすこと |

### 既存テンプレートモードテストの更新

| ケース                                                   | 期待結果                                                   |
| -------------------------------------------------------- | ---------------------------------------------------------- |
| テンプレートモード用のテストが存在する場合               | LLM専用化に伴い削除またはLLMモード対応に更新されていること |
| `generationMode === "template"` を前提にしたテストケース | 削除またはLLMフロー検証テストに置き換えられていること      |
