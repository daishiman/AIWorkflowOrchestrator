## テスト実行方法

### REPLでのテスト

```typescript
// packages/shared での REPL 起動
import {
  RuleBasedQueryClassifier,
  LLMQueryClassifier,
} from "./src/services/search";

// ルールベース分類器テスト
const classifier = new RuleBasedQueryClassifier();
const result = await classifier.classify("全体のテーマは？");
console.log(result);
// 期待: { success: true, data: { type: "global", ... } }

const weights = classifier.getSearchWeights("global");
console.log(weights);
// 期待: { keyword: 0.2, semantic: 0.3, graph: 0.5 }
```
