## 2. 日本語日付パターンテスト

### 2.1 テストケース

#### テスト1: 和暦形式

**入力テキスト**:

```
次のマイルストーンは2024年3月31日です。
プロジェクト開始日は2024年1月15日でした。
```

**抽出結果**:

- 2024年3月31日 → `date` (confidence: 0.95)
- 2024年1月15日 → `date` (confidence: 0.95)

**判定**: ✅ PASS

#### テスト2: 複数形式混在

**入力テキスト**:

```
スケジュール:
- 企画: 2024-01-15
- 開発: 2024年4月1日
- リリース: 2024/12/25
```

**抽出結果**:

- 2024-01-15 → `date`
- 2024年4月1日 → `date`
- 2024/12/25 → `date`

**判定**: ✅ PASS（3形式すべて抽出）

## 4. 制限事項と今後の対応

### 4.1 RuleBasedExtractorの制限

| 制限事項               | 状況             | 対応方針         |
| ---------------------- | ---------------- | ---------------- |
| 日本語人名の抽出       | 未対応           | LLM使用で対応    |
| 日本語の組織名         | 辞書にある分のみ | LLM使用で対応    |
| カタカナ技術用語       | 一部対応         | パターン追加可能 |
| 漢字のみのエンティティ | 未対応           | LLM使用で対応    |

### 4.2 LLM使用時の期待動作

LLMEntityExtractorを使用することで、以下が可能になる設計:

1. **日本語人名抽出**: 「山田太郎」「田中さん」等
2. **日本語組織名**: 「株式会社〇〇」「〇〇省」等
3. **カタカナ用語**: 「コンテナ」「マイクロサービス」等
4. **説明文の日本語生成**: 抽出エンティティの日本語説明
