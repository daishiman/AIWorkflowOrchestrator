# Phase 11: 手動テスト -- Skill Output Integration

## メタ情報

| 項目       | 値                       |
| ---------- | ------------------------ |
| Phase番号  | 11                       |
| 機能名     | skill-output-integration |
| タスクID   | TASK-SDK-SC-04           |
| 作成日     | 2026-04-02               |
| 依存 Phase | Phase 10（最終レビュー） |

## 目的

自動テストでは検証しきれないエンドツーエンドのシナリオを手動で確認する。特にスキル生成フロー全体（Task01-03 統合）の通しテストと、生成されたスキルのファイル保存・UI 表示を実際に操作して確認する。

## 実行タスク

### Task 11-1: 手動テスト環境の準備

```bash
# Electron アプリの起動
pnpm --filter @repo/desktop dev

# テスト用のプロジェクトルートに .claude/skills/ ディレクトリが存在しないことを確認
ls -la .claude/skills/ 2>/dev/null || echo ".claude/skills/ は存在しません（正常）"
```

### Task 11-2: MT-01 — スキル生成フロー全体の通しテスト（Task01-03 統合）

#### シナリオ

1. Electron アプリを起動する
2. skill-creator 機能を開く
3. スキル名・説明・トリガー条件などの質問に回答する（TASK-SDK-SC-02 質問エンジン）
4. SDK セッションが実行されてスキル生成が完了するまで待機する
5. `SkillCreatorResultPanel` にスキル生成完了の通知が表示されることを確認する

#### 確認項目

| 確認項目                                                      | 期待結果                                     | 結果 |
| ------------------------------------------------------------- | -------------------------------------------- | ---- |
| 質問エンジンが正しく質問を提示する                            | 質問 UI が表示される                         | -    |
| 全質問への回答後に SDK セッションが実行される                 | セッション実行中インジケーターが表示される   | -    |
| SDK セッション完了後に `SkillCreatorResultPanel` が表示される | 結果パネルが表示される                       | -    |
| スキル名が正しく表示される                                    | 入力したスキル名が見出しに表示される         | -    |
| SKILL.md 内容のプレビューが表示される                         | コードブロックで SKILL.md の内容が表示される | -    |

### Task 11-3: MT-02 — 生成されたSKILL.mdが正しく保存されること

#### シナリオ

MT-01 の実行後に、ファイルシステムを確認する。

```bash
# 生成されたスキルファイルの確認
ls -la .claude/skills/
cat .claude/skills/{生成されたスキル名}/SKILL.md
```

#### 確認項目

| 確認項目                                                      | 期待結果                                              | 結果 |
| ------------------------------------------------------------- | ----------------------------------------------------- | ---- |
| `.claude/skills/` ディレクトリが自動作成されている            | ディレクトリが存在する                                | -    |
| `.claude/skills/{スキル名}/` サブディレクトリが作成されている | スキル名のディレクトリが存在する                      | -    |
| `SKILL.md` ファイルが正しい内容で保存されている               | SDK セッションが生成したスキル内容が保存されている    | -    |
| ファイルの文字コードが UTF-8 である                           | `file .claude/skills/{name}/SKILL.md` が UTF-8 を返す | -    |

### Task 11-4: MT-03 — SkillCreatorConversationPanel に新スキル結果が表示されること

#### シナリオ

MT-01/MT-02 の実行後に、Electron アプリの `SkillCreatorConversationPanel` 内に表示される `SkillCreatorResultPanel` を確認する。

#### 確認項目

| 確認項目                                                                     | 期待結果                                 | 結果 |
| ---------------------------------------------------------------------------- | ---------------------------------------- | ---- |
| `SkillCreatorConversationPanel` に新しく生成されたスキル結果が表示されている | スキル名・保存先・プレビューが表示される | -    |
| スキルのステータスが「登録済み」として表示される                             | SkillRegistry への登録が反映されている   | -    |
| 「スキルを開く」ボタンをクリックするとエディタでファイルが開く               | SKILL.md がエディタで開く                | -    |

### Task 11-5: MT-04 — 既存スキル上書き確認ダイアログ（FR-006）

#### シナリオ

1. MT-01 を 2 回実行して、同名スキルを生成しようとする
2. 2 回目の生成時に上書き確認ダイアログが表示されることを確認する

#### 確認項目

| 確認項目                                                                    | 期待結果                                            | 結果 |
| --------------------------------------------------------------------------- | --------------------------------------------------- | ---- |
| 同名スキル生成時に `SkillCreatorResultPanel` に上書き確認バナーが表示される | 「同名のスキルが既に存在します」バナーが表示される  | -    |
| ユーザーがキャンセルした場合は既存ファイルが上書きされない                  | `.claude/skills/{name}/SKILL.md` の内容が変わらない | -    |
