### Task 4: 最終判定

#### 目的

全レビュー結果を総合し、リリース可否を判定する。

#### 判定ルール

| 条件                                 | 判定結果                               |
| ------------------------------------ | -------------------------------------- |
| 全観点がPASS                         | リリース可 → Phase 11へ                |
| MINORが1件以上（MAJOR/CRITICALなし） | リリース可（改善点を記録）→ Phase 11へ |
| MAJORが1件以上                       | リリース不可 → 該当Phaseへ差し戻し     |
| CRITICALが1件以上                    | リリース不可 → 即時修正対応            |

#### 戻り先決定テーブル

| 問題の種類       | 戻り先  |
| ---------------- | ------- |
| 要件の問題       | Phase 1 |
| 設計の問題       | Phase 2 |
| テスト設計の問題 | Phase 4 |
| 実装の問題       | Phase 5 |
| テスト拡充の問題 | Phase 6 |
| カバレッジ未達   | Phase 7 |
| コード品質の問題 | Phase 8 |

#### MINOR判定時の未タスク化フロー

1. MINOR判定の指摘事項を分析
2. `docs/30-workflows/unassigned-task/` に未タスク指示書を作成
3. Phase 11へ進行
