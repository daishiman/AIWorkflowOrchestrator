# Prompt Elegance Review Improved

## 目的

本ブランチの変更分を、2つの skill 定義に漏れなく反映し、30種の思考法を使って検証したうえで、最小複雑性の解決策へ改善する。

## 実行条件

- 先に `task-specification-creator` と `aiworkflow-requirements` を読む
- 変更分は `git diff` で固定する
- 改善より先に、skill 準拠の不足と参照切れを確定する
- コミット、PR、push は行わない

## フェーズ

### Phase 1: 変更分と正本の固定

- 本ブランチの差分を収集する
- 2つの skill 定義を読み込む
- 依存関係と current facts を固定する

### Phase 2: 並列検証

- SubAgent A: skill 準拠検証
- SubAgent B: 30思考法による多角的分析
- 両者の結果が揃うまで改善に進まない

### Phase 3: 統合判断

- 矛盾、漏れ、不整合、依存関係不整合を整理する
- patch 修正で足りるか、再構成が必要かを判断する
- 既存実装の破棄は合理的な根拠がある場合のみ検討する

### Phase 4: 並列改善

- 独立した文書群は並列で修正する
- 依存関係があるものは直列にする
- 参照、名称、成果物、完了条件を同じ wave で揃える

### Phase 5: 最終検証

- 4条件を再検証する
- 残留差分を列挙する
- 直前の改善が新しい drift を作っていないか確認する
