## コンポーネント品質評価

### ApprovalSheet 再利用パターン

`ApprovalSheet` は既存の承認フロー（例: governance approval）で使用されているコンポーネントを再利用している。
これにより以下が担保される:

- 視覚品質: 既存 UI デザインシステムに準拠
- アクセシビリティ: 既存 aria 属性・フォーカス管理を継承
- HIG 準拠: 既存コンポーネントの動作を踏襲

### ボタン識別子確認済み

```tsx
data-testid="approve-button"
data-testid="reject-button"
```

ユニットテスト（TC-APPR-09, 17）で識別子を使用した操作確認済み。
