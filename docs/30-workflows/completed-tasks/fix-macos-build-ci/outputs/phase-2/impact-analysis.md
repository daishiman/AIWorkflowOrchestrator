# 影響範囲分析書

## 概要

`electron-builder.yml` の修正による影響範囲を分析し、リスクと対策を整理する。

---

## 影響範囲マトリクス

| 影響対象               | 影響度   | 種類 | 対策                           |
| ---------------------- | -------- | ---- | ------------------------------ |
| CI ビルド (macOS)      | 高（正） | 改善 | エラー解消、ビルド成功         |
| ローカルビルド (macOS) | 低       | 変更 | ZIP のみ生成（実用上問題なし） |
| CI ビルド (Windows)    | なし     | -    | 無効化中のため影響なし         |
| CI ビルド (Linux)      | なし     | -    | 無効化中のため影響なし         |
| リリースフロー         | なし     | -    | 現状リリースワークフロー未使用 |
| 配布形式               | 中       | 変更 | DMG 非提供、ZIP で代替         |

---

## 詳細分析

### 1. CI ビルド (macOS)

**影響**: 高（正の影響＝改善）

| 項目       | Before         | After                |
| ---------- | -------------- | -------------------- |
| ビルド結果 | 失敗           | **成功**             |
| 生成物     | なし（エラー） | ZIP (x64, arm64)     |
| ビルド時間 | N/A（失敗）    | 短縮（DMG 生成なし） |

**確認項目**:

- [x] `hdiutil` エラーが発生しなくなる
- [x] ZIP ファイルが正常に生成される
- [x] アーティファクトがアップロードされる

### 2. ローカルビルド (macOS)

**影響**: 低

| 項目         | Before                                    | After        |
| ------------ | ----------------------------------------- | ------------ |
| 実行コマンド | `pnpm --filter @repo/desktop package:mac` | 同じ         |
| 生成物       | DMG + ZIP                                 | **ZIP のみ** |
| 動作         | 正常                                      | 正常         |

**確認項目**:

- [x] ローカルでのビルドが成功する
- [x] 開発者のワークフローに影響がない
- [x] アプリの動作は変わらない

### 3. 他プラットフォームへの影響

**影響**: なし

| プラットフォーム | 状態     | 影響                              |
| ---------------- | -------- | --------------------------------- |
| Windows          | 無効化中 | なし                              |
| Linux            | 無効化中 | なし                              |
| macOS (Intel)    | 無効化中 | なし（将来有効化時も ZIP で動作） |

### 4. リリースフローへの影響

**影響**: なし（現状）

- 現在リリースワークフローは使用されていない
- `publish` 設定はコメントアウト済み
- 将来リリースワークフローを追加する際に DMG 対応を検討

### 5. 配布形式の変更

**影響**: 中

| 項目         | Before             | After      | 対策       |
| ------------ | ------------------ | ---------- | ---------- |
| DMG          | 提供               | **非提供** | ZIP で代替 |
| ZIP          | 提供               | 提供       | -          |
| ユーザー体験 | DMG インストーラー | ZIP 展開   | 手順説明   |

**考慮事項**:

- macOS ユーザーは ZIP からアプリをインストール可能
- App Store 以外の配布では ZIP が広く使われている
- DMG はインストーラーとして便利だが必須ではない

## リスク評価

### 特定されたリスク

| リスク                        | 確率 | 影響度 | 総合 | 緩和策               |
| ----------------------------- | ---- | ------ | ---- | -------------------- |
| DMG が必要なユーザーへの影響  | 低   | 低     | 低   | ZIP で代替可能       |
| 将来 DMG 再有効化時の設定漏れ | 低   | 中     | 低   | dmg セクションを残す |
| ローカルビルドの混乱          | 低   | 低     | 低   | ドキュメント更新     |

### リスク対応方針

1. **DMG 設定の保持**: `dmg` セクションを削除せず残す
2. **ドキュメント更新**: Phase 12 で変更内容を文書化
3. **将来対応**: リリースワークフローで DMG 生成を検討
