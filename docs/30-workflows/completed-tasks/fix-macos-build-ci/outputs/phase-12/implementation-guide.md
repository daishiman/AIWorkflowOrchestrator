## Part 1: 概念的説明

### この修正は何をしているのか？

**比喩で説明**:

マンションに入るときに「入館証」が必要なように、macOSアプリも動作するために「許可証」が必要です。
この修正は、その「許可証」ファイルを作成しています。

```
入館証なし → 入れない（ビルド失敗）
入館証あり → 入れる（ビルド成功）
```

### なぜこの修正が必要だったのか？

**問題の状況**:

1. アプリのビルド設定に「ここに許可証があるよ」と書いてあった
2. でも実際にはその許可証ファイルがなかった
3. ビルドプロセスが「許可証が見つからない！」とエラーを出していた

**解決策**:

設定で指定されている場所に、実際の許可証ファイルを作成した。

### 許可証には何が書いてあるのか？

macOSの「許可証」（entitlements）には、アプリが何をして良いかが書かれています。

今回は2つだけ許可を書きました：

1. **JITコンパイル許可**: JavaScriptを高速に実行するために必要
2. **未署名メモリ実行許可**: JITで生成したコードを実行するために必要

**なぜこの2つだけ？**

- 不要な権限は書かない（最小権限原則）
- でもJavaScript（Electron）アプリには必須

### entitlements.mac.plist の内容

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <!-- なぜこの権限が必要か：
         V8エンジンはJavaScriptをネイティブコードに
         コンパイル（JIT）して高速実行する。
         この権限がないとJITが無効になり、
         アプリの動作が著しく遅くなる。 -->
    <key>com.apple.security.cs.allow-jit</key>
    <true/>

    <!-- なぜこの権限が必要か：
         JITで生成されたコードは署名されていない。
         この権限がないと、JITコードの実行が
         ブロックされてアプリが動作しない。 -->
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
</dict>
</plist>
```

### 権限選定の根拠

| 権限                             | 採用 | 理由                                       |
| -------------------------------- | ---- | ------------------------------------------ |
| allow-jit                        | ✅   | V8のJITコンパイルに必須                    |
| allow-unsigned-executable-memory | ✅   | JITコード実行に必須                        |
| disable-library-validation       | ❌   | Electronは外部ライブラリを動的ロードしない |
| network系権限                    | ❌   | 非サンドボックス環境では不要               |
| その他8権限                      | ❌   | Electron/V8動作に不要                      |

## 用語集

| 用語             | 読み方                | 意味                             |
| ---------------- | --------------------- | -------------------------------- |
| entitlements     | エンタイトルメンツ    | macOSアプリの権限設定            |
| plist            | ピーリスト            | Apple形式の設定ファイル（XML）   |
| Hardened Runtime | ハードンド ランタイム | macOSのセキュリティ機能          |
| JIT              | ジット                | Just-In-Time（実行時コンパイル） |
| codesign         | コードサイン          | macOSの署名コマンド              |
| ad-hoc           | アドホック            | 開発者ID無しの署名               |
| Gatekeeper       | ゲートキーパー        | macOSのアプリ検証機能            |
