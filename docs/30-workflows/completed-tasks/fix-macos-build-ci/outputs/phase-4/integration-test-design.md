## 統合テストシナリオ

### IT-01: entitlements読み込みテスト

| 項目         | 内容                                                   |
| ------------ | ------------------------------------------------------ |
| **接続点**   | electron-builder.yml → entitlements.mac.plist          |
| **検証内容** | electron-builderがentitlementsファイルを正しく読み込む |
| **前提条件** | entitlements.mac.plistがbuild/配下に存在               |
| **実行方法** | `pnpm --filter @repo/desktop package:mac`              |
| **成功基準** | "cannot read entitlement data" エラーが発生しない      |
| **失敗基準** | "cannot read entitlement data" エラーが発生            |

### IT-02: codesign実行テスト

| 項目         | 内容                                             |
| ------------ | ------------------------------------------------ |
| **接続点**   | electron-builder → codesign コマンド             |
| **検証内容** | codesignがentitlementsを適用してad-hoc署名を完了 |
| **前提条件** | 有効なplistファイル、macOS環境                   |
| **実行方法** | パッケージングプロセス内で自動実行               |
| **成功基準** | 署名プロセスがエラーなしで完了                   |
| **失敗基準** | codesign関連のエラーが発生                       |

### IT-03: 成果物生成テスト

| 項目         | 内容                                 |
| ------------ | ------------------------------------ |
| **接続点**   | electron-builder → dist/ディレクトリ |
| **検証内容** | .zipファイルが正しく生成される       |
| **前提条件** | ビルドプロセスが完了                 |
| **実行方法** | `ls apps/desktop/dist/*.zip`         |
| **成功基準** | .zipファイルが1つ以上存在            |
| **失敗基準** | .zipファイルが生成されない           |

### IT-04: アーティファクトアップロードテスト

| 項目         | 内容                                                   |
| ------------ | ------------------------------------------------------ |
| **接続点**   | GitHub Actions → Artifacts                             |
| **検証内容** | ビルド成果物がアーティファクトとしてアップロードされる |
| **前提条件** | CIビルドが成功                                         |
| **実行方法** | GitHub Actions UI確認                                  |
| **成功基準** | `electron-macos-arm64` アーティファクトが存在          |
| **失敗基準** | アーティファクトがアップロードされない                 |

### IT-05: 署名付きアプリ起動テスト

| 項目         | 内容                                       |
| ------------ | ------------------------------------------ |
| **接続点**   | .app → macOS Gatekeeper                    |
| **検証内容** | 署名済みアプリがmacOSで起動できる          |
| **前提条件** | アーティファクトをダウンロード・展開済み   |
| **実行方法** | 手動テスト（ダブルクリック起動）           |
| **成功基準** | アプリが正常に起動、メインウィンドウ表示   |
| **失敗基準** | Gatekeeperブロック、起動エラー、クラッシュ |

## 統合テストカテゴリ別チェックリスト

### ファイル存在テスト

| ID    | テスト内容                         | 検証方法         |
| ----- | ---------------------------------- | ---------------- |
| FE-01 | entitlements.mac.plistの存在       | `test -f`        |
| FE-02 | electron-builder.ymlの参照パス整合 | 設定ファイル確認 |

### 構文検証テスト

| ID    | テスト内容           | 検証方法       |
| ----- | -------------------- | -------------- |
| SV-01 | plistのXML構文有効性 | `plutil -lint` |
| SV-02 | 必須キーの存在       | `PlistBuddy`   |

### ビルドフローテスト

| ID    | テスト内容                 | 検証方法                      |
| ----- | -------------------------- | ----------------------------- |
| BF-01 | 依存関係のビルド           | `pnpm build`                  |
| BF-02 | デスクトップアプリのビルド | `pnpm --filter desktop build` |
| BF-03 | パッケージング             | `pnpm package:mac`            |

### 成果物生成テスト

| ID    | テスト内容                     | 検証方法          |
| ----- | ------------------------------ | ----------------- |
| AG-01 | .zipファイルの生成             | `ls dist/*.zip`   |
| AG-02 | ファイルサイズの妥当性         | `du -h`           |
| AG-03 | アーティファクトのアップロード | GitHub Actions UI |

## エラーハンドリングシナリオ

| シナリオ                     | 期待されるエラー                 | 対処方法       |
| ---------------------------- | -------------------------------- | -------------- |
| entitlementsファイル不在     | cannot read entitlement data     | ファイルを作成 |
| plist構文エラー              | plutil: Unexpected character     | 構文を修正     |
| electron-builder.ymlパスミス | File not found                   | パスを修正     |
| 権限不足                     | JIT compilation failed（実行時） | 必須権限を追加 |
