## 目的

Phase 6で拡充したテストのカバレッジを再計測し、品質基準を満たしているかをゲート判定する。未達の場合はPhase 6に戻る。

## 実行タスク

### Task 1: カバレッジ再計測

**目的**: 最新のテストコードでカバレッジを計測する

**手順**:

1. テストカバレッジを計測する:
   ```bash
   pnpm --filter @repo/desktop vitest run --coverage src/renderer/components/skill/__tests__/PermissionDialog.test.tsx
   ```
2. 以下の結果を記録する:

| メトリクス | 計測値  | 目標値 | 判定 |
| ---------- | ------- | ------ | ---- |
| Line       | \_\_\_% | 80%    | □    |
| Branch     | \_\_\_% | 60%    | □    |
| Function   | \_\_\_% | 80%    | □    |

### Task 2: カバレッジギャップ分析

**目的**: カバレッジが不足している箇所を特定する

**手順**:

1. カバレッジレポートの詳細（ファイル別・行別）を確認する
2. 未カバー行・未カバーブランチを一覧化する
3. 各ギャップについて以下を判断する:

| 未カバー箇所                            | 対応要否 | 理由                        |
| --------------------------------------- | -------- | --------------------------- |
| （例）フォーカストラップ内のrefチェック | 要       | Branch カバレッジ向上のため |
| （例）早期リターン null                 | 済       | Phase 4で既にテスト済み     |

### Task 3: ゲート判定

**目的**: カバレッジ基準の達成状況を判定する

**判定基準**:

| 判定 | 条件                                        | 次のアクション |
| ---- | ------------------------------------------- | -------------- |
| PASS | Line≥80%, Branch≥60%, Function≥80% 全て達成 | Phase 8 に進む |
| FAIL | いずれかの基準を未達                        | Phase 6 に戻る |

### Task 4: カバレッジ検証レポートの作成

**目的**: カバレッジ結果をドキュメントに記録する

**手順**:

1. `outputs/phase-7/coverage-report.md` を作成する
2. 計測結果、ギャップ分析、ゲート判定を記載する
