# Phase 1: 受け入れ基準 - PermissionDialog コンポーネント

| AC-ID  | 対象    | 受け入れ基準                                                                         | テスト方法     |
| ------ | ------- | ------------------------------------------------------------------------------------ | -------------- |
| AC-001 | FR-001  | `pendingPermission=null` の場合、DOMにダイアログ要素が存在しない                     | ユニットテスト |

| AC-004 | FR-005  | `args.command="ls -la"` の場合、`<pre>` タグ内に `ls -la` がそのまま表示される       | ユニットテスト |
| AC-005 | FR-006  | `args.path="/tmp/file.txt"` の場合、`<pre>` タグ内に `/tmp/file.txt` が表示される    | ユニットテスト |
| AC-006 | FR-007  | `args={key:"value"}` の場合、JSONフォーマットされた文字列が表示される                | ユニットテスト |

| AC-014 | NFR-004 | Tabキーでフォーカスがダイアログ内のインタラクティブ要素間を循環する                  | ユニットテスト |
| AC-015 | NFR-005 | Escapeキー押下で拒否操作が実行される                                                 | ユニットテスト |

## 検証方法

- **AC-001〜AC-015**: Vitest + @testing-library/react によるユニットテスト
- **NFR-006 (コントラスト比)**: Tailwind CSSデフォルトカラー使用により保証
- **NFR-007 (パフォーマンス)**: React標準レンダリングのため追加計測不要
- **NFR-011 (XSS防止)**: React JSXの自動エスケープにより保証、テストで確認
