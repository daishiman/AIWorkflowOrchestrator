## 1. スコープ内（In Scope）

### 1.1 修正対象コンポーネント

| コンポーネント     | ファイル                                                     | 修正内容                                   |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------ |
| SkillImportManager | `apps/desktop/src/main/services/skill/SkillImportManager.ts` | 型検証追加、ミューテックス導入、Logger導入 |
| SkillService       | `apps/desktop/src/main/services/skill/SkillService.ts`       | 孤立ID処理の追加、DEBUGログ削除            |

### 1.2 対処する問題

| 問題ID | 問題                                     | 対処方法                         |
| ------ | ---------------------------------------- | -------------------------------- |
| P1     | スキャンキャッシュとインポートIDの不整合 | 孤立ID検出とWARNログ出力         |
| P2     | 並列アクセスでのキャッシュ競合           | async-mutexによる排他制御        |
| P3     | store初期化での予期しない型返却          | Zodによるランタイム型検証        |
| P4     | DEBUGログ形式の問題                      | Loggerクラス導入とログレベル制御 |
| P5     | エラーレスポンスの一貫性問題             | IPCResult形式への統一            |

| 統合       | skillHandlers      | `apps/desktop/src/main/ipc/__tests__/skillHandlers.test.ts`                 |

### 1.4 追加する依存パッケージ

## 4. 成功基準

### 4.1 必須達成項目

1. **バグ修正**: インポートしたスキルがアプリ再起動後も保持される
2. **堅牢性**: ストア破損時でもクラッシュせず復旧する
3. **テスト**: Line Coverage 80%以上を達成
4. **品質**: Lint/型チェックがすべてPASS

### 4.2 推奨達成項目

1. **ログ整備**: DEBUGログが本番で出力されない
2. **コード品質**: エラーレスポンス形式の統一
3. **ドキュメント**: 実装ガイドの更新
