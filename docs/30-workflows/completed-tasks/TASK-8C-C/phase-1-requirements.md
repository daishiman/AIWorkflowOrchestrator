## 目的

スキルインポートと実行のE2Eテストの要件を明確化し、6つのテストケースの受け入れ基準を定義する。

## 実行タスク

- 要件抽出: 元タスク仕様書（TASK-8C-C）から機能要件・非機能要件を抽出
- 受け入れ基準作成: 6つのテストケースに対する検証可能な受け入れ基準を定義
- テスト対象特定: インポートフローと実行フローの検証対象を明確化

## 実行手順

### ステップ1: 機能要件の抽出

元タスク仕様書から6つのテストケースの機能要件を抽出する。

| TC   | テストケース名           | 検証対象                                 |
| ---- | ------------------------ | ---------------------------------------- |
| TC-1 | インポートダイアログ表示 | 未インポートスキル選択時のダイアログ表示 |
| TC-2 | スキル詳細表示           | インポートダイアログ内の詳細情報表示     |
| TC-3 | インポート実行           | インポートボタン押下後の状態変更         |
| TC-4 | ストリーミング表示       | スキル実行中のストリーミングビュー表示   |
| TC-5 | 停止ボタン表示           | 実行中の停止ボタン表示                   |
| TC-6 | 実行中止                 | 停止ボタン押下後のキャンセル状態         |

### ステップ2: 非機能要件の抽出

| 要件カテゴリ     | 要件                                    |
| ---------------- | --------------------------------------- |
| パフォーマンス   | 各テストケースは10秒以内に完了          |
| 再現性           | テスト結果は実行環境に依存しない        |
| 独立性           | 各テストケースは他のテストに依存しない  |
| フィクスチャ依存 | TASK-8C-Eで作成されたフィクスチャを使用 |

### ステップ3: 受け入れ基準の定義

| TC   | 受け入れ基準                                                         |
| ---- | -------------------------------------------------------------------- |
| TC-1 | 未インポートスキル選択→インポートボタン押下→ダイアログ表示           |
| TC-2 | ダイアログ内に「許可ツール」「サブエージェント」セクションが表示     |
| TC-3 | インポート完了後、ダイアログが閉じ「インポート済み」セクションに追加 |
| TC-4 | スキル実行開始後、`data-testid="skill-streaming-view"`が表示         |
| TC-5 | 実行中に「停止」ボタンが表示される                                   |
| TC-6 | 停止ボタン押下後、「キャンセル」ステータスが表示される               |
