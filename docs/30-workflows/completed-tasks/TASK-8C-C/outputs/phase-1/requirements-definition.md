## 機能要件

### テストケース一覧

| TC   | テストケース名           | 検証対象                                 | カテゴリ       |
| ---- | ------------------------ | ---------------------------------------- | -------------- |
| TC-1 | インポートダイアログ表示 | 未インポートスキル選択時のダイアログ表示 | Import Flow    |
| TC-2 | スキル詳細表示           | インポートダイアログ内の詳細情報表示     | Import Flow    |
| TC-3 | インポート実行           | インポートボタン押下後の状態変更         | Import Flow    |
| TC-4 | ストリーミング表示       | スキル実行中のストリーミングビュー表示   | Execution Flow |
| TC-5 | 停止ボタン表示           | 実行中の停止ボタン表示                   | Execution Flow |
| TC-6 | 実行中止                 | 停止ボタン押下後のキャンセル状態         | Execution Flow |
| TC-7 | 再スキャン実行           | スキャン状態・一覧更新                   | Rescan Flow    |

### TC-1: インポートダイアログ表示

| 項目     | 内容                                             |
| -------- | ------------------------------------------------ |
| 目的     | 未インポートスキル選択時にダイアログが表示される |
| 前提条件 | アプリが起動している                             |
| 操作     | スキル選択ボタン→インポートボタン                |
| 期待結果 | 「スキルをインポート」ダイアログが表示           |

### TC-2: スキル詳細表示

| 項目     | 内容                                         |
| -------- | -------------------------------------------- |
| 目的     | インポートダイアログ内で詳細情報が表示される |
| 前提条件 | インポートダイアログが表示されている         |
| 操作     | ダイアログ内容を確認                         |
| 期待結果 | 「許可ツール」「サブエージェント」が表示     |

### TC-3: インポート実行

| 項目     | 内容                                                |
| -------- | --------------------------------------------------- |
| 目的     | インポート完了後、スキルがインポート済みになる      |
| 前提条件 | インポートダイアログが表示されている                |
| 操作     | 「インポート」ボタンをクリック                      |
| 期待結果 | ダイアログ閉じる→「インポート済み」セクションに追加 |

### TC-4: ストリーミング表示

| 項目     | 内容                                     |
| -------- | ---------------------------------------- |
| 目的     | スキル実行中にストリーミングビューが表示 |
| 前提条件 | test-skillがインポート済み               |
| 操作     | スキル選択→プロンプト入力→Enter          |
| 期待結果 | skill-streaming-viewが表示               |

### TC-5: 停止ボタン表示

| 項目     | 内容                     |
| -------- | ------------------------ |
| 目的     | 実行中に停止ボタンが表示 |
| 前提条件 | スキルが実行中           |
| 操作     | 実行状態を確認           |
| 期待結果 | 「停止」ボタンが表示     |

### TC-6: 実行中止

| 項目     | 内容                                   |
| -------- | -------------------------------------- |
| 目的     | 停止ボタン押下で実行がキャンセルされる |
| 前提条件 | スキルが実行中                         |
| 操作     | 「停止」ボタンをクリック               |
| 期待結果 | 「キャンセル」ステータスが表示         |

### TC-7: 再スキャン実行

| 項目     | 内容                           |
| -------- | ------------------------------ |
| 目的     | 再スキャンでスキル一覧が更新   |
| 前提条件 | スキル選択UIが表示されている   |
| 操作     | 「再スキャン」ボタンをクリック |
| 期待結果 | 「スキャン中」→一覧更新        |

## 非機能要件

| 要件カテゴリ     | 要件                                    |
| ---------------- | --------------------------------------- |
| パフォーマンス   | 各テストケースは10秒以内に完了          |
| 再現性           | テスト結果は実行環境に依存しない        |
| 独立性           | 各テストケースは他のテストに依存しない  |
| フィクスチャ依存 | TASK-8C-Eで作成されたフィクスチャを使用 |
| テスト実行時間   | 全テスト合計で60秒以内                  |
