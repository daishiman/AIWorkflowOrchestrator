## 詳細受け入れ基準

### AC-1: インポートダイアログ表示

**Given**: アプリケーションが起動している
**When**: ユーザーが以下の操作を行う

1. スキル選択ボタン（`[aria-label="スキルを選択"]`）をクリック
2. インポートボタン（`[data-testid="import-skill-button"]`）をクリック

**Then**: 「スキルをインポート」というテキストを含むダイアログが表示される

### AC-2: スキル詳細表示

**Given**: インポートダイアログが表示されている
**When**: ダイアログ内容を確認する
**Then**:

- 「許可ツール」セクションが表示される
- 「サブエージェント」セクションが表示される

### AC-3: インポート実行

**Given**: インポートダイアログが表示されている
**When**: 「インポート」ボタンをクリックする
**Then**:

1. ダイアログが閉じる（`state: "hidden"`）
2. スキル選択UIを開くと「インポート済み」セクションにスキルが表示される

### AC-4: ストリーミング表示

**Given**: test-skillがインポート済み
**When**: ユーザーが以下の操作を行う

1. スキルを選択
2. プロンプトを入力
3. Enterキーを押下

**Then**: `[data-testid="skill-streaming-view"]`要素が表示される

### AC-5: 停止ボタン表示

**Given**: スキルが実行中
**When**: UI状態を確認する
**Then**: 「停止」というテキストを持つボタンが表示される

### AC-6: 実行中止

**Given**: スキルが実行中
**When**: 「停止」ボタンをクリックする
**Then**: 「キャンセル」というテキストが表示される

### AC-7: 再スキャン実行

**Given**: スキル選択UIが表示されている
**When**: 「再スキャン」ボタンをクリックする
**Then**:

1. 「スキャン中」というテキストが表示される
2. スキャン完了後、スキル一覧が更新される

## 検証方法

| AC   | 検証方法                      | セレクタ/条件                                  |
| ---- | ----------------------------- | ---------------------------------------------- |
| AC-1 | locator.toBeVisible()         | `text="スキルをインポート"`                    |
| AC-2 | locator.toBeVisible()         | `text="許可ツール"`, `text="サブエージェント"` |
| AC-3 | waitForSelector + toBeVisible | `text="インポート済み"`                        |
| AC-4 | locator.toBeVisible()         | `[data-testid="skill-streaming-view"]`         |
| AC-5 | locator.toBeVisible()         | `button:has-text("停止")`                      |
| AC-6 | locator.toBeVisible()         | `text="キャンセル"`                            |
| AC-7 | waitForSelector + toBeVisible | `text="スキャン中"`, `[role="listbox"]`        |

## 非機能受け入れ基準

| カテゴリ       | 基準                       | 検証方法             |
| -------------- | -------------------------- | -------------------- |
| パフォーマンス | 各テストケース10秒以内完了 | Vitest timeout設定   |
| 再現性         | 5回連続実行で結果が同一    | CI/CDパイプライン    |
| 独立性         | 単体実行でも結果が同一     | `-t`オプションで検証 |
| テスト総時間   | 全テスト60秒以内           | テスト実行ログ確認   |
