## スコープ内

### 新規フィクスチャ（6種類）

| フィクスチャ           | 目的                         | 配置先                                                   |
| ---------------------- | ---------------------------- | -------------------------------------------------------- |
| boundary-skill/        | 境界値テスト用               | `apps/desktop/src/__tests__/__fixtures__/skill-creator/` |
| missing-fields-skill/  | 必須フィールド欠落テスト用   | 同上                                                     |
| forbidden-files-skill/ | 禁止ファイル検出テスト用     | 同上                                                     |
| invalid-name-skill/    | 名前フォーマット違反テスト用 | 同上                                                     |
| empty-agents-skill/    | 空agentsディレクトリテスト用 | 同上                                                     |
| invalid-schema-skill/  | 不正スキーマテスト用         | 同上                                                     |

### テストケース拡張

| 項目             | 内容                                                                |
| ---------------- | ------------------------------------------------------------------- |
| 対象ファイル     | `apps/desktop/src/__tests__/fixtures/skill-creator.fixture.test.ts` |
| 新規テストケース | 34件（TC-063~TC-096）                                               |
| 既存テストケース | 62件（TC-001~TC-062）維持                                           |
| テスト品質改善   | D カテゴリ（D1, D2, D3）対応                                        |

### テストヘルパー関数

| 関数名                  | 用途                             |
| ----------------------- | -------------------------------- |
| `parseValidationOutput` | JSON出力のパース                 |
| `getExitCode`           | EXIT_CODEの取得                  |
| `fixtureDir`            | フィクスチャディレクトリパス解決 |

## スコープ外

| 項目                                         | 理由                                    |
| -------------------------------------------- | --------------------------------------- |
| 検証スクリプト本体のロジック変更             | テスト追加のみが対象                    |
| skill-creator スキル本体の変更               | テストフィクスチャのみが対象            |
| E2Eテストフィクスチャの変更                  | skill-creator専用フィクスチャのみが対象 |
| TASK-8C-Fで作成済み5種類のフィクスチャの変更 | 既存フィクスチャは不変                  |
