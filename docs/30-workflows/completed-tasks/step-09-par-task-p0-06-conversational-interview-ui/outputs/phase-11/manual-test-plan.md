# Manual Test Plan — Phase 11 TASK-P0-06

## 前提条件

1. `pnpm install` 実行済み
2. `pnpm --filter @repo/desktop dev` でデスクトップアプリ起動
3. スキル作成ワークフローを開始できる状態

## 手動テスト手順

### MT-01: 会話型UIの基本表示

1. スキル作成画面を開く
2. ワークフローを開始する
3. **確認**: チャットバブル形式で質問が表示されること
4. **確認**: 左側にアシスタントメッセージ（質問）が表示されること
5. **確認**: プログレスバーが上部に表示されること

### MT-02: single_select 操作

1. single_select 型の質問が表示された状態で
2. 選択チップの1つをクリック
3. **確認**: 選択されたチップが視覚的にハイライトされること
4. 「送信」ボタンをクリック
5. **確認**: 右側にユーザーの回答バブルが表示されること
6. **確認**: 次の質問が表示されること

### MT-03: multi_select 操作

1. multi_select 型の質問が表示された状態で
2. 複数のチェックボックスを選択
3. **確認**: 選択状態が視覚的に反映されること
4. 「送信」ボタンをクリック
5. **確認**: 選択した項目がカンマ区切りで回答バブルに表示されること

### MT-04: free_text 操作

1. free_text 型の質問が表示された状態で
2. テキストエリアにテキストを入力
3. Enter キーを押す
4. **確認**: テキストが送信されること
5. Shift+Enter で改行できることを確認

### MT-05: confirm 操作

1. confirm 型の質問が表示された状態で
2. 「はい」ボタンをクリック
3. **確認**: 即座に送信されること（送信ボタン不要）
4. Y キーを押しても同様に動作することを確認

### MT-06: secret 操作

1. secret 型の質問が表示された状態で
2. パスワードフィールドに入力
3. **確認**: 入力値がマスクされていること
4. 目のアイコンをクリック
5. **確認**: 入力値が表示/非表示で切り替わること

### MT-07: undo 操作

1. 1つ以上の質問に回答済みの状態で
2. 「← 戻る」ボタンをクリック
3. **確認**: 最後の回答が取り消され、前の質問が再表示されること
4. 最初の質問まで戻った状態で「← 戻る」が無効化されていることを確認

### MT-08: 熟練度切替

1. 「初心者」モードで質問を確認
2. **確認**: ヒントテキストが表示されていること
3. 「エンジニア」ボタンをクリック
4. **確認**: ヒントテキストが非表示になること

### MT-09: バリデーション

1. single_select で未選択のまま「送信」をクリック
2. **確認**: バリデーションエラーメッセージが表示されること
3. free_text で空のまま Enter を押す
4. **確認**: 送信されないこと
