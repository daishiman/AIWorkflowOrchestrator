## inferSmartDefaults エラー時フォールバック確認

- `inferSmartDefaults` は純粋関数であり、通常は例外を投げない
- ただし将来の非同期化に備え `try/catch` パターンを `handleStep0Next` に適用済み
- エラー時は `setSmartDefaults(null)` → `ConversationRoundStep` は `DEFAULT_SMART_DEFAULTS`（全フィールド null）で動作
- UX への影響: スマートデフォルトが適用されないが、ユーザーは手動で選択できるため問題なし
