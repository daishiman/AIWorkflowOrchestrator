## 受け入れ基準一覧

### AC-1: スクリプト実行可能性

| 項目     | 内容                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| ID       | AC-1                                                                                     |
| 対応要件 | FR-6, NFR-2                                                                              |
| 基準     | `scripts/verify-ipc-4layer.js` が存在し、`node scripts/verify-ipc-4layer.js` で実行可能  |
| 検証方法 | `node scripts/verify-ipc-4layer.js` をプロジェクトルートで実行し、エラーなく完了すること |
| 合格条件 | exit code が 0 または 1 であること（2以上はスクリプトエラー）                            |

### AC-2: shared -> preload 未登録チャネル検出

| 項目     | 内容                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| ID       | AC-2                                                                                  |
| 対応要件 | FR-1                                                                                  |
| 基準     | shared channels に存在し preload whitelist に未登録のチャネルを検出してエラー出力する |
| 検証方法 | テスト用に shared に仮チャネルを追加し、preload whitelist に追加しない状態で実行する  |
| 合格条件 | 未登録チャネルがエラーとして stderr に出力されること                                  |

**テストシナリオ**:

1. テスト用の shared channels ファイルに `"test:channel-x"` を追加
2. preload whitelist には追加しない
3. スクリプト実行
4. 出力に `test:channel-x` が Rule-1 違反として報告される

### AC-3: preload -> main 未実装チャネル検出

| 項目     | 内容                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| ID       | AC-3                                                                                       |
| 対応要件 | FR-2                                                                                       |
| 基準     | preload invoke whitelist に存在し main handler に未実装のチャネルを検出してエラー出力する  |
| 検証方法 | テスト用に preload whitelist に仮チャネルを追加し、main handler に追加しない状態で実行する |
| 合格条件 | 未実装チャネルがエラーとして stderr に出力されること                                       |

**テストシナリオ**:

1. テスト用の preload whitelist に `"test:unhandled"` を追加
2. main handler には追加しない
3. スクリプト実行
4. 出力に `test:unhandled` が Rule-2 違反として報告される

### AC-4: renderer -> shared 未定義チャネル検出

| 項目     | 内容                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| ID       | AC-4                                                                                |
| 対応要件 | FR-3                                                                                |
| 基準     | renderer sink で使用され shared channels に未定義のチャネルを検出してエラー出力する |
| 検証方法 | テスト用の preload safeInvoke に shared 未定義のチャネルを追加して実行する          |
| 合格条件 | 未定義チャネルがエラーとして stderr に出力されること                                |

**テストシナリオ**:

1. テスト用の renderer 使用チャネルに `"unknown:channel"` を追加
2. shared channels には追加しない
3. スクリプト実行
4. 出力に `unknown:channel` が Rule-3 違反として報告される

### AC-5: 全整合時の正常終了

| 項目     | 内容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| ID       | AC-5                                                                   |
| 対応要件 | FR-4                                                                   |
| 基準     | 全チャネルが4層で整合している場合は exit code 0 で正常終了する         |
| 検証方法 | 現状のコードベースで不整合がない状態（テスト用フィクスチャ）で実行する |
| 合格条件 | exit code 0、stdout にサマリー出力                                     |

### AC-6: 不整合時のCI失敗

| 項目     | 内容                                        |
| -------- | ------------------------------------------- |
| ID       | AC-6                                        |
| 対応要件 | FR-4                                        |

| 検証方法 | 意図的に不整合を作成した状態で実行する      |
| 合格条件 | exit code 1、stderr にエラー詳細            |
