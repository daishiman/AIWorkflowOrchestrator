## 計測コマンドの最適化記録

| 観点                             | 内容                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `gh run view --json jobs` の制限 | `createdAt` フィールドが存在しない。REST API（`gh api .../jobs`）を使用する必要がある                   |
| Python フォールバック            | 今回は Python が利用可能だったため不要。`gh run view --json jobs` の `createdAt` 非対応の代替として有効 |
| `--paginate` の必要性            | 26 ジョブのため 1 ページで完結。ただし大規模 Run では `--paginate` が必須                               |
| jq vs Python                     | `fromdateiso8601` は jq 1.6+ 対応。REST API 利用時は Python の方が確実で移植性が高い                    |
