## 目的

TASK-CI-OPT-001 Phase 3 の MINOR 指摘 CI-M-01（シャード数 17 でのキューイング時間未確認）を解決するため、
計測スコープ・前提条件・検証可能な完了基準（AC-1〜AC-5）を定義する。

## 実行タスク

### Task 1: 真の論点の固定

**現状の問題**

TASK-CI-OPT-001 によりシャード数が 16→17 に変更された。
第2波ジョブ一斉起動時の同時ジョブ数：

```
test-desktop × 17 + typecheck × 1 + test-shared × 1 + e2e × 1 = 20 ジョブ
```

GitHub Free Tier の並列実行上限はちょうど 20 ジョブ。理論上は範囲内だが、
GitHub Actions のジョブスケジューリングは内部実装依存であり、実測確認が必要。

**真の論点**

「シャード数 17 において GitHub Actions のキューイングが実際に発生するか、
発生する場合のキューイング時間が許容範囲（60 秒以内）か」が未検証のまま運用されている。

**TASK-CI-OPT-001 との連携**

本タスクは TASK-CI-OPT-001 Phase 3 設計レビューゲートの MINOR 指摘（CI-M-01）を解決する。
`docs/30-workflows/completed-tasks/task-ci-optimization-001/phase-3-design-review.md` の MINOR 追跡テーブルに
「実測後に 16 への調整を検討」として記録済み。

### Task 2: 前提条件・依存関係の確認

| 前提条件                                                             | 確認方法                                       |
| -------------------------------------------------------------------- | ---------------------------------------------- |
| TASK-CI-OPT-001 の PR がマージされ、シャード数 17 が main に反映済み | `git log --oneline origin/main` で確認         |
| main ブランチで少なくとも 1 回の CI 実行が完了している               | `gh run list --branch main --status completed` |
| `gh` CLI がインストール済みでリポジトリへのアクセス権限がある        | `gh auth status`                               |

**重要**: TASK-CI-OPT-001 の PR マージ前は本タスクを実行してはならない。

### Task 3: 計測アプローチの決定

**採用アプローチ**: `gh run view <run-id> --json jobs` で取得できる各ジョブの
`createdAt`（キューに投入された時刻）と `startedAt`（実行開始時刻）の差分でキューイング時間を算出。

**判定基準**:

| 計測結果                     | 判定                 | 次のアクション                    |
| ---------------------------- | -------------------- | --------------------------------- |
| 最大キューイング時間 ≤ 60 秒 | シャード数 17 継続   | 継続判定を記録して完了            |
| 最大キューイング時間 > 60 秒 | シャード数 16 に戻す | Phase 13 で ci.yml 変更 PR を作成 |

### Task 4: 受入条件の確定

| ID   | 条件                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| AC-1 | TASK-CI-OPT-001 マージ後の完了済み CI Run ID が特定されている                     |
| AC-2 | 17 シャード全ての `createdAt`・`startedAt` を取得し最大キューイング時間を算出済み |
| AC-3 | 最大キューイング時間が 60 秒以内 or 超過かの判定を確定済み                        |
| AC-4 | 判定結果に基づくアクション（継続 or 16 への戻し）を完了済み                       |
| AC-5 | TASK-CI-OPT-001 の CI-M-01 指摘が「解決済み」として記録されている                 |

### Task 5: スコープ境界の定義

**含む**:

- TASK-CI-OPT-001 の PR マージ後の CI 実行ログでキューイング時間を計測
- 計測結果に基づくシャード数の最終決定（継続 or 16 への戻し）
- キューイング時間 1 分超の場合の `.github/workflows/ci.yml` 変更 PR 作成
- 判定結果の記録

**含まない**:

- シャード数 17 以外の CI 設定変更
- CI アーキテクチャの変更
- node_modules キャッシュや CI_MAX_FORKS 設定の変更
- TASK-CI-OPT-001 の実装変更

### Task 6: タスク分類の確認（Phase 1 必須チェック）

| 分類項目    | 判定            | 根拠                                          |
| ----------- | --------------- | --------------------------------------------- |
| UI task     | NO              | UI コンポーネントへの変更なし                 |
| docs-only   | YES（条件付き） | 計測のみの場合はドキュメント更新のみ          |

| NON_VISUAL  | YES             | CI ログ確認・コマンド実行タスク               |
