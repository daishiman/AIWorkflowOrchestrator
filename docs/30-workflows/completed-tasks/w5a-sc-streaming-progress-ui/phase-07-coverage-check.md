## 目的

`GenerateStep.tsx` および関連 Hook のテストカバレッジが基準値（Line 80% / Branch 60% / Function 80%）を充足していることを確認する。未達の場合は Phase 6 に戻る。

## 背景

Phase 6 でテストを拡充したが、カバレッジ基準を実際に満たしているかは計測しなければ分からない。本Phaseではカバレッジを計測し、基準達成のゲート判定を行う。未達の場合はPhase 6 に戻りテストを追加する。

## 実行タスク

### タスク1: カバレッジ計測の実行

**目的**: 対象ファイルのカバレッジを計測する

**実行手順**:

1. P40（Vitest実行パス）対策: 対象パッケージのディレクトリから実行する
2. 以下のコマンドを実行する:
   ```bash
   cd apps/desktop && pnpm vitest run --coverage src/renderer/components/skill/wizard/GenerateStep.tsx src/renderer/hooks/useGenerationProgress.ts src/renderer/hooks/useCancelGeneration.ts
   ```
3. カバレッジレポートの出力を保存する

**期待される成果物**:

- カバレッジレポート（テキスト出力）

### タスク2: カバレッジレポートの確認

**目的**: 3指標が基準値を満たしているかを判定する

**実行手順**:

1. Line Coverage: 80%以上であることを確認する
2. Branch Coverage: 60%以上であることを確認する
3. Function Coverage: 80%以上であることを確認する

**期待される成果物**:

- 各指標の実測値の記録

### タスク3: 未達箇所の特定

**目的**: カバレッジが基準未達の場合に、追加テストが必要な箇所を特定する

**実行手順**:

1. Branch Coverage が低い場合: エラーパスの分岐が未テストの可能性が高いため、未テストの分岐を特定する
2. Function Coverage が低い場合: P41（v8カバレッジ）対策としてインライン関数のカウントに注意しながら未テスト関数を特定する
3. 未達箇所をリスト化する

**期待される成果物**:

- 未達箇所のリスト（未達の場合のみ）

### タスク4: ゲート判定

**目的**: Phase 8 への進行可否を判定する

**実行手順**:

1. 全指標が基準値以上の場合: PASS と記録し Phase 8 へ進む
2. いずれかが未達の場合: Phase 6 に戻り追加テストを作成する
3. 最大イテレーション: 2回。3回目は未達項目をMINOR指摘として未タスク仕様書に変換し、Phase 8 へ進む

**期待される成果物**:

- ゲート判定結果の記録（PASS / Phase 6 へ戻る / MINOR指摘として記録しPhase 8 へ進む）
