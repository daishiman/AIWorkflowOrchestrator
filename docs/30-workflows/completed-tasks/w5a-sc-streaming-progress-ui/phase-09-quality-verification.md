## 目的

Lint・型チェック・全テスト実行の3点セットで品質を最終検証し、Phase 10 最終レビューに進める状態であることを確認する。

## 背景

Phase 8 でリファクタリングを実施した結果、コード構造が大幅に変更されている。構造変更に伴い、Lint違反・型エラー・テスト回帰が発生していないことを網羅的に検証する必要がある。本Phaseで品質ゲートを通過することで、Phase 10 の最終レビューを効率的に進められる状態を担保する。

## 実行タスク

### タスク1: ESLint 実行

**目的**: コーディング規約違反を検出・修正する

**実行手順**:

1. コマンド: `pnpm --filter @repo/desktop lint`
2. エラー・警告が 0 件であることを確認する
3. 未使用 import の排除（`no-unused-vars` ルール）

**期待される成果物**:

- ESLint 実行結果（エラー 0 件・警告 0 件）

### タスク2: TypeScript 型チェック

**目的**: 型安全性を検証する

**実行手順**:

1. コマンド: `pnpm --filter @repo/desktop typecheck`
2. `any` 型・型アサーション（`as`）の不適切な使用がないことを確認する
3. エラー 0 件であることを確認する

**期待される成果物**:

- TypeScript 型チェック結果（エラー 0 件）

### タスク3: 全テスト実行

**目的**: 全テストが PASS し、リグレッションがないことを確認する

**実行手順**:

1. P40（Vitest実行パス）: 対象パッケージディレクトリから実行
2. コマンド: `cd apps/desktop && pnpm vitest run`
3. 新規追加テストが全て PASS であることを確認する
4. 既存テストへの影響がないことを確認する（リグレッション確認）

**期待される成果物**:

- テスト実行結果（全 PASS）

### タスク4: 品質チェックリスト確認

**目的**: コード品質の最終確認を行う

**実行手順**:

1. `any` 型が使われていないことを確認する
2. `@ts-ignore` / `@ts-expect-error` が使われていないことを確認する（使う場合は理由コメント必須）
3. 未使用 import がないことを確認する
4. boolean 変数名に `is` / `has` / `can` / `should` プレフィックスが使われていることを確認する

**期待される成果物**:

- 品質チェックリスト確認結果
