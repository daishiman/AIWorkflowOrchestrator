## 目的

実際のElectronアプリを操作し、ストリーミング進捗UIが正しく動作することを手動で確認する。P53（スクリーンショット制約）: CLI環境ではPlaywright `page.screenshot()` を代替使用する。

## 背景

Phase 10 の最終レビューで AC-3（進捗ストリーミング）・AC-6（エラーメッセージ）の技術的充足が確認された。Phase 11 では、自動テストでは検出困難な視覚的・体験的な問題を人手で検証し、ユーザー目線での品質を担保する。

## 実行タスク

### タスク1: スキル生成中のプログレスバー動作確認

**目的**: プログレスバーが生成進捗に応じて正しくアニメーションすることを視覚的に確認する。

**実行手順**:

1. スキル生成ウィザードを開き、最終ステップ（GenerateStep）に進む
2. 生成開始後、プログレスバーが 0% から動き始めることを確認する
3. 各段階（構造計画中→SKILL.md生成中→agents生成中→バリデーション中）でステップ表示が更新されることを確認する
4. 生成完了時にプログレスバーが 100% になることを確認する

**期待される成果物**:

- プログレスバー動作のスクリーンショットまたは代替証跡

### タスク2: エラー時のリトライボタン表示確認

**目的**: LLMエラー発生時に適切なエラーUIとリトライ機能が表示されることを確認する。

**実行手順**:

1. LLMエラーをシミュレートする（テスト用の不正APIキーを使用）
2. エラーメッセージとリトライボタンが表示されることを確認する
3. リトライボタン押下で生成が再試行されることを確認する

**期待される成果物**:

- エラーUI表示のスクリーンショットまたは代替証跡

### タスク3: キャンセルで中断されることの確認

**目的**: 生成中のキャンセル操作が正しく機能することを確認する。

**実行手順**:

1. スキル生成中にキャンセルボタンを押す
2. 生成が中断され、「キャンセルしました」メッセージが表示されることを確認する
3. ウィザードが先頭ステップに戻ること（または閉じること）を確認する

**期待される成果物**:

- キャンセル動作のスクリーンショットまたは代替証跡

### タスク4: API Key 未設定時の設定画面誘導確認

**目的**: API Key 未設定のエッジケースで適切な誘導UIが表示されることを確認する。

**実行手順**:

1. API Key を削除した状態でスキル生成を試みる
2. 設定画面への誘導リンク付きエラーメッセージが表示されることを確認する
3. リンク押下で設定画面が開くことを確認する

**期待される成果物**:

- API Key未設定時のエラーUI表示のスクリーンショットまたは代替証跡

### タスク5: P53対策 - CLI環境での代替検証

**目的**: CLI環境でスクリーンショットが直接取得できない場合の代替検証方法を実施する。

**実行手順**:

1. スクリーンショットが取得できない場合は、Playwright の `page.screenshot()` を使用する
2. または、自動テストの実行ログを視覚確認の代替証跡とする

**期待される成果物**:

- 代替証跡ファイル（Playwrightスクリーンショットまたはテスト実行ログ）

## 統合テスト連携

手動テストは自動テスト（Phase 4-6）では検出困難な視覚的・体験的品質を補完する。具体的には以下の観点で自動テストと相互補完する:

- **プログレスバーのアニメーション品質**: 自動テストでは DOM 状態のみ検証。手動テストで滑らかさ・視認性を確認
- **エラーUIの分かりやすさ**: 自動テストではメッセージ存在のみ検証。手動テストでユーザー理解性を確認
- **キャンセル操作のレスポンス**: 自動テストではイベント発火のみ検証。手動テストで体感速度を確認
