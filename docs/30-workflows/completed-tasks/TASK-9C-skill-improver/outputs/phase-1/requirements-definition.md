# TASK-9C 要件定義書

## メタ情報

| 項目   | 値                               |
| ------ | -------------------------------- |
| タスク | TASK-9C スキル改善・自動修正機能 |
| 作成日 | 2026-02-03                       |
| Phase  | 1                                |

## 目的

スキルの品質分析・改善提案・自動修正・プロンプト最適化機能を提供し、ユーザーが「このスキルを改善して」と指示するだけでAIがスキルを自動的に改善できるようにする。

---

## 機能要件（FR）

| FR-ID | 要件                                      | 優先度 | 説明                                                                                        |
| ----- | ----------------------------------------- | ------ | ------------------------------------------------------------------------------------------- |
| FR-01 | スキル構造・品質の分析機能                | 必須   | SkillAnalyzer.analyze()でスキルの静的分析とAI分析を実行し、スコアと改善提案を生成           |
| FR-02 | 分析結果に基づく改善提案生成              | 必須   | 分析結果に suggestions[] を含め、type/priority/description/autoFixable を提供               |
| FR-03 | 自動修正の実行（ユーザー確認/自動モード） | 必須   | SkillImprover.applyImprovements()で改善を適用。autoFix オプションで自動/手動選択可能        |
| FR-04 | プロンプト最適化機能                      | 必須   | PromptOptimizer.optimize()でプロンプトの明確性・具体性・網羅性を向上                        |
| FR-05 | 改善前バックアップ作成                    | 必須   | 改善適用前に元ファイルのバックアップを作成し、エラー時にロールバック可能                    |
| FR-06 | 改善結果の検証・テスト                    | 必須   | 改善後のスキルが正常に動作することを検証可能にする（構造チェック）                          |
| FR-07 | 複数バリアント生成（A/Bテスト用）         | 任意   | PromptOptimizer.generateVariants()で同一プロンプトの異なるバリアントを生成（A/Bテスト支援） |

---

## 非機能要件（NFR）

| NFR-ID | 要件                                     | 優先度 | 説明                                                                    |
| ------ | ---------------------------------------- | ------ | ----------------------------------------------------------------------- |
| NFR-01 | 分析処理は30秒以内に完了                 | 必須   | SkillAnalyzer.analyze()の実行時間を30秒以内に収める（ユーザー体験向上） |
| NFR-02 | 改善処理中のエラーからの復旧が可能       | 必須   | バックアップからの復元機能(restoreFromBackup)を提供し、データ損失を防止 |
| NFR-03 | TypeScript型安全性の確保                 | 必須   | 全エンティティ・IPCリクエスト/レスポンスに厳密な型定義、any型の使用禁止 |
| NFR-04 | 既存スキルサービスとの統合性             | 必須   | 既存のSkillService/skillHandlers.tsのパターンに準拠した設計・実装       |
| NFR-05 | Claude Agent SDK query() APIの正しい使用 | 必須   | SDK仕様に従った呼び出し（systemPrompt, maxTurns, JSON応答パース）       |
