## 目的

実際のアプリケーション上でチャット履歴機能の動作を手動で検証する。

## 背景

自動テストでは検出できないUI/UXの問題や、実際のユーザー操作フローでの問題を発見するため、手動テストを実施する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: テスト環境準備

**目的**: 手動テスト用の環境を準備する

**実行手順**:

1. アプリケーションをビルドする:

   ```bash
   pnpm --filter @repo/desktop build
   ```

2. アプリケーションを起動する:

   ```bash
   pnpm --filter @repo/desktop dev
   ```

3. フィーチャーフラグを確認する:
   - [ ] `USE_NEW_CHAT_HISTORY_ARCH` がONになっていること

4. テスト用データベースを初期化する:
   - [ ] 既存データをバックアップ（必要な場合）
   - [ ] テスト用の初期データを準備

**期待される成果物**:

- 起動したアプリケーション

---

### タスク2: 基本機能テスト

**目的**: チャット履歴の基本機能が動作することを確認する

**実行手順**:

1. セッション作成テスト:
   - [ ] 新規セッションを作成できる
   - [ ] セッションタイトルが正しく表示される
   - [ ] セッションがリストに追加される

2. メッセージ追加テスト:
   - [ ] ユーザーメッセージを送信できる
   - [ ] AIレスポンスが保存される
   - [ ] メッセージ履歴が正しく表示される

3. セッション一覧テスト:
   - [ ] セッション一覧が表示される
   - [ ] 最終更新日時でソートされる
   - [ ] プレビューが30文字以内で表示される

4. セッション選択テスト:
   - [ ] セッションを選択できる
   - [ ] 選択したセッションのメッセージが表示される

**期待される成果物**:

- `outputs/phase-11/basic-function-test-result.md` - 基本機能テスト結果

---

### タスク3: 編集機能テスト

**目的**: セッション・メッセージの編集機能が動作することを確認する

**実行手順**:

1. タイトル変更テスト:
   - [ ] セッションタイトルを変更できる
   - [ ] 変更がリストに反映される
   - [ ] 3文字未満のタイトルでエラーが表示される
   - [ ] 100文字を超えるタイトルでエラーが表示される

2. お気に入り機能テスト:
   - [ ] お気に入りに追加できる
   - [ ] お気に入りから解除できる
   - [ ] お気に入りフラグが保存される

3. ピン留め機能テスト:
   - [ ] ピン留めできる
   - [ ] ピン解除できる
   - [ ] ピン留め上限（10件）でエラーが表示される
   - [ ] ピン留めセッションが上部に表示される

**期待される成果物**:

- `outputs/phase-11/edit-function-test-result.md` - 編集機能テスト結果

---

### タスク4: 検索機能テスト

**目的**: FTS5検索機能が動作することを確認する

**実行手順**:

1. キーワード検索テスト:
   - [ ] タイトルで検索できる
   - [ ] メッセージ内容で検索できる
   - [ ] 検索結果が正しく表示される
   - [ ] 検索結果がスコア順でソートされる

2. フィルタ機能テスト:
   - [ ] お気に入りでフィルタできる
   - [ ] ピン留めでフィルタできる
   - [ ] 日付範囲でフィルタできる

3. 検索パフォーマンステスト:
   - [ ] 大量データ（100件以上）でも高速に検索できる
   - [ ] 検索結果の表示が遅延しない

**期待される成果物**:

- `outputs/phase-11/search-function-test-result.md` - 検索機能テスト結果

---

### タスク5: エクスポート機能テスト

**目的**: エクスポート機能が動作することを確認する

**実行手順**:

1. Markdownエクスポートテスト:
   - [ ] セッションをMarkdown形式でエクスポートできる
   - [ ] 出力ファイルが正しくフォーマットされている
   - [ ] メタデータが含まれている
   - [ ] メッセージが時系列順で出力される

2. JSONエクスポートテスト:
   - [ ] セッションをJSON形式でエクスポートできる
   - [ ] 出力ファイルが有効なJSONである
   - [ ] 全てのフィールドが含まれている

3. エクスポート対象選択テスト:
   - [ ] 単一セッションをエクスポートできる
   - [ ] 複数セッションを一括エクスポートできる（対応している場合）

**期待される成果物**:

- `outputs/phase-11/export-function-test-result.md` - エクスポート機能テスト結果

---

### タスク6: 削除機能テスト

**目的**: 削除機能が動作することを確認する

**実行手順**:

1. セッション削除テスト:
   - [ ] セッションを削除できる
   - [ ] 削除確認ダイアログが表示される
   - [ ] 削除後、リストから消える
   - [ ] 関連メッセージも削除される

2. ソフトデリートテスト（対応している場合）:
   - [ ] 削除フラグが設定される
   - [ ] 削除済みセッションが一覧に表示されない
   - [ ] 管理者機能で復元できる（対応している場合）

**期待される成果物**:

- `outputs/phase-11/delete-function-test-result.md` - 削除機能テスト結果

---

### タスク7: エラー処理テスト

**目的**: エラー発生時の挙動を確認する

**実行手順**:

1. バリデーションエラーテスト:
   - [ ] 無効なタイトルでエラーメッセージが表示される
   - [ ] 空のメッセージでエラーが表示される
   - [ ] 文字数制限超過でエラーが表示される

2. ネットワークエラーテスト（シミュレーション）:
   - [ ] DB接続エラー時に適切なエラーが表示される
   - [ ] リトライボタンが表示される（対応している場合）

3. 同時操作テスト:
   - [ ] 複数タブからの同時操作でデータ不整合が発生しない
   - [ ] 楽観的ロックが機能する（対応している場合）

**期待される成果物**:

- `outputs/phase-11/error-handling-test-result.md` - エラー処理テスト結果

---

### タスク8: リグレッションテスト

**目的**: 既存機能にリグレッションがないことを確認する

**実行手順**:

1. 既存ワークフローテスト:
   - [ ] 通常のチャット操作フローが動作する
   - [ ] 他の機能（設定、プロンプト管理等）に影響がない

2. データ互換性テスト:
   - [ ] 既存データが正しく読み込める
   - [ ] 新アーキテクチャで保存したデータが旧コードでも読める（フラグOFF時）

3. パフォーマンス比較テスト:
   - [ ] 操作レスポンスが悪化していない
   - [ ] メモリ使用量が増加していない

**期待される成果物**:

- `outputs/phase-11/regression-test-result.md` - リグレッションテスト結果

---

### タスク9: テスト結果サマリー作成

**目的**: 手動テスト結果を集約する

**実行手順**:

1. テスト結果を集計する:
   - 実施テスト数
   - 成功テスト数
   - 失敗テスト数
   - 未実施テスト数

2. 発見した問題を記録する:
   - 問題の重要度（Critical/Major/Minor）
   - 再現手順
   - 期待動作と実際の動作

3. 手動テスト完了判定を行う:
   - **PASS**: Critical問題なし、Major問題2件以下
   - **FAIL**: Critical問題あり、またはMajor問題3件以上

**期待される成果物**:

- `outputs/phase-11/manual-test-summary.md` - 手動テストサマリー
