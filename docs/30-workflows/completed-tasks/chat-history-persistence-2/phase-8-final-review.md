## レビューゲート

### レビュー結果判定

| 判定     | 条件                     | 次のアクション            |
| -------- | ------------------------ | ------------------------- |
| PASS     | 全レビュー観点で問題なし | 次のPhaseへ進行           |
| MINOR    | 軽微な指摘あり           | 指摘対応後、次のPhaseへ   |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻る      |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認 |

### 戻り先決定基準

| 問題の種類       | 戻り先                |
| ---------------- | --------------------- |
| 要件の問題       | Phase 1（要件定義）   |
| 設計の問題       | Phase 2（設計）       |
| テスト設計の問題 | Phase 4（テスト）     |
| 実装の問題       | Phase 5（実装）       |
| 品質の問題       | Phase 6（リファクタ） |

### レビュー観点

#### 要件充足確認

- [ ] 全機能要件が実装されている
- [ ] 非機能要件が満たされている
- [ ] スコープ外の機能が含まれていない

#### 設計準拠確認

- [ ] DBスキーマが設計通りである
- [ ] API仕様が設計通りである
- [ ] UIが設計通りである

#### コード品質確認

- [ ] 命名規則が統一されている
- [ ] コードスタイルが統一されている
- [ ] ドキュメントコメントが適切である

#### アーキテクチャ確認

- [ ] レイヤー間の依存関係が正しい
- [ ] 責務の分離が適切である
