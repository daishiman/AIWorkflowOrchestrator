## 目的

変更をコミットし、ユーザーの明示的な許可を得てからPull Requestを作成し、CIを確認する。

---

## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

---

## 実行タスク

| タスク               | 責務                                         |
| -------------------- | -------------------------------------------- |
| ローカル動作確認依頼 | ユーザーにローカルでの動作確認を依頼         |
| 変更サマリー提示     | 変更内容のサマリーを提示しPR作成の許可を確認 |
| PR作成               | ユーザーの許可後に`/ai:diff-to-pr`を実行     |
| CI確認               | CIが通過したことを確認                       |
| タスク移動           | タスクディレクトリをcompleted-tasksに移動    |

---

## 実行手順

### 1. ローカル確認チェックリスト【PR作成前に必須】

PR作成前に以下を**必ず**確認すること:

| #   | 確認項目             | コマンド例            | 結果 |
| --- | -------------------- | --------------------- | ---- |
| 1   | ビルドが成功する     | `pnpm build`          | [ ]  |
| 2   | 全テストがパスする   | `pnpm test`           | [ ]  |
| 3   | 型チェックがパスする | `pnpm typecheck`      | [ ]  |
| 4   | Lintエラーがない     | `pnpm lint`           | [ ]  |
| 5   | 実際の動作確認       | `pnpm dev` で手動確認 | [ ]  |

### 2. 変更サマリーの提示と許可確認【必須】

変更内容のサマリーを提示し、PRを作成してよいかユーザーに確認する。

**変更内容サマリー**:

| ファイル                                                | 変更内容                 |
| ------------------------------------------------------- | ------------------------ |
| `apps/desktop/src/preload/index.ts`                     | historyAPI公開追加       |
| `apps/desktop/src/renderer/global.d.ts`                 | Window型にHistoryAPI追加 |
| `apps/desktop/src/preload/__tests__/historyAPI.test.ts` | テストコード追加         |

**重要**: ユーザーから明示的な許可を得るまでPR作成を実行しないこと。

### 3. `/ai:diff-to-pr` を実行

ユーザーの許可を得た後、PR作成を実行する。

```
/ai:diff-to-pr
```

### 4. CI確認

- [ ] PRが作成されている
- [ ] CIが全て通過している

### 5. タスク完了処理

PRが作成され、CIが通過した後:

```bash
# タスクディレクトリをcompleted-tasksに移動
mv docs/30-workflows/history-preload-setup/ docs/30-workflows/completed-tasks/

# 未タスク指示書を削除（該当する場合）
rm docs/30-workflows/unassigned-task/task-history-preload-setup.md

# 変更をコミット
git add docs/30-workflows/
git commit -m "docs(workflows): history-preload-setupをcompleted-tasksに移動"
git push
```
