# 要件定義書: IPCチャンネル整理 (TASK-FIX-4-1-IPC-CONSOLIDATION)

## メタ情報

| 項目   | 値              |
| ------ | --------------- |
| Phase  | 1               |
| 作成日 | 2026-02-04      |
| 作成者 | Claude Opus 4.5 |

---

## 1. 概要

スキル機能のIPCチャンネルが段階的な開発（TASK-3, 4, 7, 9C）で増殖し、同じ機能に対して複数のチャンネルが存在している。本タスクでは仕様書準拠のIPCチャンネル体系を確立する。

---

## 2. 機能要件 (FR)

### FR-001: チャンネル名の統一

| 要件ID   | 要件                                                         | 優先度 |
| -------- | ------------------------------------------------------------ | ------ |
| FR-001-1 | 旧チャンネル`skill:list-available`を`skill:list`に統一       | 必須   |
| FR-001-2 | 旧チャンネル`skill:list-imported`を`skill:getImported`に統一 | 必須   |
| FR-001-3 | 仕様書定義の12チャンネルを正式サポート                       | 必須   |

### FR-002: ハードコード文字列の排除

| 要件ID   | 要件                                                              | 優先度 |
| -------- | ----------------------------------------------------------------- | ------ |
| FR-002-1 | `"skill:complete" as string`を`IPC_CHANNELS.SKILL_COMPLETE`に置換 | 必須   |
| FR-002-2 | `"skill:error" as string`を`IPC_CHANNELS.SKILL_ERROR`に置換       | 必須   |

### FR-003: 定義の一元化

| 要件ID   | 要件                                                                            | 優先度 |
| -------- | ------------------------------------------------------------------------------- | ------ |
| FR-003-1 | IPC_CHANNELS定義を`preload/channels.ts`に集約                                   | 必須   |
| FR-003-2 | `packages/shared/src/ipc/channels.ts`のスキル関連定義を削除または再エクスポート | 必須   |

---

## 3. 非機能要件 (NFR)

### NFR-001: セキュリティ

| 要件ID    | 要件                                              | 優先度 |
| --------- | ------------------------------------------------- | ------ |
| NFR-001-1 | ホワイトリストパターン（safeInvoke/safeOn）を維持 | 必須   |
| NFR-001-2 | sender検証を全ハンドラーで実施                    | 必須   |
| NFR-001-3 | ALLOWED_INVOKE_CHANNELS/ALLOWED_ON_CHANNELSを更新 | 必須   |

### NFR-002: 型安全性

| 要件ID    | 要件                          | 優先度 |
| --------- | ----------------------------- | ------ |
| NFR-002-1 | TypeScriptコンパイルエラー0件 | 必須   |
| NFR-002-2 | `as string`キャストの排除     | 必須   |

### NFR-003: 後方互換性

| 要件ID    | 要件                                           | 優先度 |
| --------- | ---------------------------------------------- | ------ |
| NFR-003-1 | 既存のRenderer側コードが動作すること           | 必須   |
| NFR-003-2 | 既存のテストが成功すること（または適切に更新） | 必須   |
