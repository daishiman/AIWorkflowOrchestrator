## 目的

TDD Refactor Phase: テストをパスした状態を維持しながら、コード品質を改善する。

## 背景

本タスクは定数定義のみの変更であるため、大規模なリファクタリングは不要。
主に以下の観点でコード品質を確認・改善:

- コメントの整合性
- 命名の一貫性
- グループ化の論理性

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コメントの整合性確認

**目的**: コメントが既存パターンと一貫しているか確認する

**実行手順**:

1. 追加したチャネルのコメントを確認する
2. 既存のコメントスタイルと比較する
3. 必要に応じて修正する

**確認観点**:

- [ ] コメントが日本語/英語で統一されているか
- [ ] グループコメントのスタイルが一貫しているか
- [ ] インラインコメントの位置が統一されているか

**期待される成果物**:

- コメント整合性チェックリスト

---

### タスク2: 命名の一貫性確認

**目的**: 命名規則が既存パターンと一致しているか確認する

**実行手順**:

1. 追加したチャネル定数名を確認する
2. 既存の命名パターンと比較する
3. 不整合があれば修正する

**確認観点**:

- [ ] 定数名がSCREAMING_SNAKE_CASEか
- [ ] チャネル値が`namespace:action`形式か
- [ ] 接頭辞`SKILL_`が一貫しているか

**期待される成果物**:

- 命名規則チェックリスト

---

### タスク3: グループ化の論理性確認

**目的**: チャネルのグループ化が論理的か確認する

**実行手順**:

1. 追加したチャネルの配置位置を確認する
2. 論理的なグループ分けになっているか確認する
3. 必要に応じて配置を調整する

**確認観点**:

- [ ] 同じ機能グループのチャネルが隣接しているか
- [ ] ホワイトリストの登録順が本体と一致しているか
- [ ] コメントでグループが明示されているか

**期待される成果物**:

- グループ化チェックリスト

---

### タスク4: テストの再実行と確認

**目的**: リファクタリング後もテストがパスすることを確認する

**実行手順**:

1. TypeScriptコンパイルを実行する
2. Lintを実行する
3. テストを実行する

**検証コマンド**:

```bash
# 型チェック
pnpm --filter @repo/desktop typecheck

# Lint
pnpm --filter @repo/desktop lint

# テスト実行
pnpm --filter @repo/desktop test
```

**期待される成果物**:

- テスト実行結果（全パス）
