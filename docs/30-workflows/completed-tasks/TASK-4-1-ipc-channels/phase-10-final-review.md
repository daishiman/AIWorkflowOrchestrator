## 目的

実装の全体品質と整合性を最終検証し、手動テスト・ドキュメント更新に進む前に問題がないことを確認する。

## 背景

本タスクは後続タスク（TASK-4-2, TASK-5-1）の基盤となるため、
チャネル定義の品質を最終確認することが重要。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 要件充足性の最終確認

**目的**: 実装が全ての要件を満たしているか最終確認する

**実行手順**:

1. index.mdの要件を読み込む
2. 実装が全要件を満たしているか確認する
3. 不足があれば記録する

**確認チェックリスト**:

- [ ] 新規チャネル定数が全て追加されている
- [ ] ホワイトリストに適切に登録されている
- [ ] 型定義が正しくエクスポートされている
- [ ] 既存チャネルとの重複がない

**期待される成果物**:

- 要件充足性確認結果

---

### タスク2: テスト結果の最終確認

**目的**: 全テストがパスしていることを最終確認する

**実行手順**:

1. 全テストを実行する
2. 結果を確認する
3. 失敗があれば記録する

**検証コマンド**:

```bash
# テスト実行
pnpm --filter @repo/desktop test

# カバレッジ確認
pnpm --filter @repo/desktop test -- --coverage
```

**確認項目**:

- [ ] 全ユニットテストがパス
- [ ] カバレッジ基準を満たしている

**期待される成果物**:

- テスト結果確認レポート

---

### タスク3: 静的解析の最終確認

**目的**: 静的解析に問題がないことを最終確認する

**実行手順**:

1. TypeScriptコンパイルを実行する
2. ESLintを実行する
3. 結果を確認する

**検証コマンド**:

```bash
# 型チェック
pnpm --filter @repo/desktop typecheck

# Lint
pnpm --filter @repo/desktop lint
```

**確認項目**:

- [ ] TypeScriptエラー: 0
- [ ] ESLintエラー: 0

**期待される成果物**:

- 静的解析確認レポート

---

### タスク4: レビュー結果の判定

**目的**: 最終レビュー結果を判定する

**実行手順**:

1. 全チェック結果を集計する
2. 問題の有無を判定する
3. 次のアクションを決定する

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`

## レビュー結果判定

| 判定     | 条件                     | 次のアクション            |
| -------- | ------------------------ | ------------------------- |
| PASS     | 全レビュー観点で問題なし | Phase 11へ進行            |

| MAJOR    | 重大な問題あり           | 該当Phaseへ戻り修正       |
