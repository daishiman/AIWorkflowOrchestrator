### リスク 3: CompleteStep 後方互換性（低リスク）

| 項目         | 内容                                                                                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リスク内容   | `CompleteStep` の `onClose` を optional 化することで、既存の呼び出し元が `onClose` を渡さなくなった場合に閉じる手段がなくなる                                                                                                     |
| リスクレベル | 低                                                                                                                                                                                                                                |
| 影響範囲     | `CompleteStep` を使用している全箇所                                                                                                                                                                                               |
| 対応策       | `onClose` を optional にする（`() => void \| undefined`）が、既存の呼び出し元は引き続き `onClose` を渡しているため実質的な動作変更はない。`CompleteStep` 内で `onClose` が undefined の場合は閉じるボタンを非表示にする実装にする |
| 対応状況     | 対応済み（CompleteStep.tsx で undefined チェックを実装）                                                                                                                                                                          |
