## 実行手順

### Task 1: 機能要件抽出

元タスク指示書から以下の機能要件を抽出・確認する。

#### 機能要件（FR）

| FR-ID | 要件                                     | 優先度 |
| ----- | ---------------------------------------- | ------ |
| FR-1  | タイムスタンプが定期的に自動更新される   | 必須   |
| FR-2  | 更新間隔が経過時間に応じて動的に変化する | 必須   |
| FR-3  | タブが非表示の時は更新を停止する         | 必須   |
| FR-4  | タブが再表示された時は更新を再開する     | 必須   |
| FR-5  | 既存のMessageTimestamp表示形式は維持する | 必須   |

#### 更新間隔仕様

| 経過時間   | 更新間隔 | 理由                     |
| ---------- | -------- | ------------------------ |
| 1分未満    | 1秒      | 秒数の変化を正確に反映   |
| 1分〜1時間 | 1分      | 分単位で十分、負荷軽減   |
| 1時間以上  | 1時間    | 時間単位で十分、最小負荷 |

### Task 2: 非機能要件定義

#### 非機能要件（NFR）

| NFR-ID | カテゴリ       | 要件                             | 基準           |
| ------ | -------------- | -------------------------------- | -------------- |
| NFR-1  | パフォーマンス | 100メッセージでもFPS 60を維持    | FPS >= 60      |
| NFR-2  | パフォーマンス | メモリリークがない               | ヒープ増加なし |
| NFR-3  | パフォーマンス | CPUスパイクがない                | CPU使用率安定  |
| NFR-4  | バッテリー     | 非表示時はタイマーが停止している | タイマー0個    |
| NFR-5  | 保守性         | 既存テストが全てPASS             | テスト100%成功 |
| NFR-6  | 保守性         | 新規機能のテストカバレッジ100%   | カバレッジ100% |

### Task 3: 受け入れ基準作成

#### 受け入れ基準（AC）

| AC-ID | 対応要件 | 受け入れ基準                                                     |
| ----- | -------- | ---------------------------------------------------------------- |
| AC-1  | FR-1     | メッセージ送信後、タイムスタンプが自動的に更新されることを確認   |
| AC-2  | FR-2     | 1分未満は1秒、1分以上は1分、1時間以上は1時間間隔で更新される     |
| AC-3  | FR-3     | タブを非表示にした後、setIntervalがクリアされていることを確認    |
| AC-4  | FR-4     | タブを再表示した後、setIntervalが再設定されていることを確認      |
| AC-5  | FR-5     | 「X秒前」「X分前」「X時間前」「X日前」の表示形式が維持されている |
| AC-6  | NFR-1    | 100メッセージ表示時にDevToolsでFPSを計測し60以上を確認           |
| AC-7  | NFR-2    | 10分間実行後、ヒープサイズの持続的な増加がないことを確認         |
| AC-8  | NFR-3    | タイマー更新時にCPU使用率スパイクが発生しないことを確認          |
