## 1. 機能要件（FR）

### 1.1 機能要件一覧

| FR-ID | 要件                                     | 優先度 | 説明                                                               |
| ----- | ---------------------------------------- | ------ | ------------------------------------------------------------------ |
| FR-1  | タイムスタンプが定期的に自動更新される   | 必須   | MessageTimestampコンポーネントの表示が自動的に更新される           |
| FR-2  | 更新間隔が経過時間に応じて動的に変化する | 必須   | パフォーマンス最適化のため、経過時間に応じた適応的な更新間隔を採用 |
| FR-3  | タブが非表示の時は更新を停止する         | 必須   | バッテリー消費・パフォーマンス最適化のため                         |
| FR-4  | タブが再表示された時は更新を再開する     | 必須   | ユーザー体験を損なわないため                                       |
| FR-5  | 既存のMessageTimestamp表示形式は維持する | 必須   | 「X秒前」「X分前」「X時間前」「X日前」形式を維持                   |

### 1.2 更新間隔仕様

| 経過時間   | 更新間隔 | 理由                                          |
| ---------- | -------- | --------------------------------------------- |
| 1分未満    | 1秒      | 秒数の変化を正確に反映（「5秒前」→「6秒前」） |
| 1分〜1時間 | 1分      | 分単位で十分な精度を確保しつつ負荷軽減        |
| 1時間以上  | 1時間    | 時間単位で十分、最小負荷で動作                |

### 1.3 表示形式仕様

現在の `formatRelativeTime` 関数の出力形式を維持する。

| 経過時間  | 表示形式        | 例         |
| --------- | --------------- | ---------- |
| 0〜59秒   | `${秒}秒前`     | "30秒前"   |
| 1〜59分   | `${分}分前`     | "5分前"    |
| 1〜23時間 | `${時間}時間前` | "2時間前"  |
| 1日以上   | `${日}日前`     | "3日前"    |
| 未来      | "たった今"      | "たった今" |

## 3. 技術要件

### 3.1 使用技術

| 技術                | 用途                              |
| ------------------- | --------------------------------- |
| React useEffect     | タイマーのライフサイクル管理      |
| React useState      | 現在時刻の状態管理                |
| React useRef        | タイマーIDの保持                  |
| React useContext    | TimestampProviderによるバッチ更新 |
| React.memo          | 不要な再レンダリング防止          |
| Page Visibility API | タブの可視状態検知                |
| setInterval         | 定期的な更新処理                  |

### 3.2 実装方針

1. **useIntervalフック**: 再利用可能なタイマーフックを作成
2. **TimestampContext**: 全メッセージのタイムスタンプをバッチ更新
3. **可視状態検知**: Page Visibility APIでタブの表示状態を監視
4. **React.memo**: MessageTimestampの不要な再レンダリングを防止
