## 検証シナリオ

### シナリオ1: 自動更新動作確認

```
前提条件: SkillStreamDisplayにメッセージが表示されている
操作: 何も操作せずに待機
期待結果:
  - 30秒後、タイムスタンプが「30秒前」から「31秒前」「32秒前」...と変化
  - 1分後、タイムスタンプが「1分前」に変化
  - 以降、1分ごとに「2分前」「3分前」...と変化
```

### シナリオ2: 更新間隔の動的変化確認

```
前提条件: メッセージが30秒前に送信されている
操作: 更新間隔を観察
期待結果:
  - 1分未満: 1秒ごとに更新
  - 1分経過後: 1分ごとに更新（「1分前」「2分前」...）
  - 1時間経過後: 1時間ごとに更新
```

### シナリオ3: タブ非表示時の動作確認

```
前提条件: タイムスタンプが自動更新中
操作: 別のタブに切り替え、または最小化
期待結果:
  - タイマーが停止（CPUリソースを消費しない）
  - タブを再表示すると、タイマーが再開
  - 表示再開時、正確な経過時間が即座に反映される
```

### シナリオ4: 大量メッセージでのパフォーマンス確認

```
前提条件: 100件のメッセージが表示されている
操作: 10分間表示したまま待機
期待結果:
  - FPSが60を維持
  - メモリ使用量が安定（ヒープの持続的増加なし）
  - CPUスパイクなし
```
