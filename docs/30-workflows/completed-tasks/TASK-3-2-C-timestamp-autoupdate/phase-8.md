## 実行手順

### Task 1: コードスメル検出

以下の観点でコードを確認する。

| 観点             | チェック項目                               |
| ---------------- | ------------------------------------------ |
| 重複コード       | 同じ処理が複数箇所に存在しないか           |
| 命名             | 変数・関数名が適切か                       |
| 関数の長さ       | 関数が長すぎないか（20行以下推奨）         |
| 単一責任         | 各関数・コンポーネントが単一の責任を持つか |
| マジックナンバー | 数値リテラルが定数化されているか           |
| コメント         | 不要なコメントがないか                     |

### Task 2: リファクタリング実行

#### 想定されるリファクタリング項目

| 項目              | 内容                               |
| ----------------- | ---------------------------------- |
| 定数の整理        | UPDATE_INTERVALSの定義場所を最適化 |
| 型定義の整理      | 共通型の抽出・整理                 |
| hooks/index.ts    | エクスポートのバレルファイル追加   |
| contexts/index.ts | エクスポートのバレルファイル追加   |
| コメントの整理    | JSDocコメントの一貫性確保          |

### Task 3: テスト継続成功確認

```bash
# リファクタリング後のテスト実行

# 型チェック
```
