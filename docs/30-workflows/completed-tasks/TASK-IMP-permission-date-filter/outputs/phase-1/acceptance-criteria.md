## 受け入れ基準一覧

| AC-ID | 受け入れ基準                                                                                       | 関連FR/NFR |
| ----- | -------------------------------------------------------------------------------------------------- | ---------- |
| AC-1  | 期間プリセット「今日」を選択すると、本日00:00:00以降のエントリのみ表示される                       | FR-1       |
| AC-2  | 期間プリセット「過去7日」を選択すると、7日前00:00:00以降のエントリのみ表示される                   | FR-1       |
| AC-3  | 期間プリセット「過去30日」を選択すると、30日前00:00:00以降のエントリのみ表示される                 | FR-1       |
| AC-4  | 期間プリセット「全期間」を選択すると、全エントリが表示される                                       | FR-1, FR-6 |
| AC-5  | カスタム範囲でstart/endを指定すると、その範囲内のエントリのみ表示される                            | FR-2       |
| AC-6  | ツール名フィルタ「Bash」と期間「今日」を同時適用すると、今日のBashエントリのみ表示される           | FR-3       |
| AC-7  | 判断結果フィルタ「denied」と期間「過去7日」を同時適用すると、7日以内のdeniedエントリのみ表示される | FR-3       |
| AC-8  | フィルタ結果が0件の場合、空状態メッセージが表示される（既存のフィルタ結果なしメッセージを流用）    | FR-1       |

## UI表示に関する基準

| AC-ID  | 受け入れ基準                                                               | 関連FR |
| ------ | -------------------------------------------------------------------------- | ------ |
| AC-UI1 | プリセット選択時（全期間/今日/過去7日/過去30日）にカスタム日付入力が非表示 | FR-4   |
| AC-UI2 | カスタム範囲選択時にstart/endの日付入力欄が表示される                      | FR-5   |
| AC-UI3 | デフォルト状態で「全期間」が選択されている                                 | FR-6   |
