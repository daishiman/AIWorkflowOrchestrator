## 実行手順

### 1. カバレッジ測定

```bash
pnpm --filter @repo/shared test:coverage
```

### 2. ギャップ分析

- 未到達の行/分岐/関数を特定
- 統合テスト不足領域を特定

### 3. 追加テスト作成

- ユニット/統合テストの不足分を追加
- エッジケース・エラーケースを追加
