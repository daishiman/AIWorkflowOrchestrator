## テスト方針

Knowledge Graph Storeはバックエンドライブラリであり、UIを持たないため、手動テスト検証は以下の方針で実施：

1. **自動テストスイートの実行結果確認**
2. **APIの使用シナリオ検証**
3. **エラーハンドリングの動作確認**

## 統合テストシナリオ

### シナリオ1: 文書からのナレッジグラフ構築

```
1. 文書から3つのエンティティを抽出・追加
2. エンティティ間に2つの関係を追加
3. グラフ統計を取得
4. 開始ノードからBFSトラバーサル実行
```

| ステップ         | 期待結果                       | 実際の結果 |
| ---------------- | ------------------------------ | ---------- |
| エンティティ追加 | 3件追加成功                    | ✅         |
| 関係追加         | 2件追加成功                    | ✅         |
| 統計取得         | entityCount=3, relationCount=2 | ✅         |
| トラバーサル     | 全ノード訪問                   | ✅         |

### シナリオ2: 重複エンティティのマージ

```
1. エンティティA（confidence=0.8）を追加

```

| 期待結果                 | 実際の結果 |
