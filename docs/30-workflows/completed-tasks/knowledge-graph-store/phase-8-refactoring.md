## リファクタリング観点

| 観点             | 確認項目                         |
| ---------------- | -------------------------------- |
| 重複排除         | 同じロジックの繰り返しがないか   |
| 命名改善         | 変数・関数名が意図を表しているか |
| 関数分割         | 関数が単一責任になっているか     |
| 早期リターン     | ネストが深すぎないか             |
| マジックナンバー | 定数化されているか               |
