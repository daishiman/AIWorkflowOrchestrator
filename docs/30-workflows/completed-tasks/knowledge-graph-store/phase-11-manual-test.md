## 目的

自動テストでは検証できない実環境動作を手動で確認する。

## 背景

Knowledge Graphストアはバックエンドサービスのため、REPL/スクリプト経由での動作確認を行う。

## テストカテゴリ

| カテゴリ   | テスト対象                               |
| ---------- | ---------------------------------------- |
| 機能テスト | エンティティCRUD、関係CRUD、トラバーサル |
| 性能テスト | 大量データでのトラバーサル性能           |
| 統合テスト | 実際のSQLiteDBとの連携                   |

## テストケース

### エンティティ操作

| No  | テスト項目         | 操作手順                                 | 期待結果                         | 実行結果 |
| --- | ------------------ | ---------------------------------------- | -------------------------------- | -------- |
| 1   | エンティティ作成   | upsertEntityを呼び出す                   | 新規エンティティが作成される     |          |
| 2   | エンティティ取得   | getEntity(id)を呼び出す                  | 指定IDのエンティティが取得できる |          |
| 3   | エンティティマージ | 同じnormalizedNameで再度upsertEntity     | mentionCountが増加する           |          |
| 4   | 類似検索           | findSimilarEntities(embedding)を呼び出す | 類似度の高いエンティティが返る   |          |

### 関係操作

| No  | テスト項目 | 操作手順                         | 期待結果                           | 実行結果 |
| --- | ---------- | -------------------------------- | ---------------------------------- | -------- |
| 5   | 関係追加   | addRelationを呼び出す            | 新規関係が作成される               |          |
| 6   | 関係取得   | getRelations(entityId)を呼び出す | 指定エンティティの関係が取得できる |          |
| 7   | 重み更新   | 同じ関係で再度addRelation        | weightが増加する                   |          |

### グラフトラバーサル

| No  | テスト項目      | 操作手順                                       | 期待結果                            | 実行結果 |
| --- | --------------- | ---------------------------------------------- | ----------------------------------- | -------- |
| 8   | BFSトラバーサル | traverse(startId, {maxDepth: 3})を呼び出す     | 近傍エンティティが取得できる        |          |
| 9   | 最短パス        | findShortestPath(sourceId, targetId)を呼び出す | 最短パスが取得できる（または null） |          |
| 10  | 統計取得        | getStats()を呼び出す                           | グラフ統計が取得できる              |          |
