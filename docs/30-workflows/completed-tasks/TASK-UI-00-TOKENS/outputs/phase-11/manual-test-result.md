## 検証方法の補足

本タスク（TASK-UI-00-TOKENS）は CSS デザイントークンの定義に関するものであり、実際のアプリ起動による視覚的検証は対象外です。以下の方法でコードベース検証を実施しました。

1. **CSS 変数値の直接確認**: `tokens.css` の各テーマブロック内の変数定義を直接読み取り、Apple HIG 仕様との一致を確認
2. **git diff によるkanagawa-dragon変更検出**: `git diff HEAD -- tokens.css` で kanagawa-dragon テーマの変更がコメントのみであることを確認
3. **自動テストによるWCAGコントラスト比検証**: `renderWithTheme.test.tsx` 内の WCAG 検証テスト（28テスト全PASS）で代替
4. **Python スクリプトによるコントラスト比の独立計算**: WCAG 2.1 の相対輝度/コントラスト比アルゴリズムで独立検証
5. **テーマ間変数セット整合性**: awk + diff で 3 テーマの変数名セットを抽出・比較し、31 変数が完全一致であることを確認
6. **CSS 構造分析**: マイクロインタラクショントークンと `@keyframes` がグローバルスコープで定義されていることを確認し、テーマ切替の影響を受けないことを検証
