## 受け入れ基準一覧（AC-001〜AC-012）

### AC-1: テーマカラー正確性

| AC ID  | 基準                                                                                             | 検証方法                                                                | 対応要件           |
| ------ | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- | ------------------ |
| AC-001 | `[data-theme="light"]` の全セマンティック変数が Apple HIG System Colors の公式値と一致する       | tokens.css の値と要件定義書 FR-L-001〜FR-L-012 の値を1対1で照合         | FR-L-001〜FR-L-012 |
| AC-002 | `[data-theme="dark"]` の全セマンティック変数が Apple HIG System Colors (Dark) の公式値と一致する | tokens.css の値と要件定義書 FR-D-001〜FR-D-012 の値を1対1で照合         | FR-D-001〜FR-D-012 |
| AC-003 | `[data-theme="kanagawa-dragon"]` の全変数が本タスク実施前と同一である（変更なし）                | `git diff` で kanagawa-dragon セレクタ内のCSS変数に差分がないことを確認 | NFR-004            |

### AC-2: WCAG 2.1 AA コントラスト比

| AC ID  | 基準                                                                                                                                                               | 検証方法                            | 対応要件 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------- | -------- |
| AC-004 | `--text-primary` と `--bg-primary` のコントラスト比が全3テーマで 4.5:1 以上                                                                                        | WCAG コントラスト比計算ツールで検証 | NFR-001  |
| AC-005 | `--text-secondary` と `--bg-primary` のコントラスト比が全3テーマで 4.5:1 以上                                                                                      | WCAG コントラスト比計算ツールで検証 | NFR-001  |
| AC-006 | `--text-muted` と `--bg-primary` のコントラスト比は18px未満のテキストで 4.5:1 を満たさない可能性がある。使用箇所で個別検証が必要であることをドキュメントに明記する | 計算結果を記録し、使用制限を文書化  | NFR-001  |

### AC-3: マイクロインタラクション

| AC ID  | 基準                                                                                                                         | 検証方法                                   | 対応要件             |
| ------ | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | -------------------- |
| AC-007 | `:root` に `--ease-bounce`, `--ease-anticipate`, `--scale-hover`, `--scale-active`, `--scale-bounce` の5変数が定義されている | tokens.css の `:root` セクションを目視確認 | FR-MI-001〜FR-MI-005 |
| AC-008 | `@keyframes success-bounce` が3ステップ（0%, 50%, 100%）で定義されている                                                     | tokens.css のキーフレーム定義を確認        | FR-MI-006            |
| AC-009 | `@keyframes error-shake` が5ステップ（0%, 20%, 40%, 60%, 80%, 100%）で定義されている                                         | tokens.css のキーフレーム定義を確認        | FR-MI-007            |

### AC-4: テストヘルパー
