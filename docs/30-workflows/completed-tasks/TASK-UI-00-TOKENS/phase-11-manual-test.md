## 目的

自動テストでは検証できないテーマの視覚的品質を手動で確認する。CSS変数によるlight/darkテーマの見た目、テーマ切替時のトランジション品質、マイクロインタラクションの動作感、アクセシビリティ（コントラスト比・キーボード操作）を目視・操作で検証する。

**目的**: 自動テストでは検証できない視覚的品質・インタラクション品質を手動で確認する。

**期待される成果物**:

## 実行手順

### 事前準備

1. `pnpm --filter @repo/desktop dev` でアプリを起動
2. DevTools（`Cmd+Option+I`）を開く
3. 設定画面からテーマ切替が可能であることを確認

### DevToolsでのCSS変数確認方法

```javascript
// body要素のCSS変数値を取得
getComputedStyle(document.body).getPropertyValue("--color-bg");
getComputedStyle(document.body).getPropertyValue("--color-text");
getComputedStyle(document.body).getPropertyValue("--interaction-hover-scale");
getComputedStyle(document.body).getPropertyValue("--interaction-duration");
```
