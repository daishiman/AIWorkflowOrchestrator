# Phase 8 リファクタリング計画

## 目的

重複していた認証 preflight 判定と誘導文言を共通化し、変更点を最小化する。

## 実施内容

| 項目  | 内容                                  | 結果                            |
| ----- | ------------------------------------- | ------------------------------- |
| RF-01 | `skillExecutionAuthPreflight.ts` 新設 | AgentView/Hook/Store で共通利用 |
| RF-02 | 誘導文言の共通化                      | 文言ドリフトを抑止              |
| RF-03 | execute 前ガードの早期 return         | 無駄な IPC 呼び出しを削減       |

## 非機能効果

- 可読性向上（重複ロジック排除）
- 保守容易性向上（仕様変更時の改修点集約）
