## 実行タスク

### タスク1: 機能レビュー

**レビュー観点**:

1. agentSliceテストがrenderHookパターンに完全移行されているか
2. 参照安定性テストが全セレクタに対して実施されているか
3. 再レンダリングテストが実施されているか
4. 3つのSliceテスト間のパターンが統一されているか

### タスク2: 品質レビュー

**レビュー観点**:

1. カバレッジ基準が達成されているか
2. TypeScript型エラーが0件か
3. ESLintエラーが0件か
4. テストの可読性・保守性が十分か

### タスク3: 互換性レビュー

**レビュー観点**:

1. 既存テストにリグレッションがないか
2. テスト実行時間が許容範囲内か
3. happy-dom環境で全テストが正常動作するか

### タスク4: 受け入れ基準の検証

- [ ] AC-1: agentSliceテストのrenderHook移行完了

## レビューゲート判定

| 判定     | 条件                     | 次のアクション                       |
| -------- | ------------------------ | ------------------------------------ |
| PASS     | 全レビュー観点で問題なし | Phase 11へ進行                       |
| MINOR    | 軽微な指摘あり           | 未タスク仕様書に変換後Phase 11へ     |
| MAJOR    | 重大な問題あり           | 戻り先を問題の種類で決定（下表参照） |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認            |

### MAJOR判定時の戻り先決定基準

| 問題の種類       | 戻り先                      |
| ---------------- | --------------------------- |
| 要件の問題       | Phase 1（要件定義）         |
| 設計の問題       | Phase 2（設計）             |
| テスト設計の問題 | Phase 4（テスト作成）       |
| 実装の問題       | Phase 5（実装）             |
| テスト拡充の問題 | Phase 6（テスト拡充）       |
| カバレッジ未達   | Phase 7（カバレッジ確認）   |
| コード品質の問題 | Phase 8（リファクタリング） |

> **注意**: MINOR判定の指摘は全て未タスク仕様書に変換すること（省略不可）
