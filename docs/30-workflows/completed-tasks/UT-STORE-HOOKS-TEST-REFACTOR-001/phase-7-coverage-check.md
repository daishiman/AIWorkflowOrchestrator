## 実行タスク

### タスク1: カバレッジ計測

**実行手順**:

```bash
# 対象テスト全体のカバレッジ計測
pnpm --filter @repo/desktop test -- --run --coverage agentSlice.selectors authModeSlice.selectors llmSlice.selectors
```

### テスト数記録基準（coverage-standards.md準拠）

| ルール                   | 説明                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| **実測値のみ使用**       | `pnpm test` の実行結果から取得した実際の数値のみ記載する。推定値・概算値は使用しない     |
| **実行コマンドを明記**   | テスト数を取得したコマンド（例: `pnpm vitest run --reporter=verbose`）を成果物に記録する |
| **タイムスタンプを付与** | テスト実行日時を記録し、数値の鮮度を保証する                                             |

> Phase間で数値が異なる場合は、各Phase実行時点の実測値を記載し、差分の理由を明記すること。

### タスク2: カバレッジ基準との比較

**カバレッジ基準**:

| 指標              | 最低基準 | 推奨基準 | 実測値 |

| Line Coverage     | 80%      | 90%      | -      |
| Branch Coverage   | 60%      | 70%      | -      |
| Function Coverage | 80%      | 90%      | -      |
