## 1. リスクバッジデザイン仕様

### 1.1 バッジスタイル

- サイズ: `text-xs`（12px）
- パディング: `px-1.5 py-0.5`
- 角丸: `rounded`
- フォント: `font-medium`
- ボーダー: `border`（1px solid）
- 配置: ツール名バッジの右横（`inline-flex items-center gap-1`親要素内）

### 1.2 リスクレベル別カラーマッピング

| RiskLevel | 背景色          | テキスト色        | ボーダー色          |
| --------- | --------------- | ----------------- | ------------------- |
| Low       | `bg-green-100`  | `text-green-800`  | `border-green-200`  |
| Medium    | `bg-yellow-100` | `text-yellow-800` | `border-yellow-200` |
| High      | `bg-orange-100` | `text-orange-800` | `border-orange-200` |
| Critical  | `bg-red-100`    | `text-red-800`    | `border-red-200`    |

### 1.3 WCAG 2.1 AA コントラスト比検証計画

| RiskLevel | 背景色（Hex）        | テキスト色（Hex）    | 推定コントラスト比 |
| --------- | -------------------- | -------------------- | ------------------ |
| Low       | #dcfce7 (green-100)  | #166534 (green-800)  | ~7.5:1 (PASS)      |
| Medium    | #fef9c3 (yellow-100) | #854d0e (yellow-800) | ~5.5:1 (PASS)      |
| High      | #ffedd5 (orange-100) | #9a3412 (orange-800) | ~5.8:1 (PASS)      |
| Critical  | #fee2e2 (red-100)    | #991b1b (red-800)    | ~6.0:1 (PASS)      |

全レベルで4.5:1以上を満たす見込み。Phase 9で正式検証を行う。

## 2. セキュリティ影響テキスト表示仕様

### 2.1 表示位置

人間可読説明文（getDescription）の直下

### 2.2 スタイル

```html
<p class="text-xs text-gray-500 mt-1">{セキュリティ影響テキスト}</p>
```

- フォントサイズ: `text-xs`（12px）
- テキスト色: `text-gray-500`（#6b7280）
- マージン: `mt-1`（4px上マージン）
- 人間可読説明文（text-sm text-gray-600）より小さく薄い色で差別化

## 3. アクセシビリティ仕様

### 3.1 aria属性

- リスクバッジ: `aria-label="リスクレベル: {riskLevel}"`
- 既存のaria属性（aria-modal, aria-labelledby, aria-describedby等）に影響なし

### 3.2 キーボードナビゲーション

- リスクバッジはフォーカス不要（情報表示のみ、操作要素ではない）
- 既存のフォーカストラップ（Tab/Shift+Tab）に影響なし
- 既存のEscapeキーハンドリングに影響なし

### 3.3 色覚多様性対応

- リスクレベルはテキスト（Low/Medium/High/Critical）で識別可能
- 色のみに依存しない設計

## 4. レイアウト互換性

### 4.1 既存要素との共存

| 要素                      | 変更 | 備考                 |
| ------------------------- | ---- | -------------------- |
| ヘッダー（⚠️ + タイトル） | なし | 変更なし             |
| ツールアイコン            | なし | 既存のまま           |
| ツール名バッジ            | なし | 既存のまま           |
| リスクバッジ              | 追加 | ツール名バッジの右横 |
| 人間可読説明文            | なし | 既存のまま           |
| セキュリティ影響テキスト  | 追加 | 人間可読説明文の直下 |
| 詳細展開ボタン            | なし | 既存のまま           |
| チェックボックス          | なし | 既存のまま           |
| 3ボタン                   | なし | 既存のまま           |

### 4.2 レスポンシブ対応

- リスクバッジはインライン要素のため、ツール名バッジと同一行に収まる
- 幅が狭い場合は自然に折り返される（flex-wrap等の特別な対応不要）
