## 未タスク候補詳細

### 候補1: リスクレベル動的変更機能

| 項目   | 内容                                                                                    |
| ------ | --------------------------------------------------------------------------------------- |
| 概要   | ユーザーまたは管理者がツールのリスクレベルを動的に変更できる機能                        |
| 理由   | 現在のリスクレベルはハードコード（TOOL_METADATA定数）。カスタマイズ需要がある場合に対応 |
| 優先度 | 低（現時点でカスタマイズ需要は確認されていない）                                        |

### 候補2: リスクレベル自動拒否ロジック

| 項目   | 内容                                                                 |
| ------ | -------------------------------------------------------------------- |
| 概要   | Criticalレベルのツールを自動的に拒否するオプション機能               |
| 理由   | セキュリティ強化のため、高リスクツールの自動ブロック機能が有用       |
| 優先度 | 中（セキュリティ向上に直結するが、ユーザビリティとのバランスが必要） |

### 候補3: PermissionSettingsリスクレベル表示

| 項目   | 内容                                                           |
| ------ | -------------------------------------------------------------- |
| 概要   | 設定画面のPermissionSettingsセクションにリスクレベル一覧を表示 |
| 理由   | ユーザーが全ツールのリスクレベルを一覧で確認できる管理画面     |
| 優先度 | 低（PermissionDialogで個別確認は既に可能）                     |
