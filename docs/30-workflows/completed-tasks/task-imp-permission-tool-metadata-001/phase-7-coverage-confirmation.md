## 目的

toolMetadata.tsとPermissionDialog.tsx（リスクバッジ関連部分）のテストカバレッジが目標値を達成しているかを計測・検証する。未達の場合はPhase 6に戻りテストを追加する。

---

## 実行タスク

### Task 1: カバレッジ計測

**目的**: 全テストを実行しカバレッジレポートを生成する。

**手順**:

1. カバレッジ付きでテストを実行する：

   ```bash
   pnpm vitest run apps/desktop/src/renderer/components/skill/__tests__/ --coverage
   ```

2. toolMetadata.tsのカバレッジを確認する：

   | 指標              | 目標値 | 実測値 | 判定 |
   | ----------------- | ------ | ------ | ---- |
   | Line Coverage     | 95%+   |        |      |
   | Branch Coverage   | 60%+   |        |      |
   | Function Coverage | 80%+   |        |      |

3. PermissionDialog.tsxのカバレッジ（リスクバッジ関連行）を確認する

**期待される成果物**: カバレッジ計測結果

### Task 2: カバレッジ判定

**目的**: カバレッジ目標達成/未達を判定する。

**手順**:

1. 以下の判定基準に従う：

   | 条件                                              | アクション              |
   | ------------------------------------------------- | ----------------------- |
   | toolMetadata.ts Lines 95%以上かつ全指標が目標以上 | Phase 8へ進行           |
   | いずれかの指標が目標未達                          | Phase 6に戻りテスト追加 |

2. 未達の場合、未カバーの行・分岐を特定し、Phase 6で追加すべきテストケースを明記する

**期待される成果物**: カバレッジ判定結果

### Task 3: カバレッジレポート作成

**目的**: カバレッジ計測結果を文書化する。

**手順**:

1. 全対象ファイルのカバレッジ結果をテーブルにまとめる
2. 未カバー行がある場合はその理由を記録する（到達不能コード等）
3. Phase 6との差分（改善度）を記録する

**期待される成果物**: カバレッジレポート
