## 実行タスク

### Task 1: ローカル確認チェックリスト

**目的**: PR作成前に全品質ゲートをクリアしていることを確認する。

**手順**:

1. 以下のチェックリストを順番に実行する：

   | #   | 確認項目                       | コマンド                                                                | 結果 |
   | --- | ------------------------------ | ----------------------------------------------------------------------- | ---- |
   | 1   | ビルドが成功する               | `pnpm --filter @repo/desktop build`                                     |      |
   | 2   | 全テストがPASSする             | `pnpm vitest run apps/desktop/src/renderer/components/skill/__tests__/` |      |
   | 3   | TypeScript型チェックがPASSする | `pnpm --filter @repo/desktop exec tsc --noEmit`                         |      |
   | 4   | ESLintエラーがない             | `pnpm --filter @repo/desktop lint`                                      |      |
   | 5   | 実際の動作確認（該当する場合） | `pnpm --filter @repo/desktop dev` で手動確認                            |      |

2. 全チェックがPASSしていることを確認する
3. FAILがある場合は該当Phaseに戻り修正する

**期待される成果物**: ローカル確認チェック結果

### Task 2: ユーザー許可の取得

**目的**: PR作成の明示的な許可をユーザーから得る。

**手順**:

1. ユーザーに以下の情報を提示する：
   - 変更されたファイルの一覧
   - テスト結果サマリー
   - カバレッジ結果
   - 手動テスト結果サマリー

2. ユーザーから明示的な「PR作成してよい」という許可を得る

3. **許可が得られるまでPR作成は実行しない**

**期待される成果物**: ユーザー許可記録

### Task 3: PR作成

**目的**: `/ai:diff-to-pr`コマンドでPRを作成する。

**手順**:

1. ユーザーの許可を確認した後、`/ai:diff-to-pr`を実行する

2. PRの内容：
   - タイトル: `feat(permission): PermissionDialogツールリスクレベル・セキュリティメタデータ表示 (#606)`
   - ブランチ: `task/task-imp-permission-tool-metadata-001`
   - ベースブランチ: `main`

3. PR作成後、CIの実行結果を確認する

4. CIがFAILした場合は原因を調査し修正する

**期待される成果物**: PR URL

### Task 4: CI確認とマージ可能報告

**目的**: CIが全てPASSし、マージ可能な状態であることを確認する。

**手順**:

1. GitHub ActionsのCI結果を確認する
2. 全CIジョブがPASSしていることを確認する
3. ユーザーにマージ可能であることを報告する
4. **マージはユーザーがGitHub UIで手動実行する**（自動マージは行わない）

**期待される成果物**: CI確認結果・マージ可能報告
