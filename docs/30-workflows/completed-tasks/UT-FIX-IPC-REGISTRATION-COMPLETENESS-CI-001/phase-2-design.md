## 目的

`registerRuntimeSkillCreatorHandlers()` のスナップショットテスト設計・実装ファイル一覧を確定する。

## 背景

Phase 1 で確定した対象ハンドラ登録関数に対し、どのようなモック戦略・スナップショット設計でテストを構築するかを決定する。設計が確定してから実装に進むことで、手戻りを防ぐ。

---

## 実行タスク

### タスク1: テスト設計書の作成

**目的**: モック戦略・スナップショット設計・アサーション方針を確定する

**実行手順**:

1. モック戦略を決定する
   - `vi.mock("electron")` で `ipcMain` をモックし、`handle` 呼び出し引数を配列に記録する
   - `registerRuntimeSkillCreatorHandlers()` 用に最小限の `BrowserWindow` スタブを用意する
2. スナップショット対象を決定する
   - `registerRuntimeSkillCreatorHandlers()` から収集したソート済みチャネル名配列（18 チャネル = public runtime 16 + auxiliary 2）
3. 重複検出ロジックを設計する
   - `Set` 変換後の長さと配列長が一致するかのアサーション
4. テストファイル配置方針を決定する
   - テスト対象ファイルと同階層の `__tests__/` または `*.test.ts` パターン

**テスト設計方針（事前定義）**:

| 観点                 | 設計内容                                                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| モック戦略           | `vi.mock("electron")` で `ipcMain` をモック、`registerRuntimeSkillCreatorHandlers` 用の `BrowserWindow` スタブを併用          |
| スナップショット対象 | `registerRuntimeSkillCreatorHandlers()` から収集したソート済みチャネル名配列（18 チャネル = public runtime 16 + auxiliary 2） |
| 重複検出             | `Set` 変換後の長さと配列長が一致するかのアサーション                                                                          |
| テストファイル配置   | テスト対象ファイルと同階層の `__tests__/` または `*.test.ts` パターンに合わせる                                               |

**期待される成果物**:

- `outputs/phase-2/test-design.md` （テスト設計書）

### タスク2: 変更ファイル一覧の確定

**目的**: 本タスクで新規作成・変更するファイルを全て列挙する

**実行手順**:

1. 新規作成ファイルを特定する
2. 自動生成ファイルを特定する
3. 変更なしのファイルを確認する（既存ファイルへの変更がないことを確認）

**変更ファイル一覧（事前定義）**:

| 操作     | ファイルパス                                                                                    | 内容                       |
| -------- | ----------------------------------------------------------------------------------------------- | -------------------------- |
| 新規作成 | `apps/desktop/src/main/ipc/__tests__/ipcHandlerRegistrationSnapshot.test.ts`                    | スナップショットテスト本体 |
| 自動生成 | `apps/desktop/src/main/ipc/__tests__/__snapshots__/ipcHandlerRegistrationSnapshot.test.ts.snap` | スナップショットファイル   |

**期待される成果物**:
