## 概要

本ドキュメントは、設計タスクの机上 walkthrough で発見された設計時点の既知課題を記録する。プロダクションコードが存在しないため、実行時の不具合ではなく、設計上の未確定事項・補完が必要な箇所を列挙する。

## 発見事項

### DI-1: Approval token TTL の具体値が未定義（R-M1 由来）

| 項目       | 内容                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------ |
| 重要度     | LOW                                                                                              |
| 発見元     | シナリオ 4, ステップ 4-3                                                                         |
| 内容       | Approval token の有効期限が「単一操作ごとに失効」と定義されているが、具体的な秒数（TTL）が未定義 |
| 影響       | 実装時に TTL を決定する必要がある。R-M1 で Phase 5 での 300s 固定が提案されている                |
| 対応方針   | 後続の実装タスク Phase 5 で TTL = 300s を採用し、テストで検証する                                |
| ステータス | Phase 3 MINOR R-M1 として記録済み                                                                |

### DI-2: Disclosure banner 再表示アイコンの配置が未確定（R-M2 由来）

| 項目       | 内容                                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| 重要度     | LOW                                                                                                               |
| 発見元     | シナリオ 6, ステップ 6-4                                                                                          |
| 内容       | Disclosure banner dismiss 後の再表示アイコンの具体的な配置位置が「Session Dock ヘッダー」までしか定義されていない |
| 影響       | R-M2 で Phase 5 での「Session Dock ヘッダー右端に info icon 配置」が提案されている                                |
| 対応方針   | 後続の実装タスク Phase 5 で Session Dock ヘッダー右端に info icon を配置する                                      |
| ステータス | Phase 3 MINOR R-M2 として記録済み                                                                                 |

### DI-3: Advanced Console read-only モードの制約詳細が未定義（R-M3 由来）

| 項目       | 内容                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------- |
| 重要度     | LOW                                                                                           |
| 発見元     | シナリオ 8, ステップ 8-9                                                                      |
| 内容       | running / done / aborted state での Advanced Console read-only モードの具体的な制約が未詳細化 |
| 影響       | R-M3 で Phase 5 での「input 系操作を disabled にする」が提案されている                        |

### DI-4: NFR-4 パフォーマンス基準の検証方法が未定義

| 項目       | 内容                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 重要度     | MEDIUM                                                                                    |
| 発見元     | 検証チェックリスト NFR-4                                                                  |
| 内容       | Approval Sheet の表示が 200ms 以内に完了するという NFR-4 の検証方法が定義されていない     |
| 影響       | 実装後のパフォーマンステストで計測基準と計測方法を定める必要がある                        |
| 対応方針   | 後続の実装タスクで Performance.now() を使用した計測、または React Profiler での計測を行う |
| ステータス | 未タスク候補                                                                              |

### DI-5: NFR-5 キーボードアクセシビリティの詳細仕様が未定義

| 項目       | 内容                                                                                  |
