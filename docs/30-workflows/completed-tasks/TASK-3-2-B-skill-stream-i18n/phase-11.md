## 検証手順

1. 開発サーバーを起動: `pnpm --filter @repo/desktop dev`
2. ブラウザの言語設定を日本語に変更
3. アプリを開き、Task 1のテストを実行
4. ブラウザの言語設定を英語に変更
5. ページをリロードし、Task 2のテストを実行
6. Task 3のアクセシビリティ検証を実行
7. Task 4のレグレッション確認を実行
