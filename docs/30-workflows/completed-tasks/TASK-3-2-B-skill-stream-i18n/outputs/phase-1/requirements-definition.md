## 1. 概要

SkillStreamDisplayコンポーネントおよび関連ユーティリティのUIテキストを多言語化対応し、日本語（ja）・英語（en）の2言語をサポートする。

---

## 2. 機能要件（FR）

| FR-ID | 要件                                               | 優先度 | 検証方法               |
| ----- | -------------------------------------------------- | ------ | ---------------------- |
| FR-01 | UIテキストが翻訳キー経由で表示される               | 必須   | ユニットテスト         |
| FR-02 | formatRelativeTimeがロケールに応じた出力を返す     | 必須   | ユニットテスト         |
| FR-03 | aria-labelが翻訳対応する                           | 必須   | アクセシビリティテスト |
| FR-04 | 日本語（ja）と英語（en）の2言語をサポートする      | 必須   | 手動テスト             |
| FR-05 | ブラウザの言語設定に基づいて自動で言語が選択される | 任意   | 手動テスト             |

### FR-01: UIテキスト翻訳

**対象テキスト**:

- ステータス: 待機中、実行中、完了、エラー、中断
- ボタン: 中断、リセット
- メッセージ: スキル実行を開始してください、実行中...
- フィードバック: コピーしました

**実装方法**:

- react-i18nextのuseTranslation hookを使用
- 翻訳キーを`skill-stream`名前空間に格納

### FR-02: formatRelativeTime多言語化

**対象テキスト**:

- たった今 / Just now
- X秒前 / X seconds ago
- X分前 / X minutes ago
- X時間前 / X hours ago
- X日前 / X days ago

**実装方法**:

- ロケール引数を追加（デフォルト: 'ja'）
- i18nextのt関数を使用、または独立した翻訳関数を実装

### FR-03: aria-label多言語化

**対象テキスト**:

- 実行中
- メッセージをコピー
- スキル実行を中断
- 状態をリセット

**実装方法**:

- useTranslation hookから取得した翻訳をaria-labelに設定

## 3. 非機能要件（NFR）

| NFR-ID | 要件                         | 基準                 | 検証方法             |
| ------ | ---------------------------- | -------------------- | -------------------- |
| NFR-01 | 翻訳ファイルのバンドルサイズ | 10KB以下/言語        | ビルド後サイズ確認   |
| NFR-02 | 翻訳取得のパフォーマンス     | 100ms以下            | パフォーマンステスト |
| NFR-03 | 既存テストの互換性           | 全テストPASS維持     | CI                   |
| NFR-04 | TypeScript型安全性           | 翻訳キーの型チェック | 型チェック           |

### NFR-01: バンドルサイズ

- 翻訳ファイルは名前空間単位で分割
- 必要な名前空間のみ読み込み
- JSON形式で最小化

### NFR-02: パフォーマンス

- 翻訳結果はuseMemoでキャッシュ
- 不要な再レンダリングを防止
- 初回読み込み時のみ翻訳ファイルをフェッチ

### NFR-03: 互換性

- 既存のテストは修正なしでPASS
- モックi18nプロバイダーをテスト環境で提供
- 翻訳キーが存在しない場合はキー名をフォールバック表示

### NFR-04: 型安全性

- 翻訳キーの型定義を作成
- 存在しないキーへのアクセスでコンパイルエラー
- IntelliSense補完対応

## 4. 統合テスト連携要件

| 接続要件カテゴリ | 記載内容                                                              |
| ---------------- | --------------------------------------------------------------------- |
| i18nプロバイダー | I18nextProviderでアプリ全体をラップする必要あり                       |
| ロケール取得     | ブラウザ言語設定（navigator.language）から自動検出                    |
| フォールバック   | 対応外言語の場合は日本語（ja）にフォールバック                        |
| データフロー     | i18n設定 → I18nextProvider → useTranslation hook → コンポーネント描画 |

---

## 5. アーキテクチャ層別要件

| 層                         | 確認観点                                         |
| -------------------------- | ------------------------------------------------ |
| フロントエンド（Renderer） | i18nプロバイダー設定、useTranslation hook使用    |
| ユーティリティ             | formatRelativeTimeのロケール引数対応             |
| 翻訳リソース               | JSON形式の翻訳ファイル（名前空間: skill-stream） |

## 7. 制約事項

- アプリ全体のi18n導入は対象外（SkillStreamDisplay関連のみ）
- 言語切替UIの実装は対象外
- 3言語以上の翻訳は対象外（将来タスクとして起票）

---

## 8. リスクと対策

| リスク             | 影響度 | 発生確率 | 対策                            |
| ------------------ | ------ | -------- | ------------------------------- |
| バンドルサイズ増加 | 低     | 中       | 翻訳ファイルの遅延読み込み      |
| 翻訳漏れ           | 中     | 中       | TypeScript型による翻訳キー検証  |
| パフォーマンス低下 | 低     | 低       | useMemoによる翻訳結果キャッシュ |
