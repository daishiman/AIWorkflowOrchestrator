## 技術的負債

### 現状の制約

1. **happy-dom環境の制限**
   - Clipboard API モックが困難
   - React concurrent mode との相性問題
   - 対応策: jsdom環境への切り替えを検討

2. **formatRelativeTimeの独自翻訳テーブル**
   - i18nextのt関数を使用していない
   - 理由: React context外でも使用可能にするため
   - 影響: 翻訳ファイルとの二重管理
