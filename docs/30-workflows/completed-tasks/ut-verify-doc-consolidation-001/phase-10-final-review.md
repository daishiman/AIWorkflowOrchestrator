## レビュー結果判定

| 判定     | 条件                     | 次のアクション                     |
| -------- | ------------------------ | ---------------------------------- |
| PASS     | AC・NFR 全て確認済み     | Phase 11（手動テスト）へ進行       |
| MINOR    | 軽微な表現の修正のみ必要 | 修正後、Phase 11 へ進行            |
| MAJOR    | AC の未達・NFR 違反あり  | 影響範囲に応じて Phase 5〜8 へ戻る |
| CRITICAL | 要件との根本的な矛盾     | Phase 1 へ戻りユーザー確認         |

### 戻り先決定基準

| 問題の種類                   | 戻り先                          |
| ---------------------------- | ------------------------------- |
| ラベル未追記・責務分離未追記 | Phase 5（ドキュメント更新実施） |
| フォーマット・リンク問題     | Phase 8〜9                      |
| 設計方針の問題               | Phase 2（設計）                 |
| 要件との矛盾                 | Phase 1（要件定義）             |
