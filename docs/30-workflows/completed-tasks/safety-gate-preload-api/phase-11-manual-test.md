## 実行手順

### ステップ 1: テストシナリオ実行

#### シナリオ 1: Renderer からの呼び出し確認

1. Electron アプリを起動する
2. DevTools コンソールで以下を実行:
   ```javascript
   window.electronAPI.skill
     .evaluateSafety("test-skill")
     .then((result) => console.log("Result:", result))
     .catch((err) => console.error("Error:", err));
   ```
3. **期待結果**: `{ success: true, data: { skillName: "test-skill", ... } }` または `{ success: false, error: { code: "...", message: "..." } }` が返される

#### シナリオ 2: 不正引数での呼び出し

1. DevTools コンソールで以下を実行:
   ```javascript
   window.electronAPI.skill
     .evaluateSafety("")
     .then((result) => console.log("Result:", result))
     .catch((err) => console.error("Error:", err));
   ```
2. **期待結果**: `{ success: false, error: { code: "VALIDATION_ERROR", message: "..." } }` が返される

#### シナリオ 3: API 存在確認

1. DevTools コンソールで以下を実行:
   ```javascript
   typeof window.electronAPI.skill.evaluateSafety;
   ```
2. **期待結果**: `"function"` が返される
