## 改善余地のある観点

| 項目                                            | 現状                                                                                        | 改善提案                                                                                                   |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 「既に実装済みのケース」のフロー記述            | Phase 4〜8 が実装前提で書かれているため、P50 ヒット時のフローが読者に自明ではない           | スキル内に「P50 ヒット時の Phase 4〜8 代替フロー」テンプレートを用意                                       |
