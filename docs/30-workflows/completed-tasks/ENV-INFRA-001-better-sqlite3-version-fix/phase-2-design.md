## 目的

Node.jsバージョン管理の仕組みを設計し、環境間の不一致を防止する。

---

## 実行タスク

### Task 1: バージョン管理設計

**バージョン管理方式**:

| 方式    | ファイル       | 目的                               |
| ------- | -------------- | ---------------------------------- |
| nvm     | `.nvmrc`       | 開発者がnvmで自動切替できる        |
| engines | `package.json` | pnpm/npmがバージョン制約をチェック |
| フック  | `.husky/`      | Pre-installでバージョンチェック    |

### Task 2: .nvmrc設計

**ファイル内容**:

```
v22.0.0
```

**設計根拠**:

- 現在の開発環境で使用されているNode.jsバージョンを採用
- LTS（Long Term Support）バージョンを推奨

### Task 3: package.json engines設計

**追加フィールド**:

| フィールド | 値                 | 説明                 |
| ---------- | ------------------ | -------------------- |
| node       | `>=22.0.0 <23.0.0` | Node.js 22.x系に限定 |
| pnpm       | `>=9.0.0`          | pnpm 9.x以上を要求   |

### Task 4: バージョンチェックスクリプト設計

**ファイル**: `.husky/hooks/check-node-version.sh`

**フロー**:

| ステップ | アクション                            |
| -------- | ------------------------------------- |
| 1        | .nvmrcからNode.jsバージョンを読み取る |
| 2        | 現在のNode.jsバージョンを取得         |
| 3        | バージョンを比較                      |
| 4        | 不一致の場合、警告を表示してexit 1    |
| 5        | 一致の場合、成功メッセージを表示      |
