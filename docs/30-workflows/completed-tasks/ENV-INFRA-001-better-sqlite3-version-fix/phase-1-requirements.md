## 目的

better-sqlite3のNODE_MODULE_VERSION不一致問題の根本原因を診断し、解決に必要な要件を定義する。

---

## 実行タスク

### Task 1: 問題診断

現在のNode.jsバージョンとbetter-sqlite3のビルド状況を確認する。

**診断コマンド**:

| コマンド                                            | 目的                           |
| --------------------------------------------------- | ------------------------------ |
| `node -v`                                           | 現在のNode.jsバージョン確認    |
| `pnpm list better-sqlite3`                          | better-sqlite3のバージョン確認 |
| `ls -la node_modules/better-sqlite3/build/Release/` | ネイティブモジュールの状態確認 |

### Task 2: 要件抽出

**機能要件（FR）**:

| ID    | 要件                                              | 優先度 |
| ----- | ------------------------------------------------- | ------ |
| FR-01 | better-sqlite3を現在のNode.jsバージョンで再ビルド | 高     |
| FR-02 | .nvmrcファイルでNode.jsバージョンを固定           | 高     |
| FR-03 | package.json enginesフィールドでバージョン制約    | 中     |
| FR-04 | Pre-installフックでバージョンチェック             | 中     |

**非機能要件（NFR）**:

| ID     | 要件                                       | 優先度 |
| ------ | ------------------------------------------ | ------ |
| NFR-01 | バージョン不一致時に明確なエラーメッセージ | 高     |
| NFR-02 | 開発者オンボーディングの簡素化             | 中     |
| NFR-03 | CI/CD環境との互換性                        | 中     |

### Task 3: 受け入れ基準作成

| 要件  | 受け入れ基準                                                |
| ----- | ----------------------------------------------------------- |
| FR-01 | workflow-repository.test.tsの10個のテストが全て成功         |
| FR-02 | .nvmrcファイルが存在し、正しいバージョンが記載されている    |
| FR-03 | package.json enginesフィールドにNode.jsバージョン制約がある |
| FR-04 | 異なるNode.jsバージョンでpnpm install時に警告が表示される   |
