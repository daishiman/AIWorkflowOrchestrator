# Phase 2: スクリプト設計書

## 既存スクリプト分析

### scripts/setup-native-modules.sh

**目的**: ネイティブモジュール（better-sqlite3等）のアーキテクチャ・Node.jsバージョン検証とリビルド

**フロー**:

```
┌─────────────────────────────────────────────────────────┐
│ 1. 現在のアーキテクチャ取得                              │
│    - Node.js process.arch から取得                       │
│    - arm64/x64 → arm64/x86_64 に変換                    │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 2. better-sqlite3バイナリ検索                            │
│    - node_modules内を検索                                │
│    - 見つからない場合 → リビルドフラグ=true              │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 3. アーキテクチャ比較                                    │
│    - file コマンドでバイナリのアーキテクチャ取得         │
│    - 不一致の場合 → リビルドフラグ=true                  │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 4. 互換性テスト                                          │
│    - Node.jsから直接require('better-sqlite3')           │
│    - NODE_MODULE_VERSIONエラー検出 → リビルドフラグ=true │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 5. リビルド実行（必要な場合）                            │
│    - pnpm store prune でキャッシュクリア                 │
│    - pnpm rebuild better-sqlite3                        │
│    - 失敗時: pnpm install --force                       │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 6. 結果確認                                              │
│    - リビルド後のアーキテクチャ確認                      │
│    - 不正な場合はエラー終了                              │
└─────────────────────────────────────────────────────────┘
```

**評価**: ✅ 完璧な設計

### .husky/pre-push

**目的**: プッシュ前のCI相当チェック

**Node.jsバージョンチェックフロー**:

```
┌─────────────────────────────────────────────────────────┐
│ 1. .nvmrc存在確認                                        │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 2. メジャーバージョン比較                                │
│    - .nvmrc: 22.21.1 → 22                               │
│    - 現在: v22.x.x → 22                                 │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 3. 自動切替試行（不一致の場合）                          │
│    - fnm use                                            │
│    - nvm use                                            │
│    - volta run                                          │
└─────────────────────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────┐
│ 4. 結果処理                                              │
│    - 成功: テスト実行                                    │
│    - 失敗: SKIP_NATIVE_TESTS=true でlint/typecheckのみ  │
└─────────────────────────────────────────────────────────┘
```

**評価**: ✅ 適切な設計
