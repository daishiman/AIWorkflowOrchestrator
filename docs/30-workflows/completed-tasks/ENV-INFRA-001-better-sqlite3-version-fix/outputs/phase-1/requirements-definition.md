# Phase 1: 要件定義書

## 機能要件（FR）

| ID    | 要件                                                              | 優先度 | 受け入れ基準                                                        |
| ----- | ----------------------------------------------------------------- | ------ | ------------------------------------------------------------------- |
| FR-01 | better-sqlite3を現在のNode.jsバージョン・アーキテクチャで再ビルド | 高     | workflow-repository.test.tsの10個のテストが全て成功                 |
| FR-02 | .nvmrcファイルでNode.jsバージョンを固定                           | 高     | .nvmrcファイルが存在し、正しいバージョン（22.21.1）が記載されている |

## 問題の本質

今回の問題は**Node.jsバージョン不一致**ではなく、**アーキテクチャ不一致**でした。

- Node.jsバージョン: 22.21.1（正しい）
- アーキテクチャ: arm64を期待しているが、x86_64向けバイナリが読み込まれている

これはグローバルpnpmストアに古いバイナリがキャッシュされていることが原因です。

## 結論

既存の設定（.nvmrc、package.json engines、volta）は適切に設定されています。主な対応は：

1. better-sqlite3の再ビルド（`pnpm rebuild better-sqlite3`）
2. バージョンチェックスクリプトの確認・強化
3. ドキュメント更新（トラブルシューティング手順の追加）
