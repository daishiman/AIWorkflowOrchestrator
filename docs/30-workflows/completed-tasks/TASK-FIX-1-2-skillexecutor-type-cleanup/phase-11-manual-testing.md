## 目的

自動テストでは検証できないリファクタリング後の動作確認（型整合性、ランタイム動作）を手動で確認する。

## 実行タスク

- 型整合性検証: リファクタリング後の型定義が正しくimportされていることを確認
- ビルド検証: TypeScriptコンパイルが正常に完了することを確認
- ランタイム動作確認: アプリケーション起動時にエラーが発生しないことを確認

## テストカテゴリ

本タスクはリファクタリング（型定義の統一）のため、以下のカテゴリに絞って検証を行う：

- **型安全性テスト**: 共有型への統一により型エラーが発生しないこと
- **ビルドテスト**: TypeScriptコンパイルが成功すること
- **リグレッションテスト**: 既存機能が正常に動作すること
