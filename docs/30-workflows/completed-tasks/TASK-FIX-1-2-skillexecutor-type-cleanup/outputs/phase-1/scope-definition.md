## 1. スコープ概要

本タスクは、SkillExecutor.ts 内の重複型定義を正本（`@repo/shared/types/skill.ts`）に統合する **リファクタリングタスク** である。

機能追加やビジネスロジックの変更は行わない。

---

## 2. スコープ内（In Scope）

### 2.1 型定義の削除と統合

| 作業項目             | 詳細                                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------------------- |
| 完全一致型の削除     | ExecutionState, ExecutionInfo, SkillExecutionErrorCode, SkillExecutionError, ExecutionContext の5型を削除 |
| import 置換          | 削除した型を `@repo/shared` から import                                                                   |
| 差異型の統合         | SkillExecutionRequest, SkillExecutionResponse を正本拡張後に import                                       |
| ローカル型のリネーム | SkillStreamMessage → SkillExecutorStreamMessage                                                           |

### 2.2 正本の拡張

| 作業項目                    | 詳細                                                              |
| --------------------------- | ----------------------------------------------------------------- |
| SkillExecutionRequest 拡張  | skillId, timeout, sessionId, retryConfig プロパティ追加           |
| SkillExecutionResponse 拡張 | error 型を union 型に拡張                                         |
| RetryConfig 型追加          | SkillExecutor で使用する RetryConfig 型を正本に追加（必要な場合） |

### 2.3 テストコードの更新

| 作業項目        | 詳細                             |
| --------------- | -------------------------------- |
| 型参照の更新    | テストコード内の型参照を更新     |
| import 文の更新 | テストファイルの import 文を整理 |

### 2.4 ドキュメント更新

| 作業項目       | 詳細                            |
| -------------- | ------------------------------- |
| JSDoc コメント | 型の移動に伴う JSDoc 参照の更新 |
| 実装ガイド     | 型統合の経緯と使用方法の記載    |

---

## 3. スコープ外（Out of Scope）

### 3.1 明示的に除外する項目

| 項目                                 | 除外理由                       |
| ------------------------------------ | ------------------------------ |
| SkillExecutor のビジネスロジック変更 | 本タスクはリファクタリングのみ |
| 新機能の追加                         | 機能追加は別タスクで対応       |
| パフォーマンス最適化                 | 本タスクのスコープ外           |
| IPC チャンネル定義の変更             | 通信仕様は変更しない           |
| Renderer 側の大規模変更              | 型変更への追従のみ             |
| 他の services/ 配下のファイル        | SkillExecutor.ts のみが対象    |
| SkillMetadata 型の変更               | 既に Omit で適切に処理済み     |

### 3.2 将来タスクへの引き継ぎ

| 項目                          | 引き継ぎ先                                 |
| ----------------------------- | ------------------------------------------ |
| SkillStreamMessage の完全統合 | Discriminated Union への完全移行は別タスク |
| RetryConfig の共通化検討      | 他モジュールでも使用する場合は別タスク     |
