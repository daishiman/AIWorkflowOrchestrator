## 目的

Phase 2で作成した設計の妥当性を検証し、実装に進む前に問題がないことを確認する。

## 背景

型エクスポートの追加は、パッケージの公開APIを変更するため、既存のコードベースへの影響や互換性を事前に確認する必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 要件適合性の確認

**目的**: 設計がPhase 1の要件を満たしているか確認する

**実行手順**:

1. 必要な型が全てエクスポートされているか確認:
   - [ ] `Community`
   - [ ] `CommunitySummary`
   - [ ] `StoredEntity`
   - [ ] `CommunityId`
   - [ ] `EntityId`

2. 追加で有用な型もエクスポートされているか確認:
   - [ ] `CommunityStructure`
   - [ ] `GraphNode`, `GraphEdge`, `GraphPath`
   - [ ] エラー関連（`CommunityErrorCode`, `CommunityDetectionError`）

3. 受け入れ基準との照合:
   - [ ] `import { ... } from "@repo/shared"` でインポート可能
   - [ ] 循環参照なし
   - [ ] 既存エクスポートとの重複なし

**期待される成果物**:

- 要件適合性チェック結果

---

### タスク2: 循環参照チェック

**目的**: 設計が循環参照を引き起こさないことを検証する

**実行手順**:

1. 依存関係グラフを確認:

```
packages/shared/index.ts
  └─ ./src/services/graph/index.ts
       └─ ./types.ts
            └─ ../../types/rag/branded.ts
                 └─ (依存なし)
```

2. 循環参照チェックリスト:
   - [ ] `services/graph` → `index.ts` への依存がない
   - [ ] `types/rag/branded` → `services/graph` への依存がない
   - [ ] 追加するエクスポートがサイクルを作らない

3. 結論を記録

**期待される成果物**:

- 循環参照チェック結果

---

### タスク3: 既存エクスポートとの重複確認

**目的**: 追加するエクスポートが既存のものと重複していないことを確認する

**実行手順**:

1. 現在の `export * from "./types"` の内容を確認
2. `CommunityId`, `EntityId` が既にエクスポートされているか確認
3. 重複がある場合の対応方針を決定

**期待される成果物**:

- 重複確認結果

---

### タスク4: レビュー結果を判定

**目的**: 設計レビューの最終判定を行う

**実行手順**:

1. 以下の観点で判定:

| 観点       | 判定基準                                   |
| ---------- | ------------------------------------------ |
| 要件適合性 | 必要な型が全てエクスポートされている       |
| 循環参照   | 循環参照が発生しない                       |
| 既存互換性 | 既存のエクスポートが壊れない               |
| コード品質 | TypeScriptのベストプラクティスに従っている |

2. 判定結果:

| 判定     | 条件             | 次のアクション            |
| -------- | ---------------- | ------------------------- |
| PASS     | 全観点で問題なし | Phase 4へ進行             |
| MINOR    | 軽微な指摘あり   | 指摘対応後、Phase 4へ     |
| MAJOR    | 重大な問題あり   | Phase 2へ戻る             |
| CRITICAL | 致命的な問題あり | Phase 1へ戻りユーザー確認 |

**期待される成果物**:

- レビュー結果判定書（`outputs/phase-3/review-result.md`）
