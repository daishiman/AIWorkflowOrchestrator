## 検出された未タスク候補: 1件

### UT-SEC-001: detectProvider実装によるvalidateメソッド活用

| 項目     | 内容                                                                                                                                                                                  |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ソース   | Phase 10最終レビュー MINOR指摘#1                                                                                                                                                      |
| 概要     | `consumeState`はプロバイダー検証なしでstateを消費するため、`validate`によるプロバイダー照合の方がセキュアだが、現在コールバック側でプロバイダーを特定する`detectProvider`関数が未実装 |
| 優先度   | Low                                                                                                                                                                                   |
| 対応方針 | DEBT-SEC-002（PKCE実装）またはDEBT-SEC-003（URL詳細検証）と合わせて対応。コールバックURLからプロバイダーを検出する仕組みを実装し、`consumeState`を`validate`に置換する                |
| 影響範囲 | `apps/desktop/src/main/index.ts`（handleAuthCallback内）                                                                                                                              |

**補足**: 現在の`consumeState`でもstate自体の検証（存在確認・有効期限・ワンタイムユース）は行われており、CSRF防止の基本要件は満たしている。プロバイダー照合は追加のセキュリティ強化となる。
