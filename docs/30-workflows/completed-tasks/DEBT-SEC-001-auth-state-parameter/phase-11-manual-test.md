## 目的

実際のOAuth認証フローでstate parameter検証が正しく動作することを手動で確認する。自動テストでカバーできない実環境での動作検証を行う。

## 実行タスク

- 機能テスト: 各OAuthプロバイダーでのstate検証（正常系）
- セキュリティテスト: 不正なstate・state欠落時の異常系検証
- リグレッション: 既存の認証フローが壊れていないことの確認

### 実行手順

1. アプリをプレビューモードで起動する：

   ```bash
   pnpm --filter @repo/desktop preview
   ```

2. DevTools を開き、コンソールタブを確認する

3. 各テストケースを実行し、ターミナルログとDevToolsコンソールを確認する

4. 異常系テストの場合は、コールバックURLを手動で改ざんしてテストする：

   ```
   # 正常なコールバックURL例
   aiworkflow://auth/callback#access_token=xxx&state=正常なstate

   # 改ざんURL（テスト4用）
   aiworkflow://auth/callback#access_token=xxx&state=tampered_value

   # state欠落URL（テスト5用）
   aiworkflow://auth/callback#access_token=xxx
   ```
