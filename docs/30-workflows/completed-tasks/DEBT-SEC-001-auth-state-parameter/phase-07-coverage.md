## カバレッジ不足時のループバック

カバレッジ基準を満たさない場合、以下の手順でPhase 6に戻る:

### ループバック判定

| 条件           | 対応                                    |
| -------------- | --------------------------------------- |
| Line < 80%     | Phase 6に戻り、未カバー行のテスト追加   |
| Branch < 60%   | Phase 6に戻り、未カバー分岐のテスト追加 |
| Function < 80% | Phase 6に戻り、未カバー関数のテスト追加 |
| 全基準達成     | Phase 8（リファクタリング）へ進行       |

### ループバック手順

1. カバレッジレポートから未カバー行/分岐を特定
2. Phase 6のテストケースに追加テストを設計
3. テスト実装・実行
4. 再度Phase 7でカバレッジ測定
5. 基準達成まで繰り返し
