## スコープ概要

本機能は、AIWorkflowOrchestratorにおいてユーザーがスキル実行時の認証方式を選択できるようにする機能である。サブスクリプション認証（Claude Code CLIトークン経由）とAPIキー認証（Anthropic APIキー直接設定）の2つの認証方式をサポートする。

---

## 含むもの（In Scope）

### 機能

| ID   | 機能                   | 詳細                                              |
| ---- | ---------------------- | ------------------------------------------------- |
| IS-1 | 認証方式選択UI         | セグメントコントロールで2つの認証方式を選択       |
| IS-2 | 認証方式の永続化       | electron-storeで選択を保存、再起動後も維持        |
| IS-3 | サブスクリプション認証 | macOS Keychain経由でClaude Code CLIトークンを取得 |
| IS-4 | APIキー認証            | 既存AuthKeyServiceを活用したAPIキー認証           |
| IS-5 | 認証状態表示           | 現在の認証方式と認証有効性をUIに表示              |
| IS-6 | 認証エラーハンドリング | エラー種別に応じたメッセージとガイダンスを表示    |
| IS-7 | 確認ダイアログ         | 認証方式変更時の確認ダイアログ                    |
| IS-8 | IPCチャンネル拡張      | auth-mode:get/set/status/validateチャンネル       |

### バックエンドサービス

| ID    | サービス                | 詳細                                     |
| ----- | ----------------------- | ---------------------------------------- |
| IS-9  | AuthModeService         | 認証方式の取得/設定/バリデーションを統括 |
| IS-10 | SubscriptionAuthService | keytarを使用したKeychain経由トークン取得 |
| IS-11 | APIKeyAuthService拡張   | 既存AuthKeyServiceに認証モード概念を追加 |

### プラットフォーム

| ID    | 対象  | 備考                        |
| ----- | ----- | --------------------------- |
| IS-12 | macOS | 初期リリースはmacOSのみ対応 |

### テスト

| ID    | テスト種別       | 詳細                                         |
| ----- | ---------------- | -------------------------------------------- |
| IS-13 | 単体テスト       | 各サービスクラスの単体テスト                 |
| IS-14 | 統合テスト       | IPC通信を含む統合テスト                      |
| IS-15 | UIコンポーネント | 認証方式セレクタ、状態インジケーターのテスト |

## 含まないもの（Out of Scope）

| OS-1 | Windows/Linuxサポート        | macOS Keychain依存のため、別タスクとして対応        |
| OS-2 | トークン自動リフレッシュ     | Claude Code CLIが管理、本機能では参照のみ           |
| OS-3 | サブスクリプション契約管理   | Webダッシュボードで管理、本機能はトークン利用のみ   |
| OS-4 | 複数アカウント切り替え       | 単一アカウント前提、複数アカウントは別タスク        |
| OS-5 | OAuth認証フロー実装          | CLIで認証済みトークンを利用、認証フロー自体は対象外 |
| OS-6 | APIキー作成・管理            | Anthropicコンソールで管理、本機能は設定・利用のみ   |
| OS-7 | 認証ログのダッシュボード     | 監査ログは記録するが、表示UIは別タスク              |
| OS-8 | オフラインモード             | 認証はオンライン前提                                |
| OS-9 | 生体認証（Touch ID/Face ID） | macOS Keychainの標準機能を利用、追加実装なし        |

### バックエンド

| OS-10 | サーバーサイド認証管理 | クライアントサイドのみ、サーバー連携は別タスク |

## リスクと制約

### リスク

| ID  | リスク                          | 影響 | 対策                                       |
