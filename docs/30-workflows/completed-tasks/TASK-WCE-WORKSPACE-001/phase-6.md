## 目的

Phase 5の実装に対してテストを拡充し、カバレッジ目標を達成する。

## 実行タスク

### Task 1: カバレッジ分析

テストカバレッジを測定し、不足領域を特定する。

```bash
pnpm --filter @repo/desktop test:coverage
```

### Task 2: 境界値テスト追加

| テストケース                                      | 対象関数             |
| ------------------------------------------------- | -------------------- |
| workspacePathが最大長の場合                       | isWithinWorkspace    |
| ファイルパスに特殊文字が含まれる場合              | extractFilesFromTree |
| 非常に深いネスト（100階層以上）の場合             | extractFilesFromTree |
| folderFileTreesが非常に大きい（1000ファイル）場合 | flattenFileTrees     |

### Task 3: エッジケーステスト追加

| テストケース                                    | 期待結果                 |
| ----------------------------------------------- | ------------------------ |
| workspacePathがundefinedの場合                  | nullとして扱われる       |
| フォルダが追加/削除された直後のアクセス         | 最新の状態が反映される   |
| 同時に複数のread-fileリクエストが発行された場合 | 全て正常に処理される     |
| ファイルツリーに循環参照がある場合（異常系）    | 適切にエラーハンドリング |

### Task 4: 統合テスト拡充

| テストカテゴリ     | 追加テスト内容                                  |
| ------------------ | ----------------------------------------------- |
| API接続テスト      | workspacePathあり/なしの両パターン              |
| データフローテスト | Workspace Slice更新→useFileContext再計算→UI反映 |
| エラーハンドリング | PERMISSION_DENIED時のユーザーフィードバック     |
