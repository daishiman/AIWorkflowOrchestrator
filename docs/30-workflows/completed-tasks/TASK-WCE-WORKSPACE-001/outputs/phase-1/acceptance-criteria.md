# 受け入れ基準: TASK-WCE-WORKSPACE-001

## 機能要件の受け入れ基準

| FR/NFR | 受け入れ基準                                                                        |
| ------ | ----------------------------------------------------------------------------------- |
| FR-01  | `getWorkspacePath()`がリクエストパラメータからworkspacePathを取得し、それを使用する |
| FR-02  | `getAvailableFiles()`がfolderFileTreesの全ファイルパスを配列で返す                  |
| FR-03  | ワークスペース外パスで`chat-edit:read-file`を呼ぶとPERMISSION_DENIEDエラーが返る    |
| FR-04  | workspacePathがnullまたはundefinedの場合、nullを返す                                |
| NFR-01 | パス取得処理の実行時間が10ms未満であることをテストで検証                            |
| NFR-02 | Workspace Sliceの変更後、次のAPI呼び出しで最新の一覧が取得できる                    |
| NFR-03 | 既存のchat-edit:read-file, chat-edit:write-file APIが正常動作する                   |

## テストシナリオ

### FR-01: ワークスペースパス取得

| No  | シナリオ                       | 期待結果                                 |
| --- | ------------------------------ | ---------------------------------------- |
| 1   | workspacePathが指定された場合  | そのパスがワークスペース検証に使用される |
| 2   | workspacePathがnullの場合      | ワークスペース検証がスキップされる       |
| 3   | workspacePathがundefinedの場合 | ワークスペース検証がスキップされる       |

### FR-02: ファイル一覧取得

| No  | シナリオ                           | 期待結果                             |
| --- | ---------------------------------- | ------------------------------------ |
| 1   | folderFileTreesが空の場合          | 空配列が返される                     |
| 2   | 単一フォルダのファイルツリーがある | そのフォルダのファイル一覧が返される |
| 3   | 複数フォルダのファイルツリーがある | 全フォルダのファイル一覧が統合される |
| 4   | ネストされたディレクトリ構造       | 再帰的にファイルが抽出される         |

### FR-03: ワークスペース外アクセス制限

| No  | シナリオ                                  | 期待結果                           |
| --- | ----------------------------------------- | ---------------------------------- |
| 1   | ワークスペース内ファイルへのアクセス      | 正常にファイルが読み込まれる       |
| 2   | ワークスペース外ファイルへのアクセス      | PERMISSION_DENIEDエラーが返される  |
| 3   | パストラバーサルを含むパスへのアクセス    | PERMISSION_DENIEDエラーが返される  |
| 4   | workspacePathがnullでファイルへのアクセス | 検証がスキップされ正常読み込み可能 |

### FR-04: 未設定時のデフォルト値

| No  | シナリオ                  | 期待結果                        |
| --- | ------------------------- | ------------------------------- |
| 1   | workspace.foldersが空配列 | getAvailableFiles()が空配列返却 |
| 2   | folderFileTreesが空Map    | getAvailableFiles()が空配列返却 |
