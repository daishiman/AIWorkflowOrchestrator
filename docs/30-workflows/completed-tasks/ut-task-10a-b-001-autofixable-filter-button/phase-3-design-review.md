## 実行タスク

### Task 3-1: レビュー観点定義

- FR/NFR/AC 網羅性
- 既存UIとの回帰有無
- 単一責務原則（UIと状態の分離）

### Task 3-2: 設計差分レビュー

- `SuggestionList` 変更点レビュー
- `useSkillAnalysis` 変更点レビュー
- 型/命名/可読性レビュー

### Task 3-3: Gate判定

- PASS: そのまま Phase 4 へ進行
- MINOR: 修正指示を記録し Phase 4 と並行で解消
- MAJOR: Phase 2 へ差し戻し
