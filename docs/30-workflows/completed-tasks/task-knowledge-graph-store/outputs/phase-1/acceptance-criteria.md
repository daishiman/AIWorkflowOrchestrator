## 1. EntityStore 受け入れ基準

### 1.1 addEntity

| AC ID      | 受け入れ基準                                                                 | 優先度 |
| ---------- | ---------------------------------------------------------------------------- | ------ |
| AC-ENT-001 | 新規エンティティが正常に永続化される                                         | 必須   |
| AC-ENT-002 | 戻り値として `Result<StoredEntity, Error>` が返される                        | 必須   |
| AC-ENT-003 | 既存エンティティ（同一normalizedName）の場合、mentionCountが加算される       | 必須   |
| AC-ENT-004 | 既存エンティティの場合、aliasesが統合される                                  | 必須   |
| AC-ENT-005 | 名前は自動的に正規化（小文字化・空白正規化）されてnormalizedNameに保存される | 必須   |
| AC-ENT-006 | createdAt, updatedAtが自動設定される                                         | 必須   |

### 1.2 getEntity

| AC ID      | 受け入れ基準                                     | 優先度 |
| ---------- | ------------------------------------------------ | ------ |
| AC-ENT-010 | 指定IDのエンティティが正常に取得できる           | 必須   |
| AC-ENT-011 | 存在しないIDの場合、`Result.ok(null)` が返される | 必須   |
| AC-ENT-012 | EntityId型（Branded Type）でIDが受け取られる     | 必須   |

### 1.3 getEntityByName

| AC ID      | 受け入れ基準                                       | 優先度 |
| ---------- | -------------------------------------------------- | ------ |
| AC-ENT-020 | 正規化名で検索し、一致するエンティティを返す       | 必須   |
| AC-ENT-021 | 大文字小文字を区別せず検索できる                   | 必須   |
| AC-ENT-022 | 存在しない名前の場合、`Result.ok(null)` が返される | 必須   |

### 1.4 updateEntity

| AC ID      | 受け入れ基準                                               | 優先度 |
| ---------- | ---------------------------------------------------------- | ------ |
| AC-ENT-030 | 指定フィールドが正しく更新される                           | 必須   |
| AC-ENT-031 | 存在しないIDの場合、`EntityNotFoundError` が返される       | 必須   |
| AC-ENT-032 | updatedAtが自動更新される                                  | 必須   |
| AC-ENT-033 | 部分更新が可能（指定されていないフィールドは変更されない） | 必須   |

### 1.5 deleteEntity

| AC ID      | 受け入れ基準                                         | 優先度 |
| ---------- | ---------------------------------------------------- | ------ |
| AC-ENT-040 | エンティティが正常に削除される                       | 必須   |
| AC-ENT-041 | 関連するrelationsがCASCADE削除される                 | 必須   |
| AC-ENT-042 | 存在しないIDの場合、`EntityNotFoundError` が返される | 必須   |
| AC-ENT-043 | 関連するentity_communitiesが削除される               | 必須   |

### 1.6 searchEntities

| AC ID      | 受け入れ基準                            | 優先度 |
| ---------- | --------------------------------------- | ------ |
| AC-ENT-050 | type条件で絞り込みができる              | 必須   |
| AC-ENT-051 | name条件（部分一致）で絞り込みができる  | 必須   |
| AC-ENT-052 | limit, offsetによるページングが機能する | 必須   |
| AC-ENT-053 | 複合条件（AND）での絞り込みができる     | 推奨   |
| AC-ENT-054 | 該当なしの場合、空配列が返される        | 必須   |

### 1.7 bulkUpsertEntities

| AC ID      | 受け入れ基準                                         | 優先度 |
| ---------- | ---------------------------------------------------- | ------ |
| AC-ENT-060 | 複数エンティティが一括で追加/更新される              | 必須   |
| AC-ENT-061 | 1000件/秒以上の処理速度を達成する                    | 必須   |
| AC-ENT-062 | トランザクション内で処理される（全成功または全失敗） | 必須   |
| AC-ENT-063 | 各エンティティに対してupsertロジックが適用される     | 必須   |

## 2. RelationStore 受け入れ基準

### 2.1 addRelation

| AC ID      | 受け入れ基準                                                       | 優先度 |
| ---------- | ------------------------------------------------------------------ | ------ |
| AC-REL-001 | 証拠情報付きで関係が正常に作成される                               | 必須   |
| AC-REL-002 | 自己ループ（source == target）の場合、`SelfLoopError` が返される   | 必須   |
| AC-REL-003 | 証拠情報が0件の場合、`EvidenceRequiredError` が返される            | 必須   |
| AC-REL-004 | 起点エンティティが存在しない場合、`EntityNotFoundError` が返される | 必須   |
| AC-REL-005 | 終点エンティティが存在しない場合、`EntityNotFoundError` が返される | 必須   |
| AC-REL-006 | 証拠情報がrelation_evidenceテーブルに保存される                    | 必須   |
| AC-REL-007 | evidence_countが証拠件数で設定される                               | 必須   |

### 2.2 getRelation

| AC ID      | 受け入れ基準                                     | 優先度 |
| ---------- | ------------------------------------------------ | ------ |
| AC-REL-010 | 指定IDの関係が正常に取得できる                   | 必須   |
| AC-REL-011 | 証拠情報も含めて取得される                       | 必須   |
| AC-REL-012 | 存在しないIDの場合、`Result.ok(null)` が返される | 必須   |

### 2.3 deleteRelation

| AC ID      | 受け入れ基準                                 | 優先度 |
| ---------- | -------------------------------------------- | ------ |
| AC-REL-020 | 関係が正常に削除される                       | 必須   |
| AC-REL-021 | 関連するrelation_evidenceがCASCADE削除される | 必須   |
| AC-REL-022 | 存在しないIDでも正常終了する（冪等性）       | 推奨   |

### 2.4 getRelationsByEntity

| AC ID      | 受け入れ基準                                              | 優先度 |
| ---------- | --------------------------------------------------------- | ------ |
| AC-REL-030 | 指定エンティティを起点とする全関係が取得できる            | 必須   |
| AC-REL-031 | 指定エンティティを終点とする全関係が取得できる            | 必須   |
| AC-REL-032 | direction指定（outgoing/incoming/both）で絞り込みができる | 推奨   |
| AC-REL-033 | 該当なしの場合、空配列が返される                          | 必須   |

### 2.5 bulkAddRelations

| AC ID      | 受け入れ基準                             | 優先度 |
| ---------- | ---------------------------------------- | ------ |
| AC-REL-040 | 複数関係が一括で追加される               | 必須   |
| AC-REL-041 | 各関係に証拠情報必須チェックが適用される | 必須   |
| AC-REL-042 | 各関係に自己ループチェックが適用される   | 必須   |
| AC-REL-043 | トランザクション内で処理される           | 必須   |

## 5. エラー型 受け入れ基準

| エラークラス          | 使用条件                     | 含まれる情報       |
| --------------------- | ---------------------------- | ------------------ |
| EntityNotFoundError   | 指定エンティティが存在しない | エンティティID     |
| SelfLoopError         | 自己参照関係の作成試行       | 対象エンティティID |
| EvidenceRequiredError | 証拠なしでの関係作成試行     | 関係情報           |
| DatabaseError         | データベース操作エラー       | 元のエラー情報     |

## 6. 非機能要件 受け入れ基準

### 6.1 パフォーマンス

| AC ID      | 受け入れ基準                                      | 優先度 |
| ---------- | ------------------------------------------------- | ------ |
| AC-NFR-001 | 1000件のエンティティバッチ追加が1秒以内に完了する | 必須   |
| AC-NFR-002 | 10000件のエンティティ検索が2秒以内に完了する      | 必須   |
| AC-NFR-003 | 深度10のグラフ探索が5秒以内に完了する             | 必須   |

### 6.2 型安全性

| AC ID      | 受け入れ基準                                                        | 優先度 |
| ---------- | ------------------------------------------------------------------- | ------ |
| AC-NFR-010 | EntityId, RelationId, CommunityIdがBranded Typeとして定義されている | 必須   |
| AC-NFR-011 | 異なるID型を誤って使用した場合、コンパイルエラーになる              | 必須   |
| AC-NFR-012 | IDEで型情報が正しく表示される                                       | 必須   |

### 6.3 エラー処理

| AC ID      | 受け入れ基準                                 | 優先度 |
| ---------- | -------------------------------------------- | ------ |
| AC-NFR-020 | 全APIがResult<T, Error>型を返す              | 必須   |
| AC-NFR-021 | エラー時にスタックトレースが保持される       | 必須   |
| AC-NFR-022 | エラーメッセージが問題特定に十分な情報を含む | 必須   |
