## 1. 概要

### 1.1 目的

Knowledge Graph StoreはRAGパイプラインにおけるナレッジグラフ（知識グラフ）の永続化と操作を担当するリポジトリ層である。エンティティ（ノード）と関係（エッジ）のCRUD操作、グラフ探索機能を提供する。

### 1.2 背景

GraphRAG基盤として、テキストから抽出したエンティティと関係を構造化データとして永続化し、グラフ探索による高度な情報検索を実現する必要がある。

### 1.3 対象ユーザー

- RAGパイプライン（内部システム）
- エンティティ抽出サービス（内部システム）
- 関係抽出サービス（内部システム）

## 2. 機能要件（FR）

### 2.1 Entity CRUD（FR-001）

| 項目   | 内容                                 |
| ------ | ------------------------------------ |
| ID     | FR-001                               |
| 優先度 | 必須                                 |
| 説明   | エンティティの作成・取得・更新・削除 |

#### 詳細要件

| #        | 要件                     | 説明                                                                                                |
| -------- | ------------------------ | --------------------------------------------------------------------------------------------------- |
| FR-001-1 | エンティティ追加         | 新規エンティティを永続化する。既存エンティティの場合はupsert（mentionCount加算、aliases統合）を行う |
| FR-001-2 | エンティティ取得（ID）   | 指定IDのエンティティを取得する。存在しない場合はnullを返す                                          |
| FR-001-3 | エンティティ取得（名前） | 正規化名で検索し、一致するエンティティを返す                                                        |
| FR-001-4 | エンティティ更新         | 指定フィールドを更新する。存在しないIDの場合はエラー                                                |
| FR-001-5 | エンティティ削除         | エンティティと関連するrelationsをCASCADE削除する                                                    |
| FR-001-6 | エンティティ検索         | 条件（type, name等）に一致するエンティティリストを返す                                              |

### 2.2 Relation CRUD（FR-002）

| 項目   | 内容                                   |
| ------ | -------------------------------------- |
| ID     | FR-002                                 |
| 優先度 | 必須                                   |
| 説明   | 関係の作成・取得・削除（証拠情報付き） |

#### 詳細要件

| #        | 要件                 | 説明                                                               |
| -------- | -------------------- | ------------------------------------------------------------------ |
| FR-002-1 | 関係追加             | 証拠情報付きで関係を作成する。自己ループ（source == target）は禁止 |
| FR-002-2 | 関係取得（ID）       | 指定IDの関係を取得する。存在しない場合はnull                       |
| FR-002-3 | 関係削除             | 関係と関連するevidenceをCASCADE削除する                            |
| FR-002-4 | エンティティ関係取得 | 指定エンティティを起点または終点とする全関係を返す                 |
| FR-002-5 | 証拠必須チェック     | 関係作成時、最低1件の証拠情報を必須とする                          |

### 2.3 Community CRUD（FR-003）

| 項目   | 内容                               |
| ------ | ---------------------------------- |
| ID     | FR-003                             |
| 優先度 | 必須                               |
| 説明   | コミュニティの作成・取得・階層操作 |

#### 詳細要件

| #        | 要件                   | 説明                                                       |
| -------- | ---------------------- | ---------------------------------------------------------- |
| FR-003-1 | コミュニティ作成       | 新規コミュニティを作成する                                 |
| FR-003-2 | コミュニティ取得（ID） | 指定IDのコミュニティを取得する                             |
| FR-003-3 | 階層レベル検索         | 指定階層レベルのコミュニティリストを返す                   |
| FR-003-4 | 子コミュニティ取得     | 指定コミュニティの子コミュニティリストを返す               |
| FR-003-5 | メンバー取得           | 指定コミュニティのメンバーエンティティリストを返す         |
| FR-003-6 | メンバー追加           | エンティティをコミュニティに追加する（entity_count更新）   |
| FR-003-7 | メンバー削除           | エンティティをコミュニティから削除する（entity_count更新） |

### 2.4 グラフ探索（FR-004）

| 項目   | 内容                          |
| ------ | ----------------------------- |
| ID     | FR-004                        |
| 優先度 | 必須                          |
| 説明   | BFSトラバーサル、最短経路探索 |

#### 詳細要件

| #        | 要件            | 説明                                                                  |
| -------- | --------------- | --------------------------------------------------------------------- |
| FR-004-1 | BFSトラバーサル | 指定エンティティから指定深度までのBFS探索結果を返す                   |

| FR-004-3 | 隣接ノード取得  | 指定エンティティに隣接するエンティティリストを返す                    |

## 3. 非機能要件（NFR）

### 3.1 パフォーマンス（NFR-001）

| 項目     | 要件                 | 基準          |
| -------- | -------------------- | ------------- |
| 処理速度 | バッチ操作の効率性   | 1000件/秒以上 |
| 検索速度 | 10000件検索          | 2秒以内       |
| 探索速度 | グラフ探索（深度10） | 5秒以内       |

### 3.2 データ整合性（NFR-002）

| 項目       | 要件             | 基準                     |
| ---------- | ---------------- | ------------------------ |
| 参照整合性 | CASCADE削除対応  | FK制約による自動削除     |
| 重複検出   | エンティティ重複 | normalizedNameによる検出 |
| 証拠必須   | 関係作成時       | 1件以上の証拠必須        |

### 3.3 型安全性（NFR-003）

| 項目   | 要件              | 基準                              |
| ------ | ----------------- | --------------------------------- |
| ID型   | Branded Types使用 | EntityId, RelationId, CommunityId |
| 型推論 | IDE補完対応       | 全APIで型情報が表示される         |

### 3.4 エラー処理（NFR-004）

| 項目       | 要件             | 基準                                 |
| ---------- | ---------------- | ------------------------------------ |
| 戻り値     | Result型パターン | ok/err による明示的処理              |
| エラー分類 | カスタムエラー型 | EntityNotFoundError, SelfLoopError等 |

## 4. スコープ

### 4.1 スコープ内

| 機能                        | 説明                                   |
| --------------------------- | -------------------------------------- |
| Entity CRUD                 | エンティティの作成・取得・更新・削除   |
| Relation CRUD               | 関係の作成・取得・削除（証拠情報付き） |
| Community CRUD              | コミュニティの作成・取得・階層操作     |
| グラフ探索（BFS、最短経路） | トラバーサル、パス検索                 |
| バッチ操作                  | 一括追加・更新                         |
| 統計情報取得                | グラフ統計                             |

### 4.2 スコープ外

| 機能                            | 説明                           |
| ------------------------------- | ------------------------------ |
| エンティティ抽出（NER）         | 上位レイヤーの責務             |
| 関係抽出（Relation Extraction） | 上位レイヤーの責務             |
| コミュニティ検出                | Leidenアルゴリズム等は別タスク |
| ベクトル類似検索                | 将来対応（DiskANN統合後）      |

## 5. 接続要件

### 5.1 Store間連携

```
┌─────────────────────────────────────────────────────────────┐
│                    GraphQueryService                         │
│   (traverse, findShortestPath, getNeighbors, getStats)      │
└─────────────────────────────────────────────────────────────┘
        │                    │                    │
        ▼                    ▼                    ▼
┌───────────────┐   ┌───────────────┐   ┌───────────────────┐
│  EntityStore  │◀─▶│ RelationStore │   │  CommunityStore   │
│               │   │               │   │                   │
│ - addEntity   │   │ - addRelation │   │ - create          │
│ - getEntity   │   │ - getRelation │   │ - findById        │
│ - updateEntity│   │ - deleteRel.  │   │ - addMember       │
│ - deleteEntity│   │ - getRelBy... │   │ - removeMember    │
│ - searchEnt.. │   │               │   │                   │
└───────────────┘   └───────────────┘   └───────────────────┘
        │                    │
        │                    ▼
        │           ┌───────────────────┐
        │           │RelationEvidence   │
        │           │Store              │
        │           │                   │
        │           │ - addEvidence     │
        │           │ - getEvidences    │
        └──────────▶│ - deleteEvidence  │
                    └───────────────────┘
```

### 5.2 データフロー

| フロー                                | 説明                             |
| ------------------------------------- | -------------------------------- |
| アプリ層 → Store層                    | RAGパイプラインからのAPI呼び出し |
| Store層 → Drizzle ORM                 | SQLクエリ生成・実行              |
| Drizzle ORM → SQLite                  | データベース操作                 |
| EntityStore → RelationStore           | EntityIdによる参照               |
| RelationStore → RelationEvidenceStore | 証拠情報の管理                   |
| EntityStore → CommunityStore          | メンバーシップ管理               |

### 5.3 外部連携

| 連携先           | 用途                       |
| ---------------- | -------------------------- |
| RAGパイプライン  | エンティティ・関係の永続化 |
| エンティティ抽出 | 抽出結果の保存             |
| 関係抽出         | 関係・証拠の保存           |

## 6. データベーステーブル

### 6.1 対象テーブル

| テーブル           | 用途                          | 実装状況    |
| ------------------ | ----------------------------- | ----------- |
| entities           | Knowledge Graphノード         | ✅ 実装済み |
| relations          | Knowledge Graphエッジ         | ✅ 実装済み |
| relation_evidence  | 関係の証拠チャンク            | ✅ 実装済み |
| communities        | Leidenクラスター              | ✅ 実装済み |
| entity_communities | エンティティ-コミュニティ中間 | ✅ 実装済み |
| chunk_entities     | チャンク-エンティティ中間     | ✅ 実装済み |

### 6.2 主要カラム

#### entities

| カラム           | 型      | 説明               |
| ---------------- | ------- | ------------------ |
| id               | TEXT    | 主キー（UUID）     |
| name             | TEXT    | エンティティ名     |
| type             | TEXT    | エンティティ種別   |
| description      | TEXT    | エンティティの説明 |

| カラム           | 型      | 説明               |
| ---------------- | ------- | ------------------ |

| target_entity_id | TEXT    | 終点エンティティID |
| relation_type    | TEXT    | 関係種別           |

## 7. 制約条件

### 7.1 技術的制約

| 制約         | 説明                              |
| ------------ | --------------------------------- |
| データベース | SQLite（Turso統一アーキテクチャ） |
| ORM          | Drizzle ORM                       |
| 言語         | TypeScript 5.x                    |
| ランタイム   | Node.js                           |

### 7.2 ビジネス制約

| 制約           | 説明                                |
| -------------- | ----------------------------------- |
| 証拠必須       | 関係作成時は最低1件の証拠情報が必須 |
| 自己ループ禁止 | source == target の関係は作成不可   |
| ソフトデリート | deleted_atによる論理削除対応        |
