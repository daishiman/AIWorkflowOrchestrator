### タスク3: ゲート判定

**目的**: Phase 11 への進行可否を判定する

**実行手順**:

1. 以下の判定基準に従ってゲート判定を行う:

   | 判定     | 条件                           | 次のアクション                     |
   | -------- | ------------------------------ | ---------------------------------- |
   | PASS     | 全 AC 満たし、全品質ゲート通過 | Phase 11 へ進行                    |
   | MINOR    | 軽微な指摘あり                 | 指摘対応後、Phase 11 へ進行        |
   | MAJOR    | 重大な問題あり                 | 影響範囲に応じて Phase 5〜8 へ戻る |
   | CRITICAL | 致命的な問題あり               | Phase 1 へ戻りユーザー確認         |

2. 判定結果を `outputs/phase-10/gate-decision.md` に記録する

**期待される成果物**:

- `outputs/phase-10/gate-decision.md`（ゲート判定書）
