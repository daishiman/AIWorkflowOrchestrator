## 1. スコープ定義

### 1.1 スコープ内

| カテゴリ         | 内容                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| アルゴリズム実装 | Leidenアルゴリズムのコア処理（ローカル移動、リファインメント、集約） |
| コミュニティ検出 | モジュラリティ最適化によるクラスタリング                             |
| 階層構造         | 複数レベルの階層的コミュニティ構造の構築                             |
| パラメータ制御   | resolution, maxLevels, minCommunitySize, seed                        |
| 永続化           | communitiesテーブルへの保存、エンティティマッピング                  |
| クエリ機能       | エンティティ/レベルによるコミュニティ取得                            |
| インターフェース | ICommunityDetectorの定義と実装                                       |
| 型定義           | Community, CommunityStructure, CommunityDetectionOptions             |

### 1.2 スコープ外

| カテゴリ             | 内容                               | 理由             |
| -------------------- | ---------------------------------- | ---------------- |
| コミュニティ要約生成 | LLMによるコミュニティ説明文生成    | CONV-08-03で実装 |
| ベクトル類似検索     | コミュニティのベクトル類似検索     | 将来タスク       |
| リアルタイム更新     | グラフ変更時の自動再検出           | 将来タスク       |
| 分散処理             | 大規模グラフの分散コミュニティ検出 | 将来タスク       |
| UI                   | コミュニティ可視化UI               | 別レイヤー       |

### 1.3 前提条件

| 前提条件                 | 詳細                                       |
| ------------------------ | ------------------------------------------ |
| CONV-08-01完了           | Knowledge Graphストアが実装済み            |
| IKnowledgeGraphStore存在 | グラフデータ取得インターフェースが利用可能 |
| データベーススキーマ存在 | communitiesテーブルが定義済み              |
| Branded Types定義済み    | EntityId, CommunityId等が利用可能          |

### 1.4 制約条件

| 制約               | 詳細                     |
| ------------------ | ------------------------ |
| 言語               | TypeScript 5.x           |
| データベース       | SQLite/Turso (libSQL)    |
| ORM                | Drizzle ORM              |
| エラーハンドリング | Result<T, Error>パターン |

## 2. 機能要件 (FR) 分類

### 2.1 FR一覧

| FR-ID  | 名称                               | 優先度 | 説明                                      |
| ------ | ---------------------------------- | ------ | ----------------------------------------- |
| FR-001 | コミュニティ検出                   | 必須   | Leidenアルゴリズムによる検出              |
| FR-002 | 階層的コミュニティ構造             | 必須   | 複数レベルの階層構造構築                  |
| FR-003 | パラメータによる検出制御           | 必須   | resolution, maxLevels等のオプション       |
| FR-004 | 検出結果の永続化                   | 必須   | DBへのコミュニティ保存                    |
| FR-005 | コミュニティ取得                   | 必須   | エンティティ/レベルからのコミュニティ取得 |
| FR-006 | ICommunityDetectorインターフェース | 必須   | 抽象インターフェース定義                  |

### 2.2 FR詳細

#### FR-001: コミュニティ検出

**記述形式**: システムは[Leidenアルゴリズム]を使用して[Knowledge Graphからコミュニティを検出]する。

| サブ機能 | 説明                                             |
| -------- | ------------------------------------------------ |
| FR-001-1 | ローカル移動フェーズ（モジュラリティゲイン計算） |
| FR-001-2 | リファインメントフェーズ（品質改善）             |
| FR-001-3 | 集約フェーズ（ノード統合）                       |
| FR-001-4 | 収束判定                                         |

#### FR-002: 階層的コミュニティ構造

**記述形式**: システムは[検出結果]から[親子関係を持つ階層構造]を構築する。

| サブ機能 | 説明                     |
| -------- | ------------------------ |
| FR-002-1 | レベル別コミュニティ生成 |
| FR-002-2 | 親コミュニティID設定     |
| FR-002-3 | 子コミュニティID配列管理 |

#### FR-003: パラメータによる検出制御

**記述形式**: ユーザーは[オプションパラメータ]を指定して[検出動作を制御]できる。

| パラメータ       | 説明                       |
| ---------------- | -------------------------- |
| resolution       | コミュニティ粒度制御       |
| maxLevels        | 最大階層レベル制限         |
| minCommunitySize | 最小コミュニティサイズ制限 |
| seed             | 再現性のための乱数シード   |
| maxIterations    | 最大イテレーション数制限   |

#### FR-004: 検出結果の永続化

**記述形式**: システムは[検出したコミュニティ]を[データベースに永続化]する。

| サブ機能 | 説明                                    |
| -------- | --------------------------------------- |
| FR-004-1 | 既存コミュニティ削除                    |
| FR-004-2 | コミュニティ挿入                        |
| FR-004-3 | エンティティ-コミュニティマッピング保存 |

#### FR-005: コミュニティ取得

**記述形式**: システムは[エンティティIDまたはレベル]から[コミュニティ情報を取得]する。

| サブ機能 | 説明                                         |
| -------- | -------------------------------------------- |
| FR-005-1 | エンティティIDから全レベルのコミュニティ取得 |
| FR-005-2 | 指定レベルのコミュニティ一覧取得             |
| FR-005-3 | コミュニティのメンバーエンティティ取得       |

## 6. リスクと緩和策

| リスク                   | 影響度 | 発生確率 | 緩和策                          |
| ------------------------ | ------ | -------- | ------------------------------- |
| 大規模グラフでの性能低下 | 高     | 中       | 分割処理の検討、キャッシュ導入  |
| メモリ不足               | 高     | 低       | ストリーミング処理の検討        |
| 収束しない               | 中     | 低       | maxIterations制限、早期終了条件 |
| 品質の低いコミュニティ   | 中     | 低       | リファインメントフェーズの強化  |
