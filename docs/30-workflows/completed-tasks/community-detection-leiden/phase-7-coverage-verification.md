## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。未達の場合はPhase 6へ戻る。

## 背景

テストカバレッジ確認は、リファクタリングに進む前の品質ゲートとして機能する。カバレッジが不足している状態でリファクタリングを行うと、バグの見逃しリスクが高まる。

## 実行手順

### 1. カバレッジ再測定

```bash
pnpm --filter @repo/shared test:coverage
```

### 2. 統合テスト実行

```bash
pnpm --filter @repo/shared test:integration
```

### 3. 判定

- **基準達成**: Phase 8へ進行
- **基準未達**: Phase 6へ戻り、テスト拡充を継続

### 4. レポート出力

カバレッジレポートを以下の形式で出力:

```markdown

| 指標              | 達成値 | 目標 | 判定      |
| ----------------- | ------ | ---- | --------- |
| Line Coverage     | XX%    | 80%  | PASS/FAIL |
| Branch Coverage   | XX%    | 60%  | PASS/FAIL |
| Function Coverage | XX%    | 80%  | PASS/FAIL |

## 統合テスト結果

| カテゴリ           | 成功 | 失敗 | 判定      |
| ------------------ | ---- | ---- | --------- |
| GraphStore連携     |      |      | PASS/FAIL |
| データフロー       |      |      | PASS/FAIL |
| エラーハンドリング |      |      | PASS/FAIL |
| 再現性             |      |      | PASS/FAIL |
```
