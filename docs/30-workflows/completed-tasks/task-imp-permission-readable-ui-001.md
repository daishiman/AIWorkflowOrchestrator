## 1. なぜこのタスクが必要か（Why）

### 1.1 背景

specification.mdのUI/UX仕様では、権限確認ダイアログの将来対応として「人間可読な操作説明」への移行が言及されている。現在のPermissionDialogは、技術的な引数（コマンド文字列、JSONオブジェクト）をそのまま表示しているが、非技術者ユーザーにとっては理解しにくい場合がある。

### 1.2 問題点・課題

| 課題               | 詳細                                               |
| ------------------ | -------------------------------------------------- |
| 技術的表示の難解さ | `ls -la /path/to/dir` が何をするか非技術者には不明 |
| コンテキスト欠如   | 操作の目的や影響が伝わりにくい                     |
| 意思決定の困難さ   | 許可/拒否の判断材料が不十分な場合がある            |

### 1.3 放置した場合の影響

| 影響カテゴリ | 影響内容                                 | 重要度 |
| ------------ | ---------------------------------------- | ------ |
| UX品質       | 非技術者ユーザーが操作内容を理解できない | 中     |
| 信頼性       | 理解できない操作を許可することへの不安   | 中     |
| 採用障壁     | 技術者以外へのプロダクト展開が困難       | 中     |

---

## 2. 何を達成するか（What）

### 2.1 目的

PermissionDialogの操作説明を自然言語化し、非技術者ユーザーでも操作内容を理解して適切な判断ができるようにする。

### 2.2 最終ゴール

- [ ] ツール操作が日本語の自然文で説明される
- [ ] 技術的詳細は「詳細を表示」で展開可能
- [ ] 10種類以上のツールに対応する説明テンプレートが用意される
- [ ] 既存テストが全てPASSする
- [ ] 新規テストが追加される

### 2.3 スコープ

**含まれるもの**:

- ツール別説明テンプレートの実装
- 説明文生成ロジック
- 詳細展開UI
- テストケースの追加

**含まれないもの**:

- 多言語対応（日本語のみ）
- AI生成による動的説明文
- 説明文のカスタマイズ設定

### 2.4 成果物

| 成果物               | パス                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 修正後コンポーネント | `apps/desktop/src/renderer/components/skill/PermissionDialog.tsx`                |

## 4. 実行手順

### Phase 1: 説明テンプレート設計

**目的**: ツール別の人間可読な説明テンプレートを設計

**手順**:

1. 各ツールの典型的な操作を分析
2. 日本語説明テンプレートを作成
3. プレースホルダー（{path}, {command}等）を定義

**説明テンプレート例**:

```typescript
const toolDescriptions: Record<
  string,
  (args: Record<string, unknown>) => string
> = {
  Bash: (args) => `「${args.command}」コマンドを実行します`,
  Read: (args) => `「${args.path}」ファイルを読み取ります`,
  Write: (args) => `「${args.path}」ファイルに書き込みます`,
  Edit: (args) => `「${args.path}」ファイルを編集します`,
  Glob: (args) => `「${args.pattern}」パターンでファイルを検索します`,
  Grep: (args) => `「${args.pattern}」を含むファイルを検索します`,
};
```

**成果物**: permissionDescriptions.ts

**完了条件**:

- [ ] 10種類以上のツールテンプレートが定義されている
- [ ] デフォルトテンプレートが存在する

### Phase 2: UI実装

**目的**: 説明文表示と詳細展開UIを実装

**手順**:

1. PermissionDialog.tsxに説明文表示を追加
2. 「詳細を表示」折りたたみUIを実装
3. 技術的詳細を折りたたみ内に移動

**成果物**: 修正後のPermissionDialog.tsx

**完了条件**:

- [ ] 説明文が本文に表示される
- [ ] 詳細展開で技術情報が表示される
- [ ] 展開/折りたたみがキーボード操作可能

### Phase 3: テスト

**目的**: 説明文表示のテストを追加

**手順**:

1. 既存テストが全てPASSすることを確認
2. 説明テンプレートのユニットテストを追加
3. UI表示テストを追加

**成果物**: 追加テスト

**完了条件**:

- [ ] 全テストPASS
- [ ] カバレッジ基準維持
