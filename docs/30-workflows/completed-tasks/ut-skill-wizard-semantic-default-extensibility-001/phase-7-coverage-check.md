## 目的

変更した関数・ブロックのカバレッジを可視化し、保護されていない分岐がないことを確認する。
Phase 5 の実装変更（`resolveSemanticLabel()` の shared 外部化）と
Phase 6 の拡張テストが組み合わさって、変更ファイルの全コードパスが
テストで保護されていることを定量的に示す。

> **NOTE: Feedback BEFORE-QUIT-002 適用** — カバレッジ対象範囲を明示し、
> **変更ファイル外を対象外**とする。変更していないファイルのカバレッジ低下を
> 問題視しないよう、計測前にスコープを宣言すること。
