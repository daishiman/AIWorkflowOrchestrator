### 「許容」判定の根拠（references リンク切れ 149件）

`aiworkflow-requirements` は 150個の references ファイルを持つ大規模仕様スキル。SKILL.md に全ファイルへの直接リンクを記載すると 500行制限を超過するリスクがある。そのため、以下の運用が意図的に設計されている:

1. `indexes/resource-map.md` で全ファイルのカテゴリ別一覧を提供
2. `indexes/topic-map.md` でセクション単位のナビゲーションを提供
3. `indexes/keywords.json` でキーワード検索を提供

この設計は Progressive Disclosure パターンに準拠しており、SKILL.md からの直接リンクは不要。

## 運用ルール提案

### 1. 許容 Warning の取り扱い

- **対象**: 大規模 references スキルの参照リンク切れ（Progressive Disclosure 設計に起因）
- **許容条件**: `indexes/resource-map.md` または `indexes/topic-map.md` で該当ファイルがナビゲーション可能であること
- **閾値**: 許容 Warning の件数増減は監視するが、Phase 12 の合否判定には影響しない

### 2. 要監視 Warning の取り扱い

- **対象**: description フィールドの Anchors/Trigger 未記載、少数の references リンク切れ
- **監視方法**: Phase 12 実行時に前回との件数比較を行い、件数増加があれば原因を調査
- **閾値**: 3件以上の増加で「要対応」に昇格

### 3. 要対応 Warning の取り扱い

- **対象**: 構造不備、必須フィールド未記入、SKILL.md 行数超過の可能性がある状態
- **対応期限**: 検出した Phase 内で修正、または未タスク指示書を作成
- **閾値**: 1件でも存在する場合は Phase 12 の完了条件に追加
