**判断**: ASCII フローチャートを維持する。理由は以下の3点:

1. ターミナル環境（Claude Code の主要実行環境）では Mermaid はレンダリングされず、ソースコードとして表示される
2. ASCII フローチャートは Mermaid ソースよりも可読性が高い（罫線文字による視覚的な分岐構造）
3. task-specification-creator/references/ 配下で Mermaid の使用前例がなく、一貫性を維持
