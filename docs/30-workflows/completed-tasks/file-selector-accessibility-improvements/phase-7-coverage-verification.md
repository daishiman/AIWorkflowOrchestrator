## 目的

Phase 6のテスト拡充結果を検証し、カバレッジ基準を満たすまでゲートとして確認する。未達の場合はPhase 6へ戻りテストを追加する。

## 背景

リファクタリング（Phase 8）に進む前に、十分なテストカバレッジが確保されていることを確認する。これにより、リファクタリング時の品質担保が可能になる。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ測定

**目的**: ユニットテストのカバレッジを測定し、基準達成を確認する

**実行手順**:

1. カバレッジレポートを生成:

```bash
pnpm --filter @repo/desktop test:coverage -- --grep "useFocusTrap\|FileSelectorModal\|FileSelectorTrigger\|FileSelectorFileList"
```

2. 以下の基準と照合:

| 指標              | 最低基準 | 推奨基準 | 現在値 | 判定 |
| ----------------- | -------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | 90%      | TBD    | TBD  |
| Branch Coverage   | 60%      | 70%      | TBD    | TBD  |
| Function Coverage | 80%      | 90%      | TBD    | TBD  |

3. 未カバー箇所を特定:
   - useFocusTrap: 未カバー行/分岐を列挙
   - FileSelectorModal: 未カバー行/分岐を列挙
   - FileSelectorTrigger: 未カバー行/分岐を列挙
   - FileSelectorFileList: 未カバー行/分岐を列挙

**期待される成果物**:

- ユニットテストカバレッジレポート（outputs/phase-7/unit-coverage.md）

### タスク4: 全テスト実行と結果確認

**目的**: 全テストを実行し、全て成功することを確認する

**実行手順**:

1. 全テストを実行:

```bash
pnpm --filter @repo/desktop test:run
```

2. テスト結果を確認:
   - 成功テスト数
   - 失敗テスト数
   - スキップテスト数

3. 失敗テストがある場合は原因を特定

**期待される成果物**:

- テスト実行結果レポート（outputs/phase-7/test-results.md）
