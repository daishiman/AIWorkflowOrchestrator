## 目的

UX・実環境でのアクセシビリティ動作確認を行う。自動テストでは検証できないスクリーンリーダーでの実際の操作感を確認する。

## 背景

Phase 10で最終レビューが完了した。実際のスクリーンリーダーやキーボードのみでの操作を手動で確認し、ユーザー体験の品質を保証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 開発環境での動作確認

**目的**: 開発環境でアプリケーションを起動し、基本動作を確認する

**実行手順**:

1. アプリケーションを起動:

```bash
pnpm --filter @repo/desktop dev
```

2. FileSelectorコンポーネントを含む画面に移動

3. 基本動作確認:
   - [ ] トリガーボタンをクリックしてモーダルが開く
   - [ ] ファイルリストが表示される
   - [ ] ファイルを選択できる
   - [ ] モーダルを閉じることができる

**期待される成果物**:

- 動作確認チェックリスト

---

### タスク2: キーボードナビゲーションテスト

**目的**: キーボードのみで全ての操作が可能であることを確認する

**実行手順**:

1. キーボードテストシナリオ:

| 操作                          | 期待動作                                     | 結果 |
| ----------------------------- | -------------------------------------------- | ---- |
| Tabでトリガーにフォーカス     | トリガーにフォーカスリングが表示される       | [ ]  |
| Enter/Spaceでモーダル開く     | モーダルが開き、フォーカスがモーダル内に移動 | [ ]  |
| Tabでモーダル内フォーカス移動 | フォーカスがモーダル内で循環する             | [ ]  |
| Shift+Tabで逆順移動           | フォーカスが逆順に移動する                   | [ ]  |
| ↓キーでリスト内移動           | 次のファイルにフォーカスが移動               | [ ]  |
| ↑キーでリスト内移動           | 前のファイルにフォーカスが移動               | [ ]  |
| Homeキー                      | 先頭のファイルにフォーカス移動               | [ ]  |
| Endキー                       | 末尾のファイルにフォーカス移動               | [ ]  |
| Enter/Spaceでファイル選択     | ファイルが選択される                         | [ ]  |
| Escapeでモーダル閉じる        | モーダルが閉じ、トリガーにフォーカスが戻る   | [ ]  |

2. 問題があれば記録

**期待される成果物**:

- キーボードナビゲーションテスト結果（outputs/phase-11/keyboard-test-results.md）

### タスク3: VoiceOver（macOS）テスト

**目的**: macOS VoiceOverでの操作と読み上げを確認する

**実行手順**:

1. VoiceOverを有効化: `Cmd + F5`

2. VoiceOverテストシナリオ:

| 操作                         | 期待される読み上げ                                   | 結果 |
| ---------------------------- | ---------------------------------------------------- | ---- |
| トリガーにフォーカス         | 「ファイルを選択、ボタン、折りたたまれています」     | [ ]  |
| モーダルを開く               | 「ファイルを選択、ダイアログ」                       | [ ]  |
| モーダル内でナビゲート       | モーダル内の要素が読み上げられる                     | [ ]  |
| ファイルリストにフォーカス   | 「ファイル一覧、リストボックス」                     | [ ]  |
| ファイル項目にフォーカス     | 「[ファイル名]、オプション、選択されていません」     | [ ]  |
| ファイルを選択               | 「[ファイル名]を選択しました」（aria-live）          | [ ]  |
| 選択済みファイルにフォーカス | 「[ファイル名]、オプション、選択されています」       | [ ]  |
| モーダルを閉じる             | フォーカスがトリガーに戻り、「折りたたまれています」 | [ ]  |

3. 問題があれば記録

**期待される成果物**:

- VoiceOverテスト結果（outputs/phase-11/voiceover-test-results.md）
