# 受け入れ基準 - TASK-FIX-WORKTREE-CONFLICT-001

## AC-1〜AC-8 定義

| AC番号 | 基準                                                                          | 検証方法                       | 担当             |
| ------ | ----------------------------------------------------------------------------- | ------------------------------ | ---------------- |
| AC-1   | 並列ブランチが LOGS.md を更新してもマージコンフリクトが発生しない             | git merge テスト               | 前提（実施済み） |
| AC-2   | EVALS.json が並列マージで破損しない（JSON 構造が有効）                        | `jq . EVALS.json` でエラーなし | FIX-001-A        |
| AC-3   | `.claude/**` のみを変更した PR は CI をスキップして即マージ可能               | CI ログで "skipped" 確認       | FIX-001-B        |
| AC-4   | `indexes/*.json` がマージ後に自動再生成される                                 | `git merge` 後のフック実行確認 | FIX-001-C        |
| AC-5   | SKILL.md の変更履歴部分はコンフリクトなしにマージできる                       | git merge テスト（ローカル）   | FIX-001-D        |
| AC-6   | 全スキルの SKILL-changelog.md が存在し、SKILL.md から変更履歴が削除されている | `ls` + `grep` 確認             | FIX-001-D        |
| AC-7   | `gwt` で新規 worktree 作成後に post-merge フックが自動インストールされる      | `test -x "$HOOK_PATH"`         | FIX-001-E        |
| AC-8   | B レイアウト起動時の `gwt-layout-init` が重いフックをスキップして完了する     | tmux B 起動時のログ確認        | FIX-001-F        |

## 機能要件

| ID   | 要件                                            | 優先度 |
| ---- | ----------------------------------------------- | ------ |
| FR-1 | EVALS.json のマージ戦略を merge=ours に変更     | 高     |
| FR-2 | CI がスキルファイルのみの変更を検知してスキップ | 高     |
| FR-3 | マージ後に indexes/\*.json が自動再生成         | 高     |
| FR-4 | git フックが自動インストールされる仕組みを提供  | 中     |
| FR-5 | SKILL.md の変更履歴が別ファイルとして管理       | 中     |

## 非機能要件

| ID    | 要件                                                  | 優先度 |
| ----- | ----------------------------------------------------- | ------ |
| NFR-1 | post-merge フックは 30 秒以内に完了                   | 高     |
| NFR-2 | フックのインストールは冪等（2回実行しても副作用なし） | 高     |
| NFR-3 | SKILL-changelog.md は UTF-8 / LF で保存               | 中     |
| NFR-4 | シェルスクリプトは bash で動作（zsh 依存を避ける）    | 中     |
