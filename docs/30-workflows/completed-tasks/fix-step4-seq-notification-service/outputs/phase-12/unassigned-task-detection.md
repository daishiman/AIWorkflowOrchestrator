## 本タスクのスコープ外として記録された未対応事項

| 未対応事項                                                               | 優先度 | タスク候補名                       | 理由                                                              |
| ------------------------------------------------------------------------ | ------ | ---------------------------------- | ----------------------------------------------------------------- |
| Windows/Linux 通知対応（`Notification.isSupported()` が false の環境）   | 低     | `feat-notification-cross-platform` | 本タスクは macOS MVP として意図的にスコープを限定                 |
| 通知設定 UI（ユーザーが通知のオン/オフを設定できる機能）                 | 低     | `feat-notification-settings-ui`    | ユーザー設定機能は独立したタスクとして設計が必要                  |
| 通知の重複防止（短時間に複数スキル生成を実行した場合のポップアップ管理） | 低     | `feat-notification-deduplication`  | 現時点では複数通知は許容。UX 改善として別タスクで対応             |
| `notify()` 失敗時のモニタリング（ログ収集・アラート）                    | 低     | `ops-notification-monitoring`      | `console.warn` のみでは本番運用の可視性が低い。監視基盤整備が必要 |

---

## 記録日時と優先度の根拠

- 全 4 件は「低」優先度とした。通知機能はコア機能（スキル生成）の補助であり、
  これらが欠けてもアプリの主機能は正常に動作する
- `feat-notification-cross-platform` は将来的なマルチプラットフォーム対応時に着手する
- `feat-notification-deduplication` と `ops-notification-monitoring` は
  ユーザーフィードバックが蓄積されてから優先度を再評価する
