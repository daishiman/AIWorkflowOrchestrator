## 機能要件の受け入れ基準

### AC-01: 会話自動保存（FR-01）

| AC-ID   | 検証項目                                                        | 検証方法                        |
| ------- | --------------------------------------------------------------- | ------------------------------- |
| AC-01-1 | メッセージ送信後、DBの`chat_messages`にレコードが作成されている | SQLiteクエリで確認 / 自動テスト |
| AC-01-2 | 新規会話の場合、`chat_sessions`にもレコードが作成されている     | SQLiteクエリで確認 / 自動テスト |
| AC-01-3 | `chat_sessions.message_count`が正確にインクリメントされている   | SQLiteクエリで確認 / 自動テスト |
| AC-01-4 | `chat_sessions.updated_at`が更新されている                      | SQLiteクエリで確認 / 自動テスト |
| AC-01-5 | `chat_sessions.last_message_preview`が最新メッセージを反映      | SQLiteクエリで確認 / 自動テスト |

**テストシナリオ:**

```gherkin
Scenario: 新規会話でのメッセージ保存
  Given 会話が存在しない状態
  When ユーザーがメッセージを送信する
  Then chat_sessionsに新規レコードが作成される
  And chat_messagesにメッセージレコードが作成される
  And message_countが1になる
  And last_message_previewが送信メッセージと一致する

Scenario: 既存会話へのメッセージ追加
  Given conversationId=abc123の会話が存在する
  And その会話にメッセージが2件ある
  When 同じ会話にメッセージを送信する
  Then chat_messagesに新規レコードが追加される
  And message_countが3になる
  And updated_atが更新される
```

### AC-02: 会話復元（FR-02）

| AC-ID   | 検証項目                                            | 検証方法   |
| ------- | --------------------------------------------------- | ---------- |
| AC-02-1 | アプリ再起動後、会話一覧に前回の会話が表示される    | 手動テスト |
| AC-02-2 | 会話を選択すると、全メッセージ履歴がロードされる    | 手動テスト |
| AC-02-3 | メッセージの順序（message_index）が正確に復元される | 自動テスト |

**テストシナリオ:**

```gherkin
Scenario: アプリ再起動後の会話復元
  Given 会話Aにメッセージが5件保存されている
  When アプリを再起動する
  Then 会話一覧に会話Aが表示される
  And 会話Aを選択すると5件のメッセージが順序通りに表示される
```

### AC-03: 会話一覧表示（FR-03）

| AC-ID   | 検証項目                                              | 検証方法   |
| ------- | ----------------------------------------------------- | ---------- |
| AC-03-1 | 会話一覧に会話タイトルが表示される                    | 手動テスト |
| AC-03-2 | 会話一覧に最終更新日時が表示される                    | 手動テスト |
| AC-03-3 | 会話一覧にメッセージ数が表示される                    | 手動テスト |
| AC-03-4 | 会話一覧が最新順（updated_at DESC）でソートされている | 自動テスト |
| AC-03-5 | ピン留めされた会話が上部に表示される                  | 手動テスト |

**テストシナリオ:**

```gherkin
Scenario: 会話一覧の表示順序
  Given 以下の会話が存在する:
    | title  | updated_at          | is_pinned |
    | 会話A  | 2026-01-24 10:00    | false     |
    | 会話B  | 2026-01-24 11:00    | false     |
    | 会話C  | 2026-01-24 09:00    | true      |
  When 会話一覧を表示する
  Then 表示順序は 会話C, 会話B, 会話A となる
```

### AC-04: 会話選択・継続（FR-04）

| AC-ID   | 検証項目                                                       | 検証方法   |
| ------- | -------------------------------------------------------------- | ---------- |
| AC-04-1 | 会話選択後、全メッセージ履歴がチャットUIに表示される           | 手動テスト |
| AC-04-2 | 選択した会話で新規メッセージを送信すると、同じ会話に追加される | 手動テスト |
| AC-04-3 | LLMへのリクエストにconversationIdが含まれる                    | 自動テスト |

**テストシナリオ:**

```gherkin
Scenario: 過去会話の継続
  Given 会話Aにメッセージが3件ある
  When 会話Aを選択する
  And 新しいメッセージを送信する
  Then 会話Aのメッセージが4件になる
  And 新しいメッセージに同じconversationIdが設定される
```

### AC-05: 会話削除（FR-05）

| AC-ID   | 検証項目                                 | 検証方法         |
| ------- | ---------------------------------------- | ---------------- |
| AC-05-1 | 会話削除後、DBの`deleted_at`が設定される | SQLiteクエリ確認 |
| AC-05-2 | 削除した会話が一覧から消える             | 手動テスト       |
| AC-05-3 | 削除した会話のメッセージも非表示になる   | SQLiteクエリ確認 |

**テストシナリオ:**

```gherkin
Scenario: 会話の削除
  Given 会話Aが存在する
  When 会話Aを削除する
  Then chat_sessions.deleted_atに現在時刻が設定される
  And 会話一覧に会話Aが表示されなくなる
```

### AC-06: 会話タイトル自動生成（FR-06）

| AC-ID   | 検証項目                                                 | 検証方法   |
| ------- | -------------------------------------------------------- | ---------- |
| AC-06-1 | 新規会話作成時、最初のメッセージからタイトルが生成される | 自動テスト |
| AC-06-2 | タイトルは最大50文字に切り詰められる                     | 自動テスト |

**テストシナリオ:**

```gherkin
Scenario: タイトル自動生成
  Given 会話が存在しない
  When "こんにちは、今日の天気を教えてください" というメッセージで会話を開始する
  Then 会話タイトルが "こんにちは、今日の天気を教えてください" になる

Scenario: 長いメッセージからのタイトル生成
  Given 会話が存在しない
  When 60文字以上のメッセージで会話を開始する
  Then 会話タイトルは50文字に切り詰められる
```
