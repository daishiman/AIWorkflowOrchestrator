## スコープ概要

本タスクでは、LLMチャット機能の会話履歴をSQLiteに永続化し、アプリ再起動後も会話を継続できる機能を実装する。

---

## スコープ内（In Scope）

### 1. データベース層

| 項目                       | 詳細                                                            |
| -------------------------- | --------------------------------------------------------------- |
| ConversationRepository実装 | chat_sessions/chat_messagesテーブルへのCRUD操作を行うRepository |
| トランザクション管理       | 複数テーブルにまたがる操作のトランザクション制御                |
| インデックス最適化         | 検索・ソートに必要なインデックスの追加                          |

### 2. IPC通信層

| IPCチャンネル            | 説明                       |
| ------------------------ | -------------------------- |
| conversation:list        | 会話一覧取得               |
| conversation:get         | 特定会話とメッセージ取得   |
| conversation:create      | 新規会話作成               |
| conversation:update      | 会話情報更新（タイトル等） |
| conversation:delete      | 会話削除（ソフトデリート） |
| conversation:add-message | メッセージ追加             |

### 3. Renderer層

| 項目                     | 詳細                                           |
| ------------------------ | ---------------------------------------------- |
| Redux Store連携          | llmSliceにconversation関連のstate/actions追加  |
| 会話一覧UIコンポーネント | ConversationList.tsx（一覧表示・選択・削除）   |
| 既存チャットUIとの統合   | 会話選択時のメッセージロード・新規会話作成連携 |

### 4. 機能

| 機能                 | 説明                                 |
| -------------------- | ------------------------------------ |
| 会話自動保存         | メッセージ送信時の自動保存           |
| 会話復元             | アプリ起動時の会話一覧復元           |
| 会話一覧表示         | タイトル・更新日時・メッセージ数表示 |
| 会話選択・継続       | 過去会話の選択と継続対話             |
| 会話削除             | ソフトデリートによる削除             |
| 会話タイトル自動生成 | 最初のメッセージからタイトル生成     |
| 会話タイトル編集     | ユーザーによるタイトル変更           |
| 会話検索（基本）     | タイトルでのLIKE検索                 |

### 5. テスト

| テスト種別     | 対象                                         |
| -------------- | -------------------------------------------- |
| ユニットテスト | ConversationRepository、タイトル生成ロジック |
| 統合テスト     | IPCハンドラー、Repository統合                |
| 手動テスト     | UI操作、アプリ再起動、エラー表示確認         |

## スコープ外（Out of Scope）

### 将来タスクとして検討

| 項目                        | 理由                                                  | 将来タスクID（仮） |
| --------------------------- | ----------------------------------------------------- | ------------------ |
| クラウド同期                | ローカルファースト優先、インフラ検討が必要            | FUTURE-CLOUD-SYNC  |
| 会話エクスポート/インポート | 優先度低、フォーマット設計が必要                      | FUTURE-EXPORT      |
| 会話共有機能                | マルチユーザー機能未実装                              | FUTURE-SHARE       |
| 全文検索エンジン            | FTS5導入検討が必要                                    | FUTURE-FTS         |
| ユーザー認証連携            | user_idはローカル固定値で対応（マルチユーザー未対応） | FUTURE-AUTH        |
| 会話アーカイブ              | 優先度低                                              | FUTURE-ARCHIVE     |
| 添付ファイル対応            | workspace-chat-editタスクで対応予定                   | WCE-UI             |

### 本タスクで対応しない理由

1. **クラウド同期**: オフラインファースト設計のため、まずローカル永続化を完成させる
2. **全文検索**: 基本的なLIKE検索で初期リリースし、必要に応じてFTS5を導入
3. **ユーザー認証連携**: 現時点ではシングルユーザー想定

## 境界条件

### 制限事項

| 項目                  | 制限                                        |
| --------------------- | ------------------------------------------- |
| メッセージ長          | 1〜100,000文字（chat_messages.content制約） |
| タイトル長            | 3〜100文字（chat_sessions.title制約）       |
| 最大会話数            | 技術的制限なし（ストレージ容量に依存）      |
| 最大メッセージ数/会話 | 技術的制限なし                              |
| user_id               | ローカル固定値「local-user」を使用          |

### 前提条件

| 項目                            | 説明                                   |
| ------------------------------- | -------------------------------------- |
| SQLite利用可能                  | better-sqlite3がMain Processで使用可能 |
| chat_sessions/chat_messages設計 | database-schema.mdに定義済み           |
| llmSlice実装済み                | Redux Store基盤が存在                  |
| IPC基盤実装済み                 | Electron IPC通信が動作                 |
