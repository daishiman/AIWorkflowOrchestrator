# Phase 7: テストカバレッジ確認

## メタ情報

| 項目   | 値                                   |
| ------ | ------------------------------------ |
| Phase  | 7                                    |
| 機能名 | llm-conversation-history-persistence |

## 目的

Phase 6で拡充したテスト結果を検証し、カバレッジ基準を満たすことを確認する。

## 実行タスク

- **カバレッジ再測定**: テストカバレッジの再計測
- **統合テスト実行**: 統合テストの実行と結果確認
- **ゲート判定**: カバレッジ基準達成の判定

## 実行手順

### ステップ1: カバレッジ再測定

```bash
pnpm --filter @repo/desktop test:coverage
```

### ステップ2: 統合テスト実行

```bash
pnpm --filter @repo/desktop test:integration
```

### ステップ3: 未達の場合の対応

カバレッジ未達や統合テスト失敗がある場合、Phase 6へ戻って拡充する。

## 統合テスト連携【必須】

統合テストの再実行とゲート判定:

| 判定項目               | 基準 | 結果 |
| ---------------------- | ---- | ---- |
| ユニットテストLine     | 80%+ |      |
| ユニットテストBranch   | 60%+ |      |
| ユニットテストFunction | 80%+ |      |
| IPC統合テスト          | 100% |      |
| Repository統合テスト   | 100% |      |
| 正常系シナリオ         | 100% |      |
| 異常系シナリオ         | 80%+ |      |

## カバレッジ判定基準

### PASS条件

- Line Coverage ≥ 80%
- Branch Coverage ≥ 60%
- Function Coverage ≥ 80%
- 全統合テストがPASS
- 全IPCチャンネルがテスト済み

### FAIL時の対応

1. 不足領域を特定
2. Phase 6に戻り追加テスト作成
3. 再度Phase 7を実行
