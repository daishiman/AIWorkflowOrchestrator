## 2. 実行タスク

### Task 1-1: 仕様書確認

**目的**: specification.md §5.1 の型定義仕様を確認し、実装対象を特定する

**手順**:

1. `docs/30-workflows/skill-import-agent-system/specification.md` を開く
2. §5.1「型定義」セクションを確認
3. 定義されている全ての型をリストアップ
4. 各型のプロパティ・用途を理解

**確認項目**:

- [ ] SkillMetadata 型の全プロパティ
- [ ] SkillSubResource 型の全プロパティ
- [ ] SkillOtherFile 型の全プロパティ
- [ ] ImportedSkill 型の全プロパティ
- [ ] SkillExecutionRequest 型の全プロパティ
- [ ] SkillExecutionResponse 型の全プロパティ
- [ ] SkillExecutionStatus の全値
- [ ] SkillStreamMessage の Discriminated Union 構造
- [ ] 各メッセージコンテンツ型（Assistant/ToolUse/ToolResult/Status/Error）
- [ ] PermissionRequest 型の全プロパティ
- [ ] PermissionResponse 型の全プロパティ

### Task 1-2: 既存型確認

**目的**: 既存の skill.ts の型定義を確認し、拡張方針を決定する

**手順**:

1. `packages/shared/src/types/skill.ts` を開く
2. 既存の型定義を確認
3. 仕様書の型定義との差分を特定
4. 拡張・追加が必要な型を決定

**確認項目**:

- [ ] 既存の Skill/SkillDetail 型と SkillMetadata の関係
- [ ] 既存の OperationResult 型の再利用可否
- [ ] 既存の SkillScanResult/ImportResult 型の維持
- [ ] 既存のエクスポート設定

### Task 1-3: システム仕様確認

**目的**: aiworkflow-requirements の関連仕様を確認し、整合性を確保する

**手順**:

1. `interfaces-agent-sdk.md` を確認（SDK関連型）
2. `error-handling.md` を確認（エラーコード）
3. `architecture-patterns.md` を確認（型定義パターン）

**確認項目**:

- [ ] Agent SDK の型定義との重複・整合性
- [ ] エラーコード定義のパターン適用
- [ ] 型定義のモジュール分割パターン

## 3. 受け入れ基準

### 3.1 機能要件

| ID    | 要件                                                             | 優先度 |
| ----- | ---------------------------------------------------------------- | ------ |
| FR-01 | specification.md §5.1 の全型定義が実装されている                 | 必須   |
| FR-02 | 既存の型定義との後方互換性が維持されている                       | 必須   |
| FR-03 | 型エクスポートが `packages/shared/src/index.ts` に追加されている | 必須   |
| FR-04 | Discriminated Union 型が型ガード可能な構造になっている           | 必須   |
| FR-05 | 全ての public 型に JSDoc コメントが付与されている                | 必須   |

### 3.2 非機能要件

| ID     | 要件                                             | 優先度 |
| ------ | ------------------------------------------------ | ------ |
| NFR-01 | TypeScript strict モードでコンパイルエラーがない | 必須   |
| NFR-02 | `pnpm --filter @repo/shared build` が成功する    | 必須   |
| NFR-03 | 他パッケージ（desktop/web）からインポート可能    | 必須   |
| NFR-04 | 型定義のみで実行時コードを含まない（定数を除く） | 必須   |

### 3.3 品質要件

| ID    | 要件                       | 基準 |
| ----- | -------------------------- | ---- |
| QR-01 | 型定義が仕様書と完全に一致 | 100% |
| QR-02 | JSDoc カバレッジ           | 100% |
| QR-03 | eslint/prettier エラーなし | 0件  |
