## 3. 実行タスク

### Task 10-1: 実装レビュー

**手順**:

1. `packages/shared/src/types/skill.ts` を開く
2. specification.md §5.1 と照合
3. 各チェック項目を確認
4. 判定結果を記録

### Task 10-2: テストレビュー

**手順**:

1. テスト実行結果を確認
2. テストカバレッジを確認
3. 各チェック項目を確認
4. 判定結果を記録

**コマンド**:

```bash
pnpm --filter @repo/shared test -- --run
```

### Task 10-3: 品質レビュー

**手順**:

1. Phase 9 の品質保証結果を確認
2. 追加の品質チェックを実行
3. 各チェック項目を確認
4. 判定結果を記録

**コマンド**:

```bash
pnpm --filter @repo/shared typecheck
pnpm --filter @repo/shared lint
pnpm --filter @repo/shared build
```

### Task 10-4: 整合性レビュー

**手順**:

1. 仕様書との一致を最終確認
2. 他パッケージでのインポートを確認
3. 各チェック項目を確認
4. 判定結果を記録

### Task 10-5: 総合判定

**手順**:

1. 全チェック項目の判定結果を集計
2. 問題点があれば該当フェーズに差し戻し
3. 問題なければ Phase 11 に進む
