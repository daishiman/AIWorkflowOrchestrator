## 1. 目的

テストカバレッジを確認し、品質基準を満たしていることを検証する。型定義タスクでは実行時コードが少ないため、主に静的解析と型チェックに焦点を当てる。

---

## 2. カバレッジ基準

### 2.1 型定義タスクの特殊性

型定義は TypeScript のコンパイル時に検証されるため、実行時カバレッジの概念が異なる。

| 検証対象             | 検証方法         | 基準 |
| -------------------- | ---------------- | ---- |
| 型定義の存在         | コンパイル成功   | 100% |
| 型の正確性           | テストでの型使用 | 100% |
| エクスポートの正確性 | インポートテスト | 100% |
| JSDoc コメント       | 手動確認         | 100% |

### 2.2 テストカバレッジ目標

| 指標                 | 目標 | 備考                         |
| -------------------- | ---- | ---------------------------- |
| 型定義テストカバー率 | 100% | 全型がテストで使用されている |
| インポートテスト     | 100% | 全型がインポート可能         |
| エッジケーステスト   | 80%+ | 主要なエッジケースをカバー   |

## 3. 実行タスク

### Task 7-1: テスト実行・結果確認

**目的**: 全テストが成功することを確認

**コマンド**:

```bash
# 全テスト実行
pnpm --filter @repo/shared test -- --run

# 詳細出力
pnpm --filter @repo/shared test -- --run --reporter=verbose
```

**期待結果**:

- 全テストがパス（緑）
- エラーなし

### Task 7-2: 型チェック実行

**目的**: TypeScript の型チェックが成功することを確認

**コマンド**:

```bash
# 型チェック
pnpm --filter @repo/shared typecheck

# 厳格モードでの確認
pnpm --filter @repo/shared tsc --noEmit --strict
```

**期待結果**:

- コンパイルエラーなし
- 型警告なし

### Task 7-3: ビルド確認

**目的**: パッケージが正常にビルドできることを確認

**コマンド**:

```bash
# ビルド
pnpm --filter @repo/shared build

# ビルド成果物の確認
ls -la packages/shared/dist/
```

**期待結果**:

- ビルド成功
- dist/ に型定義ファイル（.d.ts）が生成

### Task 7-4: 依存パッケージからのインポート確認

**目的**: desktop/web パッケージから型がインポートできることを確認

**確認方法**:

```typescript
// apps/desktop または apps/web のファイルで確認
import type {
  SkillMetadata,
  SkillStreamMessage,
  PermissionRequest,
} from "@repo/shared";

// コンパイルが通ればOK
```

**コマンド**:

```bash
# desktop パッケージの型チェック
pnpm --filter @repo/desktop typecheck

# web パッケージの型チェック
pnpm --filter @repo/web typecheck
```

### Task 7-5: カバレッジレポート作成

**目的**: テストカバレッジの状況をドキュメント化

**レポート内容**:

| カテゴリ               | テスト数 | パス | カバー率 |
| ---------------------- | -------- | ---- | -------- |
| 型存在テスト           | -        | -    | -        |
| インポートテスト       | -        | -    | -        |
| オプショナルプロパティ | -        | -    | -        |
| Discriminated Union    | -        | -    | -        |
| エッジケース           | -        | -    | -        |
| **合計**               | -        | -    | -        |
