## 1. 目的

テストカバレッジが目標基準を満たしていることを確認し、不足があれば追加テストを作成する。

---

## 2. カバレッジ目標

### 2.1 ユニットテストカバレッジ

| 指標              | 最低基準 | 推奨基準 | 現在値 |
| ----------------- | -------- | -------- | ------ |
| Line Coverage     | 80%      | 90%      | -      |
| Branch Coverage   | 60%      | 70%      | -      |
| Function Coverage | 80%      | 90%      | -      |

---

## 3. 実行タスク

### Task 7-1: カバレッジ計測

**目的**: 現在のテストカバレッジを計測する

**手順**:

```bash
# カバレッジ付きでテスト実行
pnpm --filter @repo/shared test -- --run --coverage

# HTML レポート生成（オプション）
pnpm --filter @repo/shared test -- --run --coverage --reporter=html
```

**確認項目**:

- [ ] Line Coverage が 80% 以上
- [ ] Branch Coverage が 60% 以上
- [ ] Function Coverage が 80% 以上

### Task 7-2: カバレッジ分析

**目的**: カバレッジが不足している箇所を特定する

**分析対象ファイル**:

| ファイル    | 対象関数               |
| ----------- | ---------------------- |
| security.ts | isDangerousCommand()   |
| security.ts | isProtectedPath()      |
| security.ts | matchGlobPattern()     |
| security.ts | validateAllowedTools() |
| security.ts | filterAllowedTools()   |

**分析ポイント**:

- [ ] 未カバーの行があるか
- [ ] 未カバーの分岐があるか
- [ ] エラーハンドリングパスがカバーされているか

### Task 7-3: 追加テスト作成（必要な場合）

**目的**: カバレッジ不足の箇所に対するテストを追加する

**判断基準**:

- Line Coverage < 80% → 追加テスト必須
- Branch Coverage < 60% → 分岐テスト追加
- Function Coverage < 80% → 未テスト関数のテスト追加

### Task 7-4: 最終カバレッジ確認

**目的**: 追加テスト後のカバレッジが目標を満たすことを確認する

**確認コマンド**:

```bash
pnpm --filter @repo/shared test -- --run --coverage
```
