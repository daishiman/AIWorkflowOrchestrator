## 2. 実行タスク

### Task 9-1: 静的解析

**目的**: ESLint, TypeScript による静的解析を実行する

**手順**:

```bash
# ESLint 実行
pnpm --filter @repo/shared lint

# TypeScript 型チェック
pnpm --filter @repo/shared typecheck

# Prettier フォーマットチェック
pnpm --filter @repo/shared format:check
```

**確認項目**:

- [ ] ESLint エラー 0件
- [ ] ESLint 警告 0件（推奨）
- [ ] TypeScript エラー 0件
- [ ] Prettier エラー 0件

### Task 9-2: セキュリティチェック

**目的**: セキュリティ上の問題がないか確認する

**チェックリスト**:

- [ ] 正規表現インジェクションの可能性がないか
- [ ] パストラバーサルの可能性がないか
- [ ] 機密情報のハードコーディングがないか
- [ ] 適切なエスケープ処理が行われているか

**セキュリティ観点でのコードレビュー**:

| 関数                 | リスク                   | 対策状況 |
| -------------------- | ------------------------ | -------- |
| matchGlobPattern()   | 正規表現インジェクション | [ ]      |
| isProtectedPath()    | パストラバーサル         | [ ]      |
| isDangerousCommand() | コマンドインジェクション | [ ]      |

### Task 9-3: 依存関係チェック

**目的**: 追加依存がないことを確認する

**手順**:

```bash
# package.json の依存を確認
cat packages/shared/package.json | jq '.dependencies, .devDependencies'
```

**確認項目**:

- [ ] 新規依存が追加されていないこと
- [ ] Node.js 標準ライブラリのみ使用

### Task 9-4: ビルド確認

**目的**: 本番ビルドが正常に完了することを確認する

**手順**:

```bash
# ビルド実行
pnpm --filter @repo/shared build

# ビルド成果物確認
ls -la packages/shared/dist/
```

**確認項目**:

- [ ] ビルドが成功
- [ ] 型定義ファイル（.d.ts）が生成されている
- [ ] CommonJS/ESM 両形式が出力されている（設定による）

### Task 9-5: 他パッケージからのインポート確認

**目的**: 他パッケージから正常にインポートできることを確認する

**手順**:

```bash
# desktop パッケージでのインポートテスト
pnpm --filter @repo/desktop typecheck
```

**確認項目**:

- [ ] `@repo/desktop` から `@repo/shared` のセキュリティ定数をインポート可能
- [ ] 型が正しく解決される
