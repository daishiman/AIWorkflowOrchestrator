## 3. レビュー判定基準

### 3.1 PASS条件

- 全ての要件が満たされている
- 全ての品質基準が満たされている
- 仕様書との不整合がない
- ビルド・テストが全て成功

### 3.2 FAIL条件

- 要件を満たさない実装がある
- 品質基準を満たさない
- 仕様書との不整合がある
- ビルド・テストが失敗

### 3.3 FAIL時のアクション

1. 問題のある Phase に戻り修正
2. 修正後に Phase 10 を再実行
