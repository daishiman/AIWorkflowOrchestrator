## 目的

lint、型チェック、リンク整合、ドキュメント名整合、セキュリティ確認を品質ゲートとして確認し、Phase 10 に渡す blocker を出し切る。

## 実行タスク

### Task 1: 参照・リンク品質

- broken link がないことを確認する
- `CLAUDE.md`、lane pack、skill 定義、Phase 間リンクの相対パスを確認する
- 成果物名と参照先ファイル名の不一致を洗い出す

### Task 2: 実装品質

- `pnpm lint` と `pnpm typecheck` の結果を確認する
- 既存テストが後方互換を保っているか確認する
- hardcoded string の残存有無を確認する

### Task 3: セキュリティ・性能

- XSS、インジェクション、任意ファイル読み込みに繋がる表現がないか確認する
- 動的解決に伴う性能劣化や過剰再読込がないか確認する

### Task 4: 仕様書品質

- phase 名、成果物名、artifacts 名称を統一する
- Phase 12 / 13 の成果物と実行条件が task-specification-creator 準拠か確認する
