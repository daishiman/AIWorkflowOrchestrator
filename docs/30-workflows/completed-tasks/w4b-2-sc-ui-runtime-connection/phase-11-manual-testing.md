## MT-1: LLM 生成フロー全体（plan→execute）

### 目的

AC-1（planSkill 呼び出し）、AC-3（TerminalHandoff 表示）、AC-4（execute 完了後のスキル利用可能）を実機で確認する。

### 手順

| ステップ | 操作                                                                                                                        | 期待結果                                                                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1        | サイドバーの「スキル管理」または「新しいスキルを作成」を開く                                                                | SkillLifecyclePanel が表示される                                                                                                                  |
| 2        | Step 1「依頼をまとめる」のテキストエリアに「GitHub のプルリクエストを自動的にレビューするスキルを作成してほしい」と入力する | テキストが入力フィールドに表示される                                                                                                              |
| 3        | 「方針を決める」ボタンをクリックする                                                                                        | ローディングインジケーターが表示される（AC-1 開始）                                                                                               |
| 4        | detectMode の結果を確認する（DevTools コンソール）                                                                          | `"plan"` または `"improve"` が返される場合、planSkill が呼ばれる                                                                                  |
| 5        | planSkill のレスポンスを確認する                                                                                            | `type === "integrated_api"` の場合: Plan 結果セクションが表示される。`type === "terminal_handoff"` の場合: TerminalHandoff ガイダンスが表示される |
| 6        | `integrated_api` の場合: Plan 結果セクションの「実行する」ボタンをクリックする                                              | `isGenerating=true` になり「実行する」ボタンが無効化される（AC-3）                                                                                |
| 7        | executePlan の完了を待つ                                                                                                    | プログレステキストが更新される（「スキルを生成中...」等）                                                                                         |
| 8        | 完了後にスキル一覧を確認する                                                                                                | 新規スキルが追加されている（AC-4）                                                                                                                |
| 9        | 新規スキルが自動選択されていることを確認する                                                                                | `selectSkillByName()` が呼ばれている                                                                                                              |

### 確認ポイント（AC-1, AC-3, AC-4）

- [ ] AC-4: executePlan 完了後にスキルリストが更新された

## MT-4: Terminal Handoff 表示

planSkill が `terminal_handoff` レスポンスを返した場合の UI を確認する。

### 手順（LLMAdapter 未接続環境でのテスト）

LLMAdapter が未注入の場合、RuntimeSkillCreatorFacade は graceful degradation で stub 応答（`terminal_handoff`）を返す。

| ステップ | 操作                                                                      | 期待結果                                                    |
| -------- | ------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 1        | LLMAdapter 未注入の開発環境を起動する（環境変数で制御、または DI を省略） | RuntimeSkillCreatorFacade が stub 応答を返す状態            |

| 3        | テキストエリアに説明を入力し「方針を決める」をクリックする                | planSkill が呼ばれる                                        |
| 4        | `terminal_handoff` レスポンスを受け取った際の UI を確認する               | TerminalHandoff ガイダンス（`handoffGuidance`）が表示される |
| 5        | TerminalHandoff ガイダンスの内容を確認する                                | CLI 実行の手順が表示されている                              |
| 6        | ガイダンス表示後に「方針を決める」ボタンの状態を確認する                  | `isGenerating=false` に戻っている（ローディング終了）       |

```bash
cd apps/desktop
pnpm exec playwright test --screenshot on-failure e2e/skill-lifecycle-panel.spec.ts
```

**方法 2: Electron webContents.capturePage() を使ったスクリプト**

```javascript
// apps/desktop/scripts/capture-screenshot.js
const { app, BrowserWindow } = require("electron");
// 起動後に webContents.capturePage() でキャプチャ
```
