## 目的

Phase 4-5 で作成したテストに加え、境界値・エッジケース・回帰テストを拡充してテストスイートの網羅性を高める。

## 背景

Phase 4 では問題を再現する最小限のテストを作成した。Phase 6 では以下の観点でテストを追加する:

- changelog テンプレートの必須フィールド検証
- `### 使用例` 見出しの様々な配置パターン
- 既存 Phase 12 成果物に対する回帰テスト

## 実行タスク

### タスク1: 追加テストケースの実装

**目的**: テストの網羅性を高める

**実行手順**:

1. 以下のテストケースを追加する:
   - **TC-04**: changelog テンプレートに 5 フィールドが全て存在することを確認
   - **TC-05**: `### 使用例` が存在し、コードブロックを含む場合は OK
   - **TC-06**: `### 使用例` が存在するが、コードブロックがない場合はエラー
   - **TC-07**: 既存の Phase 12 成果物に対して修正後 validator を実行し回帰がないことを確認
2. 各テストケースが PASS することを確認する

**実行コマンド**:

```bash
pnpm vitest run --reporter=verbose -- validate-phase12-implementation-guide
```
