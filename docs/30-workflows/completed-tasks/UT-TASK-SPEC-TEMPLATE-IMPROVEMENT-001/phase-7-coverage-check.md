## 目的

テストカバレッジが基準値を達成しているか確認し、未カバーの重要ロジックがあれば追加テストを作成する。

## 実行タスク

### タスク1: カバレッジ計測

**目的**: `validate-phase12-implementation-guide.js` のカバレッジを計測する

**実行手順**:

1. カバレッジ付きでテストを実行する
2. 修正した関数（`buildChecks()` 内の `part2_usage_example` チェック）のブランチカバレッジを確認する
3. 未カバーのパスがないか確認する

**実行コマンド**:

```bash
pnpm vitest run --coverage -- validate-phase12-implementation-guide
```

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: 未達の場合はテスト追加

**目的**: カバレッジ基準未達の場合は追加テストを作成する

**実行手順**:

1. Line Coverage < 80% または Branch Coverage < 60% の場合は追加テストを作成する
2. 追加テスト後に再度カバレッジを計測する
