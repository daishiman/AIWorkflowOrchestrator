## 目的

Phase 5 で実装した証跡集約テンプレート・監査手順・チェックリストをリファクタリングし、冗長な記述の除去・重複項目の統合・命名規則の統一を行う。リファクタリング前後で機能（監査結果の網羅性・検証可能性）が同一であることをテストで保証する。

## 実行タスク

- 冗長記述除去: 証跡集約テンプレート内の同一情報の重複記載を1箇所に集約する
- チェックリスト重複排除: Task 1/3/4/5 チェック項目の重複を検出・統合する
- 監査手順最適化: 不要な中間ステップを統合しステップ数を削減する
- 命名規則統一: 変数名・セクション名・ファイル参照の表記揺れを解消する
- 同一性検証: リファクタリング前後で機能が同一であることをテストで確認する

## 実行手順

### Step 1: リファクタリング対象の特定

1. Phase 5 実装サマリー（`outputs/phase-5/implementation-summary.md`）を読み、全成果物ファイルのパスを取得する
2. 各ファイルの内容を確認し、以下の観点でリファクタリング対象を洗い出す:
   - **冗長記述**: 同一テンプレート内で同じ情報が2箇所以上に記載されている箇所
   - **重複項目**: 複数チェックリスト間で同一の検証項目が存在する箇所
   - **命名揺れ**: 同一概念に対して異なる用語が使われている箇所（例: `currentViolations` vs `current_violations`）
   - **不要ステップ**: 前後のステップに統合可能な中間ステップ

### Step 2: 冗長記述の除去

1. Step 1 で特定した冗長記述を1箇所に集約する
2. 集約先を明示するコメントまたはセクション参照を追加する
3. 除去した記述の一覧をリファクタリングログに記録する

### Step 3: チェックリスト項目の重複排除

1. Task 1（実装ガイド）/ Task 3（documentation-changelog）/ Task 4（未タスク検出）/ Task 5（追加確認）のチェックリスト項目を一覧化する
2. 意味が同一の項目をグルーピングする
3. 重複項目を1つに統合し、統合元の項目IDをリファクタリングログに記録する

### Step 4: 監査手順の最適化

1. 監査手順の全ステップをフローチャート形式で可視化する
2. 連続する2ステップが「入力→加工→出力」の1ステップに統合可能な場合、統合する
3. 統合前後のステップ数をリファクタリングログに記録する

### Step 5: 命名規則の統一

1. テンプレート内の全変数名・セクション名・ファイル参照を抽出する
2. 以下の命名規則に統一する:
   - 変数名: camelCase（例: `currentViolations`）
   - セクション名: 日本語見出し（例: `## 証跡集約結果`）
   - ファイル参照: 相対パス（`outputs/` から開始）
3. 変更した命名の一覧をリファクタリングログに記録する

### Step 6: テストによる同一性検証

1. Phase 4-6 で作成した全テストを実行する
2. 全テストが PASS することを確認する
3. テスト結果のスナップショットをリファクタリングログに記録する

## 統合テスト連携【必須】

| 検証項目                                     | 手段                          | 合格基準                     |
| -------------------------------------------- | ----------------------------- | ---------------------------- |
| リファクタリング前後でテンプレート出力が同一 | Phase 4-6 のテスト全件実行    | 全テスト PASS                |
| チェックリスト項目の網羅性維持               | Phase 1 要件との突合          | 全要件がチェック項目に対応   |
| 命名規則の統一                               | grep で命名揺れパターンを検索 | 命名揺れパターンの検出数が 0 |

## 多角的チェック観点

| 観点             | 確認内容                                         | 判定基準                             |
| ---------------- | ------------------------------------------------ | ------------------------------------ |
| 機能保全性       | リファクタリング前後で監査結果の網羅性が同一か   | 全テスト PASS                        |
| 保守性           | テンプレートの記述量が削減されているか           | リファクタリング前比で記述行数が減少 |
| 可読性           | 命名規則が統一され表記揺れがないか               | 命名揺れ検出数 = 0                   |
| 一貫性           | チェックリスト項目に重複がないか                 | 重複項目数 = 0                       |
| トレーサビリティ | リファクタリング変更が全てログに記録されているか | 変更件数とログ記録件数が一致         |
