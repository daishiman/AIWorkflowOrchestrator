## 実行手順

### Step 1: Markdown Lint 検証

1. 以下のコマンドを実行し、テンプレート・手順ファイルの Markdown lint を検証する:
   ```bash
   pnpm lint
   ```
2. Lint 警告・エラーが検出された場合、全件修正する
3. 修正後に再度 `pnpm lint` を実行し、警告数が 0 であることを確認する

### Step 2: TypeScript 型チェック

1. スクリプトファイル（`.ts` / `.tsx`）に変更がある場合、以下を実行する:
   ```bash
   pnpm typecheck
   ```
2. 型チェックエラーが検出された場合、全件修正する
3. 修正後に再度 `pnpm typecheck` を実行し、エラー数が 0 であることを確認する
4. スクリプトファイルに変更がない場合、このステップは「変更なし」として記録する

### Step 3: 全テスト実行

1. Phase 4-6 で作成した関連テストを実行する:
   ```bash
   cd apps/desktop && pnpm vitest run src/（関連テストディレクトリ）
   ```
2. 全テストが PASS であることを確認する
3. 失敗テストがある場合、原因を調査して修正する
4. 修正後に再度テストを実行し、全件 PASS を確認する

### Step 4: カバレッジ基準確認

1. カバレッジレポートを生成する:
   ```bash
   cd apps/desktop && pnpm vitest run --coverage src/（関連テストディレクトリ）
   ```
2. 以下の基準を充足していることを確認する:

   | 指標              | 最低基準 | 推奨基準 |
   | ----------------- | -------- | -------- |
   | Line Coverage     | 80%      | 90%      |
   | Branch Coverage   | 60%      | 70%      |
   | Function Coverage | 80%      | 90%      |

3. 基準未達の場合、Phase 6 に戻りテストを追加する

### Step 5: 品質メトリクス記録

1. Step 1〜4 の検証結果を `outputs/phase-9/quality-report.md` に記録する
2. 記録項目:
   - Lint 検証結果（警告数: 0 / エラー数: 0）
   - 型チェック結果（エラー数: 0 / または「スクリプト変更なし」）
   - テスト実行結果（テスト数 / PASS数 / FAIL数）
   - カバレッジ結果（Line / Branch / Function の各パーセンテージ）
   - 検証実行日時

## 統合テスト連携【必須】

| 検証項目                | 手段                              | 合格基準                 |
| ----------------------- | --------------------------------- | ------------------------ |
| Lint 警告が 0 件        | `pnpm lint` 実行                  | 警告数 = 0, エラー数 = 0 |
| 型チェックエラーが 0 件 | `pnpm typecheck` 実行             | エラー数 = 0             |
| 全テストが PASS         | `pnpm vitest run` 実行            | FAIL 数 = 0              |
| カバレッジ基準充足      | `pnpm vitest run --coverage` 実行 | 全指標が最低基準以上     |

| 観点             | 確認内容                                               | 判定基準                      |
| ---------------- | ------------------------------------------------------ | ----------------------------- |
| 構文品質         | Markdown / TypeScript の構文エラーが 0 か              | Lint + TypeCheck のエラー = 0 |
| テスト品質       | 全テストが PASS しているか                             | FAIL 数 = 0                   |
| カバレッジ       | カバレッジ基準（Line 80%, Branch 60%, Fn 80%）を充足か | 全指標が最低基準以上          |
| 再現性           | テスト結果が繰り返し実行で安定しているか               | 2回連続実行で同一結果         |
| トレーサビリティ | 品質レポートに全検証結果が記録されているか             | 全 Step の結果が記載済み      |
