## 目的

自動テストでは検証困難なUI動作・E2Eシナリオを手動で確認する。InlineModelSelector の isAvailable フィルタリングが実際のユーザー操作フローで正しく動作することを検証する。

## 実行タスク

### Task 11-1: テストシナリオ実行

#### シナリオ S-01: APIキーを1つだけ設定した状態での表示確認

前提条件: Anthropic の APIキーのみ設定済み（OpenAI, Google は未設定）

| ステップ | 操作                                     | 期待結果                                                     | 判定 |
| -------- | ---------------------------------------- | ------------------------------------------------------------ | ---- |
| 1        | アプリを起動する                         | チャット画面が表示される                                     | PASS |
| 2        | ヘッダーのモデルセレクターをクリックする | ドロップダウンが開く                                         | PASS |
| 3        | ドロップダウンの内容を確認する           | Anthropic のみ表示される。OpenAI, Google は表示されない      | PASS |
| 4        | Anthropic のモデルを選択する             | モデルが選択される。セレクターに選択したモデル名が表示される | PASS |

#### シナリオ S-02: 全APIキー未設定状態での表示確認

前提条件: 全プロバイダーの APIキーが未設定

| ステップ | 操作                           | 期待結果                                                                   | 判定 |
| -------- | ------------------------------ | -------------------------------------------------------------------------- | ---- |
| 1        | 設定画面で全APIキーを削除する  | 全プロバイダーの isAvailable が false になる                               | PASS |
| 2        | チャット画面に移動する         | ヘッダーのモデルセレクターに「モデルを選択」と表示される                   | PASS |
| 3        | モデルセレクターをクリックする | ドロップダウンにプロバイダーが表示されない（空状態メッセージが表示される） | PASS |

#### シナリオ S-03: APIキー追加後の即時反映確認

前提条件: 全プロバイダーの APIキーが未設定

| ステップ | 操作                                   | 期待結果                                                     | 判定 |
| -------- | -------------------------------------- | ------------------------------------------------------------ | ---- |
| 1        | 設定画面で Google の APIキーを追加する | Google の isAvailable が true になる                         | PASS |
| 2        | チャット画面に移動する                 | ヘッダーのモデルセレクターに Google のモデルが選択可能になる | PASS |
| 3        | モデルセレクターを開く                 | Google のみ表示される。他のプロバイダーは表示されない        | PASS |
| 4        | Google のモデルを選択する              | モデルが正しく選択される                                     | PASS |

#### シナリオ S-04: 設定画面での全プロバイダー表示確認

前提条件: 一部プロバイダーの APIキーが未設定

| ステップ | 操作                                        | 期待結果                                           | 判定 |
| -------- | ------------------------------------------- | -------------------------------------------------- | ---- |
| 1        | 設定画面を開く                              | 全プロバイダーが表示される                         | PASS |
| 2        | APIキー未設定プロバイダーの表示を確認する   | グレーアウト + 「APIキー未設定」バッジが表示される | PASS |
| 3        | APIキー設定済みプロバイダーの表示を確認する | 通常の表示で選択可能                               | PASS |

### Task 11-2: テスト環境の制約事項

CLI 環境での手動テストのため、以下の制約がある（P53 参照）：

- スクリーンショットの取得は Electron の `webContents.capturePage()` または Playwright の `page.screenshot()` で代替可能
- 本 Phase では自動テスト結果（Phase 4-9）を間接的な視覚検証として活用した
