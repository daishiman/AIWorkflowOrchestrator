### 3.2 カバレッジ注記

Preloadスクリプトのカバレッジは、以下の理由でプロジェクト全体のカバレッジ計算に影響を受ける：

- `channels.ts`の定数はテストで完全にカバー
- `index.ts`のclaudeCliAPI実装はcontextBridgeのモック制限によりカバレッジ計算外
- 実際の機能カバレッジは、統合テスト（E2E）で補完
