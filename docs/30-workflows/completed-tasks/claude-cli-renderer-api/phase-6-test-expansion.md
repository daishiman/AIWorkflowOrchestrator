## 目的

テストカバレッジを向上させるため、Phase 4で作成したテストを拡充する。エッジケース、境界値、異常系のテストを追加する。

## 背景

Phase 5でGreen状態を達成したが、カバレッジ目標（Line: 80%+, Branch: 60%+, Function: 80%+）を達成するには追加テストが必要な場合がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 現在のカバレッジ確認

**目的**: 現在のテストカバレッジを計測し、不足を特定する

**実行手順**:

1. カバレッジ付きでテストを実行する: `pnpm --filter @repo/desktop test --coverage`
2. カバレッジレポートを確認する
3. 以下の基準と比較する:
   - Line Coverage: 80%以上
   - Branch Coverage: 60%以上
   - Function Coverage: 80%以上
4. 不足しているカバレッジを特定し、記録する

**期待される成果物**:

- カバレッジレポート
- 不足カバレッジの特定

---

### タスク2: エッジケーステストの追加

**目的**: 境界値や特殊ケースのテストを追加する

**実行手順**:

1. `claudeCliApi.test.ts`に以下のテストを追加する:
   - 空のリクエストパラメータ
   - 空のレスポンス
   - 最大長の入力
   - null/undefinedの扱い
2. 各メソッドで考えられるエッジケースをテストする

**期待される成果物**:

- エッジケーステスト

---

### タスク3: 異常系テストの拡充

**目的**: エラーハンドリングのテストを拡充する

**実行手順**:

1. 以下の異常系テストを追加する:
   - IPC呼び出しタイムアウト
   - IPC呼び出し失敗（ネットワークエラー相当）
   - 不正なレスポンス形式
   - セッション存在しないエラー
   - スキル存在しないエラー
2. `ClaudeCliResult`のエラーケース（`success: false`）をテストする

**期待される成果物**:

- 異常系テスト

---

### タスク4: ストリーミングイベントテストの拡充

**目的**: ストリーミングイベントの詳細なテストを追加する

**実行手順**:

1. `onSessionOutput`テストを拡充する:
   - 複数イベントの連続受信
   - 大量データのストリーミング
   - イベント購読解除後の再購読
2. `onSessionStatus`テストを拡充する:
   - 状態遷移パターン（idle → running → completed）
   - エラー状態への遷移
   - 複数セッションの同時監視

**期待される成果物**:

- ストリーミングイベント拡充テスト

---

### タスク5: 統合テストシナリオの作成

**目的**: Preload API経由の統合テストシナリオを作成する

**実行手順**:

1. 以下の統合テストシナリオを作成する:
   - スキル一覧取得 → スキル詳細取得 → スクリプト実行
   - セッション開始 → 出力監視 → セッション終了
   - 複数APIの連続呼び出し
2. モックを使用したシナリオテストを実装する

**期待される成果物**:

- 統合テストシナリオ
