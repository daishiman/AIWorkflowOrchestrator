## 目的

Phase 4〜5で作成した基本テストを拡充し、カバレッジ目標達成に向けた追加テストを作成する。

## 背景

TDDのGreenフェーズで基本的なテストは通っているが、カバレッジ目標（Line≥80%, Branch≥60%, Function≥80%）達成のためには追加のテストケースが必要である。エッジケース、境界値、異常系のテストを拡充する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 現在のカバレッジ確認

**目的**: 現在のテストカバレッジを測定し、不足箇所を特定する

**実行手順**:

1. カバレッジ測定実行:
   ```bash
   pnpm --filter @repo/shared test -- --coverage --grep "Drizzle"
   ```
2. カバレッジレポートを確認:
   - Line Coverage
   - Branch Coverage
   - Function Coverage
3. カバレッジが不足しているファイル・関数・ブランチを特定
4. 追加テストが必要な箇所をリストアップ

**期待される成果物**:

- `outputs/phase-6/coverage-baseline.md`: 初期カバレッジ測定結果

---

### タスク2: エッジケーステスト追加

**目的**: 境界値・特殊ケースのテストを追加する

**実行手順**:

1. 空データのテスト:
   - 空配列を返すケース（`findByUserId` でセッションがない）
   - 空配列の `saveMany`
2. 大量データのテスト:
   - 100件以上のセッション取得
   - ページネーションの境界値（offset=0, offset=max）
3. 特殊文字のテスト:
   - タイトルに特殊文字（日本語、絵文字、記号）
   - FTS5検索での特殊文字
4. 日時境界のテスト:
   - 同一秒に作成された複数セッション
   - 古い日時と新しい日時のソート

**期待される成果物**:

- 各テストファイルにエッジケーステスト追加

---

### タスク3: エラーハンドリングテスト追加

**目的**: エラーケースのテストを追加する

**実行手順**:

1. 無効なID形式でのテスト:
   - 不正なUUID形式での `findById`
   - 存在しないIDでの `delete`
2. 外部キー制約エラーのテスト:
   - 存在しないセッションIDへのメッセージ保存
3. Mapper変換エラーのテスト:
   - 不正なレコードからの `toDomain`
4. 同時実行テスト（オプション）:
   - 同一IDへの同時 `save`

**期待される成果物**:

- 各テストファイルにエラーハンドリングテスト追加

---

### タスク4: FTS5全文検索テスト拡充

**目的**: 全文検索機能のテストを拡充する

**実行手順**:

1. 日本語検索テスト:
   - ひらがな・カタカナ・漢字の検索
   - 日本語タイトルのマッチ
2. 部分一致テスト:
   - 前方一致
   - 複数キーワード（AND検索）
3. 検索結果0件のテスト:
   - マッチしないキーワード
   - 空文字検索
4. 大量データでの検索テスト:
   - 100件以上からの検索パフォーマンス確認

**期待される成果物**:

- `DrizzleChatSessionRepository.test.ts` にFTS5テスト追加

---

### タスク5: 統合テストシナリオ拡充

**目的**: Repository間の連携テストを拡充する

**実行手順**:

1. セッション-メッセージ連携テスト:
   - セッション作成 → 複数メッセージ追加 → 全メッセージ取得
   - メッセージ追加でセッション `updatedAt` 更新確認
2. カスケード削除テスト:
   - セッション削除時に関連メッセージも削除されることを確認
   - 外部キー制約の動作確認
3. トランザクションテスト:
   - 複数操作の原子性確認
   - ロールバック動作確認
4. 並行処理テスト（オプション）:
   - 複数の同時リクエスト処理

**期待される成果物**:

- 統合テストの拡充

---

### タスク6: カバレッジ再測定・ギャップ分析

**目的**: テスト拡充後のカバレッジを測定し、目標達成を確認する

**実行手順**:

1. カバレッジ再測定:
   ```bash
   pnpm --filter @repo/shared test -- --coverage --grep "Drizzle"
   ```
2. カバレッジ目標との比較:
   - Line Coverage ≥ 80% ?
   - Branch Coverage ≥ 60% ?
   - Function Coverage ≥ 80% ?
3. 未達の場合は追加テスト作成
4. 達成の場合は次Phaseへ

**期待される成果物**:

- `outputs/phase-6/coverage-result.md`: カバレッジ測定結果・ギャップ分析
