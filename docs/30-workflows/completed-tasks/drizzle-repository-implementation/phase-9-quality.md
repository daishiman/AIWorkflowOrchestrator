## 目的

静的解析・セキュリティチェック・パフォーマンステストを通じて、コード品質を保証する。

## 背景

リファクタリング完了後、本番リリース前の品質ゲートとして、包括的な品質チェックを実施する。型安全性、コード規約準拠、セキュリティ、パフォーマンスの各観点で検証する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析実行

**目的**: コード品質を静的解析ツールで検証する

**実行手順**:

1. TypeScript型チェック:
   ```bash
   pnpm --filter @repo/shared typecheck
   ```
2. ESLint実行:
   ```bash
   pnpm --filter @repo/shared lint
   ```
3. Prettier フォーマットチェック:
   ```bash
   pnpm --filter @repo/shared format:check
   ```
4. エラー・警告がある場合は修正
5. 全チェックがパスすることを確認

**期待される成果物**:

- `outputs/phase-9/static-analysis-result.md`: 静的解析結果

---

### タスク2: セキュリティチェック

**目的**: セキュリティ上の問題がないか検証する

**実行手順**:

1. SQLインジェクション対策の確認:
   - パラメータ化クエリの使用
   - ユーザー入力の適切なエスケープ
   - Drizzle ORMの安全なAPI使用
2. 入力バリデーションの確認:
   - Value Objectでのバリデーション
   - 境界値チェック
3. エラー情報漏洩の確認:
   - エラーメッセージに内部情報が含まれていないか
   - スタックトレースの適切な処理
4. 依存関係の脆弱性チェック（オプション）:
   ```bash
   pnpm audit
   ```

**期待される成果物**:

- `outputs/phase-9/security-check-result.md`: セキュリティチェック結果

---

### タスク3: パフォーマンステスト

**目的**: クエリパフォーマンスを検証する

**実行手順**:

1. 大量データでのテスト:
   - 1000件のセッション取得
   - 10000件のメッセージ取得
2. 検索パフォーマンステスト:
   - FTS5全文検索の応答時間
   - インデックス使用の確認
3. バッチ処理パフォーマンステスト:
   - `saveMany` の100件一括挿入
4. 結果を記録（ミリ秒単位）

**期待される成果物**:

- `outputs/phase-9/performance-test-result.md`: パフォーマンステスト結果

---

### タスク4: コードレビューチェックリスト

**目的**: セルフレビューによる品質確認を行う

**実行手順**:

1. Clean Architecture準拠:
   - [ ] Domain層への逆依存がないか
   - [ ] Mapperが適切に使用されているか
   - [ ] インターフェースに依存しているか
2. エラーハンドリング:
   - [ ] 全てのエラーが適切にハンドリングされているか
   - [ ] Result型が一貫して使用されているか
3. 命名規則:
   - [ ] 変数名・関数名が適切か
   - [ ] ファイル名・クラス名が規約に準拠しているか
4. ドキュメンテーション:
   - [ ] JSDocコメントが記載されているか
   - [ ] 複雑なロジックにコメントがあるか

**期待される成果物**:

- `outputs/phase-9/code-review-checklist.md`: コードレビューチェックリスト

---

### タスク5: 品質メトリクス集計

**目的**: 品質メトリクスを集計し、目標達成を確認する

**実行手順**:

1. テストカバレッジ:
   - Line Coverage: ?%
   - Branch Coverage: ?%
   - Function Coverage: ?%
2. コード品質:
   - 型エラー: 0件
   - Lintエラー: 0件
   - Lint警告: ?件
3. セキュリティ:
   - 脆弱性: 0件
   - SQLインジェクション対策: OK
4. テスト:
   - ユニットテスト: ?件
   - 統合テスト: ?件
   - 全テストPASS: OK

**期待される成果物**:

- `outputs/phase-9/quality-metrics.md`: 品質メトリクス集計

---

### タスク6: 品質保証完了判定

**目的**: 品質保証の完了を判定する

**実行手順**:

1. 全品質チェック項目の確認:
   - [ ] 静的解析: PASS
   - [ ] セキュリティチェック: PASS
   - [ ] パフォーマンステスト: PASS
   - [ ] コードレビューチェックリスト: 全項目OK
   - [ ] 品質メトリクス: 目標達成
2. 判定結果を記録:
   - **PASS**: 全項目OK → Phase 10へ
   - **FAIL**: 問題あり → 修正後再チェック

**期待される成果物**:

- `outputs/phase-9/quality-assurance-result.md`: 品質保証完了判定
