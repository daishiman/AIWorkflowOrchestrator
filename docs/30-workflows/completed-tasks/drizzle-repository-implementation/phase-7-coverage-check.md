## 目的

テストカバレッジが目標基準を満たしているか検証し、必要に応じて追加テストを作成する。

## 背景

Phase 6でテスト拡充を行ったが、カバレッジ目標を満たしているか最終確認が必要である。目標未達の場合はPhase 6に戻り追加テストを作成する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ詳細測定

**目的**: 全テストを実行し、詳細なカバレッジレポートを生成する

**実行手順**:

1. 全テスト実行（カバレッジ付き）:
   ```bash
   pnpm --filter @repo/shared test -- --coverage
   ```
2. カバレッジレポートを確認（HTML形式がある場合）:
   - `coverage/lcov-report/index.html` を開く
3. 対象ファイルのカバレッジを抽出:
   - `DrizzleChatSessionRepository.ts`
   - `DrizzleChatMessageRepository.ts`
4. 以下の指標を記録:
   - Line Coverage（行カバレッジ）
   - Branch Coverage（分岐カバレッジ）
   - Function Coverage（関数カバレッジ）
   - Statement Coverage（ステートメントカバレッジ）

**期待される成果物**:

- `outputs/phase-7/coverage-detailed-report.md`: 詳細カバレッジレポート

---

### タスク2: カバレッジ目標達成判定

**目的**: カバレッジが目標基準を満たしているか判定する

**実行手順**:

1. 目標基準との比較:

   | 指標              | 最低基準 | 推奨基準 | 実測値 | 判定 |
   | ----------------- | -------- | -------- | ------ | ---- |
   | Line Coverage     | 80%      | 90%      | ?%     | ?    |
   | Branch Coverage   | 60%      | 70%      | ?%     | ?    |
   | Function Coverage | 80%      | 90%      | ?%     | ?    |

2. 判定結果:
   - **PASS**: 全指標が最低基準を満たしている → Phase 8へ
   - **FAIL**: いずれかの指標が最低基準を満たしていない → Phase 6へ戻る

**期待される成果物**:

- `outputs/phase-7/coverage-judgment.md`: カバレッジ判定結果

---

### タスク3: 未カバー箇所の分析

**目的**: カバレッジが不足している箇所を特定し、原因を分析する

**実行手順**:

1. Lineカバレッジで未カバーの行を特定
2. Branchカバレッジで未カバーの分岐を特定
3. 各未カバー箇所について原因を分析:
   - テストケースの不足
   - デッドコード（到達不能コード）
   - エラーハンドリング分岐
4. 追加テストが必要な箇所をリストアップ

**期待される成果物**:

- `outputs/phase-7/uncovered-analysis.md`: 未カバー箇所分析

---

### タスク4: 統合テスト結果確認

**目的**: 統合テストが正常に動作していることを確認する

**実行手順**:

1. 統合テストのみ実行（タグ付けされている場合）:
   ```bash
   pnpm --filter @repo/shared test -- --grep "integration"
   ```
2. 全統合テストがPASSしていることを確認
3. 統合テストのカバレッジ寄与を確認

**期待される成果物**:

- `outputs/phase-7/integration-test-result.md`: 統合テスト結果

---

### タスク5: カバレッジ未達時の追加テスト作成

**目的**: カバレッジ未達の場合、追加テストを作成する

**実行手順**:

1. タスク3で特定した未カバー箇所に対するテストを作成
2. テスト実行してカバレッジが向上したことを確認
3. 目標達成までタスク1〜5を繰り返す

**期待される成果物**:

- 追加テストコード（必要な場合）

---

### タスク6: カバレッジレポート最終化

**目的**: 最終的なカバレッジレポートを作成する

**実行手順**:

1. 最終カバレッジ測定:
   ```bash
   pnpm --filter @repo/shared test -- --coverage
   ```
2. 最終結果を記録
3. カバレッジ推移（初期 → 拡充後 → 最終）を記録
4. 次Phase（リファクタリング）への引き継ぎ事項を記録

**期待される成果物**:

- `outputs/phase-7/coverage-final-report.md`: 最終カバレッジレポート
