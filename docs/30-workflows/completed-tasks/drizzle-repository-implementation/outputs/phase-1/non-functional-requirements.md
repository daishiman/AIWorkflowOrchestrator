## エラーハンドリング要件

### NFR-ERROR-001: Result<T, E> 型の使用

| 項目     | 要件                                 |
| -------- | ------------------------------------ |
| 基本方針 | 例外スローを最小化し、Result型で返却 |
| 成功時   | `ok(value)` で返却                   |
| 失敗時   | `err(error)` で返却                  |
| エラー型 | `DomainError` サブクラスを使用       |

### NFR-ERROR-002: エラーカテゴリ

| エラー種別             | 対応方法                  |
| ---------------------- | ------------------------- |
| DB接続エラー           | ログ出力 + 上位層への伝播 |
| クエリエラー           | ログ出力 + 上位層への伝播 |
| データマッピングエラー | Result.err で返却         |
| バリデーションエラー   | Result.err で返却         |

### NFR-ERROR-003: エラーメッセージ

| 項目         | 要件                                       |
| ------------ | ------------------------------------------ |
| 日本語対応   | エラーメッセージは日本語で提供             |
| コード付与   | 各エラーに一意のエラーコードを付与         |
| コンテキスト | エラー発生箇所・原因が特定可能な情報を含む |

## パフォーマンス要件

### NFR-PERF-001: クエリ効率

| 項目             | 要件                                 |
| ---------------- | ------------------------------------ |
| N+1問題回避      | バッチ取得を使用                     |
| インデックス活用 | 既存インデックスを活用したクエリ設計 |
| 不要なSELECT回避 | 必要なカラムのみ選択                 |

### NFR-PERF-002: 応答時間目標（参考値）

| 操作                | 目標応答時間 |
| ------------------- | ------------ |
| findById            | < 50ms       |
| findByUserId (20件) | < 100ms      |
| save                | < 100ms      |
| saveMany (10件)     | < 200ms      |

## セキュリティ要件

### NFR-SEC-001: SQLインジェクション対策

| 項目               | 要件                                |
