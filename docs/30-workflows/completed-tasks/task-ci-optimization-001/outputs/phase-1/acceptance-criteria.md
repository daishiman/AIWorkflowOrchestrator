## 依存関係・前提条件

- GitHub Actions のキャッシュ上限: 10GB/リポジトリ（node_modules 合計 ~500MB〜1GB で余裕あり）
- GitHub Free Tier の並列ジョブ上限: 20（シャード17+その他3ジョブ=20でちょうど収まる）
- `pnpm-lock.yaml` が存在していること（キャッシュキーのハッシュ対象）

## リスク

| リスク                                    | 対策                                                                         |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| node_modules サイズが想定（~1GB）を超える | キャッシュdownload時間が90秒超の場合は廃止し pnpm ストアキャッシュのみに戻す |
| シャード17で並列上限（20）到達            | キューイング1分超の場合はシャード数を16に戻す                                |
| CI_MAX_FORKS=3 でOOM発生                  | OOM発生1件でも確認した場合はCI_MAX_FORKS=2に戻す                             |
