## pnpm install 固定費の詳細

### なぜ `cache: "pnpm"` だけでは不十分か

`cache: "pnpm"` は pnpm のグローバルストア（`~/.local/share/pnpm/store`）をキャッシュするが、
以下の処理は毎回実行される:

1. `pnpm install --frozen-lockfile`: lockfileから`node_modules`リンクを作成（ハードリンク）
2. Electronのネイティブモジュール再ビルド（`electron-rebuild`相当）
3. `postinstall` スクリプト

これらの固定費が全ジョブで発生しており、`node_modules` をキャッシュすることで完全にスキップできる。
