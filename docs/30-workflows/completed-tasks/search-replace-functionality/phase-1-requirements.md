## 目的

検索・置換機能の目的、スコープ、受け入れ基準を明確に定義し、後続Phaseでの設計・実装の基盤を確立する。

## 背景

テキストエディターの基本機能として、検索と置換は必須の機能である。ユーザーがファイル内およびワークスペース全体での効率的な編集を行うためには、明確な要件定義が必要である。

## 機能要件チェックリスト

### ファイル内検索

- [ ] Ctrl+F で検索パネルを表示
- [ ] インクリメンタル検索（入力と同時に検索）
- [ ] 検索結果のハイライト表示
- [ ] 検索結果数の表示（例: 3/10）
- [ ] 次/前の検索結果への移動（F3/Shift+F3）
- [ ] 検索履歴の保持

### ファイル内置換

- [ ] Ctrl+H で置換パネルを表示（または検索パネルの拡張）
- [ ] 単一置換（現在の一致を置換）
- [ ] 全置換（全ての一致を置換）
- [ ] 置換プレビュー

### 検索オプション

- [ ] 大文字/小文字区別オプション
- [ ] 単語単位検索オプション
- [ ] 正規表現検索オプション
- [ ] 正規表現キャプチャグループ対応（$1, $2等）

### ワークスペース検索

- [ ] Ctrl+Shift+F でワークスペース検索パネルを表示
- [ ] 全文検索
- [ ] ファイル名検索
- [ ] 検索結果のファイル別グルーピング
- [ ] コンテキスト表示（前後の行）
- [ ] 検索結果の折りたたみ/展開
- [ ] 検索結果からファイルへのジャンプ

### ワークスペース置換

- [ ] 複数ファイル一括置換
- [ ] 置換前の確認ダイアログ
- [ ] 置換結果のプレビュー
- [ ] 元に戻す機能

### 除外設定

- [ ] 除外パターン設定（.gitignore連携）
- [ ] デフォルト除外（node_modules, .git, dist等）
- [ ] ファイルタイプフィルタ
