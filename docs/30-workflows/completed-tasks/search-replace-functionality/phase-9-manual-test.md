## 不具合対応フロー

### 重大な不具合の場合

1. 不具合レポートを作成
2. 影響範囲を特定
3. 適切なPhaseに戻って修正
   - 要件の問題: Phase 1
   - 設計の問題: Phase 2
   - 実装の問題: Phase 5

### 軽微な不具合の場合

1. 不具合レポートを作成
2. Phase 5で修正
3. 影響を受けるテストを再実行
