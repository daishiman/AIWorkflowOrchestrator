# 検索・置換機能 - 要件定義書

## 1. 機能要件

### 1.1 ファイル内検索 (FR-001)

| ID       | 要件                 | 優先度 | 詳細                                  |
| -------- | -------------------- | ------ | ------------------------------------- |
| FR-001-1 | 検索パネル表示       | 必須   | Ctrl+F で検索パネルを表示する         |
| FR-001-2 | インクリメンタル検索 | 必須   | 入力と同時に検索結果を更新する        |
| FR-001-3 | 検索結果ハイライト   | 必須   | マッチした箇所をハイライト表示する    |
| FR-001-4 | 検索結果カウント     | 必須   | 現在位置/総件数を表示する（例: 3/10） |
| FR-001-5 | 次の結果へ移動       | 必須   | F3またはEnterで次の結果に移動する     |
| FR-001-6 | 前の結果へ移動       | 必須   | Shift+F3で前の結果に移動する          |
| FR-001-7 | 検索履歴             | 推奨   | 過去の検索クエリを保持する            |

### 1.2 検索オプション (FR-002)

| ID       | 要件               | 優先度 | 詳細                       |
| -------- | ------------------ | ------ | -------------------------- |
| FR-002-1 | 大文字/小文字区別  | 必須   | トグルで切り替え可能       |
| FR-002-2 | 単語単位検索       | 必須   | 完全一致のみをマッチさせる |
| FR-002-3 | 正規表現検索       | 必須   | 正規表現パターンをサポート |
| FR-002-4 | キャプチャグループ | 推奨   | $1, $2 等の置換対応        |

### 1.3 ファイル内置換 (FR-003)

| ID       | 要件           | 優先度 | 詳細                      |
| -------- | -------------- | ------ | ------------------------- |
| FR-003-1 | 置換パネル表示 | 必須   | Ctrl+H で置換パネルを表示 |
| FR-003-2 | 単一置換       | 必須   | 現在のマッチのみを置換    |
| FR-003-3 | 全置換         | 必須   | 全てのマッチを一括置換    |
| FR-003-4 | 置換プレビュー | 推奨   | 置換前に結果を確認可能    |

### 1.4 ワークスペース検索 (FR-004)

| ID       | 要件                   | 優先度 | 詳細                                 |
| -------- | ---------------------- | ------ | ------------------------------------ |
| FR-004-1 | WS検索パネル表示       | 必須   | Ctrl+Shift+F で表示                  |
| FR-004-2 | 全文検索               | 必須   | ワークスペース全体を検索             |
| FR-004-3 | ファイル別グルーピング | 必須   | 結果をファイルごとにグループ化       |
| FR-004-4 | コンテキスト表示       | 必須   | マッチ行の前後を表示                 |
| FR-004-5 | ファイルジャンプ       | 必須   | 結果クリックで該当ファイル・行に移動 |
| FR-004-6 | 除外パターン           | 必須   | node_modules等を除外                 |
| FR-004-7 | ファイルタイプフィルタ | 推奨   | 特定の拡張子のみ検索                 |

### 1.5 ワークスペース置換 (FR-005)

| ID       | 要件             | 優先度 | 詳細                         |
| -------- | ---------------- | ------ | ---------------------------- |
| FR-005-1 | 複数ファイル置換 | 必須   | 複数ファイルを一括置換       |
| FR-005-2 | 置換確認         | 必須   | 置換前に確認ダイアログを表示 |
| FR-005-3 | 置換プレビュー   | 必須   | 変更内容を事前に確認可能     |
| FR-005-4 | アンドゥ対応     | 推奨   | 置換操作を元に戻せる         |

## 2. 非機能要件

### 2.1 パフォーマンス (NFR-001)

| ID        | 要件               | 目標値                    |
| --------- | ------------------ | ------------------------- |
| NFR-001-1 | ファイル内検索速度 | 1MBファイルで100ms以下    |
| NFR-001-2 | 全置換速度         | 10,000行で500ms以下       |
| NFR-001-3 | WS検索速度         | 1,000ファイルで3秒以下    |
| NFR-001-4 | 正規表現検索速度   | 複雑なパターンで200ms以下 |

### 2.2 ユーザビリティ (NFR-002)

| ID        | 要件                      | 詳細                               |
| --------- | ------------------------- | ---------------------------------- |
| NFR-002-1 | キーボード操作            | 全機能をキーボードのみで操作可能   |
| NFR-002-2 | VS Code互換ショートカット | 標準的なショートカットを採用       |
| NFR-002-3 | 検索状態保持              | 検索オプションをセッション間で保持 |

### 2.3 アクセシビリティ (NFR-003)

| ID        | 要件                     | 詳細                                |
| --------- | ------------------------ | ----------------------------------- |
| NFR-003-1 | スクリーンリーダー対応   | 適切なARIAラベルを設定              |
| NFR-003-2 | キーボードナビゲーション | Tab/Shift+Tabで全要素にアクセス可能 |
| NFR-003-3 | フォーカス表示           | フォーカス状態を視覚的に明確化      |
| NFR-003-4 | コントラスト             | WCAG 2.1 AA基準を満たす             |

### 2.4 セキュリティ (NFR-004)

| ID        | 要件                 | 詳細                         |
| --------- | -------------------- | ---------------------------- |
| NFR-004-1 | ReDoS対策            | 正規表現にタイムアウトを設定 |
| NFR-004-2 | 入力サニタイズ       | 特殊文字の適切なエスケープ   |
| NFR-004-3 | パストラバーサル防止 | ファイルパスの検証           |

## 3. キーボードショートカット定義

| ショートカット | 機能                             | macOS            |
| -------------- | -------------------------------- | ---------------- |
| Ctrl+F         | ファイル内検索                   | Cmd+F            |
| Ctrl+H         | ファイル内置換                   | Cmd+H            |
| Ctrl+Shift+F   | ワークスペース検索               | Cmd+Shift+F      |
| F3             | 次の検索結果                     | F3               |
| Shift+F3       | 前の検索結果                     | Shift+F3         |
| Enter          | 次の検索結果（検索フィールド内） | Enter            |
| Escape         | 検索パネルを閉じる               | Escape           |
| Ctrl+Shift+1   | 単一置換                         | Cmd+Shift+1      |
| Ctrl+Alt+Enter | 全置換                           | Cmd+Option+Enter |

---

## 4. スコープ外

以下の機能は本タスクのスコープ外とする:

- セマンティック検索（RAG機能で対応）
- シンボル検索（Go to Definition等）
- 画像内テキストの検索
- バイナリファイル内の検索
- 検索インデックスの永続化

## 5. 依存関係

### 前提コンポーネント

- エディターコンポーネント（既存）
- ファイルツリーコンポーネント（既存）
- キーボードショートカット管理（既存）

- SearchPanel（ファイル内検索UI）
- WorkspaceSearchPanel（WS検索UI）
