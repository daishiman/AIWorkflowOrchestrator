## 品質チェックリスト

### 機能検証

- [ ] 全ユニットテスト成功
- [ ] 全統合テスト成功
- [ ] 全E2Eテスト成功（該当する場合）

### コード品質

```bash
# Lint実行
pnpm lint

# 型チェック
pnpm typecheck

# フォーマットチェック
pnpm format:check
```

- [ ] Lintエラーなし
- [ ] 型エラーなし
- [ ] コードフォーマット適用済み

### テスト網羅性

```bash
# カバレッジ確認
pnpm test:coverage
```

- [ ] テストカバレッジ80%以上

### セキュリティ

```bash
# 依存関係の脆弱性スキャン
pnpm audit

# ReDoS検査（正規表現パターン）
# 手動確認
```

- [ ] 依存関係に重大な脆弱性なし
- [ ] ReDoSリスクのある正規表現パターンなし
- [ ] 入力値の適切なサニタイズ

### パフォーマンス

| テストケース                      | 目標    | 結果 |
| --------------------------------- | ------- | ---- |
| 1MBファイルでの検索               | < 100ms | [ ]  |
| 10,000行ファイルでの全置換        | < 500ms | [ ]  |
| 1,000ファイルのワークスペース検索 | < 3秒   | [ ]  |
| 正規表現検索（複雑なパターン）    | < 200ms | [ ]  |
