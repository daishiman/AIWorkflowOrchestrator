## 判定基準

| 判定  | 条件                               | 対応                         |
| ----- | ---------------------------------- | ---------------------------- |
| PASS  | 全観点で問題なし                   | Phase 4へ進行                |
| MINOR | 軽微な指摘あり（実装中に対応可能） | 指摘対応後Phase 4へ進行      |
| MAJOR | 重大な問題あり（設計変更が必要）   | 影響範囲に応じて戻り先を決定 |

**判定マトリクス:**

| 問題の種類            | 影響範囲 | 判定  | 戻り先  |
| --------------------- | -------- | ----- | ------- |
| IPC設計の根本的な問題 | 高       | MAJOR | Phase 2 |
| UI設計の根本的な問題  | 高       | MAJOR | Phase 2 |
| 要件漏れ              | 高       | MAJOR | Phase 1 |
| ホワイトリスト漏れ    | 中       | MINOR | -       |
| 型定義の軽微な修正    | 低       | MINOR | -       |
| ドキュメントの不備    | 低       | MINOR | -       |
