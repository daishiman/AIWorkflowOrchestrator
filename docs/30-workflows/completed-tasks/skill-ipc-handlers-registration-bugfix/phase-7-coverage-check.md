## 目的

テストカバレッジが目標基準を満たしているか確認し、
不足している場合は追加テストを行う。

## 背景

Phase 6でテストを拡充したが、カバレッジ目標を達成しているか検証が必要。
バグ修正においても品質基準を満たす必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ計測

**目的**: 現在のテストカバレッジを正確に計測する

**実行手順**:

1. カバレッジ付きでテストを実行
2. カバレッジレポートを出力
3. 各指標を確認

**実行コマンド**:

```bash
# カバレッジ付きテスト実行
pnpm --filter @repo/desktop test -- --coverage

# HTMLレポート出力
pnpm --filter @repo/desktop test -- --coverage --reporter=html
```

**期待される成果物**:

- `outputs/phase-7/coverage-metrics.md`: カバレッジ指標レポート

---

### タスク2: 目標達成確認

**目的**: カバレッジ目標を達成しているか確認する

**カバレッジ目標**:

| 指標              | 最低基準 | 推奨基準 | 現在値 | 判定 |
| ----------------- | -------- | -------- | ------ | ---- |
| Line Coverage     | 80%      | 90%      |        |      |
| Branch Coverage   | 60%      | 70%      |        |      |
| Function Coverage | 80%      | 90%      |        |      |

**実行手順**:

1. 各指標を目標と比較
2. 未達の指標を特定
3. 追加テストが必要な箇所を洗い出し

**期待される成果物**:

- `outputs/phase-7/coverage-assessment.md`: カバレッジ評価レポート

---

### タスク3: 追加テスト（必要な場合）

**目的**: カバレッジ目標未達の場合、追加テストを実装する

**実行手順**:

1. カバレッジが不足している行/ブランチを特定
2. 該当箇所をカバーするテストを追加
3. 再度カバレッジを計測
4. 目標達成を確認

**期待される成果物**:

- 追加されたテストコード（必要な場合）

---

### タスク4: 統合テスト再実行

**目的**: 全統合テストが正常に動作することを確認する

**実行手順**:

1. 全テストを実行
2. 統合テストが全てパスすることを確認
3. 結果を記録

**実行コマンド**:

```bash
# 全テスト実行
pnpm --filter @repo/desktop test

# 統合テストのみ実行（該当するパターンで）
pnpm --filter @repo/desktop test -- --grep "integration"
```

**期待される成果物**:

- `outputs/phase-7/integration-test-result.md`: 統合テスト結果
