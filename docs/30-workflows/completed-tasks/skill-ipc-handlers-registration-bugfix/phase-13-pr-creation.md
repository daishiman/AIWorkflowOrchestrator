## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認チェックリスト

**目的**: PR作成前に必須のローカル確認を行う

**実行手順**:

1. ビルドが成功することを確認
2. 全テストがパスすることを確認
3. 型チェックがパスすることを確認
4. Lintエラーがないことを確認

**確認コマンド**:

```bash
# ビルド
pnpm --filter @repo/desktop build

# テスト
pnpm --filter @repo/desktop test

# 型チェック
pnpm typecheck

# Lint
pnpm lint
```

**チェックリスト**:

| #   | 確認項目             | コマンド                            | 結果 |
| --- | -------------------- | ----------------------------------- | ---- |
| 1   | ビルドが成功する     | `pnpm --filter @repo/desktop build` |      |
| 2   | 全テストがパスする   | `pnpm --filter @repo/desktop test`  |      |
| 3   | 型チェックがパスする | `pnpm typecheck`                    |      |
| 4   | Lintエラーがない     | `pnpm lint`                         |      |

**期待される成果物**:

- `outputs/phase-13/local-check-result.md`: ローカル確認結果

---

### タスク2: 変更差分の確認

**目的**: コミット対象の変更を確認する

**実行手順**:

1. `git status` で変更ファイルを確認
2. `git diff` で変更内容を確認
3. 不要な変更が含まれていないことを確認

**確認コマンド**:

```bash
# 変更ファイル一覧
git status

# 変更差分
git diff
```

**期待される成果物**:

- `outputs/phase-13/diff-summary.md`: 変更差分サマリー

---

### タスク3: ユーザー承認の取得【必須】

**目的**: PR作成前にユーザーの明示的な承認を得る

**実行手順**:

1. ローカル確認結果を報告
2. 変更差分サマリーを報告
3. ユーザーにPR作成の許可を求める
4. 許可が得られてから次のタスクへ進む

**重要**: PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。

**期待される成果物**:

- ユーザー承認の記録

---

### タスク4: コミットとPR作成

**目的**: 変更をコミットしPRを作成する

**前提**: タスク3でユーザー承認を得ていること

**実行手順**:

1. 変更をステージング
2. コミットを作成
3. リモートにプッシュ
4. `/ai:diff-to-pr` を使用してPR作成

**コミットメッセージ形式**:

```
fix(desktop): skillAPI引数形式をオブジェクト形式に統一

Agent画面の無限ローディング問題を修正。
preloadのskillAPIで配列を直接渡していたが、
ハンドラー側が期待するオブジェクト形式に修正。

- import: skillIds → { skillIds }
- remove: skillId → { skillId }
- getDetail: skillId → { skillId }

Closes #XXX

Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>
```

**期待される成果物**:

- コミット
- Pull Request

---

### タスク5: CI確認

**目的**: CIパイプラインが正常に完了することを確認する

**実行手順**:

1. PR作成後、CIの実行を待つ
2. 全CIジョブがパスすることを確認
3. 失敗した場合は原因を調査し修正

**確認項目**:

| CIジョブ   | 状態 | 備考 |
| ---------- | ---- | ---- |
| Build      |      |      |
| Test       |      |      |
| Lint       |      |      |
| Type Check |      |      |

**期待される成果物**:

- `outputs/phase-13/ci-result.md`: CI結果レポート

---

### タスク6: マージ準備完了報告

**目的**: PRがマージ可能な状態であることを報告する

**実行手順**:

1. 全CIがパスしていることを確認
2. PR URLを報告
3. マージはユーザーがGitHub UIで手動実行することを案内

**重要**: マージは自動実行しない。ユーザーがGitHub UIで手動実行する。

**期待される成果物**:

- マージ準備完了報告

## 重要な注意事項

### PR作成に関する重要な注意

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |

### マージに関する注意

マージはユーザーがGitHub UIで手動実行する。
このPhaseではマージ準備完了の報告までを行う。
