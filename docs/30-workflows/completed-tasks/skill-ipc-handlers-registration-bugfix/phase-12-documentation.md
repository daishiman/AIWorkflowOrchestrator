### タスク1: 実装ガイド作成

**目的**: バグ修正の技術的詳細を記録する

**実行手順**:

1. Part 1: 概念的説明（初学者・非技術者向け）を作成
2. Part 2: 技術的詳細（開発者向け）を作成
3. 修正内容と理由を記録

**実装ガイド構成**:

```markdown
# スキルIPCハンドラー登録バグ修正 - 実装ガイド

## Part 1: 概念的説明

### 問題の概要

Agent画面でスキル一覧が表示されない問題が発生していました。

### 原因

preload（フロントエンド）とmain（バックエンド）の間で、
データの渡し方に不一致がありました。

### 解決策

データの渡し方を統一することで、正常に通信できるようになりました。

## Part 2: 技術的詳細

### 根本原因

preload/index.tsで配列を直接渡していたが、
skillHandlers.tsはオブジェクト形式 `{ skillIds: string[] }` を期待。

### 修正内容

1. `import` メソッド: `skillIds` → `{ skillIds }`
2. `remove` メソッド: `skillId` → `{ skillId }`
3. `getDetail` メソッド: `skillId` → `{ skillId }`

### 関連ファイル

- `apps/desktop/src/renderer/preload/index.ts`
- `apps/desktop/src/main/ipc/skillHandlers.ts`
```

**期待される成果物**:

- `outputs/phase-12/implementation-guide.md`: 実装ガイド

### タスク4: システム仕様書更新（aiworkflow-requirements）

**目的**: 必要に応じてシステム仕様書を更新する

**実行手順**:

3. タスク完了ステータスを追加

**更新判断基準**:

| 更新が必要な場合            | 更新が不要な場合                         |
| --------------------------- | ---------------------------------------- |
| 新規インターフェース/型追加 | 内部実装の詳細変更のみ                   |
| 既存インターフェース変更    | リファクタリング（インターフェース不変） |
| 新規定数/設定値追加         | バグ修正（仕様変更なし）                 |

**本タスクの判断**:

- バグ修正であり、インターフェースの変更はない
- ただし、IPC Handler Registration Patternの文書化として `architecture-patterns.md` に記録済み（6.11.0）
