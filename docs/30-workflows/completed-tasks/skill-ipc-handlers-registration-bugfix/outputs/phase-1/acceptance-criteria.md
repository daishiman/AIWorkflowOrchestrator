| skill:get-detail | `{ skillId: "" }`   | `{ skillId: "" }`   |

### レスポンス形式の仕様

全てのスキル関連IPCは `OperationResult<T>` 形式で応答:

```typescript
type OperationResult<T> =
  | { success: true; data: T }
  | { success: false; error: string };
```
