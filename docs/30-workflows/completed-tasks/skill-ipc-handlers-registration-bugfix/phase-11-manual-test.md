## 目的

UX・実環境での動作を手動テストで確認し、
バグが正しく修正されていることを最終検証する。

## 背景

自動テストではカバーできないUI/UXの観点や、
実際のElectron環境での動作を手動で確認する必要がある。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 関連自動テストの実行確認

**目的**: 手動テスト前に自動テストが全てパスしていることを確認する

**実行手順**:

1. 全テストを実行: `pnpm --filter @repo/desktop test`
2. 全テストがパスしていることを確認
3. 結果を記録

**実行コマンド**:

```bash
# テスト実行
pnpm --filter @repo/desktop test

# ビルド
pnpm --filter @repo/desktop build
```

**期待される成果物**:

- 全テストパスの確認結果

---

### タスク2: 機能テスト（正常系）

**目的**: Agent画面でスキル機能が正常に動作することを確認する

**実行手順**:

1. Electronアプリを起動: `pnpm --filter @repo/desktop start`
2. Agent画面に遷移
3. スキル一覧が表示されることを確認（無限ローディングでないこと）
4. スキルのインポート機能をテスト
5. スキルの削除機能をテスト
6. スキルの詳細表示をテスト

**テスト項目**:

| TC-ID  | 機能             | 期待結果                           | 結果 | 備考 |
| ------ | ---------------- | ---------------------------------- | ---- | ---- |
| TC-001 | Agent画面表示    | スキル一覧が正常に表示される       |      |      |
| TC-002 | スキルインポート | スキルがインポートできる           |      |      |
| TC-003 | スキル削除       | スキルが削除できる                 |      |      |
| TC-004 | スキル詳細表示   | スキルの詳細が表示される           |      |      |
| TC-005 | 再読み込み       | 画面再読み込み後も正常に表示される |      |      |

**期待される成果物**:

- `outputs/phase-11/functional-test-result.md`: 機能テスト結果

---

### タスク3: エラーハンドリングテスト（異常系）

**目的**: エラー状態での動作を確認する

**実行手順**:

1. 存在しないスキルIDでの操作をテスト
2. ネットワークエラー時の動作を確認（シミュレート可能な場合）
3. エラーメッセージが適切に表示されることを確認

**テスト項目**:

| TC-ID  | 状況                     | 期待結果                     | 結果 | 備考 |
| ------ | ------------------------ | ---------------------------- | ---- | ---- |
| TC-101 | 存在しないスキルの削除   | エラーメッセージが表示される |      |      |
| TC-102 | 空のスキルIDでインポート | 適切にハンドリングされる     |      |      |

**期待される成果物**:

- `outputs/phase-11/error-handling-test-result.md`: 異常系テスト結果

---

### タスク4: 統合テスト（UI/IPC接続）

**目的**: UI操作からIPC通信、結果表示までの一連の流れを確認する

**実行手順**:

1. Agent画面でスキル一覧を表示
2. スキルを選択
3. インポート操作を実行
4. 結果が画面に反映されることを確認
5. 削除操作を実行
6. 結果が画面に反映されることを確認

**テスト項目**:

| テスト項目   | 結果 | 課題有無 |
| ------------ | ---- | -------- |
| IPC接続      |      |          |
| 正常系フロー |      |          |
| エラー表示   |      |          |
| 状態同期     |      |          |

**期待される成果物**:

- `outputs/phase-11/integration-test-result.md`: 統合テスト結果

---

### タスク5: 発見課題の記録

**目的**: 手動テスト中に発見した課題を記録する

**実行手順**:

1. 各テストで発見した課題を記録
2. 課題の重要度を評価
3. 対応要否を判断

**期待される成果物**:

- `outputs/phase-11/discovered-issues.md`: 発見課題レポート
