## タスク分類（Phase 1 宣言に基づく）

**分類: NON_VISUAL（Renderer内部ロジック中心）＋補助スクリーンショット検証**

本タスクは `resolveExternalIntegration` の内部ロジック変更を主対象としつつ、Q5 の visual regression 確認として補助スクリーンショットも取得する。
そのため、動作確認・コード確認・ログ出力に加えて、Q5 single / multi 状態の画像証跡を残す。

ただし、以下のコード確認は必須とする:

- スキルウィザード Q5 で複数ツール選択後のスキル生成が正常動作すること
- `ConversationRoundStep.tsx` の「主ツール」バッジが削除されていることのコード確認
- M-01 TODO コメントが削除されていることのコード確認
- Q5 の single / multi 選択状態で主ツールバッジが表示されないことのスクリーンショット確認

## 目的

3層評価（Semantic / Functional / Regression）で実装品質を確認し、AC-1〜AC-7 の充足を最終確認する。
補助スクリーンショットは、Q5 の表示状態が主ツールバッジなしで安定していることの視覚証跡として用いる。

## 実行タスク

- アプリ起動確認: Electron アプリが正常起動すること
- Semantic 評価: `resolveExternalIntegration` の型・インターフェース妥当性の確認
- Functional 評価: 複数ツール並列処理・単一ツール後方互換・フォールバック動作の確認
- Regression 評価: 既存スキル生成フロー全体への影響がないことの確認
- M-01 TODO 削除確認: コードベース全体で M-01 TODO が存在しないことを確認

## 実行手順

### 1. アプリ起動

```bash
# Electron デスクトップアプリの起動
pnpm --filter @repo/desktop dev
```

起動後、アプリが正常に表示されることを確認する。

### 2. スキルウィザード Q5 での複数ツール選択テスト

1. アプリのメニューまたはサイドバーから「スキル作成」を選択する
2. スキル作成ウィザードが開くことを確認する
3. Q1〜Q4 を適切に入力して Q5（外部ツール連携）まで進む
4. Q5 で複数のツール（例: Slack, GitHub）を選択する
5. ウィザードを最後まで進み、スキルが正常に生成されることを確認する

**期待結果**: 複数ツール選択後もスキル生成が正常に完了し、エラーが発生しないこと

### 3. 単一ツール選択での後方互換性確認（AC-3）

1. Q5 でツールを 1 つだけ選択する
2. ウィザードを最後まで進み、スキルが正常に生成されることを確認する
3. 生成されたスキルの内容が単一ツール選択時の従来動作と一致することを確認する

**期待結果**: 単一ツール選択時も正常にスキルが生成されること（後方互換性維持）

### 4. 空配列・未対応ツールのフォールバック確認（AC-4）

```bash
# 空配列フォールバックと未対応ツールフォールバックを unit test で確認
pnpm --filter @repo/desktop exec vitest run \
  src/renderer/components/skill/__tests__/resolveExternalIntegration.test.ts -t "AC-4"
```

> 注意: 手動テストでは、対象ケースのテスト結果とコード確認の両方を証跡にする。

**期待結果**: エラーをスローせず、安全なフォールバック値（空の merged object）を返すこと

### 5. M-01 TODO コメント削除確認（AC-7）

```bash
# M-01 TODO の残存確認
rg -n "M-01" apps/desktop/src
```

**期待結果**: 0 件ヒットすること（コメントが全て削除されていること）

### 6. ConversationRoundStep.tsx の「主ツール」バッジ削除確認

> 本確認は、`UT-SKILL-WIZARD-MSO-MAIN-TOOL-UI-001` で実装された暫定措置バッジが本タスク完了により削除対象となった場合にのみ実施する。

```bash
# バッジ関連コードの残存確認
rg -n "主ツール|shouldShowMainToolBadge|MAIN_TOOL" \
  apps/desktop/src/renderer/components/skill/wizard/ConversationRoundStep.tsx
```

**期待結果**: バッジ削除が完了している場合は 0 件ヒット、または削除対象外の場合は本確認をスキップして理由を記録する

## 評価観点

### Semantic 評価（型・インターフェース妥当性）

| 評価項目                                                                     | 確認方法                                                             | 合格基準                           |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------- |
| `resolveExternalIntegration` の引数型が `string[]` に変更されていること      | TypeScript 定義ファイルまたは実装ファイルで型を確認                  | 引数型が `string[]` であること     |
| 返り値の型がマージ後の統合情報を正しく表現していること                       | 型定義を確認し、API エンドポイント・認証方式・主要操作が含まれること | 全フィールドが型に含まれていること |
| `SkillCreateWizard.tsx` の呼び出し箇所が `string[]` を渡していること（AC-5） | コードレビューで呼び出し箇所を確認                                   | 配列渡しに更新されていること       |

### Functional 評価（並列処理・マージ・フォールバック）

| 評価項目                                                                               | 確認方法                                                 | 合格基準                                               |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| 複数ツール選択時に `Promise.all` で並列処理が実行されること（AC-1）                    | テストコードまたはコードレビューで並列処理の実装を確認   | `Promise.all` または同等の並列処理が実装されていること |
| 各ツールの統合情報（API エンドポイント・認証方式・主要操作）がマージされること（AC-2） | テストケースでマージ後の結果が期待値と一致することを確認 | 全ツールの情報が結果に含まれていること                 |
| 単一ツール選択時に従来と同一の動作を維持すること（AC-3）                               | 単一ツールのテストケースで従来と同一の結果を確認         | 結果が従来実装と同一であること                         |

### Regression 評価（既存フロー影響なし）

| 評価項目                                                                | 確認方法                                                       | 合格基準                                   |
| ----------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------ |
| スキル生成フロー全体（Q1〜Q6 → スキル出力）が正常に動作すること         | アプリでウィザード全体を操作し、スキル生成が完了することを確認 | スキルが正常に生成されること               |
| `resolveExternalIntegration` 以外のウィザードステップへの影響がないこと | Q1〜Q4、Q6 の各ステップを操作し、挙動に変化がないことを確認    | 他のステップで予期しない動作変化がないこと |
| 既存の自動テストが全件 PASS していること                                | `pnpm --filter @repo/desktop test` の結果を確認                | 全件 PASS であること                       |
