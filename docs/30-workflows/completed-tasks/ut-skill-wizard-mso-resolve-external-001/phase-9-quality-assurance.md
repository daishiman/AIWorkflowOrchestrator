## 目的

line budget、link、mirror parity を一括判定する。

本フェーズでは、実装・リファクタリングが完了したコードに対して、静的解析・テスト・ビルドを網羅的に実行し、全チェックが PASS していることを確認する。また、`resolveExternalIntegration` の行数増加量（line budget）と mirror parity（`.claude` と `.agents` の同期状態）についても確認し、本タスクの完了基準を満たしていることを判定する。

## PASS / FAIL 判定基準

### PASS 条件（全て満たすこと）

| #   | 判定項目              | 基準                                                                   |
| --- | --------------------- | ---------------------------------------------------------------------- |
| 1   | TypeScript 型チェック | `pnpm --filter @repo/desktop typecheck` がエラー 0 件で終了すること    |
| 2   | ESLint チェック       | `pnpm --filter @repo/desktop lint` がエラー 0 件で終了すること         |
| 3   | テスト全件            | `pnpm --filter @repo/desktop test` が全件 PASS すること                |
| 4   | テストカバレッジ      | `resolveExternalIntegration` のカバレッジが 90% 以上であること（AC-6） |
| 5   | ビルド                | `pnpm --filter @repo/desktop build` がエラーなしで完了すること         |
| 6   | line budget           | 行数増加量が許容範囲内であること                                       |
| 7   | mirror parity         | `.claude` と `.agents` の同期が確認されていること                      |
| 8   | M-01 TODO 削除        | M-01 TODO コメントが全て削除されていること（AC-7）                     |

### FAIL 条件（いずれか1つでも該当する場合）

- `pnpm --filter @repo/desktop typecheck` でエラーが 1 件以上発生している
- `pnpm --filter @repo/desktop lint` でエラーが 1 件以上発生している
- テストが 1 件以上 FAIL している
- `resolveExternalIntegration` のカバレッジが 90% 未満である
- ビルドがエラーで失敗している
- M-01 TODO コメントが残存している

### FAIL 時の対処

FAIL が発生した場合は、該当するチェック項目の問題を修正し、**全てのチェックを再実行**してから判定を行う。部分的な再実行は認めない（修正が他の項目に影響する可能性があるため）。
