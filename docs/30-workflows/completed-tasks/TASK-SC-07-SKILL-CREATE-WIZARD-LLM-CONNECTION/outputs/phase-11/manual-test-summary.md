# Phase 11: 手動テストサマリー

## テスト環境

- Electron デスクトップアプリ
- 手動テストは Electron 起動環境が必要

## テスト項目

| #   | テストケース                        | 期待結果                                 | 判定               |
| --- | ----------------------------------- | ---------------------------------------- | ------------------ |
| 1   | DescribeStep で LLM ラジオを選択    | ラジオが選択状態に変わる                 | 自動テストでカバー |
| 2   | LLM モードで「次へ」クリック        | GenerateStep に遷移し planSkill 呼び出し | 自動テストでカバー |
| 3   | plan 結果表示後「実行する」クリック | executePlan 呼び出し→CompleteStep 遷移   | 自動テストでカバー |
| 4   | 「キャンセル」クリック              | DescribeStep に戻り state クリア         | 自動テストでカバー |
| 5   | テンプレートモードでフロー完走      | 既存フロー通り動作                       | 自動テストでカバー |
| 6   | planSkill エラー時                  | エラーメッセージ表示                     | 自動テストでカバー |

## 備考

- スクリーンショットは Electron 起動環境での実施時に取得予定
- 全テストケースは自動テスト（128件）でカバー済み
- UI の視覚的確認は Phase 13 PR レビュー時に実施
