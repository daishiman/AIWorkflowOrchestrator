## レビュー観点

### 1. モック戦略の妥当性

| チェック項目                                                      | 確認結果 |
| ----------------------------------------------------------------- | -------- |
| `vi.mock` パターンが既存テストと統一されているか                  | ☐        |
| Storeモックが`useSkillStore`のセレクタパターンに対応しているか    | ☐        |
| テスト間の分離が保証されているか（`beforeEach`で`clearAllMocks`） | ☐        |
| 部分オーバーライドパターンが適切か                                | ☐        |

### 2. テストデータの網羅性

| チェック項目                                                 | 確認結果 |
| ------------------------------------------------------------ | -------- |
| `SkillMetadata` のファクトリが全フィールドをカバーしているか | ☐        |
| `SkillPermissionRequest` のツール別バリエーションがあるか    | ☐        |
| `SkillStreamMessage` の全タイプ（5種）がカバーされているか   | ☐        |
| 境界値データ（空配列、null、長い文字列等）が含まれているか   | ☐        |

### 3. テスト構造の妥当性

| チェック項目                                            | 確認結果 |
| ------------------------------------------------------- | -------- |
| 55テストケースが全て`describe/it`構造に配置されているか | ☐        |
| テストの独立性が保証されているか（テスト間依存なし）    | ☐        |
| `userEvent.setup()` パターンが統一されているか          | ☐        |
| 非同期操作に`waitFor`が使用されているか                 | ☐        |

### 4. アクセシビリティテストの妥当性

| チェック項目                                                      | 確認結果 |
| ----------------------------------------------------------------- | -------- |
| WAI-ARIA Listboxパターンのテストが含まれているか（SkillSelector） | ☐        |
| `aria-expanded`, `aria-haspopup` の検証が含まれているか           | ☐        |
| キーボードナビゲーション（Escape, ArrowDown）のテストがあるか     | ☐        |
| ダイアログのフォーカス管理テストがあるか                          | ☐        |

## 統合テスト連携【必須】

| レビュー観点       | 確認項目                                                |
| ------------------ | ------------------------------------------------------- |
| Store接続テスト    | Store状態→UIレンダリングのデータフローが検証されるか    |
| アクション呼び出し | UIイベント→Storeアクション呼び出しが検証されるか        |
| エラーハンドリング | インポート失敗、実行エラー時のUI表示テストがあるか      |
| 状態遷移テスト     | `SkillExecutionStatus` の各状態でのUI変化テストがあるか |

## 多角的チェック観点（AIが判断）

| 観点             | 適用判断                          | 確認項目                                             |
| ---------------- | --------------------------------- | ---------------------------------------------------- |
| UI/UX            | テスト設計のUI検証品質 → **適用** | テスト設計がUI仕様を正しく検証する構造になっているか |
| アクセシビリティ | a11yテスト設計の品質 → **適用**   | WCAG基準のテスト設計が十分か                         |
| セキュリティ     | テストコードのみ → **適用外**     | -                                                    |
| パフォーマンス   | テスト実行速度 → **限定的適用**   | テスト設計がパフォーマンスを考慮しているか           |
