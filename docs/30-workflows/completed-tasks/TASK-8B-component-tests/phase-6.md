# Phase 6: テスト拡充

## メタ情報

| 項目   | 値                           |

| Phase  | 6                            |
| タスク | TASK-8B コンポーネントテスト |

## 目的

Phase 5で全テスト成功を確認した後、カバレッジ目標達成に向けてテストを拡充する。境界値テスト、エラーケースのテスト、アクセシビリティ追加テストを実装する。

## 実行タスク

- カバレッジ分析: 現在のカバレッジを測定し不足領域を特定
- 境界値テスト追加: 空データ、長文字列、特殊文字等のエッジケース
- エラーケース追加: インポート失敗、ネットワークエラー等
- アクセシビリティテスト追加: スクリーンリーダー対応、フォーカス管理

## ユニットテストカバレッジ基準

| 指標               | 最低基準 | 推奨基準 |
| ------------------ | -------- | -------- |
| Line Coverage      | 80%      | 90%      |
| Branch Coverage    | 60%      | 70%      |
| Function Coverage  | 80%      | 90%      |
| Statement Coverage | 80%      | 90%      |

## 実行手順

### ステップ1: カバレッジ測定

```bash
# カバレッジ測定
pnpm --filter @repo/desktop test -- --run --coverage src/renderer/components/skill/__tests__/
```

### ステップ2: ギャップ分析

カバレッジレポートから以下を特定:

| 分析対象     | 確認内容                                         |
| ------------ | ------------------------------------------------ |
| 未到達の行   | 条件分岐で到達していないコードパス               |
| 未テスト関数 | テストされていないイベントハンドラ、ヘルパー関数 |
| 未到達分岐   | if/else、三項演算子の未テスト分岐                |

### ステップ3: 追加テスト作成

**SkillSelector 追加テスト候補**:

| テスト内容                            | カテゴリ         |
| ------------------------------------- | ---------------- |
| スキルリストが空の場合の表示          | 境界値           |
| スキル名が非常に長い場合の表示        | 境界値           |
| importedSkillsとavailableSkills両方空 | 境界値           |
| ドロップダウン開閉の連続操作          | インタラクション |
| Tab キーでのフォーカス移動            | a11y             |

**SkillImportDialog 追加テスト候補**:

| テスト内容                     | カテゴリ |
| ------------------------------ | -------- |
| 全サブリソースが空の場合       | 境界値   |
| description が空文字列の場合   | 境界値   |
| allowedTools が空配列の場合    | 境界値   |
| インポート失敗時のエラー表示   | エラー   |
| ダイアログのフォーカストラップ | a11y     |

**PermissionDialog 追加テスト候補**:

| テスト内容                               | カテゴリ     |
| ---------------------------------------- | ------------ |
| args が空オブジェクトの場合              | 境界値       |
| reason が未定義の場合                    | 境界値       |
| toolName が未知のツールの場合            | 境界値       |
| リスクレベルバッジの表示確認（全レベル） | レンダリング |
| ツールアイコンの表示確認                 | レンダリング |

**SkillStreamingView 追加テスト候補**:

| テスト内容                        | カテゴリ   |
| --------------------------------- | ---------- |
| メッセージリストが空の場合        | 境界値     |
| 大量メッセージ（100件以上）の表示 | 境界値     |
| cancelled ステータスの表示        | ステータス |
| 複数のtool_use/tool_resultの連続  | 複合       |
| 自動スクロール動作確認            | UX         |

### ステップ4: カバレッジ再測定

## 多角的チェック観点（AIが判断）

| 観点             | 適用判断                          | 確認項目                               |
| ---------------- | --------------------------------- | -------------------------------------- |
| UI/UX            | テスト拡充でUI検証強化 → **適用** | 拡充テストがUI品質の検証を向上させるか |
| アクセシビリティ | a11y追加テスト → **適用**         | WCAG基準の追加テストが十分か           |
| セキュリティ     | テストコードのみ → **適用外**     | -                                      |
| パフォーマンス   | テスト実行速度 → **限定的適用**   | テスト追加後も実行時間が10秒以内か     |
