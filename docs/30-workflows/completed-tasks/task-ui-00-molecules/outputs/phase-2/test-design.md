# Phase 2 テスト設計

- 作成日: 2026-03-04

## テスト分類

| 種別         | 方針                                      |
| ------------ | ----------------------------------------- |
| 単体テスト   | props・イベント・表示分岐を検証           |
| a11yテスト   | role/aria、フォーカス制御、キーボード操作 |
| テーマテスト | `data-theme` の3テーマ描画                |
| レスポンシブ | モバイル向けクラス/レイアウト検証         |

## 共通ルール

- `@testing-library/react` + `fireEvent` を使用
- タイマー依存は `vi.useFakeTimers` を使用
- クリップボードは `navigator.clipboard` をモック
- 期待値はユーザー観点（`role`, `aria-label`, フォーカス位置）
