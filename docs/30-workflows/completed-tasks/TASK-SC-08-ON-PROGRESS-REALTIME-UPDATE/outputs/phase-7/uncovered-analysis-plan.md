## collaborativeモードのplanning overlap分析

collaborativeモードのphase（例: `"planning"`, `"generating"`）は、
`PHASE_TO_STAGE`マップのcreateモード用エントリと同一のキーを使用する場合がある。
これは意図的な設計であり、createモードのphaseと同じstageへマッピングされることが期待動作。

```
collaborativeモード phase "planning" → PHASE_TO_STAGE["planning"] → "planning" stage
createモード phase "planning"        → PHASE_TO_STAGE["planning"] → "planning" stage
```

**判定**: 重複ではなく共有設計。テスト追加不要。Phase 8でコメント明示を推奨。
