### タスク2: 機能テスト（正常系）

**目的**: 主要機能が正常に動作することを確認する。

**実行手順**:

1. 会話一覧機能テスト
   - 一覧が正しく表示されるか
   - ページネーションが動作するか
   - 検索が動作するか
   - 新規会話作成が動作するか
2. 会話詳細機能テスト
   - 会話選択→詳細表示が動作するか
   - メッセージ一覧が表示されるか
   - タイトル編集が動作するか
3. メッセージ入力機能テスト
   - テキスト入力が動作するか
   - Enter送信が動作するか

### タスク6: 発見課題リスト作成

**目的**: 手動テストで発見した課題をリスト化する。

**実行手順**:

1. 発見課題を重要度別に分類する
   - Critical: 即時対応必要
   - Major: 対応必要
   - Minor: 改善推奨
   - Info: 情報共有
2. 対応方針を決定する
   - 本タスクで対応
   - 別タスクとして管理

**期待される成果物**:

- `outputs/phase-11/discovered-issues.md`
