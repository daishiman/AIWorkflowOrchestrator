## 目的

テストカバレッジが目標値（80%+）を達成していることを確認し、統合テストの再実行とゲート判定を行う。

## 背景

Phase 5〜6で実装・テスト拡充を行ったため、カバレッジ目標達成を確認してから次フェーズに進む。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ確認

**目的**: ユニットテストのカバレッジを確認する。

**実行手順**:

1. カバレッジ計測を実行する
   ```bash
   pnpm --filter @repo/desktop vitest run --coverage
   ```
2. 以下の目標値を確認する
   | 指標 | 最低基準 | 推奨基準 | 達成値 |
   | ----------------- | -------- | -------- | ------ |
   | Line Coverage | 80% | 90% | ？ |
   | Branch Coverage | 60% | 70% | ？ |
   | Function Coverage | 80% | 90% | ？ |
3. 未達の場合はPhase 6に戻り追加テストを作成する

**期待される成果物**:

- カバレッジレポート

---

### タスク2: コンポーネント別カバレッジ確認

**目的**: 各コンポーネントのカバレッジを個別に確認する。

**実行手順**:

1. Preload API カバレッジ確認
   - `apps/desktop/src/preload/` のカバレッジ
2. Hooks カバレッジ確認
   - `apps/desktop/src/renderer/hooks/` のカバレッジ
3. UIコンポーネント カバレッジ確認
   - `apps/desktop/src/renderer/components/conversation/` のカバレッジ
4. 特に低い箇所を特定してリスト化する

**期待される成果物**:

- コンポーネント別カバレッジレポート

---

### タスク3: 統合テスト再実行

**目的**: 統合テストが全て成功することを確認する。

**実行手順**:

1. 全テストを実行する
   ```bash
   pnpm --filter @repo/desktop test
   ```
2. 失敗テストがあれば原因を調査・修正する
3. 全テスト成功を確認する

**期待される成果物**:

- テスト実行結果ログ（全PASS）

---

### タスク4: ゲート判定

**目的**: カバレッジ目標達成を判定する。

**実行手順**:

1. カバレッジ目標達成状況を確認する
   - Line Coverage 80%以上: ✅/❌
   - Branch Coverage 60%以上: ✅/❌
   - Function Coverage 80%以上: ✅/❌
2. 判定を行う
   - PASS: 全目標達成 → Phase 8へ
   - FAIL: 目標未達 → Phase 6に戻り追加テスト
3. 判定結果をドキュメント化する

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`
