## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認

**目的**: PR作成前に最終確認を行う。

**実行手順**:

1. ビルド確認
   ```bash
   pnpm --filter @repo/desktop build
   ```
2. 全テスト実行
   ```bash
   pnpm --filter @repo/desktop test
   ```
3. 型チェック
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
4. Lint
   ```bash
   pnpm --filter @repo/desktop lint
   ```
5. 全て成功することを確認する

**期待される成果物**:

- ローカル確認結果ログ

---

### タスク2: 変更内容確認

**目的**: コミット対象の変更内容を確認する。

**実行手順**:

1. 変更ファイル一覧を確認する
   ```bash
   git status
   ```
2. 変更差分を確認する
   ```bash
   git diff
   ```
3. コミット対象から除外すべきファイルがないか確認する
   - .env ファイル
   - 機密情報を含むファイル
   - 不要なファイル

**期待される成果物**:

- 変更内容確認メモ

---

### タスク3: PR作成（ユーザー許可後）

**目的**: PRを作成する。

**⚠️ 重要: ユーザーの明示的な許可を得てから実行すること**

**実行手順**:

1. ユーザーにPR作成の許可を確認する
2. 許可を得たら `/ai:diff-to-pr` スキルを実行する
   - ブランチ名: `feature/conversation-history-ui-implementation`
   - PR本文にIssue番号（#485）を含める

**PR本文テンプレート**:

```markdown
## Summary

- 会話履歴UIコンポーネント（ConversationListPanel, ConversationDetailView, MessageInput）の実装
- Preload API（conversationAPI）の追加
- カスタムHooks（useConversations, useConversation, useMessages）の実装
- テストカバレッジ80%+達成

Closes #485

## Test plan

- [ ] 会話一覧が正しく表示される
- [ ] 会話選択→詳細表示が動作する
- [ ] メッセージ送信が動作する
- [ ] 新規会話作成・削除が動作する
- [ ] 検索機能が動作する
- [ ] エラー時に適切なメッセージが表示される

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

**期待される成果物**:

- GitHub PR URL

## PR作成に関する重要な注意

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                     | 理由                                           |
| -------------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                           | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行する | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする                   | 動作確認されていないコードがPRに含まれる       |
