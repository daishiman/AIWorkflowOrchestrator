## 目的

TDD Refactor Phaseとして、テストを通したまま実装コードの品質を向上させる。

## 背景

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: コード品質分析

**目的**: リファクタリング対象箇所を特定する。

**実行手順**:

1. ESLint警告を確認する
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. 型安全性の問題を確認する
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
3. コードの重複箇所を特定する
4. 可読性が低い箇所を特定する
5. リファクタリング対象リストを作成する

**期待される成果物**:

- リファクタリング対象リスト

---

### タスク2: 共通ロジック抽出

**目的**: 重複コードを共通関数・コンポーネントに抽出する。

**実行手順**:

1. ローディング・エラー状態の表示ロジックを共通化する
   - LoadingState コンポーネント
   - ErrorDisplay コンポーネント
   - EmptyState コンポーネント
2. IPC呼び出しのエラーハンドリングを共通化する
3. ページネーション状態管理を共通化する
4. テストを実行して成功を確認する

**期待される成果物**:

- 共通コンポーネント・関数

---

### タスク3: Hooksリファクタリング

**目的**: カスタムHooksの品質を向上させる。

**実行手順**:

1. useConversations のリファクタリング
   - 責務の分離（一覧取得 vs CRUD操作）
   - メモ化の最適化
2. useConversation のリファクタリング
   - キャッシュ戦略の検討
3. useMessages のリファクタリング
   - 楽観的更新の検討
4. テストを実行して成功を確認する

**期待される成果物**:

- リファクタリング済みHooks

---

### タスク4: コンポーネントリファクタリング

**目的**: UIコンポーネントの品質を向上させる。

**実行手順**:

1. Props定義の整理
   - 不要なPropsの削除
   - 型定義の厳密化
2. レンダリング最適化
   - React.memoの適用
   - useCallbackの適用
3. アクセシビリティ改善
   - aria属性の追加
   - キーボードナビゲーション改善
4. テストを実行して成功を確認する

**期待される成果物**:

- リファクタリング済みコンポーネント

---

### タスク5: パフォーマンス最適化

**目的**: レンダリング・データ取得のパフォーマンスを最適化する。

**実行手順**:

1. 不要な再レンダリングを特定・修正する
2. メッセージリストの仮想スクロール検討（大量メッセージ対応）
3. デバウンス・スロットリングの適用確認
4. テストを実行して成功を確認する

**期待される成果物**:

- パフォーマンス最適化済みコード

---

### タスク6: リファクタリング完了確認

**目的**: リファクタリング後もテストが成功することを確認する。

**実行手順**:

1. 全テストを実行する
   ```bash
   pnpm --filter @repo/desktop test
   ```
2. 全テスト成功を確認する
3. 型チェックを実行する
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
4. Lintを実行する
   ```bash
   pnpm --filter @repo/desktop lint
   ```

**期待される成果物**:

- テスト実行結果ログ（全PASS）
