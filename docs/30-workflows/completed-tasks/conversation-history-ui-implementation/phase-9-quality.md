## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 静的解析

**目的**: コード品質を静的解析で検証する。

**実行手順**:

1. ESLint実行（エラーゼロ確認）
   ```bash
   pnpm --filter @repo/desktop lint
   ```
2. TypeScript型チェック（エラーゼロ確認）
   ```bash
   pnpm --filter @repo/desktop typecheck
   ```
3. Prettier フォーマット確認
   ```bash
   pnpm --filter @repo/desktop format:check
   ```
4. 問題があれば修正する

**期待される成果物**:

- 静的解析結果ログ（全PASS）

---

### タスク2: セキュリティチェック

**目的**: セキュリティ上の問題がないことを確認する。

**実行手順**:

1. XSS対策確認
   - ユーザー入力のサニタイズ
   - dangerouslySetInnerHTMLの不使用
2. IPC通信セキュリティ確認
   - ホワイトリスト登録確認
   - safeInvokeパターン使用確認
   - sender検証確認
3. 機密情報漏洩チェック
   - ハードコードされたシークレットの不存在
   - console.logの不要な情報出力確認

**期待される成果物**:

- セキュリティチェックリスト

---

### タスク3: パフォーマンスチェック

**目的**: パフォーマンス要件を満たしていることを確認する。

**実行手順**:

1. レンダリングパフォーマンス確認
   - 初期レンダリング: <100ms
   - リスト表示: <200ms
2. 不要な再レンダリングの確認
   - React DevToolsでの確認
3. メモリリーク確認
   - useEffect クリーンアップ確認
   - イベントリスナー解除確認

**期待される成果物**:

- パフォーマンスチェックリスト

---

### タスク4: アクセシビリティチェック

**目的**: WCAG 2.1 AA準拠を確認する。

**実行手順**:

1. キーボードナビゲーション確認
   - Tab順序が論理的か
   - Enter/Spaceでアクションが実行されるか
   - Escapeでダイアログが閉じるか
2. スクリーンリーダー対応確認
   - aria-label設定確認
   - role属性設定確認
3. 色コントラスト確認
   - 十分なコントラスト比

**期待される成果物**:

- アクセシビリティチェックリスト

---

### タスク5: 総合品質判定

**目的**: 品質保証の総合判定を行う。

**実行手順**:

1. 全チェック項目の結果を集計する
2. 問題がある場合は修正する
3. 品質レポートを作成する

**期待される成果物**:

- `outputs/phase-9/quality-report.md`
