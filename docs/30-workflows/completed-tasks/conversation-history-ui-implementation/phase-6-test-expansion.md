## 目的

テストカバレッジを向上させるための追加テストを作成し、カバレッジ目標（80%+）達成に向けて拡充する。

## 背景

Phase 4で作成した基本テストに加え、エッジケース・異常系・境界値テストを追加してカバレッジを向上させる。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: カバレッジ現状確認

**目的**: 現在のテストカバレッジを確認し、不足箇所を特定する。

**実行手順**:

1. カバレッジ計測を実行する
   ```bash
   pnpm --filter @repo/desktop vitest run --coverage
   ```
2. カバレッジレポートを確認する
   - Line Coverage
   - Branch Coverage
   - Function Coverage
3. カバレッジ不足箇所をリスト化する

**期待される成果物**:

- カバレッジ分析メモ

---

### タスク2: エッジケーステスト追加

**目的**: 境界条件・エッジケースのテストを追加する。

**実行手順**:

1. Preload API エッジケース
   - 空のIDでの呼び出し
   - 不正な型での呼び出し
   - ネットワークエラー時の動作
2. Hooks エッジケース
   - 空の会話一覧
   - 大量のメッセージ
   - 同時操作（競合状態）
3. コンポーネント エッジケース
   - 長いタイトルの表示
   - 長いメッセージの表示
   - 特殊文字の表示
   - 空の状態からの遷移

**期待される成果物**:

- 追加テストファイル

---

### タスク3: 異常系テスト追加

**目的**: エラーハンドリングのテストを追加する。

**実行手順**:

1. API エラーテスト
   - IPC通信失敗
   - タイムアウト
   - 認証エラー
2. バリデーションエラーテスト
   - 無効な入力
   - 必須フィールド欠落
3. コンポーネント エラー表示テスト
   - エラーメッセージ表示
   - リトライ機能
   - フォールバック表示

**期待される成果物**:

- 追加テストファイル

---

### タスク4: アクセシビリティテスト追加

**目的**: WCAG 2.1 AA準拠のアクセシビリティテストを追加する。

**実行手順**:

1. キーボードナビゲーションテスト
   - Tab順序
   - Enter/Spaceでのアクション
   - Escapeでのキャンセル
2. スクリーンリーダー対応テスト
   - aria-label確認
   - role属性確認
   - aria-live確認
3. フォーカス管理テスト
   - ダイアログ表示時のフォーカストラップ
   - フォーカス復帰

**期待される成果物**:

- 追加テストファイル

---

### タスク5: 統合テスト追加

**目的**: コンポーネント間・IPC間の統合テストを追加する。

**実行手順**:

1. 一覧→詳細遷移テスト
   - 会話選択→詳細表示
   - 詳細→一覧戻り
2. メッセージ送信フローテスト
   - 入力→送信→表示更新
   - 送信中状態→完了状態
3. CRUD操作フローテスト
   - 作成→表示→更新→削除

**期待される成果物**:

- 統合テストファイル

---

### タスク6: カバレッジ再確認

**目的**: テスト追加後のカバレッジを確認する。

**実行手順**:

1. カバレッジ計測を再実行する
   ```bash
   pnpm --filter @repo/desktop vitest run --coverage
   ```
2. カバレッジ向上を確認する
3. まだ不足している箇所があれば追加テストを作成する

**期待される成果物**:

- カバレッジレポート
