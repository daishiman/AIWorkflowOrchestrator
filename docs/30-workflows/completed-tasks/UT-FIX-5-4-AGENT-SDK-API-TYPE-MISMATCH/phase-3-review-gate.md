## レビュー観点

### 観点1: 型一貫性

| チェック項目                                                 | 結果 |
| ------------------------------------------------------------ | ---- |
| Preload types.ts と Shared types.ts で同じ型定義になっている | [ ]  |
| 実装の戻り値型（`Promise<void>`）と型定義が一致している      | [ ]  |
| JSDoc コメントが適切に更新されている                         | [ ]  |

### 観点2: 破壊的変更の有無

| チェック項目                                  | 結果 |
| --------------------------------------------- | ---- |
| `void` → `Promise<void>` は後方互換性がある   | [ ]  |
| 既存の `abort()` 呼び出し箇所が影響を受けない | [ ]  |
| イベントハンドラ等での直接呼び出しが問題ない  | [ ]  |

### 観点3: 呼び出し箇所への影響

| チェック項目                                      | 結果 |
| ------------------------------------------------- | ---- |
| `abort()` の呼び出し箇所が特定されている          | [ ]  |
| 各呼び出し箇所で `await` パターンが使用可能になる | [ ]  |
| 修正不要の呼び出し箇所が確認されている            | [ ]  |

### 観点4: TypeScript型チェック

| チェック項目                               | 結果 |
| ------------------------------------------ | ---- |
| 型定義変更後に `pnpm typecheck` が通過する | [ ]  |
| 関連ファイルで型エラーが発生しない         | [ ]  |
| `@repo/shared` のビルドが成功する          | [ ]  |

### 観点5: IPC契約整合性

| チェック項目                            | 結果 |
| --------------------------------------- | ---- |
| `agent:abort` IPCチャンネルの契約が明確 | [ ]  |
| Main プロセスの実装と型定義が一致       | [ ]  |
| Preload の safeInvoke パターンと整合    | [ ]  |
