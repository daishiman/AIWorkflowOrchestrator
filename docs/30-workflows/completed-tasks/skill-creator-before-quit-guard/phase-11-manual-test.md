## 目的

実際の Electron アプリ上で before-quit ガードの動作を目視確認する。ユニットテストでは検証できないダイアログ表示とユーザーインタラクションを確認する。

## 実行タスク

1. Electron アプリを起動して before-quit ガードを有効化する
2. スキル生成中 / 非実行時の終了挙動を確認する
3. ダイアログ表示文言とボタンを確認する
4. 結果を `outputs/phase-11/manual-test-result.md` に記録する

## 分類

**NON_VISUAL**: UI の見た目変更なし。ダイアログは OS 標準コンポーネントを使用。スクリーンショット不要。

```bash
# アプリ起動
pnpm --filter @repo/desktop dev
```

## 手動テストシナリオ

### MT-01: スキル生成実行中にアプリを終了しようとする（確認ダイアログ）

**前提条件**: スキル生成が進行中（skill-creator:execute-plan が実行中）

**手順**:

1. スキル生成を開始する
2. 生成が完了する前にアプリを終了しようとする（Cmd+Q または ×ボタン）
3. ダイアログが表示されることを確認する

**期待結果**:

- 警告ダイアログが表示される
- メッセージ: 「スキル作成が進行中です」
- ボタン: 「中断して終了」「キャンセル」

**合否**: ✅ / ❌

---

### MT-02: ダイアログで「キャンセル」を選択する

**前提条件**: MT-01 でダイアログが表示されている

**手順**:

1. 「キャンセル」ボタンをクリックする

**期待結果**:

- ダイアログが閉じる
- アプリは終了しない
- スキル生成が継続している

**合否**: ✅ / ❌

---

### MT-03: ダイアログで「中断して終了」を選択する

**前提条件**: MT-01 でダイアログが表示されている

**手順**:

1. 「中断して終了」ボタンをクリックする

**期待結果**:

- アプリが終了する
- クラッシュレポートが表示されない（正常終了）

**合否**: ✅ / ❌

---

### MT-04: スキル生成未実行時にアプリを終了する（通常終了）

**前提条件**: スキル生成を実行していない

**手順**:

1. アプリを終了しようとする（Cmd+Q）

**期待結果**:

- ダイアログが表示されない
- アプリが即座に終了する

**合否**: ✅ / ❌
