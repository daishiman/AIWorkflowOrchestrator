## 目的

Phase 6のテスト拡充結果を検証し、カバレッジ基準を満たすことをゲートとして確認する。

## 背景

リファクタリングに進む前に、十分なテストカバレッジがあることを保証し、リファクタリング時の安全網を確保する。

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ユニットテストカバレッジ検証

**目的**: ユニットテストのカバレッジが基準を満たすことを確認

**実行手順**:

1. カバレッジレポートを生成:
   ```bash
   pnpm --filter @repo/shared test:coverage -- community-summarizer
   ```
2. カバレッジ基準を確認:
   | 指標 | 最低基準 | 現在値 | 判定 |
   | ---- | -------- | ------ | ---- |
   | Line Coverage | 80% | **_% | ⬜ |
   | Branch Coverage | 60% | _**% | ⬜ |
   | Function Coverage | 80% | \_\_\_% | ⬜ |
3. 未達の場合は Phase 6 に戻る

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`

---

### タスク2: 結合テストカバレッジ検証

**目的**: 結合テストのカバレッジが基準を満たすことを確認

**実行手順**:

1. 統合テストを実行:
   ```bash
   pnpm --filter @repo/shared test -- community-summarizer.integration
   ```
2. カバレッジ基準を確認:
   | 指標 | 目標 | 現在値 | 判定 |
   | ---- | ---- | ------ | ---- |
   | APIエンドポイント | 100% | **_% | ⬜ |
   | モジュール間インターフェース | 100% | _**% | ⬜ |
   | 正常系シナリオ | 100% | **_% | ⬜ |
   | 異常系シナリオ | 80%+ | _**% | ⬜ |
   | 外部連携ポイント | 100% | \_\_\_% | ⬜ |
3. 未達の場合は Phase 6 に戻る

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（結合テストセクション）

---

### タスク3: 統合テスト再実行（統合テスト連携）

**目的**: 全統合テストが成功することを確認

**実行手順**:

1. 全統合テストを実行:
   ```bash
   pnpm --filter @repo/shared test:integration
   ```
2. 結果を確認:
   - 全テストがPASSしていること
   - 警告がないこと
3. 失敗がある場合は原因を特定し修正

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（統合テスト結果セクション）

---

### タスク4: ゲート判定

**目的**: Phase 8への進行可否を判定

**実行手順**:

1. 全ての基準を確認:
   - [ ] ユニットテスト: Line 80%+, Branch 60%+, Function 80%+
   - [ ] 結合テスト: 全カテゴリ基準達成
   - [ ] 統合テスト: 全テスト成功
2. 判定:
   - **PASS**: 全基準達成 → Phase 8へ
   - **FAIL**: 未達項目あり → Phase 6へ戻る
3. 判定結果を記録

**期待される成果物**:

- `outputs/phase-7/coverage-report.md`（判定結果セクション）
