## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: 要件充足確認

**目的**: 元の要件が全て満たされていることを確認

**実行手順**:

1. 受け入れ基準（`outputs/phase-1/acceptance-criteria.md`）を確認
2. 各基準の充足状況を検証:
   - [ ] AC-01: 単一コミュニティの要約生成 ✅/❌
   - [ ] AC-02: 子コミュニティの要約を使用した生成 ✅/❌
   - [ ] AC-03: 全コミュニティの一括要約生成（階層順） ✅/❌
   - [ ] AC-04: 埋め込み生成とセマンティック検索 ✅/❌
   - [ ] AC-05: レベル指定検索 ✅/❌
   - [ ] AC-06: 要約の更新 ✅/❌
   - [ ] AC-07: 部分失敗時の継続処理 ✅/❌
3. 未充足項目がある場合は対応

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`（要件充足セクション）

---

### タスク2: 設計整合性確認

**目的**: 実装が設計に従っていることを確認

**実行手順**:

1. 設計書（`outputs/phase-2/`）を確認
2. 実装との整合性を検証:
   - [ ] アーキテクチャ設計通りの構成
   - [ ] インターフェース設計通りのAPI
   - [ ] 型定義設計通りの型
   - [ ] プロンプト設計通りの出力
3. 乖離がある場合は設計または実装を修正

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`（設計整合性セクション）

---

### タスク3: 統合テスト結果確認（統合テスト連携）

**目的**: 全統合テストが成功していることを最終確認

**実行手順**:

1. 統合テスト結果（`outputs/phase-7/`）を確認
2. 品質レポート（`outputs/phase-9/`）を確認
3. 全テストが成功していることを検証
4. カバレッジ基準が達成されていることを検証

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`（統合テストセクション）

---

### タスク4: ドキュメント整合性確認

**目的**: ドキュメントが実装と一致していることを確認

**実行手順**:

1. 各Phase成果物の整合性を確認
2. コードコメント・JSDocの確認
3. 不整合がある場合は修正

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`（ドキュメント整合性セクション）

---

### タスク5: 最終判定

**目的**: Phase 11への進行可否を判定

**実行手順**:

1. 全レビュー項目を確認:
   - [ ] 要件充足: 全AC達成
   - [ ] 設計整合性: 乖離なし
   - [ ] 統合テスト: 全成功
   - [ ] ドキュメント整合性: 一致
2. 判定:
   - **PASS**: 全項目OK → Phase 11へ
   - **MINOR**: 軽微な問題 → 対応後、Phase 11へ
   - **MAJOR**: 重大な問題 → 影響範囲に応じて戻る
   - **CRITICAL**: 致命的な問題 → Phase 1へ戻りユーザー確認
3. 判定結果を記録

**期待される成果物**:

- `outputs/phase-10/final-review-result.md`（判定結果セクション）

## レビューゲート判定基準

### レビュー結果判定

| 判定     | 条件                     | 次のアクション            |
| -------- | ------------------------ | ------------------------- |
| PASS     | 全レビュー観点で問題なし | Phase 11へ進行            |
| MINOR    | 軽微な指摘あり           | 指摘対応後、Phase 11へ    |
| MAJOR    | 重大な問題あり           | 影響範囲に応じて戻る      |
| CRITICAL | 致命的な問題あり         | Phase 1へ戻りユーザー確認 |

### 戻り先決定基準

| 問題の種類       | 戻り先                |
| ---------------- | --------------------- |
| 要件の問題       | Phase 1（要件定義）   |
| 設計の問題       | Phase 2（設計）       |
| テスト設計の問題 | Phase 4（テスト）     |
| 実装の問題       | Phase 5（実装）       |
| 品質の問題       | Phase 8（リファクタ） |
