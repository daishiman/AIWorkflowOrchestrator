## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認

**目的**: PR作成前に全ての品質チェックをローカルで実行する

**実行手順**:

1. 以下のコマンドを順番に実行:

```bash
# ビルド確認
pnpm --filter @repo/desktop build

# 型チェック
pnpm --filter @repo/desktop typecheck

# Lintチェック
pnpm --filter @repo/desktop lint

# テスト実行
pnpm --filter @repo/desktop test -- --testPathPattern="streaming"
```

2. 全てのチェックが成功することを確認
3. 結果を記録

**期待される成果物**:

- `outputs/phase-13/local-check-result.md`

---

### タスク2: コミット作成

**目的**: 変更内容を適切なコミットメッセージでコミットする

**実行手順**:

1. 変更ファイルを確認:

```bash
git status
git diff --stat
```

2. コミットメッセージを作成:
   - 形式: `feat(animation): ストリーミングUIアニメーションの実装`
   - 本文に主要な変更点を記載

3. **ユーザーの許可を得てから**コミットを実行

**期待される成果物**:

- コミット完了

---

### タスク3: PR作成

**目的**: Pull Requestを作成する

**実行手順**:

1. **ユーザーの明示的な許可を得る**
2. `/ai:diff-to-pr` を使用してPRを作成
3. PR本文に以下を含める:
   - 概要
   - 主要な変更点
   - アクセシビリティ対応
   - テスト計画

**期待される成果物**:

- PR URL

---

### タスク4: CI確認

**目的**: CI/CDパイプラインが成功することを確認する

**実行手順**:

1. PR作成後、CIの実行を待機
2. 以下のCIジョブが成功することを確認:
   - ビルド
   - 型チェック
   - Lint
   - テスト
3. CI失敗時は修正してコミット追加

**期待される成果物**:

- `outputs/phase-13/ci-result.md`

---

### タスク5: 完了報告

**目的**: Phase 13の完了を報告する

**実行手順**:

1. 以下の内容で完了報告を作成:
   - PR URL
   - CI結果
   - マージ可能状態かどうか

**期待される成果物**:

- `outputs/phase-13/completion-report.md`
