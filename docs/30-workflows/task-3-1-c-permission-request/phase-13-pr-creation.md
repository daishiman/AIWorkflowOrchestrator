## 目的

`/ai:diff-to-pr` でコミット・PR・CI確認を行い、タスクを完了する。

## 背景

ドキュメント更新が完了した。
本 Phase では、変更をコミットし、Pull Request を作成する。

---

## 重要な注意事項

**⚠️ PR作成はユーザーの明示的な許可を得てから実行すること**

| 禁止事項                               | 理由                                           |
| -------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                     | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`実行 | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする             | 動作確認されていないコードがPRに含まれる       |

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認チェックリスト

**目的**: PR作成前に全ての確認項目をクリアする

**必須チェックリスト**:

| #   | 確認項目             | コマンド              | 結果 |
| --- | -------------------- | --------------------- | ---- |
| 1   | ビルドが成功する     | `pnpm build`          | [ ]  |
| 2   | 全テストがパスする   | `pnpm test`           | [ ]  |
| 3   | 型チェックがパスする | `pnpm typecheck`      | [ ]  |
| 4   | Lintエラーがない     | `pnpm lint`           | [ ]  |
| 5   | 実際の動作確認       | `pnpm dev` で手動確認 | [ ]  |

**実行コマンド**:

```bash
# 並列で実行可能な確認
pnpm build && pnpm test && pnpm typecheck && pnpm lint
```

**期待される成果物**:

- ローカル確認結果

---

### タスク2: 変更差分の確認

**目的**: コミット対象の変更を確認する

**実行手順**:

1. 変更ファイルを一覧表示する
2. 各ファイルの変更内容を確認する
3. 不要な変更が含まれていないことを確認する

**実行コマンド**:

```bash
# 変更ファイル一覧
git status

# 差分確認
git diff

# ステージング済み差分
git diff --cached
```

**変更予定ファイル**:

| ファイル                                                | 変更内容                    |
| ------------------------------------------------------- | --------------------------- |
| `apps/desktop/src/main/services/skill/SkillExecutor.ts` | PermissionRequest Hook 追加 |
| `packages/shared/src/ipc/channels.ts`                   | 権限チャネル追加            |
| `apps/desktop/src/main/services/skill/__tests__/...`    | テストファイル追加          |
| `docs/...`                                              | ドキュメント追加            |

**期待される成果物**:

- 変更差分確認結果

### タスク3: ユーザー確認

**目的**: PR作成の許可をユーザーから得る

**確認項目**:

1. 全てのローカル確認が完了している
2. 変更内容が意図通りである
3. PR作成を進めてよい

**ユーザーへの確認メッセージ**:

- ドキュメント
