## 非機能要件一覧

### NFR-001: 権限リクエスト送信性能

| 項目     | 内容                                          |
| -------- | --------------------------------------------- |
| ID       | NFR-001                                       |
| カテゴリ | パフォーマンス                                |
| 要件     | 権限リクエスト送信は 100ms 以内に完了すること |

**詳細**:

- IPC メッセージ送信処理の応答時間
- サニタイズ処理を含む
- 理由文生成を含む
- 計測ポイント: Hook 呼び出しから IPC 送信完了まで

**検証方法**:

- パフォーマンステストで計測
- 95パーセンタイルで 100ms 以内

---

### NFR-002: タイムアウト設定

| 項目     | 内容                                               |
| -------- | -------------------------------------------------- |
| ID       | NFR-002                                            |
| カテゴリ | パフォーマンス                                     |
| 要件     | タイムアウト時間は設定可能とする（デフォルト30秒） |

**詳細**:

- デフォルト値: 30,000ms
- 最小値: 5,000ms
- 最大値: 300,000ms (5分)
- 設定場所: SkillExecutor オプション

**検証方法**:

- 単体テストでタイムアウト動作を確認
- カスタムタイムアウト値の適用を確認

---

### NFR-003: 機密情報保護

| 項目     | 内容                                          |
| -------- | --------------------------------------------- |
| ID       | NFR-003                                       |
| カテゴリ | セキュリティ                                  |
| 要件     | 機密情報（APIキー、パスワード等）は表示しない |

**詳細**:

- マスク対象キーワード:
  - `password`, `passwd`, `pwd`
  - `secret`, `token`, `key`, `api_key`, `apikey`
  - `credential`, `auth`, `bearer`
  - `private_key`, `access_token`, `refresh_token`
- マスク形式: `[REDACTED]` または `***...***`
- 大文字小文字を区別しない

**検証方法**:

- 機密情報を含む引数でのテスト
- サニタイズ後の出力に機密情報が含まれないことを確認

---

### NFR-004: 長大引数の省略

| 項目     | 内容                                  |
| -------- | ------------------------------------- |
| ID       | NFR-004                               |
| カテゴリ | セキュリティ                          |
| 要件     | 500文字を超える引数は省略して表示する |

**詳細**:

- 閾値: 500文字
- 省略形式: `{先頭200文字}...[省略: {残り文字数}文字]`
- 配列の場合は要素ごとに適用
- ネストしたオブジェクトにも再帰的に適用

**検証方法**:

- 500文字を超える引数でのテスト
- 省略形式が正しく適用されることを確認

---

### NFR-005: 日本語対応

| 項目     | 内容                                             |
| -------- | ------------------------------------------------ |
| ID       | NFR-005                                          |
| カテゴリ | ユーザビリティ                                   |
| 要件     | 権限リクエスト理由は日本語で分かりやすく表示する |

**詳細**:

- ツール別日本語テンプレート:
  - Bash: `「{command}」コマンドを実行します`
  - Write: `「{file_path}」にファイルを作成します`
  - Edit: `「{file_path}」ファイルを編集します`
  - Read: `「{file_path}」ファイルを読み込みます`
  - Glob: `「{pattern}」パターンでファイル検索します`
  - Grep: `「{pattern}」パターンでテキスト検索します`
  - その他: `{toolName}ツールを使用します`
- 技術用語は適切に日本語化または説明を追加

**検証方法**:

- 各ツールでの理由文生成テスト
- 日本語として自然な文章であることを確認

---

### NFR-006: キャンセル対応

| 項目     | 内容                                   |
| -------- | -------------------------------------- |
| ID       | NFR-006                                |
| カテゴリ | 信頼性                                 |
| 要件     | AbortSignal によるキャンセルに対応する |

**詳細**:

- AbortSignal を監視し、中断時は即座に停止
- キャンセル時は適切なクリーンアップを実行
- 待機中の Promise をリジェクト
- PermissionResolver からリクエストを削除

**検証方法**:

- AbortController でのキャンセルテスト
- リソースリークがないことを確認
