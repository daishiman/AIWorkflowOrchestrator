## 目的

## 背景

全てのPhaseが完了し、品質が保証された状態で、変更をメインブランチにマージするためのPRを作成する。

---

## ⚠️ PR作成に関する重要な注意【必須確認】

**PR作成は自動実行しない。必ずユーザーの明示的な許可を得てから実行すること。**

| 禁止事項                                 | 理由                                           |
| ---------------------------------------- | ---------------------------------------------- |
| 勝手にPRを作成する                       | レビュー前の変更がリモートに反映されてしまう   |
| ユーザー確認なしで`/ai:diff-to-pr`を実行 | 意図しないブランチやコミットが作成される可能性 |
| ローカル確認をスキップする               | 動作確認されていないコードがPRに含まれる       |

---

## 実行タスク

> 以下のタスクを順番に実行してください。

### タスク1: ローカル確認を実行

**目的**: PR作成前に全ての確認項目をパスすることを確認する

**実行手順**:

1. ビルドを確認:

```bash
pnpm --filter @repo/shared build
```

2. テストを確認:

```bash
pnpm --filter @repo/shared test:run
```

3. 型チェックを確認:

```bash
pnpm --filter @repo/shared typecheck
```

4. Lintを確認:

```bash
pnpm --filter @repo/shared lint
```

5. 全てがパスすることを確認

**期待される成果物**:

- ローカル確認成功

---

### タスク2: ユーザーにPR作成の許可を確認【必須】

**目的**: PR作成前にユーザーの明示的な許可を得る

**実行手順**:

1. ユーザーに以下を確認:
   - 変更内容の確認
   - PR作成の許可

2. 確認メッセージ例:

```
以下の変更をPRとして作成してよろしいですか？

【変更内容】
- packages/shared/index.ts に型エクスポートを追加
- Community関連型、Branded ID型、エラークラス、ユーティリティ関数をエクスポート

【確認済み項目】
- ビルド成功
- テスト全件成功
- 型チェック成功
- Lint成功

PR作成を許可しますか？（yes/no）
```

3. ユーザーから明示的な許可（「yes」「はい」など）を得る

**期待される成果物**:

- ユーザーからのPR作成許可

---

### タスク3: PR作成（ユーザー許可後）

**目的**: `/ai:diff-to-pr`スキルを使用してPRを作成する

**実行手順**:

1. **ユーザー許可後にのみ**、`/ai:diff-to-pr`スキルを実行
2. PRが作成されることを確認
3. PR URLを記録

**期待される成果物**:

- PR URL

---

### タスク4: CI通過を確認

**目的**: CIが全て通過することを確認する

**実行手順**:

1. GitHub PRページでCIステータスを確認
2. 全てのCIチェックが通過することを確認
3. 失敗した場合は原因を調査し、修正

**期待される成果物**:

- CI通過確認

---

### タスク5: タスクディレクトリを移動

**目的**: タスクを完了として完了タスクフォルダに移動する

**実行手順**:

1. タスクディレクトリを移動:

```bash
mv docs/30-workflows/shared-type-export-02-main-index/ docs/30-workflows/completed-tasks/
```

2. 元の未タスク指示書を削除:

```bash
rm docs/30-workflows/unassigned-task/task-shared-community-types-export-02.md
```

3. 移動を確認:

```bash
ls docs/30-workflows/completed-tasks/ | grep shared-type-export-02
```

4. 変更をコミット:

```bash
git add docs/30-workflows/
git commit -m "docs(workflows): SHARED-TYPE-EXPORT-02をcompleted-tasksに移動"
```

**期待される成果物**:

- タスクディレクトリが`completed-tasks/`に移動
