## 目的

動作を変えずにコード品質を改善する。既存実装は高品質なため、Phase 5で追加した部分を中心に改善する。

## リファクタリング対象

| 対象                     | 観点                       |
| ------------------------ | -------------------------- |
| グローバルショートカット | コードの重複排除、責務分離 |
| IPCプロバイダ            | エラーハンドリング改善     |
| テストコード             | テストヘルパーの共通化     |

## 実行タスク

### Task 8-1: コードスメル検出

新規追加したコードのコードスメルを検出する。

| スメル       | 確認箇所                   |
| ------------ | -------------------------- |
| 重複コード   | ショートカット登録ロジック |
| 長いメソッド | IPCプロバイダ              |
| 不適切な命名 | 変数名、関数名             |

### Task 8-2: リファクタリング実施

テストが継続成功することを確認しながらリファクタリングを行う。

### Task 8-3: テスト継続成功確認

```bash
pnpm --filter @repo/desktop test:run
pnpm --filter @repo/desktop test:e2e
```

## 統合テスト連携【必須】

```bash
# リファクタリング後のテスト実行
```
