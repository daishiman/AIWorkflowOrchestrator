## 実行手順

### ステップ1: 正常起動テスト

1. `pnpm --filter @repo/desktop dev` でアプリケーションを起動する
2. DevTools のコンソールに IPC 関連のエラーログが出力されていないことを確認する
3. Settings 画面を開き、全ての機能（AuthKey設定、AuthMode切替、スキル管理）が動作することを確認する

| 確認項目                       | 期待結果           | 実測結果 |
| ------------------------------ | ------------------ | -------- |
| アプリ起動時のコンソールエラー | IPC 関連エラーなし | -        |
| Settings 画面の AuthKey 操作   | 正常に動作する     | -        |
| Settings 画面の AuthMode 切替  | 正常に動作する     | -        |
| スキル一覧の表示               | 正常に表示される   | -        |

### ステップ2: 障害シミュレーション

一時的にコードを変更して特定のハンドラ登録を失敗させ、Graceful Degradation を検証する:

1. `registerSkillHandlers` 呼び出し前に `throw new Error("Simulated failure")` を挿入する
2. アプリケーションを起動する
3. 以下を確認する:

| 確認項目                     | 期待結果                                                       | 実測結果 |
| ---------------------------- | -------------------------------------------------------------- | -------- |
| アプリ起動                   | クラッシュせず正常に起動する                                   | -        |
| コンソールログ               | `[IPC] Failed to register registerSkillHandlers:` が出力される | -        |
| Settings 画面の AuthKey 操作 | 正常に動作する（Skill とは独立）                               | -        |
| スキル関連操作               | 適切なエラーメッセージが表示される                             | -        |

4. シミュレーション用のコード変更を元に戻す

### ステップ3: ログ出力確認

| 確認項目                             | 期待結果                                       | 実測結果 |
| ------------------------------------ | ---------------------------------------------- | -------- |
| 全成功時のログ                       | `[IPC] All N handlers registered successfully` | -        |
| 部分失敗時のログ                     | `[IPC] M/N handlers failed to register`        | -        |
| エラーログにファイルパスが含まれない | パス情報が出力されていない                     | -        |
| エラーログに環境変数値が含まれない   | 環境変数情報が出力されていない                 | -        |

## 統合テスト連携

- 手動テストで確認した動作結果を Phase 10 の要件充足マトリクスと照合する
- 自動テストでカバーできない UI レベルの挙動を記録する
