## ゲート判定

| 判定 | 条件                                              | 次のアクション |
| ---- | ------------------------------------------------- | -------------- |
| PASS | 全カバレッジ基準達成 AND 全セキュリティテスト成功 | Phase 8へ進行  |
| FAIL | カバレッジ基準未達 OR セキュリティテスト失敗      | Phase 6へ戻る  |

### ゲート判定の詳細

**PASS条件（全て満たす必要あり）**:

1. ユニットテストカバレッジ: Line 80%+, Branch 60%+, Function 80%+
2. 結合テストカバレッジ: 正常系100%, 異常系80%+
3. セキュリティテスト: 全項目PASS
4. キーが平文でログ・ストレージに露出しないこと

**FAIL時の対応**:

- カバレッジ未達の場合: 不足テストを特定し、Phase 6で追加
- セキュリティテスト失敗の場合: 実装の修正が必要な場合はPhase 5へ戻る
