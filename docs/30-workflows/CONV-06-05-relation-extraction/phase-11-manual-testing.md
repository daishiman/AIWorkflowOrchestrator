## 手動テストシナリオ

### シナリオ1: 基本的な関係抽出

**目的**: 標準的なテキストからエンティティ間の関係を抽出できることを確認

**手順**:

1. サンプルテキストを準備（技術ドキュメントなど）
2. エンティティ抽出を実行
3. 関係抽出を実行
4. 結果を確認

**確認項目**:

- [ ] 関係が正しく抽出されている
- [ ] 関係タイプが適切に分類されている
- [ ] 信頼度スコアが妥当
- [ ] エビデンステキストが正確

### シナリオ2: 複数チャンクのバッチ処理

**目的**: 複数チャンクの一括処理が正常に動作することを確認

**手順**:

1. 複数のチャンクを準備（5〜10チャンク）
2. バッチ抽出を実行
3. 結果を確認

**確認項目**:

- [ ] 全チャンクが処理されている
- [ ] 処理時間が妥当
- [ ] 重複関係がマージされている

### シナリオ3: エッジケース処理

**目的**: 特殊なケースでの振る舞いを確認

**手順**:

1. 空のチャンクで抽出を試行
2. エンティティが1つのみのチャンクで抽出を試行
3. 非常に長いテキストで抽出を試行

**確認項目**:

- [ ] エラーが適切にハンドリングされている
- [ ] 空の結果が正しく返される
- [ ] タイムアウトが発生しない

### シナリオ4: ExtractionPipeline統合

**目的**: パイプライン全体での動作を確認

**手順**:

1. ExtractionPipelineを設定
2. チャンクを入力
3. エンティティと関係の両方が抽出されることを確認

**確認項目**:

- [ ] エンティティ抽出後に関係抽出が実行される
- [ ] 結果がリポジトリに保存される
- [ ] エラー時の振る舞いが適切
