## 目的

Electronアプリを実際に起動し、エラー種別ごとのUI表示・ボタン動作・状態リカバリを手動で確認する。自動テストでは検証困難な視覚的な表示・アニメーション・実際のSettings遷移を確認する。

## 実行タスク

### Task 1: 手動テスト環境の準備

```bash
# アプリのビルドと起動
pnpm --filter @repo/desktop dev

# または Electron起動
pnpm --filter @repo/desktop build && pnpm --filter @repo/desktop start
```

### Task 2: API_KEY_MISSING エラーの確認（AC-1）

#### 前提条件の設定

Settings > AI Provider で APIキーを一時的に削除または空にする。

#### 確認手順

1. WorkspaceChatパネルでメッセージを送信する
2. エラーバナーが表示されることを確認する

#### 期待結果チェックリスト

| 確認項目                                          | 期待値                              | 結果   |
| ------------------------------------------------- | ----------------------------------- | ------ |
| エラーバナーが表示される                          | 表示される                          | 未確認 |
| エラーメッセージが「APIキーが設定されていません」 | 表示される                          | 未確認 |
| 「設定を開く」ボタンが表示される                  | 表示される                          | 未確認 |
| 「再試行」ボタンが表示されない                    | 表示されない                        | 未確認 |
| 「設定を開く」クリックでSettings画面に遷移        | Settings > AI Provider が表示される | 未確認 |
| エラーバナーの×ボタンでバナーが消える             | バナーが消える                      | 未確認 |

### Task 3: NETWORK_ERROR エラーの確認（AC-2）

#### 前提条件の設定

ネットワーク切断またはテスト用のネットワークエラーを発生させる（開発ツールでオフライン設定等）。

#### 期待結果チェックリスト

| 確認項目                                         | 期待値             | 結果   |
| ------------------------------------------------ | ------------------ | ------ |
| エラーバナーが表示される                         | 表示される         | 未確認 |
| エラーメッセージが「ネットワークエラー」を含む   | 表示される         | 未確認 |
| 「再試行」ボタンが表示される                     | 表示される         | 未確認 |
| 「設定を開く」ボタンが表示されない               | 表示されない       | 未確認 |
| 「再試行」クリックで直前のメッセージが再送される | 送信が試みられる   | 未確認 |
| 再試行中はボタンが「再試行中...」になる          | disabled状態になる | 未確認 |

| 確認項目                                    | 期待値               | 結果   |

| ストリーミング中の状態表示が正しい          | ローディング表示正常 | 未確認 |

### Task 9: P53対策（CLI環境のスクリーンショット代替）

CLI環境でのスクリーンショット取得が困難な場合は、自動テストの実行ログを視覚検証の代替記録として使用する。

```bash
# テスト実行ログをファイルに保存（視覚検証の代替）
cd apps/desktop && pnpm vitest run src/renderer/views/WorkspaceView \
  2>&1 | tee /tmp/manual-test-log.txt

echo "テスト実行ログ: /tmp/manual-test-log.txt"
```

## 実行手順

1. **Task 1**: 開発環境でアプリを起動する
2. **Task 2**: API_KEY_MISSING シナリオを実行し、全チェック項目を確認する
3. **Task 3**: NETWORK_ERROR シナリオを実行し、全チェック項目を確認する
4. **Task 4**: RATE_LIMIT シナリオを実行し、全チェック項目を確認する
5. **Task 5**: その他エラーシナリオを実行し、全チェック項目を確認する
6. **Task 6**: エラー後のchat状態リカバリを確認する
7. **Task 7**: 視覚的なApple HIG準拠を確認する
8. **Task 8**: アクセシビリティを補助的に確認する
