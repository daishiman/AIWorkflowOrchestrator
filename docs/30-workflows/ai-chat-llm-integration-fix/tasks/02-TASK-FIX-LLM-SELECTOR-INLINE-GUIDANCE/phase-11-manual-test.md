## 目的

Electron アプリを実際に起動し、モデル未選択→バナー表示→Settings遷移→モデル選択→バナー消去のフローをE2Eシナリオとして確認する。自動テストでは検証できないUIの見た目・アニメーション・レイアウトの品質を確認する。

## 実行タスク

### Task 1: 手動テスト環境準備

```bash
# デスクトップアプリのビルドと起動
pnpm --filter @repo/desktop build
pnpm --filter @repo/desktop dev
```

**CLI環境での代替対応（P53対策）**:

デスクトップアプリが起動できない環境では、Playwright を使用した自動スクリーンショット取得で代替する:

```bash
# Playwright での視覚確認（利用可能な場合）
pnpm --filter @repo/desktop exec playwright test --headed
```

### Task 2: シナリオ1 — メインフロー（ChatView）

**シナリオ**: モデル未選択状態でChatViewを開き、バナー経由でSettings画面へ遷移してモデルを選択後、バナーが消えることを確認する。

#### ステップ

| ステップ | 操作                                   | 期待結果                                         | 確認 |
| -------- | -------------------------------------- | ------------------------------------------------ | ---- |
| 1        | アプリ起動（モデル未選択状態）         | -                                                | -    |
| 2        | ChatView を表示する                    | ガイダンスバナーが表示されている                 | -    |
| 3        | バナーのメッセージテキストを確認       | 「AIモデルが選択されていません」と表示されている | -    |
| 4        | バナーの「設定画面へ」ボタンをクリック | Settings 画面に遷移する（1クリックで到達）       | -    |
| 5        | LLM セクションでプロバイダーを選択     | プロバイダーが選択される                         | -    |
| 6        | モデルを選択する                       | モデルが選択される                               | -    |
| 7        | ChatView に戻る                        | ガイダンスバナーが表示されていない（自動消去）   | -    |

#### UIビジュアル確認

| 確認項目                                 | 基準                           | 確認 |
| ---------------------------------------- | ------------------------------ | ---- |
| バナーの背景色がシステムカラー準拠       | Apple HIG 警告色（オレンジ系） | -    |
| ボタンの色が systemBlue (#007AFF)        | ライトモードで青色ボタン       | -    |
| バナーのアニメーション                   | 200ms フェード（ガクつきなし） | -    |
| バナー高さが適切（押しつけがましくない） | 44px〜56px 程度                | -    |
| 8px グリッド準拠のスペーシング           | 余白が適切に確保されている     | -    |

### Task 4: シナリオ3 — ダークモード確認
