## 残論点

- `generate_skill_md.js` の実際の `--plan` JSON スキーマ（`tasks` フィールドの詳細）は本修正では最小形（空配列）を使用する。
  スキルの内容をより詳細に反映したい場合は別タスクで対応する。
- `Date.now()` を `crypto.randomUUID()` に置き換えることで衝突リスクをゼロにできるが、
  現時点では不要と判断（許容リスク）。
