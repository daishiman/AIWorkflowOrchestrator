## 目的

Electron アプリを実際に起動し、`InlineModelSelector` コンポーネントの動作を視覚的に確認する。ドロップダウン操作・ライト/ダークモード切替・キーボード操作を手動で検証する。

## 実行タスク

### 事前準備

```bash
# Electron アプリのビルドと起動
cd apps/desktop
pnpm dev
```

### シナリオ1: ドロップダウン操作の視覚的確認

**目的**: InlineModelSelector のドロップダウンが正しく表示・動作することを視覚的に確認する

**手順**:

1. アプリを起動し、`InlineModelSelector` が配置されているビュー（チャット画面等）を開く
2. セレクターのトリガーをクリックし、ドロップダウンが正しく表示されることを確認する
3. プロバイダーを選択し、モデルリストが切り替わることを確認する
4. モデルを選択し、トリガーの表示が更新されることを確認する
5. ドロップダウン外をクリックし、閉じることを確認する

**期待結果**:

- ドロップダウンがトリガーの下に正しくアンカーされて表示される
- プロバイダー選択でモデルリストが即時切り替わる
- モデル選択後、トリガーに選択中の「ProviderName / ModelName」が表示される
- 外部クリックでドロップダウンが閉じる

### シナリオ2: ライト/ダークモード切替確認

**目的**: ライト/ダーク両モードで Apple HIG 準拠のカラーが正しく適用されていることを確認する

**手順**:

1. ライトモードでアプリを起動し、`InlineModelSelector` のデザインを確認する
   - トリガーのボーダー色・背景色が Apple HIG のライトモードカラーに準拠していること
   - ヘルスドットの色が視認できること
   - ドロップダウンの項目のコントラスト比が十分であること
2. ダークモードに切り替え（macOS System Preferences またはアプリ内テーマ切替）
3. ダークモードでのデザインを確認する
   - ライトモードと同様の項目を確認する

**期待結果**:

- ライトモード: 白背景、グレーボーダー（`#C6C6C8`相当）
- ダークモード: 暗い背景（`#1C1C1E`相当）、グレーボーダー（`#38383A`相当）
- 両モードで文字が読みやすいこと（コントラスト比 4.5:1 以上）

### シナリオ3: キーボード操作確認

**目的**: キーボードのみで操作できることを確認する

**手順**:

1. Tab キーでセレクタートリガーにフォーカスを当てる
2. Enter または Space キーでドロップダウンを開く
3. Tab キーでプロバイダー項目を移動する
4. Enter キーでプロバイダーを選択する
5. Tab キーでモデル項目を移動する
6. Enter キーでモデルを選択する
7. Escape キーでドロップダウンを閉じる
8. ドロップダウンが閉じた後にトリガーにフォーカスが戻ることを確認する

**期待結果**:

- マウスを使わずに全操作が完了できる
- フォーカスが正しく移動し、視覚的フォーカスインジケーター（青いリング等）が表示される
- Escape キーでドロップダウンが閉じ、フォーカスがトリガーに戻る

### シナリオ4: compact prop の視覚確認

**目的**: compact=true 時にコンパクトサイズで表示されることを確認する

**手順**:

1. 通常の `InlineModelSelector`（compact=false）の表示サイズを確認する
2. `compact={true}` の `InlineModelSelector` の表示サイズを確認する（DevTools で強制的に prop を変更するか、コンポーネントが配置されたビューを確認する）

**期待結果**:

- compact=true ではフォントサイズ・パディングが縮小されている
- compact=false と比べてコンポーネントの高さが小さい
