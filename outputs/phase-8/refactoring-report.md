## 判断根拠

| 検討事項                           | 判断       | 理由                                                                             |
| ---------------------------------- | ---------- | -------------------------------------------------------------------------------- |
| esbuild の rebuild は必須か        | 現状維持   | 将来的な安全のため含める方針は妥当                                               |
| `electron-rebuild` ツールへの移行  | 採用しない | 追加 devDependency が必要、explicit な指定の方が対象明確、変更量最小方針と不整合 |
| postinstall のエラー時サイレント化 | 採用しない | エラーをサイレントにすると ABI 不一致の根本原因が見えにくくなる                  |
