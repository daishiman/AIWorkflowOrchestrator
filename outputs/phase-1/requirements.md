# Phase 1: 要件定義 - Custom Execution Environment UI

## タスク情報

- **タスクID**: AGENT-006
- **タスク名**: Custom Execution Environment UI
- **フェーズ**: Phase 1 - 要件定義
- **作成日**: 2026-01-13
- **ステータス**: 完了

## 概要

AIエージェントの実行結果をプレビューするためのカスタム実行環境UIを実装する。HTML、Markdown、ターミナル、コード実行環境のプレビューに対応した分割レイアウトUIを提供する。

## 機能要件

### FR-001: 分割レイアウト

| ID       | 要件                                               | 優先度 |
| -------- | -------------------------------------------------- | ------ |
| FR-001-1 | 左右2パネルの分割レイアウトを表示する              | 必須   |
| FR-001-2 | ディバイダーをドラッグしてパネルサイズを変更できる | 必須   |
| FR-001-3 | キーボード操作でパネルサイズを変更できる           | 必須   |
| FR-001-4 | 最小/最大比率を設定できる                          | 必須   |
| FR-001-5 | 右パネルを非表示にできる                           | 任意   |

### FR-002: 環境選択

| ID       | 要件                                                       | 優先度 |
| -------- | ---------------------------------------------------------- | ------ |
| FR-002-1 | ドロップダウンで環境タイプを選択できる                     | 必須   |
| FR-002-2 | 利用可能な環境タイプ: none, html, markdown, terminal, code | 必須   |
| FR-002-3 | リフレッシュボタンでプレビューを更新できる                 | 任意   |
| FR-002-4 | フルスクリーンボタンで全画面表示できる                     | 任意   |

### FR-003: HTMLプレビュー

| ID       | 要件                                       | 優先度 |
| -------- | ------------------------------------------ | ------ |
| FR-003-1 | HTMLコンテンツをiframe内でレンダリングする | 必須   |
| FR-003-2 | スタイル付きHTMLを正しく表示する           | 必須   |
| FR-003-3 | 画像を含むHTMLを表示する                   | 必須   |

### FR-004: Markdownプレビュー

| ID       | 要件                                             | 優先度 |
| -------- | ------------------------------------------------ | ------ |
| FR-004-1 | MarkdownをHTMLに変換して表示する                 | 必須   |
| FR-004-2 | GFM (GitHub Flavored Markdown) をサポートする    | 必須   |
| FR-004-3 | コードブロック、テーブル、リストを正しく表示する | 必須   |

### FR-005: ターミナル/コード環境

| ID       | 要件                                       | 優先度 |
| -------- | ------------------------------------------ | ------ |
| FR-005-1 | ターミナル環境のプレースホルダーを表示する | 必須   |
| FR-005-2 | コード実行環境のプレースホルダーを表示する | 必須   |

## セキュリティ要件

### SR-001: XSS攻撃防止

| ID       | 要件                                                 | 優先度 |
| -------- | ---------------------------------------------------- | ------ |
| SR-001-1 | HTMLコンテンツをサニタイズしてXSS攻撃を防止する      | 必須   |
| SR-001-2 | scriptタグを除去する                                 | 必須   |
| SR-001-3 | イベントハンドラ属性（onclick, onerror等）を除去する | 必須   |
| SR-001-4 | javascript: URLを無効化する                          | 必須   |

### SR-002: iframe分離

| ID       | 要件                           | 優先度 |
| -------- | ------------------------------ | ------ |
| SR-002-1 | iframe sandbox属性を設定する   | 必須   |
| SR-002-2 | allow-scriptsを禁止する        | 必須   |
| SR-002-3 | allow-popupsを禁止する         | 必須   |
| SR-002-4 | allow-top-navigationを禁止する | 必須   |
| SR-002-5 | allow-formsを禁止する          | 必須   |

### SR-003: CSP (Content Security Policy)

| ID       | 要件                         | 優先度 |
| -------- | ---------------------------- | ------ |
| SR-003-1 | script-src 'none'を設定する  | 必須   |
| SR-003-2 | connect-src 'none'を設定する | 必須   |
| SR-003-3 | form-action 'none'を設定する | 必須   |

## アクセシビリティ要件

| ID       | 要件                                    | 優先度 |

| AR-001-2 | 矢印キーでパネルサイズを調整できる      | 必須   |
| AR-001-3 | Home/Endキーで最小/最大比率に設定できる | 任意   |

### AR-002: スクリーンリーダー対応

| -------- | ----------------------------------------------------- | ------ |
| AR-002-1 | aria-valuenow, aria-valuemin, aria-valuemaxを設定する | 必須   |

| AR-002-3 | role="separator"を設定する                            | 必須   |

| ID        | 要件                                         | 優先度 |

| NFR-001-2 | 大きなコンテンツでもレンダリングが遅延しない | 必須   |

### NFR-002: 保守性

| ID        | 要件                                        | 優先度 |
| --------- | ------------------------------------------- | ------ |

## 技術スタック

- **フレームワーク**: React 18
- **状態管理**: Zustand
- **スタイリング**: Tailwind CSS + clsx
- **HTMLサニタイズ**: DOMPurify
- **Markdownパーサー**: marked
- **テスト**: Vitest + Testing Library
