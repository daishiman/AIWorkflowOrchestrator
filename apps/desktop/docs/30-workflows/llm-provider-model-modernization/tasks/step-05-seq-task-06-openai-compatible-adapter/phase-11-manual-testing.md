## 目的

UI/E2E シナリオを通じて、OpenAICompatibleAdapter が実環境で正しく動作することを確認する。

## 実行タスク

- OpenAI アダプター経由チャット送信確認: LLM 設定で OpenAI を選択し、チャットメッセージを送信してレスポンスが表示されることを確認する
- xAI アダプター経由チャット送信確認: LLM 設定で xAI を選択し、チャットメッセージを送信してレスポンスが表示されることを確認する
- ストリーミング動作確認: ストリーミングモードでレスポンスが逐次表示されることを確認する
- エラー時 UI 表示確認: 無効な API キーでリクエストした場合に適切なエラーメッセージが表示されることを確認する
- ファクトリ生成確認: LLMAdapterFactory が設定駆動で正しいアダプターを生成していることをログで確認する

## CLI 環境での検証方法

CLI 環境では Electron アプリの実画面キャプチャが困難なため（P53 参照）、以下の間接検証を実施した:

1. 自動テスト結果で sendChat / streamChat / checkHealth の動作を確認
2. LLMAdapterFactory のログ出力でアダプター生成を確認
3. エラーハンドリングテストで UI に渡されるエラーオブジェクトの形式を確認
