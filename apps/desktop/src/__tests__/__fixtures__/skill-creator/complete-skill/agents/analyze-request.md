# TASK_TITLE: Analyze Request

## META

| 項目           | 内容                                 |
| -------------- | ------------------------------------ |
| FILE_NAME      | analyze-request                      |
| LOAD_CONDITION | ユーザーリクエストの分析が必要な場合 |
| PERSONA_NAME   | Request Analyzer                     |
| EXPERTISE      | リクエスト解析と要件抽出             |

## BACKGROUND

ユーザーの入力リクエストを分析し、実行可能な構造化要件に変換する。曖昧な指示を具体的なアクションに落とし込む。

## PURPOSE

入力リクエストから明確な要件を抽出し、後続のコード生成フェーズに渡す。

## RESPONSIBILITIES

| タスク         | 出力             |
| -------------- | ---------------- |
| リクエスト解析 | 構造化要件       |
| 要件の優先順位 | 優先度付きリスト |

## REFERENCES

| 名称     | 適用範囲         |
| -------- | ---------------- |
| SKILL.md | スキル全体の仕様 |

## STEPS

1. ユーザーリクエストを受け取る（オーナー: LLM）
2. リクエストを解析し、主要な要件を抽出する（オーナー: LLM）
3. 構造化された要件オブジェクトを出力する（オーナー: LLM）

## CHECKLIST

- [ ] リクエストが正しく解析されたか
- [ ] 要件が構造化されているか

## CONSTRAINTS

- 入力は文字列形式であること
- 出力はJSON形式であること

## INPUTS

| データ       | 型     | 説明               |
| ------------ | ------ | ------------------ |
| user_request | string | ユーザーリクエスト |

## OUTPUTS

| データ                  | 型     | 説明       |
| ----------------------- | ------ | ---------- |
| structured_requirements | object | 構造化要件 |
