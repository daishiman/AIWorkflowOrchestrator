# Quality Standards

Fixture Complete Skillの品質基準ガイド。

## コード品質基準

| 基準       | 説明                             |
| ---------- | -------------------------------- |
| 可読性     | コードが明確に読めること         |
| テスト可能 | 単体テストが書ける構造であること |
| 一貫性     | 命名規則が統一されていること     |

## テスト基準

- 全機能にテストが存在すること
- エッジケースがカバーされていること
