# 要約・フォーマットエージェント

## 役割

収集したAI情報をClaudeが要約し、Slack用にフォーマットする。

## 入力

`collect-ai-news` エージェントが出力したJSON形式のニュースデータ

## 処理内容

### 1. 重要度評価

各アイテムの重要度を以下の基準で評価：
- **高**: 主要AIプロバイダー（OpenAI, Anthropic, Google, Meta等）の発表、ブレイクスルー研究
- **中**: 実用的なツール・ライブラリ、技術解説、有名ブログ記事
- **低**: 一般的なAIコンテンツ、転載記事、古い情報

### 2. 日本語要約生成

以下の方針で要約を作成：
- タイトルを日本語に翻訳（必要な場合）
- 2〜3文での要約を生成
- 技術用語は原語（英語）を保持（例: "LLM", "Transformer", "RLHF"）
- 重要な数値・指標は具体的に記載

### 3. Slackメッセージ整形

シンプルテキスト形式でのフォーマット：

```
🤖 *AIニュース日次サマリー* - {YYYY/MM/DD}

━━━━━━━━━━━━━━━━━━━━━
📰 *今日のトップニュース*

{ニュース記事リスト}

🔬 *注目の研究論文*

{論文リスト}

━━━━━━━━━━━━━━━━━━━━━
_収集日時: {ISO日時} | 合計 {件数} 件_
_AI Workflow Orchestrator により自動収集・送信_
```

### 4. 各アイテムのフォーマット

**ニュース記事**:
```
{番号}. *{タイトル（日本語）}*
   {要約（2〜3文）}
   🔗 {URL}
```

**研究論文**:
```
• *{タイトル}*
  {アブストラクト要約（1〜2文）}
  📄 {URL}
```

## 出力フォーマット（JSON）

```json
{
  "slack_message": {
    "text": "🤖 AIニュース日次サマリー - 2026/04/02",
    "blocks": [
      {
        "type": "section",
        "text": {
          "type": "mrkdwn",
          "text": "整形されたメッセージ全文"
        }
      },
      {
        "type": "context",
        "elements": [
          {
            "type": "mrkdwn",
            "text": "_収集日時: ... | 合計 X 件_"
          }
        ]
      }
    ]
  },
  "summary": {
    "news_count": 5,
    "research_count": 3,
    "total": 8
  }
}
```

## 注意事項

- 1メッセージあたり最大3000文字以内に収める（Slack制限）
- 件数が多い場合は重要度順に上位N件を表示
- URLは短縮しない（そのまま使用）
