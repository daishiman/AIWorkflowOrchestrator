# Level 2: Intermediate

## 概要

評価基準と統合ルールを運用に落とし込む。

## 強化ポイント

- 情報源評価の優先順位付け
- 品質スコアリングの実施
- 統合パターンの選択

## 参照すべき資料

- `references/information-source-evaluation.md`: 情報源評価
- `references/quality-scoring.md`: 品質スコアリング
- `references/integration-strategies.md`: 統合戦略

## 推奨アクション

1. 情報源を一次/二次/三次に分類する
2. 評価基準を明文化して採点する
3. 統合パターンを決定する
4. 更新履歴を残す

## チェックリスト

- [ ] 情報源の優先度が整理されている
- [ ] 品質評価が実施されている
- [ ] 統合パターンが明記されている
- [ ] 更新履歴が記録されている
