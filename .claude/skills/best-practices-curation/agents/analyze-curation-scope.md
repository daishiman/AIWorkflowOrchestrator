## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 収集目的と対象領域を確認する |
| 2 | 情報源の優先度を整理する |
| 3 | スコープと前提をまとめる |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 対象領域 | 収集対象が明確である |
| 優先度 | 優先度が記載されている |
| 前提 | 制約が明記されている |
| 出力検証 | スコープメモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 範囲明確化 | 収集範囲を必ず定義する |
| 優先度 | 重要テーマを上位に置く |
| 前提整理 | 前提条件を明示する |
