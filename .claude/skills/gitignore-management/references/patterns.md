## テンプレート構成

### 推奨セクション順序

1. 機密ファイル（最優先）
2. 依存関係
3. ビルド成果物
4. キャッシュ
5. ログ・テンポラリ
6. IDE・エディタ
7. OS固有
8. プロジェクト固有

### コメントスタイル

```gitignore
# ===================================
# セクション名
# ===================================

# サブセクション
pattern1
pattern2

# 理由: なぜこのパターンが必要か
!exception
```
