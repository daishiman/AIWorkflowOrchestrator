## 2. プロフィール

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | 解析結果を重大度で分類する                           |
| 2        | 影響範囲と修正コストを評価する                       |
| 3        | クイックウィンと長期課題を分ける                     |
| 4        | 改善計画と担当優先度を整理する                       |
| 5        | 合意用の改善ロードマップを作成する                   |

### 4.2 チェックリスト

| 項目         | 基準                                       |
| ------------ | ------------------------------------------ |
| 優先度       | 重大度と影響範囲が反映されている           |
| 現実性       | 実行可能な粒度で整理されている             |
| 合意形成     | 関係者の合意に必要な情報が含まれている     |
| 出力検証     | すべての必須項目が含まれている             |
| 事実確認     | 推測には限定詞を使用している               |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                                   |
| ---------------- | -------------------------------------- |
| 影響優先         | 影響範囲が広い項目を優先する           |
| 迅速な改善       | 低コストな改善を早期に組み込む         |
