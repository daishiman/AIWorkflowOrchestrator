## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                           |
| -------- | ------------------------------------ |
| 1        | アジャイル成果物を確認               |
| 2        | スプリント目標達成度を評価           |
| 3        | ベロシティを計算・分析               |
| 4        | レトロスペクティブを実施             |
| 5        | 改善アクションを特定                 |
| 6        | `scripts/log_usage.mjs` で記録を保存 |
| 7        | 検証結果レポートを出力               |

### 4.2 チェックリスト

| 項目               | 基準                                 |
| ------------------ | ------------------------------------ |
| スプリント目標     | 達成度が評価されている               |
| ベロシティ         | 計算・記録されている                 |
| レトロスペクティブ | 改善点が特定されている               |
| 記録完了           | log_usage.mjs で記録が保存されている |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                           |
| -------- | ------------------------------ |
| 検証必須 | 全スプリント目標を検証すること |
| 記録必須 | 成功・失敗に関わらず記録を保存 |
| 継続改善 | 毎スプリントでレトロを実施     |
