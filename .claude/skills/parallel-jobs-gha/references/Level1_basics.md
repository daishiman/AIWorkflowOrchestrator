# Level 1: Basics

## 概要

GitHub Actionsの並列ジョブ実行とジョブ依存関係管理のスキル。

SKILL.md の内容だけで完結する基本運用を扱います。

## 前提条件

- SKILL.md の概要とワークフローを読了している
- 対象タスクの目的と成果物を把握している
- GitHub Actionsの基本的な構文を理解している

## 詳細ガイド

### 使用タイミング

- GitHub Actionsワークフローで並列ジョブ実行が必要な場合
- ジョブ間の依存関係を制御したい場合
- CI/CDパイプラインの実行時間を短縮したい場合
- ジョブ間でデータを受け渡す必要がある場合

### 必要な知識

- **needs構文**: ジョブ依存関係の定義方法
- **outputs**: 文字列データの受け渡し
- **artifacts**: ファイルの受け渡し
- **cache**: 依存関係の共有
- **matrix戦略**: 並列度の調整

### 判断基準

- **適用すべき**: ジョブが独立している、データ受け渡しが明確、依存関係が非循環
- **避けるべき**: 循環依存、過剰な並列化、不要なartifacts

### 成果物の最小要件

- YAML構文が有効であること
- ジョブ依存関係が明示されていること（needs）
- データ受け渡しが適切に実装されていること（outputs/artifacts/cache）

### 参照書籍

- 『The Pragmatic Programmer』（Andrew Hunt, David Thomas）: 実践的改善
- 『Continuous Delivery』（Jez Humble, David Farley）: CI/CDベストプラクティス

### 主要リソース

- `SKILL.md`: スキルの目的・前提・判断基準の基礎
- `assets/parallel-workflow.yaml`: ワークフローテンプレート

## 実践手順

1. SKILL.md の概要と目的を確認する
2. 並列化の目的を明確にする（実行時間短縮/リソース効率化/早期失敗検出）
3. 適用タイミングと成果物の期待値を言語化する
4. ワークフローセクションに従ってPhase 1から順に進める
