## スナップショット戦略

### 概念

```
Events: E1 → E2 → E3 → ... → E100
                      ↓
State = Snapshot(E50) + Apply(E51..E100)
```

### トリガー条件

| 戦略         | トリガー         | 用途             |
| ------------ | ---------------- | ---------------- |
| イベント数   | N件ごと          | 一般的           |
| 時間ベース   | N分/時間ごと     | 定期更新         |
| サイズベース | Nバイト超過      | 大量データ       |
| オンデマンド | 明示的リクエスト | 特定アグリゲート |

### スナップショット構造

| フィールド  | 説明             |
| ----------- | ---------------- |
| aggregateId | 対象ID           |
| version     | 時点のバージョン |
| state       | シリアライズ状態 |
| createdAt   | 作成日時         |

## イベントリプレイ

### 用途

| 用途             | 説明                     |
| ---------------- | ------------------------ |
| Read Model再構築 | Projection修正後の再構築 |
| デバッグ         | 問題再現                 |
| 監査             | 過去状態の検証           |
| マイグレーション | 新システムへの移行       |

### リプレイ種類

| 種類   | 範囲               |
| ------ | ------------------ |
| 全体   | 全イベント         |
| 増分   | 特定時点以降       |
| 選択的 | 特定ストリームのみ |

---

## パフォーマンス最適化

### インデックス戦略

| インデックス          | 用途             |
| --------------------- | ---------------- |
| stream_id             | ストリーム検索   |
| event_type            | タイプ別検索     |
| occurred_at           | 時系列検索       |
| (stream_id, sequence) | 順序付き読み取り |

### パーティショニング

| 戦略  | 分割基準  | 適用場面       |
| ----- | --------- | -------------- |
| Hash  | stream_id | 均等分散       |
| Range | 時間      | 時系列データ   |
| List  | テナント  | マルチテナント |

## アーカイブ戦略

| 戦略         | 説明               |
| ------------ | ------------------ |
| Cold Storage | 古いイベントを移動 |
| 圧縮         | イベント圧縮保存   |
| サマリー     | 期間ごとに集約     |
| TTL          | 保持期間後に削除   |
