## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 目的と制約を整理する |
| 2 | パターン選定ガイドで候補を絞る |
| 3 | 適用パターンと理由を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的 | 目的が明記されている |
| 選定 | パターン理由が記録されている |
| 制約 | 制約が整理されている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 選定 | 単一パターンを優先する |
| 例外 | 例外条件を記録する |
