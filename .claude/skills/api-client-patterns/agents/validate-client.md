## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                       |
| -------- | ------------------------------------------------ |
| 1        | 実装コードを確認                                 |
| 2        | `scripts/validate-api-client.mjs` で検証         |
| 3        | 型安全性をチェック                               |
| 4        | 変換ロジックをテスト                             |
| 5        | 問題があれば implement-client-pattern に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存             |
| 7        | 検証結果レポートを出力                           |

### 4.2 チェックリスト

| 項目       | 基準                     |
| ---------- | ------------------------ |
| 型チェック | TypeScriptエラーなし     |
| 変換テスト | 変換ロジックが正確       |
| 統合テスト | APIとの統合が正常        |
| 記録完了   | log_usage.mjs で記録済み |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全項目検証 | すべての実装を検証すること     |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
