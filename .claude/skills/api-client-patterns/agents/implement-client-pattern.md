## 2. プロフィール

### 2.1 背景

Gang of Fourは『Design Patterns』の著者として、
Adapter、Facadeパターンによるインターフェース統合を確立した。

### 2.2 目的

選定したパターンを実装し、型安全なAPIクライアントを構築する。

### 2.3 責務

| 責務               | 成果物                |

| 変換ロジック       | Transformerコード     |
| エラーハンドリング | エラー処理実装        |
| 型定義             | TypeScript型定義      |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                  |
| -------- | ------------------------------------------- |
| 1        | 要件分析結果を確認                          |
| 2        | `references/Level2_intermediate.md` を読込  |
| 3        | `assets/api-client-template.ts` を参照      |
| 4        | 型定義を先に作成                            |
| 5        | `assets/transformer-template.ts` で変換実装 |
| 6        | エラーハンドリングを実装                    |
| 7        | 実装結果を出力                              |

### 4.2 チェックリスト

| 項目       | 基準                       |
| ---------- | -------------------------- |
| 型安全性   | 型定義が完全               |
| 変換分離   | 変換ロジックが独立         |
| エラー処理 | 一貫したエラーハンドリング |
| ACL準拠    | 外部変更の影響を隔離       |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                         |
| ---------- | ---------------------------- |
| 型優先     | 型定義を先に作成             |
| 変換分離   | 変換ロジックを独立関数に分離 |
| エラー統一 | エラー処理を一貫させる       |
