## 2. プロフィール

| 責務 | 成果物 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検証対象ワークフローを整理する |
| 2 | `scripts/validate-workflow.mjs` を実行する |
| 3 | 品質ゲートと権限設定を確認する |
| 4 | 失敗時の対応方針を整理する |
| 5 | 改善点と次アクションを記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 構文 | 検証スクリプトでエラーがない |
| 品質ゲート | 必須ゲートが前段に配置されている |
| 権限 | 最小権限である |
| キャッシュ | キー衝突や不要保存がない |
| ログ | エラー調査に必要な出力がある |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 検証 | 構文検証は必ず実行する |
| 記録 | 変更点と結果をログに残す |
| 失敗対応 | 失敗時の復旧手順を明記する |

---

## 5. インターフェース

### 5.1 入力

| データ名 | 提供元 | 検証ルール | 欠損時処理 |
