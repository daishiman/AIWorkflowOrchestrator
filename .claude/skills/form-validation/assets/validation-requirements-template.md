## 6. エラーメッセージ設計方針

### 原則

1. 具体的: 何が間違っているかを明確に示す
2. 修正可能: どうすれば修正できるかを示す
3. 一貫性: 同じ種類のエラーは同じ形式で表示
4. 国際化: i18n対応を考慮

### エラーメッセージ例

| エラー種別       | メッセージテンプレート                                                   |
| ---------------- | ------------------------------------------------------------------------ |
| 必須フィールド空 | {{フィールド名}}は必須です                                               |
| 最小長未満       | {{フィールド名}}は{{最小}}文字以上で入力してください                     |
| 最大長超過       | {{フィールド名}}は{{最大}}文字以内で入力してください                     |
