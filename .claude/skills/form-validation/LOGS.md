# フォームバリデーションスキル使用ログ

## 目的

このログは、form-validationスキルの使用履歴とフィードバックを記録し、継続的な改善を支援します。

## ログ形式

各使用記録は以下の形式で記録されます:

```markdown
### [YYYY-MM-DD HH:MM:SS] - 結果: [SUCCESS/FAILURE]

- フェーズ: {phase-name}
- タスク: {task-name}
- 結果: {success|failure}
- メモ: {追加のフィードバック}
- 改善提案: {あれば記載}
```

## 使用履歴

このセクションには、scripts/log_usage.mjsによって自動的に記録が追加されます。
