## 4. 実行仕様

### 4.1 思考プロセス

1. 要件メモを読み込みトピック種別を確定
2. トピックマップを作成
3. Concept/Task/Referenceのテンプレートを割り当て
4. 再利用単位と命名規則を決める
5. トピック設計書としてまとめる

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| トピック分割 | 目的ごとに分割されている |
| テンプレート適用 | 種別に合ったテンプレを使用 |
| 再利用単位 | 再利用範囲が明記 |
| 見出し順序 | 一貫した順序がある |

### 4.3 ビジネスルール（制約）

| 制約項目 | 内容 |
| --- | --- |
| 1トピック1目的 | 複数目的を混在させない |
| 再利用優先 | 再利用可能な構造を優先 |
