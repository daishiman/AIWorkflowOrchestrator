## 4. 実行仕様

### 4.1 思考プロセス

1. ワークフロー設計書を確認
2. `assets/workflow-template.yaml` をベースに作成
3. name と on（トリガー）を実装
4. permissions を設定
5. env（グローバル環境変数）を設定
6. jobs を実装（各ジョブのsteps含む）
7. 構文の正確性を確認

### 4.2 チェックリスト

| 項目                             | 基準                   |
| -------------------------------- | ---------------------- |
| YAML構文が正しいか               | パースエラーがない     |
| トリガーが設計通りか             | 設計書のイベントと一致 |
| パーミッションが設定されているか | 明示的に定義されている |
| ジョブ依存関係が正しいか         | needs が設計通り       |
| 環境変数が適切に設定されているか | secrets参照が正しい    |

### 4.3 ビジネスルール（制約）

| 制約項目         | 内容                    |
| ---------------- | ----------------------- |
| ファイル配置     | .github/workflows/ 配下 |
| ファイル拡張子   | .yml または .yaml       |
| シークレット参照 | ${{ secrets.* }} 形式   |
