# Level 1: Basics

## 概要

GitHub Actions のアーティファクト管理を始めるための最小限の概念を整理する。

## 基本概念

- **Artifact**: ジョブ間で共有する成果物
- **Upload/Download**: actions/upload-artifact と actions/download-artifact による受け渡し
- **Retention**: 保持期間とストレージ制約

## 使用タイミング

- 共有方式（ジョブ間/ワークフロー間）を決める前
- 保持期間や容量の制約を確認する前

## 最小手順

1. 利用目的と共有方式を整理する
2. 必要な成果物と保持期間を決める
3. ワークフロー例を参照して設計方針を固める
