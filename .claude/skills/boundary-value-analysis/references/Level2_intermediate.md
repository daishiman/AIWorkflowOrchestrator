# Level 2: Intermediate

## 概要

実務で使える境界値テストの設計手順を整理する。

## 強化ポイント

- 有効/無効クラスの網羅
- 境界値の系統的抽出
- エッジケース追加

## 参照すべき資料

- `references/boundary-value-fundamentals.md`: 境界値分析の基礎
- `references/equivalence-partitioning.md`: 同値分割手法
- `references/edge-cases-catalog.md`: エッジケース集

## 推奨アクション

1. 同値クラスを有効/無効で分ける
2. 下限/上限/±1をテストケース化する
3. エッジケースを追加する

## チェックリスト

- [ ] 無効クラスのテストがある
- [ ] 境界値がテストケース化されている
- [ ] 代表エッジケースが含まれている
