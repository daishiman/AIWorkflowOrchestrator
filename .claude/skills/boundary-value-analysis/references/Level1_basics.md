# Level 1: Basics

## 概要

境界値分析と同値分割の基本概念を整理する。

## 基本概念

- 同値クラス（有効/無効）
- 境界値（下限/上限/±1）
- 代表値選定

## 使用タイミング

- テスト設計の初期段階
- 入力制約の確認時

## 最小手順

1. 入力範囲と制約を整理する
2. 同値クラスを定義する
3. 境界値を抽出する
