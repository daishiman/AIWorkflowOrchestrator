## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | テストケース一覧を確認する |
| 2 | 境界値/無効値の網羅性を確認する |
| 3 | 不足ケースを整理する |
| 4 | 検証メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 境界値網羅 | 下限/上限/±1が確認できる |
| 無効値 | 無効クラスのテストがある |
| エッジ | 代表エッジが含まれる |
| 出力検証 | 検証メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 網羅性 | 主要境界値を省略しない |
| 記録 | 不足点を必ず記録する |
| 改善 | 改善案を提示する |

---

## 5. インターフェース

### 5.1 入力
