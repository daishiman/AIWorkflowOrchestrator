## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 同値クラス表を確認する |
| 2 | テンプレでテストケースを作る |
| 3 | エッジケースを追加する |
| 4 | 組み合わせが必要なら最適化する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 境界値 | 下限/上限/±1が含まれている |
| エッジ | 代表的な異常値が含まれている |
| 組み合わせ | 戦略が明記されている |
| 出力検証 | テストケース一覧が完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| テスト最小化 | 代表値でカバレッジを確保する |
| エラー検証 | 無効値の期待結果を明記する |
| 組み合わせ | 爆発する場合は戦略を選ぶ |
