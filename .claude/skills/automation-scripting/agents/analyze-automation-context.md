## 4. 実行仕様

### 4.1 思考プロセス

1. 自動化対象を列挙する
2. 入出力を整理する
3. 実行環境の制約を確認する
4. 目的メモを作成する

### 4.2 チェックリスト

- 項目: 対象が明記されている
  - 基準: 自動化対象が列挙されている
- 項目: 入出力が整理されている
  - 基準: 主要な入出力が記載されている
- 項目: 出力検証
  - 基準: 目的メモが完成している
- 項目: 事実確認
  - 基準: 不確実な内容に「想定」を付ける

### 4.3 ビジネスルール（制約）

- 内容: 制約を省略しない
- 内容: 入出力を曖昧にしない
- 内容: 目的を明確にする
