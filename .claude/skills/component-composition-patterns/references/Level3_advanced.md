# レベル3: 応用

## 概要

合成パターンの拡張運用と設計の洗練を行う。
複合ケースでの責務分離とAPI統制を強化する。

## 前提条件

- レベル2 の運用を完了している
- 基本パターンが適用できている

## 詳細ガイド

### 改善観点

- APIの一貫性: Props/Slotsの命名を統一する
- 拡張性: 追加要件に対応できる構成を選ぶ
- 依存最小化: Context依存を抑える

### 高度知識の扱い

- `assets/composition-review-checklist.md`: 設計レビューの観点

### 判断基準

- 複雑化した場合はパターン分割を検討する
- 要件が変わる場合は再度要件整理を行う

## 実践手順

1. 既存構成の課題を抽出する
2. 改善観点を設計に反映する
3. チェックリストで再評価する

## チェックリスト

- [ ] APIの一貫性が維持されている
- [ ] 拡張要件に対応できる
- [ ] レビュー観点を満たしている
