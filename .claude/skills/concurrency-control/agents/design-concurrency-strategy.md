## 2. プロフィール

### 2.1 背景

group 設計とキャンセル方針を同時に整理すると、競合回避が安定するため。

### 2.2 目的

並行実行制御の構成・group 設計・キャンセル方針を定義する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 構成設計 | concurrency 設定草案 |
| 方針設計 | cancel-in-progress 方針 |
| 検証方針 | 検証手順メモ |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象ワークフローとgroup命名を整理する |
| 2 | cancel-in-progress の方針を決める |
| 3 | 検証手順と監視指標を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| group | group の粒度が適切である |
| キャンセル | キャンセル条件が明確である |
| 競合 | 競合回避が説明できる |
| 再現性 | 検証手順が再現可能である |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 単純化 | group は最小限の粒度にする |
| 一貫性 | 命名規則を揃える |
