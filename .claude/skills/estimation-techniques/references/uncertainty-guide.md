# 不確実性管理ガイド

> 相対パス: `references/uncertainty-guide.md`
> 原典: Agile Estimating and Planning (Mike Cohn)

---

## コーン・オブ・アンサータンティ

| フェーズ   | 不確実性範囲 | 見積もり精度 |
| ---------- | ------------ | ------------ |
| 初期構想   | 4x - 0.25x   | ±400%        |
| 要件定義後 | 2x - 0.5x    | ±100%        |
| 設計完了後 | 1.5x - 0.67x | ±50%         |
| 実装中     | 1.25x - 0.8x | ±25%         |
| 完了直前   | 1.1x - 0.9x  | ±10%         |

---

## 確信度の評価

| レベル | 確信度  | 説明                       | 対応         |
| ------ | ------- | -------------------------- | ------------ |
| 高     | 80%+    | 類似経験あり、要件明確     | 通常見積もり |
| 中     | 50-80%  | 部分的な経験、要件やや曖昧 | バッファ追加 |
| 低     | 50%未満 | 未経験、要件不明確         | スパイク実施 |

---

## リスク・バッファの設計

| バッファ種類         | 計算方法                | 用途           |
| -------------------- | ----------------------- | -------------- |
| 個別バッファ         | 見積もり × 不確実性係数 | 個別ストーリー |
| プロジェクトバッファ | 全体 × 15-30%           | リリース計画   |
| 管理バッファ         | 固定（1-2スプリント）   | 予期せぬ事態   |

```
調整後見積もり = 元見積もり × (1 + 不確実性係数)

不確実性係数:
  低確信度: 0.5-1.0
  中確信度: 0.2-0.5
  高確信度: 0.1-0.2
```

## 再見積もりのトリガー

| トリガー        | 説明                   |
| --------------- | ---------------------- |
| 要件変更        | 受け入れ基準の大幅変更 |
| 技術発見        | 想定外の技術的課題     |
| 依存関係変化    | 外部依存の追加・変更   |
| チーム変更      | メンバーの増減         |
| 3スプリント経過 | 定期的な見直し         |

---

## スパイクの活用

| 項目           | 説明                     |
| -------------- | ------------------------ |
| 目的           | 不確実性の低減           |
| タイムボックス | 1-2日                    |
| 成果物         | 調査結果、見積もり根拠   |
| 見積もり       | 固定（タイムボックス分） |

**スパイク後のアクション**:

1. 調査結果を共有
2. 本タスクを再見積もり
3. 必要に応じて分割
