## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | SLOG-002のスキーマ定義を確認する                     |
| 2        | PIIに該当するフィールドを分類する                   |

### 4.2 チェックリスト

| 項目         | 基準                                       |
| ------------ | ------------------------------------------ |
| 準拠性       | スキーマと一致している                     |
| PII対応      | マスキング方針が実装されている             |
| 検証結果     | エラーと改善点が整理されている             |
| 出力検証     | すべての必須項目が含まれている             |
| 事実確認     | 推測には限定詞を使用している               |

### 4.3 ビジネスルール（制約）

| 制約                 | 説明                                   |
