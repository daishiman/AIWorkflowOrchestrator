## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 設計方針を確認する |
| 2 | マイグレーションを生成する |
| 3 | 安全性チェックを実行する |
| 4 | ロールバック案を用意する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 生成 | 生成手順が記録されている |
| 検証 | 安全性チェックが実行済み |
| ロールバック | 復旧手順が準備されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 変更最小化 | 影響を最小に抑える |
| ロールバック優先 | 復旧手順を先に確保 |
