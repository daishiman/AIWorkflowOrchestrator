## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象範囲を確認する |
| 2 | スキャンを実行する |
| 3 | 結果を整理する |
| 4 | 例外や失敗を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| スキャン | 成功ログがある |
| 結果 | 脆弱性一覧が整理されている |
| 条件 | 実行条件が記録されている |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 対象限定 | 指定範囲のみ対象 |
| 記録必須 | 条件は必ず記録 |
