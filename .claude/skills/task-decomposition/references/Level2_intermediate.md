# レベル2: 実務的な分解パターン

## 分解パターン

### 成果物ベース分解

- 成果物を上位に置き、成果物単位でタスクを切る
- レビューや検証の単位が明確になる

### 価値ベース分解

- 価値が高い順にタスクを並べる
- 段階的に価値を提供する計画に向く

### リスクベース分解

- リスクが高い箇所から詳細化する
- 早期に不確実性を潰す

## 依存関係の表現

- 完了依存: 前工程の完了が必須
- 情報依存: 情報が揃えば着手可能
- 環境依存: 実行環境の準備が必要

## 粒度調整の指標

- 1タスクあたり1〜2日で完了できるか
- 完了条件が明確に定義できるか
- 別の担当者が引き継いでも理解できるか
