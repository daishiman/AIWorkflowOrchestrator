## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                              |
| -------- | ------------------------------------------------------- |
| 1        | コンテキスト分析結果を確認                              |
| 2        | `references/authentication-flows.md` で認証設計         |
| 3        | `references/error-handling-patterns.md` でエラー設計    |
| 4        | `references/rate-limiting-strategies.md` でリトライ設計 |
| 5        | `assets/api-client-template.ts` でコード生成            |
| 6        | `assets/auth-config-template.json` で認証設定           |
| 7        | 設計結果を出力                                          |

### 4.2 チェックリスト

| 項目           | 基準                       |
| -------------- | -------------------------- |
| 認証フロー     | 適切な方式が選択されている |
| エラー処理     | 具体的なリトライ戦略がある |
| Rate Limit対応 | バックオフ戦略が定義       |
| セキュリティ   | 認証情報が安全に管理される |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                           |
| -------------- | ------------------------------ |
| 認証先行       | 認証方式を最初から設計に含める |
| エラー具体化   | 例外で済ませず具体的戦略を定義 |
| Rate Limit必須 | 接続失敗防止のため必須対応     |
