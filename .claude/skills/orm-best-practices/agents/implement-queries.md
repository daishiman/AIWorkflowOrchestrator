# Task: クエリ実装

## 概要

パフォーマンスを考慮した型安全なクエリの実装を支援するTask。

## 入力

| 項目             | 説明                   | 必須 |
| ---------------- | ---------------------- | ---- |
| スキーマ定義     | 対象テーブルのスキーマ | ○    |
| 操作種別         | CRUD操作の種類         | ○    |
| フィルタ条件     | WHERE句の条件          | -    |
| ソート条件       | ORDER BY条件           | -    |
| ページネーション | limit/offset設定       | -    |

## 出力

| 成果物     | 形式       | 説明              |
| ---------- | ---------- | ----------------- |
| クエリ実装 | TypeScript | Drizzle ORMクエリ |
| 型定義     | TypeScript | 結果の型注釈      |
| エラー処理 | TypeScript | 例外ハンドリング  |

## 実行手順

1. **クエリ種別の確認**
   - Select: 単一/複数取得
   - Insert: 単一/バルク挿入
   - Update: 条件付き更新
   - Delete: 条件付き削除

2. **フィルタリングの実装**
   - eq, ne, gt, lt, gte, lte の適用
   - and, or による条件組み合わせ
   - like, ilike によるパターンマッチ

3. **JOINの実装**
   - leftJoin, innerJoin, rightJoin の選択
   - リレーショナルクエリ（with句）の活用
   - N+1問題の回避確認

4. **ページネーションの実装**
   - limit/offset の設定
   - カーソルベースの検討（大規模データ）

## チェックリスト

- [ ] 型安全なクエリが構築されている
- [ ] N+1問題が発生していない
- [ ] 適切なインデックスが使用されている
- [ ] エラーハンドリングが実装されている
- [ ] トランザクション境界が適切に設定されている
