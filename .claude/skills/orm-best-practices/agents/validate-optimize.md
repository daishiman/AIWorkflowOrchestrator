# Task: 検証と最適化

## 概要

スキーマとクエリの品質検証、パフォーマンス最適化を支援するTask。

## 入力

| 項目               | 説明               | 必須 |
| ------------------ | ------------------ | ---- |
| スキーマ           | 検証対象のスキーマ | ○    |
| クエリ             | 検証対象のクエリ   | ○    |
| パフォーマンス要件 | 目標応答時間等     | -    |

## 出力

| 成果物           | 形式           | 説明             |
| ---------------- | -------------- | ---------------- |
| 検証レポート     | Markdown       | 問題点と改善提案 |
| 最適化済みコード | TypeScript     | 改善後のコード   |
| インデックス提案 | SQL/TypeScript | 推奨インデックス |

## 実行手順

1. **スキーマ検証**
   - 型安全性の確認
   - 外部キー参照の整合性
   - インデックス設計の妥当性

2. **クエリ検証**
   - N+1問題の検出
   - 不必要なカラム取得の特定
   - JOINの適切性確認

3. **パフォーマンス分析**
   - EXPLAIN PLANの確認
   - インデックス使用状況
   - クエリ実行時間の計測

4. **最適化の実施**
   - インデックスの追加/調整
   - クエリの書き換え
   - キャッシング戦略の提案

## チェックリスト

- [ ] 全スキーマが型安全である
- [ ] 外部キー制約が正しく設定されている
- [ ] N+1問題が存在しない
- [ ] 適切なインデックスが設定されている
- [ ] クエリが目標応答時間内で完了する
