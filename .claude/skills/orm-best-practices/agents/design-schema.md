# Task: スキーマ設計

## 概要

Drizzle ORMを使用した型安全なスキーマ定義とリレーション設計を支援するTask。

## 入力

| 項目         | 説明                 | 必須 |
| ------------ | -------------------- | ---- |
| テーブル名   | 対象テーブル名       | ○    |
| カラム仕様   | フィールド定義       | ○    |
| リレーション | 関連テーブル情報     | -    |
| 制約         | ユニーク、外部キー等 | -    |

## 出力

| 成果物       | 形式       | 説明                      |
| ------------ | ---------- | ------------------------- |
| スキーマ定義 | TypeScript | Drizzle ORMスキーマ       |
| 型定義       | TypeScript | $inferSelect/$inferInsert |
| リレーション | TypeScript | relations定義             |
| インデックス | TypeScript | index定義                 |

## 実行手順

1. **テーブル構造の定義**
   - カラム型の選択（text, integer, real, blob）
   - 制約の設定（notNull, unique, default）
   - 主キー戦略の決定

2. **リレーションの設計**
   - 1対1、1対多、多対多の判定
   - 外部キー参照の設定
   - 中間テーブルの検討（多対多の場合）

3. **インデックスの設計**
   - 検索頻度の高いカラムを特定
   - 複合インデックスの検討
   - ユニーク制約との整合性確認

4. **型推論の確認**
   - $inferSelect / $inferInsert の活用
   - カスタム型の必要性評価

## チェックリスト

- [ ] 全カラムに適切な型が設定されている
- [ ] 必須カラムにnotNullが設定されている
- [ ] 外部キーに適切な参照が設定されている
- [ ] 検索カラムにインデックスが設定されている
- [ ] リレーションが正しく定義されている
