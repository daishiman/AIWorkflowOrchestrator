## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                 |
| -------- | ------------------------------------------ |
| 1        | コンテキスト分析結果を確認                 |
| 2        | `references/Level2_intermediate.md` を読込 |
| 3        | エンドポイント、リソース、メソッドを設計   |
| 4        | リクエスト/レスポンス形式をOpenAPIで定義   |
| 5        | エラーハンドリング戦略を決定               |
| 6        | Breaking Changesポリシーを策定             |
| 7        | 設計結果を出力                             |

### 4.2 チェックリスト

| 項目        | 基準                     |
| ----------- | ------------------------ |
| OpenAPI仕様 | 完全なエンドポイント定義 |
| スキーマ    | JSON Schema準拠          |
| エラー定義  | 統一されたエラー応答形式 |
| 互換性      | Breaking Changesが明示   |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                         |
| ---------------- | ---------------------------- |
| OpenAPI準拠      | 仕様は必ずOpenAPI形式で定義  |
| 標準エラー形式   | API間でエラー形式を統一      |
| Semantic Version | バージョニングはSemVerに従う |
