# トークン計測ガイド

## 目的

コンテキストウィンドウの予算内に収めるため、トークン使用量を見積もる。

## 基本方針

- まず概算、次に精度を上げる
- 文字数ベースの概算を先に行う
- 重要情報の削減前に計測する

## 見積もり手順

1. 対象テキストの文字数を計測する
2. 文字数をトークン換算する（目安: 3〜4文字 = 1トークン）
3. 余裕枠（10〜20%）を確保する
4. 目標削減率を設定する

## 参考計算例

- 文字数 12,000 文字
- 目安換算: 12,000 / 3.5 = 約 3,429 トークン
- 余裕枠 15% → 3,943 トークン

## 注意点

- 変換精度はモデルと言語で変わる
- 数値は目安として扱い、検証で調整する
- トークン予算は必ず記録する
