# レベル1: 基礎

## 概要

コンテキストウィンドウの基本概念と、トークン予算を意識した情報整理の初歩を扱う。

SKILL.md と本レベルのみで完結する基本運用を対象とする。

## 前提条件

- SKILL.md の概要とワークフローを読了している
- 目的と成果物のイメージがある

## 詳細ガイド

### 使用タイミング

- コンテキスト整理の初期段階で適用する
- トークン予算が未確定のときに適用する

### 必要な知識

- 対象領域: コンテキストウィンドウ最適化の基礎
- 主要概念: トークン予算 / 優先順位 / 必須情報 / 削除候補
- 実務指針: テンプレートで棚卸しを行う

### 判断基準

- 避けるべき判断: 計測なしで削減方針を決める

### 成果物の最小要件

- 目的・制約・トークン予算・必須情報が明記されている
- 主要テンプレート: `assets/context-window-plan-template.md`

### 参照書籍

- 『High Performance Browser Networking』: 計測から改善する姿勢

### 主要リソース

- `SKILL.md`: 基本方針とワークフロー
- `references/token-counting-guide.md`: トークン計測の基礎

### 主要テンプレート

- `assets/context-window-plan-template.md`: 参照のみ

## 実践手順

1. 目的と成果物を1文で整理する
2. トークン予算を概算し、記録する
3. 必須情報と削除候補を分類する
