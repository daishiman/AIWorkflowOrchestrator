# レベル3: 応用

## 概要

圧縮技法の適用と、情報保持と簡潔性のバランス調整を扱う。

## 前提条件

- レベル2の成果物が揃っている
- 圧縮方針が決定している

## 詳細ガイド

### 使用タイミング

- 圧縮処理を実行するフェーズ
- 重要情報の保持が優先される場面

### 必要な知識

- 圧縮技法の種類と適用条件
- 情報密度を維持するための構造化

### 成果物要件

- 圧縮サマリと削除/保持理由が明記されている
- 参照形式が統一されている

## 実践手順

1. 圧縮ルールに従って要約する
2. 重要情報の欠落がないか検証する
3. 参照形式を整える
