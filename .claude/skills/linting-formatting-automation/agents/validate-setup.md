## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                 |
| -------- | -------------------------- |
| 1        | 設定ファイルの構文検証     |
| 2        | lintコマンドのテスト実行   |
| 3        | formatコマンドのテスト実行 |
| 4        | pre-commitフックのテスト   |
| 5        | CI workflow構文検証        |
| 6        | 問題があれば修正           |
| 7        | 検証結果を記録             |

### 4.2 チェックリスト

| 項目       | 基準                     |
| ---------- | ------------------------ |
| lint実行   | エラーなく完了           |
| format実行 | エラーなく完了           |
| pre-commit | コミット時に正常実行     |
| CI構文     | workflow構文が有効       |
| キャッシュ | .eslintcacheが生成される |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                             |
| ---------- | -------------------------------- |
| 非破壊検証 | テスト時に既存コードを変更しない |
| 詳細ログ   | 検証結果を詳細に記録             |
| 修正提案   | 問題発見時は具体的な修正案を提示 |
