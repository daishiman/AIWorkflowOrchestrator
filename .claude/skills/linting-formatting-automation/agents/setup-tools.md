## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                      |
| -------- | ----------------------------------------------- |
| 1        | ツール選択結果を確認                            |
| 2        | 必要なパッケージを特定                          |
| 3        | 設定ファイルを生成（assets/テンプレートを使用） |
| 4        | package.jsonにスクリプトを追加                  |
| 5        | .gitignoreにキャッシュディレクトリを追加        |
| 6        | 設定をテスト実行して検証                        |

### 4.2 チェックリスト

| 項目         | 基準                                     |
| ------------ | ---------------------------------------- |
| パッケージ   | 必要な依存関係がすべてインストール済み   |
| 設定ファイル | 正しいフォーマットで生成済み             |
| スクリプト   | lint/lint:fix が動作する                 |
| Prettier互換 | ESLint使用時はeslint-config-prettier適用 |

### 4.3 ビジネスルール（制約）

| 制約                       | 説明                                 |
| -------------------------- | ------------------------------------ |
| Flat Config優先            | ESLint v9+ではflat config形式を使用  |
| eslint-config-prettier最後 | Prettier競合回避のため最後に適用     |
| キャッシュ有効化           | パフォーマンスのためキャッシュを設定 |

## 5. インターフェース

### 5.1 入力

| データ名         | 提供元               | 検証ルール       | 欠損時処理     |
| ---------------- | -------------------- | ---------------- | -------------- |
| ツール選択結果   | analyze-requirements | 有効なツール名   | デフォルト使用 |
| プロジェクト情報 | ファイルシステム     | package.json存在 | エラー         |

### 5.2 出力

| 成果物名               | 受領先             | 内容                      |
| ---------------------- | ------------------ | ------------------------- |
| 設定ファイル群         | ファイルシステム   | eslint.config.js等        |
| インストールコマンド   | ユーザー           | pnpm add -D ...           |
| package.jsonスクリプト | integrate-workflow | lint/format関連スクリプト |

#### 出力テンプレート

```bash
# ESLint + Prettier
pnpm add -D eslint @eslint/js typescript-eslint prettier eslint-config-prettier

# Biome
pnpm add -D @biomejs/biome
```
