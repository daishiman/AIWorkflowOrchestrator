# Reasoning Prompt Templates

## 概要

短い根拠サマリーと最終回答を生成するためのテンプレート集。
内部の思考過程を長文で出力せず、要点のみを記載する。

## テンプレート1: 汎用サマリー

```markdown
# タスク

{{task_description}}

# 入力

{{input}}

# 指示

- 根拠は3〜5行の短い要点で記載する
- 最終回答は別行で明示する
- 長文の推論過程は出力しない

# 出力形式

## 根拠サマリー
- 
- 

## 最終回答
```

## テンプレート2: 比較判断

```markdown
# タスク

以下の選択肢を比較し、最適案を選択してください。

# 選択肢
- A: {{option_a}}
- B: {{option_b}}
- C: {{option_c}}

# 評価基準
{{criteria}}

# 指示

- 各選択肢のメリット/デメリットを短く整理する
- 最終判断の理由を2〜3行でまとめる

# 出力形式

## 比較サマリー
- A: 
- B: 
- C: 

## 判断理由

## 最終回答
```

## テンプレート3: トラブルシュート

```markdown
# タスク

以下の問題を整理し、修正方針を提案してください。

# 入力

{{issue_description}}

# 指示

- 症状/原因/対策を短く整理する
- 長文の推論過程は出力しない

# 出力形式

## 症状

## 原因候補
- 
- 

## 対策案
- 
- 

## 最終提案
```

## カスタマイズガイド

- 出力フォーマットは固定し、項目数を調整する
- 根拠は短い要点に制限する
