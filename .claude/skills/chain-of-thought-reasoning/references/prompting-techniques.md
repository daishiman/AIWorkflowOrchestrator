# Reasoning Prompting Techniques

## 概要

短い根拠サマリーと最終回答を明確に出力するためのプロンプト設計指針。

## 基本フレーズ

- "根拠を短く3行でまとめてください"
- "結論の理由を要点で示してください"
- "前提と制約を先に整理してください"

## 出力フォーマット指定

```markdown
## 根拠サマリー
- 
- 

## 最終回答
```

## 設計のポイント

- 出力形式を固定する
- 根拠の行数を制限する
- 不確実性は明記させる

## チェックリスト

- [ ] 出力形式が明示されている
- [ ] 根拠の長さが制限されている
- [ ] 前提の明記が指示されている
