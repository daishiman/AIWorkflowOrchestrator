# ランナー単価ガイド

## 目的

ランナー種別ごとの単価差を理解し、最適な選定を行う。

## 主要ポイント

- macOS は Linux より大幅に高単価
- Windows は Linux より高単価
- self-hosted は課金対象外だが運用コストがある

## 運用指針

1. OS依存がないジョブは Linux へ寄せる
2. テスト専用のジョブは一段低コストのランナーで実行する
3. self-hosted は稼働率と保守を考慮する

## 参考チェック

- 実際の単価は GitHub 公式の料金表で確認する
- 変更があるため、数値は常に最新の公式情報を参照する
