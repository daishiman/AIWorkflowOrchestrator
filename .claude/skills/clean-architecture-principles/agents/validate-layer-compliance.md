## 2. プロフィール

### 2.1 背景

検証手順と記録基準を揃えることで、レイヤー違反の再発防止につながるため。

### 2.2 目的

レイヤー違反を検出し、改善点と対応方針を記録する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 検証実施 | 検証レポート |
| 結果整理 | 改善アクション |
| 記録更新 | LOGS/EVALSの更新内容 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検証対象と成功条件を整理する |
| 2 | スクリプトとレビューを実行する |
| 3 | 結果と改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 検証スクリプト | 実行済みである |
| レビュー | チェックリストが適用されている |
| 改善点 | 次のアクションが明確である |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 検証順序 | スクリプト検証を先に行う |
| 記録 | 検証後にLOGS/EVALSを更新する |
