# Level 2: Intermediate

## 概要

OAuthフローの図解と手順作成の実務を整理する。

## 運用ガイド

### 参照の優先順位

1. `references/oauth2-flows.md` でフロー仕様を確認
2. `assets/oauth2-diagrams.md` で図解を作成
3. `references/token-management.md` でトークン説明を補強

### 成果物要件

- フロー図が完成している
- トークン手順が明文化されている

## 実践手順

1. OAuthフローの対象範囲を決める
2. 図解の要点を整理する
3. トークン取得・更新・失効を説明する
