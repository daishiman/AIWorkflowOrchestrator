## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 統合方針とコンテキストマップを確認する |
| 2 | 責務と依存の妥当性を確認する |
| 3 | リスクと改善点を整理する |
| 4 | 検証メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 妥当性 | 依存と責務の矛盾がない |
| リスク | リスクが記載されている |
| 改善 | 改善提案が記載されている |
| 出力検証 | 検証メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 境界維持 | 責務の重複を避ける |
| 依存抑制 | 双方向依存は最小限にする |
| 記録 | 不足点を必ず記録する |
