# 段階的導入ステップ

## 基本ステップ

1. ベースライン確認: 既存テストが通る状態を確認
2. 変化点の隔離: 影響範囲を最小化するために境界を作る
3. 新しい抽象の導入: インターフェース/抽象クラスを追加
4. 旧実装との並行稼働: 旧実装を残したまま新実装を接続
5. 呼び出し移行: 呼び出し箇所を段階的に切り替える
6. 旧実装の削除: 依存が全て移行したら削除
7. 整理と命名: 不要な分岐/コメントを整理

## 変更量の目安

- 1ステップでの差分はレビュー可能な量に限定
- 依存箇所が多い場合はフェーズを細かく分割

## 安全策

- 各ステップでテストを実行する
- ロールバック条件を先に定義する
