## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 重点領域に改善施策を割り当てる           |
| 2        | 目標値と期限を設定する                   |
| 3        | 検証方法と指標を明記する                 |

### 4.2 チェックリスト

| 項目            | 基準                                   |
| --------------- | -------------------------------------- |
| 施策の具体性     | 具体的な改善内容が記載されている       |
| 目標値           | 数値目標が明記されている               |
| 検証方法         | 計測方法が示されている                 |
| 出力検証         | すべての必須項目が含まれている         |
| 事実確認         | 推測には限定詞を使用                   |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                                 |
| ------------ | ------------------------------------ |
| 段階的実施   | 1回で100%を目指さない               |
| 目標整合     | 目標値はチーム合意を前提とする       |
