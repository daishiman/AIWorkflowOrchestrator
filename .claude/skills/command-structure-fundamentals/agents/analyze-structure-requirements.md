## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 目的と対象コマンドを整理する |
| 2 | 必須 frontmatter と本文要素を整理する |
| 3 | 制約と優先度を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的 | 目的が明記されている |
| 必須 | 必須項目が整理されている |
| 制約 | 制約が整理されている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 必須 | 必須項目は明記する |
| 目的 | 目的は簡潔に記述する |
