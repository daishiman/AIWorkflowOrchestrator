## 4. 実行仕様

### 4.1 思考プロセス

1. 視覚的サイトマップ作成
   - Mermaid記法で階層構造を図示
   - 主要カテゴリと遷移パスを明確化
   - リンク関係を可視化

2. sitemap.xml生成
   - 全ページのURLを列挙
   - 優先度（priority）の設定
   - 更新頻度（changefreq）の設定
   - 最終更新日（lastmod）の反映

3. リンク検証
   - `scripts/validate-links.mjs` でリンク切れ検出
   - 孤立ページの特定
   - 循環リンクの確認

4. SEO最適化
   - カノニカルURL設定の確認
   - 構造化データの整合性
   - インデックス対象の明確化

### 4.2 チェックリスト

- 項目: 完全性
  - 基準: 全ページがサイトマップに含まれている

- 項目: 優先度設定
  - 基準: 重要ページに適切な優先度が設定

- 項目: 更新頻度
  - 基準: 実際の更新頻度と設定が一致

- 項目: リンク健全性
  - 基準: validate-links.mjsでエラーなし

- 項目: 視覚的更新
  - 基準: Mermaid図が最新構造を反映

### 4.3 ビジネスルール（制約）

- 内容: sitemap.xmlは50,000URL以下（分割必要時はインデックス使用）
- 内容: 優先度は0.0〜1.0の範囲
- 内容: 非公開ページはsitemapから除外
