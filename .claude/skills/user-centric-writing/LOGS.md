## 記録方法

### 自動記録（推奨）

スキル実行後に以下のコマンドを実行:

```bash
node .claude/skills/user-centric-writing/scripts/log_usage.mjs \
  --result success \
  --task "content-drafting" \
  --phase "Phase 12-1" \
  --notes "Implementation guide Part 1 created"
```

### 手動記録

上記のログフォーマットに従って、このファイルに直接追記することも可能です。
