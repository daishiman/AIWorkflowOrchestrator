## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                             |
| -------- | -------------------------------------- |
| 1        | 実装結果を確認                         |
| 2        | `scripts/validate-skill.mjs` で検証    |
| 3        | モックが期待通りに動作するか確認       |
| 4        | パフォーマンスへの影響を測定           |
| 5        | 問題があれば implement-mock に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存   |
| 7        | 検証結果レポートを出力                 |

### 4.2 チェックリスト

| 項目           | 基準                     |
| -------------- | ------------------------ |
| 動作確認       | テストが期待通りに動作   |
| パフォーマンス | 許容範囲内               |
| 最適化         | Level3で最適化確認済み   |
| 記録完了       | log_usage.mjs で記録済み |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 全項目検証 | すべてのモックを検証すること   |
| 記録必須   | 成功・失敗に関わらず記録を保存 |
| 差し戻し可 | 問題があれば前Taskに差し戻す   |
