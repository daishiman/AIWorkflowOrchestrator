## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                   |
| -------- | -------------------------------------------- |
| 1        | コンテキスト分析結果を確認                   |
| 2        | `references/msw-integration-guide.md` を読込 |
| 3        | `assets/mock-handler-template.ts` を参照     |
| 4        | ハンドラーを作成                             |
| 5        | エラーケースをモック化                       |
| 6        | ネットワーク遅延をシミュレート               |
| 7        | 実装結果を出力                               |

### 4.2 チェックリスト

| 項目         | 基準                     |
| ------------ | ------------------------ |
| MSW設定      | 環境設定が完了           |
| ハンドラー   | 全エンドポイントをカバー |
| エラーモック | 4xx、5xxが実装           |
| 遅延設定     | 必要に応じて設定         |

### 4.3 ビジネスルール（制約）

| 制約     | 説明                          |
| -------- | ----------------------------- |
| 再利用性 | 汎用的なモックハンドラー設計  |
| 正確性   | 実API仕様に基づいたレスポンス |
| 動的値   | タイムスタンプやIDは動的生成  |
