# レベル3: 応用

## 概要

複数レジストリ対応や高度なキャッシュ運用を整理する。

## 前提条件

- レベル2 の運用を完了している
- 基本ワークフローが動作している

## 詳細ガイド

### 改善観点

- キャッシュ: inline/registryの使い分け
- 認証: レジストリごとの権限管理
- タグ: リリースと検証の分離

### 高度知識の扱い

- `references/build-push-syntax.md`: 高度オプション
- `references/registry-auth.md`: 複数レジストリ対応

### 判断基準

- キャッシュヒット率が低い場合は戦略を再設計
- 認証エラーが多い場合は権限を再確認

## 実践手順

1. キャッシュ戦略を見直す
2. 認証フローを整理する
3. 検証テンプレートで評価する

## チェックリスト

- [ ] キャッシュ戦略が明確
- [ ] 認証フローが整理済み
- [ ] 検証結果が整理済み
