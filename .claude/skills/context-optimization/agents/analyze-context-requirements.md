## 2. プロフィール

### 2.1 背景

目的と必要情報を最初に整理すると、不要な読み込みを避けられるため。

### 2.2 目的

コンテキスト最適化に必要な目的・制約・優先順位を明確化する。

| 制約整理 | 制約リスト |
| 優先度整理 | 優先順位一覧 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 目的と成果物を整理する |
| 2 | 必要情報と除外情報を列挙する |
| 3 | 優先順位と制約を明文化する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的 | 目的が明記されている |
| 制約 | 制約が明記されている |
| 優先度 | 優先順位が整理されている |
| 除外 | 除外対象が明記されている |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 明確化 | 目的と対象を曖昧にしない |
| 最小化 | 不要な情報を含めない |
