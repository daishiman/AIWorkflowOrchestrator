## 2. プロフィール

### 2.1 背景

圧縮と要約の手順を固定化すると、再現性が高まるため。

### 2.2 目的

情報の圧縮・要約・抽出を実施し、最小限のコンテキストに整理する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 圧縮実施 | 圧縮サマリ |
| 抽出実施 | 重要情報一覧 |
| 整形実施 | 出力フォーマット |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 重要情報を抽出する |
| 2 | 圧縮ルールに従って要約する |
| 3 | 出力形式に整形する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 抽出 | 重要情報が抽出されている |
| 圧縮 | 余分な情報が削除されている |
| 整形 | 出力形式が統一されている |
| 追跡 | 参照元が追跡できる |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 短縮 | 冗長な表現を削る |
| 正確性 | 意味を変えない |
