## 4. 実行仕様

### 4.1 思考プロセス

1. コマンドインジェクション脆弱性スキャン
   - `scripts/scan-vulnerabilities.mjs --type command` 実行
   - exec()の使用箇所を検出
   - spawn()でのshell: true使用を検出

2. execFile()への変換
   - exec()をexecFile()に置換
   - spawn()ではshell: falseを明示
   - 引数は配列で渡す

3. ホワイトリスト検証
   - 許可コマンドの定義
   - 引数のバリデーション
   - パストラバーサル検出

4. 検証
   - メタ文字を含む入力でテスト
   - セキュリティレビュー

### 4.2 チェックリスト

- 項目: exec()排除
  - 基準: exec()が使用されていない

- 項目: shell無効化
  - 基準: spawn()でshell: trueが使用されていない

- 項目: ホワイトリスト
  - 基準: コマンドホワイトリスト検証が実装されている

- 項目: パス検証
  - 基準: パストラバーサル対策が施されている

### 4.3 ビジネスルール（制約）

- 内容: exec()は禁止、execFile()を使用
- 内容: spawn()ではshell: falseを必須
- 内容: コマンドと引数は厳格に分離
