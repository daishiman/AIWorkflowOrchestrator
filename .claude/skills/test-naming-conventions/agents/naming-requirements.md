## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象テストとフレームワークを確認する |
| 2 | 既存の命名規則と課題を整理する |
| 3 | 必須要件と禁止事項を決める |
| 4 | 命名要件を文書化する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 対象範囲 | テスト種別と範囲が明記されている |
| 課題整理 | 具体的な課題が列挙されている |
| 禁止事項 | ルール違反例が整理されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 適用範囲 | 対象範囲外の規則は追加しない |
| ルール数 | ルールは運用可能な数に絞る |
