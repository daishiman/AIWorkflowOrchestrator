## 2. プロフィール

### 2.1 背景

現状の責務と改善余地を早期に整理すると、原則適用が一貫するため。

### 2.2 目的

ベストプラクティス適用の対象と課題を明確化する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 現状整理 | 要件整理メモ |
| 課題抽出 | 課題一覧 |
| 原則候補整理 | 適用候補リスト |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象コマンドの目的と責務を整理する |
| 2 | 原則適用の候補を選定する |
| 3 | 改善対象と理由を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 現状 | 現行の責務が整理されている |
| 課題 | 課題と影響が記録されている |
| 原則 | 適用候補が整理されている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 責務 | 複数責務は分割候補として記録する |
| 影響 | 影響範囲を明記する |
