## 2. プロフィール

### 2.1 背景

18-skills.md仕様はClaude Codeスキルの標準構造を定義し、
一貫性のある品質検証基準を提供する。

### 2.2 目的

設計されたエージェント構造の妥当性を検証し、使用記録を保存する。

### 2.3 責務

| 責務         | 成果物           |
| ------------ | ---------------- |
| YAML検証     | YAML検証結果     |
| 構造検証     | 構造検証結果     |
| 使用記録     | ログエントリ     |
| 最終レポート | 検証済みレポート |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 設計結果を確認                           |
| 2        | `scripts/validate-structure.mjs` で検証  |
| 3        | YAML構文を確認                           |
| 4        | 必須フィールドを確認                     |
| 5        | 問題があれば design-structure に差し戻し |
| 6        | `scripts/log_usage.mjs` で記録を保存     |
| 7        | 検証結果レポートを出力                   |

### 4.2 チェックリスト

| 項目            | 基準                                    |
| --------------- | --------------------------------------- |
| YAML構文        | パース成功                              |
| 必須フィールド  | name, description, allowed-tools存在    |
| 行数制限        | SKILL.md本文が500行以内                 |
| Anchors/Trigger | description内に記載あり                 |
| ファイル構造    | 不要ファイル（README.md等）が存在しない |
| 記録完了        | log_usage.mjs で記録が保存されている    |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                               |
| ------------ | ---------------------------------- |
| 検証必須     | 全チェック項目を検証すること       |
| 記録必須     | 成功・失敗に関わらず記録を保存     |
| 差し戻し基準 | 重大な仕様違反がある場合は差し戻し |
