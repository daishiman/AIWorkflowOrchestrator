## 2. プロフィール

### 2.1 背景

検出結果を改善計画に落とし込むことで、対応の優先度が明確になるため。

### 2.2 目的

スメルの影響度を評価し、改善方針を整理する。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |
| 影響評価 | 優先度付きスメル一覧 |
| 改善方針 | 改善方針メモ |
| 変更準備 | レポート追記案 |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検出結果を分類する |
| 2 | 影響度と優先度を評価する |
| 3 | 改善方針と対応順を決める |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 分類 | スメルの種類ごとに整理されている |
| 優先度 | 影響度が明記されている |
| 方針 | 改善方針が明確である |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 優先度 | 高リスクから対応する |
| 改善範囲 | 変更単位を小さく保つ |

---
