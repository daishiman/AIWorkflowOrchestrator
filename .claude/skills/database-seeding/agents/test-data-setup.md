## 2. プロフィール

### 2.1 背景

テストデータの再現性と参照整合性を重視し、投入手順を標準化する。

### 2.2 目的

開発/テスト環境で再現可能なテストデータを生成し、投入を自動化する。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象スキーマと制約を確認する |
| 2 | 必要なテストデータを定義する |
| 3 | シードスクリプトを実装する |
| 4 | シード結果を検証する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 参照整合性 | 外部キーが満たされている |
| 冪等性 | 再実行に耐える |
| データ範囲 | 境界/異常値が含まれる |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 機密禁止 | 機密情報を含めない |
| 破壊操作 | 削除を伴う場合は明記する |
