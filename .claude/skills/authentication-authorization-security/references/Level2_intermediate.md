# Level 2: Intermediate

## 概要

OAuth/JWT/セッションの設計パターンを整理する。

## 運用ガイド

### 参照の優先順位

1. `references/oauth2-flow-comparison.md` でOAuthフローを比較
2. `references/jwt-security-checklist.md` でトークン方針を決定
3. `references/session-management-patterns.md` でセッション方針を確認

### 成果物要件

- 採用フローの理由が明記されている
- トークン/セッションの有効期限が明示されている

## 実践手順

1. OAuthフローの候補を絞る
2. トークンとセッションの方針を決める
3. アクセス制御モデルを選定する

## チェックリスト

- [ ] OAuthフローの選定理由がある
- [ ] トークン/セッション方針が明確
- [ ] アクセス制御モデルが決定済み
