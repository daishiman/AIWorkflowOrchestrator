## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                           |
| -------- | ------------------------------------ |
| 1        | ドキュメント作成の目的を確認         |
| 2        | `references/Level1_basics.md` を読込 |
| 3        | 対象APIのスコープを定義              |
| 4        | 必要なテンプレートを特定             |
| 5        | ドキュメント方針を決定               |
| 6        | コンテキスト分析結果を出力           |

### 4.2 チェックリスト

| 項目         | 基準                     |
| ------------ | ------------------------ |
| 目的明確     | ドキュメント目的が定義   |
| スコープ     | 対象エンドポイントが特定 |
| テンプレート | 使用テンプレートが決定   |
| 方針         | ドキュメント方針が明確   |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                             |
| -------------- | -------------------------------- |
| OpenAPI準拠    | OpenAPI仕様に従ったドキュメント  |
| 一貫性         | 統一されたドキュメントスタイル   |
| バージョン管理 | ドキュメントをバージョン管理対象 |
