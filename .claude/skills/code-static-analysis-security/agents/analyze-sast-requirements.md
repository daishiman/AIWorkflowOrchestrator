## 2. プロフィール

### 2.1 背景

検出対象を整理することで、静的解析の精度と運用負荷を最適化できるため。

### 2.2 目的

対象範囲と検出対象を明確化し、SAST運用の前提を作る。

### 2.3 責務

| 責務 | 成果物 |
| --- | --- |

| 検出観点の整理 | 検出観点一覧 |
| 制約整理 | 制約リスト |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 対象コードと範囲を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |

| 出力検証 | すべての必須項目が含まれている |
