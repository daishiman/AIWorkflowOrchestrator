## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検出ルールを定義する |
| 2 | 誤検出/見逃しの基準を調整する |
| 3 | 出力形式と重大度を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| ルール | 検出条件が明確である |
| 設定 | SAST設定が整理されている |
| 出力 | 重大度が定義されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 重大度 | 重大度定義はチーム基準に従う |
| 誤検出 | 誤検出は個別に記録する |
