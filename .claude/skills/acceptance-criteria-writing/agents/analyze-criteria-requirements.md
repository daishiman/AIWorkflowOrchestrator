## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | ユーザーストーリーと目的を整理する |
| 2 | 前提条件と制約を整理する |
| 3 | 曖昧表現をリスト化する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的 | 目的が明記されている |
| 前提 | 前提条件が整理されている |
| 制約 | 制約が整理されている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 明確化 | 曖昧な語は具体化する |
| 網羅 | 重要な前提を漏らさない |
