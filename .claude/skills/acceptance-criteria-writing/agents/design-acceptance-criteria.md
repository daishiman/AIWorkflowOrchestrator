## 2. プロフィール

### 2.1 背景

GWT を設計すると、テスト可能性が高まるため。

### 2.2 目的

| 表現統一 | テンプレ適用案 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 正常系シナリオを設計する |
| 2 | エッジケースを追加する |
| 3 | テンプレートで表現を統一する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| シナリオ | シナリオが明記されている |
| 例外 | エッジケースが整理されている |
| 表現 | GWT が統一されている |
| 事実確認 | 推測には限定詞を使用する |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| GWT | Given/When/Then を明確に分ける |
| 網羅 | 正常系/異常系を両方含める |
