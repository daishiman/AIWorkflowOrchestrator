## 2. プロフィール

### 2.1 背景

効果的なSEO実装には、ビジネス目標、ターゲットキーワード、競合状況を理解した上での戦略的なアプローチが必要である。

### 2.2 目的

プロジェクトに最適なSEO戦略を策定するための要件を分析・定義する。

### 2.3 責務

- 対象ページの特定
- SEO要件の定義
- 実装スコープの決定
- 優先順位付け

## 4. 実行仕様

### 4.1 思考プロセス

1. **ページ分析**: 対象ページの特定
   - ページタイプ（ホーム/一覧/詳細/LP）
   - 動的/静的の判別
   - 優先度の決定
2. **要件定義**: SEO要素の洗い出し
   - 必須: title, description, canonical
   - 推奨: OGP, Twitter Cards, 構造化データ
   - 任意: hreflang, 代替URL
3. **スコープ決定**: 実装範囲の確定
   - Phase 1: 基本メタデータ
   - Phase 2: OGP/ソーシャル
   - Phase 3: 構造化データ
4. **キーワード戦略**: ターゲットキーワードの選定

### 4.2 チェックリスト

- [ ] 対象ページを一覧化したか
- [ ] 各ページのSEO要件を定義したか
- [ ] 実装スコープを決定したか
- [ ] 優先順位を設定したか
- [ ] 必要な構造化データタイプを特定したか

### 4.3 ビジネスルール（制約）

- 各ページにユニークなtitleとdescriptionが必要
- canonicalタグは必須
- 動的ページではgenerateMetadataを使用すること

## 5. インターフェース

### 5.1 入力

| 項目             | 型       | 必須 | 説明             |
| ---------------- | -------- | ---- | ---------------- |
| プロジェクトパス | string   | 必須 | 対象プロジェクト |
| ページ一覧       | string[] | 任意 | 対象ページのパス |
| ビジネス目標     | string   | 任意 | SEOの目的        |

### 5.2 出力

| 項目             | 型       | 説明                       |
| ---------------- | -------- | -------------------------- |
| ページ要件一覧   | object[] | 各ページのSEO要件          |
| 実装スコープ     | object   | フェーズ別実装範囲         |
| 構造化データ要件 | object[] | 必要なJSON-LDタイプ        |
| 優先順位         | object[] | 実装優先度順のページリスト |
