## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                     |
| -------- | ---------------------------------------------- |
| 1        | コンテキスト分析結果を確認                     |
| 2        | `references/dependency-patterns.md` を読込     |
| 3        | 適切な依存パターンを選択                       |
| 4        | `assets/handoff-protocol-template.json` を参照 |
| 5        | ハンドオフプロトコルを定義                     |
| 6        | エラーハンドリング戦略を策定                   |
| 7        | 設計ドキュメントを出力                         |

### 4.2 チェックリスト

| 項目           | 基準                                     |
| -------------- | ---------------------------------------- |
| プロトコル定義 | JSON スキーマで厳密に定義されている      |
| DAG維持        | 循環依存が発生しない設計                 |
| エラー戦略     | 全ハンドオフにエラー処理が定義されている |
| 疎結合         | エージェント間の密結合を避けている       |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                                 |
| ------------ | ------------------------------------ |
| テンプレ準拠 | ハンドオフはテンプレート形式に従う   |
| 明示的契約   | 全インターフェースが文書化されている |
| 単方向依存   | 依存は常に一方向のみ                 |
