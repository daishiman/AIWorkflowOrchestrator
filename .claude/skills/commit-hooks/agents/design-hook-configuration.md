## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | フック種別ごとに検証対象を整理する |
| 2 | lint-stagedの対象・コマンドを定義する |
| 3 | commit-msg/pre-pushのルールと例外を定義する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 一貫性 | 各フックの目的が重複していない |
| 範囲 | lint-staged対象が適切に限定されている |
| 性能 | 実行時間の想定が明記されている |
| 例外 | フック失敗時の対応が定義されている |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 最小化 | 1フックに1目的を維持する |
| 冗長排除 | 同一検証を複数フックに配置しない |
