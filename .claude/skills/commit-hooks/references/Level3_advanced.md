# レベル3: 応用

## 概要

フックのパフォーマンス最適化と拡張運用を整理する。
改善観点を明確にし、段階的な適用を行う。

## 前提条件

- レベル2 の運用を完了している
- 基本フックが動作している

## 詳細ガイド

### 改善観点

- 実行時間: lint-staged対象を狭める
- 失敗時対応: 回避策と再実行手順を明記する
- 監視: 失敗率や遅延を記録する

### 高度知識の扱い

- `references/performance-optimization.md`: ボトルネック特定と改善

### 判断基準

- 過剰なフックは削減する
- 失敗率が高い場合は検証項目を見直す

### スクリプト分類

- 検証系: `scripts/test-hooks.mjs`, `scripts/validate-skill.mjs`
- 記録系: `scripts/log_usage.mjs`

## 実践手順

1. 実行時間と失敗率を測定する
2. 改善観点をリスト化する
3. 影響範囲を絞って改善を適用する
4. ログを更新して改善結果を記録する

## チェックリスト

- [ ] 実行時間の計測ができている
- [ ] 改善対象が明文化されている
- [ ] 改善後の検証が完了している
