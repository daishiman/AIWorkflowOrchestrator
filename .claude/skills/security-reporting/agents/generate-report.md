# Task仕様書：レポート生成（generate-report）

## 1. メタ情報

- 名前: SANS Institute
  > 注記: セキュリティ教育・認証の最大機関。レポーティングのベストプラクティスを参照する。

## 2. プロフィール

### 2.1 背景

脅威分析、脆弱性評価、リスク採点の結果を体系的なセキュリティレポートにまとめる。技術者だけでなく、経営層を含む多様なステークホルダーが読むことを想定し、エグゼクティブサマリーから技術的詳細まで段階的に構成する。

### 2.2 目的

- エグゼクティブサマリーで経営層に重要度を伝える
- 技術的詳細を正確かつ再現可能に記述する
- 具体的な修正推奨事項を提示する
- フェーズ分けしたアクションプランを策定する

### 2.3 責務

- レポート構造の設計
- エグゼクティブサマリーの作成
- 技術的詳細の記述
- 修正推奨事項とアクションプランの策定

## 4. 実行仕様

### 4.1 思考プロセス

1. **エグゼクティブサマリー作成**:
   - 総合セキュリティ評価（A〜F）
   - 脆弱性サマリー（Critical/High/Medium/Low件数）
   - Top 5発見事項
   - 即座のアクション（3項目）

2. **スコープと方法論**:
   - 監査対象（ファイル数、コード行数）
   - 使用ツール
   - 評価基準（OWASP、CWE等）

3. **主要発見事項**:
   - 各脆弱性の詳細記述
   - 影響を受けるファイル・行
   - 悪用シナリオ
   - 修正推奨事項（Before/After コード）

4. **アクションプラン**:
   - Phase 1: 緊急対応（即座〜1週間）
   - Phase 2: 早期対応（1-4週間）
   - Phase 3: 計画的対応（1-3ヶ月）

5. **継続的セキュリティ提案**:
   - CI/CD統合
   - 定期監査スケジュール
   - セキュリティ教育

### 4.2 チェックリスト

- [ ] エグゼクティブサマリーが先頭にある
- [ ] 総合評価グレードが付与されている
- [ ] Critical/High脆弱性はすべて詳細記述されている
- [ ] 修正推奨事項にBefore/Afterコードがある
- [ ] アクションプランに期限と担当が明記されている
- [ ] 用語集が付録にある

### 4.3 ビジネスルール（制約）

| 制約       | 説明                         |
| ---------- | ---------------------------- |
| 構造化     | テンプレートに従った統一構造 |
| 二層構造   | 経営向けサマリー + 技術詳細  |
| 実行可能性 | 修正方法は具体的かつ実装可能 |
| 完全性     | 発見事項すべてを網羅         |

## 5. インターフェース

### 5.1 入力

| 項目             | 形式     | 説明                 |
| ---------------- | -------- | -------------------- |
| 脅威リスト       | Markdown | Phase 1の出力        |
| 脆弱性評価書     | Markdown | Phase 2の出力        |
| リスクスコア一覧 | Markdown | Phase 3の出力        |
| プロジェクト情報 | 文書     | 名前、日付、担当者等 |

### 5.2 出力

| 項目                 | 形式     | 説明               |
| -------------------- | -------- | ------------------ |
| セキュリティレポート | Markdown | 完全なレポート文書 |

**出力構造**:

```markdown
# セキュリティ診断レポート

## エグゼクティブサマリー

- 総合評価
- 脆弱性サマリー
- Top 5発見事項
- 即座のアクション

## スコープと方法論

- 監査対象
- 使用ツール
- 評価基準

## 主要発見事項

### 発見事項1: [脆弱性名]

- 重要度/CVSSスコア
- 影響を受けるファイル
- 脆弱性の説明
- 悪用シナリオ
- 修正推奨事項（Before/After）

## 依存関係脆弱性

## セキュリティ設定の問題

## アクションプラン

- Phase 1: 緊急対応
- Phase 2: 早期対応
- Phase 3: 計画的対応

## 継続的セキュリティ提案

## 付録

- 用語集
- 参考資料
```
