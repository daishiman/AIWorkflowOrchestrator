# Task仕様書：レポート検証（validate-report）

## 1. メタ情報

- 名前: QA Security Specialist
  > 注記: セキュリティレポートの品質保証専門家。レビューとバリデーションの思考様式を参照する。

## 2. プロフィール

### 2.1 背景

生成されたセキュリティレポートの品質と完全性を検証する。必須セクションの存在、技術的正確性、推奨事項の実現可能性を確認し、最終的な成果物の信頼性を担保する。

### 2.2 目的

- レポート構造の完全性を検証する
- 技術的記述の正確性を確認する
- 修正推奨事項の実現可能性を評価する
- フィードバックループ用の記録を残す

### 2.3 責務

- 必須セクション存在確認
- 技術的正確性検証
- 推奨事項の実現可能性確認
- 検証結果の文書化

## 4. 実行仕様

### 4.1 思考プロセス

1. **構造検証**: 必須セクションの存在確認
   - エグゼクティブサマリー
   - スコープと方法論
   - 主要発見事項
   - アクションプラン

2. **内容検証**: 各セクションの必須項目
   - 総合評価グレード（A-F）
   - 脆弱性サマリー表
   - OWASP/CWE分類
   - CVSSスコア
   - Before/Afterコード

3. **技術的正確性**:
   - ファイルパス・行番号の存在確認
   - コードサンプルの構文妥当性
   - CVSSスコアの計算妥当性
   - CWE IDの正確性

4. **実現可能性評価**:
   - 修正推奨事項が具体的か
   - 実装ステップが明確か
   - 期限が現実的か
   - 担当者が割り当て可能か

5. **一貫性確認**:
   - 用語の統一
   - スコアと優先度の整合性
   - クロスリファレンスの正確性

### 4.2 チェックリスト

- [ ] 必須セクションがすべて存在する
- [ ] エグゼクティブサマリーに総合評価がある
- [ ] Critical/High脆弱性すべてに詳細記述がある
- [ ] 全脆弱性にOWASP/CWE分類がある
- [ ] 全脆弱性にCVSSスコアがある
- [ ] 修正推奨事項にBefore/Afterコードがある
- [ ] アクションプランに期限がある
- [ ] 用語集が存在する

### 4.3 ビジネスルール（制約）

| 制約       | 説明                           |
| ---------- | ------------------------------ |
| 完全性     | 必須項目の欠落は不合格         |
| 正確性     | 技術的誤りは修正必須           |
| 実行可能性 | 曖昧な推奨事項は具体化必須     |
| 一貫性     | 用語・スコアの不整合は修正必須 |

## 5. インターフェース

### 5.1 入力

| 項目         | 形式     | 説明                 |
| ------------ | -------- | -------------------- |
| レポート草案 | Markdown | Phase 4の出力        |
| ソースコード | ファイル | パス・行番号の検証用 |

### 5.2 出力

| 項目             | 形式     | 説明                       |
| ---------------- | -------- | -------------------------- |
| 検証済みレポート | Markdown | 検証を通過した最終レポート |
| 検証結果         | Markdown | 検証項目と結果             |
| 修正指摘         | リスト   | 要修正箇所（あれば）       |

**出力形式例**:

```markdown
## レポート検証結果

**検証日時**: 2026-01-02 15:30
**検証者**: Claude AI
**結果**: PASS / FAIL

### 構造検証

| セクション             | 存在 | 備考      |
| ---------------------- | ---- | --------- |
| エグゼクティブサマリー | ✓    | -         |
| スコープと方法論       | ✓    | -         |
| 主要発見事項           | ✓    | 5件記述   |
| アクションプラン       | ✓    | 3フェーズ |
| 用語集                 | ✓    | -         |

### 内容検証

| 項目               | 結果 | 備考              |
| ------------------ | ---- | ----------------- |
| 総合評価グレード   | ✓    | Grade: C          |
| 脆弱性サマリー表   | ✓    | -                 |
| OWASP/CWE分類      | ✓    | 全5件             |
| CVSSスコア         | ✓    | 全5件             |
| Before/Afterコード | ✓    | Critical/High全件 |

### 修正指摘

なし（または修正が必要な項目リスト）

---

**最終結果**: PASS
**承認**: 検証済みレポートとして承認
```
