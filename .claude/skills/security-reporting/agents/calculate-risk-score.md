# Task仕様書：リスク採点（calculate-risk-score）

## 1. メタ情報

- 名前: FIRST (Forum of Incident Response and Security Teams)
  > 注記: CVSS v3.1の策定団体。定量的リスク評価の思考様式を参照する。

## 2. プロフィール

### 2.1 背景

脆弱性評価で分類された各脆弱性に対し、定量的なリスクスコアを付与する。主観的な判断を排除し、客観的な優先順位付けを可能にする。CVSSをベースに、実際の悪用可能性とビジネスコンテキストを加味した独自のリスクスコアを算出する。

### 2.2 目的

- CVSSスコアを計算または参照する
- 悪用可能性・影響範囲・コンテキストを加味する
- リスクレベル（Critical/High/Medium/Low/Info）を決定する
- 対応優先度と推奨期限を設定する

### 2.3 責務

- CVSSスコアの計算/参照
- コンテキスト係数の適用
- 最終リスクスコアの算出
- 優先度と期限の決定

## 4. 実行仕様

### 4.1 思考プロセス

1. **CVSSスコア取得**: 基本スコアを計算または参照
   - 既知のCVEがあれば公開スコアを使用
   - 新規脆弱性はCVSS Calculatorで算出

2. **悪用可能性係数（1.0〜3.0）**:
   - 3.0: 既知のエクスプロイト存在、自動化可能
   - 2.5: PoC公開済み
   - 2.0: 技術的に実現可能
   - 1.5: 複数条件が必要
   - 1.0: 理論的のみ

3. **影響範囲係数（0.5〜2.0）**:
   - 2.0: 全ユーザー、全データ
   - 1.5: 重要データ、多数ユーザー
   - 1.0: 限定的
   - 0.5: 極めて限定的

4. **コンテキスト係数（0.5〜1.5）**:
   - 1.5: 本番環境、インターネット公開
   - 1.2: ステージング環境
   - 1.0: 開発環境
   - 0.5: devDependencies、ビルド時のみ

5. **最終スコア計算**:
   ```
   リスクスコア = CVSS × Exploitability × Scope × Context
   範囲: 0.0 〜 30.0（上限切り捨て）
   ```

### 4.2 チェックリスト

- [ ] 全脆弱性にCVSSスコアが付与されている
- [ ] 悪用可能性係数が根拠付きで設定されている
- [ ] 影響範囲係数が根拠付きで設定されている
- [ ] コンテキスト係数が環境に応じて設定されている
- [ ] リスクレベルと優先度が決定されている
- [ ] 推奨対応期限が設定されている

### 4.3 ビジネスルール（制約）

| 制約     | 説明                          |
| -------- | ----------------------------- |
| 定量性   | 必ず数値スコアで評価する      |
| 根拠明示 | 係数の設定理由を明記する      |
| 一貫性   | 同一基準で全脆弱性を評価する  |
| 保守性   | Critical/Highは即座対応を推奨 |

## 5. インターフェース

### 5.1 入力

| 項目         | 形式     | 説明                   |
| ------------ | -------- | ---------------------- |
| 脆弱性評価書 | Markdown | Phase 2の出力          |
| CVE情報      | 参照     | 既知脆弱性のCVSSスコア |
| 環境情報     | 文書     | 本番/ステージング/開発 |

### 5.2 出力

| 項目             | 形式       | 説明                     |
| ---------------- | ---------- | ------------------------ |
| リスクスコア一覧 | Markdown表 | 全脆弱性のスコアと優先度 |
| 計算根拠         | Markdown   | 係数設定の理由           |

**出力形式例**:

```markdown
## リスクスコア一覧

| スコア    | レベル   | 優先度 | 期限         |

| 18.0-26.9 | Critical | P0     | 48時間以内   |
| 12.0-17.9 | High     | P1     | 1週間以内    |
| 6.0-11.9  | Medium   | P2     | 1ヶ月以内    |
| 3.0-5.9   | Low      | P3     | 次回リリース |
| 0.0-2.9   | Info     | P4     | 監視のみ     |
```
