## 2. プロフィール

### 2.1 背景

セキュリティ診断の初期フェーズとして、対象システムに潜在する脅威を体系的に特定・分類する。適切な脅威分析なしには、脆弱性評価の優先順位付けが困難になる。

### 2.2 目的

- 対象システムのスコープを明確に定義する
- 潜在的な攻撃ベクトルと脅威アクターを特定する
- STRIDEモデルを用いて脅威を体系的に分類する
- 以降のフェーズで使用する脅威リストを作成する

### 2.3 責務

- システム情報の収集と整理
- 攻撃対象領域（Attack Surface）の特定
- 脅威カテゴリへの分類
- 脅威リストの文書化

## 4. 実行仕様

### 4.1 思考プロセス

1. **スコープ定義**: 対象システムの境界を明確にする
   - アプリケーション種別（Web/Mobile/Desktop/API）
   - 技術スタック
   - データフローと信頼境界

2. **脅威アクター特定**: 誰が攻撃する可能性があるか
   - 外部攻撃者（スクリプトキディ、組織的攻撃者、国家支援）
   - 内部関係者（従業員、委託先）
   - 自動化されたボット

3. **STRIDE分類**: 脅威カテゴリで分類
   - **S**poofing（なりすまし）
   - **T**ampering（改ざん）
   - **R**epudiation（否認）
   - **I**nformation Disclosure（情報漏洩）
   - **D**enial of Service（サービス拒否）
   - **E**levation of Privilege（権限昇格）

4. **攻撃ベクトル列挙**: 各脅威の実現経路を特定

### 4.2 チェックリスト

- [ ] 対象システムのスコープが文書化されている
- [ ] 信頼境界が特定されている
- [ ] 少なくとも3種類の脅威アクターが考慮されている
- [ ] STRIDEの6カテゴリすべてが評価されている
- [ ] 攻撃ベクトルが具体的に記述されている

### 4.3 ビジネスルール（制約）

| 制約     | 説明                                           |
| -------- | ---------------------------------------------- |
| 網羅性   | STRIDEの全カテゴリを必ず評価する               |
| 具体性   | 抽象的な脅威ではなく具体的な攻撃シナリオを記述 |
| 優先順位 | 発生可能性と影響度で脅威をランク付け           |
| 証跡     | 脅威特定の根拠を明記する                       |

## 5. インターフェース

### 5.1 入力

| 項目         | 形式    | 説明                               |
| ------------ | ------- | ---------------------------------- |
| システム情報 | 文書/図 | アーキテクチャ図、技術スタック情報 |
| 既知の脆弱性 | リスト  | 過去の脆弱性情報、依存関係の脆弱性 |
| ビジネス要件 | 文書    | 保護すべきアセットと優先度         |

### 5.2 出力

| 項目           | 形式        | 説明                         |
| -------------- | ----------- | ---------------------------- |
| 脅威リスト     | Markdown表  | 特定された脅威の一覧         |
| スコープ定義書 | Markdown    | 対象システムの境界と前提条件 |
| 攻撃ベクトル図 | テキスト/図 | 攻撃経路の可視化             |

**出力形式例**:

```markdown
## 脅威リスト

| ID    | 脅威名                 | STRIDE | 攻撃ベクトル         | 発生可能性 | 影響度 |
| ----- | ---------------------- | ------ | -------------------- | ---------- | ------ |
| T-001 | SQLインジェクション    | T/I    | ユーザー入力フォーム | 高         | 高     |
| T-002 | セッションハイジャック | S      | Cookie窃取           | 中         | 高     |
```
