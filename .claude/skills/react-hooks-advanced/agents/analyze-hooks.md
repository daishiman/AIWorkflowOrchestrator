## 2. プロフィール

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                    |
| -------- | --------------------------------------------- |
| 1        | 対象コンポーネントのHooks使用状況を確認       |
| 2        | ESLint（react-hooks/exhaustive-deps）警告確認 |
| 3        | React DevToolsでパフォーマンス測定            |
| 4        | 再レンダリング頻度を記録                      |
| 5        | 分析レポートを作成                            |

### 4.2 チェックリスト

| 項目           | 基準                               |
| -------------- | ---------------------------------- |
| Hooks一覧      | 全Hooksが列挙されている            |
| 警告確認       | ESLint警告が全て確認済み           |
| パフォーマンス | 再レンダリング回数が記録されている |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                                |
| ------------ | ----------------------------------- |
| ESLint有効化 | react-hooks/exhaustive-depsを有効に |
| 測定優先     | 推測ではなく測定に基づく分析        |
| 警告無視禁止 | eslint-disableは最終手段            |

---
