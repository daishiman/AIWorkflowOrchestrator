# Logging & Observability 基礎知識

> **相対パス**: `references/basics.md`
> **読込条件**: 初回使用時

---

## オブザーバビリティとは

| 概念             | 説明                                           |
| ---------------- | ---------------------------------------------- |
| 可観測性         | 外部出力からシステム内部状態を推測できる能力   |
| 3本柱            | Logs, Metrics, Traces の統合による完全な可視化 |
| デバッガビリティ | 未知の問題を調査・解決できる能力               |

---

## ログレベル定義

| レベル | 数値 | 用途                     | 本番環境 |
| ------ | ---- | ------------------------ | -------- |
| FATAL  | 0    | システム停止を伴う障害   | 出力     |
| ERROR  | 1    | 即座の対応が必要なエラー | 出力     |
| WARN   | 2    | 注意が必要な状況         | 出力     |
| INFO   | 3    | 重要なビジネスイベント   | 出力     |
| DEBUG  | 4    | 開発時の詳細情報         | 抑制     |
| TRACE  | 5    | 最詳細なトレース情報     | 抑制     |

---

## 構造化ログの必須フィールド

| フィールド | 型       | 説明                          |
| ---------- | -------- | ----------------------------- |
| timestamp  | ISO 8601 | イベント発生時刻              |
| level      | string   | ログレベル                    |
| message    | string   | 人間可読メッセージ            |
| service    | string   | サービス名                    |
| trace_id   | string   | 分散トレース ID（オプション） |
| span_id    | string   | スパン ID（オプション）       |

---

## ログライブラリ比較 (Node.js)

| ライブラリ | 特徴                   | ユースケース      |
| ---------- | ---------------------- | ----------------- |
| Pino       | 高速、低オーバーヘッド | 高スループットAPI |
| Winston    | 柔軟、多機能           | 複雑なログ要件    |
| Bunyan     | JSON特化、シンプル     | マイクロサービス  |

---

## メトリクスの種類

| 種類      | 説明           | 例                  |
| --------- | -------------- | ------------------- |
| Counter   | 単調増加する値 | リクエスト数        |
| Gauge     | 上下する現在値 | メモリ使用量        |
| Histogram | 値の分布       | レスポンスタイム    |
| Summary   | パーセンタイル | p50, p99 レイテンシ |

---

## 分散トレーシング用語

| 用語        | 説明                           |
| ----------- | ------------------------------ |
| Trace       | 1リクエストの全体フロー        |
| Span        | Trace 内の個別操作             |
| Context     | サービス間で伝播するメタデータ |
| Propagation | Trace コンテキストの伝達方法   |

---

## 保持期間ガイドライン

| データ種別   | 推奨期間  | 理由               |
| ------------ | --------- | ------------------ |
| エラーログ   | 30-90日   | インシデント調査   |
| アクセスログ | 7-30日    | デバッグ・監査     |
| メトリクス   | 13-15ヶ月 | YoY 比較           |
| トレース     | 7-14日    | パフォーマンス分析 |
