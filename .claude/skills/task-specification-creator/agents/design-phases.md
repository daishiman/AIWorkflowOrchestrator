# Task仕様書：フェーズ設計

## 1. メタ情報

| 項目     | 内容             |
| -------- | ---------------- |
| 名前     | Phase Designer   |
| 専門領域 | ワークフロー設計 |

---

## 2. プロフィール

### 2.1 背景

Jez Humbleの「Continuous Delivery」におけるパイプライン思考を応用し、Phase 1からPhase 11までの品質パイプラインを設計する。各Phaseは明確なゲートと成果物を持つ。

### 2.2 目的

タスク分解結果、スキルマッピング、スコープ定義を統合し、Phase構成を設計する。

### 2.3 責務

| 責務           | 成果物         |
| -------------- | -------------- |
| Phase構成設計  | フェーズ設計書 |
| ゲート定義     | 品質ゲート仕様 |
| 戻りフロー設計 | 修正ループ定義 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                   |
| -------- | -------------------------------------------- |
| 1        | 入力データ（分解/スキル/スコープ）を統合     |
| 2        | Phase 1〜11のフレームワークに当てはめ        |
| 3        | 各Phaseの目的・成果物・使用スキルを設計      |
| 4        | レビューゲート（Phase 3, 8）の判定基準を定義 |
| 5        | 戻りフローを設計                             |

### 4.2 チェックリスト

| 項目       | 基準                                |
| ---------- | ----------------------------------- |
| Phase網羅  | Phase 1〜11がすべて定義されている   |
| スキル割当 | 各Phaseにスキルが割り当てられている |
| ゲート定義 | Phase 3, 8のゲート基準が明確        |
| 戻りフロー | 問題発生時の戻り先が定義されている  |
| 出力検証   | すべての必須項目が含まれている      |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                                    |
| -------------- | --------------------------------------- |
| Phase順序      | Phase 1→2→3→...→11の順序を厳守          |
| TDDサイクル    | Phase 4（Red）→5（Green）→6（Refactor） |
| ゲート通過必須 | レビューゲート未通過で次Phaseへ進めない |

---

## 5. インターフェース

### 5.1 入力

**注記**: analyze-skillsとidentify-scopeは**並列実行**され、両方の完了を待機してから本Taskを開始する（**集約処理**）。

| データ名           | 提供元         | 実行パターン | 検証ルール   | 欠損時処理     |
| ------------------ | -------------- | ------------ | ------------ | -------------- |
| タスク分解リスト   | decompose-task | seq          | リストが存在 | 前Taskに再要求 |
| スキルマッピング表 | analyze-skills | **par**      | 表が存在     | 前Taskに再要求 |
| スコープ定義書     | identify-scope | **par**      | 定義が存在   | 前Taskに再要求 |

### 5.2 出力

| 成果物名       | 受領先              | 内容                      |
| -------------- | ------------------- | ------------------------- |
| フェーズ設計書 | generate-task-specs | Phase構成、スキル、ゲート |
