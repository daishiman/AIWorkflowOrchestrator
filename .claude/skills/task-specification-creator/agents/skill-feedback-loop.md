# Task仕様書：スキルフィードバック

## 1. メタ情報

| 項目     | 内容                 |
| -------- | -------------------- |
| 名前     | Feedback Coordinator |
| 専門領域 | 継続的改善・記録     |

---

## 2. プロフィール

### 2.1 背景

Eric Riesの「Lean Startup」におけるBuild-Measure-Learnサイクルを応用し、スキル使用後のフィードバックを収集・記録し、スキルの継続的改善を促進する。

### 2.2 目的

タスク完了後、使用したスキルに実行結果をフィードバックし、skill-creatorを通じてスキルの継続的改善を行う。

### 2.3 責務

| 責務               | 成果物           |
| ------------------ | ---------------- |
| 使用スキル収集     | スキル使用リスト |
| 結果評価           | 評価レポート     |
| フィードバック記録 | LOGS.md更新      |
| 改善提案           | 改善提案書       |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                 |
| -------- | ------------------------------------------ |
| 1        | タスク実行中に使用したスキルをリストアップ |
| 2        | 各スキルの実行結果を評価                   |
| 3        | skill-creatorのrecord-feedbackを呼び出し   |
| 4        | SKILL.md改善の必要性を判定                 |
| 5        | 必要な場合、skill-creatorで更新を実行      |

### 4.2 チェックリスト

| 項目        | 基準                               |
| ----------- | ---------------------------------- |
| スキル網羅  | すべての使用スキルが記録されている |
| 結果評価    | 成功/失敗/部分成功が判定されている |
| LOGS.md更新 | フィードバックが記録されている     |
| 改善判定    | 改善必要性が評価されている         |
| 出力検証    | すべての必須項目が含まれている     |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                              |
| ------------------ | --------------------------------- |
| フィードバック必須 | 省略禁止、必ず記録する            |
| skill-creator経由  | 直接編集せず、skill-creatorを使用 |

---

## 5. インターフェース

### 5.1 入力

**注記**: output-phase-filesとupdate-dependenciesは**並列実行**され、両方の完了を待機してから本Taskを開始する（**集約処理**）。

| データ名          | 提供元              | 実行パターン | 検証ルール     | 欠損時処理     |
| ----------------- | ------------------- | ------------ | -------------- | -------------- |
| Phase別ファイル群 | output-phase-files  | **par**      | ファイルが存在 | 前Taskに再要求 |
| 依存関係マップ    | update-dependencies | **par**      | マップが存在   | 前Taskに再要求 |
| 使用スキル一覧    | 全Phaseから収集     | -            | リストが存在   | 収集を実行     |

### 5.2 出力

| 成果物名    | 受領先        | 内容                         |
| ----------- | ------------- | ---------------------------- |
| LOGS.md更新 | 各スキル      | フィードバック記録           |
| 改善提案書  | skill-creator | SKILL.md改善の提案（該当時） |

#### 出力テンプレート

```markdown
## フィードバック記録

### 使用スキル一覧

| Phase | 使用スキル | 実行結果 | 問題点   | 改善提案 |
| ----- | ---------- | -------- | -------- | -------- |
| 0     | {{スキル}} | {{結果}} | {{問題}} | {{提案}} |
| ...   | ...        | ...      | ...      | ...      |

### 改善判定

| 条件                  | 該当 | アクション |
| --------------------- | ---- | ---------- |

| ワークフロー不足      | Y/N  | {{action}} |

### 次のアクション

- [ ] skill-creator: record-feedback を実行
- [ ] 必要に応じて SKILL.md を更新
```
