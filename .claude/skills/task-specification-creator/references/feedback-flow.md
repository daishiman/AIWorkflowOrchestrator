# スキルフィードバックフロー

タスク完了後に使用したスキルへフィードバックを反映するためのプロセス定義。

## フロー概要

```
┌──────────────────────────────────────────────────────────────┐
│                    タスク実行フェーズ                         │
├──────────────────────────────────────────────────────────────┤
│  Phase 1 → Phase 2 → ... → Phase 10 → Phase 11              │
│      ↓         ↓               ↓                            │
│  [スキル使用記録を蓄積]                                       │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│                    フィードバック収集                         │
├──────────────────────────────────────────────────────────────┤
│  1. 使用スキル一覧の整理                                      │
│  2. 各スキルの実行結果評価                                    │
│  3. 問題点・改善点の特定                                      │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────┐
│                    skill-creator 呼び出し                     │
├──────────────────────────────────────────────────────────────┤
│  Task: record-feedback                                       │
│  入力: 使用スキル、結果、問題点、改善提案                      │
└──────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────┬────────────────────────────┐
│         LOGS.md 更新            │     SKILL.md 改善判定      │
├─────────────────────────────────┼────────────────────────────┤
│ - 実行日時                      │ [改善が必要?]               │
│ - コンテキスト                  │   ├── Yes → SKILL.md更新   │
│ - 結果                          │   └── No → 完了            │
│ - 発見事項                      │                            │
└─────────────────────────────────┴────────────────────────────┘
```

---

## ステップ詳細

### Step 1: 使用スキル記録

各Phaseで使用したスキルを以下の形式で記録:

```markdown
## 使用スキル記録

| Phase | スキル名                 | 開始時刻 | 終了時刻 | 結果     |
| ----- | ------------------------ | -------- | -------- | -------- |
| 1     | requirements-engineering | 10:00    | 10:30    | 成功     |
| 2     | architectural-patterns   | 10:35    | 11:00    | 成功     |
| 2     | domain-modeling          | 11:00    | 11:20    | 成功     |
| 4     | tdd-principles           | 11:25    | 12:00    | 部分成功 |
| ...   | ...                      | ...      | ...      | ...      |
```

### Step 2: 結果評価

各スキルの実行結果を以下の基準で評価:

| 評価     | 基準                                           |
| -------- | ---------------------------------------------- |
| 成功     | スキルの指示通りに実行し、期待通りの成果を得た |
| 部分成功 | 実行できたが、一部期待と異なる結果があった     |
| 失敗     | スキルの指示が不明確で実行できなかった         |
| 該当なし | スキルの適用が不適切だった                     |

### Step 3: 問題点特定

以下の観点で問題点を洗い出す:

1. **ワークフローの問題**
   - Phase/アクションの順序が不適切
   - 必要なステップが欠落
   - 不要なステップが存在

2. **説明の問題**
   - 指示が曖昧で解釈が分かれる
   - 前提条件が明記されていない
   - 成果物の形式が不明確

3. **Trigger条件の問題**
   - スキル選定時に迷った
   - 他のスキルとの境界が不明確

4. **リソースの問題**
   - agents/の説明が不足
   - references/の情報が古い
   - assets/のテンプレートが不適合

### Step 4: 改善提案作成

問題点に対する具体的な改善提案を作成:

```markdown
## 改善提案

### スキル: tdd-principles

**問題**: テスト粒度のガイドが不足しており、大きすぎるテストを書いてしまった

**改善案**:

1. ベストプラクティスに「1テスト1アサーション」を追加
2. references/に「テスト粒度ガイド」を追加
3. assets/にテストテンプレートを追加

**優先度**: 高（3回以上同じ問題発生）
```

### Step 5: skill-creator呼び出し

`skill-creator`スキルの`record-feedback`タスクを実行:

```
[skill-creator を使用]

Task: record-feedback

入力:
- スキル: tdd-principles
- 結果: 部分成功
- Phase: 3
- 問題点: テスト粒度のガイド不足
- 改善提案:
  1. ベストプラクティス追加
  2. テスト粒度ガイド追加
  3. テストテンプレート追加
```

### Step 6: LOGS.md更新

`skill-creator`が各スキルのLOGS.mdに追記:

```markdown
## 2024-01-15 - タスク実行フィードバック

### コンテキスト

- タスク: ユーザー認証機能実装
- Phase: 4（テスト作成）
- 実行者: Claude Code

### 結果

- ステータス: 部分成功
- 所要時間: 35分

### 発見事項

- **良かった点**: Red-Green-Refactorサイクルの説明は明確
- **問題点**: テスト粒度のガイドが不足
- **改善提案**: テスト粒度ガイドの追加

### 次のアクション

- [ ] references/test-granularity.md を追加
- [ ] ベストプラクティスに「1テスト1アサーション」を追加
```

### Step 7: SKILL.md改善判定

以下の条件でSKILL.md改善を判定:

| 条件                  | 判定 | アクション               |
| --------------------- | ---- | ------------------------ |
| 同じ問題が3回以上発生 | 改善 | ベストプラクティスに追加 |
| ワークフロー不足      | 改善 | Phase/アクション追加     |
| Trigger選定ミスが多発 | 改善 | Trigger条件見直し        |
| 成果物形式が不統一    | 改善 | テンプレート追加         |
| 上記以外              | 保留 | LOGS.mdに記録のみ        |

## 自動化

### フィードバック記録スクリプト

```bash
node .claude/skills/task-specification-creator/scripts/log_usage.mjs \
  --skill "tdd-principles" \
  --result "partial-success" \
  --phase "3" \
  --issue "テスト粒度ガイド不足" \
  --proposal "テスト粒度ガイド追加"
```

### 改善判定スクリプト

```bash
node .claude/skills/skill-creator/scripts/check_improvement_needed.mjs \
  --skill "tdd-principles"
```

---

## 重要原則

1. **フィードバックは必須**: 省略せず必ず記録する
2. **具体的な記述**: 抽象的な問題点ではなく、具体的な状況を記録
3. **改善提案の付与**: 問題点には必ず改善提案を付ける
4. **skill-creatorを経由**: 直接編集せず、skill-creatorを通じて更新
5. **継続的改善**: フィードバックサイクルを回して品質向上を図る
