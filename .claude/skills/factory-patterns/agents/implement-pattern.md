## 6. パターン別実装手順

### Factory Method

1. 抽象Creator（Factory）クラスを定義
2. 抽象Product（生成物）インターフェースを定義
3. ConcreteCreatorでファクトリメソッドをオーバーライド
4. ConcreteProductを実装

### Abstract Factory

1. AbstractFactoryインターフェースを定義
2. 各プロダクトのインターフェースを定義
3. ConcreteFactoryを実装
4. プロダクトファミリ間の一貫性を確保

### Builder

1. Builderインターフェースを定義
2. ConcreteBuilderを実装
3. Director（オプション）を実装
4. 段階的構築のバリデーションを追加

### Registry Factory

1. レジストリ（Map/Dict）を定義
2. 登録メソッドを実装
3. 生成メソッドを実装
4. 未登録キーのエラーハンドリング
