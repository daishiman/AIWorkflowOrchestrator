## Entity vs Value Object

### 判断基準

| 質問                   | Entity | Value Object |
| ---------------------- | ------ | ------------ |
| 同一性の追跡が必要か   | Yes    | No           |
| ライフサイクルがあるか | Yes    | No           |
| 属性が変わっても同じか | Yes    | No           |
| 交換可能か             | No     | Yes          |

## Entity設計

### 識別子の設計

| 種類     | 例               | 使用場面       |
| -------- | ---------------- | -------------- |
| UUID     | 550e8400-e29b... | 分散システム   |
| ULID     | 01ARZ3NDEK...    | ソート可能     |
| 連番     | 1, 2, 3...       | 単純なシステム |
| 自然キー | ISBN-978-...     | 外部識別子     |

---

## Value Object設計

### 設計原則

| 原則     | 実装方法             |
| -------- | -------------------- |
| 不変性   | readonlyフィールド   |
| 自己検証 | ファクトリメソッド   |
| 等価性   | equals()メソッド     |
| 値の変換 | 新インスタンスを返す |

---

## 不変条件の実装

### パターン

| パターン     | 説明               | 例               |
| ------------ | ------------------ | ---------------- |
| 生成時検証   | コンストラクタで   | ファクトリ       |
| 操作時検証   | メソッド内で       | ガード節         |
| 状態遷移検証 | 状態変更を制限     | ステートパターン |
