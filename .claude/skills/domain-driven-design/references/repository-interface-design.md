## 集約専用リポジトリ

### 設計原則

| 原則           | 説明                   |
| -------------- | ---------------------- |
| 集約ルート単位 | 内部Entityは扱わない   |
| 完全な集約返却 | 部分的ロードはしない   |
| ドメイン言語   | 技術用語を避ける       |

---

## 検索パターン

| パターン     | 説明         | 使用場面     |
| ------------ | ------------ | ------------ |
| 仕様パターン | 複雑な条件   | 動的検索     |
| CQRS         | 読み書き分離 | 複雑なクエリ |

---

## 実装ガイドライン

### やるべきこと

| 項目             | 説明               |
| ---------------- | ------------------ |
| 集約の完全ロード | 遅延ロードは避ける |
| トランザクション | save()で完結       |
| ID生成           | nextId()提供       |

### 避けるべきこと

| 項目             | 理由               |
| ---------------- | ------------------ |
| 部分更新メソッド | 整合性が壊れる     |
| 複雑な検索       | 読み取り専用で分離 |
| 技術的な命名     | ドメイン言語を使う |
