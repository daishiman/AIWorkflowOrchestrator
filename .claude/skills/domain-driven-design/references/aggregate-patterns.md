# 集約設計パターン

> **相対パス**: `references/aggregate-patterns.md`
> **読込条件**: 集約設計時に参照

---

## 集約境界の決定

### 判断基準

| 基準                 | 説明                       |
| -------------------- | -------------------------- |
| トランザクション整合性 | 同時に変更すべきものを含む |
| 不変条件             | 常に満たすべきルール       |
| ライフサイクル       | 生成・削除が同時           |

### アンチパターン

| アンチパターン   | 問題点           | 解決策         |
| ---------------- | ---------------- | -------------- |
| 巨大集約         | パフォーマンス   | 分割してID参照 |
| 集約間の直接参照 | 強結合           | ID参照に変更   |
| 貧血集約         | ロジック散逸     | 振る舞いを内包 |

---

## 集約間の連携

### パターン

| パターン         | 使用場面       | 例             |
| ---------------- | -------------- | -------------- |
| ID参照           | 集約間の関連   | customerId     |
| ドメインイベント | 集約間の通知   | OrderPlaced    |
| 結果整合性       | 非同期での整合 | イベントハンドラ |

## リポジトリ設計

### 基本メソッド

| メソッド   | 責務             |
| ---------- | ---------------- |
| findById   | IDで取得         |
| save       | 保存（新規/更新）|
| delete     | 削除             |
| nextId     | ID生成           |
