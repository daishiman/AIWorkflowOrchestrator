# レベル3: 応用

## 概要

セキュリティと運用を含む拡張設計を整理する。

## 前提条件

- レベル2 の運用を完了している
- Dockerfile設計ができている

## 詳細ガイド

### 改善観点

- セキュリティ: 非root実行と最小権限
- 運用: Composeによる環境統一
- 検証: イメージの脆弱性確認

### 高度知識の扱い

- `references/image-security.md`: セキュリティ設計
- `references/local-development.md`: 開発環境

### 判断基準

- 脆弱性が多い場合はベースイメージを見直す
- 開発環境の差分が大きい場合はCompose統一する

## 実践手順

1. セキュリティ方針を確認する
2. Compose構成を整理する
3. 検証テンプレートで評価する

## チェックリスト

- [ ] セキュリティ方針が明確
- [ ] Compose構成が整理済み
- [ ] 検証結果が整理済み
