## 2. プロフィール

### 2.1 背景

electron-builderとelectron-updaterを使用した自動更新システムの実装パターンを体系化。

### 2.2 目的

electron-updaterを使用した安全で信頼性の高い自動更新機能を実装する。

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                     |
| -------- | ---------------------------------------------- |
| 1        | 既存のプロジェクト構成を確認                   |
| 2        | electron-updater依存関係をインストール         |
| 3        | autoUpdater初期化コードを実装                  |
| 4        | 更新検知・ダウンロード・インストールフロー実装 |
| 5        | エラーハンドリングとログ記録を追加             |
| 6        | ユーザー通知UIを実装                           |
| 7        | テスト環境での動作確認                         |

### 4.2 チェックリスト

| 項目               | 基準                                             |
| ------------------ | ------------------------------------------------ |
| セキュリティ       | コード署名と更新パッケージの検証が実装されている |
| ユーザー体験       | 更新の進捗がユーザーに明確に表示される           |
| エラー処理         | ネットワークエラー等すべてのエラーケースに対処   |
| ロールバック可能性 | 問題発生時に前バージョンに戻せる                 |
| 非侵入的           | ユーザーの作業を中断しない                       |

### 4.3 ビジネスルール（制約）

| 制約                 | 説明                                                   |
| -------------------- | ------------------------------------------------------ |
| 自動インストール禁止 | 更新のインストールは必ずユーザー確認を取る             |
| 署名必須             | すべての更新パッケージにコード署名が必要               |
| バージョン管理       | Semantic Versioningに従う                              |
| ダウングレード禁止   | 新しいバージョンから古いバージョンへの更新は許可しない |

## 5. インターフェース

### 5.1 入力

| データ名             | 提供元   | 検証ルール                   | 欠損時処理              |
| -------------------- | -------- | ---------------------------- | ----------------------- |
| アプリケーション設定 | ユーザー | package.jsonに更新設定が存在 | 設定作成を提案          |
| 更新サーバーURL      | ユーザー | 有効なHTTPS URL              | ローカルテスト用URL提示 |

### 5.2 出力

| 成果物名              | 受領先   | 内容                               |
| --------------------- | -------- | ---------------------------------- |
| autoUpdater実装コード | ユーザー | メインプロセスでの自動更新ロジック |
| 更新UI実装            | ユーザー | レンダラープロセスでの進捗表示     |

#### 出力テンプレート

使用テンプレート: `assets/update-server.ts`

```typescript
// メインプロセス (main.ts)
import { autoUpdater } from "electron-updater";

function setupAutoUpdater() {
  // 更新チェック設定
  autoUpdater.checkForUpdatesAndNotify();

  // イベントハンドラー
  autoUpdater.on("checking-for-update", () => {
    // 更新確認中
  });

  autoUpdater.on("update-available", (info) => {
    // 更新が利用可能
  });

  autoUpdater.on("update-downloaded", (info) => {
    // ダウンロード完了、ユーザーに確認
  });

  autoUpdater.on("error", (err) => {
    // エラーハンドリング
  });
}
```
