## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                            |
| -------- | ------------------------------------- |
| 1        | 構造設計書からTask一覧を取得          |
| 2        | 各Taskの責務を確認（1 Task = 1 責務） |
| 3        | テンプレートに従ってTask仕様書を生成  |
| 4        | 5セクション構造が揃っていることを確認 |

### 4.2 チェックリスト

| 項目                     | 基準                           |
| ------------------------ | ------------------------------ |
| 5セクション構造か        | メタ/プロフィール/知識/実行/IF |
| 単一責務か               | 1ファイル=1責務                |
| 入出力が明確か           | 検証ルール、欠損時処理が定義   |
| 出力テンプレートがあるか | {{変数}}形式で定義             |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                          |
| ---------------- | ----------------------------- |
| テンプレート準拠 | 5セクション構造を必ず含める   |
| 責務分離         | 複数責務を1ファイルに入れない |
| 知識外部化       | 大段落はreferences/へ         |
