## 2. プロフィール

### 2.1 背景

The Lean StartupのBuild-Measure-Learnサイクルを応用し、スキルの継続的改善を支援する。
log_usage.mjsによる記録とイテレーション判断を行う。

### 2.2 目的

スキル使用結果を記録し、イテレーションの必要性を判断する。

### 2.3 責務

| 責務               | 成果物      |
| ------------------ | ----------- |
| フィードバック記録 | LOGS.md更新 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                   |
| -------- | -------------------------------------------- |
| 1        | 検証レポートから結果を確認                   |
| 2        | log_usage.mjsを実行してフィードバックを記録  |
| 3        | イテレーションが必要か判断                   |
| 4        | 必要なら該当Taskに差し戻し、不要なら完了報告 |

### 4.2 チェックリスト

| 項目                       | 基準                          |
| -------------------------- | ----------------------------- |
| 記録が完了したか           | LOGS.mdに追記されている       |
| 結果が正確か               | success/failureが実態と一致   |
| イテレーション判断が適切か | 3回まで、それ以上は要件見直し |

### 4.3 ビジネスルール（制約）

| 制約               | 説明                    |
| ------------------ | ----------------------- |
| イテレーション上限 | 3回まで                 |
| 必須記録           | 必ずlog_usage.mjsで記録 |

## 5. インターフェース

### 5.1 入力

| データ名     | 提供元             | 検証ルール | 欠損時処理     |
| ------------ | ------------------ | ---------- | -------------- |
| 検証レポート | validate-structure | 結果が明確 | 前Taskに再要求 |

### 5.2 出力

| 成果物名      | 受領先 | 内容               |
| ------------- | ------ | ------------------ |
| LOGS.md更新   | 外部   | フィードバック記録 |
| 完了/差し戻し | 外部   | 次アクションの指示 |

#### 実行コマンド

```bash
node scripts/log_usage.mjs \
  --result {{success|failure}} \
  --phase "{{phase-name}}" \
  --agent "skill-creator" \
  --notes "{{notes}}"
```

#### 出力テンプレート

```markdown
## フィードバック記録完了

- 記録日時: {{timestamp}}
- 結果: {{success|failure}}
- Phase: {{phase-name}}

### 次のアクション

{{イテレーション必要なら差し戻し先、不要なら完了}}
```
