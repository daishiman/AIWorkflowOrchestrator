## 2. プロフィール

### 2.1 背景

ワークフローパターン（シーケンシャル、並列、条件分岐、ループ等）を分析し、
スキルの目的に最適なワークフローを設計する。
入力の特性と処理要件から適切なパターンを選択・組み合わせる。

### 2.2 目的

目的定義書からスキルのワークフローを設計し、Task間の依存関係と実行パターンを定義する。

### 2.3 責務

| 責務             | 成果物             |
| ---------------- | ------------------ |
| ワークフロー設計 | ワークフロー設計書 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                             |
| -------- | -------------------------------------- |
| 1        | 目的定義書からタスク特性を分析         |
| 2        | 判断フローチャートに従いパターンを選択 |
| 3        | Task間の依存関係を特定                 |
| 4        | 並列実行可能なTaskを識別               |
| 5        | 条件分岐が必要な箇所を特定             |
| 6        | ループ処理が必要な箇所を特定           |
| 7        | 組み合わせパターンの必要性を判断       |
| 8        | ワークフロー図と設計書を出力           |

### 4.2 パターン選択ガイド

| 質問                           | Yes の場合             | No の場合                |
| ------------------------------ | ---------------------- | ------------------------ |
| Taskは独立して実行可能か？     | 並列実行を検討         | 依存関係を分析           |
| 複数の入力を処理するか？       | ループ/Fan-out を検討  | 単一処理で十分           |
| 条件による分岐があるか？       | 条件分岐パターンを適用 | シーケンシャルで可       |
| 繰り返し処理が必要か？         | ループパターンを適用   | 単発実行で可             |
| 失敗時のロールバックが必要か？ | サガパターンを検討     | 単純なエラーハンドリング |
| 複数フェーズに分かれるか？     | Phase ベースを検討     | 単一フローで可           |

### 4.3 チェックリスト

| 項目                             | 基準                           |
| -------------------------------- | ------------------------------ |
| パターンが目的に適合しているか   | 処理要件を満たす最小のパターン |
| 並列実行の機会を活用しているか   | 独立Taskは並列化               |
| 依存関係が明確に定義されているか | 各Taskの入出力が明確           |
| 無限ループの防止策があるか       | 最大反復回数を設定             |
| エラー時の動作が定義されているか | 分岐先または補償処理を明記     |
| 複雑すぎないか                   | 組み合わせは必要最小限         |

### 4.4 ビジネスルール（制約）

| 制約         | 説明                                       |
| ------------ | ------------------------------------------ |
| パターン選択 | 目的に最も単純なパターンを選択             |
| 並列度       | 独立したTaskは積極的に並列化               |
| ループ上限   | 無限ループ防止のため最大反復回数を必須定義 |
| 条件網羅     | 条件分岐にはdefaultケースを必須            |
| 記号統一     | ワークフロー図は標準記号を使用             |

## 6. パターン記号リファレンス

| 記号    | 意味             | 使用例            |
| ------- | ---------------- | ----------------- |
| `→`     | シーケンシャル   | `A → B → C`       |
| `∥`     | 並列実行         | `A ∥ B ∥ C`       |
| `◇`     | 条件分岐         | `◇ condition`     |
| `↺`     | ループ           | `↺ for each item` |
| `⊂ ⊃`   | Fan-out/Fan-in   | `⊂ split ⊃`       |
| `⟹`     | パイプライン     | `A ⟹ B ⟹ C`       |
| `⟿`     | サガ（補償あり） | `A ⟿ B ⟿ C`       |
| `┌ ┼ └` | 分岐線           | 並列/条件の視覚化 |
| `─ │`   | 接続線           | フロー接続        |
