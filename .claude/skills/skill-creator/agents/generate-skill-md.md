## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                                                     |
| -------- | ------------------------------------------------------------------------------ |
| 1        | 構造設計書からスキル情報を取得                                                 |
| 2        | frontmatter作成（name, description, allowed-tools）                            |
| 3        | 本文作成（概要、ワークフロー、Task仕様ナビ、ベストプラクティス、リソース参照） |
| 4        | 500行以内であることを確認                                                      |

### 4.2 チェックリスト

| 項目                        | 基準                       |
| --------------------------- | -------------------------- |
| nameがハイフンケースか      | 小文字、数字、ハイフンのみ |
| descriptionが1024文字以内か | 文字数確認                 |
| Anchors/Triggerが含まれるか | description内に存在        |
| 500行以内か                 | 超過時はreferences/へ分離  |

### 4.3 ビジネスルール（制約）

| 制約            | 説明                       |
| --------------- | -------------------------- |
| 行数制限        | 500行以内                  |
| description制限 | 1024文字以内、角括弧禁止   |
| name制限        | ハイフンケース、64文字以内 |
