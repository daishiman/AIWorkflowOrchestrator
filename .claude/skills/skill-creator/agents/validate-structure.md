## 2. プロフィール

### 2.1 背景

Continuous Deliveryのパイプライン思考を応用し、自動化された検証を実行する。
quick_validate.mjsによる構造検証とチェックリストによる品質確認を行う。

### 2.2 目的

作成されたスキルが18-skills.md §8の品質基準を満たすことを検証する。

### 2.3 責務

| 責務         | 成果物       |
| ------------ | ------------ |
| 構造検証実行 | 検証レポート |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | quick_validate.mjsを実行         |
| 2        | エラーがあれば該当Taskに差し戻し |
| 3        | チェックリスト（§8.1）で品質確認 |
| 4        | 検証レポートを出力               |

### 4.2 チェックリスト

| 項目                        | 基準                     |
| --------------------------- | ------------------------ |
| SKILL.mdが500行以内か       | wc -l で確認             |
| frontmatterが有効か         | YAMLパーサーで検証       |
| nameがハイフンケースか      | 正規表現で検証           |
| descriptionが1024文字以内か | 文字数カウント           |
| Anchors/Triggerがあるか     | description内に存在確認  |
| 禁止ファイルがないか        | README.md等の不在確認    |
| references/がリンク済みか   | SKILL.mdから直リンク確認 |
| agents/\*.mdが5セクションか | テンプレート準拠確認     |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                     |
| ---------------- | ------------------------ |
| エラー時差し戻し | 該当Taskに修正を要求     |
| 完璧主義回避     | 重大な問題がなければ完了 |

---

## 5. インターフェース

### 5.1 入力

**注記**: generate-skill-mdとgenerate-agentsは**並列実行**される。両方の完了を待機してから本Taskを開始する。

| データ名     | 提供元            | 実行パターン | 検証ルール     | 欠損時処理     |
| ------------ | ----------------- | ------------ | -------------- | -------------- |
| SKILL.md     | generate-skill-md | **par**      | SKILL.mdが存在 | 前Taskに再要求 |
| agents/\*.md | generate-agents   | **par**      | ファイルが存在 | 前Taskに再要求 |
