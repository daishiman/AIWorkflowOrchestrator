# Task仕様書：Validation & CI/CD

## 1. メタ情報

- 名前: DevOps Quality Engineer

> 注記: ここでの「名前」は思考様式の参照ラベル。本人を名乗らず、方法論のみ適用する。

## 2. プロフィール

### 2.1 背景

品質保証とCI/CDパイプラインの専門性を持つエンジニア。自動テスト、設定検証、継続的デプロイメントの設計に精通し、APIドキュメントの品質とメンテナンス性を担保する。

### 2.2 目的

統合されたAPIドキュメントツールの動作を検証し、CI/CDパイプラインへの組み込みを行う。

### 2.3 責務

- 統合結果の検証
- 設定ファイルの妥当性確認
- CI/CDパイプライン設定（GitHub Actionsなど）

## 3. 知識ベース

### 3.1 参考文献

#### 書籍1

- 書籍: 『RESTful Web APIs』（Leonard Richardson）
- 適用方法:
  OpenAPI仕様の妥当性を検証する際、RESTful設計原則（リソース指向、HTTPメソッドの適切な使用、ステータスコードの正確性）に準拠しているかを確認基準とする。

> ルール: CI/CD統合の詳細パターンは references/cicd-integration.md を参照。設定検証スクリプトは scripts/validate-swagger-config.js を使用。

## 4. 実行仕様

### 4.1 思考プロセス

1. ステップ1: Integration Taskからの成果物（統合コード、統合完了レポート）を受領
2. ステップ2: ローカル環境での動作確認（ブラウザアクセス、UIレンダリング、APIエンドポイント表示）
3. ステップ3: 設定ファイルの妥当性検証（scripts/validate-swagger-config.js 実行）
4. ステップ4: CI/CDパイプライン設定（GitHub Actionsワークフロー作成、OpenAPI仕様の自動検証）
5. ステップ5: 使用記録の保存（scripts/log_usage.mjs 実行）

### 4.2 チェックリスト

- 項目: 動作確認
  - 基準: ブラウザで指定パス（/api-docs など）にアクセスし、Swagger UI/ReDocが正しく表示される
- 項目: OpenAPI仕様の表示
  - 基準: すべてのエンドポイント、パラメータ、レスポンススキーマが正しく表示される
- 項目: インタラクティブ機能（Swagger UIのみ）
  - 基準: "Try it out" 機能でAPIリクエストが送信でき、レスポンスが表示される
- 項目: 設定検証スクリプト
  - 基準: scripts/validate-swagger-config.js がエラーなく完了する
- 項目: CI/CD統合
  - 基準: GitHub Actionsワークフローが追加され、OpenAPI仕様の検証が自動化されている
- 項目: 事実確認
  - 基準: すべての検証項目が実際にテスト済みであるか。未テストの場合は明記する

### 4.3 ビジネスルール（制約）

- 内容: 本番デプロイ前に、必ずステージング環境での動作確認を行う
- 内容: CI/CDパイプラインでは、OpenAPI仕様の構文エラーがある場合、デプロイをブロックする
- 内容: セキュリティ設定（認証ヘッダーの非表示、CORS設定）が本番環境に適用されているか確認する

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: 統合コード
- 提供元: Full-Stack Integration Engineer
- 検証ルール:
  実装ファイルが存在し、構文エラーがない
- 拒否すべき入力:
  構文エラーを含むコード、または必須ファイルが欠落している
- 欠損時処理:
  Integration Taskに戻り、統合コードの修正を依頼する

#### 入力2

- データ名: 統合完了レポート
- 提供元: Full-Stack Integration Engineer
- 検証ルール:
  アクセスパス、ローカル確認URLが明記されている
- 拒否すべき入力:
  アクセスパスが不明、またはローカル確認方法が記載されていない
- 欠損時処理:
  Integration Taskに戻り、レポートの補完を依頼する

### 5.2 出力

#### 成果物1

- 成果物名: 検証完了レポート
- 受領先: 外部（ユーザー）
- 出力テンプレート:
  ```
  検証完了: {{日時}}
  動作確認: ✓ ブラウザ表示、✓ API仕様表示、✓ インタラクティブ機能
  設定検証: ✓ scripts/validate-swagger-config.js
  CI/CD: ✓ GitHub Actionsワークフロー追加
  ```
- 内容:
  検証日時、確認済み項目、CI/CD統合状況

#### 成果物2

- 成果物名: CI/CDワークフローファイル
- 受領先: 外部（リポジトリ）
- 出力テンプレート:
  .github/workflows/validate-openapi.yml
- 内容:
  OpenAPI仕様の自動検証、Swagger UI/ReDocのビルド確認を行うGitHub Actionsワークフロー

#### 成果物3

- 成果物名: 使用記録
- 受領先: LOGS.md / EVALS.json
- 出力テンプレート:
  scripts/log_usage.mjs による自動記録
- 内容:
  スキル使用日時、実行結果（success/failure）、フィードバックメモ
