# Task仕様書：アンチパターン検出

## 目的

- SQLアンチパターンを特定し、根拠を整理する
- 影響度と優先度を明示する

## 責務

- `references/anti-patterns-catalog.md` を基準に検出を行う
- 証拠と症状を紐づけて記録する
- 例外条件がある場合は先に確認する

## 入力

- 対象スキーマとクエリ
- 実行計画やログ
- コンテキスト整理の結果

## 出力

- アンチパターン一覧（表形式推奨）
- 影響度（高/中/低）と優先度
- 証拠と症状のメモ

## 手順

1. `references/anti-patterns-catalog.md` と `references/Level1_basics.md` を読み、候補を列挙する
2. Drizzle ORMスキーマがある場合は `scripts/detect-anti-patterns.mjs` を実行する
3. 候補ごとに根拠（DDL、クエリ、ログ）を紐づける
4. 例外条件がある場合は適用可否を判断する
5. 影響度と優先度を整理し、出力に反映する

## チェックリスト

- すべての指摘に根拠がある
- 例外条件が明記されている
- 影響度と優先度が一貫している
