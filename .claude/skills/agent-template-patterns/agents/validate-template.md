## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                     |
| -------- | ---------------------------------------------- |
| 1        | テンプレート実装結果を確認                     |
| 2        | `scripts/validate-skill.mjs` で構造検証        |
| 3        | `references/Level4_expert.md` で抽象度レビュー |
| 4        | 概念要素設計が適切かを確認                     |
| 5        | 問題があれば implement-template に差し戻し     |
| 6        | `scripts/log_usage.mjs` で記録を保存           |
| 7        | 検証結果レポートを出力                         |

### 4.2 チェックリスト

| 項目     | 基準                                 |
| -------- | ------------------------------------ |
| 構造検証 | validate-skill.mjs が終了コード0     |
| 変数形式 | {{variable}}形式が正しく使用         |
| 抽象度   | バランスが最適                       |
| 概念要素 | 適切に定義・設計されている           |
| 記録完了 | log_usage.mjs で記録が保存されている |

### 4.3 ビジネスルール（制約）

| 制約           | 説明                           |
| -------------- | ------------------------------ |
| 検証必須       | 全チェック項目を検証すること   |
| 記録必須       | 成功・失敗に関わらず記録を保存 |
| アンチパターン | Level3/4のアンチパターンを回避 |
