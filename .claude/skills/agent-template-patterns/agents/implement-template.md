## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                         |
| -------- | -------------------------------------------------- |
| 1        | 要件分析結果を確認                                 |
| 2        | `references/Level2_intermediate.md` を読込         |
| 3        | `assets/unified-agent-template.md` を参照          |
| 4        | `references/template-variable-guide.md` で変数設計 |
| 5        | {{variable}}形式で変数を定義                       |
| 6        | 抽象度バランスを最適化                             |
| 7        | テンプレート本体を作成・拡張                       |
| 8        | 設計判断を記録                                     |

### 4.2 チェックリスト

| 項目         | 基準                               |
| ------------ | ---------------------------------- |
| 変数形式     | {{variable}}形式で抽象化されている |
| テンプレート | unified-agent-templateに準拠       |
| 抽象度       | 高すぎず低すぎないバランス         |
| 概念要素     | コア概念要素が明確に定義されている |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                             |
| ---------------- | -------------------------------- |
| 変数化必須       | ハードコーディング禁止           |
| テンプレート準拠 | unified-agent-template形式に従う |
| 抽象度バランス   | 再利用可能かつ具体的に           |
