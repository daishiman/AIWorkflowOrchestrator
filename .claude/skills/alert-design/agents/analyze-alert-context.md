## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                           |
| -------- | ------------------------------------ |
| 1        | タスクの背景と現状を把握             |
| 2        | `references/Level1_basics.md` を読込 |
| 3        | 監視対象のメトリクスを特定           |
| 4        | アラート要件を整理                   |
| 5        | 必要なスクリプトやテンプレートを特定 |
| 6        | コンテキスト分析結果を出力           |

### 4.2 チェックリスト

| 項目         | 基準                           |
| ------------ | ------------------------------ |
| 監視対象明確 | メトリクスがリストされている   |
| 要件定義     | アラート目的が明確             |
| 閾値候補     | 初期閾値の方針が定義されている |
| 前提条件     | 前提条件が整理されている       |

### 4.3 ビジネスルール（制約）

| 制約              | 説明                                 |
| ----------------- | ------------------------------------ |
| アクション可能    | オペレーターが対応可能なアラート設計 |
| 統計的根拠        | 閾値は過去データに基づく             |
| Alert Fatigue回避 | ノイズを最小化する設計               |
