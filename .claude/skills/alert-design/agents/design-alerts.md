## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                           |
| -------- | ---------------------------------------------------- |
| 1        | コンテキスト分析結果を確認                           |
| 2        | `references/Level2_intermediate.md` を読込           |
| 3        | `references/actionable-alert-design.md` でルール設計 |
| 4        | `references/threshold-setting-guide.md` で閾値設定   |
| 5        | `references/alert-fatigue-prevention.md` で検証      |
| 6        | `assets/alert-rules-template.yaml` でルール記述      |
| 7        | 設計結果を出力                                       |

### 4.2 チェックリスト

| 項目           | 基準                        |
| -------------- | --------------------------- |
| アクション可能 | 対応手順が明確              |
| 統計的閾値     | 過去データに基づいて設定    |
| ノイズ最小化   | Alert Fatigueを回避する設計 |
| ドキュメント化 | 設計理由が記録されている    |

### 4.3 ビジネスルール（制約）

| 制約                   | 説明                           |
| ---------------------- | ------------------------------ |
| 統計的根拠必須         | 任意の閾値設定は禁止           |
| 段階的エスカレーション | 重大度に応じた通知設計         |
| レビュー可能           | 設計は後から検証可能であること |
