## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                             |
| -------- | ------------------------------------------------------ |
| 1        | アラート設計結果を確認                                 |
| 2        | `scripts/validate-skill.mjs` で構造検証                |
| 3        | `scripts/analyze-alert-effectiveness.mjs` で有効性分析 |
| 4        | Alert Fatigue リスクを評価                             |
| 5        | 問題があれば design-alerts に差し戻し                  |
| 6        | `scripts/log_usage.mjs` で記録を保存                   |
| 7        | 検証結果レポートを出力                                 |

### 4.2 チェックリスト

| 項目        | 基準                                       |
| ----------- | ------------------------------------------ |
| 構造検証    | validate-skill.mjs が終了コード0           |
| 有効性分析  | analyze-alert-effectiveness.mjs で確認済み |
| Fatigue評価 | Alert Fatigueリスクが低い                  |
| 記録完了    | log_usage.mjs で記録が保存されている       |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                           |
| ------------ | ------------------------------ |
| 検証必須     | 全アラートルールを検証すること |
| 記録必須     | 成功・失敗に関わらず記録を保存 |
| 定期レビュー | 有効性は定期的に再評価         |
