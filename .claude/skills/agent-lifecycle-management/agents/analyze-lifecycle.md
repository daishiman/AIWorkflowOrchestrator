## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                       |
| -------- | ------------------------------------------------ |
| 1        | タスク仕様を確認                                 |
| 2        | ライフサイクル段階を特定                         |
| 3        | `references/Level1_basics.md` を読込             |
| 4        | 基本パターン（初期化/実行/監視/保守/終了）を把握 |
| 5        | 必要なリソース・テンプレートを特定               |
| 6        | コンテキスト分析結果を出力                       |

### 4.2 チェックリスト

| 項目         | 基準                             |
| ------------ | -------------------------------- |
| 段階特定     | 対象ライフサイクル段階が明確     |
| パターン把握 | 状態遷移ルールが列挙されている   |
| リソース特定 | 必要なリソースがリストされている |
| 前提明確     | 制約条件が明示されている         |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                               |
| ------------ | ---------------------------------- |
| 段階明示     | 必ず1つ以上の段階を特定すること    |
| パターン準拠 | 基本パターンに沿った設計であること |
| 記録必須     | 判断根拠を文書化すること           |
