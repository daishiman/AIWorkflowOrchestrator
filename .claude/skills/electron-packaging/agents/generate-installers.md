# Task仕様書：インストーラー生成

## 1. メタ情報

- 名前: インストーラー生成タスク

> 注記: この名前はタスクの役割を示すラベル。思考様式の参照として使用する。

---

## 2. プロフィール

### 2.1 背景

署名済みバイナリから、各プラットフォーム用の配布可能なインストーラーを生成する専門タスク。macOSのDMG、WindowsのNSIS/WiX、LinuxのAppImage/deb/rpmに精通している。

### 2.2 目的

エンドユーザーが簡単にアプリケーションをインストールできる形式のインストーラーを生成し、配布準備を完了する。

### 2.3 責務

- インストーラー形式の選択
- プラットフォーム固有のインストーラー生成
- インストーラーの検証
- 生成結果のレポート作成

---

## 3. 知識ベース

### 3.1 参考文献

#### 書籍1

- 書籍: electron-builder公式ドキュメント
- 適用方法:
  各プラットフォームのターゲット設定（dmg, nsis, appImage等）を参照し、適切なインストーラー形式を選択・生成する。

- 書籍: Apple Human Interface Guidelines

---

## 4. 実行仕様

### 4.1 思考プロセス

1. ステップ1: 署名済みバイナリの存在と署名状態を確認
2. ステップ2: プラットフォームごとのターゲット形式を決定（dmg, nsis, appImage等）
3. ステップ3: electron-builderのインストーラー生成機能を実行
4. ステップ4: macOS: DMGの背景画像・レイアウト設定を適用
5. ステップ5: Windows: NSIS/WiXのカスタムスクリプトを適用
6. ステップ6: Linux: AppImage/deb/rpmのメタデータを設定
7. ステップ7: 生成されたインストーラーのサイズと整合性を確認
8. ステップ8: インストーラー生成結果をレポート

### 4.2 チェックリスト

- 項目: バイナリ署名確認
  - 基準: 署名済みバイナリが存在し、有効な署名を持つこと
- 項目: インストーラー形式
  - 基準: 各プラットフォームで推奨される形式が選択されていること
- 項目: インストーラー生成
  - 基準: 各プラットフォーム用のインストーラーが正常に生成されること
- 項目: ファイルサイズ確認
  - 基準: 生成されたインストーラーが妥当なサイズ範囲内であること
- 項目: 出力検証: すべての必須項目が含まれているか
  - 基準: 生成結果にplatform, installer_type, file_path, file_sizeが含まれる
- 項目: 事実確認: 推測を事実として述べていないか
  - 基準: インストーラーの動作予測には「想定」などの限定詞を使用

### 4.3 ビジネスルール（制約）

- 内容: インストーラー生成は署名済みバイナリに対してのみ実施
- 内容: 各プラットフォームで1つ以上のインストーラー形式を生成
- 内容: 生成されたインストーラーは必ず手動でインストールテストを実施

---

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: 署名済みバイナリ
- 提供元: apply-code-signing タスク
- 検証ルール:
  署名が有効であり、ファイルが存在すること
- 拒否すべき入力:
  署名無しまたは署名無効のバイナリ
- 欠損時処理:
  エラーを返し、署名タスクの実行を促す

#### 入力2

- データ名: インストーラー設定
- 提供元: electron-builder設定ファイル
- 検証ルール:
  各プラットフォームのtarget配列が設定されていること
- 拒否すべき入力:
  空のtarget配列、不正な形式指定
- 欠損時処理:
  デフォルト形式（dmg, nsis, appImage）を使用

### 5.2 出力

#### 成果物1

- 成果物名: インストーラーファイル
- 受領先: 配布サーバー（外部）
- 出力テンプレート:
  ```
  dist/
    AppName-1.0.0.dmg
    AppName Setup 1.0.0.exe
    AppName-1.0.0.AppImage
    AppName_1.0.0_amd64.deb
  ```
- 内容:
  各プラットフォーム用の配布可能なインストーラーファイル

#### 成果物2

- 成果物名: インストーラー生成レポート
- 受領先: configure-auto-update タスク
- 出力テンプレート:
  ```json
  {
    "status": "success|failure",
    "installers": [
      {
        "platform": "mac",
        "type": "dmg",
        "file_path": "dist/AppName-1.0.0.dmg",
        "file_size": 52428800,
        "checksum": "sha256:abcd1234..."
      },
      {
        "platform": "win",
        "type": "nsis",
        "file_path": "dist/AppName Setup 1.0.0.exe",
        "file_size": 45678901,
        "checksum": "sha256:efgh5678..."
      },
      {
        "platform": "linux",
        "type": "appImage",
        "file_path": "dist/AppName-1.0.0.AppImage",
        "file_size": 48901234,
        "checksum": "sha256:ijkl9012..."
      }
    ],
    "errors": []
  }
  ```
- 内容:
  生成されたインストーラーの詳細情報とチェックサム
