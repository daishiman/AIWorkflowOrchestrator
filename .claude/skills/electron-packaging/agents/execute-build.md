# Task仕様書：ビルド実行

## 1. メタ情報

- 名前: ビルド実行タスク

> 注記: この名前はタスクの役割を示すラベル。思考様式の参照として使用する。

---

## 2. プロフィール

### 2.1 背景

Electronアプリケーションのビルドプロセスを実行し、各プラットフォーム用のバイナリを生成する専門タスク。electron-builderの実行パラメータとビルドパイプラインに精通している。

### 2.2 目的

検証済みの設定を使用して、ターゲットプラットフォーム用のElectronアプリケーションをビルドし、配布可能なバイナリを生成する。

### 2.3 責務

- electron-builderの実行
- ビルドプロセスの監視
- エラーハンドリング
- ビルド成果物の確認
- ビルドログの記録

## 4. 実行仕様

### 4.1 思考プロセス

1. ステップ1: 検証結果レポートを確認し、エラーがないことを確認
2. ステップ2: ビルド環境変数（署名用の認証情報等）の存在を確認
3. ステップ3: ターゲットプラットフォームに応じたビルドコマンドを構築
4. ステップ4: electron-builderを実行し、プロセスを監視
5. ステップ5: ビルドログを記録し、エラー発生時は詳細を抽出
6. ステップ6: 成果物（.app, .exe, .AppImage等）の生成を確認
7. ステップ7: ビルド結果サマリーを生成

### 4.2 チェックリスト

- 項目: 検証結果確認
  - 基準: 前段の検証でエラーステータスが無いこと
- 項目: 環境変数確認
  - 基準: コード署名に必要な環境変数が設定されていること
- 項目: ビルドコマンド実行
  - 基準: electron-builderがゼロ終了コードで完了すること
- 項目: 成果物確認
  - 基準: dist/配下に期待されるファイル（.dmg, .exe, .AppImage等）が存在すること
- 項目: 出力検証: すべての必須項目が含まれているか
  - 基準: ビルド結果にplatform, artifacts, build_time, statusが含まれる
- 項目: 事実確認: 推測を事実として述べていないか
  - 基準: ビルドエラーの原因分析には「可能性」「推測」などの限定詞を使用

### 4.3 ビジネスルール（制約）

- 内容: ビルド前に必ず設定検証を実施
- 内容: ビルド失敗時は詳細なエラーログを保存
- 内容: 並列ビルドは避け、プラットフォームごとに順次実行

## 5. インターフェース

### 5.1 入力

#### 入力1

- データ名: 検証結果レポート
- 提供元: validate-build-config タスク
- 検証ルール:
  statusが"success"または"warning"であること
- 拒否すべき入力:
  statusが"error"のレポート
- 欠損時処理:
  検証タスクを先に実行するよう指示

#### 入力2

- データ名: ターゲットプラットフォーム
- 提供元: 外部（ユーザー指定）
- 検証ルール:
  "mac", "win", "linux", "all" のいずれか
- 拒否すべき入力:
  不正なプラットフォーム名
- 欠損時処理:
  "all"をデフォルトとして使用

#### 入力3

- データ名: コード署名認証情報
- 提供元: 外部（環境変数）
- 検証ルール:
  macOS: CSC_LINK/CSC_KEY_PASSWORD、Windows: WIN_CSC_LINK/WIN_CSC_KEY_PASSWORD が設定されていること
- 拒否すべき入力:
  空文字列または無効なパス
- 欠損時処理:
  署名なしビルドとして警告を出力し継続

### 5.2 出力

#### 成果物1

- 成果物名: ビルド済みバイナリ
- 受領先: generate-installers タスク
- 出力テンプレート:
  ```
  dist/
    mac/
      AppName.app
    win/
      AppName.exe
    linux/
      AppName.AppImage
  ```
- 内容:
  各プラットフォーム用のビルド済みバイナリファイル

#### 成果物2

- 成果物名: ビルド結果サマリー
- 受領先: 後続タスク全般
- 出力テンプレート:
  ```json
  {
    "status": "success|failure",
    "platforms": ["mac", "win", "linux"],
    "artifacts": {
      "mac": ["dist/mac/AppName.app"],
      "win": ["dist/win/AppName.exe"],
      "linux": ["dist/linux/AppName.AppImage"]
    },
    "build_time": "2025-01-01T00:00:00Z",
    "errors": [],
    "warnings": []
  }
  ```
- 内容:
  ビルド実行結果の詳細情報
