# 18-skills.md仕様サマリー

> 完全な仕様は `docs/00-requirements/18-skills.md` を参照してください。

## 概要

Skillは、Claude の能力を拡張するモジュール式の自己完結型パッケージ。特定ドメインの専門知識、ワークフロー、ツール統合を提供する「オンボーディングガイド」として機能し、汎用エージェントを専門エージェントに変換します。

## コア原則（§2）

### 2.1 簡潔さが鍵

- Claude既知の情報は省略
- 冗長な説明より簡潔な例を優先
- 「Claudeは本当にこの説明を必要としているか？」と問いかける

### 2.2 書籍参照によるコンテキスト圧縮

- 書籍名は「圧縮された知識体系への参照」として機能
- 1スキル1-3冊の著名書籍を選択
- 適用コンセプトを明示

### 2.3 適切な自由度の設定

| 自由度 | 使用場面                                         | 記述形式                                 |
| ------ | ------------------------------------------------ | ---------------------------------------- |
| 高     | 複数のアプローチが有効、判断がコンテキストに依存 | テキストベースの指示                     |
| 中     | 推奨パターンが存在、一定の変動は許容             | 擬似コードまたはパラメータ付きスクリプト |
| 低     | 操作が脆弱でエラーを起こしやすい、一貫性が重要   | 特定のスクリプト、少数のパラメータ       |

### 2.4 Progressive Disclosure（段階的開示）

| レベル | 読み込み対象                     | トークン目安       |
| ------ | -------------------------------- | ------------------ |
| 1      | メタデータ（name + description） | ~100語             |
| 2      | SKILL.md 本文                    | <5,000語           |
| 3      | バンドルリソース                 | 無制限（実行可能） |

## Skill構造仕様（§3）

### 3.1 標準フォルダ構造

```
skill-name/
├── SKILL.md              # 必須: メインファイル（500行以内推奨）
├── scripts/              # 任意: 実行可能コード（Python/Bash等）
│   └── log_usage.mjs     # 推奨: フィードバックループ用標準スクリプト
├── references/           # 任意: コンテキストに読み込む参照資料
└── assets/               # 任意: 出力で使用するファイル（テンプレート等）
```

**重要**: README.md, INSTALLATION_GUIDE.md等の補助ドキュメントは作成しない

### 3.2 SKILL.md YAML Frontmatter

```yaml
---
name: { { skill-name } }
description: |
  {{スキルの概要説明（2-3行）}}

  📖 参照書籍:
  - 『{{書籍名}}』（{{著者名}}）: {{適用コンセプト}}

  Use when {{英語での発動条件}}.
references:
  - book: "{{書籍名}}"
    author: "{{著者名}}"
    concepts:
      - "{{コンセプト1}}"
---
```

### 3.2.4 description フィールドの規則

| 規則                       | 説明                                                  |
| -------------------------- | ----------------------------------------------------- |
| 最大1024文字               | 簡潔かつ包括的に                                      |
| 角括弧禁止                 | `<` `>` は使用不可                                    |
| 「何を」と「いつ」を含める | スキルの機能と発動条件の両方を記述                    |
| 本文に「When to Use」不要  | 発動条件はdescriptionに書く（本文は発動後に読まれる） |
| 書籍参照を含める           | 📖 参照書籍セクションで知識体系を明示                 |

### 3.2.5 本文推奨セクション

| セクション           | 必須 | 説明                                   |
| -------------------- | ---- | -------------------------------------- |
| 概要                 | 必須 | 1-2文でスキルの目的を説明              |
| ワークフロー         | 推奨 | 複数ステップのプロセス（Phase ベース） |
| ベストプラクティス   | 必須 | すべきこと/避けるべきことのリスト      |
| 関連スキル           | 推奨 | 他スキルとの関係（フルパスで記述）     |
| コマンドリファレンス | 推奨 | スクリプト・リソースへのアクセス方法   |

**行数制約**: 500行以内。超過時は references/ に分離。

## フィードバックループ（§7）

### 7.3 log_usage.mjs

**引数**:

| 引数       | 必須 | 説明                       |
| ---------- | ---- | -------------------------- |
| `--result` | 必須 | `success` または `failure` |
| `--phase`  | 任意 | 実行したフェーズ名         |
| `--agent`  | 任意 | 実行したエージェント名     |
| `--notes`  | 任意 | 追加のフィードバックメモ   |

**使用形式**:

```bash
node .claude/skills/{{skill-name}}/scripts/log_usage.mjs \
  --result {{success|failure}} \
  --phase "{{phase-name}}" \
  --agent "{{agent-name}}"
```

## 品質基準（§8）

### 8.1 スキル作成時のチェックリスト

| チェック項目                                 | 検証方法                  |
| -------------------------------------------- | ------------------------- |
| SKILL.md が 500 行以内                       | `wc -l SKILL.md`          |
| YAML frontmatter が有効                      | YAMLパーサーで検証        |
| name がハイフンケース（最大64文字）          | 正規表現で検証            |
| description が 1024 文字以内                 | 文字数カウント            |
| 書籍参照が含まれている                       | references フィールド確認 |
| 不要な補助ドキュメントがない                 | README.md 等の不在確認    |
| references/ のファイルが SKILL.md からリンク | grep で検証               |

### 8.2 ベストプラクティス要約

| カテゴリ               | ベストプラクティス                                      |
| ---------------------- | ------------------------------------------------------- |
| 簡潔さ                 | 説明より例を優先、Claude が既に知っていることは書かない |
| 書籍参照               | 1-3冊の著名書籍で知識体系を圧縮参照                     |
| 自由度                 | タスクの脆弱性に応じて具体性を調整                      |
| Progressive Disclosure | SKILL.md を軽量に、詳細は references/ に                |
| 重複回避               | 情報は SKILL.md か references/ のどちらか一方のみ       |
| スクリプト             | 繰り返し書くコードはスクリプト化、必ずテスト            |
| 発動条件               | description に明確に記述（本文ではなく）                |
| 相対パス               | references/ へのリンクは相対パスで記述                  |
