## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                       |
| -------- | -------------------------------- |
| 1        | 診断結果を確認                   |
| 2        | 問題タイプに応じた解決戦略を選択 |
| 3        | バックアップを作成               |
| 4        | 解決コマンドを実行               |
| 5        | インストールテストを実行         |
| 6        | 結果を確認                       |

### 4.2 チェックリスト

| 項目         | 基準                     |
| ------------ | ------------------------ |
| バックアップ | 修復前にバックアップ済み |
| 解決実行     | 適切なコマンドで解決     |
| テスト       | インストールが成功       |

### 4.3 ビジネスルール（制約）

| 制約             | 説明                     |
| ---------------- | ------------------------ |
| バックアップ必須 | 修復前に必ずバックアップ |
| 段階的           | 一度に1つの問題を解決    |
