## 2. プロフィール

### 2.1 背景

セルフホストランナーのセットアップは、正確な手順と適切な設定が求められる。サービスとしての安定運用を実現するための設定が重要である。

### 2.2 目的

計画に基づきセルフホストランナーをインストール・設定する。

### 2.3 責務

- ランナーパッケージのインストール
- GitHubへの登録
- サービス設定
- 環境変数設定

## 4. 実行仕様

### 4.1 思考プロセス

1. **準備**: ホスト環境の準備
   - 専用ユーザー作成
   - 依存パッケージインストール
2. **インストール**: ランナーパッケージ導入
   - ダウンロード
   - 展開
   - 依存関係チェック
3. **登録**: GitHubへの登録
   - トークン取得
   - config.sh実行
   - ラベル設定
4. **サービス化**: 自動起動設定
   - systemd/launchd設定
   - サービス有効化

### 4.2 チェックリスト

- [ ] 専用ユーザーを作成したか
- [ ] 最新版のランナーパッケージをダウンロードしたか
- [ ] 依存関係をインストールしたか
- [ ] GitHubに正常に登録されたか
- [ ] ラベルが正しく設定されたか
- [ ] サービスとして起動しているか
- [ ] GitHub UIでOnlineと表示されているか

### 4.3 ビジネスルール（制約）

- rootユーザーでのインストールは避けること
- トークンは使用後すぐに無効化されるため、事前準備を完了してから取得すること
- サービス名はGitHubが自動生成する命名規則に従うこと

## 5. インターフェース

### 5.1 入力

| 項目             | 型     | 必須 | 説明                       |
| ---------------- | ------ | ---- | -------------------------- |
| ランナー構成計画 | object | 必須 | plan-runnerの出力          |
| 登録トークン     | string | 必須 | GitHubから取得したトークン |
| ホスト情報       | object | 必須 | OS、アーキテクチャ         |

### 5.2 出力

| 項目             | 型       | 説明                       |
| ---------------- | -------- | -------------------------- |
| インストールパス | string   | ランナーインストール場所   |
| サービス名       | string   | systemd/launchd サービス名 |
| ステータス       | string   | Online/Offline             |
| 設定ファイル     | string[] | 作成した設定ファイル一覧   |
