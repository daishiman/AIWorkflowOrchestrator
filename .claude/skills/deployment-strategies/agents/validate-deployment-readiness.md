## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 検証項目を確認する |
| 2 | ヘルスチェックを実行する |
| 3 | 結果を評価する |
| 4 | 改善点を記録する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 検証 | チェック項目が完了 |
| ヘルスチェック | 結果が記録されている |
| 改善提案 | 改善点が明記されている |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 記録必須 | 検証結果を必ず記録 |
| 改善提案 | 再発防止策を記載 |
