# チェックポイント設計

> **相対パス**: `references/checkpoint-design.md`
> **読込条件**: チェックポイント設計の詳細が必要な場合

---

## チェックポイントとは

セッション状態を保存し、後で復元可能にする仕組み。
セッション中断時の再開や、複雑な変更のロールバックを可能にする。

---

## チェックポイントの構成

```markdown
## セッションチェックポイント

### 基本情報

- 作成日時: 2026-01-02T10:30:00Z
- 目的: タスクXの実装中断

### 進行中タスク

- [ ] タスクA: 50%完了
- [ ] タスクB: 未着手

### コンテキスト要約

- 実装方針: YYYアプローチを採用
- 注意点: ZZZに注意が必要

### 重要ファイル

- src/main.ts: 主要な変更対象
- tests/main.test.ts: テストファイル

### 次のアクション

1. タスクAの残り部分を実装
2. テストを追加
```

---

## 作成タイミング

| タイミング         | 理由                       |
| ------------------ | -------------------------- |
| 複雑な変更の開始前 | ロールバック可能に         |
| 長時間作業の区切り | 中断時の再開を容易に       |
| 重要な意思決定後   | 決定の記録と復元           |
| セッション終了時   | 次回セッションへの引き継ぎ |

---

## 保存場所

```
.claude/
└── checkpoints/
    ├── checkpoint-2026-01-02-task-x.md
    └── checkpoint-2026-01-02-session-end.md
```

---

## 復元手順

1. チェックポイントファイルを読み込む
2. 重要ファイルを再度読み込む
3. TodoWriteでタスクリストを復元
4. コンテキスト要約を確認
