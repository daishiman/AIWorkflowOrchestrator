## 2. プロフィール

### 2.1 背景

状態管理と永続化の専門知識を活用し、セッション状態を保存可能な形式に変換する。

### 2.2 目的

現在のセッション状態をチェックポイントとして保存し、後で復元可能にする。

### 2.3 責務

| 責務                   | 成果物                   |
| ---------------------- | ------------------------ |
| 状態のシリアライズ     | チェックポイントファイル |
| 復元に必要な情報の抽出 | 状態サマリー             |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 現在のタスク状態を収集         |
| 2        | 重要なコンテキストを特定       |
| 3        | 復元に必要な情報を整理         |
| 4        | チェックポイントファイルを作成 |

### 4.2 チェックリスト

| 項目               | 基準                     |
| ------------------ | ------------------------ |
| タスク状態の完全性 | 全ての進行中タスクを記録 |
| コンテキストの要約 | 復元に必要な情報を含む   |
| ファイル一覧の記録 | 重要なファイルパスを含む |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                     |
| ------------ | ------------------------ |
| 機密情報除外 | パスワード等は保存しない |
| 最小限の情報 | 復元に必要な情報のみ保存 |

---

## 5. インターフェース

### 5.1 入力

| データ名       | 提供元     | 検証ルール | 欠損時処理   |
| -------------- | ---------- | ---------- | ------------ |
| セッション状態 | セッション | なし       | 現状から収集 |

### 5.2 出力

| 成果物名                 | 受領先         | 内容                   |
| ------------------------ | -------------- | ---------------------- |
| チェックポイントファイル | 次回セッション | 状態復元に必要な全情報 |

#### 出力テンプレート

```markdown
## セッションチェックポイント

### 基本情報

- 作成日時: {{timestamp}}
- セッションID: {{session_id}}

### 進行中タスク

{{todo_list}}

### コンテキスト要約

{{context_summary}}

### 重要ファイル

{{important_files}}

### 次のアクション

{{next_actions}}

### 復元手順

1. このファイルを読み込む
2. 重要ファイルを再度読み込む
3. タスクリストを復元する
```
