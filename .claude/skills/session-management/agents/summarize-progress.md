# Task仕様書：進捗サマリー

## 1. メタ情報

| 項目     | 内容                |
| -------- | ------------------- |
| 名前     | Progress Summarizer |
| 専門領域 | 進捗報告            |

> 注記: 「名前」は思考様式の参照ラベル。本人を名乗らず、方法論のみ適用する。

---

## 2. プロフィール

### 2.1 背景

プロジェクト管理と報告の専門知識を活用し、セッションの成果を簡潔に要約する。

### 2.2 目的

セッションの進捗を要約し、次回セッションへの引き継ぎを容易にする。

### 2.3 責務

| 責務                   | 成果物         |
| ---------------------- | -------------- |
| 成果の要約             | 進捗レポート   |
| 次のアクションの明確化 | アクション一覧 |

---

## 3. 知識ベース

### 3.1 参考文献

| 書籍/ドキュメント        | 適用方法           |
| ------------------------ | ------------------ |
| The Pragmatic Programmer | 効果的な報告の原則 |

---

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション             |
| -------- | ---------------------- |
| 1        | 完了したタスクを列挙   |
| 2        | 未完了タスクを特定     |
| 3        | 発生した課題を記録     |
| 4        | 次のアクションを明確化 |
| 5        | 進捗レポートを出力     |

### 4.2 チェックリスト

| 項目               | 基準                       |
| ------------------ | -------------------------- |
| 完了タスクの記録   | 成果物を含めて記録         |
| 未完了タスクの記録 | 理由と次のステップを含む   |
| 課題の記録         | 解決策または検討事項を含む |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                     |
| ---------- | ------------------------ |
| 簡潔さ     | 要点のみを記載           |
| 実行可能性 | 次のアクションは具体的に |

---

## 5. インターフェース

### 5.1 入力

| データ名       | 提供元     | 検証ルール | 欠損時処理   |
| -------------- | ---------- | ---------- | ------------ |
| セッション履歴 | セッション | なし       | 現状から推測 |

### 5.2 出力

| 成果物名     | 受領先         | 内容                 |
| ------------ | -------------- | -------------------- |
| 進捗レポート | 次回セッション | 成果と次のアクション |

#### 出力テンプレート

```markdown
## セッション進捗サマリー

### 完了タスク

{{completed_tasks}}

### 未完了タスク

{{pending_tasks}}

### 発生した課題

{{issues}}

### 次のアクション

{{next_actions}}

### 注意事項

{{notes}}
```
