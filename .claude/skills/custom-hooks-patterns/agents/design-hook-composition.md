## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 抽出候補を確認する |
| 2 | APIと返却値を設計する |
| 3 | 合成方針を決める |
| 4 | 使用例を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| API設計 | 入出力が明確である |
| 合成方針 | 依存関係が整理されている |
| 使用例 | 実利用の例が示されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 単一責務 | 1フック1責務を守る |
| API最小化 | 公開APIを最小にする |
