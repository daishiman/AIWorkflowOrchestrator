# 仕様検証ワークフロー

> 仕様: 仕様の整合性と品質を検証

## 概要

references/内の仕様ファイルが正しく管理されているかを検証するワークフロー。

## 前提条件

- 検証対象のスキル構造が存在

## 手順

### Step 1: 構造検証

```bash
node scripts/validate-structure.mjs
```

**チェック項目**:

| 項目                  | 基準                            | 優先度 |
| --------------------- | ------------------------------- | ------ |
| 必須ディレクトリ      | references/, scripts/, indexes/ | 必須   |
| 必須ファイル          | SKILL.md                        | 必須   |
| references/ファイル数 | 20以上                          | 推奨   |
| インデックスファイル  | topic-map.md, keywords.json     | 推奨   |
| ファイルサイズ        | 500行以下                       | 推奨   |
| 命名規則              | kebab-case、番号なし            | 推奨   |

### Step 2: インデックス整合性

```bash
# インデックスを再生成して差分確認
node scripts/generate-index.mjs

# 生成されたキーワード数を確認
cat indexes/keywords.json | grep totalKeywords
```

### Step 3: 検索機能テスト

```bash
# 主要キーワードで検索テスト
node scripts/search-spec.mjs "認証"
node scripts/search-spec.mjs "API"
node scripts/search-spec.mjs "Turso"
```

### Step 4: ファイル統計確認

```bash
node scripts/list-specs.mjs --stats
```

**確認項目**:

| 項目             | 期待値                 |
| ---------------- | ---------------------- |
| 総ファイル数     | 20以上                 |
| 総行数           | 記録用                 |
| 500行超ファイル  | なし（または分割予定） |
| 番号付きファイル | なし                   |

### Step 5: 記述スタイル確認

各ファイルが以下のガイドラインに従っているか確認:

| チェック項目       | 基準                     |
| ------------------ | ------------------------ |
| 文章による説明     | ソースコードより文章優先 |
| 表・箇条書きの活用 | 構造化された情報         |
| 理解しやすい粒度   | 誰でも理解可能           |
| 設計意図の明記     | なぜそうするかが明確     |

## 出力

検証結果のサマリー:

| 項目         | 状態  |
| ------------ | ----- |
| 構造         | ✅/❌ |
| インデックス | ✅/❌ |
| 検索機能     | ✅/❌ |
| 命名規則     | ✅/❌ |
| 記述スタイル | ✅/❌ |

## 検証基準

| 項目                  | 基準       | 優先度 |
| --------------------- | ---------- | ------ |
| 必須ディレクトリ      | 全て存在   | 必須   |
| references/ファイル数 | 20以上     | 推奨   |
| インデックス          | 生成可能   | 必須   |
| キーワード数          | 300以上    | 推奨   |
| 検索応答              | エラーなし | 必須   |
| kebab-case命名        | 全ファイル | 推奨   |
| 500行以下             | 全ファイル | 推奨   |

## 問題発生時の対応

### インデックスエラー

```bash
# インデックスを強制再生成
rm -rf indexes/*
node scripts/generate-index.mjs
```

### 検索エラー

```bash
# スクリプトの動作確認
node scripts/search-spec.mjs --help
```

### ファイルサイズ超過

```bash
# 分割スクリプトで対応
node scripts/split-reference.mjs
```

## 注意事項

- 定期的な検証を推奨（週1回程度）
- 大規模更新後は必ず実行
- エラー時はログを確認
