# Sprint Planning Skill - Usage Logs

## 概要

このファイルはスプリント計画スキルの使用履歴とフィードバックを記録します。
`scripts/log_usage.mjs` により自動的に更新されます。

## ログフォーマット

各エントリは以下の形式で記録されます：

```
### [YYYY-MM-DD HH:MM:SS] - [SUCCESS/FAILURE]

- **Phase**: フェーズ名
- **Agent**: エージェント名（該当する場合）
- **Duration**: 実行時間（分）
- **Notes**: 追加メモ・フィードバック
```
