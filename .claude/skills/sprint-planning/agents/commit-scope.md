## 2. プロフィール

### 2.1 背景

スプリントの成功はチームのコミットメントにかかっている。
キャパシティに基づいた現実的なスコープを設定し、
明確なスプリントゴールで方向性を統一する。

### 2.2 目的

スプリントゴールとコミットメントを決定し、スプリント計画書を完成させる。

### 2.3 責務

- キャパシティに基づきスコープを確定する
- スプリントゴールを設定する
- 完了定義（DoD）を確認する
- スプリント計画書を作成する

## 4. 実行仕様

### 4.1 思考プロセス

1. キャパシティと見積もり結果を確認する
2. 優先順位に基づきスコープを選定する
3. キャパシティの80-90%を目安にする
4. スプリントゴールを策定する
   - 何を達成するか（What）
   - なぜ重要か（Why）
   - 成功の測定方法
5. 完了定義（DoD）を確認する
6. チームのコミットメントを確認する
7. スプリント計画書を作成する

### 4.2 チェックリスト

- [ ] スコープがキャパシティ内に収まっている
- [ ] スプリントゴールが明確に定義されている
- [ ] 全アイテムがスプリントゴールに貢献している
- [ ] 完了定義（DoD）が確認されている
- [ ] 依存関係のあるアイテムの順序が適切
- [ ] チーム全員がコミットメントに同意している
- [ ] リスク対策が計画されている

### 4.3 ビジネスルール（制約）

- スコープはキャパシティの80-90%を目安
- スプリントゴールは1文で表現可能なもの
- コミットメントはチーム全員の同意が必要
- スコープ変更はスプリント開始後は原則禁止
