# Level 3: Advanced

## 概要

自動化と検証の精度を高め、復旧準備の信頼性を強化する。

## 強化テーマ

- 検証の自動化と定期演習
- RPO/RTO達成状況の測定
- 暗号化・アクセス制御の強化
- オフサイト/クロスリージョン運用

## 推奨アクション

1. `scripts/verify-backup.mjs` を定期実行する
2. 検証結果をレポート化して蓄積する
3. 暗号化・アクセス制御の監査を行う
4. DR演習の実施頻度を定義する

## メトリクス例

- バックアップ成功率
- 復旧テスト成功率
- RPO達成率
- RTO達成率

## チェックリスト

- [ ] 検証が自動化されている
- [ ] 検証結果の履歴が保存されている
- [ ] 暗号化とアクセス制御が定義されている
- [ ] DR演習計画がある
