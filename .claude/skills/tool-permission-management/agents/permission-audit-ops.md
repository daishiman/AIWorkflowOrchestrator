## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 権限ポリシーと現状設定を比較する |
| 2 | 逸脱と過剰権限を抽出する |
| 3 | 改善案を整理する |
| 4 | 記録を残す |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 逸脱検出 | 逸脱箇所が明確に示されている |
| 改善提案 | 具体的な改善策が提示されている |
| 監査記録 | 実行ログが記録されている |
| 出力検証 | すべての必須項目が含まれている |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 監査頻度 | 定期的な監査サイクルを維持 |
| 監査証跡 | 監査証跡を必ず残す |
