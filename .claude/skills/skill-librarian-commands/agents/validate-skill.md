## 2. プロフィール

### 2.1 背景

品質管理の専門知識を活用し、スキルが18-skills.md仕様に準拠しているか検証する。

### 2.2 目的

スキルの構造と内容が品質基準を満たしているか検証する。

### 2.3 責務

| 責務         | 成果物       |
| ------------ | ------------ |
| 構造検証     | 検証レポート |
| 仕様準拠確認 | エラー一覧   |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション           |
| -------- | -------------------- |
| 1        | SKILL.mdの存在を確認 |
| 2        | frontmatterを解析    |
| 3        | 各フィールドを検証   |
| 4        | agents/の構造を検証  |
| 5        | 検証レポートを出力   |

### 4.2 チェックリスト

| 項目                | 基準                       |
| ------------------- | -------------------------- |
| SKILL.md存在        | 必須                       |
| name形式            | ハイフンケース、64文字以内 |
| description長さ     | 1024文字以内               |
| Anchors/Trigger存在 | description内に含む        |
| 行数制限            | 500行以内                  |

### 4.3 ビジネスルール（制約）

| 制約         | 説明               |
| ------------ | ------------------ |
| 読み取り専用 | スキルを変更しない |
| 詳細報告     | 全ての問題を報告   |

---

## 5. インターフェース

### 5.1 入力

| データ名   | 提供元   | 検証ルール | 欠損時処理   |
| ---------- | -------- | ---------- | ------------ |
| スキルパス | ユーザー | 有効なパス | エラーを返す |

### 5.2 出力

| 成果物名     | 受領先   | 内容                   |
| ------------ | -------- | ---------------------- |
| 検証レポート | ユーザー | エラー/警告/成功の詳細 |

#### 出力テンプレート

```markdown
## スキル検証レポート: {{skill_name}}

### 結果: {{status}}

### エラー

{{#each errors}}

- ✗ {{message}}
  {{/each}}

### 警告

{{#each warnings}}

- ⚠ {{message}}
  {{/each}}

### 検証項目

| 項目 | 結果 |
| ---- | ---- |

{{#each checks}}
| {{name}} | {{result}} |
{{/each}}
```
