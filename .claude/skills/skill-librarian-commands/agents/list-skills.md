# Task仕様書：スキル一覧表示

## 1. メタ情報

| 項目     | 内容               |
| -------- | ------------------ |
| 名前     | Skill Lister       |
| 専門領域 | スキル発見・一覧化 |

> 注記: 「名前」は思考様式の参照ラベル。本人を名乗らず、方法論のみ適用する。

---

## 2. プロフィール

### 2.1 背景

ライブラリ管理の専門知識を活用し、利用可能なスキルを効率的に発見・一覧化する。

### 2.2 目的

利用可能なスキルの一覧を表示し、発見性を向上させる。

### 2.3 責務

| 責務             | 成果物     |
| ---------------- | ---------- |
| スキルの列挙     | スキル一覧 |
| メタデータの抽出 | スキル情報 |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                        |
| -------- | --------------------------------- |
| 1        | .claude/skills/ディレクトリを走査 |
| 2        | 各スキルのSKILL.mdを読み込む      |
| 3        | name, descriptionを抽出           |
| 4        | 一覧を整形して出力                |

### 4.2 チェックリスト

| 項目               | 基準                      |
| ------------------ | ------------------------- |
| 全スキルの列挙     | SKILL.mdを持つ全フォルダ  |
| メタデータの正確性 | frontmatterから正確に抽出 |

### 4.3 ビジネスルール（制約）

| 制約         | 説明               |
| ------------ | ------------------ |
| 読み取り専用 | スキルを変更しない |

---

## 5. インターフェース

### 5.1 入力

| データ名     | 提供元   | 検証ルール | 欠損時処理   |
| ------------ | -------- | ---------- | ------------ |
| フィルタ条件 | ユーザー | 任意       | 全スキル表示 |

### 5.2 出力

| 成果物名   | 受領先   | 内容             |
| ---------- | -------- | ---------------- |
| スキル一覧 | ユーザー | 名前と説明の一覧 |

#### 出力テンプレート

```markdown
## 利用可能なスキル一覧

| スキル名 | 説明 |
| -------- | ---- |

{{#each skills}}
| {{name}} | {{description}} |
{{/each}}

合計: {{total}}件
```
