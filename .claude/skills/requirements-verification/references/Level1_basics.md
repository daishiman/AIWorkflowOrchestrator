# Level 1: 要件検証の基礎

## 目的

要件検証の基本観点を理解し、最低限の品質基準を満たす。

## 基本用語

- **検証 (Verification)**: 要件が正しく記述されているかを確認する
- **妥当性確認 (Validation)**: 要件がユーザーの意図に合っているかを確認する

## 主要な品質観点

1. **一貫性**: 要件同士が矛盾していない
2. **完全性**: 必要な要件が抜けていない
3. **実現可能性**: 技術/コスト/期間の制約内で実現可能
4. **検証可能性**: テストや測定で合否判定ができる

## 基本チェック

- 曖昧語（例: 速い、適切、など）がないか
- FR/NFR/制約が明示されているか
- 受け入れ基準があるか
- 要件IDで追跡可能か
