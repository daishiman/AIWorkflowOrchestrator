# 要件検証技法

## 一貫性チェック

- 用語集の有無を確認
- 同一概念の表現ゆれを抽出
- 条件式の矛盾（条件/結果の逆転）を検出

## 完全性チェック

- CRUD観点の網羅性
- 例外/エラー処理の網羅性
- 非機能要件の網羅性

## 検証可能性チェック

- 受け入れ基準（Given-When-Then）
- 数値化されているか
- 合否判定条件が明記されているか

## 実現可能性チェック

- 技術的制約との整合
- 期間/コストの制約との整合
- 外部依存の可用性確認

## 評価スコア例

- 明確性 = 1 - (曖昧語の行数 / 全行数)
- 完全性 = 受け入れ基準付き要件 / 全要件
- 検証可能性 = テスト可能な要件 / 全要件
