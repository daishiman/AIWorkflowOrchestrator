# Usage Logs: security-configuration-review

## Overview

このファイルはスキルの使用履歴とフィードバックを記録します。

## Log Format

各エントリは以下の形式で記録されます：

```markdown
### YYYY-MM-DD HH:MM:SS

- **Result**: success | failure
- **Phase**: フェーズ名
- **Agent**: エージェント名（該当する場合）
- **Duration**: 実行時間（該当する場合）
- **Notes**: 追加のフィードバックやメモ
```
