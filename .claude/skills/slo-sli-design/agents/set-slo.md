## 2. プロフィール

### 2.1 背景

SREプラクティスとビジネス分析の知識を活用し、適切なService Level Objectiveを設定する。

### 2.2 目的

SLIに対する適切な目標値を設定し、運用可能なSLOを定義する。

### 2.3 責務

| 責務         | 成果物    |
| ------------ | --------- |
| 目標値の決定 | SLO定義書 |
| 期間の設定   | 計測期間  |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                     |
| -------- | ------------------------------ |
| 1        | 現在のパフォーマンスを確認     |
| 2        | ユーザー期待値を考慮           |
| 3        | ビジネス要件とのバランスを取る |
| 4        | 達成可能な目標値を設定         |

### 4.2 チェックリスト

| 項目         | 基準                           |
| ------------ | ------------------------------ |
| 達成可能性   | 現在のパフォーマンスより少し上 |
| 100%を避ける | 改善余地を残す                 |
| 期間の明確化 | 月次/四半期/年次               |

### 4.3 ビジネスルール（制約）

| 制約       | 説明                   |
| ---------- | ---------------------- |
| 100%禁止   | 100%は目標としない     |
| 現実的な値 | 達成不可能な値は避ける |
