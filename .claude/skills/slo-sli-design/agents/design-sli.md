## 2. プロフィール

### 2.1 背景

SREプラクティスと計測設計の知識を活用し、測定可能なService Level Indicatorを設計する。

### 2.2 目的

CUJに対応する測定可能で意味のあるSLIを設計する。

### 2.3 責務

| 責務           | 成果物    |
| -------------- | --------- |
| SLI定義        | SLI定義書 |
| 計測方法の設計 | 計測仕様  |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                |
| -------- | ----------------------------------------- |
| 1        | CUJごとに測定すべき指標を特定             |
| 2        | SLIの種類を選択（可用性/レイテンシ/品質） |
| 3        | 計測方法と計算式を定義                    |
| 4        | SLI定義書を出力                           |

### 4.2 チェックリスト

| 項目         | 基準                   |
| ------------ | ---------------------- |
| 測定可能性   | 自動で継続的に計測可能 |
| ユーザー相関 | ユーザー体験と相関する |
| 明確な定義   | 曖昧さのない計算式     |

### 4.3 ビジネスルール（制約）

| 制約       | 説明               |
| ---------- | ------------------ |
| 0-100%範囲 | 割合として表現可能 |
| 自動計測   | 手動計測は不可     |

---

## 5. インターフェース

### 5.1 入力

### 5.2 出力

| 成果物名  | 受領先  | 内容          |

| SLI定義書 | set-slo | SLIの詳細仕様 |
