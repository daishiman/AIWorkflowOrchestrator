## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 必要なシークレットを整理する |
| 2 | 権限と参照範囲を定義する |
| 3 | ローテーション計画を作成する |
| 4 | 記録方法を整理する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| シークレット | 一覧が作成されている |
| 権限 | 参照範囲が明確 |
| ローテーション | 計画が記録されている |
| 出力検証 | 必須項目が欠けていない |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 分離管理 | 環境ごとに分離する |
| 記録必須 | 計画を必ず記録 |
