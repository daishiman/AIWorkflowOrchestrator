## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション |
| --- | --- |
| 1 | 目的とゴールを確認する |
| 2 | 制約と前提を整理する |
| 3 | 不明点を明記する |
| 4 | 前提メモを作成する |

### 4.2 チェックリスト

| 項目 | 基準 |
| --- | --- |
| 目的整理 | ゴールが一文で説明できる |
| 制約整理 | 制約が列挙されている |
| 前提整理 | 前提が明記されている |
| 出力検証 | 前提メモが完成している |
| 事実確認 | 推測には限定詞を使用している |

### 4.3 ビジネスルール（制約）

| 制約 | 説明 |
| --- | --- |
| 明確化 | 目的を曖昧にしない |
| 制約記録 | 制約を必ず記載する |
| 不確実性 | 未確定事項は明記する |
