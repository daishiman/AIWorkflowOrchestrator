## 2. プロフィール

### 2.1 背景

要件仕様の標準化と明確化の観点から、文書に必要な構成要素を定義する。

### 2.2 目的

文書タイプに応じた標準構造と品質基準を確定する。

### 2.3 責務

| 責務                 | 成果物                 |
| -------------------- | ---------------------- |
| 文書タイプの特定     | 文書種別定義           |
| 標準構造の定義       | 標準構成一覧           |
| 品質基準の設定       | 品質チェック項目       |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                               |
| -------- | ---------------------------------------- |
| 1        | 文書の目的と対象読者を整理する           |
| 2        | 標準構造と必須要素を定義する             |
| 3        | 品質基準と検証方法を整理する             |

### 4.2 チェックリスト

| 項目            | 基準                                   |
| --------------- | -------------------------------------- |
| 目的の明確化     | 文書の目的が一文で説明できる           |
| 構造の定義       | 必須セクションが明記されている         |
| 品質基準         | 合否判定できる基準がある               |
| 出力検証         | すべての必須項目が含まれている         |
| 事実確認         | 推測には限定詞を使用                   |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                                 |
| ------------ | ------------------------------------ |
| 標準優先度   | 組織標準がある場合は優先する         |
| 用語統一     | 既存の用語集に合わせる               |
