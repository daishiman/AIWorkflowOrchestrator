# ドキュメント組織化パターン

> **相対パス**: `references/organization-patterns.md`
> **読込条件**: 設計フェーズで参照

---

## トピックベース組織化

### 原則

| 原則       | 説明                   |
| ---------- | ---------------------- |
| 単一責任   | 1ファイル = 1トピック  |
| 凝集度優先 | 関連情報は近くに配置   |
| 疎結合     | ファイル間依存を最小化 |

### パターン

| パターン         | 適用場面           | 例                    |
| ---------------- | ------------------ | --------------------- |
| 機能別           | 機能ごとに分類     | auth/, payment/       |
| レイヤー別       | 技術層ごとに分類   | api/, domain/, infra/ |
| ライフサイクル別 | 開発段階ごとに分類 | design/, impl/, test/ |

---

## ファイル分割パターン

### 分割判断基準

| 指標         | 閾値   | アクション         |
| ------------ | ------ | ------------------ |
| ファイル行数 | >500行 | 分割必須           |
| トピック数   | >1     | トピックごとに分割 |
| 参照頻度差   | 大     | 頻度別に分割       |

### 分割戦略

| 戦略     | 説明                     | 使用場面            |
| -------- | ------------------------ | ------------------- |
| 水平分割 | 同レベルで複数ファイルに | 大きな章を分割      |
| 垂直分割 | 抽象度でレイヤー化       | 概要/詳細を分離     |
| 参照分離 | 参照資料を別ファイルに   | データ/定義を外部化 |

## 階層設計

### 推奨階層深度

| 深度 | 推奨度 | 理由                 |
| ---- | ------ | -------------------- |
| 1-2  | 最適   | 発見性が最も高い     |
| 3    | 許容   | 適切な分類があれば可 |
| 4    | 限界   | これ以上は発見性低下 |
| 5+   | 非推奨 | ナビゲーション困難   |

### 階層命名

| レベル | 命名方針             | 例             |
| ------ | -------------------- | -------------- |
| 1      | 広いカテゴリ         | docs/          |
| 2      | 具体的なドメイン     | docs/api/      |
| 3      | 細分化されたトピック | docs/api/auth/ |

---

## 命名規則

### ファイル命名

| 形式           | 例             | 使用場面       |
| -------------- | -------------- | -------------- |
| ハイフンケース | my-document.md | 一般ファイル   |
| スネークケース | my_document.md | データファイル |

### 禁止パターン

| パターン     | 問題点         |
| ------------ | -------------- |
| スペース含む | パス問題       |
| 日本語含む   | 互換性問題     |
| 特殊文字含む | エスケープ問題 |

## 参照関係

### 参照方向ルール

| 方向      | 可否 | 説明             |
| --------- | ---- | ---------------- |
| 詳細→抽象 | OK   | 自然な依存方向   |
| 抽象→詳細 | 注意 | 必要最小限に     |
| 循環参照  | NG   | 依存関係の複雑化 |

### リンク形式

| 形式     | 例                   | 使用場面   |
| -------- | -------------------- | ---------- |
| 相対パス | `[link](./file.md)`  | 同階層参照 |
| 上位参照 | `[link](../file.md)` | 親階層参照 |
