## 記録方法

### 自動記録（推奨）

スキル実行後に以下のコマンドを実行:

```bash
node .claude/skills/documentation-architecture/scripts/log_usage.mjs \
  --result success \
  --task "structure-analysis" \
  --phase "Phase 1" \
  --notes "Initial structure analysis completed"
```

### 手動記録

上記のログフォーマットに従って、このファイルに直接追記することも可能です。
