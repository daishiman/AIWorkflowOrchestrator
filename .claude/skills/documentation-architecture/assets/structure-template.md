# ドキュメント構造テンプレート

> **用途**: 新規ドキュメント構造設計時の雛形
> **相対パス**: `assets/structure-template.md`

---

## 標準ディレクトリ構造

```
{{project-name}}/
├── docs/
│   ├── overview.md              # プロジェクト概要（100行以内）
│   ├── getting-started.md       # 開始ガイド（200行以内）
│   ├── architecture/            # アーキテクチャドキュメント
│   │   ├── overview.md          # アーキテクチャ概要
│   │   ├── components.md        # コンポーネント説明
│   │   └── decisions/           # ADR (Architecture Decision Records)
│   │       └── adr-001.md
│   ├── guides/                  # ガイド・チュートリアル
│   │   ├── development.md       # 開発ガイド
│   │   └── deployment.md        # デプロイガイド
│   └── reference/               # リファレンス
│       ├── api.md               # API リファレンス
│       └── glossary.md          # 用語集
└── README.md                    # リポジトリ概要（簡潔に）
```

---

## ファイル命名規則

| 種類             | 形式            | 例                    |
| ---------------- | --------------- | --------------------- |
| 一般ドキュメント | kebab-case      | `getting-started.md`  |
| 概要ファイル     | overview        | `overview.md`         |
| ADR              | adr-NNN         | `adr-001.md`          |
| インデックス     | index または \_ | `index.md`, `_toc.md` |

---

## ファイルテンプレート

### 概要ドキュメント

```markdown
# {{タイトル}}

## 概要

{{1-2文で目的を説明}}

## 主要コンポーネント

### {{コンポーネント1}}

{{簡潔な説明}}

### {{コンポーネント2}}

{{簡潔な説明}}

## 関連リソース

- [{{関連1}}]({{パス}})
- [{{関連2}}]({{パス}})
```

### ガイドドキュメント

```markdown
# {{ガイドタイトル}}

## 前提条件

- {{前提1}}
- {{前提2}}

## 手順

### ステップ1: {{ステップ名}}

{{説明}}

### ステップ2: {{ステップ名}}

{{説明}}

## トラブルシューティング

### {{問題1}}

**症状**: {{症状}}
**解決策**: {{解決策}}

## 関連リソース

- [{{関連1}}]({{パス}})
```

### リファレンスドキュメント

```markdown
# {{リファレンスタイトル}}

## 目次

1. [{{セクション1}}](#{{アンカー1}})
2. [{{セクション2}}](#{{アンカー2}})

## {{セクション1}}

| 項目     | 説明     | 例     |
| -------- | -------- | ------ |
| {{項目}} | {{説明}} | {{例}} |

## {{セクション2}}

{{内容}}
```

## 構造設計チェックリスト

| 項目                     | 確認 |
| ------------------------ | ---- |
| 各ファイルが500行以下    | [ ]  |
| 階層深度が4層以下        | [ ]  |
| 命名規則が統一されている | [ ]  |
| 1ファイル1トピック       | [ ]  |
| 相互参照が有効           | [ ]  |
| 循環参照がない           | [ ]  |
| 目次/ナビゲーションあり  | [ ]  |
