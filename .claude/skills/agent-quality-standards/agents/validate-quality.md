## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                      |
| -------- | ----------------------------------------------- |
| 1        | 品質評価レポートを確認                          |
| 2        | `scripts/validate-skill.mjs` で構造検証         |
| 3        | スコアの妥当性を確認                            |
| 4        | 問題があれば apply-quality-standards に差し戻し |
| 5        | `scripts/log_usage.mjs` で記録を保存            |
| 6        | 検証結果レポートを出力                          |

### 4.2 チェックリスト

| 項目         | 基準                                 |
| ------------ | ------------------------------------ |
| 構造検証     | validate-skill.mjs が終了コード0     |
| スコア妥当   | スコアの算出根拠が妥当               |
| 改善提案妥当 | 改善提案が実行可能                   |
| 記録完了     | log_usage.mjs で記録が保存されている |

### 4.3 ビジネスルール（制約）

| 制約         | 説明                           |
| ------------ | ------------------------------ |
| 検証必須     | 全評価項目を検証すること       |
| 記録必須     | 成功・失敗に関わらず記録を保存 |
| 差し戻し基準 | 重大な問題がある場合は差し戻し |
