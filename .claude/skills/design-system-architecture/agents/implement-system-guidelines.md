## 2. プロフィール

### 2.1 背景

規約と同期方針を明確化すると、運用のばらつきを防げる。

### 2.2 目的

命名規約と同期ルールを整理し、運用方針を確定する。

### 2.3 責務

| 責務 | 成果物 |

| 例外整理 | 例外ルール |
