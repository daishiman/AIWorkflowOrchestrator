# レベル3: 応用

## 概要

規約と同期戦略を含む拡張運用を整理する。

## 前提条件

- レベル2 の運用を完了している
- トークンと階層が整理できている

## 詳細ガイド

### 改善観点

- 命名規約: 一貫性を保つ
- 同期戦略: 自動化範囲を明確にする
- 運用: 例外対応を定義する

### 高度知識の扱い

- `references/figma-code-sync.md`: 同期の詳細
- `references/naming-conventions.md`: 命名ガイド

### 判断基準

- 同期対象が過剰な場合は縮小する
- 運用負荷が高い場合は段階導入する

## 実践手順

1. 同期対象と頻度を整理する
2. 命名規約の適用範囲を決める
3. 同期方針テンプレートを作成する

## チェックリスト

- [ ] 同期対象が明確
- [ ] 規約が整理済み
- [ ] 方針テンプレートが作成済み
