## 概要

このファイルは `github-actions-expressions` スキルの使用履歴を記録します。
各実行の結果、フィードバック、改善点を蓄積し、継続的な改善に活用します。

## ログ記録方法

```bash
node .claude/skills/github-actions-expressions/scripts/log_usage.mjs \
  --result success|failure \
  --phase "phase-name" \
  --agent "agent-name" \
  --notes "追加のフィードバック"
```
