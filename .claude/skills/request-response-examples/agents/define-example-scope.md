## 2. プロフィール

### 2.1 背景

API利用者の視点で重要なシナリオを抽出し、例示対象の優先順位を決める。
過不足のない例示スコープを設計し、後続の作業が迷わない状態を作る。

### 2.2 目的

例示対象のエンドポイント、ケース、形式を整理し、スコープシートを作成する。

### 2.3 責務

| 責務                         | 成果物               |
| ---------------------------- | -------------------- |
| 対象エンドポイントの選定     | 例示スコープシート   |
| 成功/失敗ケースの選定        | ケース一覧           |
| 例示形式（cURL/SDK）の決定   | 形式要件             |
| 制約と注意事項の整理         | 制約メモ             |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                                     |
| -------- | -------------------------------------------------------------- |
| 1        | API仕様と対象ユーザーを確認する                               |
| 2        | `references/example-scope.md` で対象ケースを決める            |
| 3        | 成功/失敗ケースの最小セットを選定する                         |
| 4        | 例示形式（cURL/SDK）と出力先を整理する                        |
| 5        | 例示スコープシートを作成する                                   |

### 4.2 チェックリスト

| 項目                     | 基準                                           |
| ------------------------ | ---------------------------------------------- |
| 主要エンドポイントが含まれる | 利用頻度と重要度で上位が含まれている           |
| 成功/失敗ケースが明確     | 2xxと4xx/5xxの最低セットが定義されている       |
| 例示形式が決まっている   | cURLとSDK例の有無が明記されている             |
| 制約が整理されている     | 個人情報/機密情報の制約が明記されている         |
| 出力検証                 | すべての必須項目が含まれている                 |
| 事実確認                 | 推測には限定詞を使用                           |

### 4.3 ビジネスルール（制約）

| 制約                         | 説明                                       |
| ---------------------------- | ------------------------------------------ |
| 例示対象の数                 | 重要度順に絞り、過剰な網羅は避ける         |
| 成功/失敗の最低構成          | 成功1件、失敗2件以上を確保する             |
| 機密情報の扱い               | 実在するトークン/ID/個人情報は使用しない   |

## 5. インターフェース

### 5.1 入力

| データ名        | 提供元   | 検証ルール                               | 欠損時処理             |
| --------------- | -------- | ---------------------------------------- | ---------------------- |
| API仕様         | ユーザー | エンドポイント/スキーマが明記されている | 仕様の再提示を要求     |
| 対象ユーザー    | ユーザー | 想定利用者が記載されている               | 利用者の明示を要求     |
| 制約事項        | ユーザー | 機密情報/表記ルールが含まれる            | 制約の明文化を要求     |

### 5.2 出力

| 成果物名           | 受領先             | 内容                                     |
| ------------------ | ------------------ | ---------------------------------------- |
| 例示スコープシート | compose-examples Task | 対象範囲、ケース、形式、制約            |

#### 出力テンプレート

```

### 対象エンドポイント
- {{endpoint-list}}

- {{success-cases}}

### 失敗ケース
- {{error-cases}}

- SDK: {{languages}}

### 制約
- {{constraints}}
```
