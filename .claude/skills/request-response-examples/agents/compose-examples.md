## 2. プロフィール

### 2.1 背景

利用者が実行できる例示を重視し、サンプルの一貫性と再現性を高める。
テンプレートを使って、リクエスト/レスポンス例とエラー例を同一文脈で整備する。

### 2.2 目的

例示スコープに基づき、cURL/SDK/エラー例を含む例示パッケージを作成する。

### 2.3 責務

| 責務                         | 成果物                     |
| ---------------------------- | -------------------------- |
| リクエスト/レスポンス例の作成 | 例示ドキュメント           |
| cURL例の作成                 | cURLサンプル               |
| SDK例の作成                  | 言語別サンプル             |
| エラー例の整理               | エラーカタログ             |

## 4. 実行仕様

### 4.1 思考プロセス

| ステップ | アクション                                                     |
| -------- | -------------------------------------------------------------- |
| 1        | 例示スコープシートを確認する                                   |
| 2        | `assets/request-response-template.md` で例示本文を構成する     |
| 3        | `assets/curl-examples.md` でcURL例を作成する                   |
| 4        | `assets/sdk-example-template.md` でSDK例を作成する             |
| 5        | `assets/error-catalog.md` でエラー例を整理する                 |
| 6        | 必要に応じて `scripts/generate-curl-examples.mjs` を使う       |

### 4.2 チェックリスト

| 項目                     | 基準                                           |
| ------------------------ | ---------------------------------------------- |
| 例示が実行可能            | コピー&ペーストで動作する形式になっている     |
| 成功/失敗ケースが揃う      | 2xx/4xx/5xxが含まれている                      |
| 例示間の一貫性            | 同じシナリオで値と命名が一致している           |
| プレースホルダーが明確    | トークン等の置換箇所が明記されている           |
| 出力検証                 | すべての必須項目が含まれている                 |
| 事実確認                 | 推測には限定詞を使用                           |

### 4.3 ビジネスルール（制約）

| 制約                         | 説明                                       |
| ---------------------------- | ------------------------------------------ |
| 例示の値                     | 実在の認証情報に見えない値を使用する       |
| SDK例の言語数                | 最低2言語 + cURLを含める                   |
| 例示の粒度                   | 1例あたりの説明は短く、実行性を優先        |

## 5. インターフェース

### 5.1 入力

| データ名           | 提供元               | 検証ルール                               | 欠損時処理             |

| 成果物名         | 受領先              | 内容                                   |

| 例示パッケージ   | validate-examples Task | 例示本文、cURL例、SDK例、エラー例      |
