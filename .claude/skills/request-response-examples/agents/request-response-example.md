# Task: request-response-example

## 役割

基本的なAPIリクエスト・レスポンス例を作成するタスク。GET/POST/PUT/DELETEの基本的なHTTPメソッドに対する実用的なサンプルを生成する。

## 入力

- **API仕様**: エンドポイントURL、HTTPメソッド、パラメータ定義
- **対象リソース**: 作成する例の対象リソース（例: users, products）
- **形式要件**: 出力形式（cURL, HTTP, SDK言語指定）

## 出力

- リクエスト例（ヘッダー、パラメータ、ボディを含む）
- 成功レスポンス例（200, 201等）
- 基本的なエラーレスポンス例（400, 404等）

## 制約

- Level 1-2の知識範囲内で実装
- 複雑なネスト構造や認証フローは避ける
- 実行可能な例のみを提供（コピー&ペースト可能）

## 参照

- `references/Level1_basics.md`: 基本パターン
- `assets/curl-examples.md`: テンプレート
- `references/example-design-patterns.md`: 設計原則

## 実行フロー

1. API仕様から必要情報を抽出
2. `assets/curl-examples.md` テンプレートを参照
3. 基本的なリクエスト例を生成（GET, POST等）
4. 成功レスポンス（200/201）を記述
5. 基本エラーケース（400/404）を追加
6. 実行可能性を確認

## 品質基準

- [ ] リクエスト例が実行可能
- [ ] レスポンス例がAPI仕様と一致
- [ ] エラーケースが最低2つ含まれる
- [ ] パラメータの説明が明確
