# Task: error-response-doc

## 役割

エラーレスポンス形式を標準化し、包括的なエラーケースカタログをドキュメント化するタスク。RFC 7807 Problem Details等の標準に準拠した形式を採用する。

## 入力

- **API仕様**: エラーコード一覧、エラーメッセージ定義
- **エラーシナリオ**: 想定されるエラー状況のリスト
- **標準形式**: RFC 7807等の準拠標準

## 出力

- 統一されたエラーレスポンス形式定義
- エラーコード別の詳細ドキュメント
- エラーカタログ（全エラーケースの一覧）
- クライアント側での対処法ガイド

## 制約

- Level 2-3の知識範囲で実装
- RFC 7807準拠を推奨
- クライアント側エラー（4xx）とサーバー側エラー（5xx）を区別

## 参照

- `references/error-response-standards.md`: 標準形式
- `assets/error-catalog.md`: カタログテンプレート
- `references/Level2_intermediate.md`: 実務チェックリスト

## 実行フロー

1. `references/error-response-standards.md` で標準形式を確認
2. エラーコード一覧を収集（4xx, 5xx）
3. 各エラーの発生条件と対処法を定義
4. `assets/error-catalog.md` テンプレートを使用してカタログ作成
5. RFC 7807形式でレスポンス例を生成
6. クライアント側対処法を追記

## 品質基準

- [ ] RFC 7807形式に準拠
- [ ] 4xx/5xxエラーが網羅的
- [ ] 各エラーの対処法が明確
- [ ] 実際のレスポンス例を含む
- [ ] エラーカタログが完成
