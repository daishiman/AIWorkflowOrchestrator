# Task: advanced-scenario

## 役割

複雑なシナリオのリクエスト・レスポンス例を作成するタスク。認証フロー、ページネーション、WebSocket、ファイルアップロード等の高度なケースを扱う。

## 入力

- **シナリオタイプ**: OAuth2フロー、ページング、WebSocket、マルチパート等
- **API仕様**: 詳細な仕様とフロー図
- **セキュリティ要件**: 認証・認可の要件

## 出力

- シナリオ全体のフロー図
- 各ステップのリクエスト・レスポンス例
- 状態管理コード
- エラーケースと復旧処理
- セキュリティベストプラクティス

## 制約

- Level 3-4の知識範囲で実装
- セキュリティリスクに配慮
- 実装の複雑性を適切に説明
- 段階的な実装例を提供

## 参照

- `references/Level3_advanced.md`: 複雑なパターン
- `references/Level4_expert.md`: 専門的実装
- `references/example-design-patterns.md`: 設計原則

## 実行フロー

1. `references/Level3_advanced.md` または `Level4_expert.md` でパターンを確認
2. シナリオ全体のフローを図解
3. 各ステップの詳細を記述
   - OAuth2: 認可コード取得 → トークン交換 → API呼び出し
   - ページング: 初回リクエスト → 次ページ取得ループ
   - WebSocket: 接続確立 → メッセージ送受信 → 切断
4. エラーケース（タイムアウト、認証失敗等）を追加
5. セキュリティ考慮事項を明記
6. 完全な実装例を提供

## 品質基準

- [ ] フロー全体が明確に図解されている
- [ ] 各ステップのリクエスト・レスポンスが完全
- [ ] エラーケースと復旧処理を含む
- [ ] セキュリティベストプラクティスに準拠
- [ ] 実装が段階的に説明されている
